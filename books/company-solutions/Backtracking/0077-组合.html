题目与约束

给定两个整数 n 和 k，返回范围 [1, n] 中所有可能的 k 个数的组合。

你可以按任何顺序返回答案。

示例 1：

输入：n = 4, k = 2
输出：
[
  [2,4],
  [3,4],
  [2,3],
  [1,2],
  [1,3],
  [1,4],
]

示例 2：

输入：n = 1, k = 1
输出：[[1]]

提示：

  • 1 <= n <= 20
  • 1 <= k <= n

核心不变量

回溯路径 path 始终保持严格递增（每层只从 start 往 n 选），因此每个组合只被生成一次、不会重复；当 path.size() == k 时收集答案。

完整推导

思路推导

  1. 直觉与痛点（组合为什么不能暴力多层循环）

若用 k 层 for 循环枚举，k 是变量，无法静态写出固定层数。而组合的"选一个、再往后选、选够 k 个就停"本质是树形搜索，用回溯最自然。

  1. 破局思路（递增起点，逐步做选择）

维护一个 path 记录已选数字，参数 start 表示下一个可选的起点。每层从 start 到 n 枚举：

  • 选 i，path 加入 i；
  • 递归，起点变为 i + 1（保证后面都比 i 大，避免重复并保持递增）；
  • 回溯，把 i 弹出。

当 path.size() == k 时，把 path 的一个拷贝加入结果并返回。以 n=4,k=2 为例：先选 1，再从 2 开始依次选 2/3/4 得 [1,2][1,3][1,4]；回到选 2，再选 3/4 得 [2,3][2,4]；再选 3、4 得 [3,4]。

  1. 关键追问（如何剪枝？）

如果当前还需 need = k - path.size() 个数，那么 i 最多取到 n - need + 1：再往后取，剩余数字根本凑不满 k 个，白搜。把循环上界从 n 收紧到 n - need + 1 就是经典剪枝。

  1. 易错点提示
  • 递归起点必须是 i + 1，若用 i 会重复选同一个数。
  • 结果要存 path 的副本，否则后续回溯会改掉已收集的列表。
  • 剪枝边界要算对，+1 别漏。

Java 实现（回溯 + 剪枝）

import java.util.ArrayList;
import java.util.ArrayDeque;
import java.util.Deque;
import java.util.List;

class Solution {
    public List<List<Integer>> combine(int n, int k) {
        List<List<Integer>> res = new ArrayList<>();
        Deque<Integer> path = new ArrayDeque<>();
        backtrack(n, k, 1, path, res);
        return res;
    }

    private void backtrack(int n, int k, int start,
                           Deque<Integer> path, List<List<Integer>> res) {
        if (path.size() == k) {
            res.add(new ArrayList<>(path)); // 存副本
            return;
        }
        // 还需 need 个数，i 至多取到 n - need + 1
        int need = k - path.size();
        for (int i = start; i <= n - need + 1; i++) {
            path.addLast(i);
            backtrack(n, k, i + 1, path, res); // 起点后移，保证递增
            path.removeLast();                 // 回溯
        }
    }
}

复杂度

  • 时间：O(C(n, k) · k)，共 C(n,k) 个组合，每个组合拷贝/输出长度为 k。
  • 空间：O(k)，递归深度与 path 长度均不超过 k（不计存放结果的 res）。

易错点与扩展（面试高频考点）

  1. 起点写错：递归传 i + 1 而非 i，否则会出现 [2,2] 这种非法组合。
  2. 忘记存副本：res.add(path) 存的是同一引用，回溯后会被清空，必须 new ArrayList<>(path)。
  3. 剪枝边界：i <= n - (k - path.size()) + 1，漏掉 +1 会少搜或多搜。
  4. 面试追问——组合总和 / 子集：本题是"组合型回溯"的母题，子集是"每个元素选/不选"，组合总和是"可重复选取"，只需调整起点与终止条件。
  5. 面试追问——k 固定时能否用迭代：可以按字典序逐个生成下一个组合，但回溯更直观通用，面试首选回溯。

C++ 实现

#include <vector>
using namespace std;

class Solution {
public:
    vector<vector<int>> combine(int n, int k) {
        vector<vector<int>> res;
        vector<int> path;
        backtrack(n, k, 1, path, res);
        return res;
    }

private:
    void backtrack(int n, int k, int start,
                   vector<int>& path, vector<vector<int>>& res) {
        if ((int)path.size() == k) {
            res.push_back(path); // 存副本
            return;
        }
        int need = k - (int)path.size();
        for (int i = start; i <= n - need + 1; i++) { // 剪枝上界
            path.push_back(i);
            backtrack(n, k, i + 1, path, res);
            path.pop_back(); // 回溯
        }
    }
};

Python 实现

class Solution:
    def combine(self, n: int, k: int) -> list[list[int]]:
        res = []
        path = []

        def backtrack(start: int) -> None:
            if len(path) == k:
                res.append(path[:])   # 存副本
                return
            need = k - len(path)
            # i 至多取到 n - need + 1
            for i in range(start, n - need + 2):
                path.append(i)
                backtrack(i + 1)      # 起点后移，保证递增
                path.pop()            # 回溯

        backtrack(1)
        return res
