636. 函数的独占时间

本题学习状态正在读取学习记录…下次复习：—
本次复习：
按 M 快速切换薄弱标记
遮住推导与代码，先自己想，再逐段揭示
难度中等核心模式栈模拟函数调用，累计相邻时间戳差时间复杂度O(m)空间复杂度O(n)

题目与约束

有一个 单线程 CPU 正在运行一个含有 n 道函数的程序。每道函数都有一个位于 0 和 n-1 之间的唯一标识符。

函数调用 存储在一个 调用栈 上 ：当一个函数调用开始时，它的标识符将会推入栈中。而当一个函数调用结束时，它的标识符将会从栈中弹出。标识符位于栈顶的函数是 当前正在执行的函数 。每当一个函数开始或者结束时，将会记录一条日志，包括函数标识符、是开始还是结束、以及相应的时间戳。

给你一个由日志组成的列表 logs ，其中 logs[i] 表示第 i 条日志消息，该消息是一个按 "{function_id}:{"start" | "end"}:{timestamp}" 进行格式化的字符串。例如，"0:start:3" 意味着标识符为 0 的函数调用在时间戳 3 的 起始开始执行 ；而 "1:end:2" 意味着标识符为 1 的函数调用在时间戳 2 的 末尾结束执行。注意，函数可以 调用多次，可能存在递归调用 。

函数的 独占时间 定义是在这个函数在程序所有函数调用中执行时间的总和，调用其他函数花费的时间不算该函数的独占时间。例如，如果一个函数被调用两次，一次调用执行 2 单位时间，另一次调用执行 1 单位时间，那么该函数的 独占时间 为 2 + 1 = 3 。

以数组形式返回每个函数的 独占时间 ，其中第 i 个下标对应的值表示标识符 i 的函数的独占时间。

示例 1：

输入：n = 2, logs = ["0:start:0","1:start:2","1:end:5","0:end:6"]
输出：[3,4]
解释：
函数 0 在时间戳 0 的起始开始执行，执行 2 个单位时间，于时间戳 1 的末尾结束执行。
函数 1 在时间戳 2 的起始开始执行，执行 4 个单位时间，于时间戳 5 的末尾结束执行。
函数 0 在时间戳 6 的开始恢复执行，执行 1 个单位时间。
所以函数 0 总共执行 2 + 1 = 3 个单位时间，函数 1 总共执行 4 个单位时间。

示例 2：

输入：n = 1, logs = ["0:start:0","0:start:2","0:end:5","0:start:6","0:end:6","0:end:7"]
输出：[8]
解释：
函数 0 在时间戳 0 的起始开始执行，执行 2 个单位时间，并递归调用它自身。
函数 0（递归调用）在时间戳 2 的起始开始执行，执行 4 个单位时间。
函数 0（初始调用）恢复执行，并立刻再次调用它自身。
函数 0（第二次递归调用）在时间戳 6 的起始开始执行，执行 1 个单位时间。
函数 0（初始调用）在时间戳 7 的起始恢复执行，执行 1 个单位时间。
所以函数 0 总共执行 2 + 4 + 1 + 1 = 8 个单位时间。

示例 3：

输入：n = 2, logs = ["0:start:0","0:start:2","0:end:5","1:start:6","1:end:6","0:end:7"]
输出：[7,1]
解释：
函数 0 在时间戳 0 的起始开始执行，执行 2 个单位时间，并递归调用它自身。
函数 0（递归调用）在时间戳 2 的起始开始执行，执行 4 个单位时间。
函数 0（初始调用）恢复执行，并立刻调用函数 1 。
函数 1 在时间戳 6 的起始开始执行，执行 1 个单位时间，于时间戳 6 的末尾结束执行。
函数 0（初始调用）在时间戳 7 的起始恢复执行，执行 1 个单位时间，于时间戳 7 的末尾结束执行。
所以函数 0 总共执行 2 + 4 + 1 = 7 个单位时间，函数 1 总共执行 1 个单位时间。

提示：

  • 1 <= n <= 100

  • 2 <= logs.length <= 500

  • 0 <= function_id < n

  • 0 <= timestamp <= 109

  • 两个开始事件不会在同一时间戳发生

  • 两个结束事件不会在同一时间戳发生

  • 每道函数都有一个对应 "start" 日志的 "end" 日志

核心不变量

用栈保存当前调用链上的函数 id，用 prev 记录上一条日志处理到的时间位置；遇到 start 时给栈顶函数累加 time - prev，遇到 end 时给该函数累加 time - prev + 1 并更新 prev，保证每段时间只归属真正独占它的函数。

完整推导

思路推导

  1. 直觉与痛点（时间片会「嵌套」）

单线程 CPU 同一时刻只执行一个函数，但存在递归调用与函数调用：一旦有子函数被调用，父函数的计时必须暂停，等子函数返回后再继续。要还原这种「嵌套计时」，最自然的结构就是调用栈。

  1. 破局思路（扫描日志 + 计时指针）

维护一个栈 stack（栈顶是当前正在执行的函数）和一个变量 prev（记录上一次「处理到」的时间点）。依次扫描每条日志：

  • 遇到 start: t：说明从 prev 到 t 这段 CPU 时间由当前栈顶函数独占（若栈非空），于是 res[栈顶] += t - prev；然后把新函数压栈，令 prev = t。
  • 遇到 end: t：说明栈顶这个函数从 prev 到 t（含端点 t）都在执行，累计 res[该函数] += t - prev + 1；然后弹出该函数，令 prev = t + 1，因为时间戳 t 已被这一层占用。
  1. 关键追问（为什么 end 要 +1、prev 要 +1）

时间戳按「单位时间点」计：end: 5 表示该函数一直占用到时间戳 5 结束，包含 5 这个单位，所以区间长度是 t - prev + 1。同时被结束函数占用了 t，父函数恢复执行的起点是 t + 1，因此 prev 更新为 t + 1。

  1. 小例子

["0:start:0","1:start:2","1:end:5","0:end:6"]：start 0 压栈、prev=0；start 1 时栈顶 0 得 2-0=2，压 1、prev=2；end 1 时函数 1 得 5-2+1=4，弹栈、prev=6；end 0 时函数 0 得 6-6+1=1。最终 res[0]=2+1=3、res[1]=4，与示例一致。

Java 实现（exclusiveTime）

import java.util.*;

class Solution {
    public int[] exclusiveTime(int n, List<String> logs) {
        int[] res = new int[n];              // 每个函数的独占时间
        Deque<Integer> stack = new ArrayDeque<>(); // 当前调用栈（存函数 id）
        int prev = 0;                        // 上一次处理到的时间位置

        for (String log : logs) {
            String[] parts = log.split(":");
            int id = Integer.parseInt(parts[0]);
            String type = parts[1];
            int time = Integer.parseInt(parts[2]);

            if (type.equals("start")) {
                // 从 prev 到 time 这段归当前栈顶函数所有
                if (!stack.isEmpty()) {
                    res[stack.peek()] += time - prev;
                }
                stack.push(id);   // 新函数开始执行
                prev = time;
            } else {
                // 栈顶函数从 prev 执行到 time（含 time），长度 time-prev+1
                res[id] += time - prev + 1;
                stack.pop();      // 该函数结束
                prev = time + 1;  // 时间戳 time 已被占用，父函数从 time+1 恢复
            }
        }
        return res;
    }
}

C++ 实现

#include <vector>
#include <string>
#include <stack>
using namespace std;

class Solution {
public:
    vector<int> exclusiveTime(int n, vector<string>& logs) {
        vector<int> res(n, 0);
        stack<int> st;      // 当前调用栈，存函数 id
        int prev = 0;       // 上一次处理到的时间位置

        for (const string& log : logs) {
            int p1 = log.find(':');
            int p2 = log.find(':', p1 + 1);
            int id = stoi(log.substr(0, p1));
            string type = log.substr(p1 + 1, p2 - p1 - 1);
            int time = stoi(log.substr(p2 + 1));

            if (type == "start") {
                if (!st.empty()) {
                    res[st.top()] += time - prev;
                }
                st.push(id);
                prev = time;
            } else {
                res[id] += time - prev + 1;
                st.pop();
                prev = time + 1;
            }
        }
        return res;
    }
};

Python 实现

class Solution:
    def exclusiveTime(self, n: int, logs: list[str]) -> list[int]:
        res = [0] * n
        stack = []   # 当前调用栈，存函数 id
        prev = 0     # 上一次处理到的时间位置

        for log in logs:
            fid, typ, t = log.split(':')
            fid, t = int(fid), int(t)

            if typ == 'start':
                # prev 到 t 之间归当前栈顶函数所有
                if stack:
                    res[stack[-1]] += t - prev
                stack.append(fid)
                prev = t
            else:
                # 栈顶函数执行到 t（含 t），长度 t - prev + 1
                res[fid] += t - prev + 1
                stack.pop()
                prev = t + 1

        return res

复杂度

  • 时间：O(m)，其中 m = logs.length，每条日志只解析、处理一次，栈操作 O(1)。
  • 空间：O(n)，栈的深度最多为同时活跃的函数调用层数，不超过 n。
易错点与扩展（面试高频考点）
  1. end 少加 1：结束时刻的区间长度是 time - prev + 1，漏掉 +1 会少算一个单位时间，是最常见错误。
  2. prev 的更新方式：start 后 prev = time，end 后 prev = time + 1，两者不同步会导致整体错位。
  3. 递归同名函数：多个 start 可能是同一个 id 的递归调用（示例 2），所以栈里存 id 而非「是否已出现」，结束时要弹栈而不是清零。
  4. 字符串解析："id:start:time" 用 split(":") 得到三段；时间戳可达 10^9，int 足够，但累计和若更大需注意用 long。
  5. 面试延展：本题是「栈模拟嵌套区间计时」的典型。类似变形有括号匹配计时、任务调度中的嵌套耗时统计等，核心都是「进入子过程前结算父过程、退出子过程时结算自身」。
