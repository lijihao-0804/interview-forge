1190. 反转每对括号间的子串

本题学习状态正在读取学习记录…下次复习：—
本次复习：
按 M 快速切换薄弱标记
遮住推导与代码，先自己想，再逐段揭示
难度中等核心模式括号配对 + 奇偶层方向翻转（wormhole 跳转），一次遍历时间复杂度O(n)空间复杂度O(n)

题目与约束

给出一个字符串 s（仅含有小写英文字母和括号）。

请你按照从括号内到外的顺序，逐层反转每对匹配括号中的字符串，并返回最终的结果。

注意，您的结果中 不应 包含任何括号。

示例 1：

输入：s = "(abcd)"
输出："dcba"

示例 2：

输入：s = "(u(love)i)"
输出："iloveu"
解释：先反转子字符串 "love" ，然后反转整个字符串。

示例 3：

输入：s = "(ed(et(oc))el)"
输出："leetcode"
解释：先反转子字符串 "oc" ，接着反转 "etco" ，然后反转整个字符串。

提示：

  • 1 <= s.length <= 2000

  • s 中只有小写英文字母和括号

  • 题目测试用例确保所有括号都是成对出现的

核心不变量

每对匹配括号相当于一个“传送门”：走到 ( 就跳到它的 ) 并把遍历方向翻转，走到 ) 就跳到它的 ( 并翻转方向。按这个规则从头走一遍，落下的字符顺序恰好就是逐层反转后的结果。

完整推导

思路推导

  1. 直觉与痛点（逐层反转眼花缭乱）

最直接的想法是用栈：遇到 ( 就开一个新容器，遇到 ) 就把当前容器里的内容反转后接到外层。这思路清晰，但每次 ) 都要真正翻转一段字符串，最坏嵌套下总代价可达 O(n²)。

  1. 破局思路（把“反转”变成“换方向走”）

注意一个性质：每进入或离开一层括号，就相当于把“阅读方向”反过来一次。于是我们不需要真的去翻转字符串，只要改变遍历方向即可。

先做一次括号配对：用栈扫一遍，记录每对括号的对应下标 match[i]。然后再从下标 0 出发，方向 dir = 1：

  • 遇到字母：直接追加到答案，i += dir；
  • 遇到 ( 或 )：i = match[i]（跳到配对端），并令 dir = -dir（反转方向），再 i += dir。
  1. 小例子（(abcd)）

配对：match[0]=5, match[5]=0。从 i=0 出发是 (，跳到 5、方向变 -1，再走一步到 4；随后依次读 d,c,b,a 到达 0；又遇到 (，跳到 5、方向变 1，再走一步越过右边界结束。输出 dcba，正确。

嵌套的 (ed(et(oc))el) 同理：内层 oc 因方向多次翻转被读成 co，逐层“翻转”的效果被方向切换自动完成，最终得到 leetcode。

Java 实现（括号配对 + 方向翻转）

import java.util.ArrayDeque;
import java.util.Deque;

class Solution {
    public String reverseParentheses(String s) {
        int n = s.length();
        int[] match = new int[n]; // match[i] 为与 i 配对的括号下标
        Deque<Integer> stack = new ArrayDeque<>();

        // 第一遍：括号配对
        for (int i = 0; i < n; i++) {
            char ch = s.charAt(i);
            if (ch == '(') {
                stack.push(i);
            } else if (ch == ')') {
                int open = stack.pop();
                match[open] = i;
                match[i] = open;
            }
        }

        // 第二遍：按“传送门 + 反向”的规则走一遍
        StringBuilder sb = new StringBuilder();
        int i = 0;
        int dir = 1;
        while (i >= 0 && i < n) {
            char ch = s.charAt(i);
            if (ch == '(' || ch == ')') {
                i = match[i];   // 跳到配对端
                dir = -dir;     // 反转方向
            } else {
                sb.append(ch);
            }
            i += dir;
        }
        return sb.toString();
    }
}

C++ 实现

#include <string>
#include <vector>
#include <stack>
using namespace std;

class Solution {
public:
    string reverseParentheses(string s) {
        int n = s.size();
        vector<int> match(n, -1);
        stack<int> st;

        // 第一遍：括号配对
        for (int i = 0; i < n; ++i) {
            if (s[i] == '(') {
                st.push(i);
            } else if (s[i] == ')') {
                int open = st.top();
                st.pop();
                match[open] = i;
                match[i] = open;
            }
        }

        // 第二遍：传送门 + 方向翻转
        string res;
        int i = 0, dir = 1;
        while (i >= 0 && i < n) {
            if (s[i] == '(' || s[i] == ')') {
                i = match[i];
                dir = -dir;
            } else {
                res.push_back(s[i]);
            }
            i += dir;
        }
        return res;
    }
};

Python 实现

class Solution:
    def reverseParentheses(self, s: str) -> str:
        n = len(s)
        match = [-1] * n
        stack = []

        # 第一遍：括号配对
        for i, ch in enumerate(s):
            if ch == '(':
                stack.append(i)
            elif ch == ')':
                j = stack.pop()
                match[i] = j
                match[j] = i

        # 第二遍：传送门 + 方向翻转
        res = []
        i, direction = 0, 1
        while 0 <= i < n:
            if s[i] == '(' or s[i] == ')':
                i = match[i]
                direction = -direction
            else:
                res.append(s[i])
            i += direction

        return ''.join(res)

复杂度

  • 时间：O(n)。配对扫一遍、遍历扫一遍，每个字符至多被访问常数次，没有真实的字符串翻转。
  • 空间：O(n)。match 数组与栈均为线性。
易错点与扩展（面试高频考点）
  1. 走完传送门后要再 i += dir：i = match[i] 只是跳到括号另一端，还必须朝新方向迈一步，否则会在同一位置反复触发传送门导致死循环。
  2. 方向每次经过括号就翻转一次：无论是 ( 还是 ) 都翻转，这是“逐层反转”的关键。
  3. 配对数组只对括号有效：字母位置不需要 match，遍历时按普通字符处理。
  4. 朴素栈解法：用栈存 StringBuilder，遇 ( 压栈、遇 ) 弹栈反转再接回。写起来短，但在深嵌套下是 O(n²)；本题 n ≤ 2000 也能过，但要清楚复杂度差异。
  5. 通用性：这种“用配对跳转 + 奇偶方向”的手法，也可用于处理任意嵌套结构的分层反转/遍历问题。
