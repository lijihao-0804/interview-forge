150. 逆波兰表达式求值

难度中等核心模式栈：数字入栈，运算符弹出两个操作数计算后压回时间复杂度O(n)空间复杂度O(n)

题目与约束

给你一个字符串数组 tokens ，表示一个根据 逆波兰表示法 表示的算术表达式。

请你计算该表达式。返回一个表示表达式值的整数。

注意：

  • 有效的算符为 '+'、'-'、'*' 和 '/' 。

  • 每个操作数（运算对象）都可以是一个整数或者另一个表达式。

  • 两个整数之间的除法总是 向零截断 。

  • 表达式中不含除零运算。

  • 输入是一个根据逆波兰表示法表示的算术表达式。

  • 答案及所有中间计算结果可以用 32 位 整数表示。

示例 1：

输入：tokens = ["2","1","+","3","*"]
输出：9
解释：该算式转化为常见的中缀算术表达式为：((2 + 1) * 3) = 9

示例 2：

输入：tokens = ["4","13","5","/","+"]
输出：6
解释：该算式转化为常见的中缀算术表达式为：(4 + (13 / 5)) = 6

示例 3：

输入：tokens = ["10","6","9","3","+","-11","","/","","17","+","5","+"]
输出：22
解释：该算式转化为常见的中缀算术表达式为：
((10 * (6 / ((9 + 3) * -11))) + 17) + 5
= ((10 * (6 / (12 * -11))) + 17) + 5
= ((10 * (6 / -132)) + 17) + 5
= ((10 * 0) + 17) + 5
= (0 + 17) + 5
= 17 + 5
= 22

提示：

  • 1 <= tokens.length <= 104

  • tokens[i] 是一个算符（"+"、"-"、"*" 或 "/"），或是在范围 [-200, 200] 内的一个整数

逆波兰表达式：

逆波兰表达式是一种后缀表达式，所谓后缀就是指算符写在后面。

  • 平常使用的算式则是一种中缀表达式，如 ( 1 + 2 ) * ( 3 + 4 ) 。

  • 该算式的逆波兰表达式写法为 ( ( 1 2 + ) ( 3 4 + ) * ) 。

逆波兰表达式主要有以下两个优点：

  • 去掉括号后表达式无歧义，上式即便写成 1 2 + 3 4 + *也可以依据次序计算出正确结果。

  • 适合用栈操作运算：遇到数字则入栈；遇到算符则取出栈顶两个数字进行计算，并将结果压入栈中

核心不变量

任一时刻栈中保存的是"尚未参与运算的中间结果"；遇到运算符时，先弹出的是右操作数、后弹出的是左操作数，计算 左 op 右 后压回。

完整推导

思路推导

  1. 后缀表达式为什么适合栈

后缀表达式里运算符总在它的两个操作数之后。当我们从左往右扫描时，遇到数字就先存起来；一旦遇到运算符，离它最近、还没被用掉的两个数字正好就是它的两个操作数。这种"后进先出"的取用顺序，正是栈的特性。

  1. 具体规则
  • 遇到数字：转成整数压栈。
  • 遇到 + - * /：弹出两次栈顶，记为 b（右操作数）和 a（左操作数），计算 a op b 后压回栈。
  • 扫描结束后，栈中唯一剩下的元素就是整个表达式的值。
  1. 小例子（示例 1：["2","1","+","3","*"]）
  • 2、1 入栈 → 栈 [2,1]
  • +：弹出 b=1、a=2，2+1=3 入栈 → 栈 [3]
  • 3 入栈 → 栈 [3,3]
  • *：弹出 b=3、a=3，3*3=9 入栈 → 栈 [9]
  • 结果 9。
  1. 除法细节（向零截断）

题目要求除法向零截断。Java、C++ 的整数除法本身就是向零截断；而 Python 的 // 是向下取整（如 -7 // 2 = -4），必须改成 int(a / b) 才能得到 -3。

Java 实现（evalRPN）

import java.util.ArrayDeque;
import java.util.Deque;

class Solution {
    public int evalRPN(String[] tokens) {
        Deque<Integer> stack = new ArrayDeque<>();
        for (String t : tokens) {
            if (t.equals("+") || t.equals("-") || t.equals("*") || t.equals("/")) {
                int b = stack.pop(); // 先弹出的是右操作数
                int a = stack.pop(); // 后弹出的是左操作数
                switch (t) {
                    case "+":
                        stack.push(a + b);
                        break;
                    case "-":
                        stack.push(a - b);
                        break;
                    case "*":
                        stack.push(a * b);
                        break;
                    case "/":
                        // Java 整数除法天然向零截断
                        stack.push(a / b);
                        break;
                    default:
                        break;
                }
            } else {
                stack.push(Integer.parseInt(t));
            }
        }
        return stack.pop();
    }
}

C++ 实现

#include <vector>
#include <string>
#include <stack>
using namespace std;

class Solution {
public:
    int evalRPN(vector<string>& tokens) {
        stack<int> st;
        for (const string& t : tokens) {
            if (t == "+" || t == "-" || t == "*" || t == "/") {
                int b = st.top(); st.pop(); // 右操作数
                int a = st.top(); st.pop(); // 左操作数
                if (t == "+") {
                    st.push(a + b);
                } else if (t == "-") {
                    st.push(a - b);
                } else if (t == "*") {
                    st.push(a * b);
                } else {
                    st.push(a / b); // C++ 整数除法向零截断
                }
            } else {
                st.push(stoi(t));
            }
        }
        return st.top();
    }
};

Python 实现

class Solution:
    def evalRPN(self, tokens: list[str]) -> int:
        stack = []
        for t in tokens:
            if t in ("+", "-", "*", "/"):
                b = stack.pop()  # 右操作数
                a = stack.pop()  # 左操作数
                if t == "+":
                    stack.append(a + b)
                elif t == "-":
                    stack.append(a - b)
                elif t == "*":
                    stack.append(a * b)
                else:
                    # Python 的 // 向下取整，这里需向零截断
                    stack.append(int(a / b))
            else:
                stack.append(int(t))
        return stack[0]

复杂度

  • 时间：O(n)，每个 token 只处理一次，入栈/出栈和四则运算都是常数时间。
  • 空间：O(n)，最坏情况（全是数字）栈中会累积全部操作数。
易错点与扩展（面试高频考点）
  1. 弹出顺序搞反：一定先弹 b（右操作数）、再弹 a（左操作数），计算 a - b、a / b；写成 b - a 或 b / a 会错（加乘无所谓，减除致命）。
  2. Python 除法取整方向：// 是向下取整，负数会算错，必须用 int(a / b) 实现向零截断；Java/C++ 直接整除即可。
  3. 负数字符串识别："-11" 是数字不是运算符，靠"字符串是否等于 + - * /"来判断即可，Integer.parseInt / stoi / int 都能正确解析带负号的数字。
  4. 运算符判断方式：直接比较字符串相等，不要用首字符判断（负号会混淆）；比较时用 equals 而非 ==。
  5. 结果为栈顶：扫描结束后栈里应恰好剩一个元素，直接返回它；若想更稳妥可断言栈大小为 1。
