# 232. 用栈实现队列

| 题目信息 | 内容 |
|---|---|
| 难度 | 简单 |
| 核心模式 | 双栈倒换：入队栈 + 出队栈，均摊 O(1) |
| 时间复杂度 | 均摊 O(1)，单次最坏 O(n) |
| 空间复杂度 | O(n) |

## 题目与约束

请你仅使用两个栈实现先入先出队列。队列应当支持一般队列支持的所有操作（`push`、`pop`、`peek`、`empty`）：

实现 `MyQueue` 类：

- `void push(int x)` 将元素 x 推到队列的末尾

- `int pop()` 从队列的开头移除并返回元素

- `int peek()` 返回队列开头的元素

- `boolean empty()` 如果队列为空，返回 `true` ；否则，返回 `false`

说明：

- 你 只能 使用标准的栈操作 —— 也就是只有 `push to top`, `peek/pop from top`, `size`, 和 `is empty` 操作是合法的。

- 你所使用的语言也许不支持栈。你可以使用 list 或者 deque（双端队列）来模拟一个栈，只要是标准的栈操作即可。

 

示例 1：

输入：  
["MyQueue", "push", "push", "peek", "pop", "empty"]  
[[], [1], [2], [], [], []]  
输出：  
[null, null, null, 1, 1, false]  
解释：  
MyQueue myQueue = new MyQueue();  
myQueue.push(1); // queue is: [1]  
myQueue.push(2); // queue is: [1, 2] (leftmost is front of the queue)  
myQueue.peek(); // return 1  
myQueue.pop(); // return 1, queue is [2]  
myQueue.empty(); // return false

 

提示：

- `1 <= x <= 9`

- 最多调用 `100` 次 `push`、`pop`、`peek` 和 `empty`

- 假设所有操作都是有效的 （例如，一个空的队列不会调用 `pop` 或者 `peek` 操作）

 

进阶：

- 你能否实现每个操作均摊时间复杂度为 `O(1)` 的队列？换句话说，执行 `n` 个操作的总时间复杂度为 `O(n)` ，即使其中一个操作可能花费较长时间。

## 核心不变量

> `outStack` 的栈顶就是队头；只有在 `outStack` 为空时，才把 `inStack` 的元素整体倒入，且每个元素最多被搬一次。

## 完整推导

### 思路推导

1. **直觉与痛点：栈是「后进先出」，队列是「先进先出」。** 一个栈直接做不到队列的顺序，但**两个栈**配合就能「负负得正」：元素经过两次栈反转，顺序就恢复了。
2. **两个栈分工。** `inStack` 负责入队，`outStack` 负责出队。
   - `push(x)`：直接压入 `inStack`。
   - `pop()/peek()`：如果 `outStack` 为空，就把 `inStack` 里的元素**全部**弹出并压入 `outStack`（顺序反转一次）；然后从 `outStack` 取栈顶。
   - 小例子：`push(1)`、`push(2)` 后 `inStack = [1,2]`（栈顶 2）。`pop()` 时 `outStack` 为空，把 `inStack` 全部倒入得 `outStack = [2,1]`（栈顶 1），`outStack.pop()` 得到 `1`，正是队头。✅
3. **为什么均摊 O(1)。** 每个元素一生只会从 `inStack` 搬到 `outStack` 一次，因此 n 次操作总搬移次数不超过 n，均摊到每次就是 O(1)。

### Java 实现（双栈实现）
```java
import java.util.ArrayDeque;
import java.util.Deque;

class MyQueue {
    // 入队栈：负责 push
    private Deque<Integer> inStack;
    // 出队栈：负责 pop / peek
    private Deque<Integer> outStack;

    public MyQueue() {
        inStack = new ArrayDeque<>();
        outStack = new ArrayDeque<>();
    }

    public void push(int x) {
        inStack.push(x);
    }

    public int pop() {
        // 出队栈为空时，把入队栈的元素整体倒过来
        if (outStack.isEmpty()) {
            while (!inStack.isEmpty()) {
                outStack.push(inStack.pop());
            }
        }
        return outStack.pop();
    }

    public int peek() {
        if (outStack.isEmpty()) {
            while (!inStack.isEmpty()) {
                outStack.push(inStack.pop());
            }
        }
        return outStack.peek();
    }

    public boolean empty() {
        // 两个栈都空，队列才空
        return inStack.isEmpty() && outStack.isEmpty();
    }
}
```

### 复杂度
- 时间：`push`、`empty` 为 O(1)；`pop`、`peek` 均摊 O(1)（单次最坏 O(n)，发生在需要整体倒栈时）。
- 空间：O(n)，两个栈合计保存 n 个元素。

### 易错点与扩展（面试高频考点）

1. **绝不能「出队栈非空还继续倒」。** 只有 `outStack` 为空时才允许把 `inStack` 倒入；否则会把已经排好的队头顺序打乱，得到错误结果。
2. **`empty` 要同时检查两个栈。** 只判断 `inStack` 非空是常见 bug —— 数据可能都在 `outStack` 里。
3. **`peek` 与 `pop` 共用倒栈逻辑。** 提取成一个私有方法 `inToOut()` 可避免重复代码，也减少出错。
4. **均摊复杂度的道理要讲清。** 单次 `pop` 可能 O(n)，但每个元素最多搬一次，所以 n 次操作总计 O(n)，满足进阶要求。
5. **用 Deque 模拟栈。** Java 中推荐 `ArrayDeque`（`push/pop/peek` 都操作栈顶）；Python 用 `list` 的 `append/pop` 即可。

### C++ 实现
```cpp
#include <stack>
using namespace std;

class MyQueue {
    stack<int> inStack, outStack; // inStack 入队，outStack 出队
public:
    MyQueue() {}

    void push(int x) {
        inStack.push(x);
    }

    int pop() {
        if (outStack.empty()) {
            while (!inStack.empty()) {
                outStack.push(inStack.top());
                inStack.pop();
            }
        }
        int v = outStack.top();
        outStack.pop();
        return v;
    }

    int peek() {
        if (outStack.empty()) {
            while (!inStack.empty()) {
                outStack.push(inStack.top());
                inStack.pop();
            }
        }
        return outStack.top();
    }

    bool empty() {
        return inStack.empty() && outStack.empty();
    }
};
```

### Python 实现
```python
class MyQueue:
    def __init__(self):
        self.in_stack = []   # 入队栈
        self.out_stack = []  # 出队栈

    def push(self, x: int) -> None:
        self.in_stack.append(x)

    def pop(self) -> int:
        if not self.out_stack:
            while self.in_stack:
                self.out_stack.append(self.in_stack.pop())
        return self.out_stack.pop()

    def peek(self) -> int:
        if not self.out_stack:
            while self.in_stack:
                self.out_stack.append(self.in_stack.pop())
        return self.out_stack[-1]

    def empty(self) -> bool:
        return not self.in_stack and not self.out_stack
```
