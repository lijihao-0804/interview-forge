1047. 删除字符串中的所有相邻重复项

本题学习状态正在读取学习记录…下次复习：—
本次复习：
按 M 快速切换薄弱标记
遮住推导与代码，先自己想，再逐段揭示
难度简单核心模式用栈抵消相邻相同字符（后进先出）时间复杂度O(n)空间复杂度O(n)

题目与约束

给出由小写字母组成的字符串 s，重复项删除操作 会选择两个相邻且相同的字母，并删除它们。

在 s 上反复执行重复项删除操作，直到无法继续删除。

在完成所有重复项删除操作后返回最终的字符串。答案保证唯一。

示例 1：

输入："abbaca"
输出："ca"
解释：
例如，在 "abbaca" 中，我们可以删除 "bb" 由于两字母相邻且相同，这是此时唯一可以执行删除操作的重复项。之后我们得到字符串 "aaca"，其中又只有 "aa" 可以执行重复项删除操作，所以最后的字符串为 "ca"。

示例 2：

输入：s = "azxxzy"
输出："ay"

提示：

  • 1 <= s.length <= 105

  • s 仅由小写英文字母组成。

核心不变量

扫描到第 i 个字符时，栈里保存的正是"前 i 个字符消除完所有可消除的相邻重复后的结果"，且这个结果内部已不含任何相邻重复、也不会再与更早的字符发生消除。

完整推导

思路推导

  1. 暴力模拟为什么慢

最直觉的做法是反复扫描字符串，发现相邻相同就删掉，删完再从头扫描。但每删除一次都可能让新拼接处的两侧字符变成相邻重复，需要重新检查；最坏情况（例如 "aaaa...a"）每次只删一对、反复扫描，整体退化成 O(n²)。

  1. 换个视角：把"删除"看成"配对抵消"

从左到右逐个把字符压入一个栈。每次要压入的字符 c 如果和栈顶相同，说明这两个字符此刻是相邻且相同的，直接把它俩一起消掉——也就是不压入，反而把栈顶弹出。如果不同，就正常压入。

  1. 正确性小例子（"abbaca"）
  • a → 栈 ["a"]
  • b → 栈 ["a","b"]
  • b → 与栈顶 b 相同，弹出 → 栈 ["a"]
  • a → 与栈顶 a 相同，弹出 → 栈 []
  • c → 栈 ["c"]
  • a → 栈 ["c","a"]

最终栈内容 "ca"，与答案一致。关键在于：弹出后暴露出来的新栈顶会自动与下一个待处理字符继续比较，恰好模拟了"删除后左右拼接"的效果，而无需回头重扫。

  1. 为什么答案唯一

任意时刻可消除的相邻相同字符对都来自同一段连续相同字符，消除顺序不影响最终结果，因此最终字符串唯一，栈无论怎么走都得到同一个答案。

Java 实现（removeDuplicates）

class Solution {
    public String removeDuplicates(String s) {
        // 用 StringBuilder 模拟栈：只在尾部追加/删除，效率高于 Stack
        StringBuilder stack = new StringBuilder();

        for (int i = 0; i < s.length(); i++) {
            char c = s.charAt(i);
            int len = stack.length();
            // 栈非空且栈顶字符与当前字符相同，说明二者相邻相等，一起抵消
            if (len > 0 && stack.charAt(len - 1) == c) {
                stack.deleteCharAt(len - 1);
            } else {
                // 否则正常入栈
                stack.append(c);
            }
        }

        return stack.toString();
    }
}

C++ 实现

#include <string>
using namespace std;

class Solution {
public:
    string removeDuplicates(string s) {
        string st;  // 直接用 string 当栈，尾部即栈顶
        for (char c : s) {
            // 栈非空且栈顶与当前字符相同 -> 抵消；否则入栈
            if (!st.empty() && st.back() == c) {
                st.pop_back();
            } else {
                st.push_back(c);
            }
        }
        return st;
    }
};

Python 实现

class Solution:
    def removeDuplicates(self, s: str) -> str:
        stack = []
        for c in s:
            # 栈非空且栈顶与当前字符相同 -> 弹出抵消；否则压入
            if stack and stack[-1] == c:
                stack.pop()
            else:
                stack.append(c)
        return "".join(stack)

复杂度

  • 时间：O(n)。每个字符恰好入栈一次、最多出栈一次，append 与 deleteCharAt(len - 1) 都是 O(1) 的尾部操作。
  • 空间：O(n)。最坏情况下（如 "abcd..." 无相邻重复）栈需要保存全部字符；若不计输出所占空间，额外辅助空间也是 O(n)（栈的深度）。
易错点与扩展（面试高频考点）

  1. 弹出后要"继续比较"：删除栈顶后，新的栈顶可能和下一个字符再次相同，而上面的循环天然满足这点——每次只用当前字符和"当前栈顶"比较即可，千万别写成只和原始相邻位置比较。

  2. 用 String 拼接会超时：在循环里用 s = s.substring(...) 反复创建新字符串是 O(n²)，10^5 规模下必然超时。必须用 StringBuilder（Java）或 string 当栈（C++）、list（Python）。

  3. 空栈判断顺序：先判断 len > 0 再取栈顶，避免对空栈取 charAt(-1) 越界。短路求值保证了安全。

  4. 与"括号匹配"同构：本题与"有效括号"用的是同一套栈思想——遇到"可与栈顶配对"的就弹出，否则压入。可以把"相同字符"推广成"一对匹配关系"，框架完全复用。

  5. 扩展：返回删除后的长度 / 不能回头扫描。若题目改成"只允许一次线性扫描且不能回溯"，栈依旧是标准答案；若改成"每次可删除任意一对相同字符（不要求相邻）"，则只需统计每个字符出现次数的奇偶性。
