题目与约束

设计一个类似堆栈的数据结构，将元素推入堆栈，并从堆栈中弹出出现频率最高的元素。

实现 FreqStack 类:

  • FreqStack() 构造一个空的堆栈。

  • void push(int val) 将一个整数 val 压入栈顶。

  • int pop() 删除并返回堆栈中出现频率最高的元素。

  • 如果出现频率最高的元素不只一个，则移除并返回最接近栈顶的元素。

示例 1：

输入：
["FreqStack","push","push","push","push","push","push","pop","pop","pop","pop"],
[[],[5],[7],[5],[7],[4],[5],[],[],[],[]]
输出：[null,null,null,null,null,null,null,5,7,5,4]
解释：
FreqStack = new FreqStack();
freqStack.push (5);//堆栈为 [5]
freqStack.push (7);//堆栈是 [5,7]
freqStack.push (5);//堆栈是 [5,7,5]
freqStack.push (7);//堆栈是 [5,7,5,7]
freqStack.push (4);//堆栈是 [5,7,5,7,4]
freqStack.push (5);//堆栈是 [5,7,5,7,4,5]
freqStack.pop ();//返回 5 ，因为 5 出现频率最高。堆栈变成 [5,7,5,7,4]。
freqStack.pop ();//返回 7 ，因为 5 和 7 出现频率最高，但7最接近顶部。堆栈变成 [5,7,5,4]。
freqStack.pop ();//返回 5 ，因为 5 出现频率最高。堆栈变成 [5,7,4]。
freqStack.pop ();//返回 4 ，因为 4, 5 和 7 出现频率最高，但 4 是最接近顶部的。堆栈变成 [5,7]。

提示：

  • 0 <= val <= 109

  • push 和 pop 的操作数不大于 2 * 104。

  • 输入保证在调用 pop 之前堆栈中至少有一个元素。

核心不变量

频率为 f 的所有元素都按压栈先后存放进 group[f] 这个栈里，其栈顶就是该频率中最晚压入（最接近栈顶）的元素；pop 只需从最高频率 maxFreq 对应的栈顶取即可。

完整推导

思路推导

  1. 直觉与痛点（暴力怎么做、为什么慢）

最直接的想法是维护一个普通栈，pop 时扫描整个栈统计频率、挑频率最高且最靠顶的元素。但每次 pop 都要 O(n) 统计，操作数达 2×10⁴，会退化成 O(n²)。我们需要让 push 和 pop 都接近 O(1)。

  1. 破局思路（频率分组 + 每组一个栈）

维护三样东西： - freq：值 → 当前出现次数； - group：频率 → 该频率的元素栈（栈顶是最新压入的）； - maxFreq：当前出现过的最大频率。

push(val) 时，val 的频率 f = freq[val] + 1，把它压进 group[f]，并更新 maxFreq = max(maxFreq, f)。

  1. 关键追问（pop 之后 maxFreq 怎么维护？）

pop 时取 group[maxFreq] 的栈顶元素 val（它天然是“频率最高者中最靠顶”的），把 freq[val] 减 1。如果取完这组变空了，说明频率为 maxFreq 的元素已经没了，就把 maxFreq 减 1。因为频率最多只比原来低 1，且不会出现“maxFreq 组非空却要降到更低”的情况，所以只需 maxFreq-- 一步即可。

示例 push 5,7,5,7,4,5 后：group[1]=[5,7,4]（栈顶 4）、group[2]=[5,7]、group[3]=[5]，maxFreq=3；第一次 pop 取 group[3] 栈顶 5，group[3] 空 → maxFreq=2；下一次取 group[2] 栈顶 7……与示例输出 5,7,5,4 完全一致。

Java 实现（FreqStack）

import java.util.ArrayDeque;
import java.util.Deque;
import java.util.HashMap;
import java.util.Map;

class FreqStack {
    private final Map<Integer, Integer> freq = new HashMap<>();       // 值 -> 当前频率
    private final Map<Integer, Deque<Integer>> group = new HashMap<>(); // 频率 -> 该频率的元素栈
    private int maxFreq = 0;                                          // 当前最大频率

    public FreqStack() {
    }

    public void push(int val) {
        int f = freq.getOrDefault(val, 0) + 1;
        freq.put(val, f);
        // 把 val 压入频率 f 对应的栈，栈顶即该频率中最新的元素
        group.computeIfAbsent(f, k -> new ArrayDeque<>()).push(val);
        maxFreq = Math.max(maxFreq, f);
    }

    public int pop() {
        Deque<Integer> stack = group.get(maxFreq);
        int val = stack.pop();          // 频率最高者中最接近栈顶的元素
        freq.put(val, maxFreq - 1);     // 该元素频率降 1
        if (stack.isEmpty()) {
            maxFreq--;                  // 最高频率组空了，整体频率下移一层
        }
        return val;
    }
}

复杂度

  • 时间：push 与 pop 均为均摊 O(1)，哈希表读写与栈操作都是常数时间。
  • 空间：O(n)，freq 与 group 里最多各存 n 个元素（n 为总 push 次数）。

易错点与扩展（面试高频考点）

  1. maxFreq 只能减 1，不能重扫：group[maxFreq] 取空后，下一高频率一定是 maxFreq-1，因为任何元素频率每次只增加 1，不存在跳级。用重扫最大值会破坏 O(1)。
  2. “最接近栈顶”的语义靠同频率栈保证：同一频率的元素按压入顺序入栈，pop 取栈顶自然就是“该频率中最晚压入、最靠近整体栈顶”的那个，无需额外排序。
  3. freq 与 group 必须同步：pop 后既要让 freq[val] 降 1，也要让该元素在下次被 push 时进入新的频率组，两者不能只改一个。
  4. 不能用单一优先队列：用 (频率, 时间戳) 堆可以做出结果，但 push 变成 O(log n) 且要惰性删除；本解法更简洁且均摊 O(1)。
  5. 扩展：如果要求 pop 返回“频率最低”的元素，思路完全对称，只需把 maxFreq 换成 minFreq，并在必要时维护最低频率即可（做法类似 LFU 缓存）。

C++ 实现

#include <vector>
#include <unordered_map>
#include <algorithm>
using namespace std;

class FreqStack {
public:
    FreqStack() {}

    void push(int val) {
        int f = ++freq[val];              // 频率自增
        group[f].push_back(val);          // 压入对应频率组（末尾即最新）
        maxFreq = max(maxFreq, f);
    }

    int pop() {
        int val = group[maxFreq].back();  // 最高频率组中最新的元素
        group[maxFreq].pop_back();
        --freq[val];
        if (group[maxFreq].empty()) {
            --maxFreq;                    // 该频率组空了，下移一层
        }
        return val;
    }

private:
    unordered_map<int, int> freq;              // 值 -> 频率
    unordered_map<int, vector<int>> group;     // 频率 -> 元素栈（vector 末尾当栈顶）
    int maxFreq = 0;
};

Python 实现

class FreqStack:

    def __init__(self):
        self.freq = {}        # 值 -> 当前频率
        self.group = {}       # 频率 -> 该频率的元素栈（列表末尾为栈顶）
        self.max_freq = 0     # 当前最大频率

    def push(self, val: int) -> None:
        f = self.freq.get(val, 0) + 1
        self.freq[val] = f
        self.group.setdefault(f, []).append(val)  # 压入频率 f 的栈
        self.max_freq = max(self.max_freq, f)

    def pop(self) -> int:
        stack = self.group[self.max_freq]
        val = stack.pop()                 # 最高频率组中最新的元素
        self.freq[val] -= 1
        if not stack:
            self.max_freq -= 1            # 该频率组空了，整体下移一层
        return val
