题目与约束

给你一个以字符串表示的非负整数 num 和一个整数 k ，移除这个数中的 k 位数字，使得剩下的数字最小。请你以字符串形式返回这个最小的数字。

示例 1 ：

<strong>输入：</strong>num = "1432219", k = 3
<strong>输出：</strong>"1219"
<strong>解释：</strong>移除掉三个数字 4, 3, 和 2 形成一个新的最小的数字 1219 。

示例 2 ：

<strong>输入：</strong>num = "10200", k = 1
<strong>输出：</strong>"200"
<strong>解释：</strong>移掉首位的 1 剩下的数字为 200. 注意输出不能有任何前导零。

示例 3 ：

<strong>输入：</strong>num = "10", k = 2
<strong>输出：</strong>"0"
<strong>解释：</strong>从原数字移除所有的数字，剩余为空就是 0 。

提示：

  • 1 <= k <= num.length <= 105

  • num 仅由若干位数字（0 - 9）组成

  • 除了 0 本身之外，num 不含任何前导零

核心不变量

从左到右扫描数字，用一个栈维护"当前已保留的最优前缀"，栈内始终保持单调不减；每当遇到比栈顶更小的数字且还有删除名额，就弹出栈顶（删掉左边更大的那位），最后若还有剩余名额就从末尾删除。剩下的高位越小，整体数值越小。

完整推导

思路推导

  1. 直觉与痛点（越小的高位决定整体）

比较两个等长数字大小，是从高位到低位比。所以要让结果最小，就必须让靠前的位尽量小。删除的 k 个数字应该优先用来"消灭"那些挡在更小数字前面的较大数字。

  1. 破局思路（单调栈，遇到更小就弹掉前面更大的）

依次读入每一位数字：

  • 只要"还有删除名额 k > 0"且"栈顶数字比当前数字大"，说明栈顶这个较大的高位挡了路，弹掉它、k--；
  • 然后把当前数字压栈。

这样栈里会保持单调不减，等价于"在允许删除 k 位的前提下，保留下来的是字典序最小的子序列"。

小例子 num = "1432219", k = 3：1 入栈 → 4 入栈 → 3 < 4 弹掉 4（k=2），压 3 → 2 < 3 弹掉 3（k=1），压 2 → 再遇 2 相等不弹，压 2 → 1 < 2 弹掉一个 2（k=0），压 1 → 9 入栈。结果 "1219"。

  1. 收尾与去零

如果扫描完 k 还没用完（例如数字本身单调递增 "12345"），说明没有"逆序对"可删，只能从末尾删掉剩下的 k 位，这样删掉的都是最低位，损失最小。最后去掉前导零，若结果为空则返回 "0"。

Java 实现（单调栈）

import java.util.ArrayDeque;
import java.util.Deque;

class Solution {
    public String removeKdigits(String num, int k) {
        Deque<Character> stack = new ArrayDeque<>();
        for (char c : num.toCharArray()) {
            // 当前数字更小，且还有删除名额：弹掉前面更大的高位
            while (k > 0 && !stack.isEmpty() && stack.peekLast() > c) {
                stack.pollLast();
                k--;
            }
            stack.addLast(c);
        }
        // 名额未用完：从末尾删除（去掉最低位）
        while (k > 0 && !stack.isEmpty()) {
            stack.pollLast();
            k--;
        }
        // 拼接并去掉前导零
        StringBuilder sb = new StringBuilder();
        for (char c : stack) {
            sb.append(c);
        }
        int i = 0;
        while (i < sb.length() && sb.charAt(i) == '0') {
            i++;
        }
        String res = sb.substring(i);
        return res.isEmpty() ? "0" : res;
    }
}

复杂度

  • 时间：O(n)。每个数字最多进栈一次、出栈一次，扫描与拼接都是线性的。
  • 空间：O(n)。栈最多存放全部 n 位数字。

易错点与扩展（面试高频考点）

  1. 收尾删除：扫描结束后 k 可能仍大于 0（如 "12345", k = 2），必须从末尾再删 k 位，否则结果位数不对。
  2. 前导零处理：删完后可能产生前导零（如 "10200" 删 1 得 "0200"），要 lstrip('0')；若全部删空则返回 "0"。
  3. 相等时不要弹：条件用 stack.top > c（严格大于），用 >= 会把相等的数字也删掉，白白浪费名额。
  4. k 等于长度：所有数字被删光，需返回 "0" 而不是空字符串。
  5. 暴力找峰值是 O(nk)：每次扫描找第一个下降点再删，最坏 O(n·k) 会超时；单调栈一趟 O(n) 才是标准解，也是"单调栈 + 贪心"的经典模板。

402. 移掉 K 位数字

C++ 实现

#include <string>
using namespace std;

class Solution {
public:
    string removeKdigits(string num, int k) {
        string st;                       // 用 string 当栈
        for (char c : num) {
            while (k > 0 && !st.empty() && st.back() > c) {
                st.pop_back();           // 弹掉前面更大的高位
                k--;
            }
            st.push_back(c);
        }
        while (k > 0 && !st.empty()) {   // 名额未用完，从末尾删
            st.pop_back();
            k--;
        }
        int i = 0;
        while (i < (int)st.size() && st[i] == '0') i++;   // 去前导零
        st = st.substr(i);
        return st.empty() ? "0" : st;
    }
};

Python 实现

class Solution:
    def removeKdigits(self, num: str, k: int) -> str:
        stack = []
        for c in num:
            while k > 0 and stack and stack[-1] > c:
                stack.pop()          # 弹掉前面更大的高位
                k -= 1
            stack.append(c)
        while k > 0 and stack:       # 名额未用完，从末尾删
            stack.pop()
            k -= 1
        res = ''.join(stack).lstrip('0')   # 去前导零
        return res if res else '0'
