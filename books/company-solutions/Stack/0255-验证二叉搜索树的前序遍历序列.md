## 题目与约束

## 核心不变量

> 先序遍历中，一旦某个节点被弹出栈，说明我们已经进入它的右子树，此后出现的所有值都必须大于该节点；用一个下界 `low` 记录"最近一次转向右子树时父节点的值"。

## 完整推导

### 思路推导

1. **BST 先序的结构**

   一棵 BST 的先序遍历是：`根 → 左子树（全部小于根） → 右子树（全部大于根）`。所以整段序列会先"一路向左下降"，形成一个递减的下降段，之后再"回退上升"进入某个祖先的右子树。

2. **用栈复现遍历路径**

   顺序扫描 `preorder`，把当前元素入栈，栈中保存的是"从根出发、尚未完成左子树的这条路径"，因此栈内自底向顶是递减的。

   当遇到 `x` 比栈顶大时，说明我们正从某个节点的左子树回退、进入它的右子树。此时栈顶（以及所有小于 `x` 的更早祖先）的右子树已经开始，它们永远不会再出现在后续序列里，于是把它们弹出，并把**最后弹出的值**记为新的下界 `low`：此后所有元素都必须大于这个祖先。

3. **下界校验**

   若某个 `x < low`，说明它落在了某个已完成祖先的右子树范围内，却比该祖先还小，违反 BST 性质，直接返回 `false`。

4. **小例子**

   `[5,2,1,3,6]`：依次入栈 5、2、1；遇到 3，弹出 1、2，`low=2`，入栈 3；遇到 6，弹出 3、5，`low=5`，入栈 6，全部合法 → `true`。

   `[5,2,6,1,3]`：遇到 6 时弹出 2、5，`low=5`；随后读到 1，`1 < 5` → `false`。

### Java 实现（单调栈）

```java
import java.util.ArrayDeque;
import java.util.Deque;

class Solution {
    public boolean verifyPreorder(int[] preorder) {
        Deque<Integer> stack = new ArrayDeque<>();
        int low = Integer.MIN_VALUE; // 当前允许的最小值（下界）

        for (int x : preorder) {
            // 落入已完成祖先的右子树，却比下界还小 -> 非法
            if (x < low) {
                return false;
            }
            // 回退到右子树：压平所有小于 x 的祖先，并抬高下界
            while (!stack.isEmpty() && stack.peek() < x) {
                low = stack.pop();
            }
            stack.push(x);
        }
        return true;
    }
}
```

### 复杂度

- 时间：O(n)。每个元素最多入栈一次、出栈一次，均摊下来是线性时间。
- 空间：O(n)。最坏情况（纯递减序列，即只有左链）时栈内会保留全部 n 个元素。

### 易错点与扩展（面试高频考点）

1. **只判断"递减再上升"是错的**：必须维护 `low` 下界，否则 `[5,2,6,1,3]` 这类"右子树里藏着小值"的非法序列会被漏判。
2. **`low` 的初值**：用 `Integer.MIN_VALUE` 而不是 `0`。本题元素为正，但通用做法应从最小可能值开始，避免把合法的负值误判。
3. **相等元素的处理**：本题保证元素互不相同；若题目允许重复，会比较 `<` 与 `<=` 的边界，需重新约定。
4. **进阶——O(1) 额外空间**：可以把 `preorder` 数组本身当作栈使用，用一个下标 `top` 模拟 `push`/`pop`，从而把额外空间降到 O(1)。
5. **面试追问**：单调栈弹出时 `low` 一定要更新为"最后弹出的那个值"（即最靠近 x 的那个更大的祖先），而不是最早弹出的最小值。

### C++ 实现

```cpp
#include <vector>
#include <climits>
using namespace std;

class Solution {
public:
    bool verifyPreorder(vector<int>& preorder) {
        vector<int> stack;          // 复用为单调栈
        long long low = LLONG_MIN;  // 下界
        for (int x : preorder) {
            if (x < low) return false;
            while (!stack.empty() && stack.back() < x) {
                low = stack.back(); // 抬高下界
                stack.pop_back();
            }
            stack.push_back(x);
        }
        return true;
    }
};
```

### Python 实现

```python
from typing import List

class Solution:
    def verifyPreorder(self, preorder: List[int]) -> bool:
        stack = []
        low = float('-inf')  # 下界
        for x in preorder:
            if x < low:
                return False
            while stack and stack[-1] < x:
                low = stack.pop()  # 抬高下界
            stack.append(x)
        return True
```
