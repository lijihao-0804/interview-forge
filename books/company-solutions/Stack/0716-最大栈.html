核心不变量

主栈保存全部元素并维持栈序；辅助栈 maxStack 的栈顶始终等于主栈当前的最大值（相等时重复压入），因此 peekMax 就是取辅助栈栈顶。

完整推导

思路推导

  1. 直觉与痛点（为什么普通栈不够）

普通栈的 push / pop / top 都是 O(1)，但要"随时拿到最大值"，如果每次 peekMax 都扫描一遍栈，就退化成 O(n)。问题的本质是：最大值随 push/pop 动态变化，必须边压栈边维护。

  1. 破局思路（双栈并行）

主栈 stack 负责真实的入栈出栈顺序；辅助栈 maxStack 只在"新元素不小于当前最大值"时同步压入。这样 maxStack 的栈顶就是主栈里的当前最大值。 小例子：依次 push 5, 1, 5 → stack = [5,1,5]，maxStack = [5,5]（1 比 5 小，不入辅助栈；第二个 5 等于最大值，也要入），此时 peekMax = 5。

  1. 关键追问（popMax 怎么删"最靠上的最大值"？）

popMax 要删的不是栈顶，而是"值最大、且最靠近栈顶"的元素。做法：先 maxStack.pop() 拿到最大值 mx；再从主栈栈顶往下弹出元素并暂存到临时栈，直到遇到第一个 == mx 的元素（这就是最靠上的最大值）把它删掉；最后把临时栈里的元素按原顺序压回主栈。栈内其余元素的相对顺序完全不变。

  1. 小例子串起来：stack=[5,1,5]、maxStack=[5,5]，调用 popMax：mx=5，从栈顶扫到 5 立即命中删除，stack=[5,1]、maxStack=[5]，返回 5。随后 pop 得 1（1≠5，辅助栈不动），peekMax 仍是 5，与示例输出一致。

Java 实现（MaxStack 双栈）

import java.util.ArrayDeque;
import java.util.Deque;

class MaxStack {
    private final Deque<Integer> stack;    // 主栈：维护真实的栈顺序
    private final Deque<Integer> maxStack; // 辅助栈：栈顶始终是当前最大值

    public MaxStack() {
        stack = new ArrayDeque<>();
        maxStack = new ArrayDeque<>();
    }

    public void push(int x) {
        stack.push(x);
        // 只有 x 不小于当前最大值才同步入辅助栈；用 >= 才能保留重复的最大值
        if (maxStack.isEmpty() || x >= maxStack.peek()) {
            maxStack.push(x);
        }
    }

    public int pop() {
        int x = stack.pop();
        // 弹出的值正好等于当前最大值时，辅助栈才同步弹出（数值比较，Integer 会自动拆箱）
        if (!maxStack.isEmpty() && x == maxStack.peek()) {
            maxStack.pop();
        }
        return x;
    }

    public int top() {
        return stack.peek();
    }

    public int peekMax() {
        return maxStack.peek();
    }

    public int popMax() {
        int max = maxStack.pop();     // 先拿到当前最大值
        Deque<Integer> buffer = new ArrayDeque<>();
        // 从栈顶往下找最靠上的最大值，途中元素暂存到 buffer
        while (stack.peek() != max) { // Integer 与 int 比较会自动拆箱，等于数值比较
            buffer.push(stack.pop());
        }
        stack.pop();                  // 真正移除这个最靠上的最大值
        // 把暂存的元素原样压回，恢复其余元素的相对顺序
        while (!buffer.isEmpty()) {
            stack.push(buffer.pop());
        }
        return max;
    }
}

复杂度

  • 时间：push / top / peekMax 均为 O(1)；pop 为 O(1)；popMax 最坏需要把主栈顶部一段元素搬进搬出，为 O(n)。
  • 空间：O(n)。两个栈合计最多保存 n 个元素，popMax 的临时栈规模也不超过当前栈深。

易错点与扩展（面试高频考点）

  1. push 的条件必须是 >= 而不是 >：用严格大于时，重复的最大值只记录一份，一旦 pop/popMax 删掉一个最大值，辅助栈就提前弹空，之后 peekMax 直接出错。
  2. pop 的同步判断必须用 ==：只有弹出的值恰好等于 maxStack 栈顶时才同步弹出辅助栈，否则会把并非当前最大值的元素误同步掉。
  3. popMax 恢复顺序：暂存用栈（LIFO），压回时再 pop 出来，顺序才对；若用队列暂存再依次压回会颠倒顺序。
  4. Java 的 Integer 比较陷阱：Deque<Integer>.peek() 返回 Integer，与 int 用 ==/!= 会自动拆箱做数值比较（安全）；但若两个 Integer 直接用 ==，那是引用比较，必须改用 equals。
  5. 进阶 O(log n) 解法：用"双向链表 + 有序映射（TreeMap）"。双向链表维护栈的入出顺序（尾插尾删）；TreeMap<Integer, 栈结构> 记录"值 → 该值所有节点的位置"，其中最近压入的在栈顶。push 同时插入链表尾和映射；pop 删链表尾并从映射移除；peekMax 取 TreeMap.lastKey()；popMax 取 lastKey() 对应列表的最后一个节点删除。这样 top 为 O(1)，其余全为 O(log n)。

716. 最大栈

C++ 实现

#include <stack>
using namespace std;

class MaxStack {
private:
    stack<int> st;     // 主栈
    stack<int> maxSt;  // 辅助栈，栈顶为当前最大值
public:
    MaxStack() {}

    void push(int x) {
        st.push(x);
        // 用 >= 保留重复的最大值
        if (maxSt.empty() || x >= maxSt.top()) {
            maxSt.push(x);
        }
    }

    int pop() {
        int x = st.top();
        st.pop();
        if (!maxSt.empty() && x == maxSt.top()) {
            maxSt.pop();
        }
        return x;
    }

    int top() {
        return st.top();
    }

    int peekMax() {
        return maxSt.top();
    }

    int popMax() {
        int mx = maxSt.top();
        maxSt.pop();
        stack<int> buffer;
        // 找最靠上的最大值，途中元素暂存
        while (st.top() != mx) {
            buffer.push(st.top());
            st.pop();
        }
        st.pop(); // 移除该最大值
        // 原样压回，恢复顺序
        while (!buffer.empty()) {
            st.push(buffer.top());
            buffer.pop();
        }
        return mx;
    }
};

Python 实现

class MaxStack:
    def __init__(self):
        self.stack = []       # 主栈
        self.max_stack = []   # 辅助栈，栈顶为当前最大值

    def push(self, x: int) -> None:
        self.stack.append(x)
        # 用 >= 保留重复的最大值
        if not self.max_stack or x >= self.max_stack[-1]:
            self.max_stack.append(x)

    def pop(self) -> int:
        x = self.stack.pop()
        if self.max_stack and x == self.max_stack[-1]:
            self.max_stack.pop()
        return x

    def top(self) -> int:
        return self.stack[-1]

    def peekMax(self) -> int:
        return self.max_stack[-1]

    def popMax(self) -> int:
        mx = self.max_stack.pop()
        buffer = []
        # 找最靠上的最大值，途中元素暂存
        while self.stack[-1] != mx:
            buffer.append(self.stack.pop())
        self.stack.pop()  # 移除该最大值
        # 原样压回，恢复顺序
        while buffer:
            self.stack.append(buffer.pop())
        return mx
