难度中等核心模式单栈延迟计算：乘除立即合并，加减压栈求和时间复杂度O(n)空间复杂度O(n)

题目与约束

给你一个字符串表达式 s ，请你实现一个基本计算器来计算并返回它的值。

整数除法仅保留整数部分。

你可以假设给定的表达式总是有效的。所有中间结果将在 [-231, 231 - 1] 的范围内。

注意：不允许使用任何将字符串作为数学表达式计算的内置函数，比如 eval() 。

示例 1：

输入：s = "3+2*2"
输出：7

示例 2：

输入：s = " 3/2 "
输出：1

示例 3：

输入：s = " 3+5 / 2 "
输出：5

提示：

  • 1 <= s.length <= 3 * 105

  • s 由整数和算符 ('+', '-', '*', '/') 组成，中间由一些空格隔开

  • s 表示一个有效表达式

  • 表达式中的所有整数都是非负整数，且在范围 [0, 231 - 1] 内

  • 题目数据 保证 答案是一个 32-bit 整数

核心不变量

栈中累计的是所有尚未合并的「加法项」；每遇到乘除，立即与栈顶合并成新的一项。

完整推导

思路推导

  1. 痛点：乘除优先级高于加减。 如果老老实实从左到右算，3+2*2 会错误地算成 (3+2)*2=10。真正要做的是让 2*2 先算完，再参与加法。
  2. 破局：用栈把「加法项」一个个存起来。 用一个变量 num 累积当前数字、用 sign 记录数字前面的运算符（初始为 '+'）。遍历到下一个运算符或字符串结尾时，根据 sign 决定： - '+'：把 +num 压栈； - '-'：把 -num 压栈； - '*'：弹出栈顶乘上 num 再压回； - '/'：弹出栈顶除以 num 再压回。 最后把栈中所有数相加，就是答案。
  3. 小例子：3+2*2。 - 读到 3，遇 '+'：sign 原为 '+'，压入 3；sign='+'。 - 读到 2，遇 '*'：sign 为 '+'，压入 2；sign='*'。 - 读到 2，到末尾：sign 为 '*'，栈顶 2*2=4 压回。 - 栈 [3,4]，求和 7。✅
  4. 除法细节： 题目要求「只保留整数部分」即向零截断。C++/Java 的整数除法本身就向零截断，而 Python 的 // 是向下取整，需要额外处理。

Java 实现（单栈 + 延迟计算）

import java.util.ArrayDeque;
import java.util.Deque;

class Solution {
    public int calculate(String s) {
        Deque<Integer> stack = new ArrayDeque<>();
        int num = 0;              // 当前正在解析的数字
        char sign = '+';          // 当前数字前面的运算符，初始视作 '+'
        int n = s.length();

        for (int i = 0; i < n; i++) {
            char ch = s.charAt(i);
            // 1. 累计多位数
            if (Character.isDigit(ch)) {
                num = num * 10 + (ch - '0');
            }
            // 2. 遇到运算符，或到了末尾，就把上一个数字结算掉
            if ((!Character.isDigit(ch) && ch != ' ') || i == n - 1) {
                switch (sign) {
                    case '+': stack.push(num); break;
                    case '-': stack.push(-num); break;
                    case '*': stack.push(stack.pop() * num); break;
                    case '/': stack.push(stack.pop() / num); break; // int 除法向零截断
                }
                sign = ch;    // 更新为当前运算符
                num = 0;      // 清空，准备解析下一个数
            }
        }

        // 3. 栈中所有加法项求和
        int res = 0;
        while (!stack.isEmpty()) {
            res += stack.pop();
        }
        return res;
    }
}

C++ 实现

#include <string>
#include <stack>
#include <cctype>
using namespace std;

class Solution {
public:
    int calculate(string s) {
        stack<int> st;
        long long num = 0;
        char sign = '+';
        int n = s.size();

        for (int i = 0; i < n; ++i) {
            char ch = s[i];
            if (isdigit(ch)) {
                num = num * 10 + (ch - '0');
            }
            if ((!isdigit(ch) && ch != ' ') || i == n - 1) {
                if (sign == '+') {
                    st.push((int)num);
                } else if (sign == '-') {
                    st.push((int)-num);
                } else if (sign == '*') {
                    int top = st.top(); st.pop();
                    st.push(top * (int)num);
                } else { // '/'
                    int top = st.top(); st.pop();
                    st.push(top / (int)num); // C++ 整数除法向零截断
                }
                sign = ch;
                num = 0;
            }
        }

        int res = 0;
        while (!st.empty()) {
            res += st.top();
            st.pop();
        }
        return res;
    }
};

Python 实现

class Solution:
    def calculate(self, s: str) -> int:
        def trunc_div(a: int, b: int) -> int:
            # 向零截断的整数除法（Python 的 // 是向下取整）
            q = abs(a) // abs(b)
            return q if (a >= 0) == (b >= 0) else -q

        stack = []
        num = 0
        sign = '+'
        n = len(s)

        for i in range(n):
            ch = s[i]
            if ch.isdigit():
                num = num * 10 + int(ch)
            if (not ch.isdigit() and ch != ' ') or i == n - 1:
                if sign == '+':
                    stack.append(num)
                elif sign == '-':
                    stack.append(-num)
                elif sign == '*':
                    stack.append(stack.pop() * num)
                else:  # '/'
                    stack.append(trunc_div(stack.pop(), num))
                sign = ch
                num = 0

        return sum(stack)

复杂度

  • 时间：O(n)，字符串只被遍历一次，每个数字入栈一次、求和时出栈一次。
  • 空间：O(n)，栈最坏会保存 O(n) 个加法项（例如全是加减法时）。
易错点与扩展（面试高频考点）
  1. 多位数必须累积。 表达式里出现 123 这样的数字，要用 num = num * 10 + digit 逐位拼接，不能只看单字符。
  2. 末尾数字要补结算。 循环结束时最后一个数字还没有被压栈，必须用 i == n - 1 这一条件把它结算掉，否则漏算。
  3. Python 的除法陷阱。 // 是向下取整：-3 // 2 = -2，而题目要求向零截断得 -1。应写成向零截断的除法（如取绝对值相除再补符号，或用 int(a / b) 配合整数处理）。
  4. sign 记录的是「数字前面的算子」。 初值设成 '+'，这样第一个数字会被当作正数压栈，逻辑才自洽。
  5. 扩展：含括号。 若题目加上括号（如 224 题），可把括号内结果当作一个整体数再参与运算，或用两个栈「数字栈 + 符号栈」递归求解。
