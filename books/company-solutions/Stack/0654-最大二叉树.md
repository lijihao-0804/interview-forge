# 654. 最大二叉树

| 题目信息 | 内容 |
|---|---|
| 难度 | 中等 |
| 核心模式 | 分治：区间最大值作根，递归左右子区间 |
| 时间复杂度 | O(n²)（最坏）/ O(n log n)（平均） |
| 空间复杂度 | O(n) |

## 题目与约束

给定一个不重复的整数数组 `nums` 。**最大二叉树** 可以用下面的算法从 `nums` 递归地构建：

- 创建一个根节点，其值为 `nums` 中的最大值。
- 递归地在最大值 **左边** 的 **子数组前缀上** 构建左子树。
- 递归地在最大值 **右边** 的 **子数组后缀上** 构建右子树。

返回 *`nums` 构建的 **最大二叉树*** 。

**示例 1：**

```
输入：nums = [3,2,1,6,0,5]
输出：[6,3,5,null,2,0,null,null,1]
解释：递归调用如下所示：
- [3,2,1,6,0,5] 中的最大值是 6 ，左边部分是 [3,2,1] ，右边部分是 [0,5] 。
    - [3,2,1] 中的最大值是 3 ，左边部分是 [] ，右边部分是 [2,1] 。
        - 空数组，无子节点。
        - [2,1] 中的最大值是 2 ，左边部分是 [] ，右边部分是 [1] 。
            - 空数组，无子节点。
            - 只有一个元素，所以子节点是一个值为 1 的节点。
    - [0,5] 中的最大值是 5 ，左边部分是 [0] ，右边部分是 [] 。
        - 只有一个元素，所以子节点是一个值为 0 的节点。
        - 空数组，无子节点。
```

**示例 2：**

```
输入：nums = [3,2,1]
输出：[3,null,2,null,1]
```

**提示：**

- `1 <= nums.length <= 1000`
- `0 <= nums[i] <= 1000`
- `nums` 中的所有整数 **互不相同**

## 核心不变量

> 对区间 `[lo, hi]`，最大值所在下标 `m` 就是该子树的根，`[lo, m-1]` 全部挂成左子树、`[m+1, hi]` 全部挂成右子树；分治地维护"区间 → 子树"的对应关系。

## 完整推导

### 思路推导

1. **直觉（题干已经把算法写出来了）**

   题目直接给出了递归定义：最大值当根，左边递归建左子树，右边递归建右子树。所以最自然的解法就是照定义写递归分治。

2. **关键点（如何在一段区间里找最大值）**

   递归函数带上区间边界 `[lo, hi]`（避免反复拷贝子数组）。在区间内线性扫描找最大值下标 `m`，用它建根，再分别对 `[lo, m-1]`、`[m+1, hi]` 递归。

3. **递归终止**

   当 `lo > hi` 时区间为空，返回 `null`，对应"空子数组无子节点"。

4. **小例子（示例 2，nums = [3,2,1]）**

   - `[3,2,1]` 最大值 `3` 在下标 0 → 根 3，左边空，右边 `[2,1]`；
   - `[2,1]` 最大值 `2` → 根 2，左边空，右边 `[1]`；
   - `[1]` → 根 1。
   得到树 `3 → 右 2 → 右 1`，即输出 `[3,null,2,null,1]`。

5. **优化方向（单调栈 O(n)）**

   线性扫描找最大值让最坏情况（数组有序）退化为 `O(n²)`。可以用"单调递减栈"一次遍历建树：每个新节点不断弹出比它小的栈顶作为其左孩子，最后栈内元素依次成为右链，做到 O(n)。

### Java 实现（constructMaximumBinaryTree）

```java
class Solution {
    public TreeNode constructMaximumBinaryTree(int[] nums) {
        return build(nums, 0, nums.length - 1);
    }

    // 在闭区间 [lo, hi] 上构建最大二叉树
    private TreeNode build(int[] nums, int lo, int hi) {
        if (lo > hi) {
            return null; // 空区间，无子节点
        }

        // 找区间内最大值下标
        int maxIdx = lo;
        for (int i = lo + 1; i <= hi; i++) {
            if (nums[i] > nums[maxIdx]) {
                maxIdx = i;
            }
        }

        // 最大值作根，左右子区间递归构建
        TreeNode root = new TreeNode(nums[maxIdx]);
        root.left = build(nums, lo, maxIdx - 1);
        root.right = build(nums, maxIdx + 1, hi);
        return root;
    }
}
```

### 复杂度

- 时间：平均 O(n log n)，最坏 O(n²)。每层需扫描区间找最大值，随机数据树高期望 O(log n)；当数组已有序时树退化为链，每层扫描长度递减，总代价 O(n²)。
- 空间：O(n)，递归调用栈最坏深度 O(n)（链状树），另加新建树本身 O(n)。

### 易错点与扩展（面试高频考点）

1. **区间边界写错**：左子树是 `[lo, maxIdx-1]`、右子树是 `[maxIdx+1, hi]`，不要包含 `maxIdx` 本身，否则无限递归。
2. **终止条件**：必须用 `lo > hi` 返回 `null`，`lo == hi` 是合法的单元素区间，要正常建节点。
3. **重复拷贝子数组**：每层 `Arrays.copyOfRange` 会额外 O(n) 且难写边界，改成传下标区间更干净。
4. **最坏复杂度**：面试常追问"能否 O(n)"——答单调栈：维护递减栈，新值弹出更小的栈顶作其左孩子，栈顶剩余元素作新值的父/右链。
5. **与"从前序/中序构造二叉树"的联系**：本质都是先定根再划分区间，理解"根的位置划分左右子区间"这一不变量的迁移很关键。

## 力扣原题

[654. 最大二叉树](https://leetcode.cn/problems/maximum-binary-tree/)

### C++ 实现

```cpp
class Solution {
public:
    TreeNode* constructMaximumBinaryTree(vector<int>& nums) {
        return build(nums, 0, (int)nums.size() - 1);
    }

private:
    TreeNode* build(vector<int>& nums, int lo, int hi) {
        if (lo > hi) return nullptr; // 空区间

        int maxIdx = lo;
        for (int i = lo + 1; i <= hi; ++i) {
            if (nums[i] > nums[maxIdx]) maxIdx = i;
        }

        TreeNode* root = new TreeNode(nums[maxIdx]);
        root->left = build(nums, lo, maxIdx - 1);
        root->right = build(nums, maxIdx + 1, hi);
        return root;
    }
};
```

### Python 实现

```python
class Solution:
    def constructMaximumBinaryTree(self, nums: List[int]) -> Optional[TreeNode]:
        def build(lo: int, hi: int) -> Optional[TreeNode]:
            if lo > hi:
                return None  # 空区间

            max_idx = lo
            for i in range(lo + 1, hi + 1):
                if nums[i] > nums[max_idx]:
                    max_idx = i

            root = TreeNode(nums[max_idx])
            root.left = build(lo, max_idx - 1)
            root.right = build(max_idx + 1, hi)
            return root

        return build(0, len(nums) - 1)
```
