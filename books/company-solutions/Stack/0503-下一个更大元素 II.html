503. 下一个更大元素 II

本题学习状态正在读取学习记录…下次复习：—
本次复习：
按 M 快速切换薄弱标记
遮住推导与代码，先自己想，再逐段揭示
难度中等核心模式单调栈 + 循环数组遍历两圈时间复杂度O(n)空间复杂度O(n)

题目与约束

给定一个循环数组 nums （ nums[nums.length - 1] 的下一个元素是 nums[0] ），返回 nums 中每个元素的 下一个更大元素 。

数字 x 的 下一个更大的元素 是按数组遍历顺序，这个数字之后的第一个比它更大的数，这意味着你应该循环地搜索它的下一个更大的数。如果不存在，则输出 -1 。

示例 1:

输入: nums = [1,2,1]
输出: [2,-1,2]
解释: 第一个 1 的下一个更大的数是 2；
数字 2 找不到下一个更大的数；
第二个 1 的下一个最大的数需要循环搜索，结果也是 2。

示例 2:

输入: nums = [1,2,3,4,3]
输出: [2,3,4,-1,4]

提示:

  • 1 <= nums.length <= 104

  • -109 <= nums[i] <= 109

核心不变量

用一个单调递减栈保存“还没找到下一个更大元素”的下标；遍历两圈数组，当前元素比栈顶下标对应的值大时，栈顶就找到了答案并弹出。

完整推导

思路推导

  1. 先看无环版本

对普通数组，从右往左维护一个单调栈：栈里只保留可能成为“下一个更大元素”的候选，当前元素只要比栈顶大就不断弹出，弹完后栈顶就是答案。等价地，从左往右遍历时，把“等待答案”的下标压栈，遇到更大的当前值就结算栈顶。

  1. 循环数组怎么处理？

最直接的技巧是把数组“拉直”成长度 2n 的虚拟数组，但真正只复制一遍、用 i % n 映射下标即可。第二圈的作用是给“数组末尾还需要转头看前面”的元素补齐答案，这样每个元素最多被结算一次，不会重复。

  1. 只在前 n 个位置压栈

第二圈（i >= n）只用来结算第一圈遗留的栈元素，不再压栈，否则会重复入栈、重复写入答案。判断条件写成 if (i < n) stack.push(idx)。

  1. 小例子（[1,2,1]）
  • i=0：栈空，压入下标 0。
  • i=1（值 2）：2 > nums[0]=1，结算 res[0]=2，弹出；压入 1。
  • i=2（值 1）：1 < 2，压入 2。
  • i=3（3%3=0，值 1）：不压栈；1 < 2（栈顶），不结算。
  • i=4（4%3=1，值 2）：2 > nums[2]=1，结算 res[2]=2，弹出；此时栈顶 1，nums[1]=2 不小于 2，停止。
  • 剩下下标 1 始终没被结算，保持初始值 -1。结果 [2,-1,2]，正确。

Java 实现（nextGreaterElements）

import java.util.ArrayDeque;
import java.util.Arrays;
import java.util.Deque;

class Solution {
    public int[] nextGreaterElements(int[] nums) {
        int n = nums.length;
        int[] res = new int[n];
        Arrays.fill(res, -1); // 找不到更大元素时保持 -1

        Deque<Integer> stack = new ArrayDeque<>(); // 存下标，对应值单调递减

        // 遍历两圈：第二圈只结算，不再压栈
        for (int i = 0; i < 2 * n; i++) {
            int idx = i % n;
            while (!stack.isEmpty() && nums[stack.peek()] < nums[idx]) {
                res[stack.pop()] = nums[idx]; // 栈顶找到了下一个更大元素
            }
            if (i < n) {
                stack.push(idx); // 仅第一圈记录下标
            }
        }
        return res;
    }
}

C++ 实现

class Solution {
public:
    vector<int> nextGreaterElements(vector<int>& nums) {
        int n = nums.size();
        vector<int> res(n, -1);
        stack<int> st; // 存下标，对应值单调递减

        for (int i = 0; i < 2 * n; i++) {
            int idx = i % n;
            while (!st.empty() && nums[st.top()] < nums[idx]) {
                res[st.top()] = nums[idx];
                st.pop();
            }
            if (i < n) {
                st.push(idx);
            }
        }
        return res;
    }
};

Python 实现

class Solution:
    def nextGreaterElements(self, nums: list[int]) -> list[int]:
        n = len(nums)
        res = [-1] * n
        stack = []  # 存下标，对应值单调递减

        for i in range(2 * n):
            idx = i % n
            while stack and nums[stack[-1]] < nums[idx]:
                res[stack.pop()] = nums[idx]
            if i < n:
                stack.append(idx)
        return res

复杂度

  • 时间：O(n)，每个下标最多入栈一次、出栈一次，遍历两圈共 2n 次。
  • 空间：O(n)，单调栈最坏情况下容纳全部 n 个下标。
易错点与扩展（面试高频考点）
  1. 第二圈继续压栈：若 i >= n 时仍 push，同一元素会被重复入栈、导致答案被覆盖或下标混乱；务必只在 i < n 时压栈。
  2. 比较用 < 而非 <=：题目要“严格更大”，相等元素不构成答案，所以用 <；用 <= 会错误地把相等值当答案。
  3. 循环长度：i < 2 * n 遍历两圈最直观；由于只在 i < n 时压栈，第二圈只需覆盖下标 0 ~ n-2，写成 2 * n - 1 也已足够，不会漏解。
  4. 结果初始化：所有位置先填 -1，天然处理“不存在更大元素”的情形，无需额外判断。
  5. 扩展：同类型还有“每日温度”“柱状图中最大的矩形”“接雨水”等，都是单调栈思想；循环数组场景统一用“遍历两圈 + 取模”即可复用。
