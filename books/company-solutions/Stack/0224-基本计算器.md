# 224. 基本计算器

| 题目信息 | 内容 |
|---|---|
| 难度 | 困难 |
| 核心模式 | 栈保存"括号前的累加值与符号"，单次扫描求值 |
| 时间复杂度 | O(n) |
| 空间复杂度 | O(n) |

## 题目与约束

给你一个字符串表达式 `s` ，请你实现一个基本计算器来计算并返回它的值。

注意:不允许使用任何将字符串作为数学表达式计算的内置函数，比如 `eval()` 。

 

示例 1：

```
<strong>输入：</strong>s = "1 + 1"
<strong>输出：</strong>2
```

示例 2：

```
<strong>输入：</strong>s = " 2-1 + 2 "
<strong>输出：</strong>3
```

示例 3：

```
<strong>输入：</strong>s = "(1+(4+5+2)-3)+(6+8)"
<strong>输出：</strong>23
```

 

提示：

- `1 <= s.length <= 3 * 105`

- `s` 由数字、`'+'`、`'-'`、`'('`、`')'`、和 `' '` 组成

- `s` 表示一个有效的表达式

- `'+'` 不能用作一元运算(例如， `"+1"` 和 `"+(2 + 3)"` 无效)

- `'-'` 可以用作一元运算(即 `"-1"` 和 `"-(2 + 3)"` 是有效的)

- 输入中不存在两个连续的操作符

- 每个数字和运行的计算将适合于一个有符号的 32位 整数

[🔗 前往力扣原题验证 →](https://leetcode.cn/problems/basic-calculator/)

## 核心不变量

> 扫描过程中维护"当前括号层的累加值 `res`、当前符号 `sign`、正在读的数字 `num`"；遇到 `'('` 就把外层 `res` 与 `sign` 压栈，遇到 `')'` 再取出并合并。

## 完整推导

### 思路推导

1. **直觉与痛点**：表达式只有加减和括号，没有乘除，也没有优先级问题——真正难的是**括号嵌套**：进入括号时要"暂停外层、开始内层"，出括号时要把内层结果按外层符号合并回来。

2. **破局思路（单层扫描 + 栈）**：维护三个变量：
   - `res`：当前层的累加和（不含正在读的数字）；
   - `num`：正在拼的数字（可能多位）；
   - `sign`：`num` 前面要乘的符号，`+1` 或 `-1`。

   每遇到 `+`/`-`，就把上一段 `sign * num` 结算进 `res`，重置 `num`，更新 `sign`。

3. **处理括号（关键）**：遇到 `'('` 时，把当前的 `res` 和 `sign` **压栈**（相当于"存档外层现场"），然后把 `res`、`sign`、`num` 归零，开始独立计算括号内部。遇到 `')'` 时，先把当前段 `sign * num` 结算进 `res`，再从栈里弹出外层 `sign` 与 `res`，令 `res = 外层res + 外层sign * 内层res`。

4. **收尾**：循环结束后，最后一段 `num` 还没结算，补一句 `res += sign * num`。

   小例子：`"-(2+3)"`。读到 `-` 时 `sign=-1`；读到 `(` 压栈 `(res=0, sign=-1)` 后内层重算得 5；`)` 时合并 `0 + (-1)*5 = -5`。一元负号就这样被自然支持。

### Java 实现（符号栈单次扫描）

```java
import java.util.ArrayDeque;
import java.util.Deque;

class Solution {
    public int calculate(String s) {
        Deque<Integer> stack = new ArrayDeque<>();
        int res = 0;    // 当前层累加和
        int num = 0;    // 正在读的数字
        int sign = 1;   // 当前数字的符号
        for (int i = 0; i < s.length(); i++) {
            char c = s.charAt(i);
            if (Character.isDigit(c)) {
                num = num * 10 + (c - '0');
            } else if (c == '+') {
                res += sign * num; num = 0; sign = 1;
            } else if (c == '-') {
                res += sign * num; num = 0; sign = -1;
            } else if (c == '(') {
                stack.push(res);    // 存档外层累加值
                stack.push(sign);   // 存档外层符号
                res = 0; sign = 1; num = 0;
            } else if (c == ')') {
                res += sign * num; num = 0;          // 结算内层最后一段
                int prevSign = stack.pop();
                int prevRes = stack.pop();
                res = prevRes + prevSign * res;      // 与外层合并
            }
            // c == ' ' 时直接忽略
        }
        res += sign * num;   // 结算最后一段
        return res;
    }
}
```

### 复杂度

- 时间：O(n)，每个字符恰好处理一次。
- 空间：O(n)，最坏情况下括号嵌套深度达 n/2，栈中元素随之增长。

### 易错点与扩展（面试高频考点）

1. **括号内要先结算 `num`**：在处理 `')'` 时若忘了 `res += sign * num`，形如 `"(1+(4+5+2)-3)"` 里紧贴右括号的数字会丢失。
2. **压栈顺序与出栈顺序**：压栈是 `res` 再 `sign`，出栈就得先弹 `sign` 再弹 `res`，顺序反了就全错。
3. **一元负号**：`'-'` 可以是一元运算符。本解法用 `sign` 天然支持，无需特判；切忌把 `'+'` 当一元处理（题目保证不会出现）。
4. **多位数与空格**：数字要 `num*10 + digit` 逐位拼；空格直接跳过，不要参与任何分支。
5. **扩展**：若加入乘除（LeetCode 227），需要在读到数字后按乘除优先级先与栈顶合并，再入栈；若要求支持所有运算符与括号，则用双栈（操作数栈 + 操作符栈）或转后缀表达式求值。

### C++ 实现

```cpp
#include <string>
#include <stack>
using namespace std;

class Solution {
public:
    int calculate(string s) {
        stack<long long> st;
        long long res = 0, num = 0;
        int sign = 1;
        for (char c : s) {
            if (c >= '0' && c <= '9') {
                num = num * 10 + (c - '0');
            } else if (c == '+') {
                res += sign * num; num = 0; sign = 1;
            } else if (c == '-') {
                res += sign * num; num = 0; sign = -1;
            } else if (c == '(') {
                st.push(res);
                st.push(sign);
                res = 0; sign = 1; num = 0;
            } else if (c == ')') {
                res += sign * num; num = 0;
                int prevSign = st.top(); st.pop();
                long long prevRes = st.top(); st.pop();
                res = prevRes + prevSign * res;
            }
            // 空格忽略
        }
        res += sign * num;
        return (int) res;
    }
};
```

### Python 实现

```python
class Solution:
    def calculate(self, s: str) -> int:
        stack = []
        res = 0
        num = 0
        sign = 1
        for c in s:
            if c.isdigit():
                num = num * 10 + int(c)
            elif c == '+':
                res += sign * num; num = 0; sign = 1
            elif c == '-':
                res += sign * num; num = 0; sign = -1
            elif c == '(':
                stack.append(res)      # 存档外层累加值
                stack.append(sign)     # 存档外层符号
                res = 0; sign = 1; num = 0
            elif c == ')':
                res += sign * num; num = 0
                prev_sign = stack.pop()
                prev_res = stack.pop()
                res = prev_res + prev_sign * res
        res += sign * num
        return res
```
