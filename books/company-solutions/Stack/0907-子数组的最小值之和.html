题目与约束

给定一个整数数组 arr，找到 min(b) 的总和，其中 b 的范围为 arr 的每个（连续）子数组。

由于答案可能很大，因此 返回答案模 10^9 + 7。

示例 1：

输入：arr = [3,1,2,4]
输出：17
解释：
子数组为 [3]，[1]，[2]，[4]，[3,1]，[1,2]，[2,4]，[3,1,2]，[1,2,4]，[3,1,2,4]。
最小值为 3，1，2，4，1，1，2，1，1，1，和为 17。

示例 2：

输入：arr = [11,81,94,43,3]
输出：444

提示：

  • 1 <= arr.length <= 3 * 10^4
  • 0 <= arr[i] <= 3 * 10^4

核心不变量

换个视角：不要枚举子数组，而是枚举「最小值是谁」。元素 arr[i] 作为最小值的子数组个数 =（左边可选起点数）×（右边可选终点数），总数乘以 arr[i] 就是它对答案的贡献。

完整推导

思路推导

  1. 痛点：子数组共有 O(n²) 个，逐一求最小值是 O(n³)，显然不行。需要把「子数组」的视角翻转成「元素」的视角。

  2. 贡献法：对每个位置 i，找出所有「以 arr[i] 为最小值」的子数组。设左边第一个 严格小于 arr[i] 的位置为 L，右边第一个 小于或等于 arr[i] 的位置为 R。则合法的左端点有 i - L 种、右端点有 R - i 种，贡献为 arr[i] * (i - L) * (R - i)。

  3. 为什么两边取法不同（去重的关键）：若两边都用「严格小于」或都用「小于等于」，遇到相等元素时同一子数组会被重复计算（或漏算）。约定「左边严格小于、右边小于等于」，让相等的元素只在最右边那一个上结算，保证每个子数组的最小值唯一归属。

  4. 单调栈求边界：正向扫描用单调递增栈（栈内元素值递增），弹出条件为 arr[栈顶] >= arr[i]，弹出的瞬间就确定了它的右边界（下一个更小或相等）；反向扫描同理求左边界（弹出条件 arr[栈顶] > arr[i]），各 O(n)。

  5. 小例子：arr = [3,1,2,4]。 - 3：左无更小 → 左 1 种；右边第一个 ≤3 是 1（下标 1）→ 右 1 种；贡献 3*1*1 = 3。 - 1：左 2 种、右 3 种 → 1*2*3 = 6。 - 2：左 1 种、右 2 种 → 2*1*2 = 4。 - 4：左 1 种、右 1 种 → 4*1*1 = 4。 - 合计 3+6+4+4 = 17，与示例一致。

Java 实现（sumSubarrayMins）

import java.util.ArrayDeque;
import java.util.Deque;

class Solution {
    private static final int MOD = 1_000_000_007;

    public int sumSubarrayMins(int[] arr) {
        int n = arr.length;
        int[] left = new int[n];   // 以 i 为最小值时，左端点可选个数
        int[] right = new int[n];  // 以 i 为最小值时，右端点可选个数
        Deque<Integer> stack = new ArrayDeque<>();

        // 1. 求左边第一个严格小于 arr[i] 的位置
        for (int i = 0; i < n; i++) {
            while (!stack.isEmpty() && arr[stack.peek()] >= arr[i]) {
                stack.pop();
            }
            left[i] = stack.isEmpty() ? i + 1 : i - stack.peek();
            stack.push(i);
        }

        stack.clear();

        // 2. 求右边第一个小于等于 arr[i] 的位置（保证重复元素不重复计数）
        for (int i = n - 1; i >= 0; i--) {
            while (!stack.isEmpty() && arr[stack.peek()] > arr[i]) {
                stack.pop();
            }
            right[i] = stack.isEmpty() ? n - i : stack.peek() - i;
            stack.push(i);
        }

        // 3. 累加每个元素的贡献
        long res = 0;
        for (int i = 0; i < n; i++) {
            res = (res + (long) arr[i] * left[i] % MOD * right[i]) % MOD;
        }
        return (int) res;
    }
}

复杂度

  • 时间：O(n)，两个方向各扫描一次，每个下标最多入栈、出栈各一次。
  • 空间：O(n)，两个边界数组与单调栈。

易错点与扩展（面试高频考点）

  1. 重复元素的计数方向不一致：一侧用「严格小于」另一侧必须用「小于等于」，否则相等元素会被重复累加，答案偏大。这是本题最容易踩的坑。
  2. 整数溢出：arr[i] * left[i] * right[i] 最大可达约 3e4 × 3e4 × 3e4，远超 int，必须用 long 并在累加过程取模。
  3. 边界哨兵：栈为空时用 i+1（左边全可取）、n-i（右边全可取）表示，别写成 0。
  4. 单调栈一维 DP 写法：也可一趟求出「以 i 结尾的所有子数组最小值之和」dp[i] = dp[j] + arr[i]*(i-j)（j 为左侧更小元素），累加 dp[i] 即为答案，思路上等价。
  5. 栈存下标而非值：需要下标来计算区间长度，因此栈里放索引。

C++ 实现

class Solution {
public:
    int sumSubarrayMins(vector<int>& arr) {
        const int MOD = 1'000'000'007;
        int n = arr.size();
        vector<int> left(n), right(n);
        stack<int> st;

        // 左边第一个严格小于 arr[i] 的位置
        for (int i = 0; i < n; i++) {
            while (!st.empty() && arr[st.top()] >= arr[i]) st.pop();
            left[i] = st.empty() ? i + 1 : i - st.top();
            st.push(i);
        }

        while (!st.empty()) st.pop();

        // 右边第一个小于等于 arr[i] 的位置
        for (int i = n - 1; i >= 0; i--) {
            while (!st.empty() && arr[st.top()] > arr[i]) st.pop();
            right[i] = st.empty() ? n - i : st.top() - i;
            st.push(i);
        }

        long long res = 0;
        for (int i = 0; i < n; i++) {
            res = (res + (long long) arr[i] * left[i] % MOD * right[i]) % MOD;
        }
        return (int) res;
    }
};

Python 实现

class Solution:
    def sumSubarrayMins(self, arr: List[int]) -> int:
        MOD = 10 ** 9 + 7
        n = len(arr)
        left = [0] * n
        right = [0] * n
        stack = []

        # 左边第一个严格小于 arr[i] 的位置
        for i in range(n):
            while stack and arr[stack[-1]] >= arr[i]:
                stack.pop()
            left[i] = i + 1 if not stack else i - stack[-1]
            stack.append(i)

        stack.clear()

        # 右边第一个小于等于 arr[i] 的位置
        for i in range(n - 1, -1, -1):
            while stack and arr[stack[-1]] > arr[i]:
                stack.pop()
            right[i] = n - i if not stack else stack[-1] - i
            stack.append(i)

        res = 0
        for i in range(n):
            res = (res + arr[i] * left[i] * right[i]) % MOD
        return res
