# 678. 有效的括号字符串

| 题目信息 | 内容 |
|---|---|
| 难度 | 中等 |
| 核心模式 | 贪心维护未匹配左括号数量的可行区间 |
| 时间复杂度 | O(n) |
| 空间复杂度 | O(1) |

## 题目与约束

给你一个只包含三种字符的字符串，支持的字符类型分别是 `'('`、`')'` 和 `'*'`。请你检验这个字符串是否为有效字符串，如果是**有效**字符串返回 `true`。

**有效**字符串符合如下规则：

- 任何左括号 `'('` 必须有相应的右括号 `')'`。
- 任何右括号 `')'` 必须有相应的左括号 `'('`。
- 左括号 `'('` 必须在对应的右括号之前 `')'`。
- `'*'` 可以被视为单个右括号 `')'`，或单个左括号 `'('`，或一个空字符串 `""`。

**示例 1：**

```
输入：s = "()"
输出：true
```

**示例 2：**

```
输入：s = "(*)"
输出：true
```

**示例 3：**

```
输入：s = "(*))"
输出：true
```

**提示：**

- `1 <= s.length <= 100`
- `s[i]` 为 `'('`、`')'` 或 `'*'`

## 核心不变量

> 扫描过程中，只要维护“当前未匹配左括号数量”的可能取值区间 `[low, high]`，且 `low` 始终不为负、`high` 始终不为负，扫描结束时 `low == 0` 即存在合法匹配。

## 完整推导

### 思路推导

1. **直觉与痛点（`'*'` 带来不确定性）**

   如果只有 `'('` 和 `')'`，只需一个计数器：遇 `'('` 加一、遇 `')'` 减一，全程非负且结束为零即可。但 `'*'` 可以变成 `'('`、`')'` 或空串，同一条路径上它会“上下浮动”，单一计数器无法同时表达所有可能。

2. **破局思路（用区间代替单值）**

   与其追踪某一个计数，不如追踪所有可能计数的**范围** `[low, high]`：

   - 遇 `'('`：所有情况都加一，`low++`、`high++`。
   - 遇 `'*'`：最“省”的用法是当右括号，`low = max(low-1, 0)`；最“费”的用法是当左括号，`high++`。
   - 遇 `')'`：所有情况都减一，`low = max(low-1, 0)`、`high--`。

   其中 `low` 用 `max(...,0)` 截断，是因为未匹配左括号数一旦变负（多出右括号）我们会立刻判定不可行；把 `low` 夹在 0 表示“可以选择让某些 `'*'` 当空串或右括号把亏空补齐”。

3. **关键追问（何时判失败、何时判成功？）**

   - 若某一步 `high < 0`，说明即使把所有 `'*'` 都当作左括号也不够匹配当前右括号，**直接返回 `false`**。
   - 扫描结束后，只要 `low == 0`，就说明存在一种 `'*'` 的分配方式让左右括号完全配对（`high` 只需 ≥ 0 即可，多出的左括号可用 `'*'` 当空串抵消）。
   - 例：`s = "(*))"`，依次得到区间 `[1,1] → [1,2] → [0,1] → [0,0]`，结束时 `low == 0`，返回 `true`。

### Java 实现（贪心区间法）

```java
class Solution {
    public boolean checkValidString(String s) {
        // low：把 '*' 尽量当右括号时，未匹配左括号的最少数量
        // high：把 '*' 尽量当左括号时，未匹配左括号的最多数量
        int low = 0, high = 0;
        for (int i = 0; i < s.length(); i++) {
            char c = s.charAt(i);
            if (c == '(') {
                low++;
                high++;
            } else if (c == ')') {
                low = Math.max(low - 1, 0); // 亏空则夹到 0（靠 '*' 补）
                high--;
                if (high < 0) {
                    return false; // 再多 '*' 也补不回这个右括号
                }
            } else { // '*'
                low = Math.max(low - 1, 0); // 当右括号或空串
                high++;                     // 当左括号
            }
        }
        // 只要可能存在“全部匹配”的方案，即 low 能降到 0
        return low == 0;
    }
}
```

### 复杂度

- 时间：`O(n)`，只需一次线性扫描，每个字符做常数次更新。
- 空间：`O(1)`，只使用 `low`、`high` 两个整型变量。

### 易错点与扩展（面试高频考点）

1. **不能用单一计数器**：`'*'` 让计数存在多种可能，必须用 `[low, high]` 区间表达，否则会误判。
2. **`low` 要截断到 0**：遇 `')'` 或 `'*'` 时 `low = max(low-1, 0)`，表示“可以选择把某些 `'*'` 用来补右括号的亏空”；若忘记截断，`low` 变负会导致错误。
3. **`high < 0` 立即失败**：这说明右括号已经多到即使所有 `'*'` 都当左括号也救不回来。
4. **结束判定是 `low == 0` 而非 `high == 0`**：`high` 只是“最多可能”，多出的左括号可由 `'*'` 当空串消化。
5. **扩展：双栈解法**：用一个栈存 `'('` 的下标，另一个栈存 `'*'` 的下标，遇 `')'` 优先匹配 `'('`，不够则匹配 `'*'`；最后把剩余的 `'('` 与 `'*'` 按位置配对。时间 `O(n)`、空间 `O(n)`，思路直观但不如区间法省空间。

## 力扣原题

[678. 有效的括号字符串](https://leetcode.cn/problems/valid-parenthesis-string/)

### C++ 实现

```cpp
#include <string>
#include <algorithm>
using namespace std;

class Solution {
public:
    bool checkValidString(string s) {
        int low = 0, high = 0;
        for (char c : s) {
            if (c == '(') {
                ++low;
                ++high;
            } else if (c == ')') {
                low = max(low - 1, 0);
                --high;
                if (high < 0) return false;
            } else { // '*'
                low = max(low - 1, 0);
                ++high;
            }
        }
        return low == 0;
    }
};
```

### Python 实现

```python
class Solution:
    def checkValidString(self, s: str) -> bool:
        low = high = 0
        for c in s:
            if c == '(':
                low += 1
                high += 1
            elif c == ')':
                low = max(low - 1, 0)
                high -= 1
                if high < 0:
                    return False
            else:  # '*'
                low = max(low - 1, 0)
                high += 1
        return low == 0
```
