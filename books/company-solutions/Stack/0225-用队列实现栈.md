# 225. 用队列实现栈

| 题目信息 | 内容 |
|---|---|
| 难度 | 简单 |
| 核心模式 | 双队列倒腾，让队头始终是栈顶 |
| 时间复杂度 | push O(n)，pop/top/empty O(1) |
| 空间复杂度 | O(n) |

## 题目与约束

请你仅使用两个队列实现一个后入先出（LIFO）的栈，并支持普通栈的全部四种操作（`push`、`top`、`pop` 和 `empty`）。

实现 `MyStack` 类：

- `void push(int x)` 将元素 x 压入栈顶。

- `int pop()` 移除并返回栈顶元素。

- `int top()` 返回栈顶元素。

- `boolean empty()` 如果栈是空的，返回 `true` ；否则，返回 `false` 。

 

注意：

- 你只能使用队列的标准操作 —— 也就是 `push to back`、`peek/pop from front`、`size` 和 `is empty` 这些操作。

- 你所使用的语言也许不支持队列。 你可以使用 list （列表）或者 deque（双端队列）来模拟一个队列 , 只要是标准的队列操作即可。

 

示例：

```
<strong>输入：</strong>
["MyStack", "push", "push", "top", "pop", "empty"]
[[], [1], [2], [], [], []]
<strong>输出：</strong>
[null, null, null, 2, 2, false]

<strong>解释：</strong>
MyStack myStack = new MyStack();
myStack.push(1);
myStack.push(2);
myStack.top(); // 返回 2
myStack.pop(); // 返回 2
myStack.empty(); // 返回 False
```

 

提示：

- `1 <= x <= 9`

- 最多调用`100` 次 `push`、`pop`、`top` 和 `empty`

- 每次调用 `pop` 和 `top` 都保证栈不为空

 

进阶：你能否仅用一个队列来实现栈。

[🔗 前往力扣原题验证 →](https://leetcode.cn/problems/implement-stack-using-queues/)

## 核心不变量

> `q1` 的队头永远等于栈顶，整个队列按「从栈顶到栈底」的顺序排列。

## 完整推导

### 思路推导

1. **直觉与痛点：队列只会「先进先出」。** 队列从队头取、队尾放，天然是先进先出；而栈要求后进先出。要让最新压入的元素最先离开，必须想办法把它「顶」到队头。
2. **双队列配合：把新元素插到最前面。** 用 `q1` 存数据、`q2` 当临时中转。每次 `push`：新元素先放入 `q2`，再把 `q1` 中所有元素依次搬到 `q2`（它们自然排在新元素后面），最后交换 `q1`、`q2` 两个引用。这样新元素就稳稳落在 `q1` 的队头。
   - 小例子：`push(1)` 后 `q1=[1]`；再 `push(2)`：`q2=[2]`，把 `q1` 搬到 `q2` 得 `q2=[2,1]`，交换后 `q1=[2,1]`。此时 `q1.poll()` 得到 `2`，正是栈顶。
3. **加减法权衡。** 上面把代价压在 `push`（O(n) 搬移），换来 `pop/top/empty` 全是 O(1)。也可以反过来让 `push` O(1)、`pop` O(n)，两者总复杂度同阶，任选一种实现即可。

### Java 实现（双队列实现）
```java
import java.util.LinkedList;
import java.util.Queue;

class MyStack {
    // q1 始终存放栈内元素，栈顶元素位于 q1 的队头
    private Queue<Integer> q1;
    // q2 作为临时中转队列
    private Queue<Integer> q2;

    public MyStack() {
        q1 = new LinkedList<>();
        q2 = new LinkedList<>();
    }

    public void push(int x) {
        // 1. 新元素先放进辅助队列 q2
        q2.offer(x);
        // 2. 把 q1 中原有元素全部搬到 q2 的后面，使新元素排到队头
        while (!q1.isEmpty()) {
            q2.offer(q1.poll());
        }
        // 3. 交换两个引用，q1 重新成为"栈"
        Queue<Integer> tmp = q1;
        q1 = q2;
        q2 = tmp;
    }

    public int pop() {
        // 栈顶即 q1 队头，直接弹出
        return q1.poll();
    }

    public int top() {
        // 只读不删
        return q1.peek();
    }

    public boolean empty() {
        return q1.isEmpty();
    }
}
```

### 复杂度
- 时间：`push` 为 O(n)，需要把 `q1` 的 n 个元素搬移一次；`pop`、`top`、`empty` 均为 O(1)。
- 空间：O(n)，两个队列合计最多保存 n 个元素。

### 易错点与扩展（面试高频考点）

1. **交换引用而不是搬数据。** `push` 完成后要交换 `q1`、`q2` 的引用（或指针），不要试图把整个容器内容复制回 `q1`，否则多出无谓的开销。
2. **`top` 与 `pop` 别搞混。** `top` 只需「看一眼」队头，用 `peek()`；`pop` 才用 `poll()` 真正删除。题目保证调用 `pop/top` 时栈非空。
3. **进阶：单队列实现。** 只用一个队列也能做：`push(x)` 先把 x 入队，然后执行「队列长度减 1」次「弹出队头再压回队尾」，把新元素转到队头；其余操作不变。`push` O(n)，`pop/top` O(1)。
4. **复杂度取舍要讲清。** 常见追问是「能不能让所有操作都 O(1)」——用队列模拟栈无法做到所有操作严格 O(1)，本质上必有一次 O(n) 的搬移被摊到某一侧。
5. **不要依赖 `size` 以外的队列实现细节。** 题目限定只能用队列标准操作，避免直接按索引访问内部元素。

## 力扣原题

### C++ 实现
```cpp
#include <queue>
using namespace std;

class MyStack {
    queue<int> q1, q2; // q1 存数据，q2 中转
public:
    MyStack() {}

    void push(int x) {
        q2.push(x);              // 新元素先入 q2
        while (!q1.empty()) {    // 把 q1 全部搬到 q2 后面
            q2.push(q1.front());
            q1.pop();
        }
        swap(q1, q2);            // 交换后 q1 队头即栈顶
    }

    int pop() {
        int v = q1.front();
        q1.pop();
        return v;
    }

    int top() {
        return q1.front();
    }

    bool empty() {
        return q1.empty();
    }
};
```

### Python 实现
```python
from collections import deque


class MyStack:
    def __init__(self):
        self.q1 = deque()  # 存数据，队头即栈顶
        self.q2 = deque()  # 中转

    def push(self, x: int) -> None:
        self.q2.append(x)
        while self.q1:
            self.q2.append(self.q1.popleft())
        self.q1, self.q2 = self.q2, self.q1

    def pop(self) -> int:
        return self.q1.popleft()

    def top(self) -> int:
        return self.q1[0]

    def empty(self) -> bool:
        return not self.q1
```
