# 1475. 商品折扣后的最终价格

| 题目信息 | 内容 |
|---|---|
| 难度 | 简单 |
| 核心模式 | 单调递增栈求「右侧第一个不大于当前值」的元素 |
| 时间复杂度 | O(n) |
| 空间复杂度 | O(n) |

## 题目与约束

给你一个数组 `prices`，其中 `prices[i]` 是商店里第 `i` 件商品的价格。

商店里正在进行促销活动，如果你要买第 `i` 件商品，那么你可以得到与 `prices[j]` 相等的折扣，其中 `j` 是满足 `j > i` 且 `prices[j] <= prices[i]` 的 **最小下标**，如果没有满足条件的 `j`，你将没有任何折扣。

请你返回一个数组，数组中第 `i` 个元素是折扣后你购买商品 `i` 最终需要支付的价格。

**示例 1：**

```
输入：prices = [8,4,6,2,3]
输出：[4,2,4,2,3]
解释：
商品 0 的价格为 prices[0]=8，你将得到 prices[1]=4 的折扣，所以最终价格为 8 - 4 = 4。
商品 1 的价格为 prices[1]=4，你将得到 prices[3]=2 的折扣，所以最终价格为 4 - 2 = 2。
商品 2 的价格为 prices[2]=6，你将得到 prices[3]=2 的折扣，所以最终价格为 6 - 2 = 4。
商品 3 和 4 都没有折扣。
```

**示例 2：**

```
输入：prices = [1,2,3,4,5]
输出：[1,2,3,4,5]
解释：在这个例子中，所有商品都没有折扣。
```

**示例 3：**

```
输入：prices = [10,1,1,6]
输出：[9,0,1,6]
```

**提示：**

- `1 <= prices.length <= 500`
- `1 <= prices[i] <= 10^3`

## 核心不变量

> 用单调递增栈保存「尚未找到折扣」的商品下标。当扫描到 `prices[i]` 时，凡栈中价格 `>= prices[i]` 的下标，其右侧第一个不大于自己的元素正是 `i`（最近的），可以立即结算；结算后弹出。栈内价格始终保持从底到顶递增。

## 完整推导

### 思路推导

1. **暴力做法的痛点**
   对每个 `i` 向右找第一个 `prices[j] <= prices[i]`，最坏 O(n²)。本题 n≤500 能过，但面试要考察更优的单调栈。

2. **换个角度：谁来「结算」某个商品？**
   一个商品 `i` 在等到右边第一个「不大于自己」的元素时才能结算。把还没结算的商品下标按价格维护起来，一旦来了一个更便宜（或相等）的价格，它就能给之前那些价格更高的商品当折扣。

3. **单调栈实现**
   从左到右遍历，维护一个价格 **严格递增**（从栈底到栈顶）的下标栈。对当前 `i`：
   - 当栈非空且 `prices[栈顶] >= prices[i]`，说明栈顶商品遇到了右侧第一个不高于自己的价格，结算 `res[栈顶] = prices[栈顶] - prices[i]`，弹出；
   - 反复直到栈顶价格小于 `prices[i]`；
   - 再把 `i` 压栈。

   小例子：`[8,4,6,2,3]`。8 入栈；遇到 4，8≥4 结算 `8-4=4`，4 入栈；遇到 6，6 不触发（4<6），入栈；遇到 2，6≥2 结算 `6-2=4`，4≥2 结算 `4-2=2`，2 入栈；遇到 3，2<3 不结算，入栈。最终 `[4,2,4,2,3]`。

4. **没有折扣的商品**
   扫描结束后仍留在栈里的下标，右侧没有不高于它的价格，保持原价即可（结果数组初始化为 `prices` 的副本）。

### Java 实现（finalPrices）

```java
import java.util.ArrayDeque;
import java.util.Deque;

class Solution {
    public int[] finalPrices(int[] prices) {
        int n = prices.length;
        int[] res = prices.clone();       // 默认无折扣，等于原价
        Deque<Integer> stack = new ArrayDeque<>(); // 存下标，价格单调递增

        for (int i = 0; i < n; i++) {
            // 当前价格不高于栈顶，栈顶商品找到了右侧第一个折扣
            while (!stack.isEmpty() && prices[stack.peek()] >= prices[i]) {
                int idx = stack.pop();
                res[idx] = prices[idx] - prices[i];
            }
            stack.push(i);
        }
        return res;
    }
}
```

### 复杂度

- 时间：O(n)。每个下标至多入栈、出栈各一次，栈操作摊还 O(1)，整体线性。
- 空间：O(n)。栈最坏保存全部下标（如价格严格递增时）；结果数组 O(n)。

### 易错点与扩展（面试高频考点）

1. **比较符号要用 `>=`**：题目要求 `prices[j] <= prices[i]`，即允许相等价格作为折扣。写成 `>` 会漏掉「同价折扣」的情况（如 `[10,1,1,6]` 中第二件 1 应得第一件 1 的全额折扣，结果为 0）。
2. **「最小下标」由单调栈天然保证**：一旦遇到满足条件的 `i` 就立即结算并弹出，此时 `i` 就是最近的合法下标，无需额外查找。
3. **结果初始化**：先把 `res` 拷贝为 `prices`，只对找到折扣的商品做减法，避免为「无折扣」单独判空。
4. **栈中存下标而非值**：结算时要写回第 `idx` 个位置，必须存下标；只存值无法定位。
5. **扩展**：这是「下一个更小/更大元素」系列的模板题。把 `>=` 改成 `>` 并反转比较方向，即可求「下一个更大元素」（LeetCode 496/503）；再进一步可解决「柱状图中最大的矩形」（84）与「接雨水」（42）等单调栈经典题。

## 力扣原题

[1475. 商品折扣后的最终价格](https://leetcode.cn/problems/final-prices-with-a-special-discount-in-a-shop/)

### C++ 实现

```cpp
#include <vector>
using namespace std;

class Solution {
public:
    vector<int> finalPrices(vector<int>& prices) {
        int n = prices.size();
        vector<int> res = prices; // 默认无折扣
        vector<int> st;           // 存下标，价格单调递增
        for (int i = 0; i < n; i++) {
            while (!st.empty() && prices[st.back()] >= prices[i]) {
                int idx = st.back();
                st.pop_back();
                res[idx] = prices[idx] - prices[i];
            }
            st.push_back(i);
        }
        return res;
    }
};
```

### Python 实现

```python
from typing import List

class Solution:
    def finalPrices(self, prices: List[int]) -> List[int]:
        n = len(prices)
        res = prices[:]  # 默认无折扣
        stack = []       # 存下标，价格单调递增
        for i in range(n):
            while stack and prices[stack[-1]] >= prices[i]:
                idx = stack.pop()
                res[idx] = prices[idx] - prices[i]
            stack.append(i)
        return res
```
