# 1574. 删除最短的子数组使剩余数组有序

| 题目信息 | 内容 |
|---|---|
| 难度 | 中等 |
| 核心模式 | 双指针收缩：保留一个有序前缀 + 一个有序后缀 |
| 时间复杂度 | O(n) |
| 空间复杂度 | O(1) |

## 题目与约束

给你一个整数数组 `arr`，请你删除一个子数组（可以为空），使得 `arr` 中剩下的元素是 **非递减** 的。

一个子数组指的是原数组中连续的一个子序列。

请你返回满足题目要求的最短子数组的长度。

**示例 1：**

```
输入：arr = [1,2,3,10,4,2,3,5]
输出：3
解释：我们需要删除的最短子数组是 [10,4,2] ，长度为 3 。剩余元素形成非递减数组 [1,2,3,3,5] 。
另一个正确的解为删除子数组 [3,10,4] 。
```

**示例 2：**

```
输入：arr = [5,4,3,2,1]
输出：4
解释：由于数组是严格递减的，我们只能保留一个元素。所以我们需要删除长度为 4 的子数组，要么删除 [5,4,3,2]，要么删除 [4,3,2,1]。
```

**示例 3：**

```
输入：arr = [1,2,3]
输出：0
解释：数组已经是非递减的了，我们不需要删除任何元素。
```

**示例 4：**

```
输入：arr = [1]
输出：0
```

**提示：**

- `1 <= arr.length <= 10^5`
- `0 <= arr[i] <= 10^9`

## 核心不变量

> 删除后剩下的元素一定是「原数组的一个有序前缀 + 原数组的一个有序后缀」；我们要找的就是让这个前缀尾与后缀头能够衔接（`arr[l] <= arr[r]`）的、删除区间最短的一对。

## 完整推导

### 思路推导

1. **直觉与痛点（能不能暴力？）**

   枚举所有可能的删除区间 `[i, j]` 再判断剩余是否有序，是 `O(n^2)` 甚至 `O(n^3)`，`n = 10^5` 直接超时。必须利用「有序」这一结构。

2. **关键观察（剩余部分只能是前后两段）**

   如果删除的是一段连续子数组，那么剩下的就是左边一段和右边一段拼接而成。要让整体非递减，左边这段自身必须非递减、右边这段自身也必须非递减，并且左段最大值不能超过右段最小值。

   因此先求出：
   - **最长有序前缀**：从下标 `0` 出发，一直右移，直到 `arr[i] > arr[i+1]` 停下，于是 `arr[0..i]` 为有序前缀；
   - **最长有序后缀**：从末尾出发，一直左移，直到 `arr[j-1] > arr[j]` 停下，于是 `arr[j..n-1]` 为有序后缀。

   小例子 `arr = [1,2,3,10,4,2,3,5]`：前缀停在 `i=3`（`3<=10` 成立，`10<=4` 不成立），后缀停在 `j=5`（`4<=2` 不成立）。

3. **破局思路（两个指针去接缝）**

   枚举「保留前缀的前 `l+1` 个元素」（`l` 从 `0` 走到 `i`），再让后缀起点 `r` 从 `j` 出发向右滑动，直到 `arr[r] >= arr[l]`，此时可以删掉中间 `(l, r)` 之间的全部元素，长度为 `r - l - 1`。由于 `arr[l]` 随 `l` 增大而增大，`r` 只会单调右移，不会回退，整体 `O(n)`。

   还要考虑两种「只保留一边」的情况：只保留后缀（删掉前 `j` 个，长度 `j`）、只保留前缀（当 `r` 走到 `n` 时自然覆盖）。

4. **回到示例 1**

   前缀 `l=1`（值 `2`）时，后缀第一个 `>= 2` 的位置是 `r=5`（值 `2`），删除长度 `5-1-1 = 3`，正好删掉 `[3,10,4]`，得到答案 `3`。

### Java 实现（findLengthOfShortestSubarray）

```java
class Solution {
    public int findLengthOfShortestSubarray(int[] arr) {
        int n = arr.length;

        // 1. 找最长非递减前缀的末尾下标 i
        int i = 0;
        while (i + 1 < n && arr[i] <= arr[i + 1]) {
            i++;
        }
        // 整个数组已经非递减，无需删除
        if (i == n - 1) {
            return 0;
        }

        // 2. 找最长非递减后缀的起始下标 j
        int j = n - 1;
        while (j > 0 && arr[j - 1] <= arr[j]) {
            j--;
        }

        // 情况：只保留后缀，删除前 j 个元素
        int ans = j;

        // 3. 枚举前缀保留到 l，用 r 找后缀能与 arr[l] 衔接的最靠左位置
        //    r 随 l 单调右移，总移动量 O(n)
        for (int l = 0, r = j; l <= i; l++) {
            while (r < n && arr[r] < arr[l]) {
                r++;
            }
            // 删除 (l, r) 之间的元素
            ans = Math.min(ans, r - l - 1);
        }
        return ans;
    }
}
```

### 复杂度

- 时间：O(n)，求前后缀各扫描一遍，双指针 `l`、`r` 都只单调前进，合计 O(n)。
- 空间：O(1)，只用了若干下标变量。

### 易错点与扩展（面试高频考点）

1. **漏掉「前缀 + 后缀拼接」**：只比较「保留前缀」和「保留后缀」两种方案会漏解，必须考虑两者接缝。
2. **接缝比较必须是 `arr[r] < arr[l]` 才右移**：因为要求非递减，`arr[r] == arr[l]` 是合法衔接，不能跳过。
3. **前后缀判定用 `<=`**：相等元素仍属于非递减，写成 `<` 会把相等区间错误切分。
4. **整数组已有序要提前返回 0**：否则 `j` 会算成 `0`、`i` 会等于 `n-1`，虽然也能兜住，但显式返回更清晰。
5. **双指针单调性**：`r` 不能在每轮 `l` 后重置回 `j`，否则退化成 `O(n^2)`。

## 力扣原题

### C++ 实现

```cpp
class Solution {
public:
    int findLengthOfShortestSubarray(vector<int>& arr) {
        int n = arr.size();

        // 最长非递减前缀末尾 i
        int i = 0;
        while (i + 1 < n && arr[i] <= arr[i + 1]) {
            i++;
        }
        if (i == n - 1) {
            return 0;
        }

        // 最长非递减后缀起点 j
        int j = n - 1;
        while (j > 0 && arr[j - 1] <= arr[j]) {
            j--;
        }

        // 只保留后缀的方案
        int ans = j;

        // 枚举前缀保留到 l，r 单调右移
        for (int l = 0, r = j; l <= i; l++) {
            while (r < n && arr[r] < arr[l]) {
                r++;
            }
            ans = min(ans, r - l - 1);
        }
        return ans;
    }
};
```

from typing import List


class Solution:
    def findLengthOfShortestSubarray(self, arr: List[int]) -> int:
        n = len(arr)

        # 最长非递减前缀末尾 i
        i = 0
        while i + 1 < n and arr[i] <= arr[i + 1]:
            i += 1
        if i == n - 1:
            return 0

        # 最长非递减后缀起点 j
        j = n - 1
        while j > 0 and arr[j - 1] <= arr[j]:
            j -= 1

        # 只保留后缀的方案
        ans = j

        # 枚举前缀保留到 l，r 单调右移
        r = j
        for l in range(i + 1):
            while r < n and arr[r] < arr[l]:
                r += 1

        return ans
