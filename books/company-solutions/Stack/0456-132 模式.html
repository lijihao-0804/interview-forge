时间复杂度 O(n)
空间复杂度 O(n)

题目与约束

给你一个整数数组 nums，数组中共有 n 个整数。132 模式的子序列 由三个整数 nums[i]、nums[j] 和 nums[k] 组成，并同时满足：

  • i < j < k
  • nums[i] < nums[k] < nums[j]

如果 nums 中存在 132 模式 的子序列，返回 true；否则，返回 false。

示例 1：

输入：nums = [1,2,3,4]
输出：false
解释：序列中不存在 132 模式的子序列。

示例 2：

输入：nums = [3,1,4,2]
输出：true
解释：序列中有 1 个 132 模式的子序列： [1, 4, 2] 。

示例 3：

输入：nums = [-1,3,2,0]
输出：true
解释：序列中有 3 个 132 模式的子序列： [-1, 3, 2]、[-1, 3, 0] 和 [-1, 2, 0] 。

提示：

  • n == nums.length
  • 1 <= n <= 2 * 10^5
  • -10^9 <= nums[i] <= 10^9

核心不变量

从右向左扫描时，栈中保存的是若干“候选的 nums[j]”，而变量 third 记录所有已被弹出的值里的最大值，即当前可用的最大 nums[k]；一旦遇到 nums[i] < third，说明 i < j < k 且 nums[i] < nums[k] < nums[j] 已同时成立。

完整推导

思路推导

  1. 直觉与痛点（三层暴力太慢）：直接三重循环枚举 i < j < k 是 O(n³)，n 可达 2*10^5，必然超时。要想降复杂度，就要把“固定 j 找左右两侧”的过程压到一次扫描里完成。

  2. 破局思路（从右往左，盯住 nums[k]）：132 的模式形如“小（nums[i]）→ 大（nums[j]）→ 中（nums[k]）”。我们逆序扫描，把已经见过的元素当成可能的 nums[j] 放进一个单调递减栈（栈底大、栈顶小）。当新元素 nums[i] 比栈顶大时，栈顶那些更小的元素就不可能再当 nums[j] 了，但它们可以降级成 nums[k]——用一个变量 third 记住这些被弹出值中的最大值（最理想的 nums[k]）。

  3. 判定（为什么 nums[i] < third 就赢）：third 是由某个 nums[j]（在 i 右边且比它大）弹出的，所以天然满足 nums[k] < nums[j] 且 k > j > i。此时若 nums[i] < third，三个位置、三个大小关系全部凑齐，直接返回 true。

以 nums = [3,1,4,2] 为例：从右往左，先压 2；遇到 4 时弹出 2，third = 2，压入 4；再遇到 1，1 < 2，命中，返回 true。

Java 实现（find132pattern）

import java.util.Deque;
import java.util.ArrayDeque;

class Solution {
    public boolean find132pattern(int[] nums) {
        // third 表示当前可用的最大 nums[k]（被弹出的“次大值”）
        long third = Long.MIN_VALUE;
        // 单调递减栈，存放候选的 nums[j]
        Deque<Integer> stack = new ArrayDeque<>();

        // 从右向左扫描
        for (int i = nums.length - 1; i >= 0; i--) {
            // 找到 nums[i] < nums[k]，即 132 中的 1 与 2 就位
            if (nums[i] < third) {
                return true;
            }
            // nums[i] 比栈顶大：栈顶元素不配再做 nums[j]，降级为 nums[k]
            while (!stack.isEmpty() && stack.peek() < nums[i]) {
                third = stack.pop();
            }
            // 当前元素作为新的候选 nums[j]
            stack.push(nums[i]);
        }
        return false;
    }
}

复杂度

  • 时间：O(n)。每个下标恰好入栈一次、出栈一次，逆序扫描一遍，总体线性。
  • 空间：O(n)。最坏情况（数组单调递增）栈会容纳所有元素。

易错点与扩展（面试高频考点）

  1. 单调栈的方向别搞反：这里是“从右往左 + 递减栈（栈顶最小）”。while (stack.peek() < nums[i]) 弹出的是比当前小的值，把它们当作 nums[k] 候选，这个方向很容易写反成递增栈。
  2. third 初值要用极小值：nums[i] 可到 -10^9，用 Integer.MIN_VALUE 或 Long.MIN_VALUE 初始化 third，避免与合法的负数混淆。代码里用 long 更保险。
  3. 判定必须在入栈前：先判断 nums[i] < third，再弹栈、再压栈。顺序错了会漏掉“当前元素本身充当 nums[i]”的情况。
  4. third 只在弹出时更新：不是每次循环都更新，它代表“历史被弹出值中的最大值”，这正是栈单调性带来的最优 nums[k]。
  5. 扩展追问——枚举 nums[j] 的写法：也可以用“前缀最小值 + 有序集合/二分”从中间枚举 j，在右侧找满足 nums[i] < x < nums[j] 的 x，复杂度 O(n log n)；单调栈是 O(n) 的更优解。

C++ 实现

#include <vector>
#include <stack>
#include <climits>
using namespace std;

class Solution {
public:
    bool find132pattern(vector<int>& nums) {
        long long third = LLONG_MIN;   // 当前可用的最大 nums[k]
        stack<int> st;                 // 单调递减栈，存放候选 nums[j]

        for (int i = (int)nums.size() - 1; i >= 0; --i) {
            if (nums[i] < third) {
                return true;           // 凑齐 1 < 2 且 2 < 3
            }
            while (!st.empty() && st.top() < nums[i]) {
                third = st.top();      // 降级为 nums[k] 候选
                st.pop();
            }
            st.push(nums[i]);
        }
        return false;
    }
};

Python 实现

class Solution:
    def find132pattern(self, nums: list[int]) -> bool:
        third = float('-inf')   # 当前可用的最大 nums[k]
        stack = []              # 单调递减栈，存放候选 nums[j]

        for x in reversed(nums):
            if x < third:
                return True     # 1 < 2 且 2 < 3，命中
            while stack and stack[-1] < x:
                third = stack.pop()   # 降级为 nums[k] 候选
            stack.append(x)

        return False
