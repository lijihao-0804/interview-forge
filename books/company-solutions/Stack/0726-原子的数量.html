726. 原子的数量

难度困难核心模式栈 + 哈希表，括号内计数整体结算时间复杂度最坏 O(n² log n)空间复杂度O(n)

题目与约束

给你一个字符串化学式 formula ，返回 每种原子的数量 。

原子总是以一个大写字母开始，接着跟随 0 个或任意个小写字母，表示原子的名字。

如果数量大于 1，原子后会跟着数字表示原子的数量。如果数量等于 1 则不会跟数字。

  • 例如，"H2O" 和 "H2O2" 是可行的，但 "H1O2" 这个表达是不可行的。

两个化学式连在一起可以构成新的化学式。

  • 例如 "H2O2He3Mg4" 也是化学式。

由括号括起的化学式并佐以数字（可选择性添加）也是化学式。

  • 例如 "(H2O2)" 和 "(H2O2)3" 是化学式。

返回所有原子的数量，格式为：第一个（按字典序）原子的名字，跟着它的数量（如果数量大于 1），然后是第二个原子的名字（按字典序），跟着它的数量（如果数量大于 1），以此类推。

示例 1：

输入：formula = "H2O"
输出："H2O"
解释：原子的数量是 {'H': 2, 'O': 1}。

示例 2：

输入：formula = "Mg(OH)2"
输出："H2MgO2"
解释：原子的数量是 {'H': 2, 'Mg': 1, 'O': 2}。

示例 3：

输入：formula = "K4(ON(SO3)2)2"
输出："K4N2O14S4"
解释：原子的数量是 {'K': 4, 'N': 2, 'O': 14, 'S': 4}。

提示：

  • 1 <= formula.length <= 1000

  • formula 由英文字母、数字、'(' 和 ')' 组成

  • formula 总是有效的化学式

核心不变量

每一对括号内的原子先独立汇总，遇到 ) 时把整组计数乘以系数再并入外层。

完整推导

思路推导

  1. 痛点：括号嵌套导致系数层层相乘。 例如 K4(ON(SO3)2)2，最里层 SO3 先成组，再乘上外层 )2 的系数 2，还要再乘最外层系数。这种“最内层先算、算完交给外层”的顺序，天然就是后进先出，所以用栈。

  2. 栈里装什么？ 栈中每一个元素是“当前这一层”的哈希表 Map<原子名, 数量>。初始压入一个空表代表最外层。

  3. 三种字符分别处理： - 遇到 (：压入一张新的空表，表示进入更深一层。 - 遇到 )：弹出栈顶这层表，读出紧跟其后的数字作为系数（没有则为 1），把表里每个计数乘以系数，累加合并到新的栈顶（外层表）。 - 遇到大写字母：解析出完整原子名（一个大写 + 后续连续小写），再读可选数字，累加到栈顶表。

  4. 收尾： 全部扫描完后，栈中只剩一张表，即所有原子的总计数；按原子名字典序排序后拼接输出（数量为 1 省略数字）。

Java 实现（countOfAtoms）

import java.util.ArrayDeque;
import java.util.Deque;
import java.util.Map;
import java.util.TreeMap;

class Solution {
    public String countOfAtoms(String formula) {
        // 栈中每层用 TreeMap，天然按原子名字典序
        Deque<Map<String, Integer>> stack = new ArrayDeque<>();
        stack.push(new TreeMap<>());
        int n = formula.length(), i = 0;

        while (i < n) {
            char c = formula.charAt(i);
            if (c == '(') {
                // 进入新的一层，压入空表
                stack.push(new TreeMap<>());
                i++;
            } else if (c == ')') {
                i++;
                // 解析右括号后的系数，缺省为 1
                int start = i;
                while (i < n && Character.isDigit(formula.charAt(i))) i++;
                int mult = (i > start) ? Integer.parseInt(formula.substring(start, i)) : 1;
                // 弹出一层，整组乘以系数后并入外层
                Map<String, Integer> group = stack.pop();
                Map<String, Integer> outer = stack.peek();
                for (Map.Entry<String, Integer> e : group.entrySet()) {
                    outer.merge(e.getKey(), e.getValue() * mult, Integer::sum);
                }
            } else {
                // 解析原子名：一个大写字母 + 连续小写字母
                int start = i;
                i++; // 跳过开头大写字母
                while (i < n && Character.isLowerCase(formula.charAt(i))) i++;
                String name = formula.substring(start, i);
                // 解析原子后的数量，缺省为 1
                start = i;
                while (i < n && Character.isDigit(formula.charAt(i))) i++;
                int cnt = (i > start) ? Integer.parseInt(formula.substring(start, i)) : 1;
                stack.peek().merge(name, cnt, Integer::sum);
            }
        }

        // 栈顶即最终结果（TreeMap 已按字典序）
        StringBuilder sb = new StringBuilder();
        for (Map.Entry<String, Integer> e : stack.peek().entrySet()) {
            sb.append(e.getKey());
            if (e.getValue() > 1) sb.append(e.getValue());
        }
        return sb.toString();
    }
}

C++ 实现

class Solution {
public:
    string countOfAtoms(string formula) {
        vector<map<string, int>> st;
        st.push_back({});
        int n = formula.size(), i = 0;
        while (i < n) {
            char c = formula[i];
            if (c == '(') {
                st.push_back({});
                i++;
            } else if (c == ')') {
                i++;
                int start = i;
                while (i < n && isdigit((unsigned char)formula[i])) i++;
                int mult = (i > start) ? stoi(formula.substr(start, i - start)) : 1;
                map<string, int> group = move(st.back());
                st.pop_back();
                for (auto& p : group) st.back()[p.first] += p.second * mult;
            } else {
                int start = i;
                i++; // 大写字母
                while (i < n && islower((unsigned char)formula[i])) i++;
                string name = formula.substr(start, i - start);
                start = i;
                while (i < n && isdigit((unsigned char)formula[i])) i++;
                int cnt = (i > start) ? stoi(formula.substr(start, i - start)) : 1;
                st.back()[name] += cnt;
            }
        }
        string res;
        for (auto& p : st.back()) {
            res += p.first;
            if (p.second > 1) res += to_string(p.second);
        }
        return res;
    }
};

Python 实现

class Solution:
    def countOfAtoms(self, formula: str) -> str:
        stack = [{}]  # 每层: dict 原子名 -> 数量
        i, n = 0, len(formula)
        while i < n:
            c = formula[i]
            if c == '(':
                stack.append({})
                i += 1
            elif c == ')':
                i += 1
                start = i
                while i < n and formula[i].isdigit():
                    i += 1
                mult = int(formula[start:i]) if i > start else 1
                group = stack.pop()
                for name, cnt in group.items():
                    stack[-1][name] = stack[-1].get(name, 0) + cnt * mult
            else:
                start = i
                i += 1  # 大写字母
                while i < n and formula[i].islower():
                    i += 1
                name = formula[start:i]
                start = i
                while i < n and formula[i].isdigit():
                    i += 1
                cnt = int(formula[start:i]) if i > start else 1
                stack[-1][name] = stack[-1].get(name, 0) + cnt
        return ''.join(k + (str(v) if v > 1 else '') for k, v in sorted(stack[0].items()))

复杂度

  • 时间：最坏 O(n² log n)。每遇 ) 都要把该层原子并回父层，嵌套深度 d 时同一批原子被重复合并 d 次；Java 的 TreeMap 再乘 log k。n ≤ 1000 实际仍可通过。
  • 空间：O(n)，栈深度与各层哈希表容纳的原子条目总计不超过 O(n)。
易错点与扩展（面试高频考点）
  1. 缺省系数为 1："H2O" 里的 O 没有数字，系数必须当 1 处理，不能当 0。
  2. 多位数系数要完整读取：如 "C12H22O11" 中的 12、22、11，要用连续数字整体解析，不能只读一位。
  3. 合并用累加而非覆盖：同名原子可能来自不同分组（如 (OH)2 中的 H 与外面的 H 会相遇），必须 merge/+=。
  4. ( 与 ) 的配对要严格靠栈：不要用变量记录“层号”，嵌套时容易错位。
  5. 输出规则：数量为 1 时省略数字；原子名按字典序（ASCII，大写在小写之前，天然可用 TreeMap）。
