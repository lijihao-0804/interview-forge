# 589. N 叉树的前序遍历

| 题目信息 | 内容 |
|---|---|
| 难度 | 简单 |
| 核心模式 | DFS 前序遍历（根 → 各子树依次） |
| 时间复杂度 | O(n) |
| 空间复杂度 | O(h) |

## 题目与约束

给定一个 n 叉树的根节点 `root`，返回其节点值的**前序遍历**。

n 叉树在输入中按层序遍历进行序列化表示，每组子节点由空值 `null` 分隔（请参见示例）。

**示例 1：**

```
输入：root = [1,null,3,2,4,null,5,6]
输出：[1,3,5,6,2,4]
```

**示例 2：**

```
输入：root = [1,null,2,3,4,5,null,null,6,7,null,8,null,9,10,null,null,11,null,12,null,13,null,null,14]
输出：[1,2,3,6,7,11,14,4,8,12,5,9,13,10]
```

**提示：**

- 节点总数在范围 `[0, 10⁴]` 内
- `0 <= Node.val <= 10⁴`
- n 叉树的高度小于或等于 `1000`

**进阶：** 递归法很简单，你可以使用迭代法完成此题吗？

## 核心不变量

> 前序遍历顺序 = 先访问根节点，再按 `children` 数组的先后顺序，对每一棵子树递归地做前序遍历。

## 完整推导

### 思路推导

1. **明确"前序"的定义**

   与二叉树前序（根 → 左 → 右）推广一致：先记录根，再**从左到右**依次处理每个孩子。对 n 叉树而言，就是"根 → 第 1 个子树 → 第 2 个子树 → … → 第 k 个子树"。

2. **递归是最直接的写法**

   `preorder(root) = [root.val] + preorder(child_1) + preorder(child_2) + … + preorder(child_k)`。递归出口是 `root` 为空时返回空。

3. **迭代写法（进阶要求）**

   用一个栈。先把根入栈；每次弹出节点即"访问"它，再把它的孩子**逆序**压栈——因为栈是后进先出，逆序压入才能保证弹出时按原 `children` 顺序从左到右。这样不需要递归，且不会因深度 1000 而栈溢出。

4. **小例子（示例 1：root = [1,null,3,2,4,null,5,6]）**

   根 1 先输出；其孩子为 3、2、4。进入 3，输出 3，3 的孩子 5、6 依次输出；回到 2 输出 2；回到 4 输出 4。结果 `[1,3,5,6,2,4]`，与题目一致。

### Java 实现（preorder）

```java
/*
// Definition for a Node.
class Node {
    public int val;
    public List<Node> children;

    public Node() {}
    public Node(int _val) { val = _val; }
    public Node(int _val, List<Node> _children) {
        val = _val;
        children = _children;
    }
}
*/

class Solution {
    public List<Integer> preorder(Node root) {
        List<Integer> res = new ArrayList<>();
        dfs(root, res);
        return res;
    }

    private void dfs(Node node, List<Integer> res) {
        if (node == null) return;
        res.add(node.val);                       // 先访问根
        if (node.children != null) {
            for (Node child : node.children) {   // 再按顺序递归每个孩子
                dfs(child, res);
            }
        }
    }
}
```

### 复杂度

- 时间：O(n)，每个节点恰好被访问（输出）一次。
- 空间：O(h)，h 为树高，即递归栈的深度；最坏情况（链状 n 叉树）为 O(n)。

### 易错点与扩展（面试高频考点）

1. **迭代压栈必须逆序**：若按 `children` 正序压栈，弹出顺序会变成从右到左，输出与预期相反。
2. **空节点处理**：`root == null` 时返回空列表；节点 `children` 可能为 `null`（视建树方式），遍历前要判空。
3. **不要与后序 / 层序混淆**：前序是"进来就记录"，后序是"孩子都处理完再记录"，层序是 BFS 队列。
4. **深度可达 1000**：递归通常没问题，但若担心栈空间，可用显式栈迭代（进阶要求）。
5. **`children` 类型是列表**：n 叉树不像二叉树只有左右两个孩子，务必按整个列表顺序遍历。

## 力扣原题

[589. N 叉树的前序遍历](https://leetcode.cn/problems/n-ary-tree-preorder-traversal/)

### C++ 实现

```cpp
/*
// Definition for a Node.
class Node {
public:
    int val;
    vector<Node*> children;

    Node() {}
    Node(int _val) { val = _val; }
    Node(int _val, vector<Node*> _children) { val = _val; children = _children; }
};
*/

class Solution {
public:
    vector<int> preorder(Node* root) {
        vector<int> res;
        dfs(root, res);
        return res;
    }

private:
    void dfs(Node* node, vector<int>& res) {
        if (node == nullptr) return;
        res.push_back(node->val);              // 先访问根
        for (Node* child : node->children) {   // 再按顺序递归每个孩子
            dfs(child, res);
        }
    }
};
```

### Python 实现

```python
class Solution:
    def preorder(self, root: 'Node') -> List[int]:
        res = []

        def dfs(node):
            if node is None:
                return
            res.append(node.val)          # 先访问根
            if node.children:
                for child in node.children:  # 再按顺序递归每个孩子
                    dfs(child)

        dfs(root)
        return res
```
