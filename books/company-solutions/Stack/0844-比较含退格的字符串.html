844. 比较含退格的字符串

本题学习状态正在读取学习记录…下次复习：—
本次复习：
按 M 快速切换薄弱标记
遮住推导与代码，先自己想，再逐段揭示
难度简单核心模式双指针从后往前扫描，用计数器抵消退格时间复杂度O(m + n)空间复杂度O(1)

题目与约束

给定 s 和 t 两个字符串，当它们分别被输入到空白的文本编辑器后，如果两者相等，返回 true 。# 代表退格字符。

注意：如果对空文本输入退格字符，文本继续为空。

示例 1：

输入：s = "ab#c", t = "ad#c"
输出：true
解释：s 和 t 都会变成 "ac"。

示例 2：

输入：s = "ab##", t = "c#d#"
输出：true
解释：s 和 t 都会变成 ""。

示例 3：

输入：s = "a#c", t = "b"
输出：false
解释：s 会变成 "c"，但 t 仍然是 "b"。

提示：

  • 1 <= s.length, t.length <= 200

  • s 和 t 只含有小写字母以及字符 '#'

进阶：

  • 你可以用 O(n) 的时间复杂度和 O(1) 的空间复杂度解决该问题吗？

核心不变量

从后往前扫描时，一个 # 抵消的是它前面最近的一个有效字符；用计数器记录「待抵消次数」，遇到普通字符且计数器为 0 时，它才是最终保留下来的字符。

完整推导

思路推导

  1. 朴素解法与其缺陷

用栈模拟最直观：遇普通字符入栈，遇 # 弹栈，最后比较两栈。时间 O(m+n)，但需要 O(m+n) 额外空间，不满足进阶要求。

  1. 为什么可以「从后往前」

退格只会删除它前面的字符，因此一个字符是否被保留，只取决于它后面有多少个尚未抵消的 #。从末尾向前扫描，边扫边累计 # 的数量，就能在不真正删除字符的情况下判断当前字符是否应当保留。

  1. 双指针抵消流程

两个指针 i、j 分别指向 s、t 末尾，两个计数器 skipS、skipT 记录各自待抵消的退格数。每轮：

  • 让 i 向前跳过被退格抵消的字符，停在 s 的下一个「有效字符」上；
  • 让 j 对 t 做同样的事；
  • 若两者都还有效字符，比较是否相同；若一个还有一个没有，说明长度/内容不同，返回 false；
  • 否则同时前移，进入下一轮。

全部扫完仍一致则返回 true。

  1. 小例子（s = "ab#c"）

从末尾看：c 后面没有 #，有效，c 保留；接着 # 记 skipS=1；再遇到 b，被 skipS 抵消；再遇到 a，skipS 已为 0，a 保留。有效字符序列为 a、c，即 "ac"，与 t 一致。

Java 实现（backspaceCompare）

class Solution {
    public boolean backspaceCompare(String s, String t) {
        int i = s.length() - 1;   // s 的扫描指针（从后往前）
        int j = t.length() - 1;   // t 的扫描指针
        int skipS = 0, skipT = 0; // 各自待抵消的退格数量

        while (i >= 0 || j >= 0) {
            // 让 i 停到 s 的下一个有效字符
            while (i >= 0) {
                if (s.charAt(i) == '#') {
                    skipS++;
                    i--;
                } else if (skipS > 0) {
                    skipS--;
                    i--;
                } else {
                    break;
                }
            }
            // 让 j 停到 t 的下一个有效字符
            while (j >= 0) {
                if (t.charAt(j) == '#') {
                    skipT++;
                    j--;
                } else if (skipT > 0) {
                    skipT--;
                    j--;
                } else {
                    break;
                }
            }

            // 两边都还有字符：必须相同
            if (i >= 0 && j >= 0) {
                if (s.charAt(i) != t.charAt(j)) {
                    return false;
                }
            } else if (i >= 0 || j >= 0) {
                // 一边还有、一边没了，长度不一致
                return false;
            }

            i--;
            j--;
        }
        return true;
    }
}

C++ 实现

class Solution {
public:
    bool backspaceCompare(string s, string t) {
        int i = (int) s.size() - 1, j = (int) t.size() - 1;
        int skipS = 0, skipT = 0;
        while (i >= 0 || j >= 0) {
            while (i >= 0) {
                if (s[i] == '#') { skipS++; i--; }
                else if (skipS > 0) { skipS--; i--; }
                else break;
            }
            while (j >= 0) {
                if (t[j] == '#') { skipT++; j--; }
                else if (skipT > 0) { skipT--; j--; }
                else break;
            }
            if (i >= 0 && j >= 0) {
                if (s[i] != t[j]) return false;
            } else if (i >= 0 || j >= 0) {
                return false;
            }
            i--; j--;
        }
        return true;
    }
};

Python 实现

class Solution:
    def backspaceCompare(self, s: str, t: str) -> bool:
        i, j = len(s) - 1, len(t) - 1
        skip_s = skip_t = 0

        while i >= 0 or j >= 0:
            while i >= 0:
                if s[i] == '#':
                    skip_s += 1
                    i -= 1
                elif skip_s > 0:
                    skip_s -= 1
                    i -= 1
                else:
                    break

            while j >= 0:
                if t[j] == '#':
                    skip_t += 1
                    j -= 1
                elif skip_t > 0:
                    skip_t -= 1
                    j -= 1
                else:
                    break

            if i >= 0 and j >= 0:
                if s[i] != t[j]:
                    return False
            elif i >= 0 or j >= 0:
                return False

            i -= 1
            j -= 1

        return True

复杂度

  • 时间：O(m + n)。每个字符最多被指针访问常数次，两个串各扫描一遍。
  • 空间：O(1)。只用了两个指针和两个计数器，满足进阶要求。
易错点与扩展（面试高频考点）
  1. 退格不能「越界删除」：对空文本再输入 # 仍是空。计数器方式天然处理这点——skip 只在遇到普通字符时才消耗。
  2. 指针越界比较：循环结束后要区分「两边都有字符」「只有一边有字符」「都没有」三种情况，漏判会出现数组越界或误判。
  3. 正向栈解法：StringBuilder 或栈模拟同样正确，时间 O(m+n) 但空间 O(m+n)，面试可先讲此版再优化到双指针。
  4. 边界：全是 #：两个串都为纯退格时都变成空串，应返回 true；双指针流程会同时越界、直接返回 true，正确。
  5. 扩展：若要求返回「最终字符串」而非比较，栈/StringBuilder 更直接；双指针只适合判断相等。
