71. 简化路径

题目与约束

给你一个字符串 path ，表示指向某一文件或目录的 Unix 风格 绝对路径 （以 '/' 开头），请你将其转化为 更加简洁的规范路径。

在 Unix 风格的文件系统中规则如下：

  • 一个点 '.' 表示当前目录本身。

  • 此外，两个点 '..' 表示将目录切换到上一级（指向父目录）。

  • 任意多个连续的斜杠（即，'//' 或 '///'）都被视为单个斜杠 '/'。

  • 任何其他格式的点（例如，'...' 或 '....'）均被视为有效的文件/目录名称。

返回的 简化路径 必须遵循下述格式：

  • 始终以斜杠 '/' 开头。

  • 两个目录名之间必须只有一个斜杠 '/' 。

  • 最后一个目录名（如果存在）不能 以 '/' 结尾。

  • 此外，路径仅包含从根目录到目标文件或目录的路径上的目录（即，不含 '.' 或 '..'）。

返回简化后得到的 规范路径 。

示例 1：

输入：path = "/home/"

输出："/home"

解释：

应删除尾随斜杠。

示例 2：

输入：path = "/home//foo/"

输出："/home/foo"

解释：

多个连续的斜杠被单个斜杠替换。

示例 3：

输入：path = "/home/user/Documents/../Pictures"

输出："/home/user/Pictures"

解释：

两个点 ".." 表示上一级目录（父目录）。

示例 4：

输入：path = "/../"

输出："/"

解释：

不可能从根目录上升一级目录。

示例 5：

输入：path = "/.../a/../b/c/../d/./"

输出："/.../b/d"

解释：

"..." 在这个问题中是一个合法的目录名。

提示：

  • 1 <= path.length <= 3000

  • path 由英文字母，数字，'.'，'/' 或 '_' 组成。

  • path 是一个有效的 Unix 风格绝对路径。

核心不变量

用栈保存"已经确定的目录名"：遇到普通名字就入栈，遇到 .. 就弹出栈顶（栈空则忽略），遇到 . 或空串就跳过；最终栈里的内容就是规范路径的各级目录。

完整推导

思路推导

  1. 直觉与痛点（为什么是栈）

.. 的含义是"退回上一级"，正好对应"撤销最近一次进入的目录"。这种后进先出的行为就是栈。把每个有效目录名压栈，遇到 .. 就弹栈，天然实现了目录的进出。

  1. 破局思路（先切分，再逐个处理）

连续的 / 会产生空串，/ 本身也可以用 split("/") 拆开。对每个片段 part：

  • part == "" 或 part == "."：无意义，跳过；
  • part == ".."：若栈非空则弹栈（根目录再往上无效，直接忽略）；
  • 其他：合法的目录名，入栈。

以 "/home/user/Documents/../Pictures" 为例：依次入栈 home、user、Documents，遇 .. 弹出 Documents，再入 Pictures，栈为 [home, user, Pictures]，拼成 "/home/user/Pictures"。

  1. 关键追问（"..." 为什么是合法目录名？）

规则明确只有单个 . 和双个 .. 有特殊含义，"..."、"...." 等都当作普通目录名。所以判断必须用精确相等 part == "." / part == ".."，不能用"以点开头"之类模糊条件。

  1. 易错点提示
  • 用精确相等判断，"..." 不能当 .. 处理。
  • .. 在根目录时弹栈要防空。
  • 最后拼接要以 / 开头、无尾斜杠；栈空时返回 "/"。

Java 实现（栈）

import java.util.ArrayDeque;
import java.util.Deque;

class Solution {
    public String simplifyPath(String path) {
        Deque<String> stack = new ArrayDeque<>();
        // 按 '/' 切分，连续斜杠会产生空串，统一跳过
        for (String part : path.split("/")) {
            if (part.isEmpty() || part.equals(".")) {
                continue;                 // 当前目录，忽略
            } else if (part.equals("..")) {
                if (!stack.isEmpty()) {   // 根目录之上无效
                    stack.pollLast();     // 退回上一级
                }
            } else {
                stack.addLast(part);      // 合法目录名入栈
            }
        }

        StringBuilder sb = new StringBuilder();
        for (String dir : stack) {
            sb.append('/').append(dir);   // 每级前补一个 '/'
        }
        return sb.length() == 0 ? "/" : sb.toString();
    }
}

C++ 实现

#include <string>
#include <vector>
#include <sstream>
using namespace std;

class Solution {
public:
    string simplifyPath(string path) {
        vector<string> st;
        stringstream ss(path);
        string token;
        // getline 以 '/' 为分隔符逐段读取
        while (getline(ss, token, '/')) {
            if (token.empty() || token == ".") {
                continue;
            } else if (token == "..") {
                if (!st.empty()) st.pop_back();
            } else {
                st.push_back(token);
            }
        }
        string res;
        for (const string& s : st) {
            res += "/" + s;
        }
        return res.empty() ? "/" : res;
    }
};

Python 实现

class Solution:
    def simplifyPath(self, path: str) -> str:
        stack = []
        for part in path.split('/'):
            if part == '' or part == '.':
                continue
            elif part == '..':
                if stack:
                    stack.pop()
            else:
                stack.append(part)
        return '/' + '/'.join(stack)

复杂度

  • 时间：O(n)，切分与遍历每个字符/片段各一次。
  • 空间：O(n)，栈最多保存全部目录名。
易错点与扩展（面试高频考点）
  1. 把 "..." 误判成 ..：必须 equals("..") 精确匹配，否则结果错误。
  2. 根目录弹栈越界：/../ 时栈为空，.. 必须直接忽略，否则抛异常。
  3. 尾斜杠与前导斜杠：拼接时每级目录前加 /，栈空返回 "/"，天然不会出现尾斜杠。
  4. 空串处理：split("/") 对前导 /、连续 // 会产生空串，必须跳过。
  5. 面试追问——不用 split：可用双指针手动扫描每个 / 之间的片段，逻辑一致，可省一次内存分配。
