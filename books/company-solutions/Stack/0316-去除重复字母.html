题目与约束

给你一个字符串 s ，请你去除字符串中重复的字母，使得每个字母只出现一次。需保证 返回结果的字典序最小（要求不能打乱其他字符的相对位置）。

示例 1：

输入：s = "bcabc"
输出："abc"

示例 2：

输入：s = "cbacdcbc"
输出："acdb"

提示：

  • 1 <= s.length <= 104

  • s 由小写英文字母组成

注意：该题与 1081 https://leetcode.cn/problems/smallest-subsequence-of-distinct-characters 相同

核心不变量

单调栈内始终维护"当前可构造的字典序最小、且字符各不重复的子序列"；只有当栈顶字符在当前位置之后还会再次出现时，才可以安全地把它弹出。

完整推导

思路推导

  1. 目标拆解：要三个条件同时满足——每个字母只留一个、保持相对顺序、字典序最小。前两条要求"选一个子序列"，第三条要求"选尽量小的字符靠前"。

  2. 贪心直觉：从左往右扫描，遇到比栈顶更小的字符，就希望它排到前面去。但直接替换会丢失字符，所以必须确认被替换的字符"后面还有机会再出现"。

  3. 用最后出现位置判断：预处理 last[c] 表示字符 c 在 s 中最后出现的下标。当前字符 c 在下标 i 时，若栈顶字符 top 满足 top > c 且 last[top] > i，说明 top 后面还会再出现，可以放心弹出，让更小的 c 上位；否则贸然弹出会导致 top 彻底丢失。

  4. 去重与收尾：用 used 记录已在栈内的字符，已入栈就跳过；弹出时把 used 复位。每个字符至多入栈、出栈各一次，整体线性。

以 s = "bcabc" 为例（last: b=3, c=4, a=2）： - b 入栈 → [b]；c 入栈 → [b,c]； - a：c > a 且 last[c]=4>2 弹 c；b > a 且 last[b]=3>2 弹 b；a 入栈 → [a]； - b 入栈 → [a,b]；c 入栈 → [a,b,c]，得 "abc" ✓

Java 实现（单调栈 + 贪心）

class Solution {
    public String removeDuplicateLetters(String s) {
        int[] last = new int[26];          // 每个字母最后出现的下标
        for (int i = 0; i < s.length(); i++) {
            last[s.charAt(i) - 'a'] = i;
        }

        boolean[] used = new boolean[26];  // 是否已在栈中
        StringBuilder st = new StringBuilder();

        for (int i = 0; i < s.length(); i++) {
            char c = s.charAt(i);
            if (used[c - 'a']) {
                continue;                   // 已入栈，跳过重复
            }
            // 栈顶更大且后面还会再出现，就弹出
            while (st.length() > 0) {
                char top = st.charAt(st.length() - 1);
                if (top > c && last[top - 'a'] > i) {
                    used[top - 'a'] = false;
                    st.deleteCharAt(st.length() - 1);
                } else {
                    break;
                }
            }
            st.append(c);
            used[c - 'a'] = true;
        }
        return st.toString();
    }
}

复杂度

  • 时间：O(n)。每个字符最多入栈一次、出栈一次，均摊线性。
  • 空间：O(1)。last、used 都是固定 26 大小的数组，栈最多装 26 个字符（相对字母表是常数）。

易错点与扩展（面试高频考点）

  1. 漏掉 used 判断：不判重会让同一字母多次入栈，结果出现重复字符；已入栈必须直接跳过。
  2. 弹栈条件缺一不可：栈顶 > c（否则弹出会变大、更差）且 last[栈顶] > i（否则弹出就永久丢失该字符）。少任一条都会出错。
  3. 弹出后忘记复位 used：弹出 top 时一定要 used[top] = false，否则它后面再出现时会被误判为"已在栈中"而跳过。
  4. 用可变容器模拟栈：Java 用 StringBuilder、C++ 用 string、Python 用 list 当栈，比反复字符串拼接高效得多。
  5. 同类题族：「1081. 不同字符的最小子序列」（本题同题）、「402. 移掉 K 位数字」、「单调栈去重」都属于"单调栈 + 保留/删除判断"的套路，可迁移。

力扣原题

316. 去除重复字母

C++ 实现

#include <string>
#include <vector>
using namespace std;

class Solution {
public:
    string removeDuplicateLetters(string s) {
        vector<int> last(26, -1);
        for (int i = 0; i < (int)s.size(); ++i) {
            last[s[i] - 'a'] = i;
        }

        vector<bool> used(26, false);
        string st;

        for (int i = 0; i < (int)s.size(); ++i) {
            char c = s[i];
            if (used[c - 'a']) continue;   // 已入栈，跳过
            while (!st.empty() && st.back() > c && last[st.back() - 'a'] > i) {
                used[st.back() - 'a'] = false;
                st.pop_back();
            }
            st.push_back(c);
            used[c - 'a'] = true;
        }
        return st;
    }
};

Python 实现

class Solution:
    def removeDuplicateLetters(self, s: str) -> str:
        last = {c: i for i, c in enumerate(s)}   # 每个字母最后出现位置
        used = set()                             # 已在栈中的字母
        st = []                                  # 用 list 模拟单调栈

        for i, c in enumerate(s):
            if c in used:
                continue
            # 栈顶更大且后面还会再出现，就弹出
            while st and st[-1] > c and last[st[-1]] > i:
                used.remove(st.pop())
            st.append(c)
            used.add(c)
        return "".join(st)
