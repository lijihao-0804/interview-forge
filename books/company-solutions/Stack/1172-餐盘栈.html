1172. 餐盘栈

本题学习状态正在读取学习记录…下次复习：—
本次复习：
按 M 快速切换薄弱标记
遮住推导与代码，先自己想，再逐段揭示
难度困难核心模式设计题：有序集合维护「第一个未满栈」+ 动态数组维护各栈时间复杂度push/pop/popAtStack 均为 O(log n)空间复杂度O(m)

题目与约束

我们把无限数量 ∞ 的栈排成一行，按从左到右的次序从 0 开始编号。每个栈的的最大容量 capacity 都相同。

实现一个叫「餐盘」的类 DinnerPlates：

  • DinnerPlates(int capacity) - 给出栈的最大容量 capacity。

  • void push(int val) - 将给出的正整数 val 推入 从左往右第一个 没有满的栈。

  • int pop() - 返回 从右往左第一个 非空栈顶部的值，并将其从栈中删除；如果所有的栈都是空的，请返回 -1。

  • int popAtStack(int index) - 返回编号 index 的栈顶部的值，并将其从栈中删除；如果编号 index 的栈是空的，请返回 -1。

提示：

  • 1 <= capacity <= 20000

  • 1 <= val <= 20000

  • 0 <= index <= 100000

  • 最多会对 push，pop，和 popAtStack 进行 200000 次调用。

核心不变量

用一个动态数组按编号存所有栈；再用一个有序集合保存“当前未满的栈编号”。push 取集合中最小编号，popAtStack 把该栈编号放回集合，pop 从最右侧非空栈取栈顶——任何时刻集合中的编号都对应真实存在且未满的栈。

完整推导

思路推导

  1. 直觉与痛点（三条规则各自的方向）

push 要“最左边第一个未满”，pop 要“最右边第一个非空”，popAtStack 要按编号随机访问。如果每次 push 都从左往右扫描找空栈，最坏 O(n)，调用 20 万次会超时。所以关键是：如何快速知道“最左边第一个未满栈”。

  1. 破局思路（用有序集合当“空位目录”）

维护 available = 所有未满栈的编号 的有序集合（如 TreeSet）。它天然支持“取最小元素”，正好是 push 要的目标。

  • push(val)：若集合为空，说明所有已存在的栈都满了，就在数组末尾新建一个栈并把它加入集合；然后取集合中最小下标，压入 val；若压完后该栈满了，就把它从集合里移除。
  • pop()：先清理数组末尾所有空栈（同时把它们从集合里删掉），再从最后一个栈弹栈顶；弹出后该栈必然未满，把它加回集合。
  • popAtStack(index)：越界或空栈返回 -1；否则弹出栈顶并把它加回集合（因为弹完后它就不满了）。
  1. 关键追问（为什么 pop 要清理尾部空栈）

若 popAtStack(0) 把编号 0 的栈清空，它仍是“合法但空的栈”。而 pop 要的是“最右侧非空栈”，如果不清掉尾部空栈，可能在末尾遇到一连串空栈。清理后，数组最后一个元素就是最右侧非空栈，pop 直接取它即可。

Java 实现（TreeSet + ArrayDeque 数组）

import java.util.ArrayDeque;
import java.util.ArrayList;
import java.util.Deque;
import java.util.List;
import java.util.TreeSet;

class DinnerPlates {
    private final int capacity;
    private final List<Deque<Integer>> stacks; // 按编号存每个栈
    private final TreeSet<Integer> available;  // 未满栈的编号（有序，便于取最小）

    public DinnerPlates(int capacity) {
        this.capacity = capacity;
        this.stacks = new ArrayList<>();
        this.available = new TreeSet<>();
    }

    public void push(int val) {
        // 没有未满栈，就在最右侧新建一个
        if (available.isEmpty()) {
            stacks.add(new ArrayDeque<>());
            available.add(stacks.size() - 1);
        }
        int idx = available.first(); // 从左往右第一个未满的栈
        stacks.get(idx).push(val);
        if (stacks.get(idx).size() == capacity) {
            available.remove(idx); // 装满后从目录中移除
        }
    }

    public int pop() {
        // 清理末尾所有空栈
        while (!stacks.isEmpty() && stacks.get(stacks.size() - 1).isEmpty()) {
            available.remove(stacks.size() - 1);
            stacks.remove(stacks.size() - 1);
        }
        if (stacks.isEmpty()) {
            return -1;
        }
        int idx = stacks.size() - 1;
        int val = stacks.get(idx).pop();
        available.add(idx); // 弹出后不再满，重新可用
        return val;
    }

    public int popAtStack(int index) {
        if (index >= stacks.size() || stacks.get(index).isEmpty()) {
            return -1;
        }
        int val = stacks.get(index).pop();
        available.add(index); // 弹出后不再满
        return val;
    }
}

C++ 实现

#include <vector>
#include <stack>
#include <set>
using namespace std;

class DinnerPlates {
    int cap;
    vector<stack<int>> stacks;
    set<int> available; // 未满栈的编号（有序）

public:
    DinnerPlates(int capacity) : cap(capacity) {}

    void push(int val) {
        if (available.empty()) {
            stacks.push_back(stack<int>());
            available.insert((int) stacks.size() - 1);
        }
        int idx = *available.begin(); // 最左的未满栈
        stacks[idx].push(val);
        if ((int) stacks[idx].size() == cap) {
            available.erase(idx);
        }
    }

    int pop() {
        // 清理末尾空栈
        while (!stacks.empty() && stacks.back().empty()) {
            available.erase((int) stacks.size() - 1);
            stacks.pop_back();
        }
        if (stacks.empty()) return -1;
        int idx = (int) stacks.size() - 1;
        int val = stacks[idx].top();
        stacks[idx].pop();
        available.insert(idx);
        return val;
    }

    int popAtStack(int index) {
        if (index >= (int) stacks.size() || stacks[index].empty()) return -1;
        int val = stacks[index].top();
        stacks[index].pop();
        available.insert(index);
        return val;
    }
};

Python 实现

import heapq

class DinnerPlates:
    def __init__(self, capacity: int):
        self.cap = capacity
        self.stacks = []      # 每个位置是一个 list，尾部为栈顶
        self.available = []   # 小根堆：未满栈的编号

    def push(self, val: int) -> None:
        # 丢弃失效的堆顶（编号已不存在，或该栈已满）
        while self.available:
            idx = self.available[0]
            if idx < len(self.stacks) and len(self.stacks[idx]) < self.cap:
                break
            heapq.heappop(self.available)

        if not self.available:
            self.stacks.append([])
            heapq.heappush(self.available, len(self.stacks) - 1)

        idx = heapq.heappop(self.available)
        self.stacks[idx].append(val)
        if len(self.stacks[idx]) < self.cap:
            heapq.heappush(self.available, idx)  # 仍未满，继续放回

    def pop(self) -> int:
        # 清理末尾空栈
        while self.stacks and not self.stacks[-1]:
            self.stacks.pop()
        if not self.stacks:
            return -1
        idx = len(self.stacks) - 1
        val = self.stacks[idx].pop()
        heapq.heappush(self.available, idx)
        return val

    def popAtStack(self, index: int) -> int:
        if index >= len(self.stacks) or not self.stacks[index]:
            return -1
        val = self.stacks[index].pop()
        heapq.heappush(self.available, index)
        return val

复杂度

  • 时间：push / pop / popAtStack 中的有序集合操作均为 O(log n)（Java TreeSet.add、C++ set.insert、Python heappush）；pop 的尾部清理均摊到每次删除也是 O(log n)。
  • 空间：O(m)，m 为当前存储的元素总数（每个元素恰好存一次）。
易错点与扩展（面试高频考点）
  1. available 必须同步维护：栈装满时移除、弹出后加回、清理尾栈时删除，三处漏一处就会出现“指向已满/不存在栈”的脏编号。
  2. push 新建栈的时机：只有集为空才新建，不能因为“最后一个栈满了”就新建，因为中间可能还有没满的栈。
  3. pop 前先清尾部空栈：否则会取到空栈或索引越界，导致“最右非空”判断错误。
  4. popAtStack 越界要返回 -1：index 可能远大于当前栈数量，必须先判 index >= stacks.size()。
  5. 扩展：也可用 PriorityQueue<Integer> 替代 TreeSet（只需最小、不需有序遍历），配合懒删除；或用并查集维护“下一个未满栈”，把 push 做到近似 O(α)。
