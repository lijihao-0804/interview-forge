496. 下一个更大元素 I

本题学习状态正在读取学习记录…下次复习：—
本次复习：
按 M 快速切换薄弱标记
遮住推导与代码，先自己想，再逐段揭示
难度简单核心模式单调栈预处理 nums2 的「下一个更大元素」并存入哈希表，再查表回答 nums1时间复杂度O(n₁ + n₂)空间复杂度O(n₂)

题目与约束

nums1 中数字 x 的 下一个更大元素 是指 x 在 nums2 中对应位置 右侧 的 第一个 比 x 大的元素。

给你两个 没有重复元素 的数组 nums1 和 nums2 ，下标从 0 开始计数，其中nums1 是 nums2 的子集。

对于每个 0 <= i < nums1.length ，找出满足 nums1[i] == nums2[j] 的下标 j ，并且在 nums2 确定 nums2[j] 的 下一个更大元素 。如果不存在下一个更大元素，那么本次查询的答案是 -1 。

返回一个长度为 nums1.length 的数组 ans 作为答案，满足 ans[i] 是如上所述的 下一个更大元素 。

示例 1：

输入：nums1 = [4,1,2], nums2 = [1,3,4,2].
输出：[-1,3,-1]
解释：nums1 中每个值的下一个更大元素如下所述：

  • 4 ，用加粗斜体标识，nums2 = [1,3,4,2]。不存在下一个更大元素，所以答案是 -1 。

  • 1 ，用加粗斜体标识，nums2 = [1,3,4,2]。下一个更大元素是 3 。

  • 2 ，用加粗斜体标识，nums2 = [1,3,4,2]。不存在下一个更大元素，所以答案是 -1 。

示例 2：

输入：nums1 = [2,4], nums2 = [1,2,3,4].
输出：[3,-1]
解释：nums1 中每个值的下一个更大元素如下所述：

  • 2 ，用加粗斜体标识，nums2 = [1,2,3,4]。下一个更大元素是 3 。

  • 4 ，用加粗斜体标识，nums2 = [1,2,3,4]。不存在下一个更大元素，所以答案是 -1 。

提示：

  • 1 <= nums1.length <= nums2.length <= 1000

  • 0 <= nums1[i], nums2[i] <= 104

  • nums1和nums2中所有整数 互不相同

  • nums1 中的所有整数同样出现在 nums2 中

进阶：你可以设计一个时间复杂度为 O(nums1.length + nums2.length) 的解决方案吗？

核心不变量

在 nums2 上从左到右扫描并维护一个单调递减的栈：当遇到比栈顶更大的元素 x 时，栈顶元素们的「下一个更大元素」就是 x，逐个弹栈并记录，直到栈顶不小于 x；扫描结束后仍在栈中的元素没有下一个更大元素，答案记为 -1。

完整推导

思路推导

  1. 直觉与痛点（对每个元素向右找第一个更大者？）

对 nums1 中每个数都回到 nums2 里向右线性找第一个更大元素，最坏是 O(n₁ · n₂)。但题目有大量重复查询：只要先把 nums2 中每个元素的答案一次性算好，之后对 nums1 直接查表即可。

  1. 破局思路（单调栈一趟扫完 nums2）

核心观察：如果从左往右扫，某元素 a 迟迟没被某个更大值“接住”，说明它仍在等待。用栈保存这些「还没找到答案」的元素，并保持值单调递减。当扫描到 x：

  • 只要栈非空且 x > 栈顶，就说明栈顶的下一个更大元素就是 x，弹栈并写入哈希表 next[栈顶] = x；
  • 重复到栈顶不再小于 x，再把 x 入栈。

以 nums2=[1,3,4,2] 为例：1 入栈；读 3，3>1，记 next[1]=3 并弹栈，3 入栈；读 4，4>3，记 next[3]=4，4 入栈；读 2，2<4 直接入栈。最终栈中 [4,2] 无更大元素，答案 -1。

  1. 关键追问（为什么整体是线性的？）

每个元素最多入栈一次、出栈一次，所以扫描 nums2 总代价 O(n₂)。之后遍历 nums1 逐个查哈希表 O(n₁)。合计 O(n₁ + n₂)，正好满足进阶要求。

Java 实现（单调栈 + 哈希表）

import java.util.ArrayDeque;
import java.util.Deque;
import java.util.HashMap;
import java.util.Map;

class Solution {
    public int[] nextGreaterElement(int[] nums1, int[] nums2) {
        // next[x]：x 在 nums2 中的下一个更大元素；键为数值，因为元素互不相同
        Map<Integer, Integer> next = new HashMap<>();
        Deque<Integer> stack = new ArrayDeque<>(); // 单调递减栈（存数值）

        for (int x : nums2) {
            // 当前元素 x 是栈顶元素的“下一个更大元素”
            while (!stack.isEmpty() && stack.peek() < x) {
                next.put(stack.pop(), x);
            }
            stack.push(x);
        }
        // 仍留在栈中的元素没有下一个更大元素，查表时默认 -1

        int[] ans = new int[nums1.length];
        for (int i = 0; i < nums1.length; i++) {
            ans[i] = next.getOrDefault(nums1[i], -1);
        }
        return ans;
    }
}

C++ 实现

#include <vector>
#include <stack>
#include <unordered_map>
using namespace std;

class Solution {
public:
    vector<int> nextGreaterElement(vector<int>& nums1, vector<int>& nums2) {
        unordered_map<int, int> nxt; // 值 -> 下一个更大元素
        stack<int> st;               // 单调递减栈（存数值）

        for (int x : nums2) {
            while (!st.empty() && st.top() < x) {
                nxt[st.top()] = x;
                st.pop();
            }
            st.push(x);
        }

        vector<int> ans;
        ans.reserve(nums1.size());
        for (int x : nums1) {
            auto it = nxt.find(x);
            ans.push_back(it == nxt.end() ? -1 : it->second);
        }
        return ans;
    }
};

Python 实现

class Solution:
    def nextGreaterElement(self, nums1: list[int], nums2: list[int]) -> list[int]:
        nxt = {}          # 值 -> 下一个更大元素
        stack = []        # 单调递减栈（存数值）

        for x in nums2:
            while stack and stack[-1] < x:
                nxt[stack.pop()] = x
            stack.append(x)

        return [nxt.get(x, -1) for x in nums1]

复杂度

  • 时间：O(n₁ + n₂)。nums2 中每个元素最多入栈、出栈各一次；nums1 查询为 O(1) 均摊。
  • 空间：O(n₂)。栈与哈希表最多存 n₂ 个元素。
易错点与扩展（面试高频考点）
  1. 栈中存值还是存下标：本题元素互不相同，存数值即可；若数组可能重复，应存下标，否则无法区分相同值对应的不同位置。
  2. 是「严格大于」才弹栈：条件必须是 stack.peek() < x。若写成 <=，遇到相等元素会误判为「下一个更大」，而题目要求的是「更大」。
  3. 查表默认值 -1：扫描结束后仍在栈里的元素没有下一个更大元素，getOrDefault 的默认值必须是 -1，不能漏。
  4. 不要求 nums1 顺序与 nums2 一致：nums1 是子集但顺序任意，用哈希表按值映射，天然不依赖位置，无需排序或双指针。
  5. 扩展——下一个更大元素 II（循环数组 / 每日温度）：把 nums2 在逻辑上翻倍（取模遍历一遍）即可处理环形；「每日温度」则是同一单调栈模板，只是记录的是下标差（等待天数）。
