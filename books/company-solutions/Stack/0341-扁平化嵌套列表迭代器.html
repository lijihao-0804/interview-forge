341. 扁平化嵌套列表迭代器

本题学习状态正在读取学习记录…下次复习：—
本次复习：
按 M 快速切换薄弱标记
遮住推导与代码，先自己想，再逐段揭示
难度中等核心模式栈 + 惰性展开（按需产出的迭代器）时间复杂度均摊 O(1)空间复杂度O(n)

题目与约束

给你一个嵌套的整数列表 nestedList 。每个元素要么是一个整数，要么是一个列表；该列表的元素也可能是整数或者是其他列表。请你实现一个迭代器将其扁平化，使之能够遍历这个列表中的所有整数。

实现扁平迭代器类 NestedIterator ：

  • NestedIterator(List<NestedInteger> nestedList) 用嵌套列表 nestedList 初始化迭代器。

  • int next() 返回嵌套列表的下一个整数。

  • boolean hasNext() 如果仍然存在待迭代的整数，返回 true ；否则，返回 false 。

你的代码将会用下述伪代码检测：

initialize iterator with nestedList
res = []
while iterator.hasNext()
    append iterator.next() to the end of res
return res

如果 res 与预期的扁平化列表匹配，那么你的代码将会被判为正确。

示例 1：

输入：nestedList = [[1,1],2,[1,1]]
输出：[1,1,2,1,1]
解释：通过重复调用 next 直到 hasNext 返回 false，next 返回的元素的顺序应该是: [1,1,2,1,1]。

示例 2：

输入：nestedList = [1,[4,[6]]]
输出：[1,4,6]
解释：通过重复调用 next 直到 hasNext 返回 false，next 返回的元素的顺序应该是: [1,4,6]。

提示：

  • 1 <= nestedList.length <= 500

  • 嵌套列表中的整数值在范围 [-106, 106] 内

核心不变量

栈中存放「尚未输出的元素」；hasNext 负责把栈顶的列表不断展开，保证栈顶永远是可直接输出的整数（或栈为空），next 只负责弹出栈顶整数。

完整推导

思路推导

  1. 两种实现路线
  • 一次性 DFS 打平：构造时把整个嵌套结构递归压成一个数组，next/hasNext 只是移动下标。简单，但会一次性占用 O(n) 并把所有元素提前求值，不够"惰性"。
  • 栈 + 惰性展开：只在需要时才展开一层，天然契合迭代器语义，是本题的主流解法。
  1. 为什么要逆序压栈

栈是"后进先出"。为了让弹出顺序与原列表从左到右一致，必须把元素从右往左压栈，这样最左边的元素才在栈顶、最先被弹出。

  1. hasNext 是展开引擎

只要栈顶不是整数而是列表，就弹出它、把它的子元素逆序压回去，循环往复，直到栈顶是整数或栈空。正因为列表里还可能套列表，所以这里必须是 while 而不是 if。

  1. next 直接返回

在 hasNext 保证栈顶为整数的前提下，next 只需弹出栈顶并取 getInteger()。每个元素入栈一次、出栈一次，整体均摊 O(1)。

  • 小例子 [1,[4,[6]]]：逆序压栈后栈顶是 1，输出 1；接着栈顶是 [4,[6]]，展开成 4 与 [6]，输出 4；再展开 [6]，输出 6 → [1,4,6]。

Java 实现（NestedIterator）

import java.util.ArrayDeque;
import java.util.Deque;
import java.util.Iterator;
import java.util.List;

public class NestedIterator implements Iterator<Integer> {
    // 栈中保存待输出的 NestedInteger，栈顶始终"准备好"被输出
    private final Deque<NestedInteger> stack = new ArrayDeque<>();

    public NestedIterator(List<NestedInteger> nestedList) {
        // 逆序压栈，保证弹出顺序与列表从左到右一致
        for (int i = nestedList.size() - 1; i >= 0; i--) {
            stack.push(nestedList.get(i));
        }
    }

    @Override
    public Integer next() {
        // 调用前 hasNext 已保证栈顶是整数
        return stack.pop().getInteger();
    }

    @Override
    public boolean hasNext() {
        // 不断展开栈顶的列表，直到栈顶是整数或栈空
        while (!stack.isEmpty() && !stack.peek().isInteger()) {
            NestedInteger top = stack.pop();
            List<NestedInteger> list = top.getList();
            for (int i = list.size() - 1; i >= 0; i--) {
                stack.push(list.get(i));
            }
        }
        return !stack.isEmpty();
    }
}

C++ 实现

#include <vector>
#include <stack>

class NestedIterator {
private:
    std::stack<NestedInteger> st;   // 栈顶始终准备好被输出

public:
    NestedIterator(std::vector<NestedInteger>& nestedList) {
        // 逆序压栈，保证弹出顺序与列表从左到右一致
        for (int i = (int)nestedList.size() - 1; i >= 0; i--) {
            st.push(nestedList[i]);
        }
    }

    int next() {
        // 调用前 hasNext 已保证栈顶是整数
        int val = st.top().getInteger();
        st.pop();
        return val;
    }

    bool hasNext() {
        // 不断展开栈顶的列表，直到栈顶是整数或栈空
        while (!st.empty() && !st.top().isInteger()) {
            NestedInteger top = st.top();
            st.pop();
            std::vector<NestedInteger> list = top.getList();
            for (int i = (int)list.size() - 1; i >= 0; i--) {
                st.push(list[i]);
            }
        }
        return !st.empty();
    }
};

Python 实现

class NestedIterator:
    def __init__(self, nestedList: [NestedInteger]):
        # 逆序保存到列表末尾，pop() 时即从最左元素开始
        self.stack = list(reversed(nestedList))

    def next(self) -> int:
        # 调用前 hasNext 已保证栈顶是整数
        return self.stack.pop().getInteger()

    def hasNext(self) -> bool:
        # 不断展开栈顶的列表，直到栈顶是整数或栈为空
        while self.stack and not self.stack[-1].isInteger():
            top = self.stack.pop()
            self.stack.extend(reversed(top.getList()))
        return len(self.stack) > 0

复杂度

  • 时间：均摊 O(1) 每次 next/hasNext；整个迭代过程每个元素恰好入栈、出栈各一次，总计 O(n)。
  • 空间：O(n)，最坏情况（如深层/宽层嵌套）栈中同时保留 O(n) 个待处理元素。
易错点与扩展（面试高频考点）
  1. 必须逆序压栈：按正序 push 会让最右元素先出，输出顺序颠倒。
  2. hasNext 要用 while 循环展开：嵌套可能有多层，单次 if 只能展开一层，遇到 [4,[6]] 这种会卡住。
  3. next 与 hasNext 的契约：next 假设调用方已先调用过 hasNext；如果不放心，可在 next 内部也调用一次 hasNext 兜底（本题测试总是先行 hasNext）。
  4. 一次性打平 vs 惰性展开的取舍：一次性打平实现简单，但构造即 O(n) 且耗尽内存；惰性栈更符合"迭代器"设计初衷，也更能应对超大/惰性数据源。
  5. 注意 NestedInteger 接口：只用 isInteger()、getInteger()、getList()，不要在题目里自行实现该接口。
