736. Lisp 语法解析

题目与约束

给你一个类似 Lisp 语句的字符串表达式 expression，求出其计算结果。

表达式语法如下所示:

  • 表达式可以为整数，let 表达式，add 表达式，mult 表达式，或赋值的变量。表达式的结果总是一个整数。

  • (整数可以是正整数、负整数、0)

  • let 表达式采用 "(let v1 e1 v2 e2 ... vn en expr)" 的形式，其中 let 总是以字符串 "let"来表示，接下来会跟随一对或多对交替的变量和表达式，也就是说，第一个变量 v1被分配为表达式 e1 的值，第二个变量 v2 被分配为表达式 e2 的值，依次类推；最终 let 表达式的值为 expr表达式的值。

  • add 表达式表示为 "(add e1 e2)" ，其中 add 总是以字符串 "add" 来表示，该表达式总是包含两个表达式 e1、e2 ，最终结果是 e1 表达式的值与 e2 表达式的值之 和 。

  • mult 表达式表示为 "(mult e1 e2)" ，其中 mult 总是以字符串 "mult" 表示，该表达式总是包含两个表达式 e1、e2，最终结果是 e1 表达式的值与 e2 表达式的值之 积 。

  • 在该题目中，变量名以小写字符开始，之后跟随 0 个或多个小写字符或数字。为了方便，"add" ，"let" ，"mult" 会被定义为 "关键字" ，不会用作变量名。

  • 最后，要说一下作用域的概念。计算变量名所对应的表达式时，在计算上下文中，首先检查最内层作用域（按括号计），然后按顺序依次检查外部作用域。测试用例中每一个表达式都是合法的。有关作用域的更多详细信息，请参阅示例。

示例 1：

输入：expression = "(let x 2 (mult x (let x 3 y 4 (add x y))))"
输出：14
解释：
计算表达式 (add x y), 在检查变量 x 值时，
在变量的上下文中由最内层作用域依次向外检查。
首先找到 x = 3, 所以此处的 x 值是 3 。

示例 2：

输入：expression = "(let x 3 x 2 x)"
输出：2
解释：let 语句中的赋值运算按顺序处理即可。

示例 3：

输入：expression = "(let x 1 y 2 x (add x y) (add x y))"
输出：5
解释：
第一个 (add x y) 计算结果是 3，并且将此值赋给了 x 。
第二个 (add x y) 计算结果是 3 + 2 = 5 。

提示：

  • 1 <= expression.length <= 2000

  • exprssion 中不含前导和尾随空格

  • expressoin 中的不同部分（token）之间用单个空格进行分隔

  • 答案和所有中间计算结果都符合 32-bit 整数范围

  • 测试用例中的表达式均为合法的且最终结果为整数

核心不变量

每个 let 新建一层作用域，变量从最内层向外层查找；let 的绑定按书写顺序依次生效。

完整推导

思路推导

  1. 先分词。 把 (、) 各当作一个独立 token，其余连续的字母/数字/负号按空白切分成 token。例如 (let x 2 ...) 变成 [ "(", "let", "x", "2", ... ]。这样递归时只需在 token 列表上滑动下标。

  2. 写一个递归求值函数 parse()。 它从当前 token 开始解析一个完整表达式并返回其整数值： - 若当前 token 不是 (，它就是整数（以 - 或数字开头）或变量（小写字母开头），直接返回。 - 若是 (，看下一个 token 是哪种操作符。

  3. 处理 let。 压入一层新作用域，然后循环读取“变量 表达式”对：只要当前 token 是变量名，且它后面紧跟的不是 )，就说明它是绑定变量，解析其表达式后存入当前作用域。一旦遇到后面紧跟 ) 的变量，或遇到 (，就说明这已是 let 的最终表达式，求出它的值、弹出作用域并返回。

  4. 处理 add / mult。 依次解析两个子表达式，返回它们的和或积。变量查找时从最内层作用域向外层逐层查找。

Java 实现（evaluate）

import java.util.ArrayList;
import java.util.HashMap;
import java.util.List;
import java.util.Map;

class Solution {
    private List<String> tokens;
    private int pos;
    private List<Map<String, Integer>> scopes; // 作用域栈：0 为最外层

    public int evaluate(String expression) {
        tokens = tokenize(expression);
        pos = 0;
        scopes = new ArrayList<>();
        scopes.add(new HashMap<>());
        return parse();
    }

    // 分词：括号单独成 token，其余按空白/括号切开
    private List<String> tokenize(String s) {
        List<String> res = new ArrayList<>();
        int i = 0, n = s.length();
        while (i < n) {
            char c = s.charAt(i);
            if (c == ' ') {
                i++;
            } else if (c == '(' || c == ')') {
                res.add(String.valueOf(c));
                i++;
            } else {
                int j = i;
                while (j < n && s.charAt(j) != ' ' && s.charAt(j) != '(' && s.charAt(j) != ')') j++;
                res.add(s.substring(i, j));
                i = j;
            }
        }
        return res;
    }

    private boolean isVar(String t) {
        char c = t.charAt(0);
        return c >= 'a' && c <= 'z';
    }

    // 解析并求值一个表达式，返回整数值
    private int parse() {
        String tok = tokens.get(pos);

        // 原子表达式：整数或变量
        if (!tok.equals("(")) {
            pos++;
            if (tok.charAt(0) == '-' || Character.isDigit(tok.charAt(0))) {
                return Integer.parseInt(tok);
            }
            for (int k = scopes.size() - 1; k >= 0; k--) {
                if (scopes.get(k).containsKey(tok)) return scopes.get(k).get(tok);
            }
            return 0; // 合法输入下不会走到
        }

        String op = tokens.get(pos + 1);
        pos += 2; // 跳过 "(" 和操作符

        if (op.equals("let")) {
            scopes.add(new HashMap<>());
            while (true) {
                // 变量名且其后不是 ')' ⇒ 这是一个绑定
                if (isVar(tokens.get(pos)) && !tokens.get(pos + 1).equals(")")) {
                    String var = tokens.get(pos);
                    pos++;
                    int val = parse();
                    scopes.get(scopes.size() - 1).put(var, val);
                } else {
                    int val = parse();      // 最终表达式
                    pos++;                  // 跳过 ')'
                    scopes.remove(scopes.size() - 1);
                    return val;
                }
            }
        } else {
            int a = parse();
            int b = parse();
            pos++; // 跳过 ')'
            return op.equals("add") ? a + b : a * b;
        }
    }
}

C++ 实现

class Solution {
public:
    int evaluate(string expression) {
        tokens = tokenize(expression);
        pos = 0;
        scopes.clear();
        scopes.push_back({});
        return parse();
    }

private:
    vector<string> tokens;
    int pos;
    vector<map<string, int>> scopes;

    vector<string> tokenize(const string& s) {
        vector<string> res;
        int i = 0, n = s.size();
        while (i < n) {
            char c = s[i];
            if (c == ' ') {
                i++;
            } else if (c == '(' || c == ')') {
                res.push_back(string(1, c));
                i++;
            } else {
                int j = i;
                while (j < n && s[j] != ' ' && s[j] != '(' && s[j] != ')') j++;
                res.push_back(s.substr(i, j - i));
                i = j;
            }
        }
        return res;
    }

    bool isVar(const string& t) {
        return !t.empty() && t[0] >= 'a' && t[0] <= 'z';
    }

    int parse() {
        string tok = tokens[pos];
        if (tok != "(") {
            pos++;
            if (tok[0] == '-' || isdigit((unsigned char)tok[0])) return stoi(tok);
            for (int k = (int)scopes.size() - 1; k >= 0; k--) {
                auto it = scopes[k].find(tok);
                if (it != scopes[k].end()) return it->second;
            }
            return 0;
        }

        string op = tokens[pos + 1];
        pos += 2;

        if (op == "let") {
            scopes.push_back({});
            while (true) {
                if (isVar(tokens[pos]) && tokens[pos + 1] != ")") {
                    string var = tokens[pos];
                    pos++;
                    int val = parse();
                    scopes.back()[var] = val;
                } else {
                    int val = parse();
                    pos++;            // 跳过 ')'
                    scopes.pop_back();
                    return val;
                }
            }
        } else {
            int a = parse();
            int b = parse();
            pos++;                    // 跳过 ')'
            return op == "add" ? a + b : a * b;
        }
    }
};

Python 实现

class Solution:
    def evaluate(self, expression: str) -> int:
        self.tokens = self._tokenize(expression)
        self.pos = 0
        self.scopes = [{}]
        return self._parse()

    def _tokenize(self, s: str):
        res = []
        i, n = 0, len(s)
        while i < n:
            c = s[i]
            if c == ' ':
                i += 1
            elif c in '()':
                res.append(c)
                i += 1
            else:
                j = i
                while j < n and s[j] not in ' ()':
                    j += 1
                res.append(s[i:j])
                i = j
        return res

    def _is_var(self, t: str) -> bool:
        return t[0].islower()

    def _parse(self) -> int:
        tok = self.tokens[self.pos]
        if tok != '(':
            self.pos += 1
            if tok[0] == '-' or tok[0].isdigit():
                return int(tok)
            for scope in reversed(self.scopes):
                if tok in scope:
                    return scope[tok]
            return 0

        op = self.tokens[self.pos + 1]
        self.pos += 2

        if op == 'let':
            self.scopes.append({})
            while True:
                if self._is_var(self.tokens[self.pos]) and self.tokens[self.pos + 1] != ')':
                    var = self.tokens[self.pos]
                    self.pos += 1
                    val = self._parse()
                    self.scopes[-1][var] = val
                else:
                    val = self._parse()
                    self.pos += 1          # 跳过 ')'
                    self.scopes.pop()
                    return val
        else:
            a = self._parse()
            b = self._parse()
            self.pos += 1                  # 跳过 ')'
            return a + b if op == 'add' else a * b

复杂度

  • 时间：O(n)，每个 token（字符）只被扫描与处理常数次。
  • 空间：O(n)，分词得到的 token 列表与作用域栈、递归深度均与表达式长度同阶。
易错点与扩展（面试高频考点）
  1. let 绑定顺序生效：示例 3 里 x 被后面的 (add x y) 重新赋值，后面的表达式必须读到新值，所以边读边算、逐条写回作用域。
  2. 区分“绑定变量”与“最终表达式”：二者都可能以变量形式出现，判据是变量后面是否紧跟 )——紧跟 ) 的是最终表达式。
  3. 负数字面量：以 - 开头的 token 要当整数解析，别误判成变量。
  4. 作用域进出要成对：let 结束务必弹出这层作用域，否则会污染外层同名变量的取值。
  5. 关键字不是变量：add/let/mult 在 ( 之后按操作符处理；只有非 ( 位置且小写开头的 token 才是变量。
