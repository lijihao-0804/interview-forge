题目与约束

给你一棵二叉树的根节点 root，返回其节点值的 后序遍历。后序遍历的访问顺序是：先递归遍历左子树，再递归遍历右子树，最后访问根节点。

示例 1：

输入：root = [1,null,2,3]
输出：[3,2,1]

示例 2：

输入：root = [1,2,3,4,5,null,8,null,null,6,7,9]
输出：[4,6,7,5,2,9,8,3,1]

示例 3：

输入：root = []
输出：[]

示例 4：

输入：root = [1]
输出：[1]

提示：

  • 树中节点的数目在范围 [0, 100] 内
  • -100 <= Node.val <= 100

进阶： 递归算法很简单，你可以通过迭代算法完成吗？

核心不变量

后序序列等于「根 → 右 → 左」序列的整体反转；因此只需按前序的镜像方式遍历，再把结果反转即得后序。

完整推导

思路推导

  1. 后序的定义（左 → 右 → 根）

后序遍历最后才访问根，递归写法最直观：dfs(left)、dfs(right)、再记录根。但直接迭代时，"根要等两个孩子都处理完才记录"，这一步没有前序那么自然。

  1. 破局思路（借道"根 → 右 → 左"）

观察一个对称关系：如果按"根 → 右 → 左"的顺序遍历得到序列 S，那么把 S 反转，恰好就是"左 → 右 → 根"，正是后序。而"根 → 右 → 左"极易实现：和前序一样用栈，只是把压栈顺序改为 先压左、再压右，这样下一轮先弹出右孩子。

  1. 小例子（示例 1：[1,null,2,3]）
  • 栈 [1]，弹出 1 记录；先压左（空）再压右 2 → 栈 [2]
  • 弹出 2 记录；先压左 3 再压右（空）→ 栈 [3]
  • 弹出 3 记录 → 得 [1,2,3]
  • 整体反转 → [3,2,1]，正是后序。
  1. 收尾

空树返回空列表；遍历完把结果列表反转即可。

Java 实现（postorderTraversal）

import java.util.ArrayDeque;
import java.util.ArrayList;
import java.util.Collections;
import java.util.Deque;
import java.util.List;

/**
 * Definition for a binary tree node.
 * public class TreeNode {
 *     int val;
 *     TreeNode left;
 *     TreeNode right;
 *     TreeNode() {}
 *     TreeNode(int val) { this.val = val; }
 *     TreeNode(int val, TreeNode left, TreeNode right) {
 *         this.val = val;
 *         this.left = left;
 *         this.right = right;
 *     }
 * }
 */
class Solution {
    public List<Integer> postorderTraversal(TreeNode root) {
        List<Integer> res = new ArrayList<>();
        if (root == null) {
            return res;
        }
        Deque<TreeNode> stack = new ArrayDeque<>();
        stack.push(root);
        while (!stack.isEmpty()) {
            TreeNode node = stack.pop();
            res.add(node.val);
            // 先压左、再压右，使弹出顺序为“根 → 右 → 左”
            if (node.left != null) {
                stack.push(node.left);
            }
            if (node.right != null) {
                stack.push(node.right);
            }
        }
        // 反转后即“左 → 右 → 根”，即后序
        Collections.reverse(res);
        return res;
    }
}

复杂度

  • 时间：O(n)，每个节点入栈、出栈各一次，最后反转一遍同样 O(n)。
  • 空间：O(h)，栈最多保存一条根到叶的路径；最坏退化链为 O(n)。

易错点与扩展（面试高频考点）

  1. 压栈顺序必须"先左后右"：只有先压左再压右，弹出才是"根 → 右 → 左"，反转后才是后序；写反了就变成前序。
  2. 别忘记反转：得到的是"根 → 右 → 左"，遗漏 Collections.reverse 会直接返回错误顺序。
  3. 空树判断：root == null 提前返回，避免对空栈/空节点操作。
  4. 另一种迭代法：用单个栈配合 lastVisited 标记记录"上一个被访问的节点"，当 node.right == lastVisited 时才记录当前节点；这种写法不反转、更贴合后序语义，但逻辑更绕，面试中能说清即可。
  5. 三序关系：前序"根左右"、后序"左右根"、中序"左根右"。本题的"反转技巧"仅对后序成立（因为后序 = 前序镜像的逆序）。

C++ 实现

#include <vector>
using namespace std;

/**
 * Definition for a binary tree node.
 * struct TreeNode {
 *     int val;
 *     TreeNode *left;
 *     TreeNode *right;
 *     TreeNode() : val(0), left(nullptr), right(nullptr) {}
 *     TreeNode(int x) : val(x), left(nullptr), right(nullptr) {}
 *     TreeNode(int x, TreeNode *left, TreeNode *right) : val(x), left(left), right(right) {}
 * };
 */
class Solution {
public:
    vector<int> postorderTraversal(TreeNode* root) {
        vector<int> res;
        dfs(root, res);
        return res;
    }

private:
    void dfs(TreeNode* node, vector<int>& res) {
        if (node == nullptr) {
            return;
        }
        dfs(node->left, res);     // 左
        dfs(node->right, res);    // 右
        res.push_back(node->val); // 根
    }
};

Python 实现

from typing import Optional, List

# Definition for a binary tree node.
# class TreeNode:
#     def __init__(self, val=0, left=None, right=None):
#         self.val = val
#         self.left = left
#         self.right = right
class Solution:
    def postorderTraversal(self, root: Optional[TreeNode]) -> List[int]:
        res = []

        def dfs(node: Optional[TreeNode]) -> None:
            if not node:
                return
            dfs(node.left)        # 左
            dfs(node.right)       # 右
            res.append(node.val)  # 根

        dfs(root)
        return res
