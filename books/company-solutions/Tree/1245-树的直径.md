# 1245. 树的直径

| 题目信息 | 内容 |
|---|---|
| 难度 | 中等 |
| 核心模式 | 两次 BFS/DFS 求树的直径（也可树形 DP） |
| 时间复杂度 | O(n) |
| 空间复杂度 | O(n) |

## 题目与约束

给定一棵无向树，返回它的**直径**——即树中最长路径上的**边数**。

树由 `n` 个节点组成，节点编号为 `0` 到 `n - 1`。给定二维数组 `edges`，其中 `edges.length == n - 1`，`edges[i] = [u_i, v_i]` 表示节点 `u_i` 与 `v_i` 之间存在一条无向边。

**示例 1：**

```
输入：edges = [[0,1],[0,2]]
输出：2
解释：树中最长的路径是 1 - 0 - 2（含 2 条边）。
```

**示例 2：**

```
输入：edges = [[0,1],[1,2],[2,3],[1,4],[4,5]]
输出：4
解释：树中最长的路径是 3 - 2 - 1 - 4 - 5（含 4 条边）。
```

**提示：**

- `n == edges.length + 1`
- `1 <= n <= 10^4`
- `0 <= edges[i][0], edges[i][1] < n`
- `edges[i][0] != edges[i][1]`
- 输入的边构成一棵无向树

## 核心不变量

> 从任意一点出发找到的最远点 `u`，一定是某条直径的一个端点；再从 `u` 出发找到的最远距离，就是整棵树的直径。

## 完整推导

### 思路推导

1. **树的结构特点**

   树是无环连通图，任意两点之间的路径**唯一**，距离就是这条路径上的边数。直径即「所有点对距离」的最大值。若直接枚举点对，是 `O(n²)`，`n` 达到 `10^4` 时偏慢，需要更聪明的做法。

2. **两次 BFS 的巧妙之处**

   - 第一次：从任意节点（比如 `0`）出发做 BFS，记录每个节点的距离，找到离它最远的节点 `u`。
   - 第二次：从 `u` 出发再做一次 BFS，找到离 `u` 最远的节点 `v`，此时 `dist(u, v)` 就是树的直径。

3. **为什么第一次的最远点一定是直径端点？**

   直观理解：把树想象成一根主干加若干分支。从任意点出发往远处走，走得最远的方向一定通到主干的一个末端（否则绕回来会更远）。可以交换论证：设真实直径为 `(a, b)`，从起点 `s` 出发最远到 `u`，则 `dist(s,u) >= dist(s,a)`，进而可推出 `dist(u,b) >= dist(a,b)`，而 `dist(a,b)` 已是最大值，故 `dist(u,b) = dist(a,b)`，`u` 必是某个直径端点。第二次从 `u` 找最远点，自然得到直径。

4. **小例子**

   `edges = [[0,1],[1,2],[2,3],[1,4],[4,5]]`，结构是一棵以 `1` 为枢纽的树。从 `0` 出发最远可达 `3` 或 `5`（距离 3），取 `u = 3`；从 `3` 出发最远到 `5`，距离 `3-2-1-4-5 = 4`，即直径 4。

### Java 实现（两次 BFS）

```java
import java.util.ArrayDeque;
import java.util.ArrayList;
import java.util.Arrays;
import java.util.Deque;
import java.util.List;

class Solution {
    public int treeDiameter(int[][] edges) {
        int n = edges.length + 1;
        // 建邻接表（无向树）
        List<List<Integer>> g = new ArrayList<>();
        for (int i = 0; i < n; i++) g.add(new ArrayList<>());
        for (int[] e : edges) {
            g.get(e[0]).add(e[1]);
            g.get(e[1]).add(e[0]);
        }

        int far1 = bfs(g, 0, n)[0];        // 第一次：找到离 0 最远的点
        int diameter = bfs(g, far1, n)[1]; // 第二次：从该点出发的最远距离即直径
        return diameter;
    }

    // 从 start 出发 BFS，返回 {最远节点, 最远距离}
    private int[] bfs(List<List<Integer>> g, int start, int n) {
        int[] dist = new int[n];
        Arrays.fill(dist, -1);
        Deque<Integer> q = new ArrayDeque<>();
        q.offer(start);
        dist[start] = 0;

        int farNode = start;
        while (!q.isEmpty()) {
            int u = q.poll();
            for (int v : g.get(u)) {
                if (dist[v] == -1) {          // 未访问过
                    dist[v] = dist[u] + 1;
                    if (dist[v] > dist[farNode]) farNode = v;
                    q.offer(v);
                }
            }
        }
        return new int[]{farNode, dist[farNode]};
    }
}
```

### 复杂度

- 时间：`O(n)`。建图 `O(n)`；两次 BFS 各访问每个节点、每条边一次，合计 `O(n)`。
- 空间：`O(n)`。邻接表存 `2(n-1)` 条边、`dist` 数组与队列均为 `O(n)`。

### 易错点与扩展（面试高频考点）

1. **返回的是边数而非点数**：直径定义为路径上的边数，`dist` 直接就是边数；不要多加 1。
2. **`n = 1` 的边界**：`edges` 为空时只有一个节点，直径为 `0`；两次 BFS 都能正确返回 0，别在取邻接表时越界。
3. **两次 BFS 的起点顺序**：第一次可从任意点出发，第二次必须从第一次得到的最远点出发，顺序不能反。
4. **建图要双向**：树是无向的，`u→v` 与 `v→u` 都要加边；只加单向会变成有向图导致结果错误。
5. **扩展——树形 DP**：一次 DFS 即可，对每个节点维护「向下的最长链」和「次长链」，用 `最长 + 次长` 更新答案，同样 `O(n)`，且更容易推广到带权边的情形（两次 BFS 需相应改成按距离搜索）。

## 力扣原题

### C++ 实现

```cpp
#include <vector>
#include <queue>
#include <utility>
using namespace std;

class Solution {
    // 从 start 出发 BFS，返回 {最远节点, 最远距离}
    pair<int, int> bfs(const vector<vector<int>>& g, int start, int n) {
        vector<int> dist(n, -1);
        queue<int> q;
        q.push(start);
        dist[start] = 0;

        int farNode = start;
        while (!q.empty()) {
            int u = q.front();
            q.pop();
            for (int v : g[u]) {
                if (dist[v] == -1) {
                    dist[v] = dist[u] + 1;
                    if (dist[v] > dist[farNode]) farNode = v;
                    q.push(v);
                }
            }
        }
        return {farNode, dist[farNode]};
    }

public:
    int treeDiameter(vector<vector<int>>& edges) {
        int n = static_cast<int>(edges.size()) + 1;
        vector<vector<int>> g(n);
        for (auto& e : edges) {
            g[e[0]].push_back(e[1]);
            g[e[1]].push_back(e[0]);
        }

        auto p1 = bfs(g, 0, n);            // 第一次：最远点
        auto p2 = bfs(g, p1.first, n);     // 第二次：直径
        return p2.second;
    }
};
```

### Python 实现

```python
from typing import List
from collections import deque


class Solution:
    def treeDiameter(self, edges: List[List[int]]) -> int:
        n = len(edges) + 1
        g = [[] for _ in range(n)]
        for u, v in edges:
            g[u].append(v)
            g[v].append(u)

        def bfs(start: int):
            dist = [-1] * n
            dist[start] = 0
            q = deque([start])
            far_node = start
            while q:
                u = q.popleft()
                for v in g[u]:
                    if dist[v] == -1:
                        dist[v] = dist[u] + 1
                        if dist[v] > dist[far_node]:
                            far_node = v
                        q.append(v)
            return far_node, dist[far_node]

        u, _ = bfs(0)          # 第一次：最远点
        _, diameter = bfs(u)   # 第二次：从最远点出发的最远距离
        return diameter
```
