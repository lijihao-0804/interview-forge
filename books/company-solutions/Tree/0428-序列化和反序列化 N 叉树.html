题目与约束

序列化是指将一个数据结构转化为位序列的过程，以便可以将其存储在文件中或内存缓冲区中，并在稍后于相同或不同的计算机环境中恢复。请设计一个用于序列化和反序列化 N 叉树的算法。

N 叉树是指每个节点都有不超过 N 个孩子节点的有向无环图结构。序列化 / 反序列化算法的实现没有限制，你只需要保证 N 叉树可以被序列化为一个字符串，并且该字符串可以被反序列化恢复为原始的 N 叉树结构即可。

示例 1：

输入：root = [1,null,3,2,4,null,5,6]
输出：[1,null,3,2,4,null,5,6]
解释：上面为 N 叉树，下面为序列化再反序列化后得到的树，两者应完全一致。

示例 2：

输入：root = [1,null,2,3,4,5,null,null,6,7,null,8,null,9,10,null,null,11,null,12,null,13,null,null,14]
输出：[1,null,2,3,4,5,null,null,6,7,null,8,null,9,10,null,null,11,null,12,null,13,null,null,14]

示例 3：

输入：root = []
输出：[]

提示：

  • 树中节点数在范围 [0, 10^4] 内
  • 每个节点的子节点数在范围 [0, 10^4] 内
  • 0 <= Node.val <= 10^4
  • 树的高度小于等于 1000

说明：Node 的定义为 val（节点值）与 children（孩子节点列表）。题目只要求序列化结果能正确还原原树，不限定具体字符串格式。

核心不变量

序列化时对每个节点写出"节点值 + 孩子数量"，再按顺序递归其孩子；反序列化读取同一个值后，用刚读到的孩子数量决定递归边界，从而唯一还原每个节点的结构。

完整推导

思路推导

  1. 难点（前序序列化为什么不够）

普通二叉树可用 null 标记空孩子来划分结构，但 N 叉树孩子数不固定，单靠一串值无法知道"哪个节点下面挂几个孩子"。所以必须显式记录每个节点的孩子数量。

  1. 序列化（前序 + 孩子数）

对每个节点依次写入两项：val 和 children.size()，然后用逗号分隔；随后递归序列化它的每一个孩子。整个过程是前序遍历，父节点信息先于孩子写入。

  1. 反序列化（按同样顺序读）

把字符串按逗号切成 token，用一个下标游标顺序读取：先读 val，再读 count；建好节点后，循环 count 次递归构造孩子，正好消耗掉属于这棵子树的 token。因为写入和读取顺序完全对称，游标不会错位。

  1. 小例子（root = [1,null,3,2,4,null,5,6]）

节点 1 有 3 个孩子（3、2、4），节点 3 有 2 个孩子（5、6）。 序列化为 1,3, 3,2, 5,0, 6,0, 2,0, 4,0,：每个 值,孩子数 依次排列。反序列化读到 1,3 就知道 1 有 3 个孩子，随后按序构造这 3 棵子树。

Java 实现（Codec：serialize / deserialize）

import java.util.ArrayList;
import java.util.List;

class Codec {
    // 序列化：前序遍历，每个节点记录 "值,孩子数量"
    public String serialize(Node root) {
        StringBuilder sb = new StringBuilder();
        serializeHelper(root, sb);
        return sb.toString();
    }

    private void serializeHelper(Node node, StringBuilder sb) {
        if (node == null) {
            return;
        }
        sb.append(node.val).append(',');
        sb.append(node.children == null ? 0 : node.children.size()).append(',');
        if (node.children != null) {
            for (Node child : node.children) {
                serializeHelper(child, sb);
            }
        }
    }

    // 反序列化：按同一顺序读取 "值,孩子数量"，再递归构造孩子
    public Node deserialize(String data) {
        if (data == null || data.isEmpty()) {
            return null;
        }
        String[] tokens = data.split(",");
        int[] idx = {0}; // 用数组模拟引用传递的游标
        return deserializeHelper(tokens, idx);
    }

    private Node deserializeHelper(String[] tokens, int[] idx) {
        int val = Integer.parseInt(tokens[idx[0]++]);
        int count = Integer.parseInt(tokens[idx[0]++]);

        Node node = new Node(val);
        node.children = new ArrayList<>(); // 构造函数可能未初始化，需手动建表
        for (int i = 0; i < count; i++) {
            node.children.add(deserializeHelper(tokens, idx));
        }
        return node;
    }
}

复杂度

  • 时间：O(n)，每个节点在序列化与反序列化中各访问一次，字符串切分也只需线性时间。
  • 空间：O(n)，递归调用栈深度最坏为树高（可达 1000），序列化结果与 token 数组同样占用 O(n)。

易错点与扩展（面试高频考点）

  1. 孩子数量必须记录：只写节点值无法区分孩子边界，这是 N 叉树与二叉树序列化的最大区别。
  2. children 初始化：Node(int) 构造器可能未初始化 children，反序列化时须 new ArrayList<>()，否则 add 会抛空指针。
  3. 空树处理：root == null 序列化为空串，反序列化遇到空串必须返回 null，两侧要配套。
  4. 游标按引用传递：Java 里用 int[] idx 或成员变量保存下标；若按值传 int 会在递归返回后丢失进度。
  5. 递归深度风险：树高可达 1000，注意栈深度；也可改用显式栈做迭代，或采用"层序 + null 分隔"的格式（与题目输入格式一致）。
  6. 扩展问法：序列化格式可自由设计（括号表示、BFS 层序、val 后跟 null 结束标记等），只要保证 deserialize(serialize(root)) 能还原即得分。

428. 序列化和反序列化 N 叉树

C++ 实现

class Codec {
public:
    // 序列化：前序，每节点写 "值,孩子数量"
    string serialize(Node* root) {
        string out;
        serializeHelper(root, out);
        return out;
    }

    // 反序列化：按同序读取
    Node* deserialize(string data) {
        if (data.empty()) return nullptr;

        vector<string> tokens;
        string cur;
        for (char c : data) {
            if (c == ',') {
                tokens.push_back(cur);
                cur.clear();
            } else {
                cur.push_back(c);
            }
        }
        if (!cur.empty()) tokens.push_back(cur);

        int idx = 0;
        return deserializeHelper(tokens, idx);
    }

private:
    void serializeHelper(Node* node, string& out) {
        if (!node) return;
        out += to_string(node->val) + "," + to_string(node->children.size()) + ",";
        for (Node* child : node->children) {
            serializeHelper(child, out);
        }
    }

    Node* deserializeHelper(vector<string>& tokens, int& idx) {
        int val = stoi(tokens[idx++]);
        int count = stoi(tokens[idx++]);

        Node* node = new Node(val);
        for (int i = 0; i < count; ++i) {
            node->children.push_back(deserializeHelper(tokens, idx));
        }
        return node;
    }
};

Python 实现

class Codec:
    def serialize(self, root: 'Node') -> str:
        tokens = []

        def dfs(node):
            if node is None:
                return
            tokens.append(str(node.val))
            tokens.append(str(len(node.children) if node.children else 0))
            for child in node.children or []:
                dfs(child)

        dfs(root)
        return ",".join(tokens)

    def deserialize(self, data: str) -> 'Node':
        if not data:
            return None

        tokens = data.split(",")
        idx = 0

        def dfs():
            nonlocal idx
            val = int(tokens[idx]); idx += 1
            count = int(tokens[idx]); idx += 1

            node = Node(val, [])
            for _ in range(count):
                node.children.append(dfs())
            return node

        return dfs()
