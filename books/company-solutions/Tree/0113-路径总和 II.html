113. 路径总和 II

本题学习状态正在读取学习记录…下次复习：—

遮住推导与代码，先自己想，再逐段揭示
难度中等核心模式DFS + 回溯（路径记录）时间复杂度O(n²)空间复杂度O(h)

题目与约束

给你二叉树的根节点 root 和一个整数目标和 targetSum ，找出所有 从根节点到叶子节点 路径总和等于给定目标和的路径。

叶子节点 是指没有子节点的节点。

示例 1：

输入：root = [5,4,8,11,null,13,4,7,2,null,null,5,1], targetSum = 22
输出：[[5,4,11,2],[5,8,4,5]]

示例 2：

输入：root = [1,2,3], targetSum = 5
输出：[]

示例 3：

输入：root = [1,2], targetSum = 0
输出：[]

提示：

  • 树中节点总数在范围 [0, 5000] 内

  • -1000 <= Node.val <= 1000

  • -1000 <= targetSum <= 1000

🔗 前往力扣原题验证 →

核心不变量

递归过程中始终维护一条“当前路径”：进入节点就压入、离开节点就弹出；只有叶子处总和命中，才把这条路径的深拷贝加入结果。

完整推导

思路推导

  1. 与 112 的关系

判断“是否存在”只需要返回布尔值；本题要“找出所有”，所以除了用同样的“减法”判断命中，还必须把命中的整条路径完整记录下来。

  1. 怎么维护一条路径

用一个 path 列表跟着递归走：进入某个节点时 path.append(node.val)，处理完它的左右子树后再 path.pop()（这就是回溯）。这样 path 永远对应当前从根到当前节点的链。

  1. 命中与收集

当某节点是叶子且“剩余目标 == 该节点值”时，path 里正好是从根到叶的完整路径，把它的深拷贝加入结果集。

  1. 小例子

root = [5,4,8,11,null,13,4,7,2,...]，targetSum = 22：走到 5→4→11→2 时剩余命中去为 2，收集 [5,4,11,2]；另一支 5→8→4→5 命中，收集 [5,8,4,5]。

Java 实现（pathSum）

import java.util.ArrayList;
import java.util.ArrayDeque;
import java.util.Deque;
import java.util.List;

/**
 * Definition for a binary tree node.
 * public class TreeNode {
 *     int val;
 *     TreeNode left;
 *     TreeNode right;
 *     TreeNode() {}
 *     TreeNode(int val) { this.val = val; }
 *     TreeNode(int val, TreeNode left, TreeNode right) {
 *         this.val = val;
 *         this.left = left;
 *         this.right = right;
 *     }
 * }
 */
class Solution {
    public List<List<Integer>> pathSum(TreeNode root, int targetSum) {
        List<List<Integer>> res = new ArrayList<>();
        Deque<Integer> path = new ArrayDeque<>();
        dfs(root, targetSum, path, res);
        return res;
    }

    private void dfs(TreeNode node, int remain, Deque<Integer> path, List<List<Integer>> res) {
        if (node == null) {
            return;
        }
        // 选择：把当前节点加入路径
        path.addLast(node.val);

        // 叶子且剩余目标命中：收集这条路径的深拷贝
        if (node.left == null && node.right == null && remain == node.val) {
            res.add(new ArrayList<>(path));
        } else {
            // 继续向左右子树搜索，剩余目标递减
            dfs(node.left, remain - node.val, path, res);
            dfs(node.right, remain - node.val, path, res);
        }

        // 回溯：撤销选择，保证兄弟分支的路径不受影响
        path.removeLast();
    }
}

C++ 实现

/**
 * Definition for a binary tree node.
 * struct TreeNode {
 *     int val;
 *     TreeNode *left;
 *     TreeNode *right;
 *     TreeNode() : val(0), left(nullptr), right(nullptr) {}
 *     TreeNode(int x) : val(x), left(nullptr), right(nullptr) {}
 *     TreeNode(int x, TreeNode *left, TreeNode *right) : val(x), left(left), right(right) {}
 * };
 */
class Solution {
public:
    vector<vector<int>> pathSum(TreeNode* root, int targetSum) {
        vector<vector<int>> res;
        vector<int> path;
        dfs(root, targetSum, path, res);
        return res;
    }

private:
    void dfs(TreeNode* node, int remain, vector<int>& path, vector<vector<int>>& res) {
        if (node == nullptr) return;
        path.push_back(node->val); // 选择

        if (node->left == nullptr && node->right == nullptr && remain == node->val) {
            res.push_back(path); // 命中，复制当前路径
        } else {
            dfs(node->left, remain - node->val, path, res);
            dfs(node->right, remain - node->val, path, res);
        }

        path.pop_back(); // 回溯，撤销选择
    }
};

Python 实现

from typing import Optional, List

# Definition for a binary tree node.
# class TreeNode:
#     def __init__(self, val=0, left=None, right=None):
#         self.val = val
#         self.left = left
#         self.right = right

class Solution:
    def pathSum(self, root: Optional[TreeNode], targetSum: int) -> List[List[int]]:
        res = []
        path = []

        def dfs(node, remain):
            if not node:
                return
            path.append(node.val)  # 选择
            if not node.left and not node.right and remain == node.val:
                res.append(path[:])  # 命中，深拷贝当前路径
            else:
                dfs(node.left, remain - node.val)
                dfs(node.right, remain - node.val)
            path.pop()  # 回溯，撤销选择

        dfs(root, targetSum)
        return res

复杂度

  • 时间：O(n²)，最坏情况下每个节点都可能是某条命中路径的一部分，而每次收集需要复制长度 O(h) 的路径；因节点值可正可负，无法有效剪枝。
  • 空间：O(h)，递归栈与 path 的深度均等于树高（不计用于存放结果的空间）；最坏链状树为 O(n)。
易错点与扩展（面试高频考点）
  1. 必须存深拷贝：若直接 res.add(path)，后续回溯 pop 会把已收集的路径一起改掉，结果全错。
  2. 只在叶子判断：非叶子节点即使剩余目标已命中，也不能算一条完整的根到叶路径。
  3. 漏掉回溯 pop：不弹出会让兄弟分支“串味”，路径里混入别的分支节点。
  4. 节点值可为负：不能用“剩余目标 < 0 就剪枝”的贪心，必须老老实实走完。
  5. 空树返回 []，targetSum = 0 也不会产生任何路径。
