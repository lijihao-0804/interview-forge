题目与约束

设计一个找到数据流中第 k 大元素的类（class）。注意是排序后的第 k 大元素，不是第 k 个不同的元素。

请实现 KthLargest 类：

  • KthLargest(int k, int[] nums) 使用整数 k 和整数流 nums 初始化对象。
  • int add(int val) 将 val 插入数据流 nums 后，返回当前数据流中第 k 大的元素。

示例 1：

输入：
["KthLargest", "add", "add", "add", "add", "add"]
[[3, [4, 5, 8, 2]], [3], [5], [10], [9], [4]]
输出：[null, 4, 5, 5, 8, 8]
解释：
KthLargest kthLargest = new KthLargest(3, [4, 5, 8, 2]);
kthLargest.add(3);   // 返回 4
kthLargest.add(5);   // 返回 5
kthLargest.add(10);  // 返回 5
kthLargest.add(9);   // 返回 8
kthLargest.add(4);   // 返回 8

示例 2：

输入：
["KthLargest", "add", "add", "add", "add"]
[[4, [7, 7, 7, 7, 8, 3]], [2], [10], [9], [9]]
输出：[null, 7, 7, 7, 8]
解释：
KthLargest kthLargest = new KthLargest(4, [7, 7, 7, 7, 8, 3]);
kthLargest.add(2);   // 返回 7
kthLargest.add(10);  // 返回 7
kthLargest.add(9);   // 返回 7
kthLargest.add(9);   // 返回 8

提示：

  • 0 <= nums.length <= 10⁴
  • 1 <= k <= nums.length + 1
  • -10⁴ <= nums[i] <= 10⁴
  • -10⁴ <= val <= 10⁴
  • 最多调用 add 方法 10⁴ 次

核心不变量

小顶堆里始终只保存"当前最大的 k 个数"，堆顶就是这 k 个数里最小的，也就是第 k 大。

完整推导

思路推导

  1. 直觉（只要前 k 大，别的都可丢）

第 k 大只与"最大的 k 个数"有关。比它们更小的元素永远不可能成为第 k 大，所以可以毫不犹豫地淘汰。用一个大小为 k 的小顶堆，堆顶天然就是这 k 个候选里最小的，即第 k 大。

  1. 初始化（把 nums 灌进堆并裁剪）

逐个 offer 进堆；一旦堆大小超过 k，就 poll 弹出堆顶（当前最小值）。扫完后堆里正好是最大的 k 个数。

  1. add（插入 + 裁剪 + 读堆顶）

新值 offer 进去，若堆大小超过 k 就弹掉堆顶，最后 peek() 就是答案。

  1. 小例子（k=3，流 [4,5,8,2]）

灌入后保留最大 3 个 {4,5,8}，堆顶 4。add(3)：堆变 {3,4,5,8} 超 k，弹 3，堆顶 4，返回 4；add(10)：弹 4，堆 {5,8,10}，返回 5。与示例一致。

Java 实现（KthLargest）

import java.util.PriorityQueue;

class KthLargest {
    private final int k;
    // 小顶堆：堆顶是当前 k 个候选里最小的，即第 k 大
    private final PriorityQueue<Integer> minHeap;

    public KthLargest(int k, int[] nums) {
        this.k = k;
        this.minHeap = new PriorityQueue<>();
        for (int x : nums) {
            minHeap.offer(x);
            // 超过 k 个就把最小值淘汰
            if (minHeap.size() > k) {
                minHeap.poll();
            }
        }
    }

    public int add(int val) {
        minHeap.offer(val);
        if (minHeap.size() > k) {
            minHeap.poll();
        }
        // 堆顶即第 k 大
        return minHeap.peek();
    }
}

复杂度

  • 时间：初始化对 n 个元素各做一次 O(log k) 的插入/删除，共 O(n log k)；每次 add 为 O(log k)。
  • 空间：O(k)，堆中最多保存 k 个元素。

易错点与扩展（面试高频考点）

  1. 大顶堆 vs 小顶堆：求"第 k 大"要用小顶堆；若建大顶堆则无法在 O(1) 拿到第 k 大，会退化。
  2. 初始化也要裁剪：构造后若 nums.length > k 必须保证堆大小为 k，否则 peek 出的不是第 k 大。
  3. k 可能大于初始元素个数：如 k = nums.length + 1，初始堆不足 k 个，add 后才会补满，此时堆顶仍是正确结果（题目保证数据合法）。
  4. 重复元素：第 k 大按"排序后位置"计，重复值各算一个，小顶堆天然支持，不需要去重。
  5. 扩展：若求"第 k 小"则改用大顶堆；若数据流无限且需要中位数，可用"对顶堆"（大小堆分别维护一半元素）。

C++ 实现

class KthLargest {
private:
    int k;
    priority_queue<int, vector<int>, greater<int>> minHeap; // 小顶堆
public:
    KthLargest(int k, vector<int>& nums) {
        this->k = k;
        for (int x : nums) {
            minHeap.push(x);
            if ((int)minHeap.size() > k) {
                minHeap.pop();
            }
        }
    }

    int add(int val) {
        minHeap.push(val);
        if ((int)minHeap.size() > k) {
            minHeap.pop();
        }
        return minHeap.top();
    }
};

Python 实现

import heapq

class KthLargest:

    def __init__(self, k: int, nums: list[int]):
        self.k = k
        self.heap = []
        for x in nums:
            heapq.heappush(self.heap, x)
            if len(self.heap) > k:
                heapq.heappop(self.heap)

    def add(self, val: int) -> int:
        heapq.heappush(self.heap, val)
        if len(self.heap) > self.k:
            heapq.heappop(self.heap)
        return self.heap[0]
