题目与约束

我们可以为二叉树 T 定义一个 翻转操作 ，如下所示：选择任意节点，然后交换它的左子树和右子树。

只要经过一定次数的翻转操作后，能使 X 等于 Y，我们就称二叉树 X 翻转 等价 于二叉树 Y。

这些树由根节点 root1 和 root2 给出。如果两个二叉树是翻转 等价 的树，则返回 true ，否则返回 false 。

示例 1：

<strong>输入：</strong>root1 = [1,2,3,4,5,6,null,null,null,7,8], root2 = [1,3,2,null,6,4,5,null,null,null,null,8,7]
<strong>输出：</strong>true
<strong>解释：</strong>我们翻转值为 1，3 以及 5 的三个节点。

示例 2:

<strong>输入:</strong> root1 = [], root2 = []
<strong>输出:</strong> true

示例 3:

<strong>输入:</strong> root1 = [], root2 = [1]
<strong>输出:</strong> false

提示：

  • 每棵树节点数在 [0, 100] 范围内

  • 每棵树中的每个值都是唯一的、在 [0, 99] 范围内的整数

核心不变量

两棵子树翻转等价，当且仅当根值相同，且它们的子树「不交换」或「左右交换」两种配对方式中有一种完全等价。

完整推导

思路推导

  1. 先对齐根：两棵树翻转等价的前提是根节点值相同。若两个根都为空 → 等价；只有一个为空 → 不等价；值不同 → 不等价。这些是递归的终止条件。

  2. 分两种配对方式递归：根对齐后，左右子树有两种可能的对应： - 不翻转：root1.left 对 root2.left，root1.right 对 root2.right； - 翻转：root1.left 对 root2.right，root1.right 对 root2.left。 只要任意一种配对方式「双方都等价」，整棵树就等价。

  3. 递归结构即答案：把上面两类分别用递归调用表示，返回二者的「或」。由于翻转操作可以在每个节点独立选择，这恰好覆盖了所有可能的翻转组合。

  4. 小例子：root1 = [1,2,3]，root2 = [1,3,2]。根都是 1；不翻转配对为 (2,3) 与 (3,2) 不等价，但翻转配对 root1.left(2) 对 root2.right(2)、root1.right(3) 对 root2.left(3) 都与空子树等价，于是返回 true——正是翻转根节点得到的结果。

Java 实现（递归同步比较）

/**
 * Definition for a binary tree node.
 * public class TreeNode {
 *     int val;
 *     TreeNode left;
 *     TreeNode right;
 *     TreeNode() {}
 *     TreeNode(int val) { this.val = val; }
 *     TreeNode(int val, TreeNode left, TreeNode right) {
 *         this.val = val;
 *         this.left = left;
 *         this.right = right;
 *     }
 * }
 */
class Solution {
    public boolean flipEquiv(TreeNode root1, TreeNode root2) {
        // 终止条件：结构对齐
        if (root1 == null && root2 == null) return true;
        if (root1 == null || root2 == null) return false;
        if (root1.val != root2.val) return false;

        // 情况一：不交换左右子树
        boolean noFlip = flipEquiv(root1.left, root2.left)
                      && flipEquiv(root1.right, root2.right);
        // 情况二：交换左右子树后再比较
        boolean flip = flipEquiv(root1.left, root2.right)
                    && flipEquiv(root1.right, root2.left);

        return noFlip || flip;
    }
}

复杂度

  • 时间：O(n)，每个节点对最多被访问常数次（n 为较小树的节点数），递归在结构不匹配时立即剪枝。
  • 空间：O(h)，递归栈深度等于树高，最坏（链状）为 O(n)。

易错点与扩展（面试高频考点）

  1. 空树判断必须写全两种情况：(null, null) 返回 true，(null, 非null) 或 (非null, null) 返回 false。漏掉任一条都会空指针或误判。

  2. 值不同要立刻返回 false：翻转只改变左右位置、不改变节点值，所以根值不同必然不等价，先剪枝能显著提速。

  3. 两种配对的「与/或」组合不能写错：每种配对内部是「与」（左右都要等价），两种配对之间是「或」（满足其一即可）。

  4. 不要真的去物理翻转再比较：直接带「是否交换」两种可能递归比较即可，物理翻转再逐点比对既浪费又易错。

  5. 扩展：若允许节点值重复，则需在值相同的前提下继续递归，不能假设值唯一；本题虽保证唯一，但写法上已不依赖唯一性，鲁棒性更好。

力扣原题

951. 翻转等价二叉树

C++ 实现

/**
 * Definition for a binary tree node.
 * struct TreeNode {
 *     int val;
 *     TreeNode *left;
 *     TreeNode *right;
 *     TreeNode() : val(0), left(nullptr), right(nullptr) {}
 *     TreeNode(int x) : val(x), left(nullptr), right(nullptr) {}
 *     TreeNode(int x, TreeNode *left, TreeNode *right) : val(x), left(left), right(right) {}
 * };
 */
class Solution {
public:
    bool flipEquiv(TreeNode* root1, TreeNode* root2) {
        if (!root1 && !root2) return true;
        if (!root1 || !root2) return false;
        if (root1->val != root2->val) return false;

        bool noFlip = flipEquiv(root1->left, root2->left)
                   && flipEquiv(root1->right, root2->right);
        bool flip = flipEquiv(root1->left, root2->right)
                 && flipEquiv(root1->right, root2->left);
        return noFlip || flip;
    }
};

Python 实现

# Definition for a binary tree node.
# class TreeNode:
#     def __init__(self, val=0, left=None, right=None):
#         self.val = val
#         self.left = left
#         self.right = right
from typing import Optional

class Solution:
    def flipEquiv(self, root1: Optional[TreeNode], root2: Optional[TreeNode]) -> bool:
        if not root1 and not root2:
            return True
        if not root1 or not root2:
            return False
        if root1.val != root2.val:
            return False

        no_flip = (self.flipEquiv(root1.left, root2.left)
                   and self.flipEquiv(root1.right, root2.right))
        flip = (self.flipEquiv(root1.left, root2.right)
                and self.flipEquiv(root1.right, root2.left))
        return no_flip or flip
