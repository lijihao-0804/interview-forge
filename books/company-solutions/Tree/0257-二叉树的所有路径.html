题目与约束

给你一个二叉树的根节点 root。按任意顺序，返回所有从根节点到叶子节点的路径。

叶子节点 是指没有子节点的节点。

示例 1：

输入：root = [1,2,3,null,5]
输出：["1->2->5","1->3"]

示例 2：

输入：root = [1]
输出：["1"]

提示：

  • 树中节点的数目在范围 [1, 100] 内
  • -100 <= Node.val <= 100

核心不变量

递归进入节点时把当前值加入路径，到达叶子时把整条路径收进答案，回溯返回时再把这个值从路径中移除，保证兄弟分支看到的路径是干净的。

完整推导

思路推导

  1. 直觉：边遍历边记录路径

这是典型的 DFS/回溯题。从根出发一路向下，把沿途经过的节点值收集起来，到叶子时就把这一段路径输出。

  1. 递归设计

定义 dfs(node, path)：先把 node.val 追加到 path；若 node 是叶子（左右均空），就把 path 拼成 "a->b->c" 存进结果；否则继续递归左右孩子。

  1. 回溯的细节

递归返回父节点前，要把当前节点从 path 末尾弹出，否则进入兄弟分支时路径里会残留上一个分支的节点。这个"加入 → 递归 → 撤销"就是标准回溯三件套。

  1. 小例子

root = [1,2,3,null,5]：走到 1→2→5 是叶子，得到 "1->2->5"；回到根走右孩子 1→3 是叶子，得到 "1->3"。

Java 实现（DFS 回溯）

import java.util.ArrayList;
import java.util.List;

/**
 * Definition for a binary tree node.
 * public class TreeNode {
 *     int val;
 *     TreeNode left;
 *     TreeNode right;
 *     TreeNode() {}
 *     TreeNode(int val) { this.val = val; }
 *     TreeNode(int val, TreeNode left, TreeNode right) {
 *         this.val = val;
 *         this.left = left;
 *         this.right = right;
 *     }
 * }
 */
class Solution {
    public List<String> binaryTreePaths(TreeNode root) {
        List<String> res = new ArrayList<>();
        if (root == null) return res;
        dfs(root, new ArrayList<>(), res);
        return res;
    }

    private void dfs(TreeNode node, List<Integer> path, List<String> res) {
        path.add(node.val); // 加入当前节点

        if (node.left == null && node.right == null) {
            // 到达叶子：把路径拼成 "a->b->c"
            StringBuilder sb = new StringBuilder();
            for (int i = 0; i < path.size(); i++) {
                if (i > 0) sb.append("->");
                sb.append(path.get(i));
            }
            res.add(sb.toString());
        } else {
            if (node.left != null) dfs(node.left, path, res);
            if (node.right != null) dfs(node.right, path, res);
        }

        path.remove(path.size() - 1); // 回溯：撤销当前节点
    }
}

复杂度

  • 时间：O(n²)。每个节点只访问一次，但每条路径都要拼接成字符串，所有路径字符串的总长度最坏可达 O(n²)（如"梳状"树，叶子深度之和为 O(n²)）。
  • 空间：O(n)。除答案本身外，递归栈深度最大为 O(n)，回溯用的 path 长度也不超过树高。

易错点与扩展（面试高频考点）

  1. 叶子判定错误：叶子必须是"左右子都为空"；只有单边为空（如只有左孩子）的节点不是叶子，要继续往下走。
  2. 忘记回溯：不执行 path.remove(...) 会导致路径串层，出现 "1->2->3" 这类错误。
  3. 字符串拼接效率：用 StringBuilder/join 一次性拼接，避免在递归里反复 + 产生大量临时对象。
  4. 空树：根为空时直接返回空列表，dfs 不要对 null 取 val。
  5. 扩展——返回 List<List<Integer>>：若题目要的是节点值列表而非字符串，只需在叶子处 res.add(new ArrayList<>(path)) 做一次拷贝即可。

C++ 实现

#include <string>
#include <vector>
using namespace std;

/**
 * Definition for a binary tree node.
 * struct TreeNode {
 *     int val;
 *     TreeNode *left;
 *     TreeNode *right;
 *     TreeNode() : val(0), left(nullptr), right(nullptr) {}
 *     TreeNode(int x) : val(x), left(nullptr), right(nullptr) {}
 *     TreeNode(int x, TreeNode *left, TreeNode *right) : val(x), left(left), right(right) {}
 * };
 */
class Solution {
public:
    vector<string> binaryTreePaths(TreeNode* root) {
        vector<string> res;
        vector<int> path;
        if (root) dfs(root, path, res);
        return res;
    }

private:
    void dfs(TreeNode* node, vector<int>& path, vector<string>& res) {
        path.push_back(node->val);
        if (!node->left && !node->right) {
            string s;
            for (size_t i = 0; i < path.size(); ++i) {
                if (i) s += "->";
                s += to_string(path[i]);
            }
            res.push_back(s);
        } else {
            if (node->left) dfs(node->left, path, res);
            if (node->right) dfs(node->right, path, res);
        }
        path.pop_back(); // 回溯
    }
};

Python 实现

from typing import List, Optional

# Definition for a binary tree node.
# class TreeNode:
#     def __init__(self, val=0, left=None, right=None):
#         self.val = val
#         self.left = left
#         self.right = right
class Solution:
    def binaryTreePaths(self, root: Optional[TreeNode]) -> List[str]:
        res = []

        def dfs(node, path):
            path.append(str(node.val))
            if not node.left and not node.right:
                res.append("->".join(path))
            else:
                if node.left:
                    dfs(node.left, path)
                if node.right:
                    dfs(node.right, path)
            path.pop()  # 回溯

        if root:
            dfs(root, [])
        return res
