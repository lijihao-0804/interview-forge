# 129. 求根节点到叶节点数字之和

| 题目信息 | 内容 |
|---|---|
| 难度 | 中等 |
| 核心模式 | 二叉树 DFS，边递归边累加路径数字 |
| 时间复杂度 | O(n) |
| 空间复杂度 | O(h) |

## 题目与约束

给你一个二叉树的根节点 `root`，树中每个节点都存放有一个 `0` 到 `9` 之间的数字。

每条从根节点到叶节点的路径都代表一个数字：

- 例如，从根节点到叶节点的路径 `1 -> 2 -> 3` 表示数字 `123`。

计算从根节点到叶节点生成的**所有数字之和**。

**叶节点**是指没有子节点的节点。

**示例 1：**

```
输入：root = [1,2,3]
输出：25
解释：
从根到叶子节点路径 1->2 代表数字 12
从根到叶子节点路径 1->3 代表数字 13
因此，数字总和 = 12 + 13 = 25
```

**示例 2：**

```
输入：root = [4,9,0,5,1]
输出：1026
解释：
从根到叶子节点路径 4->9->5 代表数字 495
从根到叶子节点路径 4->9->1 代表数字 491
从根到叶子节点路径 4->0 代表数字 40
因此，数字总和 = 495 + 491 + 40 = 1026
```

**提示：**

- 树中节点的数目在范围 `[1, 1000]` 内
- `0 <= Node.val <= 9`
- 树的深度不超过 `10`

## 核心不变量

> 递归到某个节点时，传入的 `cur` 恰好是「从根到它父节点」组成的数字；到叶节点时 `cur*10 + val` 就是这条完整路径所代表的数。

## 完整推导

### 思路推导

1. **路径数字的递推关系**

   一条路径每往下走一层，相当于在已有数字末尾接上新的一位：`新数字 = 旧数字 * 10 + 节点值`。比如 `1 -> 2`：`1*10+2 = 12`；再往下 `-> 3`：`12*10+3 = 123`。

2. **DFS 携带「前缀数字」下行**

   定义 `dfs(node, cur)`：`cur` 表示到达 `node` 之前已经累积的数字。进入节点先更新 `cur = cur*10 + node.val`。若它是叶子，就把 `cur` 返回；否则把左右子树的返回值相加。

3. **小例子（示例 1）**

   - 从根 `1` 出发，`cur = 1`；
   - 走左 `2`，`cur = 12`，是叶子，贡献 `12`；
   - 走右 `3`，`cur = 13`，是叶子，贡献 `13`；
   - 合计 `25`。

4. **为什么不用显式存路径**

   数字的累积是「一次性可加」的，`cur` 按值传递即可，无需保存整条路径列表，递归返回时天然回溯。

### Java 实现（sumNumbers）

```java
/**
 * Definition for a binary tree node.
 * public class TreeNode {
 *     int val;
 *     TreeNode left;
 *     TreeNode right;
 *     TreeNode() {}
 *     TreeNode(int val) { this.val = val; }
 *     TreeNode(int val, TreeNode left, TreeNode right) {
 *         this.val = val;
 *         this.left = left;
 *         this.right = right;
 *     }
 * }
 */
class Solution {
    public int sumNumbers(TreeNode root) {
        return dfs(root, 0);
    }

    // cur：到达 node 之前已累积的数字
    private int dfs(TreeNode node, int cur) {
        if (node == null) {
            return 0;
        }
        cur = cur * 10 + node.val; // 把当前位接到末尾
        // 叶子节点：这条路径到此结束，返回完整数字
        if (node.left == null && node.right == null) {
            return cur;
        }
        // 非叶子：累加左右子树的贡献
        return dfs(node.left, cur) + dfs(node.right, cur);
    }
}
```

### 复杂度

- 时间：O(n)，每个节点恰好访问一次。
- 空间：O(h)，递归栈深度等于树高；最坏（链状树）为 O(n)，平衡树为 O(log n)。

### 易错点与扩展（面试高频考点）

1. **空节点返回 0，而不是返回 `cur`**：只有真正的叶节点才结算数字，空指针只是递归的结束条件，不能把累积值重复计入。
2. **叶节点判定**：必须同时判断 `left == null && right == null`；只有一个孩子时不能提前结算。
3. **按值传递 `cur`**：不要把 `cur` 写成成员变量再回退，按值传递最省心；若用成员变量，递归回溯时要手动还原。
4. **数据范围与溢出**：本题深度 ≤ 10、结果在 `int` 范围内；若深度更大应改用 `long`。
5. **BFS 替代方案**：也可用队列存 `(节点, 当前数字)` 做层序遍历，遇到叶子累加，与 DFS 等价，只是空间变为 O(宽度)。

## 力扣原题

[129. 求根节点到叶节点数字之和](https://leetcode.cn/problems/sum-root-to-leaf-numbers/)

### C++ 实现

```cpp
/**
 * Definition for a binary tree node.
 * struct TreeNode {
 *     int val;
 *     TreeNode *left;
 *     TreeNode *right;
 *     TreeNode() : val(0), left(nullptr), right(nullptr) {}
 *     TreeNode(int x) : val(x), left(nullptr), right(nullptr) {}
 *     TreeNode(int x, TreeNode *left, TreeNode *right) : val(x), left(left), right(right) {}
 * };
 */
class Solution {
public:
    int sumNumbers(TreeNode* root) {
        return dfs(root, 0);
    }
private:
    int dfs(TreeNode* node, int cur) {
        if (!node) return 0;
        cur = cur * 10 + node->val;
        if (!node->left && !node->right) return cur;
        return dfs(node->left, cur) + dfs(node->right, cur);
    }
};
```

### Python 实现

```python
# Definition for a binary tree node.
# class TreeNode:
#     def __init__(self, val=0, left=None, right=None):
#         self.val = val
#         self.left = left
#         self.right = right
class Solution:
    def sumNumbers(self, root: Optional[TreeNode]) -> int:
        def dfs(node, cur):
            if not node:
                return 0
            cur = cur * 10 + node.val
            if not node.left and not node.right:
                return cur
            return dfs(node.left, cur) + dfs(node.right, cur)

        return dfs(root, 0)
```
