# 110. 平衡二叉树

| 题目信息 | 内容 |
|---|---|
| 难度 | 简单 |
| 核心模式 | 后序 DFS 自底向上求高度 |
| 时间复杂度 | O(n) |
| 空间复杂度 | O(h) |

## 题目与约束

给定一个二叉树，判断它是否是 **平衡二叉树**。

本题中，一棵平衡二叉树定义为：一个二叉树**每个节点**的左右两个子树的高度差的绝对值不超过 1。

**示例 1：**

```
输入：root = [3,9,20,null,null,15,7]
输出：true
```

**示例 2：**

```
输入：root = [1,2,2,3,3,null,null,4,4]
输出：false
```

**示例 3：**

```
输入：root = []
输出：true
```

**提示：**

- 树中的节点数在范围 `[0, 5000]` 内
- `-10^4 <= Node.val <= 10^4`

## 核心不变量

> 一棵树平衡 ⟺ 左右子树都平衡，且左右子树高度差不超过 1；把“高度”和“是否平衡”合并成一次后序遍历，用 `-1` 表示不平衡即可。

## 完整推导

### 思路推导

1. **直觉与痛点（自顶向下会重复算）**

   最直接的想法：对每个节点分别求左右子树高度 `height(left)`、`height(right)`，判断差值是否 ≤ 1。但求高度本身要遍历子树，而每个节点都被反复求高度，复杂度退化到 `O(n²)`，链状树会超时。

2. **破局思路（后序遍历，一次带出两个信息）**

   由于判断某节点是否平衡依赖它的左右子树结果，天然适合**后序 DFS**：先递归拿到左子树、右子树的高度，再判断当前节点差值。为了让一次遍历同时得到“高度”和“是否平衡”，约定：函数返回该子树的高度；若发现不平衡就返回 `-1` 作为哨兵。

   - 左右任一子树返回 `-1` → 当前子树直接返回 `-1`；
   - 否则若 `|leftH - rightH| > 1` → 返回 `-1`；
   - 否则返回 `max(leftH, rightH) + 1`。

   最终整棵树返回非 `-1` 即为平衡。

3. **关键追问（为什么能剪枝？）**

   一旦某棵子树不平衡，它上面的所有祖先都不可能平衡（平衡要求“每个节点”都满足），所以 `-1` 会一路向上传播，无需再比较高度，等于提前剪枝。这就是能把 `O(n²)` 降到 `O(n)` 的原因。

### Java 实现（isBalanced）

```java
/**
 * Definition for a binary tree node.
 * public class TreeNode {
 *     int val;
 *     TreeNode left;
 *     TreeNode right;
 *     TreeNode() {}
 *     TreeNode(int val) { this.val = val; }
 *     TreeNode(int val, TreeNode left, TreeNode right) {
 *         this.val = val;
 *         this.left = left;
 *         this.right = right;
 *     }
 * }
 */
class Solution {
    public boolean isBalanced(TreeNode root) {
        return height(root) != -1;
    }

    // 返回以 node 为根的子树高度；若该子树不平衡则返回 -1
    private int height(TreeNode node) {
        if (node == null) {
            return 0;
        }
        int left = height(node.left);
        if (left == -1) {
            return -1; // 左子树已不平衡，直接剪枝
        }
        int right = height(node.right);
        if (right == -1) {
            return -1; // 右子树已不平衡
        }
        if (Math.abs(left - right) > 1) {
            return -1; // 当前节点高度差超标
        }
        return Math.max(left, right) + 1;
    }
}
```

### 复杂度

- 时间：`O(n)`，每个节点只被访问一次，高度信息自底向上一次算出。
- 空间：`O(h)`，递归栈深度等于树高 `h`；最坏（链状）为 `O(n)`。

### 易错点与扩展（面试高频考点）

1. **写成自顶向下 `O(n²)`**：对每个节点都调用一次求高度，重复遍历；面试应直接给出后序一次遍历的解法。
2. **`-1` 哨兵不向上传播**：拿到 `left == -1` 或 `right == -1` 要立即返回 `-1`，否则会对非法高度继续做算术。
3. **空树默认平衡**：`height(null) = 0`，`isBalanced(null)` 返回 `true`，符合题意。
4. **“平衡”定义别记错**：是**每个节点**左右子树高度差 ≤ 1，不是只看根节点。
5. **扩展**：若要返回“最少删除多少个节点使其平衡”或构造平衡树，思路仍是后序遍历配合高度，只是返回值从哨兵改为携带更多信息。

### C++ 实现

```cpp
#include <algorithm>
#include <cstdlib>
using namespace std;

/**
 * Definition for a binary tree node.
 * struct TreeNode {
 *     int val;
 *     TreeNode *left;
 *     TreeNode *right;
 *     TreeNode() : val(0), left(nullptr), right(nullptr) {}
 *     TreeNode(int x) : val(x), left(nullptr), right(nullptr) {}
 *     TreeNode(int x, TreeNode *left, TreeNode *right) : val(x), left(left), right(right) {}
 * };
 */
class Solution {
public:
    bool isBalanced(TreeNode* root) {
        return height(root) != -1;
    }

private:
    // 返回子树高度；不平衡返回 -1
    int height(TreeNode* node) {
        if (node == nullptr) return 0;
        int left = height(node->left);
        if (left == -1) return -1;
        int right = height(node->right);
        if (right == -1) return -1;
        if (abs(left - right) > 1) return -1;
        return max(left, right) + 1;
    }
};
```

### Python 实现

```python
from typing import Optional

# Definition for a binary tree node.
# class TreeNode:
#     def __init__(self, val=0, left=None, right=None):
#         self.val = val
#         self.left = left
#         self.right = right

class Solution:
    def isBalanced(self, root: Optional[TreeNode]) -> bool:
        def height(node: Optional[TreeNode]) -> int:
            if not node:
                return 0
            left = height(node.left)
            if left == -1:
                return -1
            right = height(node.right)
            if right == -1:
                return -1
            if abs(left - right) > 1:
                return -1
            return max(left, right) + 1

        return height(root) != -1
```
