题目与约束

给定一个单链表的头节点 head，其中的元素 按升序排序，将其转换为高度平衡的二叉搜索树。

高度平衡二叉树是指一个二叉树每个节点的左右两个子树的高度差的绝对值不超过 1。

示例 1：

输入: head = [-10,-3,0,5,9]
输出: [0,-3,9,-10,null,5]
解释: 一个可能的答案是 [0,-3,9,-10,null,5]，它表示所示的高度平衡的二叉搜索树。

示例 2：

输入: head = []
输出: []

提示：

  • head 中的节点数在 [0, 2 × 10^4] 范围内
  • -10^5 <= Node.val <= 10^5

核心不变量

升序链表的中点就是 BST 的根；中点左边的元素全小于它、构成左子树，右边全大于它、构成右子树，递归后天然满足 BST 性质且高度平衡。

完整推导

思路推导

  1. 直觉与痛点（为什么要取中点？）

BST 的中序遍历是升序，所以升序链表本身就可以看作某棵 BST 的中序序列。而要让树高度平衡，最自然的做法是让左右子树节点数尽量相等——于是根应该取序列中点。若取端点，树会退化成一条链。

  1. 破局思路（快慢指针找中点，切两半递归）

在链表上用快慢指针：慢指针每次走一步、快指针每次走两步。当快指针到达末尾时，慢指针正好落在中点。记录中点的前驱 prev，把 prev.next 断开，左半段是 [head, prev]，右半段是 [mid.next, end]。

以 mid 为根，左子树由左半段递归构造，右子树由右半段递归构造，天然满足左 < 根 < 右且高度平衡。

  1. 关键追问（边界与终止条件）
  • 链表为空 → 返回 null；
  • 只剩一个节点 → 直接返回该节点（否则找不到中点前驱会导致空指针）。

小例子：[-10,-3,0,5,9]，中点 0 作根，左段 [-10,-3] 的中点 -3 作左孩子，右段 [5,9] 的中点 9 作右孩子，继续递归即得 [0,-3,9,-10,null,5]。

Java 实现（sortedListToBST）

/**
 * Definition for singly-linked list.
 * public class ListNode {
 *     int val;
 *     ListNode next;
 *     ListNode() {}
 *     ListNode(int val) { this.val = val; }
 *     ListNode(int val, ListNode next) { this.val = val; this.next = next; }
 * }
 */
/**
 * Definition for a binary tree node.
 * public class TreeNode {
 *     int val;
 *     TreeNode left;
 *     TreeNode right;
 *     TreeNode() {}
 *     TreeNode(int val) { this.val = val; }
 *     TreeNode(int val, TreeNode left, TreeNode right) {
 *         this.val = val;
 *         this.left = left;
 *         this.right = right;
 *     }
 * }
 */
class Solution {
    public TreeNode sortedListToBST(ListNode head) {
        if (head == null) {
            return null;
        }
        if (head.next == null) {
            return new TreeNode(head.val); // 单节点直接作为叶子
        }

        // 快慢指针找中点，prev 记录中点的前驱
        ListNode slow = head, fast = head, prev = null;
        while (fast != null && fast.next != null) {
            prev = slow;
            slow = slow.next;
            fast = fast.next.next;
        }

        // 断开左半段，slow 即中点（根）
        prev.next = null;
        TreeNode root = new TreeNode(slow.val);
        root.left = sortedListToBST(head);        // 左半段
        root.right = sortedListToBST(slow.next);  // 右半段
        return root;
    }
}

复杂度

  • 时间：O(n log n)，每层递归共扫描约 O(n) 个节点找中点，平衡树下共 O(log n) 层。
  • 空间：O(log n)，递归栈深度等于平衡树高度。

易错点与扩展（面试高频考点）

  1. 忘记录 prev 断链：不断开左半段会让递归区间无法收缩，陷入死循环。
  2. 单节点未提前返回：只剩一个节点时 prev 会是 null，直接 prev.next = null 抛空指针。
  3. 快慢指针终止条件：while (fast != null && fast.next != null) 保证慢指针落在中点；写成 fast.next.next 前必须判 fast.next。
  4. 进阶 O(n) 解法：先用中序遍历按序消费链表、边遍历边建树——递归左子树时链表的当前节点恰好是根，可把时间从 O(n log n) 降到 O(n)（代价是需要模拟中序顺序，实现更绕）。面试可主动提。
  5. 对比“有序数组转 BST”：数组可直接下标取中点 O(1)，而链表取中点是 O(n)，这正是复杂度差异的根源。

力扣原题

109. 有序链表转换二叉搜索树

C++ 实现

/**
 * Definition for singly-linked list.
 * struct ListNode {
 *     int val;
 *     ListNode *next;
 *     ListNode() : val(0), next(nullptr) {}
 *     ListNode(int x) : val(x), next(nullptr) {}
 *     ListNode(int x, ListNode *next) : val(x), next(next) {}
 * };
 */
/**
 * Definition for a binary tree node.
 * struct TreeNode {
 *     int val;
 *     TreeNode *left;
 *     TreeNode *right;
 *     TreeNode() : val(0), left(nullptr), right(nullptr) {}
 *     TreeNode(int x) : val(x), left(nullptr), right(nullptr) {}
 *     TreeNode(int x, TreeNode *left, TreeNode *right) : val(x), left(left), right(right) {}
 * };
 */
class Solution {
public:
    TreeNode* sortedListToBST(ListNode* head) {
        if (head == nullptr) return nullptr;
        if (head->next == nullptr) return new TreeNode(head->val);

        // 快慢指针找中点，prev 为中点前驱
        ListNode* slow = head;
        ListNode* fast = head;
        ListNode* prev = nullptr;
        while (fast != nullptr && fast->next != nullptr) {
            prev = slow;
            slow = slow->next;
            fast = fast->next->next;
        }

        prev->next = nullptr; // 断开左半段
        TreeNode* root = new TreeNode(slow->val);
        root->left = sortedListToBST(head);
        root->right = sortedListToBST(slow->next);
        return root;
    }
};

Python 实现

from typing import Optional

# Definition for singly-linked list.
# class ListNode:
#     def __init__(self, val=0, next=None):
#         self.val = val
#         self.next = next
# Definition for a binary tree node.
# class TreeNode:
#     def __init__(self, val=0, left=None, right=None):
#         self.val = val
#         self.left = left
#         self.right = right

class Solution:
    def sortedListToBST(self, head: Optional[ListNode]) -> Optional[TreeNode]:
        if not head:
            return None
        if not head.next:
            return TreeNode(head.val)

        # 快慢指针找中点，prev 记录中点前驱
        slow, fast, prev = head, head, None
        while fast and fast.next:
            prev = slow
            slow = slow.next
            fast = fast.next.next

        prev.next = None  # 断开左半段
        root = TreeNode(slow.val)
        root.left = self.sortedListToBST(head)
        root.right = self.sortedListToBST(slow.next)
        return root
