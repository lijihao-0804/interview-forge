# 362. 敲击计数器

| 题目信息 | 内容 |
|---|---|
| 难度 | 中等 |
| 核心模式 | 队列存时间戳，查询时弹出 300 秒之前的记录 |
| 时间复杂度 | hit O(1)，getHits 均摊 O(1) |
| 空间复杂度 | O(300)，窗口内最多 300 秒的记录 |

## 题目与约束

设计一个敲击计数器（Hit Counter），它可以统计过去 5 分钟内（即过去 300 秒内）收到过的敲击次数。

系统接收一个以秒为粒度的时间戳参数 `timestamp`，并假定对系统的调用是按时间先后顺序进行的（即 `timestamp` 单调递增）。同一秒内可能发生多次敲击。

实现 `HitCounter` 类：

- `HitCounter()`：初始化敲击计数器对象；
- `void hit(int timestamp)`：记录一次发生在 `timestamp`（单位：秒）的敲击。同一时间戳可能发生多次敲击；
- `int getHits(int timestamp)`：返回从 `timestamp` 起过去 5 分钟内（即过去 300 秒内）的敲击次数。

**示例：**

```
输入：
["HitCounter", "hit", "hit", "hit", "getHits", "hit", "getHits", "getHits"]
[[], [1], [2], [3], [4], [300], [300], [301]]
输出：
[null, null, null, null, 3, null, 4, 3]

解释：
HitCounter hitCounter = new HitCounter();
hitCounter.hit(1);       // 时刻 1 收到一次敲击
hitCounter.hit(2);       // 时刻 2 收到一次敲击
hitCounter.hit(3);       // 时刻 3 收到一次敲击
hitCounter.getHits(4);   // 时刻 4 查询，过去 300 秒内有 3 次
hitCounter.hit(300);     // 时刻 300 收到一次敲击
hitCounter.getHits(300); // 时刻 300 查询，返回 4
hitCounter.getHits(301); // 时刻 301 查询，时刻 1 的记录已过期，返回 3
```

**提示：**

- `1 <= timestamp <= 2 * 10^9`
- 所有调用都按时间先后顺序进行（`timestamp` 单调递增）
- `hit` 和 `getHits` 最多被调用 `300` 次

## 核心不变量

> 维护一个按时间递增的队列，窗口为 `(timestamp - 300, timestamp]`；查询时把队首所有 `<= timestamp - 300` 的记录弹出，剩下的队列长度就是答案。

## 完整推导

### 思路推导

1. **窗口边界**：所谓「过去 5 分钟」指与当前 `timestamp` 相差小于 300 秒的记录，即满足 `t > timestamp - 300`（等价 `t >= timestamp - 299`）。因此所有 `t <= timestamp - 300` 的记录都已过期。

2. **为什么用队列？** 因为时间戳单调递增，新记录总比旧记录晚，天然满足先进先出。过期的一定在队首，弹出队首直到遇到未过期为止，剩下的数量就是窗口内的敲击次数。

3. **小例子（hit 1,2,3, getHits(4)）**：队列 `[1,2,3]`，阈值 `4-300 = -296`，无需弹出，返回 `3`。之后 `hit(300)`，队列 `[1,2,3,300]`；`getHits(301)` 阈值 `1`，弹出 `1`（`1 <= 1`），剩 `[2,3,300]`，返回 `3`，与示例一致。

4. **多次同一秒**：队列允许重复时间戳，重复元素各自计数、各自过期，无需合并。

### Java 实现（队列 + 滑动窗口）

```java
import java.util.ArrayDeque;
import java.util.Deque;

class HitCounter {
    private Deque<Integer> hits;   // 按时间递增保存敲击时间戳

    public HitCounter() {
        hits = new ArrayDeque<>();
    }

    public void hit(int timestamp) {
        hits.offerLast(timestamp);
    }

    public int getHits(int timestamp) {
        // 弹出所有已超过 300 秒（含边界）的记录
        while (!hits.isEmpty() && hits.peekFirst() <= timestamp - 300) {
            hits.pollFirst();
        }
        return hits.size();
    }
}
```

### 复杂度

- 时间：`hit` 为 O(1)；`getHits` 中每条记录最多被弹出一次，均摊 O(1)。
- 空间：O(300)。因为时间戳单调递增，窗口内最多保留 300 秒的记录。

### 易错点与扩展（面试高频考点）

1. **过期边界要含等号**：条件是 `t <= timestamp - 300`（即相差达到 300 秒就过期），写成 `<` 会把边界记录多算进去，导致答案偏大。
2. **同一秒多次敲击**：队列直接重复入队即可；若用「每秒一个计数桶」则需对同秒累加而不是覆盖。
3. **单调递增是前提**：题目保证 `timestamp` 单调不减，才能用「弹出队首」的模型；若无序则要考虑哈希桶或有序结构。
4. **扩展：数据量很大时**可改用「循环数组 + 秒级分桶」的经典设计，每 300 秒一个环形桶，`getHits` 时把桶里时间戳不等于当前时间戳的视为过期，做到严格 O(1) 且空间恒定。
5. **别每次查询重扫全部**：只要每次查询弹出已过期部分，剩余数量直接取 `size()`，避免重复遍历。

### C++ 实现

```cpp
#include <queue>

class HitCounter {
    std::queue<int> hits;   // 按时间递增保存敲击时间戳

public:
    HitCounter() {}

    void hit(int timestamp) {
        hits.push(timestamp);
    }

    int getHits(int timestamp) {
        // 弹出所有已超过 300 秒（含边界）的记录
        while (!hits.empty() && hits.front() <= timestamp - 300) {
            hits.pop();
        }
        return (int)hits.size();
    }
};
```

### Python 实现

```python
from collections import deque


class HitCounter:

    def __init__(self):
        self.hits = deque()   # 按时间递增保存敲击时间戳

    def hit(self, timestamp: int) -> None:
        self.hits.append(timestamp)

    def getHits(self, timestamp: int) -> int:
        # 弹出所有已超过 300 秒（含边界）的记录
        while self.hits and self.hits[0] <= timestamp - 300:
            self.hits.popleft()
        return len(self.hits)
```
