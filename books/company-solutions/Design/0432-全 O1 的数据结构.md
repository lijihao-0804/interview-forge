# 432. 全 O(1) 的数据结构

| 题目信息 | 内容 |
|---|---|
| 难度 | Hard |
| 核心模式 | 双向链表按计数分桶 + 哈希表定位，实现 O(1) 增删与最值查询 |
| 时间复杂度 | O(1) （每次操作的平均时间） |
| 空间复杂度 | O(n) |

## 题目与约束

请你设计一个用于存储字符串计数的数据结构，并能够返回计数最小和最大的字符串。

实现 `AllOne` 类：

- `AllOne()` 初始化数据结构的对象。

- `inc(String key)` 字符串 `key` 的计数增加 `1` 。如果数据结构中尚不存在 `key` ，那么插入计数为 `1` 的 `key` 。

- `dec(String key)` 字符串 `key` 的计数减少 `1` 。如果 `key` 的计数在减少后为 `0` ，那么需要将这个 `key` 从数据结构中删除。测试用例保证：在减少计数前，`key` 存在于数据结构中。

- `getMaxKey()` 返回任意一个计数最大的字符串。如果没有元素存在，返回一个空字符串 `""` 。

- `getMinKey()` 返回任意一个计数最小的字符串。如果没有元素存在，返回一个空字符串 `""` 。

注意：每个函数都应当满足 `O(1)` 平均时间复杂度。

 

示例：

```
<strong>输入</strong>
["AllOne", "inc", "inc", "getMaxKey", "getMinKey", "inc", "getMaxKey", "getMinKey"]
[[], ["hello"], ["hello"], [], [], ["leet"], [], []]
<strong>输出</strong>
[null, null, null, "hello", "hello", null, "hello", "leet"]

<strong>解释</strong>
AllOne allOne = new AllOne();
allOne.inc("hello");
allOne.inc("hello");
allOne.getMaxKey(); // 返回 "hello"
allOne.getMinKey(); // 返回 "hello"
allOne.inc("leet");
allOne.getMaxKey(); // 返回 "hello"
allOne.getMinKey(); // 返回 "leet"
```

 

提示：

- `1 <= key.length <= 10`

- `key` 由小写英文字母组成

- 测试用例保证：在每次调用 `dec` 时，数据结构中总存在 `key`

- 最多调用 `inc`、`dec`、`getMaxKey` 和 `getMinKey` 方法 `5 * 104` 次

[🔗 前往力扣原题验证 →](https://leetcode.cn/problems/all-oone-data-structure/)

## 核心不变量

> 双向链表中的每个节点代表一个「计数值」，节点内部存放所有计数恰好等于该值的 key，且链表严格按计数升序排列，因此表头之后是 min、表尾之前是 max。

## 完整推导

### 思路推导

1. **直觉与痛点（为什么普通做法不行）**：如果用一个哈希表记录 `key -> count`，`inc`/`dec` 是 O(1)，但 `getMaxKey`/`getMinKey` 必须遍历整张表，最坏 O(n)，无法满足要求。真正的难点是：如何在不遍历的情况下，随时拿到最小/最大计数？

2. **破局思路（按计数分桶）**：把所有「计数相同」的 key 放进同一个桶里，再把桶按计数从小到大串成一条**双向链表**。这样：
   - `getMinKey` 就是表头之后的第一个桶，
   - `getMaxKey` 就是表尾之前的最后一个桶，
   - 取值只需从桶里随便取一个 key，都是 O(1)。

   例如依次 `inc("a")`、`inc("a")`、`inc("b")`，链表示意：`head -> [1: b] -> [2: a] -> tail`。

3. **关键追问（怎么让 inc/dec 也保持 O(1)）**：每个 key 用哈希表 `map` 直接定位到它所在的桶节点。`inc` 时它的目标计数是 `cur+1`：
   - 若下一个桶的计数正好是 `cur+1`，直接把 key 挪进下一个桶；
   - 否则在当前位置后面新建一个计数为 `cur+1` 的桶再放进去。
   - 最后把 key 从旧桶删掉，旧桶空了就把桶节点从链表摘除。

   `dec` 完全对称，目标计数是 `cur-1`，看向前一个桶即可。由于每步只改动常数个指针和集合操作，均为 O(1) 平均。

### Java 实现（双向链表 + 哈希表分桶）

```java
import java.util.HashMap;
import java.util.HashSet;
import java.util.Map;
import java.util.Set;

class AllOne {

    // 链表节点：代表一个计数桶
    private static class Node {
        int count;                       // 该桶对应的计数
        Set<String> keys = new HashSet<>(); // 计数恰好为 count 的所有 key
        Node prev, next;

        Node(int count) {
            this.count = count;
        }
    }

    private final Node head;             // 升序哨兵头（count = 0）
    private final Node tail;             // 升序哨兵尾（count = 0）
    private final Map<String, Node> map; // key -> 所在的桶节点

    public AllOne() {
        head = new Node(0);
        tail = new Node(0);
        head.next = tail;
        tail.prev = head;
        map = new HashMap<>();
    }

    public void inc(String key) {
        Node node = map.get(key);
        if (node == null) {
            // 全新 key，计数为 1
            if (head.next != tail && head.next.count == 1) {
                head.next.keys.add(key);
                map.put(key, head.next);
            } else {
                Node n = new Node(1);
                n.keys.add(key);
                insertAfter(head, n);
                map.put(key, n);
            }
        } else {
            int target = node.count + 1;
            Node nxt = node.next;
            if (nxt != tail && nxt.count == target) {
                // 目标桶已存在，直接迁移
                nxt.keys.add(key);
                map.put(key, nxt);
            } else {
                // 目标桶不存在，新建并插到当前节点之后
                Node n = new Node(target);
                n.keys.add(key);
                insertAfter(node, n);
                map.put(key, n);
            }
            removeKey(node, key); // 从旧桶移除（空了会自动摘除节点）
        }
    }

    public void dec(String key) {
        Node node = map.get(key);
        if (node.count == 1) {
            // 计数归零，彻底删除
            map.remove(key);
            removeKey(node, key);
        } else {
            int target = node.count - 1;
            Node prv = node.prev;
            if (prv != head && prv.count == target) {
                prv.keys.add(key);
                map.put(key, prv);
            } else {
                Node n = new Node(target);
                n.keys.add(key);
                insertBefore(node, n);
                map.put(key, n);
            }
            removeKey(node, key);
        }
    }

    public String getMaxKey() {
        if (tail.prev == head) {
            return "";
        }
        return tail.prev.keys.iterator().next();
    }

    public String getMinKey() {
        if (head.next == tail) {
            return "";
        }
        return head.next.keys.iterator().next();
    }

    // 把节点 n 插到 base 之后
    private void insertAfter(Node base, Node n) {
        n.prev = base;
        n.next = base.next;
        base.next.prev = n;
        base.next = n;
    }

    // 把节点 n 插到 base 之前
    private void insertBefore(Node base, Node n) {
        insertAfter(base.prev, n);
    }

    // 从桶里删掉一个 key；桶空了就把桶节点从链表摘除
    private void removeKey(Node node, String key) {
        node.keys.remove(key);
        if (node.keys.isEmpty()) {
            node.prev.next = node.next;
            node.next.prev = node.prev;
        }
    }
}
```

### 复杂度

- 时间：O(1)（平均）。每次 `inc`/`dec` 只涉及常数次哈希查找、集合增删和指针改写；`getMaxKey`/`getMinKey` 直接读表尾/表头，无需遍历。因此四个操作都是平均 O(1)。
- 空间：O(n)，n 为不同 key 的数量。每个 key 存一份于哈希表和某个桶集合中；桶的个数不超过 key 的个数。

### 易错点与扩展（面试高频考点）

1. **桶的增删顺序**：`inc` 是「先迁移/新建目标桶，再从旧桶删」，`dec` 是「先迁移/新建，再从旧桶删」。顺序错了（先删旧桶导致节点被回收）会导致悬空指针或空指针。
2. **空桶必须从链表摘除**：否则 `getMaxKey`/`getMinKey` 可能取到空桶，或者在 `inc` 判断 `next.count == target` 时被空桶卡住。摘除空桶是保证「表头就是最小、表尾就是最大」这一步的关键。
3. **`dec` 后计数为 0 的处理**：题目保证 `dec` 前 key 存在，计数变为 0 时必须同时从 `map` 删除并移出桶，不能保留计数 0 的桶。
4. **哨兵节点的作用**：头尾各放一个 dummy 节点，可以省掉大量边界判断（如链表为空、插入到头/尾），代码更稳。
5. **扩展：若要求返回「确定」的 min/max 而非任意一个**，可在桶内改用有序结构或额外维护一个代表 key；也可用「计数 -> 桶」的哈希表替代链表，但那样又难以 O(1) 求最值，链表按序排列正是为了这一步。

### C++ 实现

```cpp
class AllOne {
    struct Node {
        int count;
        std::unordered_set<std::string> keys;
        Node *prev, *next;
        Node(int c) : count(c), prev(nullptr), next(nullptr) {}
    };

    Node *head, *tail;
    std::unordered_map<std::string, Node*> mp;

    void insertAfter(Node* base, Node* n) {
        n->prev = base;
        n->next = base->next;
        base->next->prev = n;
        base->next = n;
    }

    void removeKey(Node* node, const std::string& key) {
        node->keys.erase(key);
        if (node->keys.empty()) {
            node->prev->next = node->next;
            node->next->prev = node->prev;
            delete node;
        }
    }

public:
    AllOne() {
        head = new Node(0);
        tail = new Node(0);
        head->next = tail;
        tail->prev = head;
    }

    void inc(std::string key) {
        auto it = mp.find(key);
        if (it == mp.end()) {
            if (head->next != tail && head->next->count == 1) {
                head->next->keys.insert(key);
                mp[key] = head->next;
            } else {
                Node* n = new Node(1);
                n->keys.insert(key);
                insertAfter(head, n);
                mp[key] = n;
            }
        } else {
            Node* node = it->second;
            int target = node->count + 1;
            Node* nxt = node->next;
            if (nxt != tail && nxt->count == target) {
                nxt->keys.insert(key);
                mp[key] = nxt;
            } else {
                Node* n = new Node(target);
                n->keys.insert(key);
                insertAfter(node, n);
                mp[key] = n;
            }
            removeKey(node, key);
        }
    }

    void dec(std::string key) {
        Node* node = mp[key];
        if (node->count == 1) {
            mp.erase(key);
            removeKey(node, key);
        } else {
            int target = node->count - 1;
            Node* prv = node->prev;
            if (prv != head && prv->count == target) {
                prv->keys.insert(key);
                mp[key] = prv;
            } else {
                Node* n = new Node(target);
                n->keys.insert(key);
                insertAfter(prv, n);
                mp[key] = n;
            }
            removeKey(node, key);
        }
    }

    std::string getMaxKey() {
        if (tail->prev == head) return "";
        return *tail->prev->keys.begin();
    }

    std::string getMinKey() {
        if (head->next == tail) return "";
        return *head->next->keys.begin();
    }
};
```

### Python 实现

```python
class AllOne:
    class Node:
        __slots__ = ("count", "keys", "prev", "next")

        def __init__(self, count):
            self.count = count
            self.keys = set()
            self.prev = None
            self.next = None

    def __init__(self):
        self.head = self.Node(0)
        self.tail = self.Node(0)
        self.head.next = self.tail
        self.tail.prev = self.head
        self.mp = {}

    def _insert_after(self, base, node):
        node.prev = base
        node.next = base.next
        base.next.prev = node
        base.next = node

    def _remove_key(self, node, key):
        node.keys.remove(key)
        if not node.keys:
            node.prev.next = node.next
            node.next.prev = node.prev

    def inc(self, key: str) -> None:
        if key not in self.mp:
            if self.head.next is not self.tail and self.head.next.count == 1:
                self.head.next.keys.add(key)
                self.mp[key] = self.head.next
            else:
                node = self.Node(1)
                node.keys.add(key)
                self._insert_after(self.head, node)
                self.mp[key] = node
        else:
            node = self.mp[key]
            target = node.count + 1
            nxt = node.next
            if nxt is not self.tail and nxt.count == target:
                nxt.keys.add(key)
                self.mp[key] = nxt
            else:
                new = self.Node(target)
                new.keys.add(key)
                self._insert_after(node, new)
                self.mp[key] = new
            self._remove_key(node, key)

    def dec(self, key: str) -> None:
        node = self.mp[key]
        if node.count == 1:
            del self.mp[key]
            self._remove_key(node, key)
        else:
            target = node.count - 1
            prv = node.prev
            if prv is not self.head and prv.count == target:
                prv.keys.add(key)
                self.mp[key] = prv
            else:
                new = self.Node(target)
                new.keys.add(key)
                self._insert_after(prv, new)
                self.mp[key] = new
            self._remove_key(node, key)

    def getMaxKey(self) -> str:
        if self.tail.prev is self.head:
            return ""
        return next(iter(self.tail.prev.keys))

    def getMinKey(self) -> str:
        if self.head.next is self.tail:
            return ""
        return next(iter(self.head.next.keys))
```
