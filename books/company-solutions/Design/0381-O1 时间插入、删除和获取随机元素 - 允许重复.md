# 381. O(1) 时间插入、删除和获取随机元素 - 允许重复

| 题目信息 | 内容 |
|---|---|
| 难度 | 困难 |
| 核心模式 | 动态数组 + 哈希表（值→下标集合），删除时用末尾元素覆盖 |
| 时间复杂度 | O(1)（平均） |
| 空间复杂度 | O(n) |

## 题目与约束

`RandomizedCollection` 是一种包含数字集合（可能是重复的）的数据结构。它应该支持插入和删除特定元素，以及删除随机元素。

实现 `RandomizedCollection` 类：

- `RandomizedCollection()` 初始化空的 `RandomizedCollection` 对象。
- `bool insert(int val)` 将一个 `val` 项插入到集合中，即使该项已经存在。如果该项**不存在**，则返回 `true`，否则返回 `false`。
- `bool remove(int val)` 如果存在，从集合中移除**一个** `val` 项。如果该项存在，则返回 `true`，否则返回 `false`。注意，如果 `val` 在集合中出现多次，我们只删除其中一个。
- `int getRandom()` 从当前的多个元素集合中返回一个随机元素。每个元素被返回的概率与集合中包含的相同值的数量**线性相关**。

你必须实现类的函数，使每个函数的**平均**时间复杂度为 `O(1)`。

**注意：**生成测试用例时，只有在 `RandomizedCollection` 中**至少有一项**时，才会调用 `getRandom`。

**示例 1：**

```
输入
["RandomizedCollection", "insert", "insert", "insert", "getRandom", "remove", "getRandom"]
[[], [1], [1], [2], [], [1], []]
输出
[null, true, false, true, 2, true, 1]

解释
RandomizedCollection collection = new RandomizedCollection(); // 初始化一个空的集合。
collection.insert(1);   // 返回 true，因为集合不包含 1。
                        // 将 1 插入到集合中。
collection.insert(1);   // 返回 false，因为集合包含 1。
                        // 将另一个 1 插入到集合中。集合现在包含 [1,1]。
collection.insert(2);   // 返回 true，因为集合不包含 2。
                        // 将 2 插入到集合中。集合现在包含 [1,1,2]。
collection.getRandom(); // getRandom 应当：
                        // 有 2/3 的概率返回 1，
                        // 1/3 的概率返回 2。
collection.remove(1);   // 返回 true，因为集合包含 1。
                        // 从集合中移除 1。集合现在包含 [1,2]。
collection.getRandom(); // getRandom 应该返回 1 或 2，两者的可能性相同。
```

**提示：**

- `-2^31 <= val <= 2^31 - 1`
- `insert`、`remove` 和 `getRandom` 最多**总共**被调用 `2 * 10^5` 次
- 当调用 `getRandom` 时，数据结构中**至少有一个**元素

## 核心不变量

> 用动态数组保存所有元素（含重复）以保证 `getRandom` 按下标等概率取样；用哈希表记录「每个值 → 它出现过的所有下标集合」。删除时把末尾元素搬到被删位置并同步修正下标，即可在 `O(1)`（平均）内完成。

## 完整推导

### 思路推导

1. **为什么需要「数组 + 哈希」两件套**：要支持 `O(1)` 随机，必须用**数组**——`random.nextInt(size)` 取下标天然等概率，且值出现几次就占几个位置，概率自动「与数量线性相关」。要支持 `O(1)` 判断存在与定位，必须用**哈希表**。单用集合无法随机，单用哈希无法按下标等概率，所以两者缺一不可。

2. **难点在删除**：数组中间删一个元素要 `O(n)` 搬移。标准技巧是**和末尾交换再 `pop`**：把末尾元素填到要删的位置，然后删除末尾。这样数组始终保持紧凑、无空洞。

3. **重复值带来的额外难点**：一个值可能出现多次，所以哈希表的值不能是「一个下标」，而必须是「**下标集合**」。删除 `val` 时，从它的下标集合里随便取一个下标 `i`，把它和末尾交换。

4. **同步修正下标（最容易错的一步）**：把末尾元素 `lastVal` 搬到位置 `i` 后，`lastVal` 的下标集合里要**删掉 `lastIdx`、加上 `i`**。特判：
   - 若 `i == lastIdx`（要删的就是末尾），无需搬运，直接 `pop`；
   - 若 `lastVal == val`（末尾元素和要删的值相同），下标集合是同一个，操作要格外注意顺序。
   最后若 `val` 的下标集合空了，把整个键删掉。

5. **插入的返回值**：先判断「插入前该值是否存在」——不存在才返回 `true`。注意是「是否存在」而不是「插入后被删」，用 `containsKey` 即可。

### Java 实现（数组 + 值→下标集合）

```java
import java.util.ArrayList;
import java.util.HashMap;
import java.util.HashSet;
import java.util.List;
import java.util.Map;
import java.util.Random;
import java.util.Set;

class RandomizedCollection {
    private final List<Integer> nums;                       // 所有元素（含重复）
    private final Map<Integer, Set<Integer>> valToIndices;  // 值 -> 该值出现的下标集合
    private final Random random;

    public RandomizedCollection() {
        nums = new ArrayList<>();
        valToIndices = new HashMap<>();
        random = new Random();
    }

    public boolean insert(int val) {
        // 插入前是否不存在，决定返回值
        boolean absent = !valToIndices.containsKey(val);
        nums.add(val);
        valToIndices.computeIfAbsent(val, x -> new HashSet<>()).add(nums.size() - 1);
        return absent;
    }

    public boolean remove(int val) {
        if (!valToIndices.containsKey(val)) {
            return false;
        }
        Set<Integer> idxSet = valToIndices.get(val);
        // 取出一个待删除下标
        int removeIdx = idxSet.iterator().next();
        idxSet.remove(removeIdx);

        int lastIdx = nums.size() - 1;
        int lastVal = nums.get(lastIdx);

        // 用末尾元素覆盖被删位置，并修正末尾元素的下标记录
        if (removeIdx != lastIdx) {
            nums.set(removeIdx, lastVal);
            Set<Integer> lastSet = valToIndices.get(lastVal);
            lastSet.remove(lastIdx);
            lastSet.add(removeIdx);
        }
        nums.remove(lastIdx);

        // 该值的下标集合空了，删除主键
        if (idxSet.isEmpty()) {
            valToIndices.remove(val);
        }
        return true;
    }

    public int getRandom() {
        // 按下标随机，天然等概率
        return nums.get(random.nextInt(nums.size()));
    }
}
```

### 复杂度

- 时间：**平均 `O(1)`**。`insert` 为数组尾插 + 集合插入；`remove` 为集合取/删一个下标 + 末尾交换，均为平均常数（哈希表与哈希集合的平均复杂度）；`getRandom` 为一次随机下标访问。
- 空间：`O(n)`。数组存 `n` 个元素，哈希表为每个下标存一份记录，总计 `O(n)`。

### 易错点与扩展（面试高频考点）

1. **删除时下标同一性陷阱**：当 `removeIdx == lastIdx` 时不能再去 `nums.set` 和更新 `lastSet`（会越界或误删）；当 `lastVal == val` 时，`idxSet` 与 `lastSet` 是同一个集合，务必先 `idxSet.remove(removeIdx)` 再处理 `lastSet`，顺序错了会导致集合混乱。
2. **哈希表的值必须是「下标集合」**：若只存一个下标，重复元素第二次出现就会覆盖前一个下标，`remove` 时将找不到正确的元素。
3. **`insert` 的返回值语义**：返回的是「插入前是否不存在」，用 `containsKey` 判断；不要误用「集合大小是否变化」。
4. **`getRandom` 的等概率来源**：必须基于「数组下标」随机，而不是基于「不同值」随机，否则重复值的返回概率就不符合「与数量线性相关」。
5. **与 380 题（不允许重复）对照**：380 用 `list + map<val, index>` 即可；本题因为允许重复，`map` 的 value 升级为 `Set<Integer>`，这是两题唯一但关键的区别。

### C++ 实现

```cpp
#include <vector>
#include <unordered_map>
#include <unordered_set>
#include <cstdlib>
using namespace std;

class RandomizedCollection {
    vector<int> nums;                                   // 所有元素（含重复）
    unordered_map<int, unordered_set<int>> valToIndices; // 值 -> 下标集合
public:
    RandomizedCollection() {}

    bool insert(int val) {
        bool absent = valToIndices.find(val) == valToIndices.end();
        nums.push_back(val);
        valToIndices[val].insert((int)nums.size() - 1);
        return absent;
    }

    bool remove(int val) {
        if (valToIndices.find(val) == valToIndices.end()) {
            return false;
        }
        int removeIdx = *valToIndices[val].begin();
        valToIndices[val].erase(removeIdx);

        int lastIdx = (int)nums.size() - 1;
        int lastVal = nums[lastIdx];

        // 末尾元素覆盖被删位置，修正其下标记录
        if (removeIdx != lastIdx) {
            nums[removeIdx] = lastVal;
            valToIndices[lastVal].erase(lastIdx);
            valToIndices[lastVal].insert(removeIdx);
        }
        nums.pop_back();

        if (valToIndices[val].empty()) {
            valToIndices.erase(val);
        }
        return true;
    }

    int getRandom() {
        return nums[rand() % nums.size()];
    }
};
```

### Python 实现

```python
import random


class RandomizedCollection:
    def __init__(self):
        self.nums = []                 # 所有元素（含重复）
        self.val_to_indices = {}       # 值 -> 下标集合

    def insert(self, val: int) -> bool:
        absent = val not in self.val_to_indices
        self.nums.append(val)
        self.val_to_indices.setdefault(val, set()).add(len(self.nums) - 1)
        return absent

    def remove(self, val: int) -> bool:
        if val not in self.val_to_indices:
            return False

        idx_set = self.val_to_indices[val]
        remove_idx = idx_set.pop()

        last_idx = len(self.nums) - 1
        last_val = self.nums[last_idx]

        # 用末尾元素覆盖被删位置，并修正末尾元素的下标记录
        if remove_idx != last_idx:
            self.nums[remove_idx] = last_val
            self.val_to_indices[last_val].discard(last_idx)
            self.val_to_indices[last_val].add(remove_idx)

        self.nums.pop()

        if not idx_set:
            del self.val_to_indices[val]
        return True

    def getRandom(self) -> int:
        return random.choice(self.nums)
```
