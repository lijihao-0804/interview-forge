题目信息 内容
难度 中等
核心模式 树状数组（Fenwick）维护前缀和，支持单点更新与区间查询
时间复杂度 构造 O(n log n)，update / sumRange 均 O(log n)
空间复杂度 O(n)

题目与约束

给你一个数组 nums，请你完成两类查询：

  • 其中一类查询要求更新数组 nums 下标对应的值；
  • 另一类查询要求返回数组 nums 中索引 left 和索引 right 之间（包含）的 nums 元素的和，其中 left <= right。

实现 NumArray 类：

  • NumArray(int[] nums) 用整数数组 nums 初始化对象；
  • void update(int index, int val) 将 nums[index] 的值更新为 val；
  • int sumRange(int left, int right) 返回数组 nums 中索引 left 和索引 right 之间（包含）的 nums 元素的和（即 nums[left] + nums[left + 1], ..., nums[right]）。

示例 1：

输入：
["NumArray", "sumRange", "update", "sumRange"]
[[[1, 3, 5]], [0, 2], [1, 2], [0, 2]]
输出：
[null, 9, null, 8]

解释：
NumArray numArray = new NumArray([1, 3, 5]);
numArray.sumRange(0, 2); // 返回 1 + 3 + 5 = 9
numArray.update(1, 2);   // nums = [1,2,5]
numArray.sumRange(0, 2); // 返回 1 + 2 + 5 = 8

提示：

  • 1 <= nums.length <= 3 * 10^4
  • -100 <= nums[i] <= 100
  • 0 <= index < nums.length
  • -100 <= val <= 100
  • 0 <= left <= right < nums.length
  • 调用 update 和 sumRange 方法次数不大于 3 * 10^4

核心不变量

树状数组中第 i 个元素保存的是“下标区间 (i - lowbit(i), i] 的元素和”，前缀和可通过不断减去 lowbit 累加得到，单点更新则不断加上 lowbit 向上修正。

完整推导

思路推导

  1. 前缀和数组的局限：用普通前缀和能做到 O(1) 查询，但一次更新会牵动后面所有前缀，O(n)。而本题更新和查询次数都可达 3*10^4，全用前缀和是 O(n·q) 会超时。

  2. 引入树状数组：它把“更新 O(log n) + 查询 O(log n)”做到平衡。下标记为 1..n，每个位置 i 管一段长度 lowbit(i) 的区间。

  3. 小例子（[1,3,5]）： - tree = [0,1,4,5]（tree[1]=1，tree[2]=1+3=4，tree[3]=5）。 - 前缀和 prefix(2)：i=3 加 tree[3]=5，i=3-1=2 加 tree[2]=4，得 9。 - update(1, 2)：delta = 2-3 = -1，更新 tree[2] -= 1，nums=[1,2,5]。

  4. 区间和 = 两个前缀和相减：sumRange(l, r) = prefix(r) - prefix(l-1)。

Java 实现（Fenwick 树状数组）

class NumArray {
    private int[] tree;   // 树状数组，下标 1..n
    private int[] nums;   // 原始数组，便于算 delta
    private int n;

    public NumArray(int[] nums) {
        this.n = nums.length;
        this.nums = new int[n];
        this.tree = new int[n + 1];
        for (int i = 0; i < n; i++) {
            update(i, nums[i]);       // 初始化为 0，逐点写入
        }
    }

    public void update(int index, int val) {
        int delta = val - nums[index];
        nums[index] = val;
        for (int i = index + 1; i <= n; i += i & (-i)) {
            tree[i] += delta;         // 沿 lowbit 向上修正
        }
    }

    public int sumRange(int left, int right) {
        return prefix(right) - prefix(left - 1);
    }

    private int prefix(int i) {       // 前 i 个元素（0..i）之和
        int sum = 0;
        for (i = i + 1; i > 0; i -= i & (-i)) {
            sum += tree[i];
        }
        return sum;
    }
}

复杂度

  • 时间：构造时对每个位置调用一次 update，共 O(n log n)；update、sumRange 均为 O(log n)。
  • 空间：O(n)，tree 与 nums 各占 O(n)。

易错点与扩展（面试高频考点）

  1. 下标偏移：树状数组习惯 1-based，代码里 index + 1 别漏，否则 i & (-i) 会算错。
  2. lowbit 的写法：i & (-i) 取最低位的 1，更新向上 +、查询向下 -，方向写反就错。
  3. update 用 delta 而非直接赋值：树状数组存的是增量信息，必须算出 val - nums[index] 再更新，并同步改 nums。
  4. 边界 left - 1 < 0：prefix(-1) 应得 0，代码中 i = -1 + 1 = 0 不进入循环，天然返回 0，需确认实现无越界。
  5. 扩展：也可用线段树（区间更新/查询更通用）或分块（Sqrt Decomposition）实现，复杂度同阶但常数不同。

C++ 实现

class NumArray {
    vector<int> tree, nums;
    int n;

    void add(int index, int delta) {
        for (int i = index + 1; i <= n; i += i & (-i)) {
            tree[i] += delta;
        }
    }

    int prefix(int i) {              // 0..i 的和
        int s = 0;
        for (i = i + 1; i > 0; i -= i & (-i)) {
            s += tree[i];
        }
        return s;
    }

public:
    NumArray(vector<int>& nums) {
        this->nums = nums;
        n = nums.size();
        tree.assign(n + 1, 0);
        for (int i = 0; i < n; i++) add(i, nums[i]);
    }

    void update(int index, int val) {
        int delta = val - nums[index];
        nums[index] = val;
        add(index, delta);
    }

    int sumRange(int left, int right) {
        return prefix(right) - prefix(left - 1);
    }
};

Python 实现

class NumArray:
    def __init__(self, nums):
        self.nums = nums
        self.n = len(nums)
        self.tree = [0] * (self.n + 1)
        for i, v in enumerate(nums):
            self._add(i, v)

    def _add(self, index, delta):
        i = index + 1
        while i <= self.n:
            self.tree[i] += delta
            i += i & (-i)

    def _prefix(self, i):            # 0..i 的和
        s = 0
        i += 1
        while i > 0:
            s += self.tree[i]
            i -= i & (-i)
        return s

    def update(self, index, val):
        self._add(index, val - self.nums[index])
        self.nums[index] = val

    def sumRange(self, left, right):
        return self._prefix(right) - self._prefix(left - 1)
