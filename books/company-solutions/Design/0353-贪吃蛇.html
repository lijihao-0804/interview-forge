题目信息 内容
难度 中等
核心模式 双端队列存蛇身 + 哈希集合做 O(1) 碰撞判定
时间复杂度 每次 move 均为 O(1)
空间复杂度 O(food.length)，即蛇身最大长度

题目与约束

请你设计一个「贪吃蛇」游戏。游戏在一个 height × width 的屏幕上进行，屏幕上的坐标用 (行, 列) 表示，左上角为 (0, 0)。

蛇初始位于左上角 (0, 0)，初始长度为 1 个单位。

给你一个二维数组 food，其中 food[i] = [ri, ci] 表示第 i 块食物的位置。当蛇吃到一块食物时，它的长度与得分都会加 1。

食物是逐个出现的：只有当蛇吃掉当前食物后，下一块食物才会出现。食物出现时，保证它不会落在蛇身占据的格子上。

当蛇撞到墙（越界），或者蛇头移动到了自己身体占据的格子上（撞到自己）时，游戏结束。注意：如果蛇头移动到当前蛇尾所在的格子，这不算撞到自己，因为蛇尾会随这一步一起移动开。

实现 SnakeGame 类：

  • SnakeGame(int width, int height, int[][] food)：用一个大小为 height × width 的屏幕和食物位置数组 food 初始化对象；
  • int move(String direction)：按照 direction 方向移动一步，返回移动后的游戏得分；如果游戏结束，返回 -1。

示例 1：

输入：
["SnakeGame", "move", "move", "move", "move", "move", "move"]
[[3, 2, [[1, 2], [0, 1]]], ["R"], ["D"], ["R"], ["U"], ["L"], ["U"]]
输出：
[null, 0, 0, 1, 1, 2, 2]

解释：
SnakeGame snakeGame = new SnakeGame(3, 2, [[1, 2], [0, 1]]);
snakeGame.move("R"); // 返回 0
snakeGame.move("D"); // 返回 0
snakeGame.move("R"); // 返回 1，蛇吃到第一块食物，第二块食物出现在 (0, 1)
snakeGame.move("U"); // 返回 1
snakeGame.move("L"); // 返回 2，蛇吃到第二块食物，之后不再有食物
snakeGame.move("U"); // 返回 -1，蛇撞到边界，游戏结束

提示：

  • 1 <= width, height <= 10^4
  • 1 <= food.length <= 50
  • food[i].length == 2
  • 0 <= ri < height
  • 0 <= ci < width
  • direction.length == 1
  • direction 为 'U'、'D'、'L' 或 'R'
  • move 方法最多被调用 10^4 次

核心不变量

蛇身用双端队列按「头 → 尾」顺序保存坐标，蛇头进队、蛇尾出队；只有吃到食物时蛇尾才不弹出，其余情况每步都弹尾，因此「判断撞尾」必须在弹尾之后进行。

完整推导

思路推导

  1. 蛇身怎么存？ 蛇每走一步，本质是「头进、尾出」，是一个典型的双端队列（deque）操作。把每个格子压成一个整数 r * width + c，队头是蛇头、队尾是蛇尾。

  2. 怎么快速判碰撞？ 若每次都在队列里线性查找蛇头是否压到身体，最坏 O(蛇长)。再加一个哈希集合同步维护蛇身格子，contains 就是 O(1)。队列负责「先进先出」的增删，集合负责「是否占用」的判断，两者必须同步更新。

  3. 关键细节：先弹尾再判碰撞。 如果这一步没吃到食物，蛇尾会离开原格子，所以蛇头移入原蛇尾格子是合法的。因此处理顺序是：先假设不长身体 → 弹出队尾并从集合删除 → 再检查新蛇头是否在集合中。吃到食物时才跳过弹尾（蛇长 +1）。

  4. 小例子（width=3, height=2, food=[[1,2],[0,1]]）：初始蛇 {(0,0)}。走 R → 头 (0,1)，未吃到，弹尾 (0,0)，合法；再走 D → 头 (1,1)；走 R → 头 (1,2) 正好是食物，得分 1 且不弹尾，蛇长变 2；……最后一步 U 使头到 (-1,1) 越界，返回 -1。

Java 实现（双端队列 + 哈希集合模拟）

import java.util.ArrayDeque;
import java.util.Deque;
import java.util.HashSet;
import java.util.Set;

class SnakeGame {
    private int width, height;
    private int[][] food;
    private int foodIndex;      // 下一块待吃食物的下标
    private int score;          // 当前得分 == 已吃食物数
    private Deque<Integer> snake;      // 蛇身坐标，head 在队首
    private Set<Integer> occupied;     // 蛇身占据的格子，便于 O(1) 判碰撞

    public SnakeGame(int width, int height, int[][] food) {
        this.width = width;
        this.height = height;
        this.food = food;
        this.foodIndex = 0;
        this.score = 0;
        this.snake = new ArrayDeque<>();
        this.occupied = new HashSet<>();
        snake.offerFirst(0);       // 初始蛇头在 (0,0)，编码 0*width+0
        occupied.add(0);
    }

    public int move(String direction) {
        // 1. 根据方向算新蛇头坐标
        int head = snake.peekFirst();
        int r = head / width;
        int c = head % width;
        switch (direction) {
            case "U": r--; break;
            case "D": r++; break;
            case "L": c--; break;
            case "R": c++; break;
        }

        // 2. 越界即撞墙，游戏结束
        if (r < 0 || r >= height || c < 0 || c >= width) {
            return -1;
        }

        int newHead = r * width + c;

        // 3. 判断这一步是否吃到食物
        boolean eat = foodIndex < food.length
                && food[foodIndex][0] == r
                && food[foodIndex][1] == c;

        // 4. 未吃到食物时，蛇尾会离开，先弹尾再判碰撞
        if (!eat) {
            int tail = snake.pollLast();
            occupied.remove(tail);
        }

        // 5. 若新蛇头已在蛇身中，说明撞到自己
        if (occupied.contains(newHead)) {
            return -1;
        }

        // 6. 合法，蛇头进队
        snake.offerFirst(newHead);
        occupied.add(newHead);

        if (eat) {
            score++;
            foodIndex++;            // 下一块食物登场
        }
        return score;
    }
}

复杂度

  • 时间：每次 move 都是 O(1)。移动、入队、出队、集合判重均为常数时间操作。
  • 空间：O(food.length)。蛇身最长等于 食物数 + 1，队列与集合的规模都不超过它。

易错点与扩展（面试高频考点）

  1. 判碰撞顺序不能错：必须「先弹尾（未吃食物时）再判蛇头是否撞身体」，否则蛇头移入原蛇尾格子会被误判为撞自己。
  2. 吃到食物这一步不弹尾：因为蛇要变长，尾巴留在原地；忘记这一点会导致蛇身长度不增长。
  3. 食物下标单独指针：食物是逐个出现的，用一个 foodIndex 指针记录下一块食物，吃到后才前进，不要用「食物坐标是否等于蛇头」去反推。
  4. 编码坐标避免对象开销：把 (r,c) 压成 r*width + c 一个整数，既省内存又便于哈希；注意 width 是列数。
  5. 边界优先判断：先判越界再判碰撞，越界时直接返回 -1，避免后续用非法坐标。

C++ 实现

#include <deque>
#include <unordered_set>
#include <string>
#include <vector>
using namespace std;

class SnakeGame {
    int width, height;
    vector<vector<int>> food;
    int foodIndex = 0;
    int score = 0;
    deque<int> snake;                 // 蛇身坐标，head 在队首
    unordered_set<int> occupied;      // 蛇身占用格子

public:
    SnakeGame(int width, int height, vector<vector<int>>& food)
        : width(width), height(height), food(food) {
        snake.push_front(0);          // (0,0)
        occupied.insert(0);
    }

    int move(string direction) {
        int head = snake.front();
        int r = head / width;
        int c = head % width;
        if (direction == "U") --r;
        else if (direction == "D") ++r;
        else if (direction == "L") --c;
        else if (direction == "R") ++c;

        if (r < 0 || r >= height || c < 0 || c >= width) return -1;

        int newHead = r * width + c;
        bool eat = foodIndex < (int)food.size()
                && food[foodIndex][0] == r && food[foodIndex][1] == c;

        if (!eat) {
            int tail = snake.back();
            snake.pop_back();
            occupied.erase(tail);
        }
        if (occupied.count(newHead)) return -1;

        snake.push_front(newHead);
        occupied.insert(newHead);
        if (eat) { ++score; ++foodIndex; }
        return score;
    }
};

Python 实现

from collections import deque
from typing import List


class SnakeGame:

    def __init__(self, width: int, height: int, food: List[List[int]]):
        self.width = width
        self.height = height
        self.food = food
        self.food_index = 0
        self.score = 0
        self.snake = deque([0])      # 蛇身坐标，head 在队首
        self.occupied = {0}          # 蛇身占用格子

    def move(self, direction: str) -> int:
        head = self.snake[0]
        r, c = divmod(head, self.width)
        if direction == "U":
            r -= 1
        elif direction == "D":
            r += 1
        elif direction == "L":
            c -= 1
        elif direction == "R":
            c += 1

        if r < 0 or r >= self.height or c < 0 or c >= self.width:
            return -1

        new_head = r * self.width + c
        eat = (self.food_index < len(self.food)
               and self.food[self.food_index][0] == r
               and self.food[self.food_index][1] == c)

        if not eat:
            tail = self.snake.pop()
            self.occupied.remove(tail)

        if new_head in self.occupied:
            return -1

        self.snake.appendleft(new_head)
        self.occupied.add(new_head)
        if eat:
            self.score += 1
            self.food_index += 1
        return self.score
