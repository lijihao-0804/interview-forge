384. 打乱数组

本次复习：
按 M 快速切换薄弱标记
遮住推导与代码，先自己想，再逐段揭示
难度中等核心模式Fisher–Yates 洗牌，从后往前与 [0, i] 随机位置交换时间复杂度O(n)空间复杂度O(n)

题目与约束

给你一个整数数组 nums ，设计算法来打乱一个没有重复元素的数组。打乱后，数组的所有排列应该是 等可能 的。

实现 Solution class:

  • Solution(int[] nums) 使用整数数组 nums 初始化对象

  • int[] reset() 重设数组到它的初始状态并返回

  • int[] shuffle() 返回数组随机打乱后的结果

示例 1：

输入
["Solution", "shuffle", "reset", "shuffle"]
[[[1, 2, 3]], [], [], []]
输出
[null, [3, 1, 2], [1, 2, 3], [1, 3, 2]]
解释
Solution solution = new Solution([1, 2, 3]);
solution.shuffle(); // 打乱数组 [1,2,3] 并返回结果。任何 [1,2,3]的排列返回的概率应该相同。例如，返回 [3, 1, 2]
solution.reset(); // 重设数组到它的初始状态 [1, 2, 3] 。返回 [1, 2, 3]
solution.shuffle(); // 随机返回数组 [1, 2, 3] 打乱后的结果。例如，返回 [1, 3, 2]

提示：

  • 1 <= nums.length <= 50

  • -106 <= nums[i] <= 106

  • nums 中的所有元素都是 唯一的

  • 最多可以调用 104 次 reset 和 shuffle

核心不变量

Fisher–Yates：从后往前遍历，第 i 个位置与 [0, i] 中均匀随机的位置交换；每步各分支概率相等，从而 n! 种排列等概率出现。

完整推导

思路推导

  1. 朴素做法的缺陷：一个常见错误是「对每个位置，随机选一个位置交换」。如果每次都在整个 [0, n-1] 里随机选，某些排列会被重复生成、某些被漏掉，概率并不均匀。要保证等可能，必须严格控制每个位置可选的随机范围。

  2. Fisher–Yates 的直觉：把数组想象成一排卡片。第一步：从全部 n 张里抽一张放到最后位置（它有 n 种等可能）；第二步：从剩下 n-1 张里抽一张放到倒数第二位置（n-1 种等可能）……以此类推。乘法原理给出 n × (n-1) × … × 1 = n! 种等可能结果，恰好覆盖所有排列。

  3. 实现细节：从 i = n-1 递减到 1，令 j = random[0, i]，交换 arr[i] 与 arr[j]。注意 j 的范围是闭区间 [0, i]（含 i 本身，表示「这个位置不动」也是合法的一种）。

  4. reset 的实现：初始化时保存一份原始数组的副本 original；reset 返回 original 的拷贝即可。shuffle 每次都基于 original 重新拷贝一份再洗，保证多次调用 shuffle 相互独立、且不污染原始状态。

Java 实现（Fisher–Yates）

import java.util.Random;

class Solution {
    private final int[] original;          // 保存初始数组，reset 用
    private final Random random = new Random();

    public Solution(int[] nums) {
        original = nums.clone();
    }

    public int[] reset() {
        // 返回初始数组的副本，避免外部修改内部状态
        return original.clone();
    }

    public int[] shuffle() {
        // 每次基于原始数组的一份新拷贝洗牌，保证各次调用独立
        int[] arr = original.clone();
        for (int i = arr.length - 1; i > 0; i--) {
            int j = random.nextInt(i + 1); // [0, i] 闭区间均匀随机
            int tmp = arr[i];
            arr[i] = arr[j];
            arr[j] = tmp;
        }
        return arr;
    }
}

C++ 实现

#include <vector>
#include <cstdlib>
using namespace std;

class Solution {
    vector<int> original;   // 保存初始数组
public:
    Solution(vector<int>& nums) : original(nums) {}

    vector<int> reset() {
        return original;
    }

    vector<int> shuffle() {
        vector<int> arr = original; // 每次基于原始数组的新副本
        for (int i = (int)arr.size() - 1; i > 0; --i) {
            int j = rand() % (i + 1); // [0, i] 均匀随机
            swap(arr[i], arr[j]);
        }
        return arr;
    }
};

Python 实现

import random


class Solution:
    def __init__(self, nums: list[int]):
        self.original = nums[:]   # 保存初始数组

    def reset(self) -> list[int]:
        return self.original[:]

    def shuffle(self) -> list[int]:
        arr = self.original[:]    # 每次基于原始数组的新副本
        for i in range(len(arr) - 1, 0, -1):
            j = random.randint(0, i)  # [0, i] 闭区间均匀随机
            arr[i], arr[j] = arr[j], arr[i]
        return arr

复杂度

  • 时间：O(n)。shuffle 遍历一遍数组，每次常数次交换；reset 为 O(n)（数组拷贝）。
  • 空间：O(n)。保存 original 副本，以及每次 shuffle 生成的 O(n) 结果数组。
易错点与扩展（面试高频考点）
  1. 随机范围写错破坏均匀性：必须是 random.nextInt(i + 1)（即 [0, i]）。若写成 nextInt(n) 或 [i, n-1]，都会导致某些排列概率偏高、某些偏低，不再是等可能。
  2. 直接返回内部数组引用：reset / shuffle 若返回内部数组本身，调用方修改返回值会污染后续状态，应返回 clone()。
  3. 在原始数组上就地洗牌：若直接对 original 洗牌，reset 就无法还原初始状态；必须每次从副本洗。
  4. j 含边界 i：允许 j == i（原地不动）是正确且必要的，漏掉它会让随机范围少一种可能。
  5. 正确性证明要会说：第 i 步有 i+1 种等可能选择，各步独立相乘得 n!，与全排列总数相等，故每个排列概率恰为 1/n!。
