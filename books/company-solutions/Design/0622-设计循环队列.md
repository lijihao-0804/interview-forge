# 622. 设计循环队列

| 题目信息 | 内容 |
|---|---|
| 难度 | 中等 |
| 核心模式 | 定长数组 + 头指针 + 计数器模拟环形缓冲 |
| 时间复杂度 | O(1)（每个操作均为常数时间） |
| 空间复杂度 | O(k)（k 为队列容量） |

## 题目与约束

设计你的循环队列实现。 循环队列是一种线性数据结构，其操作表现基于 FIFO（先进先出）原则并且队尾被连接在队首之后以形成一个循环。它也被称为“环形缓冲器”。

循环队列的一个好处是我们可以利用这个队列之前用过的空间。在一个普通队列里，一旦一个队列满了，我们就不能插入下一个元素，即使在队列前面仍有空间。但是使用循环队列，我们能使用这些空间去存储新的值。

你的实现应该支持如下操作：

- `MyCircularQueue(k)`: 构造器，设置队列长度为 k 。

- `Front`: 从队首获取元素。如果队列为空，返回 -1 。

- `Rear`: 获取队尾元素。如果队列为空，返回 -1 。

- `enQueue(value)`: 向循环队列插入一个元素。如果成功插入则返回真。

- `deQueue()`: 从循环队列中删除一个元素。如果成功删除则返回真。

- `isEmpty()`: 检查循环队列是否为空。

- `isFull()`: 检查循环队列是否已满。

 

示例：

```
MyCircularQueue circularQueue = new MyCircularQueue(3); // 设置长度为 3
circularQueue.enQueue(1);  // 返回 true
circularQueue.enQueue(2);  // 返回 true
circularQueue.enQueue(3);  // 返回 true
circularQueue.enQueue(4);  // 返回 false，队列已满
circularQueue.Rear();  // 返回 3
circularQueue.isFull();  // 返回 true
circularQueue.deQueue();  // 返回 true
circularQueue.enQueue(4);  // 返回 true
circularQueue.Rear();  // 返回 4
```

 

提示：

- 所有的值都在 0 至 1000 的范围内；

- 操作数将在 1 至 1000 的范围内；

- 请不要使用内置的队列库。

## 核心不变量

> 用固定数组 `data` 加头指针 `head` 与元素个数 `count` 描述队列：队首在 `head`，队尾在 `(head + count - 1) % k`，新元素写入 `(head + count) % k`。

## 完整推导

### 思路推导

1. **直觉与痛点（普通队列会「假满」）**

   用普通数组做队列，出队后前面会留下空洞，指针不断后移，最终「数组没满但队尾指针越界」，明明前面有空位也插不进——这就是「假溢出」。循环队列通过取模让指针绕回数组头部，把空洞重新利用起来。

2. **两个指针还差一个计数**

   若只维护 `head`（队首）和 `tail`（队尾下一个位置），「队空」和「队满」都会表现为 `head == tail`，无法区分。经典解法有两种：一是牺牲一个空位（容量 `k+1`）；二是额外维护计数器 `count`。这里采用更直观的**计数器**方案。

3. **各操作如何落到公式**

   设容量为 `k`、头指针 `head`、元素个数 `count`：

   - 判空：`count == 0`；判满：`count == k`。
   - 入队：未满时写入下标 `(head + count) % k`，然后 `count++`。
   - 出队：非空时 `head = (head + 1) % k`，然后 `count--`。
   - 取队首：`data[head]`；取队尾：`data[(head + count - 1) % k]`。

4. **小例子**

   以 `k = 3` 演示示例：依次入队 1、2、3 后 `count = 3` 已满，再来 4 被判满返回 `false`。此时 `head = 0`，队尾 = `data[(0+3-1)%3] = data[2] = 3`。`deQueue` 后 `head = 1`、`count = 2`；再入队 4 写入 `(1+2)%3 = 0` 号位，`count = 3`，队尾 = `data[(1+3-1)%3] = data[0] = 4`，与题目输出完全一致。

### Java 实现（定长数组 + 头指针 + 计数）

```java
class MyCircularQueue {
    private final int[] data;   // 承载元素的定长数组
    private final int capacity; // 容量 k
    private int head;           // 队首所在下标
    private int count;          // 当前元素个数

    public MyCircularQueue(int k) {
        this.capacity = k;
        this.data = new int[k];
        this.head = 0;
        this.count = 0;
    }

    public boolean enQueue(int value) {
        if (isFull()) {
            return false;
        }
        // 新元素放在队尾的下一个位置（取模实现环形）
        data[(head + count) % capacity] = value;
        count++;
        return true;
    }

    public boolean deQueue() {
        if (isEmpty()) {
            return false;
        }
        // 头指针后移并环形回绕，count 减少
        head = (head + 1) % capacity;
        count--;
        return true;
    }

    public int Front() {
        if (isEmpty()) {
            return -1;
        }
        return data[head];
    }

    public int Rear() {
        if (isEmpty()) {
            return -1;
        }
        return data[(head + count - 1) % capacity];
    }

    public boolean isEmpty() {
        return count == 0;
    }

    public boolean isFull() {
        return count == capacity;
    }
}
```

### 复杂度

- 时间：`O(1)`。入队、出队、取队首/队尾、判空判满均为常数次算术与取模运算。
- 空间：`O(k)`。需要一个长度为 `k` 的数组，外加几个整型变量。

### 易错点与扩展（面试高频考点）

1. **取模用错基数**：所有下标回绕都应 `% capacity`（即 `k`），而不是 `% (k+1)`，除非你采用的是「牺牲一个空位」的方案。
2. **`Rear` 的下标**：队尾是 `(head + count - 1) % k`；当 `count` 为 0 时必须先判空返回 `-1`，否则会算出负数下标或越界。
3. **空/满判定**：只用 `head`、`tail` 双指针时 `head == tail` 无法区分空和满，必须用 `count` 或牺牲一个槽位。
4. **负数取模**：某些语言对负数取模会得到负值，务必保证 `head + count - 1 >= 0`（`count > 0` 时成立）。
5. **扩展**：把固定数组换成链表并首尾相连，即为「循环链表」实现；生产环境中的环形缓冲区还常用「读指针 + 写指针 + 无锁 CAS」实现并发安全。

### C++ 实现

```cpp
#include <vector>
using namespace std;

class MyCircularQueue {
private:
    vector<int> data;   // 定长数组
    int capacity;       // 容量 k
    int head;           // 队首下标
    int count;          // 当前元素个数

public:
    MyCircularQueue(int k) {
        capacity = k;
        data.assign(k, 0);
        head = 0;
        count = 0;
    }

    bool enQueue(int value) {
        if (isFull()) return false;
        data[(head + count) % capacity] = value;  // 环形写入队尾
        count++;
        return true;
    }

    bool deQueue() {
        if (isEmpty()) return false;
        head = (head + 1) % capacity;             // 环形后移队首
        count--;
        return true;
    }

    int Front() {
        if (isEmpty()) return -1;
        return data[head];
    }

    int Rear() {
        if (isEmpty()) return -1;
        return data[(head + count - 1) % capacity];
    }

    bool isEmpty() {
        return count == 0;
    }

    bool isFull() {
        return count == capacity;
    }
};
```

### Python 实现

```python
class MyCircularQueue:
    def __init__(self, k: int):
        self.capacity = k
        self.data = [0] * k   # 定长数组
        self.head = 0         # 队首下标
        self.count = 0        # 当前元素个数

    def enQueue(self, value: int) -> bool:
        if self.isFull():
            return False
        self.data[(self.head + self.count) % self.capacity] = value  # 环形写入队尾
        self.count += 1
        return True

    def deQueue(self) -> bool:
        if self.isEmpty():
            return False
        self.head = (self.head + 1) % self.capacity                  # 环形后移队首
        self.count -= 1
        return True

    def Front(self) -> int:
        if self.isEmpty():
            return -1
        return self.data[self.head]

    def Rear(self) -> int:
        if self.isEmpty():
            return -1
        return self.data[(self.head + self.count - 1) % self.capacity]

    def isEmpty(self) -> bool:
        return self.count == 0

    def isFull(self) -> bool:
        return self.count == self.capacity
```
