# 1570. 两个稀疏向量的点积

| 题目信息 | 内容 |
|---|---|
| 难度 | 中等 |
| 核心模式 | 只存非零元素 + 双指针归并求点积 |
| 时间复杂度 | 构造 O(n)，点积 O(nnz1 + nnz2) |
| 空间复杂度 | O(nnz1 + nnz2) |

## 题目与约束

请设计一个类 `SparseVector`，用于表示一个**稀疏向量**（大部分元素为 0 的向量），并支持计算两个稀疏向量的点积。

你的 `SparseVector` 类需要实现：

- `SparseVector(int[] nums)`：用一个整数数组 `nums` 构造该稀疏向量。
- `dotProduct(SparseVector vec)`：返回当前向量与向量 `vec` 的点积。点积定义为对应位置元素乘积之和，即 `sum(nums1[i] * nums2[i])`。

**示例 1：**

```
输入：
nums1 = [1,0,0,2,3]
nums2 = [0,3,0,4,0]
输出：8
解释：
v1 = SparseVector(nums1)
v2 = SparseVector(nums2)
v1.dotProduct(v2) = 1*0 + 0*3 + 0*0 + 2*4 + 3*0 = 8
```

**示例 2：**

```
输入：
nums1 = [0,1,0,0,0]
nums2 = [0,0,0,0,2]
输出：0
解释：
v1 = SparseVector(nums1)
v2 = SparseVector(nums2)
v1.dotProduct(v2) = 0*0 + 1*0 + 0*0 + 0*0 + 0*2 = 0
```

**提示：**

- `n == nums1.length == nums2.length`
- `1 <= n <= 10^5`
- `0 <= nums1[i], nums2[i] <= 100`
- 向量的下标从 `0` 开始。

**进阶：** 如果其中一个向量非常稀疏（非零元素极少），而另一个向量并不稀疏，你会如何优化点积的计算？

## 核心不变量

> 只保存每个向量的「(下标, 非零值)」对，点积时用双指针按下标归并，下标相同才累加乘积，其余位置乘积恒为 0 可直接跳过。

## 完整推导

### 思路推导

1. **直觉与痛点（逐位相乘太浪费）**：直接对 0..n-1 逐位相乘，需要 O(n) 时间，但稀疏向量绝大多数位置是 0，乘以任何数都是 0，完全没必要遍历那些位置。真正贡献点积的只有「两个向量都非零」的位置。

2. **只存非零元素**：构造时把每个非零元素记成 `(下标, 值)` 的二元组，按构造顺序（下标递增）放入列表。这样存储量与「非零元素个数 nnz」成正比，而不是与 n 成正比。

3. **双指针归并**：两个列表都按下标升序。设两个指针 i、j：
   - 若 `a[i].index == b[j].index`：累加 `a[i].val * b[j].val`，两指针同进。
   - 若 `a[i].index < b[j].index`：说明 a 的这个位置在 b 中必为 0，跳过 i。
   - 否则跳过 j。
   整个过程 O(nnz1 + nnz2)。

4. **小例子**：`nums1=[1,0,0,2,3]` → 非零对 `(0,1),(3,2),(4,3)`；`nums2=[0,3,0,4,0]` → `(1,3),(3,4)`。归并到下标 3 时相等，累加 `2*4=8`，其余下标不重合，最终答案 8。

### Java 实现（SparseVector）

```java
import java.util.ArrayList;
import java.util.List;

class SparseVector {
    // 只保存非零元素：每个元素是 {下标, 值}
    private final List<int[]> pairs = new ArrayList<>();

    SparseVector(int[] nums) {
        for (int i = 0; i < nums.length; i++) {
            if (nums[i] != 0) {
                pairs.add(new int[]{i, nums[i]});
            }
        }
    }

    // 返回当前向量与 vec 的点积
    public int dotProduct(SparseVector vec) {
        List<int[]> a = this.pairs;
        List<int[]> b = vec.pairs;
        int i = 0, j = 0, ans = 0;
        while (i < a.size() && j < b.size()) {
            int[] pa = a.get(i);
            int[] pb = b.get(j);
            if (pa[0] == pb[0]) {
                ans += pa[1] * pb[1]; // 下标相同才相乘累加
                i++;
                j++;
            } else if (pa[0] < pb[0]) {
                i++; // a 的下标更小，b 在该处为 0，跳过
            } else {
                j++; // b 的下标更小，a 在该处为 0，跳过
            }
        }
        return ans;
    }
}
```

### 复杂度

- 时间：构造 O(n) 扫描一遍；点积 O(nnz1 + nnz2)，nnz 为非零元素个数，远小于 n 时非常高效。
- 空间：O(nnz1 + nnz2)，仅存储非零元素。

### 易错点与扩展（面试高频考点）

1. **点积不是乘积数组**：只累加「下标完全相同」的位置，不能把两个非零列表按顺序直接相乘。
2. **下标必须保存**：非零列表不能只存值，否则丢失位置信息，无法判断是否对齐。
3. **整数范围**：单值 ≤ 100、n ≤ 1e5，最大点积约 100*100*1e5 = 1e9，仍在 int 范围内，但用 long 累加更保险。
4. **进阶优化（哈希表法）**：若一个向量极稀疏，可把较稀疏的向量存成「下标→值」的 HashMap，遍历另一个向量的非零项去查表累加，复杂度 O(min(nnz1, nnz2)) 的查询量；双指针法则对两向量都稀疏时最优。
5. **设计题格式**：LeetCode 判题会直接调用构造函数与 `dotProduct`，不要写 `main`，也不要改动方法签名。

## 力扣原题

[1570. 两个稀疏向量的点积](https://leetcode.cn/problems/dot-product-of-two-sparse-vectors/)

### C++ 实现

```cpp
class SparseVector {
public:
    // 只保存非零元素：{下标, 值}，按下标升序
    vector<pair<int, int>> pairs;

    SparseVector(vector<int>& nums) {
        for (int i = 0; i < (int)nums.size(); ++i) {
            if (nums[i] != 0) pairs.push_back({i, nums[i]});
        }
    }

    // 返回当前向量与 vec 的点积
    int dotProduct(SparseVector& vec) {
        int i = 0, j = 0, ans = 0;
        while (i < (int)pairs.size() && j < (int)vec.pairs.size()) {
            if (pairs[i].first == vec.pairs[j].first) {
                ans += pairs[i].second * vec.pairs[j].second;
                ++i;
                ++j;
            } else if (pairs[i].first < vec.pairs[j].first) {
                ++i;
            } else {
                ++j;
            }
        }
        return ans;
    }
};
```

### Python 实现

```python
class SparseVector:
    def __init__(self, nums: List[int]):
        # 只保存非零元素：(下标, 值)，按下标升序
        self.pairs = [(i, v) for i, v in enumerate(nums) if v != 0]

    def dotProduct(self, vec: "SparseVector") -> int:
        i = j = 0
        ans = 0
        a, b = self.pairs, vec.pairs
        while i < len(a) and j < len(b):
            if a[i][0] == b[j][0]:
                ans += a[i][1] * b[j][1]
                i += 1
                j += 1
            elif a[i][0] < b[j][0]:
                i += 1
            else:
                j += 1
        return ans
```
