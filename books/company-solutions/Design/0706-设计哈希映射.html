题目与约束

不使用任何内建的哈希表库设计一个哈希映射（HashMap）。

实现 MyHashMap 类：

  • MyHashMap() 用空映射初始化对象

  • void put(int key, int value) 向 HashMap 插入一个键值对 (key, value) 。如果 key 已经存在于映射中，则更新其对应的值 value 。

  • int get(int key) 返回特定的 key 所映射的 value ；如果映射中不包含 key 的映射，返回 -1 。

  • void remove(key) 如果映射中存在 key 的映射，则移除 key 和它所对应的 value 。

示例：

输入：
["MyHashMap", "put", "put", "get", "get", "put", "get", "remove", "get"]
[[], [1, 1], [2, 2], [1], [3], [2, 1], [2], [2], [2]]
输出：
[null, null, null, 1, -1, null, 1, null, -1]
解释：
MyHashMap myHashMap = new MyHashMap();
myHashMap.put(1, 1); // myHashMap 现在为 [[1,1]]
myHashMap.put(2, 2); // myHashMap 现在为 [[1,1], [2,2]]
myHashMap.get(1); // 返回 1 ，myHashMap 现在为 [[1,1], [2,2]]
myHashMap.get(3); // 返回 -1（未找到），myHashMap 现在为 [[1,1], [2,2]]
myHashMap.put(2, 1); // myHashMap 现在为 [[1,1], [2,1]]（更新已有的值）
myHashMap.get(2); // 返回 1 ，myHashMap 现在为 [[1,1], [2,1]]
myHashMap.remove(2); // 删除键为 2 的数据，myHashMap 现在为 [[1,1]]
myHashMap.get(2); // 返回 -1（未找到），myHashMap 现在为 [[1,1]]

提示：

  • 0 <= key, value <= 106

  • 最多调用 104 次 put、get 和 remove 方法

核心不变量

键 key 经哈希函数映射到唯一桶 key % B，同一个键的所有操作必然落在同一个桶里，桶内链表按 key 精确匹配。

完整推导

思路推导

  1. 直觉（用桶把大键域压缩）

键的取值范围可达 10⁶，但操作次数只有 10⁴。开一个 100 万长的数组太浪费，于是用"桶"把键散布到较小空间：index = key % B。所有映射到同一桶的键用链表串起来，这就是链地址法。

  1. put（找到就更新，找不到就头插）

先算出桶号，遍历该桶链表：命中同 key 就更新 value；没命中就在链头插入新节点（头插 O(1)）。

  1. get / remove（同样定位到桶再细找）

get 遍历桶链表返回匹配 value，否则 -1；remove 用一个 dummy 哨兵简化删除，找到目标节点后跳过它。

  1. 小例子（put(1,1)、put(2,2)、get(3)）

设 B=10007，1 % B = 1、2 % B = 2 落在不同桶；get(3) 在桶 3 里找不到，返回 -1。更新 put(2,1) 时在桶 2 命中 key=2，直接改值为 1。

Java 实现（MyHashMap）

class MyHashMap {
    private static final int BUCKETS = 10007; // 取质数，减少聚集

    // 桶内链表节点
    private static class Node {
        int key;
        int value;
        Node next;
        Node(int key, int value) {
            this.key = key;
            this.value = value;
        }
    }

    private final Node[] table;

    public MyHashMap() {
        table = new Node[BUCKETS];
    }

    private int hash(int key) {
        return key % BUCKETS;
    }

    public void put(int key, int value) {
        int idx = hash(key);
        // 已存在则更新
        for (Node cur = table[idx]; cur != null; cur = cur.next) {
            if (cur.key == key) {
                cur.value = value;
                return;
            }
        }
        // 不存在则头插
        Node node = new Node(key, value);
        node.next = table[idx];
        table[idx] = node;
    }

    public int get(int key) {
        int idx = hash(key);
        for (Node cur = table[idx]; cur != null; cur = cur.next) {
            if (cur.key == key) {
                return cur.value;
            }
        }
        return -1;
    }

    public void remove(int key) {
        int idx = hash(key);
        Node dummy = new Node(-1, -1); // 哨兵，简化删除头节点
        dummy.next = table[idx];
        Node prev = dummy;
        while (prev.next != null) {
            if (prev.next.key == key) {
                prev.next = prev.next.next; // 跳过目标节点
                break;
            }
            prev = prev.next;
        }
        table[idx] = dummy.next;
    }
}

复杂度

  • 时间：平均 O(1)。哈希把键均匀打散后，单桶链长约为 n/B，put/get/remove 均为 O(1 + n/B)；最坏（全部冲突）退化为 O(n)。
  • 空间：O(n + B)，n 为实际键值对数量，B 为桶数组大小。

易错点与扩展（面试高频考点）

  1. put 必须处理"更新"语义：同一 key 重复 put 是覆盖 value，不是又插一个节点，否则 get 会拿到旧值。
  2. remove 的链表删除：删除头节点易漏处理，用 dummy 哨兵统一处理，避免额外分支。
  3. 桶大小选取：桶数取质数（如 10007）能减少聚集；桶太小冲突多退化，桶太大浪费空间。
  4. -1 不能当"空标记"：value 允许为 0，所以用链表结构区分"不存在"和"值为 0"，不能靠 value 是否 0 判断存在。
  5. 扩展：同套思路可实现 MyHashSet（只需存 key）；另外可用"开放寻址 + 线性探测"代替拉链，但要注意删除时打标记（tombstone）。

C++ 实现

class MyHashMap {
private:
    static const int BUCKETS = 10007;
    struct Node {
        int key, value;
        Node* next;
        Node(int k, int v) : key(k), value(v), next(nullptr) {}
    };
    Node* table[BUCKETS];

    int hash(int key) { return key % BUCKETS; }

public:
    MyHashMap() {
        for (int i = 0; i < BUCKETS; ++i) table[i] = nullptr;
    }

    void put(int key, int value) {
        int idx = hash(key);
        for (Node* cur = table[idx]; cur != nullptr; cur = cur->next) {
            if (cur->key == key) {
                cur->value = value;
                return;
            }
        }
        Node* node = new Node(key, value);
        node->next = table[idx];
        table[idx] = node;
    }

    int get(int key) {
        int idx = hash(key);
        for (Node* cur = table[idx]; cur != nullptr; cur = cur->next) {
            if (cur->key == key) return cur->value;
        }
        return -1;
    }

    void remove(int key) {
        int idx = hash(key);
        Node dummy(-1, -1);
        dummy.next = table[idx];
        Node* prev = &dummy;
        while (prev->next != nullptr) {
            if (prev->next->key == key) {
                prev->next = prev->next->next;
                break;
            }
            prev = prev->next;
        }
        table[idx] = dummy.next;
    }
};

Python 实现

class MyHashMap:

    def __init__(self):
        self.BUCKETS = 10007
        # 每个桶是一条 [key, value] 链表，这里用 list 存节点
        self.table = [[] for _ in range(self.BUCKETS)]

    def _hash(self, key: int) -> int:
        return key % self.BUCKETS

    def put(self, key: int, value: int) -> None:
        bucket = self.table[self._hash(key)]
        for pair in bucket:
            if pair[0] == key:
                pair[1] = value
                return
        bucket.append([key, value])

    def get(self, key: int) -> int:
        bucket = self.table[self._hash(key)]
        for pair in bucket:
            if pair[0] == key:
                return pair[1]
        return -1

    def remove(self, key: int) -> None:
        bucket = self.table[self._hash(key)]
        for i, pair in enumerate(bucket):
            if pair[0] == key:
                bucket.pop(i)
                return
