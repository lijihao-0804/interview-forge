# 460. LFU 缓存

| 题目信息 | 内容 |
|---|---|
| 难度 | 困难 |
| 核心模式 | 哈希表 + 频率分桶双向链表（O(1) 淘汰） |
| 时间复杂度 | O(1)（get / put 均摊） |
| 空间复杂度 | O(capacity) |

## 题目与约束

请你为 最不经常使用（LFU）缓存算法设计并实现数据结构。

实现 `LFUCache` 类：

- `LFUCache(int capacity)` - 用数据结构的容量 `capacity` 初始化对象

- `int get(int key)` - 如果键 `key` 存在于缓存中，则获取键的值，否则返回 `-1` 。

- `void put(int key, int value)` - 如果键 `key` 已存在，则变更其值；如果键不存在，请插入键值对。当缓存达到其容量 `capacity` 时，则应该在插入新项之前，移除最不经常使用的项。在此问题中，当存在平局（即两个或更多个键具有相同使用频率）时，应该去除 最久未使用 的键。

为了确定最不常使用的键，可以为缓存中的每个键维护一个 使用计数器 。使用计数最小的键是最久未使用的键。

当一个键首次插入到缓存中时，它的使用计数器被设置为 `1` (由于 put 操作)。对缓存中的键执行 `get` 或 `put` 操作，使用计数器的值将会递增。

函数 `get` 和 `put` 必须以 `O(1)` 的平均时间复杂度运行。

 

示例：

```
<strong>输入：</strong>
["LFUCache", "put", "put", "get", "put", "get", "get", "put", "get", "get", "get"]
[[2], [1, 1], [2, 2], [1], [3, 3], [2], [3], [4, 4], [1], [3], [4]]
<strong>输出：</strong>
[null, null, null, 1, null, -1, 3, null, -1, 3, 4]

<strong>解释：</strong>
// cnt(x) = 键 x 的使用计数
// cache=[] 将显示最后一次使用的顺序（最左边的元素是最近的）
LFUCache lfu = new LFUCache(2);
lfu.put(1, 1);   // cache=[1,_], cnt(1)=1
lfu.put(2, 2);   // cache=[2,1], cnt(2)=1, cnt(1)=1
lfu.get(1);      // 返回 1
                 // cache=[1,2], cnt(2)=1, cnt(1)=2
lfu.put(3, 3);   // 去除键 2 ，因为 cnt(2)=1 ，使用计数最小
                 // cache=[3,1], cnt(3)=1, cnt(1)=2
lfu.get(2);      // 返回 -1（未找到）
lfu.get(3);      // 返回 3
                 // cache=[3,1], cnt(3)=2, cnt(1)=2
lfu.put(4, 4);   // 去除键 1 ，1 和 3 的 cnt 相同，但 1 最久未使用
                 // cache=[4,3], cnt(4)=1, cnt(3)=2
lfu.get(1);      // 返回 -1（未找到）
lfu.get(3);      // 返回 3
                 // cache=[3,4], cnt(4)=1, cnt(3)=3
lfu.get(4);      // 返回 4
                 // cache=[3,4], cnt(4)=2, cnt(3)=3
```

 

提示：

- `1 <= capacity <= 104`

- `0 <= key <= 105`

- `0 <= value <= 109`

- 最多调用 `2 * 105` 次 `get` 和 `put` 方法

[🔗 前往力扣原题验证 →](https://leetcode.cn/problems/lfu-cache/)

## 核心不变量

> 每个频率 `f` 对应一条双向链表（桶），桶内按“最近使用”从头部到尾部排列；`minFreq` 始终指向当前存在的最小的非空桶频率，淘汰时从 `minFreq` 桶的**尾部**取最久未使用的节点。

## 完整推导

### 思路推导

1. **直觉与痛点（为什么普通 LRU 不够）**：LRU 只按“最近使用时间”排序，而 LFU 先看**使用次数**，次数相同才看“最久未使用”。这需要两个维度同时维护，单条链表无法表达。

2. **破局（频率分桶）**：维护 `freq -> 双向链表` 的映射，每条链表的头部是“该频率下最近使用”的键，尾部是“最久未使用”的键。再维护 `key -> 节点` 的映射，节点里存 `key / value / freq`，这样能 `O(1)` 定位并修改。

3. **访问（get / put 命中）时的频率迁移**：节点从频率 `f` 的链表摘除，插入频率 `f+1` 的链表**头部**（表示最近使用）。若摘除后 `f` 桶空了且 `f == minFreq`，则 `minFreq` 后移为 `f+1`（只有刚好是最小桶变空时才需要动 `minFreq`）。

4. **插入新键与淘汰**：新键频率恒为 1，插入频率 1 桶头部，并把 `minFreq = 1`。容量满时，从 `minFreq` 桶的**尾部**摘掉最久未使用的节点并删除对应 `key` 映射。以示例为例：`put(3,3)` 时 `minFreq=1`，尾部是键 2（比键 1 更久未用），淘汰 2，正确。

### Java 实现（LFUCache）

```java
import java.util.HashMap;
import java.util.Map;

class LFUCache {

    // 双向链表节点
    private static class Node {
        int key, value, freq;
        Node prev, next;
        Node(int key, int value) {
            this.key = key;
            this.value = value;
            this.freq = 1;
        }
    }

    // 带头尾哨兵的双向链表，头部为最近使用，尾部为最久未使用
    private static class DoublyLinkedList {
        Node head, tail;
        int size;

        DoublyLinkedList() {
            head = new Node(0, 0);
            tail = new Node(0, 0);
            head.next = tail;
            tail.prev = head;
            size = 0;
        }

        void addFirst(Node node) {
            node.next = head.next;
            node.prev = head;
            head.next.prev = node;
            head.next = node;
            size++;
        }

        void remove(Node node) {
            node.prev.next = node.next;
            node.next.prev = node.prev;
            size--;
        }

        Node removeLast() {
            if (size == 0) {
                return null;
            }
            Node last = tail.prev;
            remove(last);
            return last;
        }
    }

    private final int capacity;
    private int minFreq;                                   // 当前最小频率
    private final Map<Integer, Node> keyToNode;            // key -> 节点
    private final Map<Integer, DoublyLinkedList> freqToDLL; // 频率 -> 桶链表

    public LFUCache(int capacity) {
        this.capacity = capacity;
        this.minFreq = 0;
        this.keyToNode = new HashMap<>();
        this.freqToDLL = new HashMap<>();
    }

    public int get(int key) {
        Node node = keyToNode.get(key);
        if (node == null) {
            return -1;
        }
        increaseFreq(node);       // 使用频率 +1 并迁移桶
        return node.value;
    }

    public void put(int key, int value) {
        if (capacity <= 0) {
            return;
        }
        Node node = keyToNode.get(key);
        if (node != null) {
            // 已存在：更新值并提升频率
            node.value = value;
            increaseFreq(node);
        } else {
            // 容量已满：淘汰 minFreq 桶尾部（最久未使用）
            if (keyToNode.size() >= capacity) {
                DoublyLinkedList minList = freqToDLL.get(minFreq);
                Node evicted = minList.removeLast();
                keyToNode.remove(evicted.key);
            }
            Node newNode = new Node(key, value);
            keyToNode.put(key, newNode);
            freqToDLL.computeIfAbsent(1, k -> new DoublyLinkedList()).addFirst(newNode);
            minFreq = 1;          // 新键频率为 1，最小频率重置
        }
    }

    // 将节点从频率 f 桶迁到频率 f+1 桶，并维护 minFreq
    private void increaseFreq(Node node) {
        int freq = node.freq;
        DoublyLinkedList list = freqToDLL.get(freq);
        list.remove(node);

        // 最小桶被清空，最小频率上移
        if (freq == minFreq && list.size == 0) {
            minFreq++;
        }

        node.freq = freq + 1;
        freqToDLL.computeIfAbsent(node.freq, k -> new DoublyLinkedList()).addFirst(node);
    }
}
```

### 复杂度

- 时间：`O(1)`。`get`/`put` 只涉及哈希表查找、双向链表的头插与 O(1) 摘除，以及常数次 `minFreq` 维护。
- 空间：`O(capacity)`。最多缓存 `capacity` 个节点，外加频率桶的哈希表开销。

### 易错点与扩展（面试高频考点）

1. **`minFreq` 的更新条件**：只有当“被清空的桶频率恰好等于 `minFreq`”时才 `minFreq++`；其它情况（如在更大的桶里移除节点）绝不能动 `minFreq`，否则会淘汰错对象。
2. **新键必把 `minFreq` 置 1**：无论是首次插入还是淘汰后插入，新节点频率都是 1，`minFreq` 必须重置为 1，否则会从一个已经空了的桶里淘汰。
3. **同频平局按“最久未使用”淘汰**：桶必须维护插入顺序——最近访问的放头部，淘汰取尾部。这一步常被误写成“随便删一个”。
4. **更新已存在的键要提升频率**：`put` 命中已有 key 时也要走 `increaseFreq`，不能只改 value；`get` 命中同样要提升。
5. **`put` 与 `get` 的语义差异**：`put` 新插入算“使用 1 次”，命中已有键的 `put` 也算一次使用；容量为 0 时直接忽略。可与 LRU（146 题）对照：LRU 是单链表 + 时间维度，LFU 是“频率桶 + 桶内 LRU”的双层结构。

### C++ 实现

```cpp
#include <unordered_map>
#include <list>
using namespace std;

class LFUCache {
    struct Node {
        int key;
        int value;
        int freq;
    };

    int capacity;
    int minFreq;
    // key -> 该 key 在对应频率链表中的迭代器
    unordered_map<int, list<Node>::iterator> keyToIter;
    // 频率 -> 双向链表（头部最近使用，尾部最久未使用）
    unordered_map<int, list<Node>> freqToList;

    void increaseFreq(int key) {
        auto it = keyToIter[key];
        int freq = it->freq;
        int value = it->value;

        auto &lst = freqToList[freq];
        lst.erase(it);
        if (lst.empty()) {
            freqToList.erase(freq);
            if (minFreq == freq) {
                ++minFreq;
            }
        }

        freqToList[freq + 1].push_front(Node{key, value, freq + 1});
        keyToIter[key] = freqToList[freq + 1].begin();
    }

public:
    LFUCache(int capacity) : capacity(capacity), minFreq(0) {}

    int get(int key) {
        if (keyToIter.find(key) == keyToIter.end()) {
            return -1;
        }
        int value = keyToIter[key]->value;
        increaseFreq(key);
        return value;
    }

    void put(int key, int value) {
        if (capacity <= 0) {
            return;
        }
        if (keyToIter.find(key) != keyToIter.end()) {
            keyToIter[key]->value = value;
            increaseFreq(key);
        } else {
            if ((int)keyToIter.size() >= capacity) {
                auto &minList = freqToList[minFreq];
                int evictKey = minList.back().key;   // 尾部最久未使用
                minList.pop_back();
                keyToIter.erase(evictKey);
                if (minList.empty()) {
                    freqToList.erase(minFreq);
                }
            }
            freqToList[1].push_front(Node{key, value, 1});
            keyToIter[key] = freqToList[1].begin();
            minFreq = 1;
        }
    }
};
```

### Python 实现

```python
from collections import OrderedDict


class LFUCache:

    def __init__(self, capacity: int):
        self.capacity = capacity
        self.min_freq = 0
        self.key_to_val = {}       # key -> [value, freq]
        self.freq_to_keys = {}     # freq -> OrderedDict[key, None]

    def _increase(self, key: int) -> None:
        value, freq = self.key_to_val[key]
        # 从旧频率桶中移除
        del self.freq_to_keys[freq][key]
        if not self.freq_to_keys[freq]:
            del self.freq_to_keys[freq]
            if self.min_freq == freq:
                self.min_freq += 1
        # 频率 +1，加入新桶的末尾（最近使用）
        self.key_to_val[key][1] = freq + 1
        self.freq_to_keys.setdefault(freq + 1, OrderedDict())[key] = None

    def get(self, key: int) -> int:
        if key not in self.key_to_val:
            return -1
        self._increase(key)
        return self.key_to_val[key][0]

    def put(self, key: int, value: int) -> None:
        if self.capacity <= 0:
            return
        if key in self.key_to_val:
            self.key_to_val[key][0] = value
            self._increase(key)
        else:
            if len(self.key_to_val) >= self.capacity:
                # 淘汰 min_freq 桶中最久未使用的键（最早插入）
                evict_key, _ = self.freq_to_keys[self.min_freq].popitem(last=False)
                del self.key_to_val[evict_key]
            self.key_to_val[key] = [value, 1]
            self.freq_to_keys.setdefault(1, OrderedDict())[key] = None
            self.min_freq = 1
```
