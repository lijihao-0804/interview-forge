题目信息 内容
难度 困难
核心模式 预处理：枚举所有「前缀#后缀」组合存入哈希表
时间复杂度 预处理 O(W·L²)，查询 O(L)
空间复杂度 O(W·L²)

题目与约束

设计一个包含一些单词的特殊词典，并能够通过前缀和后缀来检索单词。

实现 WordFilter 类：

  • WordFilter(string[] words) 使用词典中的单词 words 初始化对象。
  • f(string pref, string suff) 返回词典中具有前缀 pref 和后缀 suff 的单词的下标。如果存在不止一个满足要求的下标，返回其中 最大的下标。如果不存在这样的单词，返回 -1。

示例：

输入
["WordFilter", "f"]
[[["apple"]], ["a", "e"]]
输出
[null, 0]
解释
WordFilter wordFilter = new WordFilter(["apple"]);
wordFilter.f("a", "e"); // 返回 0 ，因为下标为 0 的单词：前缀 prefix = "a" 且 后缀 suffix = "e" 。

提示：

  • 1 <= words.length <= 10^4
  • 1 <= words[i].length <= 7
  • 1 <= pref.length, suff.length <= 7
  • words[i]、pref 和 suff 仅由小写英文字母组成
  • 最多对函数 f 执行 10^4 次调用

核心不变量

「前缀为 pref 且后缀为 suff」等价于「键 pref#suff 在预处理的哈希表中存在」，而按下标顺序写入并允许覆盖，就能让表里存的永远是满足条件的最大下标。

完整推导

思路推导

  1. 直觉与痛点（查询多、单词短） 每次 f(pref, suff) 都去把所有单词扫一遍，最坏 10^4 × 10^4 次字符串比较，会超时。但换个角度：单词长度最多 7，前缀、后缀的组合数量其实非常有限。

  2. 破局思路（空间换时间的预处理） 在构造 WordFilter 时，就把每个单词拆成「所有前缀 × 所有后缀」的组合，用一个形如 前缀 + "#" + 后缀 的字符串作键，值存该单词的下标，写进哈希表。查询 f 时只需拼出同样的键，O(1) 查表。

以 "apple"（下标 0）为例，会生成： "a#e"、"a#le"、"a#ple"、"a#pple"、"a#apple"、"ap#e"、…、"apple#apple" 等组合。

小例子：查询 f("a","e") 拼出 "a#e"，表里正好有，值 0。

  1. 关键追问（怎么保证是「最大下标」？） 按单词下标从小到大顺序写入。若同一个键被后面的更大下标覆盖，表里留下的自然就是最大值。所以不需要任何额外比较，覆盖写入本身即保证最大下标。

  2. 复杂度来源 每个单词长度 L ≤ 7，前缀至多 L 种、后缀至多 L 种，组合 ≤ L²。单词数 W ≤ 10^4，所以预处理约 W·L² ≤ 4.9×10^5 个键，完全可接受。查询只拼一个长度 ≤ 15 的键。

Java 实现（预处理哈希表）

import java.util.HashMap;
import java.util.Map;

class WordFilter {
    // 键："前缀#后缀"，值：满足条件的最大下标
    private final Map<String, Integer> map = new HashMap<>();

    public WordFilter(String[] words) {
        // 按下标从小到大写入，后写覆盖前写，天然保留最大下标
        for (int idx = 0; idx < words.length; idx++) {
            String w = words[idx];
            int len = w.length();
            // 枚举所有前缀
            for (int i = 1; i <= len; i++) {
                String prefix = w.substring(0, i);
                // 枚举所有后缀
                for (int j = 1; j <= len; j++) {
                    String suffix = w.substring(len - j);
                    map.put(prefix + "#" + suffix, idx);
                }
            }
        }
    }

    public int f(String pref, String suff) {
        // 直接查表，找不到返回 -1
        return map.getOrDefault(pref + "#" + suff, -1);
    }
}

复杂度

  • 时间：预处理 O(W·L²)，W 为单词数、L 为单词最大长度（≤7）；单次查询 O(L)（拼键与哈希），远快于暴力扫描。
  • 空间：O(W·L²)，哈希表最多存约 W·L² 个键值对。

易错点与扩展（面试高频考点）

  1. 覆盖顺序不能反：必须按下标从小到大写入，靠「后写覆盖」保证最大下标；若反过来，就会留下较小下标，答案错误。
  2. 分隔符要选好：用 # 之类不在字母表中的字符做分隔，避免前缀后缀拼接产生歧义（如 "a"+"bc" 与 "ab"+"c"）。
  3. 内存估算：W=10^4, L=7 时最多约 49 万条，注意用合适的哈希结构；若内存吃紧可改用字典树（Trie）方案。
  4. Trie 扩展方案：也可建「前缀树 + 后缀树」或把每个单词 w 插成 w + "{" + w 的前后缀树，查询时匹配到节点后取该节点子树中最大下标，适合考察对字典树的掌握。
  5. 空串边界：本题 pref、suff 长度至少为 1，无需处理空前缀/空后缀；但枚举时下标从 1 开始，别写成从 0 开始导致空串键。

745. 前缀和后缀搜索

C++ 实现

#include <vector>
#include <string>
#include <unordered_map>
using namespace std;

class WordFilter {
    unordered_map<string, int> mp;
public:
    WordFilter(vector<string>& words) {
        // 按下标从小到大写入，后写覆盖前写，保留最大下标
        for (int idx = 0; idx < (int)words.size(); idx++) {
            const string& w = words[idx];
            int len = w.size();
            for (int i = 1; i <= len; i++) {
                string prefix = w.substr(0, i);
                for (int j = 1; j <= len; j++) {
                    string suffix = w.substr(len - j);
                    mp[prefix + "#" + suffix] = idx;
                }
            }
        }
    }

    int f(string pref, string suff) {
        auto it = mp.find(pref + "#" + suff);
        return it == mp.end() ? -1 : it->second;
    }
};

Python 实现

class WordFilter:
    def __init__(self, words: list[str]):
        self.d = {}
        # 按下标从小到大写入，后写覆盖前写，保留最大下标
        for idx, w in enumerate(words):
            n = len(w)
            for i in range(1, n + 1):
                prefix = w[:i]
                for j in range(1, n + 1):
                    suffix = w[n - j:]
                    self.d[prefix + '#' + suffix] = idx

    def f(self, pref: str, suff: str) -> int:
        return self.d.get(pref + '#' + suff, -1)
