# 1420. 生成数组

| 题目信息 | 内容 |
|---|---|
| 难度 | 困难 |
| 核心模式 | 动态规划：按"当前最大值 + 前缀最大值更新次数"计数，前缀和优化转移 |
| 时间复杂度 | O(n·m·k) |
| 空间复杂度 | O(m·k) |

## 题目与约束

给定三个整数 `n`、`m` 和 `k`。考虑用下面的算法找出正整数数组中最大的元素：

```
maximum = -1
search_cost = 0
for i 从 0 到 n-1:
    如果 maximum < arr[i]:
        maximum = arr[i]
        search_cost = search_cost + 1
返回 maximum 的下标
```

也就是说，从左往右扫描数组，维护当前遇到的最大值（初始为 `-1`），每当遇到一个**严格大于**当前最大值的元素，就更新最大值并把 `search_cost` 加一。`search_cost` 即数组的**严格前缀最大值**个数（第一个元素必然计入一次）。

请你构建一个具有以下属性的数组 `arr`：

- `arr` 中包含确切的 `n` 个整数。
- `1 <= arr[i] <= m`，其中 `0 <= i < n`。
- 将上面提到的算法应用于 `arr` 之后，`search_cost` 的值等于 `k`。

返回在满足上述条件的情况下构建数组 `arr` 的 **方法数量**。由于答案可能会很大，所以 **必须** 对 `10^9 + 7` 取余。

**示例 1：**

```
输入：n = 2, m = 3, k = 1
输出：6
解释：可能的数组分别为 [1, 1], [2, 1], [2, 2], [3, 1], [3, 2], [3, 3]
```

**示例 2：**

```
输入：n = 5, m = 2, k = 3
输出：0
解释：没有数组可以满足上述条件
```

**示例 3：**

```
输入：n = 9, m = 1, k = 1
输出：1
解释：唯一可能的数组是 [1, 1, 1, 1, 1, 1, 1, 1, 1]
```

**提示：**

- `1 <= n <= 50`
- `1 <= m <= 100`
- `0 <= k <= n`

## 核心不变量

> `dp[i][j][c]` 表示长度为 `i`、当前最大值为 `j`、`search_cost` 恰为 `c` 的数组个数；`search_cost` 只在"新元素严格大于此前最大值"时加一。

## 完整推导

### 思路推导

1. **把"cost"落到状态里**：`search_cost` 只在遇到**新的严格最大值**时 +1，所以它天然适合放进 DP 的维度。我们关心的状态是"已经填了 `i` 个数、当前最大值是 `j`、已经更新了 `c` 次"，记为 `dp[i][j][c]`。

2. **怎么转移（考虑第 `i` 个数放什么）**：
   - 若第 `i` 个数 `v <= j`（不刷新最大值，共 `j` 种取法）：状态从 `dp[i-1][j][c]` 转移来，`cost` 不变，贡献 `dp[i-1][j][c] * j`。
   - 若第 `i` 个数 `v == j` 且此前的最大值 `j' < j`（刷新最大值到 `j`，`cost` +1）：把上一轮所有 `j' < j` 的 `dp[i-1][j'][c-1]` 求和，作为贡献。

   即：
   ```
   dp[i][j][c] = dp[i-1][j][c] * j  +  sum_{j' < j} dp[i-1][j'][c-1]
   ```

3. **前缀和优化**：后半段是"对 `j'` 的前缀和"，预处理 `prefix[j][c] = sum_{t=1..j} dp[i-1][t][c]`，就能 `O(1)` 取出，总复杂度 `O(n·m·k)`。

4. **初值与答案**：长度 1 时，`dp[1][j][1] = 1`（每个 `j ∈ [1, m]`，最大值就是 `j`，cost 为 1）。最终答案为 `sum_{j=1..m} dp[n][j][k]`。若 `k == 0` 或 `k > m`，直接无解返回 0（cost 至少为 1，且每次更新最大值都严格增大，最多只能增大 `m` 次）。

   验证 `n=2, m=3, k=1`：`dp[2][j][1] = dp[1][j][1]*j = j`，答案 `1+2+3 = 6`。✓

### Java 实现（三维 DP + 前缀和）

```java
class Solution {
    public int numOfArrays(int n, int m, int k) {
        final int MOD = 1_000_000_007;
        // cost 至少为 1；每次更新都让最大值严格变大，故最多 m 次
        if (k == 0 || k > n || k > m) {
            return 0;
        }

        // dp[j][c]：当前长度下，最大值为 j、cost 为 c 的方案数
        long[][] dp = new long[m + 1][k + 1];
        // 长度为 1 的初始状态
        for (int j = 1; j <= m; j++) {
            dp[j][1] = 1;
        }

        for (int i = 2; i <= n; i++) {
            // 预处理前缀和 prefix[j][c] = sum_{t=1..j} dp[t][c]
            long[][] prefix = new long[m + 1][k + 1];
            for (int c = 1; c <= k; c++) {
                for (int j = 1; j <= m; j++) {
                    prefix[j][c] = (prefix[j - 1][c] + dp[j][c]) % MOD;
                }
            }

            long[][] ndp = new long[m + 1][k + 1];
            for (int j = 1; j <= m; j++) {
                for (int c = 1; c <= k; c++) {
                    // 情况一：第 i 个数取 1..j，不刷新最大值
                    long val = dp[j][c] * j % MOD;
                    // 情况二：第 i 个数取 j，前一状态最大值 < j，cost 由 c-1 变 c
                    if (c >= 2) {
                        val = (val + prefix[j - 1][c - 1]) % MOD;
                    }
                    ndp[j][c] = val;
                }
            }
            dp = ndp;
        }

        long ans = 0;
        for (int j = 1; j <= m; j++) {
            ans = (ans + dp[j][k]) % MOD;
        }
        return (int) ans;
    }
}
```

### 复杂度

- 时间：`O(n·m·k)`。外层枚举长度 `i`（`n`），内层枚举最大值 `j`（`m`）与 cost `c`（`k`），每次转移 `O(1)`。
- 空间：`O(m·k)`。只保留上一轮 `dp` 和一个前缀和数组，均为 `(m+1)×(k+1)`。

### 易错点与扩展（面试高频考点）

1. **"严格大于"而非"大于等于"**：只有新元素严格大于此前最大值才使 `cost+1`；取等号时不算新纪录，应归入"不刷新"分支。
2. **情况一乘的是 `j` 不是 `m`**：不刷新最大值时，第 `i` 位只能取 `1..j` 共 `j` 种；写成 `m` 会把更大的数也算进来导致状态错乱。
3. **初值 `k==0` 的处理**：长度 1 的数组 `cost` 必为 1，所以 `k==0` 时答案 0；`k>m` 也不可能（最多更新 `m` 次）。
4. **取模时机**：加法和乘法后都要 `% MOD`，用 `long` 承接乘法避免 `int` 溢出。
5. **空间优化扩展**：由于 `dp[i]` 只依赖 `dp[i-1]`，可滚动数组；也可进一步用二维前缀和/组合数学（第二类斯特林数思路）把复杂度降到 `O(n·k)` 左右，但实现更复杂。

### C++ 实现

```cpp
#include <vector>
using namespace std;

class Solution {
public:
    int numOfArrays(int n, int m, int k) {
        const long long MOD = 1000000007LL;
        if (k == 0 || k > n || k > m) {
            return 0;
        }

        // dp[j][c]
        vector<vector<long long>> dp(m + 1, vector<long long>(k + 1, 0));
        for (int j = 1; j <= m; j++) {
            dp[j][1] = 1;
        }

        for (int i = 2; i <= n; i++) {
            // 前缀和
            vector<vector<long long>> prefix(m + 1, vector<long long>(k + 1, 0));
            for (int c = 1; c <= k; c++) {
                for (int j = 1; j <= m; j++) {
                    prefix[j][c] = (prefix[j - 1][c] + dp[j][c]) % MOD;
                }
            }

            vector<vector<long long>> ndp(m + 1, vector<long long>(k + 1, 0));
            for (int j = 1; j <= m; j++) {
                for (int c = 1; c <= k; c++) {
                    long long val = dp[j][c] * j % MOD;
                    if (c >= 2) {
                        val = (val + prefix[j - 1][c - 1]) % MOD;
                    }
                    ndp[j][c] = val;
                }
            }
            dp.swap(ndp);
        }

        long long ans = 0;
        for (int j = 1; j <= m; j++) {
            ans = (ans + dp[j][k]) % MOD;
        }
        return (int) ans;
    }
};
```

### Python 实现

```python
class Solution:
    def numOfArrays(self, n: int, m: int, k: int) -> int:
        MOD = 10**9 + 7
        if k == 0 or k > n or k > m:
            return 0

        # dp[j][c]
        dp = [[0] * (k + 1) for _ in range(m + 1)]
        for j in range(1, m + 1):
            dp[j][1] = 1

        for _ in range(2, n + 1):
            # prefix[j][c] = sum_{t=1..j} dp[t][c]
            prefix = [[0] * (k + 1) for _ in range(m + 1)]
            for c in range(1, k + 1):
                for j in range(1, m + 1):
                    prefix[j][c] = (prefix[j - 1][c] + dp[j][c]) % MOD

            ndp = [[0] * (k + 1) for _ in range(m + 1)]
            for j in range(1, m + 1):
                for c in range(1, k + 1):
                    val = dp[j][c] * j % MOD
                    if c >= 2:
                        val = (val + prefix[j - 1][c - 1]) % MOD
                    ndp[j][c] = val
            dp = ndp

        return sum(dp[j][k] for j in range(1, m + 1)) % MOD
```
