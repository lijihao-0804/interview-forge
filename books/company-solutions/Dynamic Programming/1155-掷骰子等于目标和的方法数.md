# 1155. 掷骰子等于目标和的方法数

| 题目信息 | 内容 |
|---|---|
| 难度 | 中等 |
| 核心模式 | 计数型 DP：逐个骰子枚举面值，累加凑出目标和的方案数 |
| 时间复杂度 | O(n·k·target) |
| 空间复杂度 | O(target) |

## 题目与约束

这里有 `n` 个一样的骰子，每个骰子上都有 `k` 个面，分别标号为 `1` 到 `k` 。

给定三个整数 `n`、`k` 和 `target`，请返回投掷骰子的所有可能得到的结果（共有 `kn` 种方式），使得骰子面朝上的数字总和等于 `target`。

由于答案可能很大，你需要对 `109 + 7` 取模。

 

示例 1：

```
<strong>输入：</strong>n = 1, k = 6, target = 3
<strong>输出：</strong>1
<strong>解释：</strong>你掷了一个有 6 个面的骰子。
得到总和为 3 的结果的方式只有一种。
```

示例 2：

```
<strong>输入：</strong>n = 2, k = 6, target = 7
<strong>输出：</strong>6
<strong>解释：</strong>你掷了两个骰子，每个骰子有 6 个面。
有 6 种方式得到总和为 7 的结果: 1+6, 2+5, 3+4, 4+3, 5+2, 6+1。
```

示例 3：

```
<strong>输入：</strong>n = 30, k = 30, target = 500
<strong>输出：</strong>222616187
<strong>解释：</strong>返回的结果必须对 10<sup>9</sup> + 7 取模。
```

 

提示：

- `1 <= n, k <= 30`

- `1 <= target <= 1000`

[🔗 前往力扣原题验证 →](https://leetcode.cn/problems/number-of-dice-rolls-with-target-sum/)

## 核心不变量

> `dp[s]` 表示“已经投完当前这些骰子、点数和恰为 `s` 的方案数”；每加入一个新骰子，就枚举它朝上的面 `f`，把 `dp[s-f]` 累加到新的第 `s` 位。

## 完整推导

### 思路推导

1. **直觉与痛点（“方案数”而非“是否存在”）**

   这和“能否凑出目标和”不同，我们要数的是**有多少种不同的投掷结果**。如果暴力枚举 `k^n` 种组合，`n=k=30` 时是天文本。注意到每一轮的决策只依赖“前面骰子已经凑出多少点”，这就是典型的可重叠子问题。

2. **破局思路（按骰子逐个转移）**

   设 `dp[s]` 为“当前已投的这些骰子，和为 `s` 的方案数”。初始时一颗骰子都没投，唯一的和是 `0`，方案数记 `dp[0] = 1`。

   每多投一颗骰子，就枚举这颗骰子朝上的面 `f ∈ [1, k]`：一颗新骰子让总和的增量是 `f`，所以新的 `dp[s]` 要累加上“投之前就已经凑出 `s - f`”的所有方案，即

   ```
   new_dp[s] = Σ_{f=1..k} dp[s - f]   (要求 s - f >= 0)
   ```

   以 `n=2, k=6, target=7` 为例：投完第一颗后 `dp[1..6] = 1`。投第二颗时，`new_dp[7] = dp[6]+dp[5]+dp[4]+dp[3]+dp[2]+dp[1] = 6`，正好对应 `1+6,2+5,…,6+1` 六种组合。

3. **关键追问（为什么可以用一维滚动）**

   计算第 `i` 颗骰子的状态只用到第 `i-1` 颗的 `dp`，与更早的层无关。因此用一个一维数组即可，每轮新建一个 `next` 承接，算完再替换 `dp`，空间降到 `O(target)`。

4. **边界**：若 `target > n·k`（全掷最大也凑不到）或 `target < n`（每颗至少 1 点），`dp[target]` 自然为 `0`，无需特判。

### Java 实现（计数 DP + 滚动数组）

```java
class Solution {
    public int numRollsToTarget(int n, int k, int target) {
        final int MOD = 1_000_000_007;
        // dp[s]：投完当前这些骰子后，点数和为 s 的方案数
        int[] dp = new int[target + 1];
        dp[0] = 1; // 一颗都没投时，和为 0 有 1 种方案

        for (int dice = 1; dice <= n; dice++) {
            int[] next = new int[target + 1];
            for (int s = 1; s <= target; s++) {
                long sum = 0;
                // 枚举这一颗骰子朝上的面 f
                for (int f = 1; f <= k && f <= s; f++) {
                    sum += dp[s - f];
                }
                next[s] = (int) (sum % MOD);
            }
            dp = next; // 滚动到下一颗
        }
        return dp[target];
    }
}
```

### 复杂度

- 时间：`O(n·k·target)`。共 `n` 颗骰子，每颗枚举 `target` 个和、每个和枚举 `k` 个面值。
- 空间：`O(target)`。只用当前层与下一层两个长度 `target+1` 的数组滚动。

### 易错点与扩展（面试高频考点）

1. **取模时机**：累加可能超过 `int`，用 `long` 暂存后再 `% MOD`，不要在中途丢失精度，也不要忘记最后一步取模。
2. **面值上界 `f <= s`**：当 `s < k` 时，超过 `s` 的面值会让下标 `s-f` 为负，必须用 `f <= s` 限制。
3. **必须新建 `next` 再替换**：若直接原地更新 `dp[s]`，同一颗骰子会被重复使用，语义变成“无限个骰子”。
4. **`target > n·k` 自然得 0**：DP 状态不会越过合法范围，无需特判即可返回 0。
5. **扩展优化**：内层求和本质是滑动窗口（连续 `k` 项之和），用前缀和可把单次转移降到 `O(1)`，总复杂度 `O(n·target)`，在 `target` 更大时很有用。

## 力扣原题

[1155. 掷骰子等于目标和的方法数](https://leetcode.cn/problems/number-of-dice-rolls-with-target-sum/)

### C++ 实现

```cpp
#include <vector>
using namespace std;

class Solution {
public:
    int numRollsToTarget(int n, int k, int target) {
        const int MOD = 1'000'000'007;
        vector<int> dp(target + 1, 0);
        dp[0] = 1;

        for (int dice = 1; dice <= n; ++dice) {
            vector<int> next(target + 1, 0);
            for (int s = 1; s <= target; ++s) {
                long long sum = 0;
                for (int f = 1; f <= k && f <= s; ++f) {
                    sum += dp[s - f];
                }
                next[s] = static_cast<int>(sum % MOD);
            }
            dp.swap(next);
        }
        return dp[target];
    }
};
```

### Python 实现

```python
class Solution:
    def numRollsToTarget(self, n: int, k: int, target: int) -> int:
        MOD = 10 ** 9 + 7
        # dp[s]：投完当前这些骰子后，点数和为 s 的方案数
        dp = [0] * (target + 1)
        dp[0] = 1

        for _ in range(n):
            nxt = [0] * (target + 1)
            for s in range(1, target + 1):
                total = 0
                for f in range(1, min(k, s) + 1):
                    total += dp[s - f]
                nxt[s] = total % MOD
            dp = nxt

        return dp[target]
```
