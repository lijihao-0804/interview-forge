836. 矩形重叠

本题学习状态正在读取学习记录…下次复习：—
本次复习：
按 M 快速切换薄弱标记
遮住推导与代码，先自己想，再逐段揭示
难度简单核心模式二维投影：x 轴与 y 轴投影区间同时有正长度交集时间复杂度O(1)空间复杂度O(1)

题目与约束

矩形以列表 [x1, y1, x2, y2] 的形式表示，其中 (x1, y1) 为左下角的坐标，(x2, y2) 是右上角的坐标。矩形的上下边平行于 x 轴，左右边平行于 y 轴。

如果相交的面积为 正 ，则称两矩形重叠。需要明确的是，只在角或边接触的两个矩形不构成重叠。

给出两个矩形 rec1 和 rec2 。如果它们重叠，返回 true；否则，返回 false 。

示例 1：

输入： rec1 = [0,0,2,2], rec2 = [1,1,3,3]

输出： true

解释：

两个矩形在由 (1,1)、(2,1)、(1,2) 和 (2,2) 四个顶点围成的区域内重叠。

该区域的面积大于零，因此两个矩形重叠。

示例 2：

输入： rec1 = [0,0,1,1], rec2 = [1,0,2,1]

输出： false

解释：

两个矩形共用 x = 1 处的竖直边，但它们没有任何公共的内部区域。

由于它们的交集面积为零，因此两个矩形不重叠。

示例 3：

输入： rec1 = [0,0,1,1], rec2 = [2,2,3,3]

输出： false

解释：

两个矩形完全分离。矩形 rec1 在 x = 1 和 y = 1 处结束，而矩形 rec2 从 x = 2 和 y = 2 处开始。

因此，它们没有任何公共点，也就不存在重叠。

提示：

  • rec1.length == 4

  • rec2.length == 4

  • -109 <= rec1[i], rec2[i] <= 109

  • rec1 和 rec2 表示一个面积不为零的有效矩形

核心不变量

两个轴平行矩形重叠（面积为正）当且仅当它们在 x 轴上的投影区间和 y 轴上的投影区间都「严格」相交。

思路推导

  1. 降维：二维重叠 = 两个一维投影同时重叠

轴平行矩形的交集仍是轴平行矩形，其宽 = x 投影交集长度，其高 = y 投影交集长度。面积 = 宽 × 高 > 0，当且仅当宽 > 0 且高 > 0 同时成立。于是问题拆成两个独立的一维区间重叠判断。

  1. 一维区间严格重叠的判据

区间 [a1, a2] 与 [b1, b2] 有正长度交集，等价于 a1 < b2 且 b1 < a2。这里用严格小于，正好排除「只贴边/贴角」的情形（此时交集长度为 0）。

  1. 把 rec 数组代进去

rec1 的 x 范围是 [rec1[0], rec1[2]]、y 范围是 [rec1[1], rec1[3]]；rec2 同理。于是：

x 重叠: rec1[0] < rec2[2] && rec2[0] < rec1[2] y 重叠: rec1[1] < rec2[3] && rec2[1] < rec1[3] 两者同时为真即重叠。

  1. 小例子（示例 2）

x 方向：0 < 2 且 1 < 1？后一个为假（1 < 1 不成立），说明 x 投影只接触不重叠，整体返回 false，符合示例。

Java 实现（isRectangleOverlap）

class Solution {
    public boolean isRectangleOverlap(int[] rec1, int[] rec2) {
        // x 轴投影必须有正长度交集，才可能面积为正
        boolean overlapX = rec1[0] < rec2[2] && rec2[0] < rec1[2];
        // y 轴投影同理
        boolean overlapY = rec1[1] < rec2[3] && rec2[1] < rec1[3];
        return overlapX && overlapY;
    }
}

C++ 实现

class Solution {
public:
    bool isRectangleOverlap(vector<int>& rec1, vector<int>& rec2) {
        bool overlapX = rec1[0] < rec2[2] && rec2[0] < rec1[2];
        bool overlapY = rec1[1] < rec2[3] && rec2[1] < rec1[3];
        return overlapX && overlapY;
    }
};

Python 实现

class Solution:
    def isRectangleOverlap(self, rec1: list[int], rec2: list[int]) -> bool:
        overlap_x = rec1[0] < rec2[2] and rec2[0] < rec1[2]
        overlap_y = rec1[1] < rec2[3] and rec2[1] < rec1[3]
        return overlap_x and overlap_y

复杂度

  • 时间：O(1)。只做几次比较。
  • 空间：O(1)。无额外存储。
易错点与扩展（面试高频考点）
  1. 严格小于 vs 小于等于：题目要求「只在角或边接触不算重叠」，所以必须用 <，不能用 <=，否则示例 2 会被误判为 true。
  2. 别写成「包含关系」：有人会分别判断「一个矩形完全包含另一个」，这不覆盖「交叉重叠但不包含」的情况。
  3. 坐标范围：绝对值可达 10⁹，但这里只做大小比较、不做加减乘法，不会溢出 int。
  4. 换一种等价写法：不重叠 = 一个在另一个的左侧/右侧/上方/下方，最后取反；两种写法等价，但正向投影法更不易写错边界。
  5. 扩展：多矩形求交集面积通常用「扫描线 + 线段树」，本题只是两矩形特例，直接投影比较即可。
