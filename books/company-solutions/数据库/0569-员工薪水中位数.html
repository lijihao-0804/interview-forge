题目与约束

表：Employee

+--------------+---------+
| Column Name  | Type    |
+--------------+---------+
| id           | int     |
| company      | varchar |
| salary       | int     |
+--------------+---------+

id 是这张表的主键（具有唯一值的列）。该表的每一行表示一个员工所属的公司以及他的薪水。

编写一个解决方案，找出每家公司 薪水中位数 对应的那些行。

在计算中位数时，如果一家公司的员工人数为偶数，则中位数为中间两个薪水的平均值。结果需要返回中位数工资对应的 原始员工行（包含 id、company、salary 三列）。结果表可按任意顺序返回。

示例 1：

输入：
Employee 表:
+----+---------+--------+
| id | company | salary |
+----+---------+--------+
| 1  | A       | 2341   |
| 2  | A       | 341    |
| 3  | A       | 15     |
| 4  | A       | 15314  |
| 5  | A       | 451    |
| 6  | A       | 513    |
| 7  | B       | 15     |
| 8  | B       | 13     |
| 9  | B       | 1154   |
| 10 | B       | 1345   |
| 11 | B       | 1221   |
| 12 | B       | 234    |
| 13 | C       | 2345   |
| 14 | C       | 2645   |
| 15 | C       | 2645   |
| 16 | C       | 2645   |
| 17 | C       | 65     |
+----+---------+--------+

输出：
+----+---------+--------+
| id | company | salary |
+----+---------+--------+
| 5  | A       | 451    |
| 6  | A       | 513    |
| 12 | B       | 234    |
| 9  | B       | 1154   |
| 14 | C       | 2645   |
+----+---------+--------+

说明：

  • A 公司 6 人，中间两个薪水是 451、513（对应 id 5、6），因此输出这两行；
  • B 公司 6 人，中间两个薪水是 234、1154（对应 id 12、9）；
  • C 公司 5 人，中位名次是第 3 名，薪水 2645（对应 id 14），只输出一行。

提示：

  • 每家公司至少有一名员工。
  • 薪水相同的行按 id 升序确定名次，以保证结果稳定（这是对 SQL 中同薪并列次序的一个明确约定）。
  • 结果表可按任意顺序返回，本题实现统一按 id 升序输出以便对照。

核心不变量

把每家公司员工按薪水排序后，中位数就落在第 ⌊(cnt+1)/2⌋ 与 ⌈(cnt+1)/2⌉ 名：cnt 为偶数时是两行，奇数时两名重合为一行——取这些名次对应的原始行即为答案。

完整推导

思路推导

  1. 把“中位数”翻译成“名次”

中位数的位置只和人数有关。设某公司人数为 cnt： - cnt 为奇数，中位数是第 (cnt+1)/2 名（唯一）； - cnt 为偶数，中位数区间是第 cnt/2 与 cnt/2+1 名（两行都要返回，公式 (cnt+1)/2 向下、(cnt+2)/2 向下正好得到这两个名次）。

于是问题变成：在每家公司内部按薪水排名，挑出中位名次的那一（几）行。

  1. SQL 的标准解法（窗口函数）

在真实数据库里，用 ROW_NUMBER() 按公司分组、按薪水升序排名，再用 COUNT(*) 得到每家公司人数，筛出中位名次即可：

sql SELECT id, company, salary FROM ( SELECT id, company, salary, ROW_NUMBER() OVER (PARTITION BY company ORDER BY salary) AS rn, COUNT(*) OVER (PARTITION BY company) AS cnt FROM Employee ) t WHERE rn IN (FLOOR((cnt + 1) / 2), CEIL((cnt + 1) / 2));

没有窗口函数的旧版本可用自连接统计“比它小的行数”来定位名次，思路一致。

  1. 本题的等价实现

为了满足三种通用语言的可运行实现，下面的 Java / C++ / Python 都直接对内存中的员工记录做“分组 + 排序 + 取中位名次”，得到的行与上述 SQL 完全一致（同薪时按 id 升序，保证与示例输出吻合）。

  1. 小例子（C 公司）

C 公司 5 人：2345, 2645, 2645, 2645, 65。按薪水升序（同薪按 id）为 65(id17), 2345(id13), 2645(id14), 2645(id15), 2645(id16)。cnt=5，中位名次为第 3 名 → id=14，只输出一行。

Java 实现（medianSalary）

import java.util.*;

class Solution {
    // 员工记录：id、公司、薪水
    static class Employee {
        int id;
        String company;
        int salary;
        Employee(int id, String company, int salary) {
            this.id = id;
            this.company = company;
            this.salary = salary;
        }
    }

    public List<String[]> medianSalary(List<Employee> employees) {
        // 1. 按公司分组
        Map<String, List<Employee>> groups = new LinkedHashMap<>();
        for (Employee e : employees) {
            groups.computeIfAbsent(e.company, k -> new ArrayList<>()).add(e);
        }

        List<String[]> res = new ArrayList<>();
        for (List<Employee> g : groups.values()) {
            // 2. 组内按薪水升序、id 升序排名（id 用于同薪时稳定次序）
            g.sort(Comparator.comparingInt((Employee e) -> e.salary)
                             .thenComparingInt(e -> e.id));
            int cnt = g.size();
            int lo = (cnt + 1) / 2; // 下中位名次（1-based）
            int hi = (cnt + 2) / 2; // 上中位名次（1-based），奇数时与 lo 相同
            TreeSet<Integer> ranks = new TreeSet<>();
            ranks.add(lo);
            ranks.add(hi);
            // 3. 取中位名次对应的原始行
            for (int r : ranks) {
                Employee e = g.get(r - 1);
                res.add(new String[]{
                        String.valueOf(e.id), e.company, String.valueOf(e.salary)
                });
            }
        }
        return res;
    }
}

复杂度

  • 时间：O(n log n)，主要开销是对每家公司内部排序；所有公司规模之和为 n，各组 O(k log k) 求和不超过 O(n log n)。
  • 空间：O(n)，分组存储所有员工记录，另需排序的临时空间。

易错点与扩展（面试高频考点）

  1. 奇偶名次公式：lo = (cnt+1)/2、hi = (cnt+2)/2（整除向下取整）可同时覆盖奇偶两种情况；宁可写通用公式，也别分两套容易写错的分支。
  2. 同薪并列的名次：真实 SQL 里 ORDER BY salary 对相同薪水次序不保证，返回哪个 id 可能不同；本题用 id 升序作为稳定次序以复现示例。
  3. 偶数取两行而非平均成一个数：题目要求返回“中位数对应的原始行”，偶数时两行都要给出；切勿把两个中间薪水求平均后当成结果。
  4. 别用 DENSE_RANK 混淆：ROW_NUMBER（唯一名次）、RANK（并列跳号）、DENSE_RANK（并列不跳号）含义不同，中位数定位应使用 ROW_NUMBER 或对并列有明确约定的排名方式。
  5. 扩展：若只要求每家公司“中位数薪水值”，可用 COUNT + 自连接或 PERCENTILE_CONT(0.5)；若要求“每个部门中位数”，把 PARTITION BY company 换成部门列即可，框架完全复用。

力扣原题

C++ 实现

#include <vector>
#include <string>
#include <map>
#include <set>
#include <algorithm>
using namespace std;

struct Employee {
    int id;
    string company;
    int salary;
};

class Solution {
public:
    vector<vector<string>> medianSalary(vector<Employee>& employees) {
        // 1. 按公司分组
        map<string, vector<Employee>> groups;
        for (const auto& e : employees) {
            groups[e.company].push_back(e);
        }

        vector<vector<string>> res;
        for (auto& kv : groups) {
            auto& g = kv.second;
            // 2. 组内按薪水升序、id 升序排名
            sort(g.begin(), g.end(), [](const Employee& a, const Employee& b) {
                if (a.salary != b.salary) return a.salary < b.salary;
                return a.id < b.id;
            });
            int cnt = (int)g.size();
            int lo = (cnt + 1) / 2; // 下中位名次（1-based）
            int hi = (cnt + 2) / 2; // 上中位名次（1-based）
            set<int> ranks = {lo, hi};
            // 3. 取中位名次对应的原始行
            for (int r : ranks) {
                const Employee& e = g[r - 1];
                res.push_back({to_string(e.id), e.company, to_string(e.salary)});
            }
        }
        return res;
    }
};

Python 实现

from collections import defaultdict

class Solution:
    def medianSalary(self, employees):
        # 1. 按公司分组（employees 中每个元素是 dict：id/company/salary）
        groups = defaultdict(list)
        for e in employees:
            groups[e["company"]].append(e)

        res = []
        for company, g in groups.items():
            # 2. 组内按薪水升序、id 升序排名
            g.sort(key=lambda e: (e["salary"], e["id"]))
            cnt = len(g)
            lo = (cnt + 1) // 2   # 下中位名次（1-based）
            hi = (cnt + 2) // 2   # 上中位名次（1-based），奇数时与 lo 相同
            # 3. 取中位名次对应的原始行
            for r in sorted({lo, hi}):
                e = g[r - 1]
                res.append([e["id"], e["company"], e["salary"]])
        return res
