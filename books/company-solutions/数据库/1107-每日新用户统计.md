# 1107. 每日新用户统计

| 题目信息 | 内容 |
|---|---|
| 难度 | 中等 |
| 核心模式 | 每个用户取最早登录日期 + 按日期分组计数（窗口过滤 90 天） |
| 时间复杂度 | O(n log n) |
| 空间复杂度 | O(n) |

## 题目与约束



[🔗 前往力扣原题验证 →](https://leetcode.cn/problems/new-users-daily-count/)

## 核心不变量

> 一个用户对答案的贡献，只由他在窗口内的"最早登录日期"决定——同一用户其它日期的登录记录一律忽略，且每个用户最多贡献一次。

## 完整推导

### 思路推导

1. **先"去重"到"首次登录"**

   题目的关键是"首次登录"。对每个用户，只需要在所有 `activity = 'login'` 的记录里取 `MIN(activity_date)`，这就是他的首次登录日期；`logout / jobs / groups / homepage` 等记录完全无关。

2. **再用"窗口"过滤**

   只有 `2019-04-01 <= 首次登录日期 <= 2019-06-30` 的用户才进入统计（`2019-06-30` 往前 90 天正好是 `2019-04-01`）。像用户 3、用户 5 的首次登录都早于窗口，直接丢弃；用户 5 在 `2019-06-21` 虽然有 login，但不是首次，也不计。

3. **最后按日期分组计数**

   把保留下来的"首次登录日期"做一次 `GROUP BY login_date` + `COUNT(*)`，即得每天的新用户数。

4. **标准 SQL 解法**

   ```sql
   SELECT login_date, COUNT(*) AS user_count
   FROM (
       SELECT user_id, MIN(activity_date) AS login_date
       FROM Traffic
       WHERE activity = 'login'
       GROUP BY user_id
   ) t
   WHERE login_date >= DATE_SUB('2019-06-30', INTERVAL 90 DAY)
     AND login_date <= '2019-06-30'
   GROUP BY login_date
   ORDER BY login_date;
   ```

   本题数据接口未提供可直接运行的 SQL 环境，为满足三种通用语言的可运行实现，下面的 Java / C++ / Python 都在内存记录上逐条模拟上述"取最早登录 → 窗口过滤 → 按日期计数"的三段逻辑，结果与上述 SQL 完全一致。

### Java 实现（dailyNewUsers）

```java
import java.time.LocalDate;
import java.util.*;

class Solution {
    // 一条访问记录：用户、行为、日期（形如 "2019-06-21"）
    static class Record {
        int userId;
        String activity;
        String activityDate;
        Record(int userId, String activity, String activityDate) {
            this.userId = userId;
            this.activity = activity;
            this.activityDate = activityDate;
        }
    }

    public List<String[]> dailyNewUsers(List<Record> traffic) {
        // 1. 求每个用户的最早登录日期（只关心 activity == "login"）
        Map<Integer, String> firstLogin = new HashMap<>();
        for (Record r : traffic) {
            if (!"login".equals(r.activity)) {
                continue;
            }
            String cur = firstLogin.get(r.userId);
            if (cur == null || r.activityDate.compareTo(cur) < 0) {
                firstLogin.put(r.userId, r.activityDate);
            }
        }

        // 2. 只保留 [today-90, today] 内的首次登录，并按日期聚合
        LocalDate today = LocalDate.parse("2019-06-30");
        LocalDate lower = today.minusDays(90);          // 2019-04-01
        Map<String, Integer> count = new TreeMap<>();   // TreeMap：按日期升序
        for (String d : firstLogin.values()) {
            LocalDate date = LocalDate.parse(d);
            if (!date.isBefore(lower) && !date.isAfter(today)) {
                count.merge(d, 1, Integer::sum);
            }
        }

        // 3. 输出 (login_date, user_count)
        List<String[]> res = new ArrayList<>();
        for (Map.Entry<String, Integer> e : count.entrySet()) {
            res.add(new String[]{e.getKey(), String.valueOf(e.getValue())});
        }
        return res;
    }
}
```

### 复杂度

- 时间：O(n log n)。第一遍遍历 O(n)；对不同用户的最早登录日期排序/计数为 O(u log u)（`u` 为不同用户数，`u <= n`），`TreeMap` 的插入同样是 O(log u)。若只要求任意顺序，可用哈希表把这一步降到期望 O(n)。
- 空间：O(n)。需要保存每个用户的最早登录日期以及按日期的计数。

### 易错点与扩展（面试高频考点）

1. **别把"登录次数"当成"新用户数"**：同一用户当天多次 `login` 只能算一次；必须先按用户取 `MIN(activity_date)` 去重，这一步是整题的灵魂。

2. **窗口边界与开闭**：`2019-06-30` 往前 90 天是 `2019-04-01`，边界含等号；`2019-03-01` 这种早于下界的首次登录必须排除，否则会多算。

3. **只统计 `activity = 'login'`**：`logout / homepage` 等信息完全无关，忘记加 `WHERE activity = 'login'` 会把错误的日期当首次活动。

4. **日期比较**：ISO 格式 `yyyy-MM-dd` 可以用字符串字典序直接比较（C++ 实现即利用这一点），无需额外解析；但若格式不统一，务必先规整成同一格式。

5. **扩展**：若要统计"每日活跃用户数（DAU）"，则不取 `MIN`，而是按 `(user_id, activity_date)` 去重后计数；若要"留存率"，则以首次登录日为起点按天数差分组。核心都是先想清楚"每个用户只贡献什么"。

## 力扣原题

### C++ 实现

```cpp
#include <vector>
#include <string>
#include <map>
#include <unordered_map>
using namespace std;

struct Record {
    int userId;
    string activity;
    string activityDate; // 形如 "2019-06-21"
};

class Solution {
public:
    vector<vector<string>> dailyNewUsers(vector<Record>& traffic) {
        // 1. 每个用户的最早登录日期（ISO 日期字典序即时间序）
        unordered_map<int, string> firstLogin;
        for (const auto& r : traffic) {
            if (r.activity != "login") continue;
            auto it = firstLogin.find(r.userId);
            if (it == firstLogin.end() || r.activityDate < it->second) {
                firstLogin[r.userId] = r.activityDate;
            }
        }

        // 2. 窗口 [2019-04-01, 2019-06-30]，按日期聚合（map 保证升序）
        const string today = "2019-06-30";
        const string lower = "2019-04-01";
        map<string, int> count;
        for (const auto& kv : firstLogin) {
            const string& d = kv.second;
            if (d >= lower && d <= today) {
                count[d]++;
            }
        }

        // 3. 输出 (login_date, user_count)
        vector<vector<string>> res;
        for (const auto& kv : count) {
            res.push_back({kv.first, to_string(kv.second)});
        }
        return res;
    }
};
```

### Python 实现

```python
from datetime import date, timedelta
from collections import defaultdict

class Solution:
    def dailyNewUsers(self, traffic):
        # traffic：每个元素是 dict，含 user_id / activity / activity_date(形如 "2019-06-21")
        # 1. 每个用户的最早登录日期
        first_login = {}
        for r in traffic:
            if r["activity"] != "login":
                continue
            uid = r["user_id"]
            d = r["activity_date"]
            if uid not in first_login or d < first_login[uid]:
                first_login[uid] = d

        # 2. 只统计 [today-90, today] 内的首次登录，按日期聚合
        today = date(2019, 6, 30)
        lower = today - timedelta(days=90)  # 2019-04-01
        count = defaultdict(int)
        for d in first_login.values():
            dd = date.fromisoformat(d)
            if lower <= dd <= today:
                count[d] += 1

        # 3. 按日期升序输出 (login_date, user_count)
        return [[d, count[d]] for d in sorted(count)]
```
