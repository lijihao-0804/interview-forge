题目与约束

给你一个非负整数 x，计算并返回 x 的算术平方根。

由于返回类型是整数，结果只保留整数部分，小数部分将被舍去。

注意： 不允许使用任何内置指数函数和算符，例如 pow(x, 0.5) 或者 x ** 0.5。

示例 1：

输入：x = 4
输出：2

示例 2：

输入：x = 8
输出：2
解释：8 的算术平方根是 2.82842...，由于返回类型是整数，小数部分将被舍去。

提示：

  • 0 <= x <= 2^31 - 1

核心不变量

答案 ans 是满足 ans² <= x 的最大整数；在 [0, x] 上二分，mid² <= x 就向右收缩并记录 mid，否则向左收缩。

完整推导

思路推导

  1. 直觉与痛点（为什么能二分）

函数 f(m) = m² 在非负整数上单调递增。我们要找"最大的、平方不超过 x 的整数"，这正是一个有序空间上的边界查找，天然可以用二分。

  1. 破局思路（在值域上二分答案）

令 l = 0, r = x，每次取中点 mid = l + (r - l) / 2：

  • 若 mid² <= x，说明 mid 是候选答案，先记下 ans = mid，然后往右半区继续找更大的（l = mid + 1）；
  • 若 mid² > x，说明 mid 太大，往左半区收缩（r = mid - 1）。

循环结束 ans 就是满足条件的最大整数。

以 x = 8 为例：l=0,r=8，mid=4，16>8 → r=3；mid=1，1<=8 → ans=1,l=2；mid=2，4<=8 → ans=2,l=3；mid=3，9>8 → r=2 结束。ans = 2，正确。

  1. 关键追问（mid * mid 会不会溢出？）

会！x 最大到 2^31 - 1，mid 也可能接近 46340 的量级但若直接 int * int，某次 mid 接近 x 时会溢出成负数，导致判断错误。因此要用更宽的类型（Java long、C++ long long）做乘法。

  1. 易错点提示
  • 必须用 long（或 long long）计算 mid * mid。
  • 用 l + (r - l) / 2 而不是 (l + r) / 2 防止加法溢出。
  • 边界 x = 0 时能正确返回 0。

Java 实现（二分查找）

class Solution {
    public int mySqrt(int x) {
        int l = 0, r = x, ans = 0;
        while (l <= r) {
            int mid = l + (r - l) / 2;          // 防溢出写法
            if ((long) mid * mid <= x) {        // 用 long 防乘法溢出
                ans = mid;                      // mid 是可行解，先记录
                l = mid + 1;                    // 尝试更大的
            } else {
                r = mid - 1;                    // 太大，收缩右界
            }
        }
        return ans;
    }
}

复杂度

  • 时间：O(log x)，二分区间 [0, x]，每轮折半。
  • 空间：O(1)，只用常数个整型变量。

易错点与扩展（面试高频考点）

  1. 乘法溢出：mid * mid 在 int 下会溢出，务必强转 long / long long。
  2. 中点写法：l + (r - l) / 2 比 (l + r) / 2 更安全。
  3. 返回的是下取整：要找 mid² <= x 的最大 mid，因此可行时要继续往右试探，而不是立即返回。
  4. 面试追问——牛顿迭代法：ans = (ans + x / ans) / 2 反复迭代，收敛极快（二次收敛），可作 O(log x) 的替代方案，注意用整数除法并处理收敛条件 ans * ans > x。
  5. 面试追问——要求精确到小数位：在二分时把 r 取为浮点或引入 eps，返回浮点结果即可，框架不变。

69. x 的平方根

C++ 实现

class Solution {
public:
    int mySqrt(int x) {
        int l = 0, r = x, ans = 0;
        while (l <= r) {
            int mid = l + (r - l) / 2;
            if ((long long)mid * mid <= x) { // long long 防溢出
                ans = mid;
                l = mid + 1;
            } else {
                r = mid - 1;
            }
        }
        return ans;
    }
};

Python 实现

class Solution:
    def mySqrt(self, x: int) -> int:
        l, r, ans = 0, x, 0
        while l <= r:
            mid = l + (r - l) // 2
            if mid * mid <= x:   # Python 大整数不会溢出
                ans = mid
                l = mid + 1
            else:
                r = mid - 1
        return ans
