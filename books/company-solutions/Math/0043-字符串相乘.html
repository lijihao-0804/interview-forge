43. 字符串相乘

难度中等核心模式竖式乘法 + 数组暂存进位时间复杂度O(m·n)空间复杂度O(m+n)

题目与约束

给定两个以字符串形式表示的非负整数 num1 和 num2，返回 num1 和 num2 的乘积，它们的乘积也表示为字符串形式。

注意：不能使用任何内置的 BigInteger 库或直接将输入转换为整数。

示例 1:

输入: num1 = "2", num2 = "3"
输出: "6"

示例 2:

输入: num1 = "123", num2 = "456"
输出: "56088"

提示：

  • 1 <= num1.length, num2.length <= 200

  • num1 和 num2 只能由数字组成。

  • num1 和 num2 都不包含任何前导零，除了数字0本身。

🔗 前往力扣原题验证 →

核心不变量

长度分别为 m、n 的两个数相乘，结果最多 m+n 位；num1[i] 与 num2[j] 的乘积最终落在结果数组的 i+j（进位位）与 i+j+1（本位）上。

完整推导

思路推导

  1. 直觉与痛点（为什么不能直接乘？）

题目明确禁止 BigInteger、也禁止把字符串直接转成整数。num1、num2 长度可达 200 位，即便用 64 位整型也装不下。因此只能回到小学竖式乘法的思路，一位一位地算、一位一位地存。

  1. 破局思路（把每一位的乘积塞进数组）

设 num1 长 m、num2 长 n，开一个长度 m+n 的整型数组 res 暂存结果的每一位。从右往左枚举 i、j，计算 mul = num1[i] * num2[j]。这个 mul 应该加到数组的哪一格？答案是 i+j+1（本位），若超过 9 则把十位数进到 i+j（高位）。例如 "123" × "456"，num1[2]=3、num2[2]=6 的乘积落在下标 2+2+1=5。

  1. 关键追问（进位怎么处理才不乱？）

注意 res[i+j+1] 里可能已经有之前累积的值，所以不能直接赋值，要先做 sum = mul + res[p2]，再令 res[p2] = sum % 10、res[p1] += sum / 10。这样每一位都不超过 9，进位则叠加到高位，天然形成正确竖式。最后从左到右跳过前导零拼成字符串即可。

Java 实现（multiply）

class Solution {
    public String multiply(String num1, String num2) {
        // 任一因子为 0，结果直接为 "0"
        if (num1.equals("0") || num2.equals("0")) {
            return "0";
        }
        int m = num1.length(), n = num2.length();
        // 结果最多 m + n 位
        int[] res = new int[m + n];

        for (int i = m - 1; i >= 0; i--) {
            for (int j = n - 1; j >= 0; j--) {
                int mul = (num1.charAt(i) - '0') * (num2.charAt(j) - '0');
                int p1 = i + j;      // 进位位
                int p2 = i + j + 1;  // 本位
                int sum = mul + res[p2];
                res[p2] = sum % 10;  // 本位保留个位
                res[p1] += sum / 10; // 十位进到高位
            }
        }

        // 跳过高位可能残留的前导零
        StringBuilder sb = new StringBuilder();
        for (int d : res) {
            if (sb.length() == 0 && d == 0) {
                continue;
            }
            sb.append(d);
        }
        return sb.length() == 0 ? "0" : sb.toString();
    }
}

C++ 实现

#include <string>
#include <vector>

class Solution {
public:
    string multiply(string num1, string num2) {
        if (num1 == "0" || num2 == "0") return "0";
        int m = num1.size(), n = num2.size();
        vector<int> res(m + n, 0);

        for (int i = m - 1; i >= 0; --i) {
            for (int j = n - 1; j >= 0; --j) {
                int mul = (num1[i] - '0') * (num2[j] - '0');
                int p1 = i + j, p2 = i + j + 1;
                int sum = mul + res[p2];
                res[p2] = sum % 10;
                res[p1] += sum / 10;
            }
        }

        string sb;
        for (int d : res) {
            if (sb.empty() && d == 0) continue;
            sb.push_back(char('0' + d));
        }
        return sb.empty() ? "0" : sb;
    }
};

Python 实现

class Solution:
    def multiply(self, num1: str, num2: str) -> str:
        if num1 == "0" or num2 == "0":
            return "0"
        m, n = len(num1), len(num2)
        res = [0] * (m + n)

        for i in range(m - 1, -1, -1):
            for j in range(n - 1, -1, -1):
                mul = (ord(num1[i]) - ord('0')) * (ord(num2[j]) - ord('0'))
                p1, p2 = i + j, i + j + 1
                total = mul + res[p2]
                res[p2] = total % 10
                res[p1] += total // 10

        # 去掉前导零
        idx = 0
        while idx < len(res) and res[idx] == 0:
            idx += 1
        return "".join(map(str, res[idx:]))

复杂度

  • 时间：O(m·n)，两层循环分别枚举 num1、num2 的每一位，每一次做 O(1) 的乘加取余。
  • 空间：O(m+n)，结果数组长度为 m+n（不含返回字符串所需的输出空间）。
易错点与扩展（面试高频考点）
  1. 下标映射别写反：本位是 i+j+1、进位是 i+j，写反会在长数相乘时整体错位。
  2. 进位必须累加而非赋值：res[p1] += sum / 10，因为高位可能已有之前 j 轮留下的进位；写成 = 会丢进位。
  3. 零的特殊处理："0" × "123" 若不提前返回会得到空串或 "000"，需在开头特判或用「跳过前导零 + 全零兜底」处理。
  4. 不能转整数：面试官会以「200 位」为由来卡 long，问的就是竖式本质，答「转 long 再转回」会被判不合格。
  5. 扩展：若要求支持负数或小数，只需额外记录符号位、统计小数位数，再对纯数字部分套用本模板，最后补回小数点。
