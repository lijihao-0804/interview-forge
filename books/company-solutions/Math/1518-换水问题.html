题目与约束

超市正在促销，你可以用 numExchange 个空水瓶从超市兑换一瓶水。最开始，你一共购入了 numBottles 瓶水。

如果喝掉了水瓶中的水，那么水瓶就会变成空的。

给你两个整数 numBottles 和 numExchange，返回你最多可以喝到多少瓶水。

示例 1：

输入：numBottles = 9, numExchange = 3
输出：13
解释：你可以用 3 个空瓶兑换 1 瓶水。
所以最多能喝到 9 + 3 + 1 = 13 瓶水。

示例 2：

输入：numBottles = 15, numExchange = 4
输出：19
解释：你可以用 4 个空瓶兑换 1 瓶水。
所以最多能喝到 15 + 3 + 1 = 19 瓶水。

提示：

  • 1 <= numBottles <= 100
  • 2 <= numExchange <= 100

核心不变量

每轮兑换后，空瓶数变为「本次兑换剩余的空瓶（余数）+ 新兑换并喝掉产生的空瓶（商）」，总喝到的瓶数持续累加，直到空瓶数不足以再兑换。

完整推导

思路推导

  1. 直觉（把过程一步步模拟）：初始买了 numBottles 瓶，喝完全部变成空瓶，所以「已喝瓶数」和「空瓶数」一开始都是 numBottles。

  2. 每轮兑换：只要空瓶数 empty >= numExchange，就能兑换。兑换得到的水瓶数 newBottles = empty / numExchange，喝掉后它们又变成空瓶；同时 empty % numExchange 是这次没凑够一份、留下来的空瓶。于是更新： - total += newBottles - empty = empty % numExchange + newBottles

  3. 终止条件：当 empty < numExchange 时无法再兑换，循环结束，返回 total。

  4. 小例子：numBottles = 9, numExchange = 3。 - 初始 total = 9, empty = 9。 - 第一轮 new = 3, total = 12, empty = 0 + 3 = 3。 - 第二轮 new = 1, total = 13, empty = 0 + 1 = 1。 - 1 < 3 结束，返回 13。

Java 实现（numWaterBottles）

class Solution {
    public int numWaterBottles(int numBottles, int numExchange) {
        int total = numBottles;   // 已经喝到的瓶数
        int empty = numBottles;   // 当前手里的空瓶数

        while (empty >= numExchange) {
            int newBottles = empty / numExchange;      // 本轮兑换到的新水
            total += newBottles;
            // 剩余没凑够一份的空瓶 + 新喝出的空瓶
            empty = empty % numExchange + newBottles;
        }
        return total;
    }
}

复杂度

  • 时间：O(log_{numExchange} numBottles)。每轮空瓶数大约缩小为原来的 1/numExchange，对数级收敛。
  • 空间：O(1)，只用常数个变量。

易错点与扩展（面试高频考点）

  1. 空瓶更新别只写 empty / numExchange：必须加上余数 empty % numExchange，否则会丢掉没兑换掉的空瓶。
  2. 初始值别写错：total 与 empty 都应初始化为 numBottles，因为一开始买的全部会喝掉。
  3. 循环条件用 >=：恰好等于 numExchange 时仍可兑换一瓶。
  4. 数学公式法（扩展）：本题等价于「每换一瓶净消耗 numExchange - 1 个空瓶」，答案可写成 numBottles + (numBottles - 1) / (numExchange - 1)，可作为 O(1) 解法在面试中炫技。
  5. 边界：numExchange = 2 时最激进，空瓶几乎全都能再换，结果接近 2 * numBottles - 1。

C++ 实现

class Solution {
public:
    int numWaterBottles(int numBottles, int numExchange) {
        int total = numBottles;   // 已经喝到的瓶数
        int empty = numBottles;   // 当前空瓶数
        while (empty >= numExchange) {
            int newBottles = empty / numExchange;
            total += newBottles;
            empty = empty % numExchange + newBottles;
        }
        return total;
    }
};
