题目与约束

给你一个整数 x ，如果 x 是一个回文整数，返回 true ；否则，返回 false 。

回文数是指正序（从左向右）和倒序（从右向左）读都是一样的整数。

  • 例如，121 是回文，而 123 不是。

示例 1：

<strong>输入：</strong>x = 121
<strong>输出：</strong>true

示例 2：

<strong>输入：</strong>x = -121
<strong>输出：</strong>false
<strong>解释：</strong>从左向右读, 为 -121 。 从右向左读, 为 121- 。因此它不是一个回文数。

示例 3：

<strong>输入：</strong>x = 10
<strong>输出：</strong>false
<strong>解释：</strong>从右向左读, 为 01 。因此它不是一个回文数。

提示：

  • -231 <= x <= 231 - 1

进阶：你能不将整数转为字符串来解决这个问题吗？

🔗 前往力扣原题验证 →

核心不变量

把数字从中间劈成两半，后半段反转之后必然等于前半段；若是奇数位，反转后的后半段多出中间一位，去掉它再比较即可。

思路推导

  1. 直觉与痛点（双指针反转字符串）

最直接的做法是把整数变成字符串，用左右双指针向中间夹逼，一旦发现不相等就返回 false。这能过，但使用了 O(n) 额外空间，而进阶要求正是"不转字符串"。

  1. 破局思路（只反转一半，边反转边缩小原数）

关键洞察：判断回文不需要把整个数反转，只要比较前后两半就行。于是可以这样：不断用 % 10 取出原数 x 的末位，拼到 reverted 上（reverted = reverted * 10 + x % 10），同时 x /= 10。

由于 x 在不断变短、reverted 在不断变长，当 reverted >= x 时说明后半段已经追上甚至超过了前半段，此时停止。

以 x = 1221 为例：reverted = 1, x = 122 → reverted = 12, x = 12，此时 reverted >= x（12 ≥ 12），停止；比较 x == reverted（12 == 12）成立，是回文。

  1. 关键追问（奇数位和特殊值怎么办？）
  • 奇数位：如 12321，停止时 x = 12、reverted = 123，多了一位中间数 3。此时比较 x == reverted / 10（12 == 12）即可。
  • 负数：直接 false，因为负号反转后会跑到末尾（-121 → 121-）。
  • 末位是 0 且本身非 0：如 10，回文数的最高位不可能是 0，直接 false。这一步既能提前剪枝，也避免 x=0 被误判。

Java 实现（isPalindrome）

class Solution {
    public boolean isPalindrome(int x) {
        // 负数不可能是回文；末位为 0 且本身非 0 的数（如 10）也不是
        if (x < 0 || (x % 10 == 0 && x != 0)) {
            return false;
        }

        int reverted = 0;
        // 只反转一半：当反转部分追上或超过剩余部分时停止
        while (x > reverted) {
            reverted = reverted * 10 + x % 10;
            x /= 10;
        }

        // 偶数位：两半相等；奇数位：reverted 多一位中间数，去掉它再比
        return x == reverted || x == reverted / 10;
    }
}

复杂度

  • 时间：O(log₁₀x)，只处理了数字的一半位数。
  • 空间：O(1)，只用常数个整型变量。

易错点与扩展（面试高频考点）

  1. 负数一律 false：-121 反转得到 121-，不是回文。
  2. x = 10 的特判：末尾为 0 而本身非 0 的数不可能回文，需用 x % 10 == 0 && x != 0 单独排除，否则 x=0 会被误伤。
  3. 反转一半而非全部：全反转在 x 接近 INT_MAX 时可能溢出，反转一半天然规避。
  4. 奇数位的处理：比较时别忘了 reverted / 10 去掉中间那位。
  5. 面试延展：可以先讲字符串双指针 O(n) 空间版本，再优化到 O(1) 空间的数学版本，体现思路演进。
