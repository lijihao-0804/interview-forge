# 415. 字符串相加

| 题目信息 | 内容 |
|---|---|
| 难度 | 简单 |
| 核心模式 | 双指针从后往前模拟竖式加法（逐位相加 + 进位） |
| 时间复杂度 | O(max(m, n)) |
| 空间复杂度 | O(1)（不计返回值占用的结果串） |

## 题目与约束

给定两个字符串形式的非负整数 `num1` 和`num2` ，计算它们的和并同样以字符串形式返回。

你不能使用任何內建的用于处理大整数的库（比如 `BigInteger`）， 也不能直接将输入的字符串转换为整数形式。

 

示例 1：

输入：num1 = "11", num2 = "123"  
输出："134"

示例 2：

输入：num1 = "456", num2 = "77"  
输出："533"

示例 3：

输入：num1 = "0", num2 = "0"  
输出："0"

 

 

提示：

- `1 <= num1.length, num2.length <= 104`

- `num1` 和`num2` 都只包含数字 `0-9`

- `num1` 和`num2` 都不包含任何前导零

[🔗 前往力扣原题验证 →](https://leetcode.cn/problems/add-strings/)

## 核心不变量

> 两个指针分别指向两串末尾，逐位相加时把进位 `carry` 带入下一位；某串越界后按 0 参与运算。

## 完整推导

### 思路推导

1. **直觉（为什么要从后往前）**

   竖式加法就是"从个位开始加，逢十进一"。字符串的最低位在末尾，所以用两个指针 `i`、`j` 分别指向 `num1`、`num2` 的最后一个字符，向高位推进。

2. **补零规则（长度不等怎么办）**

   当某个指针已经越过开头（`i < 0` 或 `j < 0`），就把这一位当作 0。这样两数长度不同也不用手动对齐。

3. **进位处理（关键）**

   每一位计算 `sum = a + b + carry`：当前位结果是 `sum % 10`，新的进位是 `sum / 10`。循环条件要一直走到 `i`、`j` 都耗尽**且进位为 0**，否则最高位产生的进位会丢失。

4. **小例子（"456" + "77"）**

   - `6+7=13` → 写 `3`，进位 `1`
   - `5+7+1=13` → 写 `3`，进位 `1`
   - `4+0+1=5` → 写 `5`，进位 `0`
   - 结果为逆序收集的 `3,3,5`，翻转得 `"533"`

### Java 实现（addStrings）

```java
class Solution {
    public String addStrings(String num1, String num2) {
        StringBuilder sb = new StringBuilder();
        int i = num1.length() - 1;
        int j = num2.length() - 1;
        int carry = 0;

        // 只要还有位没处理，或还有进位，就继续
        while (i >= 0 || j >= 0 || carry != 0) {
            // 越界位按 0 处理，字符转数字要减去 '0'
            int a = i >= 0 ? num1.charAt(i) - '0' : 0;
            int b = j >= 0 ? num2.charAt(j) - '0' : 0;
            int sum = a + b + carry;

            sb.append(sum % 10);   // 当前位的数字
            carry = sum / 10;      // 进位留给下一位
            i--;
            j--;
        }
        // 上面是从低位往高位追加，最后需要翻转
        return sb.reverse().toString();
    }
}
```

### 复杂度

- 时间：O(max(m, n))，`m`、`n` 为两串长度，最长的那串每个字符处理一次，额外再翻转一次结果串。
- 空间：O(1)，除却保存返回结果所需的 `StringBuilder` 外，只用常数个整型变量。

### 易错点与扩展（面试高频考点）

1. **字符转数字**：一定要 `charAt(i) - '0'`，直接强转 `(int)` 得到的是 ASCII 码，答案会离谱。
2. **循环条件漏写 `carry != 0`**：如 `"9" + "1"`，若少了进位判断会输出 `"0"` 而不是 `"10"`。
3. **两串长度不等**：忘记用三元表达式补 0，就会数组越界或逻辑错乱。
4. **结果顺序**：低位先追加，最终必须 `reverse`；也可改用 `insert(0, c)`，但那样是 O(n²)。
5. **不能偷懒转整数**：长度可达 10^4 位，`Integer.parseInt` / `long` 都会溢出，这正是题目禁止转整数的原因。扩展问法还能顺带考"字符串相乘"（第 43 题）。

### C++ 实现

```cpp
class Solution {
public:
    string addStrings(string num1, string num2) {
        string res;
        int i = (int)num1.size() - 1;
        int j = (int)num2.size() - 1;
        int carry = 0;

        while (i >= 0 || j >= 0 || carry) {
            int a = i >= 0 ? num1[i] - '0' : 0;
            int b = j >= 0 ? num2[j] - '0' : 0;
            int sum = a + b + carry;

            res.push_back(char('0' + sum % 10));
            carry = sum / 10;
            --i;
            --j;
        }
        // 低位先追加，需要倒过来
        reverse(res.begin(), res.end());
        return res;
    }
};
```

### Python 实现

```python
class Solution:
    def addStrings(self, num1: str, num2: str) -> str:
        i, j = len(num1) - 1, len(num2) - 1
        carry = 0
        res = []

        while i >= 0 or j >= 0 or carry:
            a = int(num1[i]) if i >= 0 else 0
            b = int(num2[j]) if j >= 0 else 0
            total = a + b + carry

            res.append(str(total % 10))
            carry = total // 10
            i -= 1
            j -= 1

        # res 里是低位在前，翻转拼接
        return "".join(reversed(res))
```
