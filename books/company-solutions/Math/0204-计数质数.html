题目与约束

给定整数 n ，返回 所有小于非负整数 n 的质数的数量 。

示例 1：

输入：n = 10
输出：4
解释：小于 10 的质数一共有 4 个, 它们是 2, 3, 5, 7 。

示例 2：

输入：n = 0
输出：0

示例 3：

输入：n = 1
输出：0

提示：

  • 0 <= n <= 5 * 106

🔗 前往力扣原题验证 →

核心不变量

筛法进行到任意时刻，isComposite 中已被标记的数一定是合数；每当我们遇到一个尚未被标记的数 i，它必然是质数，于是把它所有从 i*i 起的倍数都标记为合数。

完整推导

思路推导

  1. 直觉与痛点（逐个试除太慢）

判断每个数是否为质数，最直接是对每个数试除到 √x，总体约 O(n√n)，当 n = 5×10^6 时严重超时。

  1. 破局思路（用质数去筛掉合数）

换个角度：与其「逐个判断」，不如「一次性划掉」。开一个长度为 n 的布尔数组 isComposite，初始全为 false。从 2 开始遍历，遇到一个未被标记的数 i，它就是质数；然后把 i 的所有倍数 2i, 3i, ... 标记为合数。

  1. 关键优化（从 i*i 开始筛）

i 的倍数中，2i, 3i, ..., (i-1)i 这些更小的倍数，早已被比 i 小的质因子筛掉了，无需重复。所以只需从 i*i 开始标记。这也意味着当 i*i >= n 时无需再筛，循环可以只处理到 i < n（内层条件判断 i*i < n）。

  1. 小例子验证

n = 10：i=2 是质数，标记 4,6,8；i=3 是质数，标记 9；i=4 已标记跳过；i=5 质数，但 5*5=25 >= 10 不再筛；i=6,7,8,9 依此类推。质数为 2,3,5,7，共 4 个，与示例一致。

Java 实现（countPrimes）

class Solution {
    public int countPrimes(int n) {
        if (n < 3) {
            return 0; // 0、1、2 之前没有质数
        }
        // isComposite[i] == true 表示 i 是合数
        boolean[] isComposite = new boolean[n];
        int count = 0;
        for (int i = 2; i < n; i++) {
            if (!isComposite[i]) {
                count++; // i 是质数
                // 从 i*i 开始标记，用 long 防止 i*i 溢出
                if ((long) i * i < n) {
                    for (long j = (long) i * i; j < n; j += i) {
                        isComposite[(int) j] = true;
                    }
                }
            }
        }
        return count;
    }
}

复杂度

  • 时间：O(n log log n)。每个质数 p 标记约 n/p 个倍数，求和 Σ n/p（p 为质数）约为 n log log n，是筛法的经典复杂度。
  • 空间：O(n)。需要一个长度为 n 的布尔数组。

易错点与扩展（面试高频考点）

  1. i*i 溢出：int 下 i*i 在 i 接近 46341 时会溢出为负数，导致内层循环错误。必须用 long 计算 i*i 再和 n 比较。
  2. 边界 n < 3：n = 0,1,2 时都返回 0（小于 2 没有质数）。n = 2 时 new boolean[2] 合法、循环不进入、返回 0 也正确，因此提前返回只是剪枝、不影响正确性。
  3. 从 2 倍数开始筛也没错但更慢：从 2i 开始会重复标记已筛过的数，虽然结果正确但常数更大；从 i*i 起是标准优化。
  4. 标记整段而非逐个 if：核心是「用质数划掉倍数」而非「逐个数判断质数」，这是筛法区别于试除法的本质。
  5. 扩展（线性筛 / 欧拉筛）：可做到严格 O(n)：维护质数表，对每个数 i 用它和已知质数逐个相乘来标记，且一旦 i % p == 0 就停，保证每个合数只被它的最小质因子筛一次。面试中可作为筛法的进阶亮点。

C++ 实现

class Solution {
public:
    int countPrimes(int n) {
        if (n < 3) return 0;
        vector<bool> isComposite(n, false);
        int count = 0;
        for (int i = 2; i < n; ++i) {
            if (!isComposite[i]) {
                ++count;
                if ((long long)i * i < n) {
                    for (long long j = (long long)i * i; j < n; j += i) {
                        isComposite[j] = true;
                    }
                }
            }
        }
        return count;
    }
};

Python 实现

class Solution:
    def countPrimes(self, n: int) -> int:
        if n < 3:
            return 0
        is_composite = [False] * n
        count = 0
        for i in range(2, n):
            if not is_composite[i]:
                count += 1
                if i * i < n:
                    for j in range(i * i, n, i):
                        is_composite[j] = True
        return count
