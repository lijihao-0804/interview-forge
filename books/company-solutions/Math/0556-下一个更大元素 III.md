# 556. 下一个更大元素 III

| 题目信息 | 内容 |
|---|---|
| 难度 | 中等 |
| 核心模式 | 数字转字符数组后求下一个排列 |
| 时间复杂度 | O(m) |
| 空间复杂度 | O(m) |

## 题目与约束

给你一个正整数 `n` ，请你找出符合条件的最小整数，其由重新排列 `n` 中存在的每位数字组成，并且其值大于 `n` 。如果不存在这样的正整数，则返回 `-1` 。

注意 ，返回的整数应当是一个 32 位整数 ，如果存在满足题意的答案，但不是 32 位整数 ，同样返回 `-1` 。

 

示例 1：

输入：n = 12  
输出：21

示例 2：

输入：n = 21  
输出：-1

 

提示：

- `1 <= n <= 231 - 1`

[🔗 前往力扣原题验证 →](https://leetcode.cn/problems/next-greater-element-iii/)

## 核心不变量

> 「用同样数字重排得到的最小更大数」等价于这串数字的 **下一个字典序排列**，即经典 next permutation 问题。

## 完整推导

### 思路推导

1. **转化问题**：把整数 `n` 拆成数字字符串（如 `n = 12` → `"12"`）。要求「由相同数字重排、且比原数更大的最小整数」，这正是求这串数字的 **下一个排列**。

2. **定位可提升位**：从右往左找第一对满足 `a[i] < a[i+1]` 的位置 `i`。这说明 `i` 右侧是一个「从右向左递增、即下降」的序列，已经无法靠调整后缀变得更大，必须提升 `a[i]`。若找不到这样的 `i`（整个串非递增，如 `21`），说明已是最大排列，返回 `-1`。

3. **交换与翻转**：在 `i` 右侧从右往左找第一个 `a[j] > a[i]` 的数字（它是最小的、能放在 `i` 位的更大数字），交换 `a[i]` 与 `a[j]`。此时后缀仍是降序，为了让整体最小，把 `i+1` 到末尾的后缀 **反转成升序**，即得下一个排列。

   示例 `n = 12`：`i = 0`（`1 < 2`），右侧 `j = 1`，交换得 `21`，后缀单元素无需反转，答案 `21`。
   示例 `n = 21`：不存在 `a[i] < a[i+1]`，返回 `-1`。

4. **32 位校验**：重排后可能超过 `int` 上限（如 `2147483647` 附近），用 `long`/`long long` 承接，超过 `2^31 - 1` 则返回 `-1`。

### Java 实现（next permutation）

```java
class Solution {
    public int nextGreaterElement(int n) {
        char[] a = String.valueOf(n).toCharArray();
        int m = a.length;

        // 1. 从右往左找第一个 a[i] < a[i+1]
        int i = m - 2;
        while (i >= 0 && a[i] >= a[i + 1]) {
            i--;
        }
        if (i < 0) {
            return -1;               // 已是最大排列，无解
        }

        // 2. 在右侧从右往左找第一个大于 a[i] 的数字
        int j = m - 1;
        while (a[j] <= a[i]) {
            j--;
        }
        swap(a, i, j);

        // 3. 反转 i+1 之后的后缀，使其升序（整体尽可能小）
        for (int l = i + 1, r = m - 1; l < r; l++, r--) {
            swap(a, l, r);
        }

        // 4. 用 long 承接，溢出 32 位则返回 -1
        long val = Long.parseLong(new String(a));
        return val > Integer.MAX_VALUE ? -1 : (int) val;
    }

    private void swap(char[] a, int i, int j) {
        char t = a[i];
        a[i] = a[j];
        a[j] = t;
    }
}
```

### 复杂度

- 时间：O(m)，`m` 为数字位数（最多 10 位），三次线性扫描 + 一次反转。
- 空间：O(m)，字符数组与字符串副本。

### 易错点与扩展（面试高频考点）

1. **找 `i` 用 `>=` 而非 `>`**：`while (i >= 0 && a[i] >= a[i+1])`，遇到相等要继续左移，否则会在重复数字上出错。
2. **找 `j` 用 `<=`**：`while (a[j] <= a[i])`，必须严格大于才能构成更大数。
3. **后缀要反转不是排序**：交换后 `i+1` 之后必然是降序，反转即升序，`O(m)`；用排序也无妨但更慢。
4. **越界返回 `-1`**：答案超过 `2147483647` 时返回 `-1`，务必先转 `long` 再判断，避免 `int` 溢出。
5. **举一反三**：同源题 31「下一个排列」直接操作数组；本题只是把它套在整数的数字上，并加了 32 位边界。

### C++ 实现

```cpp
class Solution {
public:
    int nextGreaterElement(int n) {
        string a = to_string(n);
        int m = a.size();

        // 1. 从右往左找第一个 a[i] < a[i+1]
        int i = m - 2;
        while (i >= 0 && a[i] >= a[i + 1]) i--;
        if (i < 0) return -1;                 // 已是最大排列

        // 2. 右侧从右往左找第一个大于 a[i] 的数字
        int j = m - 1;
        while (a[j] <= a[i]) j--;
        swap(a[i], a[j]);

        // 3. 反转后缀，使其升序
        reverse(a.begin() + i + 1, a.end());

        // 4. 溢出 32 位返回 -1
        long long val = stoll(a);
        return val > INT_MAX ? -1 : (int)val;
    }
};
```

### Python 实现

```python
class Solution:
    def nextGreaterElement(self, n: int) -> int:
        a = list(str(n))
        m = len(a)

        # 1. 从右往左找第一个 a[i] < a[i+1]
        i = m - 2
        while i >= 0 and a[i] >= a[i + 1]:
            i -= 1
        if i < 0:
            return -1                          # 已是最大排列

        # 2. 右侧从右往左找第一个大于 a[i] 的数字
        j = m - 1
        while a[j] <= a[i]:
            j -= 1
        a[i], a[j] = a[j], a[i]

        # 3. 反转后缀，使其升序
        a[i + 1:] = reversed(a[i + 1:])

        # 4. 溢出 32 位返回 -1
        val = int(''.join(a))
        return val if val <= 2 ** 31 - 1 else -1
```
