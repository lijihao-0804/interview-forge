# 258. 各位相加

| 题目信息 | 内容 |
|---|---|
| 难度 | 简单 |
| 核心模式 | 数学规律（数根） |
| 时间复杂度 | O(1) |
| 空间复杂度 | O(1) |

## 题目与约束

给定一个非负整数 `num`，反复将各个位上的数字相加，直到结果为一位数。返回这个结果。

**示例 1：**

```
输入: num = 38
输出: 2
解释: 各位相加的过程为：
38 --> 3 + 8 --> 11
11 --> 1 + 1 --> 2
由于 2 是一位数，所以返回 2。
```

**示例 2：**

```
输入: num = 0
输出: 0
```

**提示：**

- `0 <= num <= 2^31 - 1`

**进阶：** 你可以不使用循环或者递归，在 `O(1)` 时间复杂度内解决这个问题吗？

## 核心不变量

> 反复各位相加得到的一位数就是"数根"：`num == 0` 时为 `0`，否则等于 `1 + (num - 1) % 9`（即对 9 取模、把结果映射到 1..9）。

## 完整推导

### 思路推导

1. **朴素模拟**

   循环地把 `num` 的每一位拆出来求和，直到结果小于 10。时间 O(log num)，空间 O(1)。这是最容易想到的写法。

2. **发现同余规律**

   任意整数与它各位数字之和对 `9` 同余：因为 `10 ≡ 1 (mod 9)`，所以 `10^k ≡ 1 (mod 9)`，展开十进制就得到两者模 9 相同。反复相加不改变这个余数，最终的一位数（数根）满足相同的模 9 余数。

3. **处理 0 与"整除 9"的边界**

   如果直接取 `num % 9`，9 的倍数会得到 `0`，但数根应为 `9`。所以对正数用 `(num - 1) % 9 + 1`，它把结果规整地映射到 `1..9`；`num == 0` 单独返回 `0`。

4. **小例子**

   `38`：`(38-1) % 9 + 1 = 37 % 9 + 1 = 1 + 1 = 2` ✓。`18`：`(18-1) % 9 + 1 = 17 % 9 + 1 = 8 + 1 = 9` ✓。

### Java 实现（数学公式 / 数根）

```java
class Solution {
    public int addDigits(int num) {
        // 0 是唯一的例外，数根为 0
        if (num == 0) {
            return 0;
        }
        // 正数的数根落在 1..9，等价于反复各位相加的结果
        return 1 + (num - 1) % 9;
    }
}
```

### 复杂度

- 时间：O(1)。只做一次取模与加法运算。
- 空间：O(1)。只用常数个变量。

### 易错点与扩展（面试高频考点）

1. **漏判 `num == 0`**：`0` 的数根是 `0`，而公式 `(num-1)%9+1` 用在 0 上会算错，必须特判。
2. **误写成 `num % 9`**：这样 9、18、27 等 9 的倍数会返回 `0`，而正确答案是 `9`。
3. **公式记忆**：`(num - 1) % 9 + 1` 是"把 0..8 的结果映射到 1..9"的标准技巧。
4. **模拟法也要会写**：若面试官要求先写朴素解，用双重循环逐位求和同样正确，只是 O(log num)。
5. **数根的应用**：这类"同余 / 进制"技巧也常见于判断整除、循环小数、校验位等问题。

class Solution {

    int addDigits(int num) {

        return 1 + (num - 1) % 9;
    }
};
