题目与约束

给你 k 枚相同的鸡蛋，并可以使用一栋从第 1 层到第 n 层共有 n 层楼的建筑。

已知存在楼层 f ，满足 0 <= f <= n ，任何从 高于 f 的楼层落下的鸡蛋都会碎，从 f 楼层或比它低的楼层落下的鸡蛋都不会破。

每次操作，你可以取一枚没有碎的鸡蛋并把它从任一楼层 x 扔下（满足 1 <= x <= n）。如果鸡蛋碎了，你就不能再次使用它。如果某枚鸡蛋扔下后没有摔碎，则可以在之后的操作中 重复使用 这枚鸡蛋。

请你计算并返回要确定 f 确切的值 的 最小操作次数 是多少？

示例 1：

<strong>输入：</strong>k = 1, n = 2
<strong>输出：</strong>2
<strong>解释：</strong>
鸡蛋从 1 楼掉落。如果它碎了，肯定能得出 f = 0 。 
否则，鸡蛋从 2 楼掉落。如果它碎了，肯定能得出 f = 1 。 
如果它没碎，那么肯定能得出 f = 2 。 
因此，在最坏的情况下我们需要移动 2 次以确定 f 是多少。

示例 2：

<strong>输入：</strong>k = 2, n = 6
<strong>输出：</strong>3

示例 3：

<strong>输入：</strong>k = 3, n = 14
<strong>输出：</strong>4

提示：

  • 1 <= k <= 100

  • 1 <= n <= 104

核心不变量

用 i 枚鸡蛋、最多移动 j 次，能确定的最大楼层数为 dp[i][j] = dp[i-1][j-1] + dp[i][j-1] + 1；答案就是使 dp[k][j] >= n 的最小 j。

完整推导

思路推导

  1. 直觉与痛点（正着按楼层 DP）

设 dp[k][n] 为“k 枚蛋、n 层楼”的最小移动次数。第一次在楼层 x 扔： - 碎了 → 剩下 k-1 枚蛋、要查 x-1 层楼； - 没碎 → 仍是 k 枚蛋、要查上方 n-x 层楼。

于是 dp[k][n] = 1 + min over x of max(dp[k-1][x-1], dp[k][n-x])。但这需要枚举 x，复杂度 O(k·n²)，在 n = 10⁴ 时约 10¹²，必然超时。即使用二分找“碎/不碎”的交叉点优化到 O(k·n·log n)，也仍然较重。

  1. 破局思路（逆向：问“给 d 次机会能测多少层”）

把问题反过来想：用 i 枚蛋、最多 j 次移动，最多能确定多少层楼？ 记为 dp[i][j]。

我们第一次挑某层扔下去： - 碎了：这枚蛋作废，剩下 i-1 枚蛋、j-1 次机会，能覆盖下方 dp[i-1][j-1] 层； - 没碎：蛋还在，剩 j-1 次机会，能覆盖上方 dp[i][j-1] 层； - 再加上被扔的那一层本身。

所以 dp[i][j] = dp[i-1][j-1] + dp[i][j-1] + 1。只要 dp[k][j] >= n，说明 j 次移动足够，返回 j。

  1. 关键追问（怎么把二维压成一维？）

固定“步数”这一维，用一维数组 dp[i] 滚动表示“当前 j 轮下、i 枚蛋能覆盖的楼层数”。每轮更新 dp[i] = dp[i-1] + dp[i] + 1（右边两值都必须是上一轮的值），因此 i 要从大到小逆序更新，才能保证 dp[i-1] 还没被本轮覆盖。dp[0] 恒为 0（0 枚蛋测不了任何楼层）。

以 k=2 为例逐轮看 dp[2]：第 1 轮 =1，第 2 轮 =3，第 3 轮 =6，第 4 轮 =10，第 5 轮 =15……（通项恰为 C(j,1)+C(j,2)）。当 n=6 时，第 3 轮 dp[2]=6 >= 6，答案 3，与示例一致。

Java 实现（superEggDrop）

import java.util.Arrays;

class Solution {
    public int superEggDrop(int k, int n) {
        // dp[i] 表示：用 i 枚鸡蛋、在当前移动次数下，最多能确定的楼层数
        int[] dp = new int[k + 1];
        int moves = 0;
        // 只要 k 枚蛋还覆盖不到 n 层，就再给一次机会
        while (dp[k] < n) {
            moves++;
            // 逆序更新，保证 dp[i-1]、dp[i] 用的都是上一轮（moves-1）的值
            for (int i = k; i >= 1; i--) {
                dp[i] = dp[i - 1] + dp[i] + 1;
            }
        }
        return moves;
    }
}

复杂度

  • 时间：O(k·ans)，其中 ans 为最小移动次数（不超过 n），即最坏 O(k·n)。相比正向 O(k·n²) 有质的提升。
  • 空间：O(k)，只需一维长度为 k+1 的滚动数组。

易错点与扩展（面试高频考点）

  1. 方向别搞反：本题的最优解法是“逆推”——枚举步数、问能覆盖多少层，而不是“正推”枚举楼层。正向 O(k·n²) 在 n=10⁴ 下必超时，是最大的性能陷阱。
  2. 一维滚动必须逆序：dp[i] = dp[i-1] + dp[i] + 1 里依赖上一轮的 dp[i-1]，若升序更新会用到本轮新值导致答案偏大。写代码时务必 for (int i = k; i >= 1; i--)。
  3. dp[0] = 0 的语义：0 枚鸡蛋无论如何测不了任何楼层，这保证 i=1 时 dp[1] = 0 + dp[1] + 1 每轮稳定加 1（相当于线性扫描），符合“只有 1 枚蛋只能从底层往上试”的直觉。
  4. 溢出与边界：dp 值可能超过 int（理论上界约 n，本题 n ≤ 10⁴ 安全）；若泛化到大 n 需用 long 或及时截断到 n。
  5. 扩展：正向二分版本：若面试官要求写“按楼层”的 DP，可用单调性把 min over x 用二分降到 O(k·n·log n)，dp[k][n] = 1 + min_x max(dp[k-1][x-1], dp[k][n-x])，两者都要会。

C++ 实现

#include <vector>
using namespace std;

class Solution {
public:
    int superEggDrop(int k, int n) {
        vector<int> dp(k + 1, 0);   // dp[i]：i 枚蛋、当前移动次数下可确定的最大楼层数
        int moves = 0;
        while (dp[k] < n) {
            ++moves;
            // 逆序更新，保证使用的是上一轮的值
            for (int i = k; i >= 1; --i) {
                dp[i] = dp[i - 1] + dp[i] + 1;
            }
        }
        return moves;
    }
};

Python 实现

class Solution:
    def superEggDrop(self, k: int, n: int) -> int:
        # dp[i]：i 枚鸡蛋、当前移动次数下能确定的最大楼层数
        dp = [0] * (k + 1)
        moves = 0
        while dp[k] < n:
            moves += 1
            # 逆序遍历，保证 dp[i-1] 仍是上一轮的值
            for i in range(k, 0, -1):
                dp[i] = dp[i - 1] + dp[i] + 1
        return moves
