题目信息 内容
难度 中等
核心模式 统计阶乘中因子 5 的个数
时间复杂度 O(log₅ n)
空间复杂度 O(1)

题目与约束

给定一个整数 n，返回 n! 结果中尾随零的数量。

提示 n! = n * (n - 1) * (n - 2) * ... * 3 * 2 * 1

示例 1：

输入：n = 3
输出：0
解释：3! = 6 ，不含尾随 0

示例 2：

输入：n = 5
输出：1
解释：5! = 120 ，有一个尾随 0

示例 3：

输入：n = 0
输出：0

提示：

  • 0 <= n <= 10^4

进阶： 你可以设计并实现对数时间复杂度的算法来解决此问题吗？

核心不变量

末尾的每个 0 都由一对因子 2 × 5 产生；而 n! 中因子 2 的个数永远多于因子 5，所以尾随零的个数 = 因子 5 的总个数。

完整推导

思路推导

  1. 直觉与痛点（直接算阶乘行不行？）

先算出 n! 再数末尾 0，数值会迅速膨胀到几十上百位，int、long 都存不下，既溢出又慢。必须换个角度——不真正算出阶乘。

  1. 破局思路（只数因子 5）

末尾每出现一个 0，就意味着乘出了一个 10，而 10 = 2 × 5。在 1..n 的连乘里，偶数（贡献因子 2）比 5 的倍数多得多，因此因子 2 一定够用，瓶颈是因子 5。于是问题转化为：1..n 的数中一共含有多少个因子 5。

  • n / 5 统计至少含一个 5 的数（5, 10, 15, ...）；
  • 但 25、50、125…… 各含多个 5，还需再补：n / 25、n / 125……
  • 总数为 n/5 + n/25 + n/125 + ...。
  1. 关键例子（n = 25）

直接 n/5 = 5 会漏掉 25 里多出的那个 5。加上 n/25 = 1，共 5 + 1 = 6，与真实值 25! = 15511210043330985984000000（末尾 6 个 0）一致。

代码里用循环 while (n > 0) { n /= 5; count += n; } 实现，它恰好等价于上面的级数：第一次 n/5、第二次 n/25、第三次 n/125……

Java 实现（trailingZeroes）

class Solution {
    public int trailingZeroes(int n) {
        int count = 0;
        // 每除一次 5，就累加当前 n/5；等价于 n/5 + n/25 + n/125 + ...
        while (n > 0) {
            n /= 5;
            count += n;
        }
        return count;
    }
}

复杂度

  • 时间：O(log₅ n)，每轮把 n 除以 5，循环次数为 5 进制位数。
  • 空间：O(1)，只用一个计数变量。

易错点与扩展（面试高频考点）

  1. 只数 5，不数 2：因子 2 的数量必然多于 5，真正的瓶颈是 5；数 2 反而会得到错误偏大的结果。
  2. 25/125 的额外因子不能漏：只写 n/5 会漏掉 25 = 5×5、125 = 5×5×5 这类数里多出的 5。
  3. 循环写法与级数等价：n/=5; count+=n 天然实现了 n/5 + n/25 + ...，比手写多个除法更简洁。
  4. n = 0 边界：0! = 1，没有尾随零，循环不进入直接返回 0，无需特判。
  5. 数值范围：n <= 10^4，用 int 计数足够；进阶要求的"对数时间"正是本解法自带的 O(log n)。
