# 633. 平方数之和

| 题目信息 | 内容 |
|---|---|
| 难度 | 中等 |
| 核心模式 | 双指针在 [0, √c] 上向中间夹逼 |
| 时间复杂度 | O(√c) |
| 空间复杂度 | O(1) |

## 题目与约束

给定一个非负整数 `c` ，你要判断是否存在两个整数 `a` 和 `b`，使得 `a2 + b2 = c` 。

 

示例 1：

```
<strong>输入：</strong>c = 5
<strong>输出：</strong>true
<strong>解释：</strong>1 * 1 + 2 * 2 = 5
```

示例 2：

```
<strong>输入：</strong>c = 3
<strong>输出：</strong>false
```

 

提示：

- `0 <= c <= 231 - 1`

[🔗 前往力扣原题验证 →](https://leetcode.cn/problems/sum-of-square-numbers/)

## 核心不变量

> 令 `left = 0`、`right = ⌊√c⌋`：若 `left² + right² < c`，则 `left` 与任何不大于 `right` 的数都凑不够，必须让 `left` 右移；反之 `right` 左移；解始终被夹在 `[left, right]` 内。

## 完整推导

### 思路推导

1. **直觉与痛点（枚举上界）**

   因为 `a² + b² = c` 且 `a, b ≥ 0`，可知 `a`、`b` 都不会超过 `⌊√c⌋`。最朴素的做法是枚举 `a`，再用 `c - a²` 判断是否为完全平方，时间复杂度 `O(√c · log c)`；而双指针能把这个「查平方」的过程也一起省掉。

2. **破局思路（双指针夹逼）**

   令 `left = 0`、`right = ⌊√c⌋`，计算 `sum = left² + right²`：

   - `sum == c`：找到解，返回 `true`；
   - `sum < c`：和太小，`left` 右移增大和；
   - `sum > c`：和太大，`right` 左移减小和。

   当 `left > right` 仍未命中，说明不存在这样的两个整数。

3. **为什么不会漏解**

   在 `[0, √c]` 这段单调递增的平方序列上，`left` 增大使 `sum` 变大、`right` 减小使 `sum` 变小，两个方向互不重叠地收缩搜索空间，正确答案若存在必被扫到。以 `c = 5` 为例：`(0,2) → 4 < 5`，`left=1`；`(1,2) → 5 == 5`，返回 `true`。

4. **小例子（无解）**

   `c = 3`：`(0,1) → 1 < 3`，`left=1`；此时 `left > right`，循环结束返回 `false`，正确。

### Java 实现（judgeSquareSum）

```java
class Solution {
    public boolean judgeSquareSum(int c) {
        // 用 long 防止 left*left + right*right 溢出（c 可达 2^31-1）
        long left = 0;
        long right = (long) Math.sqrt(c);

        while (left <= right) {
            long sum = left * left + right * right;
            if (sum == c) {
                return true;          // 找到 a、b
            } else if (sum < c) {
                left++;               // 和太小，左端点右移
            } else {
                right--;              // 和太大，右端点左移
            }
        }
        // 夹逼结束仍未命中，说明不存在
        return false;
    }
}
```

### 复杂度

- 时间：`O(√c)`，`left` 与 `right` 指针相向移动，总步数不超过 `2√c`。
- 空间：`O(1)`，只使用了两个指针变量。

### 易错点与扩展（面试高频考点）

1. **整数溢出**：`left * left + right * right` 在 `c` 接近 `2^31-1` 时会超出 `int` 范围，必须用 `long`（C++ 用 `long long`）。
2. **上界取整**：`right = ⌊√c⌋`，用 `Math.sqrt` 后要转成整数；浮点误差一般表现为略小于真实值，可先强转再校正，Python 用 `math.isqrt` 更稳。
3. **`while (left <= right)` 而非 `<`**：`a` 与 `b` 可以相等（如 `c = 2 = 1² + 1²`、`c = 0 = 0² + 0²`），必须允许 `left == right`。
4. **`c = 0` 的边界**：`left = right = 0`，`sum = 0 == c`，返回 `true`，符合定义。
5. **扩展（数学解法）**：由费马平方和定理，`c` 能表示为两平方和当且仅当它的所有形如 `4k+3` 的质因子的指数均为偶数。可用分解质因数得到 `O(√c)` 甚至更优的判定，但双指针更直观、面试更易写对。

### C++ 实现

```cpp
class Solution {
public:
    bool judgeSquareSum(int c) {
        // long long 防止平方和溢出
        long long left = 0;
        long long right = (long long) sqrt((double) c);

        while (left <= right) {
            long long sum = left * left + right * right;
            if (sum == c) {
                return true;
            } else if (sum < c) {
                ++left;   // 和太小，左端点右移
            } else {
                --right;  // 和太大，右端点左移
            }
        }
        return false;
    }
};
```

### Python 实现

```python
import math


class Solution:
    def judgeSquareSum(self, c: int) -> bool:
        left, right = 0, math.isqrt(c)  # isqrt 精确取整，避免浮点误差

        while left <= right:
            s = left * left + right * right
            if s == c:
                return True
            elif s < c:
                left += 1   # 和太小，左端点右移
            else:
                right -= 1  # 和太大，右端点左移

        return False
```
