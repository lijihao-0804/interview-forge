题目与约束

给定一个表示整数的字符串 n ，返回与它最近的回文整数（不包括自身）。如果不止一个，返回较小的那个。

“最近的”定义为两个整数差的绝对值最小。

示例 1:

<strong>输入:</strong> n = "123"
<strong>输出:</strong> "121"

示例 2:

<strong>输入:</strong> n = "1"
<strong>输出:</strong> "0"
<strong>解释:</strong> 0 和 2是最近的回文，但我们返回最小的，也就是 0。

提示:

  • 1 <= n.length <= 18

  • n 只由数字组成

  • n 不含前导 0

  • n 代表在 [1, 1018 - 1] 范围内的整数

🔗 前往力扣原题验证 →

核心不变量

与 n 最近的回文数，一定落在「n 的前缀镜像」「前缀 ±1 的镜像」「99…9（少一位）」与「100…001（多一位）」这几类候选之中。

完整推导

思路推导

  1. 为什么不能暴力枚举

n 最大可达 10^18，逐个判断回文并计算距离不可行。必须直接“构造”出可能最近的回文。

  1. 关键观察：回文由前一半决定

长度为 L 的回文串，只要确定了前 ceil(L/2) 位（称为前缀 prefix），后面就由镜像唯一确定。例如 L=5、前缀 123 → 12321；L=4、前缀 12 → 1221。

与 n 最接近的回文，其前缀一定在 prefix-1, prefix, prefix+1 这三个值附近（再远差值只会更大）。分别镜像即可得到三个候选。

  1. 补上“位数变化”的边界

还有两类跨位数的回文可能更近： - 少一位的全 9：10^(L-1) - 1，如 n=1000 时 999 更近； - 多一位的 100…001：10^L + 1，如 n=999 时 1001 更近。

把所有候选与 n 比较，剔除等于 n 自身的那个，取差值最小者；差值相同时取数值更小的。

  1. 小例子（n = "123"）

L=3，前缀 prefix=12： - 12 → 121（差 2） - 11 → 111（差 12） - 13 → 131（差 8） - 边界：99（差 24）、1001（差 878）

最小差值是 121，输出 121。再如 n="1"：候选有 0（前缀 0）、2（前缀 2）、0（10^0-1）、11（10^1+1），差值 1 的有 0 和 2，取较小者 0。

Java 实现（nearestPalindromic）

class Solution {
    public String nearestPalindromic(String n) {
        long num = Long.parseLong(n);
        int len = n.length();
        // 前一半（向上取整）的数值
        long prefix = Long.parseLong(n.substring(0, (len + 1) / 2));
        boolean evenLen = (len % 2 == 0);

        long best = -1;
        // 候选 1：前缀 -1、前缀、前缀 +1 的镜像
        for (long p = prefix - 1; p <= prefix + 1; p++) {
            if (p < 0 || Long.toString(p).length() > (len + 1) / 2) {
                continue; // 位数变长会溢出 long，且一定不是最近回文
            }
            long cand = buildPalindrome(p, evenLen);
            if (cand == num) {
                continue; // 必须排除自身
            }
            if (best == -1
                    || Math.abs(cand - num) < Math.abs(best - num)
                    || (Math.abs(cand - num) == Math.abs(best - num) && cand < best)) {
                best = cand;
            }
        }
        // 候选 2：位数边界（少一位全 9 / 多一位 100...001）
        // len==19（n=10^18）时 pow10(19) 会溢出 long，而 20 位候选必然不是最近回文，跳过
        long[] bounds = len <= 18
                ? new long[]{ pow10(len - 1) - 1, pow10(len) + 1 }
                : new long[]{ pow10(len - 1) - 1 };
        for (long cand : bounds) {
            if (cand == num) {
                continue;
            }
            if (best == -1
                    || Math.abs(cand - num) < Math.abs(best - num)
                    || (Math.abs(cand - num) == Math.abs(best - num) && cand < best)) {
                best = cand;
            }
        }
        return Long.toString(best);
    }

    // 用前缀 p 镜像构造回文（evenLen 表示目标长度为偶数）
    private long buildPalindrome(long p, boolean evenLen) {
        String s = Long.toString(p);
        String rev = new StringBuilder(s).reverse().toString();
        String pal = evenLen ? s + rev : s + rev.substring(1);
        return Long.parseLong(pal);
    }

    // 计算 10^e（e >= 0）
    private long pow10(int e) {
        long r = 1;
        while (e-- > 0) {
            r *= 10;
        }
        return r;
    }
}

复杂度

  • 时间：O(L)，L 为数字位数（≤18）。构造、镜像、比较都只做常数次长度 O(L) 的操作。
  • 空间：O(L)，用于存放前缀、镜像字符串等。

易错点与扩展（面试高频考点）

  1. 忘记排除自身：若 n 本身已是回文（如 121），prefix 镜像会得到自身，必须跳过，否则差值为 0 会返回错误答案。
  2. 并列时取较小值：n="1" 时 0 与 2 距离都为 1，题目要求返回较小者 0，比较逻辑需写成“距离相同时取 cand < best”。
  3. 忽略位数边界：n="1000"（更近的是 999）、n="999"（更近的是 1001）不补边界就会错。
  4. 溢出风险：10^18 仍在 64 位有符号整数范围内（long long/long 可容纳），但 10^len+1 逼近上限，务必用 64 位而非 32 位；Java 用 long、C++ 用 long long，Python 天然大整数。
  5. 术语澄清：本题回文“整数”不含前导 0，因此构造时 p=0 得到的 "0" 合法，但 p 为负要跳过。

C++ 实现

#include <string>
#include <vector>
#include <cstdlib>
using namespace std;

class Solution {
public:
    string nearestPalindromic(string n) {
        long long num = stoll(n);
        int len = n.size();
        long long prefix = stoll(n.substr(0, (len + 1) / 2));
        bool evenLen = (len % 2 == 0);

        long long best = -1;
        auto consider = [&](long long cand) {
            if (cand == num) return; // 排除自身
            if (best == -1 ||
                llabs(cand - num) < llabs(best - num) ||
                (llabs(cand - num) == llabs(best - num) && cand < best)) {
                best = cand;
            }
        };

        // 候选 1：前缀 -1、前缀、前缀 +1 的镜像
        for (long long p = prefix - 1; p <= prefix + 1; ++p) {
            if (p < 0 || (int)to_string(p).size() > (len + 1) / 2) continue; // 位数变长会溢出
            consider(buildPalindrome(p, evenLen));
        }
        // 候选 2：位数边界
        consider(pow10(len - 1) - 1);
        if (len <= 18) consider(pow10(len) + 1); // len==19 时 pow10(19) 溢出，且 20 位候选必非最近

        return to_string(best);
    }

private:
    long long buildPalindrome(long long p, bool evenLen) {
        string s = to_string(p);
        string rev(s.rbegin(), s.rend());
        string pal = evenLen ? s + rev : s + rev.substr(1);
        return stoll(pal);
    }

    long long pow10(int e) {
        long long r = 1;
        while (e-- > 0) r *= 10;
        return r;
    }
};

Python 实现

class Solution:
    def nearestPalindromic(self, n: str) -> str:
        num = int(n)
        length = len(n)
        prefix = int(n[:(length + 1) // 2])
        even_len = (length % 2 == 0)

        def build(p: int) -> int:
            s = str(p)
            rev = s[::-1]
            pal = s + rev if even_len else s + rev[1:]
            return int(pal)

        best = None

        def consider(cand: int) -> None:
            nonlocal best
            if cand == num:          # 排除自身
                return
            if (best is None
                    or abs(cand - num) < abs(best - num)
                    or (abs(cand - num) == abs(best - num) and cand < best)):
                best = cand

        # 候选 1：前缀 -1、前缀、前缀 +1 的镜像
        for p in (prefix - 1, prefix, prefix + 1):
            if p >= 0:
                consider(build(p))
        # 候选 2：位数边界
        consider(10 ** (length - 1) - 1)
        consider(10 ** length + 1)

        return str(best)
