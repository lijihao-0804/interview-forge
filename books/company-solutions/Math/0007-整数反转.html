题目与约束

给你一个 32 位的有符号整数 x ，返回将 x 中的数字部分反转后的结果。

如果反转后整数超过 32 位的有符号整数的范围 [−231, 231 − 1] ，就返回 0。

假设环境不允许存储 64 位整数（有符号或无符号）。

示例 1：

<strong>输入：</strong>x = 123
<strong>输出：</strong>321

示例 2：

<strong>输入：</strong>x = -123
<strong>输出：</strong>-321

示例 3：

<strong>输入：</strong>x = 120
<strong>输出：</strong>21

示例 4：

<strong>输入：</strong>x = 0
<strong>输出：</strong>0

提示：

  • -231 <= x <= 231 - 1

核心不变量

每次从 x 末尾取出最低位（x % 10）拼到结果的末尾（res = res * 10 + digit），并在"拼接之前"预判这一步是否会溢出。

完整推导

思路推导

  1. 直觉与痛点（能不能转成字符串？）

最直观的做法是把整数转成字符串、反转字符、再转回整数。但题目特意声明 "不允许存储 64 位整数"，就是要你正视这件事：反转后的数可能直接超出 32 位整数范围，而转字符串再用 long 兜底属于"钻空子"。真正稳妥的是纯数学做法。

  1. 破局思路（取末位、拼末位）

反复做两件事：用 x % 10 取出最低位 digit，用 x /= 10 砍掉最低位；同时把结果 res = res * 10 + digit。以 x = 123 为例：

  • digit = 3，res = 3，x = 12
  • digit = 2，res = 32，x = 1
  • digit = 1，res = 321，x = 0，结束。

负数天然成立：Java / C++ 中 -123 % 10 == -3，取出的 digit 带符号，res 自然也是负数，无需单独处理符号。

  1. 关键追问（溢出怎么防？）

这是本题唯一的考点。不能先乘再判断——res * 10 一旦溢出，结果就是未定义行为。正确做法是在拼接前预判：如果 res 已经大于 INT_MAX / 10，那么无论 digit 是多少，下一步必定溢出；如果 res 恰好等于 INT_MAX / 10，还要看 digit 是否超过 7（因为 2147483647 的最后一位是 7）。负数边界同理，看 digit 是否小于 -8。任一条件命中即返回 0。

Java 实现（reverse）

class Solution {
    public int reverse(int x) {
        int res = 0;
        while (x != 0) {
            int digit = x % 10; // 取最低位；x 为负时 digit 也为负
            // 预判正溢出：res*10+digit 会不会超过 Integer.MAX_VALUE
            if (res > Integer.MAX_VALUE / 10
                    || (res == Integer.MAX_VALUE / 10 && digit > 7)) {
                return 0;
            }
            // 预判负溢出：res*10+digit 会不会低于 Integer.MIN_VALUE
            if (res < Integer.MIN_VALUE / 10
                    || (res == Integer.MIN_VALUE / 10 && digit < -8)) {
                return 0;
            }
            res = res * 10 + digit; // 拼接最低位
            x /= 10;                // 砍掉最低位
        }
        return res;
    }
}

复杂度

  • 时间：O(log₁₀|x|)，即数字的位数，最多约 10 次循环，可视为 O(1)。
  • 空间：O(1)，只用了常数个整型变量。

易错点与扩展（面试高频考点）

  1. 溢出必须"事前"预判：res * 10 溢出后结果无意义，不能用"先算完再比较"的方式兜底。
  2. 负数取余的符号：Java / C++ 中 % 结果与被除数同号，直接拼接即可；若在 Python 里 % 恒为非负，需要先取绝对值再补符号。
  3. 末尾的 0：120 → 21，取余天然丢弃前导零，无需额外处理。
  4. 边界值：2147483647、-2147483648 这类极值反转必然溢出，应返回 0，可作为测试用例。
  5. 为什么不能用 long：题面明确禁止 64 位存储，面试时若用 long 会被追问"不许用 long 怎么办"，应直接给出边界预判写法。

7. 整数反转

C++ 实现

#include <climits>

class Solution {
public:
    int reverse(int x) {
        int res = 0;
        while (x != 0) {
            int digit = x % 10; // 取最低位
            // 预判正溢出
            if (res > INT_MAX / 10 || (res == INT_MAX / 10 && digit > 7))
                return 0;
            // 预判负溢出
            if (res < INT_MIN / 10 || (res == INT_MIN / 10 && digit < -8))
                return 0;
            res = res * 10 + digit;
            x /= 10;
        }
        return res;
    }
};

Python 实现

class Solution:
    def reverse(self, x: int) -> int:
        INT_MAX = 2 ** 31 - 1
        INT_MIN = -2 ** 31

        sign = 1
        if x < 0:
            sign = -1
            x = -x

        res = 0
        while x != 0:
            res = res * 10 + x % 10  # 拼接最低位
            x //= 10                 # 砍掉最低位

        res *= sign
        if res < INT_MIN or res > INT_MAX:
            return 0
        return res
