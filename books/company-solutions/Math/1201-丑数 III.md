# 1201. 丑数 III

| 题目信息 | 内容 |
|---|---|
| 难度 | 中等 |
| 核心模式 | 二分答案 + 容斥计数：找最小的 x 使“≤ x 的丑数个数 ≥ n” |
| 时间复杂度 | O(log(2×10^9) · log(min(a,b,c))) |
| 空间复杂度 | O(1) |

## 题目与约束

丑数是可以被 `a` **或** `b` **或** `c` 整除的 **正整数** 。

给你四个整数：`n`、`a`、`b`、`c`，请你设计一个算法来找出第 `n` 个丑数。

**示例 1：**

```
输入：n = 3, a = 2, b = 3, c = 5
输出：4
解释：丑数序列为 2, 3, 4, 5, 6, 8, 9, 10... 其中第 3 个是 4。
```

**示例 2：**

```
输入：n = 4, a = 2, b = 3, c = 4
输出：6
解释：丑数序列为 2, 3, 4, 6, 8, 9, 10, 12... 其中第 4 个是 6。
```

**示例 3：**

```
输入：n = 5, a = 2, b = 11, c = 13
输出：10
解释：丑数序列为 2, 4, 6, 8, 10, 11, 12, 13... 其中第 5 个是 10。
```

**提示：**

- `1 <= n, a, b, c <= 10^9`
- `1 <= a * b * c <= 10^18`
- 本题结果在 `[1, 2 * 10^9]` 的范围内

## 核心不变量

> 记 `count(x)` 为 `[1, x]` 内能被 `a` 或 `b` 或 `c` 整除的正整数个数。`count(x)` 关于 `x` 单调不减，于是“第 `n` 个丑数”就是**最小的满足 `count(x) >= n` 的 `x`**。

## 完整推导

### 思路推导

1. **直觉与痛点（不能一个个枚举丑数）**

   丑数由“能被 `a`/`b`/`c` 整除”定义，随着 `n` 增大，第 `n` 个丑数可能到 `2×10^9`，逐个生成不现实。但换个角度：如果我们能快速回答“`1..x` 里有多少个丑数”，就能用二分逼近答案。

2. **破局思路（容斥算 count）**

   按容斥原理：`≤ x` 中能被 `a` 或 `b` 或 `c` 整除的个数为

   ```
   count(x) = ⌊x/a⌋ + ⌊x/b⌋ + ⌊x/c⌋
            - ⌊x/lcm(a,b)⌋ - ⌊x/lcm(a,c)⌋ - ⌊x/lcm(b,c)⌋
            + ⌊x/lcm(a,b,c)⌋
   ```

   加回被重复减掉的“同时被两数整除”，再补回“同时被三数整除”。其中 `lcm(x,y)=x/gcd(x,y)*y`。

   以 `n=4, a=2,b=3,c=4` 为例，算 `x=6`：`3+2+1 - (1+1+0) + 0 = 6-2 = 4`，恰好有 4 个丑数（2,3,4,6），而 `x=5` 时为 3，所以答案是 6。

3. **关键追问（为什么二分是对的）**

   `count(x)` 随 `x` 增大只增不减，是单调函数。因此可以二分：若 `count(mid) >= n`，答案 ≤ `mid`，收缩右界；否则答案 > `mid`，抬升左界。二分上界取 `2×10^9`（题目保证结果范围）。

4. **溢出细节**：`a,b,c ≤ 10^9`，`lcm` 与乘法必须用 `long`，否则 `int` 会溢出；题目限定 `a*b*c ≤ 10^18`，故三数的最小公倍数不会超过 `long` 范围。

### Java 实现（二分 + 容斥）

```java
class Solution {
    public int nthUglyNumber(int n, int a, int b, int c) {
        long A = a, B = b, C = c;
        long ab = lcm(A, B);
        long ac = lcm(A, C);
        long bc = lcm(B, C);
        long abc = lcm(ab, C);

        long lo = 1, hi = 2_000_000_000L;
        while (lo < hi) {
            long mid = lo + (hi - lo) / 2;
            if (count(mid, A, B, C, ab, ac, bc, abc) >= n) {
                hi = mid;      // 答案在 [lo, mid]
            } else {
                lo = mid + 1;  // 答案在 (mid, hi]
            }
        }
        return (int) lo;
    }

    // [1, x] 中能被 a 或 b 或 c 整除的个数（容斥原理）
    private long count(long x, long a, long b, long c,
                       long ab, long ac, long bc, long abc) {
        return x / a + x / b + x / c
             - x / ab - x / ac - x / bc
             + x / abc;
    }

    private long gcd(long x, long y) {
        while (y != 0) {
            long t = x % y;
            x = y;
            y = t;
        }
        return x;
    }

    private long lcm(long x, long y) {
        return x / gcd(x, y) * y;
    }
}
```

### 复杂度

- 时间：`O(log(2×10^9) · log(min(a,b,c)))`。二分约 31 次，每次 `count` 是 `O(1)` 次除法；`gcd/lcm` 每次 `O(log)` 且只算常数次。
- 空间：`O(1)`。只用若干整型变量。

### 易错点与扩展（面试高频考点）

1. **必须用 `long`**：`lcm(a,b)` 可能达 `10^18` 量级，`int` 相乘溢出会得到错误计数。
2. **容斥符号别写反**：单数相加、两数相减、三数相加，顺序和符号错了结果就崩。
3. **`a,b,c` 有重复或相除时公式仍成立**：例如 `a=b` 时 `lcm(a,b)=a`，容斥项自动抵消，无需特判。
4. **二分上界与返回值**：答案在 `[1, 2×10^9]`，用 `long` 二分、最后转 `int`；注意用 `lo + (hi-lo)/2` 避免加法溢出。
5. **与 264「丑数 II」的区别**：那题丑数由质因子 `2,3,5` 生成，用三指针；本题是“被给定三数整除”，本质是计数 + 二分，别混淆。

## 力扣原题

[1201. 丑数 III](https://leetcode.cn/problems/ugly-number-iii/)

### C++ 实现

```cpp
class Solution {
public:
    int nthUglyNumber(int n, int a, int b, int c) {
        long long A = a, B = b, C = c;
        long long ab = lcm(A, B), ac = lcm(A, C), bc = lcm(B, C);
        long long abc = lcm(ab, C);

        // [1, x] 中能被 A 或 B 或 C 整除的个数（容斥）
        auto count = [&](long long x) -> long long {
            return x / A + x / B + x / C
                 - x / ab - x / ac - x / bc
                 + x / abc;
        };

        long long lo = 1, hi = 2000000000LL;
        while (lo < hi) {
            long long mid = lo + (hi - lo) / 2;
            if (count(mid) >= n) hi = mid;
            else lo = mid + 1;
        }
        return (int) lo;
    }

private:
    long long gcd(long long x, long long y) {
        while (y) {
            long long t = x % y;
            x = y;
            y = t;
        }
        return x;
    }

    long long lcm(long long x, long long y) {
        return x / gcd(x, y) * y;
    }
};
```

### Python 实现

```python
from math import gcd

class Solution:
    def nthUglyNumber(self, n: int, a: int, b: int, c: int) -> int:
        def lcm(x: int, y: int) -> int:
            return x // gcd(x, y) * y

        ab = lcm(a, b)
        ac = lcm(a, c)
        bc = lcm(b, c)
        abc = lcm(ab, c)

        # [1, x] 中能被 a 或 b 或 c 整除的个数（容斥）
        def count(x: int) -> int:
            return (x // a + x // b + x // c
                    - x // ab - x // ac - x // bc
                    + x // abc)

        lo, hi = 1, 2_000_000_000
        while lo < hi:
            mid = (lo + hi) // 2
            if count(mid) >= n:
                hi = mid
            else:
                lo = mid + 1

        return lo
```
