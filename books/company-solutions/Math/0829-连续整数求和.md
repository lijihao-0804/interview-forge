# 829. 连续整数求和

| 题目信息 | 内容 |
|---|---|
| 难度 | 困难 |
| 核心模式 | 枚举项数 k，用求和公式判断首项是否为正整数 |

## 题目与约束

给定一个正整数 `n`，返回 连续正整数满足所有数字之和为 `n` 的组数 。 

 

示例 1:

```
<strong>输入: </strong>n = 5
<strong>输出: </strong>2
<strong>解释: </strong>5 = 2 + 3，共有两组连续整数([5],[2,3])求和后为 5。
```

示例 2:

```
<strong>输入: </strong>n = 9
<strong>输出: </strong>3
<strong>解释: </strong>9 = 4 + 5 = 2 + 3 + 4
```

示例 3:

```
<strong>输入: </strong>n = 15
<strong>输出: </strong>4
<strong>解释: </strong>15 = 8 + 7 = 4 + 5 + 6 = 1 + 2 + 3 + 4 + 5
```

 

提示:

- `1 <= n <= 109`​​​​​​​

[🔗 前往力扣原题验证 →](https://leetcode.cn/problems/consecutive-numbers-sum/)

## 核心不变量

> 若 n 能写成 k 个连续正整数之和，则首项 a = (n − k(k−1)/2) / k 必须是正整数，即 n − k(k−1)/2 能被 k 整除且大于 0。

## 完整推导

### 思路推导

1. **把「连续」转成公式**

   设这一组数共有 `k` 个，首项为 `a`（a ≥ 1），则这 k 个连续正整数为 `a, a+1, …, a+k−1`，其和是等差求和：

   `n = k·a + k(k−1)/2`。

2. **反解首项 a**

   移项得 `a = (n − k(k−1)/2) / k`。所以固定 k 后，能不能凑成，只取决于两件事：`n − k(k−1)/2 > 0`（首项为正），并且它能被 `k` 整除（首项是整数）。两个条件同时满足，就恰好对应一种方案。

3. **k 枚举到哪？**

   因为 a ≥ 1，所以 `n ≥ k(k+1)/2`，即 `k` 最多到约 `√(2n)`。于是从 `k = 1` 一直试到 `k(k+1)/2 > n` 为止即可，复杂度 O(√n)。

4. **小例子（n = 15）**

   - k=1：a=15 ✓
   - k=2：15−1=14，14/2=7 ✓（7+8）
   - k=3：15−3=12，12/3=4 ✓（4+5+6）
   - k=4：15−6=9，9%4≠0 ✗
   - k=5：15−10=5，5/5=1 ✓（1+2+3+4+5）
   - k=6：需要 21 > 15，停止。共 4 组，与示例一致。

### Java 实现（consecutiveNumbersSum）

```java
class Solution {
    public int consecutiveNumbersSum(int n) {
        int count = 0;
        // 枚举项数 k：k 个连续正整数之和最小为 k(k+1)/2，超过 n 即可停止
        for (long k = 1; k * (k + 1) / 2 <= n; k++) {
            // 首项 a = (n - k(k-1)/2) / k，需为正整数
            long rem = n - k * (k - 1) / 2;
            if (rem > 0 && rem % k == 0) {
                count++;
            }
        }
        return count;
    }
}
```

### 复杂度

- 时间：O(√n)。循环变量 k 满足 k(k+1)/2 ≤ n，循环次数约为 √(2n)。
- 空间：O(1)。只用了常数个 long 变量。

### 易错点与扩展（面试高频考点）

1. **用公式 n = k·a + k(k−1)/2 还是 k(k+1)/2**：两者只差在下标定义，注意首项是 `a`（k 个数从 a 开始），别把 a 与末项混淆。
2. **整除判断别漏正数判断**：`rem % k == 0` 之外还要 `rem > 0`，否则会出现 a ≤ 0 的伪解。
3. **溢出**：n 可达 10⁹，`k*(k+1)` 虽然循环上界只有约 4.5 万，但用 `long` 更稳妥。
4. **数学等价结论**：答案等于「n 的奇因子个数」。因为一个数能表示为连续正整数之和，当且仅当它不是 2 的幂，方案数恰好是 n 的奇数因子个数，可作为交叉验证。
5. **扩展：双指针**也可在 O(√n) 内滑动窗口统计，但本公式法更简洁、常数更小。

```cpp
class Solution {
public:
    int consecutiveNumbersSum(int n) {
        int count = 0;
        for (long long k = 1; k * (k + 1) / 2 <= n; k++) {
            long long rem = n - k * (k - 1) / 2;
            if (rem > 0 && rem % k == 0) count++;
        }
        return count;
    }
};
```

### Python 实现

```python
class Solution:
    def consecutiveNumbersSum(self, n: int) -> int:
        count = 0
        k = 1
        while k * (k + 1) // 2 <= n:
            rem = n - k * (k - 1) // 2
            if rem > 0 and rem % k == 0:
                count += 1
            k += 1
        return count
```
