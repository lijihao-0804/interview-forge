# 540. 有序数组中的单一元素

| 题目信息 | 内容 |
|---|---|
| 难度 | 中等 |
| 核心模式 | 二分查找 + 成对下标奇偶性判定 |
| 时间复杂度 | O(log n) |
| 空间复杂度 | O(1) |

## 题目与约束

给你一个仅由整数组成的有序数组，其中每个元素都会出现两次，唯有一个数只会出现一次。

请你找出并返回只出现一次的那个数。

你设计的解决方案必须满足 `O(log n)` 时间复杂度和 `O(1)` 空间复杂度。

**示例 1：**

```
输入: nums = [1,1,2,3,3,4,4,8,8]
输出: 2
```

**示例 2：**

```
输入: nums = [3,3,7,7,10,11,11]
输出: 10
```

**提示：**

- `1 <= nums.length <= 10^5`
- `0 <= nums[i] <= 10^5`

## 核心不变量

> 在单一元素出现之前，每一对相同元素都占据下标 `(偶数, 奇数)`；一旦跨过单一元素，配对的下标奇偶性就会整体翻转。

## 完整推导

### 思路推导

1. **直觉与痛点（线性扫描不够）**：每个数成对出现、只有一个落单，直接遍历计数或异或都能 `O(n)` 解决，但题目硬性要求 `O(log n)`，这几乎在明示 **二分查找**。二分要成立，必须存在一个可以判定的「单调分界」。

2. **破局思路（盯住下标奇偶性）**：数组有序，相同元素一定相邻。观察「落单元素之前」和「之后」的配对规律：

   - 落单元素 **左边**：`(0,1)`、`(2,3)`…… 每一对都是「偶数下标 + 奇数下标」。
   - 落单元素 **右边**：因为前面少了一个数，配对整体错位，变成 `(奇数, 偶数)`。

   于是「配对的两个下标是 偶-奇 还是 奇-偶」就成了天然的分界信号。

3. **判定方式（把 mid 归到偶数）**：每次取中点 `mid`，若 `mid` 是奇数先 `mid--` 转成偶数，此时 `mid` 和 `mid+1` 就是一对候选：

   - 若 `nums[mid] == nums[mid+1]`，说明这一对完好，落单元素在 **右半边**，令 `lo = mid + 2`。
   - 若 `nums[mid] != nums[mid+1]`，说明配对已经断裂，落单元素在 **左半边（含 mid）**，令 `hi = mid`。

   示例 `[1,1,2,3,3,4,4]`：`mid` 落在下标 2（值 2），`nums[2]=2 != nums[3]=3`，断裂 → `hi=2`，继续收缩到下标 2，即为答案。

### Java 实现（二分查找）

```java
class Solution {
    public int singleNonDuplicate(int[] nums) {
        int lo = 0, hi = nums.length - 1;
        while (lo < hi) {
            int mid = lo + (hi - lo) / 2;
            // 统一把 mid 调整为偶数下标，使 (mid, mid+1) 成为一对
            if ((mid & 1) == 1) {
                mid--;
            }
            if (nums[mid] == nums[mid + 1]) {
                // 这一对完好，落单元素在右侧
                lo = mid + 2;
            } else {
                // 配对断裂，落单元素在左侧（包含 mid）
                hi = mid;
            }
        }
        return nums[lo];
    }
}
```

### 复杂度

- 时间：O(log n)，每次把搜索区间缩小一半。
- 空间：O(1)，只用几个整型变量。

### 易错点与扩展（面试高频考点）

1. **`mid` 必须归到偶数**：若 `mid` 是奇数却直接比较 `nums[mid]` 与 `nums[mid+1]`，配对关系错位，判断会失效。先 `mid--` 是本题的命门。
2. **边界收敛写法**：`lo = mid + 2` 而非 `mid + 1`——因为 `mid`、`mid+1` 是完好的一对，可以整体跳过；`hi = mid` 保留了可能是答案的 `mid`。
3. **循环条件 `lo < hi`**：用 `while (lo < hi)` 收敛到单个下标直接返回 `nums[lo]`，避免死循环或越界。
4. **不要用 `(lo + hi) / 2`**：大数组下有整型溢出隐患，写 `lo + (hi - lo) / 2`。
5. **举一反三**：`O(1)` 空间的另一解法是全体异或（`O(n)`）；另有「不要求 `O(log n)` 时按对跳」的 `O(n)` 双指针法。面试可先讲异或再讲二分，突出对复杂度的追求。

### C++ 实现

```cpp
class Solution {
public:
    int singleNonDuplicate(vector<int>& nums) {
        int lo = 0, hi = (int)nums.size() - 1;
        while (lo < hi) {
            int mid = lo + (hi - lo) / 2;
            if (mid & 1) mid--;               // 归到偶数下标，形成一对
            if (nums[mid] == nums[mid + 1]) {
                lo = mid + 2;                 // 完好一对，答案在右侧
            } else {
                hi = mid;                     // 配对断裂，答案在左侧
            }
        }
        return nums[lo];
    }
};
```

### Python 实现

```python
class Solution:
    def singleNonDuplicate(self, nums: List[int]) -> int:
        lo, hi = 0, len(nums) - 1
        while lo < hi:
            mid = lo + (hi - lo) // 2
            if mid % 2 == 1:                  # 归到偶数下标，形成一对
                mid -= 1
            if nums[mid] == nums[mid + 1]:
                lo = mid + 2                  # 完好一对，答案在右侧
            else:
                hi = mid                      # 配对断裂，答案在左侧
        return nums[lo]
```
