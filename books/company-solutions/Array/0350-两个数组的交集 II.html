题目与约束

给你两个整数数组 nums1 和 nums2，请你以数组形式返回两数组的交集。返回结果中每个元素出现的次数，应与元素在两个数组中都出现的次数一致（如果出现次数不一致，则考虑取较小值）。可以不考虑输出结果的顺序。

示例 1：

输入：nums1 = [1,2,2,1], nums2 = [2,2]
输出：[2,2]

示例 2：

输入：nums1 = [4,9,5], nums2 = [9,4,9,8,4]
输出：[4,9]

提示：

  • 1 <= nums1.length, nums2.length <= 1000
  • 0 <= nums1[i], nums2[i] <= 1000

进阶：

  • 如果给定的数组已经排好序呢？你将如何优化你的算法？
  • 如果 nums1 的大小比 nums2 小，哪种方法更优？
  • 如果 nums2 的元素存储在磁盘上，内存是有限的，并且你不能一次加载所有的元素到内存中，你该怎么办？

核心不变量

用哈希表统计一个数组里每个值的剩余可用次数；遍历另一个数组时，每命中一次就输出并把该计数减一，从而每个值最多输出「两数组中该值出现次数的较小值」次。

完整推导

思路推导

  1. 与"交集 I"的区别（这次要保留次数）

上一题结果唯一，用集合即可；本题要求"出现次数取较小值"，例如 [1,2,2,1] 与 [2,2] 应输出 [2,2]。集合会丢次数，所以必须换成带计数的哈希表，本质是"带库存的交集"。

  1. 计数 + 消耗
  • 先统计较短数组（设为 nums1）中每个值的出现次数 cnt；
  • 再遍历另一个数组 nums2，遇到 x 若 cnt[x] > 0，就把它加入结果并把 cnt[x] 减一。这样一旦某值在 nums1 中被"用光"，后续即使 nums2 里还有也不会再多输出。

  1. 小例子：nums1 = [1,2,2,1] → cnt = {1:2, 2:2}；遍历 nums2 = [2,2]：第一个 2 命中，cnt[2]=1，输出 2；第二个 2 命中，cnt[2]=0，再输出 2；得到 [2,2]。

  2. 为什么统计较小数组：哈希表规模取决于被统计的数组长度，选短的可以让空间降到 O(min(n, m))，是常见的工程优化。

Java 实现（intersect）

import java.util.ArrayList;
import java.util.HashMap;
import java.util.List;
import java.util.Map;

class Solution {
    public int[] intersect(int[] nums1, int[] nums2) {
        // 为节省空间，让 nums1 指向较短的数组
        if (nums1.length > nums2.length) {
            int[] tmp = nums1;
            nums1 = nums2;
            nums2 = tmp;
        }

        // 1. 统计较短数组各值的出现次数
        Map<Integer, Integer> cnt = new HashMap<>();
        for (int x : nums1) {
            cnt.put(x, cnt.getOrDefault(x, 0) + 1);
        }

        // 2. 遍历另一个数组，命中且还有库存就输出并消耗一次
        List<Integer> res = new ArrayList<>();
        for (int x : nums2) {
            Integer c = cnt.get(x);
            if (c != null && c > 0) {
                res.add(x);
                cnt.put(x, c - 1);
            }
        }

        // 3. 转数组输出
        int[] ans = new int[res.size()];
        for (int i = 0; i < res.size(); i++) {
            ans[i] = res.get(i);
        }
        return ans;
    }
}

复杂度

  • 时间：O(n + m)，统计一次、遍历一次，哈希操作均摊 O(1)。
  • 空间：O(min(n, m))，哈希表只存较短数组的去重值及其计数（外加 O(k) 结果）。

易错点与扩展（面试高频考点）

  1. 不能再用集合：本题必须保留重复次数，结果容器用列表，且要用计数扣减来限制次数。
  2. 扣减时机：先判断 cnt[x] > 0 再输出、再减一；顺序写反会导致多输出。
  3. 进阶·有序数组：若两数组已排序，用双指针即可，时间 O(n + m)、空间 O(1)，无需哈希。
  4. 进阶·nums1 更小：统计较小数组，既降空间也能减少哈希构建成本，就是上面代码的开头交换。
  5. 进阶·磁盘/内存受限：nums2 太大无法全装入内存时，可对 nums1 建立哈希计数（nums1 在内存中），再分块流式读取 nums2 逐块匹配；或借助外部排序 + 归并统计。

C++ 实现

class Solution {
public:
    vector<int> intersect(vector<int>& nums1, vector<int>& nums2) {
        if (nums1.size() > nums2.size()) swap(nums1, nums2); // 统计较短数组

        unordered_map<int, int> cnt;
        for (int x : nums1) ++cnt[x];

        vector<int> res;
        for (int x : nums2) {
            if (cnt[x] > 0) {        // 还有库存
                res.push_back(x);
                --cnt[x];            // 消耗一次
            }
        }
        return res;
    }
};

Python 实现

from collections import Counter

class Solution:
    def intersect(self, nums1: list[int], nums2: list[int]) -> list[int]:
        if len(nums1) > len(nums2):
            nums1, nums2 = nums2, nums1   # 统计较短数组

        cnt = Counter(nums1)
        res = []
        for x in nums2:
            if cnt[x] > 0:                # 还有库存
                res.append(x)
                cnt[x] -= 1               # 消耗一次
        return res
