题目信息 内容
难度 中等
核心模式 双指针逐个求交集，右端点更小的那个指针前移
时间复杂度 O(n + m)
空间复杂度 O(n + m)（结果数组）

题目与约束

给定两个由一些 闭区间 组成的列表 firstList 和 secondList，其中 firstList[i] = [starti, endi]，secondList[j] = [startj, endj]。每个区间列表都是成对 不相交 的，并且 已经排序。

返回这 两个区间列表的交集。

形式上，闭区间 [a, b]（其中 a <= b）表示实数 x 的集合，满足 a <= x <= b。两个闭区间的 交集 是一组实数，要么为空集，要么为一个闭区间。例如 [1, 3] 与 [2, 4] 的交集是 [2, 3]；[1, 3] 与 [4, 4] 的交集为空集。

示例 1：

输入：firstList = [[0,2],[5,10],[13,23],[24,25]], secondList = [[1,5],[8,12],[15,24],[25,26]]
输出：[[1,2],[5,5],[8,10],[15,23],[24,24],[25,25]]

示例 2：

输入：firstList = [[1,3],[5,9]], secondList = []
输出：[]

示例 3：

输入：firstList = [], secondList = [[4,8],[10,12]]
输出：[]

示例 4：

输入：firstList = [[1,7]], secondList = [[3,10]]
输出：[[3,7]]

提示：

  • 0 <= firstList.length, secondList.length <= 1000
  • firstList.length + secondList.length >= 1
  • 0 <= starti < endi <= 10^9
  • end_i < start_{i+1}
  • 0 <= startj < endj <= 10^9
  • end_j < start_{j+1}

核心不变量

两个区间列表各自有序且互不相交。当前两区间 A=[a1,a2]、B=[b1,b2] 的交集是 [max(a1,b1), min(a2,b2)]（非空才收录）；此后右端点更小的那个区间，已不可能再与对方更靠后的区间相交，故只前移它的指针。

完整推导

思路推导

  1. 直觉与痛点（怎么判断两个区间重叠？） 两个闭区间的交集很简单：左端取两者起点的较大值，右端取两者终点的较小值。若"左 > 右"说明没有重叠，否则 [左, 右] 就是交集。这一步是 O(1) 的。

  2. 破局思路（双指针线性扫描） 两个列表都已排序，可以用 i 指向 firstList、j 指向 secondList，每次只处理当前这一对区间，算完交集后再决定"谁往前走"。

  3. 关键追问（到底移动哪个指针？） 谁的 右端点更小，谁就先前移。原因：右端点小的那个区间已经结束了，对方后面的区间起点只会更大，它不可能再与后面任何区间相交。而右端点较大的那个区间，还可能和对方更靠后的区间产生新交集。这样每个区间最多被访问一次，整体线性。

小例子：A=[5,10]、B=[8,12]，交集 [8,10]（左取 max(5,8)=8，右取 min(10,12)=10）；因为 10 < 12，移动 A 的指针，去看 [13,23]。

  1. 收尾 任意一个列表走到尽头即可停止——此时另一个列表剩余区间都不可能再有交集（对方已无区间可比）。

Java 实现（intervalIntersection）

import java.util.ArrayList;
import java.util.List;

class Solution {
    public int[][] intervalIntersection(int[][] firstList, int[][] secondList) {
        List<int[]> res = new ArrayList<>();
        int i = 0, j = 0;
        while (i < firstList.length && j < secondList.length) {
            // 交集：左端取大、右端取小
            int lo = Math.max(firstList[i][0], secondList[j][0]);
            int hi = Math.min(firstList[i][1], secondList[j][1]);
            if (lo <= hi) {                 // 非空（含端点相切），收录
                res.add(new int[]{lo, hi});
            }
            // 右端点更小的区间不可能再与对方后续区间相交，前移其指针
            if (firstList[i][1] < secondList[j][1]) {
                i++;
            } else {
                j++;
            }
        }
        return res.toArray(new int[res.size()][]);
    }
}

复杂度

  • 时间：O(n + m)。两个指针各自单调前进，每个区间最多被访问一次，共线性扫描一遍。
  • 空间：O(n + m)。结果数组最多容纳 n + m 个区间；除结果外只用常数个变量。

易错点与扩展（面试高频考点）

  1. 端点相切要算重叠：题目是闭区间，[1,2] 与 [2,5] 共享点 2，交集为 [2,2]。判断必须用 lo <= hi，写成 < 会漏掉这类合法交集。
  2. 移动指针的依据是"右端点"：容易误比左端点或整体区间；正确做法是结束得早的那个先前进。
  3. 空列表：任一列表为空时 while 条件直接不成立，返回空数组，无需特判。
  4. 二维数组返回写法：Java 中 res.toArray(new int[res.size()][]) 才是正确的转换，写成 new int[][] 会抛异常。
  5. 扩展：若是"求所有区间的并集"（LeetCode 56 合并区间）或"给若干会议加一间会议室"（LeetCode 253），则把思路换成"按起点排序 + 维护当前右边界"；本题是"已排序双列表取交"，属于双指针扫描线（sweep line）的经典分支。

986. 区间列表的交集

C++ 实现

#include <vector>
#include <algorithm>
using namespace std;

class Solution {
public:
    vector<vector<int>> intervalIntersection(vector<vector<int>>& firstList, vector<vector<int>>& secondList) {
        vector<vector<int>> res;
        int n = firstList.size(), m = secondList.size();
        int i = 0, j = 0;
        while (i < n && j < m) {
            int lo = max(firstList[i][0], secondList[j][0]); // 左端取大
            int hi = min(firstList[i][1], secondList[j][1]); // 右端取小
            if (lo <= hi) res.push_back({lo, hi});           // 非空则收录
            if (firstList[i][1] < secondList[j][1]) i++;      // 右端更小者前进
            else j++;
        }
        return res;
    }
};

Python 实现

from typing import List

class Solution:
    def intervalIntersection(self, firstList: List[List[int]], secondList: List[List[int]]) -> List[List[int]]:
        res = []
        i = j = 0
        while i < len(firstList) and j < len(secondList):
            lo = max(firstList[i][0], secondList[j][0])  # 左端取大
            hi = min(firstList[i][1], secondList[j][1])  # 右端取小
            if lo <= hi:
                res.append([lo, hi])
            if firstList[i][1] < secondList[j][1]:
                i += 1
            else:
                j += 1
        return res
