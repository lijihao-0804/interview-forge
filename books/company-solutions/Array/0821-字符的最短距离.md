# 821. 字符的最短距离

| 题目信息 | 内容 |
|---|---|
| 难度 | 简单 |
| 核心模式 | 左右两次扫描，取两个方向距离的最小值 |
| 时间复杂度 | O(n) |
| 空间复杂度 | O(1) |

## 题目与约束

给你一个字符串 `s` 和一个字符 `c` ，且 `c` 是 `s` 中出现过的字符。

返回一个整数数组 `answer` ，其中 `answer.length == s.length` 且 `answer[i]` 是 `s` 中从下标 `i` 到离它 最近 的字符 `c` 的 距离 。

两个下标 `i` 和 `j` 之间的 距离 为 `abs(i - j)` ，其中 `abs` 是绝对值函数。

 

示例 1：

输入：s = "loveleetcode", c = "e"  
输出：[3,2,1,0,1,0,0,1,2,2,1,0]  
解释：字符 'e' 出现在下标 3、5、6 和 11 处（下标从 0 开始计数）。  
距下标 0 最近的 'e' 出现在下标 3 ，所以距离为 abs(0 - 3) = 3 。  
距下标 1 最近的 'e' 出现在下标 3 ，所以距离为 abs(1 - 3) = 2 。  
对于下标 4 ，出现在下标 3 和下标 5 处的 'e' 都离它最近，但距离是一样的 abs(4 - 3) == abs(4 - 5) = 1 。  
距下标 8 最近的 'e' 出现在下标 6 ，所以距离为 abs(8 - 6) = 2 。

示例 2：

输入：s = "aaab", c = "b"  
输出：[3,2,1,0]

 

提示：

- `1 <= s.length <= 104`

- `s[i]` 和 `c` 均为小写英文字母

- 题目数据保证 `c` 在 `s` 中至少出现一次

[🔗 前往力扣原题验证 →](https://leetcode.cn/problems/shortest-distance-to-a-character/)

## 核心不变量

> 对每个位置，离它最近的 `c` 只可能来自左边那个 `c` 或右边那个 `c`；左扫一遍、右扫一遍各取最近，二者取小即答案。

## 完整推导

### 思路推导

1. **最近来源只有两个方向。** 位置 `i` 左边离它最近的 `c`（记为左侧距离）和右边离它最近的 `c`（记为右侧距离），真正的答案就是这两者的较小值——更远的 `c` 不可能更优。

2. **左到右扫一遍，得到“左侧距离”。** 用一个变量 `prev` 记住最近一次遇到的 `c` 的下标。从左往右扫，遇到 `c` 就更新 `prev = i`，则 `answer[i] = i - prev`。扫描开始时可把 `prev` 设成一个足够小的值（如 `-n`），保证在遇到第一个 `c` 之前得到一个很大的距离，之后会被右侧扫描修正。

3. **右到左扫一遍，取最小值。** 同理用 `prev` 记录右侧最近 `c` 的下标（初值设成足够大，如 `2n`），从右往左扫，更新 `answer[i] = min(answer[i], prev - i)`。两次扫描结束，每个位置都取到了左右两侧的较小距离。

4. **小例子。** `s = "aaab", c = "b"`：左扫得到 `[?, ?, ?, 0]` 形式的左侧距离，右扫时 `prev` 依次从 3 往左传，最终得到 `[3,2,1,0]`。

### Java 实现（左右两次扫描）

```java
class Solution {
    public int[] shortestToChar(String s, char c) {
        int n = s.length();
        int[] answer = new int[n];

        // 左 -> 右：记录每个位置到左侧最近 c 的距离
        int prev = -n;                      // 用一个足够小的初值表示"左侧暂无 c"
        for (int i = 0; i < n; i++) {
            if (s.charAt(i) == c) {
                prev = i;
            }
            answer[i] = i - prev;           // 左侧距离
        }

        // 右 -> 左：用右侧最近 c 的距离去更新最小值
        prev = 2 * n;                       // 用一个足够大的初值表示"右侧暂无 c"
        for (int i = n - 1; i >= 0; i--) {
            if (s.charAt(i) == c) {
                prev = i;
            }
            answer[i] = Math.min(answer[i], prev - i);
        }

        return answer;
    }
}
```

### 复杂度

- 时间：O(n)。字符串被从左到右、从右到左各扫描一次，每次常数工作。
- 空间：O(1)。除返回数组外，只用了 `prev` 等常数个变量（返回数组不计入辅助空间）。

### 易错点与扩展（面试高频考点）

1. **初值选取不当。** `prev` 初值若为 0，第一次遇到 `c` 前会算出错误的小距离；左扫取 `-n`、右扫取 `2n` 才能保证被后续正确覆盖。
2. **只扫一遍就交卷。** 单方向扫描只能保证一侧最近，必须双向扫描再取 `min`。
3. **下标从 0 开始。** 距离是 `i - prev`（左）或 `prev - i`（右），注意方向别写反导致负数。
4. **扩展：BFS 视角。** 也可把所有 `c` 的位置当作多源起点做一次 BFS，逐层向两侧扩散，复杂度同为 O(n)，思路更直观但队列开销略大。

### C++ 实现

```cpp
#include <string>
#include <vector>
#include <algorithm>
using namespace std;

class Solution {
public:
    vector<int> shortestToChar(string s, char c) {
        int n = s.size();
        vector<int> answer(n, 0);

        // 左 -> 右：到左侧最近 c 的距离
        int prev = -n;
        for (int i = 0; i < n; i++) {
            if (s[i] == c) prev = i;
            answer[i] = i - prev;
        }

        // 右 -> 左：用右侧最近 c 的距离更新最小值
        prev = 2 * n;
        for (int i = n - 1; i >= 0; i--) {
            if (s[i] == c) prev = i;
            answer[i] = min(answer[i], prev - i);
        }

        return answer;
    }
};
```

### Python 实现

```python
from typing import List

class Solution:
    def shortestToChar(self, s: str, c: str) -> List[int]:
        n = len(s)
        answer = [0] * n

        # 左 -> 右：到左侧最近 c 的距离
        prev = -n
        for i in range(n):
            if s[i] == c:
                prev = i
            answer[i] = i - prev

        # 右 -> 左：用右侧最近 c 的距离更新最小值
        prev = 2 * n
        for i in range(n - 1, -1, -1):
            if s[i] == c:
                prev = i
            answer[i] = min(answer[i], prev - i)

        return answer
```
