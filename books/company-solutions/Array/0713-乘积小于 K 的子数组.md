# 713. 乘积小于 K 的子数组

| 题目信息 | 内容 |
|---|---|
| 难度 | 中等 |
| 核心模式 | 滑动窗口（双指针）维护乘积小于 k 的连续区间 |
| 时间复杂度 | O(n) |
| 空间复杂度 | O(1) |

## 题目与约束

给定一个整数数组 `nums` 和一个整数 `k`。

请你返回 子数组 内所有元素的 乘积严格小于 `k` 的连续子数组的数目。

 

示例 1：

输入：nums = [10,5,2,6], k = 100  
输出：8  
解释：8 个乘积小于 100 的子数组分别为：[10]、[5]、[2]、[6]、[10,5]、[5,2]、[2,6]、[5,2,6]。  
需要注意的是 [10,5,2] 并不是乘积小于 100 的子数组。

示例 2：

输入：nums = [1,2,3], k = 0  
输出：0

 

提示: 

- `1 <= nums.length <= 3 * 104`

- `1 <= nums[i] <= 1000`

- `0 <= k <= 106`

[🔗 前往力扣原题验证 →](https://leetcode.cn/problems/subarray-product-less-than-k/)

## 核心不变量

> 窗口 `[left, right]` 内的乘积始终严格小于 k；以 `right` 结尾、起点在 `[left, right]` 的每个子数组都合法，恰有 `right - left + 1` 个。

## 完整推导

### 思路推导

1. **直觉（乘积随右端单调递增）**

   因为所有 `nums[i] >= 1`，往窗口右边加元素乘积只增不减。固定 `right` 后，满足"乘积 < k"的起点是一段**连续的左边界**，这正是滑动窗口的适用条件。

2. **扩张 + 收缩（右指针进、左指针退）**

   右指针每次把 `nums[right]` 乘进 `prod`；当 `prod >= k` 时，不断把 `nums[left]` 除掉并右移 `left`，直到乘积重新 `< k` 或窗口空。

3. **计数（以 right 结尾的合法子数组数）**

   收缩完成后，`[left, right]` 内任取起点到 `right` 的乘积都 `< k`，数量为 `right - left + 1`，累加到答案。

4. **小例子（示例 1：nums=[10,5,2,6], k=100）**

   `right=0`：prod=10，合法，贡献 1；`right=1`：prod=50，贡献 2；`right=2`：prod=100 ≥ 100，左移去掉 10 得 10，贡献 2；`right=3`：prod=60，贡献 3。合计 1+2+2+3 = 8。

### Java 实现（numSubarrayProductLessThanK）

```java
class Solution {
    public int numSubarrayProductLessThanK(int[] nums, int k) {
        // k <= 1 时，任何正整数乘积都不可能小于它（nums[i] >= 1）
        if (k <= 1) {
            return 0;
        }
        int prod = 1;
        int left = 0;
        int count = 0;

        for (int right = 0; right < nums.length; right++) {
            prod *= nums[right];
            // 乘积过大，收缩左边界
            while (prod >= k) {
                prod /= nums[left];
                left++;
            }
            // 以 right 结尾的合法子数组数量
            count += right - left + 1;
        }
        return count;
    }
}
```

### 复杂度

- 时间：O(n)，`right` 前进 n 次，`left` 最多前进 n 次，两者都不回退，均摊线性。
- 空间：O(1)，只维护 `prod / left / count` 等常数变量。

### 易错点与扩展（面试高频考点）

1. **`k <= 1` 必须特判**：`nums[i] >= 1`，若 `k <= 1` 则连单个元素都不满足，直接返回 0，否则会陷入错误收缩。
2. **严格小于**：循环条件是 `prod >= k` 才收缩，必须保持"等于 k 也不合法"的严格语义。
3. **计数公式不要写反**：是以 `right` 结尾的子数组数 `right - left + 1`，漏掉会少算，误用 `left - right` 会出错。
4. **不能直接对乘积取对数或整体前缀积除法**：前缀积会溢出且存在 0/负数时失效，滑动窗口更稳。
5. **扩展**：若改为"乘积大于 k 的子数组"，可用"总子数组数 − 乘积 ≤ k 的数量"；若元素可含 0，窗口性质被破坏，需重新设计。

### C++ 实现

```cpp
class Solution {
public:
    int numSubarrayProductLessThanK(vector<int>& nums, int k) {
        if (k <= 1) return 0;
        long long prod = 1;
        int left = 0;
        int count = 0;
        for (int right = 0; right < (int)nums.size(); ++right) {
            prod *= nums[right];
            while (prod >= k) {
                prod /= nums[left];
                ++left;
            }
            count += right - left + 1;
        }
        return count;
    }
};
```

### Python 实现

```python
class Solution:
    def numSubarrayProductLessThanK(self, nums: list[int], k: int) -> int:
        if k <= 1:
            return 0
        prod = 1
        left = 0
        count = 0
        for right in range(len(nums)):
            prod *= nums[right]
            while prod >= k:
                prod //= nums[left]
                left += 1
            count += right - left + 1
        return count
```
