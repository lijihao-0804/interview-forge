题目与约束

给定一个整数数组 nums 和一个整数 k，请你在数组中找到和等于 k 的最长连续子数组，并返回该子数组的长度。如果不存在这样的子数组，返回 0。

注意：数组中可能包含负数，因此不能使用简单的滑动窗口。

示例 1：

输入：nums = [1, -1, 5, -2, 3], k = 3
输出：4
解释：子数组 [1, -1, 5, -2] 的和为 3，且是最长的。

示例 2：

输入：nums = [-2, -1, 2, 1], k = 1
输出：2
解释：子数组 [-1, 2] 的和为 1，且是最长的。

提示：

  • 1 <= nums.length <= 2 * 10^4
  • -10^4 <= nums[i] <= 10^4
  • -10^5 <= k <= 10^5

核心不变量

设 sum(t) = nums[0] + … + nums[t]（以数组下标 t 结尾，空前缀记为下标 -1、和为 0），则子数组 nums[j+1..i] 的和为 sum(i) - sum(j)。要让它为 k 且区间最长，只需为每个 i 找到最早出现的 sum(j) = sum(i) - k。

完整推导

思路推导

  1. 痛点（负数让滑窗失效）

若数组全是正数，"和等于 k 的最长子数组"可以用滑动窗口：右扩、超了左缩。但本题允许负数，窗口和不再单调，滑窗会漏解，必须换方法。

  1. 前缀和转"两点差"

用前缀和把"子数组和"转成"两个前缀和相减"。设 sum(t) = nums[0] + … + nums[t]（以数组下标 t 结尾的前缀和），并约定空前缀 sum(-1) = 0。那么子数组 nums[j+1..i] 的和 = sum(i) - sum(j)。要求它等于 k，即 sum(j) = sum(i) - k。

  1. 哈希表存"最早下标"

从左往右扫，边累加得到前缀和 sum，同时用哈希表记录每个前缀和值第一次被算出来时所在的数组下标。这里有一个约定：把空前缀和 0 记为下标 -1。于是当扫到数组下标 i、当前前缀和为 sum 时，若表里存在 sum - k 且其记录的下标为 j，就说明子数组 nums[j+1..i] 的和恰为 k，长度为 i - j。为了让区间最长，一定要用最早出现的 j，所以同一个前缀和只在首次出现时写入（putIfAbsent）。

  1. 一个小例子

nums = [1,-1,5,-2,3], k = 3。初始化表 {0: -1}。扫到下标 3 时 sum = 1-1+5-2 = 3，3 - 3 = 0 记录在下标 -1，得子数组 nums[0..3] = [1,-1,5,-2]，长度 3-(-1) = 4，和为 3，正是答案。

Java 实现（前缀和 + 哈希）

import java.util.HashMap;
import java.util.Map;

class Solution {
    public int maxSubArrayLen(int[] nums, int k) {
        // key: 某前缀和；value: 该前缀和最早出现的下标（pre 的下标）
        Map<Integer, Integer> firstIndex = new HashMap<>();
        firstIndex.put(0, -1);   // 空前缀和为 0，视作下标 -1

        int sum = 0;             // 当前前缀和
        int best = 0;            // 最长长度

        for (int i = 0; i < nums.length; i++) {
            sum += nums[i];
            // 若存在前缀和 sum - k，说明中间这段子数组和为 k
            Integer j = firstIndex.get(sum - k);
            if (j != null) {
                best = Math.max(best, i - j);   // 区间 (j, i]，长度 i - j
            }
            // 只记录首次出现的位置，才能保证最长
            firstIndex.putIfAbsent(sum, i);
        }
        return best;
    }
}

复杂度

  • 时间：O(n)。遍历数组一次，哈希表均摊 O(1) 查找与插入。
  • 空间：O(n)。最坏情况下所有前缀和互不相同，哈希表存 n 个键值对。

易错点与扩展（面试高频考点）

  1. 为什么只能记"最早"下标：同一前缀和若被后来的下标覆盖，会丢失更长区间。必须用 putIfAbsent（或判空后再放），保持首次位置。
  2. 初始化 map[0] = -1：代表空前缀。缺了它，凡是"从下标 0 开始、和恰为 k"的子数组都会被漏掉。
  3. 负数场景不能用滑动窗口：这是本题最常被追问的对比点，务必强调"和不再单调，窗口无法收缩"。
  4. 长度计算：前缀和下标与前缀之间的对应关系易错。pre 下标 j 表示"前 j 个元素"，区间 (j, i] 长度为 i - j，别多减或多加 1。
  5. 扩展：同类题"和为 k 的子数组个数"（LeetCode 560）改为统计次数，哈希表存"出现次数"而非"最早下标"；"和可被 K 整除的子数组"（974）则存前缀和取模后的余数。

力扣原题

325. 和等于 k 的最长子数组长度

C++ 实现

#include <vector>
#include <unordered_map>
#include <algorithm>
using namespace std;

class Solution {
public:
    int maxSubArrayLen(vector<int>& nums, int k) {
        unordered_map<int, int> firstIndex;  // 前缀和 -> 最早下标
        firstIndex[0] = -1;                  // 空前缀
        int sum = 0, best = 0;
        for (int i = 0; i < (int)nums.size(); ++i) {
            sum += nums[i];
            auto it = firstIndex.find(sum - k);
            if (it != firstIndex.end()) {
                best = max(best, i - it->second);
            }
            // 只在首次出现时记录
            if (firstIndex.find(sum) == firstIndex.end()) {
                firstIndex[sum] = i;
            }
        }
        return best;
    }
};

Python 实现

class Solution:
    def maxSubArrayLen(self, nums: list[int], k: int) -> int:
        first_index = {0: -1}   # 前缀和 -> 最早下标
        total = 0
        best = 0
        for i, x in enumerate(nums):
            total += x
            if total - k in first_index:
                best = max(best, i - first_index[total - k])
            # 只记录首次出现的位置
            if total not in first_index:
                first_index[total] = i
        return best
