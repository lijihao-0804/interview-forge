209. 长度最小的子数组

本题学习状态正在读取学习记录…下次复习：—
本次复习：
按 M 快速切换薄弱标记
遮住推导与代码，先自己想，再逐段揭示
难度中等核心模式滑动窗口（同向双指针）时间复杂度O(n)空间复杂度O(1)

题目与约束

给定一个含有 n 个正整数的数组和一个正整数 target 。

找出该数组中满足其总和大于等于 target 的长度最小的 子数组 [numsl, numsl+1, ..., numsr-1, numsr] ，并返回其长度。如果不存在符合条件的子数组，返回 0 。

示例 1：

输入：target = 7, nums = [2,3,1,2,4,3]
输出：2
解释：子数组 [4,3] 是该条件下的长度最小的子数组。

示例 2：

输入：target = 4, nums = [1,4,4]
输出：1

示例 3：

输入：target = 11, nums = [1,1,1,1,1,1,1,1]
输出：0

提示：

  • 1 <= target <= 109

  • 1 <= nums.length <= 105

  • 1 <= nums[i] <= 104

进阶：

  • 如果你已经实现 O(n) 时间复杂度的解法, 请尝试设计一个 O(n log(n)) 时间复杂度的解法。

核心不变量

窗口 [left, right] 的区间和始终由 sum 维护；当 sum >= target 时，右端已无法再「变短而仍满足条件」，于是收缩左端更新答案，直到 sum < target 再继续扩张右端。

完整推导

思路推导

  1. 直觉与痛点（暴力枚举两端太慢）

枚举所有子数组 [l, r] 求和，复杂度 O(n^3)（或带前缀和 O(n^2)），当 n = 10^5 时无法通过。

  1. 破局思路（数组全是正数，可以用窗口）

关键前提是「所有元素为正」。这意味着：右端往右扩，和只会变大；左端往右缩，和只会变小。这种单调性让我们能用一对同向指针维护一个「窗口」，避免重复计算。

  1. 窗口的扩张与收缩

右指针 right 从 0 遍历到末尾，每次把 nums[right] 加进 sum（扩张）。当 sum >= target 时，说明当前窗口可行，尝试收缩左端：记录当前长度 right - left + 1 更新最小值，然后 sum -= nums[left]、left++，一直收缩到 sum < target 为止。整个过程每个元素最多被加一次、减一次。

  1. 小例子验证

target = 7, nums = [2,3,1,2,4,3]：窗口扩张到 [2,3,1,2] 时和 = 8 >= 7，长度 4；收缩左端到 [3,1,2]（和 6 < 7）停止。继续扩张加入 4 得 [3,1,2,4] 和 10，收缩到 [1,2,4]（和 7）长度 3；再加 3 得 [1,2,4,3]，收缩到 [4,3]（和 7）长度 2，最终答案 2。

Java 实现（minSubArrayLen）

class Solution {
    public int minSubArrayLen(int target, int[] nums) {
        int n = nums.length;
        int left = 0;
        int sum = 0;
        int minLen = Integer.MAX_VALUE; // 记录最小长度
        for (int right = 0; right < n; right++) {
            sum += nums[right];          // 右端扩张
            // 当前窗口满足条件时，尝试收缩左端
            while (sum >= target) {
                minLen = Math.min(minLen, right - left + 1);
                sum -= nums[left];
                left++;
            }
        }
        // 没有找到任何可行窗口时返回 0
        return minLen == Integer.MAX_VALUE ? 0 : minLen;
    }
}

C++ 实现

class Solution {
public:
    int minSubArrayLen(int target, vector<int>& nums) {
        int n = nums.size();
        int left = 0;
        int sum = 0;
        int minLen = INT_MAX;
        for (int right = 0; right < n; ++right) {
            sum += nums[right];          // 右端扩张
            while (sum >= target) {       // 满足条件则收缩左端
                minLen = min(minLen, right - left + 1);
                sum -= nums[left];
                ++left;
            }
        }
        return minLen == INT_MAX ? 0 : minLen;
    }
};

Python 实现

class Solution:
    def minSubArrayLen(self, target: int, nums: List[int]) -> int:
        left = 0
        total = 0
        min_len = float('inf')
        for right, x in enumerate(nums):
            total += x                    # 右端扩张
            while total >= target:        # 满足条件则收缩左端
                min_len = min(min_len, right - left + 1)
                total -= nums[left]
                left += 1
        return 0 if min_len == float('inf') else min_len

复杂度

  • 时间：O(n)。right 指针遍历一次，left 指针最多也前进 n 次，两者互不回头，总操作数 O(n)。
  • 空间：O(1)。只用了 left、sum、minLen 等常数个变量。
易错点与扩展（面试高频考点）
  1. 前提是正数：滑动窗口成立的关键是元素全为正、和具有单调性；若数组含负数，收缩左端不一定能让和变小，必须换用前缀和 + 二分或单调队列。
  2. while 而非 if：收缩左端要用 while 一直收到 sum < target，用 if 只会收缩一次，可能错过更短的窗口。
  3. 无解返回 0：用 Integer.MAX_VALUE 做初值，最后判空返回 0，不能直接返回 MAX_VALUE。
  4. 更新答案的时机：在每次成功收缩前（即窗口仍满足 sum >= target 时）用 right - left + 1 更新，此时才是当前最短可行长度。
  5. 扩展（O(n log n) 解法）：进阶要求可构造前缀和数组 pre，对每个右端点 r 用二分查找满足 pre[r] - pre[l] >= target 的最小 l，即找 pre[l] <= pre[r] - target 的最大 l，总复杂度 O(n log n)，对应标签里的 Binary Search / Prefix Sum。
