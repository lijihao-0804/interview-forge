875. 爱吃香蕉的珂珂

本题学习状态正在读取学习记录…下次复习：—
本次复习：
按 M 快速切换薄弱标记
遮住推导与代码，先自己想，再逐段揭示
难度中等核心模式二分答案：对"吃香蕉速度 k"二分，检验是否能在 h 小时内吃完时间复杂度O(n log max(piles))空间复杂度O(1)

题目与约束

珂珂喜欢吃香蕉。这里有 n 堆香蕉，第 i 堆中有 piles[i] 根香蕉。警卫已经离开了，将在 h 小时后回来。

珂珂可以决定她吃香蕉的速度 k （单位：根/小时）。每个小时，她将会选择一堆香蕉，从中吃掉 k 根。如果这堆香蕉少于 k 根，她将吃掉这堆的所有香蕉，然后这一小时内不会再吃更多的香蕉。

珂珂喜欢慢慢吃，但仍然想在警卫回来前吃掉所有的香蕉。

返回她可以在 h 小时内吃掉所有香蕉的最小速度 k（k 为整数）。

示例 1：

输入：piles = [3,6,7,11], h = 8
输出：4

示例 2：

输入：piles = [30,11,23,4,20], h = 5
输出：30

示例 3：

输入：piles = [30,11,23,4,20], h = 6
输出：23

提示：

  • 1 <= piles.length <= 104

  • piles.length <= h <= 109

  • 1 <= piles[i] <= 109

核心不变量

"以速度 k 能在 h 小时内吃完"这一性质关于 k 单调：k 越大总耗时越少；因此可以用二分法寻找最小的可行 k。

完整推导

思路推导

  1. 先解决"给定 k，要几小时"

对每一堆 pile，吃它需要 ceil(pile / k) 小时，因为每小时最多吃 k 根、吃不完不换堆。用整数写法 (pile + k - 1) / k 避免浮点误差。把所有堆的时间加起来，得到总耗时 hours(k)。

  1. 观察单调性（为什么能二分）

k 越大，每堆耗时越少，hours(k) 单调不增。我们要找的是最小的 k 使 hours(k) <= h。这正是"二分答案"的经典模型——把答案空间当成有序数组来二分。

  1. 确定二分范围

下界 lo = 1（速度至少为 1）；上界 hi = max(piles)（再快也没意义，一堆最多一次性吃完）。二分取中点 mid，若 hours(mid) <= h 说明可行，尝试更小（hi = mid）；否则 lo = mid + 1。最终 lo 即答案。

  1. 小例子（示例 1）

piles = [3,6,7,11], h = 8。 - k=3：耗时 1+2+3+4 = 10 > 8，不行。 - k=4：耗时 1+2+2+3 = 8 <= 8，可行。

最小可行 k 为 4。

Java 实现（minEatingSpeed）

class Solution {
    public int minEatingSpeed(int[] piles, int h) {
        int lo = 1;
        int hi = 0;
        for (int p : piles) {
            hi = Math.max(hi, p); // 上界取最大堆的香蕉数
        }

        while (lo < hi) {
            int mid = lo + (hi - lo) / 2; // 防止 (lo+hi) 溢出
            if (canFinish(piles, mid, h)) {
                hi = mid;       // 可行，尝试更慢
            } else {
                lo = mid + 1;   // 不可行，必须更快
            }
        }
        return lo;
    }

    // 以速度 k 是否能在 h 小时内吃完
    private boolean canFinish(int[] piles, int k, int h) {
        long hours = 0; // 用 long 防止累加溢出 int
        for (int p : piles) {
            hours += (p + k - 1) / k; // 向上取整
            if (hours > h) {          // 提前剪枝
                return false;
            }
        }
        return hours <= h;
    }
}

C++ 实现

class Solution {
public:
    int minEatingSpeed(vector<int>& piles, int h) {
        int lo = 1;
        int hi = 0;
        for (int p : piles) hi = max(hi, p);

        while (lo < hi) {
            int mid = lo + (hi - lo) / 2;
            if (canFinish(piles, mid, h)) {
                hi = mid;
            } else {
                lo = mid + 1;
            }
        }
        return lo;
    }

private:
    bool canFinish(vector<int>& piles, int k, int h) {
        long long hours = 0;
        for (int p : piles) {
            hours += (p + k - 1) / k;
            if (hours > h) return false;
        }
        return hours <= h;
    }
};

Python 实现

class Solution:
    def minEatingSpeed(self, piles: list[int], h: int) -> int:
        def can_finish(k: int) -> bool:
            hours = 0
            for p in piles:
                hours += (p + k - 1) // k  # 向上取整
                if hours > h:
                    return False
            return hours <= h

        lo, hi = 1, max(piles)
        while lo < hi:
            mid = (lo + hi) // 2
            if can_finish(mid):
                hi = mid          # 可行，尝试更慢
            else:
                lo = mid + 1      # 不可行，必须更快
        return lo

复杂度

  • 时间：O(n log M)，M = max(piles)。二分次数约 log M 次，每次 O(n) 计算总耗时。
  • 空间：O(1)，只用了左右指针与几个变量，无额外数组。
易错点与扩展（面试高频考点）
  1. 向上取整写法：(p + k - 1) / k 是整数向上取整的标准写法；直接用 p / k 会漏掉不满一小时的余数。
  2. 总耗时用 long：piles.length 可达 10^4、每堆 10^9，累加可能超过 int，Java/C++ 需 long。
  3. 二分边界：下界必须是 1（不能是 0，k 为 0 无法吃）；上界用 max(piles) 即可，写 10^9 也能过但没必要。
  4. 单调方向别搞反：hours(mid) <= h 时说明"还能更慢"，应收缩右界 hi = mid，而不是 lo = mid。
  5. 溢出与死循环：mid = lo + (hi - lo) / 2 防止 lo + hi 溢出；循环条件 lo < hi 配 hi = mid / lo = mid + 1 可保证收敛。
