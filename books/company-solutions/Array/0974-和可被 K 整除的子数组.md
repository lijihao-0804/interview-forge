# 974. 和可被 K 整除的子数组

| 题目信息 | 内容 |
|---|---|
| 难度 | 中等 |
| 核心模式 | 前缀和取模 + 余数计数（同余即差可被 K 整除） |
| 时间复杂度 | O(n) |
| 空间复杂度 | O(k) |

## 题目与约束

给定一个整数数组 `nums` 和一个整数 `k` ，返回其中元素之和可被 `k` 整除的非空 **子数组** 的数目。

**子数组** 是数组中 **连续** 的部分。

**示例 1：**

```
输入：nums = [4,5,0,-2,-3,1], k = 5
输出：7
解释：
有 7 个子数组满足其元素之和可被 k = 5 整除：
[4, 5, 0, -2, -3, 1], [5], [5, 0], [5, 0, -2, -3], [0], [0, -2, -3], [-2, -3]
```

**示例 2：**

```
输入: nums = [5], k = 9
输出: 0
```

**提示：**

- `1 <= nums.length <= 3 * 10^4`
- `-10^4 <= nums[i] <= 10^4`
- `2 <= k <= 10^4`

## 核心不变量

> 若两个前缀和对 `k` 取模的余数相同，则二者之差（对应一段连续子数组的和）必能被 `k` 整除。

## 完整推导

### 思路推导

1. **前缀和表示子数组**：设 `P[i]` 为前 `i` 个元素之和，则子数组 `nums[i..j]` 的和为 `P[j+1] - P[i]`。

2. **同余转化**：`(P[j] - P[i]) % k == 0` 当且仅当 `P[j] % k == P[i] % k`。于是"找和能被 k 整除的子数组"变成"找两个前缀和余数相同"。

3. **边扫边统计**：用一个长度 `k` 的计数数组 `count`，`count[r]` 记录目前为止余数为 `r` 的前缀和出现次数。遍历到某个前缀和时，它能与之前所有相同余数的前缀配对，答案加上 `count[r]`，然后 `count[r]++`。初始 `count[0] = 1` 代表"空前缀"，用于单独成段的子数组。

4. **处理负数**：取模在部分语言里可能得到负数，需 `((sum % k) + k) % k` 归一化（Python 的 `%` 天然非负，可直接用）。

5. **小例子（示例 1，k = 5）**：前缀和 `4,9,9,7,4,5` 的余数为 `4,4,4,2,4,0`。逐次累加相同余数的历史计数，最终得到 `7`。

### Java 实现（subarraysDivByK）

```java
class Solution {
    public int subarraysDivByK(int[] nums, int k) {
        int[] count = new int[k]; // count[r] = 前缀和余数为 r 的出现次数
        count[0] = 1;             // 空前缀，余数 0 记 1 次
        int sum = 0;
        int ans = 0;

        for (int x : nums) {
            sum += x;
            int r = ((sum % k) + k) % k; // 归一化，保证 r 在 [0, k)
            ans += count[r];             // 与之前所有同余前缀各配成一段
            count[r]++;
        }
        return ans;
    }
}
```

### 复杂度

- 时间：O(n)，只扫描数组一遍，每次 O(1) 更新。
- 空间：O(k)，计数数组大小恰为 `k`。

### 易错点与扩展（面试高频考点）

1. **负数取模**：Java/C++ 中 `-2 % 5 == -2`，必须 `((sum % k) + k) % k` 归一化，否则下标越界或统计错乱。
2. **`count[0]` 初值为 1**：代表空前缀，否则漏掉"从下标 0 开始"的合法子数组。
3. **先加再自增**：必须 `ans += count[r]` 之后才 `count[r]++`，顺序反了会把当前自己算进去。
4. **累加和范围**：`3*10^4` 个 `10^4` 量级的数之和约 `3*10^8`，用 `int` 一般安全，但要注意极端数据，必要时用 `long` 存 `sum`。
5. **衍生题**：同套"前缀和 + 哈希表计数"模板可解"和为 K 的子数组"（余数换成精确值）、"元素和可被 K 整除"等变体。

## 力扣原题

[974. 和可被 K 整除的子数组](https://leetcode.cn/problems/subarray-sums-divisible-by-k/)

### C++ 实现

```cpp
class Solution {
public:
    int subarraysDivByK(vector<int>& nums, int k) {
        vector<int> count(k, 0);
        count[0] = 1; // 空前缀
        int sum = 0, ans = 0;

        for (int x : nums) {
            sum += x;
            int r = ((sum % k) + k) % k; // 处理负数取模
            ans += count[r];
            ++count[r];
        }
        return ans;
    }
};
```

### Python 实现

```python
from typing import List


class Solution:
    def subarraysDivByK(self, nums: List[int], k: int) -> int:
        count = [0] * k
        count[0] = 1  # 空前缀
        total = 0
        ans = 0

        for x in nums:
            total += x
            r = total % k  # Python 取模结果非负，无需归一化
            ans += count[r]
            count[r] += 1

        return ans
```
