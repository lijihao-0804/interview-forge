题目与约束

给你一个整数数组 nums。如果任一值在数组中出现 至少两次，返回 true；如果数组中每个元素互不相同，返回 false。

示例 1：

输入：nums = [1,2,3,1]

输出：true

解释：元素 1 在下标 0 和 3 出现。

示例 2：

输入：nums = [1,2,3,4]

输出：false

解释：所有元素都不同。

示例 3：

输入：nums = [1,1,1,3,3,4,3,2,4,2]

输出：true

提示：

  • 1 <= nums.length <= 10^5
  • -10^9 <= nums[i] <= 10^9

核心不变量

遍历数组时维护一个「已见过元素」的集合；一旦当前元素已在集合中，就说明它至少出现了两次，可以立即返回 true。

完整推导

思路推导

  1. 最直接的想法：两两比较

对每个元素，去它后面找有没有相同的。最坏 O(n^2)，在 n = 10^5 时会超时，不可取。

  1. 用哈希集合做「查重」

我们只关心「某个值之前出现过没有」。用一个 HashSet 记录见过的值，逐个遍历 nums：若当前值已在集合中，直接返回 true；否则把它加入集合继续。示例 1 中读到第二个 1 时，集合里已有 1，立刻返回 true。

  1. 为什么是 O(n)

向哈希集合插入与查询的平均代价都是 O(1)，每个元素最多处理一次，总时间 O(n)。代价是需要额外 O(n) 空间存集合。

  1. 替代思路（省空间）

先排序再比较相邻元素，时间 O(n log n)、空间 O(1)。当内存敏感而对时间要求稍宽时可以选它，但哈希法在本题更优。

Java 实现（containsDuplicate）

import java.util.HashSet;
import java.util.Set;

class Solution {
    public boolean containsDuplicate(int[] nums) {
        Set<Integer> seen = new HashSet<>();
        for (int x : nums) {
            // Set.add 返回 false 表示该元素已存在
            if (!seen.add(x)) {
                return true;
            }
        }
        return false;
    }
}

复杂度

  • 时间：O(n)，每个元素做一次 O(1) 平均代价的哈希查询与插入，最多遍历一遍。
  • 空间：O(n)，最坏情况所有元素互不相同，集合需存下 n 个元素。

易错点与扩展（面试高频考点）

  1. 利用 add 的返回值：HashSet 的 add 在元素已存在时返回 false，一行即可完成「查重 + 插入」，比先 contains 再 add 更简洁。
  2. 不能只比较相邻：未排序时相邻元素不一定是重复值，必须借助哈希或排序。
  3. 哈希 vs 排序的取舍：哈希法 O(n) 时间 / O(n) 空间；排序法 O(n log n) 时间 / O(1) 空间，面试时可主动说明两种权衡。
  4. 数值范围大：nums[i] 可达 ±10^9，不能开数组做计数桶，必须用哈希表（或先离散化）。
  5. 扩展：若要求「存在重复且下标距离 ≤ k」（存在重复元素 II），哈希表里改存「值 → 最近下标」，遍历时判断下标差即可。

C++ 实现

class Solution {
public:
    bool containsDuplicate(vector<int>& nums) {
        unordered_set<int> seen;
        for (int x : nums) {
            // insert 的 second 为 false 表示元素已存在
            if (!seen.insert(x).second) {
                return true;
            }
        }
        return false;
    }
};

Python 实现

class Solution:
    def containsDuplicate(self, nums: list[int]) -> bool:
        seen = set()
        for x in nums:
            if x in seen:
                return True
            seen.add(x)
        return False
