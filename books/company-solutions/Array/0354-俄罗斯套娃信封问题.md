# 354. 俄罗斯套娃信封问题

| 题目信息 | 内容 |
|---|---|
| 难度 | 困难 |
| 核心模式 | 排序预处理 + 最长严格上升子序列（耐心排序 O(n log n)） |
| 时间复杂度 | O(n log n) |
| 空间复杂度 | O(n) |

## 题目与约束

给你一个二维整数数组 `envelopes`，其中 `envelopes[i] = [wi, hi]`，表示第 `i` 个信封的宽度和高度。

当另一个信封的宽度和高度都比这个信封大的时候，这个信封就可以放进另一个信封里，如同俄罗斯套娃一样。

请计算**最多能有多少个**信封能组成一组“俄罗斯套娃”信封（即可以把一个信封放到另一个信封里面）。

**注意**：不允许旋转信封。

**示例 1：**

```
输入：envelopes = [[5,4],[6,4],[6,7],[2,3]]
输出：3
解释：最多信封的个数为 3, 组合为: [2,3] => [5,4] => [6,7]。
```

**示例 2：**

```
输入：envelopes = [[1,1],[1,1],[1,1]]
输出：1
```

**提示：**

- `1 <= envelopes.length <= 10^5`
- `envelopes[i].length == 2`
- `1 <= wi, hi <= 10^5`

## 核心不变量

> 先按宽度升序、宽度相同时按高度降序排序，问题等价于对新数组中高度序列求「最长严格上升子序列」，长度即为最多套娃层数。

## 完整推导

### 思路推导

1. **为什么能转成一维？** 一个信封能套进另一个，要求宽和高**都**严格变大，这是一个二维偏序问题。如果先固定一个维度有序，就只剩另一个维度需要处理。

2. **排序规则是关键**：按宽度升序排序；当宽度相同时，按高度**降序**排序。这样做的妙处在于——宽度相同的信封在排序后高度是递减的，它们绝不可能构成严格上升子序列，于是自动排除了「同宽信封互相嵌套」的非法情况。

3. **小例子（`[[5,4],[6,4],[6,7],[2,3]]`）**：排序后为 `[2,3]、[5,4]、[6,7]、[6,4]`（宽 6 的两个按高度降序）。取高度序列 `3, 4, 7, 4`，其最长严格上升子序列是 `3, 4, 7`，长度为 3，正好对应 `[2,3] → [5,4] → [6,7]`。

4. **求 LIS 用耐心排序**：维护一个数组 `tails`，`tails[k]` 表示长度为 `k+1` 的上升子序列的最小结尾值。每个新元素用二分找到第一个 `>= 它` 的位置并替换（严格上升找下界 `lower_bound`），若比所有结尾都大则追加。最终 `tails` 的长度就是 LIS 长度。

### Java 实现（排序 + 耐心排序 LIS）

```java
import java.util.Arrays;

class Solution {
    public int maxEnvelopes(int[][] envelopes) {
        // 宽度升序；宽度相同则高度降序，避免同宽信封被错误地串联
        Arrays.sort(envelopes, (a, b) -> a[0] == b[0] ? b[1] - a[1] : a[0] - b[0]);

        int n = envelopes.length;
        int[] tails = new int[n];   // tails[k]: 长度为 k+1 的上升子序列的最小结尾
        int len = 0;                // 当前 LIS 长度

        for (int[] e : envelopes) {
            int h = e[1];
            // 在 tails[0..len) 中找第一个 >= h 的位置（严格上升用下界）
            int lo = 0, hi = len;
            while (lo < hi) {
                int mid = (lo + hi) >>> 1;
                if (tails[mid] < h) {
                    lo = mid + 1;
                } else {
                    hi = mid;
                }
            }
            tails[lo] = h;          // 替换，或追加到末尾
            if (lo == len) {
                len++;
            }
        }
        return len;
    }
}
```

### 复杂度

- 时间：排序 O(n log n)，随后 n 次二分每次 O(log n)，总 O(n log n)。
- 空间：`tails` 数组 O(n)，排序栈空间 O(log n)，整体 O(n)。

### 易错点与扩展（面试高频考点）

1. **同宽必须按高度降序**：若同宽也按升序，两个同宽信封就会因高度递增被错误地算进 LIS，答案偏大。这是本题最经典的陷阱。
2. **严格上升用下界 `lower_bound`**：因为宽高都必须严格大于，相同高度不能接在后面；若题目改成「非严格」则改用上界。
3. **别用 O(n²) 的 DP**：`n` 可达 `10^5`，`O(n²)` 会超时，必须用二分优化的 LIS。
4. **二维偏序的通用套路**：排序固定一维 + 对另一维求 LIS/最长下降，是处理「套娃、信封、数对链」一类问题的模板。
5. **`Arrays.sort` 比较器别溢出**：这里用 `b[1]-a[1]` 在 `10^5` 范围内安全，若数值更大应改用 `Integer.compare`。

### C++ 实现

```cpp
#include <vector>
#include <algorithm>
using namespace std;

class Solution {
public:
    int maxEnvelopes(vector<vector<int>>& envelopes) {
        // 宽度升序；宽度相同则高度降序
        sort(envelopes.begin(), envelopes.end(), [](const vector<int>& a, const vector<int>& b) {
            if (a[0] != b[0]) return a[0] < b[0];
            return a[1] > b[1];
        });

        vector<int> tails;   // tails[k]: 长度 k+1 的上升子序列的最小结尾
        for (const auto& e : envelopes) {
            int h = e[1];
            // 严格上升：找第一个 >= h 的位置
            auto it = lower_bound(tails.begin(), tails.end(), h);
            if (it == tails.end()) {
                tails.push_back(h);
            } else {
                *it = h;
            }
        }
        return (int)tails.size();
    }
};
```

### Python 实现

```python
import bisect
from typing import List


class Solution:
    def maxEnvelopes(self, envelopes: List[List[int]]) -> int:
        # 宽度升序；宽度相同则高度降序
        envelopes.sort(key=lambda e: (e[0], -e[1]))

        tails = []   # tails[k]: 长度 k+1 的上升子序列的最小结尾
        for _, h in envelopes:
            # 严格上升：找第一个 >= h 的位置（bisect_left）
            idx = bisect.bisect_left(tails, h)
            if idx == len(tails):
                tails.append(h)
            else:
                tails[idx] = h
        return len(tails)
```
