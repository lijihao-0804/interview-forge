# 628. 三个数的最大乘积

| 题目信息 | 内容 |
|---|---|
| 难度 | 简单 |
| 核心模式 | 排序后比较「最大三个」与「最小两个 × 最大」 |
| 时间复杂度 | O(n log n) |
| 空间复杂度 | O(log n) |

## 题目与约束

给你一个整型数组 `nums`，在数组中找出由**三个数**组成的**最大**乘积，并返回这个**最大**乘积。

**示例 1：**

```
输入：nums = [1,2,-3]
输出：-6
解释：只有三个数字 1、2 和 -3，因此最大乘积是 1 * 2 * -3 = -6。
```

**示例 2：**

```
输入：nums = [1,2,3,4]
输出：24
解释：最大的乘积来自三个最大的数字：2 * 3 * 4 = 24。
```

**示例 3：**

```
输入：nums = [-1,-2,-3]
输出：-6
解释：只有三个数字 -1、-2 和 -3，因此最大乘积是 (-1) * (-2) * (-3) = -6。
```

**提示：**

- `3 <= nums.length <= 10^4`
- `-1000 <= nums[i] <= 1000`

## 核心不变量

> 排序后，三个数的最大乘积只可能来自两种组合：最大的三个数之积，或最小的两个数（可能都是负数）与最大数之积；取两者较大即可。

## 完整推导

### 思路推导

1. **直觉与痛点（为什么不能只取最大的三个）**

   如果数组全是正数，答案显然是最大的三个数相乘。但数组里可能混有负数：两个绝对值很大的负数相乘会变成**很大的正数**，再乘上最大的正数，就可能反超「最大三个正数」的乘积。

2. **破局思路（只有两种候选）**

   把数组升序排序。设长度为 `n`，则：

   - 组合 A：`nums[n-1] * nums[n-2] * nums[n-3]`，即最大的三个数。
   - 组合 B：`nums[0] * nums[1] * nums[n-1]`，即最小的两个数（通常是两个最负的数）乘最大数。

   答案就是 `max(A, B)`。因为任意三个数之积，要么由「最靠右的三个」取得，要么靠「最靠左的两个负数配最靠右的那个」取得，其余组合都不可能更大。

3. **小例子验证**

   以 `nums = [-100,-99,1,2,3]` 为例：排序后 A `= 3*2*1 = 6`；B `= (-100)*(-99)*3 = 29700`，取 `max = 29700`，正是正确答案。反之全正数的 `[1,2,3,4]`：A `= 24`，B `= 1*2*4 = 8`，取 24。

### Java 实现（maximumProduct）

```java
import java.util.Arrays;

class Solution {
    public int maximumProduct(int[] nums) {
        // 升序排序，便于直接取两端元素
        Arrays.sort(nums);
        int n = nums.length;

        // 组合 A：最大的三个数
        int productA = nums[n - 1] * nums[n - 2] * nums[n - 3];
        // 组合 B：最小的两个数（可能是两个负数）乘以最大数
        int productB = nums[0] * nums[1] * nums[n - 1];

        // 两种候选取较大者即为答案
        return Math.max(productA, productB);
    }
}
```

### 复杂度

- 时间：`O(n log n)`，主要开销是排序；两次乘法与取最大值都是常数时间。
- 空间：`O(log n)`，排序递归栈的额外空间（若用计数/一次扫描可降到 `O(1)`）。

### 易错点与扩展（面试高频考点）

1. **只取最大的三个数**：这是最常见的错误，忽略了两个大负数相乘可能更大，必须同时计算组合 B。
2. **越界与溢出**：本题元素绝对值 ≤ 1000，乘积最大约 `10^9`，`int` 足够；但若题目放宽范围，应改用 `long` 累乘。
3. **重复元素**：排序后重复元素照常参与计算，无需去重；例如 `[5,5,5,5]` 取任意三个都得 125。
4. **长度恰好为 3**：此时 A 与 B 是同一组三个数，`max` 自然正确，无需特判。
5. **进阶（面试加分）**：本题可做到 `O(n)` 时间、`O(1)` 空间——一次遍历同时维护「最大的三个数」和「最小的两个数」，遍历结束直接按同样公式计算，无需排序。

## 力扣原题

[628. 三个数的最大乘积](https://leetcode.cn/problems/maximum-product-of-three-numbers/)

### C++ 实现

```cpp
#include <vector>
#include <algorithm>
using namespace std;

class Solution {
public:
    int maximumProduct(vector<int>& nums) {
        sort(nums.begin(), nums.end());
        int n = nums.size();

        // 组合 A：最大的三个数
        int productA = nums[n - 1] * nums[n - 2] * nums[n - 3];
        // 组合 B：最小的两个数乘以最大数
        int productB = nums[0] * nums[1] * nums[n - 1];

        return max(productA, productB);
    }
};
```

### Python 实现

```python
class Solution:
    def maximumProduct(self, nums: list[int]) -> int:
        nums.sort()
        n = len(nums)
        # 组合 A：最大的三个数；组合 B：最小的两个数乘以最大数
        product_a = nums[n - 1] * nums[n - 2] * nums[n - 3]
        product_b = nums[0] * nums[1] * nums[n - 1]
        return max(product_a, product_b)
```
