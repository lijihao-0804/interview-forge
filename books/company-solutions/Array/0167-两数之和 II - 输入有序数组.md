# 167. 两数之和 II - 输入有序数组

| 题目信息 | 内容 |
|---|---|
| 难度 | 中等 |
| 核心模式 | 双指针从两端向中间夹逼 |
| 时间复杂度 | O(n) |
| 空间复杂度 | O(1) |

## 题目与约束

给你一个下标从 1 开始的整数数组 `numbers` ，该数组已按 非递减顺序排列。

请你从数组中找出满足相加之和等于目标数 `target` 的 两个 数。令这两个数分别是 `numbers[index1]` 和 `numbers[index2]` ，其中 `1 <= index1 < index2 <= numbers.length` 。

以长度为 2 的整数数组 `[index1, index2]` 的形式返回这两个整数的下标 `index1` 和 `index2`。

你可以假设每个输入 只对应唯一的答案 ，而且你 不可以 重复使用相同的元素。

你所设计的解决方案必须只使用常数级的额外空间。

 

示例 1：

输入：numbers = [2,7,11,15], target = 9  
输出：[1,2]  
解释：2 与 7 之和等于目标数 9 。因此 index1 = 1, index2 = 2 。返回 [1, 2] 。

示例 2：

输入：numbers = [2,3,4], target = 6  
输出：[1,3]  
解释：2 与 4 之和等于目标数 6 。因此 index1 = 1, index2 = 3 。返回 [1, 3] 。

示例 3：

输入：numbers = [-1,0], target = -1  
输出：[1,2]  
解释：-1 与 0 之和等于目标数 -1 。因此 index1 = 1, index2 = 2 。返回 [1, 2] 。

 

提示：

- `2 <= numbers.length <= 3 * 104`

- `-1000 <= numbers[i] <= 1000`

- `numbers` 按 非递减顺序 排列

- `-1000 <= target <= 1000`

- 仅存在一个有效答案

[🔗 前往力扣原题验证 →](https://leetcode.cn/problems/two-sum-ii-input-array-is-sorted/)

## 核心不变量

> 因为数组有序：若 `numbers[left] + numbers[right] < target`，则 `left` 与任何更小的右端都凑不够，`left` 必须右移；反之 `right` 必须左移。答案始终被夹在 `[left, right]` 内。

## 完整推导

### 思路推导

1. **直觉与痛点（暴力与哈希的代价）**

   直接双重循环枚举所有两数之和是 `O(n^2)`，太慢；用哈希表可以在 `O(n)` 时间解决，但需要 `O(n)` 的额外空间，而本题明确要求 **常数级额外空间**。两条路都走不通，必须利用"有序"这个条件。

2. **破局思路（左右指针夹逼）**

   设置左右两个指针 `left = 0`、`right = n - 1`，分别指向最小和最大元素。

   - 若 `numbers[left] + numbers[right] == target`，找到答案；
   - 若和 **小于** `target`，最小值都只能凑这么小，`left` 位置不可能再与任何更小右端凑出目标，于是 `left++`；
   - 若和 **大于** `target`，最大值太大了，`right` 位置不可能再与任何更大左端凑出目标，于是 `right--`。

   以 `[2,7,11,15], target=9` 为例：`2+15=17>9 → right--`；`2+11=13>9 → right--`；`2+7=9 → 返回 [1,2]`。

3. **关键追问（为什么不会漏解？）**

   每一步都**排除**了一整行（或一整列）不可能的解，但正确答案始终在被保留的区间内，所以区间收缩不会丢失答案。由于题目保证唯一解，一旦相等即可直接返回。返回时注意下标要 **加 1**（题目下标从 1 开始）。

### Java 实现（twoSum）

```java
class Solution {
    public int[] twoSum(int[] numbers, int target) {
        int left = 0;
        int right = numbers.length - 1;

        while (left < right) {
            int sum = numbers[left] + numbers[right];
            if (sum == target) {
                // 题目下标从 1 开始，因此都要 +1
                return new int[]{left + 1, right + 1};
            } else if (sum < target) {
                // 和太小，左指针右移增大和
                left++;
            } else {
                // 和太大，右指针左移减小和
                right--;
            }
        }
        // 题目保证有唯一解，理论上不会走到这里
        return new int[]{-1, -1};
    }
}
```

### 复杂度

- 时间：`O(n)`，`left` 与 `right` 相向移动，总共最多走 `n` 步。
- 空间：`O(1)`，只用了两个指针变量，满足常数级额外空间要求。

### 易错点与扩展（面试高频考点）

1. **下标要加 1**：本题数组下标从 1 开始，返回值是 `[left + 1, right + 1]`，忘记加 1 是最常见的失分点。
2. **循环条件是 `left < right`**：不能写成 `<=`，否则可能让同一个元素被用两次，违反"不可重复使用相同元素"。
3. **有序是前提**：这套双指针只对有序数组成立；无序时需先排序（但会打乱下标）或改用哈希。
4. **与「1. 两数之和」对比**：无序数组用哈希表 `O(n)` 时间 `O(n)` 空间；本题有序，双指针把空间降到 `O(1)`。
5. **面试延展**：若要求返回所有不重复的二元组（如三数之和），双指针配合"跳过相邻重复元素"是标准套路。

## 力扣原题

[167. 两数之和 II - 输入有序数组](https://leetcode.cn/problems/two-sum-ii-input-array-is-sorted/)

### C++ 实现

```cpp
#include <vector>
using namespace std;

class Solution {
public:
    vector<int> twoSum(vector<int>& numbers, int target) {
        int left = 0;
        int right = (int)numbers.size() - 1;

        while (left < right) {
            int sum = numbers[left] + numbers[right];
            if (sum == target) {
                return {left + 1, right + 1}; // 下标从 1 开始
            } else if (sum < target) {
                ++left;   // 和太小，左指针右移
            } else {
                --right;  // 和太大，右指针左移
            }
        }
        return {-1, -1};
    }
};
```

### Python 实现

```python
class Solution:
    def twoSum(self, numbers: list[int], target: int) -> list[int]:
        left, right = 0, len(numbers) - 1

        while left < right:
            s = numbers[left] + numbers[right]
            if s == target:
                return [left + 1, right + 1]  # 下标从 1 开始
            elif s < target:
                left += 1   # 和太小，左指针右移
            else:
                right -= 1  # 和太大，右指针左移

        # 题目保证有唯一解，理论上不会走到这里
        return [-1, -1]
```
