# 361. 轰炸敌人

| 题目信息 | 内容 |
|---|---|
| 难度 | 中等 |
| 核心模式 | 二维前后缀统计：分别预处理每格上下左右的敌人数（遇墙清零） |
| 时间复杂度 | O(m·n) |
| 空间复杂度 | O(m·n) |

## 题目与约束

给你一个 `m × n` 的矩阵 `grid`，其中每个格子是以下三种之一：

- `'W'`：墙（Wall）；
- `'E'`：敌人（Enemy）；
- `'0'`：空位（可以用数字 0 表示）。

现在你只能在**空位**上放置一枚炸弹，返回用这枚炸弹最多能消灭的敌人数量。

炸弹会消灭它所在**同一行和同一列**上的所有敌人，但爆炸会被墙挡住——即从炸弹位置出发，沿上下左右四个方向，一旦碰到墙 `'W'` 就停止，墙后面的敌人不受影响。

**示例 1：**

```
输入：grid = [["0","E","0","0"],["E","0","W","E"],["0","E","0","0"]]
输出：3
解释：
对于如下矩阵：
0 E 0 0
E 0 W E
0 E 0 0
在 (1,1) 放置炸弹可以消灭 3 个敌人。
```

**示例 2：**

```
输入：grid = [["W","W","W"],["0","0","0"],["E","E","E"]]
输出：1
解释：
在 (1,0) 或 (1,1) 或 (1,2) 放置炸弹，最多消灭 1 个敌人（下方被一排敌人挡住）。
```

**提示：**

- `m == grid.length`
- `n == grid[i].length`
- `1 <= m, n <= 500`
- `grid[i][j]` 为 `'W'`、`'E'` 或 `'0'`

## 核心不变量

> 对每个空格，它能炸到的敌人总数 = 该行同段（被墙分隔）敌人总数 + 该列同段敌人总数；行段、列段的敌人计数可各自通过一次从左到右/从右到左、从上到下/从下到上的动态扫描得到。

## 完整推导

### 思路推导

1. **暴力为什么慢？** 若对每个空格都向四个方向暴力数敌人，最坏 O(m·n·(m+n))，`500×500` 时会超时。

2. **拆成四个方向的前后缀**。定义 `left[i][j]` 为「从 (i,j) 往左、遇到墙为止」的敌人数量，`right`、`up`、`down` 同理。它们都可以 O(m·n) 递推：
   - 从左到右：`left[i][j] = (grid=='W' ? 0 : (grid=='E'?1:0) + left[i][j-1])`。

3. **为什么能直接相加？** 对空格而言，四个方向统计的敌人互不重叠（行来自左右、列来自上下），且都止于墙，正好等于炸弹实际能炸到的全部敌人。空格自身不是敌人，也不会重复计数。

4. **小例子**：在示例 1 的 `(1,1)` 处，向左为 `E`（1 个），向右遇到 `W` 停止（0 个），向上 `E`（1 个），向下 `E`（1 个），合计 `1+0+1+1 = 3`。

### Java 实现（四方向前后缀 DP）

```java
class Solution {
    public int maxKilledEnemies(char[][] grid) {
        int m = grid.length;
        if (m == 0) return 0;
        int n = grid[0].length;

        int[][] left = new int[m][n];
        int[][] right = new int[m][n];
        int[][] up = new int[m][n];
        int[][] down = new int[m][n];

        // 行方向：左、右
        for (int i = 0; i < m; i++) {
            for (int j = 0; j < n; j++) {
                if (grid[i][j] == 'W') {
                    left[i][j] = 0;
                } else {
                    int self = grid[i][j] == 'E' ? 1 : 0;
                    left[i][j] = self + (j > 0 ? left[i][j - 1] : 0);
                }
            }
            for (int j = n - 1; j >= 0; j--) {
                if (grid[i][j] == 'W') {
                    right[i][j] = 0;
                } else {
                    int self = grid[i][j] == 'E' ? 1 : 0;
                    right[i][j] = self + (j < n - 1 ? right[i][j + 1] : 0);
                }
            }
        }

        // 列方向：上、下
        for (int j = 0; j < n; j++) {
            for (int i = 0; i < m; i++) {
                if (grid[i][j] == 'W') {
                    up[i][j] = 0;
                } else {
                    int self = grid[i][j] == 'E' ? 1 : 0;
                    up[i][j] = self + (i > 0 ? up[i - 1][j] : 0);
                }
            }
            for (int i = m - 1; i >= 0; i--) {
                if (grid[i][j] == 'W') {
                    down[i][j] = 0;
                } else {
                    int self = grid[i][j] == 'E' ? 1 : 0;
                    down[i][j] = self + (i < m - 1 ? down[i + 1][j] : 0);
                }
            }
        }

        int best = 0;
        for (int i = 0; i < m; i++) {
            for (int j = 0; j < n; j++) {
                if (grid[i][j] == '0') {        // 只在空格放炸弹
                    int total = left[i][j] + right[i][j] + up[i][j] + down[i][j];
                    best = Math.max(best, total);
                }
            }
        }
        return best;
    }
}
```

### 复杂度

- 时间：四次扫描各 O(m·n)，加上最后统计一次 O(m·n)，总 O(m·n)。
- 空间：四个 `int[m][n]` 矩阵，O(m·n)。

### 易错点与扩展（面试高频考点）

1. **只能放在空格 `'0'` 上**：墙和敌人格都不能放炸弹，最后统计时务必判断 `grid[i][j] == '0'`。
2. **遇墙清零**：墙是两个方向的分界，统计时必须 `grid=='W'` 时把计数归零，而不是跳过。
3. **空格本身不是敌人**：`self` 项只有在 `'E'` 时为 1，空格贡献 0，避免把炸弹格自己算进去。
4. **可优化到 O(n) 空间**：行方向可用一维滚动在每行内即时求出 `rowHit[j]`，列方向用一个大小为 n 的 `colHit` 数组维护，边扫边累加，把空间降到 O(n)。
5. **别重复加当前格**：由于只在空格取和，四个方向都不含空格自身，天然不会重复，无需额外去重。

### C++ 实现

```cpp
#include <vector>
#include <algorithm>
using namespace std;

class Solution {
public:
    int maxKilledEnemies(vector<vector<char>>& grid) {
        int m = grid.size();
        if (m == 0) return 0;
        int n = grid[0].size();

        vector<vector<int>> left(m, vector<int>(n, 0)), right(m, vector<int>(n, 0));
        vector<vector<int>> up(m, vector<int>(n, 0)), down(m, vector<int>(n, 0));

        for (int i = 0; i < m; ++i) {
            for (int j = 0; j < n; ++j) {
                if (grid[i][j] == 'W') left[i][j] = 0;
                else {
                    int self = grid[i][j] == 'E' ? 1 : 0;
                    left[i][j] = self + (j > 0 ? left[i][j - 1] : 0);
                }
            }
            for (int j = n - 1; j >= 0; --j) {
                if (grid[i][j] == 'W') right[i][j] = 0;
                else {
                    int self = grid[i][j] == 'E' ? 1 : 0;
                    right[i][j] = self + (j < n - 1 ? right[i][j + 1] : 0);
                }
            }
        }

        for (int j = 0; j < n; ++j) {
            for (int i = 0; i < m; ++i) {
                if (grid[i][j] == 'W') up[i][j] = 0;
                else {
                    int self = grid[i][j] == 'E' ? 1 : 0;
                    up[i][j] = self + (i > 0 ? up[i - 1][j] : 0);
                }
            }
            for (int i = m - 1; i >= 0; --i) {
                if (grid[i][j] == 'W') down[i][j] = 0;
                else {
                    int self = grid[i][j] == 'E' ? 1 : 0;
                    down[i][j] = self + (i < m - 1 ? down[i + 1][j] : 0);
                }
            }
        }

        int best = 0;
        for (int i = 0; i < m; ++i)
            for (int j = 0; j < n; ++j)
                if (grid[i][j] == '0')
                    best = max(best, left[i][j] + right[i][j] + up[i][j] + down[i][j]);
        return best;
    }
};
```

### Python 实现

```python
from typing import List


class Solution:
    def maxKilledEnemies(self, grid: List[List[str]]) -> int:
        m = len(grid)
        if m == 0:
            return 0
        n = len(grid[0])

        left = [[0] * n for _ in range(m)]
        right = [[0] * n for _ in range(m)]
        up = [[0] * n for _ in range(m)]
        down = [[0] * n for _ in range(m)]

        for i in range(m):
            for j in range(n):
                if grid[i][j] == 'W':
                    left[i][j] = 0
                else:
                    self_e = 1 if grid[i][j] == 'E' else 0
                    left[i][j] = self_e + (left[i][j - 1] if j > 0 else 0)
            for j in range(n - 1, -1, -1):
                if grid[i][j] == 'W':
                    right[i][j] = 0
                else:
                    self_e = 1 if grid[i][j] == 'E' else 0
                    right[i][j] = self_e + (right[i][j + 1] if j < n - 1 else 0)

        for j in range(n):
            for i in range(m):
                if grid[i][j] == 'W':
                    up[i][j] = 0
                else:
                    self_e = 1 if grid[i][j] == 'E' else 0
                    up[i][j] = self_e + (up[i - 1][j] if i > 0 else 0)
            for i in range(m - 1, -1, -1):
                if grid[i][j] == 'W':
                    down[i][j] = 0
                else:
                    self_e = 1 if grid[i][j] == 'E' else 0
                    down[i][j] = self_e + (down[i + 1][j] if i < m - 1 else 0)

        best = 0
        for i in range(m):
            for j in range(n):
                if grid[i][j] == '0':
                    best = max(best, left[i][j] + right[i][j] + up[i][j] + down[i][j])
        return best
```
