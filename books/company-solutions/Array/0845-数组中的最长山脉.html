难度 中等

时间复杂度 O(n)
空间复杂度 O(1)

题目与约束

把符合下列属性的数组 arr 称为 山脉数组 ：

  • arr.length >= 3

  • 存在下标 i（0 < i < arr.length - 1），满足

  • arr[0] < arr[1] < ... < arr[i - 1] < arr[i]

  • arr[i] > arr[i + 1] > ... > arr[arr.length - 1]

给出一个整数数组 arr，返回最长山脉子数组的长度。如果不存在山脉子数组，返回 0 。

示例 1：

输入：arr = [2,1,4,7,3,2,5]
输出：5
解释：最长的山脉子数组是 [1,4,7,3,2]，长度为 5。

示例 2：

输入：arr = [2,2,2]
输出：0
解释：不存在山脉子数组。

提示：

  • 1 <= arr.length <= 104

  • 0 <= arr[i] <= 104

进阶：

  • 你可以仅用一趟扫描解决此问题吗？

  • 你可以用 O(1) 空间解决此问题吗？

核心不变量

每一个合法山脉都唯一对应一个峰顶下标 i（满足 arr[i-1] < arr[i] > arr[i+1]），山脉长度 = 向左能延伸的严格下降长度 + 向右能延伸的严格下降长度 + 1。

完整推导

思路推导

  1. 山脉一定“有尖”。 任何一座山脉都必须存在唯一一个峰顶 i，满足 arr[i-1] < arr[i] 且 arr[i] > arr[i+1]。没有这样的尖顶，就不可能是“先升后降”的结构。所以问题变成：枚举每一个可能的峰顶，量出以它为顶的山脉能有多长。

  2. 向两侧量长度。 找到峰顶 i 后，从 i 向左走，只要还满足 arr[left-1] < arr[left] 就继续左移；从 i 向右走，只要还满足 arr[right] > arr[right+1] 就继续右移。停下来时的 left、right 就是这座山的两个山脚，长度 = right - left + 1。

  3. 小例子。 arr = [2,1,4,7,3,2,5]，在 i=3（值 7）处发现峰顶：向左 4<7、1<4、2<1 不成立 → left=1；向右 3<7、2<3、5<2 不成立 → right=5；得到山脉 [1,4,7,3,2]，长度 5-1+1=5。取所有峰顶的最大值即可。

  4. 为什么是 O(n)？ 每个下标在全过程中最多被访问常数次：外层指针 i 一旦跨过某段山体就会跳到该山脉右侧，不会回头重复扫描。因此总时间线性，额外只用几个下标变量，空间 O(1)。

Java 实现（一次扫描 + 双指针扩张）

class Solution {
    public int longestMountain(int[] arr) {
        int n = arr.length;
        int ans = 0;
        int i = 1; // 峰顶不可能在首尾，从下标 1 开始找
        while (i < n - 1) {
            // 只处理真正的峰顶：左低右低
            if (arr[i - 1] < arr[i] && arr[i] > arr[i + 1]) {
                // 向左扩张严格上升段的山脚
                int left = i - 1;
                while (left > 0 && arr[left - 1] < arr[left]) {
                    left--;
                }
                // 向右扩张严格下降段的山脚
                int right = i + 1;
                while (right < n - 1 && arr[right] > arr[right + 1]) {
                    right++;
                }
                ans = Math.max(ans, right - left + 1);
                // 跳过整座山，避免重复扫描
                i = right + 1;
            } else {
                i++;
            }
        }
        return ans;
    }
}

复杂度

  • 时间：O(n)。峰顶定位后指针直接跨过整段山脉，每个元素至多被访问常数次。
  • 空间：O(1)。只用 i / left / right / ans 等少数变量，未开辟额外数组。

易错点与扩展（面试高频考点）

  1. 相等元素会打断山脉。 题目要求严格递增/递减，遇到 arr[k] == arr[k+1] 时必须视为断开，不能把平台当作坡面继续延伸。
  2. 峰顶边界判定。 峰顶必须 0 < i < n-1，首尾元素永远不能当峰顶；同时山脉长度至少为 3，单点或两点都不算。
  3. 不要漏掉“跳跃”后可能的新峰。 处理完一座山后令 i = right + 1 是安全的，因为 right 右侧才开始可能的新上升段；但若图省事写死 i++，会退化但仍正确，只是常数更大。
  4. 扩展：也可以用两个方向的前后缀数组。 先预处理 up[i]（以 i 结尾的严格上升长度）与 down[i]（以 i 开头的严格下降长度），再对每个 up[i]>1 && down[i]>1 的位置合并，时间 O(n)、空间 O(n)，思路更直白但不如双指针省空间。
  5. 边界：长度小于 3 直接返回 0。 n < 3 时循环一次都不会进入，返回 0，符合题意。

C++ 实现

#include <vector>
#include <algorithm>
using namespace std;

class Solution {
public:
    int longestMountain(vector<int>& arr) {
        int n = arr.size();
        int ans = 0;
        int i = 1;
        while (i < n - 1) {
            if (arr[i - 1] < arr[i] && arr[i] > arr[i + 1]) { // 找到峰顶
                int left = i - 1;
                while (left > 0 && arr[left - 1] < arr[left]) left--;
                int right = i + 1;
                while (right < n - 1 && arr[right] > arr[right + 1]) right++;
                ans = max(ans, right - left + 1);
                i = right + 1; // 跳过整座山
            } else {
                i++;
            }
        }
        return ans;
    }
};
