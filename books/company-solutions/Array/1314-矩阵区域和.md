# 1314. 矩阵区域和

| 题目信息 | 内容 |
|---|---|
| 难度 | 中等 |
| 核心模式 | 二维前缀和 + 边界裁剪 |
| 时间复杂度 | O(m·n) |
| 空间复杂度 | O(m·n) |

## 题目与约束

给你一个 `m x n` 的矩阵 `mat` 和一个整数 `k` ，请你返回一个矩阵 `answer` ，其中每个 `answer[i][j]` 是所有满足下述条件的元素 `mat[r][c]` 的和： 

- `i - k <= r <= i + k, `

- `j - k <= c <= j + k` 且

- `(r, c)` 在矩阵内。

 

示例 1：

```
<strong>输入：</strong>mat = [[1,2,3],[4,5,6],[7,8,9]], k = 1
<strong>输出：</strong>[[12,21,16],[27,45,33],[24,39,28]]
```

示例 2：

```
<strong>输入：</strong>mat = [[1,2,3],[4,5,6],[7,8,9]], k = 2
<strong>输出：</strong>[[45,45,45],[45,45,45],[45,45,45]]
```

 

提示：

- `m == mat.length`

- `n == mat[i].length`

- `1 <= m, n, k <= 100`

- `1 <= mat[i][j] <= 100`

[🔗 前往力扣原题验证 →](https://leetcode.cn/problems/matrix-block-sum/)

## 核心不变量

> 二维前缀和 `pre[r][c] = mat[0..r-1][0..c-1]` 的全部元素之和，任意子矩阵和都能由四个前缀和一次容斥得到。

## 完整推导

### 思路推导

1. **暴力法的代价**：对每个格子 `(i, j)` 遍历它周围 (2k+1)×(2k+1) 个元素求和。最坏 k ≈ 100、矩阵 100×100，复杂度约 O(m·n·k²)，达到 10^8，容易超时，且同一片区域会被反复相加。

2. **前缀和消除重复计算**：先建一个 `(m+1) × (n+1)` 的二维前缀和：
   `pre[r][c] = pre[r-1][c] + pre[r][c-1] - pre[r-1][c-1] + mat[r-1][c-1]`。
   之后任意子矩阵 `[r1..r2] × [c1..c2]` 的和可用容斥公式 O(1) 求出：
   `pre[r2+1][c2+1] - pre[r1][c2+1] - pre[r2+1][c1] + pre[r1][c1]`。

3. **处理越界**：对每个 `(i, j)`，把真实查询范围裁剪到矩阵内：
   `r1 = max(0, i-k)`、`r2 = min(m-1, i+k)`、`c1 = max(0, j-k)`、`c2 = min(n-1, j+k)`。这也正是题目中「(r, c) 在矩阵内」的要求。

4. **小例子**：`mat = [[1,2,3],[4,5,6],[7,8,9]]`，`k = 1`，中心 `(1,1)` 覆盖整张 3×3 矩阵，和 = 45，对应输出第二行第二列 `45`；角落 `(0,0)` 只能覆盖 `[0..1]×[0..1]` = 1+2+4+5 = 12，对应 `12`。

### Java 实现（二维前缀和）

```java
class Solution {
    public int[][] matrixBlockSum(int[][] mat, int k) {
        int m = mat.length, n = mat[0].length;
        // pre[r][c] 表示 mat 中前 r 行、前 c 列的元素和
        int[][] pre = new int[m + 1][n + 1];
        for (int i = 0; i < m; i++) {
            for (int j = 0; j < n; j++) {
                pre[i + 1][j + 1] = pre[i][j + 1] + pre[i + 1][j] - pre[i][j] + mat[i][j];
            }
        }

        int[][] ans = new int[m][n];
        for (int i = 0; i < m; i++) {
            for (int j = 0; j < n; j++) {
                // 把查询窗口裁剪到矩阵范围内
                int r1 = Math.max(0, i - k);
                int r2 = Math.min(m - 1, i + k);
                int c1 = Math.max(0, j - k);
                int c2 = Math.min(n - 1, j + k);
                ans[i][j] = pre[r2 + 1][c2 + 1] - pre[r1][c2 + 1]
                          - pre[r2 + 1][c1] + pre[r1][c1];
            }
        }
        return ans;
    }
}
```

### 复杂度

- 时间：O(m·n)，建前缀和 O(m·n)，每个格子 O(1) 容斥查询，合计 O(m·n)。
- 空间：O(m·n)，前缀和数组额外占 (m+1)×(n+1)（结果数组不计入算法额外空间）。

### 易错点与扩展（面试高频考点）

1. **前缀和下标偏移**：`pre` 多开一行一列后，访问 `mat[i][j]` 对应的是 `pre[i+1][j+1]`，容斥时四个角的下标也要随之 `+1`，极易错位。
2. **边界裁剪遗漏**：不做 `max/min` 裁剪会数组越界；裁剪后无需再单独判断窗口是否合法。
3. **容斥符号**：公式为「右下 − 上 − 左 + 左上」，符号容易记反，建议画图记忆。
4. **数据类型**：本题元素 ≤ 100、矩阵 ≤ 100×100，总和不超过 10^6，`int` 安全；若元素或规模更大需用 `long`。
5. **一维前缀和替代**：也可对每一行做前缀和，再纵向累加 k 行，复杂度 O(m·n·k)，实现稍简单但更慢，面试中二维前缀和是更被期待的答案。

```cpp
class Solution {
public:
    vector<vector<int>> matrixBlockSum(vector<vector<int>>& mat, int k) {
        int m = mat.size(), n = mat[0].size();
        vector<vector<int>> pre(m + 1, vector<int>(n + 1, 0));
        for (int i = 0; i < m; ++i) {
            for (int j = 0; j < n; ++j) {
                pre[i + 1][j + 1] = pre[i][j + 1] + pre[i + 1][j] - pre[i][j] + mat[i][j];
            }
        }
        vector<vector<int>> ans(m, vector<int>(n, 0));
        for (int i = 0; i < m; ++i) {
            for (int j = 0; j < n; ++j) {
                int r1 = max(0, i - k), r2 = min(m - 1, i + k);
                int c1 = max(0, j - k), c2 = min(n - 1, j + k);
                ans[i][j] = pre[r2 + 1][c2 + 1] - pre[r1][c2 + 1]
                          - pre[r2 + 1][c1] + pre[r1][c1];
            }
        }
        return ans;
    }
};
```

```python
class Solution:
    def matrixBlockSum(self, mat: list[list[int]], k: int) -> list[list[int]]:
        m, n = len(mat), len(mat[0])
        pre = [[0] * (n + 1) for _ in range(m + 1)]
        for i in range(m):
            for j in range(n):
                pre[i + 1][j + 1] = pre[i][j + 1] + pre[i + 1][j] - pre[i][j] + mat[i][j]

        ans = [[0] * n for _ in range(m)]
        for i in range(m):
            for j in range(n):
                r1, r2 = max(0, i - k), min(m - 1, i + k)
                c1, c2 = max(0, j - k), min(n - 1, j + k)
                ans[i][j] = (pre[r2 + 1][c2 + 1] - pre[r1][c2 + 1]
                             - pre[r2 + 1][c1] + pre[r1][c1])
        return ans
```
