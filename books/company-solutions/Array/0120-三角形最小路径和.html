题目与约束

给定一个三角形 triangle ，找出自顶向下的最小路径和。

每一步只能移动到下一行中相邻的结点上。相邻的结点 在这里指的是 下标 与 上一层结点下标 相同或者等于 上一层结点下标 + 1 的两个结点。也就是说，如果正位于当前行的下标 i ，那么下一步可以移动到下一行的下标 i 或 i + 1 。

示例 1：

<strong>输入：</strong>triangle = [[2],[3,4],[6,5,7],[4,1,8,3]]
<strong>输出：</strong>11
<strong>解释：</strong>如下面简图所示：
   <strong>2</strong>
  <strong>3</strong> 4
 6 <strong>5</strong> 7
4 <strong>1</strong> 8 3
自顶向下的最小路径和为 11（即，2 + 3 + 5 + 1 = 11）。

示例 2：

<strong>输入：</strong>triangle = [[-10]]
<strong>输出：</strong>-10

提示：

  • 1 <= triangle.length <= 200

  • triangle[0].length == 1

  • triangle[i].length == triangle[i - 1].length + 1

  • -104 <= triangle[i][j] <= 104

进阶：

  • 你可以只使用 O(n) 的额外空间（n 为三角形的总行数）来解决这个问题吗？

核心不变量

自底向上时，dp[j] 表示从第 i 行第 j 个位置走到最底部的最小路径和，转移为 dp[j] = triangle[i][j] + min(dp[j], dp[j+1])，右侧的 dp[j]、dp[j+1] 都还来自下一行的旧值。

完整推导

思路推导

  1. 自上而下的痛点：如果从顶点递归往下走，每个位置都会被多条路径重复访问，朴素 DFS 是指数级复杂度。虽然加记忆化能降到 O(n²)，但仍然要记录整张表。

  2. 倒过来想更简单：一个位置到达底部的最小路径和，只取决于它正下方和右下方两个位置。所以从最后一行开始，逐行往上推，每格的最优值都由下一行相邻两格直接得出，无需递归、无需记忆化。

  3. 状态与转移：令 dp[j] 为从第 i 行第 j 个位置到底部的最小路径和。

dp[j] = triangle[i][j] + min(dp[j], dp[j+1])

初始化 dp 为最后一行的值；从倒数第二行往上遍历即可。

  1. 小例子验证：triangle = [[2],[3,4],[6,5,7],[4,1,8,3]] - 初始 dp = [4,1,8,3] - 处理 [6,5,7]：dp=[6+min(4,1), 5+min(1,8), 7+min(8,3)] = [7,6,10] - 处理 [3,4]：dp=[3+min(7,6), 4+min(6,10)] = [9,10] - 处理 [2]：dp=[2+min(9,10)] = [11]，答案 11 ✓

Java 实现（自底向上 DP）

import java.util.List;

class Solution {
    public int minimumTotal(List<List<Integer>> triangle) {
        int n = triangle.size();
        // dp[j] 表示当前行第 j 个位置到底部的最小路径和
        int[] dp = new int[n];
        // 用最后一行的值初始化
        for (int j = 0; j < n; j++) {
            dp[j] = triangle.get(n - 1).get(j);
        }
        // 从倒数第二行开始，自底向上逐行递推
        for (int i = n - 2; i >= 0; i--) {
            for (int j = 0; j <= i; j++) {
                // 从正下方 dp[j] 与右下方 dp[j+1] 中选较小者
                // 注意 j 升序遍历时 dp[j+1] 尚未被本轮覆盖，仍是下一行的旧值
                dp[j] = triangle.get(i).get(j) + Math.min(dp[j], dp[j + 1]);
            }
        }
        return dp[0];
    }
}

复杂度

  • 时间：O(n²)。三角形共有 1+2+...+n = n(n+1)/2 个元素，每个元素只被处理一次。
  • 空间：O(n)。只用一个长度为 n 的一维数组滚动保存下一行的最优值，满足进阶要求。

易错点与扩展（面试高频考点）

  1. 初始化必须用最后一行：dp 的起点是底部，用 0 初始化会把负权路径算错（本题有负值，不能靠"默认 0"）。
  2. 原地覆盖的方向：行内 j 必须从小到大遍历。这样更新 dp[j] 时，dp[j+1] 还是下一行的旧值；若从大到小，dp[j+1] 先被覆盖，min 就会算错。
  3. 索引越界：第 i 行只有 i+1 个元素，内层循环应为 j <= i，不能写成 j < n。
  4. 空间进一步优化：其实可以连 dp 数组都不新开，直接在 triangle 最后一行上原地累加，额外空间降到 O(1)（若允许修改输入）。
  5. 与"最大路径和"对比：把 min 换成 max、dp 初始化为最后一行即可求最大路径和，框架完全一致。

力扣原题

120. 三角形最小路径和

C++ 实现

#include <vector>
#include <algorithm>
using namespace std;

class Solution {
public:
    int minimumTotal(vector<vector<int>>& triangle) {
        int n = triangle.size();
        vector<int> dp(triangle.back()); // 用最后一行初始化
        for (int i = n - 2; i >= 0; --i) {
            for (int j = 0; j <= i; ++j) {
                dp[j] = triangle[i][j] + min(dp[j], dp[j + 1]);
            }
        }
        return dp[0];
    }
};

Python 实现

class Solution:
    def minimumTotal(self, triangle: list[list[int]]) -> int:
        dp = triangle[-1][:]  # 用最后一行初始化
        for i in range(len(triangle) - 2, -1, -1):
            for j in range(len(triangle[i])):
                dp[j] = triangle[i][j] + min(dp[j], dp[j + 1])
        return dp[0]
