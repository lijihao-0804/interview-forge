# 674. 最长连续递增序列

| 题目信息 | 内容 |
|---|---|
| 难度 | 简单 |
| 核心模式 | 一次遍历 + 连续段计数 |
| 时间复杂度 | O(n) |
| 空间复杂度 | O(1) |

## 题目与约束

给定一个未经排序的整数数组，找到最长且 连续递增的子序列，并返回该序列的长度。

连续递增的子序列 可以由两个下标 `l` 和 `r`（`l < r`）确定，如果对于每个 `l <= i < r`，都有 `nums[i] < nums[i + 1]` ，那么子序列 `[nums[l], nums[l + 1], ..., nums[r - 1], nums[r]]` 就是连续递增子序列。

 

示例 1：

输入：nums = [1,3,5,4,7]  
输出：3  
解释：最长连续递增序列是 [1,3,5], 长度为3。  
尽管 [1,3,5,7] 也是升序的子序列, 但它不是连续的，因为 5 和 7 在原数组里被 4 隔开。

示例 2：

输入：nums = [2,2,2,2,2]  
输出：1  
解释：最长连续递增序列是 [2], 长度为1。

 

提示：

- `1 <= nums.length <= 104`

- `-109 <= nums[i] <= 109`

[🔗 前往力扣原题验证 →](https://leetcode.cn/problems/longest-continuous-increasing-subsequence/)

## 核心不变量

> 遍历时维护「以当前位置结尾的连续递增段长度」`cur`：若 `nums[i] > nums[i-1]` 则 `cur += 1`，否则 `cur = 1`；`cur` 的最大值即为答案。

## 完整推导

### 思路推导

1. **锁定「连续」二字**。与经典 LIS 不同，本题要求子序列在 **原数组中连续**，因此不需要考虑「跳过某些元素」的组合问题，只需顺着数组走一遍，数出每一段「一直变大」的连续段长度。

2. **一趟扫描即可**。令 `cur` 为当前连续递增段的长度。从第二个元素开始，比较 `nums[i]` 与 `nums[i-1]`：
   - 若 `nums[i] > nums[i-1]`，说明还能接着涨，`cur += 1`；
   - 否则递增断掉，当前段结束，新段从 1 重新开始（`cur = 1`）。

3. **边扫边更新最大值**。每步用 `best = max(best, cur)` 记录历史最长，扫描结束 `best` 即为答案。

小例子：`nums = [1,3,5,4,7]`，`cur` 依次为 `1,2,3,1,2`，历史最大 3 ✓。

### Java 实现（一次遍历）

```java
class Solution {
    public int findLengthOfLCIS(int[] nums) {
        int n = nums.length;
        if (n == 0) {
            return 0;
        }
        int best = 1;
        int cur = 1;
        for (int i = 1; i < n; i++) {
            if (nums[i] > nums[i - 1]) {
                cur++;              // 连续递增，长度延续
            } else {
                cur = 1;            // 断掉，重新开始
            }
            best = Math.max(best, cur);
        }
        return best;
    }
}
```

### 复杂度

- 时间：O(n)。只需一次线性扫描。
- 空间：O(1)。只用了若干计数变量。

### 易错点与扩展（面试高频考点）

1. **和 LIS 搞混**：本题要求连续，不能用 `dp[j]` 任意跳跃；一旦 `nums[i] <= nums[i-1]` 必须重置为 1。
2. **严格递增**：判断条件是 `nums[i] > nums[i-1]`，相等不算递增（示例 2 中所有值相等，答案应为 1）。
3. **空数组 / 单元素**：`n == 0` 返回 0；`n == 1` 循环不执行，`best = 1` 正确。
4. **更新时机**：每次循环都要更新 `best`，不能只在重置时更新，否则最后一段会漏掉。
5. **可扩展**：若求「最长递增子序列（可不连续）」则是 LIS 问题，需 O(n²) DP 或 O(n log n) 贪心 + 二分；两者对照是高频面试辨析题。

### C++ 实现

```cpp
#include <vector>
#include <algorithm>
using namespace std;

class Solution {
public:
    int findLengthOfLCIS(vector<int>& nums) {
        int n = nums.size();
        if (n == 0) return 0;
        int best = 1, cur = 1;
        for (int i = 1; i < n; ++i) {
            if (nums[i] > nums[i - 1]) ++cur;
            else cur = 1;
            best = max(best, cur);
        }
        return best;
    }
};
```

### Python 实现

```python
class Solution:
    def findLengthOfLCIS(self, nums: list[int]) -> int:
        n = len(nums)
        if n == 0:
            return 0
        best = cur = 1
        for i in range(1, n):
            if nums[i] > nums[i - 1]:
                cur += 1
            else:
                cur = 1
            best = max(best, cur)
        return best
```
