# 518. 零钱兑换 II

| 题目信息 | 内容 |
|---|---|
| 难度 | 中等 |
| 核心模式 | 完全背包计数（组合数） |
| 时间复杂度 | O(amount × n) |
| 空间复杂度 | O(amount) |

## 题目与约束

给你一个整数数组 `coins` 表示不同面额的硬币，另给一个整数 `amount` 表示总金额。

请你计算并返回可以凑成总金额的硬币组合数。如果任何硬币组合都无法凑出总金额，返回 `0`。

假设每一种面额的硬币有无限个。

题目数据**保证**最终结果符合 **32 位**带符号整数。

**示例 1：**

```
输入：amount = 5, coins = [1, 2, 5]
输出：4
解释：有四种方式可以凑成总金额：
5=5
5=2+2+1
5=2+1+1+1
5=1+1+1+1+1
```

**示例 2：**

```
输入：amount = 3, coins = [2]
输出：0
解释：只用面额 2 的硬币不能凑成总金额 3 。
```

**示例 3：**

```
输入：amount = 10, coins = [10]
输出：1
```

**提示：**

- `1 <= coins.length <= 300`
- `1 <= coins[i] <= 5000`
- `coins` 中的所有值**互不相同**
- `0 <= amount <= 5000`

## 核心不变量

> `dp[j]` 表示"用已遍历过的这些硬币面额"凑成金额 `j` 的组合数；外层固定按硬币种类遍历，保证每种组合（不计顺序）只被计入一次。

## 完整推导

### 思路推导

1. **直觉与痛点（组合 vs 排列）**

   每次选一枚硬币、可重复选，看起来像"排列"（`2+1` 和 `1+2` 会被当成两种）。但题目要的是**组合**：`[1,2]` 与 `[2,1]` 算同一种。若内外循环写反，就会把组合数错算成排列数。

2. **破局思路（完全背包）**

   定义 `dp[j]` 为凑成金额 `j` 的方案数，`dp[0] = 1`（凑 0 元只有"一枚都不选"这一种）。**外层遍历硬币、内层金额正序**：

   ```
   for coin in coins:
       for j from coin to amount:
           dp[j] += dp[j - coin]
   ```

   外层固定在某一枚 `coin` 时，所有方案都只使用"当前及之前"的面额；同一面额可反复用（内层正序 `j` 递增让 `dp[j-coin]` 已在本轮更新过）。这样 `dp[j]` 天然按面额顺序统计，不会重复。

   以 `amount = 5, coins = [1,2,5]` 为例：只用 `1` 时只有 `dp[5]=1`（全 1）；加入 `2` 后 `dp[5]` 增加出 `2+2+1`、`2+1+1+1`；加入 `5` 后再加上 `5` 本身，最终 `dp[5]=4`。

3. **关键追问（为什么内层要正序、外层必须是硬币？）**

   - **内层正序**：完全背包每枚硬币可用无限次，正序保证用到"本枚硬币刚刚更新过"的较小金额，从而允许重复使用同一面额。
   - **外层硬币**：把"面额"放到外层，组合只按面额种类累计；如果外层改成金额、内层遍历硬币（`dp[j] += dp[j-c]` 对每个 j），则同一组合会因选择顺序不同被多次计数，变成排列数（对应 LeetCode 377 组合总和 IV）。

### Java 实现（完全背包 + 一维滚动）

```java
class Solution {
    public int change(int amount, int[] coins) {
        // dp[j]：凑成金额 j 的组合数
        int[] dp = new int[amount + 1];
        dp[0] = 1; // 凑成 0 元：什么都不选，1 种方案

        // 外层遍历硬币（保证组合不重复），内层正序遍历金额（允许重复使用）
        for (int coin : coins) {
            for (int j = coin; j <= amount; j++) {
                dp[j] += dp[j - coin];
            }
        }

        return dp[amount];
    }
}
```

### 复杂度

- 时间：O(amount × n)。`n` 为硬币种数，每种硬币对 `amount` 个状态各更新一次。
- 空间：O(amount)。一维滚动数组保存每个金额的方案数。

### 易错点与扩展（面试高频考点）

1. **内外循环写反 → 算成排列数**：把 `amount` 放外层、`coins` 放内层，得到的是"组合总和 IV"（LeetCode 377）的答案。本题必须**硬币在外、金额在内**。
2. **内层次序写反 → 变成 0/1 背包**：若内层写 `for (int j = amount; j >= coin; j--)`，每枚硬币只能用一次，结果错误。完全背包内层必须正序。
3. **`dp[0] = 1` 不可省**：它是所有递推的种子，漏掉会全为 0。
4. **整数溢出**：题目保证最终结果在 32 位带符号范围内，用 `int` 足够；若扩展到更大规模需改 `long`。
5. **对比 LeetCode 322 零钱兑换**：322 求"最少硬币数"（求最优值），本题求"方案数"（求计数），递推从 `min` 变为 `+=`。

## 力扣原题

[518. 零钱兑换 II](https://leetcode.cn/problems/coin-change-ii/)

### C++ 实现

```cpp
#include <vector>
using namespace std;

class Solution {
public:
    int change(int amount, vector<int>& coins) {
        // dp[j]：凑成金额 j 的组合数
        vector<int> dp(amount + 1, 0);
        dp[0] = 1; // 凑 0 元只有一种方案

        // 外层硬币、内层金额正序
        for (int coin : coins) {
            for (int j = coin; j <= amount; j++) {
                dp[j] += dp[j - coin];
            }
        }

        return dp[amount];
    }
};
```

### Python 实现

```python
class Solution:
    def change(self, amount: int, coins: list[int]) -> int:
        # dp[j]：凑成金额 j 的组合数
        dp = [0] * (amount + 1)
        dp[0] = 1  # 凑 0 元只有一种方案

        # 外层硬币、内层金额正序
        for coin in coins:
            for j in range(coin, amount + 1):
                dp[j] += dp[j - coin]

        return dp[amount]
```
