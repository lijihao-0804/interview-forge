题目与约束

给你一个整数数组 nums。

请你选择数组的两个 不同 下标 i 和 j，

返回 (nums[i] - 1) * (nums[j] - 1) 的 最大值。

示例 1：

输入：nums = [3,4,5,2]
输出：12
解释：如果选择下标 i=1 和 j=2（下标从 0 开始），则可以获得最大值，(nums[1]-1)(nums[2]-1) = (4-1)(5-1) = 3*4 = 12 。

示例 2：

输入：nums = [1,5,4,5]
输出：16
解释：选择下标 i=1 和 j=3（下标从 0 开始），则可以获得最大值 (5-1)*(5-1) = 16 。

示例 3：

输入：nums = [3,7]
输出：12

提示：

  • 2 <= nums.length <= 500

  • 1 <= nums[i] <= 10^3

核心不变量

因为每个数都 ≥ 1，(x-1) 单调不减，所以乘积最大的两个下标，必然对应数组中 最大的两个元素。只需找到最大值与次大值即可。

完整推导

思路推导

  1. 把目标转化为「挑最大的两个数」 目标是最大化 (nums[i]-1)*(nums[j]-1)。由于所有 nums[i] >= 1，x-1 是非负且随 x 单调递增的，因此让乘积最大，就是让两个因子尽可能大，也就是选出数组中最大的两个元素。

  2. 先排序的朴素做法 把数组升序排序，取最后两个元素 a = nums[n-2]、b = nums[n-1]，答案即 (a-1)*(b-1)。复杂度 O(n log n)，正确但多做了排序。

  3. 一次遍历更优：维护最大值与次大值 用两个变量 max1（最大）、max2（次大）扫一遍：遇到比 max1 大的，就把原 max1 降级为 max2、新元素成为 max1；否则若比 max2 大就更新 max2。扫描结束即得到最大的两个数。小例子：[1,5,4,5]，最终 max1=5, max2=5，答案 (5-1)*(5-1)=16。

Java 实现（maxProduct）

class Solution {
    public int maxProduct(int[] nums) {
        // max1 为最大值，max2 为次大值
        int max1 = 0, max2 = 0;
        for (int x : nums) {
            if (x > max1) {
                max2 = max1; // 原最大值降级为次大值
                max1 = x;
            } else if (x > max2) {
                max2 = x;    // 更新次大值
            }
        }
        return (max1 - 1) * (max2 - 1);
    }
}

复杂度

  • 时间：O(n)。只需遍历数组一次，每个元素做常数次比较。
  • 空间：O(1)。仅使用两个额外变量。

易错点与扩展（面试高频考点）

  1. 初始值设置：由于 nums[i] >= 1，把 max1、max2 初始化为 0 是安全的；若数组可能含负数或 0，则要初始化为 Integer.MIN_VALUE，并小心「次大值」逻辑。
  2. 更新顺序别写反：发现新最大值时，必须先把旧 max1 赋给 max2，再更新 max1；顺序颠倒会丢失次大值。
  3. 下标必须不同：本题保证取两个不同下标。若用排序取末尾两个元素，自然满足；若用一次遍历，最大值与次大值来自不同位置，也满足。
  4. 不要用两重循环：枚举所有 (i,j) 是 O(n²)，虽然本题 n≤500 能过，但面试更希望看到 O(n) 的一趟扫描。
  5. 扩展：若要求「乘积最大」而非「(x-1) 乘积最大」（如 LeetCode 628 三个数的最大乘积），就不能只取最大的两个，还要考虑两个负数相乘为正的情况，需要同时维护最小两个数与最大三个数。

C++ 实现

#include <vector>
using namespace std;

class Solution {
public:
    int maxProduct(vector<int>& nums) {
        int max1 = 0, max2 = 0; // 最大值与次大值
        for (int x : nums) {
            if (x > max1) {
                max2 = max1;
                max1 = x;
            } else if (x > max2) {
                max2 = x;
            }
        }
        return (max1 - 1) * (max2 - 1);
    }
};
