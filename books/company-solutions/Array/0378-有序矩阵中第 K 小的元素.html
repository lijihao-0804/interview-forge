378. 有序矩阵中第 K 小的元素

本题学习状态正在读取学习记录…下次复习：—
本次复习：
按 M 快速切换薄弱标记
遮住推导与代码，先自己想，再逐段揭示
难度中等核心模式在值域上二分答案，用阶梯计数统计 <= mid 的元素个数时间复杂度O(n·log(max−min))空间复杂度O(1)

题目与约束

给你一个 n x n 矩阵 matrix ，其中每行和每列元素均按升序排序，找到矩阵中第 k 小的元素。 请注意，它是 排序后 的第 k 小元素，而不是第 k 个 不同 的元素。

你必须找到一个内存复杂度优于 O(n2) 的解决方案。

示例 1：

输入：matrix = [[1,5,9],[10,11,13],[12,13,15]], k = 8
输出：13
解释：矩阵中的元素为 [1,5,9,10,11,12,13,13,15]，第 8 小元素是 13

示例 2：

输入：matrix = [[-5]], k = 1
输出：-5

提示：

  • n == matrix.length

  • n == matrix[i].length

  • 1 <= n <= 300

  • -109 <= matrix[i][j] <= 109

  • 题目数据 保证 matrix 中的所有行和列都按 非递减顺序 排列

  • 1 <= k <= n2

进阶：

  • 你能否用一个恒定的内存(即 O(1) 内存复杂度)来解决这个问题?

  • 你能在 O(n) 的时间复杂度下解决这个问题吗?这个方法对于面试来说可能太超前了，但是你会发现阅读这篇文章（ this paper ）很有趣。

核心不变量

在值域 [最小值, 最大值] 上二分答案 x，用「阶梯法」以 O(n) 统计矩阵中 <= x 的元素个数 count(x)；count(x) 随 x 单调不减，最小的满足 count(x) >= k 的 x 就是第 k 小元素。

完整推导

思路推导

  1. 暴力为什么不行：最直接的做法是把 n^2 个元素全部读出来排序，时间 O(n^2 log n)、空间 O(n^2)。题目明确要求「内存复杂度优于 O(n^2)」，所以必须放弃「把所有元素摊平」的想法。

  2. 从「找值」转为「数个数」：与其一个个找第 k 小，不如问「有多少个元素 <= x」。定义 count(x) = 矩阵中 <= x 的元素个数。显然 x 越大 count(x) 越大（单调不减）。第 k 小的元素正是使 count(x) >= k 成立的最小 x——这就是典型的「二分答案」。

  3. 如何快速算 count(x)：利用「每行每列都升序」。从左下角 (n-1, 0) 出发： - 若 matrix[row][col] <= x，说明这一列从第 0 行到第 row 行全都 <= x（列升序），直接累加 row + 1 个，然后向右走 col++； - 否则 matrix[row][col] > x，说明当前行这一格及其右侧都太大，向上缩 row--。 - 每次要么 row 减一要么 col 加一，最多走 2n 步，因此单次 count 是 O(n)。

  4. 二分收敛：在整数区间 [matrix[0][0], matrix[n-1][n-1]] 上二分，mid = lo + (hi-lo)/2，若 count(mid) >= k 则 hi = mid，否则 lo = mid + 1。收敛时 lo 即答案。

Java 实现（值域二分 + 阶梯计数）

class Solution {
    public int kthSmallest(int[][] matrix, int k) {
        int n = matrix.length;
        int lo = matrix[0][0];           // 最小值（左上角）
        int hi = matrix[n - 1][n - 1];   // 最大值（右下角）

        while (lo < hi) {
            int mid = lo + (hi - lo) / 2; // 防溢出写法
            if (countLE(matrix, mid, n) >= k) {
                hi = mid;        // 答案不超过 mid
            } else {
                lo = mid + 1;    // 答案大于 mid
            }
        }
        return lo;
    }

    // 统计矩阵中 <= target 的元素个数，从左下角沿阶梯走，O(n)
    private int countLE(int[][] matrix, int target, int n) {
        int count = 0;
        int row = n - 1;   // 从左下角出发
        int col = 0;
        while (row >= 0 && col < n) {
            if (matrix[row][col] <= target) {
                count += row + 1; // 第 col 列的前 row+1 行都 <= target
                col++;            // 该列统计完，向右移动
            } else {
                row--;            // 当前格太大，整行右侧更大，向上收缩
            }
        }
        return count;
    }
}

C++ 实现

#include <vector>
using namespace std;

class Solution {
public:
    int kthSmallest(vector<vector<int>>& matrix, int k) {
        int n = (int)matrix.size();
        int lo = matrix[0][0];
        int hi = matrix[n - 1][n - 1];

        while (lo < hi) {
            int mid = lo + (hi - lo) / 2;
            if (countLE(matrix, mid, n) >= k) {
                hi = mid;
            } else {
                lo = mid + 1;
            }
        }
        return lo;
    }

private:
    // 从左下角沿阶梯统计 <= target 的元素个数
    int countLE(const vector<vector<int>>& matrix, int target, int n) {
        int count = 0;
        int row = n - 1;
        int col = 0;
        while (row >= 0 && col < n) {
            if (matrix[row][col] <= target) {
                count += row + 1;
                ++col;
            } else {
                --row;
            }
        }
        return count;
    }
};

Python 实现

class Solution:
    def kthSmallest(self, matrix: list[list[int]], k: int) -> int:
        n = len(matrix)
        lo, hi = matrix[0][0], matrix[n - 1][n - 1]

        def count_le(target: int) -> int:
            # 从左下角沿阶梯统计 <= target 的元素个数
            count, row, col = 0, n - 1, 0
            while row >= 0 and col < n:
                if matrix[row][col] <= target:
                    count += row + 1
                    col += 1
                else:
                    row -= 1
            return count

        while lo < hi:
            mid = lo + (hi - lo) // 2
            if count_le(mid) >= k:
                hi = mid
            else:
                lo = mid + 1
        return lo

复杂度

  • 时间：O(n · log(hi − lo))。值域二分的次数约为 log(max−min)（本题值域可达 2·10^9，约 31 次），每次 count 扫描 O(n)。
  • 空间：O(1)。只用几个整型变量，未申请与 n^2 规模相关的额外空间，满足进阶的内存要求。
易错点与扩展（面试高频考点）
  1. 求的是第 k 小而非第 k 个不同值：count(x) 统计的是「元素个数」而不是「不同值的个数」，重复元素要重复计数，否则示例 1 会算错。
  2. 负数与二分溢出：值域含 -10^9，必须用 lo + (hi - lo) / 2 而非 (lo + hi) / 2，避免整型溢出。
  3. 二分边界写法：用 while (lo < hi)、hi = mid 收缩、返回 lo，不要写成 lo <= hi，否则容易死循环或越界。
  4. count 的单调性：二分答案的正确性完全依赖 count(x) 单调不减，务必能向面试官证明「x 增大只会让更多元素满足」。
  5. 其他解法对照：也可用「小顶堆归并」——把每行首元素入堆，弹出 k 次，时间 O(k log n)、空间 O(n)；或用二分 + 计数（本题解，空间 O(1) 最优）。线性 O(n) 的做法需基于「按值域分割」的高级技巧，属于加分项。
