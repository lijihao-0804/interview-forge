题目与约束

给你一个目录信息列表 paths，其中每一项描述了某个目录及其下所有文件的名称与内容。请你找出文件系统中所有内容完全相同的文件，并按内容分组返回它们的完整路径。答案可按任意顺序返回。

一组重复文件至少包含两个内容完全相同的文件。

输入列表中的每一项是一个字符串，格式为：

"root/d1/d2/.../dm f1.txt(f1_content) f2.txt(f2_content) ... fn.txt(fn_content)"

表示目录 root/d1/d2/.../dm 下有 n 个文件 f1.txt, f2.txt, ... fn.txt，内容依次为 f1_content, f2_content, ... fn_content。其中 n >= 1、m >= 0；当 m = 0 时表示该目录就是根目录。

输出是一个「重复文件路径组」构成的列表，每组由所有内容相同的文件的完整路径组成，完整路径格式为 directory_path/file_name.txt。

示例 1：

输入：paths = ["root/a 1.txt(abcd) 2.txt(efgh)","root/c 3.txt(abcd)","root/c/d 4.txt(efgh)","root 4.txt(efgh)"]
输出：[["root/a/2.txt","root/c/d/4.txt","root/4.txt"],["root/a/1.txt","root/c/3.txt"]]

示例 2：

输入：paths = ["root/a 1.txt(abcd) 2.txt(efgh)","root/c 3.txt(abcd)","root/c/d 4.txt(efgh)"]
输出：[["root/a/2.txt","root/c/d/4.txt"],["root/a/1.txt","root/c/3.txt"]]

提示：

  • 1 <= paths.length <= 2 * 10^4
  • 1 <= paths[i].length <= 3000
  • 1 <= sum(paths[i].length) <= 5 * 10^5
  • paths[i] 由英文字母、数字以及 '/'、'.'、'('、')'、' ' 组成
  • 同一目录中不会有文件或子目录同名
  • 每个目录信息代表唯一目录，目录路径与文件信息之间用单个空格分隔

进阶：

  • 若面对真实文件系统，你会用广度优先还是深度优先搜索？
  • 若文件内容非常大（GB 级别），你会如何修改方案？
  • 若每次只能读取 1 KB，你会如何修改？
  • 修改后方案的时间复杂度是多少？最耗时和最耗内存的部分是什么？如何优化？
  • 如何确保找到的重复文件不是误报？

核心不变量

内容相同的文件必然落在哈希表的同一个桶里，因此「以内容为键、以路径列表为值」即可一次性聚出所有重复组。

完整推导

思路推导

  1. 直觉与痛点（怎么判断「内容相同」）

题目给的是文本形式的目录清单，每个文件的路径不同、内容可能相同。要成组，本质是一次「按内容归类」的聚合问题。最自然的做法是：用一个哈希表，键是文件内容，值是所有拥有该内容的文件路径列表。遍历完所有文件后，凡是路径列表长度大于 1 的，就是一组重复文件。

  1. 第一步：解析字符串

每个 paths[i] 用空格切成若干段：第一段是目录路径 dir，后面每段是一个 文件名(内容) 形式的 token。对每个 token，用第一个 '(' 切出文件名，用最后一个 ')' 切出内容，拼成完整路径 dir + "/" + 文件名。

以 "root/a 1.txt(abcd) 2.txt(efgh)" 为例：dir = "root/a"，两个 token 分别解出 1.txt（内容 abcd）与 2.txt（内容 efgh）。

  1. 第二步：哈希表聚合

把 dir + "/" + 文件名 追加到 map[内容] 的列表里。示例 1 中内容 efgh 对应三个路径，内容 abcd 对应两个路径，最后把长度大于 1 的列表收集起来即可。

  1. 为什么只扫一遍就够

每个文件只出现一次，解析与插入都是常数（相对字符串长度）操作，聚合完成后按内容分好的组天然满足「内容完全相同」。无须两两比较，避免了 O(F²) 的爆炸。

Java 实现（哈希表分组）

import java.util.ArrayList;
import java.util.HashMap;
import java.util.List;
import java.util.Map;

class Solution {
    public List<List<String>> findDuplicate(String[] paths) {
        // 键：文件内容；值：拥有该内容的所有文件完整路径
        Map<String, List<String>> map = new HashMap<>();

        for (String path : paths) {
            // 按空格切分，第 0 段是目录，其余每段是 "文件名(内容)"
            String[] parts = path.split(" ");
            String dir = parts[0];
            for (int i = 1; i < parts.length; i++) {
                String token = parts[i];
                int l = token.indexOf('(');
                int r = token.lastIndexOf(')');
                String name = token.substring(0, l);        // 文件名
                String content = token.substring(l + 1, r); // 括号内的内容
                map.computeIfAbsent(content, k -> new ArrayList<>())
                   .add(dir + "/" + name);
            }
        }

        // 收集所有路径数大于 1 的组，即为重复文件
        List<List<String>> res = new ArrayList<>();
        for (List<String> group : map.values()) {
            if (group.size() > 1) {
                res.add(group);
            }
        }
        return res;
    }
}

复杂度

  • 时间：O(S)，S 为所有输入字符串的总长度。每个字符基本只被扫描常数次，哈希插入均摊 O(1)。
  • 空间：O(S)，哈希表中存放了全部文件路径，总量与输入规模同阶。

易错点与扩展（面试高频考点）

  1. 解析切分点：文件名里可能含 .，内容里可能含 (、)、. 等字符，所以要用第一个 '(' 和最后一个 ')' 定位，不能简单用 split("\\(")。
  2. 内容作为键的陷阱：若内容非常大（GB 级），直接把内容当键会撑爆内存——进阶答案应改为「先按文件大小分组，再对同大小文件计算哈希/只比较哈希相同的文件」，最后逐字节校验避免哈希碰撞误报。
  3. 只需返回重复组：路径列表长度为 1 的条目要过滤掉，否则会把所有文件都返回。
  4. 不要在比较阶段两两比较：O(F²) 会超时，哈希分组才是正解。
  5. 进阶思考：真实文件系统用 DFS/BFS 均可，BFS 内存更平稳；只读 1 KB 时可用滚动哈希（如 Rabin-Karp）边读边比对，避免一次载入整文件。

力扣原题

609. 在系统中查找重复文件

C++ 实现

#include <vector>
#include <string>
#include <unordered_map>
using namespace std;

class Solution {
public:
    vector<vector<string>> findDuplicate(vector<string>& paths) {
        unordered_map<string, vector<string>> mp; // 内容 -> 路径列表

        for (const string& path : paths) {
            size_t pos = path.find(' ');              // 目录与文件之间的空格
            string dir = path.substr(0, pos);
            while (pos != string::npos) {
                size_t next = path.find(' ', pos + 1); // 下一个 token 的边界
                string token = path.substr(
                    pos + 1,
                    next == string::npos ? string::npos : next - pos - 1);
                size_t l = token.find('(');
                size_t r = token.rfind(')');
                string name = token.substr(0, l);
                string content = token.substr(l + 1, r - l - 1);
                mp[content].push_back(dir + "/" + name);
                pos = next;
            }
        }

        vector<vector<string>> res;
        for (auto& kv : mp) {
            if (kv.second.size() > 1) res.push_back(kv.second);
        }
        return res;
    }
};

Python 实现

class Solution:
    def findDuplicate(self, paths: list[str]) -> list[list[str]]:
        mp = {}  # 内容 -> 路径列表

        for path in paths:
            parts = path.split(" ")      # 第 0 段是目录，其余是 "文件名(内容)"
            directory = parts[0]
            for token in parts[1:]:
                l = token.index("(")     # 第一个左括号
                r = token.rindex(")")    # 最后一个右括号
                name = token[:l]
                content = token[l + 1:r]
                mp.setdefault(content, []).append(directory + "/" + name)

        # 只保留至少两个文件的内容组
        return [files for files in mp.values() if len(files) > 1]
