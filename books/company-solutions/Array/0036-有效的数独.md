# 36. 有效的数独

| 题目信息 | 内容 |
|---|---|
| 难度 | 中等 |
| 核心模式 | 一次遍历 + 行/列/宫三组哈希状态表 |
| 时间复杂度 | O(1)（固定 81 格） |
| 空间复杂度 | O(1) |

## 题目与约束

请你判断一个 `9 x 9` 的数独是否有效。只需要**根据以下规则**，验证已经填入的数字是否有效即可。

- 数字 `1-9` 在每一行只能出现一次。
- 数字 `1-9` 在每一列只能出现一次。
- 数字 `1-9` 在每一个以粗实线分隔的 `3x3` 宫内只能出现一次。

**注意：**

- 一个有效的数独（部分已被填充）不一定是可解的。
- 只需要根据以上规则，验证已经填入的数字是否有效即可。
- 空白格用 `'.'` 表示。

**示例 1：**

```
输入：board = 
[["5","3",".",".","7",".",".",".","."]
,["6",".",".","1","9","5",".",".","."]
,[".","9","8",".",".",".",".","6","."]
,["8",".",".",".","6",".",".",".","3"]
,["4",".",".","8",".","3",".",".","1"]
,["7",".",".",".","2",".",".",".","6"]
,[".","6",".",".",".",".","2","8","."]
,[".",".",".","4","1","9",".",".","5"]
,[".",".",".",".","8",".",".","7","9"]]
输出：true
```

**示例 2：**

```
输入：board = 
[["8","3",".",".","7",".",".",".","."]
,["6",".",".","1","9","5",".",".","."]
,[".","9","8",".",".",".",".","6","."]
,["8",".",".",".","6",".",".",".","3"]
,["4",".",".","8",".","3",".",".","1"]
,["7",".",".",".","2",".",".",".","6"]
,[".","6",".",".",".",".","2","8","."]
,[".",".",".","4","1","9",".",".","5"]
,[".",".",".",".","8",".",".","7","9"]]
输出：false
解释：除了第一行的第一个数字从 5 改为 8 以外，空格内其他数字均与示例 1 相同。但由于位于左上角的 3x3 宫内有两个 8 存在，因此这个数独是无效的。
```

**提示：**

- `board.length == 9`
- `board[i].length == 9`
- `board[i][j]` 是一位数字（`1-9`）或者 `'.'`

## 核心不变量

> 遍历到格子 `(i, j)` 时，若它所在的行 `i`、列 `j`、宫 `b` 中任一已出现该数字，则数独无效；否则把该数字同时登记进这三处的状态表。

## 完整推导

### 思路推导

1. **直觉与痛点（怎么分别校验三种约束？）**

   规则说得清楚：行内不重复、列内不重复、宫内不重复。若分三趟分别检查行、列、宫，逻辑直白但代码冗长。更妙的是：同一次扫描中，一个格子可以**同时**接受这三重校验。

2. **破局思路（给每行/每列/每宫各配一张"已出现"表）**

   开三个 `9 x 9` 的布尔表：`rows[i][d]` 表示第 `i` 行是否出现过数字 `d`，`cols[j][d]`、`boxes[b][d]` 同理。扫描到非空格时，若这三张表里任意一处已为 `true`，立刻返回 `false`；否则把它们都置为 `true`。

3. **关键追问（格子 `(i,j)` 属于哪个宫？）**

   把 9x9 切成 3x3 的大格，宫的编号可以用 `box = (i / 3) * 3 + (j / 3)` 求出。例如 `(4,7)`：`4/3=1`、`7/3=2`，宫号 `1*3+2 = 5`（即中间行、最右列那一宫）。这个映射是整道题唯一需要记住的公式。

4. **数字下标**

   字符 `'1'..'9'` 转成 `0..8` 的下标：`num = c - '1'`。空格 `'.'` 直接跳过，不参与登记。

### Java 实现（isValidSudoku）

```java
class Solution {
    public boolean isValidSudoku(char[][] board) {
        // rows[i][d]：第 i 行是否已出现数字 d（d = 0..8 对应 1..9）
        boolean[][] rows = new boolean[9][9];
        boolean[][] cols = new boolean[9][9];
        boolean[][] boxes = new boolean[9][9];

        for (int i = 0; i < 9; i++) {
            for (int j = 0; j < 9; j++) {
                char c = board[i][j];
                if (c == '.') {
                    continue;                 // 空格不参与校验
                }
                int num = c - '1';            // 映射到 0..8
                int box = (i / 3) * 3 + j / 3; // 所在 3x3 宫的编号

                // 任一维度已出现该数字 -> 无效
                if (rows[i][num] || cols[j][num] || boxes[box][num]) {
                    return false;
                }
                rows[i][num] = cols[j][num] = boxes[box][num] = true;
            }
        }
        return true;
    }
}
```

### 复杂度

- 时间：`O(1)`。棋盘固定 81 格，每格常数次操作；写作 `O(9*9)` 亦等价于常数。
- 空间：`O(1)`。三张 `9 x 9` 布尔表大小固定，不随输入增长。

### 易错点与扩展（面试高频考点）

1. **宫编号公式写错**：必须用 `(i/3)*3 + j/3`，不要写成 `(i/3)*3 + (j/3)*3` 之类的错误形式。
2. **先判后登记**：一定要"检查冲突 → 再写入"，顺序颠倒会让同一个数字与自身冲突而误判。
3. **只判有效性，不判可解性**：题目只要规则合法，不要求能填满；不要多想成"解数独"。
4. **用位掩码更省**：`rows[i]` 可用一个 `int` 的 9 个二进制位表示"该数字是否出现"，`mask & (1<<num)` 判重，能进一步压缩空间，也是面试加分写法。
5. **扩展**：本题状态表思路是"解数独"（第 37 题）回溯法的校验基础，先把这里的判重写顺，再去写回溯会顺畅很多。

### C++ 实现

```cpp
#include <vector>
using namespace std;

class Solution {
public:
    bool isValidSudoku(vector<vector<char>>& board) {
        bool rows[9][9] = {false};
        bool cols[9][9] = {false};
        bool boxes[9][9] = {false};

        for (int i = 0; i < 9; i++) {
            for (int j = 0; j < 9; j++) {
                char c = board[i][j];
                if (c == '.') continue;

                int num = c - '1';
                int box = (i / 3) * 3 + j / 3;

                if (rows[i][num] || cols[j][num] || boxes[box][num]) {
                    return false;
                }
                rows[i][num] = cols[j][num] = boxes[box][num] = true;
            }
        }
        return true;
    }
};
```

### Python 实现

```python
class Solution:
    def isValidSudoku(self, board: list[list[str]]) -> bool:
        rows = [[False] * 9 for _ in range(9)]
        cols = [[False] * 9 for _ in range(9)]
        boxes = [[False] * 9 for _ in range(9)]

        for i in range(9):
            for j in range(9):
                c = board[i][j]
                if c == '.':
                    continue

                num = ord(c) - ord('1')       # 映射到 0..8
                box = (i // 3) * 3 + j // 3   # 所在 3x3 宫的编号

                if rows[i][num] or cols[j][num] or boxes[box][num]:
                    return False

                rows[i][num] = cols[j][num] = boxes[box][num] = True

        return True
```
