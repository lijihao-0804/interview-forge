# 164. 最大间距

| 题目信息 | 内容 |
|---|---|
| 难度 | 中等 |
| 核心模式 | 桶排序 / 抽屉原理 |
| 时间复杂度 | O(n) |
| 空间复杂度 | O(n) |

## 题目与约束

给定一个无序的数组 `nums`，返回 数组在排序之后，相邻元素之间最大的差值 。如果数组元素个数小于 2，则返回 `0` 。

您必须编写一个在「线性时间」内运行并使用「线性额外空间」的算法。

 

示例 1:

输入: nums = [3,6,9,1]  
输出: 3  
解释: 排序后的数组是 [1,3,6,9], 其中相邻元素 (3,6) 和 (6,9) 之间都存在最大差值 3。

示例 2:

输入: nums = [10]  
输出: 0  
解释: 数组元素个数小于 2，因此返回 0。

 

提示:

- `1 <= nums.length <= 105`

- `0 <= nums[i] <= 109`

[🔗 前往力扣原题验证 →](https://leetcode.cn/problems/maximum-gap/)

## 核心不变量

> 由抽屉原理，把值域均分成若干宽度为 `gap = ⌈(max-min)/(n-1)⌉` 的桶后，最大间距一定出现在两个相邻的非空桶之间（桶内任意两数之差都 `< gap`），因此只需记录每个桶的最小值与最大值，再线性扫描相邻非空桶。

## 完整推导

### 思路推导

1. **直觉与痛点（排序会超时）**

   直接排序再求相邻差是 `O(n log n)`，但题目要求线性时间。值域可能高达 `10^9`，无法用计数排序直接开数组。于是需要一种"不排序也能锁定最大间距"的思路，这就是**桶排序 + 抽屉原理**。

2. **破局思路（用桶宽给答案画个下界）**

   设最小值 `min`、最大值 `max`、元素个数 `n`。把区间切成宽度 `gap = ⌈(max-min)/(n-1)⌉` 的桶。为什么这样取？因为把 `max-min` 这段距离分给 `n-1` 个间隔，平均每个间隔 `(max-min)/(n-1)`，向上取整成 `gap` 后，真正答案一定 `>= gap`。由此得出关键结论：**桶内任意两数的差都严格小于 `gap`，而答案 `>= gap`，所以最大间距绝不可能出现在同一个桶内部**，它只能横跨两个桶——具体说，是某个桶的最小值减去前一个非空桶的最大值。

3. **具体步骤**

   - 第一遍求 `min`、`max`；`n < 2` 或 `max == min` 直接返回 0。
   - 计算 `gap` 与桶数 `bucketCount = (max-min)/gap + 1`（不超过 `n`）。
   - 第二遍把每个数放进 `idx = (x-min)/gap` 号桶，只更新该桶的 `min` 与 `max`。
   - 第三遍从小到大扫描桶，记录前一个非空桶的最大值 `prevMax`，遇到非空桶就用 `bucketMin[i] - prevMax` 更新答案，再把 `prevMax` 换成 `bucketMax[i]`。

   以 `[3,6,9,1]` 为例：`min=1, max=9, n=4`，`gap=⌈8/3⌉=3`，桶数 `8/3+1=3`。桶 0 覆盖 `[1,4)` 收 `{1,3}`（min1,max3），桶 1 覆盖 `[4,7)` 收 `{6}`，桶 2 覆盖 `[7,10)` 收 `{9}`。扫描得 `6-3=3`、`9-6=3`，答案 3。

### Java 实现（桶排序 + 抽屉原理）

```java
import java.util.Arrays;

class Solution {
    public int maximumGap(int[] nums) {
        int n = nums.length;
        if (n < 2) return 0;

        // 1. 求全局最小、最大值
        int min = Integer.MAX_VALUE, max = Integer.MIN_VALUE;
        for (int x : nums) {
            min = Math.min(min, x);
            max = Math.max(max, x);
        }
        if (max == min) return 0;   // 全部相等，间距为 0

        // 2. 桶宽向上取整，保证桶数不超过 n
        long gap = ((long) max - min + n - 2) / (n - 1);       // ceil((max-min)/(n-1))
        int bucketCount = (int) (((long) max - min) / gap) + 1;

        long[] bMin = new long[bucketCount];
        long[] bMax = new long[bucketCount];
        Arrays.fill(bMin, Long.MAX_VALUE);
        Arrays.fill(bMax, Long.MIN_VALUE);

        // 3. 把元素装桶，仅记录桶内最小/最大值
        for (int x : nums) {
            int idx = (int) (((long) x - min) / gap);
            if (x < bMin[idx]) bMin[idx] = x;
            if (x > bMax[idx]) bMax[idx] = x;
        }

        // 4. 扫描相邻非空桶，跨桶差值即为候选答案
        int ans = 0;
        long prevMax = bMax[0];                 // 0 号桶必非空（含最小值）
        for (int i = 1; i < bucketCount; i++) {
            if (bMin[i] == Long.MAX_VALUE) continue;  // 空桶跳过
            ans = Math.max(ans, (int) (bMin[i] - prevMax));
            prevMax = bMax[i];
        }
        return ans;
    }
}
```

### 复杂度

- 时间：`O(n)`。求极值、装桶、扫描桶各一趟线性；桶数不超过 `n`，所以总代价 `O(n)`。相比排序的 `O(n log n)` 更优。
- 空间：`O(n)`。桶的 `min`/`max` 数组长度不超过 `n`，符合"线性额外空间"要求。

### 易错点与扩展（面试高频考点）

1. **桶宽的取整方向**：必须**向上取整**，否则 `gap` 偏小会让"桶内差 < gap"这个下界失效，进而可能漏解。表达式 `(max-min + n - 2)/(n-1)` 就是整数下的向上取整。
2. **`max == min` 的退化**：所有元素相同（例如 `[1,1,1]`）时 `max-min=0`，会算出 `gap=0`，除零崩溃，必须提前返回 0。
3. **溢出**：`max - min` 与装桶下标都用 `long` 计算，避免 `int` 在极端值（`10^9` 量级）下出错；返回值本身不超过 `10^9`，可安全转回 `int`。
4. **必须跳空桶**：只用"相邻的非空桶"更新答案；`prevMax` 要指向最近一个非空桶的最大值，而不是简单用 `i-1`。
5. **面试追问——为什么线性时间内也能求最大间距**：核心是抽屉原理给出的下界 `gap`，它保证了"答案不在桶内"，从而无需桶内排序；这也是基数排序/桶排序思想在"最值类"问题上的一次典型应用。

### C++ 实现

```cpp
#include <vector>
#include <algorithm>
#include <climits>
using namespace std;

class Solution {
public:
    int maximumGap(vector<int>& nums) {
        int n = nums.size();
        if (n < 2) return 0;

        int mn = *min_element(nums.begin(), nums.end());
        int mx = *max_element(nums.begin(), nums.end());
        if (mn == mx) return 0;

        long long gap = ((long long)mx - mn + n - 2) / (n - 1); // 向上取整
        int bucketCount = (int)(((long long)mx - mn) / gap) + 1;

        vector<long long> bMin(bucketCount, LLONG_MAX);
        vector<long long> bMax(bucketCount, LLONG_MIN);

        for (int x : nums) {
            int idx = (int)(((long long)x - mn) / gap);
            bMin[idx] = min(bMin[idx], (long long)x);
            bMax[idx] = max(bMax[idx], (long long)x);
        }

        int ans = 0;
        long long prevMax = bMax[0];            // 0 号桶必非空
        for (int i = 1; i < bucketCount; i++) {
            if (bMin[i] == LLONG_MAX) continue; // 空桶
            ans = max(ans, (int)(bMin[i] - prevMax));
            prevMax = bMax[i];
        }
        return ans;
    }
};
```

### Python 实现

```python
class Solution:
    def maximumGap(self, nums: list[int]) -> int:
        n = len(nums)
        if n < 2:
            return 0

        mn, mx = min(nums), max(nums)
        if mn == mx:
            return 0

        gap = (mx - mn + n - 2) // (n - 1)      # 桶宽，向上取整
        bucket_count = (mx - mn) // gap + 1

        inf = float('inf')
        b_min = [inf] * bucket_count
        b_max = [-inf] * bucket_count

        for x in nums:
            idx = (x - mn) // gap
            if x < b_min[idx]:
                b_min[idx] = x
            if x > b_max[idx]:
                b_max[idx] = x

        ans = 0
        prev_max = b_max[0]                     # 0 号桶必非空
        for i in range(1, bucket_count):
            if b_min[i] == inf:                 # 空桶
                continue
            ans = max(ans, b_min[i] - prev_max)
            prev_max = b_max[i]
        return ans
```
