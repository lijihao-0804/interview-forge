# 63. 不同路径 II

| 题目信息 | 内容 |
|---|---|
| 难度 | 中等 |
| 核心模式 | 滚动数组 DP：dp[j] 表示到达当前行第 j 列的路径数 |
| 时间复杂度 | O(m·n) |
| 空间复杂度 | O(n) |

## 题目与约束

给定一个 `m x n` 的整数数组 `grid`。一个机器人初始位于 左上角（即 `grid[0][0]`）。机器人尝试移动到 右下角（即 `grid[m - 1][n - 1]`）。机器人每次只能向下或者向右移动一步。

网格中的障碍物和空位置分别用 `1` 和 `0` 来表示。机器人的移动路径中不能包含 任何 有障碍物的方格。

返回机器人能够到达右下角的不同路径数量。

测试用例保证答案小于等于 `2 * 109`。

```
<strong>输入：</strong>obstacleGrid = [[0,0,0],[0,1,0],[0,0,0]]
<strong>输出：</strong>2
<strong>解释：</strong>3x3 网格的正中间有一个障碍物。
从左上角到右下角一共有 2 条不同的路径：
1. 向右 -> 向右 -> 向下 -> 向下
2. 向下 -> 向下 -> 向右 -> 向右
```

- `obstacleGrid[i][j]` 为 `0` 或 `1`

## 核心不变量

> 到达格子 `(i, j)` 的路径数等于其上方格子与左方格子路径数之和；若该格子本身是障碍，则路径数恒为 0。用一维 `dp[j]` 原地滚动即可保存"上一行同列"与"本行左列"两个来源。

## 完整推导

### 思路推导

1. **直觉与痛点（暴力搜索指数爆炸）**

   每一步只有"下"或"右"两种选择，路径数随网格指数增长，回溯枚举必然超时。但这是个典型的"数方案数"问题：从一个格子的路径数可以由邻居推出来，天然适合动态规划。

2. **破局思路（状态定义 + 转移方程）**

   设 `dp[i][j]` 为到达 `(i, j)` 的路径数：

   - 若 `(i, j)` 是障碍：`dp[i][j] = 0`；
   - 否则 `dp[i][j] = dp[i-1][j] + dp[i][j-1]`（上 + 左）。
   - 起点 `dp[0][0] = 1`（若它不是障碍）。

   小例子 `[[0,0,0],[0,1,0],[0,0,0]]`：把中间 `(1,1)` 置 0，其余按"上 + 左"累加，右下角恰为 `2`。

3. **关键追问（如何把二维压成一维？）**

   计算 `dp[i][j]` 时只需要"正上方"和"正左方"。当我们按行从左到右遍历时，`dp[j]` 尚未被本行更新，正好保存的仍是上一行的值（正上方）；而 `dp[j-1]` 已经被本行更新过，就是正左方。于是就地执行 `dp[j] += dp[j-1]` 即可，无需二维数组。

4. **收尾**：遇到障碍直接把 `dp[j]` 置 0（切断所有来路）；遍历结束返回 `dp[n-1]`。

### Java 实现（uniquePathsWithObstacles）

```java
class Solution {
    public int uniquePathsWithObstacles(int[][] obstacleGrid) {
        int m = obstacleGrid.length;
        int n = obstacleGrid[0].length;

        // dp[j]：到达"当前行第 j 列"的路径数（滚动更新）
        int[] dp = new int[n];
        // 起点初始化：若是障碍则无路可走
        dp[0] = (obstacleGrid[0][0] == 1) ? 0 : 1;

        for (int i = 0; i < m; i++) {
            for (int j = 0; j < n; j++) {
                if (obstacleGrid[i][j] == 1) {
                    dp[j] = 0;      // 障碍处路径数清零
                    continue;
                }
                if (j > 0) {
                    // dp[j]（旧值=上方）+ dp[j-1]（已更新=左方）
                    dp[j] += dp[j - 1];
                }
                // j == 0 时 dp[0] 保持原值（继承上方向下的唯一通道）
            }
        }

        return dp[n - 1];
    }
}
```

### 复杂度

- 时间：O(m·n)。需要遍历网格中的每个格子一次，每次 O(1) 转移。
- 空间：O(n)。只使用长度为 `n` 的一维滚动数组（相较于二维的 O(m·n) 是显著优化）。

### 易错点与扩展（面试高频考点）

1. **起点/终点本身就是障碍**：`obstacleGrid[0][0] == 1` 时必须返回 0，初始化 `dp[0]` 时就要判掉；同理若终点是障碍，最终 `dp[n-1]` 自然为 0。
2. **第一列不能累加**：`j == 0` 时不能执行 `dp[0] += dp[-1]`，必须单独跳过，让它继承"上方"的唯一通路。
3. **第一行的传递**：处理 `i == 0` 时，`dp[j]` 初值为 0，`dp[j] += dp[j-1]` 恰好让它等于左方格子的值，一行障碍会把后面全部切断，符合预期。
4. **答案范围**：题目保证答案 `<= 2 * 10^9`，在 `int` 范围内（`int` 上限约 `2.147×10^9`），无需 `long`。
5. **扩展——不同路径（LeetCode 62）**：无障碍版本就是本题去掉"障碍置 0"的逻辑；进一步地，纯无障碍时答案就是组合数 `C(m+n-2, m-1)`，可用数学公式直接算，但带障碍后只能靠 DP。

### C++ 实现

```cpp
#include <vector>
using namespace std;

class Solution {
public:
    int uniquePathsWithObstacles(vector<vector<int>>& obstacleGrid) {
        int m = obstacleGrid.size();
        int n = obstacleGrid[0].size();

        vector<int> dp(n, 0);
        dp[0] = (obstacleGrid[0][0] == 1) ? 0 : 1;

        for (int i = 0; i < m; i++) {
            for (int j = 0; j < n; j++) {
                if (obstacleGrid[i][j] == 1) {
                    dp[j] = 0;   // 障碍处清零
                } else if (j > 0) {
                    dp[j] += dp[j - 1];  // 上方(旧 dp[j]) + 左方(dp[j-1])
                }
            }
        }

        return dp[n - 1];
    }
};
```

### Python 实现

```python
class Solution:
    def uniquePathsWithObstacles(self, obstacleGrid: list[list[int]]) -> int:
        m, n = len(obstacleGrid), len(obstacleGrid[0])

        # dp[j]：到达当前行第 j 列的路径数
        dp = [0] * n
        dp[0] = 0 if obstacleGrid[0][0] == 1 else 1

        for i in range(m):
            for j in range(n):
                if obstacleGrid[i][j] == 1:
                    dp[j] = 0          # 障碍处清零
                elif j > 0:
                    dp[j] += dp[j - 1]  # 上方 + 左方

        return dp[n - 1]
```
