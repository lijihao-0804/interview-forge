难度 中等

时间复杂度 O(n log n)
空间复杂度 O(n)

题目与约束

给你一个整数数组 nums，请你将该数组升序排列。

你必须在 不使用任何内置函数 的情况下解决问题，时间复杂度为 O(nlog(n))，并且空间复杂度尽可能小。

示例 1：

<strong>输入：</strong>nums = [5,2,3,1]
<strong>输出：</strong>[1,2,3,5]
<strong>解释：</strong>数组排序后，某些数字的位置没有改变（例如，2 和 3），而其他数字的位置发生了改变（例如，1 和 5）。

示例 2：

<strong>输入：</strong>nums = [5,1,1,2,0,0]
<strong>输出：</strong>[0,0,1,1,2,5]
<strong>解释：</strong>请注意，nums 的值不一定唯一。

提示：

  • 1 <= nums.length <= 5 * 104

  • -5 * 104 <= nums[i] <= 5 * 104

🔗 前往力扣原题验证 →

核心不变量

归并排序先把数组二分成单元素（天然有序），再自底向上两两合并；合并时两个子区间各自有序，只要不断取较小者放入辅助数组，合并后的整段就仍然有序。

完整推导

思路推导

  1. 分治的直觉：一个长度为 1 的数组一定有序。若能把数组对半切开，各自排好序，再把两个有序段「合并」成一个有序段，问题就解决了——这是典型的分治。

  2. 合并（merge）是核心：设左右两段已分别有序。用两个指针 i、j 指向两段开头，每次取较小的放进辅助数组并后移该指针；某段取完后，把另一段剩余元素整体搬过去。因为每次取的都是当前最小，结果自然有序。

  3. 递归结构：mergeSort(lo, hi)：若 lo >= hi 直接返回；否则取 mid，递归排左半、右半，再 merge。深度为 log n，每层合并总代价 O(n)，合计 O(n log n)。

  4. 小优化：合并前若 nums[mid] <= nums[mid+1]，说明两段已经整体有序，可跳过合并，对近似有序数组更快。

  5. 小例子：[5,2,3,1] → 拆成 [5,2]、[3,1] → 再拆成 [5]、[2]、[3]、[1] → 合并 [5],[2] 得 [2,5]，合并 [3],[1] 得 [1,3] → 合并 [2,5] 与 [1,3] 得 [1,2,3,5]。

Java 实现（sortArray / mergeSort）

class Solution {
    public int[] sortArray(int[] nums) {
        int[] tmp = new int[nums.length];   // 复用的辅助数组，避免每层重复分配
        mergeSort(nums, 0, nums.length - 1, tmp);
        return nums;
    }

    private void mergeSort(int[] a, int lo, int hi, int[] tmp) {
        if (lo >= hi) {
            return;                         // 单元素天然有序
        }
        int mid = lo + (hi - lo) / 2;       // 防止 lo + hi 溢出
        mergeSort(a, lo, mid, tmp);
        mergeSort(a, mid + 1, hi, tmp);

        // 两段已整体有序则无需合并（优化）
        if (a[mid] <= a[mid + 1]) {
            return;
        }
        merge(a, lo, mid, hi, tmp);
    }

    private void merge(int[] a, int lo, int mid, int hi, int[] tmp) {
        int i = lo, j = mid + 1, k = lo;
        while (i <= mid && j <= hi) {
            if (a[i] <= a[j]) {             // 取较小者，<= 保证稳定
                tmp[k++] = a[i++];
            } else {
                tmp[k++] = a[j++];
            }
        }
        while (i <= mid) tmp[k++] = a[i++]; // 左段剩余
        while (j <= hi) tmp[k++] = a[j++];  // 右段剩余
        for (int t = lo; t <= hi; t++) {    // 拷回原数组
            a[t] = tmp[t];
        }
    }
}

复杂度

  • 时间：O(n log n)，递归深度 log n，每层合并累计处理 n 个元素。
  • 空间：O(n)，需要一个与原数组等长的辅助数组（递归栈额外 O(log n)）。

易错点与扩展（面试高频考点）

  1. 递归中点写法：用 lo + (hi - lo) / 2 而非 (lo + hi) / 2，避免大下标相加溢出。
  2. 稳定性的 <=：合并时 a[i] <= a[j] 才取左段，保证相等元素相对次序不变（稳定）；写成 < 会破坏稳定性。
  3. 辅助数组复用：把 tmp 作为参数传入而非在每次 merge 里 new，避免 O(n log n) 次分配带来的开销。
  4. 其他达标解法：快排（随机选 pivot，期望 O(n log n)、原地 O(log n) 空间，但最坏 O(n²)）；堆排序（O(n log n)、O(1) 额外空间）；以及针对值域的有计数排序/基数排序（本题值域较小可 O(n)）。
  5. 手写 vs 内置：题目明确禁止直接调用 Arrays.sort/std::sort，面试中通常要求手写归并或快排并分析复杂度。

912. 排序数组

C++ 实现

class Solution {
    void mergeSort(vector<int>& a, int lo, int hi, vector<int>& tmp) {
        if (lo >= hi) return;
        int mid = lo + (hi - lo) / 2;
        mergeSort(a, lo, mid, tmp);
        mergeSort(a, mid + 1, hi, tmp);

        if (a[mid] <= a[mid + 1]) return;   // 已有序，跳过合并

        int i = lo, j = mid + 1, k = lo;
        while (i <= mid && j <= hi) {
            tmp[k++] = (a[i] <= a[j]) ? a[i++] : a[j++];
        }
        while (i <= mid) tmp[k++] = a[i++];
        while (j <= hi) tmp[k++] = a[j++];
        for (int t = lo; t <= hi; t++) a[t] = tmp[t];
    }

public:
    vector<int> sortArray(vector<int>& nums) {
        vector<int> tmp(nums.size());
        mergeSort(nums, 0, (int)nums.size() - 1, tmp);
        return nums;
    }
};

Python 实现

class Solution:
    def sortArray(self, nums: List[int]) -> List[int]:
        def merge_sort(lo, hi):
            if lo >= hi:
                return
            mid = (lo + hi) // 2
            merge_sort(lo, mid)
            merge_sort(mid + 1, hi)

            if nums[mid] <= nums[mid + 1]:   # 已有序，跳过合并
                return

            merged = []
            i, j = lo, mid + 1
            while i <= mid and j <= hi:
                if nums[i] <= nums[j]:
                    merged.append(nums[i])
                    i += 1
                else:
                    merged.append(nums[j])
                    j += 1
            merged.extend(nums[i:mid + 1])
            merged.extend(nums[j:hi + 1])
            nums[lo:hi + 1] = merged          # 原地写回

        merge_sort(0, len(nums) - 1)
        return nums
