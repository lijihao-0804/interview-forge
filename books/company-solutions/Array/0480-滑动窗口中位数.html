题目与约束

中位数是有序序列最中间的那个数。如果序列的长度是偶数，则没有最中间的数；此时中位数是最中间的两个数的平均数。

例如：

  • [2,3,4]，中位数是 3

  • [2,3]，中位数是 (2 + 3) / 2 = 2.5

给你一个数组 nums，有一个长度为 k 的窗口从最左端滑动到最右端。窗口中有 k 个数，每次窗口向右移动 1 位。你的任务是找出每次窗口移动后得到的新窗口中元素的中位数，并输出由它们组成的数组。

示例：

给出 nums = [1,3,-1,-3,5,3,6,7]，以及 k = 3。

窗口位置                      中位数
---------------               -----
[1  3  -1] -3  5  3  6  7       1
 1 [3  -1  -3] 5  3  6  7      -1
 1  3 [-1  -3  5] 3  6  7      -1
 1  3  -1 [-3  5  3] 6  7       3
 1  3  -1  -3 [5  3  6] 7       5
 1  3  -1  -3  5 [3  6  7]      6

因此，返回该滑动窗口的中位数数组 [1,-1,-1,3,5,6]。

提示：

  • 你可以假设 k 始终有效，即：k 始终小于等于输入的非空数组的元素个数。

  • 与真实值误差在 10 ^ -5 以内的答案将被视作正确答案。

核心不变量

窗口每滑动一步，只需在有序结构中「加入一个新元素、删除一个旧元素」；中位数就是窗口中第 ⌈k/2⌉ 小（及第 ⌊k/2⌋+1 小）的元素，与绝对数值无关，只与名次有关。

完整推导

思路推导

  1. 直觉与痛点（为什么不能每次重新排序？）

暴力做法是对每个长度为 k 的窗口排序一次取中位数：共约 n 个窗口，每个排序 O(k log k)，总复杂度 O(n·k log k)。当 n、k 都到 10^5 时不可接受。相邻两个窗口只差「进一个、出一个」，大量重复信息被浪费了。

  1. 破局思路（只维护“谁在第几小”，不关心具体排序）

中位数本质上是一个顺序统计量：k 为奇数时取第 (k+1)/2 小；k 为偶数时取第 k/2 小与第 k/2+1 小的平均。我们只需要一个支持「增删元素 + 查询第 t 小」的数据结构。用坐标压缩把所有数映射到 1..m 的名次，再用树状数组维护每个名次上「当前窗口内有多少个数」：

  • 进窗：在对应名次 +1；出窗：在对应名次 -1。
  • 查询第 t 小：在树状数组上做二分（倍增），找到前缀和首次 >= t 的位置。

以 nums=[1,3,-1]（k=3）为例：名次排序后是 [-1,1,3]，计数都置 1，第 2 小（k/2+1=2）对应名次 2，即 1，正是首窗中位数。

  1. 关键追问（为什么用“名次”而不是“双堆”？）

双堆（大根堆 + 小根堆 + 延迟删除）也能做，但删除时要处理“延迟删除”与堆顶是否过期的细节，容易写错。树状数组按名次计数天然支持“精确删除某个值”，逻辑更直白、更不易错。代价是需要先做坐标压缩，而本题数组已知，压缩成本 O(n log n)，完全可接受。

Java 实现（坐标压缩 + 树状数组求第 k 小）

import java.util.Arrays;
import java.util.HashMap;
import java.util.Map;

class Solution {
    // 树状数组：单点加减 + 查询第 k 小（倍增二分）
    static class Fenwick {
        int n;
        int[] tree;

        Fenwick(int n) {
            this.n = n;
            this.tree = new int[n + 1];
        }

        void add(int i, int delta) {
            for (; i <= n; i += i & -i) {
                tree[i] += delta;
            }
        }

        // 返回最小的下标 idx，使前缀和 >= k（即第 k 小元素所在的名次）
        int kth(int k) {
            int idx = 0;
            int bit = Integer.highestOneBit(n); // <= n 的最大 2 的幂
            for (; bit > 0; bit >>= 1) {
                int next = idx + bit;
                if (next <= n && tree[next] < k) {
                    idx = next;
                    k -= tree[next];
                }
            }
            return idx + 1;
        }
    }

    public double[] medianSlidingWindow(int[] nums, int k) {
        int n = nums.length;

        // 1. 坐标压缩：把数值映射成 1..m 的名次
        int[] sorted = nums.clone();
        Arrays.sort(sorted);
        Map<Integer, Integer> rank = new HashMap<>();
        int m = 0;
        for (int i = 0; i < n; i++) {
            if (i == 0 || sorted[i] != sorted[i - 1]) {
                rank.put(sorted[i], ++m);
            }
        }
        // 名次 -> 原始值（用于最后还原中位数）
        int[] values = new int[m];
        int p = 0;
        for (int i = 0; i < n; i++) {
            if (i == 0 || sorted[i] != sorted[i - 1]) {
                values[p++] = sorted[i];
            }
        }

        Fenwick fw = new Fenwick(m);
        double[] ans = new double[n - k + 1];

        // 2. 初始化第一个窗口
        for (int i = 0; i < k; i++) {
            fw.add(rank.get(nums[i]), 1);
        }
        ans[0] = getMedian(fw, k, values);

        // 3. 窗口右移：进一个、出一个
        for (int i = k; i < n; i++) {
            fw.add(rank.get(nums[i]), 1);        // 新元素进入窗口
            fw.add(rank.get(nums[i - k]), -1);   // 旧元素离开窗口
            ans[i - k + 1] = getMedian(fw, k, values);
        }
        return ans;
    }

    private double getMedian(Fenwick fw, int k, int[] values) {
        if ((k & 1) == 1) {
            // 奇数：第 (k+1)/2 小
            return values[fw.kth(k / 2 + 1) - 1];
        }
        // 偶数：第 k/2 小与第 k/2+1 小的平均，用 long 防溢出
        long a = values[fw.kth(k / 2) - 1];
        long b = values[fw.kth(k / 2 + 1) - 1];
        return (a + b) / 2.0;
    }
}

复杂度

  • 时间：O(n log n)。坐标排序 O(n log n)；每个元素进窗、出窗各一次，每次树状数组 O(log n)；每个窗口两次 kth 查询，各 O(log n)，共 O(n log n)。
  • 空间：O(n)。树状数组 O(m)、映射表与结果数组均为 O(n)。

易错点与扩展（面试高频考点）

  1. 奇偶中位数的下标（最常见的 off-by-one）：k 为奇数取第 k/2+1 小；k 为偶数取第 k/2 与第 k/2+1 小。用 1-based 名次时别写成 0-based，否则整体错位。
  2. 两数求平均的整数溢出：两个元素可能接近 Integer.MAX_VALUE，a + b 会溢出成负数。Java 用 long、C++ 用 long long、Python 无此问题，最后再 /2.0。
  3. 坐标压缩要一并记录“名次→原值”：只保留名次会丢掉真实数值，求中位数时必须查回 values[...]，否则返回的是下标而非数值。
  4. 树状数组求第 k 小的倍增写法：bit 从「不超过 m 的最大 2 的幂」开始，条件用 tree[next] < k 才右移；返回 idx + 1。写成 <= 或漏掉 +1 都会偏一位。
  5. 面试追问——双堆方案：也可用「大根堆存小半、小根堆存大半 + 延迟删除」，O(n log k)，常数更小但删除逻辑更绕；树状数组方案 O(n log n) 更直观。两者都要保证两堆大小差不超过 1。

力扣原题

480. 滑动窗口中位数

C++ 实现

#include <vector>
#include <algorithm>
#include <unordered_map>
using namespace std;

class Solution {
    struct Fenwick {
        int n;
        vector<int> tree;
        Fenwick(int n) : n(n), tree(n + 1, 0) {}
        void add(int i, int delta) {
            for (; i <= n; i += i & -i) tree[i] += delta;
        }
        int kth(int k) {
            int idx = 0;
            int bit = 1;
            while ((bit << 1) <= n) bit <<= 1; // 不超过 n 的最大 2 的幂
            for (; bit > 0; bit >>= 1) {
                int nxt = idx + bit;
                if (nxt <= n && tree[nxt] < k) {
                    idx = nxt;
                    k -= tree[nxt];
                }
            }
            return idx + 1;
        }
    };

public:
    vector<double> medianSlidingWindow(vector<int>& nums, int k) {
        int n = nums.size();
        // 坐标压缩
        vector<int> sorted(nums);
        sort(sorted.begin(), sorted.end());
        sorted.erase(unique(sorted.begin(), sorted.end()), sorted.end());
        int m = sorted.size();

        unordered_map<int, int> rank;
        for (int i = 0; i < m; i++) rank[sorted[i]] = i + 1;

        Fenwick fw(m);
        vector<double> ans;
        ans.reserve(n - k + 1);

        for (int i = 0; i < n; i++) {
            fw.add(rank[nums[i]], 1);            // 新元素进窗
            if (i >= k) fw.add(rank[nums[i - k]], -1); // 旧元素出窗
            if (i >= k - 1) {
                if (k & 1) {
                    ans.push_back((double)sorted[fw.kth(k / 2 + 1) - 1]);
                } else {
                    long long a = sorted[fw.kth(k / 2) - 1];
                    long long b = sorted[fw.kth(k / 2 + 1) - 1];
                    ans.push_back((a + b) / 2.0);
                }
            }
        }
        return ans;
    }
};

Python 实现

class Solution:
    def medianSlidingWindow(self, nums: list[int], k: int) -> list[float]:
        # 坐标压缩：名次从 1 开始
        values = sorted(set(nums))
        m = len(values)
        rank = {v: i + 1 for i, v in enumerate(values)}

        tree = [0] * (m + 1)

        def add(i: int, delta: int) -> None:
            while i <= m:
                tree[i] += delta
                i += i & -i

        def kth(t: int) -> int:
            """返回前缀和首次 >= t 的名次（第 t 小）"""
            idx = 0
            bit = 1 << (m.bit_length() - 1)
            while bit:
                nxt = idx + bit
                if nxt <= m and tree[nxt] < t:
                    idx = nxt
                    t -= tree[nxt]
                bit >>= 1
            return idx + 1

        def median() -> float:
            if k & 1:
                return float(values[kth(k // 2 + 1) - 1])
            a = values[kth(k // 2) - 1]
            b = values[kth(k // 2 + 1) - 1]
            return (a + b) / 2.0

        n = len(nums)
        res = []
        for i in range(n):
            add(rank[nums[i]], 1)          # 新元素进窗
            if i >= k:
                add(rank[nums[i - k]], -1)  # 旧元素出窗
            if i >= k - 1:
                res.append(median())
        return res
