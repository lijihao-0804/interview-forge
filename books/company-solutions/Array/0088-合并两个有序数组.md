# 88. 合并两个有序数组

| 题目信息 | 内容 |
|---|---|
| 难度 | 简单 |
| 核心模式 | 逆向双指针，从后往前填充 |
| 时间复杂度 | O(m + n) |
| 空间复杂度 | O(1) |

## 题目与约束

给你两个按 **非递减顺序** 排列的整数数组 `nums1` 和 `nums2`，另有两个整数 `m` 和 `n`，分别表示 `nums1` 和 `nums2` 中的元素数目。

请你 **合并** `nums2` 到 `nums1` 中，使合并后的数组同样按 **非递减顺序** 排列。

**注意：** 最终合并后的数组不应由函数返回，而是存储在数组 `nums1` 中。为了应对这种情况，`nums1` 的初始长度为 `m + n`，其中前 `m` 个元素表示应合并的元素，后 `n` 个元素为 `0`，应被忽略。`nums2` 的长度为 `n`。

**示例 1：**

```
输入：nums1 = [1,2,3,0,0,0], m = 3, nums2 = [2,5,6], n = 3
输出：[1,2,2,3,5,6]
解释：需要合并 [1,2,3] 和 [2,5,6]。
合并结果是 [1,2,2,3,5,6]。
```

**示例 2：**

```
输入：nums1 = [1], m = 1, nums2 = [], n = 0
输出：[1]
解释：需要合并 [1] 和 []。
合并结果是 [1]。
```

**示例 3：**

```
输入：nums1 = [0], m = 0, nums2 = [1], n = 1
输出：[1]
解释：需要合并的数组是 [] 和 [1]。
合并结果是 [1]。
注意，因为 m = 0，所以 nums1 中没有元素。nums1 中仅存的 0 仅仅是为了确保合并结果可以顺利存放到 nums1 中。
```

**提示：**

- `nums1.length == m + n`
- `nums2.length == n`
- `0 <= m, n <= 200`
- `1 <= m + n <= 200`
- `-10^9 <= nums1[i], nums2[j] <= 10^9`

**进阶：** 你可以设计实现一个时间复杂度为 `O(m + n)` 的算法解决此问题吗？

## 核心不变量

> `nums1` 尾部的 `n` 个空位足以容纳所有待合并元素；从后往前填，每次把两个数组当前最大元素放到 `nums1[k]`，已填部分永远有序且不会覆盖尚未比较的元素。

## 完整推导

### 思路推导

1. **直觉与痛点（为什么不能从前往后）**

   最直接的想法是从前往后比较，把较小的放到 `nums1` 前面。但 `nums1` 前面本来就是有效数据，一旦往后挪就要整体移动，每次插入可能 `O(m+n)`，总复杂度退化到 `O((m+n)²)`；若额外开一个数组则要多花 `O(m+n)` 空间。题目恰好给了 `nums1` 尾部 `n` 个空位，这是解题的关键提示。

2. **破局思路（从后往前填）**

   既然尾部是空的，就从两个数组的**末尾**开始比较，谁大就把谁放到 `nums1` 的最末尾。用三个指针：`i = m-1` 指向 `nums1` 有效区末尾，`j = n-1` 指向 `nums2` 末尾，`k = m+n-1` 指向最终填充位置。每比较一次，`k` 前移一格，被取走的那个指针前移一格。

   以 `nums1 = [1,2,3,0,0,0], m = 3`、`nums2 = [2,5,6], n = 3` 为例：比较 `3` 和 `6`，放 `6`；比较 `3` 和 `5`，放 `5`；比较 `3` 和 `2`，放 `3`；再放 `2`、`2`、`1`，得到 `[1,2,2,3,5,6]`。

3. **关键追问（`nums1` 剩余部分还要处理吗？）**

   循环条件是 `i >= 0 && j >= 0`。当 `j < 0` 时，说明 `nums2` 已全部合并完，`nums1` 剩下的 `[0..i]` 本就有序且位于正确位置，无需再动；当 `i < 0` 时，说明 `nums1` 已取空，只需把 `nums2` 剩下的元素原样拷到前面即可。因此补一个 `while (j >= 0)` 就完备了。

### Java 实现（逆向双指针）

```java
class Solution {
    public void merge(int[] nums1, int m, int[] nums2, int n) {
        int i = m - 1;          // nums1 有效区的最后一个元素
        int j = n - 1;          // nums2 的最后一个元素
        int k = m + n - 1;      // 合并结果的填充位置（从末尾开始）

        // 两边都还有元素时，取较大者放到末尾
        while (i >= 0 && j >= 0) {
            if (nums1[i] > nums2[j]) {
                nums1[k--] = nums1[i--];
            } else {
                nums1[k--] = nums2[j--];
            }
        }

        // 若 nums2 还有剩余则继续拷贝；nums1 剩余则天然已在正确位置
        while (j >= 0) {
            nums1[k--] = nums2[j--];
        }
    }
}
```

### 复杂度

- 时间：`O(m + n)`。每个元素最多被访问并写入一次，指针只从右向左单向移动。
- 空间：`O(1)`。只用了 `i / j / k` 三个常量指针，原地完成，无需额外数组。

### 易错点与扩展（面试高频考点）

1. **从前往后会覆盖未处理数据**：正序写入会把 `nums1` 尚未比较的有效元素覆盖掉，除非额外开数组；从后往前才能保证"写入位置永远在尚未读取位置之后"。
2. **漏写收尾的 `while (j >= 0)`**：当 `nums1` 先用完（`i < 0`）而 `nums2` 仍有剩余时必须补拷，否则结果缺元素。反之 `nums1` 剩余无需处理。
3. **边界 `n == 0` / `m == 0`**：`n == 0` 时主循环不进入，原样返回；`m == 0` 时直接把 `nums2` 拷进 `nums1`，收尾循环已覆盖。
4. **面试追问——与"合并两个有序链表"对比**：链表合并用哑节点从头往后接，数组因尾部有空洞才能逆向，二者都是双指针线性归并的思想。
5. **面试追问——若要求去重**：合并时若写入值等于结果末尾值则跳过，可在写入处加判重；不影响 `O(m+n)` 上界。

## 力扣原题

[88. 合并两个有序数组](https://leetcode.cn/problems/merge-sorted-array/)

### C++ 实现

```cpp
#include <vector>
using namespace std;

class Solution {
public:
    void merge(vector<int>& nums1, int m, vector<int>& nums2, int n) {
        int i = m - 1;          // nums1 有效区末尾
        int j = n - 1;          // nums2 末尾
        int k = m + n - 1;      // 填充位置

        while (i >= 0 && j >= 0) {
            if (nums1[i] > nums2[j]) {
                nums1[k--] = nums1[i--];
            } else {
                nums1[k--] = nums2[j--];
            }
        }
        // nums2 若还有剩余，继续拷贝
        while (j >= 0) {
            nums1[k--] = nums2[j--];
        }
    }
};
```

### Python 实现

```python
class Solution:
    def merge(self, nums1: list[int], m: int, nums2: list[int], n: int) -> None:
        """
        Do not return anything, modify nums1 in-place instead.
        """
        i, j, k = m - 1, n - 1, m + n - 1
        while i >= 0 and j >= 0:
            if nums1[i] > nums2[j]:
                nums1[k] = nums1[i]
                i -= 1
            else:
                nums1[k] = nums2[j]
                j -= 1
            k -= 1
        # nums2 剩余元素继续拷贝
        while j >= 0:
            nums1[k] = nums2[j]
            j -= 1
            k -= 1
```
