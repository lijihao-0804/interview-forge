# 724. 寻找数组的中心下标

| 题目信息 | 内容 |
|---|---|
| 难度 | 简单 |
| 核心模式 | 前缀和：用 leftSum 与前缀和反推右侧和，找首个相等位置 |
| 时间复杂度 | O(n) |
| 空间复杂度 | O(1) |

## 题目与约束

给你一个整数数组 `nums` ，请计算数组的 中心下标 。

数组 中心下标 是数组的一个下标，其左侧所有元素相加的和等于右侧所有元素相加的和。

如果中心下标位于数组最左端，那么左侧数之和视为 `0` ，因为在下标的左侧不存在元素。这一点对于中心下标位于数组最右端同样适用。

如果数组有多个中心下标，应该返回 最靠近左边 的那一个。如果数组不存在中心下标，返回 `-1` 。

 

示例 1：

```
<strong>输入：</strong>nums = [1, 7, 3, 6, 5, 6]
<strong>输出：</strong>3
<strong>解释：</strong>
中心下标是 3 。
左侧数之和 sum = nums[0] + nums[1] + nums[2] = 1 + 7 + 3 = 11 ，
右侧数之和 sum = nums[4] + nums[5] = 5 + 6 = 11 ，二者相等。
```

示例 2：

```
<strong>输入：</strong>nums = [1, 2, 3]
<strong>输出：</strong>-1
<strong>解释：</strong>
数组中不存在满足此条件的中心下标。
```

示例 3：

```
<strong>输入：</strong>nums = [2, 1, -1]
<strong>输出：</strong>0
<strong>解释：</strong>
中心下标是 0 。
左侧数之和 sum = 0 ，（下标 0 左侧不存在元素），
右侧数之和 sum = nums[1] + nums[2] = 1 + -1 = 0 。
```

 

提示：

- `1 <= nums.length <= 104`

- `-1000 <= nums[i] <= 1000`

## 核心不变量

> 设数组总和为 `total`，当前下标 `i` 左侧和为 `left`，则右侧和恒等于 `total - left - nums[i]`；当 `left == total - left - nums[i]` 时 `i` 即为中心下标。

## 完整推导

### 思路推导

1. **直觉与痛点（避免每个下标都重新求和）**

   暴力做法是对每个 `i` 分别求左、右两侧之和，整体 O(n²)。但"左侧和"在从左往右扫描时可以增量维护，右侧和又能由总和推出，因此可以做到一次线性扫描。

2. **破局思路（前缀和反推右侧和）**

   先求 `total = sum(nums)`。从左到右扫描，维护 `left`（当前下标 `i` 之前所有元素之和）。那么 `i` 的右侧和就是 `total - left - nums[i]`。判断 `left == total - left - nums[i]` 即可；判断完再把 `nums[i]` 加进 `left`，进入下一个下标。

3. **关键判定（返回最左）**

   因为是从左到右**首次**命中就 `return`，天然满足"多个中心下标时返回最靠左"的要求；扫描完仍未命中返回 `-1`。
   小例子：`[1,7,3,6,5,6]`，`total=28`。`i=0`：left=0，右=27，不等；累加 left=1。`i=1`：left=1，右=20，不等；left=8。`i=2`：left=8，右=17，不等；left=11。`i=3`：left=11，右=28-11-6=11，相等 → 返回 3。与示例一致。

### Java 实现（pivotIndex）

```java
class Solution {
    public int pivotIndex(int[] nums) {
        int total = 0;
        for (int x : nums) {
            total += x; // 先求总和
        }

        int left = 0; // 当前下标左侧所有元素之和
        for (int i = 0; i < nums.length; i++) {
            // 右侧和 = total - left - nums[i]，相等即为中心下标
            if (left == total - left - nums[i]) {
                return i;
            }
            left += nums[i]; // 为下一个下标准备左侧和
        }
        return -1;
    }
}
```

### 复杂度

- 时间：O(n)。第一次求总和 O(n)，第二次线性扫描并做常数时间判断，合计 O(n)。
- 空间：O(1)。只用了 `total`、`left` 等常量级变量。

### 易错点与扩展（面试高频考点）

1. **右侧和别算错**：右侧和是 `total - left - nums[i]`，容易漏减 `nums[i]` 导致把中心元素本身也算进右侧。
2. **更新 `left` 的时机**：必须先判断、再把 `nums[i]` 累加进 `left`；顺序颠倒会错位。
3. **空数组/单元素边界**：`[]` 按题意不存在中心下标返回 `-1`；单元素 `[0]` 的中心下标是 0（左和右都视为 0）。
4. **负数不影响正确性**：前缀和差值判断对负数同样成立，不需要额外处理。
5. **扩展**：同类"前缀和 + 差值"思想可用于区间和、和为定值的子数组、左右平衡点等问题；若要求多次区间和，可预处理前缀和数组实现 O(1) 查询。

### C++ 实现

```cpp
#include <vector>
using namespace std;

class Solution {
public:
    int pivotIndex(vector<int>& nums) {
        int total = 0;
        for (int x : nums) total += x;

        int left = 0;
        for (int i = 0; i < (int)nums.size(); i++) {
            // 右侧和 = total - left - nums[i]
            if (left == total - left - nums[i]) {
                return i;
            }
            left += nums[i];
        }
        return -1;
    }
};
```

### Python 实现

```python
class Solution:
    def pivotIndex(self, nums: list[int]) -> int:
        total = sum(nums)
        left = 0
        for i, x in enumerate(nums):
            # 右侧和 = total - left - x
            if left == total - left - x:
                return i
            left += x
        return -1
```
