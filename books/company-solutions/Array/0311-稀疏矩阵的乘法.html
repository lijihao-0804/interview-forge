题目与约束

🔗 前往力扣原题验证 →

核心不变量

结果 C[i][j] = Σ_k A[i][k] * B[k][j]；只要跳过 A[i][k] 为 0 或 B[k][j] 为 0 的项，稀疏矩阵的乘法就能省去大量无效运算。

完整推导

思路推导

  1. 定义出发：矩阵乘法的定义就是 C[i][j] = Σ_{t=0}^{k-1} A[i][t] * B[t][j]。最直接的三重循环以 t 为中间层，复杂度 O(m·k·n)。

  2. 利用稀疏性：所谓稀疏，就是零元素很多。当 A[i][t] == 0 时，它对 C 第 i 行所有列的贡献都是 0，可以直接跳过整个 j 循环；同理内层遇到 B[t][j] == 0 也可跳过这一项的乘法。

  3. 循环顺序：把 t 放在第二层并判零，能让"跳过整行贡献"最大化，也避免了 0 * 任何数 的无谓计算。这是稀疏矩阵乘法最常用的写法。

  4. 小例子验证：A = [[1,0,0],[-1,0,3]]，B = [[7,0,0],[0,0,0],[0,0,1]]。 - C[0][0] = 1*7 + 0 + 0 = 7，C[0][2] = 0；C[1][0] = -1*7 + 0 + 0 = -7，C[1][2] = -1*0 + 0 + 3*1 = 3。 - 结果 [[7,0,0],[-7,0,3]]，与示例一致 ✓

Java 实现（行压缩遍历）

class Solution {
    public int[][] multiply(int[][] mat1, int[][] mat2) {
        int m = mat1.length;        // A 的行数
        int k = mat1[0].length;     // A 的列数 = B 的行数
        int n = mat2[0].length;     // B 的列数
        int[][] res = new int[m][n];

        for (int i = 0; i < m; i++) {
            for (int t = 0; t < k; t++) {
                // 稀疏优化：A[i][t] 为 0 时，跳过它对整行的贡献
                if (mat1[i][t] == 0) {
                    continue;
                }
                int a = mat1[i][t];
                for (int j = 0; j < n; j++) {
                    // 再跳过 B[t][j] 为 0 的项
                    if (mat2[t][j] != 0) {
                        res[i][j] += a * mat2[t][j];
                    }
                }
            }
        }
        return res;
    }
}

复杂度

  • 时间：O(m·k·n)。三重循环的渐近上界；由于零元素被跳过，实际乘法次数远小于该上界（稀疏矩阵越快）。
  • 空间：O(m·n)。只需存放结果矩阵；除输出外额外空间为 O(1)。

易错点与扩展（面试高频考点）

  1. 维度取错：k = mat1[0].length、n = mat2[0].length，二者不能混；res 是 m x n，不是 m x k。
  2. 累加写成赋值：内层必须是 res[i][j] += ...，因为同一个 res[i][j] 会被多个 t 累加。
  3. 只判 A 不判 B：对 B[t][j] 也判零能进一步减少乘法，尤其两边都稀疏时更明显。
  4. 更"稀疏"的做法：把非零元素存成三元组或 CSR（行压缩）结构，或用"行 × 列点积"只遍历非零项，可把复杂度降到与非零元个数相关。
  5. 缓存友好：若采用 i-k-j 顺序，内层连续访问 B 的一行，局部性好；若改成 i-j-k 则 B 按列访问，缓存不友好，面试可提这一点。

C++ 实现

#include <vector>
using namespace std;

class Solution {
public:
    vector<vector<int>> multiply(vector<vector<int>>& mat1, vector<vector<int>>& mat2) {
        int m = mat1.size();
        int k = mat1[0].size();
        int n = mat2[0].size();
        vector<vector<int>> res(m, vector<int>(n, 0));

        for (int i = 0; i < m; ++i) {
            for (int t = 0; t < k; ++t) {
                if (mat1[i][t] == 0) continue;      // 跳过零元素
                int a = mat1[i][t];
                for (int j = 0; j < n; ++j) {
                    if (mat2[t][j] != 0) {
                        res[i][j] += a * mat2[t][j];
                    }
                }
            }
        }
        return res;
    }
};

Python 实现

class Solution:
    def multiply(self, mat1: list[list[int]], mat2: list[list[int]]) -> list[list[int]]:
        m, k, n = len(mat1), len(mat1[0]), len(mat2[0])
        res = [[0] * n for _ in range(m)]
        for i in range(m):
            for t in range(k):
                if mat1[i][t] == 0:          # 跳过零元素
                    continue
                a = mat1[i][t]
                for j in range(n):
                    if mat2[t][j] != 0:
                        res[i][j] += a * mat2[t][j]
        return res
