题目与约束

有 n 个气球，编号为0 到 n - 1，每个气球上都标有一个数字，这些数字存在数组 nums 中。

现在要求你戳破所有的气球。戳破第 i 个气球，你可以获得 nums[i - 1] * nums[i] * nums[i + 1] 枚硬币。 这里的 i - 1 和 i + 1 代表和 i 相邻的两个气球的序号。如果 i - 1或 i + 1 超出了数组的边界，那么就当它是一个数字为 1 的气球。

求所能获得硬币的最大数量。

示例 1：

<strong>输入：</strong>nums = [3,1,5,8]
<strong>输出：</strong>167
<strong>解释：</strong>
nums = [3,1,5,8] --> [3,5,8] --> [3,8] --> [8] --> []
coins =  3*1*5    +   3*5*8   +  1*3*8  + 1*8*1 = 167

示例 2：

<strong>输入：</strong>nums = [1,5]
<strong>输出：</strong>10

提示：

  • n == nums.length

  • 1 <= n <= 300

  • 0 <= nums[i] <= 100

核心不变量

dp[i][j] 表示戳破开区间 (i, j) 内所有气球能得到的最大硬币数；枚举"最后一个被戳破"的气球 k，它把问题拆成两个互不影响的子区间。

完整推导

思路推导

  1. 正面枚举为何爆炸：如果按"先戳哪个、再戳哪个"去枚举，方案数是 n! 级别。而且每戳一个气球，左右邻居会动态改变，很难用一维状态描述。

  2. 倒着想——最后戳谁：与其问"第一个戳谁"，不如问"区间 (i, j) 里最后一个被戳破的是哪个气球 k"。当 k 最后被戳时，区间 (i, j) 里只剩它一个，它此刻的左邻居正是 i、右邻居正是 j，所以这一步的收益固定为 a[i] * a[k] * a[j]。

  3. 为什么能拆分：在 k 被戳之前，(i, k) 和 (k, j) 内的气球已经被各自戳完，且它们被戳时的边界不会越过 k。因此左边子区间用边界 (i, k)、右边子区间用边界 (k, j)，两部分互相独立、可以分别取最优：

dp[i][j] = max_{i<k<j} ( dp[i][k] + dp[k][j] + a[i]*a[k]*a[j] )

  1. 边界与顺序：在 nums 左右各补一个 1，得到 a[0..n+1]。初始区间 (i, j) 没有气球时 dp = 0。按区间长度从小到大递推（保证子区间先算好），最终答案是 dp[0][n+1]。

以 nums = [3,1,5,8] 为例，补 1 后为 [1,3,1,5,8,1]；dp[0][5] 对应全部戳完，最优顺序得 167，与示例一致 ✓

Java 实现（区间 DP）

class Solution {
    public int maxCoins(int[] nums) {
        int n = nums.length;
        // 两端各补一个 1，方便处理边界
        int[] a = new int[n + 2];
        a[0] = 1;
        a[n + 1] = 1;
        for (int i = 0; i < n; i++) {
            a[i + 1] = nums[i];
        }

        // dp[i][j]：戳破开区间 (i, j) 内所有气球的最大收益
        int[][] dp = new int[n + 2][n + 2];

        // 区间长度 len = j - i，至少为 2 才包含中间气球
        for (int len = 2; len <= n + 1; len++) {
            for (int i = 0; i + len <= n + 1; i++) {
                int j = i + len;
                // 枚举最后被戳破的气球 k
                for (int k = i + 1; k < j; k++) {
                    int gain = dp[i][k] + dp[k][j] + a[i] * a[k] * a[j];
                    if (gain > dp[i][j]) {
                        dp[i][j] = gain;
                    }
                }
            }
        }
        return dp[0][n + 1];
    }
}

复杂度

  • 时间：O(n³)。区间数量 O(n²)，每个区间内部枚举 k 是 O(n)。
  • 空间：O(n²)。二维 dp 表，外加长度 n+2 的辅助数组。

易错点与扩展（面试高频考点）

  1. 不开边界 1：忘记在两端补 1，会在处理首尾气球时下标越界或收益算错；补 1 后统一用 a[i]*a[k]*a[j]。
  2. 区间是开区间：dp[i][j] 只含 (i, j) 之间，k 必须取 i+1 .. j-1，写成闭区间会重复计入。
  3. 遍历顺序：必须按区间长度递增（或 i 递减、j 递增）计算，否则 dp[i][k]、dp[k][j] 还没准备好。这是区间 DP 最容易翻车的地方。
  4. 误区：枚举"第一个戳的"：第一个气球戳掉后左右合并，两个子问题不再独立，无法拆分，所以只能倒着枚举"最后一个"。
  5. 同类模板：本题与「矩阵链乘法」「最长回文子序列」「移除盒子」同属区间 DP，核心都是"枚举区间里的分割/最后处理点"。

力扣原题

312. 戳气球

C++ 实现

#include <vector>
#include <algorithm>
using namespace std;

class Solution {
public:
    int maxCoins(vector<int>& nums) {
        int n = nums.size();
        vector<int> a(n + 2, 1);
        for (int i = 0; i < n; ++i) a[i + 1] = nums[i];

        vector<vector<int>> dp(n + 2, vector<int>(n + 2, 0));

        for (int len = 2; len <= n + 1; ++len) {
            for (int i = 0; i + len <= n + 1; ++i) {
                int j = i + len;
                for (int k = i + 1; k < j; ++k) {
                    dp[i][j] = max(dp[i][j],
                                   dp[i][k] + dp[k][j] + a[i] * a[k] * a[j]);
                }
            }
        }
        return dp[0][n + 1];
    }
};

Python 实现

class Solution:
    def maxCoins(self, nums: list[int]) -> int:
        n = len(nums)
        a = [1] + nums + [1]
        # dp[i][j]：戳破开区间 (i, j) 内所有气球的最大收益
        dp = [[0] * (n + 2) for _ in range(n + 2)]

        for length in range(2, n + 2):          # 区间长度 j - i
            for i in range(0, n + 2 - length):
                j = i + length
                for k in range(i + 1, j):       # 枚举最后被戳破的气球
                    dp[i][j] = max(
                        dp[i][j],
                        dp[i][k] + dp[k][j] + a[i] * a[k] * a[j],
                    )
        return dp[0][n + 1]
