# 922. 按奇偶排序数组 II

| 题目信息 | 内容 |
|---|---|
| 难度 | 简单 |
| 核心模式 | 双指针原地归位 |
| 时间复杂度 | O(n) |
| 空间复杂度 | O(1) |

## 题目与约束

给定一个非负整数数组 `nums`，  `nums` 中一半整数是 奇数 ，一半整数是 偶数 。

对数组进行排序，以便当 `nums[i]` 为奇数时，`i` 也是 奇数 ；当 `nums[i]` 为偶数时， `i` 也是 偶数 。

你可以返回 任何满足上述条件的数组作为答案 。

 

示例 1：

```
<strong>输入：</strong>nums = [4,2,5,7]
<strong>输出：</strong>[4,5,2,7]
<strong>解释：</strong>[4,7,2,5]，[2,5,4,7]，[2,7,4,5] 也会被接受。
```

示例 2：

```
<b>输入：</b>nums = [2,3]
<b>输出：</b>[2,3]
```

 

提示：

- `2 <= nums.length <= 2 * 104`

- `nums.length` 是偶数

- `nums` 中一半是偶数

- `0 <= nums[i] <= 1000`

## 核心不变量

> 偶数下标只放偶数、奇数下标只放奇数；当一对位置同时放错时，它们上面的元素互换后必然同时归位。

## 完整推导

### 思路推导

1. **把问题拆成两条独立的车道**：偶数下标 `0,2,4,...` 是一条车道，只应停放偶数；奇数下标 `1,3,5,...` 是另一条车道，只应停放奇数。因为题目保证偶数、奇数各占一半，所以两条车道长度相等，一一对应。

2. **两根指针各管一条车道**：令 `even = 0` 巡游偶数下标，`odd = 1` 巡游奇数下标。检查 `nums[even]`：若它已经是偶数，说明这格停对了，`even += 2` 往后走；同理检查 `nums[odd]`，若已是奇数则 `odd += 2`。

3. **错位时一次交换解决两处**：如果 `nums[even]` 是奇数、同时 `nums[odd]` 是偶数，那么这一奇一偶恰好是「张冠李戴」。把它们互换后，偶数回了偶数位、奇数回了奇数位，位置一次修好两处，然后两指针都前进 2。

4. **小例子**：`[4,2,5,7]`。`even=0` 上 `4` 是偶数，跳过；`even=2` 上 `5` 是奇数，此时 `odd=1` 上是 `2`（偶数），交换 `5` 与 `2` → `[4,5,2,7]`，两条车道同时归位，结束。

### Java 实现（双指针就地交换）

```java
class Solution {
    public int[] sortArrayByParityII(int[] nums) {
        int n = nums.length;
        int even = 0; // 指向当前待检查的偶数下标
        int odd = 1;  // 指向当前待检查的奇数下标
        while (even < n && odd < n) {
            if (nums[even] % 2 == 0) {
                even += 2;                 // 偶数位上已是偶数，跳过
            } else if (nums[odd] % 2 == 1) {
                odd += 2;                  // 奇数位上已是奇数，跳过
            } else {
                // 偶数位上放了奇数、奇数位上放了偶数：交换后两处同时归位
                int tmp = nums[even];
                nums[even] = nums[odd];
                nums[odd] = tmp;
                even += 2;
                odd += 2;
            }
        }
        return nums;
    }
}
```

### 复杂度

- 时间：O(n)，`even`、`odd` 各自单调前进，每个元素最多被访问常数次。
- 空间：O(1)，只在原数组上做交换，没有额外数组。

### 易错点与扩展（面试高频考点）

1. **别用「分别收集再拼回去」的偷懒法**：新建两个列表存偶数和奇数再合并，虽然也对，但需要 O(n) 额外空间，不满足进阶要求。面试时应主动说出双指针原地解法。

2. **下标奇偶与数值奇偶别写反**：偶数下标配偶数、奇数下标配奇数，`even` 从 0 出发、`odd` 从 1 出发，判断条件分别是 `nums[even] % 2 == 0` 和 `nums[odd] % 2 == 1`。

3. **循环终止条件用 `while (even < n && odd < n)`**：两指针会一起推进，任意一个越界即说明全部位置处理完毕，不必额外判断。

4. **为什么交换一定成功**：题目保证偶数、奇数数量相等。如果偶数位上是奇数，那么奇数位上必有等量的「错位偶数」，因此找到一对交换即可，不会出现「凑不齐」的情况。

5. **扩展**：若数组奇偶数量不等（如偶数多一个），则无法满足全部约束，应先做可行性判断（统计数量）。

## 力扣原题

[922. 按奇偶排序数组 II](https://leetcode.cn/problems/sort-array-by-parity-ii/)

### C++ 实现

```cpp
class Solution {
public:
    vector<int> sortArrayByParityII(vector<int>& nums) {
        int n = nums.size();
        int even = 0, odd = 1;
        while (even < n && odd < n) {
            if (nums[even] % 2 == 0) {
                even += 2;
            } else if (nums[odd] % 2 == 1) {
                odd += 2;
            } else {
                swap(nums[even], nums[odd]);
                even += 2;
                odd += 2;
            }
        }
        return nums;
    }
};
```

### Python 实现

```python
from typing import List

class Solution:
    def sortArrayByParityII(self, nums: List[int]) -> List[int]:
        n = len(nums)
        even, odd = 0, 1
        while even < n and odd < n:
            if nums[even] % 2 == 0:
                even += 2
            elif nums[odd] % 2 == 1:
                odd += 2
            else:
                nums[even], nums[odd] = nums[odd], nums[even]
                even += 2
                odd += 2
        return nums
```
