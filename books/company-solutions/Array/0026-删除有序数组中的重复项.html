题目与约束

给你一个非严格递增排列的数组 nums，请你原地删除重复出现的元素，使每个元素只出现一次，返回删除后数组的新长度。元素的相对顺序应该保持一致。然后返回 nums 中唯一元素的个数。

考虑 nums 的唯一元素的数量为 k。去重后，返回唯一元素的数量 k。

nums 的前 k 个元素应包含排序后的唯一数字。下标 k - 1 之后的剩余元素可以忽略。

判题标准：

系统会用下面的代码来测试你的题解：

int[] nums = [...]; // 输入数组
int[] expectedNums = [...]; // 长度正确的期望答案

int k = removeDuplicates(nums); // 调用

assert k == expectedNums.length;
for (int i = 0; i < k; i++) {
    assert nums[i] == expectedNums[i];
}

如果所有断言都通过，那么你的题解将被通过。

示例 1：

输入：nums = [1,1,2]
输出：2, nums = [1,2,_]
解释：函数应该返回新的长度 2 ，并且原数组 nums 的前两个元素被修改为 1, 2 。
     不需要考虑数组中超出新长度后面的元素。

示例 2：

输入：nums = [0,0,1,1,1,2,2,3,3,4]
输出：5, nums = [0,1,2,3,4,_,_,_,_,_]
解释：函数应该返回新的长度 5 ，并且原数组 nums 的前五个元素被修改为 0, 1, 2, 3, 4 。
     不需要考虑数组中超出新长度后面的元素。

提示：

  • 1 <= nums.length <= 3 * 10^4
  • -100 <= nums[i] <= 100
  • nums 已按非递减顺序排列。

核心不变量

nums[0..slow] 始终是"已处理前缀"中去重后的结果，且不含重复；fast 只负责向右寻找下一个与 nums[slow] 不同的新值。

完整推导

思路推导

  1. 直觉与痛点（能不能用额外数组？）

最省心的做法是新建一个数组，把不重复的元素依次塞进去，再拷回原数组。但题目明确要求原地修改、O(1) 额外空间，这就要求我们"在原地一边读一边写"，而不能借助新容器。

  1. 破局思路（快慢指针，慢指针记结果，快指针找新值）

因为数组已排序，重复元素一定相邻，于是"是否重复"只需和"结果区最后一个元素"比较即可：

  • slow 指向当前去重结果的最后一个位置（初始 0）；
  • fast 从 1 开始向后扫描；
  • 若 nums[fast] != nums[slow]，说明发现了一个新值，把 slow 前进一格并写入 nums[fast]；
  • 若相等，说明是重复值，fast 直接跳过（不写）。

以 [1,1,2] 为例：slow=0，fast=1 时 1==1 跳过；fast=2 时 2!=1，slow=1 并写入 nums[1]=2，最终返回 slow+1 = 2，前两位是 [1,2]。

  1. 关键追问（返回值与"原地"的边界）
  • 返回的是长度 slow + 1，不是下标。
  • 慢指针只有在"遇到新值"时才前进，所以 slow 永远不会超过 fast，写入不会覆盖掉尚未读取的元素——这正是原地覆盖安全的原因。
  • nums 长度为 1 时，fast 循环不执行，直接返回 1，无需特判。

Java 实现（快慢双指针）

class Solution {
    public int removeDuplicates(int[] nums) {
        if (nums.length == 0) {
            return 0; // 空数组防御
        }

        int slow = 0; // 指向去重后结果区的最后一个位置
        for (int fast = 1; fast < nums.length; fast++) {
            // 发现与结果区末尾不同的新值
            if (nums[fast] != nums[slow]) {
                slow++;                  // 结果区扩张一格
                nums[slow] = nums[fast]; // 把新值写到结果区
            }
            // 相等则说明是重复值，fast 直接跳过
        }

        // 结果长度为 slow + 1
        return slow + 1;
    }
}

复杂度

  • 时间：O(n)。fast 指针从左到右每个元素只访问一次，slow 的推进总次数不超过 n，整体线性。
  • 空间：O(1)。只用了 slow、fast 两个整型下标，原地覆盖不申请额外数组。

易错点与扩展（面试高频考点）

  1. 返回值写成 slow：slow 是最后一个元素的下标，长度应为 slow + 1，差一错误最常发生。
  2. 比较对象写错：必须和 nums[slow]（结果区末尾）比较。由于数组有序，这等价于"和上一个保留值比"，但若与 nums[fast-1] 混用容易在去重逻辑上绕晕。
  3. 以为要真的"删除"元素：本题是"原地覆盖 + 返回长度"，k 之后的元素无需清零，判题只看前 k 个。
  4. 面试追问——允许每个元素最多出现两次（LeetCode 80）：把判断条件放宽为 nums[fast] != nums[slow-1]（slow 从 2 起），即"新值只要和结果区倒数第二个不同就可写入"，是本题的直接推广。
  5. 面试追问——删除指定值（LeetCode 27）：同样是快慢指针，只是把判据换成 nums[fast] != val，可见"快慢指针原地压缩"是一类通用模板。

力扣原题

26. 删除有序数组中的重复项

C++ 实现

#include <vector>
using namespace std;

class Solution {
public:
    int removeDuplicates(vector<int>& nums) {
        if (nums.empty()) return 0;

        int slow = 0; // 结果区最后一个位置
        for (int fast = 1; fast < (int)nums.size(); fast++) {
            if (nums[fast] != nums[slow]) {
                slow++;
                nums[slow] = nums[fast]; // 原地覆盖
            }
        }
        return slow + 1;
    }
};

Python 实现

class Solution:
    def removeDuplicates(self, nums: list[int]) -> int:
        if not nums:
            return 0

        slow = 0  # 结果区最后一个位置
        for fast in range(1, len(nums)):
            if nums[fast] != nums[slow]:
                slow += 1
                nums[slow] = nums[fast]  # 原地覆盖
        return slow + 1
