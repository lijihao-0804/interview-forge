# 718. 最长重复子数组

| 题目信息 | 内容 |
|---|---|
| 难度 | 中等 |
| 核心模式 | 动态规划：dp 记录以两数组当前位置结尾的最长公共后缀长度 |
| 时间复杂度 | O(m × n) |
| 空间复杂度 | O(n)（滚动数组） |

## 题目与约束

给两个整数数组 `nums1` 和 `nums2` ，返回 两个数组中 公共的 、长度最长的子数组的长度 。

 

示例 1：

```
<strong>输入：</strong>nums1 = [1,2,3,2,1], nums2 = [3,2,1,4,7]
<strong>输出：</strong>3
<strong>解释：</strong>长度最长的公共子数组是 [3,2,1] 。
```

示例 2：

```
<strong>输入：</strong>nums1 = [0,0,0,0,0], nums2 = [0,0,0,0,0]
<strong>输出：</strong>5
```

 

提示：

- `1 <= nums1.length, nums2.length <= 1000`

- `0 <= nums1[i], nums2[i] <= 100`

[🔗 前往力扣原题验证 →](https://leetcode.cn/problems/maximum-length-of-repeated-subarray/)

## 核心不变量

> 设 `dp[j]` 表示"以 `nums1[i-1]` 和 `nums2[j-1]` 结尾"的最长公共子数组长度；当两元素相等时 `dp[j] = dp[j-1] + 1`，否则为 0。答案取所有 `dp[j]` 的最大值。

## 完整推导

### 思路推导

1. **直觉与痛点（"子数组"意味着必须连续）**

   注意是**子数组**而不是子序列，必须连续。若暴力枚举所有起点对再逐位比较，最坏 O(m·n·min(m,n))，太慢。连续的约束恰恰给了我们一个天然的"接龙"结构：当前位置能接多长，只取决于"前一位能接多长"。

2. **破局思路（定义以当前位置结尾的状态）**

   令 `dp[i][j]` 表示以 `nums1[i-1]`、`nums2[j-1]` **结尾**的最长公共子数组长度。
   - 若 `nums1[i-1] == nums2[j-1]`，它可以接在上一位的公共后缀后面：`dp[i][j] = dp[i-1][j-1] + 1`；
   - 否则以这两个位置结尾不可能构成公共子数组，`dp[i][j] = 0`。
   答案就是所有 `dp[i][j]` 的最大值（最长的那段可能在任意位置结束）。
   小例子：`nums1=[1,2,3,2,1]`、`nums2=[3,2,1,4,7]`，匹配到 `[3,2,1]` 这一段时三个格子依次 1→2→3，最大值 3。

3. **关键优化（二维压成一维）**

   `dp[i][j]` 只依赖左上角 `dp[i-1][j-1]`。用一维数组 `dp[j]` 保存当前行，外层 `i` 递增，内层 `j` **从大到小**遍历：这样读取 `dp[j-1]` 时它还是"上一行"的旧值，不会被本行提前覆盖。空间从 O(m·n) 降到 O(n)。

### Java 实现（findLength）

```java
class Solution {
    public int findLength(int[] nums1, int[] nums2) {
        int m = nums1.length, n = nums2.length;
        int[] dp = new int[n + 1]; // dp[j] 表示以 nums2[j-1] 结尾的最长公共后缀
        int ans = 0;

        for (int i = 1; i <= m; i++) {
            // 内层逆序：保证 dp[j-1] 仍是上一行（i-1）的值，实现滚动
            for (int j = n; j >= 1; j--) {
                if (nums1[i - 1] == nums2[j - 1]) {
                    dp[j] = dp[j - 1] + 1;
                } else {
                    dp[j] = 0;
                }
                ans = Math.max(ans, dp[j]);
            }
        }
        return ans;
    }
}
```

### 复杂度

- 时间：O(m × n)。两层循环把两个数组的每一对位置都比较一次。
- 空间：O(n)。只开了一个长度为 `n+1` 的滚动数组（`n` 为较短数组时更省）。

### 易错点与扩展（面试高频考点）

1. **内层循环必须逆序**：正向遍历时 `dp[j-1]` 已被本行更新，会错误叠加；逆序才能读到上一行的值。
2. **子数组 vs 子序列**：子数组要求连续，所以不相等时必须把 `dp[j]` 清零；子序列（LCS）则保留 `max(dp[i-1][j], dp[i][j-1])`，两者状态转移不同，别混用。
3. **答案要边算边取最大**：最长公共段可能在任意位置结束，不能只返回 `dp` 数组最后一个元素。
4. **等号方向**：条件应为 `nums1[i-1] == nums2[j-1]`，注意下标偏移（`dp` 用 1-based，数组用 0-based）。
5. **扩展**：当数组很大时可用"滑动窗口对齐 + 逐对比较"或"二分长度 + 滚动哈希"把期望复杂度降下来（本题 m,n ≤ 1000，O(m·n) 的 DP 已足够）。

### C++ 实现

```cpp
#include <vector>
#include <algorithm>
using namespace std;

class Solution {
public:
    int findLength(vector<int>& nums1, vector<int>& nums2) {
        int m = nums1.size(), n = nums2.size();
        vector<int> dp(n + 1, 0);
        int ans = 0;
        for (int i = 1; i <= m; i++) {
            // 逆序保证 dp[j-1] 仍是上一行的值
            for (int j = n; j >= 1; j--) {
                if (nums1[i - 1] == nums2[j - 1]) {
                    dp[j] = dp[j - 1] + 1;
                } else {
                    dp[j] = 0;
                }
                ans = max(ans, dp[j]);
            }
        }
        return ans;
    }
};
```

### Python 实现

```python
class Solution:
    def findLength(self, nums1: list[int], nums2: list[int]) -> int:
        m, n = len(nums1), len(nums2)
        dp = [0] * (n + 1)
        ans = 0
        for i in range(1, m + 1):
            # 逆序保证 dp[j-1] 仍是上一行的值
            for j in range(n, 0, -1):
                if nums1[i - 1] == nums2[j - 1]:
                    dp[j] = dp[j - 1] + 1
                    ans = max(ans, dp[j])
                else:
                    dp[j] = 0
        return ans
```
