# 1027. 最长等差数列

| 题目信息 | 内容 |
|---|---|
| 难度 | 中等 |
| 核心模式 | 动态规划 + 哈希表：按「末尾元素 + 公差」记录最长长度 |
| 时间复杂度 | O(n^2) |
| 空间复杂度 | O(n^2) |

## 题目与约束

给定一个整数数组 `nums`，返回 `nums` 中最长等差子序列的长度。

注意：

- 子序列 是由另一个数组删除一些（也可以不删除）元素后得到的数组，并且不改变剩余元素之间的相对顺序。

- 如果对于所有 `0 <= i < seq.length - 1`，`seq[i + 1] - seq[i]` 的值都相同，则称序列 `seq` 为等差序列。

 

示例 1：

输入： nums = [3, 6, 9, 12]

输出： 4

解释： 整个数组本身就是一个公差为 3 的等差序列，因此最长等差子序列为 `[3, 6, 9, 12]`，长度为 4。

示例 2：

输入： nums = [9, 4, 7, 2, 10]

输出： 3

解释： 最长等差子序列为 `[4, 7, 10]`（下标分别为 `1`、`2`、`4`），公差为 3。不存在长度为 4 的等差子序列。

示例 3：

输入： nums = [20, 1, 15, 3, 10, 5, 8]

输出： 4

解释： 最长等差子序列为 `[20, 15, 10, 5]`（下标分别为 `0`、`2`、`4`、`5`），公差为 -5。

 

提示：

- `2 <= nums.length <= 1500`

- `0 <= nums[i] <= 500`

[🔗 前往力扣原题验证 →](https://leetcode.cn/problems/longest-arithmetic-subsequence/)

## 核心不变量

> `dp[i][d]` 表示「以 `nums[i]` 结尾、公差为 `d`」的最长等差子序列长度；枚举所有前驱 `j < i`，有 `dp[i][d] = dp[j][d] + 1`（`dp[j][d]` 不存在时取 1 再 +1）。

## 完整推导

### 思路推导

1. **状态怎么定**
   等差子序列由“末尾元素”和“公差”两个量就能唯一刻画后续走向。于是设 `dp[i][d]` = 以 `nums[i]` 结尾、公差为 `d` 的最长等差子序列长度。

2. **怎么转移**
   枚举前驱 `j`（`0 <= j < i`），令公差 `d = nums[i] - nums[j]`。那么把 `nums[i]` 接到“以 `nums[j]` 结尾、公差同为 `d`”的序列后面即可，长度加一：
   `dp[i][d] = dp[j][d] + 1`。
   若 `dp[j][d]` 不存在，说明 `nums[j]` 与 `nums[i]` 就是这条等差序列的前两个元素，长度取 2（即“单元素长度 1”再加 1）。

3. **为什么用哈希表**
   公差 `d` 可能为负数，范围是 `[-500, 500]`，无法直接当数组下标（或需要加偏移）。用哈希表把 `d → 最长长度` 映射起来，天然支持任意整数公差。

4. **小例子**
   `nums = [9, 4, 7, 2, 10]`。当算到 `10`（下标 4）时，枚举前驱 `7`（下标 2），`d = 3`，而 `dp[2][3]` 记录着以 7 结尾、公差 3 的序列 `[4,7]` 长度为 2，于是 `dp[4][3] = 3`，对应 `[4,7,10]`。全局取最大即为 3。

### Java 实现（末尾+公差的 DP）

```java
import java.util.ArrayList;
import java.util.HashMap;
import java.util.List;
import java.util.Map;

class Solution {
    public int longestArithSeqLength(int[] nums) {
        int n = nums.length;
        // dp[i] : 以 nums[i] 结尾的各个公差对应的最长长度
        List<Map<Integer, Integer>> dp = new ArrayList<>();
        for (int i = 0; i < n; i++) {
            dp.add(new HashMap<>());
        }

        int ans = 2; // 任意两个元素都能构成等差序列，长度至少为 2
        for (int i = 0; i < n; i++) {
            for (int j = 0; j < i; j++) {
                int d = nums[i] - nums[j];        // 当前公差
                // 接在以 j 结尾、公差同为 d 的序列后面；没有则说明只有 j 一个元素
                int len = dp.get(j).getOrDefault(d, 1) + 1;
                // 更新以 i 结尾、公差 d 的最长长度
                dp.get(i).put(d, Math.max(dp.get(i).getOrDefault(d, 0), len));
                ans = Math.max(ans, len);
            }
        }
        return ans;
    }
}
```

### 复杂度

- 时间：`O(n^2)`。两层循环枚举所有 `(j, i)` 对，每次哈希表操作均摊 `O(1)`。
- 空间：`O(n^2)`。最坏情况下每个 `dp[i]` 记录 `O(n)` 个不同公差，总计 `O(n^2)`。

### 易错点与扩展（面试高频考点）

1. **状态定义要含公差**：只记录“以 i 结尾的最长长度”不够，必须带公差维度 `d`，否则无法判断能否接续。
2. **默认值取 1 而非 0**：`dp[j][d]` 不存在意味着 `j` 是序列第一个元素，长度 1，再 +1 得到 2。
3. **公差可能为负**：用哈希表存 `d`，或用大小为 `2 * 500 + 1` 的数组加偏移，但绝不能直接用 `Math.abs(d)`（会把 +d 与 -d 混淆）。
4. **答案下界是 2**：`nums.length >= 2`，任意两个数都能构成长度 2 的等差序列。
5. **范围优化**：`nums[i] <= 500` 时可用定长数组 `dp[n][1001]`（偏移 500）替代哈希表，常数更小，是面试加分项。

## 力扣原题

[1027. 最长等差数列](https://leetcode.cn/problems/longest-arithmetic-subsequence/)

### C++ 实现

```cpp
#include <vector>
#include <unordered_map>
#include <algorithm>
using namespace std;

class Solution {
public:
    int longestArithSeqLength(vector<int>& nums) {
        int n = nums.size();
        // dp[i] : 以 nums[i] 结尾、各公差对应的最长长度
        vector<unordered_map<int, int>> dp(n);
        int ans = 2;

        for (int i = 0; i < n; i++) {
            for (int j = 0; j < i; j++) {
                int d = nums[i] - nums[j];
                int len = 2;
                auto it = dp[j].find(d);
                if (it != dp[j].end()) {
                    len = it->second + 1;   // 接在已有序列后面
                }
                // 更新以 i 结尾、公差 d 的最长长度
                auto it2 = dp[i].find(d);
                if (it2 == dp[i].end() || it2->second < len) {
                    dp[i][d] = len;
                }
                ans = max(ans, len);
            }
        }
        return ans;
    }
};
```

### Python 实现

```python
class Solution:
    def longestArithSeqLength(self, nums: list[int]) -> int:
        n = len(nums)
        # dp[i] : 以 nums[i] 结尾、各公差对应的最长长度
        dp = [dict() for _ in range(n)]
        ans = 2

        for i in range(n):
            for j in range(i):
                d = nums[i] - nums[j]
                length = dp[j].get(d, 1) + 1   # 没有则说明 j 是首元素，长度 1
                if length > dp[i].get(d, 0):
                    dp[i][d] = length
                if length > ans:
                    ans = length
        return ans
```
