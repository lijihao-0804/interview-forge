题目信息 内容
难度 中等
核心模式 预处理每个位置向左/向上的连续 1 长度，枚举右下角与边长
时间复杂度 O(m·n·min(m,n))
空间复杂度 O(m·n)

题目与约束

给你一个由若干 0 和 1 组成的二维网格 grid，请你找出边界全部由 1 组成的最大 正方形 子网格，并返回该子网格中的元素数量。如果不存在，则返回 0。

示例 1：

输入：grid = [[1,1,1],[1,0,1],[1,1,1]]
输出：9

示例 2：

输入：grid = [[1,1,0,0]]
输出：1

提示：

  • 1 <= grid.length <= 100

  • 1 <= grid[0].length <= 100

  • grid[i][j] 为 0 或 1

🔗 前往力扣原题验证 →

核心不变量

若以 (i,j) 为右下角、边长为 k 的正方形四条边全为 1，则必须同时满足：底边 h[i][j] >= k、右边 v[i][j] >= k、顶边 h[i-k+1][j] >= k、左边 v[i][j-k+1] >= k；其中 h/v 分别是"向左/向上连续 1 的个数"的预计算。

完整推导

思路推导

  1. 暴力为什么慢

直接枚举所有正方形（四个角 + 四条边逐格检查），最坏是 O(m²n²·边长) 级别。100×100 的网格下虽然勉强能过，但面试想要的是更清晰、可扩展的预处理解法。

  1. 预处理"向右/向上能延伸多远"

定义： - h[i][j]：以 (i,j) 为右端点，向左连续 1 的个数（含自身）； - v[i][j]：以 (i,j) 为下端点，向上连续 1 的个数（含自身）。

二者都能一遍线性递推：grid[i][j]==1 时 h[i][j] = h[i][j-1] + 1、v[i][j] = v[i-1][j] + 1，否则为 0。这样"某条水平/竖直边是否全为 1、长度是否够"就变成 O(1) 的比较。

  1. 枚举右下角 + 边长

以 (i,j) 为正方形右下角，边长 k 的上限是 min(h[i][j], v[i][j])（底边、右边要够长）。对每个 k，只需再校验： - 顶边：h[i-k+1][j] >= k（第 i-k+1 行从 j 往左至少 k 个 1）； - 左边：v[i][j-k+1] >= k（第 j-k+1 列从 i 往上至少 k 个 1）。

四条边全过，边长 k 就合法。对每个右下角从大到小尝试 k，用全局最大值剪枝（k > best 才继续试）。

  1. 小例子（示例 1）

网格 [[1,1,1],[1,0,1],[1,1,1]]，以右下角 (2,2) 为例，h[2][2]=3、v[2][2]=3，先试 k=3：顶边 h[0][2]=3>=3、左边 v[2][0]=3>=3，四边全 1，得最大正方形 3×3，面积 9。

Java 实现（largest1BorderedSquare）

class Solution {
    public int largest1BorderedSquare(int[][] grid) {
        int m = grid.length, n = grid[0].length;
        // h[i][j]：以 (i,j) 结尾向左连续 1 的个数
        // v[i][j]：以 (i,j) 结尾向上连续 1 的个数
        int[][] h = new int[m][n];
        int[][] v = new int[m][n];
        for (int i = 0; i < m; i++) {
            for (int j = 0; j < n; j++) {
                if (grid[i][j] == 1) {
                    h[i][j] = (j > 0 ? h[i][j - 1] : 0) + 1;
                    v[i][j] = (i > 0 ? v[i - 1][j] : 0) + 1;
                }
            }
        }

        int best = 0; // 记录最大合法边长
        for (int i = 0; i < m; i++) {
            for (int j = 0; j < n; j++) {
                // 以 (i,j) 为右下角，边长上限由底边、右边决定
                int maxK = Math.min(h[i][j], v[i][j]);
                // 从大到小试，k 不超过当前最优时无需再试
                for (int k = maxK; k > best; k--) {
                    // 校验顶边与左边
                    if (h[i - k + 1][j] >= k && v[i][j - k + 1] >= k) {
                        best = k;
                        break; // 已找到该右下角的最优边长
                    }
                }
            }
        }
        return best * best; // 返回元素数量（面积）
    }
}

复杂度

  • 时间：O(m·n·min(m,n))。预处理 O(m·n)；每个格子最多尝试 min(m,n) 个边长，每次 O(1) 校验。
  • 空间：O(m·n)。需要两个与网格同规模的 h、v 数组。

易错点与扩展（面试高频考点）

  1. 两个辅助方向要选对：用"向左 / 向上"来刻画底边、右边，恰好能配合"右下角"枚举；若改成"向右 / 向下"，则要把枚举点换成左上角，别把两组方向混搭导致索引越界或漏判。

  2. 四条边缺一不可：底边和右边通过 maxK 隐式保证，但顶边和左边必须在循环里显式校验，漏掉任一条都会把"缺角"的框判成合法。

  3. 索引越界：h[i-k+1][j]、v[i][j-k+1] 中的 i-k+1、j-k+1 必须 >= 0。由于 k <= maxK <= min(h[i][j], v[i][j])，且 h[i][j] <= j+1、v[i][j] <= i+1，这一条件自动满足。

  4. 返回面积不是边长：题目要"元素数量"，答案应是 best * best，只返回 best 会错。

  5. 扩展：若要求"最大以 1 为边界的矩形"，可枚举上下两条边再对每列做直方图/单调栈求最大宽度；若只统计"边界全 1 的正方形个数"，则可用同样的 h/v 预处理配合枚举，把校验改为计数。

#include <vector>
#include <algorithm>
using namespace std;

class Solution {
public:
    int largest1BorderedSquare(vector<vector<int>>& grid) {
        int m = grid.size(), n = grid[0].size();
        // h[i][j]：向左连续 1 的个数；v[i][j]：向上连续 1 的个数
        vector<vector<int>> h(m, vector<int>(n, 0));
        vector<vector<int>> v(m, vector<int>(n, 0));
        for (int i = 0; i < m; i++) {
            for (int j = 0; j < n; j++) {
                if (grid[i][j] == 1) {
                    h[i][j] = (j > 0 ? h[i][j - 1] : 0) + 1;
                    v[i][j] = (i > 0 ? v[i - 1][j] : 0) + 1;
                }
            }
        }

        int best = 0;
        for (int i = 0; i < m; i++) {
            for (int j = 0; j < n; j++) {
                int maxK = min(h[i][j], v[i][j]);
                for (int k = maxK; k > best; k--) {
                    // 校验顶边与左边
                    if (h[i - k + 1][j] >= k && v[i][j - k + 1] >= k) {
                        best = k;
                        break;
                    }
                }
            }
        }
        return best * best;
    }
};

Python 实现

class Solution:
    def largest1BorderedSquare(self, grid):
        m, n = len(grid), len(grid[0])
        # h[i][j]：向左连续 1 的个数；v[i][j]：向上连续 1 的个数
        h = [[0] * n for _ in range(m)]
        v = [[0] * n for _ in range(m)]
        for i in range(m):
            for j in range(n):
                if grid[i][j] == 1:
                    h[i][j] = (h[i][j - 1] if j > 0 else 0) + 1
                    v[i][j] = (v[i - 1][j] if i > 0 else 0) + 1

        best = 0
        for i in range(m):
            for j in range(n):
                max_k = min(h[i][j], v[i][j])
                k = max_k
                # 从大到小试，k 不超过 best 时无需再试
                while k > best:
                    if h[i - k + 1][j] >= k and v[i][j - k + 1] >= k:
                        best = k
                        break
                    k -= 1
        return best * best
