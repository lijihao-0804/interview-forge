# 442. 数组中重复的数据

| 题目信息 | 内容 |
|---|---|
| 难度 | Medium |
| 核心模式 | 原地取负标记（利用值域 [1, n] 直接当下标索引） |
| 时间复杂度 | O(n) |
| 空间复杂度 | O(1) |

## 题目与约束

给你一个长度为 `n` 的整数数组 `nums`，其中 `nums` 的所有整数都在范围 `[1, n]` 内，且每个整数出现**最多两次**。请你找出所有出现**两次**的整数，并以数组形式返回。

你必须设计并实现一个时间复杂度为 `O(n)` 且仅使用常量额外空间（不包括存储输出所需的空间）的算法解决此问题。

**示例 1：**

```
输入：nums = [4,3,2,7,8,2,3,1]
输出：[2,3]
```

**示例 2：**

```
输入：nums = [1,1,2]
输出：[1]
```

**示例 3：**

```
输入：nums = [1]
输出：[]
```

**提示：**

- `n == nums.length`
- `1 <= n <= 10^5`
- `1 <= nums[i] <= n`
- `nums` 中的每个元素出现**一次**或**两次**

## 核心不变量

> 因为所有值都落在 `[1, n]`，值 `v` 可以天然当作下标 `v-1` 使用。把「是否访问过下标 `i`」编码为 `nums[i]` 的正负号，就能在不额外开数组的情况下记录访问状态。

## 完整推导

### 思路推导

1. **直觉与痛点（为什么不能直接开哈希）**：用哈希表或计数数组统计每个数出现几次，是 O(n) 时间，但需要 O(n) 额外空间，题目明确要求常量额外空间。排序也能做，但会破坏 O(n) 时间。必须「借用数组本身」当记账本。

2. **破局思路（用下标当抽屉，用符号当标签）**：注意到 `1 <= nums[i] <= n`，于是 `nums[i] - 1` 恰好是一个合法下标。把数组看成 n 个抽屉，`nums[i]` 就是「该去哪个抽屉报到」。我们约定：
   - 遍历到值 `v = |nums[i]|`，目标下标 `idx = v - 1`；
   - 若 `nums[idx]` 还是**正数**：说明这是第一次遇到 `v`，把 `nums[idx]` 取负，做个「已访问」标记；
   - 若 `nums[idx]` 已经**是负数**：说明之前已经标记过，也就是 `v` 出现了第二次，把 `v` 收进答案。

   小例子 `[4,3,2,7,8,2,3,1]`：依次处理 4→标负下标3；3→标负下标2；2→标负下标1；7→标负下标6；8→标负下标7；再遇 2，下标1 已负 → 收 2；再遇 3，下标2 已负 → 收 3；1→标负下标0。答案 `[2,3]`。

3. **为什么取绝对值**：数组在遍历过程中会被我们改成负数，后面读到这些位置时要还原出原值，必须用 `abs`。

### Java 实现（原地取负标记）

```java
import java.util.ArrayList;
import java.util.List;

class Solution {
    public List<Integer> findDuplicates(int[] nums) {
        List<Integer> res = new ArrayList<>();
        for (int i = 0; i < nums.length; i++) {
            int idx = Math.abs(nums[i]) - 1; // 值映射到下标，注意取绝对值
            if (nums[idx] < 0) {
                // 该下标已被标记过，说明当前值出现了第二次
                res.add(idx + 1);
            } else {
                // 第一次遇到，取负标记
                nums[idx] = -nums[idx];
            }
        }
        return res;
    }
}
```

### 复杂度

- 时间：O(n)。只需一次遍历，每次做常数次取绝对值、取负、比较和写回。
- 空间：O(1)（不计输出数组）。只借用了输入数组本身的正负号作为标记，没有申请额外空间。

### 易错点与扩展（面试高频考点）

1. **忘记取绝对值**：数组被就地修改为负数，后续读取 `nums[i]` 时必须用 `abs` 还原真实值，否则下标会变成负数导致越界或逻辑错误。
2. **标记的是下标不是值**：约定 `idx = v - 1`，标记 `nums[idx]`；恢复输出时也要 `idx + 1`。这两处差 1 是最常见的 bug。
3. **重复两次的判定方式**：第一次见到某值只是标负，第二次见到才收集。若某值只出现一次，它对应的下标只会被标负一次，不会被误收。
4. **不要用「交换归位」思路套这题**：`448. 找到所有数组中消失的数字` 可用归位法，但本题要求收集重复值，取负标记更简洁；两者值域假设同为 `[1, n]`。
5. **扩展**：本题前提「每个值最多出现两次」保证结果不重复；若允许出现三次及以上，同一值会被重复收集，需要额外去重或用其他做法。

### C++ 实现

```cpp
class Solution {
public:
    std::vector<int> findDuplicates(std::vector<int>& nums) {
        std::vector<int> res;
        for (int i = 0; i < (int)nums.size(); ++i) {
            int idx = std::abs(nums[i]) - 1;   // 值映射到下标
            if (nums[idx] < 0) {
                res.push_back(idx + 1);        // 已被标记，说明重复
            } else {
                nums[idx] = -nums[idx];        // 第一次遇到，取负标记
            }
        }
        return res;
    }
};
```

### Python 实现

```python
class Solution:
    def findDuplicates(self, nums: List[int]) -> List[int]:
        res = []
        for x in nums:
            idx = abs(x) - 1          # 值映射到下标，注意取绝对值
            if nums[idx] < 0:
                res.append(idx + 1)   # 已被标记，说明重复
            else:
                nums[idx] = -nums[idx]  # 第一次遇到，取负标记
        return res
```
