# 494. 目标和

| 题目信息 | 内容 |
|---|---|
| 难度 | 中等 |
| 核心模式 | 转化为 0-1 背包计数：选出一部分元素取正号使其和为 (sum+target)/2 |
| 时间复杂度 | O(n · S) |
| 空间复杂度 | O(S) |

## 题目与约束

给你一个非负整数数组 `nums` 和一个整数 `target`。

向数组中的每个整数前添加 `'+'` 或 `'-'`，然后串联起所有整数，可以构造一个**表达式**：

- 例如，`nums = [2, 1]`，可以在 `2` 之前添加 `'+'`，在 `1` 之前添加 `'-'`，然后串联起来得到表达式 `"+2-1"`。

返回可以通过上述方法构造的、运算结果等于 `target` 的不同**表达式**的数目。

**示例 1：**

```
输入：nums = [1,1,1,1,1], target = 3
输出：5
解释：一共有 5 种方法让最终目标和为 3。
-1 + 1 + 1 + 1 + 1 = 3
+1 - 1 + 1 + 1 + 1 = 3
+1 + 1 - 1 + 1 + 1 = 3
+1 + 1 + 1 - 1 + 1 = 3
+1 + 1 + 1 + 1 - 1 = 3
```

**示例 2：**

```
输入：nums = [1], target = 1
输出：1
```

**提示：**

- `1 <= nums.length <= 20`
- `0 <= nums[i] <= 1000`
- `0 <= sum(nums[i]) <= 1000`
- `-1000 <= target <= 1000`

## 核心不变量

> 设所有元素之和为 `S`、取正号的元素和为 `P`，则表达式值 `= P - (S - P) = 2P - S`；令其等于 `target` 得 `P = (S + target) / 2`。问题等价于「从 `nums` 中选子集，使子集和恰为 `(S + target)/2` 的方案数」。

## 完整推导

### 思路推导

1. **直觉与痛点（为什么直接枚举不行？）**

   每个数有 `+`、`-` 两种选法，共 `2^n` 种组合。`n <= 20` 时约 `10^6`，回溯能过；但若把规模放大就爆炸。我们想要一个多项式解法。

2. **破局思路（把“加减混合”改写成“选或不选”）**

   记取正号的元素集合求和为 `P`，其余取负号，则所有元素总和为 `S`：

   `表达式值 = P - (S - P) = 2P - S`。

   要求它等于 `target`，即 `2P - S = target`，解得 `P = (S + target) / 2`。于是「给每个数加正负号」变成了「选出一个子集，使它的和恰好为 `bag = (S + target)/2`」，求方案数——标准的 **0-1 背包计数**。

   以 `nums=[1,1,1,1,1], target=3` 为例：`S=5`，`bag=(5+3)/2=4`，即「选 4 个 1 凑成 4」，从 5 个里选 4 个共 `C(5,4)=5` 种，答案正是 `5`。

3. **关键追问（无解条件的判定）**

   若 `S + target` 为奇数，则 `bag` 不是整数，无解返回 `0`；若 `S + target < 0`（`target < -S`），`bag` 为负，也无解返回 `0`。这两个前置判断必须在建 DP 之前做，否则下标会越界。

### Java 实现（0-1 背包计数 + 滚动数组）

```java
class Solution {
    public int findTargetSumWays(int[] nums, int target) {
        int sum = 0;
        for (int x : nums) {
            sum += x;
        }

        // 要求 sum + target 必须为非负偶数，否则无法凑出整数 bag
        int diff = sum + target;
        if (diff < 0 || (diff & 1) == 1) {
            return 0;
        }
        int bag = diff / 2;

        // dp[j]：从已处理元素中选子集，和为 j 的方案数
        int[] dp = new int[bag + 1];
        dp[0] = 1; // 选空集，和为 0，方案数为 1

        for (int x : nums) {
            // 0-1 背包：倒序枚举容量，保证每个元素只用一次
            for (int j = bag; j >= x; j--) {
                dp[j] += dp[j - x];
            }
        }
        return dp[bag];
    }
}
```

### 复杂度

- 时间：`O(n · bag)`，其中 `bag = (sum + target)/2 <= 1000`。外层遍历元素、内层遍历容量，均为常数级上界。
- 空间：`O(bag)`。滚动一维数组，只保留当前容量的方案数。

### 易错点与扩展（面试高频考点）

1. **忘记前置合法性判断**：`sum + target` 为奇数或为负时直接无解。漏掉会得到非整数 `bag` 或负下标，数组越界或结果错误。
2. **内层循环必须倒序**：0-1 背包中每个元素只能用一次，容量 `j` 从大到小枚举；若正序枚举会退化成完全背包，同一元素被重复使用。
3. **`dp[0] = 1` 的初值含义**：表示「不选任何元素、和为 0」这一种合法方案。初值设为 `0` 会导致所有结果都变成 `0`。
4. **元素为 0 的情况**：`nums` 可以含 `0`，此时内层 `j >= x` 中 `x=0` 仍会执行 `dp[j] += dp[j]`，方案数翻倍——这恰好对应「`0` 取正或取负都算不同表达式」，是正确行为。
5. **扩展——朴素回溯**：`n <= 20` 时也可直接 DFS 枚举正负号，`O(2^n)`；面试中通常要求先给回溯，再优化到背包 DP，并说明二者的等价转化。

### C++ 实现

```cpp
#include <vector>
#include <numeric>
using namespace std;

class Solution {
public:
    int findTargetSumWays(vector<int>& nums, int target) {
        int sum = accumulate(nums.begin(), nums.end(), 0);

        int diff = sum + target;
        // sum + target 必须为非负偶数
        if (diff < 0 || (diff & 1)) return 0;
        int bag = diff / 2;

        vector<int> dp(bag + 1, 0);
        dp[0] = 1; // 选空集，一种方案

        for (int x : nums) {
            // 0-1 背包，容量倒序
            for (int j = bag; j >= x; j--) {
                dp[j] += dp[j - x];
            }
        }
        return dp[bag];
    }
};
```

### Python 实现

```python
class Solution:
    def findTargetSumWays(self, nums: list[int], target: int) -> int:
        total = sum(nums)
        diff = total + target

        # sum + target 必须为非负偶数
        if diff < 0 or diff % 2 == 1:
            return 0
        bag = diff // 2

        # dp[j]：子集和为 j 的方案数
        dp = [0] * (bag + 1)
        dp[0] = 1  # 选空集，一种方案

        for x in nums:
            # 0-1 背包，容量倒序
            for j in range(bag, x - 1, -1):
                dp[j] += dp[j - x]

        return dp[bag]
```
