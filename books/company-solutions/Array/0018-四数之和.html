题目信息 内容
难度 中等
核心模式 排序 + 两重枚举 + 双指针去重
时间复杂度 O(n³)
空间复杂度 O(log n)（排序栈开销，可视为 O(1)）

题目与约束

给你一个由 n 个整数组成的数组 nums，和一个目标值 target。请你找出并返回满足下述全部条件且不重复的四元组 [nums[a], nums[b], nums[c], nums[d]]（若两个四元组元素一一对应，则认为两个四元组重复）：

  • 0 <= a, b, c, d < n
  • a、b、c 和 d 互不相同
  • nums[a] + nums[b] + nums[c] + nums[d] == target

你可以按任意顺序返回答案。

示例 1：

输入：nums = [1,0,-1,0,-2,2], target = 0
输出：[[-2,-1,1,2],[-2,0,0,2],[-1,0,0,1]]

示例 2：

输入：nums = [2,2,2,2,2], target = 8
输出：[[2,2,2,2]]

提示：

  • 1 <= nums.length <= 200
  • -10^9 <= nums[i] <= 10^9
  • -10^9 <= target <= 10^9

核心不变量

排序后先固定前两个数 nums[i]、nums[j]，再在 (j, n) 区间用双指针夹逼后两个数；任何一层跳过相邻重复值，就保证结果四元组不重复。

完整推导

思路推导

  1. 直觉与痛点（为什么不能四重循环？）

四重枚举是 O(n⁴)，n = 200 时约 1.6×10⁹，太慢；而且还要处理大量重复组合。我们需要降一维，并系统性地去重。

  1. 破局思路（两重枚举 + 双指针，把 O(n⁴) 降到 O(n³)）

类比"三数之和"：先排序，再固定前两个数 i < j，剩下两个数用双指针 l = j+1, r = n-1 在有序区间夹逼：

  • sum == target：记录答案，然后 l++、r--，并跳过与刚用过值相同的元素，避免同一组重复；
  • sum < target：右移 l 让和变大；
  • sum > target：左移 r 让和变小。

以 nums = [1,0,-1,0,-2,2], target = 0 为例：排序得 [-2,-1,0,0,1,2]。固定 (-2,-1) 时双指针可找到 (1,2) 凑成 0；固定 (-2,0)（第二层去重保证只取一次 0）找到 (0,2)；固定 (-1,0) 找到 (0,1)，正好得到题目三组答案。

  1. 关键追问（去重与溢出，两个必须踩准的点）
  • 去重：在 i、j 两层都要写 if (i > 0 && nums[i] == nums[i-1]) continue;（j 同理 j > i+1）。双指针命中后还要 while 跳过相同值。漏掉任意一处都会产生重复四元组。
  • 溢出：nums[i] 最大到 10⁹，四个数相加可达 4×10⁹，超过 int 上限 2.1×10⁹。必须用 long（Java）/long long（C++）承接和，否则比较结果错误。
  • 剪枝：由于已排序，若"当前最小四数和 > target"可提前 break，"当前最大四数和 < target"可 continue，能显著提速且不影响正确性。

Java 实现（排序 + 双指针 + 去重）

import java.util.ArrayList;
import java.util.Arrays;
import java.util.List;

class Solution {
    public List<List<Integer>> fourSum(int[] nums, int target) {
        List<List<Integer>> res = new ArrayList<>();
        int n = nums.length;
        if (n < 4) {
            return res; // 不足四个数，无解
        }

        Arrays.sort(nums); // 排序是双指针与去重的前提

        // 第一层：固定 nums[i]
        for (int i = 0; i < n - 3; i++) {
            // 跳过重复的第一个数
            if (i > 0 && nums[i] == nums[i - 1]) {
                continue;
            }
            // 剪枝：当前能取到的最小四数和已大于 target，后续 i 只会更大，直接结束
            if ((long) nums[i] + nums[i + 1] + nums[i + 2] + nums[i + 3] > target) {
                break;
            }
            // 剪枝：当前能取到的最大四数和仍小于 target，这一层 i 无解
            if ((long) nums[i] + nums[n - 1] + nums[n - 2] + nums[n - 3] < target) {
                continue;
            }

            // 第二层：固定 nums[j]
            for (int j = i + 1; j < n - 2; j++) {
                // 跳过重复的第二个数（注意下界是 i+1）
                if (j > i + 1 && nums[j] == nums[j - 1]) {
                    continue;
                }
                // 内层剪枝
                if ((long) nums[i] + nums[j] + nums[j + 1] + nums[j + 2] > target) {
                    break;
                }
                if ((long) nums[i] + nums[j] + nums[n - 1] + nums[n - 2] < target) {
                    continue;
                }

                // 双指针夹逼后两个数
                int l = j + 1, r = n - 1;
                while (l < r) {
                    // 用 long 承接，防止四个 10^9 相加溢出
                    long sum = (long) nums[i] + nums[j] + nums[l] + nums[r];
                    if (sum == target) {
                        res.add(Arrays.asList(nums[i], nums[j], nums[l], nums[r]));
                        // 跳过与当前 l、r 相同的元素，避免重复
                        while (l < r && nums[l] == nums[l + 1]) l++;
                        while (l < r && nums[r] == nums[r - 1]) r--;
                        l++;
                        r--;
                    } else if (sum < target) {
                        l++; // 和偏小，右移左指针
                    } else {
                        r--; // 和偏大，左移右指针
                    }
                }
            }
        }

        return res;
    }
}

复杂度

  • 时间：O(n³)。排序 O(n log n)；外层两层枚举合计约 n²/2 种 (i, j)，每种内部双指针扫一遍 O(n)，总为 O(n³)。
  • 空间：O(log n)。主要来自排序的递归栈；除保存答案外没有随规模增长的额外结构（不计结果集）。

易错点与扩展（面试高频考点）

  1. 整数溢出（本题最大陷阱）：四个 10⁹ 相加约 4×10⁹，超出 int。必须用 long/long long 承接和与剪枝表达式，否则判断全错。
  2. 两层去重的下界写错：i 层用 i > 0 && nums[i] == nums[i-1]，j 层必须用 j > i+1 && nums[j] == nums[j-1]（不是 j > 0），否则会误跳过合法组合。
  3. 双指针命中后的去重：sum == target 后要先分别跳过相同的 nums[l]、nums[r]，再 l++ r--，否则同一四元组会被重复加入。
  4. 剪枝的 break 与 continue 别用反：最小四数和 > target 用 break（当前 i 之后只会更大），最大四数和 < target 用 continue（换个 i 还有机会）。
  5. 面试追问——通用 k 数之和：四数之和是"递归 + 双指针"的模板特例。可写一个 kSum(nums, target, k, start)，k == 2 时退化为双指针，否则固定首个数后递归 k-1，去重逻辑与本题完全一致。

C++ 实现

#include <vector>
#include <algorithm>
using namespace std;

class Solution {
public:
    vector<vector<int>> fourSum(vector<int>& nums, int target) {
        vector<vector<int>> res;
        int n = nums.size();
        if (n < 4) return res;

        sort(nums.begin(), nums.end());

        for (int i = 0; i < n - 3; i++) {
            if (i > 0 && nums[i] == nums[i - 1]) continue;
            // 剪枝用 long long 防止溢出
            if ((long long)nums[i] + nums[i + 1] + nums[i + 2] + nums[i + 3] > target) break;
            if ((long long)nums[i] + nums[n - 1] + nums[n - 2] + nums[n - 3] < target) continue;

            for (int j = i + 1; j < n - 2; j++) {
                if (j > i + 1 && nums[j] == nums[j - 1]) continue;
                if ((long long)nums[i] + nums[j] + nums[j + 1] + nums[j + 2] > target) break;
                if ((long long)nums[i] + nums[j] + nums[n - 1] + nums[n - 2] < target) continue;

                int l = j + 1, r = n - 1;
                while (l < r) {
                    long long sum = (long long)nums[i] + nums[j] + nums[l] + nums[r];
                    if (sum == target) {
                        res.push_back({nums[i], nums[j], nums[l], nums[r]});
                        while (l < r && nums[l] == nums[l + 1]) l++;
                        while (l < r && nums[r] == nums[r - 1]) r--;
                        l++;
                        r--;
                    } else if (sum < target) {
                        l++;
                    } else {
                        r--;
                    }
                }
            }
        }
        return res;
    }
};

Python 实现

class Solution:
    def fourSum(self, nums: list[int], target: int) -> list[list[int]]:
        nums.sort()
        n = len(nums)
        res = []
        if n < 4:
            return res

        for i in range(n - 3):
            # 跳过重复的第一个数
            if i > 0 and nums[i] == nums[i - 1]:
                continue
            # 剪枝：当前最小四数和已大于 target，后续 i 只会更大
            if nums[i] + nums[i + 1] + nums[i + 2] + nums[i + 3] > target:
                break
            # 剪枝：当前最大四数和仍小于 target
            if nums[i] + nums[n - 1] + nums[n - 2] + nums[n - 3] < target:
                continue

            for j in range(i + 1, n - 2):
                # 跳过重复的第二个数
                if j > i + 1 and nums[j] == nums[j - 1]:
                    continue
                if nums[i] + nums[j] + nums[j + 1] + nums[j + 2] > target:
                    break
                if nums[i] + nums[j] + nums[n - 1] + nums[n - 2] < target:
                    continue

                l, r = j + 1, n - 1
                while l < r:
                    s = nums[i] + nums[j] + nums[l] + nums[r]
                    if s == target:
                        res.append([nums[i], nums[j], nums[l], nums[r]])
                        # 跳过重复元素
                        while l < r and nums[l] == nums[l + 1]:
                            l += 1
                        while l < r and nums[r] == nums[r - 1]:
                            r -= 1
                        l += 1
                        r -= 1
                    elif s < target:
                        l += 1
                    else:
                        r -= 1
        return res
