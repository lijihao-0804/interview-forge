题目信息 内容
难度 简单
核心模式 一次线性扫描，遇 1 累加计数、遇 0 清零并更新最大值
时间复杂度 O(n)
空间复杂度 O(1)

题目与约束

给定一个二进制数组 nums ， 计算其中最大连续 1 的个数。

示例 1：

输入：nums = [1,1,0,1,1,1]
输出：3
解释：开头的两位和最后的三位都是连续 1 ，所以最大连续 1 的个数是 3.

示例 2:

输入：nums = [1,0,1,1,0,1]
输出：2

提示：

  • 1 <= nums.length <= 105

  • nums[i] 不是 0 就是 1.

🔗 前往力扣原题验证 →

核心不变量

遍历到任一位置时，cnt 恰好是以当前位置结尾的连续 1 的长度，max 是已扫描部分出现的最大连续 1 长度。

完整推导

思路推导

  1. 直觉与痛点（为什么不统计所有段的长度再取最大？）

最直接的想法是「遇到 0 就把前面一段 1 的长度截下来比较」。其实不必切段，只要一个计数器边扫边维护即可：连续段结束的那一刻（遇到 0）就是它长度的上限，此时和答案比较一次，之后清零。

  1. 破局思路（滚动计数）

维护 cnt（当前连续 1 的个数）和 max（历史最大）：

  • 遇到 1：cnt++，并立刻用 cnt 更新 max（因为最长段可能在数组末尾结束，不能只在遇到 0 时才更新）。
  • 遇到 0：cnt = 0，连续段被截断。

以 [1,1,0,1,1,1] 为例：前两个 1 让 cnt 涨到 2，遇 0 清零；随后三个 1 让 cnt 涨到 3，max 最终为 3。

  1. 关键追问（为什么要在遇到 1 时就更新 max？）

如果只在遇到 0 时更新，那么当最长连续段一直延伸到数组末尾时（如 [1,1,1]），循环结束前都不会触发更新，答案会漏掉。把更新放在 1 分支里，等价于在每个位置都记录一次峰值，最稳妥。

Java 实现（一次扫描）

class Solution {
    public int findMaxConsecutiveOnes(int[] nums) {
        int max = 0; // 历史最大连续 1 的个数
        int cnt = 0; // 以当前位置结尾的连续 1 的个数
        for (int x : nums) {
            if (x == 1) {
                cnt++;
                if (cnt > max) {
                    max = cnt; // 立刻更新，避免末尾长段被漏掉
                }
            } else {
                cnt = 0; // 遇到 0，连续段被截断
            }
        }
        return max;
    }
}

复杂度

  • 时间：O(n)。只遍历数组一次，每个元素常数操作。
  • 空间：O(1)。仅用两个计数变量。

易错点与扩展（面试高频考点）

  1. 只在遇到 0 时更新答案会漏解：如上文 [1,1,1] 的例子，最长段在末尾，循环结束前没有 0 触发更新。必须在 1 分支里就更新 max。
  2. 忘记清零：遇到 0 一定要把 cnt 归零，否则会把不连续的 1 累加到一起。
  3. 空数组 / 全 0 的边界：题目保证长度 >= 1；全 0 时 max 应返回 0，初值设为 0 即可自然满足。
  4. 面试追问——允许翻转 k 个 0：若把题目升级为「最多把 k 个 0 翻成 1 后的最长连续 1」，可改用滑动窗口：右端扩张，窗口内 0 的个数超过 k 时收缩左端，窗口最大宽度即答案，复杂度仍为 O(n)。

C++ 实现

#include <vector>
using namespace std;

class Solution {
public:
    int findMaxConsecutiveOnes(vector<int>& nums) {
        int mx = 0;
        int cnt = 0;
        for (int x : nums) {
            if (x == 1) {
                ++cnt;
                if (cnt > mx) mx = cnt; // 立刻更新，避免末尾长段漏掉
            } else {
                cnt = 0; // 遇 0 截断
            }
        }
        return mx;
    }
};

Python 实现

class Solution:
    def findMaxConsecutiveOnes(self, nums: list[int]) -> int:
        mx = 0
        cnt = 0
        for x in nums:
            if x == 1:
                cnt += 1
                if cnt > mx:
                    mx = cnt  # 立刻更新，避免末尾长段漏掉
            else:
                cnt = 0      # 遇 0 截断
        return mx
