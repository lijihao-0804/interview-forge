# 525. 连续数组

| 题目信息 | 内容 |
|---|---|
| 难度 | 中等 |
| 核心模式 | 前缀和（把 0 记为 -1）+ 哈希表 |
| 时间复杂度 | O(n) |
| 空间复杂度 | O(n) |

## 题目与约束

给定一个二进制数组 `nums` , 找到含有相同数量的 `0` 和 `1` 的最长连续子数组，并返回该子数组的长度。

 

示例 1：

输入：nums = [0,1]  
输出：2  
说明：[0, 1] 是具有相同数量 0 和 1 的最长连续子数组。

示例 2：

输入：nums = [0,1,0]  
输出：2  
说明：[0, 1] (或 [1, 0]) 是具有相同数量 0 和 1 的最长连续子数组。

示例 3：

输入：nums = [0,1,1,1,1,1,0,0,0]  
输出：6  
解释：[1,1,1,0,0,0] 是具有相同数量 0 和 1 的最长连续子数组。

 

提示：

- `1 <= nums.length <= 105`

- `nums[i]` 不是 `0` 就是 `1`

[🔗 前往力扣原题验证 →](https://leetcode.cn/problems/contiguous-array/)

## 核心不变量

> 把 `0` 记作 `-1`、`1` 记作 `+1` 之后，"`0` 与 `1` 数量相等"就等价于"子数组和为 0"；当前前缀和与某个更早位置的前缀和相等时，两者之间就构成一段平衡子数组，其长度为两个下标的差。

## 完整推导

### 思路推导

1. **直觉与痛点（"数量相等"难直接用和表达）**

   直接数 0 和 1 的个数需要同时跟踪两个计数器，组合情况太多。但"数量相等"本质是"抵消"——只要把 `0` 当成 `-1`、`1` 当成 `+1`，就变成求**和为 0 的最长连续子数组**，问题立刻清爽。

2. **破局思路（前缀和找相同值）**

   记 `prefix[i]` 为前 `i` 个元素映射后的和（`0→-1`、`1→+1`）。子数组 `nums[l..r]` 和为 0，等价于 `prefix[r+1] == prefix[l]`。于是：
   - 用哈希表记录"每个前缀和**第一次**出现的下标"；
   - 遍历时若当前前缀和已出现过，就用 `当前位置 - 首次出现位置` 更新最大长度；否则记录当前下标。

   以 `nums = [0,1,1,1,1,1,0,0,0]` 为例，映射为 `[-1,1,1,1,1,1,-1,-1,-1]`。前缀和在走过前 3 个元素（`-1,1,1`）后为 1；继续累加，到末尾附近前缀和再次回到同值，其间距离 6，对应子数组 `[1,1,1,0,0,0]`。

3. **关键追问（为什么只记录"第一次"出现？）**

   求最长子数组，用最早的首次出现位置能使长度最大化。因此同一个前缀和只需保留最先遇到的下标，后续再遇到时直接算长度，不覆盖。

### Java 实现（前缀和 + 哈希表）

```java
import java.util.HashMap;
import java.util.Map;

class Solution {
    public int findMaxLength(int[] nums) {
        // 把 0 视作 -1，问题转化为“和为 0 的最长连续子数组”
        // map: 前缀和 -> 最早出现的下标
        Map<Integer, Integer> sumToIndex = new HashMap<>();
        sumToIndex.put(0, -1); // 空前缀和为 0，下标 -1

        int prefix = 0;
        int maxLen = 0;
        for (int i = 0; i < nums.length; i++) {
            prefix += (nums[i] == 1) ? 1 : -1;

            Integer prev = sumToIndex.get(prefix);
            if (prev != null) {
                // 相同前缀和 → 中间子数组和为 0 → 0 与 1 数量相等
                maxLen = Math.max(maxLen, i - prev);
            } else {
                sumToIndex.put(prefix, i);
            }
        }
        return maxLen;
    }
}
```

### 复杂度

- 时间：O(n)。一次遍历，哈希表操作均摊 O(1)。
- 空间：O(n)。前缀和的取值范围为 `[-n, n]`，哈希表最多存 O(n) 个不同值。

### 易错点与扩展（面试高频考点）

1. **忘记初始化 `map[0] = -1`**：这代表空前缀。若漏掉，从下标 0 开始的平衡子数组（如 `[0,1]`）会漏算。
2. **只记录最早下标**：若每次遇到都覆盖下标，长度会被算小。必须是"存在则算长度、不存在才记录"。
3. **映射方向别搞反**：`0 → -1`、`1 → +1`；反了只会求成"相反数平衡"，虽然对称仍能对，但语义易混，建议统一按 `0→-1`。
4. **连续 vs 子序列**：题目要求连续子数组，所以必须用前缀和 + 下标差，不能排序后统计。
5. **对比 LeetCode 523**：523 求"和为 k 的倍数"，本题是"和为 0"的特例（把 0、1 映射为 ±1）。两者都是"前缀和 + 哈希表存首次出现下标"，框架完全一致。

## 力扣原题

[525. 连续数组](https://leetcode.cn/problems/contiguous-array/)

### C++ 实现

```cpp
#include <vector>
#include <unordered_map>
#include <algorithm>
using namespace std;

class Solution {
public:
    int findMaxLength(vector<int>& nums) {
        // 前缀和 -> 最早出现的下标
        unordered_map<int, int> sumToIndex;
        sumToIndex[0] = -1; // 空前缀和为 0

        int prefix = 0;
        int maxLen = 0;
        for (int i = 0; i < (int)nums.size(); i++) {
            prefix += (nums[i] == 1) ? 1 : -1;

            auto it = sumToIndex.find(prefix);
            if (it != sumToIndex.end()) {
                maxLen = max(maxLen, i - it->second); // 相同前缀和 → 平衡子数组
            } else {
                sumToIndex[prefix] = i;
            }
        }
        return maxLen;
    }
};
```

### Python 实现

```python
class Solution:
    def findMaxLength(self, nums: list[int]) -> int:
        # 前缀和 -> 最早出现的下标
        sum_to_index = {0: -1}  # 空前缀和为 0
        prefix = 0
        max_len = 0

        for i, x in enumerate(nums):
            prefix += 1 if x == 1 else -1

            if prefix in sum_to_index:
                max_len = max(max_len, i - sum_to_index[prefix])  # 平衡子数组
            else:
                sum_to_index[prefix] = i

        return max_len
```
