题目与约束

给你一个整数数组 prices 和一个整数 k ，其中 prices[i] 是某支给定的股票在第 i 天的价格。

设计一个算法来计算你所能获取的最大利润。你最多可以完成 k 笔交易。也就是说，你最多可以买 k 次，卖 k 次。

注意：你不能同时参与多笔交易（你必须在再次购买前出售掉之前的股票）。

示例 1：

<strong>输入：</strong>k = 2, prices = [2,4,1]
<strong>输出：</strong>2
<strong>解释：</strong>在第 1 天 (股票价格 = 2) 的时候买入，在第 2 天 (股票价格 = 4) 的时候卖出，这笔交易所能获得利润 = 4-2 = 2 。

示例 2：

<strong>输入：</strong>k = 2, prices = [3,2,6,5,0,3]
<strong>输出：</strong>7
<strong>解释：</strong>在第 2 天 (股票价格 = 2) 的时候买入，在第 3 天 (股票价格 = 6) 的时候卖出, 这笔交易所能获得利润 = 6-2 = 4 。
     随后，在第 5 天 (股票价格 = 0) 的时候买入，在第 6 天 (股票价格 = 3) 的时候卖出, 这笔交易所能获得利润 = 3-0 = 3 。

提示：

  • 1 <= k <= 100

  • 1 <= prices.length <= 1000

  • 0 <= prices[i] <= 1000

核心不变量

每天结束，buy[j] 表示「至多完成 j 笔交易、且当前持有股票」时的最大收益，sell[j] 表示「至多完成 j 笔交易、且当前不持股」时的最大收益；sell[j] 只会因「今天卖出」而更新，且卖出前必须先持有。

完整推导

思路推导

  1. 直觉与痛点（少一次交易多一种可能）

相比「最多 2 笔」的版本，这里 k 可以到 100，不能为每笔交易都写死变量。统一做法是把「交易次数」当成一个维度，用 dp[j] 表示完成 j 笔交易的状态。

  1. 破局思路（持股 / 不持股双状态）

对每个交易次数 j 维护两个量： - buy[j]：至多 j 笔交易、此刻「手里有股票」的最大现金（买入是负收益）。 - sell[j]：至多 j 笔交易、此刻「手里没股票」的最大现金。 遍历每一天的价格 p，更新： - buy[j] = max(buy[j], sell[j-1] - p)：要么不买，要么在「至多 j-1 笔已完成交易、空仓」的基础上买进（开启第 j 笔）。 - sell[j] = max(sell[j], buy[j] + p)：要么不卖，要么以今天价格卖出。

  1. 关键追问（循环方向与初值）

buy[j] 依赖 sell[j-1]。为了只使用「前一天」的状态，交易次数 j 从 k 递减到 1 更新，这样 sell[j-1] 还没被今天覆盖。初值：buy 全设为负无穷（表示不可能持有），sell 全设为 0（不交易收益为 0）。最终答案为 sell[k]。

  1. 优化（k 很大时退化为无限次交易）

一笔交易至少占用两天，因此最多有意义的交易数是 n/2。当 k >= n/2 时，等价于「不限次数」，直接用贪心：把所有上涨区间的差价累加即可，O(n)。

Java 实现（maxProfit）

import java.util.Arrays;

class Solution {
    public int maxProfit(int k, int[] prices) {
        int n = prices.length;
        if (n == 0) {
            return 0;
        }

        // 交易次数上限：一笔交易至少 2 天，超过 n/2 等价于不限次数
        if (k >= n / 2) {
            int profit = 0;
            for (int i = 1; i < n; i++) {
                if (prices[i] > prices[i - 1]) {
                    profit += prices[i] - prices[i - 1];
                }
            }
            return profit;
        }

        // buy[j]: 至多 j 笔交易且持股的最大收益；sell[j]: 至多 j 笔交易且空仓的最大收益
        int[] buy = new int[k + 1];
        int[] sell = new int[k + 1];
        Arrays.fill(buy, Integer.MIN_VALUE / 2); // 用 MIN_VALUE/2 防止 +p 溢出

        for (int price : prices) {
            // 倒序保证 sell[j-1] 仍是「前一天」的状态
            for (int j = k; j >= 1; j--) {
                buy[j] = Math.max(buy[j], sell[j - 1] - price);
                sell[j] = Math.max(sell[j], buy[j] + price);
            }
        }

        return sell[k];
    }
}

复杂度

  • 时间：O(n·k)。外层遍历 n 天，内层遍历 k 个交易次数；若走快速路径则为 O(n)。
  • 空间：O(k)。只用了两个长度为 k+1 的滚动数组，无需 n × k 的二维表。

易错点与扩展（面试高频考点）

  1. 溢出与初值：buy 的初值若用 Integer.MIN_VALUE，buy[j] + price 会下溢；应使用 Integer.MIN_VALUE / 2 作为「负无穷」。
  2. 循环方向：j 必须从 k 倒序到 1。若正序，sell[j-1] 会被当天数据提前更新，导致同一天反复「卖出再买回」的非法叠加。
  3. 交易计数归属：把 buy[j] = sell[j-1] - p 视为「开启第 j 笔交易」，因此卖出后自然落在 sell[j]，一次买入—卖出正好计一笔，不会重复计数。
  4. k 过大：不加 k >= n/2 的快速路径也能过，但当 k 达到 n/2 以上时 DP 有大量无效状态，加贪心路径更稳。
  5. 与同类题的关系：k = 1 即第 121 题、k = 2 即第 123 题、k 无限即第 122 题，本题是这一系列的统一模板，面试常要求「一题打通」全部变体。

C++ 实现

#include <vector>
#include <algorithm>
#include <climits>

class Solution {
public:
    int maxProfit(int k, std::vector<int>& prices) {
        int n = prices.size();
        if (n == 0) {
            return 0;
        }

        // 交易次数足够多时等价于不限次数，贪心累加所有上涨差价
        if (k >= n / 2) {
            int profit = 0;
            for (int i = 1; i < n; ++i) {
                if (prices[i] > prices[i - 1]) {
                    profit += prices[i] - prices[i - 1];
                }
            }
            return profit;
        }

        std::vector<int> buy(k + 1, INT_MIN / 2);
        std::vector<int> sell(k + 1, 0);

        for (int price : prices) {
            for (int j = k; j >= 1; --j) {
                buy[j] = std::max(buy[j], sell[j - 1] - price);
                sell[j] = std::max(sell[j], buy[j] + price);
            }
        }

        return sell[k];
    }
};

Python 实现

from typing import List


class Solution:
    def maxProfit(self, k: int, prices: List[int]) -> int:
        n = len(prices)
        if n == 0:
            return 0

        # 交易次数足够多时等价于不限次数，贪心累加所有上涨差价
        if k >= n // 2:
            profit = 0
            for i in range(1, n):
                if prices[i] > prices[i - 1]:
                    profit += prices[i] - prices[i - 1]
            return profit

        NEG = float("-inf")
        buy = [NEG] * (k + 1)  # 至多 j 笔交易且持股的最大收益
        sell = [0] * (k + 1)   # 至多 j 笔交易且空仓的最大收益

        for price in prices:
            for j in range(k, 0, -1):
                buy[j] = max(buy[j], sell[j - 1] - price)
                sell[j] = max(sell[j], buy[j] + price)

        return sell[k]
