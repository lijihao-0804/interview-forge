# 598. 区间加法 II

| 题目信息 | 内容 |
|---|---|
| 难度 | 简单 |
| 核心模式 | 所有操作的公共前缀矩形 = 各维度取最小值 |
| 时间复杂度 | O(k)，k 为 `ops` 的长度 |
| 空间复杂度 | O(1) |

## 题目与约束

给你一个 `m x n` 的矩阵 `M`，初始时所有单元格的值都为 `0`。另有一个操作数组 `ops`，其中 `ops[i] = [ai, bi]` 表示对所有满足 `0 <= x < ai` 且 `0 <= y < bi` 的单元格 `M[x][y]` 都加 `1`。

在执行完所有操作之后，请计算并返回矩阵中**最大整数出现的次数**。

**示例 1：**

```
输入：m = 3, n = 3, ops = [[2,2],[3,3]]
输出：4
解释：M 中最大的整数是 2，而且 M 中有 4 个值为 2 的元素。因此返回 4。
```

**示例 2：**

```
输入：m = 3, n = 3, ops = [[2,2],[3,3],[3,3],[3,3],[2,2],[3,3],[3,3],[3,3],[2,2],[3,3],[3,3],[3,3]]
输出：4
```

**示例 3：**

```
输入：m = 3, n = 3, ops = []
输出：9
```

**提示：**

- `1 <= m, n <= 4 * 10^4`
- `0 <= ops.length <= 10^4`
- `ops[i].length == 2`
- `1 <= ai <= m`
- `1 <= bi <= n`

## 核心不变量

> 每个操作都是给左上角 `(0,0)` 出发的前缀矩形加一，因此被**所有**操作覆盖的公共矩形就是最大值的所在区域。

## 完整推导

### 思路推导

1. **直觉与痛点（不能真的去模拟矩阵）**

   直觉做法是开一个 `m x n` 的矩阵，然后每个操作都把左上角的子矩形扫一遍加一。但 `m、n` 最大可达 `4 * 10^4`，矩阵有 `1.6 * 10^9` 个格子，再加上 `10^4` 次操作，时间和空间都直接爆炸。必须换角度。

2. **换个视角（谁被加的次数最多？）**

   每个操作都从左上角 `(0,0)` 开始，覆盖的是一个「前缀矩形」`[0, ai) x [0, bi)`。一个格子被加了几次，取决于它被多少个前缀矩形覆盖。显然，越靠左上角的格子被覆盖的机会越多。

   于是「加得最多」的格子，正是被**所有**操作共同覆盖的格子。所有前缀矩形的交集仍然是前缀矩形，其行数为 `min(ai)`、列数为 `min(bi)`。

3. **小例子**

   以示例 1 为例：`ops = [[2,2],[3,3]]`。行方向取 `min(2,3)=2`，列方向取 `min(2,3)=2`，公共区域就是左上角 `2 x 2` 的 4 个格子，它们各自被两个操作都加过，最终值都是 2，其余格子只被覆盖一次或零次。答案 `2 * 2 = 4`，与题目一致。

4. **边界（`ops` 为空）**

   如果没有任何操作，整个矩阵都保持 0，所有格子都是最大值（0），答案是全部格子数 `m * n`。把 `minA、minB` 分别初始化为 `m、n` 即可自然覆盖这种情况。

### Java 实现（取各维度最小值）

```java
class Solution {
    public int maxCount(int m, int n, int[][] ops) {
        // 初始化为整个矩阵：若 ops 为空，公共区域就是整个矩阵
        int minA = m;
        int minB = n;

        // 逐个操作收缩公共前缀矩形
        for (int[] op : ops) {
            minA = Math.min(minA, op[0]);
            minB = Math.min(minB, op[1]);
        }

        // 公共区域的行数 × 列数即为最大值出现的次数
        return minA * minB;
    }
}
```

### 复杂度

- 时间：`O(k)`，其中 `k = ops.length`，只需遍历一次操作数组，每个操作做两次常数时间比较。
- 空间：`O(1)`，只用了几个整型变量，没有额外开辟与矩阵规模相关的空间。

### 易错点与扩展（面试高频考点）

1. **千万不要真的创建 `m x n` 矩阵**：规模可达 `4 * 10^4` 见方，直接内存超限。
2. **忘记 `ops` 为空的情况**：此时答案应为 `m * n`，把 `minA、minB` 初始化为 `m、n` 即可自动处理。
3. **乘法溢出**：`minA * minB` 最大约 `4*10^4 * 4*10^4 = 1.6*10^9`，在 `int` 范围内（约 `2.1*10^9`），用 `int` 安全；若数值更大需改用 `long`。
4. **本质转化**：本题是「二维差分/前缀矩形交集」的极端简化——因为所有操作都从原点出发，交集只需各维度独立取最小值，无需差分数组。
5. **面试追问**：如果操作矩形不再是前缀矩形（起点任意），就需要二维差分数组 + 前缀和来找最大值，复杂度变为 `O(mn + k)`。

## 力扣原题

[598. 区间加法 II](https://leetcode.cn/problems/range-addition-ii/)

### C++ 实现

```cpp
#include <vector>
#include <algorithm>
using namespace std;

class Solution {
public:
    int maxCount(int m, int n, vector<vector<int>>& ops) {
        int minA = m, minB = n;            // ops 为空时公共区域即整个矩阵
        for (const auto& op : ops) {
            minA = min(minA, op[0]);       // 行方向取最小
            minB = min(minB, op[1]);       // 列方向取最小
        }
        return minA * minB;                // 公共区域大小 = 最大值出现次数
    }
};
```

### Python 实现

```python
class Solution:
    def maxCount(self, m: int, n: int, ops: list[list[int]]) -> int:
        min_a, min_b = m, n          # ops 为空时公共区域即整个矩阵
        for a, b in ops:
            min_a = min(min_a, a)    # 行方向取最小
            min_b = min(min_b, b)    # 列方向取最小
        return min_a * min_b         # 公共区域大小 = 最大值出现次数
```
