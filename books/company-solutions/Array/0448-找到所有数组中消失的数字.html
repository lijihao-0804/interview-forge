题目与约束

给你一个含 n 个整数的数组 nums，其中 nums[i] 在区间 [1, n] 内。请你找出所有在 [1, n] 范围内但没有出现在 nums 中的数字，并以数组的形式返回结果。

示例 1：

输入：nums = [4,3,2,7,8,2,3,1]
输出：[5,6]

示例 2：

输入：nums = [1,1]
输出：[2]

提示：

  • n == nums.length
  • 1 <= n <= 10^5
  • 1 <= nums[i] <= n

进阶： 你能在不使用额外空间且时间复杂度为 O(n) 的情况下解决这个问题吗？你可以假定返回的数组不算在额外空间内。

核心不变量

数字 x 是否出现过，可以记录在 nums[x-1] 的符号上：只要 x 出现过，就把 nums[x-1] 置为负数；最后仍为正数的位置 i 说明数字 i+1 从未出现。

完整推导

思路推导

  1. 直觉与痛点（哈希表要额外空间）

最直接的办法是用一个 HashSet 或布尔数组记录出现过的数字，再扫一遍 [1, n] 找缺的。但这样需要 O(n) 额外空间，而进阶要求 O(1)。

  1. 破局思路（把数组本身当哈希表）

关键观察：nums[i] 的取值范围恰好是 [1, n]，和下标 [0, n-1] 一一对应。于是「数字 v 出现过」这件事，可以编码进 nums[v-1] 的符号里——把 nums[v-1] 变成负数。负数不会丢失原始信息，因为取绝对值就能还原。

  1. 具体流程

第一遍遍历：对每个 x = nums[i]，取 idx = abs(x) - 1，若 nums[idx] > 0 就令 nums[idx] = -nums[idx]（加负号表示「数字 idx+1 出现过」）。之所以要 abs，是因为当前位置可能在之前已被别人标成负数。

第二遍遍历：若 nums[i] > 0，说明数字 i+1 对应的位置从没被标记过，即 i+1 是消失的数字，收集之。

以 [4,3,2,7,8,2,3,1] 为例，标记后只有第 5、6 个位置（对应 5、6）仍为正，返回 [5,6]。

  1. 为什么是 O(1) 空间

全程只用了 abs、下标和取负运算，没有开辟与 n 同阶的辅助数组（返回结果不计入）。

Java 实现（原地负号标记）

import java.util.ArrayList;
import java.util.List;

class Solution {
    public List<Integer> findDisappearedNumbers(int[] nums) {
        int n = nums.length;

        // 第一遍：把出现过的数字 v 记录为 nums[v-1] 取负
        for (int i = 0; i < n; i++) {
            int idx = Math.abs(nums[i]) - 1; // 用绝对值兼容已被标记成负数的位置
            if (nums[idx] > 0) {
                nums[idx] = -nums[idx];
            }
        }

        // 第二遍：仍为正数的位置 i 表示数字 i+1 从未出现
        List<Integer> res = new ArrayList<>();
        for (int i = 0; i < n; i++) {
            if (nums[i] > 0) {
                res.add(i + 1);
            }
        }
        return res;
    }
}

复杂度

  • 时间：O(n)，两遍线性扫描，每个位置只做常数次操作。
  • 空间：O(1)，除返回的列表外只用了若干临时变量；结果数组按题意不计入额外空间。

易错点与扩展（面试高频考点）

  1. 忘记取绝对值：第二遍虽不受影响，但第一遍里若当前位置已被标记为负，nums[i] - 1 会变成越界或错误下标，必须用 Math.abs(nums[i]) - 1。
  2. 重复出现要防二次取负：若 nums[idx] 已经是负数，再次取负会变回正数导致漏标，所以要先判断 nums[idx] > 0。
  3. 原地修改输入是否被允许：面试中若不允许修改原数组，则退回「哈希集合」或「下标置换（把每个数换到它该在的位置）」方案，后者同样 O(1) 空间。
  4. 扩展——下标置换法：不断把 nums[i] 交换到 nums[nums[i]-1]，直到归位，最后 nums[i] != i+1 的位置即为答案；思路不同但复杂度一致。
  5. 面试追问——第 442 题「数组中重复的数据」：用完全相同的负号标记，改成收集被标记两次的位置，可一并掌握这一族题。

448. 找到所有数组中消失的数字

C++ 实现

#include <vector>
#include <cstdlib>
using namespace std;

class Solution {
public:
    vector<int> findDisappearedNumbers(vector<int>& nums) {
        int n = nums.size();

        // 第一遍：用负号标记出现过的数字
        for (int i = 0; i < n; i++) {
            int idx = abs(nums[i]) - 1;
            if (nums[idx] > 0) {
                nums[idx] = -nums[idx];
            }
        }

        // 第二遍：仍为正数的下标对应消失的数字
        vector<int> res;
        for (int i = 0; i < n; i++) {
            if (nums[i] > 0) {
                res.push_back(i + 1);
            }
        }
        return res;
    }
};

Python 实现

from typing import List

class Solution:
    def findDisappearedNumbers(self, nums: List[int]) -> List[int]:
        # 第一遍：用负号标记出现过的数字
        for x in nums:
            idx = abs(x) - 1
            if nums[idx] > 0:
                nums[idx] = -nums[idx]

        # 第二遍：仍为正数的下标对应消失的数字
        return [i + 1 for i in range(len(nums)) if nums[i] > 0]
