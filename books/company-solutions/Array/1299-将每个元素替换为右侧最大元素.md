# 1299. 将每个元素替换为右侧最大元素

| 题目信息 | 内容 |
|---|---|
| 难度 | 简单 |
| 核心模式 | 逆序扫描维护「右侧最大值」 |
| 时间复杂度 | O(n) |
| 空间复杂度 | O(n)（输出数组；若原地覆盖则 O(1)） |

## 题目与约束

给你一个数组 `arr` ，请你将每个元素用它右边最大的元素替换，如果是最后一个元素，用 `-1` 替换。

完成所有替换操作后，请你返回这个数组。

 

示例 1：

```
<strong>输入：</strong>arr = [17,18,5,4,6,1]
<strong>输出：</strong>[18,6,6,6,1,-1]
<strong>解释：</strong>
- 下标 0 的元素 --> 右侧最大元素是下标 1 的元素 (18)
- 下标 1 的元素 --> 右侧最大元素是下标 4 的元素 (6)
- 下标 2 的元素 --> 右侧最大元素是下标 4 的元素 (6)
- 下标 3 的元素 --> 右侧最大元素是下标 4 的元素 (6)
- 下标 4 的元素 --> 右侧最大元素是下标 5 的元素 (1)
- 下标 5 的元素 --> 右侧没有其他元素，替换为 -1
```

示例 2：

```
<strong>输入：</strong>arr = [400]
<strong>输出：</strong>[-1]
<strong>解释：</strong>下标<strong> </strong>0 的元素右侧没有其他元素。
```

 

提示：

- `1 <= arr.length <= 104`

- `1 <= arr[i] <= 105`

[🔗 前往力扣原题验证 →](https://leetcode.cn/problems/replace-elements-with-greatest-element-on-right-side/)

## 核心不变量

> 从右往左扫描时，变量 `maxRight` 始终保存「当前元素右侧所有元素」的最大值。

## 完整推导

### 思路推导

1. **正面硬刚的痛点**：如果对每个位置 `i` 都从头扫一遍 `i+1 .. n-1` 求最大值，总复杂度是 O(n²)，在 `n = 10^4` 时会达到 10^8 量级，不够优雅。

2. **换个方向看问题**：位置 `i` 的答案只和它右边有关，而位置 `i+1` 的答案也只看它右边。两者共享了绝大部分「右侧元素」。于是我们从右往左走，用一个变量把「已经扫过的那些元素的最大值」滚动地保留下来。

3. **小例子跑一遍**：`arr = [17,18,5,4,6,1]`。
   - 初始化 `maxRight = -1`，从 `i = 5` 开始：`ans[5] = -1`，然后 `maxRight = max(-1, 1) = 1`。
   - `i = 4`：`ans[4] = 1`，`maxRight = max(1, 6) = 6`。
   - `i = 3`：`ans[3] = 6`，`maxRight = max(6, 4) = 6`。
   - 依次得到 `ans = [18,6,6,6,1,-1]`，与示例一致。

4. **关键顺序**：一定先写 `ans[i] = maxRight`（此时 `maxRight` 还不含 `arr[i]`），再更新 `maxRight`。顺序反了就会把自己算进去。

### Java 实现（逆序滚动最大值）

```java
class Solution {
    public int[] replaceElements(int[] arr) {
        int n = arr.length;
        int[] ans = new int[n];
        int maxRight = -1;                 // 最后一个元素右侧没有元素，最大值视为 -1
        for (int i = n - 1; i >= 0; i--) {
            ans[i] = maxRight;             // 先记录「不含自己」的右侧最大值
            maxRight = Math.max(maxRight, arr[i]); // 再把当前值并入，供左边使用
        }
        return ans;
    }
}
```

### 复杂度

- 时间：O(n)，只从右到左扫描一趟，每个元素常数次操作。
- 空间：O(n)，需要长度为 n 的结果数组；若允许直接修改输入并在原数组上覆盖，则额外空间为 O(1)。

### 易错点与扩展（面试高频考点）

1. **更新顺序写反**：必须先给 `ans[i]` 赋值再更新 `maxRight`，否则会把自己算进「右侧最大值」。
2. **最后一元素漏处理**：`ans[n-1]` 必须是 `-1`；循环从 `n-1` 开始并把 `maxRight` 初值设为 `-1` 可以自然覆盖。
3. **原地写法**：如果面试要求 O(1) 额外空间，可以用 `maxRight` 保存 `arr[i]` 的原值，然后直接写回 `arr[i]`（先存 `old = arr[i]`，`arr[i] = maxRight`，再 `maxRight = max(maxRight, old)`）。
4. **与「前缀最大值」对比**：本题是后缀最大值，若题目改成「左侧最大元素」，只需从左往右扫描、替换方向相反。
5. **单调性直觉**：`ans` 从左到右非递增 / 从右往左非递减（越靠左，右侧元素越多，最大值不会更小），可用来快速自检。

## 力扣原题

[1299. 将每个元素替换为右侧最大元素](https://leetcode.cn/problems/replace-elements-with-greatest-element-on-right-side/)

### C++ 实现

```cpp
class Solution {
public:
    vector<int> replaceElements(vector<int>& arr) {
        int n = arr.size();
        vector<int> ans(n);
        int maxRight = -1;
        for (int i = n - 1; i >= 0; --i) {
            ans[i] = maxRight;
            maxRight = max(maxRight, arr[i]);
        }
        return ans;
    }
};
```

### Python 实现

```python
class Solution:
    def replaceElements(self, arr: list[int]) -> list[int]:
        n = len(arr)
        ans = [0] * n
        max_right = -1
        for i in range(n - 1, -1, -1):
            ans[i] = max_right
            if arr[i] > max_right:
                max_right = arr[i]
        return ans
```
