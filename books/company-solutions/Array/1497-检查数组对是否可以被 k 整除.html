题目与约束

给你一个整数数组 arr 和一个整数 k，其中数组长度是偶数，值为 n。

现在需要把数组恰好分成 n / 2 对，以使每对数字的和都能够被 k 整除。

如果存在这样的分法，请返回 true；否则返回 false。

示例 1：

输入：arr = [1,2,3,4,5,10,6,7,8,9], k = 5
输出：true
解释：划分后的数字对为 (1,9),(2,8),(3,7),(4,6) 以及 (5,10) 。

示例 2：

输入：arr = [1,2,3,4,5,6], k = 7
输出：true
解释：划分后的数字对为 (1,6),(2,5) 以及 (3,4) 。

示例 3：

输入：arr = [1,2,3,4,5,6], k = 10
输出：false
解释：无法在将数组中的数字分为三对的同时满足每对数字和能够被 10 整除的条件。

提示：

  • arr.length == n
  • 1 <= n <= 10^5
  • n 为偶数
  • -10^9 <= arr[i] <= 10^9
  • 1 <= k <= 10^5

核心不变量

两个数之和能被 k 整除，当且仅当它们的余数之和为 0 或 k；因此只需按余数分组，让余数 r 的数量与余数 k-r 的数量相等（余数 0 与 k/2 自配对需为偶数）。

完整推导

思路推导

  1. 直觉与痛点（直接两两配对太慢）：最朴素的做法是枚举所有配对方式，但组合数爆炸。注意到「和能被 k 整除」只取决于两个数各自对 k 取模的余数——例如 k = 5 时，1 只愿意和余数为 4 的数（即 4、9、14…）配。所以真正重要的是余数的分布，而不是数值本身。

  2. 把问题压缩到「余数指纹」：对每个 arr[i] 计算 r = arr[i] mod k（负数要修正成非负余数），用一个长度 k 的计数数组 cnt 统计每个余数出现多少次。

  3. 配对规则： - 余数 0 的数只能和余数 0 的数配对（0+0=0），所以 cnt[0] 必须是偶数。 - 余数 r（1 ≤ r < k）只能和余数 k-r 配对，因此要求 cnt[r] == cnt[k-r]。 - 特例：当 k 为偶数且 r == k/2 时，它是「自己配自己」（r+r = k），所以 cnt[k/2] 必须是偶数。

  4. 小例子验证：arr = [1,2,3,4,5,10,6,7,8,9], k = 5，余数为 [1,2,3,4,0,0,1,2,3,4]。cnt[0]=2（偶），cnt[1]=cnt[4]=2，cnt[2]=cnt[3]=2，全部满足 → true。

Java 实现（canArrange）

class Solution {
    public boolean canArrange(int[] arr, int k) {
        int[] cnt = new int[k];
        for (int x : arr) {
            // Java 的 % 可能得到负数，统一修正到 [0, k)
            int r = ((x % k) + k) % k;
            cnt[r]++;
        }

        // 余数 0 必须两两配对，数量为偶数
        if (cnt[0] % 2 != 0) {
            return false;
        }

        // 余数 r 与 k-r 数量必须相等
        for (int r = 1; r <= k / 2; r++) {
            if (r == k - r) {
                // k 为偶数时的中点余数 k/2，自己配自己，需偶数个
                if (cnt[r] % 2 != 0) {
                    return false;
                }
            } else if (cnt[r] != cnt[k - r]) {
                return false;
            }
        }
        return true;
    }
}

复杂度

  • 时间：O(n + k)，遍历数组统计余数为 O(n)，再扫描一遍计数数组为 O(k)。
  • 空间：O(k)，计数数组长度为 k。

易错点与扩展（面试高频考点）

  1. 负数取模：Java/C++ 中 -1 % 5 == -1，必须先 ((x % k) + k) % k 修正；Python 的 % 天然返回非负，无需修正。
  2. 余数 0 与中点余数：cnt[0] 必须偶数；k 为偶数时 cnt[k/2] 也必须偶数，二者都不能漏。
  3. 边界 k = 1：此时所有数余数都是 0，只要总数 n 为偶数就恒成立（题设已保证 n 为偶数）。
  4. 只统计不排序：本题不需要真的构造配对，只需计数比对，避免 O(n log n) 排序。
  5. 扩展追问：若要求返回具体配对方案，可在得到可行结论后，对每个余数桶内部依次出队配对，构造 O(n)（需输出 n/2 对），O(k) 只是余数类别数。

1497. 检查数组对是否可以被 k 整除

C++ 实现

class Solution {
public:
    bool canArrange(vector<int>& arr, int k) {
        vector<int> cnt(k, 0);
        for (int x : arr) {
            int r = ((x % k) + k) % k; // 修正负数余数
            cnt[r]++;
        }
        if (cnt[0] % 2 != 0) return false;
        for (int r = 1; r <= k / 2; ++r) {
            if (r == k - r) {
                if (cnt[r] % 2 != 0) return false;
            } else if (cnt[r] != cnt[k - r]) {
                return false;
            }
        }
        return true;
    }
};

Python 实现

class Solution:
    def canArrange(self, arr: List[int], k: int) -> bool:
        cnt = [0] * k
        for x in arr:
            cnt[x % k] += 1  # Python 的 % 对负数已返回非负余数
        if cnt[0] % 2 != 0:
            return False
        for r in range(1, k // 2 + 1):
            if r == k - r:
                if cnt[r] % 2 != 0:
                    return False
            elif cnt[r] != cnt[k - r]:
                return False
        return True
