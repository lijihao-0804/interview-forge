# 927. 三等分

| 题目信息 | 内容 |
|---|---|
| 难度 | 困难 |
| 核心模式 | 1 的个数分组 + 逐位比对 |
| 时间复杂度 | O(n) |
| 空间复杂度 | O(1) |

## 题目与约束

给定一个由 `0` 和 `1` 组成的数组 `arr` ，将数组分成  3 个非空的部分 ，使得所有这些部分表示相同的二进制值。

如果可以做到，请返回任何 `[i, j]`，其中 `i+1 < j`，这样一来：

- `arr[0], arr[1], ..., arr[i]` 为第一部分；

- `arr[i + 1], arr[i + 2], ..., arr[j - 1]` 为第二部分；

- `arr[j], arr[j + 1], ..., arr[arr.length - 1]` 为第三部分。

- 这三个部分所表示的二进制值相等。

如果无法做到，就返回 `[-1, -1]`。

注意，在考虑每个部分所表示的二进制时，应当将其看作一个整体。例如，`[1,1,0]` 表示十进制中的 `6`，而不会是 `3`。此外，前导零也是被允许的，所以 `[0,1,1]` 和 `[1,1]` 表示相同的值。

 

示例 1：

输入：arr = [1,0,1,0,1]  
输出：[0,3]

示例 2：

输入：arr = [1,1,0,1,1]  
输出：[-1,-1]

示例 3:

输入：arr = [1,1,0,0,1]  
输出：[0,2]

 

提示：

- `3 <= arr.length <= 3 * 104`

- `arr[i]` 是 `0` 或 `1`

[🔗 前往力扣原题验证 →](https://leetcode.cn/problems/three-equal-parts/)

## 核心不变量

> 三段二进制值相等 ⇒ 三段中 1 的个数相同；但 1 的个数相同只是必要条件，还需各自从第一个 1 起逐位一致（包括尾部的前导零）。

## 完整推导

### 思路推导

1. **先数 1 的总数**：记 `ones` 为数组中 1 的个数。若 `ones == 0`，数组全为 0，任意切成三段都是 `0`，直接返回 `[0, n-1]`。若 `ones % 3 != 0`，由于三段二进制值相等就必须 1 的个数相同，无法三等分，返回 `[-1, -1]`。否则每段应含 `target = ones / 3` 个 1。

2. **定位三段各自的第一个 1**：扫描数组，记录第 1 个 1（第一段开头）、第 `target + 1` 个 1（第二段开头）、第 `2*target + 1` 个 1（第三段开头）的下标 `first / second / third`。三段真正的「有效位」都从各自第一个 1 开始，之前的前导零可任意分配，不影响值。

3. **用第三段长度作为标尺逐位比对**：第三段是最后一段，长度 `len = n - third`（含尾部零）。只要三段从各自起点往后这 `len` 位完全相同，三段就等值。若任何一位对不上，返回 `[-1, -1]`。

4. **小例子**：`arr = [1,0,1,0,1]`，`ones=3, target=1`，`first=0, second=2, third=4`，`len=5-4=1`。比较 `arr[0]=arr[2]=arr[4]=1` 通过，切点 `i = first+len-1 = 0`，`j = second+len = 3`，返回 `[0,3]`。

### Java 实现（1 的计数 + 逐位比对）

```java
class Solution {
    public int[] threeEqualParts(int[] arr) {
        int n = arr.length;
        int ones = 0;
        for (int v : arr) ones += v;

        // 全为 0：任意切法都相等
        if (ones == 0) return new int[]{0, n - 1};
        // 1 的个数无法被 3 整除
        if (ones % 3 != 0) return new int[]{-1, -1};

        int target = ones / 3;
        int first = -1, second = -1, third = -1, cnt = 0;
        for (int i = 0; i < n; i++) {
            if (arr[i] == 1) {
                cnt++;
                if (cnt == 1) first = i;                 // 第一段首个 1
                else if (cnt == target + 1) second = i;  // 第二段首个 1
                else if (cnt == 2 * target + 1) third = i; // 第三段首个 1
            }
        }

        // 第三段长度（含尾部零）就是每一段有效位的长度标尺
        int len = n - third;
        for (int k = 0; k < len; k++) {
            if (arr[first + k] != arr[second + k] || arr[first + k] != arr[third + k]) {
                return new int[]{-1, -1};
            }
        }
        // i 指向第一段末尾，j 指向第三段开头
        return new int[]{first + len - 1, second + len};
    }
}
```

### 复杂度

- 时间：O(n)，一次统计 1、一次定位首 1、一次长度不超过 n 的比对。
- 空间：O(1)，只用了若干下标变量。

### 易错点与扩展（面试高频考点）

1. **忘了全 0 的特判**：`ones == 0` 时不能直接按 `target = 0` 走下去，否则「第 0 个 1」无从定位，必须单独返回 `[0, n-1]`。

2. **切点下标差 1**：返回的是 `[first + len - 1, second + len]`。`i` 是第一段最后一个位置，`j` 是第三段开始位置（中间夹的是第二段），必须保证 `i + 1 < j`，即第二段非空——这由 `target >= 1` 保证。

3. **前导零/尾部零的处理**：只从每段第一个 1 开始比较，前导零不参与；但长度标尺 `len` 要包含第三段尾部可能出现的零，否则会漏掉「尾部零数量不一致」的情况。

4. **别真去把二进制转成数值**：数组长度可达 3×10⁴，数值会溢出任何整型。必须用「按位比较」而非「转整数比较」。

5. **扩展**：把「三等分」推广到「k 等分」时，思路完全一致——只要 1 的总数能被 k 整除，再逐段比对即可。

### C++ 实现

```cpp
class Solution {
public:
    vector<int> threeEqualParts(vector<int>& arr) {
        int n = arr.size();
        int ones = 0;
        for (int v : arr) ones += v;

        if (ones == 0) return {0, n - 1};
        if (ones % 3 != 0) return {-1, -1};

        int target = ones / 3;
        int first = -1, second = -1, third = -1, cnt = 0;
        for (int i = 0; i < n; i++) {
            if (arr[i] == 1) {
                cnt++;
                if (cnt == 1) first = i;
                else if (cnt == target + 1) second = i;
                else if (cnt == 2 * target + 1) third = i;
            }
        }

        int len = n - third;
        for (int k = 0; k < len; k++) {
            if (arr[first + k] != arr[second + k] || arr[first + k] != arr[third + k]) {
                return {-1, -1};
            }
        }
        return {first + len - 1, second + len};
    }
};
```

### Python 实现

```python
from typing import List

class Solution:
    def threeEqualParts(self, arr: List[int]) -> List[int]:
        n = len(arr)
        ones = sum(arr)

        if ones == 0:
            return [0, n - 1]
        if ones % 3 != 0:
            return [-1, -1]

        target = ones // 3
        first = second = third = -1
        cnt = 0
        for i, v in enumerate(arr):
            if v == 1:
                cnt += 1
                if cnt == 1:
                    first = i
                elif cnt == target + 1:
                    second = i
                elif cnt == 2 * target + 1:
                    third = i

        length = n - third
        for k in range(length):
            if arr[first + k] != arr[second + k] or arr[first + k] != arr[third + k]:
                return [-1, -1]
        return [first + length - 1, second + length]
```
