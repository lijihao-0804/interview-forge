1219. 黄金矿工

本题学习状态正在读取学习记录…下次复习：—
本次复习：
按 M 快速切换薄弱标记
遮住推导与代码，先自己想，再逐段揭示
难度中等核心模式网格 DFS + 回溯，枚举所有不重复的路径时间复杂度O(k·3^k)，k 为有黄金的格子数空间复杂度O(k)

题目与约束

你要开发一座金矿，地质勘测学家已经探明了这座金矿中的资源分布，并用大小为 m * n 的网格 grid 进行了标注。每个单元格中的整数就表示这一单元格中的黄金数量；如果该单元格是空的，那么就是 0。

为了使收益最大化，矿工需要按以下规则来开采黄金：

  • 每当矿工进入一个单元，就会收集该单元格中的所有黄金。

  • 矿工每次可以从当前位置向上下左右四个方向走。

  • 每个单元格只能被开采（进入）一次。

  • 不得开采（进入）黄金数目为 0 的单元格。

  • 矿工可以从网格中 任意一个 有黄金的单元格出发或者是停止。

示例 1：

输入：grid = [[0,6,0],[5,8,7],[0,9,0]]
输出：24
解释：
[[0,6,0],
[5,8,7],
[0,9,0]]
一种收集最多黄金的路线是：9 -> 8 -> 7。

示例 2：

输入：grid = [[1,0,7],[2,0,6],[3,4,5],[0,3,0],[9,0,20]]
输出：28
解释：
[[1,0,7],
[2,0,6],
[3,4,5],
[0,3,0],
[9,0,20]]
一种收集最多黄金的路线是：1 -> 2 -> 3 -> 4 -> 5 -> 6 -> 7。

提示：

  • 1 <= grid.length, grid[i].length <= 15

  • 0 <= grid[i][j] <= 100

  • 最多 25 个单元格中有黄金。

核心不变量

从任意一个金格出发做「不重复进入」的深度优先搜索，路径上金量之和的最大值就是答案；回溯时必须把当前格恢复为原来的金量。

完整推导

思路推导

  1. 直觉与痛点（为什么是搜索而不是贪心）

矿工每步有上下左右 4 个选择，且走过的格子不能再走。局部「走向金量最大的邻居」并不能保证全局最优——可能为了捡一个小金子而错过连通的大块金脉。因此必须把「从某格出发能走出的所有简单路径」都探索到，也就是回溯（DFS + 撤销）。

  1. 破局思路（把走过的格子暂时当成墙）

进入 (i, j) 后，先把它累加进当前收益，再把它临时置为 0。由于 0 格本就不能进入，这恰好充当了「已访问」标记，而且不需要额外的 visited 数组。然后向四个方向递归，只要目标格 > 0 就继续。递归返回后，把 grid[i][j] 还原为原来的金量，让别的路径还能再走这一格。

  1. 关键追问（起点怎么选？）

题目允许从任意有黄金的格子出发。所以枚举所有 grid[i][j] > 0 的格子作为起点各跑一次 DFS，取全局最大即可。由于最多只有 25 个金格，起点数量很小。

  1. 小例子

对 [[0,6,0],[5,8,7],[0,9,0]]，从 9 出发：9 → 8，此时 8 的邻居里 9 已用过、6/7 可选，走 7 得 9+8+7=24；若走 6 则得 9+8+6=23。取最大即 24。

Java 实现（DFS 回溯）

class Solution {
    private int m, n;
    private int best = 0;
    private static final int[][] DIRS = {{1, 0}, {-1, 0}, {0, 1}, {0, -1}};

    public int getMaximumGold(int[][] grid) {
        m = grid.length;
        n = grid[0].length;
        // 每个有黄金的格子都可以作为起点
        for (int i = 0; i < m; i++) {
            for (int j = 0; j < n; j++) {
                if (grid[i][j] > 0) {
                    dfs(grid, i, j, 0);
                }
            }
        }
        return best;
    }

    private void dfs(int[][] grid, int i, int j, int sum) {
        int gold = grid[i][j];
        sum += gold;                  // 收集当前格的黄金
        best = Math.max(best, sum);   // 更新全局最优（可以在任意时刻停下）

        grid[i][j] = 0;               // 标记已访问：0 格不可进入，天然充当障碍
        for (int[] d : DIRS) {
            int x = i + d[0], y = j + d[1];
            if (x >= 0 && x < m && y >= 0 && y < n && grid[x][y] > 0) {
                dfs(grid, x, y, sum);
            }
        }
        grid[i][j] = gold;            // 回溯：恢复现场，供其他路径使用
    }
}

C++ 实现

#include <vector>
#include <algorithm>
using namespace std;

class Solution {
    int m, n, best = 0;
    const int dirs[4][2] = {{1, 0}, {-1, 0}, {0, 1}, {0, -1}};

    void dfs(vector<vector<int>>& grid, int i, int j, int sum) {
        int gold = grid[i][j];
        sum += gold;
        best = max(best, sum);
        grid[i][j] = 0;                 // 标记已访问
        for (auto& d : dirs) {
            int x = i + d[0], y = j + d[1];

                dfs(grid, x, y, sum);
            }
        }
        grid[i][j] = gold;              // 回溯，恢复现场

Python 实现

from typing import List

class Solution:
    def getMaximumGold(self, grid: List[List[int]]) -> int:
        m, n = len(grid), len(grid[0])
        dirs = [(1, 0), (-1, 0), (0, 1), (0, -1)]
        best = 0

        def dfs(i: int, j: int, total: int) -> None:
            nonlocal best
            gold = grid[i][j]
            total += gold
            best = max(best, total)

            grid[i][j] = 0                    # 标记已访问
            for dx, dy in dirs:
                x, y = i + dx, j + dy
                if 0 <= x < m and 0 <= y < n and grid[x][y] > 0:
                    dfs(x, y, total)
            grid[i][j] = gold                 # 回溯，恢复现场

        for i in range(m):
            for j in range(n):
                if grid[i][j] > 0:
                    dfs(i, j, 0)
        return best

复杂度

  • 时间：O(k·3^k)。k 为有黄金的格子数（本题 k <= 25）。对每个起点，除了第一步外，每深入一格最多有 3 个「未访问」的邻居可选（来路已访问），路径数上界为 3^k；起点共 k 个，故为 O(k·3^k)。实际因网格形状限制远小于该上界。
  • 空间：O(k)。递归栈深度最多等于路径上的格子数 k；除此外只用了常数变量（best、坐标等），没有额外 visited 数组。
易错点与扩展（面试高频考点）
  1. 忘记回溯/恢复现场：把 grid[i][j] = 0 之后不还原，会导致后续路径少算黄金，结果偏小。sum 用值传递（每层一份），所以只需恢复 grid。
  2. 只从一个起点搜索：题目允许任意起点，必须枚举所有 grid[i][j] > 0 的格子，否则会漏掉以别处为起点的最优路径。
  3. 把 0 也放进来搜：0 格不得进入，进入判断里要写 grid[x][y] > 0；初始化时也只在 > 0 处起搜，否则会把空当走廊。
  4. best 更新时机：在「进入并累加当前格」后立刻更新，因为矿工可以在任意时刻停下，最短的合法路径（只有一格）也要计入。
  5. 剪枝扩展：可预先统计全局黄金总量 total，在 DFS 中若 sum + 当前仍可达的剩余金量 <= best 就剪掉。注意剩余金量要按当前连通区域估算，写错边界容易误剪，面试中先说清复杂度上界即可。
