162. 寻找峰值

本题学习状态正在读取学习记录…下次复习：—

遮住推导与代码，先自己想，再逐段揭示
难度中等核心模式二分查找（按斜率定向）时间复杂度O(log n)空间复杂度O(1)

题目与约束

峰值元素是指其值严格大于左右相邻值的元素。

给你一个整数数组 nums，找到峰值元素并返回其索引。数组可能包含多个峰值，在这种情况下，返回 任何一个峰值 所在位置即可。

你可以假设 nums[-1] = nums[n] = -∞ 。

你必须实现时间复杂度为 O(log n) 的算法来解决此问题。

示例 1：

输入：nums = [1,2,3,1]
输出：2
解释：3 是峰值元素，你的函数应该返回其索引 2。

示例 2：

输入：nums = [1,2,1,3,5,6,4]
输出：1 或 5
解释：你的函数可以返回索引 1，其峰值元素为 2；
或者返回索引 5， 其峰值元素为 6。

提示：

  • 1 <= nums.length <= 1000

  • -231 <= nums[i] <= 231 - 1

  • 对于所有有效的 i 都有 nums[i] != nums[i + 1]

核心不变量

nums[mid] < nums[mid+1] 说明右侧一定存在峰值（因为右边界视为 -∞，一路向上必在某处掉头）；否则左侧（含 mid）一定存在峰值。据此每轮淘汰一半区间。

完整推导

思路推导

  1. 直觉与痛点（为什么不能线性扫？）

线性扫一遍找第一个 nums[i] > nums[i+1] 的位置当然是 O(n)，但题目强制 O(log n)，暗示必须二分。二分的前提是"能根据局部信息，确定答案必在某半边"，本题的局部信息就是相邻两点的大小关系（斜率）。

  1. 破局思路（顺着上坡走）

看 mid 和它右边的邻居 mid+1：

  • 若 nums[mid] < nums[mid+1]，当前位置在"上坡"。由于 nums[n] = -∞，从 mid+1 一路往右走，高度不可能无限上升，最终必然在某个下标处开始下降——那个转折点就是峰值。所以峰值一定在 [mid+1, hi]，令 lo = mid + 1。
  • 若 nums[mid] > nums[mid+1]，当前位置在"下坡"，说明峰值在左边（mid 自身就可能是峰值），令 hi = mid。

以 [1,2,1,3,5,6,4] 为例：lo=0,hi=6,mid=3，nums[3]=3 < nums[4]=5（上坡），lo=4；mid=5，nums[5]=6 > nums[6]=4（下坡），hi=5；lo==hi=5，返回 5，即峰值 6。

  1. 为什么一定不会漏

整个过程维护"[lo, hi] 内一定存在一个峰值"这条不变量。初始 [0, n-1] 由虚拟边界 -∞ 保证存在峰值；每轮依据斜率把区间缩小到仍含峰值的一半，最终区间收敛到单点，该点即为峰值。因为题目保证相邻元素不等（nums[i] != nums[i+1]），不会出现斜率"持平"的尴尬情况。

Java 实现（二分定向）

class Solution {
    public int findPeakElement(int[] nums) {
        int lo = 0, hi = nums.length - 1;

        // 维护「[lo, hi] 内必存在峰值」
        while (lo < hi) {
            int mid = lo + (hi - lo) / 2;

            if (nums[mid] < nums[mid + 1]) {
                lo = mid + 1;   // 上坡：峰值在右侧
            } else {
                hi = mid;       // 下坡：峰值在左侧（含 mid）
            }
        }
        return lo;              // 收敛到单点即峰值下标
    }
}

Python 实现

class Solution:
    def findPeakElement(self, nums: list[int]) -> int:
        lo, hi = 0, len(nums) - 1
        while lo < hi:
            mid = lo + (hi - lo) // 2
            if nums[mid] < nums[mid + 1]:
                lo = mid + 1    # 上坡，峰值在右侧
            else:
                hi = mid        # 下坡，峰值在左侧（含 mid）
        return lo

复杂度

  • 时间：O(log n)。每轮区间长度减半，最多 log₂n 轮。
  • 空间：O(1)。只用了 lo、hi、mid 三个下标变量。
易错点与扩展（面试高频考点）
  1. mid + 1 越界：循环条件 lo < hi 保证 mid < hi <= n-1，所以 mid + 1 一定合法；若写成 lo <= hi 就可能越界。
  2. 二分靠的是"趋势"而非"有序"：本题数组整体无序，但可以二分，因为它只需要"局部能判断方向"。这是很多人第一次见的反直觉点，务必能讲清楚。
  3. 边界虚拟 -∞ 的作用：它保证数组两端不会"永远向上"，从而峰值必然存在；也解释了为什么单元素数组直接返回 0。
  4. 只返回一个峰值即可：不要误以为要找到最大峰值或所有峰值，任意一个严格大于左右邻居的下标都合法。
  5. 面试追问——带平台的数组：若允许 nums[i] == nums[i+1]（如 1901 题"找出顶峰元素 II"在二维中的推广），需要用 <=/< 的组合并小心处理平台，思想仍是从任意位置沿更陡方向走。
