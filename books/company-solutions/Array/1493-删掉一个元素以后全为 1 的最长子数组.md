# 1493. 删掉一个元素以后全为 1 的最长子数组

| 题目信息 | 内容 |
|---|---|
| 难度 | 中等 |
| 核心模式 | 滑动窗口维护「至多包含一个 0」的最长区间 |
| 时间复杂度 | O(n) |
| 空间复杂度 | O(1) |

## 题目与约束

给你一个二进制数组 `nums`，你需要从中删除一个元素。

请你返回删除操作后，数组中仅包含 1 的 最长非空子数组 的长度。如果不存在这样的 子数组，请返回 0。

 

示例 1：

```
<strong>输入：</strong>nums = [1,1,0,1]
<strong>输出：</strong>3
<strong>解释：</strong>删除下标为 2 的元素后，得到 [1,1,1]，其中包含 3 个值为 1 的元素。
```

示例 2：

```
<strong>输入：</strong>nums = [0,1,1,1,0,1,1,0,1]
<strong>输出：</strong>5
<strong>解释：</strong>删除下标为 4 的元素后，得到 [0,1,1,1,1,1,0,1]，其中仅包含 1 的最长子数组为 [1,1,1,1,1]。
```

示例 3：

```
<strong>输入：</strong>nums = [1,1,1]
<strong>输出：</strong>2
<strong>解释：</strong>你必须删除一个元素。
```

 

提示：

- `1 <= nums.length <= 105`

- `nums[i]` 的值为 0 或 1。

[🔗 前往力扣原题验证 →](https://leetcode.cn/problems/longest-subarray-of-1s-after-deleting-one-element/)

## 核心不变量

> 「允许删除一个元素」等价于「在原数组中找一段最长的、至多含有一个 0 的连续区间」。删掉这个 0（若区间全为 1 则删掉任意一个 1）后，剩下的全是 1，长度为「区间长度 − 1」。

## 完整推导

### 思路推导

1. **把「删除一个元素」翻译成窗口约束**
   删掉一个元素后希望剩下全为 1。反过来看：原数组中一段连续区间，只要它里面「0 的个数 ≤ 1」，就一定能通过删掉那唯一的 0（或全 1 时删任意一个 1）变成全 1。于是问题转为：求最长的、至多含一个 0 的窗口，答案再减 1（因为必须删掉一个元素）。

2. **滑动窗口**
   用 `right` 右扩，把元素纳入窗口并统计其中的 0 的个数 `zeros`。当 `zeros > 1` 时，说明窗口里出现了两个 0，无法只删一个就变全 1，于是让 `left` 右移收缩，直到 `zeros <= 1`。每次收缩后更新窗口最大长度 `maxLen`。

3. **答案 = maxLen − 1**
   窗口内若有 1 个 0，删它即可；若 0 个 0（全 1），题目要求必须删一个元素，删掉一个 1 后长度为 `len−1`。两种情况都统一为 `maxLen − 1`。小例子：`[1,1,0,1]` 的最长合法窗口是整段（含 1 个 0），长度 4，答案 `4−1=3`。全 1 的 `[1,1,1]`，`maxLen=3`，答案 `3−1=2`。

### Java 实现（longestSubarray）

```java
class Solution {
    public int longestSubarray(int[] nums) {
        int left = 0, zeros = 0, maxLen = 0;
        for (int right = 0; right < nums.length; right++) {
            if (nums[right] == 0) zeros++;   // 统计窗口内 0 的个数
            while (zeros > 1) {              // 0 太多，收缩左边界
                if (nums[left] == 0) zeros--;
                left++;
            }
            maxLen = Math.max(maxLen, right - left + 1);
        }
        // 窗口内至多一个 0，删掉它（或全 1 时删一个 1），剩余长度减 1
        return maxLen - 1;
    }
}
```

### 复杂度

- 时间：O(n)。`right`、`left` 各自单向移动，每个元素进出窗口各一次。
- 空间：O(1)。只用到若干计数变量。

### 易错点与扩展（面试高频考点）

1. **别忘了「必须删除一个元素」**：很多人会直接返回窗口长度，但题目要求删掉一个元素，所以返回 `maxLen − 1`。全 1 情况下尤其明显（`[1,1,1]` 答案是 2 而非 3）。
2. **`maxLen - 1` 的边界**：数组非空所以 `maxLen ≥ 1`，结果 ≥ 0；若整段都是 0，`maxLen = 1`，答案 `0`，符合「不存在全 1 子数组返回 0」。
3. **`while` 而非 `if` 收缩**：一次右扩最多新增一个 0，用 `while` 更通用、更安全；写 `if` 在本例刚好够用，但换成「至多 k 个 0」的变体就会出错。
4. **滑动窗口与「删除」的等效关系**：把「删除某元素」转化为「窗口允许一个坏元素」是常见技巧，同样思想用于「替换后最长重复字符」（424）、「最多删 k 个元素」等题。
5. **扩展**：若把题目改成「最多删 k 个元素后全为 1」，只需把 `zeros > 1` 改成 `zeros > k`，答案应取「窗口内 1 的个数最大值」（而非窗口长度 `maxLen`），这一套模板可平滑迁移。

### C++ 实现

```cpp
#include <vector>
#include <algorithm>
using namespace std;

class Solution {
public:
    int longestSubarray(vector<int>& nums) {
        int left = 0, zeros = 0, maxLen = 0;
        for (int right = 0; right < (int)nums.size(); right++) {
            if (nums[right] == 0) zeros++;
            while (zeros > 1) {
                if (nums[left] == 0) zeros--;
                left++;
            }
            maxLen = max(maxLen, right - left + 1);
        }
        return maxLen - 1; // 必须删除一个元素
    }
};
```

### Python 实现

```python
from typing import List

class Solution:
    def longestSubarray(self, nums: List[int]) -> int:
        left = 0
        zeros = 0
        max_len = 0
        for right, x in enumerate(nums):
            if x == 0:
                zeros += 1
            while zeros > 1:
                if nums[left] == 0:
                    zeros -= 1
                left += 1
            max_len = max(max_len, right - left + 1)
        return max_len - 1  # 必须删除一个元素
```
