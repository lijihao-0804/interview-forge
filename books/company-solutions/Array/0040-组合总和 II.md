# 40. 组合总和 II

| 题目信息 | 内容 |
|---|---|
| 难度 | 中等 |
| 核心模式 | 排序 + 回溯 + 同层相邻去重 |
| 时间复杂度 | O(n · 2^n)（最坏搜索空间） |
| 空间复杂度 | O(n)（递归栈与路径，不含结果集） |

## 题目与约束

给定一个候选人编号的集合 `candidates` 和一个目标数 `target`，找出 `candidates` 中所有可以使数字和为 `target` 的组合。

`candidates` 中的每个数字在每个组合中只能使用**一次**。

**注意：** 解集不能包含重复的组合。

**示例 1：**

```
输入: candidates = [10,1,2,7,6,1,5], target = 8,
输出:
[
[1,1,6],
[1,2,5],
[1,7],
[2,6]
]
```

**示例 2：**

```
输入: candidates = [2,5,2,1,2], target = 5,
输出:
[
[1,2,2],
[5]
]
```

**提示：**

- `1 <= candidates.length <= 100`
- `1 <= candidates[i] <= 50`
- `1 <= target <= 30`

## 核心不变量

> 排序后，递归始终只从 `start` 向右选；同一层里若 `candidates[i] == candidates[i-1]` 且 `i > start`，则跳过，保证相同值的组合只被枚举一次。

## 完整推导

### 思路推导

1. **直觉与痛点（和"组合总和 I"差在哪？）**

   本题每个数字**只能用一次**，而且 `candidates` 里有**重复数字**。如果只是"选或不选"地暴力枚举，含重复数字的集合会产生大量重复组合，比如 `[1,1,6]` 可能因为两个 `1` 被反复拼出同一结果。核心难点是：既要正确限制"每个数只用一次"，又要消除结果里的重复组合。

2. **破局思路（先排序，再按"层"去重）**

   先对 `candidates` 升序排序，让相同的数字挨在一起。回溯时维护一个 `start` 指针表示"本层可从哪个下标开始选"，递归到下一层传 `i + 1`——这天然实现了"每个下标只用一次"。真正关键的是**同层去重**：在同一个 `for` 循环（同一层）里，如果当前数字与前一个数字相等，就跳过它。

   以 `[1,1,6], target = 8` 为例：排序后为 `[1,1,2,5,6,7,10]`。第一个 `1` 进入下一层后能搜到 `1+1+6=8`；当回到本层要选第二个 `1` 时，发现它与前一个 `1` 相同，直接跳过——否则会重复得到 `[1,1,6]`。

3. **关键追问（为什么"同层"重复可以跳，而"不同层"重复不能跳？）**

   不同层出现相同数字是合法的，比如 `[1,1,6]` 里的两个 `1` 分别位于第 1、2 层，必须都选。判重条件 `i > start` 正是用来区分：`i == start` 表示本层第一次遇到该值（可以选），`i > start` 表示本层中该值已经作为起点被试过（跳过）。这个 `i > start` 是整道题最容易写错的地方。

4. **剪枝**

   因为已排序，若 `candidates[i] > remain`，则后面的数只会更大，本层及之后都不可能再凑出，直接 `break` 提前结束循环。

### Java 实现（combinationSum2）

```java
import java.util.ArrayList;
import java.util.Arrays;
import java.util.List;

class Solution {
    public List<List<Integer>> combinationSum2(int[] candidates, int target) {
        List<List<Integer>> res = new ArrayList<>();
        Arrays.sort(candidates);                 // 排序：便于剪枝与同层去重
        backtrack(candidates, target, 0, new ArrayList<>(), res);
        return res;
    }

    private void backtrack(int[] candidates, int remain, int start,
                           List<Integer> path, List<List<Integer>> res) {
        if (remain == 0) {                       // 恰好凑出目标，记录一个组合
            res.add(new ArrayList<>(path));
            return;
        }

        for (int i = start; i < candidates.length; i++) {
            // 剪枝：已排序，当前值超过剩余目标，后续只会更大
            if (candidates[i] > remain) break;

            // 同层去重：本层里相同的数字只用第一个作为起点
            if (i > start && candidates[i] == candidates[i - 1]) continue;

            path.add(candidates[i]);
            // 每个数字只能用一次，下一层从 i + 1 开始
            backtrack(candidates, remain - candidates[i], i + 1, path, res);
            path.remove(path.size() - 1);        // 回溯，撤销选择
        }
    }
}
```

### 复杂度

- 时间：最坏 `O(n · 2^n)`。每个元素有"选 / 不选"两种分支，组合总数为 `2^n` 量级，每个组合复制到结果需 `O(n)`；实际因剪枝与去重远小于上界。
- 空间：`O(n)`。递归深度最多 `n`，路径 `path` 长度最多 `n`（不计返回的结果集本身）。

### 易错点与扩展（面试高频考点）

1. **去重条件必须带 `i > start`**：只写 `candidates[i] == candidates[i-1]` 会把合法的"不同层相同值"（如 `[1,1,6]`）也误杀，导致漏解。
2. **必须先排序**：去重依赖"相同数字相邻"，未排序时相邻判重完全失效。
3. **递归传 `i + 1` 而非 `i`**：本题每个数字只能用一次；若传 `i` 就变成了"组合总和 I"（可重复使用）的模型。
4. **与"组合总和 I / III"的关系**：I 是可重复选、无重复元素；III 是限定个数并用 1-9；本题是"不可重复选 + 有重复元素"，三者共用同一套回溯骨架，区别只在"下一层起点"和"去重/个数限制"。
5. **结果去重别用 `Set` 兜底**：把组合塞进 `HashSet` 虽然能去重，但白跑了大量重复分支；应在搜索阶段用同层去重剪掉，才是面试想要的 `O(2^n)` 而不是常数更大且更慢的做法。

## 力扣原题

[40. 组合总和 II](https://leetcode.cn/problems/combination-sum-ii/)

### C++ 实现

```cpp
#include <vector>
#include <algorithm>
using namespace std;

class Solution {
    void backtrack(vector<int>& candidates, int remain, int start,
                   vector<int>& path, vector<vector<int>>& res) {
        if (remain == 0) {
            res.push_back(path);
            return;
        }

        for (int i = start; i < (int)candidates.size(); i++) {
            if (candidates[i] > remain) break;                       // 剪枝
            if (i > start && candidates[i] == candidates[i - 1]) continue; // 同层去重

            path.push_back(candidates[i]);
            backtrack(candidates, remain - candidates[i], i + 1, path, res);
            path.pop_back();                                         // 回溯
        }
    }

public:
    vector<vector<int>> combinationSum2(vector<int>& candidates, int target) {
        sort(candidates.begin(), candidates.end());
        vector<vector<int>> res;
        vector<int> path;
        backtrack(candidates, target, 0, path, res);
        return res;
    }
};
```

### Python 实现

```python
class Solution:
    def combinationSum2(self, candidates: list[int], target: int) -> list[list[int]]:
        candidates.sort()          # 排序后再回溯
        res: list[list[int]] = []
        path: list[int] = []

        def backtrack(start: int, remain: int) -> None:
            if remain == 0:
                res.append(path[:])  # 记录当前组合的副本
                return

            for i in range(start, len(candidates)):
                if candidates[i] > remain:
                    break            # 已排序，后面的更大，剪枝
                if i > start and candidates[i] == candidates[i - 1]:
                    continue         # 同层去重

                path.append(candidates[i])
                backtrack(i + 1, remain - candidates[i])  # 每个数字只用一次
                path.pop()           # 回溯

        backtrack(0, target)
        return res
```
