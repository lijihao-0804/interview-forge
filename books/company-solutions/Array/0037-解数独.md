# 37. 解数独

| 题目信息 | 内容 |
|---|---|
| 难度 | 困难 |
| 核心模式 | 回溯 + 行/列/宫状态数组实现 O(1) 判重 |
| 时间复杂度 | 指数级（最坏 O(9^空格数)，9x9 常量规模下实际极快） |
| 空间复杂度 | O(81) 递归栈与状态表 |

## 题目与约束

编写一个程序，通过填充空格来解决数独问题。

数独的解法需**遵循如下规则**：

- 数字 `1-9` 在每一行只能出现一次。
- 数字 `1-9` 在每一列只能出现一次。
- 数字 `1-9` 在每一个以粗实线分隔的 `3x3` 宫内只能出现一次。

数独部分空格内已填入了数字，空白格用 `'.'` 表示。

**示例 1：**

```
输入：board = [["5","3",".",".","7",".",".",".","."],["6",".",".","1","9","5",".",".","."],[".","9","8",".",".",".",".","6","."],["8",".",".",".","6",".",".",".","3"],["4",".",".","8",".","3",".",".","1"],["7",".",".",".","2",".",".",".","6"],[".","6",".",".",".",".","2","8","."],[".",".",".","4","1","9",".",".","5"],[".",".",".",".","8",".",".","7","9"]]
输出：[["5","3","4","6","7","8","9","1","2"],["6","7","2","1","9","5","3","4","8"],["1","9","8","3","4","2","5","6","7"],["8","5","9","7","6","1","4","2","3"],["4","2","6","8","5","3","7","9","1"],["7","1","3","9","2","4","8","5","6"],["9","6","1","5","3","7","2","8","4"],["2","8","7","4","1","9","6","3","5"],["3","4","5","2","8","6","1","7","9"]]
解释：输入的数独如上图所示，唯一有效的解决方案如下所示。
```

**提示：**

- `board.length == 9`
- `board[i].length == 9`
- `board[i][j]` 是一位数字或者 `'.'`
- 题目数据**保证**输入数独仅有一个解

## 核心不变量

> 回溯过程中，"已填入的数字"与 `rows/cols/boxes` 三张状态表始终一致；每次尝试填入 `d` 前都保证它不违反任一约束，递归失败后必定原样撤销。

## 完整推导

### 思路推导

1. **直觉与痛点（为什么一定要回溯？）**

   数独每一格的选择会相互制约，贪心地"能填就填"很容易走进死胡同。必须"试探—失败—退回来换一个"——这正是回溯（DFS）的模型：沿一条路径不断填，填不下去就退回上一步换下一个候选值。

2. **破局思路（把"能不能填"变成 O(1) 查询）**

   如果每次填数都重新扫一遍行、列、宫，代价很高。做法是先预处理三张 `9 x 9` 布尔表 `rows/cols/boxes`，把盘面已有的数字登记进去。之后判断"在 `(r,c)` 填 `d` 是否合法"只需看这三张表对应位置是否全为 `false`，`O(1)` 完成。

3. **关键追问（递归怎么推进与撤销？）**

   按行优先顺序扫描（`r` 从小到大、`c` 从小到大）：遇到已填格就跳到下一格；遇到空格就枚举 `d = 1..9`，合法则写入盘面并同步三张表，递归下一格；若递归返回失败，则把盘面和三张表**恢复原状**，再试下一个 `d`。当 `r == 9` 说明所有行都填完，返回成功。

4. **正确性来源**

   题目保证解唯一，因此只要找到一条"每步都合法且最终填满"的路径，它必然就是唯一解。回溯按固定顺序穷尽所有合法分支，第一次搜到的完整填充即为答案。

### Java 实现（solveSudoku）

```java
class Solution {
    private final boolean[][] rows = new boolean[9][9];
    private final boolean[][] cols = new boolean[9][9];
    private final boolean[][] boxes = new boolean[9][9];

    public void solveSudoku(char[][] board) {
        // 1. 预处理：把盘面已有数字登记进三张状态表
        for (int i = 0; i < 9; i++) {
            for (int j = 0; j < 9; j++) {
                if (board[i][j] != '.') {
                    int num = board[i][j] - '1';
                    int b = (i / 3) * 3 + j / 3;
                    rows[i][num] = cols[j][num] = boxes[b][num] = true;
                }
            }
        }
        // 2. 从左上角开始回溯
        backtrack(board, 0, 0);
    }

    private boolean backtrack(char[][] board, int r, int c) {
        if (r == 9) return true;                          // 9 行全部填完，成功
        if (c == 9) return backtrack(board, r + 1, 0);    // 本行结束，换下一行
        if (board[r][c] != '.') return backtrack(board, r, c + 1); // 已填，跳过

        int b = (r / 3) * 3 + c / 3;
        for (int d = 0; d < 9; d++) {
            // 冲突则跳过这个候选数字
            if (rows[r][d] || cols[c][d] || boxes[b][d]) continue;

            // 试探：填入并登记
            board[r][c] = (char) ('1' + d);
            rows[r][d] = cols[c][d] = boxes[b][d] = true;

            if (backtrack(board, r, c + 1)) return true;  // 找到解，直接向上返回

            // 回溯：撤销填写与登记
            board[r][c] = '.';
            rows[r][d] = cols[c][d] = boxes[b][d] = false;
        }
        return false;                                     // 所有候选都失败
    }
}
```

### 复杂度

- 时间：最坏为指数级 `O(9^k)`（`k` 为空格的个数），因为每个空格最多尝试 9 个候选值；但棋盘固定为 9x9、且题目保证有解，配合约束剪枝实际运行极快。
- 空间：`O(81)`。递归深度最多等于空格数（≤ 81），外加三张固定大小的 `9 x 9` 状态表。

### 易错点与扩展（面试高频考点）

1. **撤销要彻底**：盘面 `board[r][c] = '.'` 与三张状态表必须一起还原，漏还原任意一处都会让后续分支被错误剪掉。
2. **递归出口别漏**：`r == 9`、`c == 9`、`board[r][c] != '.'` 三种情况要全部处理，否则会越界或死循环。
3. **先判断再写入**：与"有效数独"一样，必须是"检查合法 → 登记 → 递归 → 撤销"，不能先写后判。
4. **优化方向**：可改为"每次选择候选最少的空格"（MRV 启发式）来大幅减少分支；也可用位掩码（一个 `int` 存 9 位）替代布尔表提速。进阶还有舞蹈链（Dancing Links / X 算法）做精确覆盖求解。
5. **注意返回类型**：本题要求**原地修改** `board`，方法返回 `void`，不要试图返回新棋盘。

### C++ 实现

```cpp
#include <vector>
using namespace std;

class Solution {
    bool rows[9][9] = {false};
    bool cols[9][9] = {false};
    bool boxes[9][9] = {false};

    bool backtrack(vector<vector<char>>& board, int r, int c) {
        if (r == 9) return true;                          // 全部填完
        if (c == 9) return backtrack(board, r + 1, 0);    // 换下一行
        if (board[r][c] != '.') return backtrack(board, r, c + 1);

        int b = (r / 3) * 3 + c / 3;
        for (int d = 0; d < 9; d++) {
            if (rows[r][d] || cols[c][d] || boxes[b][d]) continue;

            board[r][c] = char('1' + d);
            rows[r][d] = cols[c][d] = boxes[b][d] = true;

            if (backtrack(board, r, c + 1)) return true;

            board[r][c] = '.';
            rows[r][d] = cols[c][d] = boxes[b][d] = false;
        }
        return false;
    }

public:
    void solveSudoku(vector<vector<char>>& board) {
        for (int i = 0; i < 9; i++) {
            for (int j = 0; j < 9; j++) {
                if (board[i][j] != '.') {
                    int num = board[i][j] - '1';
                    int b = (i / 3) * 3 + j / 3;
                    rows[i][num] = cols[j][num] = boxes[b][num] = true;
                }
            }
        }
        backtrack(board, 0, 0);
    }
};
```

### Python 实现

```python
class Solution:
    def solveSudoku(self, board: list[list[str]]) -> None:
        rows = [[False] * 9 for _ in range(9)]
        cols = [[False] * 9 for _ in range(9)]
        boxes = [[False] * 9 for _ in range(9)]

        for i in range(9):
            for j in range(9):
                if board[i][j] != '.':
                    num = ord(board[i][j]) - ord('1')
                    b = (i // 3) * 3 + j // 3
                    rows[i][num] = cols[j][num] = boxes[b][num] = True

        def backtrack(r: int, c: int) -> bool:
            if r == 9:
                return True
            if c == 9:
                return backtrack(r + 1, 0)
            if board[r][c] != '.':
                return backtrack(r, c + 1)

            b = (r // 3) * 3 + c // 3
            for d in range(9):
                if rows[r][d] or cols[c][d] or boxes[b][d]:
                    continue

                board[r][c] = chr(ord('1') + d)
                rows[r][d] = cols[c][d] = boxes[b][d] = True

                if backtrack(r, c + 1):
                    return True

                board[r][c] = '.'
                rows[r][d] = cols[c][d] = boxes[b][d] = False

            return False

        backtrack(0, 0)
```
