# 848. 字母移位

| 题目信息 | 内容 |
|---|---|
| 难度 | 中等 |
| 核心模式 | 后缀和：每个字符的移位量 = 覆盖它的 shifts 之和 |
| 时间复杂度 | O(n) |
| 空间复杂度 | O(n) |

## 题目与约束

有一个由小写字母组成的字符串 `s`，和一个长度相同的整数数组 `shifts`。

我们将字母表中的下一个字母称为原字母的 **移位** `shift()`（由于字母表是环绕的，`'z'` 将会变成 `'a'`）：

- 例如，`shift('a') = 'b'`，`shift('t') = 'u'`，以及 `shift('z') = 'a'`。

对于每个 `shifts[i] = x`，我们会将 `s` 中的**前 `i + 1` 个字母**移位 `x` 次。

返回将所有这些移位都应用到 `s` 后最终得到的字符串。

**示例 1：**

```
输入：s = "abc", shifts = [3,5,9]
输出："rpl"
解释：
我们以 "abc" 开始。
将 S 中的第 1 个字母移位 3 次后，我们得到 "dbc"。
再将 S 中的前 2 个字母移位 5 次后，我们得到 "igc"。
最后将 S 中的这 3 个字母移位 9 次后，我们得到答案 "rpl"。
```

**示例 2：**

```
输入：s = "aaa", shifts = [1,2,3]
输出："gfd"
```

**提示：**

- `1 <= s.length <= 10^5`
- `s` 由小写英文字母组成
- `shifts.length == s.length`
- `0 <= shifts[i] <= 10^9`

## 核心不变量

> 对于位置 `j` 上的字符，它会被所有满足 `i >= j` 的 `shifts[i]` 覆盖（因为 `shifts[i]` 作用于前 `i+1` 个字母）；所以它最终累计移位量恰为后缀和 `shifts[j] + shifts[j+1] + ... + shifts[n-1]`，对 26 取模即为净位移。

## 完整推导

### 思路推导

1. **别真的去逐次搬字母。** 按题意模拟，每个 `shifts[i]` 要改前 `i+1` 个字母，总操作是 O(n²)，`n=10^5` 必然超时。要先看清“谁被移了多少次”。

2. **算清楚每个位置的累计移位。** `shifts[i]` 只影响下标 `0..i`。反过来说，下标 `j` 会被 `shifts[j], shifts[j+1], ..., shifts[n-1]` 全部影响。于是 `j` 的总移位量就是一段后缀和。从右往左累加即可，一次遍历算完所有位置。

3. **取模压缩到 26。** 字母表是循环的，移位量对 26 取模即可；由于 `shifts[i]` 可到 `10^9`、`n` 可到 `10^5`，后缀和可能到 `10^14`，必须用 64 位整数并在累加时取模，避免溢出。

4. **小例子。** `s = "abc"`，`shifts = [3,5,9]`。后缀和：位置 2 得 9，位置 1 得 9+5=14，位置 0 得 9+5+3=17。对 26 取模：17→17、14→14、9→9。'a' 移 17 位到 'r'，'b' 移 14 位到 'p'，'c' 移 9 位到 'l'，得到 `"rpl"`。

### Java 实现（后缀和）

```java
class Solution {
    public String shiftingLetters(String s, int[] shifts) {
        int n = s.length();
        char[] res = s.toCharArray();
        long suffix = 0; // 当前后缀和（对 26 取模后的小值，防止溢出）

        // 从右往左累加：位置 i 的累计移位量 = shifts[i] + shifts[i+1] + ...
        for (int i = n - 1; i >= 0; i--) {
            suffix = (suffix + shifts[i]) % 26;          // 只用模 26 的位移
            res[i] = (char) ((res[i] - 'a' + suffix) % 26 + 'a');
        }
        return new String(res);
    }
}
```

### 复杂度

- 时间：O(n)。只需从右到左扫描一遍字符串，每个位置做常数次运算。
- 空间：O(n)。把字符串转成 `char[]` 就地修改后构造结果（也可视为 O(1) 额外空间，取决于是否计入结果）。

### 易错点与扩展（面试高频考点）

1. **整数溢出。** `shifts[i]` 最大 `10^9`、长度 `10^5`，直接累加后缀和会超过 `int`。要么用 `long`，要么像本解一样每步 `% 26` 保持很小。
2. **方向别搞反。** 覆盖位置 `j` 的是**后缀**（从 `j` 到末尾），不是前缀；从左往右累加会算错。稳妥做法是从右往左递推。
3. **负数取模不适用于本题。** 因为移位量恒非负，`(x % 26 + 26) % 26` 的额外保护不必要，但写成 `% 26` 后加 `'a'` 前要确保范围在 `0..25`。
4. **扩展：若改成“后缀移位”会怎样？** 如果某题定义为 `shifts[i]` 影响从 `i` 到末尾，则变为前缀和，方向相反。审题时务必看清“前 `i+1` 个”还是“从 `i` 开始”。
5. **原地修改 vs 新数组。** `String` 不可变，必须先转 `char[]` 或 `StringBuilder`，否则无法高效改字符。

### C++ 实现

```cpp
#include <string>
#include <vector>
using namespace std;

class Solution {
public:
    string shiftingLetters(string s, vector<int>& shifts) {
        int n = s.size();
        long long suffix = 0;
        for (int i = n - 1; i >= 0; i--) {
            suffix = (suffix + shifts[i]) % 26;       // 后缀和取模 26
            s[i] = char((s[i] - 'a' + suffix) % 26 + 'a');
        }
        return s;
    }
};
```

### Python 实现

```python
from typing import List

class Solution:
    def shiftingLetters(self, s: str, shifts: List[int]) -> str:
        n = len(s)
        res = list(s)
        suffix = 0
        for i in range(n - 1, -1, -1):
            suffix = (suffix + shifts[i]) % 26  # 后缀和取模 26
            res[i] = chr((ord(res[i]) - ord('a') + suffix) % 26 + ord('a'))
        return ''.join(res)
```
