时间复杂度 O(n + m)
空间复杂度 O(n + m)

题目与约束

给定两个数组 nums1 和 nums2，返回它们的交集。输出结果中的每个元素一定是唯一的。我们可以不考虑输出结果的顺序。

示例 1：

输入：nums1 = [1,2,2,1], nums2 = [2,2]
输出：[2]

示例 2：

输入：nums1 = [4,9,5], nums2 = [9,4,9,8,4]
输出：[9,4]
解释：[4,9] 也是可通过的

提示：

  • 1 <= nums1.length, nums2.length <= 1000
  • 0 <= nums1[i], nums2[i] <= 1000

核心不变量

先把 nums1 去重放入集合 S，再遍历 nums2：凡命中 S 的元素放进结果集合 R，R 天然保证结果唯一。

完整推导

思路推导

  1. 直觉与痛点（暴力两两比较太慢，且要处理重复）

如果对每个 nums2 元素都去 nums1 里线性找一遍，是 O(n·m)。而且题目要求结果唯一——nums1 里的重复元素、nums2 里的重复元素都不能让结果出现重复值。所以关键有两件事：快速判断存在性 + 自动去重。

  1. 集合同时解决两个问题

哈希集合的 contains 是 O(1)，且插入时自动去重。于是：

  • 第一遍把 nums1 全部丢进集合 S（重复自然被合并）；
  • 第二遍遍历 nums2，若 x 在 S 中，就放入结果集合 R（R 再去重一次，避免 nums2 里重复的 x 被加多次）。

  1. 小例子：nums1 = [1,2,2,1] → S = {1,2}；遍历 nums2 = [2,2]，两次都命中，但 R 是集合，最终 R = {2}，输出 [2]。

  2. 输出：把结果集合转成 int[] 即可（顺序无关）。

Java 实现（intersection）

import java.util.HashSet;
import java.util.Set;

class Solution {
    public int[] intersection(int[] nums1, int[] nums2) {
        // 1. 把 nums1 去重放入集合，便于 O(1) 判存在
        Set<Integer> set = new HashSet<>();
        for (int x : nums1) {
            set.add(x);
        }

        // 2. 遍历 nums2，命中即加入结果集合（集合再次自动去重）
        Set<Integer> res = new HashSet<>();
        for (int x : nums2) {
            if (set.contains(x)) {
                res.add(x);
            }
        }

        // 3. 集合转数组输出（顺序无关）
        int[] ans = new int[res.size()];
        int i = 0;
        for (int x : res) {
            ans[i++] = x;
        }
        return ans;
    }
}

复杂度

  • 时间：O(n + m)，构建集合 O(n)，遍历 nums2 均摊 O(1) 判存在，共 O(m)，集合转数组 O(min(n,m))。
  • 空间：O(n + m)，两个哈希集合最坏存放全部去重元素。

易错点与扩展（面试高频考点）

  1. 结果必须去重：这是本题与"两个数组的交集 II"的核心区别；nums2 里的重复命中只能算一次，所以结果容器要用集合而非列表。
  2. 顺序无关：不要纠结输出顺序，若面试要求有序则最后排序即可（O(k log k)）。
  3. 数组转换：Java 不能直接把 HashSet 返回为 int[]，要手动装箱拆箱填充。
  4. 数值范围可利用：0 <= nums[i] <= 1000，也可用 boolean[1001] 做桶标记，省去哈希开销。
  5. 其他解法：排序 + 双指针 O((n+m)log(n+m))、对 nums1 排序后对每个 nums2 元素二分查找 O(m log n)，面试可作对比。

349. 两个数组的交集

C++ 实现

class Solution {
public:
    vector<int> intersection(vector<int>& nums1, vector<int>& nums2) {
        unordered_set<int> s(nums1.begin(), nums1.end()); // nums1 去重
        unordered_set<int> res;                            // 结果去重
        for (int x : nums2) {
            if (s.count(x)) res.insert(x);
        }
        return vector<int>(res.begin(), res.end());
    }
};

Python 实现

class Solution:
    def intersection(self, nums1: list[int], nums2: list[int]) -> list[int]:
        s = set(nums1)      # nums1 去重
        res = set()         # 结果去重
        for x in nums2:
            if x in s:
                res.add(x)
        return list(res)
