题目与约束

给定一个会议时间安排的数组 intervals，其中 intervals[i] = [start_i, end_i] 表示第 i 场会议的开始和结束时间（start_i < end_i）。

请你判断一个人是否能够参加所有会议，即任意两场会议的时间区间都不重叠。

说明： 若一场会议在时刻 t 结束、另一场在时刻 t 开始，则视为不重叠，可以同时参加。

示例 1：

输入：intervals = [[0,30],[5,10],[15,20]]
输出：false
解释：会议 [0,30] 与 [5,10]、[15,20] 时间重叠，无法全部参加。

示例 2：

输入：intervals = [[7,10],[2,4]]
输出：true
解释：两场会议时间不重叠，可以全部参加。

提示：

  • 0 <= intervals.length <= 10^4
  • intervals[i].length == 2
  • 0 <= start_i < end_i <= 10^6

核心不变量

将所有会议按开始时间升序排列后，只要任意相邻两场都不重叠，则全部会议都可以参加。

完整推导

思路推导

  1. 把"任意两两不重叠"化繁为简：直接两两比较是 O(n²)。但若把会议按开始时间排好序，最可能发生冲突的一定是"相邻"两场——因为后一场的开始时间不早于前一场。

  2. 排序 + 线性扫描：按 start 升序排序。从第二场开始，比较它的开始时间 intervals[i][0] 与前一场的结束时间 intervals[i - 1][1]。

  3. 判定条件：一旦 intervals[i][0] < intervals[i - 1][1]（后一场开始早于前一场结束），说明时间重叠，直接返回 false。若扫描结束都没有冲突，返回 true。

以 [[0,30],[5,10],[15,20]] 为例：排序后仍为该顺序；5 < 30 立即判定重叠，返回 false。而 [[7,10],[2,4]] 排序为 [[2,4],[7,10]]，7 >= 4 不冲突，返回 true。

Java 实现（canAttendMeetings）

import java.util.Arrays;

class Solution {
    public boolean canAttendMeetings(int[][] intervals) {
        // 按会议开始时间升序排序
        Arrays.sort(intervals, (a, b) -> Integer.compare(a[0], b[0]));

        for (int i = 1; i < intervals.length; i++) {
            // 当前会议的开始时间早于上一场会议的结束时间 => 时间重叠
            if (intervals[i][0] < intervals[i - 1][1]) {
                return false;
            }
        }
        return true;
    }
}

复杂度

  • 时间：O(n log n)，主要开销在排序；排序后只需一趟 O(n) 扫描。
  • 空间：O(log n)，额外空间来自排序递归栈（不计输入数组本身）。

易错点与扩展（面试高频考点）

  1. 重叠判定用严格小于：intervals[i][0] < intervals[i - 1][1] 才重叠；若写成 <=，会把"上一场结束即下一场开始"这种可参加的情况误判为冲突。
  2. 必须先排序：不排序直接相邻比较会漏掉远距离的重叠区间。
  3. 空数组返回 true：intervals 为空（length == 0）时应返回 true，本题循环天然处理，不会出错。
  4. 只比较相邻即可：排序后若相邻都不重叠，则任意两场都不重叠，无需再两两比较。
  5. 与「253. 会议室 II」的关系：本题只问"能否全部参加"（重叠数是否 > 1）；若要算"最少需要几间会议室"，则需用最小堆/扫描线求最大重叠数。

C++ 实现

#include <algorithm>
#include <vector>
using namespace std;

class Solution {
public:
    bool canAttendMeetings(vector<vector<int>>& intervals) {
        // 按开始时间升序排序
        sort(intervals.begin(), intervals.end(),
             [](const vector<int>& a, const vector<int>& b) { return a[0] < b[0]; });

        for (size_t i = 1; i < intervals.size(); ++i) {
            // 后一场开始早于前一场结束 => 重叠
            if (intervals[i][0] < intervals[i - 1][1]) {
                return false;
            }
        }
        return true;
    }
};

Python 实现

from typing import List


class Solution:
    def canAttendMeetings(self, intervals: List[List[int]]) -> bool:
        # 按开始时间升序排序
        intervals.sort(key=lambda x: x[0])

        for i in range(1, len(intervals)):
            # 当前会议开始时间早于上一场结束时间 => 重叠
            if intervals[i][0] < intervals[i - 1][1]:
                return False
        return True
