# 679. 24 点游戏

| 题目信息 | 内容 |
|---|---|
| 难度 | 困难 |
| 核心模式 | 回溯：每轮任取两数合并成一个结果，递归到只剩一个数 |
| 时间复杂度 | O(1)（卡牌固定为 4 张，枚举规模为常数） |
| 空间复杂度 | O(1)（递归深度不超过 4） |

## 题目与约束

给定一个长度为 4 的整数数组 `cards`。你有 4 张卡片，每张卡片上都包含一个范围在 `[1,9]` 的数字。你应使用运算符 `['+', '-', '*', '/']` 和括号 `'('`、`')'` 将这些卡片上的数字排列成数学表达式，以获得值 24。

你须遵守以下规则：

- 除法运算符 `'/'` 表示实数除法，而不是整数除法。例如，`4 /(1 - 2 / 3) = 4 /(1 / 3) = 12`。
- 每个运算都在两个数字之间。特别是，不能使用 `"-"` 作为一元运算符。例如 `cards = [1,1,1,1]` 时，表达式 `"-1 -1 -1 -1"` 是不允许的。
- 你不能把数字串在一起。例如 `cards = [1,2,1,2]` 时，表达式 `"12 + 12"` 无效。

如果可以得到这样的表达式，其计算结果为 24，则返回 `true`，否则返回 `false`。

**示例 1：**

```
输入: cards = [4, 1, 8, 7]
输出: true
解释: (8-4) * (7-1) = 24
```

**示例 2：**

```
输入: cards = [1, 2, 1, 2]
输出: false
```

**提示：**

- `cards.length == 4`
- `1 <= cards[i] <= 9`

## 核心不变量

> 每一步把“待计算的数字集合”缩小一个：任取两个数用四种运算合并为一个结果，当集合只剩一个数时判断它是否等于 24；由于穷举了所有合并顺序与运算，必然覆盖所有合法表达式。

## 完整推导

### 思路推导

1. **直觉与痛点（括号与运算顺序爆炸）**

   四张牌加三种运算与括号，合法的表达式虽然多，但本质都是“每次把两张牌合成一张牌”。若直接枚举括号组合会非常复杂，难以覆盖全部情况。

2. **破局思路（不断合并两个数）**

   把问题看成“消元”：当前有 `n` 个数字，任选两个数 `a`、`b`，用 `+`、`-`、`*`、`/` 之一合并成新数，数字个数变为 `n-1`，继续递归。当只剩一个数时，检查它是否约等于 24。

   - 选两个数时，因为 `a-b` 与 `b-a` 不同，要用**有序**的 `(i, j)` 枚举，这样加减除的两种方向都能覆盖。
   - `+`、`*` 交换律会带来重复枚举，但规模极小，不影响正确性。

3. **关键追问（为什么这样能覆盖所有表达式？）**

   任何一个由四张牌组成的表达式，其运算树的“最底层”必然是某两个数先运算。递归正是枚举“先合并哪两个数、用哪种运算”，再对剩下的 `n-1` 个数继续，等价于枚举所有运算树的形状与运算选择，因此不会遗漏。

   以 `[4,1,8,7]` 为例，先合并 `(8-4)=4`、`(7-1)=6`，再 `4*6=24`，递归会走到这条路径并返回 `true`。

4. **浮点比较**：除法是实数除法，结果可能是分数（如 `1/3`），必须用 `double` 并以 `1e-6` 的误差判断是否等于 24；分母接近 0 时跳过该除法。

### Java 实现（回溯穷举）

```java
import java.util.ArrayList;
import java.util.List;

class Solution {
    public boolean judgePoint24(int[] cards) {
        List<Double> nums = new ArrayList<>();
        for (int c : cards) {
            nums.add((double) c); // 统一用 double，支持实数除法
        }
        return dfs(nums);
    }

    private boolean dfs(List<Double> nums) {
        int n = nums.size();
        // 只剩一个数：判断是否约等于 24
        if (n == 1) {
            return Math.abs(nums.get(0) - 24.0) < 1e-6;
        }
        // 有序地挑两个不同的数合并
        for (int i = 0; i < n; i++) {
            for (int j = 0; j < n; j++) {
                if (i == j) continue;
                // 收集除 i、j 之外剩下的数字
                List<Double> next = new ArrayList<>();
                for (int k = 0; k < n; k++) {
                    if (k != i && k != j) {
                        next.add(nums.get(k));
                    }
                }
                double a = nums.get(i), b = nums.get(j);
                // 加、减、乘三种运算
                double[] candidates = {a + b, a - b, a * b};
                for (double r : candidates) {
                    next.add(r);
                    if (dfs(next)) return true;
                    next.remove(next.size() - 1); // 回溯
                }
                // 除法：分母不能为 0
                if (Math.abs(b) > 1e-6) {
                    next.add(a / b);
                    if (dfs(next)) return true;
                    next.remove(next.size() - 1);
                }
            }
        }
        return false;
    }
}
```

### 复杂度

- 时间：`O(1)`。卡牌数量固定为 4，递归树规模是常数（每层最多约 `4×3` 种取数 × 4 种运算，总状态数有确定上界），与输入规模无关。
- 空间：`O(1)`。递归深度不超过 4，每层的辅助列表长度为常数。

### 易错点与扩展（面试高频考点）

1. **必须用实数除法**：全程用 `double`，不能用整数除法，否则 `2/3` 会变成 0 导致漏解。
2. **浮点比较用误差**：判断 24 要用 `Math.abs(x - 24) < 1e-6`，直接用 `==` 会因精度误差误判。
3. **分母为 0 要跳过**：`b` 接近 0 时不能做 `a / b`，否则得到 `Infinity`/`NaN`。
4. **有序枚举两个数**：只枚举 `i < j` 会漏掉 `a - b` 与 `b - a`、`a / b` 与 `b / a` 的差异；用有序 `(i, j)` 才能全覆盖。
5. **不允许一元负号与数字拼接**：回溯法只做两数之间的二元运算，天然满足了题目“不能有一元负号、不能拼接数字”的限制，无需额外处理。

## 力扣原题

[679. 24 点游戏](https://leetcode.cn/problems/24-game/)

### C++ 实现

```cpp
#include <vector>
#include <cmath>
using namespace std;

class Solution {
public:
    bool judgePoint24(vector<int>& cards) {
        vector<double> nums(cards.begin(), cards.end());
        return dfs(nums);
    }

private:
    bool dfs(vector<double>& nums) {
        int n = nums.size();
        if (n == 1) {
            return fabs(nums[0] - 24.0) < 1e-6;
        }
        for (int i = 0; i < n; i++) {
            for (int j = 0; j < n; j++) {
                if (i == j) continue;
                vector<double> next;
                for (int k = 0; k < n; k++) {
                    if (k != i && k != j) next.push_back(nums[k]);
                }
                double a = nums[i], b = nums[j];
                double candidates[3] = {a + b, a - b, a * b};
                for (double r : candidates) {
                    next.push_back(r);
                    if (dfs(next)) return true;
                    next.pop_back();
                }
                if (fabs(b) > 1e-6) {
                    next.push_back(a / b);
                    if (dfs(next)) return true;
                    next.pop_back();
                }
            }
        }
        return false;
    }
};
```

### Python 实现

```python
class Solution:
    def judgePoint24(self, cards: list[int]) -> bool:
        def dfs(nums: list[float]) -> bool:
            n = len(nums)
            if n == 1:
                return abs(nums[0] - 24.0) < 1e-6
            for i in range(n):
                for j in range(n):
                    if i == j:
                        continue
                    rest = [nums[k] for k in range(n) if k != i and k != j]
                    a, b = nums[i], nums[j]
                    for r in (a + b, a - b, a * b):
                        if dfs(rest + [r]):
                            return True
                    if abs(b) > 1e-6:
                        if dfs(rest + [a / b]):
                            return True
            return False

        return dfs([float(x) for x in cards])
```
