题目信息 内容
难度 中等
核心模式 排序 + 双指针 + 2 的幂计数
时间复杂度 O(n log n)
空间复杂度 O(n)

题目与约束

给你一个整数数组 nums 和一个整数 target 。

请你统计并返回 nums 中能满足其最小元素与最大元素的 和 小于或等于 target 的 非空 子序列的数目。

由于答案可能很大，请将结果对 109 + 7 取余后返回。

示例 1：

<strong>输入：</strong>nums = [3,5,6,7], target = 9
<strong>输出：</strong>4
<strong>解释：</strong>有 4 个子序列满足该条件。
[3] -> 最小元素 + 最大元素 <= target (3 + 3 <= 9)
[3,5] -> (3 + 5 <= 9)
[3,5,6] -> (3 + 6 <= 9)
[3,6] -> (3 + 6 <= 9)

示例 2：

<strong>输入：</strong>nums = [3,3,6,8], target = 10
<strong>输出：</strong>6
<strong>解释：</strong>有 6 个子序列满足该条件。（nums 中可以有重复数字）
[3] , [3] , [3,3], [3,6] , [3,6] , [3,3,6]

示例 3：

<strong>输入：</strong>nums = [2,3,3,4,6,7], target = 12
<strong>输出：</strong>61
<strong>解释：</strong>共有 63 个非空子序列，其中 2 个不满足条件（[6,7], [7]）
有效序列总数为（63 - 2 = 61）

提示：

  • 1 <= nums.length <= 105

  • 1 <= nums[i] <= 106

  • 1 <= target <= 106

核心不变量

排序后，若 nums[l] + nums[r] <= target，则以 nums[l] 为最小值、任意选取区间 (l, r] 内的元素构成的所有 2^(r-l) 个子序列全部合法；否则 nums[l] 无法与任何右端配对，收缩右指针。

完整推导

思路推导

  1. 直觉（子序列只看最大最小）：一个子序列是否合法，只由它的最小元素与最大元素之和决定，中间元素随便取。于是把数组排序后，「最小值」固定在某个位置 l，「最大值」固定在位置 r，中间 (l, r] 的元素可以有可无。

  2. 固定左端，数右端：排序后对每个左端 l，用一个指针 r 指向「仍满足 nums[l] + nums[r] <= target 的最右位置」。此时区间 (l, r] 有 r - l 个元素，它们每个都可以选择「取或不取」，再加上必须包含 nums[l]，共贡献 2^(r-l) 个合法子序列。

  3. 双指针单调性：随着 l 增大，nums[l] 变大，可容纳的最大 r 只会左移不会右移。因此 r 从右端出发单调递减，整体 O(n) 完成统计。当 nums[l] + nums[r] > target 时，说明 nums[r] 太大，r--；否则累加 2^(r-l) 后 l++。

  4. 小例子：nums=[3,5,6,7], target=9。l=0,r=3：3+7=10>9 → r=2；3+6=9≤9 → 贡献 2^(2-0)=4，l=1。此时 l=1,r=2：5+6=11>9 → r=1；仍 l=r=1，再判 5+5=10>9 → r=0，此时 l>r 才结束。答案 4，与示例一致。

Java 实现（numSubseq）

import java.util.Arrays;

class Solution {
    public int numSubseq(int[] nums, int target) {
        final int MOD = 1_000_000_007;
        int n = nums.length;
        Arrays.sort(nums);

        // 预处理 2 的幂，pow2[i] = 2^i % MOD
        int[] pow2 = new int[n];
        pow2[0] = 1;
        for (int i = 1; i < n; i++) {
            pow2[i] = (int) (pow2[i - 1] * 2L % MOD);
        }

        long ans = 0;
        int l = 0, r = n - 1;
        while (l <= r) {
            if (nums[l] + nums[r] <= target) {
                // 固定 nums[l] 为最小值，中间 (l, r] 的元素任选
                ans = (ans + pow2[r - l]) % MOD;
                l++;
            } else {
                r--;
            }
        }
        return (int) ans;
    }
}

复杂度

  • 时间：O(n log n)，排序主导；双指针统计为 O(n)。
  • 空间：O(n)，预处理 2 的幂数组（排序的递归栈可忽略）。

易错点与扩展（面试高频考点）

  1. 必须排序：不排序就无法用双指针判断「最大最小」，且子序列本身与顺序无关，排序不改变答案。
  2. 2^(r-l) 的含义：区间 (l, r] 共 r-l 个元素，每个元素独立取舍，所以是 2^(r-l)；不要误写成 2^(r-l+1)。
  3. 溢出处：pow2[i-1] * 2 用 long 计算后再取模，Java 的 int * 2 可能溢出。
  4. 重复元素：示例 2 说明相同数值视为不同元素，本题按位置计数，排序后双指针自然正确处理。
  5. 单元素子序列：l == r 时贡献 2^0 = 1，对应 [nums[l]]，只要 2*nums[l] <= target 即合法。

C++ 实现

class Solution {
public:
    int numSubseq(vector<int>& nums, int target) {
        const int MOD = 1'000'000'007;
        int n = nums.size();
        sort(nums.begin(), nums.end());

        vector<long long> pow2(n);
        pow2[0] = 1;
        for (int i = 1; i < n; ++i) {
            pow2[i] = pow2[i - 1] * 2 % MOD;
        }

        long long ans = 0;
        int l = 0, r = n - 1;
        while (l <= r) {
            if (nums[l] + nums[r] <= target) {
                ans = (ans + pow2[r - l]) % MOD;
                ++l;
            } else {
                --r;
            }
        }
        return (int) ans;
    }
};

class Solution:

        nums.sort()
