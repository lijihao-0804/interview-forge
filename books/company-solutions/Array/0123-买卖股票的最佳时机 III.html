题目与约束

给定一个数组，它的第 i 个元素是一支给定的股票在第 i 天的价格。

设计一个算法来计算你所能获取的最大利润。你最多可以完成两笔交易。

注意： 你不能同时参与多笔交易（你必须在再次购买前出售掉之前的股票）。

示例 1：

输入：prices = [3,3,5,0,0,3,1,4]
输出：6
解释：在第 4 天（股票价格 = 0）的时候买入，在第 6 天（股票价格 = 3）的时候卖出，这笔交易所能获得利润 = 3-0 = 3 。
     随后，在第 7 天（股票价格 = 1）的时候买入，在第 8 天 （股票价格 = 4）的时候卖出，这笔交易所能获得利润 = 4-1 = 3 。

示例 2：

输入：prices = [1,2,3,4,5]
输出：4
解释：在第 1 天（股票价格 = 1）的时候买入，在第 5 天 （股票价格 = 5）的时候卖出, 这笔交易所能获得利润 = 5-1 = 4 。
     注意你不能在第 1 天和第 2 天接连购买股票，之后再将它们卖出。
     因为这样属于同时参与了多笔交易，你必须在再次购买前出售掉之前的股票。

示例 3：

输入：prices = [7,6,4,3,1]
输出：0
解释：在这个情况下, 没有交易完成, 所以最大利润为 0。

示例 4：

输入：prices = [1]
输出：0

提示：

  • 1 <= prices.length <= 10^5
  • 0 <= prices[i] <= 10^5

核心不变量

只在"第一次买入、第一次卖出、第二次买入、第二次卖出"四个状态上各维护一个最大收益；因为这些状态按时间先后构成合法的交易顺序，任意转移都对应一个可行的交易方案，所以 sell2 就是答案。

完整推导

思路推导

  1. 暴力枚举的痛点：最直接的做法是枚举"第一笔买入/卖出点 + 第二笔买入/卖出点"，或枚举一个分割日分别求左侧一笔、右侧一笔的最优，复杂度 O(n²)，对 n = 10^5 无法通过。

  2. 用状态机描述一天结束时的处境：任何时刻，你只能处于以下几种状态之一——还没买过、第一次持有、第一次已卖出、第二次持有、第二次已卖出。为每种状态记下"能达到的最大收益"： - buy1：第一次买入后（持股中）的最大收益，因买入要花钱，通常为负； - sell1：第一次卖出后的最大收益； - buy2：第二次买入后的最大收益； - sell2：第二次卖出后的最大收益。

  3. 一天的四种转移（p 为当天价格）： - buy1 = max(buy1, -p)：今天第一次买入，或维持之前状态； - sell1 = max(sell1, buy1 + p)：今天第一次卖出，或维持； - buy2 = max(buy2, sell1 - p)：今天第二次买入，或维持； - sell2 = max(sell2, buy2 + p)：今天第二次卖出，或维持。

这串更新按顺序进行，天然保证了"先卖后买"的先后约束。

  1. 小例子：prices = [3,3,5,0,0,3,1,4]，初始 buy1 = buy2 = -3，sell1 = sell2 = 0。滚动到最后得到 sell2 = 6，即两笔各赚 3 ✓。

Java 实现（状态机 DP）

class Solution {
    public int maxProfit(int[] prices) {
        // buy=持股状态的最大收益（负数表支出），sell=空仓卖出状态的最大收益
        // 用第一天的价格初始化，避免 MIN_VALUE 参与加法时溢出
        int buy1 = -prices[0], sell1 = 0;
        int buy2 = -prices[0], sell2 = 0;

        for (int i = 1; i < prices.length; i++) {
            int p = prices[i];
            // 依次更新四个状态：先买后卖、先一后二，顺序保证交易合法
            buy1  = Math.max(buy1,  -p);         // 第一次买入
            sell1 = Math.max(sell1, buy1 + p);   // 第一次卖出
            buy2  = Math.max(buy2,  sell1 - p);  // 第二次买入（用第一次的收益买）
            sell2 = Math.max(sell2, buy2 + p);   // 第二次卖出
        }
        // 允许只做一笔或不做，sell2 自然覆盖这些情况（其值不会小于 0）
        return sell2;
    }
}

复杂度

  • 时间：O(n)。一次遍历，每天只做 4 次常数级的状态转移。
  • 空间：O(1)。仅用 buy1 / sell1 / buy2 / sell2 四个变量。

易错点与扩展（面试高频考点）

  1. 初始化别用 Integer.MIN_VALUE：buy1 + p 会下溢成错误值。用 -prices[0] 初始化 buy1 / buy2，sell1 / sell2 初始化为 0 最稳妥。
  2. 更新顺序不能乱：必须按 buy1 → sell1 → buy2 → sell2 的顺序原地更新，才能保证第二次买入用的是"已经卖出过第一笔"的收益，交易先后关系才成立。
  3. "最多两笔"含 0 笔和 1 笔：sell 状态始终可取 0 与历史最大值，因此只做一笔或完全不做都会被自动覆盖，无需单独处理。
  4. 推广到 k 笔的通用模板：把 buy / sell 换成数组 buy[k+1] / sell[k+1]，外层遍历天数、内层遍历交易次数，即为"最多完成 k 笔交易"的通用 O(nk) 解法；本题 k=2 直接展开成四个变量。
  5. 同日多次买卖：buy1 + p 在同一天买卖相当于利润 0，不会让答案变差，因此原地更新顺序即使"当天买当天卖"也是安全的。

C++ 实现

#include <vector>
#include <algorithm>
using namespace std;

class Solution {
public:
    int maxProfit(vector<int>& prices) {
        int buy1 = -prices[0], sell1 = 0;
        int buy2 = -prices[0], sell2 = 0;
        for (int i = 1; i < (int)prices.size(); ++i) {
            int p = prices[i];
            buy1  = max(buy1,  -p);
            sell1 = max(sell1, buy1 + p);
            buy2  = max(buy2,  sell1 - p);
            sell2 = max(sell2, buy2 + p);
        }
        return sell2;
    }
};

Python 实现

class Solution:
    def maxProfit(self, prices: list[int]) -> int:
        buy1, sell1 = -prices[0], 0
        buy2, sell2 = -prices[0], 0
        for p in prices[1:]:
            buy1 = max(buy1, -p)
            sell1 = max(sell1, buy1 + p)
            buy2 = max(buy2, sell1 - p)
            sell2 = max(sell2, buy2 + p)
        return sell2
