题目与约束

给定一个由 4 位数字组成的数组，返回可以设置的符合 24 小时制的最大时间。

24 小时格式为 "HH:MM"，其中 HH 在 00 到 23 之间，MM 在 00 到 59 之间。最小的 24 小时制时间是 00:00，而最大的是 23:59。从 00:00（午夜）开始算起，过得越久，时间越大。

以长度为 5 的字符串，按 "HH:MM" 格式返回答案。如果不能确定有效时间，则返回空字符串。

示例 1：

输入：arr = [1,2,3,4]
输出："23:41"
解释：有效的 24 小时制时间是 "12:34"，"12:43"，"13:24"，"13:42"，"14:23"，"14:32"，"21:34"，"21:43"，"23:14" 和 "23:41" 。这些时间中，"23:41" 是最大时间。

示例 2：

输入：arr = [5,5,5,5]
输出：""
解释：不存在有效的 24 小时制时间，因为 "55:55" 无效。

示例 3：

输入：arr = [0,0,0,0]
输出："00:00"

示例 4：

输入：arr = [0,0,1,0]
输出："10:00"

提示：

  • arr.length == 4
  • 0 <= arr[i] <= 9

核心不变量

所有可能的时刻都在 4 个数字的全排列里；合法且换算成分钟数最大的那个排列即为答案。

完整推导

思路推导

  1. 规模极小，直接枚举：只有 4 个数字，全排列共 4! = 24 种。把每种排列拆成「前两位做小时、后两位做分钟」，逐一判定合法性即可，完全没有性能顾虑。

  2. 合法性判定：小时 = 10*a + b 必须 < 24，分钟 = 10*c + d 必须 < 60。两个条件同时满足才是有效时间。

  3. 用「分钟总数」比较大小：把时刻换算成 hh*60 + mm，这个整数越大时间越晚。枚举过程中维护一个 best 最大值，最后再格式化回 "HH:MM"，避免手写字符串比较。

  4. 小例子：arr = [1,2,3,4]。排列出 2,3,4,1 时 hh=23, mm=41，换算 23*60+41=1421 为最大，输出 "23:41"。arr=[5,5,5,5] 时所有排列都因 hh=55 >= 24 非法，best 保持 -1，返回 ""。

Java 实现（四层枚举全排列）

class Solution {
    public String largestTimeFromDigits(int[] arr) {
        int best = -1; // 记录最大时刻（换算成分钟），-1 表示尚无合法解
        for (int i = 0; i < 4; i++) {
            for (int j = 0; j < 4; j++) {
                if (j == i) continue;
                for (int k = 0; k < 4; k++) {
                    if (k == i || k == j) continue;
                    int l = 6 - i - j - k; // 剩下那个下标记为 l（0+1+2+3=6）
                    int hh = arr[i] * 10 + arr[j];
                    int mm = arr[k] * 10 + arr[l];
                    if (hh < 24 && mm < 60) {
                        int t = hh * 60 + mm;
                        if (t > best) best = t;
                    }
                }
            }
        }
        if (best < 0) return "";
        return String.format("%02d:%02d", best / 60, best % 60);
    }
}

复杂度

  • 时间：O(1)，最多枚举 24 种排列，每种常数次运算。
  • 空间：O(1)，只用若干整型变量。

易错点与扩展（面试高频考点）

  1. 小时/分钟边界写错：小时上限是 < 24（不能 <= 24），分钟上限是 < 60。例如 24:00、23:60 都非法。

  2. 重复数字要正确去重：用「下标全排列 + 跳过已用下标」天然处理了重复值，无需额外去重；若用 next_permutation 之类则要先排序并小心重复。

  3. 格式化补零：00:00、10:00 这类必须补足两位，用 String.format("%02d:%02d", ...) 或 C++ 的 snprintf，别直接拼数字。

  4. 无解返回空串：best 初值设为 -1，最后判断 < 0 返回 ""；不要返回 "00:00" 以外的东西混淆「无解」与「零点」。

  5. 扩展：也可用贪心（先挑最大的合法十位小时、再挑最大个位小时……），但分支多易错；在 4 位数字这种固定小规模下，枚举更稳、更有说服力。

C++ 实现

class Solution {
public:
    string largestTimeFromDigits(vector<int>& arr) {
        int best = -1;
        for (int i = 0; i < 4; i++) {
            for (int j = 0; j < 4; j++) {
                if (j == i) continue;
                for (int k = 0; k < 4; k++) {
                    if (k == i || k == j) continue;
                    int l = 6 - i - j - k;
                    int hh = arr[i] * 10 + arr[j];
                    int mm = arr[k] * 10 + arr[l];
                    if (hh < 24 && mm < 60) {
                        int t = hh * 60 + mm;
                        if (t > best) best = t;
                    }
                }
            }
        }
        if (best < 0) return "";
        char buf[6];
        snprintf(buf, sizeof(buf), "%02d:%02d", best / 60, best % 60);
        return string(buf);
    }
};

Python 实现

from typing import List
from itertools import permutations

class Solution:
    def largestTimeFromDigits(self, arr: List[int]) -> str:
        best = -1
        for a, b, c, d in permutations(arr):
            hh = a * 10 + b
            mm = c * 10 + d
            if hh < 24 and mm < 60:
                t = hh * 60 + mm
                if t > best:
                    best = t
        if best < 0:
            return ""
        return "%02d:%02d" % (best // 60, best % 60)
