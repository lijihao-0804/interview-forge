# 528. 按权重随机选择

| 题目信息 | 内容 |
|---|---|
| 难度 | 中等 |
| 核心模式 | 前缀和 + 二分查找（按区间映射随机数） |
| 时间复杂度 | 构造 O(n)，pickIndex O(log n) |
| 空间复杂度 | O(n) |

## 题目与约束

给你一个 下标从 0 开始 的正整数数组 `w` ，其中 `w[i]` 代表第 `i` 个下标的权重。

请你实现一个函数 `pickIndex` ，它可以 随机地 从范围 `[0, w.length - 1]` 内（含 `0` 和 `w.length - 1`）选出并返回一个下标。选取下标 `i` 的 概率 为 `w[i] / sum(w)` 。

- 例如，对于 `w = [1, 3]`，挑选下标 `0` 的概率为 `1 / (1 + 3) = 0.25` （即，25%），而选取下标 `1` 的概率为 `3 / (1 + 3) = 0.75`（即，`75%`）。

 

示例 1：

输入：  
["Solution","pickIndex"]  
[[[1]],[]]  
输出：  
[null,0]  
解释：  
Solution solution = new Solution([1]);  
solution.pickIndex(); // 返回 0，因为数组中只有一个元素，所以唯一的选择是返回下标 0。

示例 2：

输入：  
["Solution","pickIndex","pickIndex","pickIndex","pickIndex","pickIndex"]  
[[[1,3]],[],[],[],[],[]]  
输出：  
[null,1,1,1,1,0]  
解释：  
Solution solution = new Solution([1, 3]);  
solution.pickIndex(); // 返回 1，返回下标 1，返回该下标概率为 3/4 。  
solution.pickIndex(); // 返回 1  
solution.pickIndex(); // 返回 1  
solution.pickIndex(); // 返回 1  
solution.pickIndex(); // 返回 0，返回下标 0，返回该下标概率为 1/4 。  
由于这是一个随机问题，允许多个答案，因此下列输出都可以被认为是正确的:  
[null,1,1,1,1,0]  
[null,1,1,1,1,1]  
[null,1,1,1,0,0]  
[null,1,1,1,0,1]  
[null,1,0,1,0,0]  
......  
诸若此类。

 

提示：

- `1 <= w.length <= 104`

- `1 <= w[i] <= 105`

- `pickIndex` 将被调用不超过 `104` 次

[🔗 前往力扣原题验证 →](https://leetcode.cn/problems/random-pick-with-weight/)

## 核心不变量

> 把总权重划分成若干首尾相接的区间，第 `i` 个区间长度为 `w[i]`；在 `[1, sum(w)]` 上均匀取一个整数，落在第 `i` 段内的概率恰为 `w[i] / sum(w)`，而前缀和单调递增保证二分能唯一定位这段区间。

## 完整推导

### 思路推导

1. **直觉与痛点（怎么让概率正比于权重？）**

   不能直接对下标随机取（那会等概率）。但可以把每个下标"放大"成一段长度为 `w[i]` 的小区间，铺满一条数轴；在数轴上等概率取一个点，落在哪个区间就返回哪个下标。点落在长区间（权重大）里的概率自然更大。

2. **破局思路（前缀和 + 二分）**

   构造前缀和 `prefix[i] = w[0] + ... + w[i]`，它把数轴切成了 `n` 段：
   - 下标 `0` 占据 `[1, w[0]]`；
   - 下标 `i` 占据 `(prefix[i-1], prefix[i]]`。

   每次 `pickIndex`：在 `[1, total]` 里等概率取整数 `target`，再二分查找第一个满足 `prefix[i] >= target` 的下标 `i`，即为答案。

   以 `w = [1, 3]` 为例：`prefix = [1, 4]`，`total = 4`。
   - `target = 1` → 命中下标 `0`（区间 `[1,1]`），概率 `1/4`；
   - `target ∈ {2,3,4}` → 命中下标 `1`（区间 `[2,4]`），概率 `3/4`。

3. **关键追问（为什么二分的下界是 `>= target` 而不是 `> target`？）**

   因为随机数取的是闭区间 `[1, total]` 内的整数，且每段是"左开右闭"。第一个 `prefix[i] >= target` 的下标，正好是 `target` 落入的段。若改成取 `[0, total-1]` 并找第一个 `prefix[i] > target`，也可以，但两种口径不能混用，否则边界会偏一位。

### Java 实现（前缀和 + 二分）

```java
import java.util.Random;

class Solution {
    private final int[] prefix;   // prefix[i] = w[0..i] 的累计权重
    private final int total;      // 总权重
    private final Random random = new Random();

    public Solution(int[] w) {
        int n = w.length;
        prefix = new int[n];
        int sum = 0;
        for (int i = 0; i < n; i++) {
            sum += w[i];
            prefix[i] = sum;
        }
        total = sum;
    }

    public int pickIndex() {
        // 在 [0, total) 内均匀取整数，等价于在 [1, total] 上取
        int target = random.nextInt(total) + 1;
        // 二分查找第一个 prefix[i] >= target 的下标
        int lo = 0, hi = prefix.length - 1;
        while (lo < hi) {
            int mid = lo + (hi - lo) / 2;
            if (prefix[mid] >= target) {
                hi = mid;
            } else {
                lo = mid + 1;
            }
        }
        return lo;
    }
}
```

### 复杂度

- 时间：构造 `O(n)`（一次遍历求前缀和）；`pickIndex` 为 `O(log n)`（一次二分）。
- 空间：`O(n)`，保存前缀和数组。

### 易错点与扩展（面试高频考点）

1. **随机区间口径要统一**：用 `nextInt(total)`（取值 `[0, total-1]`）就配 `prefix > target`；用 `nextInt(total) + 1`（取值 `[1, total]`）就配 `prefix >= target`。混用会错一位，导致某个下标多/少算概率。
2. **前缀和区间不能有缝/重叠**：第 `i` 段必须恰好长 `w[i]`，"左开右闭"是保证无重叠的关键。
3. **总权重溢出**：`w.length ≤ 10^4`、`w[i] ≤ 10^5`，总和最大约 `10^9`，在 `int` 范围内；若权重更大需用 `long`。
4. **多次调用的性能**：`pickIndex` 会被调用上万次，必须用 `O(log n)` 二分，不能每次线性扫描前缀和（会退化成 `O(n)`）。
5. **扩展——权重可动态变化**：若边查边改权重，可用线段树/树状数组维护前缀和并支持"按累计和二分"，把更新与查询都做到 `O(log n)`。

### C++ 实现

```cpp
#include <vector>
#include <cstdlib>
using namespace std;

class Solution {
private:
    vector<int> prefix; // prefix[i] = w[0..i] 的累计权重
    int total;          // 总权重
public:
    Solution(vector<int>& w) {
        prefix.resize(w.size());
        int sum = 0;
        for (int i = 0; i < (int)w.size(); i++) {
            sum += w[i];
            prefix[i] = sum;
        }
        total = sum;
    }

    int pickIndex() {
        // rand() % total 得到 [0, total-1]，等价于 [1, total]
        int target = rand() % total + 1;
        // 找到第一个 prefix[i] >= target 的下标
        int lo = 0, hi = (int)prefix.size() - 1;
        while (lo < hi) {
            int mid = lo + (hi - lo) / 2;
            if (prefix[mid] >= target) {
                hi = mid;
            } else {
                lo = mid + 1;
            }
        }
        return lo;
    }
};
```

### Python 实现

```python
import random
import bisect

class Solution:
    def __init__(self, w: list[int]):
        self.prefix = []
        self.total = 0
        for x in w:
            self.total += x
            self.prefix.append(self.total)

    def pickIndex(self) -> int:
        # 在 [1, total] 上均匀取整数
        target = random.randint(1, self.total)
        # 第一个 prefix[i] >= target 的下标即为答案
        return bisect.bisect_left(self.prefix, target)
```
