# 16. 最接近的三数之和

| 题目信息 | 内容 |
|---|---|
| 难度 | 中等 |
| 核心模式 | 排序 + 双指针逼近 |
| 时间复杂度 | O(n²) |
| 空间复杂度 | O(log n)（排序的栈开销，可视为 O(1)） |

## 题目与约束

给定一个长度为 `n` 的整数数组 `nums` 和 一个整数 `target`。

请你从 `nums` 中选出三个在 不同下标位置 的整数，使它们的和与 `target` 最接近。

返回这三个数的和。

假定每组输入只存在 恰好 一个解。

 

示例 1：

输入：nums = [-1,2,1,-4], target = 1  
输出：2  
解释：与 target 最接近的和是 2 (-1 + 2 + 1 = 2)。

示例 2：

输入：nums = [0,0,0], target = 1  
输出：0  
解释：与 target 最接近的和是 0（0 + 0 + 0 = 0）。

 

提示：

- `3 <= nums.length <= 1000`

- `-1000 <= nums[i] <= 1000`

- `-104 <= target <= 104`

[🔗 前往力扣原题验证 →](https://leetcode.cn/problems/3sum-closest/)

## 核心不变量

> 数组排序后，固定第一个数 `nums[i]`，用左右双指针 `l < r` 包围剩余区间：当前和小于 `target` 时右移 `l` 只能让和变大，大于 `target` 时左移 `r` 只能让和变小。

## 完整推导

### 思路推导

1. **直觉与痛点（三重循环太慢）**

   三个数各枚举一遍是 `O(n³)`，`n` 最大 1000 时约 `10⁹` 次运算，必然超时。问题在于：我们并不需要"找到某个精确组合"，而是要**让和尽量接近 `target`**，这天然适合用"排序后有序地逼近"来做。

2. **破局思路（排序 + 固定一个 + 双指针）**

   先把数组排序。枚举第一个数 `nums[i]`，问题就退化成"在 `i` 之后的区间里选两个数，让二元和尽量接近 `target - nums[i]`"。对有序区间，用左右指针 `l = i+1`、`r = n-1` 从两端向中间逼近：

   - 计算 `sum = nums[i] + nums[l] + nums[r]`，用它更新当前最优 `best`；
   - 若 `sum < target`，说明和偏小，只有右移 `l`（换成更大的数）才可能更接近，`l++`；
   - 若 `sum > target`，说明和偏大，只有左移 `r`（换成更小的数）才可能更接近，`r--`；
   - 若恰好 `sum == target`，距离为 0，已是最优，直接返回。

   以 `nums = [-1,2,1,-4], target = 1` 为例：排序得 `[-4,-1,1,2]`。固定 `-4`，`l=-1, r=2` 得 `-3`；偏小右移，`l=1` 得 `-1`；偏小右移，`l=r` 结束。固定 `-1`，`l=1, r=2` 得 `2`，恰为答案。

3. **关键追问（为什么双指针不会漏解？）**

   因为数组有序。当 `sum < target` 时，固定 `r` 而把 `l` 往左任何位置都只会更小、更差，所以 `l` 当前位置的所有组合里 `nums[r]` 已经是能给出的最大值，可以安全地 `l++` 淘汰。`sum > target` 时同理。这样每步都排除一整行/一整列，双指针合计只扫描一遍区间，配合外层 `i` 就是 `O(n²)`。

4. **易错点提示**

   - 初始 `best` 不要设成 `Integer.MAX_VALUE`，最好用前三个数的和，避免后续比较时整数溢出。
   - 距离比较要用绝对值 `Math.abs(sum - target) < Math.abs(best - target)`。
   - 想去重可加 `if (i > 0 && nums[i] == nums[i-1]) continue;`，但本题不要求去重，加不加都不影响正确性。

### Java 实现（排序 + 双指针）

```java
import java.util.Arrays;

class Solution {
    public int threeSumClosest(int[] nums, int target) {
        Arrays.sort(nums);
        int n = nums.length;

        // 用前三个数之和初始化最优解，避免使用 MAX_VALUE 导致相减溢出
        int best = nums[0] + nums[1] + nums[2];

        // 固定第一个数 nums[i]，在右侧用双指针找最接近的二元和
        for (int i = 0; i < n - 2; i++) {
            int l = i + 1;
            int r = n - 1;

            while (l < r) {
                int sum = nums[i] + nums[l] + nums[r];

                // 用当前和更新最优解
                if (Math.abs(sum - target) < Math.abs(best - target)) {
                    best = sum;
                }

                if (sum < target) {
                    l++;          // 和偏小，右移左指针让和变大
                } else if (sum > target) {
                    r--;          // 和偏大，左移右指针让和变小
                } else {
                    return target; // 恰好命中，距离为 0，最优
                }
            }
        }

        return best;
    }
}
```

### 复杂度

- 时间：`O(n²)`。排序 `O(n log n)`；外层枚举 `i` 共 `n` 次，内层双指针每个 `i` 只走一遍区间 `O(n)`，合计 `O(n²)`。
- 空间：`O(log n)`。主要来自排序的递归栈（快排/归并实现相关），不计排序则为 `O(1)` 的常数变量。

### 易错点与扩展（面试高频考点）

1. **`best` 初始化导致溢出**：若初始化为 `Integer.MAX_VALUE`，`best - target` 可能溢出成负数，比较失效。用前三数之和初始化最安全。
2. **忘记取绝对值**：`sum - target` 可能为负，"更小"不等于"更接近"，必须比较 `|sum - target|`。
3. **和恰好相等要尽早返回**：`sum == target` 时距离为 0，不可能更优，提前 `return` 可剪枝。
4. **面试追问——和三数之和（LeetCode 15）的区别**：15 题要求"和为 0 且去重、返回所有组合"，本题只要求"最接近的一个和"，因此不必收集结果、不必去重，只需维护 `best`，两者框架完全相同。
5. **剪枝优化**：在有序数组中，若 `nums[i] + nums[i+1] + nums[i+2] > target` 可提前结束外层循环，若 `nums[i] + nums[n-1] + nums[n-2] < target` 可跳过当前 `i`，实际运行更快（不影响 `O(n²)` 上界）。

### C++ 实现

```cpp
#include <vector>
#include <algorithm>
#include <cstdlib>
using namespace std;

class Solution {
public:
    int threeSumClosest(vector<int>& nums, int target) {
        sort(nums.begin(), nums.end());
        int n = nums.size();
        int best = nums[0] + nums[1] + nums[2];  // 用前三数初始化

        for (int i = 0; i < n - 2; i++) {
            int l = i + 1, r = n - 1;
            while (l < r) {
                int sum = nums[i] + nums[l] + nums[r];
                if (abs(sum - target) < abs(best - target)) {
                    best = sum;
                }
                if (sum < target) {
                    l++;         // 和偏小，右移左指针
                } else if (sum > target) {
                    r--;         // 和偏大，左移右指针
                } else {
                    return target; // 命中，距离为 0
                }
            }
        }
        return best;
    }
};
```
