题目与约束

给你一个有序数组 nums，请你原地删除重复出现的元素，使得出现次数超过两次的元素只出现两次，返回删除后数组的新长度。

不要使用额外的数组空间，你必须在原地修改输入数组并在使用 O(1) 额外空间的条件下完成。

说明：

为什么返回数值是整数，但输出的答案是数组呢？

请注意，输入数组是以「引用」方式传递的，这意味着在函数里修改输入数组对于调用者是可见的。

你可以想象内部操作如下：

// nums 是以“引用”方式传递的。也就是说，不对实参做任何拷贝
int len = removeDuplicates(nums);

// 在函数里修改输入数组对于调用者是可见的。
// 根据你的函数返回的长度, 它会打印出数组中 该长度范围内 的所有元素。
for (int i = 0; i < len; i++) {
    print(nums[i]);
}

示例 1：

输入：nums = [1,1,1,2,2,3]
输出：5, nums = [1,1,2,2,3]
解释：函数应返回新长度 length = 5, 并且原数组的前五个元素被修改为 1, 1, 2, 2, 3。不需要考虑数组中超出新长度后面的元素。

示例 2：

输入：nums = [0,0,1,1,1,1,2,3,3]
输出：7, nums = [0,0,1,1,2,3,3]
解释：函数应返回新长度 length = 7, 并且原数组的前七个元素被修改为 0, 0, 1, 1, 2, 3, 3。不需要考虑数组中超出新长度后面的元素。

提示：

  • 1 <= nums.length <= 3 * 10^4
  • -10^4 <= nums[i] <= 10^4
  • nums 已按升序排列

核心不变量

用慢指针 slow 标记"已保留区间的下一个写入位置"；只要 nums[fast] 与已保留区间倒数第二个元素 nums[slow-2] 不同，就说明写入它不会造成第三次重复，可以安全写入。

完整推导

思路推导

  1. 直觉与痛点（为什么不能只和"上一个保留值"比）

第一版（LeetCode 26）允许每个数出现一次，只需比较 nums[fast] != nums[slow-1]。但本题允许出现两次，所以要放开一格：只有当写入后会变成第三次重复时才跳过。

  1. 破局思路（快慢指针，回看两位）

设 slow 为已保留部分的下一个写入位置，fast 扫描原数组。对每个 nums[fast]：

  • 若 slow < 2（保留不足两个），直接写入 nums[slow++] = nums[fast]；
  • 否则看 nums[slow-2]：若 nums[fast] != nums[slow-2]，说明写入后该值最多出现两次，安全写入；若相等，说明已经是第三次及以上，跳过。

以 [1,1,1,2,2,3] 为例：保留 1,1（slow=2）；第三个 1 与 nums[0]=1 相等 → 跳过；2 与 nums[0]=1 不等 → 写入；第二个 2 与 nums[1]=1 不等 → 写入；3 与 nums[2]=2 不等 → 写入。结果 [1,1,2,2,3]，长度 5。

  1. 关键追问（为什么比较 slow-2 就够？）

因为数组有序，相同的值一定连续。slow-2 指向已保留区间中倒数第二个元素：只要当前值等于它，说明该值在保留区间里已经出现了至少两次，再写就是第三次。有序性保证了这个判断既必要又充分。

  1. 易错点提示
  • 是 nums[slow-2] 不是 nums[slow-1]，两者对应"最多两次"与"最多一次"。
  • slow < 2 的短路保护不能少，否则 slow-2 下标越界。
  • 返回 slow（新长度），不用管数组尾部残留。

Java 实现（快慢双指针）

class Solution {
    public int removeDuplicates(int[] nums) {
        int slow = 0; // 已保留区间的下一个写入位置
        for (int fast = 0; fast < nums.length; fast++) {
            // 保留不足两个，或当前值与已保留倒数第二个不同 -> 可写入
            if (slow < 2 || nums[fast] != nums[slow - 2]) {
                nums[slow] = nums[fast];
                slow++;
            }
        }
        return slow;
    }
}

复杂度

  • 时间：O(n)，fast 只遍历数组一遍。
  • 空间：O(1)，只用两个指针，原地修改。

易错点与扩展（面试高频考点）

  1. 下标写错：应与 nums[slow-2] 比较；写成 slow-1 就退化成"每个数只留一次"。
  2. 越界：slow < 2 时不能访问 slow-2，必须短路。
  3. 数组有序是前提：若数组无序，相同元素不连续，此方法失效。
  4. 面试追问——推广到"最多出现 k 次"：把条件改成 slow < k || nums[fast] != nums[slow-k] 即可，代码几乎不变。
  5. 面试追问——与 LeetCode 26 的关系：26 题是本题 k=1 的特例（比较 nums[slow-1]），掌握本题即掌握整类"有序数组原地去重"模板。

C++ 实现

#include <vector>
using namespace std;

class Solution {
public:
    int removeDuplicates(vector<int>& nums) {
        int slow = 0; // 已保留区间的下一个写入位置
        for (int fast = 0; fast < (int)nums.size(); fast++) {
            // 保留不足两个，或当前值不等于已保留倒数第二个 -> 可写入
            if (slow < 2 || nums[fast] != nums[slow - 2]) {
                nums[slow] = nums[fast];
                slow++;
            }
        }
        return slow;
    }
};

Python 实现

class Solution:
    def removeDuplicates(self, nums: list[int]) -> int:
        slow = 0  # 已保留区间的下一个写入位置
        for fast in range(len(nums)):
            # 保留不足两个，或当前值不等于已保留倒数第二个 -> 可写入
            if slow < 2 or nums[fast] != nums[slow - 2]:
                nums[slow] = nums[fast]
                slow += 1
        return slow
