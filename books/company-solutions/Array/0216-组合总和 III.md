# 216. 组合总和 III

| 题目信息 | 内容 |
|---|---|
| 难度 | 中等 |
| 核心模式 | 回溯（组合型）：在 1~9 中按递增顺序选 k 个不重复的数，维护剩余和 |
| 时间复杂度 | O(C(9,k) * k) |
| 空间复杂度 | O(k) |

## 题目与约束

找出所有相加之和为 `n` 的 `k` 个数的组合，且满足下列条件：

- 只使用数字1到9

- 每个数字 最多使用一次 

返回 所有可能的有效组合的列表 。该列表不能包含相同的组合两次，组合可以以任何顺序返回。

 

示例 1:

```
<strong>输入:</strong> <em><strong>k</strong></em> = 3, <em><strong>n</strong></em> = 7
<strong>输出:</strong> [[1,2,4]]
<strong>解释:</strong>
1 + 2 + 4 = 7
没有其他符合的组合了。
```

示例 2:

```
<strong>输入:</strong> <em><strong>k</strong></em> = 3, <em><strong>n</strong></em> = 9
<strong>输出:</strong> [[1,2,6], [1,3,5], [2,3,4]]
<strong>解释:
</strong>1 + 2 + 6 = 9
1 + 3 + 5 = 9
2 + 3 + 4 = 9
没有其他符合的组合了。
```

示例 3:

```
<strong>输入:</strong> k = 4, n = 1
<strong>输出:</strong> []
<strong>解释:</strong> 不存在有效的组合。
在[1,9]范围内使用4个不同的数字，我们可以得到的最小和是1+2+3+4 = 10，因为10 > 1，没有有效的组合。
```

 

提示:

- `2 <= k <= 9`

- `1 <= n <= 60`

[🔗 前往力扣原题验证 →](https://leetcode.cn/problems/combination-sum-iii/)

## 核心不变量

> 回溯过程中始终「按递增顺序选数 + 记录剩余和 `remain`」：`path` 里已选 `path.size()` 个数、还剩 `remain` 要凑；当恰好选满 `k` 个且 `remain == 0` 时，`path` 就是一个合法组合。

## 完整推导

### 思路推导

1. **把问题看成一次「选数」的搜索**

   候选集合是 `1..9`，每个数最多用一次，要选恰好 `k` 个、和为 `n`。这是典型的组合型回溯：按顺序决定「第 pos 个位置放哪个数」。

2. **关键：用递增的 `start` 避免重复组合**

   如果每次都从 1 开始选，`[1,2,4]` 与 `[4,2,1]` 会被重复枚举。规定下一层只能从「比已选数更大」的位置开始（传 `start = i + 1`），就能保证每种组合只按升序出现一次。示例 2 中 `[1,2,6]`、`[1,3,5]`、`[2,3,4]` 正是这样不重不漏地产生。

3. **两个终止条件**

   - 选满 `k` 个数：若此时 `remain == 0`，记录答案；否则直接返回。
   - 选到某个数时 `remain < i`：由于后面的数只会更大，和必然超标，可以立即 `break` 剪枝。

4. **小例子**

   `k = 3, n = 9`：先选 1（remain 8），再选 2（remain 6），再选 6 得 `[1,2,6]`；回溯后选 3、再选 5 得 `[1,3,5]`；不选 1 时从 2 起，选 2、3、4 得 `[2,3,4]`；再往后无法凑出，搜索结束。

### Java 实现（combinationSum3）

```java
import java.util.ArrayList;
import java.util.List;

class Solution {
    public List<List<Integer>> combinationSum3(int k, int n) {
        List<List<Integer>> res = new ArrayList<>();
        backtrack(res, new ArrayList<>(), 1, k, n);
        return res;
    }

    /**
     * @param start  下一层可选的最小数字，保证组合递增、不重复
     * @param k      还需要凑够的数字个数
     * @param remain 还需要凑出的剩余和
     */
    private void backtrack(List<List<Integer>> res, List<Integer> path, int start, int k, int remain) {
        // 选满 k 个数：恰好凑成 n 才记录
        if (path.size() == k) {
            if (remain == 0) {
                res.add(new ArrayList<>(path));
            }
            return;
        }
        // 从 start 到 9 依次尝试
        for (int i = start; i <= 9; i++) {
            // 剪枝：当前数已超过剩余和，后面更大，直接结束
            if (remain < i) {
                break;
            }
            path.add(i);
            backtrack(res, path, i + 1, k, remain - i); // 每个数只能用一次，下一层从 i+1 开始
            path.remove(path.size() - 1);               // 回溯，撤销选择
        }
    }
}
```

### 复杂度

- 时间：O(C(9,k) * k)。组合总数最多为 `C(9,k)`，每个合法组合复制 `path` 需要 O(k)；加上剪枝后实际远小于此上界。
- 空间：O(k)。递归深度最多 `k`，`path` 最多 `k` 个元素，不计答案本身。

### 易错点与扩展（面试高频考点）

1. **必须传 `i + 1` 而不是 `i`**：本题每个数只能用一次，若写成 `i` 会变成「可重复使用」，得到错误结果（那是组合总和 39 题的模型）。
2. **先判 `path.size() == k` 再判和**：选满 k 个数后即应停止向下搜索，否则会选出超过 k 个数。
3. **剪枝 `remain < i` 用 `break` 而非 `continue`**：因为 i 递增，一旦剩余和不够当前数，后面的数只会更大，必然都不行。
4. **结果需深拷贝 `new ArrayList<>(path)`**：直接 `res.add(path)` 会因后续回溯修改 `path` 而导致所有答案被清空。
5. **扩展**：可提前用「能选的最大 `k` 个数之和 < remain 就剪枝」进一步优化；若去掉「只用 1~9」的限制，就是一般的组合总和回溯。

## 力扣原题

[216. 组合总和 III](https://leetcode.cn/problems/combination-sum-iii/)

### C++ 实现

```cpp
class Solution {
public:
    vector<vector<int>> combinationSum3(int k, int n) {
        vector<vector<int>> res;
        vector<int> path;
        backtrack(res, path, 1, k, n);
        return res;
    }

private:
    void backtrack(vector<vector<int>>& res, vector<int>& path, int start, int k, int remain) {
        if ((int)path.size() == k) {
            if (remain == 0) res.push_back(path);
            return;
        }
        for (int i = start; i <= 9; i++) {
            if (remain < i) break;          // 剪枝：后面更大
            path.push_back(i);
            backtrack(res, path, i + 1, k, remain - i); // 每个数用一次
            path.pop_back();                // 回溯
        }
    }
};
```

### Python 实现

```python
class Solution:
    def combinationSum3(self, k: int, n: int) -> list[list[int]]:
        res = []
        path = []

        def backtrack(start: int, remain: int) -> None:
            if len(path) == k:
                if remain == 0:
                    res.append(path.copy())   # 深拷贝当前组合
                return
            for i in range(start, 10):
                if remain < i:                # 剪枝：后面数字更大
                    break
                path.append(i)
                backtrack(i + 1, remain - i)  # 每个数只能用一次
                path.pop()                    # 回溯

        backtrack(1, n)
        return res
```
