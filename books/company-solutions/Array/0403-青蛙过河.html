403. 青蛙过河

本题学习状态正在读取学习记录…下次复习：—

难度困难核心模式动态规划：map<石子坐标, 可达步长集合>时间复杂度O(n^2)空间复杂度O(n^2)

题目与约束

一只青蛙想要过河。 假定河流被等分为若干个单元格，并且在每一个单元格内都有可能放有一块石子（也有可能没有）。 青蛙可以跳上石子，但是不可以跳入水中。

给你石子的位置列表 stones（用单元格序号 升序 表示）， 请判定青蛙能否成功过河（即能否在最后一步跳至最后一块石子上）。开始时， 青蛙默认已站在第一块石子上，并可以假定它第一步只能跳跃 1 个单位（即只能从单元格 1 跳至单元格 2 ）。

如果青蛙上一步跳跃了 k 个单位，那么它接下来的跳跃距离只能选择为 k - 1、k 或 k + 1 个单位。 另请注意，青蛙只能向前方（终点的方向）跳跃。

示例 1：

输入：stones = [0,1,3,5,6,8,12,17]
输出：true
解释：青蛙可以成功过河，按照如下方案跳跃：跳 1 个单位到第 2 块石子, 然后跳 2 个单位到第 3 块石子, 接着 跳 2 个单位到第 4 块石子, 然后跳 3 个单位到第 6 块石子, 跳 4 个单位到第 7 块石子, 最后，跳 5 个单位到第 8 个石子（即最后一块石子）。

示例 2：

输入：stones = [0,1,2,3,4,8,9,11]
输出：false
解释：这是因为第 5 和第 6 个石子之间的间距太大，没有可选的方案供青蛙跳跃过去。

提示：

  • 2 <= stones.length <= 2000

  • 0 <= stones[i] <= 231 - 1

  • stones[0] == 0

  • stones 按严格升序排列

核心不变量

状态是"站在某块石子上时，所有跳到这里用过的步长 k 的集合"；由状态 (pos, k) 出发，下一步只能跳到 pos + (k-1)、pos + k、pos + (k+1)，且落点必须是石子。只要最后一块石子的可达步长集合非空，就能过河。

完整推导

思路推导

  1. 直觉与痛点（同一块石子，来的方式不同，未来也不同）

判断"能不能到终点"不能只看位置，因为到达某块石子时的步长决定了它之后还能怎么跳。同样是站在坐标 5，若是 +2 跳来的，下一步只能跳 1/2/3；若是 +3 跳来的，下一步只能跳 2/3/4。所以状态必须带上步长。

  1. 破局思路（用集合记录"到达方式"）

定义 dp[pos] = 站在坐标 pos 时，所有可能用过的跳跃步长组成的集合。转移时，对 dp[pos] 里每个 k，尝试 next ∈ {k-1, k, k+1}：

  • 必须 next > 0（只能前进，且距离为正）；
  • 若 pos + next 是一块石子，就把 next 加入 dp[pos + next]。

起点 dp[0] = {0}。因为 k = 0 时只有 next = 1 > 0 合法，这天然满足了"第一步只能跳 1"的约束——若存在 1 号石子，就会把 1 放进 dp[1]。

  1. 小例子（示例 1）

stones = [0,1,3,5,6,8,12,17]：dp[0]={0} → 只能跳到 1（存在），dp[1]={1} → 从 1 出发可选 0/1/2，只有 2 落点 3 存在，dp[3]={2} → 从 3 出发 1/2/3，2 落点 5 存在，dp[5]={2} …… 一路可到达 17，返回 true。示例 2 中坐标 4 之后下一个石子是 8，间距 4，而从 4 出发最大只能跳 3（由之前步长推不出 4），于是断掉，返回 false。

Java 实现（哈希表 DP）

import java.util.HashMap;
import java.util.HashSet;
import java.util.Map;
import java.util.Set;

class Solution {
    public boolean canCross(int[] stones) {
        int n = stones.length;
        // dp[pos] = 跳到该石子上时所有用过的步长集合
        Map<Integer, Set<Integer>> dp = new HashMap<>();
        for (int s : stones) {
            dp.put(s, new HashSet<>());
        }
        dp.get(0).add(0);            // 起点，虚拟步长 0

        for (int i = 0; i < n; i++) {
            int pos = stones[i];
            for (int k : dp.get(pos)) {
                for (int next = k - 1; next <= k + 1; next++) {
                    if (next <= 0) continue;              // 只能向前跳
                    int target = pos + next;
                    if (dp.containsKey(target)) {         // 落点必须是石子
                        dp.get(target).add(next);
                    }
                }
            }
        }
        return !dp.get(stones[n - 1]).isEmpty();
    }
}

C++ 实现

#include <vector>
#include <unordered_map>
#include <unordered_set>
using namespace std;

class Solution {
public:
    bool canCross(vector<int>& stones) {
        int n = stones.size();
        unordered_map<int, unordered_set<int>> dp;
        for (int s : stones) dp[s] = {};
        dp[0].insert(0);               // 起点，虚拟步长 0

        for (int i = 0; i < n; i++) {
            int pos = stones[i];
            unordered_set<int> cur = dp[pos];   // 拷贝，避免边遍历边修改
            for (int k : cur) {
                for (int next = k - 1; next <= k + 1; next++) {
                    if (next <= 0) continue;    // 只能向前跳
                    if (dp.count(pos + next)) { // 落点必须是石子
                        dp[pos + next].insert(next);
                    }
                }
            }
        }
        return !dp[stones[n - 1]].empty();
    }
};

Python 实现

class Solution:
    def canCross(self, stones: list[int]) -> bool:
        dp = {s: set() for s in stones}   # dp[坐标] = 到达时的步长集合
        dp[0].add(0)                      # 起点，虚拟步长 0

        for pos in stones:
            for k in list(dp[pos]):       # list 拷贝，避免遍历时修改
                for nxt in (k - 1, k, k + 1):
                    if nxt <= 0:          # 只能向前跳
                        continue
                    if pos + nxt in dp:   # 落点必须是石子
                        dp[pos + nxt].add(nxt)

        return bool(dp[stones[-1]])

复杂度

  • 时间：O(n^2)。每块石子上的步长集合最多 O(n) 种，枚举三档后继是常数，总计约 O(n^2)。
  • 空间：O(n^2)。n 块石子，每块最多记录 O(n) 个不同步长。
易错点与扩展（面试高频考点）
  1. 首跳限制别漏：起点设 dp[0] = {0}，靠 next > 0 过滤，只有 1 能落下，天然保证第一步跳 1；若直接给 {1} 反而多了一种非法的"0 步"来源。
  2. next 必须严格大于 0：跳 0 无意义、跳负数是后退，都要排除。
  3. 用坐标而非下标做 key：落点是"坐标 pos + next 是否有石子"，必须用数值坐标查表，用数组下标会错。
  4. 落点判断 O(1)：把 stones 放进 HashMap/HashSet，否则每次线性查找退化到 O(n^3)。
  5. 记忆化 DFS 是等价写法：dfs(位置, 步长) 加 memo，思路一致；n ≤ 2000，O(n^2) 两种实现都能过。还可加剪枝：从 i 能到的最远受此前最大步长限制，间距过大直接返回 false。
