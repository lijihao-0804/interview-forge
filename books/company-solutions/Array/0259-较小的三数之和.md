# 259. 较小的三数之和

## 题目与约束



[🔗 前往力扣原题验证 →](https://leetcode.cn/problems/3sum-smaller/)

## 核心不变量

> 排序后固定 `i` 与左指针 `l`，若 `nums[i] + nums[l] + nums[r] < target`，那么 `r` 取 `l+1` 到当前位置 `r` 的所有值都能与 `(i, l)` 凑成合法三元组，可一次性累加 `r - l` 个。

## 完整推导

### 思路推导

1. **暴力太慢**

   三重循环枚举 `i < j < k` 是 O(n³)，`n = 3500` 时约 `4×10¹⁰` 次运算，必然超时。难点在于要"数个数"，而不是找某个精确组合。

2. **排序 + 固定一个 + 双指针**

   先对数组排序。枚举第一个下标 `i`，令 `l = i + 1`、`r = n - 1`，用双指针在右侧区间收缩。

3. **为什么能一次累加一段**

   当 `nums[i] + nums[l] + nums[r] < target` 时，由于数组有序，固定 `i`、`l`，把 `r` 从当前位置继续往左取（即 `l+1 .. r` 中任意值），和只会更小，一定仍满足条件。于是这些 `r - l` 个位置一次全部算作合法，然后 `l++` 继续。

   反之若和 `>= target`，只有让和变小才可能满足，于是 `r--`。

4. **小例子**

   `nums = [-2,0,1,3], target = 2`：排序后仍为 `[-2,0,1,3]`。`i=0` 取 `-2`，`l=1(0), r=3(3)`，和 `=1 < 2`，累加 `3-1=2`（对应 `[-2,0,1]`、`[-2,0,3]`），`l=2`；再算 `-2+1+3=2` 不满足，`r--` 后结束。总数为 2 ✓。

### Java 实现（排序 + 双指针计数）

```java
import java.util.Arrays;

class Solution {
    public int threeSumSmaller(int[] nums, int target) {
        Arrays.sort(nums);
        int n = nums.length;
        long count = 0;  // 合法三元组最多约 71 亿，int 会溢出

        // 固定第一个下标 i，在右侧用双指针统计合法的 (j, k)
        for (int i = 0; i < n - 2; i++) {
            int l = i + 1, r = n - 1;
            while (l < r) {
                int sum = nums[i] + nums[l] + nums[r];
                if (sum < target) {
                    // 固定 i、l 后，r 取 l+1..当前 r 全部合法
                    count += r - l;
                    l++;
                } else {
                    r--; // 和太大，缩小右指针
                }
            }
        }
        return (int) count;
    }
}
```

### 复杂度

- 时间：O(n²)。排序 O(n log n)；外层枚举 `i` 共 O(n)，内层双指针每个 `i` 只扫一遍区间 O(n)，合计 O(n²)。
- 空间：O(1)。除排序递归栈外只用了常数个变量；若计入排序则为 O(log n)。

### 易错点与扩展（面试高频考点）

1. **累加的是 `r - l` 而不是 1**：固定 `i`、`l` 后，`r` 可以取 `l+1 .. r` 共 `r - l` 个位置，全部满足条件，必须整段累加。
2. **循环上界写错**：外层是 `i < n - 2`（保证右侧至少还能放两个数），内层是 `l < r`。
3. **长度不足 3**：空数组或 `n < 3` 时循环自然不进入，返回 0，无需额外特判。
4. **重复值不必去重**：本题统计的是下标三元组个数，重复值也要分别计数，不要照搬 15 题的去重逻辑。
5. **与 3Sum(15)、3Sum Closest(16) 的关系**：三者都是"排序 + 固定一个 + 双指针"，区别在于 15 要找所有和为 0 的组合并去重、16 要找最接近 `target` 的一个和、本题只需统计"小于 `target`"的个数。

### C++ 实现

```cpp
#include <vector>
#include <algorithm>
using namespace std;

class Solution {
public:
    int threeSumSmaller(vector<int>& nums, int target) {
        sort(nums.begin(), nums.end());
        int n = nums.size();
        long long count = 0;  // 合法三元组最多约 71 亿，int 会溢出
        for (int i = 0; i < n - 2; ++i) {
            int l = i + 1, r = n - 1;
            while (l < r) {
                if (nums[i] + nums[l] + nums[r] < target) {
                    count += r - l; // r 取 l+1..当前 r 全部合法
                    ++l;
                } else {
                    --r;
                }
            }
        }
        return (int)count;
    }
};
```

from typing import List

class Solution:
    def threeSumSmaller(self, nums: List[int], target: int) -> int:
        nums.sort()
        n = len(nums)
        count = 0
        for i in range(n - 2):
            l, r = i + 1, n - 1
            while l < r:
                if nums[i] + nums[l] + nums[r] < target:
                    count += r - l  # r 取 l+1..当前 r 全部合法
                    l += 1
                else:
                    r -= 1
        return count
