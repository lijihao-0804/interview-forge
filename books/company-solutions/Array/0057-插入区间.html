57. 插入区间

本题学习状态正在读取学习记录…下次复习：—
本次复习：
按 M 快速切换薄弱标记
遮住推导与代码，先自己想，再逐段揭示
难度中等核心模式一次线性扫描：左段直入 + 中段合并 + 右段直入时间复杂度O(n)空间复杂度O(n)（结果数组，额外空间 O(1)）

题目与约束

给你一个 无重叠的 ，按照区间起始端点排序的区间列表 intervals，其中 intervals[i] = [starti, endi] 表示第 i 个区间的开始和结束，并且 intervals 按照 starti 升序排列。同样给定一个区间 newInterval = [start, end] 表示另一个区间的开始和结束。

如果两个区间 至少 共享一个点，则认为它们是重叠的。

在 intervals 中插入区间 newInterval，使得 intervals 依然按照 starti 升序排列，且区间之间不重叠（如果有必要的话，可以合并区间）。

返回插入之后的 intervals。

注意 你不需要原地修改 intervals。你可以创建一个新数组然后返回它。

示例 1：

输入：intervals = [[1,3],[6,9]], newInterval = [2,5]
输出：[[1,5],[6,9]]

示例 2：

输入：intervals = [[1,2],[3,5],[6,7],[8,10],[12,16]], newInterval = [4,8]
输出：[[1,2],[3,10],[12,16]]
解释：这是因为新的区间 [4,8] 与 [3,5],[6,7],[8,10] 重叠。

提示：

  • 0 <= intervals.length <= 104

  • intervals[i].length == 2

  • 0 <= starti <= endi <= 105

  • intervals 根据 starti 按 升序 排列

  • newInterval.length == 2

  • 0 <= start <= end <= 105

核心不变量

因为 intervals 已按起点有序且互不重叠，所有与 newInterval 重叠的区间必定是一段连续的子数组；扫描完这段连续区间后，newInterval 已吸收全部重叠区间，可直接放入结果。

完整推导

思路推导

  1. 直觉与痛点（不要真的"插进去再排序合并"）

最暴力的做法是把 newInterval 塞进列表、重新排序、再整体合并，既慢又容易写错。实际上原列表已经有序且无重叠，这层"现成结构"应该被直接利用。

  1. 破局思路（把整个列表切成三段）

从头扫描，列表天然被分成三块：

  • 左段：结束点 < start，完全在新区间左边，和它不重叠 → 原样放进结果；
  • 中段：起点 <= end，与新区间有交集（含端点相切）→ 不断用它们的左右端扩张 [start, end]，把中段全部"吃掉"；
  • 右段：剩下的区间都在新区间右边，不重叠 → 原样放进结果。

小例子：intervals = [[1,2],[3,5],[6,7],[8,10],[12,16]]，newInterval = [4,8]。 [1,2] 的右端 2 < 4，属左段直接放入；接着 [3,5] 起点 3 <= 8，合并成 [3,8]；[6,7]、[8,10] 起点都 <= 8，继续合并成 [3,10]；[12,16] 起点 12 > 10，属右段原样放入。结果 [[1,2],[3,10],[12,16]]。

  1. 关键追问（端点相切算不算重叠？）

题目说"至少共享一个点即重叠"，所以 [1,2] 与 [2,5] 需要合并。代码里左段条件是 end < start（严格小于），中段条件是 startᵢ <= end（小于等于），正好把"相切"划进合并范围，不会漏掉。

  1. 收尾：中段合并完成后，无条件把最终的 [start, end] 放入结果，再补上右段即可。

Java 实现（insert）

import java.util.ArrayList;
import java.util.List;

class Solution {
    public int[][] insert(int[][] intervals, int[] newInterval) {
        List<int[]> res = new ArrayList<>();
        int n = intervals.length;
        int i = 0;
        int start = newInterval[0];
        int end = newInterval[1];

        // 1. 左段：结束点严格小于新区间起点，完全在左侧，直接放入
        while (i < n && intervals[i][1] < start) {
            res.add(intervals[i]);
            i++;
        }

        // 2. 中段：与新区间有交集（含端点相切），不断扩张 [start, end]
        while (i < n && intervals[i][0] <= end) {
            start = Math.min(start, intervals[i][0]);
            end = Math.max(end, intervals[i][1]);
            i++;
        }
        // 合并后的新区间放入结果
        res.add(new int[]{start, end});

        // 3. 右段：剩余区间都在右侧，原样放入
        while (i < n) {
            res.add(intervals[i]);
            i++;
        }

        return res.toArray(new int[res.size()][]);
    }
}

C++ 实现

#include <vector>
#include <algorithm>
using namespace std;

class Solution {
public:
    vector<vector<int>> insert(vector<vector<int>>& intervals, vector<int>& newInterval) {
        vector<vector<int>> res;
        int n = intervals.size();
        int i = 0;
        int start = newInterval[0], end = newInterval[1];

        // 左段：结束点 < 新区间起点
        while (i < n && intervals[i][1] < start) {
            res.push_back(intervals[i]);
            i++;
        }
        // 中段：与新区间重叠，扩张边界
        while (i < n && intervals[i][0] <= end) {
            start = min(start, intervals[i][0]);
            end = max(end, intervals[i][1]);
            i++;
        }
        res.push_back({start, end});
        // 右段：原样放入
        while (i < n) {
            res.push_back(intervals[i]);
            i++;
        }
        return res;
    }
};

Python 实现

class Solution:
    def insert(self, intervals: list[list[int]], newInterval: list[int]) -> list[list[int]]:
        res = []
        n = len(intervals)
        i = 0
        start, end = newInterval

        # 左段：结束点严格小于新区间起点
        while i < n and intervals[i][1] < start:
            res.append(intervals[i])
            i += 1

        # 中段：与新区间重叠（含端点相切），扩张边界
        while i < n and intervals[i][0] <= end:
            start = min(start, intervals[i][0])
            end = max(end, intervals[i][1])
            i += 1
        res.append([start, end])

        # 右段：原样放入
        while i < n:
            res.append(intervals[i])
            i += 1

        return res

复杂度

  • 时间：O(n)。每个区间最多被访问一次，左段、中段、右段合计线性扫描一遍。
  • 空间：O(n)。需要一个新的结果数组保存答案（题目也允许新建数组）；除结果外只用了常数个变量。
易错点与扩展（面试高频考点）
  1. 边界写成 < 还是 <=：左段必须用 intervals[i][1] < start（严格），否则会把"相切"的区间错误地当成不重叠；中段用 intervals[i][0] <= end（含等号），否则会漏合并相切区间。
  2. 忘记无条件放入合并区间：即使中段一个都没合并，也要把 [start, end] 放进结果，否则新区间会丢失。
  3. toArray 用法：res.toArray(new int[res.size()][]) 才能得到正确的二维数组，写成 new int[][] 会抛异常。
  4. 不要原地排序再合并：那会把 O(n) 变成 O(n log n)，且需要额外判重，得不偿失。
  5. 扩展——合并区间（LeetCode 56）：若输入未排序，则先按起点排序，再用同一套"逐个合并"的线性扫描；本题相当于"已排序版本 + 插入一个区间"的特例。
