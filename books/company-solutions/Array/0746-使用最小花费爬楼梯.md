# 746. 使用最小花费爬楼梯

| 题目信息 | 内容 |
|---|---|
| 难度 | 简单 |
| 核心模式 | 线性 DP：从下往上递推最短花费，滚动变量压缩空间 |
| 时间复杂度 | O(n) |
| 空间复杂度 | O(1) |

## 题目与约束

给你一个整数数组 `cost`，其中 `cost[i]` 是从楼梯第 `i` 个台阶向上爬需要支付的费用。

一旦你支付此费用，即可选择向上爬 **一个** 或者 **两个** 台阶。

你可以选择从下标为 `0` 或下标为 `1` 的台阶开始爬楼梯。

请你计算并返回达到楼梯顶部的 **最低** 花费，即最后一步之后的那个位置（下标 `cost.length`）。

**示例 1：**

```
输入：cost = [10,15,20]
输出：15
解释：你将从下标为 1 的台阶开始。
- 支付 15 ，向上爬两个台阶，到达楼梯顶部。
总花费为 15 。
```

**示例 2：**

```
输入：cost = [1,100,1,1,1,100,1,1,100,1]
输出：6
解释：你将从下标为 0 的台阶开始。
- 支付 1 ，向上爬两个台阶，到达下标为 2 的台阶。
- 支付 1 ，向上爬两个台阶，到达下标为 4 的台阶。
- 支付 1 ，向上爬两个台阶，到达下标为 6 的台阶。
- 支付 1 ，向上爬一个台阶，到达下标为 7 的台阶。
- 支付 1 ，向上爬两个台阶，到达下标为 9 的台阶。
- 支付 1 ，向上爬一个台阶，到达楼梯顶部。
总花费为 6 。
```

**提示：**

- `2 <= cost.length <= 1000`
- `0 <= cost[i] <= 999`

## 核心不变量

> 定义 `dp[i]` 为「到达第 `i` 个台阶的最小花费」：`dp[i] = min(dp[i-1] + cost[i-1], dp[i-2] + cost[i-2])`，起点 `dp[0] = dp[1] = 0`（站在 0、1 台阶不花钱），答案取 `dp[n]`。

## 完整推导

### 思路推导

1. **直觉与痛点（站在第 i 阶时，钱花在哪儿？）**
   注意关键点：`cost[i]` 是「**离开**第 `i` 阶向上爬」时才付的钱，站在台阶上本身不花钱。所以你可以免费站在 0 或 1 号台阶上，从那里开始往上爬。要到达第 `i` 阶，只可能来自 `i-1`（付 `cost[i-1]`）或 `i-2`（付 `cost[i-2]`），二者取小。

2. **破局思路（定义状态并递推）**
   令 `dp[i]` = 到达第 `i` 阶的最小花费（楼顶看作第 `n` 阶，`n = cost.length`）。
   - 起点：`dp[0] = 0`、`dp[1] = 0`（可以直接站上去，不付钱）。
   - 转移：`dp[i] = min(dp[i-1] + cost[i-1], dp[i-2] + cost[i-2])`，`i` 从 2 到 `n`。
   - 答案：`dp[n]`。

   小例子 `cost = [10,15,20]`：`dp[0]=0, dp[1]=0`，`dp[2]=min(0+15, 0+10)=10`（从 0 阶付 10 到 2 阶），`dp[3]=min(dp[2]+cost[2], dp[1]+cost[1])=min(10+20, 0+15)=15`，答案 `15`。

3. **关键追问（能不能只留两个变量？）**
   转移只依赖 `dp[i-1]` 与 `dp[i-2]`，用两个滚动变量即可，把空间从 `O(n)` 压到 `O(1)`，面试写出这个版本会加分。

### Java 实现（滚动变量 DP）

```java
class Solution {
    public int minCostClimbingStairs(int[] cost) {
        int n = cost.length;
        // prev2 表示 dp[i-2]，prev1 表示 dp[i-1]
        // 起点：站在 0、1 号台阶都免费
        int prev2 = 0, prev1 = 0;

        for (int i = 2; i <= n; i++) {
            // 从 i-1 爬一步，或从 i-2 爬两步，取较小花费
            int cur = Math.min(prev1 + cost[i - 1], prev2 + cost[i - 2]);
            prev2 = prev1;
            prev1 = cur;
        }
        // dp[n] 即到达楼顶（第 n 阶）的最小花费
        return prev1;
    }
}
```

### 复杂度

- 时间：`O(n)`，一次线性递推到第 `n` 阶，每步常数操作。
- 空间：`O(1)`，只用了 `prev2`、`prev1`、`cur` 三个变量。

### 易错点与扩展（面试高频考点）

1. **`cost[i]` 是「离开」的费用**：站在台阶上不付钱，付钱后才迈步。理解错成「踩上第 i 阶就要付 `cost[i]`」会把答案算错。
2. **起点可以是 0 或 1**：`dp[0] = dp[1] = 0`，两者都免费；不要误以为从 0 开始就一定要付 `cost[0]`。
3. **答案是 `dp[n]` 不是 `dp[n-1]`**：楼顶是第 `n` 阶（`cost.length`），别把最后一个台阶当终点。
4. **不要越界**：循环到 `i <= n`，访问 `cost[i-1]`、`cost[i-2]` 都是合法下标。
5. **扩展对比**：与爬楼梯（70 题）同为线性 DP，只是从「计数」变成「取最小花费」，思路完全同构；也可写成自顶向下记忆化搜索，但滚动 DP 最简洁。

## 力扣原题

[746. 使用最小花费爬楼梯](https://leetcode.cn/problems/min-cost-climbing-stairs/)

### C++ 实现

```cpp
#include <vector>
#include <algorithm>
using namespace std;

class Solution {
public:
    int minCostClimbingStairs(vector<int>& cost) {
        int n = cost.size();
        int prev2 = 0, prev1 = 0;   // dp[i-2], dp[i-1]
        for (int i = 2; i <= n; i++) {
            int cur = min(prev1 + cost[i - 1], prev2 + cost[i - 2]);
            prev2 = prev1;
            prev1 = cur;
        }
        return prev1;               // dp[n]
    }
};
```

### Python 实现

```python
class Solution:
    def minCostClimbingStairs(self, cost: list[int]) -> int:
        n = len(cost)
        prev2, prev1 = 0, 0          # dp[i-2], dp[i-1]
        for i in range(2, n + 1):
            cur = min(prev1 + cost[i - 1], prev2 + cost[i - 2])
            prev2, prev1 = prev1, cur
        return prev1                 # dp[n]
```
