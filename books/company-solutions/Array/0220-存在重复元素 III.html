题目与约束

给你一个整数数组 nums 和两个整数 indexDiff 和 valueDiff 。

找出满足下述条件的下标对 (i, j)：

  • i != j,

  • abs(i - j) <= indexDiff

  • abs(nums[i] - nums[j]) <= valueDiff

如果存在，返回 true ；否则，返回 false 。

示例 1：

输入：nums = [1,2,3,1], indexDiff = 3, valueDiff = 0
输出：true
解释：可以找出 (i, j) = (0, 3) 。
满足下述 3 个条件：
i != j --> 0 != 3
abs(i - j) abs(0 - 3) abs(1 - 1) 示例 2：

输入：nums = [1,5,9,1,5,9], indexDiff = 2, valueDiff = 3
输出：false
解释：尝试所有可能的下标对 (i, j) ，均无法满足这 3 个条件，因此返回 false 。

提示：

  • 2 <= nums.length <= 105

  • -109 <= nums[i] <= 109

  • 1 <= indexDiff <= nums.length

  • 0 <= valueDiff <= 109

核心不变量

把每个数按桶宽 w = valueDiff + 1 映射到桶号 floor(x / w)；同一窗口内若存在合法下标对，则两数必然落在同号桶或相邻桶。

完整推导

思路推导

  1. 直觉与痛点：这是 219 的加强版——不仅要"值相等"，还允许"值相差不超过 valueDiff"。如果仍用 219 的 Set 精确匹配，就无法处理"近似相等"。若用有序集合（TreeSet）查最近的前驱/后继，需要 O(n log k)，虽然不是最优但可行；而桶排序能把它压到 O(n)。

  2. 破局思路（分桶）：取桶宽 w = valueDiff + 1。把整数轴切成一段段长度为 w 的桶，数值 x 所在的桶号是 floor(x / w)。这样有一个漂亮性质：同一个桶里的任意两个数，差值一定 < w，也就是 <= valueDiff。

  3. 关键追问（跨桶怎么办？）：两个值相差 <= valueDiff 时，它们的桶号最多相差 1。所以对当前数 x，只需检查三个桶：id（同桶，命中直接成立）、id-1、id+1（相邻桶再补一次 abs 精确校验）。

  4. 窗口维护：右移时，若 i > indexDiff，把 nums[i-indexDiff-1] 对应桶删掉，保证桶内只含最近 indexDiff 个元素。

小例子：nums=[1,2,3,1], indexDiff=3, valueDiff=0，桶宽 1，桶号即数值。走到下标 3 的 1 时，桶 1 里还存着下标 0 的 1，同桶命中，返回 true。

Java 实现（桶排序滑窗）

import java.util.HashMap;
import java.util.Map;

class Solution {
    public boolean containsNearbyAlmostDuplicate(int[] nums, int indexDiff, int valueDiff) {
        long w = (long) valueDiff + 1;          // 桶宽，用 long 防溢出
        Map<Long, Long> buckets = new HashMap<>();
        for (int i = 0; i < nums.length; i++) {
            // 1. 移除滑出窗口的旧元素
            if (i > indexDiff) {
                long oldId = Math.floorDiv((long) nums[i - indexDiff - 1], w);
                buckets.remove(oldId);
            }
            long x = nums[i];
            long id = Math.floorDiv(x, w);      // 向下取整，兼容负数
            // 2. 同桶：差值必然 <= valueDiff
            if (buckets.containsKey(id)) return true;
            // 3. 相邻桶：再精确校验一次
            if (buckets.containsKey(id - 1) && Math.abs(x - buckets.get(id - 1)) <= valueDiff) return true;
            if (buckets.containsKey(id + 1) && Math.abs(x - buckets.get(id + 1)) <= valueDiff) return true;
            // 4. 入桶
            buckets.put(id, x);
        }
        return false;
    }
}

复杂度

  • 时间：O(n)，每个元素进出桶各 O(1)，每个位置只查 3 个桶。
  • 空间：O(min(n, indexDiff))，桶中同时最多保存窗口内 indexDiff+1 个元素。

易错点与扩展（面试高频考点）

  1. 负数取整：Java/C++ 的 / 是向零截断，必须用 Math.floorDiv 或自定义 floorDiv，否则负数的桶号会算错、漏判。Python 的 // 本身就是向下取整，可直接用。
  2. valueDiff = 0 的退化：此时桶宽为 1，等价于"精确相等"，代码依然正确（w 不能取 0，必须 +1）。
  3. 溢出：valueDiff 可达 10^9，nums[i] 可达 ±10^9，桶宽和桶号都要用 64 位整形（Java long / C++ long long）。
  4. 同桶即成立：不要对同桶再做 abs 判断（可省），因为桶宽设计已保证差值 <= valueDiff；相邻桶则必须补 abs 精确比较。
  5. 替代方案：TreeSet / std::set + lower_bound / ceiling 查前驱后继，O(n log k) 也能过，但桶排序是面试官最想看到的 O(n) 最优解。

力扣原题

220. 存在重复元素 III

C++ 实现

#include <vector>
#include <unordered_map>
#include <cstdlib>
using namespace std;

class Solution {
    long long floorDiv(long long a, long long b) {
        long long q = a / b;
        if ((a % b != 0) && ((a < 0) != (b < 0))) q--;   // 修正为向下取整
        return q;
    }
public:
    bool containsNearbyAlmostDuplicate(vector<int>& nums, int indexDiff, int valueDiff) {
        long long w = (long long) valueDiff + 1;
        unordered_map<long long, long long> buckets;
        int n = nums.size();
        for (int i = 0; i < n; i++) {
            if (i > indexDiff) {
                long long oldId = floorDiv((long long) nums[i - indexDiff - 1], w);
                buckets.erase(oldId);
            }
            long long x = nums[i];
            long long id = floorDiv(x, w);
            if (buckets.count(id)) return true;
            if (buckets.count(id - 1) && llabs(x - buckets[id - 1]) <= valueDiff) return true;
            if (buckets.count(id + 1) && llabs(x - buckets[id + 1]) <= valueDiff) return true;
            buckets[id] = x;
        }
        return false;
    }
};

Python 实现

class Solution:
    def containsNearbyAlmostDuplicate(self, nums: list[int], indexDiff: int, valueDiff: int) -> bool:
        w = valueDiff + 1          # 桶宽，保证同桶内两数之差 <= valueDiff
        buckets = {}               # 桶号 -> 桶内元素值
        for i, x in enumerate(nums):
            if i > indexDiff:
                old = nums[i - indexDiff - 1]
                buckets.pop(old // w, None)   # Python // 对正数 w 即向下取整
            idx = x // w
            if idx in buckets:
                return True
            if idx - 1 in buckets and abs(x - buckets[idx - 1]) <= valueDiff:
                return True
            if idx + 1 in buckets and abs(x - buckets[idx + 1]) <= valueDiff:
                return True
            buckets[idx] = x
        return False
