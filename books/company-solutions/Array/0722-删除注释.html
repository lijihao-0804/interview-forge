722. 删除注释

本题学习状态正在读取学习记录…下次复习：—
本次复习：
按 M 快速切换薄弱标记
遮住推导与代码，先自己想，再逐段揭示
难度中等核心模式逐字符状态机：//直接截断本行，/* */用跨行 inBlock 标记时间复杂度O(N)，N 为所有源码字符总数空间复杂度O(N)（不含输出为 O(1) 的游标状态，结果本身需 O(N)）

题目与约束

给一个 C++ 程序，删除程序中的注释。这个程序source是一个数组，其中source[i]表示第 i 行源码。 这表示每行源码由 '\n' 分隔。

在 C++ 中有两种注释风格，行内注释和块注释。

  • 字符串// 表示行注释，表示//和其右侧的其余字符应该被忽略。

  • 字符串/* 表示一个块注释，它表示直到下一个（非重叠）出现的*/之间的所有字符都应该被忽略。（阅读顺序为从左到右）非重叠是指，字符串/*/并没有结束块注释，因为注释的结尾与开头相重叠。

第一个有效注释优先于其他注释。

  • 如果字符串//出现在块注释中会被忽略。

  • 同样，如果字符串/*出现在行或块注释中也会被忽略。

如果一行在删除注释之后变为空字符串，那么不要输出该行。即，答案列表中的每个字符串都是非空的。

样例中没有控制字符，单引号或双引号字符。

  • 比如，source = "string s = "/* Not a comment. */";" 不会出现在测试样例里。

此外，没有其他内容（如定义或宏）会干扰注释。

我们保证每一个块注释最终都会被闭合， 所以在行或块注释之外的/*总是开始新的注释。

最后，隐式换行符可以通过块注释删除。 有关详细信息，请参阅下面的示例。

从源代码中删除注释后，需要以相同的格式返回源代码。

示例 1:

输入: source = ["/Test program /", "int main()", "{ ", " // variable declaration ", "int a, b, c;", "/ This is a test", " multiline ", " comment for ", " testing /", "a = b + c;", "}"]
输出: ["int main()","{ "," ","int a, b, c;","a = b + c;","}"]
解释: 示例代码可以编排成这样:
/Test program /
int main()
{
// variable declaration
int a, b, c;
/ This is a test
multiline
comment for
testing /
a = b + c;
}
第 1 行和第 6-9 行的字符串 /* 表示块注释。第 4 行的字符串 // 表示行注释。
编排后:
int main()
{
int a, b, c;
a = b + c;
}

示例 2:

输入: source = ["a/comment", "line", "more_comment/b"]
输出: ["ab"]
解释: 原始的 source 字符串是 "a/comment\nline\nmore_comment/b", 其中我们用粗体显示了换行符。删除注释后，隐含的换行符被删除，留下字符串 "ab" 用换行符分隔成数组时就是 ["ab"].

提示:

  • 1 <= source.length <= 100

  • 0 <= source[i].length <= 80

  • source[i] 由可打印的 ASCII 字符组成。

  • 每个块注释都会被闭合。

  • 给定的源码中不会有单引号、双引号或其他控制字符。

核心不变量

用布尔量 inBlock 表示"当前是否处于块注释中"：只有当 inBlock == false 时，收集到的字符才构成一行被 flush 输出；inBlock == true 时跨行积累的字符会与后续行的可见字符拼接，从而自动完成"跨行拼接 + 删除隐式换行"。

完整推导

思路推导

  1. 直觉与痛点（不能按行粗暴替换）

行注释 // 只影响当行，容易处理；真正的坑是块注释 /* ... */ 可能跨越多行，而且块注释结束后同一行还能接着写有效代码（如 more_comment*/b 里的 b）。所以必须以"字符流"的视角，跨行维护一个"是否在块注释中"的状态。

  1. 破局思路（状态机逐字符扫描）

维护 inBlock 和当前输出行缓冲 cur： - 若 inBlock：只看能否匹配 */，匹配上就关闭块注释并跳过这两个字符，否则跳过一个字符； - 若不在块注释：优先检查 //（命中就 break，丢弃本行剩余）；再检查 /*（命中就进入块注释、跳过两位）；其余字符正常追加到 cur。

  1. 关键判定（什么时候 flush 一行）

一行扫完时，只有 !inBlock 且 cur 非空才把 cur 作为一行输出并清空。若行末仍在块注释中，cur 就保留下来，与后面行的可见字符连在一起——这正好实现"块注释删除后跨行拼接"。 小例子：["a/*comment","line","more_comment*/b"]：第 1 行得 a 后进入块注释（不 flush）；第 2 行整行被吃；第 3 行在 */ 后接上 b，cur="ab" 才 flush → ["ab"]。

Java 实现（removeComments）

import java.util.ArrayList;
import java.util.List;

class Solution {
    public List<String> removeComments(String[] source) {
        List<String> res = new ArrayList<>();
        StringBuilder cur = new StringBuilder();
        boolean inBlock = false;

        for (String line : source) {
            for (int i = 0; i < line.length(); ) {
                if (inBlock) {
                    // 块注释中：只寻找结束标记 */
                    if (i + 1 < line.length() && line.charAt(i) == '*' && line.charAt(i + 1) == '/') {
                        inBlock = false;
                        i += 2;
                    } else {
                        i++;
                    }
                } else {
                    if (i + 1 < line.length() && line.charAt(i) == '/' && line.charAt(i + 1) == '/') {
                        break; // 行注释：丢弃本行剩余全部字符
                    } else if (i + 1 < line.length() && line.charAt(i) == '/' && line.charAt(i + 1) == '*') {
                        inBlock = true; // 块注释开始
                        i += 2;
                    } else {
                        cur.append(line.charAt(i)); // 正常可见字符
                        i++;
                    }
                }
            }
            // 只有不在块注释中，cur 才构成一条完整的输出行；空行不输出
            if (!inBlock && cur.length() > 0) {
                res.add(cur.toString());
                cur.setLength(0);
            }
        }
        return res;
    }
}

C++ 实现

#include <vector>
#include <string>
using namespace std;

class Solution {
public:
    vector<string> removeComments(vector<string>& source) {
        vector<string> res;
        string cur;
        bool inBlock = false;
        for (const string& line : source) {
            for (int i = 0; i < (int)line.size(); ) {
                if (inBlock) {
                    if (i + 1 < (int)line.size() && line[i] == '*' && line[i + 1] == '/') {
                        inBlock = false;
                        i += 2;
                    } else {
                        ++i;
                    }
                } else {
                    if (i + 1 < (int)line.size() && line[i] == '/' && line[i + 1] == '/') {
                        break; // 行注释
                    } else if (i + 1 < (int)line.size() && line[i] == '/' && line[i + 1] == '*') {
                        inBlock = true; // 块注释开始
                        i += 2;
                    } else {
                        cur.push_back(line[i]);
                        ++i;
                    }
                }
            }
            // 不在块注释中且非空，才输出并清空
            if (!inBlock && !cur.empty()) {
                res.push_back(cur);
                cur.clear();
            }
        }
        return res;
    }
};

Python 实现

class Solution:
    def removeComments(self, source: list[str]) -> list[str]:
        res = []
        cur = []
        in_block = False
        for line in source:
            i = 0
            n = len(line)
            while i < n:
                if in_block:
                    # 块注释中：寻找结束标记 */
                    if i + 1 < n and line[i] == '*' and line[i + 1] == '/':
                        in_block = False
                        i += 2
                    else:
                        i += 1
                else:
                    if i + 1 < n and line[i] == '/' and line[i + 1] == '/':
                        break  # 行注释
                    elif i + 1 < n and line[i] == '/' and line[i + 1] == '*':
                        in_block = True  # 块注释开始
                        i += 2
                    else:
                        cur.append(line[i])
                        i += 1
            # 不在块注释中且非空，才输出并清空
            if not in_block and cur:
                res.append(''.join(cur))
                cur = []
        return res

复杂度

  • 时间：O(N)，每个字符最多被访问一次（*/ 匹配时会一次跳过两位，不会重复扫描）。
  • 空间：O(N)，输出本身需要保存全部可见字符；除输出外只用了 StringBuilder 缓冲与常量状态，缓冲最多为单行长度量级。
易错点与扩展（面试高频考点）
  1. /*/ 不算闭合：判断结束标记必须是 * 紧接 / 的两位匹配，不能用单字符或重叠匹配，否则会把 /*/ 误判为结束。
  2. 块注释结束后同行仍有代码：不能在遇到 */ 时直接结束整行，必须继续扫描同一行剩余字符（如 ...*/b 中的 b）。
  3. flush 时机：只在 !inBlock 时输出当前缓冲；若在块注释中间就 flush，会把一行错误拆成两行或丢掉后续拼接的字符。
  4. 空行不输出：整行被注释掉后 cur 为空，必须跳过，否则会多出空字符串。
  5. 扩展：C 系语言词法分析中，注释与前缀判断正是"最长匹配优先"的典型（先判 //、/* 两位），与字符串/正则词法状态机思想一致。
