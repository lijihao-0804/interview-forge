# 213. 打家劫舍 II

| 题目信息 | 内容 |
|---|---|
| 难度 | 中等 |
| 核心模式 | 环形 DP 拆两次线性 DP：分别「不偷首」和「不偷尾」，取较大值 |
| 时间复杂度 | O(n) |
| 空间复杂度 | O(1) |

## 题目与约束

你是一个专业的小偷，计划偷窃沿街的房屋，每间房内都藏有一定的现金。这个地方所有的房屋都 围成一圈 ，这意味着第一个房屋和最后一个房屋是紧挨着的。同时，相邻的房屋装有相互连通的防盗系统，如果两间相邻的房屋在同一晚上被小偷闯入，系统会自动报警 。

给定一个代表每个房屋存放金额的非负整数数组，计算你 在不触动警报装置的情况下 ，今晚能够偷窃到的最高金额。

 

示例 1：

```
<strong>输入：</strong>nums = [2,3,2]
<strong>输出：</strong>3
<strong>解释：</strong>你不能先偷窃 1 号房屋（金额 = 2），然后偷窃 3 号房屋（金额 = 2）, 因为他们是相邻的。
```

示例 2：

```
<strong>输入：</strong>nums = [1,2,3,1]
<strong>输出：</strong>4
<strong>解释：</strong>你可以先偷窃 1 号房屋（金额 = 1），然后偷窃 3 号房屋（金额 = 3）。
     偷窃到的最高金额 = 1 + 3 = 4 。
```

示例 3：

```
<strong>输入：</strong>nums = [1,2,3]
<strong>输出：</strong>3
```

 

提示：

- `1 <= nums.length <= 100`

- `0 <= nums[i] <= 1000`

## 核心不变量

> 环形数组里，第一个和最后一个不能同时偷。于是答案 = max(在 `[0, n-2]` 上线性打家劫舍, 在 `[1, n-1]` 上线性打家劫舍)，两个区间覆盖了所有合法方案。

## 完整推导

### 思路推导

1. **回退到线性版本**

   不考虑环形时就是经典「打家劫舍 I」：设 `dp[i]` 为前 `i` 间房能偷到的最大金额，则 `dp[i] = max(dp[i-1], dp[i-2] + nums[i])`——要么不偷第 i 间，要么偷第 i 间并跳过第 i-1 间。

2. **环形带来的唯一额外约束**

   首尾相邻，意味着「nums[0] 与 nums[n-1] 不能同时被偷」。这个约束只有两种破法：要么不偷第一间，要么不偷最后一间。

3. **拆成两个线性子问题**

   - 方案 A：不偷最后一间，候选范围缩到区间 `[0, n-2]`，在该区间上做线性 DP。
   - 方案 B：不偷第一间，候选范围缩到区间 `[1, n-1]`，在该区间上做线性 DP。
   - 取两者最大值即覆盖所有合法方案。示例 1 `[2,3,2]`：`[0,1]` 段最大 3，`[1,2]` 段最大 3，答案 3。

4. **滚动变量省空间**

   线性 DP 只依赖前两项，用 `prev2`、`prev1` 两个变量滚动即可，把 O(n) 空间降到 O(1)。

### Java 实现（rob）

```java
class Solution {
    public int rob(int[] nums) {
        int n = nums.length;
        // 只有一间房，首尾重叠，直接偷它
        if (n == 1) return nums[0];
        // 情况一：不偷最后一间，区间 [0, n-2]
        // 情况二：不偷第一间，区间 [1, n-1]
        return Math.max(robRange(nums, 0, n - 2), robRange(nums, 1, n - 1));
    }

    /** 闭区间 [start, end] 上的线性打家劫舍，滚动变量优化空间 */
    private int robRange(int[] nums, int start, int end) {
        int prev2 = 0; // dp[i-2]
        int prev1 = 0; // dp[i-1]
        for (int i = start; i <= end; i++) {
            int cur = Math.max(prev1, prev2 + nums[i]); // 不偷 i / 偷 i
            prev2 = prev1;
            prev1 = cur;
        }
        return prev1;
    }
}
```

### 复杂度

- 时间：O(n)，两遍线性扫描，每间房常数次操作。
- 空间：O(1)，只用两个滚动变量，无额外数组。

### 易错点与扩展（面试高频考点）

1. **n == 1 必须特判**：此时 `n-2 = -1`，两个子区间会退化，必须先返回 `nums[0]`。
2. **两段区间的定义别搞混**：`[0, n-2]` 表示排除最后一间，`[1, n-1]` 表示排除第一间，二者都合法且互补，取 max。
3. **DP 初值 `prev2 = prev1 = 0`**：金额非负，从 0 起步天然正确；若金额可能为负则要另行初始化。
4. **不要真的「复制」环形数组**：把环形拆成两段线性即可，避免 O(n) 额外空间。
5. **扩展**：若房屋排成树（打家劫舍 III），则改成树形 DP——每个节点返回「偷/不偷该节点」两个值后合并。

### C++ 实现

```cpp
class Solution {
public:
    int rob(vector<int>& nums) {
        int n = nums.size();
        if (n == 1) return nums[0];
        return max(robRange(nums, 0, n - 2), robRange(nums, 1, n - 1));
    }

private:
    int robRange(vector<int>& nums, int start, int end) {
        int prev2 = 0, prev1 = 0; // dp[i-2], dp[i-1]
        for (int i = start; i <= end; i++) {
            int cur = max(prev1, prev2 + nums[i]);
            prev2 = prev1;
            prev1 = cur;
        }
        return prev1;
    }
};
```

### Python 实现

```python
class Solution:
    def rob(self, nums: list[int]) -> int:
        n = len(nums)
        if n == 1:
            return nums[0]

        def rob_range(start: int, end: int) -> int:
            prev2, prev1 = 0, 0  # dp[i-2], dp[i-1]
            for i in range(start, end + 1):
                prev2, prev1 = prev1, max(prev1, prev2 + nums[i])
            return prev1

        return max(rob_range(0, n - 2), rob_range(1, n - 1))
```
