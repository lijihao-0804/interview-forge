# 977. 有序数组的平方

| 题目信息 | 内容 |
|---|---|
| 难度 | 简单 |
| 核心模式 | 双指针对撞，从两端取绝对值较大者逆序填充 |
| 时间复杂度 | O(n) |
| 空间复杂度 | O(n)（结果数组，额外空间 O(1)） |

## 题目与约束

给你一个按 非递减顺序 排序的整数数组 `nums`，返回 每个数字的平方 组成的新数组，要求也按 非递减顺序 排序。

 

示例 1：

```
<strong>输入：</strong>nums = [-4,-1,0,3,10]
<strong>输出：</strong>[0,1,9,16,100]
<strong>解释：</strong>平方后，数组变为 [16,1,0,9,100]
排序后，数组变为 [0,1,9,16,100]
```

示例 2：

```
<strong>输入：</strong>nums = [-7,-3,2,3,11]
<strong>输出：</strong>[4,9,9,49,121]
```

 

提示：

- `1 <= nums.length <= 104`

- `-104 <= nums[i] <= 104`

- `nums` 已按 非递减顺序 排序

 

进阶：

- 请你设计时间复杂度为 `O(n)` 的算法解决本问题

## 核心不变量

> 平方后的最大值必然来自原数组的两端；双指针从两端向中间收缩，每次把较大的那个平方从结果末尾往前填，填完即整体有序。

## 完整推导

### 思路推导

1. **直觉与痛点（有序为什么还麻烦？）**
   数组本身有序，但里面有负数。平方之后大小关系会被"翻转"：绝对值越大的数平方越大，而绝对值最大的一定落在数组两端（最左的负数或最右的正数）。直接平方再排序是 `O(n log n)`，浪费了"已排序"这个条件。

2. **破局思路（两端比较，逆序填充）**
   设左指针 `i = 0`、右指针 `j = n-1`。比较 `nums[i]²` 与 `nums[j]²`，较大者就是当前剩余元素里最大的平方，把它放到结果数组的末尾 `k` 处，然后让对应指针向内移动、`k` 前移。

3. **为什么正确**
   每一步都取走了"当前剩余中的最大平方"，把它放到"结果中尚未填充的最大位置"，因此结果整体从后往前被填成非递减序列，天然有序。

4. **收尾**
   当 `i > j` 时全部元素已放入结果，循环结束。偶数个元素时两两收尾，奇数个元素时最后 `i == j` 的那一个也会被放入，不会遗漏。

   小例子：`nums = [-4,-1,0,3,10]`，左端平方 `16`、右端平方 `100`，取 `100` 放末尾（`j--`）；再比 `16` 与 `9`，取 `16`；再比 `1` 与 `9`，取 `9`；再比 `1` 与 `0`，取 `1`；最后 `0`。结果 `[0,1,9,16,100]`。

### Java 实现（sortedSquares）

```java
class Solution {
    public int[] sortedSquares(int[] nums) {
        int n = nums.length;
        int[] res = new int[n];
        int i = 0, j = n - 1;   // 双指针：指向尚未处理区间的两端
        int k = n - 1;          // 结果从后往前填，保证有序
        while (i <= j) {
            int leftVal = nums[i] * nums[i];
            int rightVal = nums[j] * nums[j];
            if (leftVal > rightVal) {
                res[k--] = leftVal; // 左端绝对值更大，放到结果末尾
                i++;
            } else {
                res[k--] = rightVal; // 右端绝对值更大（或相等），放到结果末尾
                j--;
            }
        }
        return res;
    }
}
```

### 复杂度

- 时间：O(n)。两个指针合计最多各走 n 步，每个元素只被比较、写入一次。
- 空间：O(n)。需要一个长度为 n 的结果数组；除此之外只用常数个指针变量，额外空间 O(1)。

### 易错点与扩展（面试高频考点）

1. **忘记"从后往前填"**：平方后最大值在两端，如果从前往后填就必须每次找最小值，会退化成 O(n²) 或需要额外排序；必须利用"最大值在两端"逆序填充。
2. **循环边界写错**：条件是 `i <= j`（含等号），写成 `i < j` 会在奇数长度时漏掉中间那个元素。
3. **溢出风险**：本题 `nums[i]` 绝对值不超过 `10^4`，平方最大 `10^8` 在 `int` 范围内安全；若数据范围更大，应改用 `long` 或先转 `long` 再平方。
4. **就地返回**：题目要求返回新数组，不能依赖原数组；但可以复用输入空间做"从后往前覆盖"，若追求原地则需谨慎处理指针与写入位置的先后关系。
5. **扩展**：同类"利用有序性避免排序"的题还有合并两个有序数组（LeetCode 88，从后往前双指针）、两数之和 II（LeetCode 167，对撞双指针）。

### C++ 实现

```cpp
#include <vector>
using namespace std;

class Solution {
public:
    vector<int> sortedSquares(vector<int>& nums) {
        int n = nums.size();
        vector<int> res(n);
        int i = 0, j = n - 1;
        for (int k = n - 1; k >= 0; k--) {
            if (nums[i] * nums[i] > nums[j] * nums[j]) {
                res[k] = nums[i] * nums[i]; // 左端更大
                i++;
            } else {
                res[k] = nums[j] * nums[j]; // 右端更大（或相等）
                j--;
            }
        }
        return res;
    }
};
```

### Python 实现

```python
from typing import List

class Solution:
    def sortedSquares(self, nums: List[int]) -> List[int]:
        n = len(nums)
        res = [0] * n
        i, j = 0, n - 1
        k = n - 1
        while i <= j:
            left_sq = nums[i] * nums[i]
            right_sq = nums[j] * nums[j]
            if left_sq > right_sq:
                res[k] = left_sq
                i += 1
            else:
                res[k] = right_sq
                j -= 1
            k -= 1
        return res
```
