题目信息 内容
难度 中等
核心模式 记录已翻转位置的最大下标，判断前缀最大值是否等于步数
时间复杂度 O(n)
空间复杂度 O(1)

题目与约束

给你一个长度为 n 、下标从 1 开始的二进制字符串，所有位最开始都是 0 。我们会按步翻转该二进制字符串的所有位（即，将 0 变为 1）。

给你一个下标从 1 开始的整数数组 flips ，其中 flips[i] 表示对应下标 i 的位将会在第 i 步翻转。

二进制字符串 前缀一致 需满足：在第 i 步之后，在 闭 区间 [1, i] 内的所有位都是 1 ，而其他位都是 0 。

返回二进制字符串在翻转过程中 前缀一致 的次数。

示例 1：

<strong>输入：</strong>flips = [3,2,4,1,5]
<strong>输出：</strong>2
<strong>解释：</strong>二进制字符串最开始是 "00000" 。
执行第 1 步：字符串变为 "00100" ，不属于前缀一致的情况。
执行第 2 步：字符串变为 "01100" ，不属于前缀一致的情况。
执行第 3 步：字符串变为 "01110" ，不属于前缀一致的情况。
执行第 4 步：字符串变为 "11110" ，属于前缀一致的情况。
执行第 5 步：字符串变为 "11111" ，属于前缀一致的情况。
在翻转过程中，前缀一致的次数为 2 ，所以返回 2 。

示例 2：

<strong>输入：</strong>flips = [4,1,2,3]
<strong>输出：</strong>1
<strong>解释：</strong>二进制字符串最开始是 "0000" 。
执行第 1 步：字符串变为 "0001" ，不属于前缀一致的情况。
执行第 2 步：字符串变为 "1001" ，不属于前缀一致的情况。
执行第 3 步：字符串变为 "1101" ，不属于前缀一致的情况。
执行第 4 步：字符串变为 "1111" ，属于前缀一致的情况。
在翻转过程中，前缀一致的次数为 1 ，所以返回 1 。

提示：

  • n == flips.length

  • 1 <= n <= 5 * 104

  • flips 是范围 [1, n] 中所有整数构成的一个排列

核心不变量

第 i 步后恰好有 i 个位置为 1；要让 [1, i] 全为 1 且其余为 0，当且仅当这 i 个为 1 的位置恰好就是 {1, 2, ..., i}，等价于前 i 步翻转位置的最大值等于 i。

完整推导

思路推导

  1. 把"前缀一致"翻译成下标条件：第 i 步结束后共有 i 个位置被翻成 1。若字符串前缀一致，则这 i 个 1 必须正好占据位置 1..i。也就是说，前 i 步翻转过的位置集合必须恰好是 {1, 2, ..., i}。

  2. 集合 = 前缀的判据：i 个互不相同的正整数，若它们的最大值就是 i，那这些数必然恰好是 1..i（因为都 ≤ i 且有 i 个不同的数）。所以只需追踪前 i 步翻转位置的最大值 maxPos。

  3. 破局：边走边维护 maxPos = max(maxPos, flips[i])。第 i+1 步（i 从 0 开始）时，若 maxPos == i + 1，说明这 i+1 个位置正好铺满 1..i+1，计一次前缀一致。

  4. 例子：flips = [3,2,4,1,5]。逐步 maxPos：3,3,4,4,5；与步数 1,2,3,4,5 比较，只有第 4 步（4==4）和第 5 步（5==5）相等，答案 2。✓

Java 实现（一次扫描维护前缀最大值）

class Solution {
    public int numTimesAllBlue(int[] flips) {
        int count = 0;    // 前缀一致次数
        int maxPos = 0;   // 已翻转位置的最大下标
        for (int i = 0; i < flips.length; i++) {
            maxPos = Math.max(maxPos, flips[i]);
            // 第 i+1 步后，若最大位置正好是 i+1，则 1..i+1 全为 1
            if (maxPos == i + 1) {
                count++;
            }
        }
        return count;
    }
}

复杂度

  • 时间：O(n)。只需一次线性扫描，每步做一次取最大值与一次比较。
  • 空间：O(1)。仅使用 count、maxPos 两个变量。

易错点与扩展（面试高频考点）

  1. 下标的 0/1 基准：flips 是 1 起始，循环变量 i 是 0 起始，判断要用 maxPos == i + 1，别写成 maxPos == i。
  2. 不要真的去模拟字符串：若每步都维护长度 n 的字符串并检查前缀，复杂度退化到 O(n^2)，在 n = 5*10^4 下会超时。抓住"前缀最大值"这一不变量是 O(n) 的关键。
  3. 与"求和"判据的等价性：也可用"前 i 步翻转位置之和 == i(i+1)/2"来判断，但会有溢出风险，用最大值更安全。
  4. 题目保证是排列：因为 flips 是 1..n 的一个排列，位置不会重复翻转，这才使"最大值等于步数 ⇔ 集合是前缀"成立。若允许重复翻转则结论不成立。
  5. 边界：n = 1 时 flips = [1]，第 1 步即一致，返回 1。

C++ 实现

#include <vector>
#include <algorithm>
using namespace std;

class Solution {
public:
    int numTimesAllBlue(vector<int>& flips) {
        int count = 0;
        int maxPos = 0;
        for (int i = 0; i < (int)flips.size(); i++) {
            maxPos = max(maxPos, flips[i]);
            if (maxPos == i + 1) {
                count++;
            }
        }
        return count;
    }
};

Python 实现

class Solution:
    def numTimesAllBlue(self, flips: list[int]) -> int:
        count = 0
        max_pos = 0
        for i, pos in enumerate(flips):
            max_pos = max(max_pos, pos)
            if max_pos == i + 1:
                count += 1
        return count
