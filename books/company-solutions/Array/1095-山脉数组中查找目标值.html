题目与约束

（这是一个 交互式问题 ）

你可以将一个数组 arr 称为 山脉数组 当且仅当：

  • arr.length >= 3

  • 存在一些 0 < i < arr.length - 1 的 i 使得：

  • arr[0] < arr[1] < ... < arr[i - 1] < arr[i]

  • arr[i] > arr[i + 1] > ... > arr[arr.length - 1]

给定一个山脉数组 mountainArr ，返回 最小 的 index 使得 mountainArr.get(index) == target。如果不存在这样的 index，返回 -1 。

你无法直接访问山脉数组。你只能使用 MountainArray 接口来访问数组：

  • MountainArray.get(k) 返回数组中下标为 k 的元素（从 0 开始）。

  • MountainArray.length() 返回数组的长度。

调用 MountainArray.get 超过 100 次的提交会被判定为错误答案。此外，任何试图绕过在线评测的解决方案都将导致取消资格。

示例 1：

输入：mountainArr = [1,2,3,4,5,3,1], target = 3
输出：2
解释：3 在数组中出现了两次，下标分别为 2 和 5，我们返回最小的下标 2。

示例 2：

输入：mountainArr = [0,1,2,4,2,1], target = 3
输出：-1
解释：3 在数组中没有出现，返回 -1。

提示：

  • 3 <= mountainArr.length() <= 104

  • 0 <= target <= 109

  • 0 <= mountainArr.get(index) <= 109

核心不变量

山脉数组从峰顶被切成"左侧严格递增 + 右侧严格递减"两段单调序列，任一段上的查找都能用标准二分；峰顶就是最后一个满足 arr[mid] < arr[mid+1] 的位置。

完整推导

思路推导

  1. 痛点：整体不单调，不能直接二分

普通二分要求整个数组有序。山脉数组先升后降，中间有唯一的"转折点"（峰顶）。如果直接对整体二分，target 与 arr[mid] 的大小关系无法确定该往左还是往右。

  1. 拆成三步
  • 第一步：二分找峰顶 peak。在 [0, n-1] 上比较 get(mid) 与 get(mid+1)：若 get(mid) < get(mid+1)，说明还在上坡，峰顶在右侧，lo = mid + 1；否则峰顶在左侧或就是 mid，hi = mid。收敛后 lo 即峰顶。
  • 第二步：在左侧升序段 [0, peak] 上标准二分找 target，找到就直接返回（因为要"最小下标"，左侧优先）。
  • 第三步：左段没找到，再去右侧降序段 [peak, n-1] 二分。这段是降序，比较方向要反过来：get(mid) > target 说明目标在右边（更大下标一侧），令 lo = mid + 1；否则 hi = mid - 1。
  1. 小例子（[1,2,3,4,5,3,1]，target = 3）

找峰顶：mid=3 时 get(3)=4 < get(4)=5 → 上坡，往右；最终 peak=4（值 5）。左段 [1,2,3,4,5] 二分命中下标 2，直接返回 2，正是最小下标。

  1. 为什么要缓存 get

题目限制 get 调用不超过 100 次。三次二分每次约 log2(10^4) ≈ 14 次迭代，每次迭代可能取 1~2 个下标，重复下标若不缓存会浪费配额。用一个哈希表把"下标 → 值"缓存起来，保证同一个下标只真正调用一次 get，从而稳定落在配额内。

Java 实现（findInMountainArray）

import java.util.HashMap;
import java.util.Map;

/**
 * // This is MountainArray's API interface.
 * // You should not implement it, or speculate about its implementation
 * interface MountainArray {
 *     public int get(int index) {}
 *     public int length() {}
 * }
 */
class Solution {
    private Map<Integer, Integer> cache = new HashMap<>();
    private MountainArray arr;

    // 带缓存的取值，避免同一个下标重复消耗 get 配额
    private int get(int index) {
        Integer v = cache.get(index);
        if (v != null) {
            return v;
        }
        int val = arr.get(index);
        cache.put(index, val);
        return val;
    }

    public int findInMountainArray(int target, MountainArray mountainArr) {
        this.arr = mountainArr;
        this.cache = new HashMap<>();
        int n = arr.length();

        // 1. 二分查找峰顶下标
        int lo = 0, hi = n - 1;
        while (lo < hi) {
            int mid = lo + (hi - lo) / 2;
            if (get(mid) < get(mid + 1)) {
                lo = mid + 1; // 上坡，峰顶在右侧
            } else {
                hi = mid;     // 下坡，峰顶在左侧（或就是 mid）
            }
        }
        int peak = lo;

        // 2. 左侧升序段 [0, peak] 二分，优先返回最小下标
        int l = 0, r = peak;
        while (l <= r) {
            int mid = l + (r - l) / 2;
            int v = get(mid);
            if (v == target) {
                return mid;
            } else if (v < target) {
                l = mid + 1;
            } else {
                r = mid - 1;
            }
        }

        // 3. 右侧降序段 [peak, n-1] 二分，注意比较方向相反
        l = peak;
        r = n - 1;
        while (l <= r) {
            int mid = l + (r - l) / 2;
            int v = get(mid);
            if (v == target) {
                return mid;
            } else if (v > target) {
                l = mid + 1; // 降序：值偏大说明目标在更右侧
            } else {
                r = mid - 1;
            }
        }

        return -1;
    }
}

复杂度

  • 时间：O(log n)。找峰顶一次二分、左右各一次二分，共 3 次 O(log n)，且 get 调用总数约为 O(log n)（配合缓存）。
  • 空间：O(log n)。缓存中只保存被访问过的下标，数量为 O(log n)；递归栈为常数（全是迭代实现）。

易错点与扩展（面试高频考点）

  1. 峰顶二分的边界：get(mid) 与 get(mid+1) 比较时 mid 必须保证 mid + 1 <= n - 1，用 while (lo < hi) 且 mid = lo + (hi - lo) / 2 可天然保证不会越界。

  2. 降序段比较方向写反：这是最常见的 bug。升序段 v < target 往右；降序段恰好相反，v > target 才往右。写之前先默念"这段是从大到小"。

  3. get 调用次数超限：不缓存时最坏可能接近 3×2×log₂n ≈ 84~100 次，稍有偏差就爆。务必缓存，或直接复用第一步峰顶查询的结果减少重复调用。

  4. 最小下标语义：必须先查左侧升序段，命中即返回；只有左侧彻底查不到才去右侧，否则会返回较大下标而判错。

  5. 扩展：若数组是"先降后升"（山谷），只需把峰顶判定条件取反，其余两段二分逻辑对称复用；若允许多个峰，则单调性被破坏，需改用三分或用哈希记录全部下标（但那样就不是 O(log n) 了）。

C++ 实现

#include <unordered_map>

/**
 * // This is the MountainArray's API interface.
 * // You should not implement it, or speculate about its implementation
 * class MountainArray {
 *   public:
 *     int get(int index);
 *     int length();
 * };
 */
class Solution {
    std::unordered_map<int, int> cache;
    MountainArray* arr;

    // 带缓存的取值，控制 get 调用次数
    int get(int index) {
        auto it = cache.find(index);
        if (it != cache.end()) {
            return it->second;
        }
        int val = arr->get(index);
        cache[index] = val;
        return val;
    }

public:
    int findInMountainArray(int target, MountainArray &mountainArr) {
        cache.clear();
        arr = &mountainArr;
        int n = arr->length();

        // 1. 二分查找峰顶
        int lo = 0, hi = n - 1;
        while (lo < hi) {
            int mid = lo + (hi - lo) / 2;
            if (get(mid) < get(mid + 1)) {
                lo = mid + 1;
            } else {
                hi = mid;
            }
        }
        int peak = lo;

        // 2. 左侧升序段二分
        int l = 0, r = peak;
        while (l <= r) {
            int mid = l + (r - l) / 2;
            int v = get(mid);
            if (v == target) {
                return mid;
            } else if (v < target) {
                l = mid + 1;
            } else {
                r = mid - 1;
            }
        }

        // 3. 右侧降序段二分（比较方向相反）
        l = peak;
        r = n - 1;
        while (l <= r) {
            int mid = l + (r - l) / 2;
            int v = get(mid);
            if (v == target) {
                return mid;
            } else if (v > target) {
                l = mid + 1;
            } else {
                r = mid - 1;
            }
        }

        return -1;
    }
};

Python 实现

class Solution:
    def findInMountainArray(self, target: int, mountainArr: 'MountainArray') -> int:
        cache = {}

        # 带缓存的取值，控制 get 调用次数
        def get(i: int) -> int:
            if i not in cache:
                cache[i] = mountainArr.get(i)
            return cache[i]

        n = mountainArr.length()

        # 1. 二分查找峰顶
        lo, hi = 0, n - 1
        while lo < hi:
            mid = (lo + hi) // 2
            if get(mid) < get(mid + 1):
                lo = mid + 1
            else:
                hi = mid
        peak = lo

        # 2. 左侧升序段二分
        l, r = 0, peak
        while l <= r:
            mid = (l + r) // 2
            v = get(mid)
            if v == target:
                return mid
            elif v < target:
                l = mid + 1
            else:
                r = mid - 1

        # 3. 右侧降序段二分（比较方向相反）
        l, r = peak, n - 1
        while l <= r:
            mid = (l + r) // 2
            v = get(mid)
            if v == target:
                return mid
            elif v > target:
                l = mid + 1
            else:
                r = mid - 1

        return -1
