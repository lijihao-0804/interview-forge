题目与约束

给你一个整数数组 nums 和一个整数 k ，判断数组中是否存在两个 不同的索引 i 和 j ，满足 nums[i] == nums[j] 且 abs(i - j) <= k 。如果存在，返回 true ；否则，返回 false 。

示例 1：

输入：nums = [1,2,3,1], k = 3
输出：true

示例 2：

输入：nums = [1,0,1,1], k = 1
输出：true

示例 3：

输入：nums = [1,2,3,1,2,3], k = 2
输出：false

提示：

  • 1 <= nums.length <= 105

  • -109 <= nums[i] <= 109

  • 0 <= k <= 105

核心不变量

遍历到下标 i 时，集合里恰好只保存下标落在 [i-k, i-1] 窗口内的元素值。

完整推导

思路推导

  1. 直觉与痛点：直接对每一对下标都判断 abs(i-j) <= k，枚举量是 O(n·k)，在 n、k 都到 10^5 时必然超时。真正需要关心的"重复"其实只发生在距离不超过 k 的范围内。

  2. 破局思路（滑动窗口）：我们让一个长度最多为 k+1 的窗口从左往右滑。窗口内维护的是"最近 k 个元素"的取值集合——用 HashSet 存。每向右走一步，先检查当前值是否已在集合里；若是，说明前面 k 个位置内出现过相同值，直接返回 true。

  3. 关键维护（窗口大小不越界）：当我们走到下标 i 时，窗口里只应保留 [i-k, i-1]。所以在加入 nums[i] 之前，如果 i > k，就要把已经滑出窗口的 nums[i-k-1] 从集合中删除。这样集合大小恒不超过 k+1。

小例子：nums = [1,2,3,1], k = 3。走到最后一个 1（下标 3）时，集合里是 {1,2,3}，发现 1 已存在，且距离 3 <= k，返回 true。

Java 实现（滑动窗口 + HashSet）

import java.util.HashSet;
import java.util.Set;

class Solution {
    public boolean containsNearbyDuplicate(int[] nums, int k) {
        Set<Integer> window = new HashSet<>();
        for (int i = 0; i < nums.length; i++) {
            // 保证窗口内只保留下标 [i-k, i-1] 的元素
            if (i > k) {
                window.remove(nums[i - k - 1]);
            }
            // add 返回 false 说明当前值已在窗口内，即存在满足条件的下标对
            if (!window.add(nums[i])) {
                return true;
            }
        }
        return false;
    }
}

复杂度

  • 时间：O(n)，每个元素最多被加入、删除各一次，哈希操作均摊 O(1)。
  • 空间：O(k)，集合中最多同时保存 k+1 个元素（若 k >= n 最多 n 个）。

易错点与扩展（面试高频考点）

  1. 删除时机：必须先删除 nums[i-k-1] 再判断/加入，否则窗口会多出一个本不属于 [i-k, i-1] 的旧元素，可能造成误判。
  2. HashSet.add 的返回值：add 返回 false 表示集合里已存在该值，可借它一步完成"查重 + 插入"。
  3. k = 0 的边界：窗口只含当前元素本身，永远不会与自身重复，答案恒为 false，代码逻辑天然成立。
  4. 与 217 的区别：217 只问"是否有重复"，可用全局 Set；本题多了距离约束，所以必须用会过期的滑动窗口。
  5. 变体：若要求返回具体下标对，把集合换成 Map<值, 最近下标> 即可，命中时直接取出上一次下标。

C++ 实现

#include <vector>
#include <unordered_set>
using namespace std;

class Solution {
public:
    bool containsNearbyDuplicate(vector<int>& nums, int k) {
        unordered_set<int> window;
        for (int i = 0; i < (int)nums.size(); i++) {
            if (i > k) window.erase(nums[i - k - 1]);
            // insert 返回 pair，second 为 false 表示已存在
            if (!window.insert(nums[i]).second) return true;
        }
        return false;
    }
};

Python 实现

class Solution:
    def containsNearbyDuplicate(self, nums: list[int], k: int) -> bool:
        window = set()
        for i, x in enumerate(nums):
            if i > k:
                window.discard(nums[i - k - 1])
            if x in window:
                return True
            window.add(x)
        return False
