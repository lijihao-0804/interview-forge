题目信息 内容
难度 中等
核心模式 一次遍历维护「左侧最大值」与「全局最大值」
时间复杂度 O(n)
空间复杂度 O(1)

题目与约束

给定一个数组 nums ，将其划分为两个连续子数组 left 和 right， 使得：

  • left 中的每个元素都小于或等于 right 中的每个元素。

  • left 和 right 都是非空的。

  • left 的长度要尽可能小。

在完成这样的分组后返回 left 的 长度 。

用例可以保证存在这样的划分方法。

示例 1：

输入：nums = [5,0,3,8,6]
输出：3
解释：left = [5,0,3]，right = [8,6]

示例 2：

输入：nums = [1,1,1,0,6,12]
输出：4
解释：left = [1,1,1,0]，right = [6,12]

提示：

  • 2 <= nums.length <= 105

  • 0 <= nums[i] <= 106

  • 可以保证至少有一种方法能够按题目所描述的那样对 nums 进行划分。

核心不变量

扫描时始终维护「已确定划入 left 的最大值 maxLeft」；一旦遇到比 maxLeft 更小的元素，说明它不可能属于 right（否则违反 left ≤ right），切分点必须右移，把它连同之前扫过的全部元素都并入 left，同时 maxLeft 更新为迄今全局最大值。

完整推导

思路推导

  1. 痛点：直接枚举切分点会退化成 O(n²)。关键观察是——切分点只能往右移动，不能回退，因此可以一次扫描到底。

  2. 两个变量： - maxLeft：目前「已经确定属于 left」的部分的最大值，是 left 的「天花板」。 - maxAll：从下标 0 扫描到当前位置见到的全局最大值。

  3. 遇小则扩：从左往右扫，若当前元素 nums[i] < maxLeft，它比 left 的最大值还小，若把它留给 right 就会违反 left 中每个元素 ≤ right 中每个元素，所以它必须并入 left。于是把切分点更新为 i，并把 maxLeft 提升到 maxAll（因为中间这些原本「待定」的元素现在都归 left 了，left 的最大值要取这段的全局最大值）。

  4. 小例子：[5,0,3,8,6]。 - 初始 maxLeft = maxAll = 5，切分点 cut = 0。 - 0 < 5 → 并入 left，cut = 1，maxLeft = 5。 - 3 < 5 → 并入 left，cut = 2，maxLeft = 5。 - 8：maxAll = 8，8 < 5 不成立 → 不动。 - 6：maxAll = 8，6 < 5 不成立 → 不动。 - 返回 cut + 1 = 3，即 left = [5,0,3]。

Java 实现（partitionDisjoint）

class Solution {
    public int partitionDisjoint(int[] nums) {
        int maxLeft = nums[0];  // 已确定属于 left 部分的最大值
        int maxAll = nums[0];   // 扫描至今的全局最大值
        int cut = 0;            // left 部分最后一个元素的下标

        for (int i = 1; i < nums.length; i++) {
            maxAll = Math.max(maxAll, nums[i]);

            // 当前元素比 left 最大值还小，必须并入 left
            if (nums[i] < maxLeft) {
                cut = i;
                maxLeft = maxAll; // left 扩展后，其最大值变为这段的全局最大值
            }
        }
        return cut + 1; // left 的长度
    }
}

复杂度

  • 时间：O(n)，只需一次从左到右的扫描。
  • 空间：O(1)，只用了几个整数变量。

易错点与扩展（面试高频考点）

  1. 比较用 < 而非 <=：题目要求 left ≤ right，所以只有严格更小时才必须并入 left；用 <= 会把相等元素误并入，导致切分点偏大、长度不是最小。
  2. maxLeft 更新成 maxAll 而非 nums[i]：并入的是一整段，left 的新最大值应是这段的全局最大值，而不是当前元素本身。
  3. 返回值是 cut + 1：cut 是下标，长度要加一。
  4. 边界与题面保证：题目保证存在合法划分，因此循环结束时 cut + 1 < n，right 一定非空；但若扩展到不保证的版本，需要额外校验。
  5. 另一种解法：预处理后缀最小值 sufMin[i] = min(nums[i..n-1])，再正序维护前缀最大值 preMax，找到第一个满足 preMax <= sufMin[i+1] 的位置即为答案，O(n) 时间、O(n) 空间，思路更直观但多花空间。

C++ 实现

class Solution {
public:
    int partitionDisjoint(vector<int>& nums) {
        int maxLeft = nums[0];  // 已确定属于 left 的最大值
        int maxAll = nums[0];   // 扫描至今的全局最大值
        int cut = 0;            // left 最后一个元素的下标

        for (int i = 1; i < (int)nums.size(); i++) {
            maxAll = max(maxAll, nums[i]);
            if (nums[i] < maxLeft) {
                cut = i;
                maxLeft = maxAll;
            }
        }
        return cut + 1;
    }
};

Python 实现

class Solution:
    def partitionDisjoint(self, nums: List[int]) -> int:
        max_left = nums[0]   # 已确定属于 left 的最大值
        max_all = nums[0]    # 扫描至今的全局最大值
        cut = 0              # left 最后一个元素的下标

        for i in range(1, len(nums)):
            max_all = max(max_all, nums[i])
            if nums[i] < max_left:
                cut = i
                max_left = max_all

        return cut + 1
