题目与约束

给你一个由 n 个元素组成的整数数组 nums 和一个整数 k。

请你找出平均数最大且 长度为 k 的连续子数组，并输出该最大平均数。

任何误差小于 10^-5 的答案都将被视为正确答案。

示例 1：

输入：nums = [1,12,-5,-6,50,3], k = 4
输出：12.75
解释：最大平均数 (12-5-6+50)/4 = 51/4 = 12.75

示例 2：

输入：nums = [5], k = 1
输出：5.00000

提示：

  • n == nums.length
  • 1 <= k <= n <= 10^5
  • -10^4 <= nums[i] <= 10^4

核心不变量

维护一个长度恒为 k 的窗口和 sum，窗口每右移一格就"加进新元素、删掉最左元素"，任何时刻 sum 都对应某个长度为 k 的连续子数组之和。

完整推导

思路推导

  1. 直觉（平均数之比等于和之比）

长度固定为 k，比较平均数的大小等价于比较区间和的大小。所以问题转化为：求所有长度为 k 的连续子数组里，和最大的那个。

  1. 朴素做法（逐个重算）

枚举每个起点都重新累加 k 个元素，共 (n-k+1) 个窗口、每个 O(k)，总复杂度 O(nk)，当 n=10^5、k 很大时会超时。

  1. 破局（滑动窗口复用和）

相邻两个窗口只差"一个进、一个出"。先算第一个窗口 nums[0..k-1] 的和，之后每右移一步：sum += nums[i] - nums[i-k]。这样每个元素只被加一次、减一次，总计 O(n)。

  1. 小例子（示例 1，k = 4）
  • 窗口 [1,12,-5,-6]，和 2
  • 右移：2 + 50 - 1 = 51 → [12,-5,-6,50]，和 51
  • 右移：51 + 3 - 12 = 42 → [-5,-6,50,3]，和 42

最大和 51，平均数 51/4 = 12.75。

  1. 收尾（返回浮点）

最后用 (double) maxSum / k 转换，避免整数除法把小数截断。

Java 实现（findMaxAverage）

class Solution {
    public double findMaxAverage(int[] nums, int k) {
        // 先求第一个长度为 k 的窗口和
        long sum = 0;
        for (int i = 0; i < k; i++) {
            sum += nums[i];
        }
        long maxSum = sum;

        // 窗口整体右移：加入 nums[i]，移除 nums[i-k]
        for (int i = k; i < nums.length; i++) {
            sum += nums[i] - nums[i - k];
            if (sum > maxSum) {
                maxSum = sum;
            }
        }

        // 用 double 做除法保留小数
        return (double) maxSum / k;
    }
}

复杂度

  • 时间：O(n)，初始化窗口 O(k)，之后每次右移 O(1)，共 O(n)。
  • 空间：O(1)，只用到若干累加变量，不随 n 增长。

易错点与扩展（面试高频考点）

  1. 整数除法陷阱：若写成 maxSum / k 且两者都是 int，会向下取整；必须转 double 或先把和声明为浮点。
  2. 溢出风险：n 可达 10^5、元素可达 10^4，窗口和最大约 10^9，接近 int 上限，稳妥起见用 long 存和。
  3. 窗口右移顺序：sum += nums[i] - nums[i-k] 中下标别写错，i-k 才是要移出的最左元素。
  4. k == n 的边界：此时循环一次都不执行，直接返回整段平均数，逻辑需能覆盖。
  5. 扩展：若要求"和不超过某值的最大长度窗口"，就变成变长滑动窗口，用双指针动态收缩，思路相通。

C++ 实现

class Solution {
public:
    double findMaxAverage(vector<int>& nums, int k) {
        long long sum = 0;
        for (int i = 0; i < k; ++i) {
            sum += nums[i];
        }
        long long maxSum = sum;

        for (int i = k; i < (int)nums.size(); ++i) {
            sum += nums[i] - nums[i - k];
            if (sum > maxSum) {
                maxSum = sum;
            }
        }

        return (double)maxSum / k;
    }
};

Python 实现

class Solution:
    def findMaxAverage(self, nums: List[int], k: int) -> float:
        cur = sum(nums[:k])
        best = cur

        for i in range(k, len(nums)):
            cur += nums[i] - nums[i - k]
            if cur > best:
                best = cur

        return best / k
