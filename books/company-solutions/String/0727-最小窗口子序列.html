727. 最小窗口子序列

难度困难核心模式动态规划，记录以每个位置结尾的最短匹配窗口时间复杂度O(n·m)空间复杂度O(m)

题目与约束

🔗 前往力扣原题验证 →

核心不变量

对 s 的每个结束位置 i，都记录能覆盖 t 前缀 t[0..j] 的最短窗口长度；覆盖整个 t 的最小者即答案。

完整推导

思路推导

  1. 暴力为什么慢？ 对每个起点去贪心匹配 t，匹配完再回退压缩窗口，最坏是 O(n²)。n 可达 2×10⁴，会超时。我们希望在一次从左到右的扫描里就得到答案。

  2. 状态定义： 令 dp[i][j] 表示以 s[i] 结尾、且包含 t[0..j] 作为子序列的最短窗口长度。i 表示窗口右端固定在 s[i]。

  3. 转移（分 s[i] 是否等于 t[j]）： - 若 s[i] == t[j]：可以用当前字符去接 t[j]，dp[i][j] = dp[i-1][j-1] + 1；j == 0 时直接 dp[i][0] = 1。 - 若 s[i] != t[j]：当前字符用不上，但窗口右端仍必须停在 i，只能把上一个窗口延伸一格，dp[i][j] = dp[i-1][j] + 1。 - 不可达用 INF 表示。

  4. 取答案： 遍历所有 i，在所有有限的 dp[i][m-1]（m = len(t)）中取最小值，记对应右端为 i，则起点 = i - 长度 + 1。因为转移只用到上一行，所以可用两个一维数组滚动，空间压到 O(m)。

小例子：s = "abcdebdde", t = "bde"。扫描到 i = 4（字符 e）时，dp[4][2] = 4，对应窗口 s[1..4] = "bcde"，就是最优解。

Java 实现（minWindow）

import java.util.Arrays;

class Solution {
    public String minWindow(String s, String t) {
        int n = s.length(), m = t.length();
        final long INF = Long.MAX_VALUE / 2;
        long[] prev = new long[m];          // 上一行 dp
        Arrays.fill(prev, INF);
        long best = INF;
        int bestEnd = -1;                   // 最优窗口的右端点

        for (int i = 0; i < n; i++) {
            long[] cur = new long[m];
            Arrays.fill(cur, INF);
            for (int j = 0; j < m; j++) {
                if (s.charAt(i) == t.charAt(j)) {
                    if (j == 0) {
                        cur[j] = 1;                 // 从当前字符全新开始
                    } else if (prev[j - 1] < INF) {
                        cur[j] = prev[j - 1] + 1;   // 用当前字符接上 t[j]
                    }
                } else {
                    if (prev[j] < INF) {
                        cur[j] = prev[j] + 1;       // 窗口必须延伸到 i
                    }
                }
            }
            if (cur[m - 1] < best) {
                best = cur[m - 1];
                bestEnd = i;
            }
            prev = cur;
        }

        if (bestEnd == -1) return "";
        int start = bestEnd - (int) best + 1;
        return s.substring(start, bestEnd + 1);
    }
}

class Solution {
public:
    string minWindow(string s, string t) {
        int n = s.size(), m = t.size();
        const long long INF = 1e15;
        vector<long long> prev(m, INF);

};

Python 实现

class Solution:
    def minWindow(self, s: str, t: str) -> str:
        n, m = len(s), len(t)
        INF = float('inf')
        prev = [INF] * m
        best = INF
        best_end = -1

        for i in range(n):
            cur = [INF] * m
            for j in range(m):
                if s[i] == t[j]:
                    if j == 0:
                        cur[j] = 1
                    elif prev[j - 1] < INF:
                        cur[j] = prev[j - 1] + 1
                else:
                    if prev[j] < INF:
                        cur[j] = prev[j] + 1
            if cur[m - 1] < best:
                best = cur[m - 1]
                best_end = i
            prev = cur

        if best_end == -1:
            return ""
        start = best_end - best + 1
        return s[start:best_end + 1]

复杂度

  • 时间：O(n·m)，外层遍历 s 的每个位置，内层遍历 t 的每个前缀。
  • 空间：O(m)，只保留上一行与当前行两个长度为 m 的数组。
易错点与扩展（面试高频考点）
  1. 窗口连续、t 只需是子序列：不要误判成“子串（连续）”，t 的字符之间可以隔着别的字符。
  2. s[i] != t[j] 时也要 +1：窗口右端固定为 i，必须把这一格算进长度，不能直接沿用 dp[i-1][j]。
  3. 用 INF 防溢出：不可达状态不要直接参与加法，否则会得到一个“看起来更小”的错误值。
  4. 记录右端点而非只记长度：只有知道最优长度停在哪个 i，才能反推起点。
  5. 边界：t 比 s 长或 s 中缺少 t 的字符时，best 仍为 INF，应返回 ""。
