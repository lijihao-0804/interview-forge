# 1044. 最长重复子串

| 题目信息 | 内容 |
|---|---|
| 难度 | 困难 |
| 核心模式 | 二分答案 + 滚动哈希（Rabin–Karp）判重 |
| 时间复杂度 | O(n log n) |
| 空间复杂度 | O(n) |

## 题目与约束

给你一个字符串 `s` ，考虑其所有 重复子串 ：即 `s` 的（连续）子串，在 `s` 中出现 2 次或更多次。这些出现之间可能存在重叠。

返回 任意一个 可能具有最长长度的重复子串。如果 `s` 不含重复子串，那么答案为 `""` 。

 

示例 1：

```
<strong>输入：</strong>s = "banana"
<strong>输出：</strong>"ana"
```

示例 2：

```
<strong>输入：</strong>s = "abcd"
<strong>输出：</strong>""
```

 

提示：

- `2 <= s.length <= 3 * 104`

- `s` 由小写英文字母组成

[🔗 前往力扣原题验证 →](https://leetcode.cn/problems/longest-duplicate-substring/)

## 核心不变量

> 若存在长度为 `L` 的重复子串，则一定存在长度为 `L-1` 的重复子串（取前者前缀即可）。这种单调性允许对长度二分；每一轮用滚动哈希在 `O(n)` 内判断“长度为 L 的子串是否出现两次”。

## 完整推导

### 思路推导

1. **为什么能二分长度**
   设 `f(L)` = “存在长度为 `L` 的重复子串”。如果能找到长度 `L` 的重复子串，那么它去掉最后一个字符后，前缀仍是长度为 `L-1` 的重复子串，故 `f(L) ⇒ f(L-1)`。这是一个单调的“前缀性质”，可以二分出最大的可行 `L`。

2. **如何快速判断 `f(L)`**
   暴力比较每个长度为 `L` 的窗口是 `O(n·L)` 太慢。用**滚动哈希**：预处理前缀哈希，就能 `O(1)` 算出任意子串的哈希；枚举所有长度为 `L` 的窗口，把哈希放进集合，若某个哈希重复出现，说明存在重复子串。整个过程 `O(n)`。

3. **滚动哈希公式**
   记 `pre[i]` 为 `s[0..i)` 的哈希，`pow[k] = BASE^k`。子串 `s[l..r)` 的哈希为：
   `hash(l, r) = pre[r] - pre[l] * pow[r-l] (mod MOD)`。
   为避免负值，取模后再 `+ MOD` 再取模。

4. **双哈希降低碰撞**
   单个哈希理论上可能被卡。这里同时用两个模数 `1e9+7`、`1e9+9` 计算，把两个哈希拼成一个 `long` 作为集合键，碰撞概率可忽略。

5. **小例子**
   `s = "banana"`。二分尝试 `L=3`：长度为 3 的窗口有 `ban/an/ana/nan/ana`，其中 `ana` 出现两次 → `f(3)` 成立；尝试 `L=4`：`bana/anan/nana` 均不重复 → 不成立。于是最大 `L=3`，返回 `ana`。

### Java 实现（二分 + 双模滚动哈希）

```java
import java.util.HashSet;
import java.util.Set;

class Solution {
    private static final long MOD1 = 1_000_000_007L;
    private static final long MOD2 = 1_000_000_009L;
    private static final long BASE = 131L;

    public String longestDupSubstring(String s) {
        int n = s.length();
        long[] pow1 = new long[n + 1], pow2 = new long[n + 1];
        long[] pre1 = new long[n + 1], pre2 = new long[n + 1];
        pow1[0] = pow2[0] = 1;
        for (int i = 1; i <= n; i++) {
            pow1[i] = pow1[i - 1] * BASE % MOD1;
            pow2[i] = pow2[i - 1] * BASE % MOD2;
        }
        for (int i = 0; i < n; i++) {
            long c = s.charAt(i) - 'a' + 1;
            pre1[i + 1] = (pre1[i] * BASE + c) % MOD1;
            pre2[i + 1] = (pre2[i] * BASE + c) % MOD2;
        }

        int lo = 1, hi = n - 1; // 下界从 1 起：长度 0 无意义
        int bestStart = -1, bestLen = 0;
        while (lo <= hi) {
            int mid = lo + (hi - lo) / 2;
            int st = check(s, mid, pre1, pre2, pow1, pow2);
            if (mid > 0 && st != -1) {   // 长度 mid 可行，尝试更长
                bestLen = mid;
                bestStart = st;
                lo = mid + 1;
            } else {                     // 不可行，缩短长度
                hi = mid - 1;
            }
        }
        return bestLen == 0 ? "" : s.substring(bestStart, bestStart + bestLen);
    }

    // 判断长度为 L 的子串是否重复；若重复返回其中一个起点，否则返回 -1
    private int check(String s, int L, long[] pre1, long[] pre2, long[] pow1, long[] pow2) {
        if (L == 0) {
            return -1;
        }
        int n = s.length();
        Set<Long> seen = new HashSet<>();
        for (int i = 0; i + L <= n; i++) {
            long h1 = (pre1[i + L] - pre1[i] * pow1[L] % MOD1 + MOD1) % MOD1;
            long h2 = (pre2[i + L] - pre2[i] * pow2[L] % MOD2 + MOD2) % MOD2;
            long key = (h1 << 32) | h2;   // 双哈希拼成一个 long
            if (!seen.add(key)) {
                return i;                 // 哈希重复，判定为存在重复子串
            }
        }
        return -1;
    }
}
```

### 复杂度

- 时间：`O(n log n)`。二分共 `O(log n)` 轮，每轮 `check` 线性扫描 `O(n)`，哈希计算均为 `O(1)`。
- 空间：`O(n)`。前缀哈希、幂次数组以及每轮的哈希集合都不超过 `O(n)`。

### 易错点与扩展（面试高频考点）

1. **单调性要成立**：二分的前提是“长可行则短也可行”，别把方向搞反（本解在可行时 `lo = mid + 1` 找更大）。
2. **取模防负数**：`(pre[r] - pre[l] * pow % MOD + MOD) % MOD`，少加 `MOD` 会得到负哈希导致误判。
3. **单哈希碰撞**：面试中最好说明单哈希可能被构造数据卡掉，使用双哈希或随机 `BASE` 降低风险。
4. **空串处理**：完全无重复（如 `"abcd"`）时二分取不到任何可行长度，返回 `""`。
5. **更优解法**：后缀数组 + `LCP` 可做到 `O(n log n)` 甚至 `O(n)`，后缀自动机为 `O(n)`；但滚动哈希是最好写、最稳妥的实现，面试优先。

### C++ 实现

```cpp
#include <string>
#include <vector>
#include <unordered_set>
using namespace std;

class Solution {
public:
    string longestDupSubstring(string s) {
        int n = s.size();
        const long long MOD1 = 1000000007LL, MOD2 = 1000000009LL, BASE = 131LL;
        vector<long long> pow1(n + 1, 1), pow2(n + 1, 1);
        vector<long long> pre1(n + 1, 0), pre2(n + 1, 0);

        for (int i = 1; i <= n; i++) {
            pow1[i] = pow1[i - 1] * BASE % MOD1;
            pow2[i] = pow2[i - 1] * BASE % MOD2;
        }
        for (int i = 0; i < n; i++) {
            long long c = s[i] - 'a' + 1;
            pre1[i + 1] = (pre1[i] * BASE + c) % MOD1;
            pre2[i + 1] = (pre2[i] * BASE + c) % MOD2;
        }

        int lo = 1, hi = n - 1, bestStart = -1, bestLen = 0; // 下界从 1 起
        while (lo <= hi) {
            int mid = lo + (hi - lo) / 2;
            int st = check(n, mid, pre1, pre2, pow1, pow2, MOD1, MOD2);
            if (mid > 0 && st != -1) {
                bestLen = mid;
                bestStart = st;
                lo = mid + 1;
            } else {
                hi = mid - 1;
            }
        }
        return bestLen == 0 ? string("") : s.substr(bestStart, bestLen);
    }

private:
    int check(int n, int L, vector<long long>& pre1, vector<long long>& pre2,
              vector<long long>& pow1, vector<long long>& pow2,
              long long MOD1, long long MOD2) {
        if (L == 0) return -1;
        unordered_set<long long> seen;
        seen.reserve(n * 2);
        for (int i = 0; i + L <= n; i++) {
            long long h1 = (pre1[i + L] - pre1[i] * pow1[L] % MOD1 + MOD1) % MOD1;
            long long h2 = (pre2[i + L] - pre2[i] * pow2[L] % MOD2 + MOD2) % MOD2;
            long long key = (h1 << 32) | h2;
            if (!seen.insert(key).second) {
                return i;
            }
        }
        return -1;
    }
};
```

### Python 实现

```python
class Solution:
    def longestDupSubstring(self, s: str) -> str:
        n = len(s)
        MOD1, MOD2, BASE = 1_000_000_007, 1_000_000_009, 131

        pow1 = [1] * (n + 1)
        pow2 = [1] * (n + 1)
        pre1 = [0] * (n + 1)
        pre2 = [0] * (n + 1)
        for i in range(1, n + 1):
            pow1[i] = pow1[i - 1] * BASE % MOD1
            pow2[i] = pow2[i - 1] * BASE % MOD2
        for i, ch in enumerate(s):
            c = ord(ch) - ord('a') + 1
            pre1[i + 1] = (pre1[i] * BASE + c) % MOD1
            pre2[i + 1] = (pre2[i] * BASE + c) % MOD2

        def check(L: int) -> int:
            if L == 0:
                return -1
            seen = set()
            for i in range(n - L + 1):
                h1 = (pre1[i + L] - pre1[i] * pow1[L]) % MOD1
                h2 = (pre2[i + L] - pre2[i] * pow2[L]) % MOD2
                key = (h1 << 32) | h2     # 双哈希拼成一个整数
                if key in seen:
                    return i
                seen.add(key)
            return -1

        lo, hi = 1, n - 1  # 下界从 1 起：长度 0 恒不可行
        best_start, best_len = -1, 0
        while lo <= hi:
            mid = (lo + hi) // 2
            st = check(mid)
            if mid > 0 and st != -1:
                best_len, best_start = mid, st
                lo = mid + 1
            else:
                hi = mid - 1

        return "" if best_len == 0 else s[best_start:best_start + best_len]
```
