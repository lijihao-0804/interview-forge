516. 最长回文子序列

难度中等核心模式区间动态规划（两端字符向内收缩）时间复杂度O(n²)空间复杂度O(n²)

题目与约束

给你一个字符串 s ，找出其中最长的回文子序列，并返回该序列的长度。

子序列定义为：不改变剩余字符顺序的情况下，删除某些字符或者不删除任何字符形成的一个序列。

示例 1：

输入：s = "bbbab"
输出：4
解释：一个可能的最长回文子序列为 "bbbb" 。

示例 2：

输入：s = "cbbd"
输出：2
解释：一个可能的最长回文子序列为 "bb" 。

提示：

  • 1 <= s.length <= 1000

  • s 仅由小写英文字母组成

🔗 前往力扣原题验证 →

核心不变量

dp[i][j] 只描述子串 s[i..j] 的最长回文子序列长度，其值只由「两端字符是否相等」以及更短的子区间 dp[i+1][j-1]、dp[i+1][j]、dp[i][j-1] 决定，与区间外部字符无关。

完整推导

思路推导

  1. 直觉与痛点（子串 vs 子序列）

子序列允许跳过字符，所以不能像"回文子串"那样只枚举中心向两边扩。但回文的本质是"两端对称"，因此可以从区间的角度思考：只关注当前考察的区间 s[i..j]，两端如何配对。

  1. 破局思路（定义区间 DP）

令 dp[i][j] 表示子串 s[i..j] 的最长回文子序列长度。看区间两端字符 s[i] 与 s[j]：

  • 若 s[i] == s[j]，这两个字符可以一起放进回文的两端，长度比内部区间多 2：dp[i][j] = dp[i+1][j-1] + 2。
  • 若 s[i] != s[j]，它们不可能同时在回文两端，至少舍弃一个：dp[i][j] = max(dp[i+1][j], dp[i][j-1])。

边界：单个字符 dp[i][i] = 1。

以 s = "bbbab" 为例：s[0]='b' 与 s[4]='b' 相等，故 dp[0][4] = dp[1][3] + 2；内部 "bba" 的最长回文子序列是 "bb"，长度 2，于是 dp[0][4] = 4，对应 "bbbb"。

  1. 关键追问（递推顺序为什么是从后往前？）

dp[i][j] 依赖 dp[i+1][...]（更靠右的起点）和 dp[...][j-1]（更靠左的终点），也就是依赖"更短"的区间。因此外层 i 从 n-1 递减到 0，内层 j 从 i+1 递增，保证所有子区间先算完。

Java 实现（区间 DP）

class Solution {
    public int longestPalindromeSubseq(String s) {
        int n = s.length();
        // dp[i][j] 表示子串 s[i..j] 的最长回文子序列长度
        int[][] dp = new int[n][n];

        // 单个字符本身是回文，长度 1
        for (int i = 0; i < n; i++) {
            dp[i][i] = 1;
        }

        // 按区间从短到长递推：i 从右往左，j 从左往右
        for (int i = n - 1; i >= 0; i--) {
            for (int j = i + 1; j < n; j++) {
                if (s.charAt(i) == s.charAt(j)) {
                    // 两端字符相同，一起套在回文外层
                    dp[i][j] = dp[i + 1][j - 1] + 2;
                } else {
                    // 两端字符不同，舍弃其中一端
                    dp[i][j] = Math.max(dp[i + 1][j], dp[i][j - 1]);
                }
            }
        }

        return dp[0][n - 1];
    }
}

C++ 实现

#include <string>
#include <vector>
#include <algorithm>
using namespace std;

class Solution {
public:
    int longestPalindromeSubseq(string s) {
        int n = s.size();
        // dp[i][j]：子串 s[i..j] 的最长回文子序列长度
        vector<vector<int>> dp(n, vector<int>(n, 0));
        for (int i = 0; i < n; i++) {
            dp[i][i] = 1;  // 单字符回文
        }
        // 区间从短到长：i 递减、j 递增
        for (int i = n - 1; i >= 0; i--) {
            for (int j = i + 1; j < n; j++) {
                if (s[i] == s[j]) {
                    dp[i][j] = dp[i + 1][j - 1] + 2;   // 两端配对
                } else {
                    dp[i][j] = max(dp[i + 1][j], dp[i][j - 1]); // 舍弃一端
                }
            }
        }
        return dp[0][n - 1];
    }
};

Python 实现

class Solution:
    def longestPalindromeSubseq(self, s: str) -> int:
        n = len(s)
        # dp[i][j]：子串 s[i..j] 的最长回文子序列长度
        dp = [[0] * n for _ in range(n)]
        for i in range(n):
            dp[i][i] = 1  # 单字符回文

        # 区间从短到长：i 从右往左，j 从左往右
        for i in range(n - 1, -1, -1):
            for j in range(i + 1, n):
                if s[i] == s[j]:
                    dp[i][j] = dp[i + 1][j - 1] + 2  # 两端配对
                else:
                    dp[i][j] = max(dp[i + 1][j], dp[i][j - 1])  # 舍弃一端
        return dp[0][n - 1]

复杂度

  • 时间：O(n²)。状态数为区间个数 O(n²)，每个状态 O(1) 转移。
  • 空间：O(n²)。需要二维 DP 表；由于每行只依赖下一行与当前行，可优化到 O(n) 滚动数组。
易错点与扩展（面试高频考点）
  1. 和下标的越界陷阱：当 j == i+1 且 s[i] == s[j] 时，用到 dp[i+1][j-1] = dp[i+1][i]，这是一个"空区间"。二维数组默认 0，恰好得到 0 + 2 = 2，正确；但在滚动数组写法里要显式处理，避免读到脏值。
  2. 和"最长回文子串"（LeetCode 5）的区别：子串必须连续，子序列可以跳字符。本题不能套"中心扩散"，必须用区间 DP。
  3. 递推方向写反：若 i 从左往右、j 也从小到大，会用到尚未计算的 dp[i+1][j-1]，得错解。务必 i 递减。
  4. 空间优化（进阶）：只保留两行，dp[j] 更新时需要旧的 dp[j-1]（即 dp[i+1][j-1]），用一个变量暂存 prev 即可降到 O(n)。
  5. 边界提示：题目保证 s 非空（1 <= s.length），若自行扩展可先对空串返回 0。
