# 1312. 让字符串成为回文串的最少插入次数

| 题目信息 | 内容 |
|---|---|
| 难度 | 困难 |
| 核心模式 | 区间 DP（等价于求最长回文子序列） |
| 时间复杂度 | O(n²) |
| 空间复杂度 | O(n²) |

## 题目与约束

给你一个字符串 `s` ，每一次操作你都可以在字符串的任意位置插入任意字符。

请你返回让 `s` 成为回文串的 最少操作次数 。

「回文串」是正读和反读都相同的字符串。

 

示例 1：

```
<strong>输入：</strong>s = "zzazz"
<strong>输出：</strong>0
<strong>解释：</strong>字符串 "zzazz" 已经是回文串了，所以不需要做任何插入操作。
```

示例 2：

```
<strong>输入：</strong>s = "mbadm"
<strong>输出：</strong>2
<strong>解释：</strong>字符串可变为 "mbdadbm" 或者 "mdbabdm" 。
```

示例 3：

```
<strong>输入：</strong>s = "leetcode"
<strong>输出：</strong>5
<strong>解释：</strong>插入 5 个字符后字符串变为 "leetcodocteel" 。
```

 

提示：

- `1 <= s.length <= 500`

- `s` 中所有字符都是小写字母。

[🔗 前往力扣原题验证 →](https://leetcode.cn/problems/minimum-insertion-steps-to-make-a-string-palindrome/)

## 核心不变量

> `dp[i][j]` 表示把子串 `s[i..j]` 变成回文串所需的最少插入次数，它只由更短的子区间 `dp[i+1][j]`、`dp[i][j-1]`、`dp[i+1][j-1]` 决定。

## 完整推导

### 思路推导

1. **从两端看问题**：想让 `s[i..j]` 变为回文，关键看首尾两个字符。
   - 若 `s[i] == s[j]`，它们天生配对，问题缩小为内部 `s[i+1..j-1]`，不产生额外插入：`dp[i][j] = dp[i+1][j-1]`。
   - 若 `s[i] != s[j]`，无论插入哪个字符，都至少要为其中一端「补」一个对手。补在 `j` 右侧与 `s[i]` 配对后，剩下 `s[i+1..j]`；或补在 `i` 左侧与 `s[j]` 配对后，剩下 `s[i..j-1]`。取两者较小再加 1：`dp[i][j] = 1 + min(dp[i+1][j], dp[i][j-1])`。

2. **小例子**：`s = "mbadm"`，下标 0..4。
   - `s[0]='m'`、`s[4]='m'` 相等 → `dp[0][4] = dp[1][3]`；
   - `s[1]='b'`、`s[3]='d'` 不等 → `dp[1][3] = 1 + min(dp[2][3], dp[1][2])`；
   - `s[2]='a'`，`dp[2][3]`（"ad"）与 `dp[1][2]`（"ba"）都需要 1 次插入；
   - 于是 `dp[1][3] = 2`，`dp[0][4] = 2`，与示例一致。

3. **填表顺序**：状态依赖长度更短的区间，所以按区间长度 `len` 从 2 到 n 递增地填。边界 `dp[i][i] = 0`（单个字符已是回文）。

4. **等价视角**：最少插入次数 = `n - （最长回文子序列长度）`。因为可以保留最长的回文子序列不动，其余 `n - LPS` 个字符各自都能通过与对称位置配对来补全。两种写法结果相同，这里用更直接的区间 DP。

### Java 实现（区间 DP）

```java
class Solution {
    public int minInsertions(String s) {
        int n = s.length();
        if (n <= 1) {
            return 0;
        }
        // dp[i][j]：让 s[i..j] 成为回文串的最少插入次数
        int[][] dp = new int[n][n];
        for (int len = 2; len <= n; len++) {
            for (int i = 0; i + len - 1 < n; i++) {
                int j = i + len - 1;
                if (s.charAt(i) == s.charAt(j)) {
                    dp[i][j] = dp[i + 1][j - 1];        // 首尾配对，收缩到内部
                } else {
                    dp[i][j] = 1 + Math.min(dp[i + 1][j], dp[i][j - 1]);
                }
            }
        }
        return dp[0][n - 1];
    }
}
```

### 复杂度

- 时间：O(n²)，区间长度与起点两层循环，状态总数为 n²/2 级别，每次 O(1) 转移。
- 空间：O(n²)，使用二维 DP 表；由于只依赖更短区间，可用滚动或一维优化进一步降低，但本题 n ≤ 500，二维足够。

### 易错点与扩展（面试高频考点）

1. **长度 2 的边界**：`len = 2` 且首尾相等时，`dp[i+1][j-1]` 对应空区间（`i+1 > j-1`），数组默认值 0 正好代表空串，无需特判。
2. **填表顺序**：必须按 `len` 从小到大填，否则依赖的子状态还没算出来。
3. **与「最长回文子序列」互转**：答案 = `n - LPS(s)`。面试常以此为切入点，要求你先求 LPS 再返回差值。
4. **空间优化**：一维滚动时注意 `dp[i+1][j-1]` 会被覆盖，需要临时变量保存「上一轮的左上角」。
5. **区分同类题**：本题是「插入」；若改成「删除使回文」最少删除次数，答案同样是 `n - LPS`；若要求「替换」，则是另一个经典区间 DP。

## 力扣原题

[1312. 让字符串成为回文串的最少插入次数](https://leetcode.cn/problems/minimum-insertion-steps-to-make-a-string-palindrome/)

### C++ 实现

```cpp
class Solution {
public:
    int minInsertions(string s) {
        int n = s.size();
        if (n <= 1) return 0;
        vector<vector<int>> dp(n, vector<int>(n, 0));
        for (int len = 2; len <= n; ++len) {
            for (int i = 0; i + len - 1 < n; ++i) {
                int j = i + len - 1;
                if (s[i] == s[j]) {
                    dp[i][j] = dp[i + 1][j - 1];
                } else {
                    dp[i][j] = 1 + min(dp[i + 1][j], dp[i][j - 1]);
                }
            }
        }
        return dp[0][n - 1];
    }
};
```

### Python 实现

```python
class Solution:
    def minInsertions(self, s: str) -> int:
        n = len(s)
        if n <= 1:
            return 0
        dp = [[0] * n for _ in range(n)]
        for length in range(2, n + 1):
            for i in range(n - length + 1):
                j = i + length - 1
                if s[i] == s[j]:
                    dp[i][j] = dp[i + 1][j - 1]
                else:
                    dp[i][j] = 1 + min(dp[i + 1][j], dp[i][j - 1])
        return dp[0][n - 1]
```
