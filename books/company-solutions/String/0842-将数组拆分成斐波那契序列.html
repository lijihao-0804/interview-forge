题目信息 内容
难度 中等
核心模式 回溯：枚举前两个数，之后每个数必须等于前两数之和
时间复杂度 O(n·log²C)（n 为串长，C 为数值上界，实际远小于指数）
空间复杂度 O(n)

题目与约束

给定一个数字字符串 num，比如 "123456579"，我们可以将它分成「斐波那契式」的序列 [123, 456, 579]。

形式上，斐波那契式序列是一个非负整数列表 f，且满足：

  • 0 <= f[i] < 2^31（也就是说，每个整数都符合 32 位有符号整数类型）
  • f.length >= 3
  • 对于所有的 0 <= i < f.length - 2，都有 f[i] + f[i + 1] = f[i + 2]

另外，请注意，将字符串拆分成小块时，每个块的数字一定不要以零开头，除非这个块是数字 0 本身。

返回从 num 拆分出来的任意一组斐波那契式的序列块，如果不能拆分则返回 []。

示例 1：

输入：num = "1101111"
输出：[11,0,11,11]
解释：输出 [110,1,111] 也可以。

示例 2：

输入: num = "112358130"
输出: []
解释: 无法拆分。

示例 3：

输入："0123"
输出：[]
解释：每个块的数字不能以零开头，因此 "01"，"2"，"3" 不是有效答案。

提示：

  • 1 <= num.length <= 200
  • num 中只含有数字

核心不变量

一旦确定了前两个数 f[0]、f[1]，后面每一个数都被唯一确定为前两数之和，只需逐个把字符串前缀按这个和切走；长度不足 3 或切不完则回溯。

完整推导

思路推导

  1. 为什么是回溯

切法的自由度只在前两个数：第一个数可以取 num 的任意非空前缀，第二个数接着取一段。前两个定了，第三个必须是二者之和，之后的数全被链式确定下来。因此我们只需要在「第一个数」「第二个数」上做穷举，再用「后续必须等于前两数之和」来剪枝验证。

  1. 回溯框架

用 idx 表示当前要切的位置，用一个列表 res 装已切出的数。每次从 idx 开始尝试取长度 1、2、…… 的前缀作为下一个数 cur：

  • 若当前字符是 '0'，只允许单独成数 0，不能再往后接（否则出现前导零）。
  • 若 cur > 2^31−1，继续加长只会更大，直接 break。
  • 若 res 已有至少两个数，令 s = res[-1] + res[-2]：cur > s 说明太长，break；cur < s 说明还不够长，continue 加长；cur == s 才能继续。

切完整个串且 res.size() >= 3，即找到答案。

  1. 小例子（num = "1101111"）

取 f0 = 11，f1 = 0，则 f2 = 11（切出 "11"），f3 = 0 + 11 = 11（切出 "11"），恰好用完，得到 [11,0,11,11]。另一条路径 f0 = 110, f1 = 1 得到 [110,1,111]，同样合法，题目接受任意一组。

Java 实现（splitIntoFibonacci）

import java.util.ArrayList;
import java.util.List;

class Solution {
    public List<Integer> splitIntoFibonacci(String num) {
        List<Integer> res = new ArrayList<>();
        backtrack(num, 0, res);
        return res;
    }

    private boolean backtrack(String num, int idx, List<Integer> res) {
        // 已切完整个字符串，且满足至少 3 个数才算成功
        if (idx == num.length()) {
            return res.size() >= 3;
        }

        long cur = 0;
        for (int i = idx; i < num.length(); i++) {
            // 前导零：'0' 只能单独作为数字 0，不能再接更多位
            if (num.charAt(idx) == '0' && i > idx) {
                break;
            }
            cur = cur * 10 + (num.charAt(i) - '0');
            // 超过 32 位有符号上界，继续加长只会更大
            if (cur > Integer.MAX_VALUE) {
                break;
            }
            int size = res.size();
            if (size >= 2) {
                long sum = (long) res.get(size - 1) + res.get(size - 2);
                if (cur > sum) {
                    break;      // 太长了，后面只会更大
                }
                if (cur < sum) {
                    continue;   // 还不够长，继续多取一位
                }
                // cur == sum 才继续往下切
            }
            res.add((int) cur);
            if (backtrack(num, i + 1, res)) {
                return true;
            }
            res.remove(res.size() - 1); // 回溯
        }
        return false;
    }
}

复杂度

  • 时间：回溯的分支由前两个数的切法决定，每个位置最多取 10 位有效数字（受 2^31 限制），实际搜索规模很小，约为 O(n·log²C)，n ≤ 200 时完全够用。
  • 空间：O(n)。递归深度与 res 长度都不超过字符串长度。

易错点与扩展（面试高频考点）

  1. 前导零规则：'0' 只能单独成数，出现 "01"、"00" 这类切法一律非法。写成 if (num[idx] == '0' && i > idx) break; 最简洁。
  2. 32 位上界：每个数必须 < 2^31。用 long 边累加边判断，超过即 break，避免溢出或超长解析异常。
  3. 至少三个数：即使整串能被切成 [a, b]，也不合法；结束条件必须是 res.size() >= 3。
  4. 剪枝的有序性：cur > sum 时 break，cur < sum 时 continue，因为加长前缀得到的数单调变大，这个单调性保证了剪枝正确。
  5. 扩展：可用「先定长度」或「字符串大数」版本处理超过 64 位的序列，但本题限制了 32 位，直接用整数即可。

842. 将数组拆分成斐波那契序列

C++ 实现

class Solution {
public:
    vector<int> splitIntoFibonacci(string num) {
        vector<int> res;
        backtrack(num, 0, res);
        return res;
    }

private:
    bool backtrack(const string& num, int idx, vector<int>& res) {
        if (idx == (int) num.size()) return res.size() >= 3;

        long long cur = 0;
        for (int i = idx; i < (int) num.size(); i++) {
            if (num[idx] == '0' && i > idx) break;   // 前导零
            cur = cur * 10 + (num[i] - '0');
            if (cur > INT_MAX) break;                // 超过 32 位上界
            if (res.size() >= 2) {
                long long s = (long long) res[res.size() - 1] + res[res.size() - 2];
                if (cur > s) break;
                if (cur < s) continue;
            }
            res.push_back((int) cur);
            if (backtrack(num, i + 1, res)) return true;
            res.pop_back();
        }
        return false;
    }
};

Python 实现

class Solution:
    def splitIntoFibonacci(self, num: str) -> list[int]:
        res = []
        n = len(num)

        def backtrack(idx: int) -> bool:
            if idx == n:
                return len(res) >= 3

            cur = 0
            for i in range(idx, n):
                if num[idx] == '0' and i > idx:   # 前导零
                    break
                cur = cur * 10 + (ord(num[i]) - 48)
                if cur > 2**31 - 1:               # 超过 32 位上界
                    break
                if len(res) >= 2:
                    s = res[-1] + res[-2]
                    if cur > s:
                        break
                    if cur < s:
                        continue
                res.append(cur)
                if backtrack(i + 1):
                    return True
                res.pop()
            return False

        backtrack(0)
        return res
