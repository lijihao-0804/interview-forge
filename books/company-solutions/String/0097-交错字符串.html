题目信息 内容
难度 中等
核心模式 二维动态规划（按 s1、s2 已用长度定状态）
时间复杂度 O(m·n)
空间复杂度 O(n)（滚动数组优化）

题目与约束

给定三个字符串 s1、s2、s3，请你验证 s3 是否由 s1 和 s2 交错 组成。

两个字符串 s 和 t 交错 的定义与过程如下，其中每个字符串都会被分割成若干 非空 子字符串：

  • s = s1 + s2 + ... + sn
  • t = t1 + t2 + ... + tm
  • |n - m| <= 1
  • 交错 是 s1 + t1 + s2 + t2 + s3 + t3 + ... 或者 t1 + s1 + t2 + s2 + t3 + s3 + ...

注意： a + b 意味着字符串 a 和 b 连接。

示例 1：

输入：s1 = "aabcc", s2 = "dbbca", s3 = "aadbbcbcac"
输出：true

示例 2：

输入：s1 = "aabcc", s2 = "dbbca", s3 = "aadbbbaccc"
输出：false

示例 3：

输入：s1 = "", s2 = "", s3 = ""
输出：true

提示：

  • 0 <= s1.length, s2.length <= 100
  • 0 <= s3.length <= 200
  • s1、s2 和 s3 都由小写英文字母组成

进阶： 您能否仅使用 O(s2.length) 额外的内存空间来解决它？

核心不变量

dp[i][j] 表示「s1 的前 i 个字符 + s2 的前 j 个字符」能否交错拼出「s3 的前 i+j 个字符」；当前匹配到 s3 的第 i+j 位，只可能来自 s1[i-1] 或 s2[j-1]。

完整推导

思路推导

  1. 直觉与痛点（暴力回溯为什么慢？）

最直接的想法是双指针加回溯：每一步决定从 s1 还是 s2 取一个字符去匹配 s3。但两条路都合法时要尝试两种，指数级重复计算。关键观察：只要 s1 用了 i 个、s2 用了 j 个，s3 必然用到了 i+j 个，状态完全由 (i, j) 决定，天然适合 DP。

  1. 状态与转移

dp[i][j] = true 当且仅当下面任一成立：

  • dp[i-1][j] 为真且 s1[i-1] == s3[i+j-1]（第 i+j 位取自 s1）
  • dp[i][j-1] 为真且 s2[j-1] == s3[i+j-1]（第 i+j 位取自 s2）
  1. 小例子（s1="aab", s2="dbb" 片段）

想象一张 (m+1)×(n+1) 的表格，dp[0][0]=true，第一行只靠自己能否匹配 s2 前缀、第一列只看 s1 前缀，之后每个格子从「上」「左」两个方向得到。

  1. 空间优化（进阶要求）

每个 dp[i][j] 只依赖上一行 dp[i-1][j]（上）与本行左侧 dp[i][j-1]（左），因此可压成一维：从左到右更新时，dp[j] 尚未更新代表「上」，dp[j-1] 已更新代表「左」。

Java 实现（isInterleave）

class Solution {
    public boolean isInterleave(String s1, String s2, String s3) {
        int m = s1.length(), n = s2.length();
        if (m + n != s3.length()) return false; // 长度不符直接 false

        // dp[j] 表示当前行（s1 已用 i 个）下，s2 已用 j 个能否匹配
        boolean[] dp = new boolean[n + 1];
        dp[0] = true;
        // 初始化第 0 行：s1 一个没用，全靠 s2 前缀
        for (int j = 1; j <= n; j++) {
            dp[j] = dp[j - 1] && s2.charAt(j - 1) == s3.charAt(j - 1);
        }

        for (int i = 1; i <= m; i++) {
            // 第 0 列：s2 一个没用，全靠 s1 前缀
            dp[0] = dp[0] && s1.charAt(i - 1) == s3.charAt(i - 1);
            for (int j = 1; j <= n; j++) {
                char c = s3.charAt(i + j - 1);
                // dp[j]（尚未更新）代表上一行即 i-1；dp[j-1]（已更新）代表本行左侧
                boolean fromS1 = dp[j] && s1.charAt(i - 1) == c;
                boolean fromS2 = dp[j - 1] && s2.charAt(j - 1) == c;
                dp[j] = fromS1 || fromS2;
            }
        }
        return dp[n];
    }
}

复杂度

  • 时间：O(m·n)，二维状态各计算一次，每次 O(1)。
  • 空间：O(n)，只保留一行滚动数组，满足进阶要求 O(s2.length)。

易错点与扩展（面试高频考点）

  1. 先判长度：s1.length + s2.length != s3.length 必须立刻返回 false，否则下标会越界。
  2. 滚动更新顺序：内层 j 必须从小到大，且先算 fromS1（用旧 dp[j]）再算 fromS2（用已更新的 dp[j-1]），顺序写反逻辑就崩。
  3. dp[0] 每行要重置：进入新的一行时必须用 dp[0] = dp[0] && s1[i-1]==s3[i-1] 更新首列，不能漏。
  4. 空串边界：s1、s2、s3 全空时返回 true；只有一个是空串时，退化为「单串匹配」。
  5. DFS + 记忆化：也可写成 memo[i][j] 的记忆化搜索，等价于本题 DP，面试可二选一。

C++ 实现

class Solution {
public:
    bool isInterleave(string s1, string s2, string s3) {
        int m = s1.size(), n = s2.size();
        if (m + n != (int)s3.size()) return false;

        vector<bool> dp(n + 1, false);
        dp[0] = true;
        for (int j = 1; j <= n; ++j) {
            dp[j] = dp[j - 1] && s2[j - 1] == s3[j - 1];
        }
        for (int i = 1; i <= m; ++i) {
            dp[0] = dp[0] && s1[i - 1] == s3[i - 1];
            for (int j = 1; j <= n; ++j) {
                char c = s3[i + j - 1];
                bool fromS1 = dp[j] && s1[i - 1] == c;
                bool fromS2 = dp[j - 1] && s2[j - 1] == c;
                dp[j] = fromS1 || fromS2;
            }
        }
        return dp[n];
    }
};

Python 实现

class Solution:
    def isInterleave(self, s1: str, s2: str, s3: str) -> bool:
        m, n = len(s1), len(s2)
        if m + n != len(s3):
            return False

        dp = [False] * (n + 1)
        dp[0] = True
        for j in range(1, n + 1):
            dp[j] = dp[j - 1] and s2[j - 1] == s3[j - 1]

        for i in range(1, m + 1):
            dp[0] = dp[0] and s1[i - 1] == s3[i - 1]
            for j in range(1, n + 1):
                c = s3[i + j - 1]
                from_s1 = dp[j] and s1[i - 1] == c
                from_s2 = dp[j - 1] and s2[j - 1] == c
                dp[j] = from_s1 or from_s2

        return dp[n]
