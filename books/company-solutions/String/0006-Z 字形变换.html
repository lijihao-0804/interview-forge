6. Z 字形变换

题目与约束

将一个给定字符串 s 根据给定的行数 numRows ，以从上往下、从左到右进行 Z 字形排列。

比如输入字符串为 "PAYPALISHIRING" 行数为 3 时，排列如下：

P   A   H   N
A P L S I I G
Y   I   R

之后，你的输出需要从左往右逐行读取，产生出一个新的字符串，比如："PAHNAPLSIIGYIR"。

请你实现这个将字符串进行指定行数变换的函数：

string convert(string s, int numRows);

示例 1：

输入：s = "PAYPALISHIRING", numRows = 3
输出："PAHNAPLSIIGYIR"

示例 2：

输入：s = "PAYPALISHIRING", numRows = 4
输出："PINALSIGYAHRPI"
解释：
P I N
A L S I G
Y A H R
P I

示例 3：

输入：s = "A", numRows = 1
输出："A"

提示：

  • 1 <= s.length <= 1000

  • s 由英文字母（小写和大写）、',' 和 '.' 组成

  • 1 <= numRows <= 1000

核心不变量

字符的落点行号沿着 0 → numRows-1 → 0 往复折返，每 2·numRows-2 个字符走完一个完整周期。

完整推导

思路推导

  1. 直觉与痛点（要不要真的画出一张二维表？）

最直白的做法是开一个 numRows × n 的二维字符矩阵，按照 Z 字的走向把字符填进去，最后逐行扫描非空格子。这样做当然能做对，但要预先知道列数、处理大量空格，既费空间又容易写错下标。

痛点：真正有用的信息只有一个——每个字符应该落在第几行。一旦行号确定，同一条行内的相对顺序天然就是原字符串顺序。

  1. 破局思路（用"行缓冲 + 方向指针"一行行接字符）

与其画整张表，不如准备 numRows 个字符串缓冲（StringBuilder / string）。维护两个变量：

  • row：当前字符要放到第几行；
  • step：当前行进方向，+1 表示向下、-1 表示向上。

每读入一个字符，就追加到 rows[row]，然后更新方向：

  • 走到第 0 行时，方向改为向下（step = +1）；
  • 走到第 numRows-1 行时，方向改为向上（step = -1）；
  • 其余行保持原方向继续走，row += step。

以 numRows = 3 为例，行号序列是 0,1,2,1,0,1,2,1,...，正是"折返跑"的轨迹。

  1. 关键追问（必须单独处理的边界）
  • numRows == 1：此时"向上/向下"没有意义，方向会原地打转导致死循环或重复，必须直接返回 s。
  • s.length() <= numRows：每个字符都独占一行，结果就是原串，可提前返回，省掉分配。
  • 另一种数学写法：利用周期 cycle = 2·numRows-2，第 i 个字符的行号可由 i % cycle 与 cycle - i % cycle 直接算出。首行、末行每个周期只有 1 个字符，中间行每个周期有 2 个字符。这种写法省掉了方向变量，但可读性不如模拟。

Java 实现（按行模拟）

class Solution {
    public String convert(String s, int numRows) {
        // 只有一行，或字符数不超过行数时，Z 字形退化为原串
        if (numRows == 1 || s.length() <= numRows) {
            return s;
        }

        // 每一行准备一个缓冲区，按行收集字符
        StringBuilder[] rows = new StringBuilder[numRows];
        for (int i = 0; i < numRows; i++) {
            rows[i] = new StringBuilder();
        }

        int row = 0;   // 当前字符所在行
        int step = 1;  // 行进方向：+1 向下，-1 向上

        for (char c : s.toCharArray()) {
            rows[row].append(c);          // 把字符放进它该去的行
            if (row == 0) {               // 触顶，接下来向下走
                step = 1;
            } else if (row == numRows - 1) { // 触底，接下来向上走
                step = -1;
            }
            row += step;                  // 移动到下一行
        }

        // 从上到下拼接所有行即为答案
        StringBuilder res = new StringBuilder();
        for (StringBuilder sb : rows) {
            res.append(sb);
        }
        return res.toString();
    }
}

C++ 实现

#include <string>
#include <vector>
using namespace std;

class Solution {
public:
    string convert(string s, int numRows) {
        // 单行或字符数不超过行数时，直接返回原串
        if (numRows == 1 || (int)s.size() <= numRows) return s;

        vector<string> rows(numRows);   // 每行一个缓冲区
        int row = 0, step = 1;          // 当前行与方向

        for (char c : s) {
            rows[row] += c;
            if (row == 0) step = 1;             // 触顶转向下
            else if (row == numRows - 1) step = -1; // 触底转向上
            row += step;
        }

        string res;
        for (const string& r : rows) res += r;  // 逐行拼接
        return res;
    }
};

Python 实现

class Solution:
    def convert(self, s: str, numRows: int) -> str:
        # 单行或字符数不超过行数时，直接返回原串
        if numRows == 1 or numRows >= len(s):
            return s

        rows = [''] * numRows          # 每行一个字符串缓冲
        row, step = 0, 1               # 当前行与方向

        for ch in s:
            rows[row] += ch
            if row == 0:
                step = 1               # 触顶转向下
            elif row == numRows - 1:
                step = -1              # 触底转向上
            row += step

        return ''.join(rows)           # 逐行拼接

复杂度

  • 时间：O(n)，其中 n = s.length()。每个字符只被追加一次，最后拼接所有行也只需再扫一遍全部字符，总操作数与字符数成正比。
  • 空间：O(n)。行缓冲区合计恰好存放 n 个字符；除输出本身外没有额外的二维矩阵开销。
易错点与扩展（面试高频考点）
  1. 忘了 numRows == 1 的短路：这是最经典的翻车点。方向在第一行既判定"向下"又永远到不了最后一行，若没有提前返回，代码逻辑会混乱甚至原地打转。
  2. 方向切换的时机：应在"把字符放进当前行之后、移动之前"判断是否触顶/触底；顺序写反会导致首尾行少放或多放字符。
  3. 输出必须按行拼接：Z 字形是"纵向排布、横向读取"，最终答案是 rows[0] + rows[1] + ...，而不是按原顺序输出。
  4. 面试追问——周期公式：能否不模拟、直接计算每个字符的行号？答：cycle = 2*numRows-2，令 r = i % cycle，则行号为 r < numRows ? r : cycle - r，再按行收集即可，时间 O(n)、无需方向变量。
  5. numRows 很大而字符串很短：如 numRows = 1000、s 只有 3 个字符，提前返回 s 可避免创建上千个空缓冲区。
