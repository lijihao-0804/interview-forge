# 91. 解码方法

| 题目信息 | 内容 |
|---|---|
| 难度 | 中等 |
| 核心模式 | 线性 DP（一维状态，单字符/双字符转移） |
| 时间复杂度 | O(n) |
| 空间复杂度 | O(n) |

## 题目与约束

一条包含字母 `A-Z` 的消息通过以下映射进行了 编码 ：

`"1" -> 'A'
"2" -> 'B'
...
"25" -> 'Y'
"26" -> 'Z'`

然而，在 解码 已编码的消息时，你意识到有许多不同的方式来解码，因为有些编码被包含在其它编码当中（`"2"` 和 `"5"` 与 `"25"`）。

例如，`"11106"` 可以映射为：

- `"AAJF"` ，将消息分组为 `(1, 1, 10, 6)`

- `"KJF"` ，将消息分组为 `(11, 10, 6)`

- 消息不能分组为  `(1, 11, 06)` ，因为 `"06"` 不是一个合法编码（只有 "6" 是合法的）。

注意，可能存在无法解码的字符串。

给你一个只含数字的 非空 字符串 `s` ，请计算并返回 解码 方法的 总数 。如果没有合法的方式解码整个字符串，返回 `0`。

题目数据保证答案肯定是一个 32 位 的整数。

 

示例 1：

```
<strong>输入：</strong>s = "12"
<strong>输出：</strong>2
<strong>解释：</strong>它可以解码为 "AB"（1 2）或者 "L"（12）。
```

示例 2：

```
<strong>输入：</strong>s = "226"
<strong>输出：</strong>3
<strong>解释：</strong>它可以解码为 "BZ" (2 26), "VF" (22 6), 或者 "BBF" (2 2 6) 。
```

示例 3：

```
<strong>输入：</strong>s = "06"
<strong>输出：</strong>0
<strong>解释：</strong>"06" 无法映射到 "F" ，因为存在前导零（"6" 和 "06" 并不等价）。
```

 

提示：

- `1 <= s.length <= 100`

- `s` 只包含数字，并且可能包含前导零。

[🔗 前往力扣原题验证 →](https://leetcode.cn/problems/decode-ways/)

## 核心不变量

> `dp[i]` 表示前 `i` 个字符的解码方案数；它只由 `dp[i-1]`（末位单字符可解）与 `dp[i-2]`（末两位可组成 10~26）两处转移而来。

## 完整推导

### 思路推导

1. **直觉与痛点（枚举所有切分是指数级）**

   把字符串切成若干 1~2 位的片段，每段必须是 `1~26` 且无前导零。切分方式随长度指数增长，不能枚举。但注意到：**处理到第 `i` 位时，只关心"最后一步是取 1 位还是 2 位"**，这正是线性 DP 的信号。

2. **破局思路（定义状态与转移）**

   令 `dp[i]` 为前缀 `s[0..i)` 的解码方案数，`dp[0] = 1`（空串视为一种方案）。考虑第 `i` 位的来源：

   - **单字符**：若 `s[i-1] != '0'`，它可以单独解码（`1~9`），贡献 `dp[i] += dp[i-1]`；
   - **双字符**：若 `i >= 2` 且 `s[i-2..i)` 组成的数在 `10 ~ 26` 之间，则末两位可整体解码，贡献 `dp[i] += dp[i-2]`。

   以 `s = "226"` 为例：`dp[0]=1`；`dp[1]=1`（`"2"`）；`dp[2]=dp[1]+dp[0]=2`（`"2|2"`、`"22"`）；`dp[3]=dp[2]+dp[1]=3`（`"2|2|6"`、`"22|6"`、`"2|26"`），结果为 3。

3. **关键追问（前导零与 `10~26` 的判定）**

   `'0'` 不能单独解码，所以单字符分支要求非 `'0'`。双字符分支要求数值 `>= 10`：这同时排除了 `"0x"` 这种前导零（如 `"06"` 数值为 6 `< 10`，被判为非法），而 `<= 26` 排除了 `"27~99"`。两者合起来正是 `10 <= val <= 26`。

### Java 实现（线性 DP）

```java
class Solution {
    public int numDecodings(String s) {
        int n = s.length();
        int[] dp = new int[n + 1];
        dp[0] = 1;                             // 空串视为 1 种方案

        for (int i = 1; i <= n; i++) {
            // 情况一：第 i 个字符单独解码（不能是 '0'）
            if (s.charAt(i - 1) != '0') {
                dp[i] += dp[i - 1];
            }
            // 情况二：第 i-1、i 个字符组成两位数解码（须在 10~26）
            if (i >= 2) {
                int two = (s.charAt(i - 2) - '0') * 10 + (s.charAt(i - 1) - '0');
                if (two >= 10 && two <= 26) {
                    dp[i] += dp[i - 2];
                }
            }
        }
        return dp[n];
    }
}
```

### 复杂度

- 时间：`O(n)`。从左到右扫一遍，每个位置做常数次判断与加法。
- 空间：`O(n)`。`dp` 数组长度为 `n+1`；由于 `dp[i]` 只依赖前两项，可滚动压缩到 `O(1)`。

### 易错点与扩展（面试高频考点）

1. **`dp[0] = 1` 的含义**：这是为了让 `i = 2` 且 `s` 恰为合法两位数（如 `"12"`）时能通过 `dp[0]` 贡献 1 种方案，不是"空串有零种"。
2. **前导零处理**：`"06"` 必须返回 0。单字符分支因 `'0'` 被跳过，双字符 `6 < 10` 被拒绝，两分支都不贡献，`dp` 自然为 0。
3. **`"10"`、`"20"` 特别小心**：末位是 `0` 时单字符分支失效，只能靠双字符 `10/20` 撑住；若写成 `"30"` 则二者皆不可解，返回 0。
4. **面试追问——空间优化**：用两个变量 `prev2 = dp[i-2]`、`prev1 = dp[i-1]` 滚动更新，可做到 `O(1)` 空间，逻辑完全一致。
5. **面试追问——为何不用记忆化搜索**：本题状态是单一线性下标，DP 递推更直观且无重复子问题，两者等价但迭代更省栈空间。

### C++ 实现

```cpp
#include <string>
#include <vector>
using namespace std;

class Solution {
public:
    int numDecodings(string s) {
        int n = s.size();
        vector<int> dp(n + 1, 0);
        dp[0] = 1;                                   // 空串 1 种方案

        for (int i = 1; i <= n; i++) {
            if (s[i - 1] != '0') {                   // 单字符解码
                dp[i] += dp[i - 1];
            }
            if (i >= 2) {                            // 双字符解码
                int two = (s[i - 2] - '0') * 10 + (s[i - 1] - '0');
                if (two >= 10 && two <= 26) {
                    dp[i] += dp[i - 2];
                }
            }
        }
        return dp[n];
    }
};
```

### Python 实现

```python
class Solution:
    def numDecodings(self, s: str) -> int:
        n = len(s)
        dp = [0] * (n + 1)
        dp[0] = 1                                  # 空串 1 种方案

        for i in range(1, n + 1):
            if s[i - 1] != '0':                    # 单字符解码
                dp[i] += dp[i - 1]
            if i >= 2:                             # 双字符解码
                two = int(s[i - 2:i])
                if 10 <= two <= 26:
                    dp[i] += dp[i - 2]
        return dp[n]
```
