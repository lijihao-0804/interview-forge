306. 累加数

难度中等核心模式枚举前两个数的切分位置 + 大数字符串加法校验后续项时间复杂度O(n^3)空间复杂度O(n)

题目与约束

累加数 是一个字符串，组成它的数字可以形成累加序列。

一个有效的 累加序列 必须 至少 包含 3 个数。除了最开始的两个数以外，序列中的每个后续数字必须是它之前两个数字之和。

给你一个只包含数字 '0'-'9' 的字符串，编写一个算法来判断给定输入是否是 累加数 。如果是，返回 true ；否则，返回 false 。

说明：累加序列里的数，除数字 0 之外，不会 以 0 开头，所以不会出现 1, 2, 03 或者 1, 02, 3 的情况。

示例 1：

输入："112358"
输出：true
解释：累加序列为: 1, 1, 2, 3, 5, 8 。1 + 1 = 2, 1 + 2 = 3, 2 + 3 = 5, 3 + 5 = 8

示例 2：

输入："199100199"
输出：true
解释：累加序列为: 1, 99, 100, 199。1 + 99 = 100, 99 + 100 = 199

提示：

  • 1 <= num.length <= 35

  • num 仅由数字（0 - 9）组成

进阶：你计划如何处理由过大的整数输入导致的溢出?

🔗 前往力扣原题验证 →

核心不变量

一旦确定了前两个数，后面每个数都被“前两项之和”唯一确定；只要依次用大数加法拼出并逐段匹配原串，就能判定这个切分是否合法。

完整推导

思路推导

  1. 穷举的边界在哪里？ 一个累加序列的前两个数决定了整个序列。前两个数把字符串切成前缀 a、中段 b，之后每项都是字符串形式的 a + b。因此只需枚举两个切分点即可。

  2. 非法前导零要剪枝：数字除单个 0 外不能以 0 开头。若 a 长度 > 1 且以 0 开头，或 b 长度 > 1 且以 0 开头，这个切分直接无效。

  3. 小例子（112358）：取 a=1, b=1 → a+b=2，串里接着是 2 ✓；再 b=1,2 → 3 ✓；2+3=5 ✓；3+5=8 ✓，恰好耗尽，返回 true。

  4. 溢出怎么办？ n<=35，数字可能超出 64 位整数。进阶答案：用字符串大数加法（逐位相加处理进位），本项目实现即采用此法，天然不怕溢出。

Java 实现（枚举 + 字符串加法）

class Solution {
    public boolean isAdditiveNumber(String num) {
        int n = num.length();
        // i 是第一个数的长度，最多取一半（否则留给后两项的空间不足）
        for (int i = 1; i <= n / 2; i++) {
            if (num.charAt(0) == '0' && i > 1) break;      // 前导零剪枝
            for (int j = i + 1; j < n; j++) {
                if (num.charAt(i) == '0' && j > i + 1) break;
                String a = num.substring(0, i);
                String b = num.substring(i, j);
                if (valid(num, j, a, b)) return true;
            }
        }
        return false;
    }

    // 从 start 开始，用 a、b 推出后续项并逐段匹配
    private boolean valid(String num, int start, String a, String b) {
        int idx = start;
        while (idx < num.length()) {
            String sum = add(a, b);
            if (!num.startsWith(sum, idx)) return false;
            idx += sum.length();
            a = b;
            b = sum;
        }
        return true;   // 恰好耗尽且至少匹配过一次（j > i 保证至少第三项）
    }

    // 字符串大数加法，避免溢出
    private String add(String a, String b) {
        StringBuilder sb = new StringBuilder();
        int i = a.length() - 1, j = b.length() - 1, carry = 0;
        while (i >= 0 || j >= 0 || carry > 0) {
            int da = i >= 0 ? a.charAt(i--) - '0' : 0;
            int db = j >= 0 ? b.charAt(j--) - '0' : 0;
            int s = da + db + carry;
            sb.append(s % 10);
            carry = s / 10;
        }
        return sb.reverse().toString();
    }
}

C++ 实现

class Solution {
public:
    bool isAdditiveNumber(string num) {
        int n = num.size();
        for (int i = 1; i <= n / 2; i++) {
            if (num[0] == '0' && i > 1) break;
            for (int j = i + 1; j < n; j++) {
                if (num[i] == '0' && j > i + 1) break;
                if (valid(num, j, num.substr(0, i), num.substr(i, j - i))) return true;
            }
        }
        return false;
    }

private:
    string add(const string& a, const string& b) {
        string res;
        int i = a.size() - 1, j = b.size() - 1, carry = 0;
        while (i >= 0 || j >= 0 || carry) {
            int s = carry + (i >= 0 ? a[i--] - '0' : 0) + (j >= 0 ? b[j--] - '0' : 0);
            res.push_back('0' + s % 10);
            carry = s / 10;
        }
        reverse(res.begin(), res.end());
        return res;
    }

    bool valid(const string& num, int start, string a, string b) {
        int idx = start;
        while (idx < (int)num.size()) {
            string sum = add(a, b);
            if (num.compare(idx, sum.size(), sum) != 0) return false;
            idx += sum.size();
            a = b;
            b = sum;
        }
        return true;
    }
};

Python 实现

class Solution:
    def isAdditiveNumber(self, num: str) -> bool:
        n = len(num)

        def add(a, b):
            i, j, carry, out = len(a) - 1, len(b) - 1, 0, []
            while i >= 0 or j >= 0 or carry:
                s = carry + (int(a[i]) if i >= 0 else 0) + (int(b[j]) if j >= 0 else 0)
                out.append(str(s % 10))
                carry = s // 10
                i -= 1
                j -= 1
            return "".join(reversed(out))

        def valid(start, a, b):
            idx = start
            while idx < n:
                s = add(a, b)
                if not num.startswith(s, idx):
                    return False
                idx += len(s)
                a, b = b, s
            return True

        for i in range(1, n // 2 + 1):
            if num[0] == "0" and i > 1:
                break
            for j in range(i + 1, n):
                if num[i] == "0" and j > i + 1:
                    break
                if valid(j, num[:i], num[i:j]):
                    return True
        return False

复杂度

  • 时间：O(n^3)，枚举两个切分点共 O(n^2)，一次校验中所有加法的总位数为 O(n)，故每次校验总代价 O(n)，整体 O(n^3)。
  • 空间：O(n)，存储当前和字符串及回溯产生的临时串。
易错点与扩展（面试高频考点）
  1. 前导零判定的位置：是“长度 > 1 才禁止以 0 开头”，单个 0 合法；写错会漏判 "101" 之类。
  2. 至少 3 个数：内层 j 从 i+1 开始，保证第二项非空且存在第三项，否则 "12" 会被误判。
  3. 溢出陷阱：n 到 35 时 long 也可能溢出，务必用字符串加法或大数类型；Java 可用 BigInteger 作为备选。
  4. 循环 break 而非 continue：一旦某个起点出现前导零，更长的切分同样非法，可以直接跳出内层。
  5. 扩展：若要求返回所有切分方案，可把“找到即返回”改为“记录路径继续搜索”的回溯。
