93. 复原 IP 地址

本题学习状态正在读取学习记录…下次复习：—
本次复习：
按 M 快速切换薄弱标记
遮住推导与代码，先自己想，再逐段揭示
难度中等核心模式回溯枚举 4 段（每段 1~3 位）时间复杂度O(3^4 · n)，实际为常数级空间复杂度O(n)（递归栈与临时段）

题目与约束

有效 IP 地址 正好由四个整数（每个整数位于 0 到 255 之间组成，且不能含有前导 0），整数之间用 '.' 分隔。

  • 例如："0.1.2.201" 和"192.168.1.1" 是 有效 IP 地址，但是 "0.011.255.245"、"192.168.1.312" 和 "192.168@1.1" 是 无效 IP 地址。

给定一个只包含数字的字符串 s ，用以表示一个 IP 地址，返回所有可能的有效 IP 地址，这些地址可以通过在 s 中插入 '.' 来形成。你 不能 重新排序或删除 s 中的任何数字。你可以按 任何 顺序返回答案。

示例 1：

输入：s = "25525511135"
输出：["255.255.11.135","255.255.111.35"]

示例 2：

输入：s = "0000"
输出：["0.0.0.0"]

示例 3：

输入：s = "101023"
输出：["1.0.10.23","1.0.102.3","10.1.0.23","10.10.2.3","101.0.2.3"]

提示：

  • 1 <= s.length <= 20

  • s 仅由数字组成

🔗 前往力扣原题验证 →

核心不变量

任意时刻已确定 k 段，则剩余字符数必须满足 4-k <= 剩余长度 <= 3*(4-k)；每段长度只能取 1~3，且要么是单个 0，要么不以 0 开头且数值 ≤ 255。

完整推导

思路推导

  1. 直觉与痛点（在哪些位置插点？）

要在字符串里插 3 个点，切成 4 段且不改变字符顺序。直接枚举所有切法会切出非法段（前导零、超过 255、段数不对）。这属于"在约束下枚举所有满足条件的切分"，是标准回溯题。

  1. 破局思路（逐段定位，段数 1→4）

用 start 表示当前段在 s 中的起点、parts 保存已确定的段。每层从 start 开始尝试取长度为 1、2、3 的段：

  • 若段长 > 1 且以 '0' 开头 → 非法，且更长只会继续非法，直接 break；
  • 若段数值 > 255 → 非法，更长只会更大，直接 break；
  • 合法则把该段加入 parts，递归处理剩余部分，回溯时弹出。
  • 当 parts 已有 4 段时，只有恰好用完整串 start == n 才收集结果，否则丢弃。

以 s = "25525511135" 为例：先取 "255"，再取 "255"，剩 "11135" 可取 "11"+"135" 或 "111"+"35"，得到两个答案。

  1. 关键追问（怎么提前剪枝？）

在进入每层前判断剩余长度：还剩 4 - len(parts) 段，每段至少 1 位、至多 3 位，所以剩余长度必须落在 [剩余段数, 3×剩余段数]。不在区间内直接返回，可剪掉大量无效分支（如剩 1 段却还有 5 个字符）。

Java 实现（回溯）

import java.util.ArrayList;
import java.util.List;

class Solution {
    public List<String> restoreIpAddresses(String s) {
        List<String> res = new ArrayList<>();
        backtrack(s, 0, new ArrayList<>(), res);
        return res;
    }

    private void backtrack(String s, int start, List<String> parts, List<String> res) {
        // 已凑齐 4 段：必须恰好用完整个字符串
        if (parts.size() == 4) {
            if (start == s.length()) {
                res.add(String.join(".", parts));
            }
            return;
        }

        // 剪枝：剩余长度须能支撑剩余段数（每段 1~3 位）
        int remainSeg = 4 - parts.size();
        int left = s.length() - start;
        if (left < remainSeg || left > remainSeg * 3) {
            return;
        }

        // 尝试当前段长度为 1、2、3
        for (int len = 1; len <= 3 && start + len <= s.length(); len++) {
            String seg = s.substring(start, start + len);

            // 前导零非法，更长也非法，直接 break
            if (len > 1 && seg.charAt(0) == '0') {
                break;
            }
            // 数值超过 255 非法，更长只会更大，直接 break
            if (Integer.parseInt(seg) > 255) {
                break;
            }

            parts.add(seg);
            backtrack(s, start + len, parts, res);
            parts.remove(parts.size() - 1);   // 回溯
        }
    }
}

C++ 实现

#include <string>
#include <vector>
using namespace std;

class Solution {
public:
    vector<string> restoreIpAddresses(string s) {
        vector<string> res;
        vector<string> parts;
        backtrack(s, 0, parts, res);
        return res;
    }

private:
    void backtrack(const string& s, int start, vector<string>& parts, vector<string>& res) {
        if (parts.size() == 4) {
            if (start == (int)s.size()) {
                string ip = parts[0];
                for (int i = 1; i < 4; i++) {
                    ip += "." + parts[i];
                }
                res.push_back(ip);
            }
            return;
        }

        int remainSeg = 4 - (int)parts.size();
        int left = (int)s.size() - start;
        if (left < remainSeg || left > remainSeg * 3) {
            return;
        }

        for (int len = 1; len <= 3 && start + len <= (int)s.size(); len++) {
            string seg = s.substr(start, len);

            if (len > 1 && seg[0] == '0') break;   // 前导零非法
            if (stoi(seg) > 255) break;            // 超过 255 非法

            parts.push_back(seg);
            backtrack(s, start + len, parts, res);
            parts.pop_back();                      // 回溯
        }
    }
};

Python 实现

class Solution:
    def restoreIpAddresses(self, s: str) -> list[str]:
        res = []
        parts = []
        n = len(s)

        def backtrack(start: int) -> None:
            if len(parts) == 4:
                if start == n:
                    res.append(".".join(parts))
                return

            remain_seg = 4 - len(parts)
            left = n - start
            # 剪枝：剩余长度须能支撑剩余段数（每段 1~3 位）
            if left < remain_seg or left > remain_seg * 3:
                return

            for length in range(1, 4):
                if start + length > n:
                    break
                seg = s[start:start + length]

                if length > 1 and seg[0] == '0':   # 前导零非法
                    break
                if int(seg) > 255:                 # 超过 255 非法
                    break

                parts.append(seg)
                backtrack(start + length)
                parts.pop()                        # 回溯

        backtrack(0)
        return res

复杂度

  • 时间：O(3^4 · n)。最多 4 段、每段 3 种长度选择，搜索树规模为常数 3^4 = 81；每次拼接结果与合法性判断涉及 O(n)，故整体近似常数级，n <= 20 时极快。
  • 空间：O(n)。递归深度最多 4 层，parts 与临时字符串总量与 n 同阶，不计返回结果。
易错点与扩展（面试高频考点）
  1. 前导零规则："0" 合法，但 "01"、"00" 非法。判断写在"段长 > 1 且首字符为 '0'"上，且要 break 而非 continue（更长段必然也以 0 开头）。
  2. 必须恰好用完字符串：凑满 4 段时若 start != n，说明还有字符没用上，不能收集；反之也不能提前停在用完整串但不足 4 段。
  3. 数值上限 255：用 Integer.parseInt 后比较，或手算三位数；一旦超 255 应 break，因为后续更长段数值只会更大。
  4. 段数剪枝别漏：left < remainSeg（字符太少）或 left > remainSeg*3（字符太多）都应提前返回，否则会做大量无效递归。
  5. 面试追问——有效 IP 的边界："0.0.0.0"、"255.255.255.255" 合法；段内不允许空、不允许 +/空格/字母。与"分割回文串"同为切割型回溯，模板一致（选择 → 递归 → 撤销）。
