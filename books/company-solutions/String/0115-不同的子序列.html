115. 不同的子序列

难度困难核心模式动态规划（匹配计数 + 滚动数组）时间复杂度O(m·n)空间复杂度O(n)

题目与约束

给你两个字符串 s 和 t ，统计并返回在 s 的 子序列 中 t 出现的个数。

测试用例保证结果在 32 位有符号整数范围内。

示例 1：

输入：s = "rabbbit", t = "rabbit"
输出：3
解释：
如下所示, 有 3 种可以从 s 中得到 "rabbit" 的方案。
rabbbit
rabbbit
rabbbit

示例 2：

输入：s = "babgbag", t = "bag"
输出：5
解释：
如下所示, 有 5 种可以从 s 中得到 "bag" 的方案。
babgbag
babgbag
babgbag
babgbag
babgbag

提示：

  • 1 <= s.length, t.length <= 1000

  • s 和 t 由英文字母组成

🔗 前往力扣原题验证 →

核心不变量

dp[j] 表示“当前已扫描的 s 后缀”能拼出 t[j:] 的方案数；当 s[i] == t[j] 时，把 dp[j+1] 的方案并进 dp[j]。

完整推导

思路推导

  1. 状态定义（从后往前看更自然）

设 dp[i][j] 表示：用 s[i:] 的子序列，能拼出 t[j:] 的方案数。答案就是 dp[0][0]。

  1. 状态转移（分“用不用 s[i]”）

对于 s[i]： - 不用它：方案数等于 dp[i+1][j]； - 用它：只有 s[i] == t[j] 时才允许，此时消耗掉 t[j]，剩余方案为 dp[i+1][j+1]。

两者相加即 dp[i][j] = dp[i+1][j] + (s[i]==t[j] ? dp[i+1][j+1] : 0)。

  1. 边界
  • j == n（t 已匹配完，空串）：任何 s 后缀都恰有 1 种选择——全都不选，所以 dp[i][n] = 1；
  • i == m 且 j < n：s 用完但 t 还没匹配完，方案为 0。
  1. 滚动数组降维

观察转移只依赖“下一行”i+1，于是把二维压成一维 dp[j]。扫描 s 时 i 从后往前，j 从前往后，就能保证计算 dp[j] 时用到的 dp[j+1] 仍是上一轮（i+1）的值。

  1. 小例子

s = "rabbbit", t = "rabbit"：三个 b 中只要选两个即可匹配 rabbit 里的 bb，共 C(3,2) = 3 种。

Java 实现（numDistinct）

class Solution {
    public int numDistinct(String s, String t) {
        int m = s.length(), n = t.length();
        if (n > m) {
            return 0; // t 比 s 长，不可能成为子序列
        }
        // dp[j] = 用当前 s 后缀匹配 t[j:] 的方案数
        long[] dp = new long[n + 1];
        dp[n] = 1; // t 为空串时唯一方案：什么都不选
        // i 从后往前扫描 s；j 从前往后，保证 dp[j+1] 仍是上一行(i+1)的值
        for (int i = m - 1; i >= 0; i--) {
            for (int j = 0; j < n; j++) {
                if (s.charAt(i) == t.charAt(j)) {
                    dp[j] += dp[j + 1];
                }
            }
        }
        return (int) dp[0];
    }
}

C++ 实现

class Solution {
public:
    int numDistinct(string s, string t) {
        int m = s.size(), n = t.size();
        if (n > m) return 0;
        // dp[j] = 用当前 s 后缀匹配 t[j:] 的方案数
        vector<long long> dp(n + 1, 0);
        dp[n] = 1; // t 为空串的唯一方案
        for (int i = m - 1; i >= 0; --i) {
            for (int j = 0; j < n; ++j) {
                if (s[i] == t[j]) {
                    dp[j] += dp[j + 1];
                }
            }
        }
        return static_cast<int>(dp[0]);
    }
};

Python 实现

class Solution:
    def numDistinct(self, s: str, t: str) -> int:
        m, n = len(s), len(t)
        if n > m:
            return 0
        # dp[j] = 用当前 s 后缀匹配 t[j:] 的方案数
        dp = [0] * (n + 1)
        dp[n] = 1  # t 为空串的唯一方案
        for i in range(m - 1, -1, -1):
            for j in range(n):
                if s[i] == t[j]:
                    dp[j] += dp[j + 1]
        return dp[0]

复杂度

  • 时间：O(m·n)，两重循环分别遍历 s 与 t。
  • 空间：O(n)，一维滚动数组，只与 t 的长度有关。
易错点与扩展（面试高频考点）
  1. 中间态用 long：虽然最终答案保证在 32 位内，但累加中间值可能溢出 int，用 long 更稳妥，最后再转回。
  2. 空串 t 答案为 1：dp[n] = 1 是全题的定海神针，漏掉它整个 DP 全错。
  3. 滚动数组的遍历顺序：i 必须倒序、j 必须正序，才能让 dp[j+1] 保持“上一行”的值；顺序写反会重复计数。
  4. 子序列 ≠ 子串：子序列允许跳过字符，所以转移里“不用 s[i]”那一项不能省。
  5. 提前返回：n > m 直接返回 0，是个自然的剪枝。
