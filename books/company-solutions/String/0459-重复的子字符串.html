题目与约束

给定一个非空的字符串 s ，检查是否可以通过由它的一个子串重复多次构成。

示例 1:

<strong>输入:</strong> s = "abab"
<strong>输出:</strong> true
<strong>解释:</strong> 可由子串 "ab" 重复两次构成。

示例 2:

<strong>输入:</strong> s = "aba"
<strong>输出:</strong> false

示例 3:

<strong>输入:</strong> s = "abcabcabcabc"
<strong>输出:</strong> true
<strong>解释:</strong> 可由子串 "abc" 重复四次构成。 (或子串 "abcabc" 重复两次构成。)

提示：

  • 1 <= s.length <= 104

  • s 由小写英文字母组成

🔗 前往力扣原题验证 →

核心不变量

设 p = lps[n-1] 为整串的最长相等真前缀/真后缀长度，则 s 由某个子串循环构成当且仅当 p > 0 且 n % (n - p) == 0，最小循环节长度为 n - p。

完整推导

思路推导

  1. 直觉（重复串长什么样）：若 s 是由长度 L 的块重复 k 次拼成（n = k * L），那么把 s 整体左移 L 位后，除末尾 L 个字符外应与原串完全重合。这正好对应“最长相等真前后缀”的想法。

  2. 破局（KMP 前缀函数 lps）：lps[i] 表示子串 s[0..i] 的最长相等真前缀/真后缀长度。整串的 p = lps[n-1] 就告诉我们：末尾有一段长度为 p 的后缀与前缀相同。于是循环节长度 L = n - p。

  3. 判定（整除条件）：只有当 p > 0 且 n 能被 L = n - p 整除时，整个串才能被这个循环节完整铺满。例如 "abab"：p = 2，L = 2，4 % 2 == 0，成立；"aba"：p = 1，L = 2，3 % 2 != 0，不成立。

  4. 等价巧解（拼接法）：s 是重复串 ⟺ s 出现在 (s + s)[1 : -1] 中。把 s+s 掐头去尾，正好排除了“只匹配到原位置”的情况，剩下的匹配必然跨越两个 s 的拼接边界，对应循环结构。

Java 实现（repeatedSubstringPattern）

class Solution {
    public boolean repeatedSubstringPattern(String s) {
        int n = s.length();
        // lps[i]：s[0..i] 的最长相等真前缀/真后缀长度
        int[] lps = new int[n];
        for (int i = 1; i < n; i++) {
            int j = lps[i - 1];
            // 失配时回退
            while (j > 0 && s.charAt(i) != s.charAt(j)) {
                j = lps[j - 1];
            }
            // 匹配则长度 +1
            if (s.charAt(i) == s.charAt(j)) {
                j++;
            }
            lps[i] = j;
        }

        int p = lps[n - 1];          // 整串最长相等真前后缀
        int len = n - p;             // 最小候选循环节长度
        return p > 0 && n % len == 0;
    }
}

复杂度

  • 时间：O(n)。构建 lps 数组时，j 只会增加或被回退，均摊到每个位置是常数，总计线性。
  • 空间：O(n)。需要长度为 n 的 lps 数组。

易错点与扩展（面试高频考点）

  1. 必须判断 p > 0：若整串没有任何相等真前后缀（如 "abcd"），p = 0 会算出 len = n，n % n == 0 恒成立，就会把任意串误判为 true。
  2. 循环节长度是 n - p 而不是 p：p 是“重合部分”长度，真正的循环块长度是 n - p，这两个量极易混淆。
  3. 整除条件不能省："abababab" 的 p = 6，len = 2，能整除；但某些串 p 存在却无法整除，说明它只是“前后缀相同”而非“整体循环”。
  4. 拼接法边界：s 长度为 1 时 (s+s)[1:-1] 为空串，s 不在其中，返回 false，与题意一致（单个字符默认 false）。
  5. 扩展追问：这题是 KMP next 数组的经典应用，与“最短回文串（KMP 求最长回文前缀）”“字符串匹配”同源，掌握 lps 的构造即可迁移。

C++ 实现

#include <string>
#include <vector>
using namespace std;

class Solution {
public:
    bool repeatedSubstringPattern(string s) {
        int n = (int)s.size();
        vector<int> lps(n, 0);
        for (int i = 1; i < n; ++i) {
            int j = lps[i - 1];
            while (j > 0 && s[i] != s[j]) {
                j = lps[j - 1];
            }
            if (s[i] == s[j]) {
                ++j;
            }
            lps[i] = j;
        }

        int p = lps[n - 1];
        int len = n - p;
        return p > 0 && n % len == 0;
    }
};

Python 实现

class Solution:
    def repeatedSubstringPattern(self, s: str) -> bool:
        n = len(s)
        lps = [0] * n
        for i in range(1, n):
            j = lps[i - 1]
            while j > 0 and s[i] != s[j]:
                j = lps[j - 1]
            if s[i] == s[j]:
                j += 1
            lps[i] = j

        p = lps[-1]
        length = n - p
        return p > 0 and n % length == 0
