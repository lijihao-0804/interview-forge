# 132. 分割回文串 II

| 题目信息 | 内容 |
|---|---|
| 难度 | 困难 |
| 核心模式 | 预处理回文表 + 线性 DP 求最少分割次数 |
| 时间复杂度 | O(n²) |
| 空间复杂度 | O(n²) |

## 题目与约束

给你一个字符串 `s`，请你将 `s` 分割成一些子串，使每个子串都是回文串。

返回符合要求的 最少分割次数 。

 

示例 1：

```
<strong>输入：</strong>s = "aab"
<strong>输出：</strong>1
<strong>解释：</strong>只需一次分割就可将 <em>s </em>分割成 ["aa","b"] 这样两个回文子串。
```

示例 2：

```
<strong>输入：</strong>s = "a"
<strong>输出：</strong>0
```

示例 3：

```
<strong>输入：</strong>s = "ab"
<strong>输出：</strong>1
```

 

提示：

- `1 <= s.length <= 2000`

- `s` 仅由小写英文字母组成

[🔗 前往力扣原题验证 →](https://leetcode.cn/problems/palindrome-partitioning-ii/)

## 核心不变量

> `cut[i]` 表示前缀 `s[0..i]` 的最少分割次数；若 `s[j+1..i]` 是回文，则 `cut[i]` 可由 `cut[j] + 1` 转移而来，取所有合法 `j` 的最小值。

## 完整推导

### 思路推导

1. **先解决「判断子串是否回文」**

   暴力对每个子串判断回文是 O(n³)，n 达 2000 会超时。用区间 DP 预处理：`isPal[i][j]` 表示 `s[i..j]` 是否回文。转移为
   `isPal[i][j] = (s[i] == s[j]) && (j - i <= 1 || isPal[i+1][j-1])`。
   从 `i` 由大到小、`j` 由小到大填表，保证 `isPal[i+1][j-1]` 先算好。

2. **再解决「最少分割」**

   定义 `cut[i]` 为前缀 `s[0..i]` 的最少分割次数。若 `s[0..i]` 本身回文，`cut[i] = 0`；否则枚举最后一段的起点 `j+1`：若 `s[j+1..i]` 是回文，则 `cut[i] = min(cut[i], cut[j] + 1)`。

3. **小例子（s = "aab"）**

   - `cut[0]`：`"a"` 回文 → `0`；
   - `cut[1]`：`"aa"` 回文 → `0`；
   - `cut[2]`：`"aab"` 不是回文。枚举 `j`：`j=1` 时 `s[2..2]="b"` 回文，`cut[1]+1 = 1`；故 `cut[2] = 1`。

4. **答案即 `cut[n-1]`**

   因为「分割次数 = 子串段数 - 1」，这种按前缀切段的方式直接统计切点，无需额外转换。

### Java 实现（minCut）

```java
class Solution {
    public int minCut(String s) {
        int n = s.length();

        // 1. 预处理：isPal[i][j] 表示 s[i..j] 是否回文
        boolean[][] isPal = new boolean[n][n];
        for (int i = n - 1; i >= 0; i--) {
            for (int j = i; j < n; j++) {
                if (s.charAt(i) == s.charAt(j) && (j - i <= 1 || isPal[i + 1][j - 1])) {
                    isPal[i][j] = true;
                }
            }
        }

        // 2. cut[i] = 前缀 s[0..i] 的最少分割次数
        int[] cut = new int[n];
        for (int i = 0; i < n; i++) {
            if (isPal[0][i]) {
                cut[i] = 0;          // 整段已是回文，无需分割
            } else {
                cut[i] = i;          // 最坏情况：每个字符切一刀，共 i 次
                for (int j = 0; j < i; j++) {
                    if (isPal[j + 1][i]) {
                        cut[i] = Math.min(cut[i], cut[j] + 1);
                    }
                }
            }
        }
        return cut[n - 1];
    }
}
```

### 复杂度

- 时间：O(n²)，回文表预处理 O(n²)，分割 DP 二层循环 O(n²)。
- 空间：O(n²)，回文表 `isPal` 占用 n×n 布尔矩阵（`cut` 为 O(n)，可忽略）。

### 易错点与扩展（面试高频考点）

1. **回文表的填表顺序**：`isPal[i][j]` 依赖 `isPal[i+1][j-1]`，必须让 `i` 从大到小遍历，否则用到的是尚未计算的旧值。
2. **边界 `j - i <= 1`**：长度为 1 或 2 且首尾相等时直接是回文，避免访问 `isPal[i+1][j-1]` 越界。
3. **`cut[i]` 初值取 `i`**：表示「每个字符单独成段」的上界，不能取 0 或大数导致转移失效。
4. **与 131「分割回文串」区分**：131 要枚举所有方案（回溯），本题只要最少次数（DP），不要用回溯暴力，否则 2000 规模必超时。
5. **中心扩展优化**：空间可降为 O(n)——边做中心扩展判断回文、边更新 `cut`；或用「从每个中心向两边扩展」的一维 DP，是进阶优化方向。

### C++ 实现

```cpp
class Solution {
public:
    int minCut(string s) {
        int n = s.size();
        vector<vector<bool>> isPal(n, vector<bool>(n, false));
        for (int i = n - 1; i >= 0; --i) {
            for (int j = i; j < n; ++j) {
                if (s[i] == s[j] && (j - i <= 1 || isPal[i + 1][j - 1])) {
                    isPal[i][j] = true;
                }
            }
        }

        vector<int> cut(n, 0);
        for (int i = 0; i < n; ++i) {
            if (isPal[0][i]) {
                cut[i] = 0;
            } else {
                cut[i] = i;
                for (int j = 0; j < i; ++j) {
                    if (isPal[j + 1][i]) {
                        cut[i] = min(cut[i], cut[j] + 1);
                    }
                }
            }
        }
        return cut[n - 1];
    }
};
```

### Python 实现

```python
class Solution:
    def minCut(self, s: str) -> int:
        n = len(s)

        # 预处理回文表
        is_pal = [[False] * n for _ in range(n)]
        for i in range(n - 1, -1, -1):
            for j in range(i, n):
                if s[i] == s[j] and (j - i <= 1 or is_pal[i + 1][j - 1]):
                    is_pal[i][j] = True

        # cut[i] = 前缀 s[0..i] 的最少分割次数
        cut = [0] * n
        for i in range(n):
            if is_pal[0][i]:
                cut[i] = 0
            else:
                cut[i] = i
                for j in range(i):
                    if is_pal[j + 1][i]:
                        cut[i] = min(cut[i], cut[j] + 1)

        return cut[n - 1]
```
