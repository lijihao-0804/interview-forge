# 468. 验证IP地址

| 题目信息 | 内容 |
|---|---|
| 难度 | 中等 |
| 核心模式 | 按分隔符拆分后逐段校验 |
| 时间复杂度 | O(n) |
| 空间复杂度 | O(n) |

## 题目与约束

给定一个字符串 `queryIP`。如果是有效的 IPv4 地址，返回 `"IPv4"` ；如果是有效的 IPv6 地址，返回 `"IPv6"` ；如果不是上述类型的 IP 地址，返回 `"Neither"` 。

有效的IPv4地址 是 `“x1.x2.x3.x4”` 形式的IP地址。 其中 `0 <= xi <= 255` 且 `xi` 不能包含 前导零。例如: `“192.168.1.1”` 、 `“192.168.1.0”` 为有效IPv4地址， `“192.168.01.1”` 为无效IPv4地址; `“192.168.1.00”` 、 `“192.168@1.1”` 为无效IPv4地址。

一个有效的IPv6地址 是一个格式为`“x1:x2:x3:x4:x5:x6:x7:x8”` 的IP地址，其中:

- `1 <= xi.length <= 4`

- `xi` 是一个 十六进制字符串 ，可以包含数字、小写英文字母( `'a'` 到 `'f'` )和大写英文字母( `'A'` 到 `'F'` )。

- 在 `xi` 中允许前导零。

例如 `"2001:0db8:85a3:0000:0000:8a2e:0370:7334"` 和 `"2001:db8:85a3:0:0:8A2E:0370:7334"` 是有效的 IPv6 地址，而 `"2001:0db8:85a3::8A2E:037j:7334"` 和 `"02001:0db8:85a3:0000:0000:8a2e:0370:7334"` 是无效的 IPv6 地址。

 

示例 1：

```
<strong>输入：</strong>queryIP = "172.16.254.1"
<strong>输出：</strong>"IPv4"
<strong>解释：</strong>有效的 IPv4 地址，返回 "IPv4"
```

示例 2：

```
<strong>输入：</strong>queryIP = "2001:0db8:85a3:0:0:8A2E:0370:7334"
<strong>输出：</strong>"IPv6"
<strong>解释：</strong>有效的 IPv6 地址，返回 "IPv6"
```

示例 3：

```
<strong>输入：</strong>queryIP = "256.256.256.256"
<strong>输出：</strong>"Neither"
<strong>解释：</strong>既不是 IPv4 地址，又不是 IPv6 地址
```

 

提示：

- `queryIP` 仅由英文字母，数字，字符 `'.'` 和 `':'` 组成。

[🔗 前往力扣原题验证 →](https://leetcode.cn/problems/validate-ip-address/)

## 核心不变量

> IPv4 恰好被 `'.'` 切成 4 段、每段为 1~3 位纯数字且无前导零、数值 ≤ 255；IPv6 恰好被 `':'` 切成 8 段、每段为 1~4 位十六进制字符。只要任一段不满足即整体无效。

## 完整推导

### 思路推导

1. **直觉（先分清是哪一类）**：合法的 IP 不会同时含 `.` 和 `:`，且 IPv4 用 `.` 分隔、IPv6 用 `:` 分隔。先看 `queryIP` 里出现的是哪种分隔符，就只往对应格式上校验，另一类直接判无效。

2. **IPv4 校验（4 段 + 数字 + 无前导零 + ≤255）**：按 `'.'` 切分，段数必须正好 4；每段长度 1~3、全为数字；长度大于 1 时首字符不能是 `'0'`；转成整数后必须 ≤ 255。

3. **IPv6 校验（8 段 + 1~4 位十六进制）**：按 `':'` 切分，段数必须正好 8；每段长度 1~4；每个字符必须是 `0-9`、`a-f`、`A-F` 之一。注意 IPv6 **允许**前导零（如 `"0db8"`、`"0000"`）。

4. **切分的坑（保留空段）**：切分必须保留空串，例如 `"1.1.1.1."` 会切出 5 段（末段为空），`"::1"` 会切出空段。只有保留空段，长度判断才能正确排除这类非法输入。

### Java 实现（validIPAddress）

```java
class Solution {
    public String validIPAddress(String queryIP) {
        if (queryIP.indexOf('.') >= 0) {
            return isIPv4(queryIP) ? "IPv4" : "Neither";
        }
        if (queryIP.indexOf(':') >= 0) {
            return isIPv6(queryIP) ? "IPv6" : "Neither";
        }
        return "Neither";
    }

    private boolean isIPv4(String ip) {
        // 使用 limit = -1 保留末尾空段
        String[] parts = ip.split("\\.", -1);
        if (parts.length != 4) {
            return false;
        }
        for (String p : parts) {
            if (p.length() == 0 || p.length() > 3) {
                return false;
            }
            // 前导零非法（"0" 本身合法）
            if (p.length() > 1 && p.charAt(0) == '0') {
                return false;
            }
            int value = 0;
            for (char c : p.toCharArray()) {
                if (c < '0' || c > '9') {
                    return false;
                }
                value = value * 10 + (c - '0');
            }
            if (value > 255) {
                return false;
            }
        }
        return true;
    }

    private boolean isIPv6(String ip) {
        String[] parts = ip.split(":", -1);
        if (parts.length != 8) {
            return false;
        }
        for (String p : parts) {
            if (p.length() < 1 || p.length() > 4) {
                return false;
            }
            for (char c : p.toCharArray()) {
                boolean hex = (c >= '0' && c <= '9')
                        || (c >= 'a' && c <= 'f')
                        || (c >= 'A' && c <= 'F');
                if (!hex) {
                    return false;
                }
            }
        }
        return true;
    }
}
```

### 复杂度

- 时间：`O(n)`。只对字符串做一次切分并逐字符扫描各段，总字符数与 `n` 同阶。
- 空间：`O(n)`。切分得到的各段字符串合计长度不超过原串。

### 易错点与扩展（面试高频考点）

1. **切分要保留空段**：Java 的 `split` 默认会丢弃末尾空串，必须写 `split("\\.", -1)` / `split(":", -1)`，否则 `"1.1.1.1."` 这类非法串会被误判为 4 段合法。
2. **IPv4 前导零规则**：只有长度 > 1 且首字符为 `'0'` 才非法；单独的 `"0"` 是合法的。别把 `"0"` 也判错。
3. **IPv6 允许前导零**：与 IPv4 相反，`"0000"`、`"0db8"` 都合法，千万别套用 IPv4 的前导零限制。
4. **不要用正则一把梭**：正则可写但边界多（`.`, `:`, 前导零、长度），面试中逐段显式校验更清晰可靠，也更易解释。
5. **分类互斥**：合法 IP 不能同时含 `.` 和 `:`；用 `indexOf` 先判断含哪种分隔符，再走对应校验，避免出现“都试一遍”的重复逻辑。

### C++ 实现

```cpp
#include <string>
#include <vector>
using namespace std;

class Solution {
    vector<string> split(const string& s, char delim) {
        vector<string> res;
        string cur;
        for (char c : s) {
            if (c == delim) {
                res.push_back(cur);
                cur.clear();
            } else {
                cur += c;
            }
        }
        res.push_back(cur);   // 保留最后一段（可能为空）
        return res;
    }

    bool isIPv4(const string& ip) {
        vector<string> parts = split(ip, '.');
        if (parts.size() != 4) {
            return false;
        }
        for (const string& p : parts) {
            if (p.empty() || p.size() > 3) {
                return false;
            }
            if (p.size() > 1 && p[0] == '0') {
                return false;
            }
            int value = 0;
            for (char c : p) {
                if (c < '0' || c > '9') {
                    return false;
                }
                value = value * 10 + (c - '0');
            }
            if (value > 255) {
                return false;
            }
        }
        return true;
    }

    bool isIPv6(const string& ip) {
        vector<string> parts = split(ip, ':');
        if (parts.size() != 8) {
            return false;
        }
        for (const string& p : parts) {
            if (p.size() < 1 || p.size() > 4) {
                return false;
            }
            for (char c : p) {
                bool hex = (c >= '0' && c <= '9')
                        || (c >= 'a' && c <= 'f')
                        || (c >= 'A' && c <= 'F');
                if (!hex) {
                    return false;
                }
            }
        }
        return true;
    }

public:
    string validIPAddress(string queryIP) {
        if (queryIP.find('.') != string::npos) {
            return isIPv4(queryIP) ? "IPv4" : "Neither";
        }
        if (queryIP.find(':') != string::npos) {
            return isIPv6(queryIP) ? "IPv6" : "Neither";
        }
        return "Neither";
    }
};
```

### Python 实现

```python
class Solution:
    def validIPAddress(self, queryIP: str) -> str:
        def is_ipv4(ip: str) -> bool:
            parts = ip.split('.')          # 保留末尾空段
            if len(parts) != 4:
                return False
            for p in parts:
                if not p.isdigit() or len(p) > 3:
                    return False
                if len(p) > 1 and p[0] == '0':   # 前导零非法
                    return False
                if int(p) > 255:
                    return False
            return True

        def is_ipv6(ip: str) -> bool:
            parts = ip.split(':')
            if len(parts) != 8:
                return False
            hexdigits = set('0123456789abcdefABCDEF')
            for p in parts:
                if not (1 <= len(p) <= 4):
                    return False
                if any(c not in hexdigits for c in p):
                    return False
            return True

        if '.' in queryIP:
            return "IPv4" if is_ipv4(queryIP) else "Neither"
        if ':' in queryIP:
            return "IPv6" if is_ipv6(queryIP) else "Neither"
        return "Neither"
```
