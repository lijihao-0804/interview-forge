时间复杂度 O(n)

题目与约束

请你来实现一个 myAtoi(string s) 函数，使其能将字符串转换成一个 32 位有符号整数。

函数 myAtoi(string s) 的算法如下：

  • 空格：读入字符串并丢弃无用的前导空格（" "）

  • 符号：检查下一个字符（假设还未到字符末尾）为 '-' 还是 '+'。如果两者都不存在，则假定结果为正。

  • 转换：通过跳过前置零来读取该整数，直到遇到非数字字符或到达字符串的结尾。如果没有读取数字，则结果为0。

  • 舍入：如果整数数超过 32 位有符号整数范围 [−231, 231 − 1] ，需要截断这个整数，使其保持在这个范围内。具体来说，小于 −231 的整数应该被舍入为 −231 ，大于 231 − 1 的整数应该被舍入为 231 − 1 。

返回整数作为最终结果。

示例 1：

输入：s = "42"

输出：42

解释：加粗的字符串为已经读入的字符，插入符号是当前读取的字符。

带下划线线的字符是所读的内容，插入符号是当前读入位置。
第 1 步："42"（当前没有读入字符，因为没有前导空格）
         ^
第 2 步："42"（当前没有读入字符，因为这里不存在 '-' 或者 '+'）
         ^
第 3 步："<u>42</u>"（读入 "42"）
           ^

示例 2：

输入：s = " -042"

输出：-42

解释：

第 1 步："<u>   </u>-042"（读入前导空格，但忽视掉）
            ^
第 2 步："   <u>-</u>042"（读入 '-' 字符，所以结果应该是负数）
             ^
第 3 步："   <u>-042</u>"（读入 "042"，在结果中忽略前导零）
               ^

示例 3：

输入：s = "1337c0d3"

输出：1337

解释：

第 1 步："1337c0d3"（当前没有读入字符，因为没有前导空格）
         ^
第 2 步："1337c0d3"（当前没有读入字符，因为这里不存在 '-' 或者 '+'）
         ^
第 3 步："1337c0d3"（读入 "1337"；由于下一个字符不是一个数字，所以读入停止）
             ^

示例 4：

输入：s = "0-1"

输出：0

解释：

第 1 步："0-1" (当前没有读入字符，因为没有前导空格)
         ^
第 2 步："0-1" (当前没有读入字符，因为这里不存在 '-' 或者 '+')
         ^
第 3 步："<u>0</u>-1" (读入 "0"；由于下一个字符不是一个数字，所以读入停止)
          ^

示例 5：

输入：s = "words and 987"

输出：0

解释：

读取在第一个非数字字符“w”处停止。

提示：

  • 0 <= s.length <= 200

  • s 由英文字母（大写和小写）、数字（0-9）、' '、'+'、'-' 和 '.' 组成

核心不变量

有效输入只可能是"前导空格 → 一个可选符号 → 一串连续数字"这三段式；一旦数字段遇到第一个非数字字符就立刻停下，溢出时向边界值饱和截断而非返回 0。

完整推导

思路推导

  1. 直觉与痛点（按规则一步步走，但坑很多）

这道题没有高深算法，考的是边界与耐心的工程能力。规则一句话：跳过前导空格、读一个符号、读连续数字、溢出截断。难的不是思路，而是各种奇怪输入——""、" "、"+"、"3.14"、" -000123abc"、超大数 "999999999999"，一个没接住就错。

  1. 破局思路（用下标 i 顺序扫描，三段各自独立）

维护一个游标 i：

  • 第一段：while (i < n && s[i] == ' ') i++; 跳过所有前导空格。
  • 第二段：若 s[i] 是 + 或 -，记录 sign，i++；否则 sign = 1。
  • 第三段：while (i < n && s[i] 是数字)，把 digit = s[i]-'0' 累加进 res = res*10 + digit，i++。

三段结束，返回 sign * res（溢出情况单独处理）。

  1. 关键追问（溢出为什么是"饱和"而不是"返回 0"？）

注意本题与"整数反转"的差别：反转溢出返回 0，而 atoi 溢出要截断到 INT_MAX / INT_MIN。因此在累加前预判：若 res > (INT_MAX - digit) / 10，说明这一位拼上去会越界，直接返回 sign == 1 ? INT_MAX : INT_MIN。用 (INT_MAX - digit) / 10 而不是 INT_MAX / 10，可以顺带把最后一位的边界也处理干净。

Java 实现（myAtoi）

class Solution {
    public int myAtoi(String s) {
        int i = 0, n = s.length();

        // 第一段：跳过前导空格
        while (i < n && s.charAt(i) == ' ') {
            i++;
        }

        // 第二段：读取符号（缺省为正）
        int sign = 1;
        if (i < n && (s.charAt(i) == '+' || s.charAt(i) == '-')) {
            sign = (s.charAt(i) == '-') ? -1 : 1;
            i++;
        }

        // 第三段：读取连续数字，并在越界时饱和截断
        int res = 0;
        while (i < n && Character.isDigit(s.charAt(i))) {
            int digit = s.charAt(i) - '0';
            // 预判：res*10 + digit 是否已超过 INT_MAX
            if (res > (Integer.MAX_VALUE - digit) / 10) {
                return sign == 1 ? Integer.MAX_VALUE : Integer.MIN_VALUE;
            }
            res = res * 10 + digit;
            i++;
        }

        return sign * res;
    }
}

复杂度

  • 时间：O(n)，每个字符最多被访问一次，n = s.length()。
  • 空间：O(1)，只用了常量个变量。

易错点与扩展（面试高频考点）

  1. 空串 / 全空格 / 只有符号：如 ""、" "、"+"、"-"，都应返回 0（没有读到任何数字）。
  2. 溢出是"饱和"不是"归零"："999999999999" 应返回 INT_MAX，"-999999999999" 应返回 INT_MIN，别照搬整数反转的返回 0。
  3. 遇到非数字立即停止："1337c0d3" 返回 1337，"3.14" 返回 3（. 不是数字），"0-1" 返回 0。
  4. 前导零："000123" 直接累加即为 123，无需特殊处理。
  5. 符号只认一个："++1"、"--1" 在第二个符号处停止、结果无数字，返回 0。
  6. 不要用语言内置的 parseInt：它会抛异常或无法做到"部分解析"，面试要求手写扫描。

8. 字符串转换整数 (atoi)

C++ 实现

#include <string>
#include <climits>
#include <cctype>
using namespace std;

class Solution {
public:
    int myAtoi(string s) {
        int i = 0, n = s.size();

        // 第一段：跳过前导空格
        while (i < n && s[i] == ' ') i++;

        // 第二段：读取符号
        int sign = 1;
        if (i < n && (s[i] == '+' || s[i] == '-')) {
            sign = (s[i] == '-') ? -1 : 1;
            i++;
        }

        // 第三段：读取连续数字并饱和截断
        int res = 0;
        while (i < n && isdigit((unsigned char)s[i])) {
            int digit = s[i] - '0';
            if (res > (INT_MAX - digit) / 10)
                return sign == 1 ? INT_MAX : INT_MIN;
            res = res * 10 + digit;
            i++;
        }

        return sign * res;
    }
};

Python 实现

class Solution:
    def myAtoi(self, s: str) -> int:
        INT_MAX = 2 ** 31 - 1
        INT_MIN = -2 ** 31

        i, n = 0, len(s)

        # 第一段：跳过前导空格
        while i < n and s[i] == ' ':
            i += 1

        # 第二段：读取符号
        sign = 1
        if i < n and s[i] in ('+', '-'):
            sign = -1 if s[i] == '-' else 1
            i += 1

        # 第三段：读取连续数字
        res = 0
        while i < n and s[i].isdigit():
            res = res * 10 + (ord(s[i]) - ord('0'))
            i += 1

        res *= sign

        # 溢出饱和截断
        if res < INT_MIN:
            return INT_MIN
        if res > INT_MAX:
            return INT_MAX
        return res
