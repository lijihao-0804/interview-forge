难度 困难
核心模式 KMP 前缀函数求「s 的最长回文前缀」，再把剩余后缀反转补到最前面
时间复杂度 O(n)
空间复杂度 O(n)

题目与约束

给定一个字符串 s，你可以通过在字符串前面添加字符将其转换为回文串。找到并返回可以用这种方式转换的最短回文串。

示例 1：

输入：s = "aacecaaa"
输出："aaacecaaa"

示例 2：

输入：s = "abcd"
输出："dcbabcd"

提示：

  • 0 <= s.length <= 5 * 104

  • s 仅由小写英文字母组成

🔗 前往力扣原题验证 →

核心不变量

只能在前面添加字符，所以答案一定是「把 s 的某个后缀反转后拼在前面」+「s」本身；要让添加的字符最少，就要让这个后缀最短，也就是让 s 的回文前缀尽量长。

完整推导

思路推导

  1. 先想清楚「补什么」

因为只能在头部加字符，最终串必然是 反转(s[i:]) + s 的形式，其中 s[i:] 是要被「镜像补齐」的后缀。补前面会让 s[i:] 与它反转后的副本对称，而 s[0:i] 必须是回文前缀才能与后面的内容接上。要让补的字符最少，就要让回文前缀 s[0:i] 尽可能长。

  1. 问题转化为：求 s 的最长回文前缀长度

示例 2 s = "abcd"：最长回文前缀只有 "a"（长度 1），剩下后缀 "bcd" 反转成 "dcb" 拼在前面得到 "dcbabcd"。示例 1 s = "aacecaaa"：最长回文前缀是 "aacecaa"（长度 7），剩余后缀 "a" 反转仍是 "a"，答案 "aaacecaaa"。

  1. 用 KMP 前缀函数求最长回文前缀

构造 t = s + "#" + reverse(s)（# 是 s 中不会出现的分隔符）。对 t 求前缀函数 pi。由于 t 的后半段正好是 s 的反转，pi 的最后一个值就是「既是 t 的前缀、又是 t 的后缀」的最长长度，而这段恰好对应 s 的最长回文前缀。示例 1 的 pi[-1] = 7。

  1. 拼接答案

取 longest = pi[-1]，后缀 s[longest:] 反转后加上 s 即为最短回文串。前缀函数一遍扫描 O(n) 完成，总复杂度线性。

Java 实现（shortestPalindrome）

class Solution {
    public String shortestPalindrome(String s) {
        if (s == null || s.length() <= 1) {
            return s;
        }
        // 构造 t = s + "#" + reverse(s)
        String rev = new StringBuilder(s).reverse().toString();
        String t = s + "#" + rev;
        int n = t.length();

        // 求 t 的前缀函数 pi
        int[] pi = new int[n];
        for (int i = 1; i < n; i++) {
            int j = pi[i - 1];
            while (j > 0 && t.charAt(i) != t.charAt(j)) {
                j = pi[j - 1];
            }
            if (t.charAt(i) == t.charAt(j)) {
                j++;
            }
            pi[i] = j;
        }

        // pi[n-1] 即 s 的最长回文前缀长度
        int longest = pi[n - 1];
        String suffix = s.substring(longest);
        // 剩余后缀反转后拼在最前面
        return new StringBuilder(suffix).reverse().toString() + s;
    }
}

复杂度

  • 时间：O(n)，构造 t 与求前缀函数都是一次线性扫描。
  • 空间：O(n)，t 与 pi 数组各占 O(n)。

易错点与扩展（面试高频考点）

  1. 分隔符必须选 s 中不出现的字符：本题只含小写字母，用 # 安全；若字符集更大要选合适分隔符，否则前缀会跨过分隔符导致错误。
  2. pi 的最后一个值才是答案：是 pi[n-1]（整串 t 的前缀函数末项），不要误取其他位置。
  3. 空串与单字符：s 长度 ≤ 1 时本身就是回文，直接返回，避免构造 t 时越界。
  4. 暴力做法会超时：逐位置判断回文前缀是 O(n^2)，在 5*10^4 规模下会 TLE，必须用 KMP/哈希/Manacher。
  5. 扩展：也可用「字符串哈希 + 二分」找最长回文前缀，或 Manacher 算法求以 0 为起点的最长回文半径；三者同为线性或 O(n log n) 级别。

214. 最短回文串

C++ 实现

class Solution {
public:
    string shortestPalindrome(string s) {
        if (s.size() <= 1) return s;

        string rev(s.rbegin(), s.rend());
        string t = s + "#" + rev;
        int n = t.size();

        vector<int> pi(n, 0);
        for (int i = 1; i < n; i++) {
            int j = pi[i - 1];
            while (j > 0 && t[i] != t[j]) {
                j = pi[j - 1];
            }
            if (t[i] == t[j]) j++;
            pi[i] = j;
        }

        int longest = pi[n - 1];        // s 的最长回文前缀长度
        string suffix = s.substr(longest);
        reverse(suffix.begin(), suffix.end());
        return suffix + s;
    }
};

Python 实现

class Solution:
    def shortestPalindrome(self, s: str) -> str:
        if len(s) <= 1:
            return s

        rev = s[::-1]
        t = s + "#" + rev
        n = len(t)

        pi = [0] * n
        for i in range(1, n):
            j = pi[i - 1]
            while j > 0 and t[i] != t[j]:
                j = pi[j - 1]
            if t[i] == t[j]:
                j += 1
            pi[i] = j

        longest = pi[-1]                # s 的最长回文前缀长度
        suffix = s[longest:][::-1]      # 剩余后缀反转
        return suffix + s
