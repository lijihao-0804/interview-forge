796. 旋转字符串

题目与约束

给定两个字符串, s 和 goal。如果在若干次旋转操作之后，s 能变成 goal ，那么返回 true 。

s 的 旋转操作 就是将 s 最左边的字符移动到最右边。

  • 例如, 若 s = 'abcde'，在旋转一次之后结果就是'bcdea' 。

示例 1：

输入： s = "abcde", goal = "cdeab"

输出： true

解释：

将 s 向左旋转 2 个位置，即可将 "ab" 移动到字符串末尾，得到 "cdeab"，与 goal 相等。

示例 2：

输入： s = "abcde", goal = "abced"

输出： false

解释：

无论对 s 进行多少次旋转，都无法得到 "abced"。由于字符的相对顺序不同，因此 goal 不是 s 的旋转结果。

提示:

  • 1 <= s.length, goal.length <= 100

  • s 和 goal 由小写英文字母组成

核心不变量

长度为 n 的字符串做任意次旋转，得到的全部结果恰好是 s + s 里所有长度为 n 的连续子串。

完整推导

思路推导

  1. 先排除不可能的情况。 旋转只改变字符的先后顺序，不增删字符，所以若 s 与 goal 长度不同，答案一定是 false。

  2. 把全部旋转结果摊平。 对 s = "abcde" 而言，各次旋转依次是 abcde、bcdea、cdeab、deabc、eabcd。若把它们首尾相接写出来，s + s = "abcdeabcde"，你会看到上面这 5 个串恰好是它长度 5 的 5 个连续窗口：abcde、bcdea、cdeab、deabc、eabcd。于是问题被“摊平”成一件事：goal 是不是 s + s 的连续子串。

  3. 一次查找收尾。 只要 s.length == goal.length 且 (s + s).contains(goal) 成立，就说明 goal 是某次旋转的结果，答案返回 true，否则返回 false。

Java 实现（字符串拼接查找）

class Solution {
    public boolean rotateString(String s, String goal) {
        // 长度不同必然无法通过旋转得到
        if (s.length() != goal.length()) {
            return false;
        }
        // 任意次旋转的结果都出现在 s + s 中
        return (s + s).contains(goal);
    }
}

复杂度

  • 时间：O(n)。拼接 s + s 需要 O(n)，随后的子串查找可借助字符串匹配算法在 O(n) 量级完成（朴素实现最坏 O(n²)，但内置查找通常已足够高效）。
  • 空间：O(n)。拼接后的 s + s 需要额外 O(n) 空间。

易错点与扩展（面试高频考点）

  1. 忘记先判长度。 若 goal 比 s 长，goal in s+s 可能误判；长度不等直接返回 false 才是严格正确的。
  2. 空串边界。 当 s 与 goal 都为空时长度相等，(s+s).contains(goal) 为真，符合预期。
  3. 不能省掉 s+s 直接用一次旋转比较。 一次旋转只对应一个结果，必须覆盖所有 n 种旋转，s+s 正是把它们一次性摊平的技巧。
  4. 扩展：KMP。 面试若追问“如何做到严格 O(n) 最坏复杂度”，可手写 KMP 在 s+s 上匹配 goal，避免朴素查找的 O(n²) 退化。

796. 旋转字符串

C++ 实现

#include <string>
using namespace std;

class Solution {
public:
    bool rotateString(string s, string goal) {
        // 长度不同直接排除
        if (s.size() != goal.size()) {
            return false;
        }
        // 任意旋转结果都是 s + s 的长度为 n 的子串
        return (s + s).find(goal) != string::npos;
    }
};

Python 实现

class Solution:
    def rotateString(self, s: str, goal: str) -> bool:
        # 长度不同或 goal 不是 s + s 的子串，均返回 False
        return len(s) == len(goal) and goal in s + s
