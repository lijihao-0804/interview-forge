题目与约束

给你一个整数数组 nums，按要求返回一个新数组 counts。数组 counts 有该性质：counts[i] 的值是 nums[i] 右侧小于 nums[i] 的元素的数量。

示例 1：

输入：nums = [5,2,6,1]
输出：[2,1,1,0]
解释：
5 的右侧有 2 个更小的元素 (2 和 1)
2 的右侧仅有 1 个更小的元素 (1)
6 的右侧有 1 个更小的元素 (1)
1 的右侧有 0 个更小的元素

示例 2：

输入：nums = [-1]
输出：[0]

示例 3：

输入：nums = [-1,-1]
输出：[0,0]

提示：

  • 1 <= nums.length <= 10^5
  • -10^4 <= nums[i] <= 10^4

核心不变量

从右往左扫描，树状数组按值离散化后维护"右侧已扫描元素"的计数；query(rank-1) 恰好是右侧严格小于当前元素的个数。

完整推导

思路推导

  1. 暴力不可行：对每个位置向右扫一遍统计更小元素，时间是 O(n²)，n 到 1e5 会超时。

  2. 抽象成两个操作：从右往左处理，每步需要"查询当前有多少个比 x 小的数"和"把 x 插入集合"。这正是有序集合/BIT 的典型场景。

  3. 值域离散化：nums[i] 范围 [-10^4, 10^4] 且可能有负数。先把所有值排序去重得到 uniq，用二分把每个值映射成 1..u 的排名 rank，值域就被压缩到数组规模。

  4. 树状数组统计：BIT 支持单点 +1 和前缀和查询。从右往左遍历 i： - res[i] = query(rank[i] - 1)，即排名严格小于它（值更小）的元素个数； - 再 add(rank[i])，把当前元素加入结构，供左侧元素统计。

小例子 nums = [5,2,6,1]，uniq = [1,2,5,6]，排名 [3,2,4,1]。从右往左： - 1（rank 1）：query(0)=0，插入 rank 1； - 6（rank 4）：query(3)=1（有 1），插入 rank 4； - 2（rank 2）：query(1)=1（有 1），插入 rank 2； - 5（rank 3）：query(2)=2（有 1,2），插入 rank 3。 结果 [2,1,1,0] ✓

Java 实现（树状数组 Fenwick）

import java.util.Arrays;
import java.util.List;

class Solution {
    public List<Integer> countSmaller(int[] nums) {
        int n = nums.length;
        // 1) 离散化：排序 + 去重
        int[] sorted = nums.clone();
        Arrays.sort(sorted);
        int u = 0;
        int[] uniq = new int[n];
        for (int i = 0; i < n; i++) {
            if (i == 0 || sorted[i] != sorted[i - 1]) {
                uniq[u++] = sorted[i];
            }
        }
        // 2) 每个值映射到 1..u 的排名
        int[] rank = new int[n];
        for (int i = 0; i < n; i++) {
            rank[i] = lowerBound(uniq, u, nums[i]) + 1;
        }
        // 3) 从右往左，用 BIT 统计右侧更小元素个数
        int[] bit = new int[u + 1];
        Integer[] res = new Integer[n];
        for (int i = n - 1; i >= 0; i--) {
            res[i] = query(bit, rank[i] - 1); // 严格小于
            add(bit, rank[i], u);
        }
        return Arrays.asList(res);
    }

    private int lowerBound(int[] a, int len, int target) {
        int lo = 0, hi = len;
        while (lo < hi) {
            int mid = lo + (hi - lo) / 2;
            if (a[mid] < target) lo = mid + 1;
            else hi = mid;
        }
        return lo;
    }

    private void add(int[] bit, int i, int u) {
        for (; i <= u; i += i & (-i)) bit[i]++;
    }

    private int query(int[] bit, int i) {
        int sum = 0;
        for (; i > 0; i -= i & (-i)) sum += bit[i];
        return sum;
    }
}

复杂度

  • 时间：O(n log n)。离散化排序 O(n log n)；之后每个元素一次查询 + 一次插入，各 O(log n)。
  • 空间：O(n)。离散化数组、排名数组、BIT 数组与结果数组均为线性规模。

易错点与扩展（面试高频考点）

  1. "严格小于"不能写成"小于等于"：要查 query(rank-1)，如果查 rank 会把相等元素也算进去，遇到重复值时答案偏大（示例 3 的 [-1,-1] 应为 [0,0]）。
  2. 方向必须是"从右往左"：只有保证 BIT 里存的都是当前元素右侧的元素，查询结果才是"右侧更小"。
  3. 离散化要先去重：用 lower_bound 把相等值映射到同一排名；重复元素共享 rank，才能正确处理相等关系。
  4. BIT 下标从 1 开始：lowbit 写法 i & (-i)，add 向上爬、query 向下减，下标为 0 会陷入死循环。
  5. 可替换解法：归并排序统计"右侧逆序对"（在合并时累加）、线段树、平衡树/树状数组均可，复杂度同为 O(n log n)；归并排序版常数更小但实现更绕。

315. 计算右侧小于当前元素的个数

C++ 实现

#include <vector>
#include <algorithm>
using namespace std;

class Solution {
public:
    vector<int> countSmaller(vector<int>& nums) {
        int n = nums.size();
        // 离散化
        vector<int> sorted(nums);
        sort(sorted.begin(), sorted.end());
        vector<int> uniq;
        for (int i = 0; i < n; ++i) {
            if (i == 0 || sorted[i] != sorted[i - 1]) uniq.push_back(sorted[i]);
        }
        int u = uniq.size();
        vector<int> rank(n);
        for (int i = 0; i < n; ++i) {
            rank[i] = int(lower_bound(uniq.begin(), uniq.end(), nums[i]) - uniq.begin()) + 1;
        }

        vector<int> bit(u + 1, 0), res(n, 0);
        auto add = [&](int i) {
            for (; i <= u; i += i & (-i)) ++bit[i];
        };
        auto query = [&](int i) {
            int s = 0;
            for (; i > 0; i -= i & (-i)) s += bit[i];
            return s;
        };

        for (int i = n - 1; i >= 0; --i) {
            res[i] = query(rank[i] - 1); // 严格小于
            add(rank[i]);
        }
        return res;
    }
};

Python 实现

class Solution:
    def countSmaller(self, nums: list[int]) -> list[int]:
        n = len(nums)
        # 离散化：值 -> 1..u 的排名
        uniq = sorted(set(nums))
        rank = {v: i + 1 for i, v in enumerate(uniq)}
        u = len(uniq)

        bit = [0] * (u + 1)
        res = [0] * n

        def add(i: int) -> None:
            while i <= u:
                bit[i] += 1
                i += i & (-i)

        def query(i: int) -> int:
            s = 0
            while i > 0:
                s += bit[i]
                i -= i & (-i)
            return s

        for i in range(n - 1, -1, -1):
            r = rank[nums[i]]
            res[i] = query(r - 1)   # 严格小于
            add(r)
        return res
