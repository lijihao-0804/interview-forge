# 673. 最长递增子序列的个数

| 题目信息 | 内容 |
|---|---|
| 难度 | 中等 |
| 核心模式 | 动态规划（LIS 长度 + 方案计数） |
| 时间复杂度 | O(n²) |
| 空间复杂度 | O(n) |

## 题目与约束

给定一个未排序的整数数组 `nums`，*返回最长递增子序列的个数*。

**注意** 这个数列必须是 **严格** 递增的。

**示例 1:**

```
输入: [1,3,5,4,7]
输出: 2
解释: 有两个最长递增子序列，分别是 [1, 3, 4, 7] 和 [1, 3, 5, 7]。
```

**示例 2:**

```
输入: [2,2,2,2,2]
输出: 5
解释: 最长递增子序列的长度是 1，并且存在 5 个子序列的长度为 1，因此输出 5。
```

**提示:**

- `1 <= nums.length <= 2000`
- `-10^6 <= nums[i] <= 10^6`

## 核心不变量

> `len[i]` 表示以 `nums[i]` 结尾的最长递增子序列长度，`cnt[i]` 表示以 `nums[i]` 结尾、长度为 `len[i]` 的子序列个数；转移时按「更长的方案被替换 / 等长的方案累加」维护。

## 完整推导

### 思路推导

1. **先只想「长度」**。经典的 O(n²) LIS：`len[i] = 1 + max(len[j])`，其中 `j < i` 且 `nums[j] < nums[i]`。这解决了「最长有多长」，但没解决「有多少个」。

2. **再加一维计数**。设 `cnt[i]` 为以 `nums[i]` 结尾、长度恰为 `len[i]` 的子序列个数。遍历 `j < i` 且 `nums[j] < nums[i]`：
   - 若 `len[j] + 1 > len[i]`：发现更长方案，更新 `len[i] = len[j] + 1`，并把计数直接重置为 `cnt[i] = cnt[j]`（之前较短方案的计数作废）。
   - 若 `len[j] + 1 == len[i]`：找到同样长的另一族方案，`cnt[i] += cnt[j]`。

3. **最后汇总答案**。先求全局最长长度 `maxLen = max(len[i])`，答案就是所有 `len[i] == maxLen` 的位置的 `cnt[i]` 之和。

小例子：`nums = [1,3,5,4,7]`。以 `7` 结尾（下标 4）时，前面 `1,3,5,4` 都比它小；其中 `len[3]=2`（`1,3,4`），`len[2]=3`（`1,3,5`）——等长归并后 `cnt[4] = 2`（`[1,3,4,7]` 与 `[1,3,5,7]`），答案 2 ✓。

4. **重复元素不合并**：严格递增要求 `nums[j] < nums[i]`，相等不能转移，所以 `[2,2,2,2,2]` 中每个位置各自独立，最长长度都是 1，计数 5 ✓。

### Java 实现（DP + 计数）

```java
import java.util.Arrays;

class Solution {
    public int findNumberOfLIS(int[] nums) {
        int n = nums.length;
        if (n == 0) {
            return 0;
        }
        int[] len = new int[n];   // 以 i 结尾的 LIS 长度
        int[] cnt = new int[n];   // 以 i 结尾、达到该长度的方案数
        Arrays.fill(len, 1);
        Arrays.fill(cnt, 1);
        int maxLen = 1;

        for (int i = 0; i < n; i++) {
            for (int j = 0; j < i; j++) {
                if (nums[j] < nums[i]) {          // 严格递增才可接上
                    if (len[j] + 1 > len[i]) {
                        len[i] = len[j] + 1;      // 找到更长方案
                        cnt[i] = cnt[j];
                    } else if (len[j] + 1 == len[i]) {
                        cnt[i] += cnt[j];         // 等长方案累加
                    }
                }
            }
            maxLen = Math.max(maxLen, len[i]);
        }

        // 汇总所有长度为 maxLen 的方案数
        int res = 0;
        for (int i = 0; i < n; i++) {
            if (len[i] == maxLen) {
                res += cnt[i];
            }
        }
        return res;
    }
}
```

### 复杂度

- 时间：O(n²)。两重循环枚举所有 `(j, i)` 数对，`n <= 2000` 可接受。
- 空间：O(n)。`len`、`cnt` 两个长度 n 的数组。

### 易错点与扩展（面试高频考点）

1. **只更新长度忘了重置计数**：当 `len[j]+1 > len[i]` 时必须 `cnt[i] = cnt[j]`，若写成 `+=` 会把已被淘汰的较短方案也累加进去。
2. **等号分支别漏**：`len[j]+1 == len[i]` 时要累加 `cnt[j]`，这是统计多族方案的关键。
3. **严格递增**：条件必须是 `nums[j] < nums[i]`，写成 `<=` 会把相等元素接上，示例 2 答案会出错。
4. **答案是「所有以 maxLen 结尾」之和**：不能只取某一个位置，也不能取 `max(cnt)`。
5. **可扩展**：本题还可用树状数组 / 线段树按值离散化做到 O(n log n)，或用「最长递增子序列 + 前缀和」的 O(n log n) 解法，面试可作进阶展示。

### C++ 实现

```cpp
#include <vector>
#include <algorithm>
using namespace std;

class Solution {
public:
    int findNumberOfLIS(vector<int>& nums) {
        int n = nums.size();
        if (n == 0) return 0;
        vector<int> len(n, 1), cnt(n, 1);
        int maxLen = 1;
        for (int i = 0; i < n; ++i) {
            for (int j = 0; j < i; ++j) {
                if (nums[j] < nums[i]) {
                    if (len[j] + 1 > len[i]) {
                        len[i] = len[j] + 1;
                        cnt[i] = cnt[j];
                    } else if (len[j] + 1 == len[i]) {
                        cnt[i] += cnt[j];
                    }
                }
            }
            maxLen = max(maxLen, len[i]);
        }
        int res = 0;
        for (int i = 0; i < n; ++i) {
            if (len[i] == maxLen) res += cnt[i];
        }
        return res;
    }
};
```

### Python 实现

```python
class Solution:
    def findNumberOfLIS(self, nums: list[int]) -> int:
        n = len(nums)
        if n == 0:
            return 0
        length = [1] * n   # 以 i 结尾的 LIS 长度
        count = [1] * n    # 以 i 结尾的 LIS 方案数
        max_len = 1
        for i in range(n):
            for j in range(i):
                if nums[j] < nums[i]:          # 严格递增
                    if length[j] + 1 > length[i]:
                        length[i] = length[j] + 1
                        count[i] = count[j]
                    elif length[j] + 1 == length[i]:
                        count[i] += count[j]
            max_len = max(max_len, length[i])
        return sum(count[i] for i in range(n) if length[i] == max_len)
```
