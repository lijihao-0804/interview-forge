# 862. 和至少为 K 的最短子数组

| 题目信息 | 内容 |
|---|---|
| 难度 | 困难 |
| 核心模式 | 前缀和 + 单调（递增）双端队列 |
| 时间复杂度 | O(n) |
| 空间复杂度 | O(n) |

## 题目与约束

给你一个整数数组 `nums` 和一个整数 `k` ，找出 `nums` 中和至少为 `k` 的 最短非空子数组 ，并返回该子数组的长度。如果不存在这样的 子数组 ，返回 `-1` 。

子数组 是数组中 连续 的一部分。

 

示例 1：

输入：nums = [1], k = 1  
输出：1

示例 2：

输入：nums = [1,2], k = 4  
输出：-1

示例 3：

输入：nums = [2,-1,2], k = 3  
输出：3

 

提示：

- `1 <= nums.length <= 105`

- `-105 <= nums[i] <= 105`

- `1 <= k <= 109`

[🔗 前往力扣原题验证 →](https://leetcode.cn/problems/shortest-subarray-with-sum-at-least-k/)

## 核心不变量

> 令前缀和 `P[0]=0, P[i]=P[i-1]+nums[i-1]`，子数组 `(i, j]` 的和为 `P[j]-P[i]`；在所有 `P[j]-P[i] >= k` 的配对里，`j-i` 最小即为答案。用单调递增双端队列维护“有用”的候选起点 `i`，每个下标进出队列各一次。

## 完整推导

### 思路推导

1. **为什么要前缀和？** 连续子数组的和用前缀和相减最方便：`sum(i, j] = P[j] - P[i]`。问题变成在 `P` 数组中找一对下标 `i < j`，使 `P[j] - P[i] >= k` 且 `j - i` 最小。

2. **为什么普通滑动窗口不行？** 因为有**负数**，前缀和不是单调的，窗口右移时左边界不一定单调收缩，双指针会失效。我们需要另一种手段在“不确定的前缀和”上找有效配对。

3. **单调队列的两条规则。** 维护一个下标双端队列，队列里的 `P` 值**严格递增**：
   - **收割答案**：若 `P[j] - P[队首] >= k`，说明以 `队首` 为起点的这段已满足条件；由于队列递增，后面的起点只会更靠右、更不可能更短，于是可以放心把队首弹出，并用 `j - 队首` 更新答案（一次 `while` 连续收割所有满足的队首）。
   - **维持单调**：若 `P[队尾] >= P[j]`，说明队尾这个起点既比 `j` 靠左、`P` 值又更大，将来只会更差，永远不会成为最优起点，直接弹出。

4. **小例子。** `nums = [2,-1,2], k = 3`，前缀和 `P = [0,2,1,3]`。走到 `j=3` 时 `P[3]=3`，队首 `P[0]=0`，差 3 ≥ 3，弹出并得到长度 `3-0=3`。答案 3。

5. **为什么是线性？** 每个下标 `j` 最多入队一次、出队一次（无论做队首还是队尾弹出），均摊 O(1)，总时间 O(n)。

### Java 实现（前缀和 + 单调双端队列）

```java
import java.util.ArrayDeque;
import java.util.Deque;

class Solution {
    public int shortestSubarray(int[] nums, int k) {
        int n = nums.length;
        long[] pre = new long[n + 1];          // pre[i] = nums[0..i-1] 之和
        for (int i = 0; i < n; i++) {
            pre[i + 1] = pre[i] + nums[i];
        }

        Deque<Integer> dq = new ArrayDeque<>(); // 存下标，pre 值严格递增
        int ans = Integer.MAX_VALUE;

        for (int j = 0; j <= n; j++) {
            // 1. 收割所有满足 pre[j]-pre[队首] >= k 的起点
            while (!dq.isEmpty() && pre[j] - pre[dq.peekFirst()] >= k) {
                ans = Math.min(ans, j - dq.pollFirst());
            }
            // 2. 维护单调递增：比 pre[j] 大的队尾永远不可能更优
            while (!dq.isEmpty() && pre[dq.peekLast()] >= pre[j]) {
                dq.pollLast();
            }
            // 3. 当前下标入队
            dq.offerLast(j);
        }

        return ans == Integer.MAX_VALUE ? -1 : ans;
    }
}
```

### 复杂度

- 时间：O(n)。每个下标最多入队一次、出队一次，均摊常数；前缀和预处理 O(n)。
- 空间：O(n)。`pre` 数组与双端队列长度均为 O(n)。

### 易错点与扩展（面试高频考点）

1. **直接用滑动窗口必错。** 因为存在负数，前缀和不单调，双指针收缩条件不成立；这道题是“单调队列”和“滑动窗口”分界的经典考点。
2. **前缀和/答案要用 `long`。** `nums` 长度 `10^5`、元素 `10^5`，前缀和可达 `10^10`，必须用 64 位整数，`int` 会溢出。
3. **出队顺序要对。** 先做队首“收割答案”，再做队尾“维护单调”，最后入队；顺序写反可能漏掉某些最优长度或让单调性被破坏。
4. **计数细节。** 子数组 `(i, j]` 长度为 `j - i`，不是 `j - i + 1`；`P` 多设一个 `P[0]=0` 就是为此。
5. **扩展：还有“前缀和 + 二分”做法。** 维护一个按 `P` 值递增的下标序列（本质就是单调队列）并对当前 `P[j]` 二分找最大 `i` 使 `P[j]-P[i] >= k`，时间 O(n log n)、空间 O(n)，常数更大但仍可过。

## 力扣原题

[862. 和至少为 K 的最短子数组](https://leetcode.cn/problems/shortest-subarray-with-sum-at-least-k/)

### C++ 实现

```cpp
#include <vector>
#include <deque>
#include <climits>
#include <algorithm>
using namespace std;

class Solution {
public:
    int shortestSubarray(vector<int>& nums, int k) {
        int n = nums.size();
        vector<long long> pre(n + 1, 0);
        for (int i = 0; i < n; i++) {
            pre[i + 1] = pre[i] + nums[i];
        }

        deque<int> dq; // 存下标，pre 值严格递增
        int ans = INT_MAX;

        for (int j = 0; j <= n; j++) {
            while (!dq.empty() && pre[j] - pre[dq.front()] >= k) {
                ans = min(ans, j - dq.front());
                dq.pop_front();
            }
            while (!dq.empty() && pre[dq.back()] >= pre[j]) {
                dq.pop_back();
            }
            dq.push_back(j);
        }

        return ans == INT_MAX ? -1 : ans;
    }
};
```

### Python 实现

```python
from typing import List
from collections import deque

class Solution:
    def shortestSubarray(self, nums: List[int], k: int) -> int:
        n = len(nums)
        pre = [0] * (n + 1)
        for i in range(n):
            pre[i + 1] = pre[i] + nums[i]

        dq = deque()          # 存下标，pre 值严格递增
        ans = n + 1           # 用哨兵表示“不存在”

        for j in range(n + 1):
            while dq and pre[j] - pre[dq[0]] >= k:
                ans = min(ans, j - dq.popleft())
            while dq and pre[dq[-1]] >= pre[j]:
                dq.pop()
            dq.append(j)

        return -1 if ans == n + 1 else ans
```
