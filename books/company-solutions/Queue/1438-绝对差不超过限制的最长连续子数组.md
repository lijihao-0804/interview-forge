# 1438. 绝对差不超过限制的最长连续子数组

| 题目信息 | 内容 |
|---|---|
| 难度 | 中等 |
| 核心模式 | 滑动窗口 + 单调队列维护窗口内的最大值与最小值 |
| 时间复杂度 | O(n) |
| 空间复杂度 | O(n) |

## 题目与约束

给你一个整数数组 `nums` 和一个整数 `limit`。

请你返回 **最长非空子数组** 的长度，要求该子数组中 **任意两个元素** 之间的差的 **绝对值** 都 **小于或等于** `limit`。

**示例 1：**

```
输入：nums = [8,2,4,7], limit = 4
输出：2
```

解释：检查所有子数组并计算最大绝对差后可知，满足条件的子数组有 `[8]`、`[2]`、`[4]`、`[7]`、`[2,4]`、`[4,7]` 等，其长度都不超过 2。例如 `[8,2]` 的最大绝对差为 `|8-2| = 6 > 4` 被排除，`[2,4,7]` 的最大绝对差为 `|7-2| = 5 > 4` 也被排除（注意元素对 `(2,7)` 不相邻但仍需比较）。因此最长子数组长度为 2。

**示例 2：**

```
输入：nums = [10,1,2,4,7,2], limit = 5
输出：4
```

解释：子数组 `[2,4,7,2]` 满足条件，其中任意两个元素之间的绝对差都不超过 5（最大为 `|7-2| = 5`）。该子数组无法向左扩展，因为 `[1,2,4,7,2]` 含元素对 `(1,7)`，其绝对差为 `|7-1| = 6 > 5`。因此最长子数组长度为 4。

**示例 3：**

```
输入：nums = [4,2,2,2,4,4,2,2], limit = 0
输出：3
```

解释：由于 `limit = 0`，子数组中任意两个元素都必须相等，因此只有由相同元素连续组成的子数组才满足条件。满足条件的最长子数组为 `[2,2,2]`，长度为 3。

**提示：**

- `1 <= nums.length <= 10^5`
- `1 <= nums[i] <= 10^9`
- `0 <= limit <= 10^9`

## 核心不变量

> 在一个连续窗口内，「任意两元素之差的绝对值都 ≤ limit」等价于「窗口最大值 − 窗口最小值 ≤ limit」。因此只要用两个单调队列实时维护窗口的极值，窗口合法性就能 O(1) 判断。

## 完整推导

### 思路推导

1. **把「任意两元素」化简成两个极值**
   窗口内任意两元素之差的最大绝对值，就是「最大值 − 最小值」。所以判断一个窗口是否合法，只需要知道窗口内的最大值和最小值，二者相减与 `limit` 比较即可，不需要两两比较。

2. **滑动窗口保证连续性**
   要求的是「连续子数组」，天然适合双指针滑动窗口：`right` 不断右扩，把元素纳入窗口；一旦窗口不合法（`max − min > limit`），就让 `left` 右移收缩，直到重新合法。全程记录窗口长度的最大值。

3. **如何 O(1) 取窗口极值——单调队列**
   如果每次都遍历窗口求最大最小值，会退化到 O(n²)（甚至 O(n·w)）。用两个双端队列分别维护：
   - `maxQ`：从队首到队尾 **单调递减**，队首就是当前窗口最大值；
   - `minQ`：从队首到队尾 **单调递增**，队首就是当前窗口最小值。

   新元素入队时，把队尾所有「不可能再成为极值」的元素弹掉（求最大值时弹掉更小的，求最小值时弹掉更大的），再把新元素压入队尾。这样每个元素至多进出队各一次，摊还 O(1)。

4. **收缩时同步清理队首**
   当 `maxQ.peekFirst() − minQ.peekFirst() > limit` 时，说明左端元素 `nums[left]` 需要移出窗口；若它恰好是某个队列的队首，就把它从该队首弹出，然后 `left++`。反复直到合法。小例子：`nums=[8,2,4,7], limit=4`，右扩到 `[8,2]` 时 `max−min=6>4`，移出 8 后窗口 `[2]` 合法，最终最长长度为 2。

### Java 实现（longestSubarray）

```java
import java.util.ArrayDeque;
import java.util.Deque;

class Solution {
    public int longestSubarray(int[] nums, int limit) {
        // maxQ 单调递减，队首为窗口最大值；minQ 单调递增，队首为窗口最小值
        Deque<Integer> maxQ = new ArrayDeque<>();
        Deque<Integer> minQ = new ArrayDeque<>();
        int left = 0, ans = 0;

        for (int right = 0; right < nums.length; right++) {
            // 维护最大值单调递减：弹掉队尾比新元素小的
            while (!maxQ.isEmpty() && maxQ.peekLast() < nums[right]) {
                maxQ.pollLast();
            }
            maxQ.offerLast(nums[right]);

            // 维护最小值单调递增：弹掉队尾比新元素大的
            while (!minQ.isEmpty() && minQ.peekLast() > nums[right]) {
                minQ.pollLast();
            }
            minQ.offerLast(nums[right]);

            // 窗口不合法时收缩左边界
            while (maxQ.peekFirst() - minQ.peekFirst() > limit) {
                if (maxQ.peekFirst() == nums[left]) maxQ.pollFirst();
                if (minQ.peekFirst() == nums[left]) minQ.pollFirst();
                left++;
            }

            // 当前窗口合法，更新答案
            ans = Math.max(ans, right - left + 1);
        }
        return ans;
    }
}
```

### 复杂度

- 时间：O(n)。`right`、`left` 各自单调前进，每个元素最多入队、出队各一次，单调队列操作摊还 O(1)，整体线性。
- 空间：O(n)。两个单调队列最坏情况下各自保存 O(n) 个元素（如数组单调时）。若只存下标也能控制在 O(n)。

### 易错点与扩展（面试高频考点）

1. **队列里存值还是存下标**：存值写法更直观，但收缩时靠「队首值是否等于 `nums[left]`」判断是否弹出；存下标写法可直接比较下标 `<= left` 来清理，更稳妥。两种都要保证出队与左指针同步。
2. **收缩用 `while` 而非 `if`**：一次右扩只能加入一个元素，但可能使 `max−min` 超出很多，需要循环收缩直到重新合法，写 `if` 会漏收缩。
3. **单调方向写反**：求最大值要维护 **递减** 队列（弹掉更小的队尾），求最小值要维护 **递增** 队列（弹掉更大的队尾），两者方向相反，最容易写反导致极值取错。
4. **等号处理**：弹队尾时用严格 `<` / `>`（保留相等元素）或 `<=` / `>=`（去重）都不影响正确性，但需与出队逻辑一致，避免误删仍可能成为极值的元素。
5. **扩展**：同类题如「滑动窗口最大值」（LeetCode 239）是单调队列模板题；「和至少为 K 的最短子数组」（862）则换成前缀和 + 单调双端队列。掌握「滑动窗口 + 单调队列维护极值」这一套模板，可迁移到大量区间最值约束题。

## 力扣原题

[1438. 绝对差不超过限制的最长连续子数组](https://leetcode.cn/problems/longest-continuous-subarray-with-absolute-diff-less-than-or-equal-to-limit/)

### C++ 实现

```cpp
#include <vector>
#include <deque>
#include <algorithm>
using namespace std;

class Solution {
public:
    int longestSubarray(vector<int>& nums, int limit) {
        deque<int> maxQ, minQ; // maxQ 单调递减，minQ 单调递增（存值）
        int left = 0, ans = 0;
        for (int right = 0; right < (int)nums.size(); right++) {
            while (!maxQ.empty() && maxQ.back() < nums[right]) maxQ.pop_back();
            maxQ.push_back(nums[right]);

            while (!minQ.empty() && minQ.back() > nums[right]) minQ.pop_back();
            minQ.push_back(nums[right]);

            while (maxQ.front() - minQ.front() > limit) {
                if (maxQ.front() == nums[left]) maxQ.pop_front();
                if (minQ.front() == nums[left]) minQ.pop_front();
                left++;
            }
            ans = max(ans, right - left + 1);
        }
        return ans;
    }
};
```

### Python 实现

```python
from collections import deque
from typing import List

class Solution:
    def longestSubarray(self, nums: List[int], limit: int) -> int:
        max_q = deque()  # 存下标，对应值单调递减
        min_q = deque()  # 存下标，对应值单调递增
        left = 0
        ans = 0
        for right, x in enumerate(nums):
            while max_q and nums[max_q[-1]] <= x:
                max_q.pop()
            max_q.append(right)

            while min_q and nums[min_q[-1]] >= x:
                min_q.pop()
            min_q.append(right)

            while nums[max_q[0]] - nums[min_q[0]] > limit:
                if max_q[0] == left:
                    max_q.popleft()
                if min_q[0] == left:
                    min_q.popleft()
                left += 1

            ans = max(ans, right - left + 1)
        return ans
```
