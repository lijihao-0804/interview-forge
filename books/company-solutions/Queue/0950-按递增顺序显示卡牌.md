# 950. 按递增顺序显示卡牌

| 题目信息 | 内容 |
|---|---|
| 难度 | 中等 |
| 核心模式 | 排序 + 逆向队列模拟 |
| 时间复杂度 | O(n log n)（排序为主） |
| 空间复杂度 | O(n) |

## 题目与约束

牌组中的每张卡牌都对应有一个唯一的整数。你可以按你想要的顺序对这套卡片进行排序。

最初，这些卡牌在牌组里是正面朝下的（即，未显示状态）。

现在，重复执行以下步骤，直到显示所有卡牌为止：

- 从牌组顶部抽一张牌，显示它，然后将其从牌组中移出。

- 如果牌组中仍有牌，则将下一张处于牌组顶部的牌放在牌组的底部。

- 如果仍有未显示的牌，那么返回步骤 1。否则，停止行动。

返回能以递增顺序显示卡牌的牌组顺序。

答案中的第一张牌被认为处于牌堆顶部。

 

示例：

```
<strong>输入：</strong>[17,13,11,2,3,5,7]
<strong>输出：</strong>[2,13,3,11,5,17,7]
<strong>解释：
</strong>我们得到的牌组顺序为 [17,13,11,2,3,5,7]（这个顺序不重要），然后将其重新排序。
重新排序后，牌组以 [2,13,3,11,5,17,7] 开始，其中 2 位于牌组的顶部。
我们显示 2，然后将 13 移到底部。牌组现在是 [3,11,5,17,7,13]。
我们显示 3，并将 11 移到底部。牌组现在是 [5,17,7,13,11]。
我们显示 5，然后将 17 移到底部。牌组现在是 [7,13,11,17]。
我们显示 7，并将 13 移到底部。牌组现在是 [11,17,13]。
我们显示 11，然后将 17 移到底部。牌组现在是 [13,17]。
我们展示 13，然后将 17 移到底部。牌组现在是 [17]。
我们显示 17。
由于所有卡片都是按递增顺序排列显示的，所以答案是正确的。
```

 

提示：

- `1 <= A.length <= 1000`

- `1 <= A[i] <= 10^6`

- 对于所有的 `i != j`，`A[i] != A[j]`

[🔗 前往力扣原题验证 →](https://leetcode.cn/problems/reveal-cards-in-increasing-order/)

## 核心不变量

> 揭示顺序是「从小到大」；模拟揭示过程时，每个被抽到的位置恰好接收当前剩余的最小牌，抽完后把下一个位置挪到队尾。

## 完整推导

### 思路推导

1. **正向难算，反向简单**：题目给了「怎么揭示」，要我们倒推「初始怎么摆」。正向模拟要知道每个位置最终会显示第几小的牌，很绕；反过来——既然揭示值递增，那第一张被拿到的位置一定放最小值，第二个被拿到的位置放次小值……

2. **用下标队列模拟「抽牌 + 挪牌」**：一开始把位置下标 `0..n-1` 排成一个队列，模拟「牌组从上到下」。队头就是当前要被抽的位置。按牌值从小到大依次处理：把当前最小的牌放到队头位置上；然后如果队列还有元素，把新的队头挪到队尾——这正好复刻「显示后，把下一张牌放到底部」的动作。

3. **为什么能还原**：正向揭示与「队列取队头、再轮转」完全同构，只是我们让牌值按递增顺序填入被抽到的位置，得到的正是能保证递增揭示的初始排列。

4. **小例子**：排序后牌 `[2,3,5,7,11,13,17]`，下标队列 `[0..6]`。
   - 放 `2` 到位置 0 → 队列 `[1,2,3,4,5,6]`，轮转 → `[2,3,4,5,6,1]`
   - 放 `3` 到位置 2 → 轮转 → `[4,5,6,1,3]`
   - 放 `5` 到位置 4 → 轮转 → `[6,1,3,5]`
   - 放 `7` 到位置 6 → 轮转 → `[3,5,1]`
   - 放 `11` 到位置 3 → 轮转 → `[5,1]`
   - 放 `13` 到位置 5 → 轮转 → `[1]`
   - 放 `17` 到位置 1。
   最终数组：位置 0..6 值为 `[2,13,3,11,5,17,7]`，与答案一致。

### Java 实现（排序 + 下标队列逆向填充）

```java
import java.util.ArrayDeque;
import java.util.Arrays;
import java.util.Deque;

class Solution {
    public int[] deckRevealedIncreasing(int[] deck) {
        int n = deck.length;
        Arrays.sort(deck);                 // 揭示顺序就是从这张表里按序取

        Deque<Integer> idx = new ArrayDeque<>();
        for (int i = 0; i < n; i++) idx.offerLast(i); // 下标队列模拟牌组

        int[] res = new int[n];
        for (int card : deck) {
            res[idx.pollFirst()] = card;   // 队头位置接收当前最小的剩余牌
            if (!idx.isEmpty()) {
                idx.offerLast(idx.pollFirst()); // 把新的队头挪到队尾（对应“下一张放到底部”）
            }
        }
        return res;
    }
}
```

### 复杂度

- 时间：O(n log n)，瓶颈在排序；队列模拟是 O(n)。
- 空间：O(n)，下标队列与结果数组。

### 易错点与扩展（面试高频考点）

1. **顺序不要搞反**：必须先「填队头」再「轮转」，模拟的是「先显示，再把下一张放底部」。若先轮转再填，结果就错位了。

2. **最后一次轮转要判空**：当队列只剩一个下标、填完它之后，`pollFirst()` 再 `offerLast()` 会因队列已空而出错，所以要用 `if (!idx.isEmpty())` 保护。

3. **答案与「牌值」无关，只与「相对大小」有关**：因为只要求递增揭示，所以排序后按下标填值即可；不要去猜原始牌值。

4. **用 `ArrayDeque` 而非 `Stack`**：这里需要的是队列（FIFO）语义，`pollFirst`/`offerLast` 表达最清晰。

5. **扩展**：该题本质是「约瑟夫式轮转」排列的构造问题，同一模型可用于生成任意「每隔一个取一个」的排列。

## 力扣原题

[950. 按递增顺序显示卡牌](https://leetcode.cn/problems/reveal-cards-in-increasing-order/)

### C++ 实现

```cpp
class Solution {
public:
    vector<int> deckRevealedIncreasing(vector<int>& deck) {
        int n = deck.size();
        sort(deck.begin(), deck.end());

        deque<int> idx;
        for (int i = 0; i < n; i++) idx.push_back(i);

        vector<int> res(n);
        for (int card : deck) {
            res[idx.front()] = card;
            idx.pop_front();
            if (!idx.empty()) {
                idx.push_back(idx.front());
                idx.pop_front();
            }
        }
        return res;
    }
};
```

### Python 实现

```python
from typing import List
from collections import deque

class Solution:
    def deckRevealedIncreasing(self, deck: List[int]) -> List[int]:
        n = len(deck)
        deck.sort()

        idx = deque(range(n))
        res = [0] * n
        for card in deck:
            res[idx.popleft()] = card      # 队头位置放当前最小的牌
            if idx:
                idx.append(idx.popleft())  # 把下一张挪到队尾
        return res
```
