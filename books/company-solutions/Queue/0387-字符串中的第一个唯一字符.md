# 387. 字符串中的第一个唯一字符

| 题目信息 | 内容 |
|---|---|
| 难度 | 简单 |
| 核心模式 | 两遍扫描：先统计词频，再找第一个词频为 1 的下标 |
| 时间复杂度 | O(n) |
| 空间复杂度 | O(1)（字母表大小固定为 26） |

## 题目与约束

给定一个字符串 `s` ，找到 它的第一个不重复的字符，并返回它的索引 。如果不存在，则返回 `-1` 。

 

示例 1：

```
<strong>输入:</strong> s = "leetcode"
<strong>输出:</strong> 0
```

示例 2:

```
<strong>输入:</strong> s = "loveleetcode"
<strong>输出:</strong> 2
```

示例 3:

```
<strong>输入:</strong> s = "aabb"
<strong>输出:</strong> -1
```

 

提示:

- `1 <= s.length <= 105`

- `s` 只包含小写字母

[🔗 前往力扣原题验证 →](https://leetcode.cn/problems/first-unique-character-in-a-string/)

## 核心不变量

> 只出现一次的字符其词频恰为 1；按原字符串下标从小到大找第一个词频为 1 的位置即为答案。

## 完整推导

### 思路推导

1. **先知道每个字符出现几次**

   要判断「不重复」，必须先知道每个字符出现的次数。用一个长度为 26 的计数数组 `cnt` 做一次词频统计。

2. **再按原顺序找第一个**

   统计完后再从左到右扫一遍 `s`，第一个满足 `cnt[c] == 1` 的下标就是「第一个唯一字符」。扫完都没有，就返回 `-1`。

3. **小例子（"loveleetcode"）**

   其中 `l`、`o` 各出现两次，`e` 出现四次，只有 `v`、`t`、`c`、`d` 各出现一次。按原序从左往右，第一个只出现一次的是下标 2 的 `v`，所以返回 2。

4. **为什么用数组而不是哈希表**

   字符串只含小写字母，26 个桶的计数数组最简单、最快，空间是常数。

### Java 实现（firstUniqChar）

```java
class Solution {
    public int firstUniqChar(String s) {
        int[] cnt = new int[26];
        // 第一遍：统计每个字符出现次数
        for (int i = 0; i < s.length(); i++) {
            cnt[s.charAt(i) - 'a']++;
        }
        // 第二遍：按原顺序找第一个只出现一次的字符
        for (int i = 0; i < s.length(); i++) {
            if (cnt[s.charAt(i) - 'a'] == 1) {
                return i;
            }
        }
        return -1;
    }
}
```

### 复杂度

- 时间：O(n)，两次线性扫描，每次 O(n)。
- 空间：O(1)，计数数组固定 26 大小。

### 易错点与扩展（面试高频考点）

1. **两遍顺序不能反**：必须先把整串统计完，再从左边找；边扫边判断会因为后面还可能再出现而误判。
2. **字符集假设**：题设只含小写字母，用 `int[26]`；若换成任意字符应改用哈希表，空间为 O(Σ)。
3. **返回的是下标不是字符**：题目要索引；空串或全重复返回 `-1`。
4. **扩展：用队列优化**。维护一个「按首次出现顺序」的队列并配合词频数组，边扫描边把已重复的字符从队头弹出，队首即第一个唯一字符（本题 tag 含 Queue）。
5. **扩展：一次遍历**。用哈希表记录「首次下标」，第二次出现时把它标记为特殊值，最后取最小下标，思路与两遍法等价。

## 力扣原题

[387. 字符串中的第一个唯一字符](https://leetcode.cn/problems/first-unique-character-in-a-string/)

### C++ 实现

```cpp
class Solution {
public:
    int firstUniqChar(string s) {
        int cnt[26] = {0};
        for (char c : s) cnt[c - 'a']++;
        for (int i = 0; i < (int)s.size(); ++i) {
            if (cnt[s[i] - 'a'] == 1) return i;
        }
        return -1;
    }
};
```

### Python 实现

```python
class Solution:
    def firstUniqChar(self, s: str) -> int:
        cnt = [0] * 26
        for ch in s:
            cnt[ord(ch) - ord('a')] += 1
        for i, ch in enumerate(s):
            if cnt[ord(ch) - ord('a')] == 1:
                return i
        return -1
```
