# 990. 等式方程的可满足性

| 题目信息 | 内容 |
|---|---|
| 难度 | 中等 |
| 核心模式 | 并查集：先合并所有相等关系，再检验所有不等关系 |
| 时间复杂度 | O(n·α(26)) ≈ O(n) |
| 空间复杂度 | O(26) = O(1) |

## 题目与约束

给定一个由表示变量之间关系的字符串方程组成的数组，每个字符串方程 `equations[i]` 的长度为 `4`，并采用两种不同的形式之一：`"a==b"` 或 `"a!=b"`。在这里，a 和 b 是小写字母（不一定不同），表示单字母变量名。

只有当可以将整数分配给变量名，以便满足所有给定的方程时才返回 `true`，否则返回 `false`。 

 

示例 1：

输入：["a==b","b!=a"]  
输出：false  
解释：如果我们指定，a = 1 且 b = 1，那么可以满足第一个方程，但无法满足第二个方程。没有办法分配变量同时满足这两个方程。

示例 2：

输入：["b==a","a==b"]  
输出：true  
解释：我们可以指定 a = 1 且 b = 1 以满足满足这两个方程。

示例 3：

输入：["a==b","b==c","a==c"]  
输出：true

示例 4：

输入：["a==b","b!=c","c==a"]  
输出：false

示例 5：

输入：["c==c","b==d","x!=z"]  
输出：true

 

提示：

- `1 <= equations.length <= 500`

- `equations[i].length == 4`

- `equations[i][0]` 和 `equations[i][3]` 是小写字母

- `equations[i][1]` 要么是 `'='`，要么是 `'!'`

- `equations[i][2]` 是 `'='`

[🔗 前往力扣原题验证 →](https://leetcode.cn/problems/satisfiability-of-equality-equations/)

## 核心不变量

> 所有 `"a==b"` 约束把 26 个变量划分成若干等价类；当且仅当每一条 `"a!=b"` 的两个变量都不在同一个等价类中时，才存在一组整数赋值满足全部方程。

## 完整推导

### 思路推导

1. **直觉与痛点（相等是"传染"的）**
   `a==b`、`b==c` 会推出 `a==c`，相等关系具有传递性。手工去推这些连锁关系既繁琐又容易漏。凡是"判断元素是否属于同一个连通/等价集合"的问题，都是并查集（Union-Find）的拿手好戏。

2. **破局思路（两遍扫描）**
   - **第一遍**：把所有 `"=="` 方程的两端做 `union`，把该合并的变量全部合并成一个等价类。
   - **第二遍**：逐条检查 `"!="` 方程，若它两端的变量 `find` 结果相同，说明它们既要求相等又要求不等，矛盾，立即返回 `false`。

3. **关键追问（为什么必须分成两遍？）**
   如果一边处理 `==` 一边处理 `!=`，那么当遇到某条 `!=` 时，与它相关的相等关系可能还没全部合并进来，就会误判为"无矛盾"。必须先让所有相等关系定型，再统一验证不等关系。

   小例子：`["a==b","b!=c","c==a"]`。第一遍合并出 `{a,b,c}` 同一类；第二遍看 `b!=c`，两者同类 → 矛盾，返回 `false`。

4. **收尾**
   全部 `"!="` 都通过检查，则返回 `true`。

### Java 实现（equationsPossible）

```java
class Solution {
    private int[] parent = new int[26];

    // 查找根节点，带路径压缩（隔代压缩）
    private int find(int x) {
        while (parent[x] != x) {
            parent[x] = parent[parent[x]];
            x = parent[x];
        }
        return x;
    }

    private void union(int x, int y) {
        int rx = find(x), ry = find(y);
        if (rx != ry) {
            parent[rx] = ry;
        }
    }

    public boolean equationsPossible(String[] equations) {
        // 初始化：每个字母各自成为独立集合
        for (int i = 0; i < 26; i++) {
            parent[i] = i;
        }
        // 第一遍：合并所有 "a==b"
        for (String e : equations) {
            if (e.charAt(1) == '=') {          // 形如 "a==b"
                union(e.charAt(0) - 'a', e.charAt(3) - 'a');
            }
        }
        // 第二遍：检验所有 "a!=b"
        for (String e : equations) {
            if (e.charAt(1) == '!') {           // 形如 "a!=b"
                int a = e.charAt(0) - 'a';
                int b = e.charAt(3) - 'a';
                if (find(a) == find(b)) {       // 既相等又不等，矛盾
                    return false;
                }
            }
        }
        return true;
    }
}
```

### 复杂度

- 时间：O(n·α(26))，近似 O(n)。每条方程只做常数次并查集操作，`α` 为反阿克曼函数，实际可视为常数；字母表固定为 26，所以整体随方程数线性。
- 空间：O(26) = O(1)。只需一个大小 26 的父节点数组，与输入规模无关。

### 易错点与扩展（面试高频考点）

1. **顺序不能反**：必须先完整合并所有 `"=="`，再检查 `"!="`；把两类方程混在一遍处理会漏判传递相等。
2. **判断符号的位置**：`e.charAt(1) == '='` 表示 `"=="`，`e.charAt(1) == '!'` 表示 `"!="`，两者靠下标 1 区分，别去比较下标 2。
3. **自反情况**：`"a!=a"` 一定矛盾（同类），`"a==a"` 永远成立；用并查集统一处理即可自然覆盖，无需特判。
4. **只映射 26 个小写字母**：下标用 `c - 'a'`，不要用字符本身或 ASCII 值当数组下标。
5. **扩展**：并查集还常用于"账户合并"（LeetCode 721）、"冗余连接"（LeetCode 684/685）、"岛屿数量 II"（LeetCode 305）等；带权并查集可进一步处理"带比例关系的等式"（LeetCode 399 除法求值）。

### C++ 实现

```cpp
#include <vector>
#include <string>
using namespace std;

class Solution {
    int parent[26];

    int find(int x) {
        while (parent[x] != x) {
            parent[x] = parent[parent[x]]; // 路径压缩
            x = parent[x];
        }
        return x;
    }

    void unite(int x, int y) {
        int rx = find(x), ry = find(y);
        if (rx != ry) parent[rx] = ry;
    }

public:
    bool equationsPossible(vector<string>& equations) {
        for (int i = 0; i < 26; i++) parent[i] = i;
        // 第一遍：合并所有 "=="
        for (auto& e : equations) {
            if (e[1] == '=') {
                unite(e[0] - 'a', e[3] - 'a');
            }
        }
        // 第二遍：检查所有 "!="
        for (auto& e : equations) {
            if (e[1] == '!') {
                if (find(e[0] - 'a') == find(e[3] - 'a')) return false;
            }
        }
        return true;
    }
};
```

### Python 实现

```python
from typing import List

class Solution:
    def equationsPossible(self, equations: List[str]) -> bool:
        parent = list(range(26))

        def find(x: int) -> int:
            while parent[x] != x:
                parent[x] = parent[parent[x]]  # 路径压缩
                x = parent[x]
            return x

        def union(x: int, y: int) -> None:
            rx, ry = find(x), find(y)
            if rx != ry:
                parent[rx] = ry

        # 第一遍：合并所有相等关系
        for e in equations:
            if e[1] == '=':
                union(ord(e[0]) - ord('a'), ord(e[3]) - ord('a'))

        # 第二遍：检查所有不等关系
        for e in equations:
            if e[1] == '!':
                if find(ord(e[0]) - ord('a')) == find(ord(e[3]) - ord('a')):
                    return False

        return True
```
