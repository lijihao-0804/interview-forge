# 305. 岛屿数量 II

| 题目信息 | 内容 |
|---|---|
| 难度 | 困难 |
| 核心模式 | 并查集 + 逐点激活，合并邻居时动态维护岛屿计数 |
| 时间复杂度 | O(k·α(mn))，α 为反阿克曼函数，近似常数 |
| 空间复杂度 | O(mn) |

## 题目与约束

给你一个大小为 `m x n` 的二进制网格 `grid`。网格表示一个地图，其中 `0` 表示水，`1` 表示陆地。最初，`grid` 中的所有单元格都是水（都为 `0`）。

你可以执行以下操作：`addLand` 操作将位置 `(row, col)` 的水变成陆地。

给定 `m` 和 `n`，以及一个长度为 `k` 的数组 `positions`，其中 `positions[i] = [ri, ci]` 表示第 `i` 次操作在网格位置 `(ri, ci)` 上添加陆地。

返回一个整数数组 `answer`，其中 `answer[i]` 是第 `i` 次 `addLand` 操作后，网格中**岛屿的数量**。

**岛屿**的定义：被水包围的陆地，通过水平或垂直方向连接相邻的陆地形成。你可以假设网格的四个边缘都被水包围。

**示例 1：**

```
输入：m = 3, n = 3, positions = [[0,0],[0,1],[1,2],[2,1]]
输出：[1,1,2,3]
解释：
最初，3x3 的网格全是水。
第 0 次 addLand(0,0)：岛屿数 1。
第 1 次 addLand(0,1)：与 (0,0) 相邻，岛屿数仍为 1。
第 2 次 addLand(1,2)：与已有陆地不相邻，岛屿数变为 2。
第 3 次 addLand(2,1)：与 (1,2) 只是对角、并不相邻，无陆地邻居，岛屿数变为 3。
```

**示例 2：**

```
输入：m = 1, n = 1, positions = [[0,0]]
输出：[1]
```

**提示：**

- `1 <= m, n, positions.length <= 10^4`
- `1 <= m * n <= 10^4`
- `positions[i].length == 2`
- `0 <= ri < m`
- `0 <= ci < n`

**进阶：** 你能在时间复杂度 `O(k log(mn))` 内解决此问题吗？

## 核心不变量

> 每激活一个新陆地，先把岛屿数 `+1`；随后检查上下左右四个相邻陆地，若分属不同连通块就合并并把岛屿数 `-1`。并查集的连通块数始终等于当前岛屿数。

## 完整推导

### 思路推导

1. **朴素做法为什么不行？** 每次加陆地都重新做一遍洪水填充（DFS/BFS）统计岛屿，单次 O(mn)，k 次就是 O(k·mn)，在 `m*n, k <= 10^4` 时最坏约 `10^8`，浪费且易超时。

2. **把“增量”利用起来**：陆地是一个一个加进来的，每次最多只影响**新格子及其四邻**。用并查集维护“哪些陆地属于同一个岛”，就能把每次变化的代价压到接近常数。

3. **小例子（示例 1）**：
   - 加 `(0,0)`：无邻居 → `count=0+1=1`。
   - 加 `(0,1)`：邻居 `(0,0)` 已是陆地且不同根 → 合并，`count=2-1=1`。
   - 加 `(1,2)`：无陆地邻居 → `count=1+1=2`。
   - 加 `(2,1)`：与 `(1,2)` 只是对角、并不相邻，无陆地邻居 → `count=2+1=3`。

4. **重复位置**：如果 `positions` 里出现已经变成陆地的格子，按题意这不算新增岛屿，直接沿用当前 `count`。

### Java 实现（并查集）

```java
import java.util.ArrayList;
import java.util.Arrays;
import java.util.List;

class Solution {
    private int[] parent;   // parent[i] == -1 表示该格子还是水
    private int count = 0;  // 当前岛屿数量

    public List<Integer> numIslands2(int m, int n, int[][] positions) {
        parent = new int[m * n];
        Arrays.fill(parent, -1);
        List<Integer> res = new ArrayList<>();
        int[][] dirs = {{1, 0}, {-1, 0}, {0, 1}, {0, -1}};

        for (int[] p : positions) {
            int r = p[0], c = p[1], id = r * n + c;
            if (parent[id] != -1) {          // 已经是陆地，跳过
                res.add(count);
                continue;
            }
            parent[id] = id;                 // 激活为陆地
            count++;                         // 先当成一个新岛

            for (int[] d : dirs) {
                int nr = r + d[0], nc = c + d[1];
                if (nr < 0 || nr >= m || nc < 0 || nc >= n) continue;
                int nid = nr * n + nc;
                if (parent[nid] != -1) {     // 邻居是陆地，尝试合并
                    int ra = find(id), rb = find(nid);
                    if (ra != rb) {
                        parent[ra] = rb;
                        count--;             // 合并后岛屿数减少
                    }
                }
            }
            res.add(count);
        }
        return res;
    }

    private int find(int x) {
        while (parent[x] != x) {
            parent[x] = parent[parent[x]];   // 路径压缩（隔代）
            x = parent[x];
        }
        return x;
    }
}
```

### 复杂度

- 时间：O(k·α(mn))，每次 addLand 最多做 4 次并查集查询/合并，α 近似常数。
- 空间：O(mn)，并查集父数组大小为 `m*n`，结果数组 O(k)。

### 易错点与扩展（面试高频考点）

1. **计数时机**：一定是“先 `+1` 再对每个有效邻居 `-1`”，顺序反了会得到错误中间值。
2. **重复位置要判重**：同一格子多次 addLand 不能重复加岛，需先检查是否已是陆地。
3. **二维坐标压平**：用 `id = r*n + c` 把二维映射到一维，并查集只处理一维下标。
4. **只合并不同根**：`ra == rb` 时若仍然 `count--` 会导致计数偏小。
5. **扩展**：若题目要求离线处理或在动态图中查连通性，并查集是标配；也可配合“按秩合并”进一步优化。

### Python 实现

```python
class Solution:
    def numIslands2(self, m: int, n: int, positions):
        parent = [-1] * (m * n)   # -1 表示水
        self.count = 0

        def find(x):
            while parent[x] != x:
                parent[x] = parent[parent[x]]
                x = parent[x]
            return x

        res = []
        for r, c in positions:
            idx = r * n + c
            if parent[idx] != -1:       # 已经是陆地
                res.append(self.count)
                continue
            parent[idx] = idx
            self.count += 1

            for dr, dc in ((1, 0), (-1, 0), (0, 1), (0, -1)):
                nr, nc = r + dr, c + dc
                if 0 <= nr < m and 0 <= nc < n and parent[nr * n + nc] != -1:
                    a, b = find(idx), find(nr * n + nc)
                    if a != b:
                        parent[a] = b
                        self.count -= 1
            res.append(self.count)
        return res
```
