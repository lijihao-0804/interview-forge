# 140. 单词拆分 II

| 题目信息 | 内容 |
|---|---|
| 难度 | 困难 |
| 核心模式 | 记忆化回溯（DFS + 备忘录，避免重复子问题） |
| 时间复杂度 | O(n·2^n)（最坏，随输出规模而定） |
| 空间复杂度 | O(n·2^n)（最坏，缓存所有句子） |

## 题目与约束

给定一个字符串 `s` 和一个字符串字典 `wordDict`，在字符串 `s` 中增加空格来构建一个句子，使得句子中所有的单词都在词典中。**以任意顺序**返回所有这些可能的句子。

**注意：** 词典中的同一个单词可能在分段中被重复使用多次。

**示例 1：**

```
输入:s = "catsanddog", wordDict = ["cat","cats","and","sand","dog"]
输出:["cats and dog","cat sand dog"]
```

**示例 2：**

```
输入:s = "pineapplepenapple", wordDict = ["apple","pen","applepen","pine","pineapple"]
输出:["pine apple pen apple","pineapple pen apple","pine applepen apple"]
解释：注意你可以重复使用字典中的单词。
```

**示例 3：**

```
输入:s = "catsandog", wordDict = ["cats","dog","sand","and","cat"]
输出:[]
```

**提示：**

- `1 <= s.length <= 20`
- `1 <= wordDict.length <= 1000`
- `1 <= wordDict[i].length <= 10`
- `s` 和 `wordDict[i]` 仅有小写英文字母组成
- `wordDict` 中所有字符串都**不同**

## 核心不变量

> 从下标 `i` 开始到结尾能拼出的所有句子，只取决于 `s[i..]` 本身，与前面怎么切分无关；因此可以把"从 `i` 出发的答案"缓存起来，每个下标只计算一次。

## 完整推导

### 思路推导

1. **直觉与痛点（暴力回溯会重复爆炸）**

   最直观的做法是回溯：从头部枚举一个在词典中的前缀，切下来，再递归处理剩余后缀，直到走到结尾。但同一段后缀会被不同前缀分割方式反复求解，导致大量重复计算，字符串稍长就会指数级变慢。

2. **破局思路（加一个"从 i 开始的答案"缓存）**

   观察：递归函数 `dfs(i)` 的结果只有"从下标 `i` 到结尾的所有合法句子"，它只与 `i` 有关。于是用备忘录 `memo[i]` 存下 `dfs(i)` 的结果，再次遇到相同 `i` 时直接取用。

   - 枚举 `end` 从 `i+1` 到 `n`，取子串 `s[i, end)`；
   - 若该子串在词典中，则递归 `dfs(end)` 得到后缀的所有句子；
   - 把当前词与每个后缀句子拼成一条完整句子（后缀为空时直接用当前词）。

3. **关键追问（为什么用"后缀拼接"而不是"前缀累积"？）**

   因为前缀是变化的、组合会爆炸；而后缀答案可以独立缓存。以 `s = "catsanddog"` 为例，`dfs(0)` 先试前缀 `cat`，得到后缀 `"sanddog"` 的所有句子 `["sand dog"]`，拼成 `"cat sand dog"`；再试前缀 `cats`，后缀 `"anddog"` 得到 `["and dog"]`，拼成 `"cats and dog"`。同一后缀 `"anddog"` 若被多次用到，缓存直接命中。

   剪枝（可选）：若存在某个下标 `i` 无论如何都拼不出来（`dfs(i)` 为空），缓存空列表后可直接跳过，避免无效递归。

### Java 实现（记忆化回溯）

```java
import java.util.ArrayList;
import java.util.HashMap;
import java.util.HashSet;
import java.util.List;
import java.util.Map;
import java.util.Set;

class Solution {
    // 备忘录：下标 i -> 从 s[i..] 能拼出的所有句子
    private Map<Integer, List<String>> memo = new HashMap<>();

    public List<String> wordBreak(String s, List<String> wordDict) {
        Set<String> dict = new HashSet<>(wordDict);
        return dfs(s, 0, dict);
    }

    private List<String> dfs(String s, int start, Set<String> dict) {
        // 命中缓存，直接返回
        if (memo.containsKey(start)) {
            return memo.get(start);
        }

        List<String> res = new ArrayList<>();
        // 走到末尾：产生一个"空后缀"，作为拼接的终止符
        if (start == s.length()) {
            res.add("");
            memo.put(start, res);
            return res;
        }

        for (int end = start + 1; end <= s.length(); end++) {
            String word = s.substring(start, end);
            if (!dict.contains(word)) {
                continue;              // 前缀不在词典，跳过
            }
            // 递归求剩余后缀的所有句子
            List<String> rest = dfs(s, end, dict);
            for (String sentence : rest) {
                // 后缀为空时直接用当前词，否则用空格连接
                res.add(sentence.isEmpty() ? word : word + " " + sentence);
            }
        }

        memo.put(start, res);          // 缓存结果
        return res;
    }
}
```

### 复杂度

- 时间：`O(n·2^n)`（最坏情况）。`n ≤ 20`，最坏时所有切分都合法，句子数量可达指数级；记忆化保证每个下标只求解一次，单次求解枚举 `O(n)` 个子串、并拼接可能较长的结果，整体是"输出敏感"的。
- 空间：`O(n·2^n)`（最坏）。备忘录最多缓存 `n` 个下标的答案，而所有答案的总字符规模最坏为指数级。

### 易错点与扩展（面试高频考点）

1. **空串终止符的处理**：`start == n` 时返回一个空串 `""` 作为"占位"，这样拼接时 `word + " " + ""` 会多出尾随空格，因此要用 `sentence.isEmpty()` 特判。
2. **必须用备忘录**：不做缓存的纯回溯在 `n` 稍大时会严重超时；缓存键是**下标**而非子串，最省空间。
3. **先做可行性预判（可选优化）**：可先用一次 DP/记忆化判断 `s` 能否被拆分，若不能直接返回 `[]`，避免无谓的枚举——这也是原版"单词拆分 I"的结论。
4. **不要真的插入空格再 split**：用 `substring` 枚举 + 字符串拼接即可，避免反复构造中间串带来的额外开销。
5. **扩展——前缀树优化**：把词典建 Trie，枚举 `end` 时沿 Trie 走，前缀不在树中即可提前停止，适合 `wordDict` 很大、单词很长的情况（本题标签也含 Trie）。

### C++ 实现

```cpp
#include <string>
#include <vector>
#include <unordered_set>
#include <unordered_map>
using namespace std;

class Solution {
    unordered_map<int, vector<string>> memo;   // 下标 -> 所有句子

    vector<string> dfs(const string& s, int start, const unordered_set<string>& dict) {
        auto it = memo.find(start);
        if (it != memo.end()) return it->second;

        vector<string> res;
        if (start == (int)s.size()) {          // 到达末尾
            res.push_back("");
            memo[start] = res;
            return res;
        }

        for (int end = start + 1; end <= (int)s.size(); end++) {
            string word = s.substr(start, end - start);
            if (!dict.count(word)) continue;
            vector<string> rest = dfs(s, end, dict);
            for (const string& sentence : rest) {
                res.push_back(sentence.empty() ? word : word + " " + sentence);
            }
        }

        memo[start] = res;
        return res;
    }

public:
    vector<string> wordBreak(string s, vector<string>& wordDict) {
        unordered_set<string> dict(wordDict.begin(), wordDict.end());
        return dfs(s, 0, dict);
    }
};
```

### Python 实现

```python
from typing import List
from functools import lru_cache


class Solution:
    def wordBreak(self, s: str, wordDict: List[str]) -> List[str]:
        words = set(wordDict)
        n = len(s)

        @lru_cache(maxsize=None)
        def dfs(start: int):
            if start == n:
                return ("",)               # 空串占位，作为拼接终止符
            res = []
            for end in range(start + 1, n + 1):
                word = s[start:end]
                if word not in words:
                    continue
                for sentence in dfs(end):
                    res.append(word if not sentence else word + " " + sentence)
            return tuple(res)

        return list(dfs(0))
```
