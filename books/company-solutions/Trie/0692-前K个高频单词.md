# 692. 前K个高频单词

| 题目信息 | 内容 |
|---|---|
| 难度 | 中等 |
| 核心模式 | 哈希计数 + 自定义排序（频率降序、字典序升序） |
| 时间复杂度 | O(n + m log m) |
| 空间复杂度 | O(m) |

## 题目与约束

给定一个单词列表 `words` 和一个整数 `k`，返回前 `k` 个出现次数最多的单词。

返回的答案应按单词出现频率**由高到低**排序；如果不同的单词有相同出现频率，则按**字典顺序**（字典序）升序排列。

**示例 1：**

```
输入: words = ["i", "love", "leetcode", "i", "love", "coding"], k = 2
输出: ["i", "love"]
解析: "i" 和 "love" 为出现次数最多的两个单词，均为 2 次。
     注意，按字母顺序 "i" 在 "love" 之前。
```

**示例 2：**

```
输入: ["the", "day", "is", "sunny", "the", "the", "the", "sunny", "is", "is"], k = 4
输出: ["the", "is", "sunny", "day"]
解析: "the"、"is"、"sunny" 和 "day" 是出现次数最多的四个单词，
     出现次数依次为 4、3、2 和 1 次。
```

**提示：**

- `1 <= words.length <= 500`
- `1 <= words[i].length <= 10`
- `words[i]` 由小写英文字母组成
- `k` 的取值范围是 `[1, 不同 words[i] 的数量]`

**进阶：** 尝试以 `O(n log k)` 时间复杂度和 `O(n)` 空间复杂度解决。

## 核心不变量

> 频率是第一排序键（降序），字典序是第二排序键（升序），二者共同唯一确定合法的输出顺序。

## 完整推导

### 思路推导

1. **先数频率**：扫描一遍 `words`，用哈希表统计每个单词出现的次数，得到若干 `(单词, 次数)` 记录。这一步是 O(n)，n 为单词总数。

2. **再排序**：把所有不同的单词取出来排序，比较规则有两条：
   - 次数不同 → 次数多的排在前面（降序）；
   - 次数相同 → 字典序小的排在前面（升序）。

   例如示例 1 中 `i`、`love` 都是 2 次，按字典序 `i` 在 `love` 前，故输出 `["i","love"]`。

3. **截取前 k 个**：排序后直接取前 `k` 个即可。若想做到进阶的 `O(n log k)`，可改用大小为 k 的小顶堆，堆顶存放「最差」的元素（次数最少；次数相同则字典序最大），最后反转输出，但面试中排序写法已足够清晰。

### Java 实现（topKFrequent）

```java
import java.util.ArrayList;
import java.util.HashMap;
import java.util.List;
import java.util.Map;

class Solution {
    public List<String> topKFrequent(String[] words, int k) {
        // 1. 统计每个单词的频率
        Map<String, Integer> cnt = new HashMap<>();
        for (String w : words) {
            cnt.put(w, cnt.getOrDefault(w, 0) + 1);
        }

        // 2. 取出所有不同的单词并按规则排序
        List<String> candidates = new ArrayList<>(cnt.keySet());
        candidates.sort((a, b) -> {
            int fa = cnt.get(a);
            int fb = cnt.get(b);
            if (fa != fb) {
                return Integer.compare(fb, fa); // 频率降序
            }
            return a.compareTo(b);              // 频率相同按字典序升序
        });

        // 3. 截取前 k 个
        return new ArrayList<>(candidates.subList(0, k));
    }
}
```

### 复杂度

- 时间：O(n + m log m)，n 为单词总数（用于统计频率），m 为不同单词数（排序开销）。
- 空间：O(m)，哈希表与候选列表各存放 m 个不同单词。

### 易错点与扩展（面试高频考点）

1. **两个排序键方向相反**：频率要降序、字典序要升序，比较器里一个取反、一个不取反，很容易写反，务必分别验证。
2. **字典序必须用字符串比较**：Java 用 `a.compareTo(b)`、C++ 用 `a < b`、Python 直接按字符串排序，不能用长度代替字典序。
3. **频率差用减法可能溢出**：虽本题频率最大 500 不会溢出，但规范写法应用 `Integer.compare(fb, fa)`。
4. **`k` 可能等于不同单词数量**：`subList(0, k)` 的边界要正确，且要返回新列表，避免暴露原列表视图。
5. **进阶思路**：用小顶堆维护「当前最优的 k 个」，堆顶为最差元素（频率小、字典序大），遍历完弹出反转即得答案，时间 O(n log k)、空间 O(m)。

## 力扣原题

[692. 前K个高频单词](https://leetcode.cn/problems/top-k-frequent-words/)

### C++ 实现

```cpp
class Solution {
public:
    vector<string> topKFrequent(vector<string>& words, int k) {
        // 1. 统计频率
        unordered_map<string, int> cnt;
        for (auto& w : words) {
            ++cnt[w];
        }

        // 2. 取出不同单词并排序
        vector<string> res;
        for (auto& kv : cnt) {
            res.push_back(kv.first);
        }
        sort(res.begin(), res.end(), [&](const string& a, const string& b) {
            if (cnt[a] != cnt[b]) {
                return cnt[a] > cnt[b]; // 频率降序
            }
            return a < b;               // 频率相同按字典序升序
        });

        // 3. 截取前 k 个
        res.resize(k);
        return res;
    }
};
```

### Python 实现

```python
from collections import Counter


class Solution:
    def topKFrequent(self, words: list[str], k: int) -> list[str]:
        cnt = Counter(words)
        # 频率降序、字典序升序；用元组 (-cnt, word) 升序排序即得目标顺序
        return sorted(cnt, key=lambda w: (-cnt[w], w))[:k]
```
