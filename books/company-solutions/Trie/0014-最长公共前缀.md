# 14. 最长公共前缀

| 题目信息 | 内容 |
|---|---|
| 难度 | 简单 |
| 核心模式 | 纵向逐列扫描 |
| 时间复杂度 | O(S)（S 为所有字符总数，等于 O(m·n)） |
| 空间复杂度 | O(1) |

## 题目与约束

编写一个函数来查找字符串数组中的最长公共前缀。

如果不存在公共前缀，返回空字符串 `""`。

**示例 1：**

```
输入：strs = ["flower","flow","flight"]
输出："fl"
```

**示例 2：**

```
输入：strs = ["dog","racecar","car"]
输出：""
解释：输入不存在公共前缀。
```

**提示：**

- `1 <= strs.length <= 200`
- `0 <= strs[i].length <= 200`
- `strs[i]` 如果非空，则仅由小写英文字母组成

## 核心不变量

> 若所有字符串的前 `i` 个字符都相同，则答案至少长 `i`；一旦某个字符串在第 `i` 位缺失或与第一个串的第 `i` 位不同，答案长度就恰为 `i`。

## 完整推导

### 思路推导

1. **直觉与痛点（能不能只和"某一个"串比？）**

   公共前缀是**所有**字符串共同拥有的部分，它必然也是任意两个字符串的公共前缀。所以最直接的思路是"拿第一个串当标尺"，让其余每个串都来和它比公共前缀，逐次缩短。这叫**横向扫描**，做起来直观，但每次比较都可能把前缀缩短后再重新对齐，更新逻辑略啰嗦。

2. **破局思路（让所有串"并排站好"，一列一列比）**

   换一个视角：把所有字符串对齐摆放，先看第 0 列、再看第 1 列……只要某一列在**所有**串里都存在且字符相同，这一列就属于公共前缀；一旦有一列出现"某个串太短，没这一位"或"字符不一致"，立即停止，答案就是前面已经通过的那些列。

   以 `["flower","flow","flight"]` 为例：
   - 第 0 列：`f, f, f` 全相同 ✔
   - 第 1 列：`l, l, l` 全相同 ✔
   - 第 2 列：`o, o, i` 出现不同 ✘ → 停止，答案为前两列 `"fl"`。

   这种**纵向扫描**只需一层"列"循环加一层"逐个串"循环，天然贴合题意。

3. **关键追问（空数组与短串）**

   - **空输入**：`strs` 为空时直接返回 `""`（题目虽保证至少 1 个，但防御一手更稳）。
   - **某个串为空串**：第 0 列就会因为"长度不够"而失败，正好返回 `""`。
   - **所有串完全相同**：列循环会一直跑到第一个串的末尾，返回整个第一个串，这是正确的最长公共前缀。

### Java 实现（纵向扫描）

```java
class Solution {
    public String longestCommonPrefix(String[] strs) {
        // 空数组防御
        if (strs == null || strs.length == 0) {
            return "";
        }

        // 以第一个字符串为标尺，逐列比较
        for (int i = 0; i < strs[0].length(); i++) {
            char c = strs[0].charAt(i);

            // 检查第 i 列是否在所有字符串中都存在且相同
            for (int j = 1; j < strs.length; j++) {
                // 某个串长度不够，或该位字符不同，说明公共前缀到 i 为止
                if (i == strs[j].length() || strs[j].charAt(i) != c) {
                    return strs[0].substring(0, i);
                }
            }
        }

        // 第一个串整体都是公共前缀
        return strs[0];
    }
}
```

### 复杂度

- 时间：`O(S)`，其中 `S` 是所有字符串的字符总数（最坏 `O(m·n)`，`m` 为串数量、`n` 为最短串长度）。纵向扫描一旦失败立即停止，实际访问的字符数不超过 `S`，是最优量级。
- 空间：`O(1)`。除返回的子串外只用了常数个下标与字符变量。

### 易错点与扩展（面试高频考点）

1. **`i == strs[j].length()` 的判断顺序**：必须先判断"长度是否够"再取 `charAt(i)`，否则短串会越界。
2. **以谁为标尺**：必须以某个确定的串（通常是第一个）作为列数上界，否则循环边界无从确定。
3. **横向 vs 纵向各有权衡**：横向扫描（两两求前缀）在"很多长串只有少量公共前缀"时能更早收敛；纵向扫描在"公共前缀很长"时更省。面试可主动说出两者差异。
4. **面试追问——分治法**：把数组一分为二，分别求左右半区的最长公共前缀，再对两个前缀求公共前缀，递归合并，复杂度同为 `O(S)`，可作为拓展思路。
5. **另一种取巧——排序后比首尾**：按字典序排序后，只需比较第一个和最后一个串的公共前缀即为全体公共前缀（因为首尾差异最大）。这是一个很漂亮的 `O(m·n log m)` 写法，适合口头补充。

## 力扣原题

[14. 最长公共前缀](https://leetcode.cn/problems/longest-common-prefix/)

### C++ 实现

```cpp
#include <string>
#include <vector>
using namespace std;

class Solution {
public:
    string longestCommonPrefix(vector<string>& strs) {
        if (strs.empty()) return "";

        // 以第一个串为标尺，逐列比较
        for (int i = 0; i < (int)strs[0].size(); i++) {
            char c = strs[0][i];
            for (int j = 1; j < (int)strs.size(); j++) {
                // 长度不够或字符不同，则公共前缀到 i 为止
                if (i == (int)strs[j].size() || strs[j][i] != c) {
                    return strs[0].substr(0, i);
                }
            }
        }
        return strs[0];
    }
};
```

### Python 实现

```python
class Solution:
    def longestCommonPrefix(self, strs: list[str]) -> str:
        if not strs:
            return ""

        first = strs[0]
        # 以第一个串为标尺，逐列比较
        for i in range(len(first)):
            c = first[i]
            for s in strs[1:]:
                # 长度不够或字符不同，则公共前缀到 i 为止
                if i >= len(s) or s[i] != c:
                    return first[:i]
        return first
```
