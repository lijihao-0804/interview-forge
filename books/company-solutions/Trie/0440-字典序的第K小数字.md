# 440. 字典序的第K小数字

| 题目信息 | 内容 |
|---|---|
| 难度 | Hard |
| 核心模式 | 字典序十叉树（Trie）上的前缀计数跳跃 |
| 时间复杂度 | O(log² n) |
| 空间复杂度 | O(1) |

## 题目与约束

给定整数 `n` 和 `k`，返回  `[1, n]` 中字典序第 `k` 小的数字。

 

示例 1:

输入: n = 13, k = 2  
输出: 10  
解释: 字典序的排列是 [1, 10, 11, 12, 13, 2, 3, 4, 5, 6, 7, 8, 9]，所以第二小的数字是 10。

示例 2:

输入: n = 1, k = 1  
输出: 1

 

提示:

- `1 <= k <= n <= 109`

[🔗 前往力扣原题验证 →](https://leetcode.cn/problems/k-th-smallest-in-lexicographical-order/)

## 核心不变量

> 把 1..n 按字典序排成「十叉树」后，任意节点 `prefix` 的整棵子树都排在它的下一个兄弟之前；只要一次性算出该子树拥有多少个数字，就能用减法整段跳过，而不必逐个枚举。

## 完整推导

### 思路推导

1. **直觉与痛点（不能真的排序）**：`n` 可达 `10^9`，把 1..n 全排一遍是 O(n log n)，必然超时。但字典序并不是随机的——它天然是一棵**十叉树**：根挂着 1..9，每个节点 `prefix` 的孩子是 `prefix*10 .. prefix*10+9`。字典序的「前序遍历」正是题目要求的顺序。

   以 `n = 13` 为例，这棵树的形状是：
   ```
   1
   ├─ 10
   ├─ 11
   ├─ 12
   └─ 13
   2 .. 9
   ```
   前序遍历得到 `1, 10, 11, 12, 13, 2, 3, …, 9`。

2. **破局思路（整棵子树一起数）**：站在某个前缀 `prefix` 上，我们先统计「以 `prefix` 为前缀的、不超过 `n` 的数字共有多少个」（记为 `count`）：
   - 若 `k` 大于 `count`，说明第 k 个数不在这棵子树里，直接整段跳过：`k -= count`，然后走向下一个兄弟 `prefix + 1`；
   - 若 `k <= count`，说明答案就在这棵子树里：先往下走一层 `prefix *= 10`，并让 `k -= 1`（把当前这个前缀本身用掉）。

3. **关键追问（如何 O(log n) 算出子树大小）**：按「层」统计。第 0 层有 `[prefix, prefix]`；第 1 层是 `[prefix*10, prefix*10+9]`；每往下乘 10。一层里落在 `[1, n]` 内的个数是 `min(n + 1, next) − cur`（用左闭右开区间避免 +1 出错），累加所有层即可。层数最多 `log n`，所以一次 `count` 是 O(log n)，而主循环最多走 O(log n) 步（要么消耗一个数字，要么下沉一层，要么跳出兄弟），总复杂度 O(log² n)。

   例如 `n = 13, prefix = 1`：第 0 层 `[1,2)` 贡献 1；第 1 层 `[10,20)` 与 `[1,14)` 交集为 `[10,14)` 贡献 4 → `count = 5`，正是 `1,10,11,12,13` 这 5 个数。

### Java 实现（前缀计数跳跃）

```java
class Solution {
    public int findKthNumber(int n, int k) {
        long cur = 1;   // 从字典序第一个数 1 开始
        k--;            // 1 本身已经算作第 1 个，先扣掉

        while (k > 0) {
            long count = countSteps(n, cur, cur + 1); // 以 cur 为前缀的子树有多少个数字
            if (count <= k) {
                // 第 k 个不在当前子树，整段跳过，走向下一个兄弟
                k -= count;
                cur++;
            } else {
                // 答案在子树内，下沉到下一层（先取 cur 本身，故 k-1）
                cur *= 10;
                k--;
            }
        }
        return (int) cur;
    }

    // 统计以 first 为前缀、范围 [first, last) 逐层扩张时，落在 [1, n] 内的数字个数
    private long countSteps(int n, long first, long last) {
        long steps = 0;
        while (first <= n) {
            // 当前层 [first, last) 与 [1, n] 的交集大小
            steps += Math.min((long) n + 1, last) - first;
            first *= 10;
            last *= 10;
        }
        return steps;
    }
}
```

### 复杂度

- 时间：O(log² n)。外层最多 O(log n) 步（每次要么 `k` 减少、要么下探一层、要么移动兄弟），每步调用一次 `countSteps` 耗时 O(log n)，相乘为 O(log² n)。对 `n = 10^9` 只需几十次运算。
- 空间：O(1)。只使用若干 `long` 变量，无额外数据结构（递归也可写成迭代，避免栈开销）。

### 易错点与扩展（面试高频考点）

1. **整型溢出**：`prefix * 10`、`last * 10`、`n + 1` 在 `int` 下可能溢出。全程用 `long` 计算，最后再转回 `int`。
2. **区间开闭要统一**：`countSteps` 用左闭右开 `[first, last)`，数量为 `min(n+1, last) - first`。若混用闭区间很容易多算/少算 1。
3. **`k` 的偏移**：从 `1` 出发时先 `k--`；进入子树时 `k--`（把当前前缀自身算一个）。这两处 `k--` 漏一个就会整体错位。
4. **跳出条件**：`while (k > 0)` 而非 `k >= 0`，否则会多走一步。
5. **扩展**：这是「字典序第 k 小」的模板题，可迁移到「按字典序输出 1..n」「字典序第 k 个排列」等；本质是**在隐式 Trie 上按子树规模做二分/跳跃**，与「求第 k 小」类问题（如二叉搜索树第 k 小）思路相通，但这里子树的规模靠公式而非节点存储。

### C++ 实现

```cpp
class Solution {
    // 统计以 first 为前缀的子树中，落在 [1, n] 内的数字个数
    long long countSteps(int n, long long first, long long last) {
        long long steps = 0;
        while (first <= n) {
            steps += std::min((long long) n + 1, last) - first;
            first *= 10;
            last *= 10;
        }
        return steps;
    }

public:
    int findKthNumber(int n, int k) {
        long long cur = 1;
        k--;                       // 1 已经算作第 1 个
        while (k > 0) {
            long long count = countSteps(n, cur, cur + 1);
            if (count <= k) {
                k -= count;        // 整棵子树跳过，走向下一个兄弟
                cur++;
            } else {
                cur *= 10;         // 下沉到下一层
                k--;
            }
        }
        return (int) cur;
    }
};
```

### Python 实现

```python
class Solution:
    def findKthNumber(self, n: int, k: int) -> int:
        def count_steps(first: int, last: int) -> int:
            # 统计以 first 为前缀、[first, last) 逐层扩张时，落在 [1, n] 内的数字个数
            steps = 0
            while first <= n:
                steps += min(n + 1, last) - first
                first *= 10
                last *= 10
            return steps

        cur = 1
        k -= 1                     # 1 已经算作第 1 个
        while k > 0:
            count = count_steps(cur, cur + 1)
            if count <= k:
                k -= count         # 整棵子树跳过，走向下一个兄弟
                cur += 1
            else:
                cur *= 10          # 下沉到下一层
                k -= 1
        return cur
```
