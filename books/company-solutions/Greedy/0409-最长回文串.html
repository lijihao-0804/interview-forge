409. 最长回文串

本题学习状态正在读取学习记录…下次复习：—

遮住推导与代码，先自己想，再逐段揭示
难度简单核心模式贪心 + 字符频次统计时间复杂度O(n)空间复杂度O(1)（字符集大小 128/52）

题目与约束

给定一个包含大写字母和小写字母的字符串 s ，返回 通过这些字母构造成的 最长的 回文串 的长度。

在构造过程中，请注意 区分大小写 。比如 "Aa" 不能当做一个回文字符串。

示例 1:

输入:s = "abccccdd"
输出:7
解释:
我们可以构造的最长的回文串是"dccaccd", 它的长度是 7。

示例 2:

输入:s = "a"
输出:1
解释：可以构造的最长回文串是"a"，它的长度是 1。

提示:

  • 1 <= s.length <= 2000

  • s 只由小写 和/或 大写英文字母组成

🔗 前往力扣原题验证 →

核心不变量

回文串是「镜像对称」的：除了至多一个字符可以放在正中间，其余每个字符都必须成对出现。所以统计频次后，把各字符能配成的最大偶数长度累加，若存在奇数剩余则再加 1 个作中心。

完整推导

思路推导

  1. 回文串的结构规律：一个回文串从外向内配对，左右各一个相同字符。也就是说，每种字符若出现 c 次，它最多能贡献 ⌊c/2⌋ × 2 个字符到回文串里——偶数部分都能用上，落单的那一个（如果有）暂时用不上。

  2. 落单字符的唯一用途是当中心：所有字符配对完可能还剩一堆「单个」的字符。回文串的中心最多只能放一个字符，所以如果有任何字符的个数为奇数，就能在末尾额外 +1，把其中某一个放到正中间。

  3. 贪心地取最优：因为每个字符只要成对就一定放进回文串不会有冲突（回文串对字符种类没有限制），所以「能用尽用」就是最优。统计所有 ⌊c/2⌋×2 求和，再判断是否存在奇数频次，存在则 +1。

小例子："abccccdd"，频次 a:1、b:1、c:4、d:2。偶数部分：c→4，d→2，其余取到 0，合计 6；存在奇数频次（a、b 都是 1），可以放一个到中心，答案 6+1=7。

Java 实现（频次统计 + 贪心）

class Solution {
    public int longestPalindrome(String s) {
        // ASCII 字符共 128 个，足够覆盖大小写字母
        int[] cnt = new int[128];
        for (char c : s.toCharArray()) {
            cnt[c]++;
        }

        int length = 0;
        boolean hasOdd = false;
        for (int v : cnt) {
            if (v > 0) {
                length += (v / 2) * 2;   // 每种字符用到最大的偶数个
                if (v % 2 == 1) {
                    hasOdd = true;       // 记录是否存在落单字符
                }
            }
        }
        // 若有落单字符，可以挑一个放到回文串正中间
        return hasOdd ? length + 1 : length;
    }
}

C++ 实现

class Solution {
public:
    int longestPalindrome(string s) {
        int cnt[128] = {0};
        for (char c : s) {
            cnt[c]++;
        }

        int length = 0;
        bool hasOdd = false;
        for (int v : cnt) {
            if (v > 0) {
                length += (v / 2) * 2;   // 取该字符能贡献的最大偶数长度
                if (v % 2 == 1) {
                    hasOdd = true;
                }
            }
        }
        return hasOdd ? length + 1 : length;
    }
};

Python 实现

from collections import Counter

class Solution:
    def longestPalindrome(self, s: str) -> int:
        cnt = Counter(s)
        length = 0
        has_odd = False
        for v in cnt.values():
            length += (v // 2) * 2   # 每种字符取最大偶数个
            if v % 2 == 1:
                has_odd = True       # 存在落单字符，可留作中心
        return length + 1 if has_odd else length

复杂度

  • 时间：O(n)，遍历字符串一遍统计频次，再遍历一次固定大小（128）的计数数组。
  • 空间：O(1)，计数数组大小与输入规模无关，是常数空间。
易错点与扩展（面试高频考点）

  1. 忘了大小写区分：'A' 和 'a' 要分开计数。用 int[128] 以字符 ASCII 作下标天然区分；若用 int[26] 而不做大小写处理就会出错。

  2. 中心字符重复加：容易写成「每种奇数频次都 +1」，这样会多加很多。中心最多只能有一个字符，所以只加一次，用布尔标记 hasOdd 控制。

  3. 全偶数时多加了 1：例如 "aabb"，全部为偶数，答案应为 4，不能盲加 1。必须由 hasOdd 决定。

  4. 直接用字符出现次数求和：若直接返回字符串长度是错误的，因为并非所有字符都能同时排成回文；必须按上述偶数规则裁剪。

  5. 扩展：变体「构造具体回文串」：本题只求长度。若要求返回具体串，可按「偶数部分各取一半拼成左半，反转接右半，再视情况补中心字符」构造，思路完全一致。
