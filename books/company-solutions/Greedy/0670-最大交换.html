难度 中等
核心模式 贪心 + 记录每个数字最后出现位置

题目与约束

给定一个非负整数，你至多可以交换一次数字中的任意两位。返回你能得到的最大值。

示例 1 :

<strong>输入:</strong> 2736
<strong>输出:</strong> 7236
<strong>解释:</strong> 交换数字2和数字7。

示例 2 :

<strong>输入:</strong> 9973
<strong>输出:</strong> 9973
<strong>解释:</strong> 不需要交换。

注意:

  • 给定数字的范围是 [0, 108]

🔗 前往力扣原题验证 →

核心不变量

从左往右找到第一个「右侧存在比它更大的数字」的位置 i，把 i 与它右侧 最大且最靠右 的那个更大数字交换，就能得到最大结果。

完整推导

思路推导

  1. 贪心直觉：高位越大越好。一个数的数值由高位决定，所以越靠左的位置，值得用越大的数字来填。只要能让某一位变大，就优先处理最靠左的那一位。

  2. 什么时候必须交换？ 从左往右扫描，若某一位 i 的右侧存在比它大的数字，则把 i 换掉一定能让数变大，且这是最靠左的、能带来收益的位置——交换它收益最大。

  3. 选哪个更大数字换过去？ 为了让结果最大，应在 i 右侧选 最大 的数字；若最大值出现多次，选 最靠右 的那个。用最靠右的可以保留更靠左的相同数字在低位，不浪费。例如 1993：位置 0 的 1 右侧最大是 9，有两个 9，换最右边的 9 得 9913（若换中间那个得到 9193，更小）。

  4. 如何快速找到右侧最大且最靠右：预先扫描一遍，用数组 last[d] 记录数字 d 最后出现的位置。对位置 i，从 9 到 a[i]+1 依次检查 last[d] > i，第一个满足的就是「比当前大、且出现过的最大数字」，其 last[d] 就是最靠右位置，交换后即最优。

小例子：2736，last 记录后，位置 0 是 2，从 9 往下找，7 在位置 1 满足 last[7]=1>0，交换 2 与 7 得 7236 ✓。

Java 实现（贪心 + 最后出现位置）

class Solution {
    public int maximumSwap(int num) {
        char[] a = Integer.toString(num).toCharArray();
        int[] last = new int[10];              // last[d] = 数字 d 最后出现的位置
        for (int i = 0; i < a.length; i++) {
            last[a[i] - '0'] = i;
        }
        for (int i = 0; i < a.length; i++) {
            int cur = a[i] - '0';
            // 尝试用右侧最大的、比 cur 大的数字来替换
            for (int d = 9; d > cur; d--) {
                if (last[d] > i) {             // 该更大数字确实出现在 i 的右侧
                    int j = last[d];
                    char t = a[i];
                    a[i] = a[j];
                    a[j] = t;
                    return Integer.parseInt(new String(a));
                }
            }
        }
        return num;                            // 无需交换
    }
}

复杂度

  • 时间：O(d²)。d 为数字位数（≤ 9）。外层遍历 d 位，内层最多查 9 个数字，常数级。
  • 空间：O(d)。字符数组与长度 10 的 last 数组。

易错点与扩展（面试高频考点）

  1. 最大值重复时要换最靠右的：如 1993，换最右的 9 才得到 9913；换靠左的 9 会得到更小的 9193。用 last[d]（最后出现位置）天然满足。
  2. 只需要「至多一次」：若字符串已非递增（从大到小），直接返回原数，不要强行交换。
  3. 别用「找全局最大数字」的粗暴思路：要把「位置」和「数值」结合，从左扫描到第一个可提升位就停。
  4. 数字可能含前导零吗？：输入是非负整数，toString 后不会有前导零，但交换后可能出现把非零换走、零留在高位的情况——本题从高位贪心，不会把高位换小，因此不会产生前导零。
  5. 可扩展：若允许交换恰好 k 次，可参考「最大交换的 k 次版本」，用贪心逐位固定最大值，思路相似但更复杂。

力扣原题

670. 最大交换

C++ 实现

#include <string>
#include <algorithm>
using namespace std;

class Solution {
public:
    int maximumSwap(int num) {
        string s = to_string(num);
        int last[10] = {0};
        for (int i = 0; i < (int)s.size(); ++i) {
            last[s[i] - '0'] = i;
        }
        for (int i = 0; i < (int)s.size(); ++i) {
            int cur = s[i] - '0';
            for (int d = 9; d > cur; --d) {
                if (last[d] > i) {
                    swap(s[i], s[last[d]]);
                    return stoi(s);
                }
            }
        }
        return num;
    }
};

Python 实现

class Solution:
    def maximumSwap(self, num: int) -> int:
        a = list(str(num))
        last = {int(d): i for i, d in enumerate(a)}  # 每个数字最后出现位置
        for i in range(len(a)):
            cur = int(a[i])
            for d in range(9, cur, -1):
                if last.get(d, -1) > i:
                    j = last[d]
                    a[i], a[j] = a[j], a[i]
                    return int("".join(a))
        return num
