题目与约束

你有 k 个 非递减排列 的整数列表。找到一个 最小 区间，使得 k 个列表中的每个列表至少有一个数包含在其中。

我们定义如果 b-a < d-c 或者在 b-a == d-c 时 a < c，则区间 [a,b] 比 [c,d] 小。

示例 1：

<strong>输入：</strong>nums = [[4,10,15,24,26], [0,9,12,20], [5,18,22,30]]
<strong>输出：</strong>[20,24]
<strong>解释：</strong> 
列表 1：[4, 10, 15, 24, 26]，24 在区间 [20,24] 中。
列表 2：[0, 9, 12, 20]，20 在区间 [20,24] 中。
列表 3：[5, 18, 22, 30]，22 在区间 [20,24] 中。

示例 2：

<strong>输入：</strong>nums = [[1,2,3],[1,2,3],[1,2,3]]
<strong>输出：</strong>[1,1]

提示：

  • nums.length == k

  • 1 <= k <= 3500

  • 1 <= nums[i].length <= 50

  • -105 <= nums[i][j] <= 105

  • nums[i] 按非递减顺序排列

核心不变量

用一个小顶堆为每个列表维护一个「当前指针」，堆顶是最小值、curMax 是当前最大值，窗口 [堆顶, curMax] 恰好覆盖每个列表至少一个元素；每次弹出最小者并把该列表指针后移，就能枚举所有可能的极小区间。

完整推导

思路推导

  1. 直觉与痛点（为什么是滑窗）

一个覆盖所有列表的区间，必须从每个列表里各取一个数，区间长度就是「所选数中的最大值 − 最小值」。要让这个差值最小，我们必然希望这些被选中的数彼此尽量靠近。随着窗口移动，可以让某个列表的指针前进，从而收紧窗口。

  1. 破局思路（k 路归并 + 堆）

把 k 个列表看成 k 路有序序列。初始时每路都取第一个元素（各自最小），用小顶堆保存这些元素及其归属（值、列表编号、下标）。设 curMax 为这 k 个首元素的最大值，于是初始窗口 [堆顶值, curMax] 就覆盖了所有列表。

每一轮：弹出堆顶（当前最小值 v），此时候选区间就是 [v, curMax]，用它去更新最优答案；然后把 v 所在列表的指针后移一位，把新元素压入堆，并更新 curMax = max(curMax, 新元素)。这样可以保证每轮窗口都是覆盖全体的、且左端尽可能收窄的区间。

  1. 关键追问（何时结束？）

当某一轮要后移的列表已经没有下一个元素时，说明无法再让窗口左端增大，也就无法再得到更小的区间，直接结束。由于 curMax 只增不减、堆顶（左端）只增不减，窗口长度最终会收敛，答案在其中取得最小值。

  1. 小例子

[[4,10,15,24,26],[0,9,12,20],[5,18,22,30]]：初始选中 {4,0,5}，窗口 [0,5]；弹出 0 换 9，窗口 [4,9]；弹出 4 换 10，窗口 [5,10]……持续收缩直到选中 {24,20,22} 时窗口 [20,24]，长度 4，为最优。

Java 实现（smallestRange）

import java.util.*;

class Solution {
    public int[] smallestRange(List<List<Integer>> nums) {
        int k = nums.size();
        // 小顶堆：按元素值升序排列，元素为 {值, 列表编号, 该列表下标}
        PriorityQueue<int[]> heap = new PriorityQueue<>((a, b) -> a[0] - b[0]);

        int curMax = Integer.MIN_VALUE;
        for (int i = 0; i < k; i++) {
            int v = nums.get(i).get(0);
            heap.offer(new int[]{v, i, 0});
            curMax = Math.max(curMax, v); // 初始窗口右端为各列表首元素最大值
        }

        // 初始答案：堆顶（当前最小值）到 curMax
        int bestL = heap.peek()[0];
        int bestR = curMax;

        while (true) {
            int[] cur = heap.poll();
            int v = cur[0], list = cur[1], idx = cur[2];

            // 当前窗口 [v, curMax] 覆盖所有列表，尝试更新最优解
            if (curMax - v < bestR - bestL
                    || (curMax - v == bestR - bestL && v < bestL)) {
                bestL = v;
                bestR = curMax;
            }

            // 把该列表指针后移，压入下一个元素
            if (idx + 1 < nums.get(list).size()) {
                int next = nums.get(list).get(idx + 1);
                heap.offer(new int[]{next, list, idx + 1});
                curMax = Math.max(curMax, next);
            } else {
                // 某个列表已耗尽，无法继续收缩窗口
                break;
            }
        }
        return new int[]{bestL, bestR};
    }
}

复杂度

  • 时间：O(N log k)，其中 N 为所有列表元素总数、k 为列表个数。每个元素最多进堆出堆各一次，堆操作代价 O(log k)。
  • 空间：O(k)，堆中最多同时保存 k 个元素（每个列表一个）。

易错点与扩展（面试高频考点）

  1. 忘记维护 curMax：curMax 不能简单取堆顶，它是「当前所有已选元素的最大值」，只增不减；漏更新会导致区间右端错误。
  2. 相等时的次级比较：题目规定长度相同要选起点更小的区间，因此更新条件是 长度更小 || (长度相等 && 起点更小)，只写 < 在部分用例上会错。
  3. 结束条件：任一路耗尽即 break，不能继续弹堆，因为此时已无法再从该列表补充元素形成合法窗口。
  4. 数值范围与溢出：元素在 [-10^5, 10^5]，差值最大约 2*10^5，用 int 安全；若范围更大需用 long。
  5. 面试延展：本题等价于「在 k 个有序数组中各取一个数，使极差最小」。堆解法是标准答案；另有「合并成一个带来源的有序数组 + 滑动窗口覆盖所有来源」的等价思路，但堆写法更省空间。

632. 最小区间

C++ 实现

#include <vector>
#include <queue>
#include <tuple>
#include <climits>
#include <algorithm>
using namespace std;

class Solution {
public:
    vector<int> smallestRange(vector<vector<int>>& nums) {
        int k = nums.size();
        // 小顶堆，元素为 {值, 列表编号, 列表内下标}
        priority_queue<tuple<int, int, int>,
                       vector<tuple<int, int, int>>,
                       greater<tuple<int, int, int>>> pq;

        int curMax = INT_MIN;
        for (int i = 0; i < k; i++) {
            int v = nums[i][0];
            pq.push({v, i, 0});
            curMax = max(curMax, v);
        }

        int bestL = get<0>(pq.top());
        int bestR = curMax;

        while (true) {
            auto [v, list, idx] = pq.top();
            pq.pop();

            if (curMax - v < bestR - bestL
                || (curMax - v == bestR - bestL && v < bestL)) {
                bestL = v;
                bestR = curMax;
            }

            if (idx + 1 < (int)nums[list].size()) {
                int next = nums[list][idx + 1];
                pq.push({next, list, idx + 1});
                curMax = max(curMax, next);
            } else {
                break;
            }
        }
        return {bestL, bestR};
    }
};

Python 实现

import heapq


class Solution:
    def smallestRange(self, nums: list[list[int]]) -> list[int]:
        k = len(nums)
        heap = []  # (值, 列表编号, 列表内下标)
        cur_max = float('-inf')

        for i in range(k):
            v = nums[i][0]
            heapq.heappush(heap, (v, i, 0))
            cur_max = max(cur_max, v)

        best_l, best_r = heap[0][0], cur_max

        while True:
            v, li, idx = heapq.heappop(heap)

            # 当前窗口 [v, cur_max] 覆盖所有列表
            if cur_max - v < best_r - best_l or (
                cur_max - v == best_r - best_l and v < best_l
            ):
                best_l, best_r = v, cur_max

            if idx + 1 < len(nums[li]):
                nxt = nums[li][idx + 1]
                heapq.heappush(heap, (nxt, li, idx + 1))
                cur_max = max(cur_max, nxt)
            else:
                break

        return [best_l, best_r]
