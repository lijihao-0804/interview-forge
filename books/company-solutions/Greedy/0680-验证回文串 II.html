680. 验证回文串 II

本题学习状态正在读取学习记录…下次复习：—
本次复习：
按 M 快速切换薄弱标记
遮住推导与代码，先自己想，再逐段揭示
难度简单核心模式双指针：首次失配时尝试删左或删右再判回文时间复杂度O(n)空间复杂度O(1)

题目与约束

给你一个字符串 s，最多 可以从中删除一个字符。

请你判断 s 是否能成为回文字符串：如果能，返回 true ；否则，返回 false 。

示例 1：

输入：s = "aba"
输出：true

示例 2：

输入：s = "abca"
输出：true
解释：你可以删除字符 'c' 。

示例 3：

输入：s = "abc"
输出：false

提示：

  • 1 <= s.length <= 105

  • s 由小写英文字母组成

核心不变量

用双指针从两端向中间比较，在第一次出现 s[i] != s[j] 时，答案只可能来自“删掉 s[i]”或“删掉 s[j]”两种分支，分别检查剩余子串是否为回文即可。

完整推导

思路推导

  1. 直觉与痛点（最多删一个字符）

如果允许删很多字符，就成了“最长回文子序列”那类问题。这里只允许删一个，代价极小，可以直接顺着双指针检查。

  1. 破局思路（在失配处二选一）

设左右指针 i、j。当 s[i] == s[j] 时，二者可以配对，直接 i++、j--。一旦出现 s[i] != s[j]，为了让整体成为回文，我们必须从这一对里删掉一个字符：

  • 删掉 s[i]：检查子串 s[i+1..j] 是否回文；
  • 删掉 s[j]：检查子串 s[i..j-1] 是否回文。

两者只要有一个成立，就返回 true；都不成立则 false。

  1. 关键追问（为什么只在这一个失配点尝试？）

在第一个失配点之前的部分已经逐一配对成功，只有这对冲突需要解决。删掉一个字符后，剩余子串必须整体就是回文，否则即使再删也不允许（已经用掉了唯一的一次删除机会）。因此只需对两个候选子串做一次普通的回文检查。

例：s = "abca"，i 指 a、j 指 a 时 a == a；推进后 s[1]='b' 与 s[2]='c' 失配，删 b 得 "aca" 回文 → true。

Java 实现（双指针 + 回文校验）

class Solution {
    public boolean validPalindrome(String s) {
        int i = 0, j = s.length() - 1;
        while (i < j) {
            if (s.charAt(i) != s.charAt(j)) {
                // 失配时，删左端 或 删右端，二者其一成立即可
                return isPalindrome(s, i + 1, j) || isPalindrome(s, i, j - 1);
            }
            i++;
            j--;
        }
        return true; // 全程匹配，本身即为回文
    }

    // 判断 s[i..j] 是否为回文（闭区间）
    private boolean isPalindrome(String s, int i, int j) {
        while (i < j) {
            if (s.charAt(i) != s.charAt(j)) {
                return false;
            }
            i++;
            j--;
        }
        return true;
    }
}

C++ 实现

#include <string>
using namespace std;

class Solution {
public:
    bool validPalindrome(string s) {
        int i = 0, j = (int)s.size() - 1;
        while (i < j) {
            if (s[i] != s[j]) {
                return isPalindrome(s, i + 1, j) || isPalindrome(s, i, j - 1);
            }
            i++;
            j--;
        }
        return true;
    }

private:
    bool isPalindrome(const string& s, int i, int j) {
        while (i < j) {
            if (s[i] != s[j]) return false;
            i++;
            j--;
        }
        return true;
    }
};

Python 实现

class Solution:
    def validPalindrome(self, s: str) -> bool:
        def is_palindrome(i: int, j: int) -> bool:
            while i < j:
                if s[i] != s[j]:
                    return False
                i += 1
                j -= 1
            return True

        i, j = 0, len(s) - 1
        while i < j:
            if s[i] != s[j]:
                # 删左端 或 删右端，任一成立即可
                return is_palindrome(i + 1, j) or is_palindrome(i, j - 1)
            i += 1
            j -= 1
        return True

复杂度

  • 时间：O(n)。主循环扫一遍；失配时最多再做两次线性回文检查，总时长仍是线性。
  • 空间：O(1)。只用双指针下标，无额外数组。
易错点与扩展（面试高频考点）
  1. 只在第一次失配处做选择：之前都匹配，冲突唯一；一旦跳过字符后剩余部分必须整体回文，不能继续“再删一个”。
  2. 两个分支要用“或”连接：删左或删右任一成功即可，不要写成“与”。
  3. 边界处理：i + 1 > j 或 i > j - 1 时对应子串为空或单字符，视为回文，isPalindrome 的 while (i < j) 天然处理。
  4. 不要真的去删除字符构造新串：构造子串会带来 O(n) 额外空间甚至 O(n^2) 时间，直接用下标区间判断最省。
  5. 扩展：若允许删 k 个字符，问题升级为“至多 k 次删除使回文”，可用区间 DP O(n^2 k) 或记忆化搜索，不再是本题的贪心双指针。
