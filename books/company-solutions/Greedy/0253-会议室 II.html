253. 会议室 II

难度中等核心模式贪心 + 小根堆，统计任意时刻的最大重叠会议数时间复杂度O(n log n)空间复杂度O(n)

题目与约束

🔗 前往力扣原题验证 →

核心不变量

所需的最少会议室数 = 任意时刻同时进行的会议数的最大值；按开始时间贪心分配并复用已结束会议室即可达到该下界。

完整推导

思路推导

  1. 问题的本质：会议室可以复用。若当前会议开始时，已有某间会议室空出来了（它里面那场会议已经结束），就直接复用；否则必须新开一间。

  2. 贪心策略：按开始时间升序遍历会议。用一个小根堆维护"正在使用的会议室的结束时间"，堆顶就是最早空出来的那间。

  3. 复用判定：若 当前会议开始时间 >= 堆顶结束时间，说明最早结束的那场会议已经结束，可以复用它的房间——弹出堆顶；随后把当前会议的结束时间压入堆。

  4. 答案：所有会议处理完后，堆的大小就是同时占用的最大会议室数量（每次只在无法复用时才净增一间）。

以 [[0,30],[5,10],[15,20]] 为例：[0,30] 入堆 → 堆 {30}；[5,10] 开始 5 < 30，无法复用，入堆 → {10,30}；[15,20] 开始 15 >= 10，复用，弹出 10，再入堆 20 → {20,30}，最终大小 2。

Java 实现（minMeetingRooms）

import java.util.Arrays;
import java.util.PriorityQueue;

class Solution {
    public int minMeetingRooms(int[][] intervals) {
        if (intervals.length == 0) {
            return 0;
        }

        // 1. 按会议开始时间升序排序
        Arrays.sort(intervals, (a, b) -> Integer.compare(a[0], b[0]));

        // 2. 小根堆：存放正在占用的会议室的“结束时间”，堆顶是最早空出的
        PriorityQueue<Integer> heap = new PriorityQueue<>();

        for (int[] it : intervals) {
            // 3. 若最早结束的会议已经结束，可复用这间会议室
            if (!heap.isEmpty() && it[0] >= heap.peek()) {
                heap.poll();
            }
            // 占用（或新开）一间会议室
            heap.offer(it[1]);
        }

        // 4. 堆的大小即为所需的最少会议室数
        return heap.size();
    }
}

C++ 实现

#include <algorithm>
#include <queue>
#include <vector>
using namespace std;

class Solution {
public:
    int minMeetingRooms(vector<vector<int>>& intervals) {
        if (intervals.empty()) return 0;

        // 按开始时间升序排序
        sort(intervals.begin(), intervals.end(),
             [](const vector<int>& a, const vector<int>& b) { return a[0] < b[0]; });

        // 小根堆：存正在占用的会议室的结束时间
        priority_queue<int, vector<int>, greater<int>> heap;
        for (auto& it : intervals) {
            // 最早结束的会议已结束，可复用房间
            if (!heap.empty() && it[0] >= heap.top()) {
                heap.pop();
            }
            heap.push(it[1]);
        }
        return (int)heap.size();
    }
};

Python 实现

import heapq
from typing import List


class Solution:
    def minMeetingRooms(self, intervals: List[List[int]]) -> int:
        if not intervals:
            return 0

        # 按开始时间升序排序
        intervals.sort(key=lambda x: x[0])

        heap = []  # 小根堆，存正在占用的会议室的结束时间
        for start, end in intervals:
            # 最早结束的会议已结束，可复用这间会议室
            if heap and start >= heap[0]:
                heapq.heappop(heap)
            heapq.heappush(heap, end)

        # 堆的大小即为最少会议室数量
        return len(heap)

复杂度

  • 时间：O(n log n)，排序 O(n log n)，每场会议至多一次堆弹出与一次堆插入，均为 O(log n)。
  • 空间：O(n)，最坏情况下所有会议都重叠，堆中同时存 n 个结束时间。
易错点与扩展（面试高频考点）
  1. 判定复用用 >=：开始时间等于某场会议的结束时间即可复用（题目约定不冲突），写成 > 会多算房间。
  2. 堆里存的是结束时间：不是开始时间，也不是会议对象；堆顶必须是最早结束的那场，才能正确贪心复用。
  3. 答案不是 heap 的最大值而是最终大小：由于每次都是"能复用则净增 0、不能复用则净增 1"，最终堆大小恰为历史最大重叠数。
  4. 双指针替代写法：把开始时间数组和结束时间数组分别排序，两个指针扫描——start < end 时房间数 +1、start 指针右移，否则 end 指针右移，本质是求最大重叠数，可把空间降到 O(n)（仍需两个排序数组）。
  5. 差分/扫描线视角：把每场会议看作 +1（开始）与 -1（结束）事件，按时间排序后求前缀和的最大值，就是答案；这也是"Prefix Sum"标签的来源。
