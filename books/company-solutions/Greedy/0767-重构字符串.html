767. 重构字符串

本题学习状态正在读取学习记录…下次复习：—
本次复习：

遮住推导与代码，先自己想，再逐段揭示
难度中等核心模式贪心 + 大顶堆按频次交替放置字符时间复杂度O(n)空间复杂度O(Σ)

题目与约束

给定一个字符串 s ，检查是否能重新排布其中的字母，使得任意两个相邻字符不相同。

返回 s 的任意可能的重新排列。若不可行，返回空字符串 "" 。

示例 1:

输入: s = "aab"
输出: "aba"

示例 2:

输入: s = "aaab"
输出: ""

提示:

  • 1 <= s.length <= 500

  • s 只包含小写字母

🔗 前往力扣原题验证 →

核心不变量

只要出现次数最多的字符不超过 ⌈n/2⌉，就一定能构造出合法排列；构造方法是每轮取频次最高的两个字符交替拼接。

完整推导

思路推导

  1. 先判断有没有解：设字符串长度为 n，某字符出现 cnt 次。若把它全部放进偶数下标（共 ⌈n/2⌉ 个位置），最多也只能放下 ⌈n/2⌉ 个；一旦 cnt > ⌈n/2⌉，必然有两个相同字符被迫相邻，直接无解。所以"最高频次 ≤ (n+1)/2"是可解的必要条件，而且它也是充分条件。

  2. 贪心构造：维护一个按频次从大到小排序的大顶堆。每轮取出频次最高的两个字符 a、b，各取一个先拼 a 再拼 b（保证它们不相邻），然后把它们剩余频次各减一，若仍大于 0 再放回堆。每次都优先处理"最紧急"的两个字符，能让同类字符被尽量摊开。

  3. 小例验证：s = "aab"，频次 a:2、b:1。第一轮取 a、b 拼成 "ab"，剩 a:1 放回；堆里只剩 a:1，收尾追加得 "aba"，合法。s = "aaab"，a:3 > (4+1)/2=2，判定无解返回 ""。

Java 实现（贪心 + 大顶堆）

import java.util.PriorityQueue;

class Solution {
    public String reorganizeString(String s) {
        // 1. 统计每个字符出现次数
        int[] cnt = new int[26];
        for (char c : s.toCharArray()) {
            cnt[c - 'a']++;
        }

        // 2. 大顶堆，按频次降序排列，元素为 {字符下标, 频次}
        PriorityQueue<int[]> pq = new PriorityQueue<>((a, b) -> b[1] - a[1]);
        for (int i = 0; i < 26; i++) {
            if (cnt[i] > 0) {
                pq.offer(new int[]{i, cnt[i]});
            }
        }

        StringBuilder sb = new StringBuilder();

        // 3. 每轮取频次最高的两个字符各取一个，交替拼接
        while (pq.size() >= 2) {
            int[] a = pq.poll();
            int[] b = pq.poll();
            sb.append((char) ('a' + a[0]));
            sb.append((char) ('a' + b[0]));

            if (--a[1] > 0) pq.offer(a);
            if (--b[1] > 0) pq.offer(b);
        }

        // 4. 处理可能剩下的最后一个字符
        if (!pq.isEmpty()) {
            int[] a = pq.poll();
            if (a[1] > 1) {
                return "";  // 剩余字符无法不相邻地放置，说明无解
            }
            sb.append((char) ('a' + a[0]));
        }

        return sb.toString();
    }
}

C++ 实现

#include <string>
#include <queue>
#include <vector>
using namespace std;

class Solution {
public:
    string reorganizeString(string s) {
        int cnt[26] = {0};
        for (char c : s) cnt[c - 'a']++;

        // 大顶堆，pair 默认按 first 降序，first 存频次
        priority_queue<pair<int, int>> pq;
        for (int i = 0; i < 26; i++)
            if (cnt[i] > 0) pq.push({cnt[i], i});

        string res;
        while (pq.size() >= 2) {
            auto a = pq.top(); pq.pop();
            auto b = pq.top(); pq.pop();
            res += (char) ('a' + a.second);
            res += (char) ('a' + b.second);
            if (--a.first > 0) pq.push(a);
            if (--b.first > 0) pq.push(b);
        }
        if (!pq.empty()) {
            auto a = pq.top();
            if (a.first > 1) return "";
            res += (char) ('a' + a.second);
        }
        return res;
    }
};

Python 实现

import heapq
from collections import Counter


class Solution:
    def reorganizeString(self, s: str) -> str:
        counts = Counter(s)
        # 用负数模拟大顶堆，堆元素为 (-频次, 字符)
        heap = [(-c, ch) for ch, c in counts.items()]
        heapq.heapify(heap)

        res = []
        while len(heap) >= 2:
            c1, ch1 = heapq.heappop(heap)
            c2, ch2 = heapq.heappop(heap)
            res.append(ch1)
            res.append(ch2)
            # 用掉一个后若仍剩余，放回堆中
            if c1 + 1 < 0:
                heapq.heappush(heap, (c1 + 1, ch1))
            if c2 + 1 < 0:
                heapq.heappush(heap, (c2 + 1, ch2))

        if heap:
            c, ch = heap[0]
            if -c > 1:
                return ""
            res.append(ch)

        return "".join(res)

复杂度

  • 时间：O(n)。统计频次 O(n)；堆中元素最多 26 个，每次弹出/压入是 O(log 26) 的常数开销，共执行 O(n) 轮，整体 O(n)。
  • 空间：O(Σ)，其中 Σ = 26 为字符集大小。计数数组与堆都不超过 26 个元素，与输入长度无关。
易错点与扩展（面试高频考点）
  1. 忘记可行性判断：不检查最高频次是否超过 (n+1)/2，在 "aaab" 这类输入上会错误地返回非法串。堆收尾时也会暴露无解，但提前判断更清晰。
  2. 一轮只取一个字符：若每轮只弹出一个字符追加，容易让次高频字符来不及插在中间，导致相邻重复；必须一次取两个交替拼接。
  3. --a[1] > 0 写成 a[1]-- > 0：前者先把频次减掉再判断剩余量，后者语义混乱；应确保减一后再检查是否还需要放回。
  4. 用数组下标越界：字符必须统一映射到 0~25（c - 'a'），不要直接拿字符当数组下标。
  5. 扩展：也可用"先按频次降序排好，再按步长 2 填偶数位、再填奇数位"的构造法（计数排序思想），同样 O(n) 且常数更小。
