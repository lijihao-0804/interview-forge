871. 最低加油次数

本题学习状态正在读取学习记录…下次复习：—
本次复习：
按 M 快速切换薄弱标记
遮住推导与代码，先自己想，再逐段揭示
难度困难核心模式贪心 + 最大堆：油不够时，从"路过但没加"的油里挑最大的补时间复杂度O(n log n)空间复杂度O(n)

题目与约束

汽车从起点出发驶向目的地，该目的地位于出发位置东面 target 英里处。

沿途有加油站，用数组 stations 表示。其中 stations[i] = [positioni, fueli] 表示第 i 个加油站位于出发位置东面 positioni 英里处，并且有 fueli 升汽油。

假设汽车油箱的容量是无限的，其中最初有 startFuel 升燃料。它每行驶 1 英里就会用掉 1 升汽油。当汽车到达加油站时，它可能停下来加油，将所有汽油从加油站转移到汽车中。

为了到达目的地，汽车所必要的最低加油次数是多少？如果无法到达目的地，则返回 -1 。

注意：如果汽车到达加油站时剩余燃料为 0，它仍然可以在那里加油。如果汽车到达目的地时剩余燃料为 0，仍然认为它已经到达目的地。

示例 1：

输入：target = 1, startFuel = 1, stations = []
输出：0
解释：可以在不加油的情况下到达目的地。

示例 2：

输入：target = 100, startFuel = 1, stations = [[10,100]]
输出：-1
解释：无法抵达目的地，甚至无法到达第一个加油站。

示例 3：

输入：target = 100, startFuel = 10, stations = [[10,60],[20,30],[30,30],[60,40]]
输出：2
解释：
出发时有 10 升燃料。
开车来到距起点 10 英里处的加油站，消耗 10 升燃料。将汽油从 0 升加到 60 升。
然后，从 10 英里处的加油站开到 60 英里处的加油站（消耗 50 升燃料），
并将汽油从 10 升加到 50 升。然后开车抵达目的地。
沿途在两个加油站停靠，所以返回 2 。

提示：

  • 1 <= target, startFuel <= 109

  • 0 <= stations.length <= 500

  • 1 <= positioni < positioni+1 < target

  • 1 <= fueli < 109

🔗 前往力扣原题验证 →

核心不变量

用一个最大堆保存"已经驶过、但尚未加油"的加油站的油量；每当当前油量不足以到达下一个位置时，就从堆中取出最大的那份油加一次，直到够用为止——这样每次补油都补在最需要的地方。

完整推导

思路推导

  1. 痛点（该在哪加油、加哪一家的？）

我们一路向东开，无法预知未来会不会缺油。暴力枚举"加/不加每个站"是指数级的。关键观察：既然目标是加油次数最少，那么每次"被迫"加油时，应该挑选迄今为止路过、还没加过的油里最大的那一份——这不会让情况变差，且能最大化续航。

  1. 贪心策略（延迟加油 + 最大堆）

先"假装不加"，把路过的每座加油站的油量都丢进一个最大堆。当油量不足以驶到下一个关键位置（下一站或终点）时，就从堆顶取出最大的油加进去，加油次数 +1；若堆空了还到不了，说明无解，返回 -1。

  1. 统一处理终点

把终点 (target, 0) 也当作一个"位置"追加到站点末尾。这样遍历到最后一个位置时，只要途中补油够用就自然抵达终点，收尾逻辑统一，无需额外判断。

  1. 小例子（示例 3）

target=100, startFuel=10。到 10（耗费 10，油 0）→ 入堆 60；油 0 到不了 20，取最大 60 加油，stops=1，油 60-10=50；到 20 入堆 30、到 30 入堆 30、到 60 入堆 40（途中油还够）……到 60 后油不足以到 100，取最大 40 加油，stops=2，抵达终点。答案 2。

Java 实现（minRefuelStops）

import java.util.Collections;
import java.util.PriorityQueue;

class Solution {
    public int minRefuelStops(int target, int startFuel, int[][] stations) {
        // 最大堆：存放"路过但还没加"的油量
        PriorityQueue<Integer> maxHeap = new PriorityQueue<>(Collections.reverseOrder());

        int stops = 0;
        long fuel = startFuel; // 用 long 防止油量累加溢出 int
        int prev = 0;          // 上一个位置

        // 把终点当作最后一个"加油站"，油量为 0
        int n = stations.length;
        for (int i = 0; i <= n; i++) {
            int pos = (i == n) ? target : stations[i][0];
            int dist = pos - prev;

            // 当前油量不足以到达该位置时，反复从堆里取最大油加
            while (fuel < dist) {
                if (maxHeap.isEmpty()) {
                    return -1; // 没油可加，无法抵达
                }
                fuel += maxHeap.poll();
                stops++;
            }

            // 到达该位置后，消耗油量；若是加油站则把油放进堆里备用
            fuel -= dist;
            if (i < n) {
                maxHeap.offer(stations[i][1]);
            }
            prev = pos;
        }
        return stops;
    }
}

C++ 实现

class Solution {
public:
    int minRefuelStops(int target, int startFuel, vector<vector<int>>& stations) {
        priority_queue<int> maxHeap; // 最大堆
        int stops = 0;
        long long fuel = startFuel;
        int prev = 0;
        int n = stations.size();

        for (int i = 0; i <= n; ++i) {
            int pos = (i == n) ? target : stations[i][0];
            int dist = pos - prev;

            while (fuel < dist) {
                if (maxHeap.empty()) return -1;
                fuel += maxHeap.top();
                maxHeap.pop();
                ++stops;
            }

            fuel -= dist;
            if (i < n) maxHeap.push(stations[i][1]);
            prev = pos;
        }
        return stops;
    }
};

Python 实现

class Solution:
    def minRefuelStops(self, target: int, startFuel: int, stations: list[list[int]]) -> int:
        import heapq

        max_heap = []  # 用负数模拟最大堆
        stops = 0
        fuel = startFuel
        prev = 0
        n = len(stations)

        for i in range(n + 1):
            pos = target if i == n else stations[i][0]
            dist = pos - prev

            while fuel < dist:
                if not max_heap:
                    return -1
                fuel += -heapq.heappop(max_heap)
                stops += 1

            fuel -= dist
            if i < n:
                heapq.heappush(max_heap, -stations[i][1])
            prev = pos

        return stops

复杂度

  • 时间：O(n log n)，每个加油站最多入堆、出堆各一次，堆操作 O(log n)，共 n 个站。
  • 空间：O(n)，最大堆中最多保存 n 个加油站的油量。
易错点与扩展（面试高频考点）
  1. 油量溢出：target、fuel_i 可达 10^9，累加后可能超过 int 上限，fuel 必须用 long（C++ 用 long long，Python 无此问题）。
  2. "延迟加油"思想：不要一经过加油站就加，而是先入堆、真正缺油时再挑最大的加，这才是最优。直接"见站就加"会得到更多次数。
  3. 终点也要参与距离判断：把 (target, 0) 追加为最后一站，避免结尾单独写一段"能否到达终点"的判断而出错。
  4. 相等边界：油量恰好等于距离时算能到达（fuel < dist 才需要加油），符合题目"剩余为 0 也算到达"的规定。
  5. 另一种解法（DP）：dp[j] 表示加 j 次油能到的最远距离，dp[0]=startFuel，对每个站点从大到小更新；时间 O(n²)，面试可用作对照，但堆贪心更优。
