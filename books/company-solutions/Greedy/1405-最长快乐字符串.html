1405. 最长快乐字符串

本题学习状态正在读取学习记录…下次复习：—
本次复习：
按 M 快速切换薄弱标记
遮住推导与代码，先自己想，再逐段揭示
难度中等核心模式贪心：每一步优先用剩余最多且不会形成三连的字母时间复杂度O((a+b+c)·1) ≈ O(a+b+c)空间复杂度O(a+b+c)（存放结果字符串）

题目与约束

如果字符串中不含有任何 'aaa'，'bbb' 或 'ccc' 这样的字符串作为子串，那么该字符串就是一个「快乐字符串」。

给你三个整数 a，b ，c，请你返回 任意一个 满足下列全部条件的字符串 s：

  • s 是一个尽可能长的快乐字符串。

  • s 中 最多 有a 个字母 'a'、b 个字母 'b'、c 个字母 'c' 。

  • s中只含有 'a'、'b' 、'c' 三种字母。

如果不存在这样的字符串 s ，请返回一个空字符串 ""。

示例 1：

输入：a = 1, b = 1, c = 7
输出："ccaccbcc"
解释："ccbccacc" 也是一种正确答案。

示例 2：

输入：a = 2, b = 2, c = 1
输出："aabbc"

示例 3：

输入：a = 7, b = 1, c = 0
输出："aabaa"
解释：这是该测试用例的唯一正确答案。

提示：

  • 0 <= a, b, c <= 100

  • a + b + c > 0

🔗 前往力扣原题验证 →

核心不变量

只要还有字母可用，就应尽量用掉当前剩余最多的那个字母；唯一约束是它不能与末尾两个字符构成三连，此时才退而使用次多的字母。

完整推导

思路推导

  1. "最长"的本质是别让某个字母堆积：如果一直用同一个字母，很快就会被迫停下（凑出 aaa）。所以要轮流消耗，优先削平剩余数量的"高峰"。直觉上：剩余最多的字母是"瓶颈"，不赶紧用掉它，最后它会因无处安放而浪费。

  2. 局部贪心规则：每一步在满足"不会与末尾两个字符构成三连"的字母里，选剩余最多的那个追加，并让其计数减一。若一个都选不了（都构成三连或都用完了），循环结束。

  3. 为什么贪心是对的：若当前最大剩余量为 M，其余字母总量为 R。当 M > 2*(R+1) 时，多余的字母注定无法全部用上，贪心已尽量多用；否则贪心每次把最长的那种"压一压"，能让各种字母交替出现，从而把能用的字母都用上，达到最长。这是本题官方题解的贪心思路。

  4. 例子：a=2,b=2,c=1。依次取：a(2→1)、b(2→1)、a(1→0)、b(1→0)、c(1→0) → "aabbc"，长度 5，全部用上，正确。

Java 实现（每步贪心选最多且合法的字母）

class Solution {
    public String longestDiverseString(int a, int b, int c) {
        int[] cnt = {a, b, c};
        char[] ch = {'a', 'b', 'c'};
        StringBuilder sb = new StringBuilder();

        while (true) {
            int best = -1;
            // 在合法（不与末尾两字符构成三连）的字母中挑剩余最多的
            for (int i = 0; i < 3; i++) {
                if (cnt[i] <= 0) {
                    continue;
                }
                int len = sb.length();
                if (len >= 2 && sb.charAt(len - 1) == ch[i] && sb.charAt(len - 2) == ch[i]) {
                    continue; // 追加它会形成三连，跳过
                }
                if (best == -1 || cnt[i] > cnt[best]) {
                    best = i;
                }
            }
            if (best == -1) {
                break; // 没有可用字母，结束
            }
            sb.append(ch[best]);
            cnt[best]--;
        }

        return sb.toString();
    }
}

C++ 实现

#include <string>
using namespace std;

class Solution {
public:
    string longestDiverseString(int a, int b, int c) {
        int cnt[3] = {a, b, c};
        char ch[3] = {'a', 'b', 'c'};
        string res;

        while (true) {
            int best = -1;
            for (int i = 0; i < 3; i++) {
                if (cnt[i] <= 0) {
                    continue;
                }
                int len = res.size();
                if (len >= 2 && res[len - 1] == ch[i] && res[len - 2] == ch[i]) {
                    continue; // 会形成三连
                }
                if (best == -1 || cnt[i] > cnt[best]) {
                    best = i;
                }
            }
            if (best == -1) {
                break;
            }
            res.push_back(ch[best]);
            cnt[best]--;
        }

        return res;
    }
};

Python 实现

class Solution:
    def longestDiverseString(self, a: int, b: int, c: int) -> str:
        cnt = [a, b, c]
        ch = ['a', 'b', 'c']
        res = []

        while True:
            best = -1
            for i in range(3):
                if cnt[i] <= 0:
                    continue
                ln = len(res)
                if ln >= 2 and res[-1] == ch[i] and res[-2] == ch[i]:
                    continue  # 会形成三连
                if best == -1 or cnt[i] > cnt[best]:
                    best = i
            if best == -1:
                break
            res.append(ch[best])
            cnt[best] -= 1

        return "".join(res)

复杂度

  • 时间：O(a + b + c)。每轮至少追加一个字符，至多循环 a+b+c 次，每轮固定只比较 3 个字母。
  • 空间：O(a + b + c)。用于存放结果字符串 sb（计数数组固定为 3，属常数）。
易错点与扩展（面试高频考点）
  1. "三连"判断只看末尾两个字符：只需比较 sb 最后两位与当前字母是否都相同，不必检查整个字符串。
  2. "最多"而非"恰好"：题目允许某些字母用不完。当剩余最多的字母已无处安放时，答案就是当前长度，别强行塞入导致出现 aaa。
  3. 平局时的取舍：多个字母剩余数相同时任选其一都不影响最终长度（题目要求"任意一个"答案即可）；但要保证选择的是合法的那个。
  4. 优先队列写法：也可用最大堆（按剩余数排序），每轮弹出最多的字母，若它与上次相同且已连续两次则先弹次多的；本质与上面三元素贪心等价。
  5. 扩展：若字母表更大（任意 k 种），思路不变——仍是"每次取剩余最多且不构成三连的字母"，堆实现可自然推广。
