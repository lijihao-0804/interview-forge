1675. 数组的最小偏移量

本题学习状态正在读取学习记录…下次复习：—
本次复习：
按 M 快速切换薄弱标记
遮住推导与代码，先自己想，再逐段揭示
难度困难核心模式大根堆贪心：先全部升到最大形态，再不断削减当前最大值时间复杂度O(n log n · log V)空间复杂度O(n)

题目与约束

给你一个由 n 个正整数组成的数组 nums 。

你可以对数组的任意元素执行任意次数的两类操作：

  • 如果元素是 偶数 ，除以 2

  • 例如，如果数组是 [1,2,3,4] ，那么你可以对最后一个元素执行此操作，使其变成 [1,2,3,2]

  • 如果元素是 奇数 ，乘上 2

  • 例如，如果数组是 [1,2,3,4] ，那么你可以对第一个元素执行此操作，使其变成 [2,2,3,4]

数组的 偏移量 是数组中任意两个元素之间的 最大差值 。

返回数组在执行某些操作之后可以拥有的 最小偏移量 。

示例 1：

输入：nums = [1,2,3,4]
输出：1
解释：你可以将数组转换为 [1,2,3,2]，然后转换成 [2,2,3,2]，偏移量是 3 - 2 = 1

示例 2：

输入：nums = [4,1,5,20,3]
输出：3
解释：两次操作后，你可以将数组转换为 [4,2,5,5,3]，偏移量是 5 - 2 = 3

示例 3：

输入：nums = [2,10,8]
输出：3

提示：

  • n == nums.length

  • 2 <= n <= 5 * 104

  • 1 <= nums[i] <= 109

核心不变量

每个数能取到的所有值，都是「奇数乘 2 得到的某个偶数」不断除以 2 得到的一条链；最省心的做法是先把每个数抬到它能取到的 最大 值（奇数乘 2），之后对它只能一路除以 2 单调下降。于是问题变成：不断削减当前最大值，记录「最大值 − 最小值」出现过的最小值。

完整推导

思路推导

  1. 直觉与痛点（操作有点绕）

奇数只能乘 2、偶数只能除以 2。注意：奇数乘 2 之后变成偶数，就能反复除以 2 降回来。也就是说，对一个数而言，任何时刻把它「升」上去都不会损失后续下降的能力，而如果先降了（比如偶数除以 2 变成奇数），就再也回不到原来那个偶数了。

  1. 关键观察（一律先升到最大）

不妨对每个数 x：如果它是奇数，先 x *= 2。这样每个数都变成偶数，且这就是它能取到的 最大形态。之后的操作只剩「除以 2」，数值只减不增。为什么不先把偶数升？偶数不能乘 2（规则不允许），所以它能取到的最大值本就是它自己。

小例子（示例 1，nums = [1,2,3,4]）：1 是奇数升为 2，3 升为 6，其余不变，得到 [2,2,6,4]。

  1. 贪心削减最大者

把当前所有数放进 大根堆，同时维护当前最小值 min。此时偏移量 = 堆顶 − min。为了缩小偏移量，唯一有意义的方向是：把 当前最大值 除以 2（它一定为偶数，因为初始全是偶数、除以 2 后若变奇数就无法再降）。每降一次，更新 min、重新计算偏移量并取历史最小。

当堆顶变成奇数时，它已无法继续下降，若再削减别的数只会让最小值更小、偏移量更大，贪心到此结束。

  1. 为什么这样能得到最优

偏移量由「全局最大」和「全局最小」决定。固定某个最大值的下降路径、不断压低最大值，是缩小两者的唯一手段；而所有可能的取值链都已被覆盖，枚举「最大值曾经取到的每个形态」即可覆盖所有候选最优状态。

Java 实现（minimumDeviation）

import java.util.PriorityQueue;

class Solution {
    public int minimumDeviation(int[] nums) {
        // 大根堆，存放每个数当前的最大形态
        PriorityQueue<Integer> maxHeap = new PriorityQueue<>((a, b) -> b - a);
        int min = Integer.MAX_VALUE;

        for (int x : nums) {
            if (x % 2 == 1) {
                x *= 2; // 奇数先升到最大形态
            }
            maxHeap.offer(x);
            min = Math.min(min, x);
        }

        int ans = maxHeap.peek() - min;

        // 不断削减当前最大值，直到它变成奇数（无法再降）
        while (!maxHeap.isEmpty()) {
            int max = maxHeap.poll();
            if (max % 2 == 1) {
                break; // 最大值已是最小形态，继续削别的数只会增大偏移
            }
            max /= 2;
            min = Math.min(min, max);
            maxHeap.offer(max);
            ans = Math.min(ans, maxHeap.peek() - min);
        }
        return ans;
    }
}

C++ 实现

class Solution {
public:
    int minimumDeviation(vector<int>& nums) {
        // 大根堆
        priority_queue<long long> maxHeap;
        long long mn = LLONG_MAX;

        for (int v : nums) {
            long long x = v;
            if (x % 2 == 1) {
                x *= 2; // 奇数升到最大形态
            }
            maxHeap.push(x);
            mn = min(mn, x);
        }

        long long ans = maxHeap.top() - mn;

        while (!maxHeap.empty()) {
            long long mx = maxHeap.top();
            maxHeap.pop();
            if (mx % 2 == 1) {
                break; // 最大值已无法再降
            }
            mx /= 2;
            mn = min(mn, mx);
            maxHeap.push(mx);
            ans = min(ans, maxHeap.top() - mn);
        }

        return (int)ans;
    }
};

Python 实现

import heapq
from typing import List


class Solution:
    def minimumDeviation(self, nums: List[int]) -> int:
        # Python 只有小根堆，存负数模拟大根堆
        max_heap = []
        mn = float("inf")

        for x in nums:
            if x % 2 == 1:
                x *= 2  # 奇数升到最大形态
            heapq.heappush(max_heap, -x)
            mn = min(mn, x)

        ans = -max_heap[0] - mn

        while max_heap:
            mx = -heapq.heappop(max_heap)
            if mx % 2 == 1:
                break  # 最大值已无法再降
            mx //= 2
            mn = min(mn, mx)
            heapq.heappush(max_heap, -mx)
            ans = min(ans, -max_heap[0] - mn)

        return ans

复杂度

  • 时间：O(n log n · log V)，每个数最多被除以 2 约 log V 次（V <= 2 * 10^9），每次堆操作 O(log n)。
  • 空间：O(n)，大根堆存放全部元素。
易错点与扩展（面试高频考点）
  1. 漏掉「奇数先乘 2」：不先升到最大形态，会漏掉「先升后降」能取到的中间值，答案偏大。
  2. long long 更稳妥：奇数最大 10^9 - 1，乘 2 后为 1999999998，仍在 int 范围内（999999999 × 2 = 1999999998 < INT_MAX，并不会溢出），但统一用 long long 处理更稳妥。
  3. 终止条件是「堆顶为奇数」：最大值是奇数时不能再除，此时贪心停止；错误地继续削减其他元素会让最小值下降、偏移增大。
  4. 最小值 min 只降不升：削最大值时会刷新全局最小值，必须随时维护，否则偏移量算错。
  5. 贪心正确性：所有候选最优状态都对应「某个历史最大值形态」，通过枚举削减过程即可全覆盖，无需回溯。
