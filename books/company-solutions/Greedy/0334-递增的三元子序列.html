题目与约束

给你一个整数数组 nums ，判断这个数组中是否存在长度为 3 的递增子序列。

如果存在这样的三元组下标 (i, j, k) 且满足 i < j < k ，使得 nums[i] < nums[j] < nums[k] ，返回 true ；否则，返回 false 。

示例 1：

输入：nums = [1,2,3,4,5]
输出：true
解释：任何 i 示例 2：

输入：nums = [5,4,3,2,1]
输出：false
解释：不存在满足题意的三元组

示例 3：

输入：nums = [2,1,5,0,4,6]
输出：true
解释：其中一个满足题意的三元组是 (1, 4, 5)，因为 nums[1] == 1 提示：

  • 1 <= nums.length <= 5 * 105

  • -231 <= nums[i] <= 231 - 1

进阶：你能实现时间复杂度为 O(n) ，空间复杂度为 O(1) 的解决方案吗？

核心不变量

遍历时始终维护 first = 目前见过的最小值、second = 「存在某个更早的 first 小于它」的最小值；一旦出现比 second 还大的数 x，就得到 first < second < x 的三元组。

完整推导

思路推导

  1. 为什么不能简单暴力

枚举三元组是 O(n³)，用「固定中间元素再看两边」是 O(n²)，都过不了 5×10⁵ 的数据规模。进阶要求 O(n)/O(1)，说明只需常数个变量边走边判断。

  1. 贪心：在顺序上先"铺两块尽量低的垫脚石"

从左往右扫，我们希望第一块石头 first 尽量小、第二块石头 second 也尽量小（只要它比 first 大）。这样后面只要出现一个比 second 大的数，三连就成立。

  1. 三个分支的更新规则
  • x <= first：出现了更小的数，把它当成新的第一块石头，first = x；
  • 否则 x <= second：它比 first 大，可以当第二块石头，second = x；
  • 否则（x > second）：first < second < x 成立，直接返回 true。
  1. 小例子 [2,1,5,0,4,6]

2→first=2；1→first=1；5→second=5；0→first=0；4→second=4；6 > 4→true。

Java 实现（increasingTriplet）

class Solution {
    public boolean increasingTriplet(int[] nums) {
        int first = Integer.MAX_VALUE;   // 目前见过的最小值
        int second = Integer.MAX_VALUE;  // 存在更早的 first 小于它的最小值
        for (int x : nums) {
            if (x <= first) {
                first = x;               // 更新第一块石头
            } else if (x <= second) {
                second = x;              // 用它作第二块石头
            } else {
                return true;             // first < second < x
            }
        }
        return false;
    }
}

复杂度

  • 时间：O(n)，只需一次线性扫描。
  • 空间：O(1)，只用了 first、second 两个变量。

易错点与扩展（面试高频考点）

  1. 更新 first 会不会让已有的 second 失效？ 不会。second 记录的是"曾经存在比它小的 first"，即使把 first 换成更靠后的更小值，second 仍对应它之前那个合法的 first，first < second 依然成立。
  2. 相等元素的处理：用 <= 归并到前两个分支，避免把相等元素误当成严格递增。
  3. 长度不足：数组长度 < 3 时循环自然走完返回 false，无需特判。
  4. 扩展到长度 k 的递增子序列：可以维护长度为 k-1 的"最小末尾数组"（类似 LIS 的 patience sorting），但那样退化为 O(n log k)，本题 k=3 只需常数变量。
  5. 对照 LIS：最长递增子序列的经典 O(n log n) 解法更通用，但本题只要判断"是否存在长度 3"，贪心 O(n)/O(1) 才是最优。

Python 实现

class Solution:
    def increasingTriplet(self, nums: list[int]) -> bool:
        first = second = float('inf')   # 第一块 / 第二块石头
        for x in nums:
            if x <= first:
                first = x               # 更新第一块石头
            elif x <= second:
                second = x              # 用它作第二块石头
            else:
                return True             # first < second < x
        return False
