题目与约束

给你一个输入字符串 (s) 和一个字符模式 (p) ，请你实现一个支持 '?' 和 '*' 匹配规则的通配符匹配：

  • '?' 可以匹配任何单个字符。

  • '*' 可以匹配任意字符序列（包括空字符序列）。

判定匹配成功的充要条件是：字符模式必须能够 完全匹配 输入字符串（而不是部分匹配）。

示例 1：

输入：s = "aa", p = "a"
输出：false
解释："a" 无法匹配 "aa" 整个字符串。

示例 2：

输入：s = "aa", p = ""
输出：true
解释：'' 可以匹配任意字符串。

示例 3：

输入：s = "cb", p = "?a"
输出：false
解释：'?' 可以匹配 'c', 但第二个 'a' 无法匹配 'b'。

提示：

  • 0 <= s.length, p.length <= 2000

  • s 仅由小写英文字母组成

  • p 仅由小写英文字母、'?' 或 '*' 组成

核心不变量

每遇到一个 '*'，只记录它的位置和当时 s 的匹配位置；一旦后续失配，就回退到"星号之后一位"，并让星号多吞掉 s 的一个字符。

完整推导

思路推导

  1. 直觉与痛点（星号到底吃多少？）

'?' 与普通字符都是一一对应，很好办；难点只在 '*'——它可以匹配 0 个、1 个、任意多个字符，事先并不知道该吃多少。若用回溯穷举「吃 0 个 / 吃 1 个 / 吃 2 个……」，最坏会指数爆炸。

  1. 破局思路（贪心 + 记住最近一个星号）

维护两个指针 sIdx、pIdx 同步前进：字符相等或 p[pIdx] == '?' 就都前进；遇到 '*' 就先假设它匹配空串，记下 star = pIdx、sTmp = sIdx，只让 pIdx 前进。这样把「星号吃多少」这个悬念留到以后。

  1. 关键追问（失配了怎么办？）

一旦当前字符对不上，且之前出现过星号（star != -1），就让那个星号「多吃一个字符」：sTmp++、sIdx = sTmp、pIdx = star + 1，从星号后一位继续尝试。因为星号能吞任意长度，这种"先少后多"的贪心不会漏解。例如 s = "adceb"、p = "*a*b"，* 会先吃空、失配后逐步多吃，直到某次 a、b 都对齐。

收尾时 s 已走完，只要 p 剩下的全是 '*' 就匹配成功，否则失败。

Java 实现（isMatch）

class Solution {
    public boolean isMatch(String s, String p) {
        int sIdx = 0, pIdx = 0;
        int star = -1;   // 最近一个 '*' 在 p 中的下标
        int sTmp = -1;   // 该 '*' 当前吞到 s 的哪个位置
        int sLen = s.length(), pLen = p.length();

        while (sIdx < sLen) {
            // 字符匹配，或模式为 '?'（可匹配任意单个字符）
            if (pIdx < pLen && (p.charAt(pIdx) == '?' || p.charAt(pIdx) == s.charAt(sIdx))) {
                sIdx++;
                pIdx++;
            } else if (pIdx < pLen && p.charAt(pIdx) == '*') {
                // 先假设 '*' 匹配空串，记录现场
                star = pIdx;
                sTmp = sIdx;
                pIdx++;
            } else if (star != -1) {
                // 失配：让最近的 '*' 多吃一个字符，然后从星号后一位重试
                pIdx = star + 1;
                sTmp++;
                sIdx = sTmp;
            } else {
                // 无星号可回退，直接失败
                return false;
            }
        }

        // s 已耗尽，p 剩余部分必须全是 '*'
        while (pIdx < pLen && p.charAt(pIdx) == '*') {
            pIdx++;
        }
        return pIdx == pLen;
    }
}

复杂度

  • 时间：最坏 O(s × p)。贪心回溯在失配时会把 sIdx 退回 sTmp，星号后的模式段可能被反复重扫；常见输入接近 O(s + p)，2000 长度内可过。
  • 空间：O(1)，只用了几个下标变量，无需额外数组。

易错点与扩展（面试高频考点）

  1. 收尾必须检查剩余模式：s 走完后，p 里可能还剩若干 '*'，务必全部跳过再看是否到底，否则 s = ""、p = "***" 会误判。
  2. 连续星号只保留一个：预处理时把连续的 '*' 合并成单个能减少无谓回退，但不影响正确性。
  3. sTmp 的含义别搞混：它记录的是「星号下一次要吞到的位置」，回退时是 sTmp++ 而不是 star++。
  4. 别用暴力回溯：'*' 分支若写成递归穷举，最坏 O(2^n)，长度 2000 必然超时。
  5. 扩展（动态规划）：设 dp[i][j] 表示 s 前 i 个与 p 前 j 个是否匹配，p[j]=='*' 时 dp[i][j] = dp[i-1][j] || dp[i][j-1]，时间 O(s·p)、空间可滚动到 O(p)，是更通用但更慢的解法，面试可作对照。

C++ 实现

#include <string>

class Solution {
public:
    bool isMatch(string s, string p) {
        int sIdx = 0, pIdx = 0;
        int star = -1, sTmp = -1;
        int sLen = s.size(), pLen = p.size();

        while (sIdx < sLen) {
            if (pIdx < pLen && (p[pIdx] == '?' || p[pIdx] == s[sIdx])) {
                ++sIdx;
                ++pIdx;
            } else if (pIdx < pLen && p[pIdx] == '*') {
                star = pIdx;
                sTmp = sIdx;
                ++pIdx;
            } else if (star != -1) {
                pIdx = star + 1;
                ++sTmp;
                sIdx = sTmp;
            } else {
                return false;
            }
        }

        while (pIdx < pLen && p[pIdx] == '*') ++pIdx;
        return pIdx == pLen;
    }
};
