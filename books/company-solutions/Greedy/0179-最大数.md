# 179. 最大数

| 题目信息 | 内容 |
|---|---|
| 难度 | 中等 |
| 核心模式 | 自定义比较器排序（拼接大小比较） |
| 时间复杂度 | O(n log n) |
| 空间复杂度 | O(n) |

## 题目与约束

给定一组非负整数 `nums`，重新排列每个数的顺序（每个数不可拆分）使之组成一个最大的整数。

**注意：** 输出结果可能非常大，所以你需要返回一个字符串而不是整数。

**示例 1：**

```
输入：nums = [10,2]
输出："210"
```

**示例 2：**

```
输入：nums = [3,30,34,5,9]
输出："9534330"
```

**提示：**

- `1 <= nums.length <= 100`
- `0 <= nums[i] <= 10^9`

## 核心不变量

> 定义「a 排在 b 前面」当且仅当字符串拼接 `a+b > b+a`；按这个比较规则排序后，从左到右拼接即为能得到的最大数。

## 完整推导

### 思路推导

1. **直觉与痛点（为什么不能直接按数值或字典序排？）**

   直觉上「大数放前面」，但位数不同时会翻车：`3` 与 `30`，若把 `30` 当成更长的数放前面得到 `303`，而正确答案是 `330`；若按字典序 `"30" < "3"` 也会排错。可见单个数的绝对大小并不能决定前后关系，关键要看「两个数拼起来谁更大」。

2. **破局思路（把比较下沉到「两人对决」）**

   对任意两个数 `a`、`b`，只比较两种拼法：`a+b` 与 `b+a`。谁拼出来更大，谁就应当排前面。例如 `3` 与 `30`：`"330" > "303"`，所以 `3` 在 `30` 前面。`9` 与 `5`：`"95" > "59"`，所以 `9` 在前。把这条规则交给排序算法当比较器即可。

3. **关键追问（这个比较规则靠谱吗？）**

   拼接比较满足自反、反对称，并且可以证明具有传递性——可以把它想象成「无限循环串 `aaaa...` 与 `bbbb...` 的字典序比较」，因此它构成一个全序，排序结果唯一且最优。排序后依次拼接，就是最大数。

4. **收尾（前导零陷阱）**

   如果排序后第一个元素是 `"0"`，说明所有数都是 0（例如 `[0,0]`），此时直接返回 `"0"`，避免输出 `"00"`。

### Java 实现（largestNumber）

```java
import java.util.Arrays;

class Solution {
    public String largestNumber(int[] nums) {
        // 1. 全部转成字符串，方便做拼接比较
        int n = nums.length;
        String[] strs = new String[n];
        for (int i = 0; i < n; i++) {
            strs[i] = String.valueOf(nums[i]);
        }

        // 2. 比较器：b+a 与 a+b 比较，让拼接后更大的数排在前面（降序）
        //    注意用字符串比较，避免大整数拼接近似或溢出
        Arrays.sort(strs, (a, b) -> (b + a).compareTo(a + b));

        // 3. 全是 0 时，避免输出 "00..." 这类前导零结果
        if (strs[0].equals("0")) {
            return "0";
        }

        // 4. 依次拼接
        StringBuilder sb = new StringBuilder();
        for (String s : strs) {
            sb.append(s);
        }
        return sb.toString();
    }
}
```

### 复杂度

- 时间：`O(n log n)` 次比较，每次比较要拼接并比较两个长度 `L` 的字符串，实际为 `O(n log n · L)`，其中 `L` 为数位长度；在本题范围内近似 `O(n log n)`。
- 空间：`O(n)`，存放字符串数组与结果字符串。

### 易错点与扩展（面试高频考点）

1. **比较器不要用减法**：写成 `(a, b) -> b - a` 或把数拼成 `long` 再相减，在 `10^9` 量级拼接后会溢出。必须比较字符串。
2. **比较器方向**：要让更大的数在前，应为 `(b + a).compareTo(a + b)`（降序），写反会得到最小数。
3. **前导零处理**：`[0, 0]`、`[0]` 这类情况必须特判返回 `"0"`，否则结果含多余前导零。
4. **`nums[i]` 为 0**：排序比较规则对含 0 的数组依旧成立，无需单独处理，只要最后做一次全零判断即可。
5. **扩展（证明/稳定性）**：可向面试官说明该比较器等价于比较无限重复串，从而具备传递性；这是「排序 + 自定义比较器」类贪心题（如把数组排成最小数）的统一套路。

## 力扣原题

[179. 最大数](https://leetcode.cn/problems/largest-number/)

### C++ 实现

```cpp
#include <string>
#include <vector>
#include <algorithm>

class Solution {
public:
    std::string largestNumber(std::vector<int>& nums) {
        std::vector<std::string> strs;
        strs.reserve(nums.size());
        for (int x : nums) {
            strs.push_back(std::to_string(x));
        }

        // a 排在 b 前面当且仅当 a+b > b+a
        std::sort(strs.begin(), strs.end(), [](const std::string& a, const std::string& b) {
            return a + b > b + a;
        });

        // 全为 0 时返回单个 "0"
        if (strs[0] == "0") {
            return "0";
        }

        std::string res;
        for (const std::string& s : strs) {
            res += s;
        }
        return res;
    }
};
```

### Python 实现

```python
from typing import List
from functools import cmp_to_key


class Solution:
    def largestNumber(self, nums: List[int]) -> str:
        strs = [str(x) for x in nums]

        # 拼接比较：a+b > b+a 时 a 在前
        def cmp(a: str, b: str) -> int:
            if a + b > b + a:
                return -1
            if a + b < b + a:
                return 1
            return 0

        strs.sort(key=cmp_to_key(cmp))

        if strs[0] == "0":
            return "0"

        return "".join(strs)
```
