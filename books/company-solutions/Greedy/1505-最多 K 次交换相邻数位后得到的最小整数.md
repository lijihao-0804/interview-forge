# 1505. 最多 K 次交换相邻数位后得到的最小整数

| 题目信息 | 内容 |
|---|---|
| 难度 | 困难 |
| 核心模式 | 贪心逐位选最小 + 树状数组维护位置偏移 |
| 时间复杂度 | O(n log n)（n 为位数，每位尝试 10 个数位） |
| 空间复杂度 | O(n) |

## 题目与约束

给定一个字符串 `num` 表示非常大的整数和一个整数 `k`。你可以交换这个整数相邻数位的数字**最多** `k` 次。

请你返回你能得到的最小整数，并以字符串形式返回。

**示例 1：**

```
输入：num = "4321", k = 4
输出："1342"
解释：4321 通过 4 次交换相邻数位得到最小整数的步骤如上图所示。
```

**示例 2：**

```
输入：num = "100", k = 1
输出："010"
解释：输出可以包含前导 0 ，但输入保证不会有前导 0 。
```

**示例 3：**

```
输入：num = "36789", k = 1000
输出："36789"
解释：不需要做任何交换。
```

**提示：**

- `1 <= num.length <= 3 * 10^4`
- `num` 只包含**数字**且不含有**前导 0**
- `1 <= k <= 10^9`

## 核心不变量

> 从左到右逐位定值：在剩余 `k` 次交换足以把某个更小的数字搬到当前位时，永远选「能搬来的最小数字」，并把它的原始位置到当前位之间仍未被使用的元素个数作为交换代价。

## 完整推导

### 思路推导

1. **直觉（贪心，越靠前越重要）**：让结果更小，最高位的贡献最大。因此我们逐位决策：当前位置应当放「在预算 `k` 内能搬过来的最小数字」。因为允许相邻交换，把一个数字从位置 `p` 搬到当前最前面，需要的交换次数等于它前面「尚未被搬走」的元素个数。

2. **痛点（怎么快速求出交换代价）**：原始下标 `p` 前面本来有 `p` 个元素，但其中一些已经被搬到前面用掉了。真正还挡在它前面的，是「下标 < p 且尚未使用」的元素个数。若用树状数组把「已使用的位置」标记为 1，则代价 = `p - 已使用前缀和(0..p-1)`。

3. **算法流程**：为每个数字 0~9 各维护一个队列，记录它在原始串中出现的所有下标（天然有序）。从左到右填每一位，依次尝试数字 `d = 0..9`：若数字 d 还有剩余下标，取它最靠前的下标 `p`，用树状数组算出代价 `cost`，若 `cost <= k` 就选中它——追加 d、让 `k -= cost`、把 p 标记为已使用、弹出该队列头，然后进入下一位。

4. **小例子**：`num="4321", k=4`。第一位尝试 0~9，能搬来的最小是数字 1（下标 3），它前面 3 个元素都在，代价 3 ≤ 4，选 1，k 变 1。第二位在剩余 {4,3,2} 中，能搬来的最小是 2（下标 2，前面还有 4、3 两个未用），代价 2 > 1，退而选 3（下标 1，前面只剩 4，代价 1 ≤ 1），k 变 0。第三、四位无法再动，得 `4,2` → 结果 `1342`，与示例一致。

### Java 实现（minInteger）

```java
import java.util.ArrayDeque;
import java.util.Deque;

class Solution {
    // 树状数组：标记「已被使用」的原始位置，支持前缀计数
    static class BIT {
        int n;
        int[] tree;
        BIT(int n) { this.n = n; this.tree = new int[n + 1]; }
        void add(int i) {                 // 0-indexed 位置
            for (i++; i <= n; i += i & (-i)) tree[i] += 1;
        }
        int sum(int i) {                  // 前缀 [0..i]
            int s = 0;
            for (i++; i > 0; i -= i & (-i)) s += tree[i];
            return s;
        }
    }

    public String minInteger(String num, int k) {
        int n = num.length();
        Deque<Integer>[] pos = new ArrayDeque[10];
        for (int d = 0; d < 10; d++) pos[d] = new ArrayDeque<>();
        for (int i = 0; i < n; i++) {
            pos[num.charAt(i) - '0'].offerLast(i);
        }

        BIT bit = new BIT(n);
        StringBuilder sb = new StringBuilder();

        for (int i = 0; i < n; i++) {
            for (int d = 0; d < 10; d++) {
                if (pos[d].isEmpty()) continue;
                int p = pos[d].peekFirst();
                int usedBefore = (p == 0) ? 0 : bit.sum(p - 1);
                int cost = p - usedBefore; // 前面还「挡着」的未使用元素个数
                if (cost <= k) {
                    k -= cost;
                    sb.append((char) ('0' + d));
                    pos[d].pollFirst();
                    bit.add(p);
                    break;
                }
            }
        }
        return sb.toString();
    }
}
```

### 复杂度

- 时间：O(n log n)。外层 n 位，每位最多试 10 个数字，每次树状数组查询/更新为 O(log n)。
- 空间：O(n)。10 个位置队列共存 n 个下标，树状数组与结果各 O(n)。

### 易错点与扩展（面试高频考点）

1. **代价计算别用原始下标差**：已搬走的元素不再挡路，必须用树状数组扣掉已使用前缀，否则 `k` 会被多扣。
2. **前导零允许**：示例 2 说明结果可以出现前导 0，输出是字符串而非整数，不要特判去掉。
3. **k 可能极大**：`k` 可达 1e9，但实际每个元素最多移动 O(n) 次，用 int 存 k 时注意 n=3e4 时最大约 9e8，仍可用 int，但建议用 long 更稳妥。
4. **每个数字用队列**：同一数字可能出现在多处，必须总取最靠前的那个（队列头）才是最优且代价最小。
5. **扩展**：也可用线段树代替树状数组；若把「最多 k 次相邻交换」换成「恰好 k 次」，需额外考虑奇偶性与重复数字，思路更复杂。

## 力扣原题

[1505. 最多 K 次交换相邻数位后得到的最小整数](https://leetcode.cn/problems/minimum-possible-integer-after-at-most-k-adjacent-swaps-on-digits/)

### C++ 实现

```cpp
class Solution {
public:
    string minInteger(string num, int k) {
        int n = num.size();
        vector<queue<int>> pos(10);
        for (int i = 0; i < n; ++i) pos[num[i] - '0'].push(i);

        vector<int> tree(n + 1, 0);
        auto add = [&](int i) {
            for (++i; i <= n; i += i & (-i)) tree[i] += 1;
        };
        auto sum = [&](int i) {          // 前缀 [0..i]
            int s = 0;
            for (++i; i > 0; i -= i & (-i)) s += tree[i];
            return s;
        };

        string res;
        res.reserve(n);
        for (int i = 0; i < n; ++i) {
            for (int d = 0; d < 10; ++d) {
                if (pos[d].empty()) continue;
                int p = pos[d].front();
                int usedBefore = (p == 0) ? 0 : sum(p - 1);
                int cost = p - usedBefore;
                if (cost <= k) {
                    k -= cost;
                    res.push_back(char('0' + d));
                    pos[d].pop();
                    add(p);
                    break;
                }
            }
        }
        return res;
    }
};
```

### Python 实现

```python
class Solution:
    def minInteger(self, num: str, k: int) -> str:
        from collections import deque
        n = len(num)
        pos = [deque() for _ in range(10)]
        for i, c in enumerate(num):
            pos[ord(c) - 48].append(i)

        tree = [0] * (n + 1)

        def add(i: int) -> None:
            i += 1
            while i <= n:
                tree[i] += 1
                i += i & (-i)

        def pref(i: int) -> int:      # 前缀 [0..i]
            i += 1
            s = 0
            while i > 0:
                s += tree[i]
                i -= i & (-i)
            return s

        res = []
        for _ in range(n):
            for d in range(10):
                if not pos[d]:
                    continue
                p = pos[d][0]
                used_before = pref(p - 1) if p > 0 else 0
                cost = p - used_before
                if cost <= k:
                    k -= cost
                    res.append(chr(48 + d))
                    pos[d].popleft()
                    add(p)
                    break
        return ''.join(res)
```
