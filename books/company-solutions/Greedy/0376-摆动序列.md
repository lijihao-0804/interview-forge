# 376. 摆动序列

| 题目信息 | 内容 |
|---|---|
| 难度 | 中等 |
| 核心模式 | 贪心累加方向翻转次数，维护 up / down 两个计数 |
| 时间复杂度 | O(n) |
| 空间复杂度 | O(1) |

## 题目与约束

如果连续数字之间的差严格地在正数和负数之间交替，则数字序列称为**摆动序列**。第一个差（如果存在的话）可能是正数或负数。仅有一个元素或者含两个不等元素的序列也视作摆动序列。

- 例如，`[1, 7, 4, 9, 2, 5]` 是一个摆动序列，因为差值 `(6, -3, 5, -7, 3)` 是正负交替出现的。
- 相反，`[1, 4, 7, 2, 5]` 和 `[1, 7, 4, 5, 5]` 不是摆动序列：第一个序列是因为它的前两个差值都是正数，第二个序列是因为它的最后一个差值为零。

**子序列**可以通过从原始序列中删除一些（也可以不删除）元素来获得，剩下的元素保持其原始顺序。

给你一个整数数组 `nums`，返回 `nums` 中作为**摆动序列**的**最长子序列的长度**。

**示例 1：**

```
输入：nums = [1,7,4,9,2,5]
输出：6
解释：整个序列均为摆动序列，各元素之间的差值为 (6, -3, 5, -7, 3)。
```

**示例 2：**

```
输入：nums = [1,17,5,10,13,15,10,5,16,8]
输出：7
解释：这个序列包含几个长度为 7 的摆动序列。
其中一个是 [1, 17, 10, 13, 10, 16, 8]，各元素之间的差值为 (16, -7, 3, -3, 6, -8)。
```

**示例 3：**

```
输入：nums = [1,2,3,4,5,6,7,8,9]
输出：2
```

**提示：**

- `1 <= nums.length <= 1000`
- `0 <= nums[i] <= 1000`

**进阶：**你能否用 `O(n)` 时间复杂度完成此题？

## 核心不变量

> 最长摆动子序列的长度，等于把数组中相邻差值「连续同向的整段」压缩成一个极值点后，所剩下的极值点（含首尾）个数；用 `up`、`down` 两个计数器各记录「以当前元素结尾且最后一步向上 / 向下」的最长长度即可。

## 完整推导

### 思路推导

1. **暴力与 DP 的痛点**：最朴素的 DP 定义 `up[i]` 为「以 `i` 结尾、最后一步上升」的最长摆动长度，`down[i]` 为最后一步下降的最长长度。但更新 `up[i]` 要回看所有 `j < i`，复杂度 `O(n^2)`。其实我们只关心**方向是否翻转**，能把它压到 `O(n)`。

2. **只关心「峰」和「谷」**：一段单调上升 `[1,2,3]` 里，中间的点对增长度毫无贡献——保留它们只会让「最后一步」方向不翻转。真正有用的是**拐点**（局部极大 / 极小）。所以最优子序列就是「峰、谷、峰、谷……」交替取。

3. **两个计数器滚动**：令 `up` = 以当前元素结尾、最新一段为上升的最长长度；`down` = 最新一段为下降的最长长度。遍历到新元素时：
   - 若 `nums[i] > nums[i-1]`（出现上涨），它能接在某个「最后一步下降」的序列后面，`up = down + 1`；
   - 若 `nums[i] < nums[i-1]`（出现下跌），`down = up + 1`；
   - 若相等，方向不变，什么都不更新。

4. **小例子验证**：对 `[1,7,4,9,2,5]`：初始 `up=down=1`；`7>1 → up=2`；`4<7 → down=3`；`9>4 → up=4`；`2<9 → down=5`；`5>2 → up=6`。最终 `max(up,down)=6` ✓，与整段都是摆动序列一致。

### Java 实现（贪心双计数器）

```java
class Solution {
    public int wiggleMaxLength(int[] nums) {
        if (nums.length < 2) {
            return nums.length; // 空 / 单元素 / 长度为 2 的边界
        }
        // up: 以当前元素结尾、最后一段呈上升趋势的最长摆动长度
        // down: 以当前元素结尾、最后一段呈下降趋势的最长摆动长度
        int up = 1;
        int down = 1;

        for (int i = 1; i < nums.length; i++) {
            if (nums[i] > nums[i - 1]) {
                // 出现上涨，接在「下降结尾」的序列后面
                up = down + 1;
            } else if (nums[i] < nums[i - 1]) {
                // 出现下跌，接在「上升结尾」的序列后面
                down = up + 1;
            }
            // 相等时方向不变，跳过
        }
        return Math.max(up, down);
    }
}
```

### 复杂度

- 时间：`O(n)`。一次线性扫描，每个元素做常数次比较与赋值。
- 空间：`O(1)`。只用 `up`、`down` 两个计数器，无需额外数组。

### 易错点与扩展（面试高频考点）

1. **把「子序列」当成「子数组」**：题目求的是可跳着选的最长子序列，不是连续子数组，所以才能把中间单调点全部跳过只留拐点。
2. **相等元素处理**：`nums[i] == nums[i-1]` 时必须不做任何更新，否则会错误地虚增长度（差值为 0 不构成摆动）。
3. **边界 `n = 1`**：直接返回 1；长度为 2 且两数不等时返回 2，也由 `max(up,down)` 自然得到，但要保证循环逻辑正确。
4. **贪心与 DP 的关系**：本题 `up/down` 递推本质上就是滚动数组优化的 DP，时间 `O(n)`、空间 `O(1)`；面试可说清「为什么可以只保留两个状态」。
5. **进阶变体**：若要求返回具体的摆动子序列本身，则需要额外记录前驱并回溯，空间不再是 `O(1)`。

### C++ 实现

```cpp
#include <vector>
#include <algorithm>
using namespace std;

class Solution {
public:
    int wiggleMaxLength(vector<int>& nums) {
        int n = (int)nums.size();
        if (n < 2) return n;

        int up = 1;   // 最后一段上升的最长摆动长度
        int down = 1; // 最后一段下降的最长摆动长度

        for (int i = 1; i < n; ++i) {
            if (nums[i] > nums[i - 1]) {
                up = down + 1;
            } else if (nums[i] < nums[i - 1]) {
                down = up + 1;
            }
            // 相等时方向不变
        }
        return max(up, down);
    }
};
```

### Python 实现

```python
class Solution:
    def wiggleMaxLength(self, nums: list[int]) -> int:
        n = len(nums)
        if n < 2:
            return n

        up = 1    # 最后一段上升的最长摆动长度
        down = 1  # 最后一段下降的最长摆动长度

        for i in range(1, n):
            if nums[i] > nums[i - 1]:
                up = down + 1
            elif nums[i] < nums[i - 1]:
                down = up + 1
            # 相等时方向不变

        return max(up, down)
```
