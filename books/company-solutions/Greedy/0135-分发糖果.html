135. 分发糖果

本题学习状态正在读取学习记录…下次复习：—
本次复习：
按 M 快速切换薄弱标记
遮住推导与代码，先自己想，再逐段揭示
难度困难核心模式贪心：两次线性扫描取两侧约束的最大值时间复杂度O(n)空间复杂度O(n)

题目与约束

n 个孩子站成一排。

给你一个整数数组 ratings 表示每个孩子的评分。

你需要按照以下要求，给这些孩子分发糖果：

  • 每个孩子 至少 分配到 1 个糖果。

  • 相邻两个孩子中，评分 更高 的那个会获得更多的糖果。

请你给每个孩子分发糖果，计算并返回需要准备的 最少 糖果数目。

示例 1：

输入：ratings = [1,0,2]
输出：5
解释：你可以分别给第一个、第二个、第三个孩子分发 2、1、2 颗糖果。

示例 2：

输入：ratings = [1,2,2]
输出：4
解释：你可以分别给第一个、第二个、第三个孩子分发 1、2、1 颗糖果。
第三个孩子只得到 1 颗糖果，这满足题面中的两个条件。

提示：

  • 1 <= n == ratings.length <= 5 * 104

  • 0 <= ratings[i] <= 5 * 104

🔗 前往力扣原题验证 →

核心不变量

对每个孩子，只考虑"左边比右边高"时他至少需要多少颗糖，再只考虑"右边比左边高"时他至少需要多少颗糖，最终取两者较大值；这样同时满足了两侧约束，且总数最小。

完整推导

思路推导

  1. 直觉与痛点（相邻约束是双向的）

规则只说了"相邻中评分更高者糖更多"，这是一个相对约束。麻烦在于一个孩子可能同时受左右两个邻居影响：比如 [1,0,2] 中间的孩子比两边都低，拿 1 颗即可；而 [1,2,3] 里第三个孩子既要多于第二个，第二个又要多于第一个，于是必须形成递增 1、2、3。

如果一次性从左到右处理，会遇到"右边邻居还没定"的问题，容易漏掉右侧约束。

  1. 破局思路（拆成两个单向问题）

把双向约束拆成两个方向分别处理：

  • 左规则（只看左边）：从左到右扫描，若 ratings[i] > ratings[i-1]，则 left[i] = left[i-1] + 1，否则 left[i] = 1。这保证每个孩子都比"左邻居比他低的那些"多拿糖。
  • 右规则（只看右边）：从右到左扫描，若 ratings[i] > ratings[i+1]，则 right[i] = right[i+1] + 1，否则 right[i] = 1。
  1. 关键追问（为什么取 max 就最优？）

任何一个合法分配，第 i 个孩子的糖数必须同时 ≥ left[i] 且 ≥ right[i]，所以至少是 max(left[i], right[i])。而取 max 后：若 i 比左邻居高，则 left[i] = left[i-1]+1 > left[i-1]，同时 max 不会更小，仍满足左侧；右侧同理。于是 max 方案合法，且逐点达到下界，自然全局最少。

以 ratings = [1,0,2] 为例：left = [1,1,2]，right = [2,1,1]，max = [2,1,2]，总和 5。

Java 实现（左右两遍扫描）

class Solution {
    public int candy(int[] ratings) {
        int n = ratings.length;
        int[] left = new int[n];
        int[] right = new int[n];

        // 左规则：从左到右，比左邻居评分高就多拿一颗
        left[0] = 1;
        for (int i = 1; i < n; i++) {
            if (ratings[i] > ratings[i - 1]) {
                left[i] = left[i - 1] + 1;
            } else {
                left[i] = 1;
            }
        }

        // 右规则：从右到左，比右邻居评分高就多拿一颗
        right[n - 1] = 1;
        for (int i = n - 2; i >= 0; i--) {
            if (ratings[i] > ratings[i + 1]) {
                right[i] = right[i + 1] + 1;
            } else {
                right[i] = 1;
            }
        }

        // 每个孩子取两侧要求的较大值，累加即为最少糖果总数
        int total = 0;
        for (int i = 0; i < n; i++) {
            total += Math.max(left[i], right[i]);
        }
        return total;
    }
}

C++ 实现

#include <vector>
#include <algorithm>
using namespace std;

class Solution {
public:
    int candy(vector<int>& ratings) {
        int n = ratings.size();
        vector<int> left(n, 1), right(n, 1);

        for (int i = 1; i < n; i++) {
            if (ratings[i] > ratings[i - 1]) left[i] = left[i - 1] + 1;
        }
        for (int i = n - 2; i >= 0; i--) {
            if (ratings[i] > ratings[i + 1]) right[i] = right[i + 1] + 1;
        }

        int total = 0;
        for (int i = 0; i < n; i++) {
            total += max(left[i], right[i]);   // 取两侧约束的较大值
        }
        return total;
    }
};

Python 实现

class Solution:
    def candy(self, ratings: list[int]) -> int:
        n = len(ratings)
        left = [1] * n
        right = [1] * n

        for i in range(1, n):
            if ratings[i] > ratings[i - 1]:
                left[i] = left[i - 1] + 1

        for i in range(n - 2, -1, -1):
            if ratings[i] > ratings[i + 1]:
                right[i] = right[i + 1] + 1

        return sum(max(left[i], right[i]) for i in range(n))

复杂度

  • 时间：O(n)。三次线性遍历（左、右、求和），每次都是常数操作。
  • 空间：O(n)。使用两个长度为 n 的辅助数组记录两侧约束；若用"峰谷"技巧可优化到 O(1) 额外空间，见易错点扩展。
易错点与扩展（面试高频考点）
  1. 不能只扫一遍：单方向扫描无法同时满足两侧约束，必须左右各扫一遍再合并。
  2. 相等时不能加一：只有严格大于（>）才 +1，== 时应重置为 1，否则会多给糖。
  3. 取 max 不是取 sum：left[i] + right[i] 是错误的，会把同一份"基础 1 颗"重复计算；正确是 max(left[i], right[i])。
  4. O(1) 空间扩展：可以按"上升段 / 下降段 / 平台"分段统计（LeetCode 官方 O(1) 解法），记录上升长度与下降长度，用 1+2+...+k 求和，适合面试追问。
  5. 边界与溢出：n 最多 5×10^4，最坏糖果数约为 n(n+1)/2 ≈ 1.25×10^9，在 int 范围内（2.1×10^9）但已接近，若数据更大应改用 long。
