410. 分割数组的最大值

本题学习状态正在读取学习记录…下次复习：—
本次复习：
按 M 快速切换薄弱标记
遮住推导与代码，先自己想，再逐段揭示
难度困难核心模式二分答案 + 贪心校验时间复杂度O(n·log(sum))空间复杂度O(1)

题目与约束

给定一个非负整数数组 nums 和一个整数 k ，你需要将这个数组分成 k 个非空的连续子数组，使得这 k 个子数组各自和的最大值 最小。

返回分割后最小的和的最大值。

子数组 是数组中连续的部分。

示例 1：

输入：nums = [7,2,5,10,8], k = 2
输出：18
解释：
一共有四种方法将 nums 分割为 2 个子数组。
其中最好的方式是将其分为 [7,2,5] 和 [10,8] 。
因为此时这两个子数组各自的和的最大值为18，在所有情况中最小。

示例 2：

输入：nums = [1,2,3,4,5], k = 2
输出：9

示例 3：

输入：nums = [1,4,4], k = 3
输出：4

提示：

  • 1 <= nums.length <= 1000

  • 0 <= nums[i] <= 106

  • 1 <= k <= min(50, nums.length)

核心不变量

若存在一种分法能让「每段和都不超过 limit」且段数不超过 k，那么更大的 limit 一定也可行——这种单调性让我们能二分答案，而校验只需一次贪心扫描。

完整推导

思路推导

  1. 直接求「最大段和最小」很难：枚举所有分割方式是组合爆炸，DP 虽然能做（O(n²k)），但本题有更优雅的解法。

  2. 把「求最优值」转成「判定一个值是否可行」：我们不直接构造最优分割，而是问：「给定一个上限 X，能否把数组切成不超过 k 段，且每段和都 ≤ X？」如果这个判定能在 O(n) 内完成，并且答案具有单调性（X 越大越容易满足），就可以二分 X。

  3. 贪心校验：要判断 X 是否可行，从左到右累加，尽量把当前段塞满（贪心让每段尽可能长，从而段数最少）。一旦加上下一个元素就超过 X，就切一刀、另起一段。最后数出一共切了几段：如果段数 ≤ k，说明可行（段数少了可以再拆，题目要求正好 k 段，但多切成更小的段只会让最大和更小，所以可行）。

  4. 二分区间：下界 lo = max(nums)（单段至少得装下最大元素），上界 hi = sum(nums)（全部装成一段）。二分找最小的可行 X。

小例子：nums = [7,2,5,10,8], k = 2。lo = 10，hi = 32。取 mid = 21：贪心 [7,2,5,10]=24>21，切成 [7,2,5]、[10,8]，共 2 段 ≤ 2，可行，收窄上界。最终收敛到 18。

Java 实现（二分答案 + 贪心校验）

class Solution {
    public int splitArray(int[] nums, int k) {
        // 二分区间：下界为单个最大元素，上界为数组总和
        long lo = 0, hi = 0;
        for (int x : nums) {
            lo = Math.max(lo, x);
            hi += x;
        }

        while (lo < hi) {
            long mid = lo + (hi - lo) / 2;
            if (canSplit(nums, k, mid)) {
                hi = mid;          // mid 可行，尝试更小的上限
            } else {
                lo = mid + 1;      // mid 不可行，必须放大上限
            }
        }
        return (int) lo;
    }

    /**
     * 判断：把数组切成「每段和不超过 limit」时，段数是否不超过 k。
     * 贪心策略：尽量把当前段塞满，塞不下才切一刀，这样段数最少。
     */
    private boolean canSplit(int[] nums, int k, long limit) {
        int parts = 1;      // 至少有一段
        long cur = 0;       // 当前段的和
        for (int x : nums) {
            if (cur + x > limit) {
                parts++;    // 当前段装不下，另起一段
                cur = x;
            } else {
                cur += x;
            }
        }
        return parts <= k;
    }
}

C++ 实现

class Solution {
public:
    int splitArray(vector<int>& nums, int k) {
        long long lo = 0, hi = 0;
        for (int x : nums) {
            lo = max(lo, (long long)x);
            hi += x;
        }

        while (lo < hi) {
            long long mid = lo + (hi - lo) / 2;
            if (canSplit(nums, k, mid)) {
                hi = mid;          // 可行，尝试缩小上限
            } else {
                lo = mid + 1;      // 不可行，放大上限
            }
        }
        return (int)lo;
    }

private:
    // 贪心校验：每段和不超过 limit 时，段数是否 <= k
    bool canSplit(vector<int>& nums, int k, long long limit) {
        int parts = 1;
        long long cur = 0;
        for (int x : nums) {
            if (cur + x > limit) {
                parts++;
                cur = x;
            } else {
                cur += x;
            }
        }
        return parts <= k;
    }
};

Python 实现

class Solution:
    def splitArray(self, nums: List[int], k: int) -> int:
        lo, hi = max(nums), sum(nums)

        def can_split(limit: int) -> bool:
            parts, cur = 1, 0
            for x in nums:
                if cur + x > limit:
                    parts += 1      # 当前段装不下，另起一段
                    cur = x
                else:
                    cur += x
            return parts <= k

        # 二分最小的可行上限
        while lo < hi:
            mid = (lo + hi) // 2
            if can_split(mid):
                hi = mid
            else:
                lo = mid + 1
        return lo

复杂度

  • 时间：O(n·log(sum))，二分次数为 log(sum(nums))，每次校验 O(n) 扫描一遍数组。
  • 空间：O(1)，只用了若干常量级变量。
易错点与扩展（面试高频考点）

  1. 下界写错成 0：lo 必须是 max(nums)，因为单个元素无法再被切割，任何合法上限都必须 ≥ 最大元素。写成 0 会导致判定永远不可行或错误。

  2. 求和爆 int：nums[i] 最大 10^6、长度最大 1000，总和可达 10^9，超过 int 安全范围（虽然本题恰好在 int 内，但累加与 mid 建议用 long，避免边界溢出）。

  3. 贪心判定逻辑反了：应是「cur + x > limit 才切段」，若写成 >= 或把条件弄反，会导致段数统计错误。段数统计必须从 1 开始（最后一段也要计入）。

  4. 单调性理解：limit 增大，所需段数非增，因此「可行」是单调的，才能二分。若题目改成「恰好 k 段且要求每段和尽量平均」则单调性表述需更小心，但仍属同类。

  5. 与 DP 解法对比（面试加分）：令 dp[i][j] 表示前 i 个数分成 j 段的最小最大和，转移 dp[i][j] = min_t max(dp[t][j-1], sum(t+1..i))，时间 O(n²k)。二分+贪心把复杂度降到 O(n log sum)，是本题最优解，但面试中能说清两种解法的取舍很加分。
