题目信息 内容
难度 中等

时间复杂度 O(log n)

题目与约束

当且仅当每个相邻位数上的数字 x 和 y 满足 x <= y 时，我们称这个整数是单调递增的。

给定一个整数 n，返回小于或等于 n 的最大数字，且数字呈单调递增。

示例 1：

输入: n = 10
输出: 9

示例 2：

输入: n = 1234
输出: 1234

示例 3：

输入: n = 332
输出: 299

提示：

  • 0 <= n <= 10^9

核心不变量

找到最靠左的“下降位”后，把它减 1，并将它右边所有位变成 9，就得到不超过 n 的最大单调递增数。

完整推导

思路推导

  1. 为什么从右往左扫？ 我们希望结果尽量大，所以应尽量少改动高位。若某处出现 s[i-1] > s[i]，就必须让 s[i-1] 变小（借位），并把 i 及其右边全部置 9（这样右边最大）。

  2. 借位会连锁。 把 s[i-1] 减 1 后，它可能又比 s[i-2] 小，导致前面也出现下降。因此从右向左遍历，每次发现 s[i-1] > s[i] 就减 1 并记录 mark = i（表示从 i 开始要补 9），继续向左检查，连锁自然被处理。

  3. 最后统一补 9。 遍历结束后，把 mark 及其右边全部设为字符 '9'。

以 332 为例：

  • 从右看 3 > 2：中间位 3 减 1 变成 2，mark = 2；
  • 继续看首位 3 > 2：首位 3 减 1 变成 2，mark = 1；
  • 从下标 1 起全部置 9 → 2 9 9，即 299，正确。

Java 实现（monotoneIncreasingDigits）

class Solution {
    public int monotoneIncreasingDigits(int n) {
        char[] arr = String.valueOf(n).toCharArray();
        int mark = arr.length; // 从哪个下标开始补 9

        // 从右向左找下降位，逐位借位
        for (int i = arr.length - 1; i > 0; i--) {
            if (arr[i - 1] > arr[i]) {
                arr[i - 1]--;   // 高位减 1
                mark = i;       // 之后（含 i）全部补 9
            }
        }

        // 把 mark 及其后面所有位设为 '9'
        for (int i = mark; i < arr.length; i++) {
            arr[i] = '9';
        }

        return Integer.parseInt(new String(arr));
    }
}

复杂度

  • 时间：O(log n)，只遍历数字的位数（十进制位数约为 log₁₀ n）。
  • 空间：O(log n)，存储数字对应的字符数组。

易错点与扩展（面试高频考点）

  1. 必须从右往左扫：从左往右会在借位后忽略连锁下降（如 332、100），得到错误答案。
  2. 用 mark 记录“从哪开始补 9”：不是一发现下降就地把后面全改 9，否则后续还可能被再次覆盖出错。
  3. 借位得到前导 0 是允许的：如 10 → "09"，parseInt 会自动去掉前导 0，得到 9。
  4. 本身已单调递增时原样返回：循环不会触发任何修改，直接返回 n。
  5. 转成字符串处理更直观：比反复取模求各位更易读，注意返回值用整数而非字符串。

C++ 实现

class Solution {
public:
    int monotoneIncreasingDigits(int n) {
        string s = to_string(n);
        int mark = s.size(); // 从哪个下标开始补 9

        for (int i = s.size() - 1; i > 0; i--) {
            if (s[i - 1] > s[i]) {
                s[i - 1]--;   // 高位减 1
                mark = i;     // 之后（含 i）全部补 9
            }
        }

        for (int i = mark; i < (int)s.size(); i++) {
            s[i] = '9';
        }

        return stoi(s);
    }
};

Python 实现

class Solution:
    def monotoneIncreasingDigits(self, n: int) -> int:
        s = list(str(n))
        mark = len(s)  # 从哪个下标开始补 9

        for i in range(len(s) - 1, 0, -1):
            if s[i - 1] > s[i]:
                s[i - 1] = str(int(s[i - 1]) - 1)  # 高位减 1
                mark = i                           # 之后（含 i）全部补 9

        for i in range(mark, len(s)):
            s[i] = '9'

        return int(''.join(s))
