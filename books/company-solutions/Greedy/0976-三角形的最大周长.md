# 976. 三角形的最大周长

| 题目信息 | 内容 |
|---|---|
| 难度 | 简单 |
| 核心模式 | 排序后从大到小贪心，检查最大边的相邻两数能否成三角形 |
| 时间复杂度 | O(n log n) |
| 空间复杂度 | O(log n) |

## 题目与约束

给定由一些正数（代表长度）组成的数组 `nums` ，返回 由其中三个长度组成的、面积不为零的三角形的最大周长 。如果不能形成任何面积不为零的三角形，返回 `0`。

 

示例 1：

```
<strong>输入：</strong>nums = [2,1,2]
<strong>输出：</strong>5
<strong>解释：</strong>你可以用三个边长组成一个三角形:1 2 2。
```

示例 2：

```
<strong>输入：</strong>nums = [1,2,1,10]
<strong>输出：</strong>0
<strong>解释：</strong>
你不能用边长 1,1,2 来组成三角形。
不能用边长 1,1,10 来构成三角形。
不能用边长 1、2 和 10 来构成三角形。
因为我们不能用任何三条边长来构成一个非零面积的三角形，所以我们返回 0。
```

 

提示：

- `3 <= nums.length <= 104`

- `1 <= nums[i] <= 106`

[🔗 前往力扣原题验证 →](https://leetcode.cn/problems/largest-perimeter-triangle/)

## 核心不变量

> 排序后，若最大边 `c` 与紧邻它的两条边 `a ≤ b` 仍不满足 `a + b > c`，则 `c` 不可能成为任何合法三角形的最大边，可以安全跳过。

## 完整推导

### 思路推导

1. **三角形条件**：三条边能构成面积非零的三角形，充要条件是**任意两边之和大于第三边**；对已排序的 `a ≤ b ≤ c`，只需检查 `a + b > c`。

2. **为什么从大往小贪心**：要周长最大，优先让最大边尽量大。固定最大边 `c = nums[i]` 时，想让 `a + b` 尽量大，自然取紧挨在它前面的两个数 `nums[i-2], nums[i-1]`。

3. **关键剪枝**：若 `nums[i-2] + nums[i-1] > nums[i]` 不成立，说明即便用前两个最大的边也撑不起 `nums[i]`，那以 `nums[i]` 为最大边的任何组合都不成立，直接令 `i--` 继续往前试。

4. **第一个成功即最优**：从最大边往前扫，第一次满足条件的三元组就是周长最大的，直接返回其和；扫完都没找到则返回 `0`。

5. **小例子（示例 2）**：排序后 `[1,1,2,10]`。最大边 `10`：`1+2=3 ≯ 10` 跳过；最大边 `2`：`1+1=2 ≯ 2`（不严格大于）跳过；没有更多三元组 → 返回 `0`。

### Java 实现（largestPerimeter）

```java
import java.util.Arrays;

class Solution {
    public int largestPerimeter(int[] nums) {
        Arrays.sort(nums); // 升序排序
        // 从最大边往前扫，取紧邻的两条边判断能否成三角形
        for (int i = nums.length - 1; i >= 2; i--) {
            if (nums[i - 2] + nums[i - 1] > nums[i]) {
                return nums[i - 2] + nums[i - 1] + nums[i];
            }
        }
        return 0; // 无法构成任何非零面积三角形
    }
}
```

### 复杂度

- 时间：O(n log n)，主要花在排序；扫描是 O(n)。
- 空间：O(log n)，排序所需的递归栈开销（可近似看作 O(1)）。

### 易错点与扩展（面试高频考点）

1. **必须严格大于**：`a + b > c` 是严格不等号，`a + b == c` 退化成一条直线，面积为 0，不算。
2. **别排序成降序后取前三**：降序取最大三条不一定能成三角形，必须带上"不满足就继续往前"的贪心扫描。
3. **贪心正确性要能说清**：排序后固定最大边，前两条邻边是能配出的最长两边；邻边都不行则更大的边更不可能行。
4. **整数溢出**：`nums[i] <= 10^6`，三边之和最大约 `3*10^6`，`int` 足够，无需 `long`。
5. **边界**：数组不足 3 个元素在题设中不会出现；找不到答案统一返回 `0`。

### C++ 实现

```cpp
class Solution {
public:
    int largestPerimeter(vector<int>& nums) {
        sort(nums.begin(), nums.end()); // 升序排序
        for (int i = nums.size() - 1; i >= 2; --i) {
            if (nums[i - 2] + nums[i - 1] > nums[i]) {
                return nums[i - 2] + nums[i - 1] + nums[i];
            }
        }
        return 0;
    }
};
```

### Python 实现

```python
from typing import List


class Solution:
    def largestPerimeter(self, nums: List[int]) -> int:
        nums.sort()  # 升序排序
        for i in range(len(nums) - 1, 1, -1):
            if nums[i - 2] + nums[i - 1] > nums[i]:
                return nums[i - 2] + nums[i - 1] + nums[i]
        return 0
```
