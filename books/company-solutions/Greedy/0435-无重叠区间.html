435. 无重叠区间

本题学习状态正在读取学习记录…下次复习：—
本次复习：
按 M 快速切换薄弱标记
遮住推导与代码，先自己想，再逐段揭示
难度Medium核心模式按右端点升序排序的贪心区间调度时间复杂度O(n log n)空间复杂度O(log n)

题目与约束

给定一个区间的集合 intervals ，其中 intervals[i] = [starti, endi] 。返回 需要移除区间的最小数量，使剩余区间互不重叠 。

注意 只在一点上接触的区间是 不重叠的。例如 [1, 2] 和 [2, 3] 是不重叠的。

示例 1:

输入: intervals = [[1,2],[2,3],[3,4],[1,3]]
输出: 1
解释: 移除 [1,3] 后，剩下的区间没有重叠。

示例 2:

输入: intervals = [ [1,2], [1,2], [1,2] ]
输出: 2
解释: 你需要移除两个 [1,2] 来使剩下的区间没有重叠。

示例 3:

输入: intervals = [ [1,2], [2,3] ]
输出: 0
解释: 你不需要移除任何区间，因为它们已经是无重叠的了。

提示:

  • 1 <= intervals.length <= 105

  • intervals[i].length == 2

  • -5 * 104 <= starti < endi <= 5 * 104

核心不变量

在所有区间中，越早结束的区间越「友好」——它给后面留下越大的空间。因此按右端点从小到大贪心选取，能保留下来的区间数量最多。

完整推导

思路推导

  1. 直觉与痛点（换一个角度算）：题目要求「最少移除几个」，等价于「最多能保留几个互不重叠的区间」，答案 = 总数 − 最多保留数。直接去纠结「删哪个」很容易陷入组合爆炸，换成「尽量多留」更简单。

  2. 破局思路（贪心：优先选结束早的）：把区间按右端点升序排列。设想你在排时间表，一个会议结束得越早，你就能越早开始下一个会议。于是： - 先选右端点最小的区间作为第一个保留区间，记录它的结束时间 end； - 之后依次扫描，只要某个区间的开始时间 >= end（说明与已选区间接得上、不重叠），就保留它，并把 end 更新为它的右端点； - 否则这个区间与当前保留区间重叠，跳过（相当于移除）。

例子：[[1,2],[2,3],[3,4],[1,3]] 按右端点排序后为 [1,2],[2,3],[1,3],[3,4]。选 [1,2]（end=2）→ [2,3] 起点 2 ≥ 2 保留（end=3）→ [1,3] 起点 1 < 3 跳过 → [3,4] 起点 3 ≥ 3 保留。共保留 3 个，移除 4 − 3 = 1 个。

  1. 为什么正确（贪心交换论证）：假设最优解第一个区间是 A，我们选的第一个是右端点最小的 B。因为 B.end <= A.end，把 A 换成 B 不会与最优解里后面的区间冲突，保留数量不减少。对剩余部分归纳，贪心即最优。

Java 实现（按右端点排序贪心）

import java.util.Arrays;

class Solution {
    public int eraseOverlapIntervals(int[][] intervals) {
        if (intervals.length == 0) {
            return 0;
        }
        // 按右端点升序排序
        Arrays.sort(intervals, (a, b) -> Integer.compare(a[1], b[1]));

        int kept = 1;                       // 至少能保留第一个区间
        int end = intervals[0][1];          // 已保留区间的最后右端点

        for (int i = 1; i < intervals.length; i++) {
            // 起点 >= 上一个保留区间的终点，说明不重叠，可以保留
            if (intervals[i][0] >= end) {
                kept++;
                end = intervals[i][1];
            }
        }
        // 最少移除数 = 总数 - 最多可保留数
        return intervals.length - kept;
    }
}

C++ 实现

class Solution {
public:
    int eraseOverlapIntervals(std::vector<std::vector<int>>& intervals) {
        if (intervals.empty()) return 0;

        // 按右端点升序排序
        std::sort(intervals.begin(), intervals.end(),
                  [](const std::vector<int>& a, const std::vector<int>& b) {
                      return a[1] < b[1];
                  });

        int kept = 1;
        int end = intervals[0][1];

        for (int i = 1; i < (int)intervals.size(); ++i) {
            if (intervals[i][0] >= end) {   // 不重叠，可以保留
                ++kept;
                end = intervals[i][1];
            }
        }
        return (int)intervals.size() - kept;
    }
};

Python 实现

class Solution:
    def eraseOverlapIntervals(self, intervals: List[List[int]]) -> int:
        if not intervals:
            return 0

        # 按右端点升序排序
        intervals.sort(key=lambda x: x[1])

        kept = 1                      # 至少保留第一个区间
        end = intervals[0][1]         # 已保留区间的最后右端点

        for start, finish in intervals[1:]:
            if start >= end:          # 不重叠，可以保留
                kept += 1
                end = finish

        # 最少移除数 = 总数 - 最多可保留数
        return len(intervals) - kept

复杂度

  • 时间：O(n log n)。瓶颈在排序；排序后一次线性扫描 O(n)，总复杂度 O(n log n)。
  • 空间：O(log n)。仅排序所需的递归栈空间（不同语言实现略有差异），除此之外只用常数个变量。
易错点与扩展（面试高频考点）
  1. 排序字段选错：必须按右端点排序，而不是左端点。按左端点排序的贪心是错的，例如 [[1,100],[2,3],[4,5]]，按左端点会先选 [1,100] 而丢掉两个小区间。
  2. 边界「接触不算重叠」：判断条件是 start >= end（允许相等），不是 >。这一点是本题最容易丢分的细节。
  3. 答案含义：很多人直接返回保留数，但题目要的是移除数，务必用 n − kept。
  4. 空数组：intervals 长度至少为 1，但稳妥起见先判空可避免访问 intervals[0] 越界。
  5. 扩展（同族题）：452. 用最少数量的箭引爆气球 是同一贪心（按右端点排序，统计需要的「箭」数）；646. 最长数对链 求最多不重叠区间对，直接返回 kept 即可。三者本质都是「区间调度」模型。
