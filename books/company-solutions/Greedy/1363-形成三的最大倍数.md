# 1363. 形成三的最大倍数

| 题目信息 | 内容 |
|---|---|
| 难度 | 困难 |
| 核心模式 | 按模 3 余数删去最少数字，再降序拼接成最大数 |
| 时间复杂度 | O(n) |
| 空间复杂度 | O(1)（固定 10 个桶，不计返回字符串） |

## 题目与约束

给你一个整数数组 `digits`，你可以通过按 **任意顺序** 连接其中某些数字来形成 **3** 的倍数，请你返回所能得到的 **最大** 的 3 的倍数。

由于答案可能不在整数数据类型范围内，请以字符串形式返回答案。如果无法得到答案，请返回一个空字符串。返回的结果不应包含不必要的前导零。

**示例 1：**

```
输入：digits = [8,1,9]
输出："981"
```

**示例 2：**

```
输入：digits = [8,6,7,1,0]
输出："8760"
```

**示例 3：**

```
输入：digits = [1]
输出：""
```

**示例 4：**

```
输入：digits = [0,0,0,0,0,0]
输出："0"
```

**提示：**

- `1 <= digits.length <= 10^4`
- `0 <= digits[i] <= 9`

## 核心不变量

> 一个数能被 3 整除，当且仅当它的各位数字之和能被 3 整除；要让数最大，就要在保留最多位数的前提下把高位放最大的数字。

## 完整推导

### 思路推导

1. **先想"最大"从哪来**：任意拼接若干数字，位数越多、高位数字越大，得到的数就越大。所以策略分两步：先保证**尽可能多保留数字**（删得越少越好），再把剩下的数字**从大到小排列**。

2. **整除 3 的钥匙——数字和**：设全部数字之和为 `sum`。若 `sum % 3 == 0`，一个都不用删；若余 1，说明"多了一点余数"，需要删去若干数字让余数归零；若余 2 同理。

3. **按余数删数的规则**：
   - 记每个数字模 3 的余数。余数为 1 的数字是 `{1,4,7}`，余数为 2 的是 `{2,5,8}`，余数为 0 的是 `{0,3,6,9}`。
   - `sum % 3 == 1`：优先删 **1 个**余 1 的数字（删最小的那个，损失最小）；若没有余 1 的数字，才删 **2 个**余 2 的数字（删最小的两个）。
   - `sum % 3 == 2`：优先删 **1 个**余 2 的数字；若没有，才删 **2 个**余 1 的数字。

   为什么"删 1 个"优于"删 2 个"？删得越少，剩余位数越多，数必然更大。只有在删 1 个不可行时才退而求其次。

4. **例子**：`digits = [8,6,7,1,0]`，和 `= 22`，`22 % 3 = 1`。余 1 的数字有 `{7,1}`，删最小的 `1`；剩下 `{8,6,7,0}` 降序得 `8760`。✓

5. **收尾处理**：降序拼接后可能出现前导零（比如全是 0 或 0 排在前面）。需要去掉多余前导零：若删完前导零后为空，说明原本有数字→返回 `"0"`；若一开始就没有任何数字→返回 `""`。

### Java 实现（计数桶 + 按余数删数）

```java
class Solution {
    public String largestMultipleOfThree(int[] digits) {
        int[] cnt = new int[10];      // 每个数字 0..9 的出现次数
        int sum = 0;
        for (int d : digits) {
            cnt[d]++;
            sum += d;
        }

        int rem = sum % 3;
        if (rem == 1) {
            // 优先删 1 个余数为 1 的数字（1,4,7），删最小的
            boolean removed = false;
            for (int d = 1; d <= 9; d += 3) {
                if (cnt[d] > 0) {
                    cnt[d]--;
                    removed = true;
                    break;
                }
            }
            if (!removed) {
                // 退而求其次：删 2 个余数为 2 的数字（2,5,8），删最小的两个
                int need = 2;
                for (int d = 2; d <= 8 && need > 0; d += 3) {
                    while (cnt[d] > 0 && need > 0) {
                        cnt[d]--;
                        need--;
                    }
                }
            }
        } else if (rem == 2) {
            // 优先删 1 个余数为 2 的数字（2,5,8），删最小的
            boolean removed = false;
            for (int d = 2; d <= 8; d += 3) {
                if (cnt[d] > 0) {
                    cnt[d]--;
                    removed = true;
                    break;
                }
            }
            if (!removed) {
                // 退而求其次：删 2 个余数为 1 的数字（1,4,7），删最小的两个
                int need = 2;
                for (int d = 1; d <= 9 && need > 0; d += 3) {
                    while (cnt[d] > 0 && need > 0) {
                        cnt[d]--;
                        need--;
                    }
                }
            }
        }

        // 从 9 到 0 依次取出，天然降序，得到最大排列
        StringBuilder sb = new StringBuilder();
        for (int d = 9; d >= 0; d--) {
            for (int k = 0; k < cnt[d]; k++) {
                sb.append((char) ('0' + d));
            }
        }

        // 去掉不必要的前导零
        int i = 0;
        while (i < sb.length() && sb.charAt(i) == '0') {
            i++;
        }
        if (i == sb.length()) {
            // 全被去掉：原本有数字则只能是 0，否则无解
            return sb.length() > 0 ? "0" : "";
        }
        return sb.substring(i);
    }
}
```

### 复杂度

- 时间：`O(n)`。统计每个数字一次是 `O(n)`；之后只在固定大小的 10 个桶上操作并为结果拼串，总代价 `O(n)`。
- 空间：`O(1)`。除返回字符串外，只用长度固定为 10 的计数数组。

### 易错点与扩展（面试高频考点）

1. **删 1 个还是删 2 个的顺序**：余 1 时先尝试删 1 个余 1 的数，删不到才删 2 个余 2 的数；余 2 时先删 1 个余 2 的数，删不到才删 2 个余 1 的数。顺序写反会少保留数字，得到错误答案。
2. **删哪一个**：要在同类余数里删**最小**的数字，才能让剩下的数最大。例如同时有 1 和 7 可删，删 1。
3. **前导零与全零**：`[0,0,0]` 应返回 `"0"` 而非空串；`[0]` 也应返回 `"0"`。判断依据是"删除前导零后是否还剩字符"。
4. **无解**：只有 1 个数字且它不能被 3 整除（如 `[1]`、`[2]`）时，删完后桶为空，返回 `""`。
5. **扩展**：若要求"最小"的 3 的倍数，则保留数字后**升序**排列（注意首位不能为 0 除非只有 0）；本质仍是同一套余数删数逻辑。

### C++ 实现

```cpp
#include <string>
#include <vector>
using namespace std;

class Solution {
public:
    string largestMultipleOfThree(vector<int>& digits) {
        int cnt[10] = {0};
        int sum = 0;
        for (int d : digits) {
            cnt[d]++;
            sum += d;
        }

        int rem = sum % 3;
        if (rem == 1) {
            bool removed = false;
            for (int d = 1; d <= 9; d += 3) { // 1,4,7
                if (cnt[d] > 0) {
                    cnt[d]--;
                    removed = true;
                    break;
                }
            }
            if (!removed) {
                int need = 2;
                for (int d = 2; d <= 8 && need > 0; d += 3) { // 2,5,8
                    while (cnt[d] > 0 && need > 0) {
                        cnt[d]--;
                        need--;
                    }
                }
            }
        } else if (rem == 2) {
            bool removed = false;
            for (int d = 2; d <= 8; d += 3) { // 2,5,8
                if (cnt[d] > 0) {
                    cnt[d]--;
                    removed = true;
                    break;
                }
            }
            if (!removed) {
                int need = 2;
                for (int d = 1; d <= 9 && need > 0; d += 3) { // 1,4,7
                    while (cnt[d] > 0 && need > 0) {
                        cnt[d]--;
                        need--;
                    }
                }
            }
        }

        string res;
        for (int d = 9; d >= 0; d--) {
            res.append(cnt[d], (char) ('0' + d));
        }

        size_t i = 0;
        while (i < res.size() && res[i] == '0') {
            i++;
        }
        if (i == res.size()) {
            return res.empty() ? "" : "0";
        }
        return res.substr(i);
    }
};
```

### Python 实现

```python
class Solution:
    def largestMultipleOfThree(self, digits: list[int]) -> str:
        cnt = [0] * 10
        for d in digits:
            cnt[d] += 1
        total = sum(digits)

        rem = total % 3
        if rem == 1:
            removed = False
            for d in range(1, 10, 3):  # 1,4,7
                if cnt[d] > 0:
                    cnt[d] -= 1
                    removed = True
                    break
            if not removed:
                need = 2
                for d in range(2, 9, 3):  # 2,5,8
                    while cnt[d] > 0 and need > 0:
                        cnt[d] -= 1
                        need -= 1
        elif rem == 2:
            removed = False
            for d in range(2, 9, 3):  # 2,5,8
                if cnt[d] > 0:
                    cnt[d] -= 1
                    removed = True
                    break
            if not removed:
                need = 2
                for d in range(1, 10, 3):  # 1,4,7
                    while cnt[d] > 0 and need > 0:
                        cnt[d] -= 1
                        need -= 1

        res = ""
        for d in range(9, -1, -1):
            res += str(d) * cnt[d]

        res = res.lstrip("0")
        if res == "":
            return "0" if any(cnt) else ""
        return res
```
