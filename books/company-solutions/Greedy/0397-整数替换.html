题目信息 内容
难度 中等
核心模式 贪心 + 位运算：奇数时优先让低两位变成 00
时间复杂度 O(log n)
空间复杂度 O(1)

题目与约束

给定一个正整数 n ，你可以做如下操作：

  • 如果 n 是偶数，则用 n / 2替换 n 。

  • 如果 n 是奇数，则可以用 n + 1或n - 1替换 n 。

返回 n 变为 1 所需的 最小替换次数 。

示例 1：

输入：n = 8
输出：3
解释：8 -> 4 -> 2 -> 1

示例 2：

输入：n = 7
输出：4
解释：7 -> 8 -> 4 -> 2 -> 1
或 7 -> 6 -> 3 -> 2 -> 1

示例 3：

输入：n = 4
输出：2

提示：

  • 1 <= n <= 231 - 1

核心不变量

偶数只能除以 2；遇到奇数时，让 n 尽快变成能被 4 整除（低两位为 00）的数最优，唯一例外是 n == 3 时应当减 1。

完整推导

思路推导

  1. 直觉与痛点（偶数没得选，奇数才纠结）

偶数只有一条路：n / 2，没有选择空间。真正需要决策的是奇数——是 +1 还是 -1？两种都能把它变成偶数，但走错方向会在后面多绕几步。

  1. 破局思路（看末两位，抢"能连除两次"的机会）

把规模除以 2 是唯一能让数字真正变小的操作，所以要尽量制造"除以 2 之后还是偶数"的局面，也就是让 n 变成 4 的倍数（二进制低两位 00）。看奇数的末两位：

  • n % 4 == 1（末两位 01）：减 1 能得到 …00，一次操作后就能连除两次。例如 9 -> 8 -> 4 -> 2 -> 1，共 4 步；若 9 -> 10 -> 5 -> 4 -> 2 -> 1 要 5 步。选减 1。
  • n % 4 == 3（末两位 11）：加 1 能得到 …00。例如 15 -> 16 -> 8 -> 4 -> 2 -> 1，共 5 步；若减 1 变成 14 -> 7 -> … 反而更慢。选加 1。
  1. 唯一例外（n == 3）

3 的末两位也是 11，按上面的规则该 +1，但 3 -> 4 -> 2 -> 1 需要 3 步，而 3 -> 2 -> 1 只需 2 步。因此 n == 3 必须特判，选择减 1。

  1. 溢出防护

n 最大为 2^31 - 1，它是奇数，n + 1 会超出 int 范围溢出成负数。实现时把 n 提升为 long 再运算即可。

Java 实现（贪心迭代）

class Solution {
    public int integerReplacement(int n) {
        long x = n;          // 用 long 防止 n = 2^31-1 时 n+1 溢出
        int steps = 0;
        while (x != 1) {
            if ((x & 1) == 0) {
                x >>= 1;                 // 偶数：直接除 2
            } else if (x == 3 || (x & 3) == 1) {
                x -= 1;                  // 末两位 01，或特判 3：减 1
            } else {
                x += 1;                  // 末两位 11（且 x != 3）：加 1
            }
            steps++;
        }
        return steps;
    }
}

复杂度

  • 时间：O(log n)。每次操作要么把 n 减半，要么把它变成偶数后再减半，整体步数与二进制位数同阶。
  • 空间：O(1)。只用了常数个变量，没有递归栈或额外容器。

易错点与扩展（面试高频考点）

  1. int 溢出：n = 2^31 - 1 是奇数，n + 1 直接溢出，务必先转 long 或用无符号处理。
  2. 漏掉 n == 3 特判：只按 n % 4 == 3 -> 加 1 会得到 3 步而非最优的 2 步。
  3. 判断条件写错：末两位可用 n % 4 == 1 / 3，也可用位运算 (n & 3) == 1，两者等价。
  4. 记忆化 DFS 也能做：Map<Long, Integer> memo 自顶向下记忆化，正确但需要 O(log n) 递归栈；贪心法空间 O(1) 更优，面试可作对比。
  5. 不要暴力枚举：n 可达 20 亿，BFS 枚举所有 ±1 分支会爆炸，必须靠"看末两位"的贪心或记忆化收敛。

Python 实现

class Solution:
    def integerReplacement(self, n: int) -> int:
        steps = 0
        while n != 1:
            if n % 2 == 0:
                n //= 2                 # 偶数：除 2
            elif n == 3 or n % 4 == 1:
                n -= 1                  # 末两位 01，或特判 3
            else:
                n += 1                  # 末两位 11 且 n != 3
            steps += 1
        return steps
