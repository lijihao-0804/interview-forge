# 122. 买卖股票的最佳时机 II

| 题目信息 | 内容 |
|---|---|
| 难度 | 中等 |
| 核心模式 | 贪心，累加所有上涨区间的价差 |
| 时间复杂度 | O(n) |
| 空间复杂度 | O(1) |

## 题目与约束

给你一个整数数组 `prices` ，其中 `prices[i]` 表示某支股票第 `i` 天的价格。

在每一天，你可以决定是否购买和/或出售股票。你在任何时候 最多 只能持有 一股 股票。然而，你可以在 同一天 多次买卖该股票，但要确保你持有的股票不超过一股。

返回 你能获得的 最大 利润 。

 

示例 1：

```
<strong>输入：</strong>prices = [7,1,5,3,6,4]
<strong>输出：</strong>7
<strong>解释：</strong>在第 2 天（股票价格 = 1）的时候买入，在第 3 天（股票价格 = 5）的时候卖出, 这笔交易所能获得利润 = 5 - 1 = 4。
随后，在第 4 天（股票价格 = 3）的时候买入，在第 5 天（股票价格 = 6）的时候卖出, 这笔交易所能获得利润 = 6 - 3 = 3。
最大总利润为 4 + 3 = 7 。
```

示例 2：

```
<strong>输入：</strong>prices = [1,2,3,4,5]
<strong>输出：</strong>4
<strong>解释：</strong>在第 1 天（股票价格 = 1）的时候买入，在第 5 天 （股票价格 = 5）的时候卖出, 这笔交易所能获得利润 = 5 - 1 = 4。
最大总利润为 4 。
```

示例 3：

```
<strong>输入：</strong>prices = [7,6,4,3,1]
<strong>输出：</strong>0
<strong>解释：</strong>在这种情况下, 交易无法获得正利润，所以不参与交易可以获得最大利润，最大利润为 0。
```

 

提示：

- `1 <= prices.length <= 3 * 104`

- `0 <= prices[i] <= 104`

## 核心不变量

> 只要明天的价格高于今天，就"今天买、明天卖"并把差价计入利润；把所有正的相邻差价相加，等于在所有上涨区间上反复交易所得的最大利润。

## 完整推导

### 思路推导

1. **直觉**：本题不限制交易次数，只要价格在上涨，就可以一直低买高卖。任何一段上涨行情都应该吃满，任何下跌行情都不该持有。

2. **区间可加性**：一段连续上涨 `[1,2,3,4,5]`，一次性从 1 买到 5 赚 4；拆成每天买卖 `(2-1)+(3-2)+(4-3)+(5-4)` 同样赚 4。二者收益完全相同，所以"能不能拆"不影响最优值——这给了贪心的合法性。

3. **破局**：于是无需关心交易的具体起止点，只需遍历一遍数组：只要 `prices[i] > prices[i-1]`，就把 `prices[i] - prices[i-1]` 累加进利润。下跌或持平时差价为负或零，忽略即可。

   以 `[7,1,5,3,6,4]` 为例：`+0(7→1下降)`, `+4(1→5)`, `+0(5→3下降)`, `+3(3→6)`, `+0(6→4下降)`，合计 `7` ✓。

### Java 实现（贪心累加正差价）

```java
class Solution {
    public int maxProfit(int[] prices) {
        int profit = 0;
        // 从第 2 天开始，逐日比较相邻两天的价格
        for (int i = 1; i < prices.length; i++) {
            // 只在上涨时交易：今天买、明天卖，吃掉这段涨幅
            if (prices[i] > prices[i - 1]) {
                profit += prices[i] - prices[i - 1];
            }
        }
        return profit;
    }
}
```

### 复杂度

- 时间：`O(n)`。只需一次线性扫描，每次做常数次比较与加法。
- 空间：`O(1)`。只用一个 `profit` 累加变量，无需额外数组。

### 易错点与扩展（面试高频考点）

1. **与"买卖股票的最佳时机 I"混淆**：I 只允许一笔交易，必须维护"历史最低买入价"求一次性最大差价；本题可无限笔，才能用"累加相邻正差价"。别把两题模板套错。
2. **贪心正确性要说清**：核心是区间可加性——把一段上涨拆成逐日交易收益不变，因此局部最优的逐日累加恰好等于全局最优。
3. **边界长度 1**：`prices.length == 1` 时循环不进入，返回 0，正确（无法交易）。
4. **也可用 DP**：维护 `hold`（持股最大现金）与 `cash`（空仓最大现金），`hold = max(hold, cash - p)`、`cash = max(cash, hold + p)`，结果一致，是通用模板。
5. **别漏掉"同一天可多次买卖"**：题目明确允许同日买卖，这进一步佐证了"逐日拆分"的合法性。

### C++ 实现

```cpp
#include <vector>
using namespace std;

class Solution {
public:
    int maxProfit(vector<int>& prices) {
        int profit = 0;
        for (int i = 1; i < (int)prices.size(); ++i) {
            if (prices[i] > prices[i - 1]) {
                profit += prices[i] - prices[i - 1];
            }
        }
        return profit;
    }
};
```

### Python 实现

```python
class Solution:
    def maxProfit(self, prices: list[int]) -> int:
        profit = 0
        for i in range(1, len(prices)):
            if prices[i] > prices[i - 1]:
                profit += prices[i] - prices[i - 1]
        return profit
```
