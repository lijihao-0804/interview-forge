题目信息 内容
难度 中等
核心模式 贪心：优先把最靠前的非 'a' 改成 'a'
时间复杂度 O(n)
空间复杂度 O(n)

题目与约束

给你一个由小写英文字母组成的回文字符串 palindrome ，请你将其中 一个 字符用任意小写英文字母替换，使得结果字符串的 字典序最小 ，且 不是 回文串。

请你返回结果字符串。如果无法做到，则返回一个 空串 。

如果两个字符串长度相同，那么字符串 a 字典序比字符串 b 小可以这样定义：在 a 和 b 出现不同的第一个位置上，字符串 a 中的字符严格小于 b 中的对应字符。例如，"abcc” 字典序比 "abcd" 小，因为不同的第一个位置是在第四个字符，显然 'c' 比 'd' 小。

示例 1：

<strong>输入：</strong>palindrome = "abccba"
<strong>输出：</strong>"aaccba"
<strong>解释：</strong>存在多种方法可以使 "abccba" 不是回文，例如 "<em><strong>z</strong></em>bccba", "a<em><strong>a</strong></em>ccba", 和 "ab<em><strong>a</strong></em>cba" 。
在所有方法中，"aaccba" 的字典序最小。

示例 2：

<strong>输入：</strong>palindrome = "a"
<strong>输出：</strong>""
<strong>解释：</strong>不存在替换一个字符使 "a" 变成非回文的方法，所以返回空字符串。

提示：

  • 1 <= palindrome.length <= 1000

  • palindrome 只包含小写英文字母。

核心不变量

要让字典序尽可能小，就贪心地从前往后找第一个不是 'a' 的字符改成 'a'；若前半段全是 'a'，则只能把最后一个字符改成 'b'。

完整推导

思路推导

  1. 字典序最小的直觉：想让结果字典序最小，就应该尽量让更靠前的位置变小。字母里最小的字符是 'a'，所以从字符串开头往后扫，找到第一个不是 'a' 的字符，把它改成 'a'，这是能让字典序最小的最激进做法。

  2. 只在左半边找：字符串原本是回文。如果改的是右半边某个位置，那么对称位置的字符也应当同步改变才可能维持回文；但我们只需要"破坏回文"，因此改动左半边（更靠前）本身就是字典序更优的。扫描范围取 [0, n/2)，即左半段（不含中点）。

  3. 小例子："abccba"，左半段为 a b c。第一个非 'a' 的字符是下标 1 的 'b'，改成 'a' 得到 "aaccba"，正是答案。

  4. 兜底情况：如果左半段全是 'a'（例如 "aaaa"、"aabaa"），说明没有更靠前的位置可以减小。此时只能"反其道而行"，把最后一个字符改成 'b'——它是能破坏回文且字典序增量最小的改法（改中点会因对称而仍是回文；改更靠前的位置会让增量更大）。特判：长度为 1 时无论怎么改都是回文，返回空串。

Java 实现（breakPalindrome）

class Solution {
    public String breakPalindrome(String palindrome) {
        int n = palindrome.length();
        // 长度为 1 时，替换后必然仍是回文，无法破坏
        if (n == 1) {
            return "";
        }
        char[] arr = palindrome.toCharArray();
        // 只在左半段寻找第一个不是 'a' 的字符，改成 'a' 即可得到最小字典序
        for (int i = 0; i < n / 2; i++) {
            if (arr[i] != 'a') {
                arr[i] = 'a';
                return new String(arr);
            }
        }
        // 左半段全是 'a'，只能把最后一个字符改成 'b' 来破坏回文
        arr[n - 1] = 'b';
        return new String(arr);
    }
}

复杂度

  • 时间：O(n)，只需扫描字符串左半段一次，构造结果字符串也是 O(n)。
  • 空间：O(n)，把字符串转成字符数组以便原地修改，占用与原串等长的额外空间。

易错点与扩展（面试高频考点）

  1. 扫描范围写成整个字符串：必须在 [0, n/2) 内找。若把整个串都扫，会在右半边改动，既破坏不了回文（对称性）又得不到最小字典序。
  2. 忽略长度 1 的特判："a" 无法破坏，必须返回空串，否则会把 'a' 改成 'b' 得到 "b"，而 "b" 仍是回文，答案错误。
  3. 兜底时改中点：奇数长度若把中点字符改掉，因中点不参与对称，字符串往往仍是回文，必须改最后一个字符。
  4. 兜底改成什么：改成 'b' 而不是 'a'（'a' 已经用尽），且是从最右侧改，保证字典序增量最小。
  5. 扩展追问：如果把"回文串"放宽成"任意串"，问题就变成"用最小代价使它不是回文"，思路仍是优先修改最靠前且影响最小的位置——与本题的贪心内核一致。

力扣原题

1328. 破坏回文串

C++ 实现

class Solution {
public:
    string breakPalindrome(string palindrome) {
        int n = palindrome.size();
        if (n == 1) return "";              // 单字符无法破坏回文
        for (int i = 0; i < n / 2; i++) {   // 只在左半段找第一个非 'a'
            if (palindrome[i] != 'a') {
                palindrome[i] = 'a';
                return palindrome;
            }
        }
        palindrome[n - 1] = 'b';            // 左半段全 'a'，改末尾为 'b'
        return palindrome;
    }
};

Python 实现

class Solution:
    def breakPalindrome(self, palindrome: str) -> str:
        n = len(palindrome)
        if n == 1:
            return ""                       # 单字符无法破坏回文
        arr = list(palindrome)
        for i in range(n // 2):             # 只在左半段找第一个非 'a'
            if arr[i] != 'a':
                arr[i] = 'a'
                return ''.join(arr)
        arr[-1] = 'b'                       # 左半段全 'a'，改末尾为 'b'
        return ''.join(arr)
