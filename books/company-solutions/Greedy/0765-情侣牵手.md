# 765. 情侣牵手

| 题目信息 | 内容 |
|---|---|
| 难度 | 困难 |
| 核心模式 | 贪心 + 位置映射：每两座一组，把座位 i 的伴侣直接换到身边 |
| 时间复杂度 | O(n) |
| 空间复杂度 | O(n) |

## 题目与约束

`n` 对情侣坐在连续排列的 `2n` 个座位上，想要牵到对方的手。

人和座位由一个整数数组 `row` 表示，其中 `row[i]` 是坐在第 `i `个座位上的人的 ID。情侣们按顺序编号，第一对是 `(0, 1)`，第二对是 `(2, 3)`，以此类推，最后一对是 `(2n - 2, 2n - 1)`。

返回 最少交换座位的次数，以便每对情侣可以并肩坐在一起。 每次交换可选择任意两人，让他们站起来交换座位。

 

示例 1:

输入: row = [0,2,1,3]  
输出: 1  
解释: 只需要交换第二个人（row[1]）和第三个人（row[2]）的位置即可。

示例 2:

输入: row = [3,2,0,1]  
输出: 0  
解释: 无需交换座位，所有的情侣都已经可以手牵手了。

 

提示:

- `2n == row.length`

- `2 <= n <= 30`

- `n` 是偶数

- `0 <= row[i] < 2n`

- `row` 中所有元素均 无重复

[🔗 前往力扣原题验证 →](https://leetcode.cn/problems/couples-holding-hands/)

## 核心不变量

> 情侣编号 `x` 的伴侣就是 `x ^ 1`；从左往右把座位两两分组（`0-1`、`2-3`…），若该组两个座位不是一对，就把 `row[i]` 的伴侣换到 `i+1` 的位置，这样每修好一组恰好只需一次交换，总交换次数最少。

## 完整推导

### 思路推导

1. **直觉与痛点（怎么判定一对？）**
   情侣 `(0,1)、(2,3)…` 的编号有个漂亮性质：偶数 `2k` 与 `2k+1` 只差最低位，因此 **`x` 的伴侣是 `x ^ 1`**（异或 1：偶数变 +1、奇数变 -1）。这让「谁跟谁是一对」变成一次位运算。

2. **破局思路（两两分组，就地修好）**
   把座位按 `(0,1)、(2,3)、…` 分成 `n` 组。对每一组左端 `i`（`i` 为偶数）：
   - 若 `row[i+1] == row[i] ^ 1`，已经成对，跳过。
   - 否则，`row[i]` 的伴侣一定在后面的某个位置 `j`，把 `row[j]` 与 `row[i+1]` 交换，让这一组立刻成对，交换数 +1。
   为了快速定位伴侣，用 `pos[value] = 下标` 的映射，`O(1)` 找到 `j`。

   小例子：`row = [0,2,1,3]`。第 0 组是 `(0,2)`，`0` 的伴侣是 `1`，在位置 2，把 `row[2]=1` 与 `row[1]=2` 交换 → `[0,1,2,3]`，交换 1 次。第 2 组 `(2,3)` 已配对，结束，答案 1。

3. **关键追问（为什么这样最贪心也最优？）**
   每一组如果两个座位不是一对，那么其中至少有一个人的伴侣不在这里，**任何方案都至少要动其中一人一次**，即该组至少需要一次交换。贪心每组恰好用一次交换修好一组，既达到下界，又不会破坏已经修好的组（把伴侣换进来、把多余的人换出去），所以总次数就是最少。

4. **收尾**
   顺序扫描完所有组，累计的交换次数即答案。

### Java 实现（贪心 + 位置映射）

```java
class Solution {
    public int minSwapsCouples(int[] row) {
        int n = row.length;
        // pos[v] = 值 v 当前所在座位下标，便于 O(1) 找到伴侣
        int[] pos = new int[n];
        for (int i = 0; i < n; i++) {
            pos[row[i]] = i;
        }

        int swaps = 0;
        // 每两个座位为一组
        for (int i = 0; i < n; i += 2) {
            int partner = row[i] ^ 1;          // 异或 1 得到伴侣编号
            if (row[i + 1] == partner) {
                continue;                      // 本组已是一对
            }
            // 把伴侣从位置 j 换到 i+1
            int j = pos[partner];
            int tmp = row[i + 1];
            row[i + 1] = row[j];
            row[j] = tmp;
            // 同步更新位置映射
            pos[row[i + 1]] = i + 1;
            pos[row[j]] = j;
            swaps++;
        }
        return swaps;
    }
}
```

### 复杂度

- 时间：`O(n)`。外层循环 `n/2` 组，每组通过 `pos` 映射 `O(1)` 定位并交换，无需每次扫描。
- 空间：`O(n)`。额外的 `pos` 数组记录每个人所在座位。

### 易错点与扩展（面试高频考点）

1. **伴侣编号用异或**：`x ^ 1` 只是因为在示例里情侣编号 `(0,1)(2,3)…` 相邻成对；若题面换成任意配对关系，需改用真正的「伴侣映射」表。
2. **交换后要更新 `pos`**：交换两个人后位置变了，必须同步维护 `pos[row[i+1]]` 和 `pos[row[j]]`，否则后续定位会错。
3. **只扫偶数下标**：组是按 `(0,1)(2,3)` 划分的，`i` 每次加 2；若写成逐个 `i++` 会重复处理、逻辑混乱。
4. **贪心选择不破坏已修好的组**：把伴侣从 `j` 换到 `i+1`，同时把 `row[i+1]` 的旧人换到 `j`，所以组 `i` 变好、其他已处理组不受影响，是正确性关键。
5. **并查集扩展（另一高频解法）**：把每个座位组看作一个点，若某组里出现两个人，就把他们各自所属情侣对的「组」连边，最终答案 = `n - 连通分量数`（每个大小为 `k` 的环需要 `k-1` 次交换）。这条思路常用于面试追问「如何做到与顺序无关」。
6. **不要直接 `O(n²)` 暴力找伴侣**：虽然 `n ≤ 30` 能过，但用 `pos` 映射做到 `O(n)` 是更规范、更易拿分的写法。

### C++ 实现

```cpp
#include <vector>
using namespace std;

class Solution {
public:
    int minSwapsCouples(vector<int>& row) {
        int n = row.size();
        vector<int> pos(n);
        for (int i = 0; i < n; i++) pos[row[i]] = i;

        int swaps = 0;
        for (int i = 0; i < n; i += 2) {
            int partner = row[i] ^ 1;      // 伴侣编号
            if (row[i + 1] == partner) continue;
            int j = pos[partner];          // 伴侣所在位置
            swap(row[i + 1], row[j]);
            pos[row[i + 1]] = i + 1;       // 同步更新位置映射
            pos[row[j]] = j;
            swaps++;
        }
        return swaps;
    }
};
```

### Python 实现

```python
class Solution:
    def minSwapsCouples(self, row: list[int]) -> int:
        n = len(row)
        pos = [0] * n
        for i, v in enumerate(row):
            pos[v] = i

        swaps = 0
        for i in range(0, n, 2):
            partner = row[i] ^ 1          # 伴侣编号
            if row[i + 1] == partner:
                continue
            j = pos[partner]              # 伴侣所在位置
            row[i + 1], row[j] = row[j], row[i + 1]
            pos[row[i + 1]] = i + 1       # 同步更新位置映射
            pos[row[j]] = j
            swaps += 1
        return swaps
```
