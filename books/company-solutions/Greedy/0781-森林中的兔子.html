781. 森林中的兔子

本题学习状态正在读取学习记录…下次复习：—
本次复习：
按 M 快速切换薄弱标记
遮住推导与代码，先自己想，再逐段揭示
难度中等核心模式贪心 + 哈希计数，按「每组 x+1 只」向上取整分组时间复杂度O(n)空间复杂度O(n)

题目与约束

森林中有未知数量的兔子。提问其中若干只兔子 "还有多少只其它兔子与你（指被提问的兔子）颜色相同?" ，将答案收集到一个整数数组 answers 中，其中 answers[i] 是第 i 只兔子的回答。

给你数组 answers ，返回森林中兔子的最少数量。

示例 1：

输入：answers = [1,1,2]
输出：5
解释：
两只回答了 "1" 的兔子可能有相同的颜色，设为红色。
之后回答了 "2" 的兔子不会是红色，否则他们的回答会相互矛盾。
设回答了 "2" 的兔子为蓝色。
此外，森林中还应有另外 2 只蓝色兔子的回答没有包含在数组中。
因此森林中兔子的最少数量是 5 只：3 只回答的和 2 只没有回答的。

示例 2：

输入：answers = [10,10,10]
输出：11

提示：

  • 1 <= answers.length <= 1000

  • 0 <= answers[i] < 1000

核心不变量

一只回答 x 的兔子所在同色组恰好有 x+1 只兔子；若有 k 只兔子都回答 x，它们至少需要占据 ⌈k/(x+1)⌉ 个颜色组。

完整推导

思路推导

  1. 单个回答的含义：若某兔子回答 x，说明和它同颜色（含它自己）一共有 x+1 只兔子。同色组里每只兔子都会给出相同的回答 x。

  2. 同答案可以合并：所有回答为 x 的兔子，理论上可以塞进尽量少的 x+1 人组里。设有 k 只兔子回答 x，那么至少需要 ⌈k/(x+1)⌉ 个组来容纳它们（每组最多 x+1 个同类回答）。

  3. 计算总数：每个组实际有 x+1 只兔子（即使组里有些兔子没被提问，也要算上），所以贡献为 ⌈k/(x+1)⌉ × (x+1)。对所有不同的答案 x 分别计算并累加即为答案。

  4. 小例验证：answers = [1,1,2]。回答 1 的有 2 只，组大小 2，⌈2/2⌉×2 = 2；回答 2 的有 1 只，组大小 3，⌈1/3⌉×3 = 3；合计 5。answers = [10,10,10]：k=3、组大小 11，⌈3/11⌉×11 = 11。

Java 实现（哈希计数 + 向上取整）

import java.util.HashMap;
import java.util.Map;

class Solution {
    public int numRabbits(int[] answers) {
        // 1. 统计每种回答出现的次数
        Map<Integer, Integer> count = new HashMap<>();
        for (int a : answers) {
            count.merge(a, 1, Integer::sum);
        }

        int total = 0;
        for (Map.Entry<Integer, Integer> e : count.entrySet()) {
            int x = e.getKey();          // 回答：还有 x 只同色
            int k = e.getValue();        // 该回答出现的次数
            int groupSize = x + 1;       // 每个同色组的兔子总数
            int groups = (k + groupSize - 1) / groupSize; // ⌈k / groupSize⌉
            total += groups * groupSize;
        }
        return total;
    }
}

C++ 实现

#include <vector>
#include <unordered_map>
using namespace std;

class Solution {
public:
    int numRabbits(vector<int>& answers) {
        unordered_map<int, int> count;
        for (int a : answers) count[a]++;

        int total = 0;
        for (auto& entry : count) {
            int x = entry.first;         // 回答
            int k = entry.second;        // 出现次数
            int groupSize = x + 1;       // 每组兔子数
            int groups = (k + groupSize - 1) / groupSize; // 向上取整
            total += groups * groupSize;
        }
        return total;
    }
};

Python 实现

from collections import Counter


class Solution:
    def numRabbits(self, answers: list[int]) -> int:
        count = Counter(answers)
        total = 0
        for x, k in count.items():
            group_size = x + 1              # 每个同色组的兔子数
            groups = (k + group_size - 1) // group_size  # 向上取整
            total += groups * group_size
        return total

复杂度

  • 时间：O(n)。一次遍历统计频次，再一次遍历不同的回答键（最多 n 种）做常数运算。
  • 空间：O(n)。哈希表最多存 n 个不同的回答。
易错点与扩展（面试高频考点）
  1. 向上取整写错：整数除法 k / (x+1) 会自动向下取整，必须用 (k + groupSize - 1) / groupSize 实现向上取整。
  2. 误以为同答案必定同色：当同答案兔子数超过 x+1 时必须拆成多个组，不能把超过 x+1 只都当成同一颜色。
  3. 漏算未提问的兔子：每个组都要补齐到 x+1 只，未出现在数组里的同色兔子也必须计入。
  4. x = 0 的边界：回答 0 表示它独色（组大小 1），每只这样的兔子各贡献 1，公式同样成立。
  5. 扩展：也可用长度为 1000 的计数数组代替哈希表，O(maxAnswer + n) 时间、O(maxAnswer) 空间，常数更小。
