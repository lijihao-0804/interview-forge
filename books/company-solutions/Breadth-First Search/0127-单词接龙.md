# 127. 单词接龙

| 题目信息 | 内容 |
|---|---|
| 难度 | 困难 |
| 核心模式 | 建虚拟图 + BFS 逐层扩展求最短转换序列 |
| 时间复杂度 | O(N·L²) |
| 空间复杂度 | O(N·L²) |

## 题目与约束

字典 `wordList` 中从单词 `beginWord` 到 `endWord` 的 转换序列 是一个按下述规格形成的序列 `beginWord -> s1 -> s2 -> ... -> sk`：

- 每一对相邻的单词只差一个字母。

-  对于 `1 <= i <= k` 时，每个 `si` 都在 `wordList` 中。注意， `beginWord` 不需要在 `wordList` 中。

- `sk == endWord`

给你两个单词 `beginWord` 和 `endWord` 和一个字典 `wordList` ，返回 从 `beginWord` 到 `endWord` 的 最短转换序列 中的 单词数目 。如果不存在这样的转换序列，返回 `0` 。

 

示例 1：

输入：beginWord = "hit", endWord = "cog", wordList = ["hot","dot","dog","lot","log","cog"]  
输出：5  
解释：一个最短转换序列是 "hit" -> "hot" -> "dot" -> "dog" -> "cog", 返回它的长度 5。

示例 2：

输入：beginWord = "hit", endWord = "cog", wordList = ["hot","dot","dog","lot","log"]  
输出：0  
解释：endWord "cog" 不在字典中，所以无法进行转换。

 

提示：

- `1 <= beginWord.length <= 10`

- `endWord.length == beginWord.length`

- `1 <= wordList.length <= 5000`

- `wordList[i].length == beginWord.length`

- `beginWord`、`endWord` 和 `wordList[i]` 由小写英文字母组成

- `beginWord != endWord`

- `wordList` 中的所有字符串 互不相同

[🔗 前往力扣原题验证 →](https://leetcode.cn/problems/word-ladder/)

## 核心不变量

> BFS 按层推进，每个单词第一次被访问时的层数，就是它到 `beginWord` 的最短转换步数。

## 完整推导

### 思路推导

1. **把问题抽象成图**

   把每个单词看作一个节点，两个单词只差一个字母就连一条无权边。问题就变成：从 `beginWord` 出发，到 `endWord` 的最短路径长度（节点数）。无权图最短路，第一反应就是 BFS。

2. **朴素建图太慢，改用「模式」虚拟节点**

   枚举任意两词是否只差一个字母是 O(N²·L)，N 可达 5000，会超时。换个角度：把单词 `hot` 在每一位替换为 `*` 得到 `*ot`、`h*t`、`ho*` 三个**模式**。凡是共享同一模式的单词，彼此都只差一个字母。于是「单词 -> 模式 -> 单词」天然构成一张稀疏虚拟图，无需两两比较。

3. **在虚拟图上做 BFS**

   从 `beginWord` 入队开始，每弹出一个单词，生成它的所有模式，把属于该模式、且尚未访问过的单词全部加入队列。因为 BFS 逐层扩展，第一次遇到 `endWord` 时的层数就是最短答案。

4. **小例子（示例 1）**

   第 1 层：`hit`；第 2 层：`hot`；第 3 层：`dot`、`lot`；第 4 层：`dog`、`log`；第 5 层：`cog`，命中即返回 5。

### Java 实现（ladderLength）

```java
import java.util.ArrayList;
import java.util.Collections;
import java.util.HashMap;
import java.util.HashSet;
import java.util.LinkedList;
import java.util.List;
import java.util.Map;
import java.util.Queue;
import java.util.Set;

class Solution {
    public int ladderLength(String beginWord, String endWord, List<String> wordList) {
        Set<String> wordSet = new HashSet<>(wordList);
        // 终点不在字典里，永远无法到达
        if (!wordSet.contains(endWord)) return 0;

        int L = beginWord.length();
        // 预处理：模式（某一位替换为 '*'）-> 匹配到的单词列表
        Map<String, List<String>> patternMap = new HashMap<>();
        for (String w : wordList) {
            for (int i = 0; i < L; i++) {
                String p = w.substring(0, i) + "*" + w.substring(i + 1);
                patternMap.computeIfAbsent(p, k -> new ArrayList<>()).add(w);
            }
        }

        Queue<String> queue = new LinkedList<>();
        Set<String> visited = new HashSet<>();
        queue.offer(beginWord);
        visited.add(beginWord);
        int steps = 1; // 当前层对应的单词数（beginWord 算 1 个）

        while (!queue.isEmpty()) {
            int size = queue.size();
            for (int k = 0; k < size; k++) {
                String cur = queue.poll();
                for (int i = 0; i < L; i++) {
                    String p = cur.substring(0, i) + "*" + cur.substring(i + 1);
                    for (String next : patternMap.getOrDefault(p, Collections.emptyList())) {
                        if (next.equals(endWord)) {
                            return steps + 1; // 再走一步就到达终点
                        }
                        if (visited.add(next)) {
                            queue.offer(next);
                        }
                    }
                }
            }
            steps++; // 进入下一层
        }
        return 0;
    }
}
```

### 复杂度

- 时间：O(N·L²)，N 为单词数、L 为单词长度。建模式表与 BFS 中每个模式串的构造都是 O(L)，共 O(N·L) 个模式，故 O(N·L²)；每个单词最多出队一次。
- 空间：O(N·L²)，模式表存储 O(N·L) 个长度为 L 的模式字符串，另加队列与访问集合。

### 易错点与扩展（面试高频考点）

1. **终点不在字典里必须提前返回 0**：`endWord` 即使和 `beginWord` 只差一个字母，只要不在 `wordList` 中也不合法。
2. **用模式建图避免 O(N²) 两两比较**：直接对所有单词两两判「是否只差一字母」在 5000 规模下会超时，模式映射是标准优化。
3. **visited 的时机**：单词应在**入队时**标记已访问，而不是出队时，否则同一层可能重复入队导致答案层数偏大甚至死循环。
4. **返回的是「单词数目」不是「边数」**：`hit -> hot -> ... -> cog` 有 4 条边但答案是 5 个单词，命中时返回 `steps + 1`。
5. **进阶：双向 BFS**。从 `beginWord` 与 `endWord` 同时扩展、每次扩展较小的一侧，可显著减少搜索空间，是面试加分答法（本题 tag 也包含「双向搜索」）。

### C++ 实现

```cpp
class Solution {
public:
    int ladderLength(string beginWord, string endWord, vector<string>& wordList) {
        unordered_set<string> wordSet(wordList.begin(), wordList.end());
        if (!wordSet.count(endWord)) return 0;

        int L = beginWord.size();
        // 模式 -> 单词列表
        unordered_map<string, vector<string>> patternMap;
        for (const string& w : wordList) {
            for (int i = 0; i < L; ++i) {
                string p = w;
                p[i] = '*';
                patternMap[p].push_back(w);
            }
        }

        queue<string> q;
        unordered_set<string> visited;
        q.push(beginWord);
        visited.insert(beginWord);
        int steps = 1;

        while (!q.empty()) {
            int size = q.size();
            for (int k = 0; k < size; ++k) {
                string cur = q.front();
                q.pop();
                for (int i = 0; i < L; ++i) {
                    string p = cur;
                    p[i] = '*';
                    auto it = patternMap.find(p);
                    if (it == patternMap.end()) continue;
                    for (const string& nxt : it->second) {
                        if (nxt == endWord) return steps + 1;
                        if (visited.insert(nxt).second) {
                            q.push(nxt);
                        }
                    }
                }
            }
            ++steps;
        }
        return 0;
    }
};
```

### Python 实现

```python
import collections

class Solution:
    def ladderLength(self, beginWord: str, endWord: str, wordList: list[str]) -> int:
        word_set = set(wordList)
        if endWord not in word_set:
            return 0

        L = len(beginWord)
        pattern_map = collections.defaultdict(list)
        for w in wordList:
            for i in range(L):
                pattern_map[w[:i] + '*' + w[i + 1:]].append(w)

        queue = collections.deque([beginWord])
        visited = {beginWord}
        steps = 1

        while queue:
            for _ in range(len(queue)):
                cur = queue.popleft()
                for i in range(L):
                    p = cur[:i] + '*' + cur[i + 1:]
                    for nxt in pattern_map.get(p, []):
                        if nxt == endWord:
                            return steps + 1
                        if nxt not in visited:
                            visited.add(nxt)
                            queue.append(nxt)
            steps += 1
        return 0
```
