# 967. 连续差相同的数字

| 题目信息 | 内容 |
|---|---|
| 难度 | 中等 |
| 核心模式 | BFS（逐位构造），每次在末位数字上加/减 k 扩展 |
| 时间复杂度 | O(9·2^(n-1)) |
| 空间复杂度 | O(9·2^(n-1)) |

## 题目与约束

返回所有长度为 `n` 且满足其每两个连续位上的数字之间的差的绝对值为 `k` 的 **非负整数** 。

请注意，**除了数字 `0` 本身之外，答案中的每个数字都 不能 有前导零**。例如，`01` 有一个前导零，所以是无效的；但 `0` 是有效的。

你可以按 **任何顺序** 返回答案。

**示例 1：**

```
输入：n = 3, k = 7
输出：[181,292,707,818,929]
解释：注意，070 不是一个有效的数字，因为它有前导零。
```

**示例 2：**

```
输入：n = 2, k = 1
输出：[10,12,21,23,32,34,43,45,54,56,65,67,76,78,87,89,98]
```

**示例 3：**

```
输入：n = 2, k = 0
输出：[11,22,33,44,55,66,77,88,99]
```

**示例 4：**

```
输入：n = 2, k = 2
输出：[13,20,24,31,35,42,46,53,57,64,68,75,79,86,97]
```

**提示：**

- `2 <= n <= 9`
- `0 <= k <= 9`

## 核心不变量

> 每一位只需保证与前一位的差的绝对值为 `k`；从首位 `1..9` 出发逐位向右生长，长度到 `n` 即为一个合法答案。

## 完整推导

### 思路推导

1. **逐位生长**：一个合法的 `n` 位数，其任意相邻两位满足 `|d[i] - d[i-1]| = k`。因此可以从最高位开始，一位一位往后接。

2. **首位特殊**：首位不能是 `0`（否则成了前导零），所以初始集合是 `1..9`。

3. **如何扩展**：设当前数字末位为 `last`，下一位只能是 `last + k` 或 `last - k`，且必须落在 `0..9`。把它们拼到末尾（`num * 10 + d`），就是长度加一后的候选。

4. **注意 `k == 0`**：此时 `last + k == last - k`，若两个分支都加会产生重复，需特判 `k != 0` 才走减分支。

5. **小例子（n = 2, k = 1）**：从 `1` 出发得 `10、12`；从 `9` 出发只保留 `98`（`9+1=10` 越界）。全部拼起来正好是示例 2 的答案。

### Java 实现（numsSameConsecDiff）

```java
import java.util.ArrayList;
import java.util.List;

class Solution {
    public int[] numsSameConsecDiff(int n, int k) {
        // 第一位取 1..9，天然避免前导零
        List<Integer> cur = new ArrayList<>();
        for (int d = 1; d <= 9; d++) {
            cur.add(d);
        }

        // 逐位扩展，直到长度达到 n
        for (int len = 2; len <= n; len++) {
            List<Integer> next = new ArrayList<>();
            for (int num : cur) {
                int last = num % 10; // 当前末位数字
                if (last + k <= 9) {
                    next.add(num * 10 + (last + k));
                }
                // k != 0 时才走减分支，避免 k=0 时重复
                if (k != 0 && last - k >= 0) {
                    next.add(num * 10 + (last - k));
                }
            }
            cur = next;
        }

        // 转成题目要求的 int[]
        int[] res = new int[cur.size()];
        for (int i = 0; i < cur.size(); i++) {
            res[i] = cur.get(i);
        }
        return res;
    }
}
```

### 复杂度

- 时间：O(9·2^(n-1))。每个数最多分叉出 2 个候选，层数 `n ≤ 9`，规模很小。
- 空间：O(9·2^(n-1))。需要存放当前这一层的所有候选数，最终结果同量级。

### 易错点与扩展（面试高频考点）

1. **前导零**：首位只能 `1..9`；中间和末位可以是 `0`，别把首位也放开。
2. **`k == 0` 去重**：不特判会得到重复答案（`last+k` 与 `last-k` 相同）。
3. **边界检查**：`last + k <= 9` 且 `last - k >= 0`，越界的分支要丢弃而不是硬加。
4. **返回类型**：Java 题面要 `int[]`，注意把 `List<Integer>` 转数组。
5. **等价拓展**：可用 DFS 递归逐位构造，思路完全一致；也可用字符串拼接再转整数，但 `num * 10 + d` 更省。

## 力扣原题

[967. 连续差相同的数字](https://leetcode.cn/problems/numbers-with-same-consecutive-differences/)

### C++ 实现

```cpp
class Solution {
public:
    vector<int> numsSameConsecDiff(int n, int k) {
        vector<int> cur;
        for (int d = 1; d <= 9; ++d) cur.push_back(d); // 首位 1..9

        for (int len = 2; len <= n; ++len) {
            vector<int> next;
            for (int num : cur) {
                int last = num % 10;
                if (last + k <= 9) next.push_back(num * 10 + last + k);
                if (k != 0 && last - k >= 0) next.push_back(num * 10 + last - k);
            }
            cur = move(next);
        }
        return cur;
    }
};
```

### Python 实现

```python
from typing import List


class Solution:
    def numsSameConsecDiff(self, n: int, k: int) -> List[int]:
        cur = list(range(1, 10))  # 首位 1..9，避免前导零

        for _ in range(2, n + 1):
            nxt = []
            for num in cur:
                last = num % 10
                if last + k <= 9:
                    nxt.append(num * 10 + last + k)
                if k != 0 and last - k >= 0:  # k==0 时避免重复
                    nxt.append(num * 10 + last - k)
            cur = nxt

        return cur
```
