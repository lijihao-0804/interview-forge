题目与约束

给你一个字符串 s 和一个字符规律 p，请你来实现一个支持 '.' 和 '*' 的正则表达式匹配。

  • '.' 匹配任意单个字符

  • '*' 匹配零个或多个前面的那一个元素

返回一个布尔值，表示匹配是否覆盖整个输入字符串（而非部分）。

示例 1：

<strong>输入：</strong>s = "aa", p = "a"
<strong>输出：</strong>false
<strong>解释：</strong>"a" 无法匹配 "aa" 整个字符串。

示例 2:

<strong>输入：</strong>s = "aa", p = "a*"
<strong>输出：</strong>true
<strong>解释：</strong>因为 '*' 代表可以匹配零个或多个前面的那一个元素, 在这里前面的元素就是 'a'。因此，字符串 "aa" 可被视为 'a' 重复了一次。

示例 3：

<strong>输入：</strong>s = "ab", p = ".*"
<strong>输出：</strong>true
<strong>解释：</strong>".*" 表示可匹配零个或多个（'*'）任意字符（'.'）。

提示：

  • 1 <= s.length <= 20

  • 1 <= p.length <= 20

  • s 只包含从 a-z 的小写字母。

  • p 只包含从 a-z 的小写字母，以及字符 . 和 *。

  • 保证每次出现字符 * 时，前面都匹配到有效的字符

核心不变量

dp[i][j] 表示 s 的前 i 个字符与 p 的前 j 个字符能否完全匹配；'*' 是唯一的分叉点——它可以让前一个元素出现 0 次（丢掉 x*）或 至少 1 次（消耗一个 s 字符后继续保留 x*）。

完整推导

思路推导

  1. 直觉与痛点（'.' 好办，'*' 要命）

. 是"任意单字符"，遇到就直接等价于匹配。真正麻烦的是 *：它作用在前一个字符上，能让那个字符出现 0 次或任意多次。比如 a* 既能匹配空串，也能匹配 a、aa、aaa……到底该匹配几次？暴力回溯会在每个 * 处分叉，指数级爆炸。

  1. 破局思路（二维 DP，把"匹配了几次"交给状态表示）

设 dp[i][j] 表示 s 的前 i 个字符能否被 p 的前 j 个字符匹配。看 p 的最后一个字符 p[j-1]：

  • 是普通字符或 .：只需看它能否和 s 的最后一个字符 s[i-1] 对上（p[j-1]=='.' 或相等）。对得上则 dp[i][j] = dp[i-1][j-1]，否则 false。
  • 是 '*'：看它的基础字符 prev = p[j-2]，有两种选择，取"或"：
    • 匹配 0 次：直接丢掉 x* 这两个字符 → dp[i][j] = dp[i][j-2]；
    • 至少匹配 1 次：若 prev 能匹配 s[i-1]（prev=='.' 或相等），消耗掉 s 的这个字符，而 x* 仍保留继续用 → dp[i][j] |= dp[i-1][j]。

这两条正是"* 匹配 0 次 / 多次"的形式化，状态把所有可能次数都枚举进去了。

  1. 关键追问（空串与初始化）
  • 边界：dp[0][0] = true（空串匹配空模式）。
  • 空串 vs 模式：dp[0][j] 只有在 p 形如 a*b*c* 时才可能为真——即 p[j-1]=='*' 且 dp[0][j-2] 为真。
  • * 一定跟在前导字符后面（题面保证），所以 p[j-2] 永远合法，不会越界。

Java 实现（isMatch）

class Solution {
    public boolean isMatch(String s, String p) {
        int m = s.length(), n = p.length();
        // dp[i][j]：s 的前 i 个字符能否与 p 的前 j 个字符完全匹配
        boolean[][] dp = new boolean[m + 1][n + 1];
        dp[0][0] = true;

        // 空串匹配形如 a*b*c* 的模式
        for (int j = 2; j <= n; j++) {
            if (p.charAt(j - 1) == '*') {
                dp[0][j] = dp[0][j - 2];
            }
        }

        for (int i = 1; i <= m; i++) {
            for (int j = 1; j <= n; j++) {
                char pc = p.charAt(j - 1);
                if (pc == '*') {
                    char prev = p.charAt(j - 2); // '*' 前面的基础字符
                    // 情况一：'x*' 匹配 0 次，丢掉这两个字符
                    dp[i][j] = dp[i][j - 2];
                    // 情况二：'x*' 至少匹配一次，消耗一个 s 字符
                    if (prev == '.' || prev == s.charAt(i - 1)) {
                        dp[i][j] = dp[i][j] || dp[i - 1][j];
                    }
                } else {
                    // 普通字符或 '.'，需与 s 的当前末位字符匹配
                    if (pc == '.' || pc == s.charAt(i - 1)) {
                        dp[i][j] = dp[i - 1][j - 1];
                    }
                }
            }
        }
        return dp[m][n];
    }
}

复杂度

  • 时间：O(mn)，状态总数为 (m+1)(n+1)，每个状态常数时间转移。
  • 空间：O(mn)，存放二维 dp 表；可滚动数组优化到 O(n)（只依赖上一行与当前行）。

易错点与扩展（面试高频考点）

  1. 漏掉"匹配 0 次"分支：dp[i][j] = dp[i][j-2] 是最容易被忘的一条，缺了它 a* 就匹配不了空串。
  2. 初始化 dp[0][j]：空串对应"多个 x*"的模式必须置真，否则 s=""、p="a*b*" 会错判。
  3. "多次匹配"用 dp[i-1][j] 而不是 dp[i-1][j-1]：保留 * 意味着这一对被反复使用，下标是同一列 j。
  4. prev 可以是 .：.* 能匹配任意长字符串，靠 prev == '.' 分支天然覆盖。
  5. 暴力回溯会 TLE：不记忆化时每个 * 都分叉，复杂度指数级；面试先说清为什么会爆炸，再给出 DP。
  6. 空间优化：由于 dp[i][j] 只依赖 dp[i-1][*] 与当前行左侧，可用一维滚动数组把空间降到 O(n)。

10. 正则表达式匹配

C++ 实现

#include <string>
#include <vector>
using namespace std;

class Solution {
public:
    bool isMatch(string s, string p) {
        int m = s.size(), n = p.size();
        vector<vector<bool>> dp(m + 1, vector<bool>(n + 1, false));
        dp[0][0] = true;

        // 空串匹配形如 a*b*c* 的模式
        for (int j = 2; j <= n; j++) {
            if (p[j - 1] == '*') dp[0][j] = dp[0][j - 2];
        }

        for (int i = 1; i <= m; i++) {
            for (int j = 1; j <= n; j++) {
                if (p[j - 1] == '*') {
                    char prev = p[j - 2];
                    // 匹配 0 次
                    dp[i][j] = dp[i][j - 2];
                    // 至少匹配 1 次
                    if (prev == '.' || prev == s[i - 1])
                        dp[i][j] = dp[i][j] || dp[i - 1][j];
                } else {
                    if (p[j - 1] == '.' || p[j - 1] == s[i - 1])
                        dp[i][j] = dp[i - 1][j - 1];
                }
            }
        }
        return dp[m][n];
    }
};

Python 实现

class Solution:
    def isMatch(self, s: str, p: str) -> bool:
        m, n = len(s), len(p)
        # dp[i][j]：s 的前 i 个字符能否与 p 的前 j 个字符完全匹配
        dp = [[False] * (n + 1) for _ in range(m + 1)]
        dp[0][0] = True

        # 空串匹配形如 a*b*c* 的模式
        for j in range(2, n + 1):
            if p[j - 1] == '*':
                dp[0][j] = dp[0][j - 2]

        for i in range(1, m + 1):
            for j in range(1, n + 1):
                if p[j - 1] == '*':
                    prev = p[j - 2]
                    # 匹配 0 次：丢掉 'x*'
                    dp[i][j] = dp[i][j - 2]
                    # 至少匹配 1 次
                    if prev == '.' or prev == s[i - 1]:
                        dp[i][j] = dp[i][j] or dp[i - 1][j]
                else:
                    if p[j - 1] == '.' or p[j - 1] == s[i - 1]:
                        dp[i][j] = dp[i - 1][j - 1]

        return dp[m][n]
