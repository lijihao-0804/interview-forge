# 60. 排列序列

| 题目信息 | 内容 |
|---|---|
| 难度 | 困难 |
| 核心模式 | 阶乘进制（康托展开）逐位定位，跳过整块排列 |
| 时间复杂度 | O(n²) |
| 空间复杂度 | O(n) |

## 题目与约束

给出集合 `[1,2,3,...,n]`，其所有元素共有 `n!` 种排列。

按大小顺序列出所有排列情况，并一一标记，当 `n = 3` 时, 所有排列如下：

- `"123"`

- `"132"`

- `"213"`

- `"231"`

- `"312"`

- `"321"`

给定 `n` 和 `k`，返回第 `k` 个排列。

 

示例 1：

输入：n = 3, k = 3  
输出："213"

示例 2：

输入：n = 4, k = 9  
输出："2314"

示例 3：

输入：n = 3, k = 1  
输出："123"

 

提示：

- `1 <= n <= 9`

- `1 <= k <= n!`

[🔗 前往力扣原题验证 →](https://leetcode.cn/problems/permutation-sequence/)

## 核心不变量

> 对剩余 `n` 个数字，第一个数字每确定一种，就固定 `(n-1)!` 个排列；用 `(k-1) / (n-1)!` 直接定位首位，再用 `(k-1) % (n-1)!` 递归到剩余数字，无需枚举任何排列。

## 完整推导

### 思路推导

1. **直觉与痛点（`n=9` 时 `9! = 362880`，枚举太浪费）**

   直接按字典序生成所有排列再取第 `k` 个，最多要生成 36 万个排列，虽然能过但很笨。实际上我们只想"直接算出第 `k` 个"，一步到位。

2. **破局思路（按首位分块，用除法跳块）**

   剩余数字按从小到大排列，第一个位置每放一个数，后面就有 `(i-1)!` 种排法，相当于一整块。把 `k` 转成从 0 开始的下标 `k-1`，则：

   - `idx = (k-1) / (i-1)!`：首位应取剩余候选里的第 `idx` 个（0 基）；
   - `k = (k-1) % (i-1)! + 1`：进入这一块内部，继续定位下一位。

   小例子 `n = 4, k = 9`：

   - 首位块大小 `3! = 6`，`(9-1)/6 = 1`，取剩余 `[1,2,3,4]` 下标 1 的数 `2`，`k` 变为 `(8 % 6) + 1 = 3`；
   - 次位块大小 `2! = 2`，剩余 `[1,3,4]`，`(3-1)/2 = 1`，取下标 1 的 `3`，`k = (2 % 2) + 1 = 1`；
   - 第三位块大小 `1! = 1`，剩余 `[1,4]`，`(1-1)/1 = 0`，取 `1`，`k` 仍为 1；
   - 最后剩 `4`。拼起来 `"2314"`，与示例一致。

3. **关键追问（`k` 是 1 基还是 0 基？）**

   题目 `k` 从 1 开始。先把 `k--` 变成 0 基，后面统一用 `idx = k / block`、`k %= block`，逻辑最干净，也不会出现"要取第 0 个还是第 1 个"的纠结。

4. **收尾**：每轮从候选列表中删除已选数字（或用有序集合），依次拼接即为答案。

### Java 实现（getPermutation）

```java
import java.util.ArrayList;
import java.util.List;

class Solution {
    public String getPermutation(int n, int k) {
        // 1. 预计算 0! .. n!
        int[] fact = new int[n + 1];
        fact[0] = 1;
        for (int i = 1; i <= n; i++) {
            fact[i] = fact[i - 1] * i;
        }

        // 2. 候选数字列表 [1, 2, ..., n]
        List<Integer> nums = new ArrayList<>();
        for (int i = 1; i <= n; i++) {
            nums.add(i);
        }

        StringBuilder sb = new StringBuilder();
        k--; // 转为 0 基下标

        // 3. 逐位定位：剩余位数从 n 递减到 1
        for (int i = n; i >= 1; i--) {
            int block = fact[i - 1];       // 当前位每取一个候选，覆盖 block 个排列
            int idx = k / block;           // 当前位应取第 idx 个候选（0 基）
            sb.append(nums.remove(idx));   // 取出并删除该候选
            k %= block;                    // 进入该块内部继续定位
        }

        return sb.toString();
    }
}
```

### 复杂度

- 时间：O(n²)。外层 `n` 轮；每轮 `List.remove(idx)` 需要移动后续元素，最坏 O(n)，合计 O(n²)。若用 `n <= 9` 规模，实际极快；用树状数组可优化到 O(n log n)，但没必要。
- 空间：O(n)。阶乘数组 `fact`、候选列表 `nums` 与结果 `StringBuilder` 都是线性规模。

### 易错点与扩展（面试高频考点）

1. **`k` 的 0 基转换**：忘记 `k--` 会导致"整体偏一位"，`k = 1` 时取错。建议一开始就 `k--`，后面全用 0 基。
2. **块大小用 `fact[i-1]` 而不是 `fact[i]`**：当前还剩 `i` 个数字时，固定首位后剩 `i-1` 位，块大小是 `(i-1)!`。
3. **删除顺序要一致**：`nums` 必须保持升序，`idx` 才对应字典序中的正确候选；取出后立刻删除，避免下一位选到重复数字。
4. **溢出问题**：`n ≤ 9`，`9! = 362880`，`int` 足够；若题目放宽到更大 `n`，阶乘和 `k` 需改用 `long`。
5. **扩展——下一个排列（LeetCode 31）/ 第 k 个排列的逆问题（康托展开排名）**：本题是"排名 → 排列"的康托展开，反过来"排列 → 排名"同样用阶乘进制，是同一套数学工具的对偶应用。

## 力扣原题

[60. 排列序列](https://leetcode.cn/problems/permutation-sequence/)

### C++ 实现

```cpp
#include <string>
#include <vector>
using namespace std;

class Solution {
public:
    string getPermutation(int n, int k) {
        // 预计算阶乘
        vector<int> fact(n + 1, 1);
        for (int i = 1; i <= n; i++) {
            fact[i] = fact[i - 1] * i;
        }

        // 候选数字
        vector<int> nums;
        for (int i = 1; i <= n; i++) {
            nums.push_back(i);
        }

        string res;
        k--; // 转为 0 基
        for (int i = n; i >= 1; i--) {
            int block = fact[i - 1];
            int idx = k / block;
            res.push_back(char('0' + nums[idx]));
            nums.erase(nums.begin() + idx);
            k %= block;
        }
        return res;
    }
};
```

### Python 实现

```python
class Solution:
    def getPermutation(self, n: int, k: int) -> str:
        # 预计算阶乘
        fact = [1] * (n + 1)
        for i in range(1, n + 1):
            fact[i] = fact[i - 1] * i

        nums = list(range(1, n + 1))
        res = []
        k -= 1  # 转为 0 基

        for i in range(n, 0, -1):
            block = fact[i - 1]      # 当前位的分块大小
            idx = k // block         # 当前位取第 idx 个候选
            res.append(str(nums.pop(idx)))
            k %= block

        return "".join(res)
```
