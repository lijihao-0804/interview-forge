509. 斐波那契数

题目与约束

斐波那契数 （通常用 F(n) 表示）形成的序列称为 斐波那契数列 。该数列由 0 和 1 开始，后面的每一项数字都是前面两项数字的和。也就是：

F(0) = 0，F(1) = 1
F(n) = F(n - 1) + F(n - 2)，其中 n > 1

给定 n ，请计算 F(n) 。

示例 1：

输入：n = 2
输出：1
解释：F(2) = F(1) + F(0) = 1 + 0 = 1

示例 2：

输入：n = 3
输出：2
解释：F(3) = F(2) + F(1) = 1 + 1 = 2

示例 3：

输入：n = 4
输出：3
解释：F(4) = F(3) + F(2) = 2 + 1 = 3

提示：

  • 0 <= n <= 30

核心不变量

计算 F(i) 时只需要前两项 F(i-1) 与 F(i-2)，更早的值用完即可丢弃，用两个滚动变量即可完成状态转移。

思路推导

  1. 朴素递归的痛点

直接按定义递归 fib(n) = fib(n-1) + fib(n-2)，会重复计算大量相同子问题，时间复杂度逼近 O(2^n)（fib(5) 里 fib(3) 就被算了两次），n 稍大就难以接受。

  1. 动态规划：从底向上递推

把 F(0), F(1), F(2), ... 依次算出存进数组，dp[i] = dp[i-1] + dp[i-2]，时间降为 O(n)，空间 O(n)。

  1. 空间再优化：滚动变量

注意到 dp[i] 只依赖前两项，用一个数组纯属浪费。于是用 prev = F(i-2)、cur = F(i-1) 两个变量，每步计算 next = prev + cur，再整体前移：prev = cur; cur = next。空间降到 O(1)。

  1. 小例子（n = 4）

初始 prev=0, cur=1： i=2 → next=1，prev=1, cur=1； i=3 → next=2，prev=1, cur=2； i=4 → next=3，prev=2, cur=3。返回 cur = 3，与示例一致。

Java 实现（fib）

class Solution {
    public int fib(int n) {
        // F(0)=0, F(1)=1，n<2 直接返回
        if (n < 2) {
            return n;
        }
        int prev = 0; // F(i-2)
        int cur = 1;  // F(i-1)
        for (int i = 2; i <= n; i++) {
            int next = prev + cur; // F(i)
            prev = cur;
            cur = next;
        }
        return cur;
    }
}

C++ 实现

class Solution {
public:
    int fib(int n) {
        if (n < 2) return n;
        int prev = 0; // F(i-2)
        int cur = 1;  // F(i-1)
        for (int i = 2; i <= n; i++) {
            int next = prev + cur;
            prev = cur;
            cur = next;
        }
        return cur;
    }
};

Python 实现

class Solution:
    def fib(self, n: int) -> int:
        if n < 2:
            return n
        prev, cur = 0, 1  # F(i-2), F(i-1)
        for _ in range(2, n + 1):
            prev, cur = cur, prev + cur
        return cur

复杂度

  • 时间：O(n)，从 2 递推到 n，共 n-1 次常数运算。
  • 空间：O(1)，只用了 prev、cur、next 三个变量。
易错点与扩展（面试高频考点）
  1. 忘记 n < 2 的边界：n = 0 或 n = 1 时若直接进入循环，可能返回错误的初值；先判边界最稳。
  2. 滚动变量更新顺序：必须先保存 next，再 prev = cur; cur = next；若先改 prev 再算，会丢掉旧值。
  3. 用递归却忘了记忆化：面试若要求“递归写法”，务必加备忘录（memo）或用 @lru_cache，否则退化为指数级。
  4. 溢出问题：本题 n <= 30，F(30)=832040 在 int 范围内；但若 n 更大需改用 long 或取模。
  5. 扩展：进一步可用「矩阵快速幂」把复杂度降到 O(log n)，或用通项公式（比内公式）直接计算，作为进阶加分项。
