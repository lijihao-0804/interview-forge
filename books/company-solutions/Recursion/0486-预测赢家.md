# 486. 预测赢家

| 题目信息 | 内容 |
|---|---|
| 难度 | 中等 |
| 核心模式 | 区间博弈 DP：`dp[i][j] = max(取左 - 对手最优, 取右 - 对手最优)` |
| 时间复杂度 | O(n²) |
| 空间复杂度 | O(n²) |

## 题目与约束

给你一个整数数组 `nums`。玩家 1 和玩家 2 基于这个数组设计了一个游戏。

玩家 1 和玩家 2 轮流进行自己的回合，玩家 1 先手。开始时，两个玩家的初始分值都是 `0`。

每一回合，玩家从数组的**任意一端**取一个数字（即 `nums[0]` 或 `nums[nums.length - 1]`），取到的数字将会从数组中**移除**（数组长度减 `1`）。玩家选中的数字将会加到他的得分上。当数组中没有剩余数字可取时，游戏结束。

如果玩家 1 能成为赢家，返回 `true`。

**注意**，如果两个玩家得分相等，同样认为玩家 1 是游戏的赢家。你可以假设每个玩家的玩法都会使他的分数最大化。

**示例 1：**

**输入：**nums = [1,5,2]

**输出：**false

**解释：**

- 玩家 1 必须先取 1 或 2，两种选择都会导致相同的结果。
- 如果玩家 1 取 1，数组变为 `[5, 2]`。玩家 2 取 5，剩下 2 给玩家 1。
- 如果玩家 1 取 2，数组变为 `[1, 5]`。玩家 2 取 5，剩下 1 给玩家 1。
- 无论哪种情况，玩家 1 最终得到 `1 + 2 = 3`，玩家 2 得到 `5`。玩家 1 永远无法获胜，所以返回 `false`。

**示例 2：**

**输入：**nums = [1,5,233,7]

**输出：**true

**解释：**

- 玩家 1 先取 1，剩下 `[5,233,7]`。然后玩家 2 必须在 5 和 7 之间选择，无论玩家 2 选择哪个数字，玩家 1 在下一次回合都可以取 233。
- 玩家 1 的得分（234）高于玩家 2（12），所以返回 `true`。

**提示：**

- `1 <= nums.length <= 20`
- `0 <= nums[i] <= 10^7`

## 核心不变量

> 记 `dp[i][j]` 为「当前轮到行动的玩家」在子数组 `nums[i..j]` 上能获得的**净胜分**（自己得分减对手得分）的最大值，则 `dp[i][j] = max(nums[i] - dp[i+1][j], nums[j] - dp[i][j-1])`。

## 完整推导

### 思路推导

1. **直觉与痛点（直接模拟双方得分？）**

   游戏是零和的：每一分都被某一方拿走，双方得分之和恒为 `sum(nums)`。因此不必分别追踪两人总分，只追踪「当前行动者最终能净胜多少分」即可。净胜分 `>= 0` 就说明先手不输（先手平局也算赢）。

2. **破局思路（区间 DP，把对手的选择“折叠”进来）**

   在区间 `[i, j]` 上，当前玩家有两个选择：

   - 取左端 `nums[i]`：此后对手面对 `[i+1, j]`，对手在该区间能获得的净胜分是 `dp[i+1][j]`（站在对手视角）。那么当前玩家的净胜分就是 `nums[i] - dp[i+1][j]`。
   - 取右端 `nums[j]`：同理得到 `nums[j] - dp[i][j-1]`。

   当前玩家会使自己净胜分最大，于是
   `dp[i][j] = max(nums[i] - dp[i+1][j], nums[j] - dp[i][j-1])`。
   单元素区间 `dp[i][i] = nums[i]`。

   以 `[1,5,233,7]` 为例：`dp[0][3]` 最终算得先手净胜 `234-12=222 >= 0`，返回 `true`。

3. **关键追问（递推顺序与判定条件）**

   因为 `dp[i][j]` 依赖更短的区间 `[i+1][j]`、`[i][j-1]`，所以按**区间长度从小到大**枚举即可。最后判断 `dp[0][n-1] >= 0`：等于 `0`（平局）也算先手赢，因此是 `>=` 而非 `>`。

### Java 实现（区间 DP）

```java
class Solution {
    public boolean predictTheWinner(int[] nums) {
        int n = nums.length;
        // dp[i][j]：当前行动者在 nums[i..j] 上能取得的净胜分（自己 - 对手）
        int[][] dp = new int[n][n];

        // 长度为 1 的区间：当前玩家直接拿走该数
        for (int i = 0; i < n; i++) {
            dp[i][i] = nums[i];
        }

        // 按区间长度从小到大递推
        for (int len = 2; len <= n; len++) {
            for (int i = 0; i + len - 1 < n; i++) {
                int j = i + len - 1;
                int takeLeft = nums[i] - dp[i + 1][j];  // 取左端后，减去对手在剩余区间的净胜分
                int takeRight = nums[j] - dp[i][j - 1]; // 取右端后，减去对手在剩余区间的净胜分
                dp[i][j] = Math.max(takeLeft, takeRight);
            }
        }

        // 净胜分 >= 0 表示先手不输（平局也算赢）
        return dp[0][n - 1] >= 0;
    }
}
```

### 复杂度

- 时间：`O(n²)`。共 `O(n²)` 个区间状态，每个状态常数时间转移。
- 空间：`O(n²)`。二维 `dp` 表；可优化为滚动一维（`dp[i]` 依赖左侧与下方），空间降到 `O(n)`。

### 易错点与扩展（面试高频考点）

1. **平局判定用 `>=`**：题目明确「得分相等也算玩家 1 赢」，所以最终条件必须是 `dp[0][n-1] >= 0`，写成 `> 0` 会漏掉平局。
2. **递推方向写反**：`dp[i][j]` 依赖更短的区间，必须按 `len` 由小到大；若按 `i`、`j` 双重循环正序枚举，依赖项还没算出来。
3. **净胜分定义要前后一致**：`dp` 存的是「当前行动者视角」的净胜分，取完一端后剩余区间的 `dp` 是「对手视角」，所以要相减而不是相加。混用视角是本题最常见错误。
4. **递归 + 记忆化等价写法**：也可写 `solve(i, j)`，返回当前行动者净胜分，加 `memo[i][j]` 缓存，复杂度同为 `O(n²)`；`n <= 20` 时纯递归 `O(2^n)` 也能过，但面试建议上 DP。
5. **扩展——偶数长度是否先手必胜？**：可以证明当 `n` 为偶数时先手必胜（总能只取奇数位或偶数位中较大的一组），所以本题只在 `n` 为奇数时有悬念；这个性质常作为面试延伸考点。

## 力扣原题

[486. 预测赢家](https://leetcode.cn/problems/predict-the-winner/)

### C++ 实现

```cpp
#include <vector>
#include <algorithm>
using namespace std;

class Solution {
public:
    bool predictTheWinner(vector<int>& nums) {
        int n = nums.size();
        // dp[i][j]：当前行动者在 nums[i..j] 上的净胜分（自己 - 对手）
        vector<vector<int>> dp(n, vector<int>(n, 0));
        for (int i = 0; i < n; i++) dp[i][i] = nums[i];

        for (int len = 2; len <= n; len++) {
            for (int i = 0; i + len - 1 < n; i++) {
                int j = i + len - 1;
                int takeLeft = nums[i] - dp[i + 1][j];
                int takeRight = nums[j] - dp[i][j - 1];
                dp[i][j] = max(takeLeft, takeRight);
            }
        }
        return dp[0][n - 1] >= 0;
    }
};
```

### Python 实现

```python
class Solution:
    def predictTheWinner(self, nums: list[int]) -> bool:
        n = len(nums)
        # dp[i][j]：当前行动者在 nums[i..j] 上的净胜分（自己 - 对手）
        dp = [[0] * n for _ in range(n)]
        for i in range(n):
            dp[i][i] = nums[i]

        for length in range(2, n + 1):
            for i in range(0, n - length + 1):
                j = i + length - 1
                take_left = nums[i] - dp[i + 1][j]
                take_right = nums[j] - dp[i][j - 1]
                dp[i][j] = max(take_left, take_right)

        return dp[0][n - 1] >= 0
```
