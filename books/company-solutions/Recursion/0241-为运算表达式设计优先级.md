# 241. 为运算表达式设计优先级

| 题目信息 | 内容 |
|---|---|
| 难度 | 中等 |
| 核心模式 | 分治 + 记忆化（枚举每个运算符作为"最后一步"） |
| 时间复杂度 | O(n · C_n)，C_n 为卡特兰数 |
| 空间复杂度 | O(n · C_n) |

## 题目与约束

给你一个由数字和运算符组成的字符串 `expression`，按不同优先级组合数字和运算符，计算并返回所有可能组合的结果。你可以**按任意顺序**返回答案。

生成的测试用例满足其对应输出值符合 32 位整数范围，不同结果的数量不超过 `10^4`。

**示例 1：**

```
输入：expression = "2-1-1"
输出：[0,2]
解释：
((2-1)-1) = 0 
(2-(1-1)) = 2
```

**示例 2：**

```
输入：expression = "2*3-4*5"
输出：[-34,-14,-10,-10,10]
解释：
(2*(3-(4*5))) = -34 
((2*3)-(4*5)) = -14 
((2*(3-4))*5) = -10 
(2*((3-4)*5)) = -10 
(((2*3)-4)*5) = 10
```

**提示：**

- `1 <= expression.length <= 20`
- `expression` 由数字和算符 `'+'`、`'-'` 和 `'*'` 组成。
- 输入表达式中的所有整数值在范围 `[0, 99]`
- 输入表达式中的所有整数都没有前导 `'-'` 或 `'+'` 表示符号。

## 核心不变量

> 任一子表达式的全部括号化结果，等于对它每个运算符切分后"左半所有结果 × 右半所有结果"做笛卡尔积再运算。

## 完整推导

### 思路推导

1. **关键观察（最后一步是谁？）**：任何完整加括号的方案，最终一定由某一次运算合并左右两段。于是枚举每一个运算符作为"最后一次运算"，就把原问题拆成左右两个规模更小的同类问题。

2. **分治**：设运算符在第 `i` 位，递归求出左子串的所有结果 `left` 和右子串的所有结果 `right`，再用该运算符把 `left` 与 `right` 两两组合，得到这一刀能产生的全部结果。

3. **记忆化**：不同切分会重复计算相同子串（例如 `"2*3-4*5"` 里 `"3-4"` 会被反复用到），用哈希表按子串缓存结果，避免指数级重复。

4. **终止条件**：若子串中没有任何运算符，说明它就是一个整数，直接返回 `[int(expr)]`。

以 `expression = "2-1-1"` 为例：以第一个 `-` 切分，左 `[2]`、右 `[0]`，得 `2-0=2`；以第二个 `-` 切分，左 `[1]`、右 `[1]`，得 `1-1=0`；答案为 `[2,0]`。

### Java 实现（diffWaysToCompute）

```java
import java.util.ArrayList;
import java.util.HashMap;
import java.util.List;
import java.util.Map;

class Solution {
    // 记忆化：缓存每个子表达式的全部计算结果
    private final Map<String, List<Integer>> memo = new HashMap<>();

    public List<Integer> diffWaysToCompute(String expression) {
        if (memo.containsKey(expression)) {
            return memo.get(expression);
        }

        List<Integer> res = new ArrayList<>();
        boolean isNumber = true;

        for (int i = 0; i < expression.length(); i++) {
            char c = expression.charAt(i);
            if (c == '+' || c == '-' || c == '*') {
                isNumber = false;
                // 以当前运算符为“最后一次运算”，递归左右子表达式
                List<Integer> left = diffWaysToCompute(expression.substring(0, i));
                List<Integer> right = diffWaysToCompute(expression.substring(i + 1));
                // 左右结果做笛卡尔积
                for (int a : left) {
                    for (int b : right) {
                        if (c == '+') {
                            res.add(a + b);
                        } else if (c == '-') {
                            res.add(a - b);
                        } else {
                            res.add(a * b);
                        }
                    }
                }
            }
        }

        // 整个表达式是纯数字，直接解析返回
        if (isNumber) {
            res.add(Integer.parseInt(expression));
        }

        memo.put(expression, res);
        return res;
    }
}
```

### 复杂度

- 时间：O(n · C_n)，其中 n 为运算符个数、C_n 为第 n 个卡特兰数（即不同括号化方案数）。记忆化后每个不同子串只计算一次，总运算量正比于"切分组合数"与"结果数量"的乘积。
- 空间：O(n · C_n)，记忆化缓存了所有子表达式的全部结果；递归深度为 O(n)。

### 易错点与扩展（面试高频考点）

1. **只按第一个运算符切分会漏解**：必须枚举所有运算符位置作为"最后一次运算"，否则拿不到全部括号化方案。
2. **纯数字判断要整体解析**：像 `12`、`99` 这样的多位数必须整体 `parseInt`，不能逐位拆开；因此循环里一旦发现运算符就要标记"不是纯数字"。
3. **结果可重复，不能去重**：示例输出的两个 `-10` 都要保留，用 `List` 而不是 `Set`，也不要在 `memo` 里做去重。
4. **记忆化的键要一致**：用子串本身作 key 最直观；若改用下标区间，务必保证左右边界含义统一，否则会错误复用。
5. **复杂度辨析**：面试常追问"为什么不是简单 O(2^n)"——实际复杂度与卡特兰数相关；也可进一步改成按区间长度自底向上的 DP（`dp[i][j]` 存第 i~j 项所有结果）来消除递归开销。

## 力扣原题

[241. 为运算表达式设计优先级](https://leetcode.cn/problems/different-ways-to-add-parentheses/)

### C++ 实现

```cpp
#include <string>
#include <unordered_map>
#include <vector>
using namespace std;

class Solution {
    unordered_map<string, vector<int>> memo;
public:
    vector<int> diffWaysToCompute(string expression) {
        if (memo.count(expression)) return memo[expression];

        vector<int> res;
        bool isNumber = true;
        for (int i = 0; i < (int)expression.size(); ++i) {
            char c = expression[i];
            if (c == '+' || c == '-' || c == '*') {
                isNumber = false;
                vector<int> left = diffWaysToCompute(expression.substr(0, i));
                vector<int> right = diffWaysToCompute(expression.substr(i + 1));
                for (int a : left) {
                    for (int b : right) {
                        if (c == '+') res.push_back(a + b);
                        else if (c == '-') res.push_back(a - b);
                        else res.push_back(a * b);
                    }
                }
            }
        }
        if (isNumber) res.push_back(stoi(expression));
        memo[expression] = res;
        return res;
    }
};
```

### Python 实现

```python
from functools import lru_cache
from typing import List


class Solution:
    def diffWaysToCompute(self, expression: str) -> List[int]:
        @lru_cache(maxsize=None)
        def dfs(expr: str):
            res = []
            is_number = True
            for i, ch in enumerate(expr):
                if ch in "+-*":
                    is_number = False
                    left = dfs(expr[:i])
                    right = dfs(expr[i + 1:])
                    for a in left:
                        for b in right:
                            if ch == '+':
                                res.append(a + b)
                            elif ch == '-':
                                res.append(a - b)
                            else:
                                res.append(a * b)
            if is_number:
                res.append(int(expr))
            return res

        return dfs(expression)
```
