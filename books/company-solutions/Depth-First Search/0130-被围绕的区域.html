题目信息 内容
难度 中等
核心模式 逆向思维：从边界 'O' 出发 DFS 标记「安全区」
时间复杂度 O(m·n)
空间复杂度 O(m·n)

题目与约束

给你一个 m x n 的矩阵 board，由若干字符 'X' 和 'O' 组成，捕获所有被围绕的区域：

  • 连接：一个单元格与水平或垂直方向上相邻的单元格连接。
  • 区域：连接所有 'O' 的单元格来形成一个区域。
  • 围绕：如果一个区域中的所有 'O' 单元格都不在棋盘的边缘，则该区域被包围。这样的区域完全被 'X' 单元格包围。

通过原地将输入矩阵中的所有 'O' 替换为 'X' 来捕获被围绕的区域。你不需要返回任何值。

示例 1：

输入：board = [['X','X','X','X'],['X','O','O','X'],['X','X','O','X'],['X','O','X','X']]
输出：[['X','X','X','X'],['X','X','X','X'],['X','X','X','X'],['X','O','X','X']]
解释：底部的区域没有被捕获，因为它在 board 的边缘并且不能被围绕。

示例 2：

输入：board = [['X']]
输出：[['X']]

提示：

  • m == board.length
  • n == board[i].length
  • 1 <= m, n <= 200
  • board[i][j] 为 'X' 或 'O'

核心不变量

一个 'O' 区域不被包围，当且仅当它能通过上下左右连通到矩阵边界；从边界出发能搜到的 'O' 就是全部「安全格」。

完整推导

思路推导

  1. 正向判断很麻烦

如果逐个 'O' 去判断它所在区域是否碰到边界，需要反复搜索并记录区域，容易重复计算。换一个反向视角：哪些 'O' 一定不该被改成 'X'？ 答案是「与边界连通的 'O'」。

  1. 从边界反向注入

遍历矩阵四条边，遇到 'O' 就以它为起点做 DFS/BFS，把所有连通的 'O' 标记成临时符号 '#'。这些 '#' 就是被「保护」起来的、与边界连通的格子。

  1. 原地收尾

再完整扫一遍矩阵：剩下的 'O' 一定是被 'X' 完全包围的，改成 'X'；而 '#' 是之前的保护格，还原成 'O'。

  1. 小例子（示例 1）

边界上只有最后一行的 'O' 能连通到边界，它被标记为 '#'；中间两块 'O' 不与任何边界相连，最后被翻成 'X'，边界那块 '#' 还原为 'O'。

Java 实现（solve）

class Solution {
    private int m, n;

    public void solve(char[][] board) {
        if (board == null || board.length == 0) return;
        m = board.length;
        n = board[0].length;

        // 1. 从四条边上的 'O' 出发，标记所有与边界连通的 'O'
        for (int i = 0; i < m; i++) {
            dfs(board, i, 0);
            dfs(board, i, n - 1);
        }
        for (int j = 0; j < n; j++) {
            dfs(board, 0, j);
            dfs(board, m - 1, j);
        }

        // 2. 收尾：剩余 'O' 是被包围的 -> 'X'；'#' 是安全格 -> 还原 'O'
        for (int i = 0; i < m; i++) {
            for (int j = 0; j < n; j++) {
                if (board[i][j] == 'O') {
                    board[i][j] = 'X';
                } else if (board[i][j] == '#') {
                    board[i][j] = 'O';
                }
            }
        }
    }

    // 把从 (i, j) 出发能连通到的 'O' 全部标记为 '#'
    private void dfs(char[][] board, int i, int j) {
        if (i < 0 || i >= m || j < 0 || j >= n || board[i][j] != 'O') {
            return;
        }
        board[i][j] = '#';
        dfs(board, i + 1, j);
        dfs(board, i - 1, j);
        dfs(board, i, j + 1);
        dfs(board, i, j - 1);
    }
}

复杂度

  • 时间：O(m·n)，每个格子最多被访问常数次（标记一次、收尾扫描一次）。
  • 空间：O(m·n)，最坏情况整个棋盘都是 'O'，递归栈（或 BFS 队列）深度可达 m·n。

易错点与扩展（面试高频考点）

  1. 正向思路易错：直接对每个 'O' 做连通块搜索并判断边界，既慢又容易漏判；「从边界反向标记」是本题的核心技巧。
  2. 只有边界上的 'O' 才是起点：不要把内部 'O' 也当作起点，否则所有 'O' 都会被误判为安全。
  3. 临时标记不能直接复用 'O'/'X'：需要 '#' 之类的第三态来区分「安全」和「待处理」，最后统一还原。
  4. 深度过大导致栈溢出：m·n 可达 4×10⁴，递归 DFS 在极端输入下可能爆栈，稳妥可用 BFS 或显式栈（并查集亦可）。
  5. 原地修改：题目要求原地改 board 且不返回值，不要新建矩阵返回。

C++ 实现

class Solution {
    int m, n;
public:
    void solve(vector<vector<char>>& board) {
        if (board.empty()) return;
        m = board.size();
        n = board[0].size();

        for (int i = 0; i < m; ++i) { dfs(board, i, 0); dfs(board, i, n - 1); }
        for (int j = 0; j < n; ++j) { dfs(board, 0, j); dfs(board, m - 1, j); }

        for (int i = 0; i < m; ++i) {
            for (int j = 0; j < n; ++j) {
                if (board[i][j] == 'O') board[i][j] = 'X';
                else if (board[i][j] == '#') board[i][j] = 'O';
            }
        }
    }
private:
    void dfs(vector<vector<char>>& b, int i, int j) {
        if (i < 0 || i >= m || j < 0 || j >= n || b[i][j] != 'O') return;
        b[i][j] = '#';
        dfs(b, i + 1, j);
        dfs(b, i - 1, j);
        dfs(b, i, j + 1);
        dfs(b, i, j - 1);
    }
};

Python 实现

class Solution:
    def solve(self, board: list[list[str]]) -> None:
        """
        Do not return anything, modify board in-place instead.
        """
        if not board:
            return
        m, n = len(board), len(board[0])

        def dfs(i, j):
            if i < 0 or i >= m or j < 0 or j >= n or board[i][j] != 'O':
                return
            board[i][j] = '#'
            dfs(i + 1, j)
            dfs(i - 1, j)
            dfs(i, j + 1)
            dfs(i, j - 1)

        # 从四条边的 'O' 出发标记安全区
        for i in range(m):
            dfs(i, 0)
            dfs(i, n - 1)
        for j in range(n):
            dfs(0, j)
            dfs(m - 1, j)

        # 收尾：剩余 'O' -> 'X'，'#' -> 'O'
        for i in range(m):
            for j in range(n):
                if board[i][j] == 'O':
                    board[i][j] = 'X'
                elif board[i][j] == '#':
                    board[i][j] = 'O'
