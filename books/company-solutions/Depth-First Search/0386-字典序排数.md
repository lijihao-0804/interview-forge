# 386. 字典序排数

| 题目信息 | 内容 |
|---|---|
| 难度 | 中等 |
| 核心模式 | 把 1..n 组织成十叉字典树，做先序遍历 |
| 时间复杂度 | O(n) |
| 空间复杂度 | O(1)（不计返回结果） |

## 题目与约束

给你一个整数 `n` ，按字典序返回范围 `[1, n]` 内所有整数。

你必须设计一个时间复杂度为 `O(n)` 且使用 `O(1)` 额外空间的算法。

 

示例 1：

```
<strong>输入：</strong>n = 13
<strong>输出：</strong>[1,10,11,12,13,2,3,4,5,6,7,8,9]
```

示例 2：

```
<strong>输入：</strong>n = 2
<strong>输出：</strong>[1,2]
```

 

提示：

- `1 <= n <= 5 * 104`

[🔗 前往力扣原题验证 →](https://leetcode.cn/problems/lexicographical-numbers/)

## 核心不变量

> 把 1..n 看成十叉树上 1..9 为根、每个数 x 的孩子是 x*10..x*10+9，字典序就是这棵树的先序遍历。

## 完整推导

### 思路推导

1. **字典序等于先序遍历**

   把所有数字当成字符串，字典序先比第一位：以 `1` 开头的全部排在以 `2` 开头的前面；同样以 `1` 开头时，`1` 本身最靠前，然后是 `10,11,...,19`。这正是一棵「每个节点最多挂 0~9 十个孩子」的十叉树的先序（根 → 子树）遍历顺序。

2. **朴素做法太重**

   把 `1..n` 全部转成字符串再排序，时间是 O(n log n)，还要额外 O(n) 空间存字符串，不满足题目要求。

3. **用「当前数字」直接走树**

   维护一个 `cur`，从 1 开始，重复 `n` 次：

   - 先把 `cur` 加入答案；
   - 若能下探孩子（`cur * 10 <= n`），就走到 `cur * 10`；
   - 否则需要「向右」或「回溯」：如果 `cur` 末位是 9，或者 `cur + 1 > n`，就不断 `cur /= 10` 退回上一层，直到可以 `cur++`。

   整个过程只用一个 `cur` 变量，遍历顺序天然是先序，也不需要递归栈，额外空间 O(1)。

4. **小例子（n = 13）**

   `1 → 10 → 11 → 12 → 13`；13 无孩子且加一越界，末位非 9 先回到 1，再 `cur++` 到 2；继续 `2 → 3 → … → 9`。得到 `[1,10,11,12,13,2,...,9]`。

### Java 实现（lexicalOrder）

```java
import java.util.ArrayList;
import java.util.List;

class Solution {
    public List<Integer> lexicalOrder(int n) {
        List<Integer> res = new ArrayList<>(n);
        int cur = 1;
        for (int i = 0; i < n; i++) {
            res.add(cur);
            if (cur * 10 <= n) {
                // 能下探就先下探：cur*10 是 cur 在字典序中的第一个后继
                cur *= 10;
            } else {
                // 不能下探：向右走；若已到 9 或加一会越界，则回溯到上一层
                while (cur % 10 == 9 || cur + 1 > n) {
                    cur /= 10;
                }
                cur++;
            }
        }
        return res;
    }
}
```

### 复杂度

- 时间：O(n)，循环恰好 n 次，每次产出一个数；回溯的总代价均摊为 O(1)。
- 空间：O(1)，除返回列表外只用了常数个变量（迭代实现不需要递归栈）。

### 易错点与扩展（面试高频考点）

1. **返回列表算不算空间**：题目要求的 O(1) 额外空间不含返回结果；若用递归实现，栈深度最多是数字位数 O(log n)，要能说清楚这一点。
2. **回溯条件要写全**：`cur % 10 == 9`（没有右兄弟）和 `cur + 1 > n`（右兄弟越界）缺一不可，否则会漏数或越界。
3. **不要先转字符串排序**：那样是 O(n log n) 时间 + O(n) 空间，直接不满足题目复杂度要求。
4. **n 的边界**：`n = 1` 时直接输出 `[1]`；循环从 `cur = 1` 起步即可正确覆盖。
5. **扩展**：若要求按字典序的第 k 小数字，可在十叉树上用「子树节点数」计数来定位，是同源技巧。

### C++ 实现

```cpp
class Solution {
public:
    vector<int> lexicalOrder(int n) {
        vector<int> res;
        res.reserve(n);
        int cur = 1;
        for (int i = 0; i < n; ++i) {
            res.push_back(cur);
            if (cur * 10 <= n) {
                cur *= 10;
            } else {
                while (cur % 10 == 9 || cur + 1 > n) {
                    cur /= 10;
                }
                ++cur;
            }
        }
        return res;
    }
};
```

### Python 实现

```python
class Solution:
    def lexicalOrder(self, n: int) -> list[int]:
        res = []
        cur = 1
        for _ in range(n):
            res.append(cur)
            if cur * 10 <= n:
                cur *= 10
            else:
                while cur % 10 == 9 or cur + 1 > n:
                    cur //= 10
                cur += 1
        return res
```
