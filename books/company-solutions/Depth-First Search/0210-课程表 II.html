难度中等核心模式拓扑排序（Kahn/BFS）：按入度为 0 的顺序逐层剥离节点时间复杂度O(V+E)空间复杂度O(V+E)

题目与约束

现在你总共有 numCourses 门课需要选，记为 0 到 numCourses - 1。给你一个数组 prerequisites ，其中 prerequisites[i] = [ai, bi] ，表示在选修课程 ai 前 必须 先选修 bi 。

  • 例如，想要学习课程 0 ，你需要先完成课程 1 ，我们用一个匹配来表示：[0,1] 。

返回你为了学完所有课程所安排的学习顺序。可能会有多个正确的顺序，你只要返回 任意一种 就可以了。如果不可能完成所有课程，返回 一个空数组 。

示例 1：

输入：numCourses = 2, prerequisites = [[1,0]]
输出：[0,1]
解释：总共有 2 门课程。要学习课程 1，你需要先完成课程 0。因此，正确的课程顺序为 [0,1] 。

示例 2：

输入：numCourses = 4, prerequisites = [[1,0],[2,0],[3,1],[3,2]]
输出：[0,2,1,3]
解释：总共有 4 门课程。要学习课程 3，你应该先完成课程 1 和课程 2。并且课程 1 和课程 2 都应该排在课程 0 之后。
因此，一个正确的课程顺序是 [0,1,2,3] 。另一个正确的排序是 [0,2,1,3] 。

示例 3：

输入：numCourses = 1, prerequisites = []
输出：[0]

提示：

  • 1 <= numCourses <= 2000

  • 0 <= prerequisites.length <= numCourses * (numCourses - 1)

  • prerequisites[i].length == 2

  • 0 <= ai, bi < numCourses

  • ai != bi

  • 所有[ai, bi] 互不相同

核心不变量

队列里始终只放「当前入度为 0」的课程；每弹出一门课就把它指向的课程入度减 1，减到 0 才允许入队。若最终排出的课程数不足 numCourses，说明存在环。

完整推导

思路推导

  1. 把先修关系建模成有向图

prerequisites[i] = [a, b] 表示「先学 b、再学 a」，于是画一条有向边 b → a，含义是「b 必须在 a 前面」。题目要求的就是这张图的一个拓扑序。

  1. 用「入度」表示还差几门先修课

一门课的入度 = 还有多少门先修课没学。入度为 0 表示它现在就能直接学。示例 1 中 [1,0] 建边 0 → 1，课程 0 入度为 0、课程 1 入度为 1，所以先输出 0。

  1. Kahn 算法：每次剥掉一个「没有前置依赖」的点

先把所有入度为 0 的课放进队列；反复出队一门课加入结果，并把它所有后继的入度减 1；某个后继入度被减到 0，就说明它的先修都学完了，可以入队。示例 2 中先入队课程 0，学完 0 后课程 1、2 入度归 0 入队，最后是课程 3。

  1. 用「数量」判环

如果图中存在环（比如 0 依赖 1、1 又依赖 0），环上的课入度永远减不到 0，永远不会进队列。最终结果数组长度若小于 numCourses，就说明无法学完，返回空数组。

Java 实现（拓扑排序 Kahn 算法）

import java.util.ArrayList;
import java.util.LinkedList;
import java.util.List;
import java.util.Queue;

class Solution {
    public int[] findOrder(int numCourses, int[][] prerequisites) {
        // 1. 建图：graph.get(b) 存所有「b 学完之后才能学」的课程
        List<List<Integer>> graph = new ArrayList<>();
        for (int i = 0; i < numCourses; i++) {
            graph.add(new ArrayList<>());
        }
        int[] indegree = new int[numCourses]; // 每门课当前入度

        for (int[] p : prerequisites) {
            int a = p[0], b = p[1]; // 先学 b，再学 a
            graph.get(b).add(a);    // 边 b -> a
            indegree[a]++;          // a 多了一个先修依赖
        }

        // 2. 所有入度为 0 的课程先入队
        Queue<Integer> queue = new LinkedList<>();
        for (int i = 0; i < numCourses; i++) {
            if (indegree[i] == 0) {
                queue.offer(i);
            }
        }

        // 3. 不断剥掉入度为 0 的点
        int[] order = new int[numCourses];
        int idx = 0;
        while (!queue.isEmpty()) {
            int cur = queue.poll();
            order[idx++] = cur; // 加入学习顺序
            for (int next : graph.get(cur)) {
                // cur 学完，后继的依赖减 1
                if (--indegree[next] == 0) {
                    queue.offer(next);
                }
            }
        }

        // 4. 排出的课程数不足，说明有环，无法完成
        return idx == numCourses ? order : new int[0];
    }
}

C++ 实现

class Solution {
public:
    vector<int> findOrder(int numCourses, vector<vector<int>>& prerequisites) {
        vector<vector<int>> graph(numCourses);
        vector<int> indegree(numCourses, 0);

        for (auto& p : prerequisites) {
            int a = p[0], b = p[1];    // 先学 b，再学 a
            graph[b].push_back(a);     // 边 b -> a
            indegree[a]++;
        }

        queue<int> q;
        for (int i = 0; i < numCourses; i++) {
            if (indegree[i] == 0) q.push(i);
        }

        vector<int> order;
        while (!q.empty()) {
            int cur = q.front();
            q.pop();
            order.push_back(cur);
            for (int nxt : graph[cur]) {
                if (--indegree[nxt] == 0) q.push(nxt);
            }
        }

        if ((int)order.size() != numCourses) return {}; // 有环
        return order;
    }
};

Python 实现

from collections import deque

class Solution:
    def findOrder(self, numCourses: int, prerequisites: list[list[int]]) -> list[int]:
        graph = [[] for _ in range(numCourses)]
        indegree = [0] * numCourses

        for a, b in prerequisites:      # 先学 b，再学 a
            graph[b].append(a)          # 边 b -> a
            indegree[a] += 1

        q = deque(i for i in range(numCourses) if indegree[i] == 0)
        order = []

        while q:
            cur = q.popleft()
            order.append(cur)
            for nxt in graph[cur]:
                indegree[nxt] -= 1
                if indegree[nxt] == 0:
                    q.append(nxt)

        return order if len(order) == numCourses else []

复杂度

  • 时间：O(V+E)，V = numCourses，E = 先修关系条数。每个节点入队、出队各一次，每条边被松弛一次。
  • 空间：O(V+E)，邻接表存整张图占用 O(V+E)，入度数组与队列各 O(V)。
易错点与扩展（面试高频考点）
  1. 边方向别写反：[a, b] 是「先 b 后 a」，边是 b → a，入度要加在 a 上。写反会得到完全相反的依赖关系。
  2. 判环靠「数量」而不是中途异常：Kahn 算法不显式找环，而是比较输出课程数与 numCourses，不足即说明有环。
  3. 返回空数组而非 null：题目要求返回 int[]，无解时返回 new int[0]，避免调用方判空踩坑。
  4. 任意一种顺序都对：入队顺序会影响最终答案，只要满足所有先修约束即可，不必追求字典序。
  5. DFS 拓扑序替代方案：用三色标记（0 未访问 / 1 访问中 / 2 已完成）做 DFS，完成后把节点压入后序列表，再整体逆序即为答案；若 DFS 时遇到「访问中」的灰色节点，说明有环，直接返回空数组。
