1233. 删除子文件夹

本题学习状态正在读取学习记录…下次复习：—
本次复习：
按 M 快速切换薄弱标记
遮住推导与代码，先自己想，再逐段揭示
难度中等核心模式字典序排序 + 前缀判断（也可用 Trie 判祖先）时间复杂度O(n log n · L)，L 为路径最大长度空间复杂度O(n · L)

题目与约束

你是一位系统管理员，手里有一份文件夹列表 folder，你的任务是要删除该列表中的所有 子文件夹，并以 任意顺序 返回剩下的文件夹。

如果文件夹 folder[i] 位于另一个文件夹 folder[j] 下，那么 folder[i] 就是 folder[j] 的 子文件夹 。folder[j] 的子文件夹必须以 folder[j] 开头，后跟一个 "/"。例如，"/a/b" 是 "/a" 的一个子文件夹，但 "/b" 不是 "/a/b/c" 的一个子文件夹。

文件夹的「路径」是由一个或多个按以下格式串联形成的字符串：'/' 后跟一个或者多个小写英文字母。

  • 例如，"/leetcode" 和 "/leetcode/problems" 都是有效的路径，而空字符串和 "/" 不是。

示例 1：

输入：folder = ["/a","/a/b","/c/d","/c/d/e","/c/f"]
输出：["/a","/c/d","/c/f"]
解释："/a/b" 是 "/a" 的子文件夹，而 "/c/d/e" 是 "/c/d" 的子文件夹。

示例 2：

输入：folder = ["/a","/a/b/c","/a/b/d"]
输出：["/a"]
解释：文件夹 "/a/b/c" 和 "/a/b/d" 都会被删除，因为它们都是 "/a" 的子文件夹。

示例 3：

输入: folder = ["/a/b/c","/a/b/ca","/a/b/d"]
输出: ["/a/b/c","/a/b/ca","/a/b/d"]

提示：

  • 1 <= folder.length <= 4 * 104

  • 2 <= folder[i].length <= 100

  • folder[i] 只包含小写字母和 '/'

  • folder[i] 总是以字符 '/' 起始

  • folder 每个元素都是 唯一 的

核心不变量

将路径按字典序排序后，「某个目录是子文件夹」当且仅当它以「最近一个被保留下来的目录」加 "/" 为前缀。

完整推导

思路推导

  1. 把「父子关系」翻译成「前缀关系」

路径 p 是 q 的子文件夹，当且仅当 p 以 q + "/" 开头。注意一定要带上那个 /："/a" 不能判成 "/ab" 的父目录，因为 "/ab" 并不以 "/a/" 开头。

  1. 排序如何帮我们「只看前一个」

把所有路径按字典序排序。由于字符 '/'（ASCII 47）比任何小写字母都小，所有以 "/a/" 开头的路径都会紧跟在 "/a" 之后，并且排在像 "/a0"、"/b" 这类在 /a 处就「分叉」的路径之前。于是同一个父目录下的所有后代在排序后会连成一段，我们只需维护「最近保留的目录」res.last，判断当前路径是否以 res.last + "/" 开头即可，无需和所有保留目录逐一比较。

  1. 一次遍历完成筛选

从前往后扫描：若结果列表非空且当前路径以「最后一个被保留的目录 + /」开头，说明它是子文件夹，跳过；否则它就是一个新的顶层目录，保留下来并成为新的 res.last。

  1. 小例子

["/a","/a/b","/c/d","/c/d/e","/c/f"] 排序后仍为原序。/a 保留；/a/b 以 /a/ 开头 → 跳过（res.last 仍是 /a）；/c/d 不以 /a/ 开头 → 保留；/c/d/e 以 /c/d/ 开头 → 跳过；/c/f 以 /c/d/ 开头？否 → 保留。结果 ["/a","/c/d","/c/f"]。

Java 实现（排序 + 前缀判断）

import java.util.ArrayList;
import java.util.Arrays;
import java.util.List;

class Solution {
    public List<String> removeSubfolders(String[] folder) {
        Arrays.sort(folder);                 // 字典序排序，父目录一定在子目录之前
        List<String> res = new ArrayList<>();
        for (String f : folder) {
            // 若 f 以「最近保留目录 + "/"」开头，则是它的子文件夹
            if (!res.isEmpty() && f.startsWith(res.get(res.size() - 1) + "/")) {
                continue;
            }
            res.add(f);
        }
        return res;
    }
}

C++ 实现

#include <vector>
#include <string>
#include <algorithm>
using namespace std;

class Solution {
public:
    vector<string> removeSubfolders(vector<string>& folder) {
        sort(folder.begin(), folder.end());       // 字典序排序
        vector<string> res;
        for (const string& f : folder) {
            // rfind(prefix, 0) == 0 表示 f 以 prefix 开头
            if (!res.empty() && f.rfind(res.back() + "/", 0) == 0) {
                continue;                          // 是最近保留目录的子文件夹
            }
            res.push_back(f);
        }
        return res;
    }
};

Python 实现

from typing import List

class Solution:
    def removeSubfolders(self, folder: List[str]) -> List[str]:
        folder.sort()                              # 字典序排序
        res = []
        for f in folder:
            if res and f.startswith(res[-1] + "/"):
                continue                           # 是最近保留目录的子文件夹
            res.append(f)
        return res

复杂度

  • 时间：O(n log n · L)。排序是 O(n log n) 次字符串比较，每次最长 L，故 O(n log n · L)；随后一次线性扫描，每次前缀判断 O(L)，即 O(n·L)。
  • 空间：O(n · L)。结果列表最多存放 n 条、每条长 L 的路径；排序的额外空间取决于实现（通常 O(log n) 或 O(n)）。
易错点与扩展（面试高频考点）
  1. 前缀少写 /：只判断 f.startsWith(parent) 会把 "/ab" 误判为 "/a" 的子目录。必须比较 parent + "/"。
  2. 不排序时的朴素做法：若不排序，则对每个路径需枚举它的所有前缀祖先并在集合中查是否存在，复杂度 O(n·L)（按段数）。排序法代码更短，是首选。
  3. 只和 res.last 比较是否足够：足够，且这正是排序的价值所在——排序保证同族后代连续出现，被跳过的子目录不会成为 res.last，res.last 始终是当前段的顶层目录。
  4. 返回值顺序：题目允许任意顺序，排序后天然有序，无需额外处理。
  5. Trie 扩展：把每条路径按 '/' 切段插入字典树，节点标记「是否是一个完整文件夹」。DFS 时一旦遇到被标记为完整文件夹的节点，就收集它并停止向下（其子树全是子文件夹）。当输入是流式、或想按目录层级处理时更自然。
