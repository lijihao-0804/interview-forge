# 827. 最大人工岛

| 题目信息 | 内容 |
|---|---|
| 难度 | 困难 |
| 核心模式 | 连通块染色编号 + 面积表，再枚举每个 0 合并四周不同岛屿 |
| 时间复杂度 | O(n²) |
| 空间复杂度 | O(n²) |

## 题目与约束

给你一个大小为 `n x n` 二进制矩阵 `grid` 。最多 只能将一格 `0` 变成 `1` 。

返回执行此操作后，`grid` 中最大的岛屿面积是多少？

岛屿 由一组上、下、左、右四个方向相连的 `1` 形成。

 

示例 1:

输入: grid = [[1, 0], [0, 1]]  
输出: 3  
解释: 将一格0变成1，最终连通两个小岛得到面积为 3 的岛屿。

示例 2:

输入: grid = [[1, 1], [1, 0]]  
输出: 4  
解释: 将一格0变成1，岛屿的面积扩大为 4。

示例 3:

输入: grid = [[1, 1], [1, 1]]  
输出: 4  
解释: 没有0可以让我们变成1，面积依然为 4。

 

提示：

- `n == grid.length`

- `n == grid[i].length`

- `1 <= n <= 500`

- `grid[i][j]` 为 `0` 或 `1`

[🔗 前往力扣原题验证 →](https://leetcode.cn/problems/making-a-large-island/)

## 核心不变量

> 给每个岛屿一个唯一编号，并记录其面积；把某个 0 变成 1 后的面积 = 1 + 四周（上/下/左/右）不同编号岛屿的面积之和。

## 完整推导

### 思路推导

1. **痛点与拆分**

   如果对每个 0 都重新做一次 BFS/DFS 求面积，复杂度会退化成 O(n⁴)。关键是把「岛屿本身」和「翻转哪一个 0」这两件事解耦：先一次性把所有原始岛屿的性质算清楚，再对每个 0 做常数级查询。

2. **第一步：染色求面积（DFS 打编号）**

   遍历整个矩阵，遇到一个还没编号的 `1`，就从这个格子出发做一次 DFS，把同一连通块所有格子都标上同一个编号 `id`（用 `2, 3, 4, …`，因为 `0/1` 已被占用），同时统计出这个连通块的面积 `area[id]`。这样每个格子都知道「我属于哪个岛」，每个岛都知道「我有多大」。

3. **第二步：枚举每个 0 合并**

   对每个值为 `0` 的格子，看它的上、下、左、右四个邻居分别属于哪些岛。用一个小集合装邻居编号去重（同一个岛可能同时从两个方向相邻，不能重复加面积）。把不同岛的 `area` 累加，再 `+1`（被翻转的这个格子本身），就是一个候选答案。

4. **小例子（示例 1）**

   `[[1,0],[0,1]]`：左上岛编号 2、面积 1，右下岛编号 3、面积 1。翻转 `(0,1)` 这个 0，它的左邻属于岛 2、下邻属于岛 3，去重后面积和 `1+1`，再加 1 得 3。

5. **全 1 兜底**

   如果矩阵里没有 0，上面的枚举不会产生任何候选，此时答案就是整个矩阵的面积 `n²`（原始最大岛面积）。

### Java 实现（largestIsland）

```java
class Solution {
    private int n;
    private int[][] grid;
    private int[] area;   // area[id] 记录编号为 id 的岛屿面积
    private int[] dirs = {-1, 0, 1, 0, -1}; // 四方向：上右下左

    public int largestIsland(int[][] grid) {
        this.grid = grid;
        this.n = grid.length;
        // 编号从 2 开始（0/1 已被 grid 占用），最多 n*n 个连通块
        this.area = new int[n * n + 2];
        int id = 2;

        // 第一步：给每个岛屿染色编号并统计面积
        for (int i = 0; i < n; i++) {
            for (int j = 0; j < n; j++) {
                if (grid[i][j] == 1) {
                    area[id] = dfs(i, j, id);
                    id++;
                }
            }
        }

        // 第二步：枚举每个 0，合并四周不同编号的岛屿
        int ans = 0;
        boolean hasZero = false;
        for (int i = 0; i < n; i++) {
            for (int j = 0; j < n; j++) {
                if (grid[i][j] == 0) {
                    hasZero = true;
                    int sum = 1;                 // 翻转当前格子
                    int[] seen = new int[4];
                    int cnt = 0;
                    for (int d = 0; d < 4; d++) {
                        int ni = i + dirs[d], nj = j + dirs[d + 1];
                        if (ni < 0 || ni >= n || nj < 0 || nj >= n) continue;
                        int nid = grid[ni][nj];
                        if (nid < 2) continue;   // 不是已编号的岛
                        // 同一个岛可能从多个方向相邻，需去重
                        boolean dup = false;
                        for (int k = 0; k < cnt; k++) {
                            if (seen[k] == nid) { dup = true; break; }
                        }
                        if (!dup) {
                            seen[cnt++] = nid;
                            sum += area[nid];
                        }
                    }
                    ans = Math.max(ans, sum);
                }
            }
        }

        // 没有 0 可翻转：直接返回整块面积（即原最大岛）
        if (!hasZero) return n * n;
        // 若存在 0 但周围没有岛，ans 至少为 1，这里再对 0 情形兜底
        return Math.max(ans, 1);
    }

    private int dfs(int i, int j, int id) {
        if (i < 0 || i >= n || j < 0 || j >= n || grid[i][j] != 1) return 0;
        grid[i][j] = id;          // 染色：标记属于哪个岛
        int size = 1;
        for (int d = 0; d < 4; d++) {
            size += dfs(i + dirs[d], j + dirs[d + 1], id);
        }
        return size;
    }
}
```

### 复杂度

- 时间：O(n²)。每个格子被 DFS 访问一次，第二遍枚举每个 0 只查四个邻居，均为常数操作。
- 空间：O(n²)。DFS 递归栈最坏深度为 n²（整块连成一片的蛇形岛），外加 `area` 数组 O(n²)。

### 易错点与扩展（面试高频考点）

1. **编号必须避开 0/1**：直接把岛标成 `1` 无法区分「是否访问过」，用 `2` 起的编号既染色又充当访问标记。
2. **邻居岛要去重**：一个 0 的上下或左右可能是同一个岛，重复累加会算大答案。用固定长度小数组或 `HashSet` 去重。
3. **全 1 的情况**：矩阵没有 0 时，枚举循环不会更新答案，必须单独返回 `n*n`。
4. **递归深度**：n=500 且整块连成一条蛇时递归深度可达 25 万，Java 默认栈可能溢出；工程上可改 BFS 或显式栈。
5. **扩展：并查集**。用 DSU 把相邻 1 合并并维护集合大小，再对每个 0 合并四周根节点，思路等价（对应 tag Union Find）。

```cpp
class Solution {
    int n;
    vector<vector<int>>* g;
    vector<int> area;
    int dirs[5] = {-1, 0, 1, 0, -1};

    int dfs(int i, int j, int id) {
        if (i < 0 || i >= n || j < 0 || j >= n || (*g)[i][j] != 1) return 0;
        (*g)[i][j] = id;
        int sz = 1;
        for (int d = 0; d < 4; d++)
            sz += dfs(i + dirs[d], j + dirs[d + 1], id);
        return sz;
    }

public:
    int largestIsland(vector<vector<int>>& grid) {
        n = grid.size();
        g = &grid;
        area.assign(n * n + 2, 0);
        int id = 2;

        for (int i = 0; i < n; i++)
            for (int j = 0; j < n; j++)
                if (grid[i][j] == 1) { area[id] = dfs(i, j, id); id++; }

        int ans = 0;
        bool hasZero = false;
        for (int i = 0; i < n; i++) {
            for (int j = 0; j < n; j++) {
                if (grid[i][j] != 0) continue;
                hasZero = true;
                int sum = 1;
                int seen[4], cnt = 0;
                for (int d = 0; d < 4; d++) {
                    int ni = i + dirs[d], nj = j + dirs[d + 1];
                    if (ni < 0 || ni >= n || nj < 0 || nj >= n) continue;
                    int nid = grid[ni][nj];
                    if (nid < 2) continue;
                    bool dup = false;
                    for (int k = 0; k < cnt; k++)
                        if (seen[k] == nid) { dup = true; break; }
                    if (!dup) { seen[cnt++] = nid; sum += area[nid]; }
```

### Python 实现

```python
class Solution:
    def largestIsland(self, grid: list[list[int]]) -> int:
        n = len(grid)
        area = {}

        def dfs(i, j, idx):
            if i < 0 or i >= n or j < 0 or j >= n or grid[i][j] != 1:
                return 0
            grid[i][j] = idx
            size = 1
            for dx, dy in ((1, 0), (-1, 0), (0, 1), (0, -1)):
                size += dfs(i + dx, j + dy, idx)
            return size

        idx = 2
        for i in range(n):
            for j in range(n):
                if grid[i][j] == 1:
                    area[idx] = dfs(i, j, idx)
                    idx += 1

        ans = 0
        has_zero = False
        for i in range(n):
            for j in range(n):
                if grid[i][j] != 0:
                    continue
                has_zero = True
                seen = set()
                total = 1
                for dx, dy in ((1, 0), (-1, 0), (0, 1), (0, -1)):
                    ni, nj = i + dx, j + dy
                    if 0 <= ni < n and 0 <= nj < n and grid[ni][nj] >= 2:
                        nid = grid[ni][nj]
                        if nid not in seen:
                            seen.add(nid)
                            total += area[nid]
                ans = max(ans, total)

        if not has_zero:
            return n * n
        return max(ans, 1)
```
