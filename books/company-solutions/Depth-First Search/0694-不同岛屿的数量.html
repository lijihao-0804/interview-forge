核心不变量

两座岛屿形状相同，当且仅当把每座岛屿的格子坐标平移到同一参考点后，得到的相对坐标集合完全一致。

完整推导

思路推导

  1. 识别整座岛屿：遍历每个格子，遇到 1 就以它为起点做 DFS/BFS 洪水填充，把这整块连通陆地的所有格子收集起来，同时把访问过的 1 置为 0，避免重复访问。

  2. 归一化坐标：对每座岛屿，以它的 DFS 起点 (r0, c0) 为原点，把每个格子记成相对坐标 (r - r0, c - c0)。这样即便两座岛屿在网格中的位置不同，只要形状一致，它们归一化后的相对坐标集合就相同。

  3. 用集合去重：把每座岛屿的相对坐标排序后拼接成一个字符串签名，放进 HashSet（C++ 用 set<string>，Python 用 set）。集合的大小就是不同岛屿的数量。

小例子（示例 2）：左上的三格 L 归一化后是「缺右下」的拐角，右下的三格 L 是「缺左上」的拐角，两者相对坐标集合不同，被算作两种；两个两格横条形状相同，只算一种。

Java 实现（numDistinctIslands）

import java.util.ArrayList;
import java.util.HashSet;
import java.util.List;
import java.util.Set;

class Solution {
    private int m, n;
    private int[][] grid;
    private final int[][] dirs = {{1, 0}, {-1, 0}, {0, 1}, {0, -1}};

    public int numDistinctIslands(int[][] grid) {
        this.grid = grid;
        this.m = grid.length;
        this.n = grid[0].length;
        Set<String> shapes = new HashSet<>();

        for (int i = 0; i < m; i++) {
            for (int j = 0; j < n; j++) {
                if (grid[i][j] == 1) {
                    List<int[]> cells = new ArrayList<>();
                    dfs(i, j, i, j, cells); // 以 (i, j) 为参考原点收集整座岛屿
                    // 归一化：相对坐标排序后拼成签名
                    cells.sort((a, b) -> a[0] != b[0] ? a[0] - b[0] : a[1] - b[1]);
                    StringBuilder sb = new StringBuilder();
                    for (int[] p : cells) {
                        sb.append(p[0]).append(',').append(p[1]).append(';');
                    }
                    shapes.add(sb.toString());
                }
            }
        }
        return shapes.size();
    }

    private void dfs(int i, int j, int r0, int c0, List<int[]> cells) {
        if (i < 0 || i >= m || j < 0 || j >= n || grid[i][j] != 1) {
            return;
        }
        grid[i][j] = 0; // 淹没，防止重复访问
        cells.add(new int[]{i - r0, j - c0}); // 记录相对坐标
        for (int[] d : dirs) {
            dfs(i + d[0], j + d[1], r0, c0, cells);
        }
    }
}

复杂度

  • 时间：O(m·n log(m·n))。每个格子访问一次是 O(m·n)，但每座岛屿要对其格坐标排序生成签名（单岛覆盖整个网格时 O(m·n log(m·n))）；若按固定 DFS 方向生成签名可省去排序、回到 O(m·n)。
  • 空间：O(m·n)，最坏情况整个网格都是 1，递归栈深度与签名集合总大小均可达 m·n。

易错点与扩展（面试高频考点）

  1. 忘记置 0 标记：访问后不把 1 改成 0，会重复遍历甚至无限递归。
  2. 只用面积去重：形状不同但格子数相同的岛屿会被误并，必须用相对坐标而非面积。
  3. 参考点不统一：归一化必须以固定参考点（如 DFS 起点）为准，否则同一形状在平移后签名不一致。
  4. HashSet<int[]> 陷阱：数组没有内容哈希，直接塞进集合会按引用比较，必须先转成字符串或列表。
  5. 旋转/翻转不算相同：本题只允许平移，不要做多余的旋转归一化，否则会把不同朝向的 L 形误判为同一种。

694. 不同岛屿的数量

C++ 实现

class Solution {
    int m, n;
    vector<pair<int, int>> cells;
    int dirs[4][2] = {{1, 0}, {-1, 0}, {0, 1}, {0, -1}};

    void dfs(vector<vector<int>>& g, int i, int j, int r0, int c0) {
        if (i < 0 || i >= m || j < 0 || j >= n || g[i][j] != 1) return;
        g[i][j] = 0;                                  // 淹没，防止重复访问
        cells.push_back({i - r0, j - c0});            // 记录相对坐标
        for (auto& d : dirs) {
            dfs(g, i + d[0], j + d[1], r0, c0);
        }
    }

public:
    int numDistinctIslands(vector<vector<int>>& grid) {
        m = grid.size();
        n = grid[0].size();
        set<string> shapes;

        for (int i = 0; i < m; i++) {
            for (int j = 0; j < n; j++) {
                if (grid[i][j] == 1) {
                    cells.clear();
                    dfs(grid, i, j, i, j);            // 以 (i, j) 为参考原点
                    sort(cells.begin(), cells.end()); // 归一化后排序
                    string sig;
                    for (auto& p : cells) {
                        sig += to_string(p.first) + "," + to_string(p.second) + ";";
                    }
                    shapes.insert(sig);
                }
            }
        }
        return (int)shapes.size();
    }
};

Python 实现

class Solution:
    def numDistinctIslands(self, grid: list[list[int]]) -> int:
        m, n = len(grid), len(grid[0])
        shapes = set()
        dirs = [(1, 0), (-1, 0), (0, 1), (0, -1)]

        def dfs(i, j, r0, c0, cells):
            if i < 0 or i >= m or j < 0 or j >= n or grid[i][j] != 1:
                return
            grid[i][j] = 0                       # 淹没，防止重复访问
            cells.append((i - r0, j - c0))       # 记录相对坐标
            for dr, dc in dirs:
                dfs(i + dr, j + dc, r0, c0, cells)

        for i in range(m):
            for j in range(n):
                if grid[i][j] == 1:
                    cells = []
                    dfs(i, j, i, j, cells)       # 以 (i, j) 为参考原点
                    shapes.add(tuple(sorted(cells)))  # 归一化签名去重

        return len(shapes)
