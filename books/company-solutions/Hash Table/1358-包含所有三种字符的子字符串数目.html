题目与约束

给你一个字符串 s，它只包含三种字符 a、b 和 c。

请你返回 a、b 和 c 都 至少 出现过一次的子字符串数目。

示例 1：

输入：s = "abcabc"
输出：10
解释：包含 a，b 和 c 各至少一次的子字符串为 "abc", "abca", "abcab", "abcabc", "bca", "bcab", "bcabc", "cab", "cabc" 和 "abc"（相同字符串算多次）。

示例 2：

输入：s = "aaacb"
输出：3
解释：包含 a，b 和 c 各至少一次的子字符串为 "aaacb", "aacb" 和 "acb"。

示例 3：

输入：s = "abc"
输出：1

提示：

  • 3 <= s.length <= 5 × 10^4
  • s 只包含字符 'a'、'b' 和 'c'

核心不变量

当以 i 结尾的子串同时含 a、b、c 时，合法的左端点个数 = min(最后一次出现 a, b, c 的位置) + 1。

完整推导

思路推导

  1. 换一种计数角度：直接枚举所有子串会 O(n²)。改成"对每个右端点 i，数一数以 i 结尾的合法子串有多少个"，累加起来即可。

  2. 关键观察：固定右端点 i，若要某个左端点 l 使 s[l..i] 含齐 a、b、c，等价于 l 不超过"a、b、c 三者各自最后一次出现位置的最小值"。设三个最后位置为 pa, pb, pc，则所有 l ∈ [0, min(pa,pb,pc)] 都合法，共 min(pa,pb,pc) + 1 个。

  3. 为什么是最小值：三个字符中最后出现得最早的那个，是"卡脖子"的那一个。左端点只有越过它之前，才能保证那个字符已经出现在窗口里；更靠右就会丢掉它。

  4. 小例子：s = "abcabc"。i=2（字符 c）时，pa=0,pb=1,pc=2，min=0，贡献 0+1=1（即 "abc"）。i=3（a）时 pa=3,pb=1,pc=2，min=1，贡献 2（"bca"、"abca"）。继续累加，最终得 10。

Java 实现（numberOfSubstrings，记录最后位置）

class Solution {
    public int numberOfSubstrings(String s) {
        int[] last = {-1, -1, -1}; // 记录 a、b、c 最后一次出现的下标
        int count = 0;
        for (int i = 0; i < s.length(); i++) {
            last[s.charAt(i) - 'a'] = i;
            // 三种字符都出现过时，以 i 结尾的合法左端点有 min+1 个
            if (last[0] >= 0 && last[1] >= 0 && last[2] >= 0) {
                count += Math.min(last[0], Math.min(last[1], last[2])) + 1;
            }
        }
        return count;
    }
}

复杂度

  • 时间：O(n)，只遍历字符串一次，每个位置做常数次操作。
  • 空间：O(1)，仅使用长度为 3 的数组记录最后出现位置。

易错点与扩展（面试高频考点）

  1. 左端点计数公式：是 min(pa,pb,pc) + 1，别漏掉 +1（从 0 到 min 一共 min+1 个左端点）。
  2. 三字符尚未集齐：在 a、b、c 没有全部出现前不能累加，否则会把非法子串算进去。
  3. 计数使用 long/int：n ≤ 5×10^4，合法子串总数最多约 n(n+1)/2 ≈ 1.25×10^9，未超过 int 上限 21 亿，int 可容纳；若数据更大则需用 long，面试中可主动提一句。
  4. 等价的双指针写法：也可维护窗口 [l, r] 使窗口内三字符齐全，则右端点固定时贡献 l+1；本解是它的空间压缩版本，本质相同。
  5. 扩展到 k 种字符：把"记录 3 个最后位置"推广为"记录 k 个最后位置"，对 min 取全部 k 个即可，思路完全一致。

C++ 实现

class Solution {
public:
    int numberOfSubstrings(string s) {
        int last[3] = {-1, -1, -1}; // a,b,c 最后一次出现的下标
        int count = 0;
        for (int i = 0; i < (int)s.size(); i++) {
            last[s[i] - 'a'] = i;
            if (last[0] >= 0 && last[1] >= 0 && last[2] >= 0) {
                count += min({last[0], last[1], last[2]}) + 1;
            }
        }
        return count;
    }
};

Python 实现

class Solution:
    def numberOfSubstrings(self, s: str) -> int:
        last = {'a': -1, 'b': -1, 'c': -1}  # 三个字符最后出现的下标
        count = 0
        for i, ch in enumerate(s):
            last[ch] = i
            if last['a'] >= 0 and last['b'] >= 0 and last['c'] >= 0:
                count += min(last['a'], last['b'], last['c']) + 1
        return count
