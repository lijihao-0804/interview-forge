题目信息 内容
难度 中等
核心模式 滑动窗口 + 哈希计数
时间复杂度 O(n)
空间复杂度 O(k)

题目与约束

给定一个字符串 s，找出至多包含 k 个不同字符的最长子串 T，返回其长度。

示例 1：

输入: s = "eceba", k = 2
输出: 3
解释: 则 T 为 "ece"，所以长度为 3。

示例 2：

输入: s = "aa", k = 1
输出: 2
解释: 则 T 为 "aa"，所以长度为 2。

提示：

  • 1 <= s.length <= 5 * 10⁴
  • 0 <= k <= 50

核心不变量

窗口 [left, right] 内不同字符的种数始终 <= k；当右指针纳入新字符导致种数超过 k 时，左指针右移收缩，直到种数重新满足 <= k。

完整推导

思路推导

  1. 识别题型

"最长子串 + 某个随区间扩大而单调变差的性质（不同字符变多）"是滑动窗口的典型信号：区间越向右扩张越容易违规，收缩左边界就能恢复。

  1. 右指针负责扩张

每读入一个字符 s[right]，就把它在哈希表中的计数加一。

  1. 左指针负责收缩

当哈希表中不同字符种数 > k 时，不断把 s[left] 的计数减一，计数减到 0 就从表中删除该键，left 右移；直到种数 <= k。

  1. 小例子 s = "eceba", k = 2

扩到 "ece" 有 2 种、长度 3；纳入 'b' 变 3 种，收缩到 "ceb"（长度 3）；纳 'a' 变 3 种，收缩到 "eba"（长度 3）。全程最大为 3。

Java 实现（lengthOfLongestSubstringKDistinct）

import java.util.HashMap;
import java.util.Map;

class Solution {
    public int lengthOfLongestSubstringKDistinct(String s, int k) {
        if (k == 0) return 0;                       // 至多 0 种字符 => 只能为空串
        Map<Character, Integer> count = new HashMap<>();
        int left = 0, best = 0;

        for (int right = 0; right < s.length(); right++) {
            char c = s.charAt(right);
            count.put(c, count.getOrDefault(c, 0) + 1);   // 扩张

            // 种数超标，收缩左边界直到 <= k
            while (count.size() > k) {
                char lc = s.charAt(left);
                count.put(lc, count.get(lc) - 1);
                if (count.get(lc) == 0) {
                    count.remove(lc);               // 计数归零要及时删键
                }
                left++;
            }

            best = Math.max(best, right - left + 1);    // 更新最大窗口长度
        }
        return best;
    }
}

复杂度

  • 时间：O(n)，left 和 right 都只单调右移，每个字符至多进窗口一次、出窗口一次。
  • 空间：O(k)，哈希表最多同时保存 k+1 个不同的字符键。

易错点与扩展（面试高频考点）

  1. k == 0 必须特判：此时任何非空子串都含至少 1 种字符，答案是 0；不特判会让窗口逻辑一直收缩到空。
  2. 计数归零要删键：count 里若保留计数为 0 的键，count.size() 会虚高，导致窗口被错误收缩。用数组实现时要额外维护 distinct 变量。
  3. 窗口长度公式：统一用 right - left + 1，不要漏掉 +1。
  4. 字符集决定容器：若字符限定 ASCII，可用 int[128] + distinct 计数更快；若字符集未知或含 Unicode，用 HashMap。
  5. 反过来做「至多 K 个不同」与「恰好 K 个不同」：恰好 K 个 = 至多 K 个 − 至多 K−1 个，这是常见的延伸问法。

340. 至多包含 K 个不同字符的最长子串

C++ 实现

#include <string>
#include <unordered_map>
#include <algorithm>

class Solution {
public:
    int lengthOfLongestSubstringKDistinct(std::string s, int k) {
        if (k == 0) return 0;                       // 至多 0 种字符
        std::unordered_map<char, int> count;
        int left = 0, best = 0;

        for (int right = 0; right < (int)s.size(); right++) {
            count[s[right]]++;                      // 扩张

            while ((int)count.size() > k) {         // 种数超标，收缩
                char lc = s[left++];
                if (--count[lc] == 0) {
                    count.erase(lc);                // 计数归零删键
                }
            }

            best = std::max(best, right - left + 1);
        }
        return best;
    }
};

Python 实现

class Solution:
    def lengthOfLongestSubstringKDistinct(self, s: str, k: int) -> int:
        if k == 0:
            return 0                       # 至多 0 种字符
        count = {}
        left = 0
        best = 0

        for right, c in enumerate(s):
            count[c] = count.get(c, 0) + 1  # 扩张

            while len(count) > k:           # 种数超标，收缩
                lc = s[left]
                count[lc] -= 1
                if count[lc] == 0:
                    del count[lc]           # 计数归零删键
                left += 1

            best = max(best, right - left + 1)

        return best
