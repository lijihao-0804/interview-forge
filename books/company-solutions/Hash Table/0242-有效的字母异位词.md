# 242. 有效的字母异位词

| 题目信息 | 内容 |
|---|---|
| 难度 | 简单 |
| 核心模式 | 字符计数（定长数组 / 哈希表） |
| 时间复杂度 | O(n) |
| 空间复杂度 | O(1) |

## 题目与约束

给定两个字符串 `s` 和 `t` ，编写一个函数来判断 `t` 是否是 `s` 的 字母异位词。

 

示例 1:

```
<strong>输入:</strong> s = "anagram", t = "nagaram"
<strong>输出:</strong> true
```

示例 2:

```
<strong>输入:</strong> s = "rat", t = "car"
<strong>输出: </strong>false
```

 

提示:

- `1 <= s.length, t.length <= 5 * 104`

- `s` 和 `t` 仅包含小写字母

 

进阶: 如果输入字符串包含 unicode 字符怎么办？你能否调整你的解法来应对这种情况？

[🔗 前往力扣原题验证 →](https://leetcode.cn/problems/valid-anagram/)

## 核心不变量

> 两个字符串是字母异位词，当且仅当每种字符出现的次数完全相同（与顺序无关）。

## 完整推导

### 思路推导

1. **定义拆解**：字母异位词 = 长度相同 + 每个字符出现次数相同，顺序可以任意。因此问题本质是"字符频次是否相等"。

2. **计数抵消**：开一个长度 26 的整型数组（对应 `a`~`z`）。遍历 `s` 时把对应位置 +1，遍历 `t` 时把对应位置 -1。一次遍历同时处理两个串。

3. **判定**：若两个串是异位词，所有字符一加一减后数组必然全为 0；否则存在非 0 项。先比较长度，长度不同可直接返回 `false`，既省时间又避免越界。

小例子：`"anagram"` 与 `"nagaram"` 计数完全抵消，返回 `true`；`"rat"` 与 `"car"` 中 `r`、`t` 与 `c` 无法抵消，返回 `false`。

### Java 实现（isAnagram）

```java
class Solution {
    public boolean isAnagram(String s, String t) {
        // 长度不同一定不是字母异位词
        if (s.length() != t.length()) {
            return false;
        }

        // 只含小写字母，用固定 26 的计数数组
        int[] count = new int[26];
        for (int i = 0; i < s.length(); i++) {
            count[s.charAt(i) - 'a']++;  // s 的字符计数 +1
            count[t.charAt(i) - 'a']--;  // t 的字符计数 -1
        }

        // 若所有计数都被完全抵消，才是字母异位词
        for (int c : count) {
            if (c != 0) {
                return false;
            }
        }
        return true;
    }
}
```

### 复杂度

- 时间：O(n)，n 为字符串长度，只需一趟遍历加一次固定 26 次的检查，26 视为常数。
- 空间：O(1)，只用了大小固定为 26 的计数数组。

### 易错点与扩展（面试高频考点）

1. **忘记先比较长度**：遇到 `s = "a"`、`t = "ab"` 这类输入时，长度不同必须先拦截，否则逻辑或下标会出问题。
2. **26 数组的隐含前提**：它假设输入只含小写英文字母；若含大写或 Unicode，应改用 `HashMap<Character, Integer>` 统计频次（这正是"进阶"要考的答案）。
3. **不要拿排序当最优**：排序法是 O(n log n)，计数法只有 O(n)，面试中优先讲计数；排序法可作为"一行式"备选。
4. **只检查是否为 0**：数组全 0 即等价，不需要再逐一比较各字符大小。
5. **进阶延伸**：Unicode 场景用哈希表；若考虑大小写不敏感，先统一转成小写再计数。

### C++ 实现

```cpp
#include <string>
using namespace std;

class Solution {
public:
    bool isAnagram(string s, string t) {
        if (s.size() != t.size()) return false;  // 长度不同直接返回 false

        int count[26] = {0};
        for (int i = 0; i < (int)s.size(); ++i) {
            count[s[i] - 'a']++;  // s 计数 +1
            count[t[i] - 'a']--;  // t 计数 -1
        }
        for (int c : count) {
            if (c != 0) return false;  // 有字符未抵消
        }
        return true;
    }
};
```

### Python 实现

```python
from typing import Dict


class Solution:
    def isAnagram(self, s: str, t: str) -> bool:
        if len(s) != len(t):
            return False

        count: Dict[str, int] = {}
        for ch in s:
            count[ch] = count.get(ch, 0) + 1
        for ch in t:
            if count.get(ch, 0) == 0:  # t 中出现了 s 里没有（或已用完）的字符
                return False
            count[ch] -= 1
        return True
```
