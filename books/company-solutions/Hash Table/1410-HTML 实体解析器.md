# 1410. HTML 实体解析器

| 题目信息 | 内容 |
|---|---|
| 难度 | 中等 |
| 核心模式 | 从左到右扫描，遇 '&' 时按已知实体最长匹配并替换 |
| 时间复杂度 | O(n) |
| 空间复杂度 | O(n)（结果字符串） |

## 题目与约束

「HTML 实体解析器」是一种特殊的解析器，它将 HTML 代码作为输入，并用字符本身替换掉所有这些特殊的字符实体。

HTML 里这些特殊字符和它们对应的字符实体包括：

- **双引号：** 字符实体为 `&quot;`，对应的字符是 `"`。
- **单引号：** 字符实体为 `&apos;`，对应的字符是 `'`。
- **与符号：** 字符实体为 `&amp;`，对应的字符是 `&`。
- **大于号：** 字符实体为 `&gt;`，对应的字符是 `>`。
- **小于号：** 字符实体为 `&lt;`，对应的字符是 `<`。
- **斜线号：** 字符实体为 `&frasl;`，对应的字符是 `/`。

给你输入字符串 `text`，请你实现一个 HTML 实体解析器，返回解析器解析后的结果。

**示例 1：**

```
输入：text = "&amp; is an HTML entity but &ambassador; is not."
输出："& is an HTML entity but &ambassador; is not."
解释：解析器把字符实体 &amp; 用 & 替换
```

**示例 2：**

```
输入：text = "and I quote: &quot;...&quot;"
输出："and I quote: \"...\""
```

**示例 3：**

```
输入：text = "Stay home! Practice on Leetcode :)"
输出："Stay home! Practice on Leetcode :)"
```

**示例 4：**

```
输入：text = "x &gt; y &amp;&amp; x &lt; y is always false"
输出："x > y && x < y is always false"
```

**示例 5：**

```
输入：text = "leetcode.com&frasl;problemset&frasl;all"
输出："leetcode.com/problemset/all"
```

**提示：**

- `1 <= text.length <= 10^5`
- 字符串可能包含 256 个 ASCII 字符中的任意字符。

## 核心不变量

> 从左到右逐字符处理，只有在遇到 `&` 且其后能精确匹配某个已知实体时才替换；替换结果不再参与后续匹配。

## 完整推导

### 思路推导

1. **为什么不能简单 `replace` 一遍**：如果先替换 `&amp;` 再替换别的，或顺序不当，会误伤。比如 `"&amp;gt;"` 期望输出 `"&gt;"`（先还原出 `&`，后面的 `gt;` 是普通字符），若先用某种"全局替换 + 再解析"就可能把它一路变成 `">"`，出错。替换结果必须**不再被二次解析**。

2. **扫描法思想**：用一个指针 `i` 从头遍历 `text`：
   - 若当前字符不是 `&`，直接拷贝，`i++`。
   - 若是 `&`，尝试匹配 6 个已知实体之一（用"原文是否以该实体开头"判断）。匹配成功就输出对应字符并跳过整个实体长度；匹配失败（如 `&ambassador;`）就原样输出 `&`，`i++`。

3. **"最长匹配"其实自动成立**：本题 6 个实体互不为前缀（`&quot; &apos; &amp; &gt; &lt; &frasl;`，`&` 后第二位即可区分），所以任意匹配顺序都不会错。一次只前进一个实体，天然避免了对替换结果再次解析。

4. **例子**：`"x &gt; y &amp;&amp; x &lt; y"` → 遇 `&gt;`→`>`，遇 `&amp;`→`&`（两个相邻，得 `&&`），遇 `&lt;`→`<`，结果 `"x > y && x < y"`。✓

### Java 实现（逐字符扫描 + 实体最长匹配）

```java
import java.util.HashMap;
import java.util.Map;

class Solution {
    public String entityParser(String text) {
        Map<String, Character> map = new HashMap<>();
        map.put("&quot;", '"');
        map.put("&apos;", '\'');
        map.put("&amp;", '&');
        map.put("&gt;", '>');
        map.put("&lt;", '<');
        map.put("&frasl;", '/');

        StringBuilder sb = new StringBuilder();
        int i = 0;
        int n = text.length();
        while (i < n) {
            if (text.charAt(i) == '&') {
                boolean matched = false;
                for (Map.Entry<String, Character> e : map.entrySet()) {
                    String key = e.getKey();
                    if (text.startsWith(key, i)) {
                        sb.append(e.getValue());
                        i += key.length();
                        matched = true;
                        break;
                    }
                }
                if (!matched) {
                    sb.append('&');
                    i++;
                }
            } else {
                sb.append(text.charAt(i));
                i++;
            }
        }
        return sb.toString();
    }
}
```

### 复杂度

- 时间：`O(n)`。每个位置最多被比较常数次（6 个固定长度实体，长度都很短），指针只前进不后退。
- 空间：`O(n)`。结果字符串 `sb` 最长与原串同阶；实体表为固定常数大小。

### 易错点与扩展（面试高频考点）

1. **警惕 `&amp;gt;` 陷阱**：正确输出是 `&gt;` 而不是 `>`。扫描法"替换后不再解析"天然正确；而"先全局替换 `&amp;` 再用库函数解码"之类会出错。
2. **非实体原样保留**：`&ambassador;` 中 `&` 后面不是已知实体，必须原样输出 `&` 并继续，不能吞掉字符。
3. **`&` 是其他实体的前缀**：匹配失败时只前进 1 位输出 `&`，绝不能按 `&` 就去吞后面若干位。
4. **大小写敏感**：实体都是小写（`&quot;` 等），匹配要严格区分大小写，`&QUOT;` 不算实体。
5. **扩展**：若实体数量多、长度不一，可用字典树（Trie）加速"从 `&` 开始的最长实体匹配"，把最坏情况也压到接近 `O(n)`。

### C++ 实现

```cpp
#include <string>
#include <vector>
#include <utility>
using namespace std;

class Solution {
public:
    string entityParser(string text) {
        vector<pair<string, char>> mp = {
            {"&quot;", '"'},
            {"&apos;", '\''},
            {"&amp;", '&'},
            {"&gt;", '>'},
            {"&lt;", '<'},
            {"&frasl;", '/'}
        };

        string res;
        int i = 0, n = text.size();
        while (i < n) {
            if (text[i] == '&') {
                bool matched = false;
                for (auto& e : mp) {
                    const string& key = e.first;
                    if (text.compare(i, key.size(), key) == 0) {
                        res.push_back(e.second);
                        i += key.size();
                        matched = true;
                        break;
                    }
                }
                if (!matched) {
                    res.push_back('&');
                    i++;
                }
            } else {
                res.push_back(text[i]);
                i++;
            }
        }
        return res;
    }
};
```

### Python 实现

```python
class Solution:
    def entityParser(self, text: str) -> str:
        mp = {
            "&quot;": '"',
            "&apos;": "'",
            "&amp;": "&",
            "&gt;": ">",
            "&lt;": "<",
            "&frasl;": "/",
        }
        res = []
        i, n = 0, len(text)
        while i < n:
            if text[i] == "&":
                matched = False
                for key, val in mp.items():
                    if text.startswith(key, i):
                        res.append(val)
                        i += len(key)
                        matched = True
                        break
                if not matched:
                    res.append("&")
                    i += 1
            else:
                res.append(text[i])
                i += 1
        return "".join(res)
```
