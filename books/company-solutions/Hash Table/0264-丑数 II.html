题目与约束

给你一个整数 n ，请你找出并返回第 n 个 丑数 。

丑数 就是质因子只包含 2、3 和 5 的正整数。

示例 1：

<strong>输入：</strong>n = 10
<strong>输出：</strong>12
<strong>解释：</strong>[1, 2, 3, 4, 5, 6, 8, 9, 10, 12] 是由前 10 个丑数组成的序列。

示例 2：

<strong>输入：</strong>n = 1
<strong>输出：</strong>1
<strong>解释：</strong>1 通常被视为丑数。

提示：

  • 1 <= n <= 1690

🔗 前往力扣原题验证 →

核心不变量

每个丑数都等于某个更小的丑数乘以 2、3 或 5；令 dp[i] = min(dp[i2]*2, dp[i3]*3, dp[i5]*5)，并把取到最小值的指针后移，即可保证序列严格递增且不重复。

完整推导

思路推导

  1. 直觉与痛点（逐个判断行不行？）

最直接的想法是从 1 开始逐个判断每个数是否为丑数（反复除以 2、3、5 看能否除尽），数到第 n 个为止。虽然能过，但每个数都要试除，做了大量无用功。更好的办法是直接按从小到大的顺序把丑数"造"出来。

  1. 关键观察（丑数从哪来？）

任何一个丑数，除以 2、3 或 5 之后仍然是丑数。反过来，任何丑数都可以由某个更小的丑数乘以 2、3 或 5 得到。于是我们只要从最小的丑数 1 出发，不断用已有丑数生成新的丑数即可。

  1. 多路归并（三条已排序的"链表"）

把"所有丑数 × 2"看成一个递增序列，同理"× 3""× 5"也是递增序列。三个指针 i2、i3、i5 分别指向这三个序列中下一个还没用过的位置。每一轮取三个乘积里的最小值作为下一个丑数，并把所有等于该最小值的指针都向后移动一位（去重）。

  1. 小例子（前 6 个）

初始 dp[0] = 1，i2 = i3 = i5 = 0。 - 候选 2, 3, 5 → 取 2，i2 后移； - 候选 4, 3, 5 → 取 3，i3 后移； - 候选 4, 6, 5 → 取 4，i2 后移； - 候选 6, 6, 5 → 取 5，i5 后移； - 候选 6, 6, 10 → 取 6，i2、i3 同时后移（避免重复生成 6）； - 候选 8, 9, 10 → 取 8……

依次得到 1, 2, 3, 4, 5, 6, 8, ...。

Java 实现（nthUglyNumber）

class Solution {
    public int nthUglyNumber(int n) {
        int[] dp = new int[n];
        dp[0] = 1;                 // 第一个丑数是 1
        int i2 = 0, i3 = 0, i5 = 0; // 三个指针分别代表 ×2、×3、×5 的待用位置

        for (int i = 1; i < n; i++) {
            // 用 long 计算，防止 dp[i2] * 5 等乘积溢出 int
            long next = Math.min(Math.min((long) dp[i2] * 2, (long) dp[i3] * 3),
                                 (long) dp[i5] * 5);
            dp[i] = (int) next;

            // 注意：三个 if 都要判断，不能写成 else if
            if (next == (long) dp[i2] * 2) i2++;
            if (next == (long) dp[i3] * 3) i3++;
            if (next == (long) dp[i5] * 5) i5++;
        }
        return dp[n - 1];
    }
}

复杂度

  • 时间：O(n)，从 1 到 n 线性生成，每次只做常数次比较与乘法。
  • 空间：O(n)，需要长度为 n 的 dp 数组保存全部丑数。

易错点与扩展（面试高频考点）

  1. 三个 if 不能写成 else if：同一个丑数可能同时等于 dp[i2]*2 与 dp[i3]*3（例如 6、10、12），必须让多个指针同时后移，否则会重复生成。
  2. 乘积溢出：dp[i5] * 5 可能接近 int 上限，用 long 计算再转回 int 更安全。
  3. 边界 n = 1：循环不进入，直接返回 dp[0] = 1，无需特判。
  4. 与"逐个判断"的对比：DP 生成是 O(n) 最优解；逐个试除虽然简单，但每次都要反复除，常数大且不符合面试期望。
  5. 扩展解法：也可用小顶堆 + 哈希去重，每次弹出最小值并压入它的 2/3/5 倍，复杂度 O(n log n)，比三指针 DP 慢，可作对比。

264. 丑数 II

C++ 实现

class Solution {
public:
    int nthUglyNumber(int n) {
        vector<long long> dp(n);
        dp[0] = 1;
        int i2 = 0, i3 = 0, i5 = 0;
        for (int i = 1; i < n; ++i) {
            long long next = min({dp[i2] * 2, dp[i3] * 3, dp[i5] * 5});
            dp[i] = next;
            // 三个独立判断，命中即前进，天然去重
            if (next == dp[i2] * 2) ++i2;
            if (next == dp[i3] * 3) ++i3;
            if (next == dp[i5] * 5) ++i5;
        }
        return (int) dp[n - 1];
    }
};

Python 实现

class Solution:
    def nthUglyNumber(self, n: int) -> int:
        dp = [0] * n
        dp[0] = 1
        i2 = i3 = i5 = 0
        for i in range(1, n):
            nxt = min(dp[i2] * 2, dp[i3] * 3, dp[i5] * 5)
            dp[i] = nxt
            # 三个独立判断，命中即前进，天然去重
            if nxt == dp[i2] * 2:
                i2 += 1
            if nxt == dp[i3] * 3:
                i3 += 1
            if nxt == dp[i5] * 5:
                i5 += 1
        return dp[n - 1]
