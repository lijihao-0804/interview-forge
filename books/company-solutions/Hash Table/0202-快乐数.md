# 202. 快乐数

| 题目信息 | 内容 |
|---|---|
| 难度 | 简单 |
| 核心模式 | 快慢指针判环（Floyd 判圈） |
| 时间复杂度 | O(log n) |
| 空间复杂度 | O(1) |

## 题目与约束

编写一个算法来判断一个数 `n` 是不是快乐数。

**「快乐数」** 定义为：

- 对于一个正整数，每一次将该数替换为它每个位置上的数字的平方和。
- 然后重复这个过程直到这个数变为 1，也可能是 **无限循环** 但始终变不到 1。
- 如果这个过程 **结果为** 1，那么这个数就是快乐数。

如果 `n` 是快乐数就返回 `true`；不是，则返回 `false`。

**示例 1：**

```
输入：n = 19
输出：true
解释：
1^2 + 9^2 = 82
8^2 + 2^2 = 68
6^2 + 8^2 = 100
1^2 + 0^2 + 0^2 = 1
```

**示例 2：**

```
输入：n = 2
输出：false
```

**提示：**

- `1 <= n <= 2^31 - 1`

## 核心不变量

> 反复做「各位数字平方和」的变换，序列要么最终到达 1，要么必然进入一个环；用快慢指针在环上相遇即可区分两种情况，无需额外存储。

## 完整推导

### 思路推导

1. **直觉与痛点（无限循环怎么办）**

   直接模拟，用 `while (n != 1)` 一直算平方和。但若它不是快乐数，就会陷入无限循环——我们根本无法靠「算到 1」来判断结束，必须识别「绕回来了」。

2. **破局思路（把变换看成有向图上的走边）**

   把每个数 `x` 看作一个节点，边指向 `squareSum(x)`。每个节点只有唯一一条出边，所以这张图要么通向 1（快乐数），要么在某处形成环（非快乐数）。判断链表是否有环的经典方法在这里同样适用。

3. **破局绝招：快慢指针**

   设 `slow` 每次走一步（做一次平方和），`fast` 每次走两步（做两次平方和）。若存在环，快指针一定会在环内追上慢指针，此时 `slow == fast` 且 `fast != 1`，判定为非快乐数；若某次 `fast` 先到达 1，则是快乐数。

4. **小例子验证**

   以 `n = 19` 为例：`19 → 82 → 68 → 100 → 1`，快指针很快到达 1，返回 `true`。以 `n = 2` 为例：`2 → 4 → 16 → 37 → 58 → 89 → 145 → 42 → 20 → 4`，又回到 4，形成环，快慢指针必相遇，返回 `false`。

### Java 实现（isHappy）

```java
class Solution {
    // 计算 n 各位数字的平方和
    private int squareSum(int n) {
        int sum = 0;
        while (n > 0) {
            int d = n % 10;
            sum += d * d;
            n /= 10;
        }
        return sum;
    }

    public boolean isHappy(int n) {
        int slow = n;
        int fast = squareSum(n);
        // 快指针没到 1 且快慢未相遇就继续走
        while (fast != 1 && slow != fast) {
            slow = squareSum(slow);                 // 慢指针走一步
            fast = squareSum(squareSum(fast));      // 快指针走两步
        }
        return fast == 1;
    }
}
```

### 复杂度

- 时间：`O(log n)`。每次计算平方和需要处理 `n` 的十进制约 `log n` 位，而序列长度在一个很小的常数范围内（非快乐数会很快进入已知的环），总体为 `O(log n)`。
- 空间：`O(1)`。只用了两个指针，没有额外集合。

### 易错点与扩展（面试高频考点）

1. **忘记判环会死循环**：只写 `while (n != 1)` 而在非快乐数上永远退不出，必须引入快慢指针或哈希集合。
2. **快慢初始化要错开**：`slow = n`、`fast = squareSum(n)`，否则一开始二者就相等，`while` 条件直接失败。也可以让 `fast` 再走一步 `squareSum(squareSum(n))`。
3. **两种解法对比**：哈希集合法更直观（`Set` 存走过的数，重复即非快乐数），时间 `O(log n)`、空间 `O(log n)`；Floyd 判圈把空间降到 `O(1)`，是本题进阶考点。
4. **数学捷径**：所有非快乐数最终都会进入 `4 → 16 → 37 → 58 → 89 → 145 → 42 → 20 → 4` 这个环，因此可以直接判断 `n == 4` 时返回 `false`，但通用性不如判圈。
5. **两位数以上才是多位平方和**：一位数（如 7）也要正常参与变换，`squareSum` 用 `while (n > 0)` 循环取每一位，天然兼容任意位数。

### Python 实现

```python
class Solution:
    def isHappy(self, n: int) -> bool:
        def square_sum(x: int) -> int:
            total = 0
            while x > 0:
                d = x % 10
                total += d * d
                x //= 10
            return total

        slow = n
        fast = square_sum(n)
        while fast != 1 and slow != fast:
            slow = square_sum(slow)             # 慢指针走一步
            fast = square_sum(square_sum(fast)) # 快指针走两步
        return fast == 1
```
