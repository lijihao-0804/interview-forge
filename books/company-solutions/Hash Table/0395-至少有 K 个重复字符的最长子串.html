题目信息 内容
难度 中等
核心模式 分治：以「出现次数不足 k」的字符为分割点递归求两段

题目与约束

给你一个字符串 s 和一个整数 k ，请你找出 s 中的最长子串， 要求该子串中的每一字符出现次数都不少于 k 。返回这一子串的长度。

如果不存在这样的子字符串，则返回 0。

示例 1：

输入：s = "aaabb", k = 3
输出：3
解释：最长子串为 "aaa" ，其中 'a' 重复了 3 次。

示例 2：

输入：s = "ababbc", k = 2
输出：5
解释：最长子串为 "ababb" ，其中 'a' 重复了 2 次， 'b' 重复了 3 次。

提示：

  • 1 <= s.length <= 104

  • s 仅由小写英文字母组成

  • 1 <= k <= 105

核心不变量

若某字符在整个区间里出现次数都不到 k，它不可能出现在任何合法子串中，因此任何合法子串都只能落在被它切开的某一段里。

完整推导

思路推导

  1. 先找「一定不在答案里」的字符

在当前区间 [l, r] 统计每个字符出现的次数。若某字符 c 的次数满足 0 < cnt[c] < k，那么任何包含 c 的子串都不可能合法，所以合法子串只能完全落在 c 的左侧或右侧。

  1. 以它为分割点分治

找到第一个这样的字符位置 i，把问题拆成 [l, i-1] 和 [i+1, r] 两个子区间分别递归求答案，取较大值。若区间内所有字符的次数都 >= k，整段就是合法子串，直接返回区间长度。

  1. 递归出口

如果区间长度本身 < k，不可能凑够 k 个重复字符，返回 0。

  1. 小例子（s="aaabb", k=3）

整段里 b 只有 2 次 < 3，于是以 b 为界切开：左侧 "aaa" 中 a 出现 3 次，全部满足 → 合法，长度 3；右侧为空。答案 3。

Java 实现（longestSubstring）

class Solution {
    public int longestSubstring(String s, int k) {
        return helper(s, 0, s.length() - 1, k);
    }

    private int helper(String s, int l, int r, int k) {
        // 区间长度不足 k，不可能有字符重复 k 次
        if (r - l + 1 < k) return 0;

        int[] cnt = new int[26];
        for (int i = l; i <= r; i++) {
            cnt[s.charAt(i) - 'a']++;
        }

        // 找一个出现次数不足 k 的字符作为分割点
        for (int i = l; i <= r; i++) {
            char c = s.charAt(i);
            if (cnt[c - 'a'] > 0 && cnt[c - 'a'] < k) {
                int left = helper(s, l, i - 1, k);
                int right = helper(s, i + 1, r, k);
                return Math.max(left, right);
            }
        }

        // 区间内所有字符都满足出现次数 >= k
        return r - l + 1;
    }
}

复杂度

  • 时间：最坏 O(n²)。每次分割都要扫描当前区间，切得极不均匀时（如几乎没有重复字符）退化为平方级；但字符集只有 26 种，实际运行的层次很浅，远快于最坏界。
  • 空间：O(n)，最坏递归深度为 n（每次递归只切掉一个字符）。

易错点与扩展（面试高频考点）

  1. 分割依据是「当前区间的词频」：每次递归都要针对当前子区间重新统计，不能复用上一层的计数。
  2. 判断条件写 > 0 && < k：出现 0 次的字符不该参与分割，否则会把区间无意义地切碎。
  3. 递归出口别漏：区间长度 < k 时直接返回 0，这既是剪枝也是正确性的保证。
  4. 扩展：滑动窗口 + 枚举不同字符数。枚举窗口内「恰好有 m 种字符」（m = 1..26），用双指针维护每个字符计数与「出现次数 >= k 的字符种数」，当两者都等于 m 时更新答案，可做到 O(26·n) = O(n)，是更稳的线性解法。
  5. 扩展：递归爆栈风险。s 长度可达 10^4，最坏递归深度可达 10^4，Java 默认栈一般可承受，工程上也可改写成显式栈或直接用滑动窗口。

力扣原题

395. 至少有 K 个重复字符的最长子串

C++ 实现

class Solution {
public:
    int longestSubstring(string s, int k) {
        return helper(s, 0, (int)s.size() - 1, k);
    }
private:
    int helper(const string& s, int l, int r, int k) {
        if (r - l + 1 < k) return 0;

        int cnt[26] = {0};
        for (int i = l; i <= r; ++i) cnt[s[i] - 'a']++;

        for (int i = l; i <= r; ++i) {
            if (cnt[s[i] - 'a'] > 0 && cnt[s[i] - 'a'] < k) {
                return max(helper(s, l, i - 1, k), helper(s, i + 1, r, k));
            }
        }
        return r - l + 1;
    }
};

Python 实现

import sys


class Solution:
    def longestSubstring(self, s: str, k: int) -> int:
        # 最坏递归深度可达 n，放宽递归上限避免 RecursionError
        sys.setrecursionlimit(20000)

        def helper(l: int, r: int) -> int:
            if r - l + 1 < k:
                return 0

            cnt = {}
            for i in range(l, r + 1):
                cnt[s[i]] = cnt.get(s[i], 0) + 1

            for i in range(l, r + 1):
                if 0 < cnt[s[i]] < k:
                    return max(helper(l, i - 1), helper(i + 1, r))

            return r - l + 1

        return helper(0, len(s) - 1)
