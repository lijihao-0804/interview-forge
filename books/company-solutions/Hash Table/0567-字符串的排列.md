# 567. 字符串的排列

| 题目信息 | 内容 |
|---|---|
| 难度 | 中等 |
| 核心模式 | 定长滑动窗口 + 字符频次比较 |
| 时间复杂度 | O(n1 + n2) |
| 空间复杂度 | O(1) |

## 题目与约束

给你两个字符串 `s1` 和 `s2` ，写一个函数来判断 `s2` 是否包含 `s1` 的 排列。如果是，返回 `true` ；否则，返回 `false` 。

换句话说，`s1` 的排列之一是 `s2` 的 子串 。

 

示例 1：

```
<strong>输入：</strong>s1 = "ab" s2 = "eidbaooo"
<strong>输出：</strong>true
<strong>解释：</strong>s2 包含 s1 的排列之一 ("ba").
```

示例 2：

```
<strong>输入：</strong>s1= "ab" s2 = "eidboaoo"
<strong>输出：</strong>false
```

 

提示：

- `1 <= s1.length, s2.length <= 104`

- `s1` 和 `s2` 仅包含小写字母

[🔗 前往力扣原题验证 →](https://leetcode.cn/problems/permutation-in-string/)

## 核心不变量

> 长度固定为 `|s1|` 的滑动窗口，其字符频次与 `s1` 的字符频次完全相等时，该窗口就是 `s1` 的一个排列。

## 完整推导

### 思路推导

1. **把“排列”翻译成“频次”**

   `s1` 的任意排列，本质就是“字符的种类和每种字符的个数”与 `s1` 完全相同。所以判断 `s2` 的某个子串是否为 `s1` 的排列，等价于判断：**存在一个长度为 `|s1|` 的子串，其字符频次与 `s1` 一致**。

2. **为什么用定长滑动窗口**

   所有可能是答案的子串长度都等于 `|s1|`。我们让一个长度固定为 `|s1|` 的窗口在 `s2` 上从左向右滑动，每次只“加入右端一个新字符、移出左端一个旧字符”，用 O(1) 时间维护频次，然后与 `s1` 的频次比较。

3. **比较的技巧**

   - 用两个长度 26 的数组 `need`（`s1` 的频次）和 `window`（当前窗口频次）。
   - 每滑一步，`window[s2[i]]++`，若窗口超过 `|s1|` 则把滑出的字符 `window[s2[i-|s1|]]--`。
   - 当窗口长度达到 `|s1|` 后，用一次 `Arrays.equals` 比较两数组。

4. **小例子（`s1="ab", s2="eidbaooo"`）**

   窗口长度 2。滑动到 `"ba"`（下标 3、4）时，`need = {a:1,b:1}`，`window = {b:1,a:1}`，两者相等 → 返回 `true`。

### Java 实现（checkInclusion）

```java
import java.util.Arrays;

class Solution {
    public boolean checkInclusion(String s1, String s2) {
        int n1 = s1.length();
        int n2 = s2.length();
        if (n1 > n2) {
            return false;
        }

        int[] need = new int[26];   // s1 的字符频次
        int[] window = new int[26]; // 当前滑动窗口的字符频次
        for (int i = 0; i < n1; i++) {
            need[s1.charAt(i) - 'a']++;
        }

        for (int i = 0; i < n2; i++) {
            // 右端加入新字符
            window[s2.charAt(i) - 'a']++;
            // 窗口长度超过 n1 时，左端移出一个字符
            if (i >= n1) {
                window[s2.charAt(i - n1) - 'a']--;
            }
            // 窗口长度恰为 n1 时比较频次
            if (i >= n1 - 1 && Arrays.equals(need, window)) {
                return true;
            }
        }
        return false;
    }
}
```

### 复杂度

- 时间：O(n1 + n2)，统计 `s1` 频次 O(n1)，窗口滑动 O(n2)，每次比较只需 O(26)（字母表大小视为常数）。
- 空间：O(1)，仅用两个长度 26 的定长数组。

### 易错点与扩展（面试高频考点）

1. **窗口长度写错**：窗口固定为 `|s1|`；滑出条件是 `i >= n1`（即窗口里已有 `n1+1` 个字符时移出最左），比较时机是 `i >= n1 - 1`。
2. **忘记先比较初始窗口**：若用“循环里先判断再移动”的写法容易漏掉第一个窗口；上面的写法是“先加右端、再移左端、再比较”，天然覆盖首窗口。
3. **两数组比较别用 `==`**：Java 里数组 `==` 比较的是引用，必须用 `Arrays.equals`；C++ 中 `vector` 可直接用 `==`；Python 里 `Counter` 可直接比较。
4. **提前剪枝**：`n1 > n2` 时不可能包含，直接返回 `false`，可省去无谓遍历。
5. **扩展变体**：把两数组比较换成一个 `diff` 计数器记录“有多少种字符频次不同”，可做到纯 O(n1 + n2)、比较 O(1)；对「找到所有字母异位词」（LeetCode 438）同样适用。

### C++ 实现

```cpp
#include <string>
#include <vector>
using namespace std;

class Solution {
public:
    bool checkInclusion(string s1, string s2) {
        int n1 = s1.size(), n2 = s2.size();
        if (n1 > n2) return false;

        vector<int> need(26, 0), window(26, 0);
        for (char c : s1) {
            need[c - 'a']++;
        }

        for (int i = 0; i < n2; ++i) {
            window[s2[i] - 'a']++;                 // 右端加入
            if (i >= n1) {
                window[s2[i - n1] - 'a']--;        // 左端移出
            }
            if (i >= n1 - 1 && need == window) {   // 窗口长度达标且频次一致
                return true;
            }
        }
        return false;
    }
};
```

### Python 实现

```python
from collections import Counter

class Solution:
    def checkInclusion(self, s1: str, s2: str) -> bool:
        n1, n2 = len(s1), len(s2)
        if n1 > n2:
            return False

        need = Counter(s1)
        window = Counter(s2[:n1])
        if need == window:
            return True

        for i in range(n1, n2):
            window[s2[i]] += 1          # 右端加入
            left = s2[i - n1]
            window[left] -= 1           # 左端移出
            if window[left] == 0:
                del window[left]
            if need == window:
                return True
        return False
```
