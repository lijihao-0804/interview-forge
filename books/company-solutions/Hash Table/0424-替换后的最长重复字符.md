# 424. 替换后的最长重复字符

| 题目信息 | 内容 |
|---|---|
| 难度 | 中等 |
| 核心模式 | 滑动窗口（窗口长度 − 最高频次 ≤ k 即合法） |
| 时间复杂度 | O(n) |
| 空间复杂度 | O(1)（固定 26 个字母的计数数组） |

## 题目与约束

给你一个字符串 `s` 和一个整数 `k`。你可以选择字符串中的任一字符，并将其更改为任何其他大写英文字符。该操作最多可执行 `k` 次。

在执行上述操作后，返回包含相同字母的最长子字符串的长度。

**示例 1：**

```
输入：s = "ABAB", k = 2
输出：4
解释：用两个'A'替换为两个'B',反之亦然。
```

**示例 2：**

```
输入：s = "AABABBA", k = 1
输出：4
解释：
将中间的一个'A'替换为'B',字符串变为 "AABBBBA"。
子串 "BBBB" 有最长重复字母, 答案为 4。
可能存在其他的方法来得到同样的结果。
```

**提示：**

- `1 <= s.length <= 10^5`
- `s` 仅由大写英文字母组成
- `0 <= k <= s.length`

## 核心不变量

> 对任意窗口，"需要替换的字符数 = 窗口长度 − 窗口内出现次数最多的字符的频次"，只要它 ≤ k，窗口就能通过替换变成全同字符。

## 完整推导

### 思路推导

1. **转化（把"替换"变成可判定条件）**

   在一个窗口里，想让它们变成同一个字母，最省力的做法是保留出现最多的那个字母，把其余字符全部替换掉。因此需要替换的数量 = `窗口长度 − 窗口内最大频次`。它 ≤ `k` 时窗口合法。

2. **滑动窗口（右扩 + 左缩）**

   用左右指针维护窗口，`cnt[26]` 记录窗口内每个字母的频次，`maxCount` 记录窗口内出现过的最大频次。右指针每次扩张一个字符并更新；若窗口变得不合法（`窗口长度 − maxCount > k`），左指针前进一格并减少对应计数。

3. **关键技巧（窗口只增不减）**

   由于只求最长长度，可以让窗口大小**永不缩小**：不合法时只把左指针右移一格（长度不变地整体平移），`maxCount` 也不必下调。因为一旦某长度成立，答案不会再变小；平移只是继续向右寻找同样长或更长的合法窗口。

4. **小例子（s = "ABAB", k = 2）**

   - 窗口不断右扩到 `"ABAB"`，字母频次 A:2、B:2，`maxCount = 2`，`4 - 2 = 2 ≤ 2`，合法，答案 4。

### Java 实现（characterReplacement）

```java
class Solution {
    public int characterReplacement(String s, int k) {
        int[] cnt = new int[26];
        int left = 0;
        int maxCount = 0; // 窗口内出现过的最大频次（只增不减）
        int ans = 0;

        for (int right = 0; right < s.length(); right++) {
            int idx = s.charAt(right) - 'A';
            cnt[idx]++;
            maxCount = Math.max(maxCount, cnt[idx]);

            // 窗口无法在 k 次替换内变成同一字符时，左边界右移
            if (right - left + 1 - maxCount > k) {
                cnt[s.charAt(left) - 'A']--;
                left++;
            }
            ans = Math.max(ans, right - left + 1);
        }
        return ans;
    }
}
```

### 复杂度

- 时间：O(n)，左右指针各自最多移动 `n` 次，窗口每步只做常数次更新。
- 空间：O(1)，`cnt` 固定大小 26，与输入规模无关。

### 易错点与扩展（面试高频考点）

1. **合法条件的方向**：判断的是 `窗口长度 − maxCount > k` 才非法，即"要替换的字符数"超预算；写成 `> k` 之外的条件都会算错。
2. **`maxCount` 只增不减是否安全**：安全。因为我们只维护"最大窗口长度"，不要求中途窗口严格合法；但若题目要求返回**具体最长子串**，就必须真正收缩窗口并保证 `maxCount` 对应当前窗口。
3. **`left` 前进时只减计数**：无需重算 `maxCount`；这也是该技巧能保持 O(n) 的原因。
4. **字符映射**：`s.charAt(right) - 'A'` 映射到 `0..25`，保证数组不越界。
5. **扩展问法**：可改成"最多替换 k 个字符使子串全为某指定字符"；也可用"窗口内不同字符种类 ≤ k+1"等变体，本质仍是滑动窗口 + 频次统计。

## 力扣原题

[424. 替换后的最长重复字符](https://leetcode.cn/problems/longest-repeating-character-replacement/)

### C++ 实现

```cpp
class Solution {
public:
    int characterReplacement(string s, int k) {
        int cnt[26] = {0};
        int left = 0, maxCount = 0, ans = 0;

        for (int right = 0; right < (int)s.size(); ++right) {
            maxCount = max(maxCount, ++cnt[s[right] - 'A']);

            if (right - left + 1 - maxCount > k) {
                --cnt[s[left] - 'A'];
                ++left;
            }
            ans = max(ans, right - left + 1);
        }
        return ans;
    }
};
```

### Python 实现

```python
class Solution:
    def characterReplacement(self, s: str, k: int) -> int:
        cnt = [0] * 26
        left = 0
        max_count = 0
        ans = 0

        for right in range(len(s)):
            idx = ord(s[right]) - ord('A')
            cnt[idx] += 1
            max_count = max(max_count, cnt[idx])

            if right - left + 1 - max_count > k:
                cnt[ord(s[left]) - ord('A')] -= 1
                left += 1

            ans = max(ans, right - left + 1)

        return ans
```
