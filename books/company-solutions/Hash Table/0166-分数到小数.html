166. 分数到小数

本题学习状态正在读取学习记录…下次复习：—
本次复习：
按 M 快速切换薄弱标记
遮住推导与代码，先自己想，再逐段揭示
难度中等核心模式长除法模拟 + 哈希表记录余数出现位置时间复杂度O(L)（L 为答案字符串长度）空间复杂度O(L)

题目与约束

给定两个整数，分别表示分数的分子 numerator 和分母 denominator，以 字符串形式返回小数 。

如果小数部分为循环小数，则将循环的部分括在括号内。

如果存在多个答案，只需返回 任意一个 。

对于所有给定的输入，保证 答案字符串的长度小于 104 。

注意，如果分数可以表示为有限长度的字符串，则 必须 返回它。

示例 1：

输入：numerator = 1, denominator = 2
输出："0.5"

示例 2：

输入：numerator = 2, denominator = 1
输出："2"

示例 3：

输入：numerator = 4, denominator = 333
输出："0.(012)"

提示：

  • -231 <= numerator, denominator <= 231 - 1

  • denominator != 0

核心不变量

余数一旦重复出现，就标志着循环节开始；循环节的起点，正是该余数第一次出现时所在的小数位下标。

完整推导

思路推导

  1. 直觉与痛点（手算长除法怎么进行？）

回忆用纸笔算 1/2 的过程：整数部分直接整除（1 / 2 = 0），剩下的余数（1）不断乘 10 再除以分母，依次得到的商就是每一位小数。算法本质就是模拟这个长除法。

  1. 破局思路（哈希表记住每个余数的位置）

长除法什么时候会出现循环？当某个余数第二次出现时，之后产生的所有商必然与第一次出现时完全一致，于是开始循环。

所以我们用一个哈希表记录 余数 -> 该余数第一次出现时对应的小数位下标。每轮先查表：若余数已经出现过，就在那个下标处插入 '('、末尾补 ')' 并结束；否则记录位置，接着 余数 *= 10 取商、取新余数。

以 4/333 为例：反复除下去，余数序列为 4, 40, 67, 4, ...，当余数 4 再次出现时，说明从它第一次对应的位置开始循环，循环节是 012，得到 0.(012)。

  1. 关键追问（符号和溢出怎么处理？）
  • 符号：用 (numerator < 0) ^ (denominator < 0) 判断是否为负，不能用两者相乘（INT_MIN 相乘会溢出）。
  • 溢出：-2^31 取绝对值会溢出，必须在取绝对值之前先转成 long。
  • 有限小数：某轮余数变成 0，说明小数部分已结束，直接返回，绝不能加括号。
  • 分子为 0：直接返回 "0"，避免出现 -0。

Java 实现（fractionToDecimal）

import java.util.HashMap;
import java.util.Map;

class Solution {
    public String fractionToDecimal(int numerator, int denominator) {
        // 分子为 0，答案就是 "0"
        if (numerator == 0) {
            return "0";
        }
        StringBuilder sb = new StringBuilder();
        // 符号：一正一负才为负，用异或避免乘法溢出
        if ((numerator < 0) ^ (denominator < 0)) {
            sb.append('-');
        }
        // 先转 long 再取绝对值，规避 -2^31 取反溢出
        long num = Math.abs((long) numerator);
        long den = Math.abs((long) denominator);

        // 整数部分
        sb.append(num / den);
        long remainder = num % den;
        // 能整除，是有限小数，直接返回
        if (remainder == 0) {
            return sb.toString();
        }

        sb.append('.');
        // 记录「余数 -> 该余数第一次出现时对应的小数位下标」
        Map<Long, Integer> seen = new HashMap<>();
        while (remainder != 0) {
            if (seen.containsKey(remainder)) {
                // 余数重复出现，从记录的起点插入左括号，末尾补右括号
                int idx = seen.get(remainder);
                sb.insert(idx, '(');
                sb.append(')');
                break;
            }
            // 记录当前余数在 sb 中的位置（即下一个商将要写入的下标）
            seen.put(remainder, sb.length());
            remainder *= 10;
            sb.append(remainder / den); // 当前小数位
            remainder %= den;           // 新的余数
        }
        return sb.toString();
    }
}

C++ 实现

#include <string>
#include <unordered_map>
using namespace std;

class Solution {
public:
    string fractionToDecimal(int numerator, int denominator) {
        if (numerator == 0) return "0";

        string res;
        // 符号：一正一负才为负
        if ((numerator < 0) ^ (denominator < 0)) res += '-';

        // 先转 long long 再取绝对值，规避 -2^31 溢出
        long long num = numerator < 0 ? -(long long)numerator : (long long)numerator;
        long long den = denominator < 0 ? -(long long)denominator : (long long)denominator;

        res += to_string(num / den);      // 整数部分
        long long rem = num % den;
        if (rem == 0) return res;         // 有限小数

        res += '.';
        unordered_map<long long, int> seen; // 余数 -> 小数位下标
        while (rem != 0) {
            if (seen.count(rem)) {
                res.insert(seen[rem], "(");
                res += ')';
                break;
            }
            seen[rem] = (int)res.size();
            rem *= 10;
            res += to_string(rem / den);  // 当前小数位
            rem %= den;
        }
        return res;
    }
};

Python 实现

class Solution:
    def fractionToDecimal(self, numerator: int, denominator: int) -> str:
        if numerator == 0:
            return "0"

        res = []
        # 符号：一正一负才为负
        if (numerator < 0) ^ (denominator < 0):
            res.append('-')

        num, den = abs(numerator), abs(denominator)
        res.append(str(num // den))       # 整数部分
        rem = num % den
        if rem == 0:                      # 有限小数
            return ''.join(res)

        res.append('.')
        seen = {}                         # 余数 -> 小数位下标
        while rem != 0:
            if rem in seen:
                res.insert(seen[rem], '(')
                res.append(')')
                break
            seen[rem] = len(res)
            rem *= 10
            res.append(str(rem // den))   # 当前小数位
            rem %= den
        return ''.join(res)

复杂度

  • 时间：O(L)，L 为结果字符串长度。每个余数最多被处理一次，循环次数不超过分母大小且被答案长度 10^4 上限约束。
  • 空间：O(L)，哈希表最多存下每个小数位对应一个余数。
易错点与扩展（面试高频考点）
  1. 符号判断别用乘积：numerator * denominator < 0 在 INT_MIN 时会溢出，用 (numerator < 0) ^ (denominator < 0) 更安全。
  2. INT_MIN 取绝对值溢出：Math.abs(Integer.MIN_VALUE) 结果仍是负数，必须 Math.abs((long) numerator) 先转 long。
  3. 整除要提前返回：余数为 0 时是有限小数，不能加 . 或括号，否则输出错误。
  4. 插入下标的选择：用 sb.length() 记录插入位，它正好是"下一位商"的下标；插入 '(' 后原字符自动右移，无需再修正。
  5. 面试延展：把余数映射到下标是"快慢指针求循环节"的另一种形式，本质与检测链表环一致。
