451. 根据字符出现频率排序

本次复习：
按 M 快速切换薄弱标记
遮住推导与代码，先自己想，再逐段揭示
难度中等核心模式统计频率 + 桶排序按频次降序拼接时间复杂度O(n)空间复杂度O(n)

题目与约束

给定一个字符串 s ，根据字符出现的 频率 对其进行 降序排序 。一个字符出现的 频率 是它出现在字符串中的次数。

返回 已排序的字符串 。如果有多个答案，返回其中任何一个。

示例 1:

输入: s = "tree"
输出: "eert"
解释: 'e'出现两次，'r'和't'都只出现一次。
因此'e'必须出现在'r'和't'之前。此外，"eetr"也是一个有效的答案。

示例 2:

输入: s = "cccaaa"
输出: "cccaaa"
解释: 'c'和'a'都出现三次。此外，"aaaccc"也是有效的答案。
注意"cacaca"是不正确的，因为相同的字母必须放在一起。

示例 3:

输入: s = "Aabb"
输出: "bbAa"
解释: 此外，"bbaA"也是一个有效的答案，但"Aabb"是不正确的。
注意'A'和'a'被认为是两种不同的字符。

提示:

  • 1 <= s.length <= 5 * 105

  • s 由大小写英文字母和数字组成

核心不变量

字符按频率降序排列，只需把每个字符重复「它的频率」次、并按频率桶从高到低依次拼接；频率相同者内部顺序任意。

完整推导

思路推导

  1. 直觉与痛点（直接排序比较次数大）

最容易想到的是把字符装进列表，用比较器按频率排序，再拼起来。但比较排序是 O(n log n)，而频率的取值范围只有 [1, n]，完全可以做得更快。

  1. 破局思路（计数 + 桶排序）

先用哈希表统计每个字符出现次数。然后开 n+1 个桶，桶下标就是频率：把「频率为 f 的字符」放进第 f 个桶。最后从 f = n 往 f = 1 倒序遍历桶，把桶内字符重复 f 次拼接到结果里，就实现了按频率降序。

  1. 为什么正确且高效

频率最大值不超过 n，所以桶数组大小 n+1 足够。整个流程只有「统计一遍 O(n) + 入桶 O(字符种类数) + 倒序拼接 O(n)」，没有比较排序，总复杂度线性。以 "tree" 为例：e→2、r→1、t→1；桶 2 里放 e，桶 1 里放 r、t；倒序拼出 eee？不——e 重复 2 次得 ee，再接 r、t，结果为 eert（或 eetr），均合法。

  1. 小细节

拼接时要「字符重复 f 次」，而不是每个字符只出现一次，否则计数信息就丢了。

Java 实现（HashMap + 桶排序）

import java.util.ArrayList;
import java.util.HashMap;
import java.util.List;
import java.util.Map;

class Solution {
    public String frequencySort(String s) {
        // 1. 统计每个字符的出现次数
        Map<Character, Integer> freq = new HashMap<>();
        for (char c : s.toCharArray()) {
            freq.put(c, freq.getOrDefault(c, 0) + 1);
        }

        // 2. 桶排序：下标为频率，桶里放该频率下的所有字符
        List<Character>[] buckets = new List[s.length() + 1];
        for (Map.Entry<Character, Integer> e : freq.entrySet()) {
            int f = e.getValue();
            if (buckets[f] == null) {
                buckets[f] = new ArrayList<>();
            }
            buckets[f].add(e.getKey());
        }

        // 3. 从高频到低频依次拼接
        StringBuilder sb = new StringBuilder();
        for (int f = buckets.length - 1; f >= 1; f--) {
            if (buckets[f] == null) {
                continue;
            }
            for (char c : buckets[f]) {
                // 字符重复 f 次
                for (int k = 0; k < f; k++) {
                    sb.append(c);
                }
            }
        }
        return sb.toString();
    }
}

C++ 实现

#include <string>
#include <vector>
#include <unordered_map>
using namespace std;

class Solution {
public:
    string frequencySort(string s) {
        // 1. 统计频率
        unordered_map<char, int> freq;
        for (char c : s) {
            freq[c]++;
        }

        // 2. 桶排序：下标为频率
        vector<vector<char>> buckets(s.size() + 1);
        for (auto& kv : freq) {
            buckets[kv.second].push_back(kv.first);
        }

        // 3. 从高频到低频拼接
        string res;
        for (int f = (int)buckets.size() - 1; f >= 1; f--) {
            for (char c : buckets[f]) {
                res.append(f, c); // 字符 c 重复 f 次
            }
        }
        return res;
    }
};

Python 实现

from collections import Counter

class Solution:
    def frequencySort(self, s: str) -> str:
        # 1. 统计频率
        freq = Counter(s)

        # 2. 桶排序：下标为频率
        buckets = [[] for _ in range(len(s) + 1)]
        for ch, f in freq.items():
            buckets[f].append(ch)

        # 3. 从高频到低频拼接
        res = []
        for f in range(len(buckets) - 1, 0, -1):
            for ch in buckets[f]:
                res.append(ch * f)  # 字符 ch 重复 f 次
        return "".join(res)

复杂度

  • 时间：O(n)，其中 n = s.length()。统计一遍字符串，桶排序遍历频率范围与字符集合，整体线性；结果串长度也为 n。
  • 空间：O(n)，桶数组大小为 n+1，加上哈希表与结果字符串，均为线性。
易错点与扩展（面试高频考点）
  1. 拼接时忘记重复 f 次：只追加一次字符会丢掉频率信息，必须内层循环追加 f 次。
  2. 大小写敏感：'A' 与 'a' 是不同字符，用 HashMap<Character,Integer> 天然区分，别错误地 toLowerCase。
  3. 桶数组越界：频率最大为 n，数组必须开 n+1，若开 n 会越界。
  4. 面试追问——改用堆 / 优先队列：可用最大堆按频率弹出，复杂度 O(k log k)（k 为字符种类数），也正确；桶排序在频率范围小时更优。
  5. 扩展——稳定要求：题目允许多个答案，同一频率内部顺序任意；若要求同频按字典序，可在桶内再排序，但不再影响 O(n) 的主流程。
