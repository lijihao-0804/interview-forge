题目信息 内容
难度 中等
核心模式 游程分组 + 字符计数：用一次交换把相邻同字符段接起来
时间复杂度 O(n)
空间复杂度 O(n)

题目与约束

如果字符串中的所有字符都相同，那么这个字符串是单字符重复的字符串。

给你一个字符串 text，你只能交换其中两个字符一次或者什么都不做，然后得到一些单字符重复的子串。返回其中最长的子串的长度。

示例 1：

<strong>输入：</strong>text = "ababa"
<strong>输出：</strong>3

示例 2：

<strong>输入：</strong>text = "aaabaaa"
<strong>输出：</strong>6

示例 3：

<strong>输入：</strong>text = "aaabbaaa"
<strong>输出：</strong>4

示例 4：

<strong>输入：</strong>text = "aaaaa"
<strong>输出：</strong>5

示例 5：

<strong>输入：</strong>text = "abcdef"
<strong>输出：</strong>1

提示：

  • 1 <= text.length <= 20000

  • text 仅由小写英文字母组成。

核心不变量

一次交换能得到的同字符段，要么是把“别处多出来的一个同字符”挪到某个连续段旁边（段长 +1），要么是把“相隔恰好一个其他字符”的两段同字符段连接起来（两段之和 +1）；两者都不能超过该字符的总出现次数。

完整推导

思路推导

  1. 直觉与痛点（交换一次到底能带来什么）

我们想得到最长的“全是同一个字符”的子串。原串里本身就有若干段连续的相同字符（称为“游程”）。一次交换只能改变两个位置，收益无非两种：多接上一个字符，或把被一个“挡路字符”隔开的两段并起来。

  1. 破局思路（先把串压缩成游程）

把 text 扫描成若干段 (字符, 连续长度)。例如 "aaabbaaa" → [(a,3),(b,2),(a,3)]。同时统计每个字符的总出现次数 freq[c]。

  1. 两种候选情形
  • 情形一（段旁加一）：对某一段 (c, len)，如果整串中还有别的 c 可以换来，就能在这一段旁接上 1 个 c，得到长度 len + 1。但也不能超过 freq[c]（字符都用完了就没了），所以贡献是 min(len + 1, freq[c])。
  • 情形二（跨一个字符合并）：若第 i 段的字符是 c，第 i+1 段长度恰为 1（是一个挡路的异字符），第 i+2 段字符又是 c，就可以把这个唯一的挡路字符换成一个 c，让左右两段连起来，长度为 两段之和 + 1，同样受 min(两段和 + 1, freq[c]) 限制。

取所有情形中的最大值即可。

  1. 校验样例
  • "ababa"：游程 a1 b1 a1 b1 a1，freq[a]=3。看中间 b1 夹住的两段 a1，合并后 1+1+1=3 ≤ 3，答案 3。
  • "aaabbaaa"：a3 b2 a3，中间是 b2（长度不是 1），无法一次连接；单段 min(3+1, 6)=4，答案 4。
  • "aaabaaa"：a3 b1 a3，中间 b1 恰为一个，合并 3+3+1=7，但 freq[a]=6，取 min(7,6)=6。

Java 实现（游程扫描 + 计数）

import java.util.ArrayList;
import java.util.List;

class Solution {
    public int maxRepOpt1(String text) {
        int n = text.length();
        int[] freq = new int[26];
        for (int i = 0; i < n; i++) {
            freq[text.charAt(i) - 'a']++;
        }

        // 把字符串压缩成若干 (字符编号, 连续长度) 的游程
        List<int[]> runs = new ArrayList<>();
        for (int i = 0; i < n; ) {
            int j = i;
            while (j < n && text.charAt(j) == text.charAt(i)) {
                j++;
            }
            runs.add(new int[]{text.charAt(i) - 'a', j - i});
            i = j;
        }

        int ans = 0;
        int m = runs.size();
        for (int idx = 0; idx < m; idx++) {
            int c = runs.get(idx)[0];
            int len = runs.get(idx)[1];

            // 情形一：从别处换一个 c 到本段旁边，最多扩 1
            ans = Math.max(ans, Math.min(len + 1, freq[c]));

            // 情形二：本段 与 相隔单个字符的同字符段 合并
            if (idx + 2 < m
                    && runs.get(idx + 1)[1] == 1
                    && runs.get(idx + 2)[0] == c) {
                int merged = len + runs.get(idx + 2)[1];
                ans = Math.max(ans, Math.min(merged + 1, freq[c]));
            }
        }
        return ans;
    }
}

复杂度

  • 时间：O(n)。统计与游程压缩各扫一遍，之后线性遍历游程。
  • 空间：O(n)。最坏情况下每个字符都不同，游程数量为 O(n)。

易错点与扩展（面试高频考点）

  1. 忘记 min(..., freq[c])：当整串的 c 已经全部集中在被考察的段里，就没有“多余的 c”拿来换，此时不能凭空 +1。这是本题最容易错的点。
  2. 挡路字符必须恰好一个：只有中间段长度为 1 才能靠一次交换连接；若为 b2 则需要两次交换，情形二不成立。
  3. 情形一的 +1 是“把别处的一个 c 换过来”，因此要求 freq[c] > len；用 min(len+1, freq[c]) 已自动处理。
  4. 全同字符串："aaaaa" 只有一段，min(6,5)=5 正确，不会错误地返回 6。
  5. 扩展：也可用“滑动窗口保证窗口内最多只有一种字符出现次数等于窗口长度、其余一个字符只出现一次”的双指针变体实现，但游程法更直观且严格线性。

力扣原题

1156. 单字符重复子串的最大长度

C++ 实现

#include <string>
#include <vector>
#include <algorithm>
using namespace std;

class Solution {
public:
    int maxRepOpt1(string text) {
        int n = text.size();
        vector<int> freq(26, 0);
        for (char ch : text) freq[ch - 'a']++;

        // 压缩成 (字符, 连续长度) 的游程
        vector<pair<int, int>> runs;
        for (int i = 0; i < n; ) {
            int j = i;
            while (j < n && text[j] == text[i]) ++j;
            runs.push_back({text[i] - 'a', j - i});
            i = j;
        }

        int ans = 0;
        int m = runs.size();
        for (int idx = 0; idx < m; ++idx) {
            int c = runs[idx].first;
            int len = runs[idx].second;

            // 情形一：段旁接一个同字符
            ans = max(ans, min(len + 1, freq[c]));

            // 情形二：跨单个异字符合并两段同字符
            if (idx + 2 < m && runs[idx + 1].second == 1 && runs[idx + 2].first == c) {
                int merged = len + runs[idx + 2].second;
                ans = max(ans, min(merged + 1, freq[c]));
            }
        }
        return ans;
    }
};

Python 实现

from collections import Counter

class Solution:
    def maxRepOpt1(self, text: str) -> int:
        freq = Counter(text)
        n = len(text)

        # 压缩成 (字符, 连续长度) 的游程
        runs = []
        i = 0
        while i < n:
            j = i
            while j < n and text[j] == text[i]:
                j += 1
            runs.append((text[i], j - i))
            i = j

        ans = 0
        m = len(runs)
        for idx in range(m):
            c, length = runs[idx]

            # 情形一：段旁接一个同字符
            ans = max(ans, min(length + 1, freq[c]))

            # 情形二：跨单个异字符合并两段同字符
            if idx + 2 < m and runs[idx + 1][1] == 1 and runs[idx + 2][0] == c:
                merged = length + runs[idx + 2][1]
                ans = max(ans, min(merged + 1, freq[c]))

        return ans
