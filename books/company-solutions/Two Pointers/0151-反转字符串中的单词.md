# 151. 反转字符串中的单词

| 题目信息 | 内容 |
|---|---|
| 难度 | 中等 |
| 核心模式 | 整体反转 + 逐词反转（双指针原地） |
| 时间复杂度 | O(n) |
| 空间复杂度 | O(n)（输出本身；除输出外 O(1)） |

## 题目与约束

给你一个字符串 `s` ，请你反转字符串中 单词 的顺序。

单词 是由非空格字符组成的字符串。`s` 中使用至少一个空格将字符串中的 单词 分隔开。

返回 单词 顺序颠倒且 单词 之间用单个空格连接的结果字符串。

注意：输入字符串 `s`中可能会存在前导空格、尾随空格或者单词间的多个空格。返回的结果字符串中，单词间应当仅用单个空格分隔，且不包含任何额外的空格。

 

示例 1：

输入：s = "the sky is blue"  
输出："blue is sky the"

示例 2：

输入：s = "  hello world  "  
输出："world hello"  
解释：反转后的字符串中不能存在前导空格和尾随空格。

示例 3：

输入：s = "a good   example"  
输出："example good a"  
解释：如果两个单词间有多余的空格，反转后的字符串需要将单词间的空格减少到仅有一个。

 

提示：

- `1 <= s.length <= 104`

- `s` 包含英文大小写字母、数字和空格 `' '`

- `s` 中 至少存在一个 单词

 

进阶：如果字符串在你使用的编程语言中是一种可变数据类型，请尝试使用 `O(1)` 额外空间复杂度的 原地 解法。

[🔗 前往力扣原题验证 →](https://leetcode.cn/problems/reverse-words-in-a-string/)

## 核心不变量

> 先把字符串规范化（去首尾空格、单词间只留一个空格），再「整体反转 + 每个单词内部再反转」，两次反转叠加等价于只反转单词顺序。

## 完整推导

### 思路推导

1. **直觉与痛点（直接 split 最省事，但空间不达标）**

   最直观的做法是 `s.split()` 按空白切分、逆序后用单个空格拼接。它简单可靠，但会额外分配一个单词列表；而题目进阶要求"原地、`O(1)` 额外空间"。面试里通常期待你能讲出双反转这个技巧。

2. **第一步：原地压缩空格（规范化）**

   用读指针 `i` 和写指针 `write` 在同一字符数组上操作：跳过所有空格，若已写过单词就先补一个空格，再把整个单词逐字符搬到 `write` 处。因为始终有 `write <= i`，写入不会覆盖尚未读取的字符，所以可以在原数组上"就地"完成。做完后 `[0, len)` 就是"无首尾空格、单词间单空格"的串。

   以 `"  hello world  "` 为例，规范化后得到 `"hello world"`，`len = 11`。

3. **第二步：整体反转**

   把 `[0, len)` 整段翻转，`"hello world"` 变成 `"dlrow olleh"`。此时单词顺序确实反了，但每个单词内部也被反了。

4. **第三步：逐词反转修复**

   再以空格为界，把每个单词单独翻转回来：`"dlrow" -> "world"`、`"olleh" -> "hello"`，最终得到 `"world hello"`。整体反转决定"单词顺序"，逐词反转只修复"单词内部字符"，二者叠加正好等于"只把单词顺序倒过来"。扫描三趟均为线性，故整体 `O(n)`。

### Java 实现（原地压缩 + 双反转）

```java
class Solution {
    public String reverseWords(String s) {
        char[] arr = s.toCharArray();
        int n = arr.length;
        int i = 0;      // 读指针
        int write = 0;  // 写指针

        // 第一步：原地压缩空格，得到规范化字符串（无首尾空格、单词间单空格）
        while (i < n) {
            while (i < n && arr[i] == ' ') i++;      // 跳过空格
            if (i == n) break;
            if (write > 0) arr[write++] = ' ';       // 单词之间补一个空格
            while (i < n && arr[i] != ' ') {         // 搬运整个单词
                arr[write++] = arr[i++];
            }
        }
        int len = write;

        // 第二步：整体反转 [0, len)
        reverse(arr, 0, len - 1);

        // 第三步：逐个单词内部反转
        int start = 0;
        for (int k = 0; k <= len; k++) {
            if (k == len || arr[k] == ' ') {          // 遇到空格或结尾
                reverse(arr, start, k - 1);
                start = k + 1;
            }
        }
        return new String(arr, 0, len);
    }

    // 反转字符数组的闭区间 [l, r]
    private void reverse(char[] a, int l, int r) {
        while (l < r) {
            char t = a[l];
            a[l++] = a[r];
            a[r--] = t;
        }
    }
}
```

### 复杂度

- 时间：`O(n)`。压缩空格、整体反转、逐词反转各扫描一遍，都是线性；`n` 为字符串长度。
- 空间：`O(n)`。返回值本身需要 `O(n)`；除输出外只用了字符数组和几个下标，额外辅助空间为 `O(1)`（Java 的 `String` 不可变，需要 `char[]` 承载结果；若语言支持可变字符串可做到真正原地）。

### 易错点与扩展（面试高频考点）

1. **多个连续空格与前导/尾随空格**：直接用 `split(" ")` 会在连续空格处切出空串，必须用 `split("\\s+")` 或像本解一样手动跳过多余空格。
2. **写指针与读指针的关系**：原地搬移时必须保证 `write <= i`，否则会覆盖还没读取的字符；本解中每次写前 `write` 都落后于或等于 `i`，是安全的。
3. **逐词反转的边界**：循环用 `k <= len`，把"结尾"当成一个虚拟空格，否则最后一个单词不会被反转。
4. **面试追问——`O(1)` 空间的意义**：若语言字符串不可变（Java/C#/Python），谈"原地"更多是考察思路；能说清"双反转"和"读写双指针压缩空格"即可，不必强行真做到零辅助空间。
5. **Python 一句话写法**：`" ".join(reversed(s.split()))`，`split()` 自动按任意空白切分并丢弃空串，是工程上最简洁的写法。

## 力扣原题

[151. 反转字符串中的单词](https://leetcode.cn/problems/reverse-words-in-a-string/)

### C++ 实现

```cpp
#include <string>
#include <algorithm>
using namespace std;

class Solution {
public:
    string reverseWords(string s) {
        int n = s.size();
        int i = 0, write = 0;

        // 第一步：原地压缩空格
        while (i < n) {
            while (i < n && s[i] == ' ') i++;
            if (i == n) break;
            if (write > 0) s[write++] = ' ';
            while (i < n && s[i] != ' ') s[write++] = s[i++];
        }
        s.resize(write);

        // 第二步：整体反转
        reverse(s.begin(), s.end());

        // 第三步：逐词反转
        int start = 0;
        for (int k = 0; k <= (int)s.size(); k++) {
            if (k == (int)s.size() || s[k] == ' ') {
                reverse(s.begin() + start, s.begin() + k);
                start = k + 1;
            }
        }
        return s;
    }
};
```

### Python 实现

```python
class Solution:
    def reverseWords(self, s: str) -> str:
        # split() 默认按任意空白字符切分，并自动去掉首尾与多余空格
        return " ".join(reversed(s.split()))
```
