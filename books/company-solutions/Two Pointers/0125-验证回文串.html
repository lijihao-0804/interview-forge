题目信息 内容
难度 简单
核心模式 左右双指针，跳过非字母数字并忽略大小写
时间复杂度 O(n)
空间复杂度 O(1)

题目与约束

如果在将所有大写字符转换为小写字符、并移除所有非字母和非数字字符之后，短语正着读和反着读都一样，则可以认为该短语是一个回文串。

字母和数字都属于字母数字字符。

给你一个字符串 s，如果它是回文串，返回 true；否则，返回 false。

示例 1：

输入: s = "A man, a plan, a canal: Panama"
输出：true
解释："amanaplanacanalpanama" 是回文串。

示例 2：

输入：s = "race a car"
输出：false
解释："raceacar" 不是回文串。

示例 3：

输入：s = " "
输出：true
解释：在移除非字母数字字符之后，s 是一个空字符串 "" 。
     由于空字符串正着反着读都一样，所以是回文串。

提示：

  • 1 <= s.length <= 2 * 10^5
  • s 仅由可打印的 ASCII 字符组成

核心不变量

双指针从两端向中间收缩，遇到非字母数字字符就跳过、比较时忽略大小写；只要出现一对不相等的有效字符即可判定不是回文，指针相遇则说明是回文。

完整推导

思路推导

  1. 直观做法及痛点：先过滤出所有字母数字字符、统一转小写、得到净化字符串 t，再判断 t == reverse(t)。这思路正确，但要额外构造一个 O(n) 的字符串（甚至两份），空间不是最优。

  2. 原地双指针：用 left 指向头、right 指向尾。每次先让 left 向后跳过非字母数字字符，让 right 向前跳过非字母数字字符；然后比较两端的字符（统一转小写）。

  3. 遇到不相等立即失败：若 s[left] 与 s[right] 忽略大小写后不同，直接返回 false；否则 left++、right-- 继续向中间靠拢。直到 left >= right 说明全部对称，返回 true。

以 "A man, a plan, a canal: Panama" 为例，忽略标点空格后是 amanaplanacanalpanama，两端逐对相同，最终为回文。

Java 实现（双指针）

class Solution {
    public boolean isPalindrome(String s) {
        int left = 0, right = s.length() - 1;
        while (left < right) {
            // 左指针跳过非字母数字字符
            while (left < right && !Character.isLetterOrDigit(s.charAt(left))) {
                left++;
            }
            // 右指针跳过非字母数字字符
            while (left < right && !Character.isLetterOrDigit(s.charAt(right))) {
                right--;
            }
            // 统一转小写后比较这对字符
            if (Character.toLowerCase(s.charAt(left)) != Character.toLowerCase(s.charAt(right))) {
                return false;
            }
            left++;
            right--;
        }
        return true;
    }
}

复杂度

  • 时间：O(n)。left、right 各自只朝一个方向移动，每个字符最多被访问一次。
  • 空间：O(1)。全程在原字符串上操作，只用两个指针，无需构造净化后的新字符串。

易错点与扩展（面试高频考点）

  1. 只跳空格是不够的：必须跳过所有非字母数字字符（标点、符号等），用 isLetterOrDigit / isalnum 判断，不能只判空格。
  2. 忽略大小写：比较前两侧都要转小写（或统一大写），否则 'A' 与 'a' 会被误判为不同。
  3. 空串 / 全标点返回 true：内层 while 把两边都跳完后 left >= right，循环结束返回 true，正好符合"空串是回文"。
  4. 内层 while 也要带 left < right：否则遇到全标点或一侧先越界时会数组下标越界。两个内层循环都需带上边界条件。
  5. C++ 的 isalnum 要传 unsigned char：把 char 提升为 int 时若为负值（扩展 ASCII）是未定义行为，应先 (unsigned char) 强转。

C++ 实现

#include <string>
#include <cctype>
using namespace std;

class Solution {
public:
    bool isPalindrome(string s) {
        int left = 0, right = (int)s.size() - 1;
        while (left < right) {
            while (left < right && !isalnum((unsigned char)s[left])) left++;
            while (left < right && !isalnum((unsigned char)s[right])) right--;
            if (tolower((unsigned char)s[left]) != tolower((unsigned char)s[right])) {
                return false;
            }
            left++;
            right--;
        }
        return true;
    }
};

Python 实现

class Solution:
    def isPalindrome(self, s: str) -> bool:
        left, right = 0, len(s) - 1
        while left < right:
            while left < right and not s[left].isalnum():
                left += 1
            while left < right and not s[right].isalnum():
                right -= 1
            if s[left].lower() != s[right].lower():
                return False
            left += 1
            right -= 1
        return True
