# 443. 压缩字符串

| 题目信息 | 内容 |
|---|---|
| 难度 | Medium |
| 核心模式 | 读写双指针原地压缩 |
| 时间复杂度 | O(n) |
| 空间复杂度 | O(1) |

## 题目与约束

给你一个字符数组 `chars` ，请使用下述算法压缩：

从一个空字符串 `s` 开始。对于 `chars` 中的每组 连续重复字符 ：

- 如果这一组长度为 `1` ，则将字符追加到 `s` 中。

- 否则，需要向 `s` 追加字符，后跟这一组的长度。

压缩后得到的字符串 `s` 不应该直接返回 ，需要转储到字符数组 `chars` 中。需要注意的是，如果组长度为 `10` 或 `10` 以上，则在 `chars` 数组中会被拆分为多个字符。

请在 修改完输入数组后 ，返回该数组的新长度。

你必须设计并实现一个只使用常量额外空间的算法来解决此问题。

注意：数组中超出返回长度的字符无关紧要，应予忽略。

 

示例 1：

输入：chars = ["a","a","b","b","c","c","c"]  
输出：6  
解释：分组是 "aa"、"bb" 和 "ccc"，压缩为 "a2b2c3"。  
在原地修改输入数组之后，chars 的前 6 个字符应为 ["a","2","b","2","c","3"]。

示例 2：

输入：chars = ["a"]  
输出：1  
解释：唯一的组是 "a"，因为它是一个单独的字符，所以保持不变。  
在原地修改输入数组后，chars 的第一个字符应为 ["a"]。

示例 3：

输入：chars = ["a","b","b","b","b","b","b","b","b","b","b","b","b"]  
输出：4  
解释：分组是 "a" 和 "bbbbbbbbbbbb"，压缩为"ab12"。  
在对输入数组进行原地修改后，chars 的前 4 个字符应为 ["a","b","1","2"]。

 

提示：

- `1 <= chars.length <= 2000`

- `chars[i]` 可以是小写英文字母、大写英文字母、数字或符号

[🔗 前往力扣原题验证 →](https://leetcode.cn/problems/string-compression/)

## 核心不变量

> 用读指针 `i` 扫描原数组、写指针 `write` 写入压缩结果，且始终有 `write <= i`，因此写回永远不会覆盖还没读到的字符。

## 完整推导

### 思路推导

1. **直觉与痛点（为什么不能新建字符串）**：直接新建一个 `StringBuilder` 拼接，逻辑最简单，但需要 O(n) 额外空间，违反「常量额外空间」的要求。题目允许就地覆盖，且写指针永远不会超过读指针，这就给了原地操作的空间。

2. **破局思路（读写双指针）**：维护两个指针：
   - `i`：读指针，标记当前这一组的起点；
   - `write`：写指针，标记下一个要写入的位置。

   每一轮先固定当前字符 `chars[i]`，用另一个指针 `j` 向后找到这组连续相同字符的终点，得到组长度 `count = j - i`。然后：
   - 先写字符本身：`chars[write++] = chars[i]`；
   - 若 `count > 1`，再把 `count` 转成字符串，逐位写入（`10` 以上会被拆成多个字符）；
   - 最后 `i = j`，进入下一组。

3. **例子走一遍**：`"a","a","b","b","c","c","c"`。第一组 `a` 长 2：写 `a`、`2` → `write=2`；第二组 `b` 长 2：写 `b`、`2` → `write=4`；第三组 `c` 长 3：写 `c`、`3` → `write=6`。返回 6，前 6 位为 `a2b2c3`。

   注意 `write <= i` 恒成立：每组最多写「1 个字符 + 若干位数字」，而数字位数不超过该组长度，所以写入量不会超过已读取量，原数组不会被提前破坏。

### Java 实现（读写双指针）

```java
class Solution {
    public int compress(char[] chars) {
        int n = chars.length;
        int write = 0;   // 写指针
        int i = 0;       // 读指针（当前组的起点）

        while (i < n) {
            int j = i;
            // 找到这一组连续相同字符的终点（不含）
            while (j < n && chars[j] == chars[i]) {
                j++;
            }
            int count = j - i;

            // 先写入字符本身
            chars[write++] = chars[i];

            // 长度大于 1 才写数字，且可能有多位
            if (count > 1) {
                String s = Integer.toString(count);
                for (int k = 0; k < s.length(); k++) {
                    chars[write++] = s.charAt(k);
                }
            }

            i = j; // 处理下一组
        }
        return write;
    }
}
```

### 复杂度

- 时间：O(n)。读指针 `i` 单调前进，`j` 也只会从头扫到尾，每个字符被读常数次，整体线性。
- 空间：O(1)。只在原地改写 `chars`，额外仅用几个整数和（转数字时）一个位数不超过 log n 的临时字符串/变量。

### 易错点与扩展（面试高频考点）

1. **数字逐位写入**：`count` 是 `12` 时必须写成两个字符 `'1'`、`'2'`，不能当成一个整体。用 `Integer.toString`/`str(count)` 再逐位写入最稳妥。
2. **单字符组不写 1**：长度恰为 1 时只写字符，不能补 `'1'`，否则结果错误（示例 2 会变成 `a1`）。
3. **写指针不能越界覆盖未读数据**：务必保证「先读后写」，`write <= i` 是安全的前提。实现上总是先把整组读完再写，天然满足。
4. **返回值是新长度**：返回 `write`，而不是数组长度 `n`；超出 `write` 的尾部应被忽略。
5. **扩展**：若字符集包含数字本身（本题确实允许 `chars[i]` 为数字），压缩格式本身有歧义，但按题目规则仍逐字符处理即可；此外「解压」是逆过程，可用类似双指针还原。

### C++ 实现

```cpp
class Solution {
public:
    int compress(std::vector<char>& chars) {
        int n = chars.size();
        int write = 0;   // 写指针
        int i = 0;       // 读指针

        while (i < n) {
            int j = i;
            // 找到这一组连续相同字符的终点
            while (j < n && chars[j] == chars[i]) {
                ++j;
            }
            int count = j - i;

            // 写入字符本身
            chars[write++] = chars[i];

            // 长度大于 1 时逐位写入数字
            if (count > 1) {
                std::string s = std::to_string(count);
                for (char c : s) {
                    chars[write++] = c;
                }
            }

            i = j;
        }
        return write;
    }
};
```

### Python 实现

```python
class Solution:
    def compress(self, chars: List[str]) -> int:
        n = len(chars)
        write = 0     # 写指针
        i = 0         # 读指针（当前组的起点）

        while i < n:
            j = i
            # 找到这一组连续相同字符的终点
            while j < n and chars[j] == chars[i]:
                j += 1
            count = j - i

            # 写入字符本身
            chars[write] = chars[i]
            write += 1

            # 长度大于 1 时逐位写入数字
            if count > 1:
                for c in str(count):
                    chars[write] = c
                    write += 1

            i = j

        return write
```
