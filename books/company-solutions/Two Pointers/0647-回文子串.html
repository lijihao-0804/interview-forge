题目与约束

给你一个字符串 s ，请你统计并返回这个字符串中 回文子串 的数目。

回文字符串 是正着读和倒过来读一样的字符串。

子字符串 是字符串中的由连续字符组成的一个序列。

示例 1：

<strong>输入：</strong>s = "abc"
<strong>输出：</strong>3
<strong>解释：</strong>三个回文子串: "a", "b", "c"

示例 2：

<strong>输入：</strong>s = "aaa"
<strong>输出：</strong>6
<strong>解释：</strong>6个回文子串: "a", "a", "a", "aa", "aa", "aaa"

提示：

  • 1 <= s.length <= 1000

  • s 由小写英文字母组成

🔗 前往力扣原题验证 →

核心不变量

每个回文子串都有唯一的"中心"（奇数长度是单个字符，偶数长度是两个字符之间的空隙）；从中心向两侧同步扩展，只要两端字符相等，就得到一个新的回文子串。

完整推导

思路推导

  1. 直觉（回文的对称性）

回文串由内向外完全对称。与其枚举所有 O(n²) 个子串再判断回文（总体 O(n³)），不如换个视角：从"中心"往两边生长。

  1. 关键点（中心有几个？）

长度 n 的字符串，回文中心共 2n-1 个： - 奇数长度回文：中心落在某个字符上，共 n 个； - 偶数长度回文：中心落在两个字符之间，共 n-1 个。

  1. 统一枚举技巧

用整数 center 从 0 到 2n-2 遍历： - left = center / 2 - right = left + center % 2

当 center 为偶数时 left == right（奇数回文）；为奇数时 right = left + 1（偶数回文）。一个循环统一处理两种中心。

  1. 小例子（示例 2，s = "aaa"）
  • 中心 0（字符 a）：扩展 ""→"a"、再往外越界，得 1 个；
  • 中心 1（字符 a）："a"、"aa"（左右各扩一位）、再外地越界……逐个数下去；
  • 累计正好得到 6 个。

每成功扩展一次计数器加一即可，因为从中心每向外走一步就是一个新的、更长的回文子串。

  1. 对比 DP

同样的问题也能用区间 DP：dp[i][j] 表示 s[i..j] 是否回文，dp[i][j] = (s[i]==s[j]) && (j-i<2 || dp[i+1][j-1])。时间 O(n²)、空间 O(n²)。中心扩展空间只要 O(1)，更优。

Java 实现（countSubstrings）

class Solution {
    public int countSubstrings(String s) {
        int n = s.length();
        int count = 0;

        // 共 2n-1 个中心，统一处理奇数/偶数长度回文
        for (int center = 0; center < 2 * n - 1; center++) {
            int left = center / 2;
            int right = left + center % 2; // 偶数中心时 left==right，奇数中心时 right=left+1

            // 从中心向两侧扩展，每次成功即多一个回文子串
            while (left >= 0 && right < n && s.charAt(left) == s.charAt(right)) {
                count++;
                left--;
                right++;
            }
        }

        return count;
    }
}

复杂度

  • 时间：O(n²)，共 2n-1 个中心，每个中心最多向两侧扩展 O(n) 次。
  • 空间：O(1)，只用了左右指针与计数器，无需额外数组。

易错点与扩展（面试高频考点）

  1. 中心数量算错：只枚举 n 个字符中心会漏掉全部偶数长度回文，必须用 2n-1 个（或分奇偶两轮分别做）。
  2. right 的初值：right = left + center % 2 是统一写法的关键；若写成 left + 1 会漏掉单个字符的回文。
  3. 扩展条件顺序：left >= 0 && right < n && s[left]==s[right] 三个条件缺一不可，越界判断要放在取值之前。
  4. 计数时机：每成功匹配一次就 count++，而不是在循环外只加一，因为一个中心可以长出多个回文。
  5. 扩展问法：若要求"最长回文子串"（第 5 题），中心扩展同样适用，只是把计数换成记录最大长度与起点；也可用 Manacher 做到 O(n)。

C++ 实现

class Solution {
public:
    int countSubstrings(string s) {
        int n = s.size();
        int count = 0;

        for (int center = 0; center < 2 * n - 1; ++center) {
            int left = center / 2;
            int right = left + center % 2; // 统一奇数/偶数中心

            while (left >= 0 && right < n && s[left] == s[right]) {
                ++count;
                --left;
                ++right;
            }
        }

        return count;
    }
};

Python 实现

class Solution:
    def countSubstrings(self, s: str) -> int:
        n = len(s)
        count = 0

        for center in range(2 * n - 1):
            left = center // 2
            right = left + center % 2  # 统一奇数/偶数中心

            while left >= 0 and right < n and s[left] == s[right]:
                count += 1
                left -= 1
                right += 1

        return count
