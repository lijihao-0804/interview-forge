# 165. 比较版本号

| 题目信息 | 内容 |
|---|---|
| 难度 | 中等 |
| 核心模式 | 双指针逐段解析 |
| 时间复杂度 | O(m + n) |
| 空间复杂度 | O(1) |

## 题目与约束

给你两个 版本号字符串 `version1` 和 `version2` ，请你比较它们。版本号由被点 `'.'` 分开的修订号组成。修订号的值 是它 转换为整数 并忽略前导零。

比较版本号时，请按 从左到右的顺序 依次比较它们的修订号。如果其中一个版本字符串的修订号较少，则将缺失的修订号视为 `0`。

返回规则如下：

- 如果 `version1 < version2` 返回 `-1`，

- 如果 `version1 > version2` 返回 `1`，

- 除此之外返回 `0`。

 

示例 1：

输入：version1 = "1.2", version2 = "1.10"

输出：-1

解释：

version1 的第二个修订号为 "2"，version2 的第二个修订号为 "10"：2 < 10，所以 version1 < version2。

示例 2：

输入：version1 = "1.01", version2 = "1.001"

输出：0

解释：

忽略前导零，"01" 和 "001" 都代表相同的整数 "1"。

示例 3：

输入：version1 = "1.0", version2 = "1.0.0.0"

输出：0

解释：

version1 有更少的修订号，每个缺失的修订号按 "0" 处理。

 

提示：

- `1 <= version1.length, version2.length <= 500`

- `version1` 和 `version2` 仅包含数字和 `'.'`

- `version1` 和 `version2` 都是 有效版本号

- `version1` 和 `version2` 的所有修订号都可以存储在 32 位整数 中

[🔗 前往力扣原题验证 →](https://leetcode.cn/problems/compare-version-numbers/)

## 核心不变量

> 从左到右逐个修订号比较：任一时刻遇到第一个不相等的修订号，它的大小就直接决定整体大小；缺失的修订号一律按 `0` 处理。

## 完整推导

### 思路推导

1. **直觉与痛点（按字符串比较会出错）**

   不能直接比较字符串：`"1.10"` 字典序小于 `"1.2"`，但按版本语义 `10 > 2`，`1.10` 反而更大。也不能简单按点切分后一次性比较，因为两边段数可能不同（如 `"1.0"` 与 `"1.0.0.0"`），缺失段要按 `0` 补齐。

2. **破局思路（双指针边扫边解析）**

   用两个指针 `i`、`j` 分别扫描两个字符串。每一轮：

   - 从 `i` 开始连续读数字，边读边累乘 `num1 = num1*10 + digit`，直到遇到 `.` 或串尾；前导零会在累乘中被自然忽略（`"01"` 解析出来就是 `1`）。
   - 对 `version2` 同理得到 `num2`。
   - 立即比较 `num1` 与 `num2`：谁大就返回 `±1`，不等则继续。
   - 跳过各自的 `.`，进入下一段。

   当某串先耗尽时，它后续的修订号按 `0` 处理；只要另一串还剩余非零修订号，比较就会立刻分出胜负。

3. **为什么缺失段按 0 就对了**

   `while (i < n1 || j < n2)` 保证只要还有一段没处理就继续循环。若 `i` 已到尾，`num1` 保持 0；若此时 `version2` 还有一段且值大于 0，就返回 `-1`；若剩余段全是 0（如 `"1.0.0.0"` 多出来的 0），则继续到双方都处理完，最终返回 0。

   以 `"1.0"` 与 `"1.0.0.0"` 为例：第 1 段 `1 == 1`，第 2 段 `0 == 0`，随后 `version1` 耗尽而 `version2` 还剩 `0`、`0`，`0 == 0`，循环结束返回 0。

### Java 实现（双指针逐段解析）

```java
class Solution {
    public int compareVersion(String version1, String version2) {
        int n1 = version1.length(), n2 = version2.length();
        int i = 0, j = 0;

        // 只要还有任意一段未处理就继续
        while (i < n1 || j < n2) {
            int num1 = 0;
            while (i < n1 && version1.charAt(i) != '.') {
                num1 = num1 * 10 + (version1.charAt(i) - '0'); // 前导零自然被忽略
                i++;
            }

            int num2 = 0;
            while (j < n2 && version2.charAt(j) != '.') {
                num2 = num2 * 10 + (version2.charAt(j) - '0');
                j++;
            }

            if (num1 > num2) return 1;
            if (num1 < num2) return -1;

            // 跳过点号，进入下一段（越界也无害，下一轮条件会拦住）
            i++;
            j++;
        }
        return 0;
    }
}
```

### 复杂度

- 时间：`O(m + n)`。两个指针各自只把所在字符串扫描一遍，`m`、`n` 分别为两串长度。
- 空间：`O(1)`。只用了若干整数与下标变量，没有额外按段切分出的数组（若用 `split` 实现则会有 `O(m+n)` 的额外空间，可作对比说明）。

### 易错点与扩展（面试高频考点）

1. **不能按字符串字典序比较**：`"10" < "2"` 在字典序里成立，但数值上 `10 > 2`，必须先转成整数再比。
2. **前导零**：`"01"` 与 `"001"` 都等于 `1`；用 `num = num*10 + digit` 累乘天然消除前导零，无需特殊处理。
3. **段数不同**：`"1.0"` 与 `"1.0.0.0"` 必须视为相等，缺失段补 `0`；循环条件写成 `i < n1 || j < n2` 才能把多出来的 `0` 段也走完。
4. **跳过点号的边界**：循环体末尾无条件 `i++; j++;` 看似会越界，但下一轮 `while` 条件会拦住；这是常见写法，也可在比较后先判断再自增。
5. **面试追问——`split` 写法**：`"1.2.3".split("\\.")` 在 Java 中要转义点号；`int` 累乘在本题约束（每段可存 32 位整数）内不会溢出，但更稳妥可用 `long` 累积。

### C++ 实现

```cpp
#include <string>
using namespace std;

class Solution {
public:
    int compareVersion(string version1, string version2) {
        int n1 = version1.size(), n2 = version2.size();
        int i = 0, j = 0;

        while (i < n1 || j < n2) {
            int num1 = 0;
            while (i < n1 && version1[i] != '.') {
                num1 = num1 * 10 + (version1[i] - '0');
                i++;
            }

            int num2 = 0;
            while (j < n2 && version2[j] != '.') {
                num2 = num2 * 10 + (version2[j] - '0');
                j++;
            }

            if (num1 > num2) return 1;
            if (num1 < num2) return -1;

            i++;
            j++;
        }
        return 0;
    }
};
```

class Solution:
    def compareVersion(self, version1: str, version2: str) -> int:

        i = j = 0

            num1 = 0
            while i < n1 and version1[i] != '.':
                num1 = num1 * 10 + int(version1[i])
                i += 1

            num2 = 0
            while j < n2 and version2[j] != '.':
                num2 = num2 * 10 + int(version2[j])
                j += 1

            if num1 > num2:
                return 1
            if num1 < num2:
                return -1

            i += 1
            j += 1
        return 0
