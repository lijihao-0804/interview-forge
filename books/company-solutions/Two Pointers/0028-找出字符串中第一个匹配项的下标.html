28. 找出字符串中第一个匹配项的下标

本题学习状态正在读取学习记录…下次复习：—
本次复习：
按 M 快速切换薄弱标记
遮住推导与代码，先自己想，再逐段揭示
难度简单核心模式KMP 前缀函数做线性字符串匹配时间复杂度O(n + m)空间复杂度O(m)

题目与约束

给你两个字符串 haystack 和 needle ，请你在 haystack 字符串中找出 needle 字符串的第一个匹配项的下标（下标从 0 开始）。如果 needle 不是 haystack 的一部分，则返回 -1 。

示例 1：

输入：haystack = "sadbutsad", needle = "sad"
输出：0
解释："sad" 在下标 0 和 6 处匹配。
第一个匹配项的下标是 0 ，所以返回 0 。

示例 2：

输入：haystack = "leetcode", needle = "leeto"
输出：-1
解释："leeto" 没有在 "leetcode" 中出现，所以返回 -1 。

提示：

  • 1 <= haystack.length, needle.length <= 104

  • haystack 和 needle 仅由小写英文字符组成

🔗 前往力扣原题验证 →

核心不变量

next[i] 始终等于 needle[0..i] 的最长相等真前后缀长度；匹配失配时据此回退，主串指针永不后退。

完整推导

思路推导

  1. 直觉与痛点（暴力为什么会慢？）

最直接的做法是枚举每个起点，逐字符比较 needle 与 haystack 的对应片段。以 haystack = "aaaaab"、needle = "aaab" 为例，前几个起点都会一直比较到最后一个字符才失配，每次白白比较了 4 个字符，最坏时间复杂度达到 O(n * m)。症结在于：失配之后，主串指针被迫回退，之前已经匹配上的信息被完全丢弃。

  1. 破局思路（把"已匹配的信息"存起来）

KMP 的核心是预先分析 needle 自身：对每个位置 i，求出 needle[0..i] 的最长相等真前后缀长度，记作 next[i]。这一步只用 needle 自己滚一遍，与 haystack 无关。

例如 needle = "abaabc" 对应的 next = [0,0,1,1,2,0]：当匹配到第 6 个字符失配时，说明前 5 个字符 abaab 已经对上，而它的最长相等前后缀是 ab，于是可以直接把 needle 右移，让开头的 ab 顶上前面的 ab 继续比，无需回退主串。

  1. 关键追问（怎么快速求 next？）

求 next 本身也是"自己匹配自己"：用双指针 i（当前字符）与 j（已匹配前缀长度）。若 needle[i] == needle[j]，则 j++ 并令 next[i] = j；否则令 j = next[j-1] 反复回退，直到能匹配或 j == 0。整个过程 i 单调前进、j 只回退不越界，均摊 O(m)。

  1. 匹配阶段

把 needle 当成"模式串"去扫 haystack：字符相等则 j++；失配则 j = next[j-1] 回退；当 j == m 时说明完整匹配，起点即 i - m + 1，直接返回。

Java 实现（strStr）

class Solution {
    public int strStr(String haystack, String needle) {
        int n = haystack.length(), m = needle.length();
        if (m == 0) return 0;               // 空模式串视为下标 0

        // 1. 计算 needle 的前缀函数 next
        int[] next = new int[m];
        for (int i = 1, j = 0; i < m; i++) {
            while (j > 0 && needle.charAt(i) != needle.charAt(j)) {
                j = next[j - 1];            // 失配则回退到次长前后缀
            }
            if (needle.charAt(i) == needle.charAt(j)) {
                j++;                        // 延长一段公共前后缀
            }
            next[i] = j;
        }

        // 2. 用 next 在主串上线性匹配
        for (int i = 0, j = 0; i < n; i++) {
            while (j > 0 && haystack.charAt(i) != needle.charAt(j)) {
                j = next[j - 1];            // 主串指针 i 不回退，只回退模式串指针
            }
            if (haystack.charAt(i) == needle.charAt(j)) {
                j++;
            }
            if (j == m) {                   // 完整匹配一段
                return i - m + 1;
            }
        }
        return -1;                          // 未找到
    }
}

C++ 实现

#include <string>
#include <vector>
using namespace std;

class Solution {
public:
    int strStr(string haystack, string needle) {
        int n = haystack.size(), m = needle.size();
        if (m == 0) return 0;

        // 构建前缀函数 next
        vector<int> next(m, 0);
        for (int i = 1, j = 0; i < m; i++) {
            while (j > 0 && needle[i] != needle[j]) j = next[j - 1];
            if (needle[i] == needle[j]) j++;
            next[i] = j;
        }

        // 主串上匹配
        for (int i = 0, j = 0; i < n; i++) {
            while (j > 0 && haystack[i] != needle[j]) j = next[j - 1];
            if (haystack[i] == needle[j]) j++;
            if (j == m) return i - m + 1;
        }
        return -1;
    }
};

Python 实现

class Solution:
    def strStr(self, haystack: str, needle: str) -> int:
        n, m = len(haystack), len(needle)
        if m == 0:
            return 0

        # 构建前缀函数 next
        nxt = [0] * m
        j = 0
        for i in range(1, m):
            while j > 0 and needle[i] != needle[j]:
                j = nxt[j - 1]
            if needle[i] == needle[j]:
                j += 1
            nxt[i] = j

        # 主串上匹配，主串指针 i 不回退
        j = 0
        for i in range(n):
            while j > 0 and haystack[i] != needle[j]:
                j = nxt[j - 1]
            if haystack[i] == needle[j]:
                j += 1
            if j == m:
                return i - m + 1
        return -1

复杂度

  • 时间：O(n + m)。构建 next 为 O(m)，匹配为 O(n)；虽然回退是 while，但 j 每次回退都会让后续前进次数减少，总回退次数不超过总前进次数，故整体线性。
  • 空间：O(m)。只额外使用长度为 m 的 next 数组（若把 needle 视作输入，这部分是唯一额外开销）。
易错点与扩展（面试高频考点）
  1. 回退条件必须是 j > 0：写成 j >= 0 会导致 next[-1] 越界，这是最常见的手写 KMP 崩溃点。
  2. next 定义要统一：有的写法把 next[0] = -1（整体右移一位），有的写成"最长相等真前后缀长度"。一定要在同一个实现里自洽，切勿混用。
  3. 返回值细节：匹配完成时主串指针 i 指向匹配段的最后一个字符，起点应是 i - m + 1，不是 i - m。
  4. 暴力法也能过：本题 10^4 规模下 O(n*m) 暴力通常可通过，面试中先讲暴力、再讲 KMP 是更稳妥的表达顺序；若要求线性，则给出 KMP。
  5. 扩展：同一个 next 思想还能求"最短循环节"（m - next[m-1]），以及解决"重复子字符串""最短回文串"等题目，属于高频延伸考点。
