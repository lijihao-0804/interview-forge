# 344. 反转字符串

| 题目信息 | 内容 |
|---|---|
| 难度 | 简单 |
| 核心模式 | 双指针对撞交换 |
| 时间复杂度 | O(n) |
| 空间复杂度 | O(1) |

## 题目与约束

编写一个函数，其作用是将输入的字符串反转过来。输入字符串以字符数组 `s` 的形式给出。

不要给另外的数组分配额外的空间，你必须原地修改输入数组、使用 O(1) 的额外空间解决这一问题。

 

示例 1：

输入：s = ["h","e","l","l","o"]  
输出：["o","l","l","e","h"]

示例 2：

输入：s = ["H","a","n","n","a","h"]  
输出：["h","a","n","n","a","H"]

 

提示：

- `1 <= s.length <= 105`

- `s[i]` 都是 ASCII 码表中的可打印字符

[🔗 前往力扣原题验证 →](https://leetcode.cn/problems/reverse-string/)

## 核心不变量

> 维护左右两个指针，交换 `s[l]` 与 `s[r]` 后向中间收缩；任意时刻 `[0, l)` 与 `(r, n-1]` 都已是反转后的正确内容。

## 完整推导

### 思路推导

1. **直觉与痛点（新建数组最省事，但被禁止）**

   最直接的是把 `s` 倒着复制到一个新数组。但题目明确要求 **原地修改**、额外空间 O(1)，这就堵死了"新建数组/切片反转"的写法，逼我们用双指针就地对调。

2. **双指针对撞**

   设左指针 `l = 0`、右指针 `r = n - 1`。交换 `s[l]` 与 `s[r]`，然后 `l++`、`r--`。每交换一次，最外层的两个位置就永久正确了，问题规模缩小为"中间的区间"。以 `["h","e","l","l","o"]` 为例：

   - 交换 `h` 与 `o` → `["o","e","l","l","h"]`
   - 交换 `e` 与 `l` → `["o","l","l","e","h"]`
   - `l` 追上 `r`，结束。

3. **终止条件**：当 `l >= r` 时停止。元素个数为奇数时中间那个字符无需移动；为偶数时两指针会正好交错。

### Java 实现（reverseString）

```java
class Solution {
    public void reverseString(char[] s) {
        int l = 0, r = s.length - 1;
        // 对撞双指针：交换两端并向中间收缩
        while (l < r) {
            char tmp = s[l];
            s[l] = s[r];
            s[r] = tmp;
            l++;
            r--;
        }
    }
}
```

### 复杂度

- 时间：O(n)，每个元素最多被访问一次，共 `n/2` 次交换。
- 空间：O(1)，只用了一个临时字符和两个下标变量，满足原地要求。

### 易错点与扩展（面试高频考点）

1. **必须原地**：不能用 `new char[]`、`s[::-1]` 之类另开空间；Python 里 `s.reverse()` 或双指针交换才是原地。
2. **循环边界**：用 `l < r`，不要用 `l <= r`（奇数长度时中间元素自交换虽无害但没必要，且暗示边界理解不清）。
3. **字符 vs 字节**：题目是 ASCII 字符数组，按下标交换即可；若面对变长 UTF-8 字节，直接按 byte 反转会破坏多字节字符，需要额外处理。
4. **返回值**：Java/Python 都是原地修改，函数不返回新数组；Python 的签名要求仅修改 `s`，不要 `return` 新列表。
5. **扩展**：把"反转整个字符串"推广为"反转字符串中的元音字母""按单词反转""反转前 k 个字符"，都是双指针 + 局部反转的变形。

## 力扣原题

[344. 反转字符串](https://leetcode.cn/problems/reverse-string/)

### C++ 实现

```cpp
class Solution {
public:
    void reverseString(vector<char>& s) {
        int l = 0, r = (int)s.size() - 1;
        while (l < r) {
            swap(s[l], s[r]);   // 对撞交换
            ++l;
            --r;
        }
    }
};
```

### Python 实现

```python
class Solution:
    def reverseString(self, s: list[str]) -> None:
        l, r = 0, len(s) - 1
        while l < r:                 # 原地对撞交换，不额外开数组
            s[l], s[r] = s[r], s[l]
            l += 1
            r -= 1
```
