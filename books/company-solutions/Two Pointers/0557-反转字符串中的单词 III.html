题目信息 内容
难度 简单
核心模式 定位每个单词区间并原地反转
时间复杂度 O(n)
空间复杂度 O(n)

题目与约束

给定一个字符串 s ，你需要反转字符串中每个单词的字符顺序，同时仍保留空格和单词的初始顺序。

示例 1：

输入：s = "Let's take LeetCode contest"
输出："s'teL ekat edoCteeL tsetnoc"

示例 2：

输入：s = "Mr Ding"
输出："rM gniD"

提示：

  • 1 <= s.length <= 5 * 10^4
  • s 包含可打印的 ASCII 字符。
  • s 不包含任何开头或结尾空格。
  • s 里 至少 有一个词。
  • s 中的所有单词都用一个空格隔开。

核心不变量

空格的位置与数量保持不变，只需把每个「被空格切开的连续字符块」就地翻面。

完整推导

思路推导

  1. 拆解任务：字符串由若干个单词和单个空格组成，单词顺序、空格都不动，只是每个单词内部字符倒序。因此问题拆成「如何界定每个单词的左右边界」+「反转这一段」。

  2. 定位边界（一次扫描）：用 start 记录当前单词的起始下标，从左往右扫描；遇到空格或走到字符串末尾时，[start, i-1] 就是当前单词，反转它，然后令 start = i + 1 进入下一个单词。

  3. 就地反转：用左右双指针 l, r 向中间交换字符，O(单词长度)。整体只遍历一遍字符串，各单词反转段互不重叠，总时间 O(n)。

示例 "Mr Ding"：start=0，扫到空格 i=2，反转 [0,1] 得 "rM"；start=3，到末尾反转 [3,6] 得 "gniD"，结果 "rM gniD"。

Java 实现（原地双指针）

class Solution {
    public String reverseWords(String s) {
        char[] a = s.toCharArray();
        int n = a.length;
        int start = 0;

        for (int i = 0; i <= n; i++) {
            // 遇到空格或到达末尾，说明一个单词结束
            if (i == n || a[i] == ' ') {
                reverse(a, start, i - 1);
                start = i + 1;          // 下一个单词的起点
            }
        }
        return new String(a);
    }

    // 反转闭区间 [l, r]
    private void reverse(char[] a, int l, int r) {
        while (l < r) {
            char t = a[l];
            a[l] = a[r];
            a[r] = t;
            l++;
            r--;
        }
    }
}

复杂度

  • 时间：O(n)，每个字符被访问常数次。
  • 空间：O(n)，toCharArray 与返回的新字符串各占 O(n)；若按「原地修改输入」计额外空间为 O(1)。

易错点与扩展（面试高频考点）

  1. 循环写 i <= n：必须让 i 走到 n（越界位）才能触发最后一个单词的收尾，否则末尾单词不会被反转。
  2. 边界 start = i + 1：用空格后一位作为新单词起点，因为题目保证单词间只有一个空格、无首尾空格，可省去跳过连续空格的逻辑。
  3. 区间是闭区间 [start, i-1]：i 指向空格本身，不属于单词，别把空格也翻进去。
  4. 别用 split 拼接就满足空间：String.join(" ", reversed words) 写法直观但额外空间更大；面试可先给直观版再优化到原地。
  5. 同类对比：151「反转字符串中的单词」反转的是 单词顺序 并处理多余空格；本题只反转 每个单词内部，两者易混，注意区分。

C++ 实现

class Solution {
public:
    string reverseWords(string s) {
        int n = s.size();
        int start = 0;
        for (int i = 0; i <= n; i++) {
            // 遇到空格或到达末尾：反转 [start, i-1]
            if (i == n || s[i] == ' ') {
                reverse(s.begin() + start, s.begin() + i);
                start = i + 1;
            }
        }
        return s;
    }
};

Python 实现

class Solution:
    def reverseWords(self, s: str) -> str:
        # 按单个空格切分，逐词倒序，再用空格拼回
        return ' '.join(word[::-1] for word in s.split(' '))
