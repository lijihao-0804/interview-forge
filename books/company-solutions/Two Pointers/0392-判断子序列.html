392. 判断子序列

本题学习状态正在读取学习记录…下次复习：—
本次复习：
按 M 快速切换薄弱标记
遮住推导与代码，先自己想，再逐段揭示
难度简单核心模式双指针贪心：在 t 中按顺序为 s 的每个字符找匹配时间复杂度O(n)（n 为 t 的长度）空间复杂度O(1)

题目与约束

给定字符串 s 和 t ，判断 s 是否为 t 的子序列。

字符串的一个子序列是原始字符串删除一些（也可以不删除）字符而不改变剩余字符相对位置形成的新字符串。（例如，"ace"是"abcde"的一个子序列，而"aec"不是）。

进阶：

如果有大量输入的 S，称作 S1, S2, ... , Sk 其中 k >= 10亿，你需要依次检查它们是否为 T 的子序列。在这种情况下，你会怎样改变代码？

致谢：

特别感谢 @pbrother 添加此问题并且创建所有测试用例。

示例 1：

输入：s = "abc", t = "ahbgdc"
输出：true

示例 2：

输入：s = "axc", t = "ahbgdc"
输出：false

提示：

  • 0 <= s.length <= 100

  • 0 <= t.length <= 10^4

  • 两个字符串都只由小写字符组成。

🔗 前往力扣原题验证 →

核心不变量

只要能在 t 中从前往后依次找到 s 的每个字符，s 就是 t 的子序列；贪心地「遇到匹配就前进」不会错过更优解。

完整推导

思路推导

  1. 两个指针各自扫描

指针 i 指向 s，指针 j 指向 t。从头遍历 t：若 t[j] == s[i]，说明匹配上一个字符，i 前进；无论是否匹配，j 都前进。

  1. 为什么贪心正确

当 t[j] 能匹配 s[i] 时就选它，不会让后面更难匹配——把匹配点尽量靠前，只会给剩余字符留下更多空间，所以「遇到就配」是最优策略。

  1. 结束条件

当 i 走到 s 末尾，说明 s 的字符全部按序匹配完，返回 true；若 j 先走到 t 末尾仍有字符没配上，返回 false。

  1. 小例子（s="abc", t="ahbgdc"）

在 t 中依次找到 a(0)、b(2)、c(5)，全部匹配 → true。而 "axc" 中的 x 在 t 里根本不出现，i 卡住 → false。

Java 实现（isSubsequence）

class Solution {
    public boolean isSubsequence(String s, String t) {
        int i = 0, j = 0;
        while (i < s.length() && j < t.length()) {
            if (s.charAt(i) == t.charAt(j)) {
                i++; // 匹配上一个字符
            }
            j++;     // t 的指针始终前进
        }
        return i == s.length();
    }
}

C++ 实现

class Solution {
public:
    bool isSubsequence(string s, string t) {
        int i = 0, j = 0;
        while (i < (int)s.size() && j < (int)t.size()) {
            if (s[i] == t[j]) ++i;
            ++j;
        }
        return i == (int)s.size();
    }
};

Python 实现

class Solution:
    def isSubsequence(self, s: str, t: str) -> bool:
        i = j = 0
        while i < len(s) and j < len(t):
            if s[i] == t[j]:
                i += 1
            j += 1
        return i == len(s)

复杂度

  • 时间：O(|t|)，指针 j 最多把整个 t 走一遍。
  • 空间：O(1)，只用两个指针。
易错点与扩展（面试高频考点）
  1. 匹配成功时 j 也要前进：写成 if (match) i++; j++; 或在循环末尾统一 j++，别漏掉 j 的自增导致死循环。
  2. 空串是任意串的子序列：s.length() == 0 时应返回 true，上面的循环天然满足（i == s.length()）。
  3. 进阶（大量 S）：预处理 t，记录每个字符出现的所有下标；对每个 s 用二分查找在对应下标列表中定位下一个匹配位置，单次查询 O(|s| log |t|)。也可预处理 next[i][c] 表示 t 从位置 i 起字符 c 的下一次出现，做到 O(|s|)。
  4. 另一种视角是 DP：判断最长公共子序列长度是否等于 |s|，但那是 O(|s|·|t|)，远不如双指针。
  5. 不要修改原串：本题只判断不构造，双指针就地扫描即可。
