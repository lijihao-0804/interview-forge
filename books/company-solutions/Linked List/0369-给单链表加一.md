# 369. 给单链表加一

| 题目信息 | 内容 |
|---|---|
| 难度 | 中等 |
| 核心模式 | 定位从右往左第一个非 9 节点加一，其后全部置 0 |
| 时间复杂度 | O(n) |
| 空间复杂度 | O(1) |

## 题目与约束

用一个**非空**单链表来表示一个非负整数：每个节点存储一位数字（`0`~`9`），且**最高位位于链表头节点**。请将这个整数**加一**，并以相同形式的单链表返回结果。

可以假设这个整数不含任何前导零，除了数字 `0` 本身。

**示例 1：**

```
输入：head = [1,2,3]
输出：[1,2,4]
解释：123 + 1 = 124。
```

**示例 2：**

```
输入：head = [9,9]
输出：[1,0,0]
解释：99 + 1 = 100，需要新增一个最高位。
```

**示例 3：**

```
输入：head = [0]
输出：[1]
```

**提示：**

- 链表节点数目在范围 `[1, 100]` 内
- `0 <= Node.val <= 9`

## 核心不变量

> 从右往左第一个不等于 9 的节点就是要发生进位的最高位：它自增 1，它右侧的所有 9 全部变成 0；若整条链表全是 9，则在最前面补一个值为 1 的新节点。

## 完整推导

### 思路推导

1. **直觉与痛点**：加一发生在**最末尾**，但进位要向左传递。单链表只能从头往后遍历，无法直接拿到尾节点，也没法从尾巴往左走。直接反转链表再处理、处理完再反转回来，代码繁琐且易错。

2. **换个角度看待进位**：加一之后，只有「末尾连续的一串 9」会变成 0，而它们左边第一个不是 9 的数字会加 1。例如 `1 -> 2 -> 9 -> 9` 加一得到 `1 -> 3 -> 0 -> 0`：末尾两个 9 变 0，前面的 2 变成 3。所以我们真正要找的是**从右往左第一个不等于 9 的节点**。

3. **一趟扫描找到它**：用一个指针从头走到尾，途中凡是 `val != 9` 的节点就记录下来，最后记录下的那个节点就是「最靠右的非 9 节点」。

4. **处理全 9 的进位**：如果整条链表都是 9（比如 `9 -> 9`），就没有非 9 节点可以加一，必须在最前面补一位 `1`。用一个**值为 0 的哑节点**接在头前面，把哑节点当作「最右非 9 节点」的兜底即可：它加一变成 `1`，后面全部置 0，正好得到 `1 -> 0 -> 0`。

### Java 实现（哑节点 + 一次扫描）

```java
/**
 * Definition for singly-linked list.
 * public class ListNode {
 *     int val;
 *     ListNode next;
 *     ListNode() {}
 *     ListNode(int val) { this.val = val; }
 *     ListNode(int val, ListNode next) { this.val = val; this.next = next; }
 * }
 */
class Solution {
    public ListNode plusOne(ListNode head) {
        // 哑节点：若整条链表全为 9，进位需要新增一个最高位
        ListNode dummy = new ListNode(0);
        dummy.next = head;

        // 从右往左找到第一个不等于 9 的节点（用 dummy 兜底全 9 的情况）
        ListNode target = dummy;
        for (ListNode cur = head; cur != null; cur = cur.next) {
            if (cur.val != 9) {
                target = cur;
            }
        }

        // 该节点加一
        target.val += 1;

        // 它右边所有节点必定都是 9，全部置 0
        for (ListNode cur = target.next; cur != null; cur = cur.next) {
            cur.val = 0;
        }

        // dummy 被加一说明原数全为 9，返回 dummy（值为 1）；否则跳过 dummy
        return dummy.val == 1 ? dummy : dummy.next;
    }
}
```

### 复杂度

- 时间：`O(n)`。第一次扫描找非 9 节点，第二次扫描把后续节点置 0，两次都是线性遍历，每次常数操作。
- 空间：`O(1)`。只用了 `dummy`、`target`、`cur` 几个指针，原地修改链表。

### 易错点与扩展（面试高频考点）

1. **漏掉全 9 的边界**：`[9]`、`[9,9,9]` 这类输入必须能在最前面补一位 `1`，不加哑节点很容易返回 `[0]` 而丢掉最高位。
2. **找的是「最右非 9」而不是「头节点」**：有人误以为从尾部开始进位等价于从头处理，写成了只判断头节点，结果 `[1,9,9]` 会算错（应得 `[2,0,0]`）。
3. **原地修改是否会污染输入**：本题允许原地改节点值；若面试要求不修改原链表，需要先拷贝，或在递归回溯时构造新节点。
4. **递归解法**：可以递归到链尾，回溯时判断「加一是否产生进位」——返回一个布尔表示是否继续进位，代码更短但需要 `O(n)` 递归栈空间。
5. **与「数组加一」的对照**：数组加一可以从后往前直接处理；链表因为单向，才需要「找最右非 9」这个等价技巧，二者思路可互相迁移。

### C++ 实现

```cpp
#include <cstddef>
using namespace std;

/**
 * Definition for singly-linked list.
 * struct ListNode {
 *     int val;
 *     ListNode *next;
 *     ListNode() : val(0), next(nullptr) {}
 *     ListNode(int x) : val(x), next(nullptr) {}
 *     ListNode(int x, ListNode *next) : val(x), next(next) {}
 * };
 */
class Solution {
public:
    ListNode* plusOne(ListNode* head) {
        ListNode* dummy = new ListNode(0);
        dummy->next = head;

        // 找到从右往左第一个不等于 9 的节点，dummy 用于兜底全 9 的情况
        ListNode* target = dummy;
        for (ListNode* cur = head; cur != nullptr; cur = cur->next) {
            if (cur->val != 9) {
                target = cur;
            }
        }

        target->val += 1;

        // target 之后的节点都是 9，全部置 0
        for (ListNode* cur = target->next; cur != nullptr; cur = cur->next) {
            cur->val = 0;
        }

        return dummy->val == 1 ? dummy : dummy->next;
    }
};
```

### Python 实现

```python
# Definition for singly-linked list.
# class ListNode:
#     def __init__(self, val=0, next=None):
#         self.val = val
#         self.next = next
from typing import Optional

class Solution:
    def plusOne(self, head: Optional[ListNode]) -> Optional[ListNode]:
        dummy = ListNode(0)
        dummy.next = head

        # 从右往左找第一个不等于 9 的节点，dummy 兜底全 9 的情况
        target = dummy
        cur = head
        while cur:
            if cur.val != 9:
                target = cur
            cur = cur.next

        target.val += 1

        # target 之后的节点都是 9，全部置 0
        cur = target.next
        while cur:
            cur.val = 0
            cur = cur.next

        return dummy if dummy.val == 1 else dummy.next
```
