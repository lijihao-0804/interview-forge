# 203. 移除链表元素

| 题目信息 | 内容 |
|---|---|
| 难度 | 简单 |
| 核心模式 | 虚拟头节点 + 单指针遍历 |
| 时间复杂度 | O(n) |
| 空间复杂度 | O(1) |

## 题目与约束

给你一个链表的头节点 `head` 和一个整数 `val`，请你删除链表中所有满足 `Node.val == val` 的节点，并返回 **新的头节点**。

**示例 1：**

```
输入：head = [1,2,6,3,4,5,6], val = 6
输出：[1,2,3,4,5]
```

**示例 2：**

```
输入：head = [], val = 1
输出：[]
```

**示例 3：**

```
输入：head = [7,7,7,7], val = 7
输出：[]
```

**提示：**

- 列表中的节点数目在范围 `[0, 10^4]` 内
- `1 <= Node.val <= 50`
- `0 <= val <= 50`

## 核心不变量

> 在虚拟头节点 `dummy` 之后，指针 `cur` 之前的所有节点都已保证不含 `val`；每次只检查 `cur.next`，等于 `val` 就跳过它，否则前进。

## 完整推导

### 思路推导

1. **直觉与痛点（头节点不好删）**

   删除链表节点需要先拿到它的 **前驱**。普通节点容易处理，但头节点没有前驱，一旦头节点本身要被删除，就要单独写一段逻辑，边界情况很容易漏。

2. **破局思路（虚拟头节点 dummy）**

   在真正的头节点前面额外造一个「哨兵」节点 `dummy`，令 `dummy.next = head`。这样原本的头节点也有了前驱，删除它就和删除普通节点完全一样，统一了操作。

3. **单指针遍历**

   设 `cur = dummy`。每次看 `cur.next`：

   - 若 `cur.next.val == val`，执行 `cur.next = cur.next.next` 把它跳过（注意 `cur` 不动，因为新的 `cur.next` 可能还要删）；
   - 否则 `cur = cur.next` 前进一格。

   循环直到 `cur.next == null`，最后返回 `dummy.next` 即为新头节点。

4. **小例子验证**

   `head = [1,2,6,3,4,5,6], val = 6`：走到 `2` 时发现 `2.next = 6`，跳过，链表变为 `1→2→3…`；后面 `5.next = 6` 同样跳过，最终得到 `[1,2,3,4,5]`。若目标是 `7` 且整表都是 `7`，则全部跳过，返回 `null`，对应示例 3。

### Java 实现（removeElements）

```java
class Solution {
    public ListNode removeElements(ListNode head, int val) {
        // 虚拟头节点，统一删除逻辑
        ListNode dummy = new ListNode(0);
        dummy.next = head;

        ListNode cur = dummy;
        while (cur.next != null) {
            if (cur.next.val == val) {
                // 跳过被删节点，cur 不前进，继续检查新的 cur.next
                cur.next = cur.next.next;
            } else {
                cur = cur.next;
            }
        }
        return dummy.next;
    }
}
```

### 复杂度

- 时间：`O(n)`。每个节点最多被访问一次，跳过操作是常数时间。
- 空间：`O(1)`。只额外创建了一个虚拟头节点。

### 易错点与扩展（面试高频考点）

1. **忘记返回 `dummy.next`**：真正的新头节点是 `dummy.next` 而不是 `dummy`，直接返回 `dummy` 会多出一个假节点。
2. **删除后 `cur` 不能前进**：命中删除时若同时写 `cur = cur.next`，会漏删连续的相同值节点（如 `[7,7,7]` 删 7 时只删掉一个）。命中时只更新 `cur.next`，`cur` 原地不动。
3. **头节点删除问题**：这正是引入虚拟头节点的原因；不引入的话需要单独 `while (head != null && head.val == val) head = head.next;` 处理，容易出错。
4. **内存泄漏（C/C++）**：C++ 里跳过节点后应 `delete` 掉被删节点，避免内存泄漏；Java/Python 有 GC 不用显式释放。
5. **扩展（递归写法）**：`head.next = removeElements(head.next, val); return head.val == val ? head.next : head;` 代码更短，但递归深度为 `O(n)`，链表很长时有栈溢出风险，面试中可作对比。

## 力扣原题

[203. 移除链表元素](https://leetcode.cn/problems/remove-linked-list-elements/)

### C++ 实现

```cpp
class Solution {
public:
    ListNode* removeElements(ListNode* head, int val) {
        ListNode dummy(0);
        dummy.next = head;
        ListNode* cur = &dummy;
        while (cur->next) {
            if (cur->next->val == val) {
                ListNode* del = cur->next;
                cur->next = cur->next->next; // 跳过被删节点
                delete del;                  // 释放内存
            } else {
                cur = cur->next;
            }
        }
        return dummy.next;
    }
};
```
