# 876. 链表的中间结点

| 题目信息 | 内容 |
|---|---|
| 难度 | 简单 |
| 核心模式 | 快慢指针（一步 vs 两步） |
| 时间复杂度 | O(n) |
| 空间复杂度 | O(1) |

## 题目与约束

给你单链表的头结点 `head` ，请你找出并返回链表的中间结点。

如果有两个中间结点，则返回第二个中间结点。

**示例 1：**

```
输入：head = [1,2,3,4,5]
输出：[3,4,5]
解释：链表只有一个中间结点，值为 3 。
```

**示例 2：**

```
输入：head = [1,2,3,4,5,6]
输出：[4,5,6]
解释：该链表有两个中间结点，值分别为 3 和 4 ，返回第二个结点。
```

**提示：**

- 链表的结点数范围是 `[1, 100]`
- `1 <= Node.val <= 100`

## 核心不变量

> 快指针每次走两步、慢指针每次走一步；当快指针走到链表末尾（`fast == null` 或 `fast.next == null`）时，慢指针恰好停在中间结点。

## 完整推导

### 思路推导

1. **直觉与痛点（先数长度行不行？）**

   最直接的做法是先遍历一遍数出链表长度 `n`，再从头走 `n / 2` 步返回。这需要两趟遍历，而且“长度”这个中间量跟本题要求其实无关。我们想要一趟走完、并且不用额外存储。

2. **破局思路（快慢指针）**

   让 `slow` 和 `fast` 同时从 `head` 出发：`slow` 每轮走 1 步，`fast` 每轮走 2 步。`fast` 的路程始终是 `slow` 的 2 倍，所以当 `fast` 走到尽头时，`slow` 恰好走了一半——也就是中点。

   以 `1→2→3→4→5` 为例：`fast` 依次落在 `1,3,5`，`slow` 依次落在 `1,2,3`，`fast` 到头时 `slow` 停在 `3`（正中间）。

3. **关键追问（偶数个结点返回哪个中点？）**

   题目要求返回**第二个**中间结点。循环条件写成 `fast != null && fast.next != null` 正好满足：当链表长度为偶数时，`fast` 走到最后一个结点时 `fast.next == null` 才停止，此时 `slow` 已经多走一步，落在第二个中点上。

   以 `1→2→3→4→5→6` 为例：`slow` 最终停在 `4`（第二个中间结点），符合要求。

### Java 实现（middleNode）

```java
/**
 * Definition for singly-linked list.
 * public class ListNode {
 *     int val;
 *     ListNode next;
 *     ListNode() {}
 *     ListNode(int val) { this.val = val; }
 *     ListNode(int val, ListNode next) { this.val = val; this.next = next; }
 * }
 */
class Solution {
    public ListNode middleNode(ListNode head) {
        ListNode slow = head;
        ListNode fast = head;
        // 快指针每次走两步，慢指针每次走一步
        while (fast != null && fast.next != null) {
            slow = slow.next;          // 慢指针走一步
            fast = fast.next.next;     // 快指针走两步
        }
        // 快指针到头时，慢指针正好在中间（偶数长度时是第二个中点）
        return slow;
    }
}
```

### 复杂度

- 时间：O(n)，快指针走完整个链表，慢指针走一半，总计一趟线性扫描。
- 空间：O(1)，只用了 `slow`、`fast` 两个指针，没有额外容器。

### 易错点与扩展（面试高频考点）

1. **循环条件别写错**：必须是 `fast != null && fast.next != null`。若写成 `fast.next != null && fast.next.next != null`，偶数长度会返回第一个中点；若漏掉 `fast != null`，空链表/单结点会空指针。
2. **偶数长度语义**：本题要求“第二个中点”，其根源就是 `fast.next != null` 这一判断，务必和题目要求对齐。
3. **空链表防御**：`head == null` 时循环不进入，直接返回 `null`，本题题面保证结点数 ≥ 1，但面试中建议显式考虑。
4. **扩展：删除中间结点**（如 LeetCode 2095）需要用 `fast.next.next` 条件或先维护 `prev` 指针，才能停在待删结点的前驱。
5. **扩展：判断回文链表 / 环形链表**均以快慢指针为核心；找中点后配合反转后半段即可判回文，这是链表面试的高频组合技。

## 力扣原题

[876. 链表的中间结点](https://leetcode.cn/problems/middle-of-the-linked-list/)

### C++ 实现

```cpp
/**
 * Definition for singly-linked list.
 * struct ListNode {
 *     int val;
 *     ListNode *next;
 *     ListNode() : val(0), next(nullptr) {}
 *     ListNode(int x) : val(x), next(nullptr) {}
 *     ListNode(int x, ListNode *next) : val(x), next(next) {}
 * };
 */
class Solution {
public:
    ListNode* middleNode(ListNode* head) {
        ListNode* slow = head;
        ListNode* fast = head;
        while (fast != nullptr && fast->next != nullptr) {
            slow = slow->next;          // 慢指针一步
            fast = fast->next->next;    // 快指针两步
        }
        return slow;
    }
};
```

### Python 实现

```python
# Definition for singly-linked list.
# class ListNode:
#     def __init__(self, val=0, next=None):
#         self.val = val
#         self.next = next
class Solution:
    def middleNode(self, head):
        slow = fast = head
        while fast and fast.next:
            slow = slow.next        # 慢指针一步
            fast = fast.next.next   # 快指针两步
        return slow
```
