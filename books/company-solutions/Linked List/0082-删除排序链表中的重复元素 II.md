# 82. 删除排序链表中的重复元素 II

| 题目信息 | 内容 |
|---|---|
| 难度 | 中等 |
| 核心模式 | 哑结点 + 前驱指针整段跳过重复 |
| 时间复杂度 | O(n) |
| 空间复杂度 | O(1) |

## 题目与约束

给定一个**已排序**的链表的头节点 `head`。

删除原始链表中所有**重复**数字的节点，只留下**不同**的数字。

返回**已排序**的链表。

**示例 1：**

```
输入：head = [1,2,3,3,4,4,5]
输出：[1,2,5]
```

**示例 2：**

```
输入：head = [1,1,1,2,3]
输出：[2,3]
```

**提示：**

- 链表中节点数目在范围 `[0, 300]` 内
- `-100 <= Node.val <= 100`
- 题目数据保证链表已经按升序**排列**

## 核心不变量

> `prev` 始终指向"已确认只出现一次、可以留在结果里的最后一个节点"，`cur` 从它后面开始；一旦发现 `cur` 与后继同值，就把整段相同的节点一次性跳过（`prev.next = 跳过后的位置`），绝不把重复值保留下来。

## 完整推导

### 思路推导

1. **直觉与痛点（为什么普通删除不够？）**

   本题要求"只要出现过一次重复，这个值就一个都不留"，而不是像第 83 题那样"保留一个"。如果用单个 `cur` 指针遇到相等就 `cur.next = cur.next.next`，只能删掉多余的副本，反而会把那个值留下一个——方向就错了。

2. **破局思路（哑结点 + 前驱指针，整段剪除）**

   为了统一处理"头节点本身就被删掉"的情况，先建一个哑结点 `dummy` 指向 `head`。令 `prev` 指向"结果链表已确认的尾部"，`cur = head`：

   - 若 `cur.next != null` 且 `cur.next.val == cur.val`：说明 `cur` 开头的这一段出现了重复。记下 `dupVal = cur.val`，用内层 `while` 把 `cur` 一路推进到第一个值不等于 `dupVal` 的节点，然后 `prev.next = cur`，**整段一次性扔掉**，`prev` 不动。
   - 否则：`cur` 是唯一值，安全地把它纳入结果，`prev = cur`，`cur = cur.next` 继续。

   以 `[1,2,3,3,4,4,5]` 为例：走到第一个 `3` 时发现 `3==3`，内层把 `cur` 推到 `4`，`prev`（此时是 `2`）直接连到 `4`；同理 `4` 这一段也被跳过；最后剩下 `1→2→5`。

3. **关键追问（为什么必须要哑结点？）**

   若头节点自身就是重复段的开头（如 `[1,1,2]`），没有哑结点就找不到"第一个重复段之前的节点"来改写指针，需要额外特判。哑结点让"头节点被删除"变成一次普通的 `prev.next` 赋值，逻辑更统一。

4. **收尾**

   返回 `dummy.next`，它指向结果链表真正的头（可能为 `null`）。

### Java 实现（哑结点 + 前驱指针）

```java
/**
 * Definition for singly-linked list.
 * public class ListNode {
 *     int val;
 *     ListNode next;
 *     ListNode() {}
 *     ListNode(int val) { this.val = val; }
 *     ListNode(int val, ListNode next) { this.val = val; this.next = next; }
 * }
 */
class Solution {
    public ListNode deleteDuplicates(ListNode head) {
        ListNode dummy = new ListNode(0, head); // 哑结点，方便处理头节点被删的情况
        ListNode prev = dummy;                  // 已确认不重复的最后一个节点
        ListNode cur = head;

        while (cur != null) {
            // 发现重复段：当前节点与后继同值
            if (cur.next != null && cur.next.val == cur.val) {
                int dupVal = cur.val;
                // 跳过整段所有等于 dupVal 的节点
                while (cur != null && cur.val == dupVal) {
                    cur = cur.next;
                }
                prev.next = cur; // 一次剪除整段重复
            } else {
                // 唯一值，纳入结果
                prev = cur;
                cur = cur.next;
            }
        }
        return dummy.next;
    }
}
```

### 复杂度

- 时间：`O(n)`。`cur` 只沿链表单向移动，每个节点最多被访问一次，内层 `while` 推进的节点不会回退。
- 空间：`O(1)`。只用了 `dummy`、`prev`、`cur` 等常数个指针，原地修改链接。

### 易错点与扩展（面试高频考点）

1. **误用第 83 题的"保留一个"逻辑**：本题要求出现重复的值**一个都不留**，必须整段跳过，不能只删多余副本。
2. **忘记哑结点导致头节点无法处理**：当 `head` 本身属于重复段（如 `[1,1,2]`）时，没有 `dummy` 就没有"前驱"可改，容易漏删或越界。
3. **内层跳过后忘记 `prev` 不前进**：跳过重复段后 `prev` 保持不变，`prev.next = cur` 才对；若顺手 `prev = cur` 就又把它当成唯一值了。
4. **边界**：空链表、单节点、全相等（如 `[1,1,1]`）都应返回 `null`，可用 `[1,1,1]` 和 `[]` 自测。
5. **对比扩展**：第 83 题（保留一个）用单指针原地去重即可；本题（全删）必须引入前驱/哑结点。两题常被连问，考察对"删一个"与"全删"的区分。

## 力扣原题

[82. 删除排序链表中的重复元素 II](https://leetcode.cn/problems/remove-duplicates-from-sorted-list-ii/)

### C++ 实现

```cpp
/**
 * Definition for singly-linked list.
 * struct ListNode {
 *     int val;
 *     ListNode *next;
 *     ListNode() : val(0), next(nullptr) {}
 *     ListNode(int x) : val(x), next(nullptr) {}
 *     ListNode(int x, ListNode *next) : val(x), next(next) {}
 * };
 */
class Solution {
public:
    ListNode* deleteDuplicates(ListNode* head) {
        ListNode dummy(0, head); // 哑结点
        ListNode* prev = &dummy; // 已确认不重复的最后一个节点
        ListNode* cur = head;

        while (cur != nullptr) {
            if (cur->next != nullptr && cur->next->val == cur->val) {
                int dupVal = cur->val;
                // 跳过整段重复
                while (cur != nullptr && cur->val == dupVal) {
                    cur = cur->next;
                }
                prev->next = cur; // 整段剪除
            } else {
                prev = cur;
                cur = cur->next;
            }
        }
        return dummy.next;
    }
};
```

### Python 实现

```python
# Definition for singly-linked list.
# class ListNode:
#     def __init__(self, val=0, next=None):
#         self.val = val
#         self.next = next
class Solution:
    def deleteDuplicates(self, head: ListNode | None) -> ListNode | None:
        dummy = ListNode(0, head)  # 哑结点
        prev = dummy               # 已确认不重复的最后一个节点
        cur = head

                dup_val = cur.val
                # 跳过整段重复
                while cur and cur.val == dup_val:
                    cur = cur.next
                prev.next = cur  # 整段剪除
            else:
                prev = cur
                cur = cur.next
        return dummy.next
```
