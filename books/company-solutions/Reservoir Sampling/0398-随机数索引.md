# 398. 随机数索引

| 题目信息 | 内容 |
|---|---|
| 难度 | 中等 |
| 核心模式 | 蓄水池抽样：边遍历边以 `1/c` 概率替换答案 |
| 时间复杂度 | O(n) |
| 空间复杂度 | O(1)（额外空间，不含输入数组） |

## 题目与约束

给你一个可能含有 重复元素 的整数数组 `nums` ，请你随机输出给定的目标数字 `target` 的索引。你可以假设给定的数字一定存在于数组中。

实现 `Solution` 类：

- `Solution(int[] nums)` 用数组 `nums` 初始化对象。

- `int pick(int target)` 从 `nums` 中选出一个满足 `nums[i] == target` 的随机索引 `i` 。如果存在多个有效的索引，则每个索引的返回概率应当相等。

 

示例：

```
<strong>输入</strong>
["Solution", "pick", "pick", "pick"]
[[[1, 2, 3, 3, 3]], [3], [1], [3]]
<strong>输出</strong>
[null, 4, 0, 2]

<strong>解释</strong>
Solution solution = new Solution([1, 2, 3, 3, 3]);
solution.pick(3); // 随机返回索引 2, 3 或者 4 之一。每个索引的返回概率应该相等。
solution.pick(1); // 返回 0 。因为只有 nums[0] 等于 1 。
solution.pick(3); // 随机返回索引 2, 3 或者 4 之一。每个索引的返回概率应该相等。
```

 

提示：

- `1 <= nums.length <= 2 * 104`

- `-231 <= nums[i] <= 231 - 1`

- `target` 是 `nums` 中的一个整数

- 最多调用 `pick` 函数 `104` 次

[🔗 前往力扣原题验证 →](https://leetcode.cn/problems/random-pick-index/)

## 核心不变量

> 遍历到第 `c` 个等于 `target` 的元素时，以 `1/c` 的概率把它选为答案（覆盖旧答案），否则保留旧答案；遍历结束时每个 `target` 被选中的概率都恰好是 `1/m`（`m` 为 `target` 出现次数）。

## 完整推导

### 思路推导

1. **直觉与痛点（不知道有几个 target）**

   要"等概率"返回某个 `target` 的下标，前提是知道 `target` 一共出现了几次。可如果先数一遍、再随机取，就要遍历两次；更麻烦的是每次 `pick` 都可能换 target。

2. **破局思路（蓄水池抽样，一趟搞定）**

   维护一个"当前答案" `result` 和"已遇到的 target 个数" `count`。从左到右扫描：

   - 遇到一个等于 `target` 的元素时，`count++`（这是第 `count` 个 target）；
   - 以 `1 / count` 的概率把 `result` 更新成当前下标，以 `1 - 1/count` 的概率保持不动。

   第 1 个 target 一定被选中；第 2 个来时有 `1/2` 概率顶掉前者；第 3 个来时有 `1/3` 概率顶掉……直觉上"越靠后越难挤掉前人"，正好平衡出均匀分布。

3. **为什么是均匀的（小证明）**

   设 `target` 共出现 `m` 次。第 `j` 个元素最终留下的概率 = 它自己被选中的概率 `1/j`，乘以后面 `m - j` 个元素都没把它顶掉的概率：

   `(1/j) × (1 - 1/(j+1)) × … × (1 - 1/m) = (1/j) × (j/m) = 1/m`。

   每个 `target` 都等于 `1/m`，概率相等。

### Java 实现（蓄水池抽样）

```java
import java.util.Random;

class Solution {
    private final int[] nums;
    private final Random rand = new Random();

    public Solution(int[] nums) {
        this.nums = nums;
    }

    public int pick(int target) {
        int result = -1;
        int count = 0;                       // 已经遇到多少个 target
        for (int i = 0; i < nums.length; i++) {
            if (nums[i] == target) {
                count++;
                // rand.nextInt(count) 落在 [0, count)，等于 0 的概率是 1/count
                if (rand.nextInt(count) == 0) {
                    result = i;              // 以 1/count 的概率替换答案
                }
            }
        }
        return result;
    }
}
```

### 复杂度

- 时间：O(n)。每次 `pick` 需要完整扫描一遍数组，无法提前返回。
- 空间：O(1) 额外空间；`nums` 的存储属于输入本身的 O(n)。

### 易错点与扩展（面试高频考点）

1. **不能提前返回**：必须扫完整个数组才能保证每个 `target` 概率相等，中途返回会破坏均匀性。
2. **`count` 的语义**：`count` 只在命中 `target` 时自增，表示"当前是第几个 target"，不是遍历下标。
3. **随机范围写对**：`rand.nextInt(count)` 产生 `[0, count)` 的整数，判 `== 0` 即概率 `1/count`；写成 `nextInt(100) < 100/count` 之类容易出错。
4. **哈希表替代方案**：预处理 `Map<值, 下标列表>`，`pick` 时在列表中随机取一个，查询 O(1)，但建表要 O(n) 空间；数据量大、内存敏感时蓄水池更省。
5. **随机源共享**：`Random` 对象应在构造时创建并被多次 `pick` 复用，避免每次调用新建导致种子相近。

## 力扣原题

[398. 随机数索引](https://leetcode.cn/problems/random-pick-index/)

### C++ 实现

```cpp
#include <vector>
#include <cstdlib>
using namespace std;

class Solution {
    vector<int> nums;
public:
    Solution(vector<int>& nums) {
        this->nums = nums;
    }

    int pick(int target) {
        int result = -1;
        int count = 0;
        for (int i = 0; i < (int)nums.size(); i++) {
            if (nums[i] == target) {
                count++;
                if (rand() % count == 0) {   // 概率 1/count
                    result = i;
                }
            }
        }
        return result;
    }
};
```

### Python 实现

```python
import random


class Solution:
    def __init__(self, nums: list[int]):
        self.nums = nums

    def pick(self, target: int) -> int:
        result = -1
        count = 0
        for i, v in enumerate(self.nums):
            if v == target:
                count += 1
                if random.randrange(count) == 0:   # 概率 1/count
                    result = i
        return result
```
