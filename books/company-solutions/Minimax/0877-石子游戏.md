# 877. 石子游戏

| 题目信息 | 内容 |
|---|---|
| 难度 | 中等 |
| 核心模式 | 博弈论 / 奇偶位划分（结论恒为真） |
| 时间复杂度 | O(1) |
| 空间复杂度 | O(1) |

## 题目与约束

Alice 和 Bob 用几堆石子在做游戏。一共有偶数堆石子，**排成一行**；每堆都有 **正** 整数颗石子，数目为 `piles[i]` 。

游戏以谁手中的石子最多来决出胜负。石子的 **总数** 是 **奇数** ，所以没有平局。

Alice 和 Bob 轮流进行，**Alice 先开始** 。每回合，玩家从行的 **开始** 或 **结束** 处取走整堆石头。这种情况一直持续到没有更多的石子堆为止，此时手中 **石子最多** 的玩家 **获胜** 。

假设 Alice 和 Bob 都发挥出最佳水平，当 Alice 赢得比赛时返回 `true` ，当 Bob 赢得比赛时返回 `false` 。

**示例 1：**

```
输入：piles = [5,3,4,5]
输出：true
解释：
Alice 先开始，只能拿前 5 颗或后 5 颗石子 。
假设他取了前 5 颗，这一行就变成了 [3,4,5] 。
如果 Bob 拿走前 3 颗，那么剩下的是 [4,5]，Alice 拿走后 5 颗赢得 10 分。
如果 Bob 拿走后 5 颗，那么剩下的是 [3,4]，Alice 拿走后 4 颗赢得 9 分。
这表明，取前 5 颗石子对 Alice 来说是一个胜利的举动，所以返回 true 。
```

**示例 2：**

```
输入：piles = [3,7,2,3]
输出：true
```

**提示：**

- `2 <= piles.length <= 500`
- `piles.length` 是 **偶数**
- `1 <= piles[i] <= 500`
- `sum(piles[i])` 是 **奇数**

## 核心不变量

> 石子堆数为偶数时，Alice 可以强迫自己拿光“所有偶数下标”的堆，或“所有奇数下标”的堆；这两类之和必不相等（总和为奇数），她选较大的一类即可必胜。

## 完整推导

### 思路推导

1. **直觉与痛点（真的要用 DP 博弈吗？）**

   一般区间取石子问题需要 minimax 区间 DP：`dp[i][j]` 表示当前玩家在区间 `[i, j]` 中相对对手能取得的最大分差。但那是在任意堆数下的通用解法，复杂度 `O(n²)`。本题给了两个极强的特殊条件：**堆数为偶数**、**总数为奇数**，这注定存在更简单的结论。

2. **破局思路（奇偶位划分）**

   把堆按位置编号 `0, 1, 2, ..., n-1`（`n` 为偶数）。分成两组：
   - 偶数下标组：`piles[0], piles[2], piles[4], ...`
   - 奇数下标组：`piles[1], piles[3], piles[5], ...`

   两组各有 `n/2` 堆。Alice 先手，她能**指定**自己整局只取某一组：因为两端恰好一端是偶数下标、一端是奇数下标（`n` 为偶数时 `n-1` 是奇数），她第一手取走一端，之后就总能“跟着”保持同一奇偶性拿下去，Bob 无论怎么取，都会把另一种奇偶的位置暴露给她。

3. **关键追问（为什么一定赢？）**

   由于总和是奇数，两组之和不可能相等。设偶数下标组之和为 `S_even`、奇数下标组为 `S_odd`，则 `S_even ≠ S_odd`，必有一组更大。Alice 开局就选总和更大的那一组，把这组全部收入囊中；Bob 只能拿到另一组。于是 Alice 得分严格多于 Bob，**必胜**。

   例如 `piles = [5,3,4,5]`：偶数下标和 `5+4=9`，奇数下标和 `3+5=8`，Alice 选偶数下标组拿 9 分，稳赢。

   结论：在本题约束下，答案**恒为 `true`**，直接返回即可。

### 易错点与扩展（面试高频考点）

1. **别over-engineer**：看到“博弈/最优策略”就条件反射写区间 DP 是常见陷阱；本题三个限制条件（偶数堆、正数、总数为奇数）正是为了让结论坍缩成恒 `true`，能一两句话讲清证明才是满分表现。
2. **证明要讲“可强制”**：关键不是“Alice 想拿哪组”，而是“Alice 能强制自己拿光某一组”。需要点明两端分属不同奇偶性、且她能持续跟住同一奇偶性。
3. **总和为奇数保证无平局**：若允许平局（如总和为偶数），两组和可能相等，结论就不成立；这是条件不可或缺的原因。
4. **扩展：一般化场景**（如 LeetCode 1140 石子游戏 II、486 预测赢家）就需要真正的区间 DP：`dp[i][j] = max(piles[i] - dp[i+1][j], piles[j] - dp[i][j-1])`，用“当前玩家相对对手的最大分差”转移，最终看 `dp[0][n-1] > 0`。
5. **面试追问“如果 Bob 先手呢？”**：同样成立，先手方永远能拿到较优的奇偶组，先手必胜——这说明本题本质是“先手必胜”的奇偶配对博弈。
