# 277. 搜寻名人

| 题目信息 | 内容 |
|---|---|
| 难度 | 中等 |
| 核心模式 | 淘汰法 + 一次验证（双指针思想） |
| 时间复杂度 | O(n) |
| 空间复杂度 | O(1) |

## 题目与约束



[🔗 前往力扣原题验证 →](https://leetcode.cn/problems/find-the-celebrity/)

## 核心不变量

> 一次 `knows(a, b)` 询问必然能淘汰一个人：若 `a` 认识 `b`，则 `a` 不可能是名人；若 `a` 不认识 `b`，则 `b` 不可能是名人。用 `n-1` 次询问淘汰到只剩一个候选人，再花 `O(n)` 次验证即可。

## 完整推导

### 思路推导

1. **直觉与痛点（暴力验证太贵）**

   最直接的做法是对每个人 `i` 都验证一遍"是否所有人认识他、且他不认识任何人"，每次验证要看 `2n` 条关系，总体 `O(n²)` 次询问。人数一多，调用次数就爆了，题目还要求尽量少调用接口。

2. **关键观察（一次询问必淘汰一人）**

   对任意两人 `a`、`b`，问一次 `knows(a, b)`：
   - 若返回 `true`：`a` 认识 `b`，那么 `a` **一定不是名人**（名人不认识任何人）→ 淘汰 `a`；
   - 若返回 `false`：`a` 不认识 `b`，那么 `b` **一定不是名人**（名人应被所有人认识）→ 淘汰 `b`。

   也就是说，每问一次，一定能从两人中排除一个人。

3. **淘汰出候选（双指针收缩）**

   维护一个"候选人" `candidate`，初始为 `0`。让 `candidate` 依次和 `i = 1, 2, ..., n-1` 比较：只要 `knows(candidate, i)` 为真，就说明 `candidate` 不合格，把 `candidate` 换成 `i`。走完一遍，最多 `n-1` 次询问后只剩唯一候选人。

   小例子（示例 1）：`candidate=0`，`knows(0,1)=true` → `candidate=1`；再比较 `knows(1,2)=false` → 保持 `1`。候选人为 `1`。

4. **必须再验证一次**

   淘汰法只保证：**如果名人存在，那么它一定是最后的 `candidate`**；但它无法排除"根本没有名人"的情况。所以还要遍历所有人验证：对每个 `i ≠ candidate`，都必须满足 `knows(candidate, i) == false` 且 `knows(i, candidate) == true`，否则返回 `-1`。

### Java 实现（findCelebrity）

```java
/* The knows API is defined in the parent class Relation.
      boolean knows(int a, int b); */

public class Solution extends Relation {
    public int findCelebrity(int n) {
        // 第一步：淘汰法找出唯一候选人
        int candidate = 0;
        for (int i = 1; i < n; i++) {
            if (knows(candidate, i)) {
                // candidate 认识 i，说明 candidate 不可能是名人
                candidate = i;
            }
        }

        // 第二步：验证候选人是否真的是名人
        for (int i = 0; i < n; i++) {
            if (i == candidate) {
                continue;
            }
            // 候选人不能认识别人；且别人必须认识候选人
            if (knows(candidate, i) || !knows(i, candidate)) {
                return -1;
            }
        }
        return candidate;
    }
}
```

### 复杂度

- 时间：`O(n)`，淘汰阶段最多 `n-1` 次询问，验证阶段最多 `2n` 次询问，总计不超过 `3n` 次调用。
- 空间：`O(1)`，只用了 `candidate` 等常数个变量。

### 易错点与扩展（面试高频考点）

1. **漏掉验证步骤**：淘汰法只能保证"若存在名人则必为候选人"，不验证就无法发现"没有名人"的情况，示例 2 会被错误地返回一个假名人。
2. **验证要查两个方向**：既要 `knows(candidate, i) == false`，也要 `knows(i, candidate) == true`，少查任一方向都会漏判。
3. **候选人初始为 0，循环从 1 开始**：避免自己和自己比较。
4. **`i == candidate` 要跳过**：验证阶段名人与自己无需比较（题目约定 `graph[i][i] == 1`）。
5. **调用次数**：淘汰 `n-1` 次 + 验证最多 `2n` 次，总计 ≤ `3n`，正好满足进阶要求。

```cpp
class Solution {

    int findCelebrity(int n) {
        // 淘汰法找唯一候选人

        for (int i = 1; i < n; ++i) {

                candidate = i; // candidate 认识 i，淘汰 candidate

            }

        return candidate;
    }
};
```
