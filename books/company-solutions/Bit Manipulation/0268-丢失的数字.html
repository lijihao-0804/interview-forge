题目与约束

给定一个包含 [0, n] 中 n 个数的数组 nums ，找出 [0, n] 这个范围内没有出现在数组中的那个数。

示例 1：

输入：nums = [3,0,1]

输出：2

解释：n = 3，因为有 3 个数字，所以所有的数字都在范围 [0,3] 内。2 是丢失的数字，因为它没有出现在 nums 中。

示例 2：

输入：nums = [0,1]

输出：2

解释：n = 2，因为有 2 个数字，所以所有的数字都在范围 [0,2] 内。2 是丢失的数字，因为它没有出现在 nums 中。

示例 3：

输入：nums = [9,6,4,2,3,5,7,0,1]

输出：8

解释：n = 9，因为有 9 个数字，所以所有的数字都在范围 [0,9] 内。8 是丢失的数字，因为它没有出现在 nums 中。

提示：

  • n == nums.length

  • 1 <= n <= 104

  • 0 <= nums[i] <= n

  • nums 中的所有数字都 独一无二

进阶：你能否实现线性时间复杂度、仅使用额外常数空间的算法解决此问题?

核心不变量

把完整集合 0..n 与数组 nums 中的每个数全部异或一遍：除缺失数外，其余每个数都出现两次，成对异或为 0，最后剩下的就是缺失数。

完整推导

思路推导

  1. 直觉与痛点（怎么找那个"落单"的数？）

数组里有 [0, n] 中的 n 个数，范围里一共 n+1 个数，正好缺了一个。如果能把"完整集合 0..n"和数组 nums 放在一起看，那么除了缺失的那个数，其余每个数都会出现两次。

  1. 异或的性质（专治成对问题）

异或满足 a ^ a = 0、a ^ 0 = a，且满足交换律、结合律。把完整集合与数组元素全部异或在一起，成对出现的数两两抵消为 0，最后唯一剩下的就是那个只出现一次的缺失数。

  1. 小例子（nums = [3, 0, 1]）

完整集合是 0, 1, 2, 3。依次异或：0 ^ 3 ^ 1 ^ 0 ^ 2 ^ 1 ^ 3。其中 0 与 0、1 与 1、3 与 3 各自抵消，最后只剩 2，即答案。

  1. 等价写法（求和作差）

缺失数 = n(n+1)/2 - sum(nums)。同样 O(n) 时间、O(1) 空间。但异或法不需要担心大数求和溢出，更优雅。

Java 实现（missingNumber）

class Solution {
    public int missingNumber(int[] nums) {
        int n = nums.length;
        int x = 0;
        // 同时异或下标 i 与 nums[i]，相当于把完整集合 0..n-1 与数组抵消
        for (int i = 0; i < n; i++) {
            x ^= i ^ nums[i];
        }
        // 完整集合还差最后一个数 n，别忘了异或它
        x ^= n;
        return x;
    }
}

复杂度

  • 时间：O(n)，只需一次线性遍历，每个元素做常数次异或。
  • 空间：O(1)，只用一个整数累加异或结果。

易错点与扩展（面试高频考点）

  1. 别忘了异或 n：循环里抵消了 0..n-1，但完整集合是 0..n，最后必须再异或 n，否则答案错误。
  2. 循环同时异或 i 和 nums[i]：i 代表完整集合的下标，nums[i] 代表实际数组元素，两者都要参与。
  3. 求和法的溢出风险：n(n+1)/2 在大 n 下可能溢出 int；本题 n <= 10^4 无碍，但更大数据需用 long，而异或法无此问题。
  4. 其他解法对比：哈希集合 O(n) 时间但要 O(n) 空间；排序 O(n log n)。只有异或/求和满足进阶的"常数空间"要求。
  5. 题目保证数字唯一：因此每个数字最多出现一次，不存在多次重复的干扰。

C++ 实现

class Solution {
public:
    int missingNumber(vector<int>& nums) {
        int n = nums.size();
        int x = 0;
        // 同时异或下标 i 与 nums[i]
        for (int i = 0; i < n; ++i) {
            x ^= i ^ nums[i];
        }
        // 补上完整集合里的 n
        x ^= n;
        return x;
    }
};

Python 实现

class Solution:
    def missingNumber(self, nums: list[int]) -> int:
        n = len(nums)
        x = 0
        # 同时异或下标 i 与 nums[i]
        for i in range(n):
            x ^= i ^ nums[i]
        # 补上完整集合里的 n
        x ^= n
        return x
