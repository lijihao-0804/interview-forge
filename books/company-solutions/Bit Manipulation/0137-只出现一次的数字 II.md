# 137. 只出现一次的数字 II

| 题目信息 | 内容 |
|---|---|
| 难度 | 中等 |
| 核心模式 | 位运算：逐位统计出现次数并对 3 取模（状态机） |
| 时间复杂度 | O(n) |
| 空间复杂度 | O(1) |

## 题目与约束

给你一个整数数组 `nums`，除某个元素仅出现**一次**外，其余每个元素都恰出现**三次**。请你找出并返回那个只出现了一次的元素。

你必须设计并实现线性时间复杂度的算法且使用常数级空间来解决此问题。

**示例 1：**

```
输入：nums = [2,2,3,2]
输出：3
```

**示例 2：**

```
输入：nums = [0,1,0,1,0,1,99]
输出：99
```

**提示：**

- `1 <= nums.length <= 3 * 10^4`
- `-2^31 <= nums[i] <= 2^31 - 1`
- `nums` 中，除某个元素仅出现**一次**外，其余每个元素都恰出现**三次**

## 核心不变量

> 把所有数按二进制位独立考虑：对任意一位，出现三次的数会让这一位的 1 的个数增加 3（模 3 为 0），只有那个只出现一次的数会留下"余数"；把所有位对 3 取模的余数拼起来，就是这个唯一元素。

## 完整推导

### 思路推导

1. **直觉与痛点（异或不再够用）**

   在"其余元素出现两次"的版本里，异或能整体抵消。但这里其余元素出现**三次**，三次相同的数异或结果是它本身，无法抵消。需要一种"逢三归零"的计数机制。

2. **破局思路（按位统计模 3）**

   对第 `b` 位（`0 ≤ b ≤ 31`），统计所有数在该位上 1 的个数 `cnt`。因为除答案外每个数都出现三次，它们对该位的贡献是 3 的倍数，所以 `cnt % 3` 恰好等于答案在该位上的值（0 或 1）。把 32 位逐一求出，就能还原答案。

   以 `nums = [2,2,3,2]`（二进制 `10,10,11,10`）为例，最低位 1 出现 1 次（`3` 贡献），`1 % 3 = 1`；次低位 1 出现 4 次，`4 % 3 = 1`。拼起来是 `11`，即 3。

3. **关键追问（能否一遍扫描、只用两个变量？）**

   可以。为每一位维护一个 0→1→2→0 的小状态机，用两个整数的对应位分别表示"已经累积到 1 次 / 2 次"。每读入一个数 `x`：

   - `ones = (ones ^ x) & ~twos`
   - `twos = (twos ^ x) & ~ones`

   逻辑是：`ones` 记录当前该位出现 1 次的位；遇到新数若该位为 1 就进位到 `twos`（2 次）；再进一次就两者同时清零（3 次即 0 次）。最终 `ones` 的各个位就是答案，且 32 位一起并行处理，天然支持负数（补码按位一致）。

### Java 实现（位运算状态机）

```java
class Solution {
    public int singleNumber(int[] nums) {
        int ones = 0;  // 该位累计出现 1 次
        int twos = 0;  // 该位累计出现 2 次
        for (int x : nums) {
            // 先更新 ones：把 x 的 1 位加进来，但已经在 twos 里的位不计
            ones = (ones ^ x) & ~twos;
            // 再更新 twos：把 x 的 1 位加进来，但已经在新的 ones 里的位不计
            twos = (twos ^ x) & ~ones;
        }
        // 出现 3 次的位会在 ones/twos 中归零，只剩出现 1 次的位
        return ones;
    }
}
```

### 复杂度

- 时间：`O(n)`。遍历一次数组，每次只做常数个位运算（32 位并行完成）。
- 空间：`O(1)`。只使用 `ones`、`twos` 两个整型变量。

### 易错点与扩展（面试高频考点）

1. **两行更新顺序不能颠倒**：必须先更新 `ones` 再更新 `twos`，且第二行用的是**新的** `ones`；否则状态机会错乱，出现 3 次的位无法归零。
2. **`~twos` / `~ones` 是取反掩码**：用"与上非"来屏蔽已经进入下一状态的位，写漏取反会导致计数错误。
3. **逐位统计法也很好写**：`for b in 0..31: cnt = Σ((x >>> b) & 1); if cnt % 3 != 0: ans |= 1 << b;` 时间 `O(32n) = O(n)`，逻辑最直观，面试可先用它讲清原理，再写状态机优化。
4. **负数的处理**：状态机基于补码按位运算，负数不需要特殊处理；但逐位统计法在语言层面要注意用**无符号右移**（Java `>>>`、C++ 转 `unsigned`），Python 的 `>>` 是算术右移，直接用逐位统计会受无限符号位干扰，故 Python 更适合状态机写法。
5. **扩展——出现两次的版本**：若其余元素出现两次，直接全部异或即可；出现三次则本状态机；可进一步推广到"出现 k 次"，用 `k` 个状态位或计数数组实现。

## 力扣原题

### C++ 实现

```cpp
#include <vector>
using namespace std;

class Solution {
public:
    int singleNumber(vector<int>& nums) {
        int ones = 0, twos = 0;
        for (int x : nums) {
            ones = (ones ^ x) & ~twos;
            twos = (twos ^ x) & ~ones;
        }
        return ones;
    }
};
```

### Python 实现

```python
class Solution:
    def singleNumber(self, nums: list[int]) -> int:
        ones = 0  # 累计出现 1 次的位
        twos = 0  # 累计出现 2 次的位
        for x in nums:
            ones = (ones ^ x) & ~twos
            twos = (twos ^ x) & ~ones
        return ones
```
