题目与约束

给你两个二进制字符串 a 和 b，以二进制字符串的形式返回它们的和。

示例 1：

输入：a = "11", b = "1"
输出："100"

示例 2：

输入：a = "1010", b = "1011"
输出："10101"

提示：

  • 1 <= a.length, b.length <= 10^4
  • a 和 b 仅由字符 '0' 或 '1' 组成
  • 字符串如果不是 "0"，就不含前导零

核心不变量

两个指针分别从 a、b 的末位往前扫，每一位三数相加（a 位 + b 位 + 进位），当前位填 sum % 2，新进位为 sum / 2；任一字符串扫完就当作补 0。

完整推导

思路推导

  1. 直觉与痛点（不能转成整数）

长度可达 10^4 位，早就超过 64 位整数范围，直接 Integer.parseInt 或 long 都会溢出/报错。所以只能在字符串层面逐位相加，就像小学列竖式做加法。

  1. 破局思路（从末位对齐，逐位加 + 进位）

设两个指针 i 指向 a 的末尾、j 指向 b 的末尾，进位 carry = 0。每轮取 a 当前位（越界记 0）和 b 当前位（越界记 0），与 carry 相加得到 sum：

  • 当前位结果 sum % 2；
  • 新的进位 sum / 2（0 或 1）；
  • i--、j-- 继续向左。

以 a = "11", b = "1" 为例：i 指 1、j 指 1，和为 2，填 0 进位 1；i 指 1、j 越界记 0，加进位得 2，填 0 进位 1；i 越界、j 越界，只剩进位 1，填 1。倒序拼接得 "100"。

  1. 关键追问（什么时候结束？）

当 i < 0 && j < 0 && carry == 0 时结束。特别地，最后可能还剩一个进位（如 11 + 1），必须补上，否则结果少一位。由于是低位先算，结果需要反转后返回。

  1. 易错点提示
  • 字符转数字是 c - '0'，别写成 (int) c。
  • 循环条件要覆盖"某串已扫完但另一串还剩"以及"最后进位"两种情况。
  • 结果要反转，或改用头插/数组倒着写。

Java 实现（双指针竖式加法）

class Solution {
    public String addBinary(String a, String b) {
        StringBuilder sb = new StringBuilder();
        int i = a.length() - 1, j = b.length() - 1;
        int carry = 0;

        // 只要还有位没算完，或还有进位，就继续
        while (i >= 0 || j >= 0 || carry != 0) {
            int sum = carry;
            if (i >= 0) sum += a.charAt(i--) - '0'; // 取 a 的当前位
            if (j >= 0) sum += b.charAt(j--) - '0'; // 取 b 的当前位
            sb.append((char) ('0' + (sum & 1)));    // 当前位 = sum % 2
            carry = sum >> 1;                        // 进位 = sum / 2
        }

        // 低位先算，结果需反转
        return sb.reverse().toString();
    }
}

复杂度

  • 时间：O(max(m, n))，m、n 为两串长度，每个字符位只处理一次。
  • 空间：O(1)，除返回的字符串外只用常数个变量（StringBuilder 的空间即结果本身）。

易错点与扩展（面试高频考点）

  1. 忘记最后的进位：循环条件必须是 i >= 0 || j >= 0 || carry != 0，漏掉 carry != 0 会在 "11" + "1" 这类用例上少一位。
  2. 结果方向搞反：从低位往高位算，拼出来是逆序的，必须 reverse。
  3. 字符与数字混用：'0' + sum 得到的是字符，sum + '0' 才是正确写法；反过来 c - '0' 才是取数值。
  4. 面试追问——能不能不用 reverse？ 可以：先算出结果长度 max(m,n)+1，用 char[] 从末尾往前填，最后跳过可能的前导 0。
  5. 面试追问——十进制大数相加（LeetCode 415） 是同一套模板，只需把 % 2 / 2 换成 % 10 / 10。

67. 二进制求和

C++ 实现

#include <string>
#include <algorithm>
using namespace std;

class Solution {
public:
    string addBinary(string a, string b) {
        string res;
        int i = (int)a.size() - 1, j = (int)b.size() - 1;
        int carry = 0;
        while (i >= 0 || j >= 0 || carry != 0) {
            int sum = carry;
            if (i >= 0) sum += a[i--] - '0';
            if (j >= 0) sum += b[j--] - '0';
            res.push_back(char('0' + (sum & 1))); // 当前位
            carry = sum >> 1;                      // 进位
        }
        reverse(res.begin(), res.end());
        return res;
    }
};

Python 实现

class Solution:
    def addBinary(self, a: str, b: str) -> str:
        i, j = len(a) - 1, len(b) - 1
        carry = 0
        res = []
        while i >= 0 or j >= 0 or carry:
            s = carry
            if i >= 0:
                s += int(a[i])
                i -= 1
            if j >= 0:
                s += int(b[j])
                j -= 1
            res.append(str(s % 2))   # 当前位
            carry = s // 2           # 进位
        return ''.join(reversed(res))
