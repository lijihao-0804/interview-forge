# 231. 2 的幂

| 题目信息 | 内容 |
|---|---|
| 难度 | 简单 |
| 核心模式 | 位运算：n & (n-1) 消去最低位的 1 |
| 时间复杂度 | O(1) |
| 空间复杂度 | O(1) |

## 题目与约束

给你一个整数 `n`，请你判断该整数是否是 2 的幂次方。如果是，返回 `true` ；否则，返回 `false` 。

如果存在一个整数 `x` 使得 `n == 2x` ，则认为 `n` 是 2 的幂次方。

 

示例 1：

输入：n = 1  
输出：true  
解释：20 = 1

示例 2：

输入：n = 16  
输出：true  
解释：24 = 16

示例 3：

输入：n = 3  
输出：false

 

提示：

- `-231 <= n <= 231 - 1`

 

进阶：你能够不使用循环/递归解决此问题吗？

[🔗 前往力扣原题验证 →](https://leetcode.cn/problems/power-of-two/)

## 核心不变量

> `n` 是 2 的幂，当且仅当 `n > 0` 且它的二进制表示中恰好只有一个 `1`。

## 完整推导

### 思路推导

1. **先看 2 的幂长什么样。** 在二进制里，2 的幂永远是「一个 1 后面跟着若干 0」：`1 = 1`、`2 = 10`、`4 = 100`、`8 = 1000`……也就是说，它只有**一个**二进制位是 1。
2. **`n - 1` 的妙用。** 对一个只含一个 1 的数减 1，会把那个最低位的 1 变成 0，并把它右边的所有 0 变成 1。例如 `8 = 1000`，`7 = 0111`。于是 `n & (n - 1)` 会把最低位的 1 消掉。
3. **小例子。**
   - `n = 8 (1000)`：`n-1 = 7 (0111)`，`8 & 7 = 0` → 只有一个 1 → `true`。
   - `n = 6 (110)`：`n-1 = 5 (101)`，`6 & 5 = 100 ≠ 0` → 有多个 1 → `false`。
   因此判据就是 `n > 0 && (n & (n - 1)) == 0`。这里用 `n > 0` 顺手排除 0 和所有负数。

### Java 实现（位运算 n & (n-1)）
```java
class Solution {
    public boolean isPowerOfTwo(int n) {
        // n > 0 排除 0 与负数；n & (n-1) == 0 说明二进制中只有一个 1
        return n > 0 && (n & (n - 1)) == 0;
    }
}
```

### 复杂度
- 时间：O(1)，只做了一次减法、一次按位与和一次比较，与 `n` 的大小无关。
- 空间：O(1)，只用了常数个变量。

### 易错点与扩展（面试高频考点）

1. **千万别漏掉 `n > 0`。** `0` 不满足（`0 & -1 == 0` 会被误判为 `true`），负数如 `-2147483648`（最小的 32 位整数，二进制是 `1000...0`）也会因只有一个 1 而被误判。必须先判正。
2. **`n = 1` 要返回 `true`。** 因为 `1 = 2^0`，是合法的 2 的幂，别漏掉指数为 0 的情况。
3. **有符号溢出。** 当 `n` 是 `int` 且为负时，`n - 1` 可能在边界处溢出，但用 `&&` 的短路特性先判断 `n > 0`，负数和 0 根本不会走到减法，安全。
4. **另一种等价写法。** `n > 0 && (n & -n) == n`：`-n` 是补码下的相反数，`n & -n` 会保留最低位的 1，若恰好等于 `n` 说明只有一个 1。
5. **进阶要求「不用循环/递归」。** 上述位运算正是标准答案，时间复杂度 O(1)，直接满足进阶。
