题目与约束

DNA序列 由一系列核苷酸组成，缩写为 'A', 'C', 'G' 和 'T'.。

  • 例如，"ACGAATTCCG" 是一个 DNA序列 。

在研究 DNA 时，识别 DNA 中的重复序列非常有用。

给定一个表示 DNA序列 的字符串 s ，返回所有在 DNA 分子中出现不止一次的 长度为 10 的序列(子字符串)。你可以按 任意顺序 返回答案。

示例 1：

输入：s = "AAAAACCCCCAAAAACCCCCCAAAAAGGGTTT"
输出：["AAAAACCCCC","CCCCCAAAAA"]

示例 2：

输入：s = "AAAAAAAAAAAAA"
输出：["AAAAAAAAAA"]

提示：

  • 0 <= s.length <= 105

  • s[i]``==``'A'、'C'、'G' or 'T'

核心不变量

长度固定为 10 的窗口每次右移一位；用一个集合记录已出现过的窗口，另一个集合记录出现次数 ≥ 2 的窗口，两者分离即可不重复地收集答案。

完整推导

思路推导

  1. 直觉与痛点（重复子串如何识别？）

题目只要找「长度恰为 10、出现至少两次」的子串。最直接的想法：枚举所有长度为 10 的子串，统计各自出现次数。痛点是若每个窗口都截取新字符串，虽然可行，但要留意「同一子串不能重复加入答案」。

  1. 破局思路（用两个集合分工）

维护一个 seen 集合存「已经见过的窗口」，一个 repeated 集合存「确认重复的窗口」。从左到右滑动窗口，每步取长度 10 的子串：若它已在 seen 中，说明至少第二次出现，放进 repeated；否则放入 seen。因为 repeated 是集合，天然去重。

  1. 关键追问（为什么是 O(n)？）

窗口有 n-9 个，每次截取与哈希的比较代价在固定长度 10 下视为常数，所以整体 O(n)。示例 "AAAAACCCCCAAAAACCCCCCAAAAAGGGTTT" 中，前 10 位 "AAAAACCCCC" 与后移一位的 "CCCCCAAAAA" 各出现两次，正好被两次收进 repeated。

  1. 扩展（滚动哈希 / 位压缩）

若把 A/C/G/T 编码成 2 个比特，一个 10 位窗口恰好是 20 比特，可用一个 int 在 O(1) 内完成「滑动更新」：cur = ((cur << 2) | code) & ((1 << 20) - 1)，再用整数集合统计。这样避免了每步截取字符串，常数更小，是标签里 Rolling Hash / Bit Manipulation 的思路来源。

Java 实现（findRepeatedDnaSequences）

import java.util.ArrayList;
import java.util.HashSet;
import java.util.List;
import java.util.Set;

class Solution {
    public List<String> findRepeatedDnaSequences(String s) {
        Set<String> seen = new HashSet<>();      // 已出现过的窗口
        Set<String> repeated = new HashSet<>();  // 出现次数 >= 2 的窗口
        int n = s.length();

        // 窗口长度固定为 10，右端点 i 从 9 开始才有完整窗口
        for (int i = 0; i + 10 <= n; i++) {
            String sub = s.substring(i, i + 10);
            // add 返回 false 说明之前已存在，即第二次（及以上）出现
            if (!seen.add(sub)) {
                repeated.add(sub);
            }
        }

        return new ArrayList<>(repeated);
    }
}

复杂度

  • 时间：O(n)。共 n-9 个窗口，每个窗口的截取与哈希在固定长度 10 下是常数代价。
  • 空间：O(n)。两个集合最多各存 O(n) 个长度 10 的字符串。

易错点与扩展（面试高频考点）

  1. 答案去重：同一重复子串可能出现三次以上，必须用集合收集结果，不能见到重复就 add 到列表，否则会有重复项。
  2. 循环边界：条件是 i + 10 <= n（等价 i <= n - 10），写成 i < n - 9 时注意字符串很短（n < 10）时不能越界，最好用 i + 10 <= n 这种更直观的写法。
  3. n < 10 的退化情况：窗口根本凑不满，循环不执行，返回空列表，符合题意。
  4. 不要漏掉「第三次出现」：第一次进 seen，第二次进 repeated，第三次及以后因已在 repeated 中会被集合自动忽略，逻辑正确。
  5. 扩展（滚动哈希 / 位压缩）：面试可主动提 2 bit × 10 = 20 bit 的编码方案，把每个窗口压成一个 int，用 & 0xFFFFF 掩码滑动更新，做到常数更小的线性扫描；这与标签中的 Rolling Hash、Bit Manipulation 相呼应。

C++ 实现

#include <string>
#include <vector>
#include <unordered_set>

class Solution {
public:
    std::vector<std::string> findRepeatedDnaSequences(std::string s) {
        std::unordered_set<std::string> seen;
        std::unordered_set<std::string> repeated;

        for (int i = 0; i + 10 <= (int)s.size(); ++i) {
            std::string sub = s.substr(i, 10);
            // insert 返回 pair，second 为 false 表示已存在
            if (!seen.insert(sub).second) {
                repeated.insert(sub);
            }
        }

        return std::vector<std::string>(repeated.begin(), repeated.end());
    }
};

Python 实现

from typing import List


class Solution:
    def findRepeatedDnaSequences(self, s: str) -> List[str]:
        seen = set()
        repeated = set()

        for i in range(len(s) - 9):
            sub = s[i:i + 10]
            if sub in seen:
                repeated.add(sub)
            else:
                seen.add(sub)

        return list(repeated)
