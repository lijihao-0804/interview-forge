题目信息 内容
难度 中等
核心模式 回溯 + 排序剪枝（k 个等和桶）
时间复杂度 O(k^n)（最坏上界，强剪枝后远低于此）
空间复杂度 O(n + k)

题目与约束

给定一个整数数组 nums 和一个正整数 k，找出是否有可能把这个数组分成 k 个非空子集，其总和都相等。

示例 1：

输入： nums = [4, 3, 2, 3, 5, 2, 1], k = 4
输出： True
说明： 有可能将其分成 4 个子集（5），（1,4），（2,3），（2,3）等于总和。

示例 2:

输入: nums = [1,2,3,4], k = 3
输出: false

提示：

  • 1 <= k <= len(nums) <= 16

  • 0 < nums[i] < 10000

  • 每个元素的频率在 [1,4] 范围内

🔗 前往力扣原题验证 →

核心不变量

把每个数字依次放进 k 个桶，只要所有桶最终都恰好等于 target = sum / k 且任意时刻都不超载，就存在合法划分。

完整推导

思路推导

  1. 预处理判定：所有元素之和 sum 若不能被 k 整除，直接返回 false；否则每个子集的目标和 target = sum / k。若最大元素都大于 target，也必然无解。

  2. 降序排序：把 nums 从大到小排序。大数先放能更快触发「超载」冲突，使搜索树尽早被剪掉，是本题最重要的优化。

  3. 回溯搜索：维护长度为 k 的桶和数组 buckets，递归地把第 idx 个数尝试放进某个桶（不超 target），放完后递归下一个数；一旦某个分支成功即返回，失败则回溯撤销。

  4. 两处关键剪枝： - 相同桶跳过：若 buckets[i] == buckets[i-1]，说明前面的同和桶已经试过并失败，跳过以消除对称重复。 - 空桶失败即终止：若把当前数放进一个空桶后整个分支失败，则无需再试其它空桶（空桶彼此等价），直接 break。

小例子：nums = [4,3,2,3,5,2,1], k = 4，sum = 20，target = 5。降序 [5,4,3,3,2,2,1]：5 单独一桶，4+1、3+2、3+2 各凑成 5，四桶齐平，返回 true。

Java 实现（canPartitionKSubsets）

import java.util.Arrays;

class Solution {
    public boolean canPartitionKSubsets(int[] nums, int k) {
        int sum = 0;
        for (int x : nums) {
            sum += x;
        }
        // 1. 总和必须能被 k 整除
        if (sum % k != 0) {
            return false;
        }
        int target = sum / k;

        // 2. 降序排序：大数优先，冲突更早暴露
        Arrays.sort(nums);
        reverse(nums);
        if (nums[0] > target) {
            return false; // 单个元素就超过目标和
        }

        int[] buckets = new int[k];
        return backtrack(nums, 0, buckets, target);
    }

    private boolean backtrack(int[] nums, int idx, int[] buckets, int target) {
        if (idx == nums.length) {
            return true; // 所有数都放完，各桶必然都等于 target
        }
        int cur = nums[idx];
        for (int i = 0; i < buckets.length; i++) {
            // 剪枝：相同和的桶不必重复尝试
            if (i > 0 && buckets[i] == buckets[i - 1]) {
                continue;
            }
            if (buckets[i] + cur > target) {
                continue;
            }
            buckets[i] += cur;
            if (backtrack(nums, idx + 1, buckets, target)) {
                return true;
            }
            buckets[i] -= cur; // 回溯

            // 剪枝：放进空桶仍失败，则其它空桶同样无望
            if (buckets[i] == 0) {
                break;
            }
        }
        return false;
    }

    private void reverse(int[] a) {
        int i = 0, j = a.length - 1;
        while (i < j) {
            int t = a[i];
            a[i] = a[j];
            a[j] = t;
            i++;
            j--;
        }
    }
}

复杂度

  • 时间：最坏上界 O(k^n)——每个数有 k 个桶可选；由于降序、相同桶跳过与空桶终止等剪枝，实际搜索量远小于上界。
  • 空间：O(n + k)，递归栈深度为 n，桶数组长度为 k（不计排序的 O(n) 辅助空间）。

易错点与扩展（面试高频考点）

  1. 漏判整除：sum % k != 0 必须最先判断，否则后面的搜索注定徒劳。
  2. 不排序导致超时：不降序排序，搜索树会爆炸；降序是提升性能的关键。
  3. 漏掉相同桶剪枝：buckets[i] == buckets[i-1] 能消掉大量对称重复状态，缺了它常 TLE。
  4. 漏掉空桶终止剪枝：把数放进空桶后失败，说明当前数无法安放，break 能显著减枝。
  5. 非空子集：题目要求每个子集非空，target 分裂正确时回溯天然保证每桶至少放一个数；另注意 k <= len(nums) 的约束。

C++ 实现

class Solution {
    bool backtrack(vector<int>& nums, int idx, vector<int>& buckets, int target) {
        if (idx == (int)nums.size()) {
            return true; // 所有数放完，各桶都等于 target
        }
        int cur = nums[idx];
        for (int i = 0; i < (int)buckets.size(); i++) {
            if (i > 0 && buckets[i] == buckets[i - 1]) continue; // 相同桶去重
            if (buckets[i] + cur > target) continue;             // 超载剪枝
            buckets[i] += cur;
            if (backtrack(nums, idx + 1, buckets, target)) return true;
            buckets[i] -= cur;                                   // 回溯
            if (buckets[i] == 0) break;                          // 空桶失败即终止
        }
        return false;
    }

public:
    bool canPartitionKSubsets(vector<int>& nums, int k) {
        int sum = 0;
        for (int x : nums) sum += x;
        if (sum % k != 0) return false;
        int target = sum / k;

        sort(nums.begin(), nums.end(), greater<int>()); // 降序排序
        if (nums[0] > target) return false;

        vector<int> buckets(k, 0);
        return backtrack(nums, 0, buckets, target);
    }
};

Python 实现

class Solution:
    def canPartitionKSubsets(self, nums: list[int], k: int) -> bool:
        total = sum(nums)
        if total % k != 0:
            return False
        target = total // k

        nums.sort(reverse=True)          # 降序：大数优先
        if nums[0] > target:
            return False

        buckets = [0] * k

        def backtrack(idx):
            if idx == len(nums):
                return True
            cur = nums[idx]
            for i in range(k):
                if i > 0 and buckets[i] == buckets[i - 1]:
                    continue                            # 相同桶去重
                if buckets[i] + cur > target:
                    continue                            # 超载剪枝
                buckets[i] += cur
                if backtrack(idx + 1):
                    return True
                buckets[i] -= cur                       # 回溯
                if buckets[i] == 0:
                    break                               # 空桶失败即终止
            return False

        return backtrack(0)
