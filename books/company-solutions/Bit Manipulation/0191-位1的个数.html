题目与约束

给定一个正整数 n，编写一个函数，获取一个正整数的二进制形式并返回其二进制表达式中 设置位 的个数（也被称为汉明重量）。

示例 1：

输入：n = 11
输出：3
解释：输入的二进制串 1011 中，共有 3 个设置位。

示例 2：

输入：n = 128
输出：1
解释：输入的二进制串 10000000 中，共有 1 个设置位。

示例 3：

输入：n = 2147483645
输出：30
解释：输入的二进制串 1111111111111111111111111111101 中，共有 30 个设置位。

提示：

  • 1 <= n <= 2^31 - 1

进阶： 如果多次调用这个函数，你将如何优化你的算法？

核心不变量

每执行一次 n &= (n - 1)，就恰好把 n 最低位上的那个 1 变成 0，其余位保持不变；因此执行次数就等于 1 的个数。

完整推导

思路推导

  1. 直觉与痛点（逐位检查太慢）

最朴素的写法是循环 32 次，看每一位是不是 1：(n >> i) & 1。虽然正确，但不管有几位 1 都要检查 32 次，且对「稀疏」的 1 完全是浪费。

  1. 破局思路（只和 1 的个数相关）

观察一个二进制数减去 1 会发生什么：最低位的 1 变成 0，它右边的所有 0 全部变成 1。例如 1011000 - 1 = 1010111。此时再做 n & (n - 1)，由于低位全被消掉，结果正好是「抹掉最低位 1」：1011000 & 1010111 = 1010000。

  1. 小例子验证

以 n = 11 = 1011 为例：

  • 1011 & 1010 = 1010，计数 1；
  • 1010 & 1001 = 1000，计数 2；
  • 1000 & 0111 = 0000，计数 3；
  • n 变为 0，循环结束，答案 3，与示例一致。
  1. 收尾

只要 n != 0 就继续，每次消去一个 1，所以循环次数 = 1 的个数，最优。

Java 实现（hammingWeight）

public class Solution {
    // you need to treat n as an unsigned value
    public int hammingWeight(int n) {
        int count = 0;
        // 每轮消去最低位的 1，直到 n 变为 0
        while (n != 0) {
            n &= (n - 1); // 抹掉最低位的 1
            count++;
        }
        return count;
    }
}

复杂度

  • 时间：O(1)。循环次数等于 1 的个数 k，最坏 k = 32，是与位宽相关的常数，视为常数时间。
  • 空间：O(1)。只使用 count 一个额外变量。

易错点与扩展（面试高频考点）

  1. 无符号语义：Java 的 int 是有符号的，高位可能是符号位，但 n &= (n - 1) 对有符号、无符号都成立，不必特殊处理；只需保证循环条件是 n != 0 而非 n > 0（若把 n 当无符号，n > 0 在某些语言里会出问题）。
  2. 不要用 while (n > 0) 判断有符号数：当最高位为 1 时 n 在 Java 里是负数，n > 0 会直接跳过。用 n != 0 更稳妥。
  3. 进阶：内建函数：多次调用可直接用 Integer.bitCount(n)（Java）、__builtin_popcount（C++）、bin(n).count('1')（Python），底层是分治掩码或查表。
  4. 扩展：分治统计（Divide and Conquer）：把 32 位按 1、2、4、8、16 分组，用掩码 0x55555555、0x33333333、0x0F0F0F0F、0x00FF00FF、0x0000FFFF 逐层把相邻组的 1 个数加起来，5 步完成，正是本题标签里的分治思想。
  5. 扩展：海量调用优化：若频繁调用，可预计算每 8 位（0~255）的 1 的个数查表，对 4 个字节分别查表求和，O(1) 且常数极小。

C++ 实现

class Solution {
public:
    int hammingWeight(int n) {
        int count = 0;
        while (n != 0) {
            n &= (n - 1); // 抹掉最低位的 1
            ++count;
        }
        return count;
    }
};

Python 实现

class Solution:
    def hammingWeight(self, n: int) -> int:
        count = 0
        while n:
            n &= n - 1  # 消去最低位的 1
            count += 1
        return count
