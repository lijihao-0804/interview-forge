# 89. 格雷编码

| 题目信息 | 内容 |
|---|---|
| 难度 | 中等 |
| 核心模式 | 镜像反射构造（等价于 i ^ (i >> 1)） |
| 时间复杂度 | O(2^n) |
| 空间复杂度 | O(1)（不计返回结果） |

## 题目与约束

n 位格雷码序列 是一个由 `2n` 个整数组成的序列，其中：

- 每个整数都在范围 `[0, 2n - 1]` 内（含 `0` 和 `2n - 1`）

- 第一个整数是 `0`

- 一个整数在序列中出现 不超过一次

- 每对 相邻 整数的二进制表示 恰好一位不同 ，且

- 第一个 和 最后一个 整数的二进制表示 恰好一位不同

给你一个整数 `n` ，返回任一有效的 n 位格雷码序列 。

<strong>输出：</strong>[0,1,3,2]
<strong>解释：</strong>
[0,1,3,2] 的二进制表示是 [00,01,11,10] 。
- 0<strong><em>0</em></strong> 和 0<em><strong>1</strong></em> 有一位不同
- <em><strong>0</strong></em>1 和 <em><strong>1</strong></em>1 有一位不同
- 1<em><strong>1</strong></em> 和 1<em><strong>0</strong></em> 有一位不同
- <em><strong>1</strong></em>0 和 <em><strong>0</strong></em>0 有一位不同
[0,2,3,1] 也是一个有效的格雷码序列，其二进制表示是 [00,10,11,01] 。
- <em><strong>0</strong></em>0 和 <em><strong>1</strong></em>0 有一位不同
- 1<em><strong>0</strong></em> 和 1<em><strong>1</strong></em> 有一位不同

提示：

- `1 <= n <= 16`

## 核心不变量

> 长度为 `2^n` 的格雷码，可把 `n-1` 位的序列整体反转并给每个数补上最高位 `1` 后拼到原序列之后；这样拼接处与首尾恰好都只差一位。

## 完整推导

### 思路推导

1. **直觉与痛点（直接枚举相邻只差一位很难）**

   要手工保证"相邻、首尾都恰好差一位"并不直观。但格雷码有一个极强的**递归自相似**结构：`n` 位的解可以由 `n-1` 位的解直接拼出来。

2. **破局思路（镜像反射）**

   设已有 `n-1` 位的合法序列 `G`。把它**复制一份并上下镜像**得到 `G'`，再给 `G'` 里每个数加上 `1 << (n-1)`（即置最高位为 1），然后把 `G'` 接到 `G` 后面：

   - `G` 内部相邻仍只差一位（原有性质）；
   - `G'` 内部是 `G` 的反序再统一加最高位，相邻仍只差一位；
   - 拼接处：`G` 末元素与 `G'` 首元素（即 `G` 末元素加最高位）只差最高位这一位；
   - 首尾：`0` 与 `G'` 末元素，只差最高位。

   从 `n=0` 的 `[0]` 出发不断翻倍即可。以 `n=2` 为例：`n=1` 得 `[0,1]`；镜像并加 2 得 `[2,3]`；拼接为 `[0,1,3,2]`。

3. **关键追问（有没有一行公式？）**

   有。第 `i` 个格雷码恰好是 `i ^ (i >> 1)`（异或相邻两位）。因为 `i` 和 `i+1` 相差的是末尾若干连续 1 的进位，其"相邻位异或"结果正好只翻一位。按此公式顺序生成即得到与镜像法相同的序列，实现最简洁。

### Java 实现（公式法）

```java
import java.util.ArrayList;
import java.util.List;

class Solution {
    public List<Integer> grayCode(int n) {
        List<Integer> res = new ArrayList<>();
        int total = 1 << n;                 // 共 2^n 个编码
        for (int i = 0; i < total; i++) {
            // 第 i 个格雷码 = i 异或 (i 右移一位)，保证相邻只差一位
            res.add(i ^ (i >> 1));
        }
        return res;
    }
}
```

### 复杂度

- 时间：`O(2^n)`。需要生成 `2^n` 个整数，每个用一次异或运算，常数时间。
- 空间：`O(1)`（不计返回结果占用的 `O(2^n)`）。除结果列表外只用了循环变量。

### 易错点与扩展（面试高频考点）

1. **`1 << n` 的规模**：`n <= 16`，结果最多 `65536` 个元素，`int` 足够，不会溢出；但若 `n` 更大要注意 `1 << n` 的溢出边界。
2. **公式 vs 镜像都要会写**：公式 `i ^ (i >> 1)` 最短；镜像拼接法便于解释为什么存在这样的序列，面试常要求手推 `n=1→2→3`。
3. **不要误写成 `i ^ (i << 1)`**：正确的是右移 `i >> 1`，写反会得到完全不同的序列（不再满足相邻差一位）。
4. **首尾闭环易被忽略**：题目要求最后一个与第一个也只差一位，公式法天然满足（`0` 与最高位置 1 的值只差最高位），无需额外处理。
5. **扩展——解码格雷码**：由格雷码反推原数可用 `x ^= x >> 1; x ^= x >> 2; x ^= x >> 4; ...`（前缀异或），是格雷码的逆变换，常见于编码器/状态机题。

### C++ 实现

```cpp
#include <vector>
using namespace std;

class Solution {
public:
    vector<int> grayCode(int n) {
        vector<int> res;
        int total = 1 << n;
        for (int i = 0; i < total; i++) {
            res.push_back(i ^ (i >> 1));   // 第 i 个格雷码
        }
        return res;
    }
};
```

### Python 实现

```python
class Solution:
    def grayCode(self, n: int) -> list[int]:
        # 第 i 个格雷码 = i ^ (i >> 1)
        return [i ^ (i >> 1) for i in range(1 << n)]
```
