题目信息 内容
难度 中等

时间复杂度 O(1)
空间复杂度 O(1)

题目与约束

给你两个整数，被除数 dividend 和除数 divisor。将两数相除，要求不使用乘法、除法和取余运算。

整数除法应该向零截断，也就是截去（truncate）其小数部分。例如，8.345 将被截断为 8，-2.7335 将被截断至 -2。

返回被除数 dividend 除以除数 divisor 得到的商。

注意： 假设我们的环境只能存储 32 位有符号整数，其数值范围是 [−2^31, 2^31 − 1]。本题中，如果商严格大于 2^31 − 1，则返回 2^31 − 1；如果商严格小于 −2^31，则返回 −2^31。

示例 1：

输入: dividend = 10, divisor = 3
输出: 3
解释: 10/3 = 3.33333.. ，向零截断后得到 3 。

示例 2：

输入: dividend = 7, divisor = -3
输出: -2
解释: 7/-3 = -2.33333.. ，向零截断后得到 -2 。

提示：

  • -2^31 <= dividend, divisor <= 2^31 - 1
  • divisor != 0

核心不变量

任何商都能表示成二进制：商 = Σ (1 << i)，其中每一位 i 满足"被除数里还够减 divisor << i"；从高位到低位贪心取位即可拼出商。

完整推导

思路推导

  1. 直觉与痛点（不能乘除取余，还能怎么算？）

直接 dividend / divisor 被禁用。退一步，只用减法反复减 divisor 可以算出商，但 dividend = 2^31-1、divisor = 1 时要减二十多亿次，必然超时。需要一次"减很多个"。

  1. 破局思路（倍增：一次减 1 个、2 个、4 个…）

把除数不断翻倍：divisor, 2*divisor, 4*divisor, ...。以 10 / 3 为例，3, 6, 12，最大不超过 10 的是 6 = 3 * 2^1，于是商至少含 2^1，从 10 里减掉 6 剩 4；再看 3 * 2^0 = 3 <= 4，商再加 2^0，剩 1，1 已小于 3，结束。总商 2^1 + 2^0 = 3，正是 10/3 的截断结果。

  1. 关键追问（怎么优雅地"由高到低"取位？）

与其从 0 开始倍增，不如从最高位 i = 31 往下扫：判断 (a >> i) >= b 是否成立（等价的、不溢出的写法是 b * 2^i <= a）。成立就说明这一位 2^i 可以计入商，于是 a -= b << i、res += 1L << i。因为 b << i 与 res 用 long 计算，天然规避了 INT_MIN 取绝对值溢出和中间结果越界的问题。

  1. 符号与边界

商的符号由 dividend、divisor 是否异号决定（用异或判断）；唯一会真正溢出的是 INT_MIN / -1 = 2^31，它超出 int 上限，需提前返回 INT_MAX。其余情况把两数都取绝对值后用 long 运算，最后补回符号即可。

Java 实现（divide）

class Solution {
    public int divide(int dividend, int divisor) {
        // 唯一真正会溢出的情形：-2^31 / -1 = 2^31，超出 int 上限
        if (dividend == Integer.MIN_VALUE && divisor == -1) {
            return Integer.MAX_VALUE;
        }

        // 商为负当且仅当两数异号
        boolean negative = (dividend < 0) ^ (divisor < 0);

        // 用 long 保存绝对值，避免 INT_MIN 取负溢出
        long a = Math.abs((long) dividend);
        long b = Math.abs((long) divisor);

        long res = 0;
        // 从最高位到最低位贪心：判断 b * 2^i 能否从 a 中减掉
        for (int i = 31; i >= 0; i--) {
            if ((a >> i) >= b) {          // 等价于 b << i <= a，且不会溢出
                a -= b << i;              // 减掉这一块
                res += 1L << i;           // 把 2^i 计入商
            }
        }

        return (int) (negative ? -res : res);
    }
}

复杂度

  • 时间：O(1)。循环固定 32 次（int 的位数），与数值大小无关。
  • 空间：O(1)。只使用若干整型变量。

易错点与扩展（面试高频考点）

  1. 必须特判 INT_MIN / -1：这是唯一结果溢出的组合，不特判会得到错误或未定义结果。
  2. Math.abs(Integer.MIN_VALUE) 仍是负数：int 的 abs 对 INT_MIN 无效，务必先转成 long 再取绝对值。
  3. 位移别用 int：1 << 31 在 int 下会变成负数，divisor << i 也可能溢出；统一用 1L << i、(long) 参与运算最稳。
  4. 截断方向是"向零"：余数直接丢弃即可；不要引入取模，本题禁止 %。
  5. 扩展：把循环从 31 改到更高的位数即可推广到大整数；该"二进制倍增"思想也是很多"不用乘除实现运算"题目的通用套路。

29. 两数相除

C++ 实现

#include <climits>
#include <cstdlib>

class Solution {
public:
    int divide(int dividend, int divisor) {
        // 唯一会溢出的情形
        if (dividend == INT_MIN && divisor == -1) return INT_MAX;

        bool negative = (dividend < 0) ^ (divisor < 0);
        long long a = llabs((long long) dividend);
        long long b = llabs((long long) divisor);

        long long res = 0;
        for (int i = 31; i >= 0; i--) {
            if ((a >> i) >= b) {          // b * 2^i <= a
                a -= b << i;
                res += 1LL << i;
            }
        }

        return (int) (negative ? -res : res);
    }
};

Python 实现

class Solution:
    def divide(self, dividend: int, divisor: int) -> int:
        INT_MAX = 2 ** 31 - 1
        INT_MIN = -2 ** 31

        # 唯一会溢出的情形
        if dividend == INT_MIN and divisor == -1:
            return INT_MAX

        negative = (dividend < 0) ^ (divisor < 0)
        a, b = abs(dividend), abs(divisor)

        res = 0
        for i in range(31, -1, -1):
            if (a >> i) >= b:             # b * 2^i <= a
                a -= b << i
                res += 1 << i

        res = -res if negative else res
        # 截断到 32 位有符号范围
        return max(INT_MIN, min(INT_MAX, res))
