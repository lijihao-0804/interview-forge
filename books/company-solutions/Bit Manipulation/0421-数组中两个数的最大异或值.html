421. 数组中两个数的最大异或值

本题学习状态正在读取学习记录…下次复习：—
本次复习：
按 M 快速切换薄弱标记
遮住推导与代码，先自己想，再逐段揭示
难度中等核心模式高位到低位逐位贪心 + 哈希集合判断前缀能否异或出候选值时间复杂度O(31n) = O(n)空间复杂度O(n)

题目与约束

给你一个整数数组 nums ，返回 nums[i] XOR nums[j] 的最大运算结果，其中 0 ≤ i ≤ j < n 。

示例 1：

输入：nums = [3,10,5,25,2,8]
输出：28
解释：最大运算结果是 5 XOR 25 = 28.

示例 2：

输入：nums = [14,70,53,83,49,91,36,80,92,51,66,70]
输出：127

提示：

  • 1 <= nums.length <= 2 * 105

  • 0 <= nums[i] <= 231 - 1

🔗 前往力扣原题验证 →

核心不变量

从最高位到最低位逐位确定答案：把每个数截至当前位的"前缀"放进集合，若存在两个前缀异或恰为"试探值"，则答案这一位可以取 1。

完整推导

思路推导

  1. 直觉（异或越大，越看高位）

异或结果的第 bit 位只取决于两个数各自的第 bit 位。想让结果大，就应优先让最高位为 1。于是从最高位往下贪心：能置 1 就置 1。

  1. 试探（怎么判断这一位能不能是 1）

维护一个已确定的答案 maxXor。对第 bit 位，先假设答案能变成 candidate = maxXor | (1 << bit)。把每个数中高于等于 bit 的位保留下来（num & mask）当作前缀，全部丢进集合。

  1. 验证（集合内的两两异或）

若存在两个前缀 p1 ^ p2 == candidate，等价于：遍历前缀 p，看 p ^ candidate 是否也在集合里。只要命中一次，说明这一位确实能凑出 1，令 maxXor = candidate；否则放弃这一位。

  1. 小例子（[3,10,5,25,2,8]）

高位逐位试探，最终得到 maxXor = 28，对应 5 (00101) XOR 25 (11001) = 11100 = 28。每一位都取到了能取的最高值。

Java 实现（findMaximumXOR）

import java.util.HashSet;
import java.util.Set;

class Solution {
    public int findMaximumXOR(int[] nums) {
        int maxXor = 0;
        int mask = 0;

        // nums[i] < 2^31，最高有效位是第 30 位（0 起）
        for (int bit = 30; bit >= 0; bit--) {
            mask |= (1 << bit);              // 累积保留高位

            Set<Integer> prefixes = new HashSet<>();
            for (int num : nums) {
                prefixes.add(num & mask);    // 收集当前位及更高位组成的前缀
            }

            int candidate = maxXor | (1 << bit); // 试探把这一位置 1
            for (int prefix : prefixes) {
                // 若两个前缀异或能等于 candidate，则这一位可达
                if (prefixes.contains(prefix ^ candidate)) {
                    maxXor = candidate;
                    break;
                }
            }
        }
        return maxXor;
    }
}

C++ 实现

class Solution {
public:
    int findMaximumXOR(vector<int>& nums) {
        int maxXor = 0;
        int mask = 0;

        for (int bit = 30; bit >= 0; --bit) {
            mask |= (1 << bit);
            unordered_set<int> prefixes;
            for (int num : nums) {
                prefixes.insert(num & mask);
            }

            int candidate = maxXor | (1 << bit);
            for (int prefix : prefixes) {
                if (prefixes.count(prefix ^ candidate)) {
                    maxXor = candidate;
                    break;
                }
            }
        }
        return maxXor;
    }
};

Python 实现

from typing import List

class Solution:
    def findMaximumXOR(self, nums: List[int]) -> int:
        max_xor = 0
        mask = 0

        for bit in range(30, -1, -1):
            mask |= (1 << bit)
            prefixes = {num & mask for num in nums}

            candidate = max_xor | (1 << bit)
            for prefix in prefixes:
                if (prefix ^ candidate) in prefixes:
                    max_xor = candidate
                    break

        return max_xor

复杂度

  • 时间：O(31n) = O(n)，外层最多 31 个二进制位，每轮扫描数组一次并遍历前缀集合一次。
  • 空间：O(n)，每轮哈希集合中最多存放 n 个不同的前缀。
易错点与扩展（面试高频考点）
  1. 最高位起点：nums[i] <= 2^31 - 1，最高有效位是第 30 位（不是 31），从 31 开始会把符号位算进去导致错误。
  2. candidate 的构造：必须是 maxXor | (1 << bit)，并且只有验证通过才更新 maxXor，不能无条件赋值。
  3. 验证写法：prefixes.contains(prefix ^ candidate) 就等价于"存在另一前缀与 prefix 异或得到 candidate"，注意集合里前缀可能重复，但无影响。
  4. mask 的累积：每轮 mask |= (1 << bit)，保证前缀只保留高位、低位清零。
  5. 扩展（Trie 解法）：把每个数按二进制插入二叉 Trie，对每个数贪心地走"相反位"分支，时间 O(31n)、空间 O(31n)，是本题另一经典解法，也常被要求手写。
