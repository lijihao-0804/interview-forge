题目与约束

给你一个整数数组 arr 。请你将数组中的元素按照其二进制表示中数字 1 的数目升序排序。

如果存在多个数字二进制中 1 的数目相同，则必须将它们按照数值大小升序排列。

请你返回排序后的数组。

示例 1：

<strong>输入：</strong>arr = [0,1,2,3,4,5,6,7,8]
<strong>输出：</strong>[0,1,2,4,8,3,5,6,7]
<strong>解释：</strong>[0] 是唯一一个有 0 个 1 的数。
[1,2,4,8] 都有 1 个 1 。
[3,5,6] 有 2 个 1 。
[7] 有 3 个 1 。
按照 1 的个数排序得到的结果数组为 [0,1,2,4,8,3,5,6,7]

示例 2：

<strong>输入：</strong>arr = [1024,512,256,128,64,32,16,8,4,2,1]
<strong>输出：</strong>[1,2,4,8,16,32,64,128,256,512,1024]
<strong>解释：</strong>数组中所有整数二进制下都只有 1 个 1 ，所以你需要按照数值大小将它们排序。

示例 3：

<strong>输入：</strong>arr = [10000,10000]
<strong>输出：</strong>[10000,10000]

示例 4：

<strong>输入：</strong>arr = [2,3,5,7,11,13,17,19]
<strong>输出：</strong>[2,3,5,17,7,11,13,19]

示例 5：

<strong>输入：</strong>arr = [10,100,1000,10000]
<strong>输出：</strong>[10,100,10000,1000]

提示：

  • 1 <= arr.length <= 500

  • 0 <= arr[i] <= 10^4

核心不变量

排序键是一个二元组 (二进制中 1 的个数, 数值本身)，按该二元组升序排列即得答案。

完整推导

思路推导

  1. 抓住排序依据：题目要求的主键是"二进制里 1 的个数"，次键是"数值大小"。只要为每个元素构造出这样一个可比较的二元组，交给标准排序即可。

  2. 如何数 1 的个数：最直接是按位统计；更高效的做法是内置函数——Java 的 Integer.bitCount、C++ 的 __builtin_popcount、Python 的 bin(x).count('1') 或 int.bit_count()。它们都是常数级（最多 32 位）。

  3. 自定义比较器：比较两个数时，先比 1 的个数；相同再比数值。Java 里对基本类型数组需装箱成 Integer[] 才能用自定义比较器，最后再拷回。

  4. 小例子：arr = [2,3,5,7,11,13,17,19]。它们的二进制分别是 10,11,101,111,1011,1101,10001,10011，1 的个数为 1,2,2,3,3,3,2,3。按 (个数, 数值) 排序：个数为 1 的只有 2；个数为 2 的 3,5,17；个数为 3 的 7,11,13,19。拼起来正好是 [2,3,5,17,7,11,13,19]。

Java 实现（sortByBits，自定义比较器）

import java.util.Arrays;

class Solution {
    public int[] sortByBits(int[] arr) {
        int n = arr.length;
        // 基本类型数组无法直接使用自定义比较器，先装箱
        Integer[] boxed = new Integer[n];
        for (int i = 0; i < n; i++) {
            boxed[i] = arr[i];
        }
        // 先按二进制中 1 的个数升序，数量相同则按数值升序
        Arrays.sort(boxed, (a, b) -> {
            int ca = Integer.bitCount(a);
            int cb = Integer.bitCount(b);
            if (ca != cb) {
                return ca - cb;
            }
            return a - b;
        });
        // 拷回原数组
        for (int i = 0; i < n; i++) {
            arr[i] = boxed[i];
        }
        return arr;
    }
}

复杂度

  • 时间：O(n log n)，排序的比较次数为 O(n log n)，每次比较中统计二进制 1 的个数为 O(1)（32 位以内）。
  • 空间：O(n)，Java 需要额外一个 Integer[] 辅助数组完成装箱排序。

易错点与扩展（面试高频考点）

  1. 只按 1 的个数排序：漏掉"数量相同按数值升序"的次键，结果就错，如示例 1 里的 [1,2,4,8] 必须保持数值升序。
  2. Java 基本类型不能直接用比较器：Arrays.sort(int[], Comparator) 不存在，必须先转 Integer[]，排完再拷回。
  3. 比较器写法：return ca - cb; 在本数据范围内不会溢出；若数值范围极大应改用 Integer.compare。
  4. popcount 的实现：Integer.bitCount / __builtin_popcount / bin(x).count('1') 都比手写循环更简洁可靠，注意 0 的 popcount 为 0。
  5. 稳定性无关：因为次键已经是数值，结果唯一，不需要依赖排序稳定性；但用二元组做键的写法天然与稳定性无关，更稳健。

1356. 根据数字二进制下 1 的数目排序

C++ 实现

class Solution {
public:
    vector<int> sortByBits(vector<int>& arr) {
        sort(arr.begin(), arr.end(), [](int a, int b) {
            int ca = __builtin_popcount(a);
            int cb = __builtin_popcount(b);
            if (ca != cb) return ca < cb; // 先按 1 的个数升序
            return a < b;                 // 再按数值升序
        });
        return arr;
    }
};

Python 实现

from typing import List

class Solution:
    def sortByBits(self, arr: List[int]) -> List[int]:
        # 排序键为 (二进制中 1 的个数, 数值本身)，均升序
        return sorted(arr, key=lambda x: (bin(x).count('1'), x))
