题目与约束

给你一个字符串数组 words ，找出并返回 length(words[i]) * length(words[j]) 的最大值，并且这两个单词不含有公共字母。如果不存在这样的两个单词，返回 0 。

示例 1：

<strong>输入：</strong>words = ["abcw","baz","foo","bar","xtfn","abcdef"]
<strong>输出：</strong>16 
<strong>解释</strong><strong>：</strong>这两个单词为<strong> </strong>"abcw", "xtfn"。

示例 2：

<strong>输入：</strong>words = ["a","ab","abc","d","cd","bcd","abcd"]
<strong>输出：</strong>4 
<strong>解释</strong><strong>：</strong>这两个单词为 "ab", "cd"。

示例 3：

<strong>输入：</strong>words = ["a","aa","aaa","aaaa"]
<strong>输出：</strong>0 
<strong>解释</strong><strong>：</strong>不存在这样的两个单词。

提示：

  • 2 <= words.length <= 1000

  • 1 <= words[i].length <= 1000

  • words[i] 仅包含小写字母

核心不变量

用一个 26 位整数记录每个单词出现过的字母集合；两词无公共字母等价于两个掩码按位与为 0。

完整推导

思路推导

  1. 朴素做法：枚举每一对单词，再逐字符检查是否有公共字母，最坏 O(N²·L)，N 到 1000 时比较吃力。

  2. 把"字母集合"压成整数：小写字母只有 26 个，可用一个 int 的第 c-'a' 位表示字母 c 是否出现。两个单词"无公共字母"就等价于两个掩码 mask1 & mask2 == 0，判交从 O(L) 降到 O(1)。

  3. 去重压缩：字母集合完全相同的单词，长度不同但互相一定冲突（掩码与不为 0），对答案只需保留其中最长的一个。用哈希表 mask -> 最大长度 收敛，后续只需在"不同掩码"之间两两判断，比较次数从 N² 降到 M²（M 为不同掩码数，M ≤ N）。

  4. 小例子："abcw" → 位 {a,b,c,w}，"xtfn" → 位 {x,t,f,n}，两者无交集，4 * 4 = 16；而 "abcdef" 含 a~f，与前者有交集，不能配对。最终最大为 16 ✓

Java 实现（位掩码）

import java.util.ArrayList;
import java.util.HashMap;
import java.util.List;
import java.util.Map;

class Solution {
    public int maxProduct(String[] words) {
        // mask -> 该字母集合下最长的单词长度
        Map<Integer, Integer> best = new HashMap<>();
        for (String w : words) {
            int mask = 0;
            for (int i = 0; i < w.length(); i++) {
                mask |= 1 << (w.charAt(i) - 'a');
            }
            best.merge(mask, w.length(), Math::max);
        }

        int ans = 0;
        List<Integer> masks = new ArrayList<>(best.keySet());
        for (int i = 0; i < masks.size(); i++) {
            for (int j = i + 1; j < masks.size(); j++) {
                int mi = masks.get(i), mj = masks.get(j);
                if ((mi & mj) == 0) {   // 无公共字母
                    ans = Math.max(ans, best.get(mi) * best.get(mj));
                }
            }
        }
        return ans;
    }
}

复杂度

  • 时间：O(N·L + M²)。构造掩码对每个单词扫描一遍，共 O(N·L)；之后只在不同掩码之间两两判断，共 O(M²)，M 为不同掩码数（≤ N）。
  • 空间：O(M)。哈希表只存不同掩码到最大长度的映射，最坏 O(N)。

易错点与扩展（面试高频考点）

  1. 掩码位宽：26 位放进 int（32 位）足够；写成 long 也可以，但别用 byte/short 溢出。
  2. 必须选不同单词：M² 只在不同掩码间枚举即可；同一掩码的单词一定共享字母，不可能满足条件，所以"每组保留最长"是安全的。
  3. 判交用 (mi & mj) == 0：位运算优先级低于 == 时要注意加括号；C++/Java 中 & 优先级低于 ==，务必写成 (mi & mj) == 0。
  4. 无解返回 0：所有单词都互相冲突时（如示例 3），答案应是 0 而不是负数或异常。
  5. 复杂度取舍：N ≤ 1000 时直接 O(N²) 枚举 pair 配合掩码判交也能过；用 mask -> maxLen 去重是常见优化，L 很大（1000）时尤其值。

318. 最大单词长度乘积

C++ 实现

#include <vector>
#include <string>
#include <unordered_map>
#include <algorithm>
using namespace std;

class Solution {
public:
    int maxProduct(vector<string>& words) {
        unordered_map<int, int> mp;   // mask -> 最大单词长度
        for (const string& w : words) {
            int mask = 0;
            for (char c : w) mask |= 1 << (c - 'a');
            int len = (int)w.size();
            auto it = mp.find(mask);
            if (it == mp.end()) mp[mask] = len;
            else it->second = max(it->second, len);
        }

        vector<pair<int, int>> v(mp.begin(), mp.end());
        int ans = 0;
        for (int i = 0; i < (int)v.size(); ++i) {
            for (int j = i + 1; j < (int)v.size(); ++j) {
                if ((v[i].first & v[j].first) == 0) {   // 无公共字母
                    ans = max(ans, v[i].second * v[j].second);
                }
            }
        }
        return ans;
    }
};

Python 实现

class Solution:
    def maxProduct(self, words: list[str]) -> int:
        best_len = {}                       # mask -> 最大单词长度
        for w in words:
            mask = 0
            for ch in w:
                mask |= 1 << (ord(ch) - ord('a'))
            if len(w) > best_len.get(mask, 0):
                best_len[mask] = len(w)

        masks = list(best_len.keys())
        ans = 0
        for i in range(len(masks)):
            for j in range(i + 1, len(masks)):
                if (masks[i] & masks[j]) == 0:   # 无公共字母
                    ans = max(ans, best_len[masks[i]] * best_len[masks[j]])
        return ans
