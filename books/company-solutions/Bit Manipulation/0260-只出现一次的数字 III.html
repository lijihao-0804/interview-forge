题目与约束

给你一个整数数组 nums，其中恰好有两个元素只出现一次，其余所有元素均出现两次。找出只出现一次的那两个元素。你可以按任意顺序返回答案。

你必须设计并实现线性时间复杂度的算法且仅使用常量额外空间来解决此问题。

示例 1：

输入：nums = [1,2,1,3,2,5]
输出：[3,5]
解释：[5, 3] 也是有效的答案。

示例 2：

输入：nums = [-1,0]
输出：[-1,0]

示例 3：

输入：nums = [0,1]
输出：[1,0]

提示：

  • 2 <= nums.length <= 3 * 10^4
  • -2^31 <= nums[i] <= 2^31 - 1
  • 除两个只出现一次的整数外，nums 中的其他数字都出现两次

核心不变量

把全部元素异或起来得到 a ^ b；取其中最低位的 1 作为分组依据，两个答案必然被分到不同组，而每个成对出现的数字都整体落入同一组，因此两组各自异或就分别得到 a 与 b。

完整推导

思路推导

  1. 先回忆单个数版本

如果只有一个数出现一次、其余都成对，全部异或即可：成对的数两两抵消，剩下的就是那个唯一值。

  1. 两个数怎么办

本题有两个只出现一次的数 a、b，全部异或得到 xor = a ^ b（成对的全抵消）。因为 a != b，所以 xor != 0，它的二进制里至少有一位是 1，这一位恰好区分了 a 和 b（一个该位为 0，一个为 1）。

  1. 按这一位分组

取最低位的 1：mask = xor & (-xor)。用 mask 扫描数组，把元素分成"该位为 1"和"该位为 0"两组。a、b 必在不同组；每个成对数字的两个副本该位相同，必然整体落在同一组，组内互相抵消。于是两组分别做异或，就得到 a 和 b。

  1. 小例子

[1,2,1,3,2,5]：全部异或 xor = 3 ^ 5 = 6 = 110₂，mask = 6 & (-6) = 2 = 010₂。按 bit1 分组：{2,2,3} 异或得 3，{1,1,5} 异或得 5，答案 [3,5] ✓。

Java 实现（异或分组）

class Solution {
    public int[] singleNumber(int[] nums) {
        int xor = 0;
        for (int x : nums) {
            xor ^= x;              // xor = a ^ b
        }

        int mask = xor & (-xor);   // 最低位的 1，用于区分 a 和 b

        int a = 0, b = 0;
        for (int x : nums) {
            if ((x & mask) != 0) {
                a ^= x;            // 该位为 1 的一组
            } else {
                b ^= x;            // 该位为 0 的一组
            }
        }
        return new int[]{a, b};
    }
}

复杂度

  • 时间：O(n)。两次线性扫描，每次都是常数时间的异或/位运算。
  • 空间：O(1)。只用了 xor、mask、a、b 四个整型变量。

易错点与扩展（面试高频考点）

  1. mask 的取法：mask = xor & (-xor) 取最低位的 1；C++ 中若 xor 为 INT_MIN，-xor 会溢出（UB），需转成 unsigned 再运算。
  2. 分组后两边都要异或：不能只算一边就返回，两个答案分别来自两组。
  3. 不能直接把 xor 拆开：xor 是 a ^ b 的混合结果，必须借某一位把两者分开才能还原。
  4. 为什么一定 xor != 0：两个答案互不相同，异或结果非零，最低位 1 一定存在，分组不会落空。
  5. 系列题对比：只出现一次的数字 I（136，其余成对，一个答案，直接全异或）、II（137，其余出现三次，用"逐位取模 3"），本题 III 用"异或 + 分组"，三题技巧各不相同。

力扣原题

260. 只出现一次的数字 III

C++ 实现

#include <vector>
using namespace std;

class Solution {
public:
    vector<int> singleNumber(vector<int>& nums) {
        int xr = 0;
        for (int x : nums) xr ^= x;              // xr = a ^ b
        // 取最低位的 1；用 unsigned 避免 -xr 在 INT_MIN 时溢出
        unsigned int mask = (unsigned int)xr & (0u - (unsigned int)xr);
        int a = 0, b = 0;
        for (int x : nums) {
            if (((unsigned int)x & mask) != 0) a ^= x;
            else b ^= x;
        }
        return {a, b};
    }
};

Python 实现

from typing import List

class Solution:
    def singleNumber(self, nums: List[int]) -> List[int]:
        xor = 0
        for x in nums:
            xor ^= x                     # xor = a ^ b
        mask = xor & (-xor)              # 最低位的 1
        a = b = 0
        for x in nums:
            if x & mask:
                a ^= x                   # 该位为 1 的一组
            else:
                b ^= x                   # 该位为 0 的一组
        return [a, b]
