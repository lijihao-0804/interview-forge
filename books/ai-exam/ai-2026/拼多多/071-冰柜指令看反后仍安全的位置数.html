题目描述

冰柜容量为 C，初始冰量为 h，依次执行 n 条整数指令 ai，每条执行后冰量增加 ai。全过程安全指每一步之后的冰量都位于闭区间 [0,C]。 必须选一个下标 1≤ i<n，交换第 i 条与第 i+1 条指令，然后执行完整序列。求使全过程安全的交换下标个数。即使两条指令数值相同，也算一个交换位置；不能把不交换算作一种方案；n=1 时答案为零。 输入格式 ：仅一组数据。首行 n,C,h，其中 1≤n≤2×105，0≤h≤C≤109；第二行 n 个整数，-109≤ai≤109。前缀和可能超出 32 位有符号整数范围。 输出格式 ：一个整数，表示合法交换位置数。

样例

输入 输出 输入 输出

5 10 5
4 -8 6 2 -3
2
4 5 2
3 2 -4 1
1

思路分析

第一步：缩小交换的影响范围。 令 P0=h，Pj=h+∑t=1jat。交换后，在第 i 步之前没有变化，第 i+1 步之后累计加入的数也没有变化。唯一变化的是 若对每个交换位置重新模拟，需要 O(n2)；现在只要检查一个新值，并保证其他旧前缀都合法。 第二步：数原本越界的前缀。 设共有 b 个原前缀不在 [0,C] 中。对候选位置 i，删去原前缀 Pi 后仍越界的数量为 b-[Pi 越界]。只有该数量为零且 P’i 合法时才计数。因此两处以上越界一定无解；唯一越界若在 Pn，也无解，因为总和不受交换影响。 第三步：检查边界。 循环仅枚举 1 到 n-1，自然覆盖 n=1。冰量恰为零或容量都合法。第一组样例可交换的位置为 i=3,4；第二组只有 i=2。Python 整数自动支持本题所需的大整数。

题解代码

Python 实现

import sys
input = sys.stdin.readline


def count_safe_swaps(n, capacity, initial, a):
    prefix = [initial]
    for value in a:
        prefix.append(prefix[-1] + value)
    bad = sum(not 0 <= value <= capacity for value in prefix[1:])
    answer = 0
    for i in range(1, n):
        remaining_bad = bad - (not 0 <= prefix[i] <= capacity)
        if remaining_bad == 0 and 0 <= prefix[i - 1] + a[i] <= capacity:
            answer += 1
    return answer


def solve():
    n, capacity, initial = map(int, input().split())
    a = list(map(int, input().split()))
    print(count_safe_swaps(n, capacity, initial, a))


solve()

复杂度分析

时间复杂度 ：O(n)，两次线性扫描。 空间复杂度 ：O(n)，保存指令和前缀和。
