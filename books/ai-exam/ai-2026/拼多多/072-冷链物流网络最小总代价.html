题目描述

有 N 个城市和 M 条已有双向公路。可以花费 W 开通某条公路作为冷链干线，也可以在城市 i 花费 Ci 建物流集散中心。所有建有中心的城市通过航空通道直接互通。求使所有城市连通的最小总代价。 必须至少建一个中心，即使 N=1 也如此。 输入格式 ：首行 N,M，1≤N≤105，0≤M≤2×105；第二行给出 N 个中心费用，1≤Ci≤109；接下来 M 行各给 u,v,W，1≤ u,v≤ N，u≠v，1≤W≤109，没有重边。 输出格式 ：一个整数，表示最小总代价。输入结构和样例均为单组数据，没有额外的测试组数。

样例

输入 输出

4 3
50 50 50 10
1 2 10
2 3 10
3 4 100
80

思路分析

第一步：为所有中心引入共同连接点。 新建虚拟城市 0，在它与每个城市 i 之间添加权值为 Ci 的边。选这条边就表示在 i 建中心，所有中心经点 0 互通。 第二步：证明等价。 原题任意合法方案都至少有一个中心，将对应虚拟边加入后，N+1 个点连通，费用不变；反过来，扩展图的任何连通方案都包含至少一条与点 0 相连的边，因此能还原出至少一个中心，且所有城市互通。由于边权为正，最优连通方案一定可以删掉环而不增加费用，所以求扩展图的最小生成树即可。 第三步：Kruskal 选边。 将 N+M 条边按费用排序，并查集维护连通块。只有两端分属不同块才选边；采用按大小合并和路径压缩。扩展图共有 N+1 个点，选出 N 条边即可停止。虚拟边保证整个图连通，原公路不连通或没有公路都不影响有解。 样例选择城市 1 和城市 4 的中心，再开通 1!↔!2、2!↔!3，代价为 50+10+10+10=80。单城时直接支付该城中心费用。

Python 实现

import sys
input = sys.stdin.readline


def min_total_cost(n, cost, roads):
    edges = [(weight, 0, i + 1) for i, weight in enumerate(cost)]
    edges.extend((weight, u, v) for u, v, weight in roads)
    edges.sort()
    parent = list(range(n + 1))
    size = [1] * (n + 1)

    def find(x):
        while x != parent[x]:
            parent[x] = parent[parent[x]]
            x = parent[x]
        return x

    total = picked = 0
    for weight, u, v in edges:
        u, v = find(u), find(v)
        if u == v:
            continue
        if size[u] < size[v]:
            u, v = v, u
        parent[v] = u
        size[u] += size[v]
        total += weight
        picked += 1
        if picked == n:
            break
    return total


def solve():
    n, m = map(int, input().split())
    cost = list(map(int, input().split()))
    roads = [tuple(map(int, input().split())) for _ in range(m)]
    print(min_total_cost(n, cost, roads))


solve()
