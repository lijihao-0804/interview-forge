冷链物流网络最小总代价

遮住推导与代码，先自己想，再逐段揭示

原题解析 · 拼多多 · 2026-10-11 · AI岗 · ACM 模式（stdin/stdout）

题目描述

有 N 个城市和 M 条已有双向公路。可以花费 W 开通某条公路作为冷链干线，也可以在城市 i 花费 Ci 建物流集散中心。所有建有中心的城市通过航空通道直接互通。求使所有城市连通的最小总代价。

必须至少建一个中心，即使 N=1 也如此。

输入格式 ：首行 N,M，1≤N≤105，0≤M≤2×105；第二行给出 N 个中心费用，1≤Ci≤109；接下来 M 行各给 u,v,W，1≤ u,v≤ N，u≠v，1≤W≤109，没有重边。

输出格式 ：一个整数，表示最小总代价。输入结构和样例均为单组数据，没有额外的测试组数。

样例

输入

输出

4 3
50 50 50 10
1 2 10
2 3 10
3 4 100
80

思路分析

第一步：为所有中心引入共同连接点。 新建虚拟城市 0，在它与每个城市 i 之间添加权值为 Ci 的边。选这条边就表示在 i 建中心，所有中心经点 0 互通。

第二步：证明等价。 原题任意合法方案都至少有一个中心，将对应虚拟边加入后，N+1 个点连通，费用不变；反过来，扩展图的任何连通方案都包含至少一条与点 0 相连的边，因此能还原出至少一个中心，且所有城市互通。由于边权为正，最优连通方案一定可以删掉环而不增加费用，所以求扩展图的最小生成树即可。

第三步：Kruskal 选边。 将 N+M 条边按费用排序，并查集维护连通块。只有两端分属不同块才选边；采用按大小合并和路径压缩。扩展图共有 N+1 个点，选出 N 条边即可停止。虚拟边保证整个图连通，原公路不连通或没有公路都不影响有解。

样例选择城市 1 和城市 4 的中心，再开通 1!↔!2、2!↔!3，代价为 50+10+10+10=80。单城时直接支付该城中心费用。

题解代码

复杂度分析

时间复杂度 ：O((N+M)log(N+M))，排序占主导。

空间复杂度 ：O(N+M)。

// 题目：冷链物流网络最小总代价
// 算法：排序 + 扫描
// 模式：ACM（stdin/stdout）
// 复杂度：时间 O((N+M)(N+M))，排序占主导；空间 O(N+M)

import java.io.*;
import java.util.*;
public class Main {
    static int[] par,sz;
    static int find(int x) {
        while(par[x]!=x) {
            par[x]=par[par[x]];
            x=par[x];
        }
        return x;
    }
    // 主函数：读取输入并输出答案
    public static void main(String[] a)throws Exception {
        FS fs=new FS();
        int n=fs.ni(),m=fs.ni();
        long[] cost=new long[n];
        for(int i=0;i<n;i++)cost[i]=fs.nl();
        int totalEdges=n+m;
        long[][] edges=new long[totalEdges][3];
        int ei=0;
        for(int i=0;i<n;i++) {
            edges[ei][0]=cost[i];
            edges[ei][1]=0;
            edges[ei][2]=i+1;
            ei++;
        }
        for(int i=0;i<m;i++) {
            int u=fs.ni(),v=fs.ni();
            long w=fs.nl();
            edges[ei][0]=w;
            edges[ei][1]=u;
            edges[ei][2]=v;
            ei++;
        }
        Arrays.sort(edges,(p,q)-> {
            if(p[0]!=q[0])return Long.compare(p[0],q[0]);if(p[1]!=q[1])return Long.compare(p[1],q[1]);return Long.compare(p[2],q[2]);
        }
        );
        par=new int[n+1];
        sz=new int[n+1];
        Arrays.fill(sz,1);
        for(int i=0;i<=n;i++)par[i]=i;
        long total=0;
        int picked=0;
        for(long[] e:edges) {
            int u=find((int)e[1]),v=find((int)e[2]);
            if(u==v)continue;
            if(sz[u]<sz[v]) {
                int tmp=u;
                u=v;
                v=tmp;
            }
            par[v]=u;
            sz[u]+=sz[v];
            total+=e[0];
            picked++;
            if(picked==n)break;
        }
        System.out.println(total);
    }
    static class FS {
        byte[] d;
        int i=0;
        FS()throws IOException {
            d=System.in.readAllBytes();
        }
        String next() {
            while(i<d.length&&d[i]<=32)i++;
            int s=i;
            while(i<d.length&&d[i]>32)i++;
            return new String(d,s,i-s);
        }
        int ni() {
            return Integer.parseInt(next());
        }
        long nl() {
            return Long.parseLong(next());
        }
    }
}

Python 实现

# 题目：冷链物流网络最小总代价
# 算法：排序 + 扫描
# 模式：ACM（stdin/stdout）
# 复杂度：时间 O((N+M)(N+M))，排序占主导；空间 O(N+M)

import sys
input = sys.stdin.readline


def min_total_cost(n, cost, roads):
    edges = [(weight, 0, i + 1) for i, weight in enumerate(cost)]
    edges.extend((weight, u, v) for u, v, weight in roads)
    edges.sort()
    parent = list(range(n + 1))
    size = [1] * (n + 1)

    def find(x):
        while x != parent[x]:
            parent[x] = parent[parent[x]]
            x = parent[x]
        return x

    total = picked = 0
    for weight, u, v in edges:
        u, v = find(u), find(v)
        if u == v:
            continue
        if size[u] < size[v]:
            u, v = v, u
        parent[v] = u
        size[u] += size[v]
        total += weight
        picked += 1
        if picked == n:
            break
    return total
