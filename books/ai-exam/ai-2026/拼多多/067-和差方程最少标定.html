和差方程最少标定

遮住推导与代码，先自己想，再逐段揭示

原题解析 · 拼多多 · 2026-08-23 · 算法岗 · ACM 模式（stdin/stdout）

题目描述

有 p 个整数量值 x1,x2,…,xp，每个值可正、可负、也可为零。给出 e 条记录，每条为以下两种之一：

D u v w ：xu-xv=w； S u v w ：xu+xv=w。

一条记录中的两个下标可以相同。先判断全部记录是否存在一组整数解；若有，再求至少需要实测多少个样品，才能唯一确定全部 p 个值。

输入描述

第一行输入两个整数 p,e。

接下来 e 行，每行输入一个大写字母 D 或 S ，以及三个整数 u,v,w。

数据范围 ：

1≤p≤100000,0≤e≤100000,

1≤u,v≤p,|w|≤109.

输出描述

第一行输出 YES 或 NO ，表示是否存在整数解。

若有解，第二行输出最少实测个数；若无解，第二行输出 -1。

思路分析

为每个变量 xi 建立两个点：本体点 i 表示 xi，镜像点 i’ 表示 -xi。这样和关系也能改写为差关系：

xu+xv=wiffxu-(-xv)=w.

每条记录必须成对加入约束，以保持本体与镜像的对称性：

D u v w 加入

xu-xv=w,(-xu)-(-xv)=-w;

S u v w 加入

xu-(-xv)=w,(-xu)-xv=-w.

D u v w 加入

S u v w 加入

维护

pot[z]=value(z)-value(parent(z)).

路径压缩后， pot[z] 就是点 z 相对其根的值。加入约束 value(a)-value(b)=c 时：若两点已同根，检查 pot[a] - pot[b] == c ；否则按大小合并，并计算新挂接根相对父根的势差。

若本体 i 与镜像 i’ 不连通，对应连通块仍有一个整数平移自由度，实测其中任意一个样品即可确定这一对镜像块。

若 i 与 i’ 连通，则路径约束固定了

value(i)-value(i′)=xi-(-xi)=2xi.

路径压缩后应计算

delta=pot[i]-pot[i′].

只有当 delta 为偶数时，xi=delta/2 才是整数；若为奇数，则方程组在有理数范围可能有解，但没有整数解。这里应使用 势之差 而不是势之和。虽然整数 a+b 与 a-b 奇偶性相同，只检查 % 2 时二者碰巧给出相同结果，但势之和并不等于 2xi，会掩盖公式和后续扩展中的错误。

若该块通过奇偶检查，则整块已被唯一确定，不需要实测。其他未固定的连通块按镜像两两配对，每对只需实测一个样品，因此答案为未固定根数除以 2。

正确性证明

镜像点定义保证每条原始记录等价于代码加入的两条差约束，因此原方程组与并查集约束等价。带权并查集始终维护点到父节点的势差；合并不同集合时设置的根间势差使新约束成立，同集合校验则准确识别矛盾。

若某点与其镜像同根，两者之差由路径唯一确定，而该差必须等于 2xi。它为奇数时不存在整数 xi；为偶数时 xi 唯一确定，并可沿势差确定整个连通块。若二者不同根，这对镜像块保留且仅保留一个自由整数参数，实测其中一个原变量即可确定整对。故算法既能正确判断整数可解性，也能得到最少实测数。

复杂度分析

时间复杂度：

O((p+e)α(p)),

空间复杂度：O(p)。 find 使用迭代路径压缩，避免 p=105 时递归栈溢出。

易错点

每条记录必须同时加入镜像约束，否则最后的连通块不再成镜像对。 合并根时，挂接方向不同，根势差公式的符号也不同。 i 与 i’ 同根只说明变量被固定在某个有理数；还必须检查 potential[i] - potential[i'] 是否为偶数，才能保证它是整数。 自环要正常处理： D i i w 仅在 w=0 时可行； S i i w 要求 w 为偶数。 找根必须在读取 potential 前完成路径压缩，使势能表示相对根的值。

Java 实现

// 题目：和差方程最少标定
// 算法：按题意模拟
// 模式：ACM（stdin/stdout）
// 复杂度：时间 O((p+e)(p)), 空间复杂度：O(p)；空间 O(p)

import java.io.*;
import java.util.*;
public class Main {
    static BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
    static StringTokenizer st;
    static String next() throws IOException {
        while (st == null || !st.hasMoreTokens()) {
            String line = br.readLine();
            if (line == null) return null;
            st = new StringTokenizer(line);
        }
        return st.nextToken();
    }
    static int nextInt() throws IOException { return Integer.parseInt(next()); }
    static long nextLong() throws IOException { return Long.parseLong(next()); }
    static int[] parent;
    static long[] size,potential;
    // 核心方法：find
    static int find(int x) {
        int[] path=new int[64];
        int len=0;
        int cur=x;
        // 循环处理
        while(parent[cur]!=cur) {
            // 条件判断
            if(len==path.length)path=Arrays.copyOf(path,len*2);
            path[len++]=cur;
            cur=parent[cur];
        }
        int root=cur;
        long tot=0;
        // 枚举位置 i
        for(int i=len-1;i>=0;i--) {
            int node=path[i];
            tot+=potential[node];
            potential[node]=tot;
            parent[node]=root;
        }
        // 返回结果
        return root;
    }
    // 核心方法：unite
    static boolean unite(int a,int b,long diff) {
        int ra=find(a),rb=find(b);
        // 条件判断
        if(ra==rb)return potential[a]-potential[b]==diff;
        // 条件判断
        if(size[ra]<size[rb]) {
            parent[ra]=rb;
            potential[ra]=potential[b]+diff-potential[a];
            size[rb]+=size[ra];
        } else {
            parent[rb]=ra;
            potential[rb]=potential[a]-diff-potential[b];
            size[ra]+=size[rb];
        }
        // 返回结果
        return true;
    }
    // 主函数：读取输入并输出答案
    public static void main(String[] a)throws IOException {
        int vc=nextInt(),rc=nextInt();
        int nc=2*vc;
        parent=new int[nc];
        size=new long[nc];
        potential=new long[nc];
        Arrays.fill(size,1);
        // 枚举位置 i
        for(int i=0;i<nc;i++)parent[i]=i;
        boolean consistent=true;
        // 循环处理
        for(int r=0;r<rc;r++) {
            String op=next();
            int u=nextInt()-1,v=nextInt()-1;
            long w=nextLong();
            // 条件判断
            if(!consistent)continue;
            boolean f1,f2;
            // 条件判断
            if(op.equals("D")) {
                f1=unite(u,v,w);
                f2=unite(u+vc,v+vc,-w);
            } else {
                f1=unite(u,v+vc,w);
                f2=unite(u+vc,v,-w);
            }
            consistent=f1&&f2;
        }
        // 条件判断
        if(!consistent) {
            System.out.println("NO");
            System.out.println(-1);
            // 返回结果
            return;
        }
        boolean[] pinned=new boolean[nc];
        // 枚举位置 i
        for(int i=0;i<vc;i++) {
            int root=find(i);
            int mr=find(i+vc);
            // 条件判断
            if(root!=mr)continue;
            long delta=potential[i]-potential[i+vc];
            // 条件判断
            if(delta%2!=0) {
                System.out.println("NO");
                System.out.println(-1);
                // 返回结果
                return;
            }
            pinned[root]=true;
        }
        int free=0;
        // 循环处理
        for(int node=0;node<nc;node++) {
            int root=find(node);
            // 条件判断
            if(root==node&&!pinned[root])free++;
        }
        System.out.println("YES");
        System.out.println(free/2);
    }
}

Python 实现

# 题目：和差方程最少标定
# 算法：按题意模拟
# 模式：ACM（stdin/stdout）
# 复杂度：时间 O((p+e)(p)), 空间复杂度：O(p)；空间 O(p)

import sys


# 读取输入并输出答案
def solve():
    input = sys.stdin.buffer.readline
    variable_count, record_count = map(int, input().split())
    node_count = 2 * variable_count

    parent = list(range(node_count))
    size = [1] * node_count
    potential = [0] * node_count

    # 核心函数：find
    def find(x):
        path = []
        current = x
        # 循环处理
        while parent[current] != current:
            path.append(current)
            current = parent[current]
        root = current

        total = 0
        # 遍历 node
        for node in reversed(path):
            total += potential[node]
            potential[node] = total
            parent[node] = root
        # 返回结果
        return root

    # 核心函数：unite
    def unite(a, b, difference):
        # value(a) - value(b) = difference
        root_a = find(a)
        root_b = find(b)
        # 条件判断
        if root_a == root_b:
            # 返回结果
            return potential[a] - potential[b] == difference

        # 条件判断
        if size[root_a] < size[root_b]:
            parent[root_a] = root_b
            potential[root_a] = potential[b] + difference - potential[a]
            size[root_b] += size[root_a]
        else:
            parent[root_b] = root_a
            potential[root_b] = potential[a] - difference - potential[b]
            size[root_a] += size[root_b]
        # 返回结果
        return True

    consistent = True
    # 遍历 _
    for _ in range(record_count):
        operation, raw_u, raw_v, raw_w = input().split()
        u = int(raw_u) - 1
        v = int(raw_v) - 1
        w = int(raw_w)

        # 条件判断
        if not consistent:
            continue

        # 条件判断
        if operation == b"D":
            first_ok = unite(u, v, w)
            second_ok = unite(u + variable_count, v + variable_count, -w)
        else:
            first_ok = unite(u, v + variable_count, w)
            second_ok = unite(u + variable_count, v, -w)
        consistent = first_ok and second_ok

    # 条件判断
    if not consistent:
        print("NO")
        print(-1)
        # 返回结果
        return

    pinned = [False] * node_count
    # 枚举位置 i
    for i in range(variable_count):
        root = find(i)
        mirror_root = find(i + variable_count)
        # 条件判断
        if root != mirror_root:
            continue

        # value(i) - value(i') = x_i - (-x_i) = 2*x_i。
        delta = potential[i] - potential[i + variable_count]
        # 条件判断
        if delta % 2 != 0:
            print("NO")
            print(-1)
            # 返回结果
            return
        pinned[root] = True

    free_roots = 0
    # 遍历 node
    for node in range(node_count):
        root = find(node)
        # 条件判断
        if root == node and not pinned[root]:
            free_roots += 1

    print("YES")
    print(free_roots // 2)


if __name__ == "__main__":
    solve()
