# 多多捕蝇

## 题目描述

$n$ 个房间，房间 $i$ 有出边指向 $a_i$（每个房间恰好一条出边）。苍蝇从任意房间出发沿边行走。在房间 $i$ 放粘蝇板的代价为 $c_i$。求最少总代价使得无论苍蝇初始在哪都能被捕获。

输出

## 思路分析

第一步：函数图的结构

每个节点出度恰好为 1，构成函数图。从任意节点出发一直走，房间数有限必然进入环。整张图由若干连通块组成，每个连通块是一个环加上汇入环的若干树枝。

第二步：为什么每个环放一块板就够

苍蝇最终会落入所在连通块的环里无限绕圈，只要环上有一块板必然经过；树枝上的房间早晚走进环，无需单独放板。不同环互不连通，必须各放至少一块。

第三步：取每个环上最便宜的房间

每个环选代价最小的房间放板，总答案是所有环最小 $c$ 之和。

第四步：用拓扑剥离找环

统计入度，把入度为 0 的房间不断出队删除（它们在树枝末端），删除时将其指向的房间入度减一。剥离结束后仍存活的房间恰好是所有环上的节点。最后沿出边遍历每个环累加最小值。

// 算法：按题意模拟
// 模式：ACM（stdin/stdout）
// 复杂度：时间 O(n)，每个房间入队出队各一次，每个环完整遍历一次；空间 O(n)

import java.io.*;
import java.util.*;
public class Main {
    // 主函数：读取输入并输出答案
    public static void main(String[] a)throws Exception {
        FS fs=new FS();
        int n=fs.ni();
        long[] c=new long[n+1];
        int[] pa=new int[n+1];
        for(int i=1;i<=n;i++)c[i]=fs.nl();
        for(int i=1;i<=n;i++)pa[i]=fs.ni();
        int[] indeg=new int[n+1];
        for(int i=1;i<=n;i++)indeg[pa[i]]++;
        boolean[] rem=new boolean[n+1];
        ArrayDeque<Integer> q=new ArrayDeque<>();
        for(int i=1;i<=n;i++)if(indeg[i]==0)q.add(i);
        while(!q.isEmpty()) {
            int u=q.poll();
            rem[u]=true;
            int v=pa[u];
            indeg[v]--;
            if(indeg[v]==0&&!rem[v])q.add(v);
        }
        boolean[] vis=new boolean[n+1];
        long ans=0;
        for(int i=1;i<=n;i++) {
            if(!rem[i]&&!vis[i]) {
                long mn=c[i];
                vis[i]=true;
                int x=pa[i];
                while(x!=i) {
                    vis[x]=true;
                    if(c[x]<mn)mn=c[x];
                    x=pa[x];
                }
                ans+=mn;
            }
        }
        System.out.println(ans);
    }
    static class FS {
        byte[] d;
        int i=0;
        FS()throws IOException {
            d=System.in.readAllBytes();
        }
        String next() {
            while(i<d.length&&d[i]<=32)i++;
            int s=i;
            while(i<d.length&&d[i]>32)i++;
            return new String(d,s,i-s);
        }
        int ni() {
            return Integer.parseInt(next());
        }
        long nl() {
            return Long.parseLong(next());
        }
    }
