驿站补给最短耗时

遮住推导与代码，先自己想，再逐段揭示

原题解析 · 拼多多 · 2026-08-23 · 算法岗 · ACM 模式（stdin/stdout）

题目描述

有 C 个驿站和 E 条双向土路。第 i 条路连接 xi 与 yi，通行需要消耗 ai 格能量并花费 wi 时间。

巡检车要从 1 号驿站到达 C 号驿站。电池容量为 B，出发时满电。在第 j 个驿站可以逐格充电，每充 1 格花费 sj 时间，电量不能超过 B。求最短到达时间；若无法到达，输出 -1。

输入描述

第一行输入三个整数 C,E,B。

第二行输入 C 个整数 s1,s2,…,sC。

接下来 E 行，每行输入 xi,yi,ai,wi，描述一条双向土路。

数据范围 ：

2≤C≤103,1≤E≤104,1≤B≤102,

0≤sj≤102,

1≤xi,yi≤C,1≤ai≤102,1≤wi≤103.

输出描述

输出从 1 号驿站到 C 号驿站的最短时间；无法到达时输出 -1。

思路分析

只记录当前驿站不足以描述状态，因为后续可走的道路还取决于剩余电量。建立分层图状态 (v,b)，表示位于驿站 v、剩余 b 格电，其中 0≤ b≤ B。

有两类转移：

若 b<B，在原地充一格电：

(v,b)→(v,b+1),代价 sv.

对道路 (v,u,a,w)，若 b≥ a，则可以通行：

(v,b)→(u,b-a),代价 w.

若 b<B，在原地充一格电：

对道路 (v,u,a,w)，若 b≥ a，则可以通行：

所有边权非负，因此从起点 (1,B) 运行 Dijkstra。第一次从堆中取出任意状态 (C,b) 时，其距离就是答案。能耗超过容量 B 的道路永远不可通行，可以在读入时丢弃。

正确性证明

任意真实行程都由“充一格电”和“通过一条道路”组成，且每一步都对应分层图中的一条边，累计时间等于路径权值。反之，分层图中的每条边都满足容量或能耗条件，因此任意图上路径都对应一段合法行程。于是原问题与从 (1,B) 到任意 (C,b) 的最短路完全等价。所有转移代价非负，Dijkstra 正确求出该最短路。

复杂度分析

状态数为 O(CB)，分层图中的充电转移为 O(CB)，道路转移为 O(EB)。时间复杂度：

O((CB+EB)log(CB)),

空间复杂度：O(CB+E)。

易错点

初始状态是满电的 (1,B)，不是 (1,0)。 到达终点时无需把电量补满；第一次弹出任意终点层即可返回。 充电单价可以为 0，但边权仍然非负，Dijkstra 依旧适用。 一条路的能耗超过 B 时，即使反复充电也无法通过。

Java 实现

// 题目：驿站补给最短耗时
// 算法：堆 / 优先队列
// 模式：ACM（stdin/stdout）
// 复杂度：时间 O((CB+EB)(CB)), 空间复杂度：O(CB+E)；空间 O(CB+E)

import java.io.*;
import java.util.*;
public class Main {
    static BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
    static StringTokenizer st;
    static String next() throws IOException {
        while (st == null || !st.hasMoreTokens()) {
            String line = br.readLine();
            if (line == null) return null;
            st = new StringTokenizer(line);
        }
        return st.nextToken();
    }
    static int nextInt() throws IOException { return Integer.parseInt(next()); }
    static long nextLong() throws IOException { return Long.parseLong(next()); }
    static class E {
        int to,energy,time;
        E(int t,int e,int tt) {
            to=t;
            energy=e;
            time=tt;
        }
    }
    // 主函数：读取输入并输出答案
    public static void main(String[] a)throws IOException {
        int ns=nextInt(),me=nextInt(),cap=nextInt();
        long[] charge=new long[ns+1];
        // 枚举位置 i
        for(int i=1;i<=ns;i++)charge[i]=nextLong();
        ArrayList<ArrayList<E>> g=new ArrayList<>();
        // 枚举位置 i
        for(int i=0;i<=ns;i++)g.add(new ArrayList<>());
        // 枚举位置 i
        for(int i=0;i<me;i++) {
            int x=nextInt(),y=nextInt(),en=nextInt(),tt=nextInt();
            // 条件判断
            if(en<=cap) {
                g.get(x).add(new E(y,en,tt));
                g.get(y).add(new E(x,en,tt));
            }
        }
        int width=cap+1;
        long INF=Long.MAX_VALUE/4;
        int total=(ns+1)*width;
        long[] dist=new long[total];
        Arrays.fill(dist,INF);
        int start=width+cap;
        dist[start]=0;
        PriorityQueue<long[]> pq=new PriorityQueue<>((p,q)->Long.compare(p[0],q[0]));
        pq.add(new long[] {
            0,start
        }
        );
        // 循环处理
        while(!pq.isEmpty()) {
            long[] top=pq.poll();
            long ct=top[0];
            int state=(int)top[1];
            // 条件判断
            if(ct!=dist[state])continue;
            int station=state/width;
            int battery=state%width;
            // 条件判断
            if(station==ns) {
                System.out.println(ct);
                // 返回结果
                return;
            }
            // 条件判断
            if(battery<cap) {
                int nst=state+1;
                long nt=ct+charge[station];
                // 条件判断
                if(nt<dist[nst]) {
                    dist[nst]=nt;
                    pq.add(new long[] {
                        nt,nst
                    }
                    );
                }
            }
            // 循环处理
            for(E e:g.get(station)) {
                // 条件判断
                if(battery<e.energy)continue;
                int nst=e.to*width+battery-e.energy;
                long nt=ct+e.time;
                // 条件判断
                if(nt<dist[nst]) {
                    dist[nst]=nt;
                    pq.add(new long[] {
                        nt,nst
                    }
                    );
                }
            }
        }
        System.out.println(-1);
    }
}

Python 实现

# 题目：驿站补给最短耗时
# 算法：堆 / 优先队列
# 模式：ACM（stdin/stdout）
# 复杂度：时间 O((CB+EB)(CB)), 空间复杂度：O(CB+E)；空间 O(CB+E)

import heapq
import sys


# 读取输入并输出答案
def solve():
    input = sys.stdin.buffer.readline
    station_count, edge_count, capacity = map(int, input().split())
    charge_time = [0] + list(map(int, input().split()))
    graph = [[] for _ in range(station_count + 1)]

    # 遍历 _
    for _ in range(edge_count):
        x, y, energy, travel_time = map(int, input().split())
        # 条件判断
        if energy <= capacity:
            graph[x].append((y, energy, travel_time))
            graph[y].append((x, energy, travel_time))

    width = capacity + 1
    infinity = 10**30
    distance = [infinity] * ((station_count + 1) * width)
    start = width + capacity
    distance[start] = 0
    heap = [(0, start)]

    # 循环处理
    while heap:
        current_time, state = heapq.heappop(heap)
        # 条件判断
        if current_time != distance[state]:
            continue

        station, battery = divmod(state, width)
        # 条件判断
        if station == station_count:
            print(current_time)
            # 返回结果
            return

        # 条件判断
        if battery < capacity:
            next_state = state + 1
            next_time = current_time + charge_time[station]
            # 条件判断
            if next_time < distance[next_state]:
                distance[next_state] = next_time
                heapq.heappush(heap, (next_time, next_state))

        for neighbor, energy, travel_time in graph[station]:
            # 条件判断
            if battery < energy:
                continue
            next_state = neighbor * width + battery - energy
            next_time = current_time + travel_time
            # 条件判断
            if next_time < distance[next_state]:
                distance[next_state] = next_time
                heapq.heappush(heap, (next_time, next_state))

    print(-1)


if __name__ == "__main__":
    solve()
