题目描述

连通无向图有 n 个景点，编号 1 到 n，有 m 条道路，按输入顺序编号 1 到 m。道路 i 连接 ui,vi，过路费为 wi，允许自环和重边。从景点 1 出发，可以反复做两类操作： 步行沿一条相邻道路到另一端，支付该边过路费，并巡检这条道路。每条道路至少要这样巡检一次。 乘快线到任意不同景点。自选一条连接两点的路线，允许重复经过景点和道路。若该路线上出现的最大道路编号为 e，本次票价仅为 we，并非最大边权，也不是路线边权之和。快线不算步行巡检。 求巡检全部道路、最后回到景点 1 的最小花费。 输入格式 ：首行 1≤T≤104。每组先读 n,m，1≤n≤2×105，0≤m≤2×105；随后 m 行按道路编号给出 ui,vi,wi，1≤ ui,vi≤ n，1≤wi≤109。每组图连通，所有组的 n 之和及 m 之和均不超过 5×105。 输出格式 ：每组一行一个最小花费。

样例

输入 输出

1
4 4
1 2 10
2 3 10
3 4 10
1 1 1
32

思路分析

第一步：先支付不可避免的巡检费用。 每条边至少步行一次，基础费用为 ∑iwi。为了最后回到起点，所有经过的步行边和快线移动组成的连通多重图必须全部为偶度数，也就是存在欧拉回路。原图奇度点必须由额外移动补成偶数，自环贡献两个度数。 额外移动可以分解成连接奇度点的路径与环，正费用环可以省去。一条额外步行路径的费用不小于这条路线上最大编号边的费用，改乘同路线快线不会更贵。快线还满足下面的超度量性质，因此多段快线也可以合成一次而不增加费用。最终只需求奇度点的最小费用两两配对。 第二步：按编号建重构树，不能按边权排序。 从仅含叶子 1,…,n 开始，按道路编号递增加边。如果合并两个不同连通块，就建立一个父节点，两个块的树根为孩子；否则不建节点。每条边的权值记到它加入后所属连通块的树节点上，节点的 own 是挂在这里的所有边权的最小值。自环和成环边虽不合并，却仍然可能显著降低票价，不能丢弃。 对节点 v 定义 根的价格就是自己的 own。没有挂边时 own 视为正无穷。 第三步：证明票价公式。 若路线最大编号为 e，则在加入前 e 条边的图中，两个端点和边 e 属于同一连通块。反过来，只要在同一块，就能先走到边 e、经过它、再到终点；允许绕路和重复使该构造合法。因此所有可能用作最大编号边的候选，正是两点最近公共祖先及其祖先节点上挂的边。于是 沿树向上 price 单调不减，故 cost(p,q)≤max(cost(p,r),cost(r,q))。这也说明合并额外移动不会更贵。 第四步：从下往上配对。 每个叶子若为奇度点，就向上交一个待配点。两个孩子各交一个时，在当前节点配成一对，支付 price；否则将剩余的一个向上交。 交换论证：若子树内两点 p,q 分别与外部 p’,q’ 配对，把它们改为内部一对、外部一对。内部价格不超过原两对中较小的价格，外部一对由超度量性质不超过原两对中较大的价格，总价不增。因此每个子树最多留一个点向外配是最优的。奇度点总数为偶数，根不会剩点。 父节点编号总大于孩子，因此倒序传播价格、正序合并奇偶即可，无须递归或真正查询 LCA。并查集另用按大小合并，避免重构树很深时影响查询效率。 样例先巡检 1、2、3 号边到达景点 4，花费 30；快线沿 3、2、1、4 号边回到 1，最大编号为 4，票价仅 1；再步行巡检 4 号自环，花费 1，总计 32。n=1 时没有奇度点，答案就是自环费用之和；m=0 的连通图只能是单点，答案为零。

题解代码

复杂度分析

时间复杂度 ：O((n+m)α(n))，按编号读入即为处理顺序，树上两遍扫描均为 O(n)。 空间复杂度 ：O(n+m)，重构树不超过 2n-1 个节点，另保存输入边。

Python 实现

import sys
input = sys.stdin.readline


def minimum_tour(n, edges):
    limit = 2 * n + 1
    infinity = 10 ** 30
    parent = [0] * limit
    left = [0] * limit
    right = [0] * limit
    price = [infinity] * limit
    odd = [0] * limit
    dsu = list(range(n + 1))
    size = [1] * (n + 1)
    node_of = list(range(n + 1))

    def find(x):
        while dsu[x] != x:
            dsu[x] = dsu[dsu[x]]
            x = dsu[x]
        return x

    count = n
    total = 0
    for u, v, weight in edges:
        total += weight
        odd[u] ^= 1
        odd[v] ^= 1
        a, b = find(u), find(v)
        if a == b:
            node = node_of[a]
            price[node] = min(price[node], weight)
        else:
            count += 1
            x, y = node_of[a], node_of[b]
            left[count], right[count] = x, y
            parent[x] = parent[y] = count
            price[count] = weight
            if size[a] < size[b]:
                a, b = b, a
            dsu[b] = a
            size[a] += size[b]
            node_of[a] = count
    for node in range(count - 1, 0, -1):
        if parent[node]:
            price[node] = min(price[node], price[parent[node]])
    for node in range(n + 1, count + 1):
        a, b = left[node], right[node]
        if odd[a] and odd[b]:
            total += price[node]
        odd[node] = odd[a] ^ odd[b]
    return total


def solve():
    tests = int(input())
    answers = []
    for _ in range(tests):
        n, m = map(int, input().split())
        edges = [tuple(map(int, input().split())) for _ in range(m)]
        answers.append(str(minimum_tour(n, edges)))
    print("\n".join(answers))


solve()
