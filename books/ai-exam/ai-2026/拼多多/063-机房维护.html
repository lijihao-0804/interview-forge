机房维护

遮住推导与代码，先自己想，再逐段揭示

来源：https://onefly.top/zero2Leetcode/04_real_interviews/pinduoduo/algo-20260816/ · 拼多多 · 2026-08-16 · 算法岗 · ACM 模式（stdin/stdout）

题意

有 n 个维护任务，第 i 个任务的开始时间、结束时间和收益分别为 si,ei,vi，占用半开区间 [si,ei)。同一时刻只能执行一个任务，每个任务至多选择一次。

若一个任务在时刻 t 结束，另一个任务恰在时刻 t 开始，两者不冲突。求可获得的最大总收益。

输入输出

第一行输入整数 n。接下来 n 行，每行输入三个整数 s,e,v。任务在输入中不保证有序。

数据范围 ：1≤n≤200000，0≤s<e≤1000000000，1≤v≤1000000000。答案可能超过 32 位整数范围。

输出一个整数，表示最大总收益。

样例

输入

输出

选择 (1,3)、(4,6)、(6,7)、(7,9) 四个任务，收益为 50+70+30+60=210。

5
1 3 50

思路

这是加权区间调度。先将任务 按结束时间升序排序 ，这样与当前任务兼容的已考虑任务必然构成排序后的一个前缀。

设 dpi 表示只考虑排序后前 i 个任务时的最大收益，且 dp0=0。对第 i 个任务 (si,ei,vi)：

不选择它，收益为 dpi-1； 选择它，在结束时间数组中二分找到最后一个满足 ej≤si 的任务。设兼容前缀含 j 个任务，则收益为 dpj+vi。

因此

使用 bisect_right 才会把结束时间恰好等于当前开始时间的任务包含进兼容前缀。

正确性证明

按照结束时间排序后，考虑前 i 个任务的任意最优方案。若方案不选第 i 个任务，它完全由前 i-1 个任务组成，收益不超过 dpi-1。若方案选择第 i 个任务，其余所选任务的结束时间都不超过 si，因此全部位于二分得到的兼容前缀中，最优收益不超过 dpj+vi。

反过来，dpi-1 对应的方案不选择当前任务，显然合法；兼容前缀最优方案中的任务均在 si 前结束，所以接上当前任务后仍无重叠，dpj+vi 也可实现。两种情况取最大便得到前 i 个任务的最优值。归纳至 i=n，所得即全局最大收益。

题解代码

复杂度

时间复杂度 ：O(nlog n)，排序与每个任务的一次二分查找占主导。

空间复杂度 ：O(n)，用于保存排序后的任务、结束时间数组和动态规划数组。

易错点

任务必须按结束时间排序，不能按开始时间排序后直接套用该状态转移。 端点相接不冲突，应使用 bisect_right 查找结束时间不大于当前开始时间的前缀。 二分范围只需覆盖当前任务之前的部分，代码用右边界 i - 1 明确限制。 最大收益可达 2×1014；Python 整数不会溢出，其他语言需使用 64 位整数。

Java 实现

// 题目：机房维护
// 算法：动态规划
// 模式：ACM（stdin/stdout）
// 复杂度：时间 O(n\log n)，排序与每个任务的一次二分查找占主导；空间 O(n)，用于保存排序后的任务、结束时间数组和动态规划数组

import java.io.*;
import java.util.*;
public class Main {
    static class T {
        int end,start,value;
        T(int e,int s,int val) {
            end=e;
            start=s;
            value=val;
        }
    }
    static int bisect(long[] arr,int lo,int hi,long key) {
        while(lo<hi) {
            int mid=(lo+hi)>>>1;
            if(arr[mid]<=key)lo=mid+1;
            else hi=mid;
        }
        return lo;
    }
    // 主函数：读取输入并输出答案
    public static void main(String[] a)throws Exception {
        FS fs=new FS();
        int n=fs.ni();
        T[] ts=new T[n];
        for(int i=0;i<n;i++) {
            int s=fs.ni(),e=fs.ni(),v=fs.ni();
            ts[i]=new T(e,s,v);
        }
        Arrays.sort(ts,(x,y)->Integer.compare(x.end,y.end));
        long[] ends=new long[n];
        for(int i=0;i<n;i++)ends[i]=ts[i].end;
        long[] dp=new long[n+1];
        for(int i=1;i<=n;i++) {
            T t=ts[i-1];
            int cc=bisect(ends,0,i-1,t.start);
            dp[i]=Math.max(dp[i-1],dp[cc]+t.value);
        }
        System.out.println(dp[n]);
    }
    static class FS {
        byte[] d;
        int i=0;
        FS()throws IOException {
            d=System.in.readAllBytes();
        }
        String next() {
            while(i<d.length&&d[i]<=32)i++;
            int s=i;
            while(i<d.length&&d[i]>32)i++;
            return new String(d,s,i-s);
        }
        int ni() {
            return Integer.parseInt(next());
        }
    }
}

        tasks.append((end, start, value))

    tasks.sort(key=lambda task: task[0])
    ends = [task[0] for task in tasks]
    dp = [0] * (n + 1)

    for i, (end, start, value) in enumerate(tasks, 1):
        compatible_count = bisect_right(ends, start, 0, i - 1)
        dp[i] = max(dp[i - 1], dp[compatible_count] + value)
