题意

商品价格为 1 到 n 的整数。选择价格分别为 a,b,c 的三件商品，要求： 1≤a≤b≤c≤n； a⊕b⊕c=0； 三个价格能够作为三角形的三条边，即任意两边之和严格大于第三边。 求满足条件的三元组数量。

输入输出

输入一行，一个整数 n。 数据范围 ：1≤n≤2500。 输出一个整数，表示合法三元组的数量。

样例 1

输入 输出 合法三元组为 (3,5,6)。

6
1

样例 2

输入 输出

10
2

思路

由异或条件可得 因此只需枚举 a,b，第三个数随之唯一确定。枚举时令 a≤b，再检查 b≤c≤n，即可保证价格有序且都在范围内。 由于 c 是最大边，三角形条件只需检查 a+b>c。整数加法满足 代入 c=a⊕b 后，a+b>c 当且仅当 a&b 非零。于是每对 (a,b) 只需常数次位运算即可判定。

正确性证明

对任意被算法计数的 (a,b,c)，算法令 c=a⊕b，所以三数异或为零；检查 a≤b≤c≤n 保证范围与顺序合法；检查 a&b 非零，根据上述恒等式等价于 a+b>c。又因为 c 为最大边，其余两条三角形不等式自动成立，因此该三元组一定合法。 反之，对任意合法三元组，由异或条件必有 c=a⊕b。算法枚举到它的 a,b 时，范围与顺序检查会通过；合法三角形满足 a+b>c，故 a&b 非零，算法必定将它计数。每个有序三元组对应唯一一对 (a,b)，不会重复。因此算法恰好统计全部合法答案。

题解代码

Python 实现

import sys


def solve():
    n = int(sys.stdin.readline())
    answer = 0

    for a in range(1, n + 1):
        for b in range(a, n + 1):
            c = a ^ b
            if b <= c <= n and (a & b) != 0:
                answer += 1

    print(answer)


if __name__ == "__main__":
    solve()

复杂度

时间复杂度 ：O(n2)，枚举所有满足 a≤b 的数对。 空间复杂度 ：O(1)，只使用若干整数变量。

易错点

价格从 1 开始，异或得到的 c=0 不合法。 必须检查 c≥b，否则会把未按非降顺序排列的三元组计入。 三角形要求严格大于；这里对应 a&b 非零，而不是允许等于零。
