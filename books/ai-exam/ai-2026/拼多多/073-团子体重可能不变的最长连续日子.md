# 团子体重可能不变的最长连续日子

> <a href="https://onefly.top/zero2Leetcode/04_real_interviews/pinduoduo/ai-20261011/" target="_blank" rel="noopener noreferrer">原题解析</a> · 拼多多 · 2026-10-11 · AI岗 · ACM 模式（stdin/stdout）

## 题目描述

按日期给出 $n$ 条整数闭区间 $[l_i,r_i]$，代表当天体重的可能值。选择非空连续日子 $[L,R]$，可以忽略至多一天的记录，但忽略后至少保留一天，并且剩下所有区间应包含某个共同整数 $x$。

求所选连续日子的最大长度 $R-L+1$，被忽略的那一天仍计入长度。

输入格式 ：仅一组数据。首行 $1\le n\le2\times10^5$；随后 $n$ 行各有 $l_i,r_i$，满足 $1\le l_i\le r_i\le10^9$。

输出格式 ：一个整数，表示最长合法连续段长度。

## 样例

输入

输出

```text
5
1 5
2 4
8 9
3 6
4 7
5
```

## 思路分析

第一步：把交集条件化为最值。 不删除记录时，公共整数存在当且仅当最大左端点不超过最小右端点；由于端点是整数，无须再考虑取整。

设最大左端点来自下标 $i$，最小右端点来自下标 $j$。删除其他任何一天都不会改变这两个冲突的最值，所以只需考虑删除 $i$ 或 $j$。若 $i=j$，该区间被所有其他区间包含，本来就有交集。

第二步：保留两个极值，且不能去重。 当 $i\ne j$ 时，删除 $i$ 后最小右端点不变，只需检查第二大左端点是否不超过最小右端点；删除 $j$ 同理，只需检查最大左端点是否不超过第二小右端点。相同端点来自不同日期时必须分别保存，不能误把第二大理解成第二个不同的数值。

第三步：滑动窗口维护。 合法窗口的任意非空子窗口仍然合法：沿用原来删掉的那一天即可；若子窗口只剩一天，就不删。因此固定右端时，合法左端形成一个后缀，双指针只需单调收缩左端。

代码采用两个懒删除堆：一个存 $(-l_i,i)$，另一个存 $(r_i,i)$。删除堆顶中下标小于左端的旧记录；临时弹出当前最值，清理过期元素后读取第二个极值，再放回。窗口长度至少为二时第二个极值一定存在；长度一直接合法。堆中未到顶的过期元素可暂时保留，总空间仍为 $O(n)$。这种写法牺牲单调队列方案的线性时间，换取更直接的“前两名”维护，仍适用于给定规模。

样例忽略第 3 天后，其余区间都包含整数 $4$，所以答案为 $5$。

```python
    while heap[0][1] < lo:
        heapq.heappop(heap)
    first = heapq.heappop(heap)
    while heap and heap[0][1] < lo:
        heapq.heappop(heap)

    heapq.heappush(heap, first)

def longest(intervals):
    max_left = []
    min_right = []

    answer = 0

            lo += 1
        answer = max(answer, hi - lo + 1)
```

## 复杂度分析

时间复杂度 ：$O(n\log n)$，每次判定做常数次堆操作，左右端点总移动次数为 $O(n)$。

空间复杂度 ：$O(n)$，两个堆和区间数组。

### Java 实现

```java
// 题目：团子体重可能不变的最长连续日子
// 算法：堆 / 优先队列
// 模式：ACM（stdin/stdout）
// 复杂度：时间 O(n\log n)，每次判定做常数次堆操作，左右端点总移动次数为 O(n)；空间 O(n)，两个堆和区间数组

import java.io.*;
import java.util.*;
public class Main {
    static final long INF=Long.MAX_VALUE/4;
    static long[] topTwo(PriorityQueue<long[]> h,long lo) {
        while(!h.isEmpty()&&h.peek()[1]<lo)h.poll();
        long[] first=h.poll();
        while(!h.isEmpty()&&h.peek()[1]<lo)h.poll();
        long second=h.isEmpty()?INF:h.peek()[0];
        h.add(first);
        return new long[] {
            first[0],first[1],second
        }
        ;
    }
    // 主函数：读取输入并输出答案
    public static void main(String[] a)throws Exception {
        FS fs=new FS();
        int n=fs.ni();
        long[][] iv=new long[n][2];
        for(int i=0;i<n;i++) {
            iv[i][0]=fs.nl();
            iv[i][1]=fs.nl();
        }
        PriorityQueue<long[]> maxLeft=new PriorityQueue<>((p,q)-> {
            if(p[0]!=q[0])return Long.compare(p[0],q[0]);return Long.compare(p[1],q[1]);
        }
        );
        PriorityQueue<long[]> minRight=new PriorityQueue<>((p,q)-> {
            if(p[0]!=q[0])return Long.compare(p[0],q[0]);return Long.compare(p[1],q[1]);
        }
        );
        int lo=0;
        int ans=0;
        for(int hi=0;hi<n;hi++) {
            maxLeft.add(new long[] {
                -iv[hi][0],hi
            }
            );
            minRight.add(new long[] {
                iv[hi][1],hi
            }
            );
            while(lo<hi) {
                long[] r1=topTwo(maxLeft,lo);
                long negLeft=r1[0];
                long i=r1[1];
                long negSecond=r1[2];
                long[] r2=topTwo(minRight,lo);
                long smallRight=r2[0];
                long j=r2[1];
                long secondRight=r2[2];
                if(i==j||-negSecond<=smallRight||-negLeft<=secondRight)break;
                lo++;
            }
            if(hi-lo+1>ans)ans=hi-lo+1;
        }
        System.out.println(ans);
    }
    static class FS {
        byte[] d;
        int i=0;
        FS()throws IOException {
            d=System.in.readAllBytes();
        }
        String next() {
            while(i<d.length&&d[i]<=32)i++;
            int s=i;
            while(i<d.length&&d[i]>32)i++;
            return new String(d,s,i-s);
        }
        int ni() {
            return Integer.parseInt(next());
        }
        long nl() {
            return Long.parseLong(next());
        }
    }
}
```
