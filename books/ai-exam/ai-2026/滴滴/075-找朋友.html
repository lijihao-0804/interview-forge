题目描述

有 N 个 A 班同学和 N 个 B 班同学，兴趣值分别为 A1,…,AN 与 B1,…,BN。将两班一一配对。若 A 班第 i 人与 B 班第 pi 人配对，矛盾值为 其中 p 是 1 到 N 的排列。求所有配对矛盾值之和的最小值。共有 T 组数据。

输入与约束

第一行：T，1≤T≤105。 每组第一行：N,M，1≤N≤105，1≤M≤109。 每组第二、三行：各 N 个整数 Ai、Bi，且 0≤ Ai,Bi<M。 所有测试数据的 N 之和不超过 3×105。 每组输出一行最小总矛盾值。

样例

输入 输出 第一组可配成 (3,2),(2,3),(1,4)，三对取模结果均为 0。

2
3 5
1 2 3
2 3 4
4 10
0 1 2 3
5 6 7 8
0
12

算法：排序贪心 + 双指针

因为 0≤ Ai,Bj<M，所以 所有对求和后，∑Ai+∑Bi 与配法无关。设满足 Ai+Bj≥ M 的配对数为 cnt，答案为 因此只需最大化达标配对数。将 A 降序、B 升序。依次处理当前最大的未处理 A 值 x：不断丢弃所有满足 x+Bj<M 的最小 B；若仍有 B，就让 x 与当前最小可达标 B 配对。

正确性证明

丢弃安全。 当前 x 是剩余 A 中最大值。若 x+b<M，则任意剩余 a≤ x 都有 a+b<M，所以 b 不可能出现在任何达标对中。 配对安全。 当最小可达标值为 b 时，若某个最优方案让 x 配更大的 b’，而 b 配某个 a≤ x，交换后 x+b≥ M；原来若 a+b’ 达标，交换后 a 得到的是 b’（等价地按两对重新安排），达标对数不会减少。也可视为：给最大 x 使用刚好够用的最小 B，保留更大的 B 只会让余下较小 A 更容易达标。 重复上述交换，可把某个最优方案变成贪心方案而不减少达标对数，故贪心最大化 cnt，从而最小化原目标。

复杂度分析

每组排序耗时 O(Nlog N)，双指针 O(N)；额外空间 O(N)（计输入及排序数组）。总规模约束下为 O(∑NlogN)。

易错点

必须利用 Ai,Bi<M，否则一对可能减去多个 M，上述二值改写失效。 目标是最大化“和至少为 M”的配对数，不是逐对最小化原余数。 B 指针既表示丢弃也表示已使用，只能单调前进。 总和可能超过 32 位；其他语言应使用 64 位整数。

import sys


def min_conflict(a, b, m):
    total = sum(a) + sum(b)
    a.sort(reverse=True)
    b.sort()
    n = len(a)
    j = 0
    cnt = 0
    for x in a:
        while j < n and x + b[j] < m:
            j += 1
        if j == n:
            break
        cnt += 1
        j += 1
    return total - m * cnt


def main():
    data = list(map(int, sys.stdin.buffer.read().split()))
    it = iter(data)
    t = next(it)
    out = []
    for _ in range(t):
        n = next(it)
        m = next(it)
        a = [next(it) for _ in range(n)]
        b = [next(it) for _ in range(n)]
        out.append(str(min_conflict(a, b, m)))
    sys.stdout.write("\n".join(out))


if __name__ == "__main__":
    main()
