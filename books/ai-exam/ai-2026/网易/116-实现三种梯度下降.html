实现三种梯度下降

遮住推导与代码，先自己想，再逐段揭示

原题解析 · 网易 · 2026-09-29 · 算法岗 · ACM 模式（stdin/stdout）

题目描述

线性回归的预测向量为 ^y=Xw。给定特征矩阵、目标向量、初始权重和训练参数，以均方误差为损失，执行指定轮数的梯度下降。

三种方法严格按以下规则更新：

batch ：每轮使用全部 m 个样本，梯度为 2mXT(Xw-y)，更新一次。 stochastic ：每轮按输入顺序逐个处理样本。第 i 个样本的梯度为 2xi(xiTw-yi)，算完立刻更新，不随机打乱。 mini_batch ：每轮按输入顺序分成大小为 batch_size 的连续批次。每批梯度为 2batchsizeXbT(Xbw-yb)，算完立即更新。 尾批即使不足指定大小，分母仍固定为 batch_size 。

每次更新均为 w←w-ηg，其中 η 为学习率，不另加偏置项。

输入描述

七行依次输入：

X ：形状为 (m,n) 的二维列表。 y ：长度为 m 的列表。 weights ：长度为 n 的初始权重列表。 learning_rate ：学习率。 n_iterations ：迭代轮数。 batch_size ：批量大小。 method ：带引号的字符串，为上述三种方法之一。

数据范围：1≤m≤50，1≤n≤5； X 与 y 的元素绝对值不超过 10，初始权重元素绝对值不超过 1；0<η≤0.01，1≤niterations≤1000，1≤ batchsize≤ m。数据保证迭代过程不会发散。

输出描述

返回最终权重向量，按 NumPy 数组默认打印格式输出，即直接 print(weights) ，不添加逗号，不自行固定小数位数。

思路分析

第一步：写清一批数据的梯度。 设本次参与更新的样本下标集合为 B，题目规定的归一化分母为 d，则损失可表示为

LB(w)=1d∑i∈B(xiTw-yi)2.

对每个权重求导，平方项产生系数 2，内积对权重的导数为特征分量，因此梯度向量为

∇LB(w)=2dXBT(XBw-yB).

先计算残差，再左乘转置矩阵，就能一次得到所有权重的梯度。批内所有分量必须基于同一个旧权重计算，不能更新一个分量后再计算下一个分量。

第二步：把三种方法的差别归结为批次和分母。 批量方法一轮只有一个批次且 d=m；随机方法每批一个样本且 d=1；小批量方法每批最多 batch_size 个样本且 d=batchsize。依次处理这些批次即可复用更新公式。

“随机”只是方法名称，本题明确要求顺序遍历，不做洗牌。后一批的残差应使用前一批更新后的权重。尾批固定分母也是本题特定口径，不能替换为常见实现中的实际尾批长度。

第三步：保持浮点类型和输出格式。 输入矩阵与权重转为浮点数组。样例使用 batch ，所以每轮一次更新， batch_size=2 不参与该方法的梯度计算。

正确性说明

初始权重与输入相同。假设某次更新前权重正确，代码选出的样本集合和分母与当前方法的规定一致，计算的矩阵表达式正是上述梯度，再按学习率更新，所得权重也正确。按批次、轮次归纳，完成指定轮数后得到要求的最终权重。

题解代码

复杂度分析

时间复杂度 ：O(Tmn)，T 为迭代轮数。三种方法每轮都处理所有样本，每个样本的计算量与特征数成正比。

空间复杂度 ：O(mn)，主要用于特征矩阵以及向量；切片不需要复制整个矩阵。

Java 实现

// 题目：实现三种梯度下降
// 算法：按题意模拟
// 模式：ACM（stdin/stdout）
// 复杂度：时间 O(Tmn)，T 为迭代轮数；空间 O(mn)，主要用于特征矩阵以及向量；切片不需要复制整个矩阵

import java.io.*;
import java.util.*;

public class Main {
    static BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
    static StringTokenizer st;
    static String next() throws IOException {
        while (st == null || !st.hasMoreTokens()) {
            String line = br.readLine();
            if (line == null) return null;
            st = new StringTokenizer(line);
        }
        return st.nextToken();
    }
    static int nextInt() throws IOException { return Integer.parseInt(next()); }
    static long nextLong() throws IOException { return Long.parseLong(next()); }
    static String nextLine() throws IOException { return br.readLine(); }

    static int pos = 0;
    static String src;

    // 核心方法：skipWs
    static void skipWs() { while (pos < src.length() && Character.isWhitespace(src.charAt(pos))) pos++; }

    // 核心方法：parseValue
    static Object parseValue() {
        skipWs();
        char c = src.charAt(pos);
        // 条件判断
        if (c == '(') return parseSeq(')');
        // 条件判断
        if (c == '[') return parseSeq(']');
        // 返回结果
        return parseNumber();
    }

    // 核心方法：parseSeq
    static List<Object> parseSeq(char close) {
        List<Object> list = new ArrayList<>();
        pos++;
        skipWs();
        // 条件判断
        if (src.charAt(pos) == close) { pos++; return list; }
        // 循环处理
        while (true) {
            list.add(parseValue());
            skipWs();
            char c = src.charAt(pos);
            // 条件判断
            if (c == ',') { pos++; continue; }
            // 条件判断
            if (c == close) { pos++; break; }
        }
        // 返回结果
        return list;
    }

    // 核心方法：parseNumber
    static Double parseNumber() {
        skipWs();
        int start = pos;
        // 条件判断
        if (src.charAt(pos) == '+' || src.charAt(pos) == '-') pos++;
        // 循环处理
        while (pos < src.length()) {
            char c = src.charAt(pos);
            // 条件判断
            if (Character.isDigit(c) || c == '.' || c == 'e' || c == 'E') pos++;
            else if ((c == '+' || c == '-') && pos > start && (src.charAt(pos - 1) == 'e' || src.charAt(pos - 1) == 'E')) pos++;
            else break;
        }
        // 返回结果
        return Double.parseDouble(src.substring(start, pos));
    }

    // 核心方法：toMatrix
    static double[][] toMatrix(Object o) {
        List<Object> rows = (List<Object>) o;
        double[][] m = new double[rows.size()][];
        // 枚举位置 i
        for (int i = 0; i < rows.size(); i++) {
            List<Object> row = (List<Object>) rows.get(i);
            m[i] = new double[row.size()];
            // 枚举阶段 j
            for (int j = 0; j < row.size(); j++) m[i][j] = (Double) row.get(j);
        }
        // 返回结果
        return m;
    }

    // 核心方法：toVector
    static double[] toVector(Object o) {
        List<Object> v = (List<Object>) o;
        double[] a = new double[v.size()];
        // 枚举位置 i
        for (int i = 0; i < v.size(); i++) a[i] = (Double) v.get(i);
        // 返回结果
        return a;
    }

    // 主函数：读取输入并输出答案
    public static void main(String[] args) throws IOException {
        String xLine = nextLine();
        String yLine = nextLine();
        String wLine = nextLine();
        String lrLine = nextLine();
        String iterLine = nextLine();
        String batchLine = nextLine();
        String methodLine = nextLine();
        src = xLine; pos = 0;
        double[][] X = toMatrix(parseValue());
        src = yLine; pos = 0;
        double[] y = toVector(parseValue());
        src = wLine; pos = 0;
        double[] w = toVector(parseValue());
        double learningRate = Double.parseDouble(lrLine.trim());
        int nIterations = Integer.parseInt(iterLine.trim());
        int batchSize = Integer.parseInt(batchLine.trim());
        String method;
        // 条件判断
        if (methodLine.contains("stochastic")) method = "stochastic";
        else if (methodLine.contains("mini")) method = "mini";
        else method = "batch";
        int m = X.length;
        int d = w.length;
        int step;
        // 条件判断
        if (method.equals("batch")) step = m;
        else if (method.equals("stochastic")) step = 1;
        else step = batchSize;
        // 循环处理
        for (int it = 0; it < nIterations; it++) {
            // 循环处理
            for (int start = 0; start < m; start += step) {
                int end = Math.min(start + step, m);
                int len = end - start;
                double[] residual = new double[len];
                // 枚举位置 i
                for (int i = start; i < end; i++) {
                    double s = 0;
                    // 枚举阶段 j
                    for (int j = 0; j < d; j++) s += X[i][j] * w[j];
                    residual[i - start] = s - y[i];
                }
                double[] gradient = new double[d];
                // 枚举阶段 j
                for (int j = 0; j < d; j++) {
                    double s = 0;
                    // 枚举位置 i
                    for (int i = start; i < end; i++) s += X[i][j] * residual[i - start];
                    gradient[j] = (2.0 / step) * s;
                }
                // 枚举阶段 j
                for (int j = 0; j < d; j++) w[j] -= learningRate * gradient[j];
            }
        }
        StringBuilder sb = new StringBuilder("[");
        // 枚举阶段 j
        for (int j = 0; j < d; j++) {
            // 条件判断
            if (j > 0) sb.append(' ');
            sb.append(Double.toString(w[j]));
        }
        sb.append(']');
        System.out.println(sb.toString());
    }
}

Python 实现

# 题目：实现三种梯度下降
# 算法：按题意模拟
# 模式：ACM（stdin/stdout）
# 复杂度：时间 O(Tmn)，T 为迭代轮数；空间 O(mn)，主要用于特征矩阵以及向量；切片不需要复制整个矩阵

import ast
import sys
import numpy as np

input = sys.stdin.readline


# 核心函数：gradient_descent
def gradient_descent(X, y, weights, learning_rate,
                     n_iterations, batch_size, method):
    m = len(X)
    w = weights.copy()
    # 条件判断
    if method == "batch":
        step = m
    # 条件判断
    elif method == "stochastic":
        step = 1
    else:
        step = batch_size
    # 遍历 _
    for _ in range(n_iterations):
        # 遍历 start
        for start in range(0, m, step):
            xb = X[start:start + step]
            yb = y[start:start + step]
            residual = xb @ w - yb
            gradient = (2.0 / step) * xb.T @ residual
            w = w - learning_rate * gradient
    # 返回结果
    return w


# 读取输入并输出答案
def solve():
    X = np.array(ast.literal_eval(input()), dtype=float)
    y = np.array(ast.literal_eval(input()), dtype=float)
    weights = np.array(ast.literal_eval(input()), dtype=float)
    learning_rate = float(input())
    n_iterations = int(input())
    batch_size = int(input())
    method = ast.literal_eval(input())
    print(gradient_descent(X, y, weights, learning_rate,
                           n_iterations, batch_size, method))


if __name__ == "__main__":
    solve()
