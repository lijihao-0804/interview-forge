# 金钩钓鱼

> <a href="https://onefly.top/zero2Leetcode/04_real_interviews/netease/algo-20260929/" target="_blank" rel="noopener noreferrer">原题解析</a> · 网易 · 2026-09-29 · 算法岗 · ACM 模式（stdin/stdout）

## 题目描述

两位玩家 sanqiu 和 xiran 玩纸牌游戏。牌的点数包括 A 、 2 至 10 、 J 、 Q 、 K ，不区分花色，不使用大小王和空白牌。

给定按牌堆从顶到底排列的字符串，两人轮流摸走全部牌， sanqiu 先摸。每位玩家按摸牌顺序形成一个手牌队列，先摸的牌先打。之后由 sanqiu 先出牌，按以下规则进行：

当前玩家取手牌队首的一张牌放到桌面末尾。 若打出非 J 的牌，且桌上原本有相同点数，就收走从那张旧牌到新牌之间的所有牌，包含两端。 若打出 J 且此前桌面非空，收走全部桌面牌，包含新打出的 J 。若此前桌面为空，则 J 留在桌面，不收牌，称为空钩。 收回的牌依次加入自己的手牌队尾， 最后打出的牌最先入队 。收牌后仍由当前玩家继续出牌；没有收牌则轮到对方。 某人没有手牌时立即结束。但如果打出最后一张牌后又收回了牌，不判定其失败。

## 输入描述

输入一个牌堆字符串 $S$，$1\le\lvert S\rvert\le56$。例如 A2345610KKQQ 中 A 是顶牌， 10 是一张牌但占两个字符。

数据保证游戏在 $10^4$ 回合内结束。

## 输出描述

输出两行：第一行为胜者 xiran 或 sanqiu ；第二行为胜者剩余手牌，按下一张出牌到最后一张的顺序排列，牌之间用一个空格分隔。

## 思路分析

第一步：正确拆牌并发牌。 扫描字符串，遇到 1 时连同后面的 0 读成 10 ，其他点数各占一个字符。从下标 $0$ 开始，偶数位置的牌给 sanqiu ，奇数位置的牌给 xiran 。手牌用双端队列，支持从左取牌、向右收牌。

第二步：用栈记录桌面顺序。 桌面列表末尾是最后打出的牌。要收牌时，从末尾逐张弹出，再追加到当前玩家队尾，自然满足“最后打出的最先入队”，无需额外翻转。

若旧桌面中相同点数的位置为 $p$，放上新牌后一直弹出，直到桌面只剩前 $p$ 张，便恰好收走两张相同牌及中间所有牌。对于 J ，只需判断打出之前桌面是否为空；非空则全部弹出，空桌则保留。

第三步：收牌后不换人。 可以用变量 collected 记录本轮是否发生收牌。若收到牌，当前玩家保持不变；否则换人。将“双方仍都有牌”作为循环条件，使胜负判定发生在本轮收牌处理之后，避免误判打出末张却马上收回牌的情况。

桌面同一点数不会同时留下两张非 J 的牌，因为第二张出现就会触发收牌。线性查找相同点数不会有多个候选位置。无论收牌多少次，手牌与桌面的牌总数始终保持不变。

## 正确性说明

初始两个队列恰好是轮流摸牌得到的顺序。假设一轮开始时双方手牌、桌面和当前玩家均与真实游戏一致，代码从队首取出相同的牌，按 J 、相同点数、无收牌三种情况执行规则，并按桌面逆序追加队尾，所以本轮结束后的牌序正确。当前玩家是否切换也与规则一致。逐轮归纳，结束时输出的胜者及其手牌均正确。

## 题解代码

### Python 实现

```python
# 题目：金钩钓鱼
# 算法：按题意模拟
# 模式：ACM（stdin/stdout）
# 复杂度：时间 O( S+TC)，T 为实际回合数、C 为牌数；空间 O(C)，两个队列、桌面与解析列表所用存储均与牌数成正比

import sys
from collections import deque

input = sys.stdin.readline


# 核心函数：parse_cards
def parse_cards(s):
    cards = []
    i = 0
    # 循环处理
    while i < len(s):
        # 条件判断
        if s[i] == "1":
            cards.append("10")
            i += 2
        else:
            cards.append(s[i])
            i += 1
    # 返回结果
    return cards


# 核心函数：play
def play(cards):
    hands = [deque(cards[::2]), deque(cards[1::2])]
    table = []
    current = 0
    # 循环处理
    while hands[0] and hands[1]:
        card = hands[current].popleft()
        collected = False
        # 条件判断
        if card == "J" and table:
            table.append(card)
            # 循环处理
            while table:
                hands[current].append(table.pop())
            collected = True
        # 条件判断
        elif card != "J" and card in table:
            position = table.index(card)
            table.append(card)
            # 循环处理
            while len(table) > position:
                hands[current].append(table.pop())
            collected = True
        else:
            table.append(card)
        # 条件判断
        if not collected:
            current = 1 - current
    winner = 0 if hands[0] else 1
    # 返回结果
    return ("sanqiu", "xiran")[winner], list(hands[winner])


# 读取输入并输出答案
def solve():
    winner, hand = play(parse_cards(input().strip()))
    print(winner)
    print(" ".join(hand))


if __name__ == "__main__":
    solve()
```

## 复杂度分析

时间复杂度 ：$O(\lvert S\rvert+TC)$，$T$ 为实际回合数、$C$ 为牌数。每轮查找与收牌最多遍历 $C$ 张牌；这里给出直接实现的保守上界。

空间复杂度 ：$O(C)$，两个队列、桌面与解析列表所用存储均与牌数成正比。

### Java 实现

```java
// 题目：金钩钓鱼
// 算法：按题意模拟
// 模式：ACM（stdin/stdout）
// 复杂度：时间 O( S+TC)，T 为实际回合数、C 为牌数；空间 O(C)，两个队列、桌面与解析列表所用存储均与牌数成正比

import java.io.*;
import java.util.*;

public class Main {
    // 核心方法：parseCards
    static List<String> parseCards(String s) {
        List<String> cards = new ArrayList<>();
        int i = 0;
        // 循环处理
        while (i < s.length()) {
            // 条件判断
            if (s.charAt(i) == '1') {
                cards.add("10");
                i += 2;
            } else {
                cards.add(String.valueOf(s.charAt(i)));
                i += 1;
            }
        }
        // 返回结果
        return cards;
    }

    // 主函数：读取输入并输出答案
    public static void main(String[] args) throws Exception {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        String line = br.readLine();
        // 条件判断
        if (line == null) return;
        List<String> cards = parseCards(line.trim());
        List<ArrayDeque<String>> hands = new ArrayList<>();
        hands.add(new ArrayDeque<String>());
        hands.add(new ArrayDeque<String>());
        // 枚举位置 i
        for (int i = 0; i < cards.size(); i++) hands.get(i % 2).addLast(cards.get(i));
        ArrayList<String> table = new ArrayList<>();
        int current = 0;
        // 循环处理
        while (!hands.get(0).isEmpty() && !hands.get(1).isEmpty()) {
            String card = hands.get(current).pollFirst();
            boolean collected = false;
            // 条件判断
            if (card.equals("J") && !table.isEmpty()) {
                table.add(card);
                // 循环处理
                while (!table.isEmpty()) hands.get(current).addLast(table.remove(table.size() - 1));
                collected = true;
            } else if (!card.equals("J") && table.contains(card)) {
                int position = table.indexOf(card);
                table.add(card);
                // 循环处理
                while (table.size() > position) hands.get(current).addLast(table.remove(table.size() - 1));
                collected = true;
            } else {
                table.add(card);
            }
            // 条件判断
            if (!collected) current = 1 - current;
        }
        int winner = hands.get(0).isEmpty() ? 1 : 0;
        String[] names = {"sanqiu", "xiran"};
        System.out.println(names[winner]);
        StringBuilder sb = new StringBuilder();
        boolean first = true;
        // 循环处理
        for (String c : hands.get(winner)) {
            // 条件判断
            if (!first) sb.append(' ');
            sb.append(c);
            first = false;
        }
        System.out.println(sb.toString());
    }
}
```
