# 恰好按键 k 次的子串

> <a href="https://onefly.top/zero2Leetcode/04_real_interviews/netease/algo-20260929/" target="_blank" rel="noopener noreferrer">原题解析</a> · 网易 · 2026-09-29 · 算法岗 · ACM 模式（stdin/stdout）

## 题目描述

游戏机有 0 、 1 两个按钮。按住一个按钮可以连续打印任意多个对应字符，换字符时必须重新按键。给定长度为 $n$ 的 01 字符串，统计最少恰好按键 $k$ 次就能打印出的非空子串数量。

这里的“最少恰好”表示 $k$ 次可以完成，而 $k-1$ 次不能完成；不是统计最少次数大于等于 $k$ 的子串。不同位置的子串分别计数，即使字符内容相同。

## 输入描述

第一行两个正整数 $n,k$，第二行为长度为 $n$ 的 01 字符串。

数据范围为 $1\le n,k\le10^6$。分档范围分别为：20% 的数据不超过 $5$，40% 不超过 $300$，60% 不超过 $5000$，100% 不超过 $10^6$。

## 输出描述

输出符合条件的子串数量。

## 样例 1

输入

输出

```text
6 2
001100
8
```

## 样例 2

输入

输出

```text
3 1
110
4
```

## 思路分析

第一步：按键次数就是连续段数。 相邻字符不同时必须换按钮，而一整段相同字符只需按住同一个按钮。因此任意非空子串的最少次数，等于其内部相邻字符变化次数加一。

把整个字符串压缩为连续段长度数组 $a$，共 $r$ 段。例如 001100 得到 $[2,2,2]$。直接枚举子串需要二次方的工作量；压段以后，只需枚举子串起点在哪一段。

第二步：当 $k\ge2$ 时使用乘法原理。 若左端点位于第 $i$ 段，恰好覆盖 $k$ 段就意味着右端点位于第 $i+k-1$ 段。中间各段只能全部包含，不存在额外选择。左端点有 $a_i$ 种选法，右端点有 $a_{i+k-1}$ 种选法，且两端所在段不同，任意组合均合法。

$$ans=\sum_{i=0}^{r-k}a_i a_{i+k-1}\qquad(k\ge2).$$

样例 1 有两组相邻段，每组贡献 $2\times2=4$，总计 $8$。

第三步：单独处理 $k=1$。 两端在同一段时必须保证左端点不在右端点之后，不能直接相乘。长度为 $a_i$ 的一段包含 $a_i(a_i+1)/2$ 个非空子串，累加即可。样例 2 的段长为 $[2,1]$，贡献为 $3+1=4$。

如果 $k>r$，不存在足够多的段，答案为 $0$。Python 整数可以直接保存结果，不会发生 32 位溢出。

## 正确性说明

每个子串由唯一的左右端点确定，也属于唯一的起始段和结束段。$k\ge2$ 时，上式恰好枚举所有相距 $k-1$ 段的端点段组合，并将其中每对合法端点计数一次；$k=1$ 时逐段枚举所有段内子串。两种情况都无重无漏，因此答案正确。

## 题解代码

### Python 实现

```python
# 题目：恰好按键 k 次的子串
# 算法：按题意模拟
# 模式：ACM（stdin/stdout）
# 复杂度：时间 O(n)，压缩与统计各进行一次线性遍历；空间 O(n)，保存字符串及至多 n 个段长

import sys
from itertools import groupby

input = sys.stdin.readline


# 核心函数：count_substrings
def count_substrings(s, k):
    runs = [sum(1 for _ in group) for _, group in groupby(s)]
    # 条件判断
    if k > len(runs):
        # 返回结果
        return 0
    # 条件判断
    if k == 1:
        # 返回结果
        return sum(length * (length + 1) // 2 for length in runs)
    # 返回结果
    return sum(runs[i] * runs[i + k - 1]
               # 枚举位置 i
               for i in range(len(runs) - k + 1))


# 读取输入并输出答案
def solve():
    n, k = map(int, input().split())
    s = input().strip()
    print(count_substrings(s, k))


if __name__ == "__main__":
    solve()
```

## 复杂度分析

时间复杂度 ：$O(n)$，压缩与统计各进行一次线性遍历。

空间复杂度 ：$O(n)$，保存字符串及至多 $n$ 个段长。

### Java 实现

```java
// 题目：恰好按键 k 次的子串
// 算法：按题意模拟
// 模式：ACM（stdin/stdout）
// 复杂度：时间 O(n)，压缩与统计各进行一次线性遍历；空间 O(n)，保存字符串及至多 n 个段长

import java.io.*;
import java.util.*;

public class Main {
    // 主函数：读取输入并输出答案
    public static void main(String[] args) throws Exception {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        StringTokenizer st = new StringTokenizer(br.readLine());
        int n = Integer.parseInt(st.nextToken());
        int k = Integer.parseInt(st.nextToken());
        String s = br.readLine().trim();
        List<Integer> runs = new ArrayList<>();
        int i = 0;
        // 循环处理
        while (i < s.length()) {
            int j = i;
            // 循环处理
            while (j < s.length() && s.charAt(j) == s.charAt(i)) j++;
            runs.add(j - i);
            i = j;
        }
        long ans = 0;
        // 条件判断
        if (k > runs.size()) {
            ans = 0;
        } else if (k == 1) {
            // 循环处理
            for (int len : runs) ans += (long) len * (len + 1) / 2;
        } else {
            // 循环处理
            for (int idx = 0; idx + k - 1 < runs.size(); idx++)
                ans += (long) runs.get(idx) * runs.get(idx + k - 1);
        }
        System.out.println(ans);
    }
}
```
