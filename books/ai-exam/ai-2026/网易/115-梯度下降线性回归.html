题目描述

编写一个使用梯度下降执行线性回归的过程。函数以 NumPy 数组 X（已带截距列的特征）和 y（目标）为输入，另外接收学习率 α 与迭代次数，返回表示线性回归模型系数的 NumPy 数组。 系数初始化为全 0，每次迭代使用全部样本计算均方误差的平均梯度 并按 更新，其中 m 为样本数。支持 numpy、scipy、pandas、scikit-learn 库。

输入描述

第 1 行输入 X，第 2 行输入 y，第 3 行输入 α，第 4 行输入迭代次数。 X 为 m 行 d 列的二维列表，第一列恒为 1（截距列）；y 为长度 m 的一维列表。样本数与特征数满足 1 ≤ m ≤ 50、2 ≤ d ≤ 4，学习率满足 0<α≤0.1，迭代次数满足 1≤iters≤5000。

输出描述

输出线性回归模型的系数，四舍五入到小数点后四位，按 NumPy 数组的默认打印格式输出，即 print(np.round(theta, 4)) 的结果。

思路分析

第一步：确认模型与初值。 线性模型为 y^=Xθ。截距已经作为第一列全 1 放进 X，θ0 本身就是截距，不需要再单独维护一个偏置项。系数初值题面规定为全 0，这是口径的一部分——迭代次数固定时，换初值会得到不同的中间结果。 第二步：写清楚梯度是怎么来的。 损失取均方误差的一半： 系数 12 与求导时平方落下的 2 恰好抵消，梯度里只剩 1m，写成矩阵形式正是题面给出的 残差 Xθ-y 的形状是 (m,)；左乘 X⊤ 把每条样本的误差按特征摊回各维，得到形状 (d,) 的梯度。 第三步：向量化实现。 逐样本、逐维度用两层循环算梯度，单轮就是 O(md) 次解释器层面的操作，5000 轮下来是百万级常数；改写成两次矩阵乘向量交给底层 BLAS 执行，常数能小两个数量级，代码也更贴近公式。 第四步：守住两个口径。 第一，必须跑满题面给定的轮数，不能因为梯度已经足够小就提前退出。样例在 1000 轮后得到 [0.8678,1.045]，距离真解 [1,1] 还有明显差距，提前停止或者改用正规方程一步求解都会直接判错。第二，输出必须走 print(np.round(theta, 4)) ，NumPy 会自动对齐列宽并把 1.045 补成 1.045 加一个空格；换成打印 Python 列表会得到逗号分隔的格式，与样例不一致。

题解代码

Python 实现

import ast
import sys

import numpy as np

input = sys.stdin.readline


# 用批量梯度下降拟合线性回归，返回跑满 iters 轮后的系数向量
def linear_regression_gd(X, y, alpha, iters):
    m = X.shape[0]
    # 系数从全 0 出发，这是题面规定的初值
    theta = np.zeros(X.shape[1])
    for _ in range(iters):
        # 预测值与真实值的残差：(m, d) @ (d,) -> (m,)
        residual = X @ theta - y
        # 均方误差的平均梯度：(d, m) @ (m,) -> (d,)，除以 m 取样本平均
        gradient = X.T @ residual / m
        # 沿负梯度方向走一步，步长由学习率 alpha 控制
        theta = theta - alpha * gradient
    return theta


def solve():
    # 前两行是 Python 列表字面量，用 literal_eval 安全解析
    X = np.array(ast.literal_eval(input()), dtype=float)
    y = np.array(ast.literal_eval(input()), dtype=float)
    alpha = float(input())
    iters = int(input())

    theta = linear_regression_gd(X, y, alpha, iters)
    # 直接打印 NumPy 数组，题面要求的就是它的默认格式（含对齐补出的空格）
    print(np.round(theta, 4))


if __name__ == "__main__":
    solve()

复杂度分析

时间复杂度 ：O(T × m × d)，其中 T 是迭代次数。每轮两次矩阵乘向量是瓶颈，轮数由输入钉死省不掉；m ≤ 50、d ≤ 4、T ≤ 5000 时总量约 106 次浮点运算。 空间复杂度 ：O(md)，存放特征矩阵与目标向量；系数与梯度只占 O(d)。

易错点

必须跑满题面给定的轮数，不能按梯度大小提前收敛退出，也不能改用正规方程直接求解。 系数初值是全 0，初值不同会导致有限轮数后的结果不同。 梯度里的除法是除以样本数 m，漏掉这个因子等于放大了学习率。 输出要直接打印 NumPy 数组，用列表打印会多出逗号，空格对齐方式也不同。
