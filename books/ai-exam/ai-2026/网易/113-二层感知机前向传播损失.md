# 二层感知机前向传播损失

> <a href="https://onefly.top/zero2Leetcode/04_real_interviews/netease/algo-20260919/" target="_blank" rel="noopener noreferrer">原题解析</a> · 网易 · 2026-09-19 · 算法岗 · ACM 模式（stdin/stdout）

## 题目描述

某电商平台计划在大促到来之前优化商品个性化推荐排序模型，在深度学习排序模型的基础上引入感知机对数据做初步分析。以二层感知机为例，第一层前向传播计算结果为 $Z_{1}=f(W_{1}X+b_{1})$，在此基础上第二层为 $Z_{2}=f(W_{2}Z_{1}+b_{2})$，激活函数都是 sigmoid。使用交叉熵损失函数，对应单条训练样本的表达式为

$$Loss=-y\cdot \log h-(1-y)\log(1-h)$$

其中 $y,h$ 分别表示样本的真值和预测的输出。

注意：输出层有多个节点时，总损失为各节点损失之和；$\log$ 为自然对数。

## 输入描述

以两个二维 list 的形式给定 $W_{1}$ 和 $W_{2}$，以同一个标量给定 $b_{1},b_{2}$（题面说明两者数值相同），再以两个二维 list 的形式给定训练数据 $X$ 和标签值 $Y$。五项在同一行内以逗号分隔，使用形如 Python 中 eval 函数的方式可以获取并还原到原始数据。

$W_{1}$ 为 $h$ 行 $d$ 列，$W_{2}$ 为 $o$ 行 $h$ 列，$X$ 为 $d$ 行 $1$ 列，$Y$ 为 $o$ 行 $1$ 列，其中 $1 \le d,h,o \le 10$；权重、偏置与特征取值均在 $[-1,1]$ 内，标签取值为 $0$ 或 $1$。

## 输出描述

给出在给定损失函数下首次前向传播完成后的 loss 值，结果以 float 类型返回，保留小数点后 3 位（与 round 函数的格式一致）。

## 思路分析

第一步：看清维度与乘法方向。 $W_{1}$ 的形状是 $(h,d)$，左乘列向量 $X$ 并加上偏置，再过一次 sigmoid：

$$Z_{1}=\sigma(W_{1}X+b),\qquad \sigma(z)=\frac{1}{1+e^{-z}}$$

维度变化为 $(h,d)\times(d,1)\to(h,1)$。偏置 $b$ 是一个标量，靠广播加到每个隐藏节点上。这里 $X$ 是列向量、权重在左，如果改成右乘或者把矩阵转置，维度立刻对不上，这是本题最容易翻车的地方。

第二步：同样的结构再走一层。 第二层的形状完全相同，只是输入换成 $Z_{1}$，而且偏置仍然用同一个 $b$（题面说明 $b_{1},b_{2}$ 给定数值相同，因此两份代码共用一个标量即可）：

$$h=\sigma(W_{2}Z_{1}+b)$$

维度变化为 $(o,h)\times(h,1)\to(o,1)$，$h$ 的每个分量是一个输出节点的预测概率。

第三步：逐节点算交叉熵，再求和。 对每个输出节点套题面公式，然后把 $o$ 个节点的损失相加：

$$Loss=\sum_{k=1}^{o}\left[-y_{k}\ln h_{k}-(1-y_{k})\ln(1-h_{k})\right]$$

标签为 $1$ 的节点只剩前一项，标签为 $0$ 的只剩后一项，逐节点代入时不要漏项。样例两个节点分别贡献 $0.4069$ 与 $1.2431$，相加为 $1.650$；若改成取平均会得到 $0.825$，与样例不符，所以本题口径确定是求和。

第四步：数值稳定性的取舍。 工程实现通常会给 $\ln$ 加一个极小量 $\varepsilon$ 防止 $h$ 取到 $0$ 或 $1$。本题权重、偏置与特征都在 $[-1,1]$ 内，隐藏层维数最多为 $10$，第二层输入的绝对值不超过 $10 \times 1+1=11$，sigmoid 的输出严格落在 $(0,1)$ 内且与两端都留有距离，不会出现 $\ln 0$，因此照公式原样实现即可。

## 题解代码

### Python 实现

```python
# 题目：二层感知机前向传播损失
# 算法：按题意模拟
# 模式：ACM（stdin/stdout）
# 复杂度：时间 O(hd+oh)，两次矩阵乘向量是全部开销，sigmoid 与损失都只是逐元素 O(h+o) 的运算；空间 O(hd+oh)，存放两个权重矩阵；中间结果 Z_1 与 h 只占 O(h+o)

import ast
import sys

import numpy as np

input = sys.stdin.readline


# sigmoid 激活：把任意实数压到 (0, 1)，两层共用
def sigmoid(z):
    return 1.0 / (1.0 + np.exp(-z))


# 做一次前向传播，返回输出层所有节点的交叉熵损失之和
def forward_loss(W1, W2, b, X, Y):
    # 第一层：隐藏层输出，(h, d) @ (d, 1) -> (h, 1)
    Z1 = sigmoid(W1 @ X + b)
    # 第二层：输出层预测值，偏置与第一层是同一个 b，(o, h) @ (h, 1) -> (o, 1)
    H = sigmoid(W2 @ Z1 + b)
    # 逐节点算交叉熵，取值范围内 H 严格落在 (0, 1) 内，log 不会取到 0
    per_node = -Y * np.log(H) - (1 - Y) * np.log(1 - H)
    # 题面要求多个输出节点时损失相加，不取平均
    return float(np.sum(per_node))

    W1 = np.array(W1, dtype=float)
```

## 复杂度分析

时间复杂度 ：$O(hd+oh)$，两次矩阵乘向量是全部开销，sigmoid 与损失都只是逐元素 $O(h+o)$ 的运算。

空间复杂度 ：$O(hd+oh)$，存放两个权重矩阵；中间结果 $Z_{1}$ 与 $h$ 只占 $O(h+o)$。

## 易错点

$X$ 是列向量、权重左乘；转置或改成右乘会直接判错。 两层共用同一个偏置 $b$，不要给第二层另配一个偏置。 多个输出节点的损失是相加而不是取平均，改成平均后样例会输出 $0.825$。 标签为 $1$ 的节点只剩 $-\log h$，为 $0$ 的只剩 $-\log(1-h)$，逐节点代入时不要漏项。

### Java 实现

```java
// 题目：二层感知机前向传播损失
// 算法：按题意模拟
// 模式：ACM（stdin/stdout）
// 复杂度：时间 O(hd+oh)，两次矩阵乘向量是全部开销，sigmoid 与损失都只是逐元素 O(h+o) 的运算；空间 O(hd+oh)，存放两个权重矩阵；中间结果 Z_1 与 h 只占 O(h+o)

import java.io.*;
import java.util.*;
import java.math.BigDecimal;
import java.math.RoundingMode;

public class Main {
    static int pos = 0;
    static String src;

    static void skipWs() { while (pos < src.length() && Character.isWhitespace(src.charAt(pos))) pos++; }

    static Object parseValue() {
        skipWs();
        char c = src.charAt(pos);
        if (c == '(') return parseSeq(')');
        if (c == '[') return parseSeq(']');
        return parseNumber();
    }

    static List<Object> parseSeq(char close) {
        List<Object> list = new ArrayList<>();
        pos++;
        skipWs();
        if (src.charAt(pos) == close) { pos++; return list; }
        while (true) {
            list.add(parseValue());
            skipWs();
            char c = src.charAt(pos);
            if (c == ',') { pos++; continue; }
            if (c == close) { pos++; break; }
        }
        return list;
    }

    static Double parseNumber() {
        skipWs();
        int start = pos;
        if (src.charAt(pos) == '+' || src.charAt(pos) == '-') pos++;
        while (pos < src.length()) {
            char c = src.charAt(pos);
            if (Character.isDigit(c) || c == '.' || c == 'e' || c == 'E') pos++;
            else if ((c == '+' || c == '-') && pos > start && (src.charAt(pos - 1) == 'e' || src.charAt(pos - 1) == 'E')) pos++;
            else break;
        }
        return Double.parseDouble(src.substring(start, pos));
    }

    static double[][] toMatrix(Object o) {
        List<Object> rows = (List<Object>) o;
        double[][] m = new double[rows.size()][];
        for (int i = 0; i < rows.size(); i++) {
            List<Object> row = (List<Object>) rows.get(i);
            m[i] = new double[row.size()];
            for (int j = 0; j < row.size(); j++) m[i][j] = (Double) row.get(j);
        }
        return m;
    }

    static double[] toVector(Object o) {
        List<Object> v = (List<Object>) o;
        double[] a = new double[v.size()];
        for (int i = 0; i < v.size(); i++) a[i] = (Double) v.get(i);
        return a;
    }

    static double[][] matMul(double[][] A, double[][] B) {
        int n = A.length, p = B.length, m = B[0].length;
        double[][] C = new double[n][m];
        for (int i = 0; i < n; i++)
            for (int j = 0; j < m; j++) {
                double s = 0;
                for (int k = 0; k < p; k++) s += A[i][k] * B[k][j];
                C[i][j] = s;
            }
        return C;
    }

    static double[][] addBias(double[][] M, Object b) {
        double[][] R = new double[M.length][];
        if (b instanceof Double) {
            double s = (Double) b;
            for (int i = 0; i < M.length; i++) {
                R[i] = new double[M[i].length];
                for (int j = 0; j < M[i].length; j++) R[i][j] = M[i][j] + s;
            }
        } else {
            List<Object> bl = (List<Object>) b;
            if (!bl.isEmpty() && bl.get(0) instanceof List) {
                double[][] bm = toMatrix(b);
                for (int i = 0; i < M.length; i++) {
                    R[i] = new double[M[i].length];
                    for (int j = 0; j < M[i].length; j++) R[i][j] = M[i][j] + bm[i % bm.length][0];
                }
            } else {
                double[] bv = toVector(b);
                for (int i = 0; i < M.length; i++) {
                    R[i] = new double[M[i].length];
                    for (int j = 0; j < M[i].length; j++) R[i][j] = M[i][j] + bv[j % bv.length];
                }
            }
        }
        return R;
    }

    static double sigmoid(double z) { return 1.0 / (1.0 + Math.exp(-z)); }

    static String format3(double v) {
        BigDecimal bd = new BigDecimal(v).setScale(3, RoundingMode.HALF_EVEN);
        String s = bd.stripTrailingZeros().toPlainString();
        if (s.indexOf('.') < 0) s += ".0";
        return s;
    }

    // 主函数：读取输入并输出答案
    public static void main(String[] args) throws Exception {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        StringBuilder all = new StringBuilder();
        String l;
        while ((l = br.readLine()) != null) all.append(l);
        src = all.toString();
        Object root = parseValue();
        List<Object> parts = (List<Object>) root;
        double[][] W1 = toMatrix(parts.get(0));
        double[][] W2 = toMatrix(parts.get(1));
        Object b = parts.get(2);
        double[][] X = toMatrix(parts.get(3));
        double[][] Y = toMatrix(parts.get(4));
        double[][] Z1 = addBias(matMul(W1, X), b);
        for (int i = 0; i < Z1.length; i++) for (int j = 0; j < Z1[i].length; j++) Z1[i][j] = sigmoid(Z1[i][j]);
        double[][] H = addBias(matMul(W2, Z1), b);
        for (int i = 0; i < H.length; i++) for (int j = 0; j < H[i].length; j++) H[i][j] = sigmoid(H[i][j]);
        double loss = 0;
        for (int i = 0; i < H.length; i++)
            for (int j = 0; j < H[i].length; j++) {
                double h = H[i][j];
                double y = Y[i][j];
                loss += -y * Math.log(h) - (1 - y) * Math.log(1 - h);
            }
        System.out.println(format3(loss));
    }
}
```
