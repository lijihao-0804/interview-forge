镜子实验室

遮住推导与代码，先自己想，再逐段揭示

来源：https://onefly.top/zero2Leetcode/04_real_interviews/jd/algo-20260926/ · 京东 · 2026-09-26 · 算法岗 · ACM 模式（stdin/stdout）

题目描述

实验室是 n 行 m 列的网格，每格为 . 、 / 或 \ 。从每个格子分别向上、右、下、左发射光线，共有 4nm 种起始条件。

每一步，光线 先在当前格子反射，再沿新方向移动一格 ：

. ：方向不变。 / ：上与右互换，下与左互换。 \ ：上与左互换，下与右互换。

离开网格即成功逃离；光线也可能永远在网格中循环。起始位置或起始方向不同就视为不同光线，求最终能逃离的光线数量。

第一行是测试组数 T，满足 1≤T≤100。每组先输入 n,m，再输入 n 行长度为 m 的网格。满足 n,m≥1、nm≤106，所有测试组的 nm 之和不超过 106。每组输出一个整数。

输入

输出

思路分析

第一步：把格子和方向一起作为状态。

一个状态是“位于某格、尚未处理该格镜子的运动方向”。这恰好对应一种起始光线，共 4nm 个状态。每个状态的后继唯一；逐束模拟虽然直接，但会反复走过相同路径，最坏达到平方级工作量。

第二步：证明前驱也至多一个。

如果光线以方向 d 进入某格，那么前一格只能是沿 d 反方向退一格的位置。在前一格中，空地及两种镜面的方向映射都是双射，所以反射前方向也唯一。若前一格位于网格外，该状态没有内部前驱。

因此状态图中，每个点的入度和出度都不超过一。有限图的每个连通部分只能是链或环：环上的光线永不逃离；链的末端一定离开网格。 链不可能汇入环 ，否则汇入点会有两个前驱。

第三步：从没有前驱的状态开始走。

所有链的起点恰好是边界入口：第一行向下、最后一行向上、第一列向右、最后一列向左。枚举这些入口，沿反射规则一直走到出口。每访问一个状态，就找到一种能够逃离的起始条件，累加访问次数即可。

各条链不共享状态，也不会进入环，所以不需要访问标记或判环集合。注意统计的是 链上的状态数 ，不是入口数量。单行、单列或角上的同一个格子会出现多个入口，但方向不同，对应不同状态，不重复计数。

第四步：用一圈哨兵简化边界。

将方向依次编码为 0,1,2,3（上、右、下、左），反射用查表完成。把网格存为一维字节数组，四周补值为 3 的哨兵；走到哨兵就结束。实际格子的编码为 0 、 1 、 2 。入口用生成器逐个产生，不额外保存整个入口列表。

样例第一组没有镜子，所有状态均逃离。第二组既有外侧链，也有内部循环；只遍历边界链便会得到答案 8 ，不会陷入内部循环。

题解代码

复杂度分析

时间复杂度 ：O(nm)，各条链互不相交，总访问次数不超过 4nm，建立网格也为线性开销。

空间复杂度 ：O(nm)，保存带边框的网格；入口和输入行均逐个产生。

Java 实现

// 题目：镜子实验室
// 算法：按题意模拟
// 模式：ACM（stdin/stdout）
// 复杂度：时间 O(nm)，各条链互不相交，总访问次数不超过 4nm，建立网格也为线性开销；空间 O(nm)，保存带边框的网格；入口和输入行均逐个产生

import java.util.*;
public class Main {
    // 主函数：读取输入并输出答案
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        if (!sc.hasNextInt()) return;
        int t = sc.nextInt();
        int[][] TURN = {{0,1,2,3},{1,0,3,2},{3,2,1,0}};
        StringBuilder out = new StringBuilder();
        for (int tc = 0; tc < t; tc++) {
            int n = sc.nextInt();
            int m = sc.nextInt();
            int width = m + 2;
            byte[] grid = new byte[(n + 2) * width];
            Arrays.fill(grid, (byte)3);
            for (int r = 1; r <= n; r++) {
                String row = sc.next();
                for (int c = 1; c <= m; c++) {
                    char ch = row.charAt(c - 1);
                    int v = ch == '.' ? 0 : (ch == '/' ? 1 : 2);
                    grid[r * width + c] = (byte) v;
                }
            }
            int[] steps = {-width, 1, width, -1};
            long total = 0;
            for (int col = 1; col <= m; col++) {
                total += escape(grid, width + col, 2, TURN, steps);
                total += escape(grid, n * width + col, 0, TURN, steps);
            }
            for (int row = 1; row <= n; row++) {
                total += escape(grid, row * width + 1, 1, TURN, steps);
                total += escape(grid, row * width + m, 3, TURN, steps);
            }
            if (tc > 0) out.append((char)10);
            out.append(total);
        }
        System.out.print(out);
    }
    static long escape(byte[] grid, int pos, int direction, int[][] TURN, int[] steps) {
        long count = 0;
        while (grid[pos] != 3) {
            direction = TURN[grid[pos]][direction];
            pos += steps[direction];
            count++;
        }
        return count;
    }
}

Python 实现

# 题目：镜子实验室
# 算法：按题意模拟
# 模式：ACM（stdin/stdout）
# 复杂度：时间 O(nm)，各条链互不相交，总访问次数不超过 4nm，建立网格也为线性开销；空间 O(nm)，保存带边框的网格；入口和输入行均逐个产生

import sys


TURN = ((0, 1, 2, 3), (1, 0, 3, 2), (3, 2, 1, 0))
TRANS = bytes.maketrans(b"./\\", bytes((0, 1, 2)))


def boundary_starts(n, m, width):
    for col in range(1, m + 1):
        yield width + col, 2
        yield n * width + col, 0
    for row in range(1, n + 1):
        yield row * width + 1, 1
        yield row * width + m, 3


def count_escape(n, m, rows):
    width = m + 2
    grid = bytearray([3]) * width
    for row in rows:
        grid.append(3)
        grid.extend(row.translate(TRANS))
        grid.append(3)
    grid.extend(bytearray([3]) * width)
    steps = (-width, 1, width, -1)
    total = 0
    for pos, direction in boundary_starts(n, m, width):
        while grid[pos] != 3:
            direction = TURN[grid[pos]][direction]
            pos += steps[direction]
            total += 1
    return total
