锚点最远盲区

遮住推导与代码，先自己想，再逐段揭示

原题解析 · 京东 · 2026-08-22 · 算法岗 · ACM 模式（stdin/stdout）

题目描述

在整数坐标轴上有 n 个温感锚点，第 i 个锚点的位置为 ui。全体位置构成整数数组 U。

对任意非空数组 U，定义：

L=min(U),R=max(U).

对区间 [L,R] 内的每个整数 x，其到最近锚点的距离为

d(x)=mini|x-ui|.

盲区半径定义为

W(U)=maxx∈Z,L≤x≤Rd(x).

现在进行 t 次修改。每次给出 r z ，将编号为 r 的锚点位置改为 z。每次修改后输出当前的 W(U)。

同一位置可以有多个锚点。

输入描述

第一行输入两个整数 n,t，分别表示锚点数量和修改次数。

第二行输入 n 个整数 u1,u2,…,un，表示初始位置。

接下来 t 行，每行输入两个整数 r,z，表示将第 r 个锚点的位置改为 z。

本题修改规模达到 105 量级，需要近似 O(log(n+t)) 地处理每次修改。

输出描述

输出 t 行，每行一个整数，表示对应修改后的盲区半径。

第一次修改后，去重位置为 [2,7,9,12]，相邻最大间距为 5，所以盲区半径为 ⌊5/2⌋=2。

关键化简

将当前不同位置去重并排序：

x1<x2<⋯<xk.

任意整数点 x∈[L,R] 要么位于锚点上，要么位于某一对相邻位置 xi,xi+1 之间。在该段内，最近锚点距离为

min(x-xi,xi+1-x),

其最大值出现在中点附近，等于

⌊xi+1-xi2⌋.

因此

W(U)=(0,k=1,displaystylemax1≤i<k⌊xi+1-xi2⌋,k≥2.)

因为向下取整是单调的，只需维护去重后相邻位置的最大间距 G，答案就是 ⌊G/2⌋。

数据结构设计

所有可能出现的位置只来自初始数组和 t 次修改目标。先离线读入全部修改，对这些坐标排序去重并压缩。

维护三部分状态：

cnt[i] ：压缩坐标 i 上当前有多少个锚点； 树状数组：保存各压缩坐标的锚点计数，用前缀秩查询当前位置的前驱和后继； 间隔多重集：保存去重位置序列中每一对相邻坐标的间距，支持插入、删除和取最大值。

Python 没有内置有序多重集，可以使用“计数字典 + 懒删除大根堆”。删除间隔时只减少计数；查询最大值时不断弹出计数已经归零的堆顶。

删除一个锚点

先将旧位置计数减一：

若计数仍大于 0，去重位置序列没有变化，不修改任何间隔； 若计数从 1 变成 0，该位置真正消失： 左右邻居都存在：删除两段旧间隔，加入左右邻居之间的新间隔； 只有一侧邻居：删除端点处的一段旧间隔； 两侧都不存在：当前没有间隔。

左右邻居都存在：删除两段旧间隔，加入左右邻居之间的新间隔； 只有一侧邻居：删除端点处的一段旧间隔； 两侧都不存在：当前没有间隔。

插入一个锚点

若目标位置原本已有锚点，只增加计数，不修改间隔。

若计数从 0 变成 1：

左右邻居都存在：删除跨过新位置的旧间隔，加入两段新间隔； 只有一侧邻居：加入端点处的新间隔； 两侧都不存在：它是唯一的去重位置，不产生间隔。

一次修改固定按“删除旧位置，再插入新位置”处理。即使新旧坐标相同，也会正确恢复原状态。

正确性证明

引理 1 ：对于任意两个相邻的不同锚点位置 xi<xi+1，该区间内整数点到最近锚点距离的最大值为 ⌊(xi+1-xi)/2⌋。

证明 ：区间内任意点的最近距离为 min(x-xi,xi+1-x)。前一项随 x 增大，后一项随 x 减小，最小值在两者最接近时最大，即中点附近；整数点上的最大值为间距的一半向下取整。

引理 2 ：间隔多重集始终恰好包含当前去重位置序列的全部相邻间距。

证明 ：初始时按去重排序序列加入所有相邻间距。删除一个仍有重复锚点的位置或插入已有位置时，去重序列不变。真正删除位置时，只有它两侧的相邻关系变化，算法按邻居存在情况准确删除旧边并合并；真正插入位置时，只有跨过该位置的相邻关系变化，算法准确拆分或新增端点边。因此每次操作后不变量成立。

引理 3 ：树状数组查询得到的前驱和后继是当前去重位置中距离目标坐标最近的左右邻居。

证明 ：树状数组按坐标顺序保存正计数。目标位置为空时，其前缀计数给出左侧锚点总秩，第 r 个锚点所在坐标即最近前驱，第 r+1 个锚点所在坐标即最近后继。重复锚点只占同一压缩坐标，不改变前驱后继坐标。

定理 ：每次修改后算法输出正确的 W(U)。

证明 ：由引理 2，间隔多重集维护当前全部相邻间距；由引理 1，最大间距除以二向下取整就是盲区半径。若只有一个不同位置，则区间退化为单点，算法输出 0。因此每次答案正确。

复杂度分析

设离线收集后共有 m≤ n+t 个不同坐标。

坐标压缩：O((n+t)log(n+t))。 每次修改：删除与插入各执行常数次树状数组和堆操作，均摊 O(log(n+t))。 总时间复杂度：O((n+t)log(n+t))。 空间复杂度：O(n+t)。

易错点

必须先对位置去重；同一坐标上的多个锚点不会产生长度为 0 的“相邻间隔”。 只有位置计数跨越 0 与 1 时才更新间隔。 删除中间位置是“两段合一段”，插入中间位置是“一段拆两段”。 答案是最大间距整除 2，不是向上取整。 需要离线读取修改目标后再做坐标压缩。 懒删除堆中可能保留失效元素，读取堆顶前必须根据计数表清理。

Java 实现

// 题目：锚点最远盲区
// 算法：堆 / 优先队列
// 模式：ACM（stdin/stdout）
// 复杂度：时间 O((n+t)(n+t))；空间 O(n+t)

import java.io.*;
import java.util.*;

public class Main {
    static BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
    static StringTokenizer st;
    static String next() throws IOException {
        while (st == null || !st.hasMoreTokens()) {
            String line = br.readLine();
            if (line == null) return null;
            st = new StringTokenizer(line);
        }
        return st.nextToken();
    }
    static int nextInt() throws IOException { return Integer.parseInt(next()); }
    static long nextLong() throws IOException { return Long.parseLong(next()); }

    static long[] coordsLong;
    // 主函数：读取输入并输出答案
    public static void main(String[] args) throws IOException {
        // 条件判断
        int n = nextInt();
        int t = nextInt();
        long[] positions = new long[n];
        // 枚举位置 i
        for (int i = 0; i < n; i++) positions[i] = nextLong();
        int[] qIdx = new int[t];
        long[] qVal = new long[t];
        TreeSet<Long> coordSet = new TreeSet<>();
        // 枚举位置 i
        for (int i = 0; i < n; i++) coordSet.add(positions[i]);
        // 枚举位置 i
        for (int i = 0; i < t; i++) { qIdx[i] = nextInt() - 1; qVal[i] = nextLong(); coordSet.add(qVal[i]); }
        long[] coords = new long[coordSet.size()];
        int ci = 0; for (long v : coordSet) coords[ci++] = v;
        coordsLong = coords;
        int size = coords.length;
        Map<Long,Integer> rank = new HashMap<>();
        // 枚举位置 i
        for (int i = 0; i < size; i++) rank.put(coords[i], i);
        int[] count = new int[size];
        int[] bit = new int[size + 1];
        final int[] totalBox = {0};
        int distinct = 0;
        Map<Long,Integer> gapCount = new HashMap<>();
        PriorityQueue<Long> maxHeap = new PriorityQueue<>();
        // 枚举位置 i
        for (int i = 0; i < size; i++) { }
        // initialize below after helper definitions
        Solver solver = new Solver(count, bit, size, coords, totalBox, gapCount, maxHeap);
        // 循环处理
        for (long value : positions) solver.addIndex(rank.get(value));
        int prev = -1;
        // 枚举位置 i
        for (int i = 0; i < size; i++) {
            // 条件判断
            if (count[i] > 0) { if (prev >= 0) solver.gapAdd(coords[i] - coords[prev]); prev = i; }
        }
        StringBuilder sb = new StringBuilder();
        // 循环处理
        for (int qi = 0; qi < t; qi++) {
            solver.removeAt(rank.get(positions[qIdx[qi]]));
            positions[qIdx[qi]] = qVal[qi];
            solver.insertAt(rank.get(qVal[qi]));
            int ans = solver.distinct <= 1 ? 0 : (int) (solver.largestGap() / 2);
            // 条件判断
            if (qi > 0) sb.append((char)10);
            sb.append(ans);
        }
        System.out.print(sb);
    }
    static class Solver {
        int[] count; int[] bit; int size; long[] coords; int[] totalBox; Map<Long,Integer> gapCount; PriorityQueue<Long> maxHeap; int distinct = 0;
        Solver(int[] count, int[] bit, int size, long[] coords, int[] totalBox, Map<Long,Integer> gapCount, PriorityQueue<Long> maxHeap) {
            this.count = count; this.bit = bit; this.size = size; this.coords = coords; this.totalBox = totalBox; this.gapCount = gapCount; this.maxHeap = maxHeap;
        }
        void bitAdd(int index, int delta) { totalBox[0] += delta; index += 1; while (index <= size) { bit[index] += delta; index += index & -index; } }
        int bitSum(int index) { int result = 0; index += 1; while (index > 0) { result += bit[index]; index -= index & -index; } return result; }
        int bitKth(int k) { int index = 0; int step = 1 << (31 - Integer.numberOfLeadingZeros(size)); while (step != 0) { int nxt = index + step; if (nxt <= size && bit[nxt] < k) { index = nxt; k -= bit[nxt]; } step >>= 1; } return index; }
        int[] neighbors(int index) { int leftCount = bitSum(index); int left = leftCount > 0 ? bitKth(leftCount) : -1; int right = leftCount < totalBox[0] ? bitKth(leftCount + 1) : -1; return new int[]{left, right}; }
        void gapAdd(long gap) { gapCount.merge(gap, 1, Integer::sum); maxHeap.add(-gap); }
        void gapRemove(long gap) { gapCount.put(gap, gapCount.getOrDefault(gap, 0) - 1); }
        long largestGap() { while (!maxHeap.isEmpty() && gapCount.getOrDefault(-maxHeap.peek(), 0) == 0) maxHeap.poll(); return maxHeap.isEmpty() ? 0 : -maxHeap.peek(); }
        void addIndex(int index) { if (count[index] == 0) distinct++; count[index]++; bitAdd(index, 1); }
        void removeAt(int index) {
            count[index]--;
            bitAdd(index, -1);
            // 条件判断
            if (count[index] > 0) return;
            distinct--;
            int[] nb = neighbors(index); int left = nb[0], right = nb[1];
            // 条件判断
            if (left >= 0 && right >= 0) { gapRemove(coords[index] - coords[left]); gapRemove(coords[right] - coords[index]); gapAdd(coords[right] - coords[left]); }
            else if (left >= 0) gapRemove(coords[index] - coords[left]);
            else if (right >= 0) gapRemove(coords[right] - coords[index]);
        }
        void insertAt(int index) {
            // 条件判断
            if (count[index] == 0) {
                int[] nb = neighbors(index); int left = nb[0], right = nb[1];
                // 条件判断
                if (left >= 0 && right >= 0) { gapRemove(coords[right] - coords[left]); gapAdd(coords[index] - coords[left]); gapAdd(coords[right] - coords[index]); }
                else if (left >= 0) gapAdd(coords[index] - coords[left]);
                else if (right >= 0) gapAdd(coords[right] - coords[index]);
                distinct++;
            }
            count[index]++;
            bitAdd(index, 1);
        }
    }
}

Python 实现

# 题目：锚点最远盲区
# 算法：堆 / 优先队列
# 模式：ACM（stdin/stdout）
# 复杂度：时间 O((n+t)(n+t))；空间 O(n+t)

import sys
from heapq import heappop, heappush


# 读取输入并输出答案
def solve():
    data = list(map(int, sys.stdin.buffer.read().split()))
    iterator = iter(data)
    n = next(iterator)
    t = next(iterator)
    positions = [next(iterator) for _ in range(n)]
    queries = [(next(iterator) - 1, next(iterator)) for _ in range(t)]

    coords = sorted(set(positions) | {value for _, value in queries})
    size = len(coords)
    rank = {value: index for index, value in enumerate(coords)}

    count = [0] * size
    bit = [0] * (size + 1)
    total = 0

    # 核心函数：bit_add
    def bit_add(index, delta):
        nonlocal total
        total += delta
        index += 1
        # 循环处理
        while index <= size:
            bit[index] += delta
            index += index & -index

    # 核心函数：bit_sum
    def bit_sum(index):
        result = 0
        index += 1
        # 循环处理
        while index > 0:
            result += bit[index]
            index -= index & -index
        # 返回结果
        return result

    # 核心函数：bit_kth
    def bit_kth(k):
        """返回第 k 个锚点所在的零基压缩坐标，k 从 1 开始。"""
        index = 0
        step = 1 << (size.bit_length() - 1)
        # 循环处理
        while step:
            nxt = index + step
            # 条件判断
            if nxt <= size and bit[nxt] < k:
                index = nxt
                k -= bit[nxt]
            step >>= 1
        # 返回结果
        return index

    # 核心函数：neighbors
    def neighbors(index):
        """仅在 count[index] == 0 时调用。"""
        left_count = bit_sum(index)
        left = bit_kth(left_count) if left_count > 0 else -1
        right = bit_kth(left_count + 1) if left_count < total else -1
        # 返回结果
        return left, right

    gap_count = {}
    max_heap = []

    # 核心函数：gap_add
    def gap_add(gap):
        gap_count[gap] = gap_count.get(gap, 0) + 1
        heappush(max_heap, -gap)

    # 核心函数：gap_remove
    def gap_remove(gap):
        gap_count[gap] -= 1

    # 核心函数：largest_gap
    def largest_gap():
        # 循环处理
        while max_heap and gap_count.get(-max_heap[0], 0) == 0:
            heappop(max_heap)
        # 返回结果
        return -max_heap[0] if max_heap else 0

    distinct = 0

    # 核心函数：remove_at
    def remove_at(index):
        nonlocal distinct
        count[index] -= 1
        bit_add(index, -1)
        # 条件判断
        if count[index] > 0:
            # 返回结果
            return

        distinct -= 1
        left, right = neighbors(index)
        # 条件判断
        if left >= 0 and right >= 0:
            gap_remove(coords[index] - coords[left])
            gap_remove(coords[right] - coords[index])
            gap_add(coords[right] - coords[left])
        # 条件判断
        elif left >= 0:
            gap_remove(coords[index] - coords[left])
        # 条件判断
        elif right >= 0:
            gap_remove(coords[right] - coords[index])

    # 核心函数：insert_at
    def insert_at(index):
        nonlocal distinct
        # 条件判断
        if count[index] == 0:
            left, right = neighbors(index)
            # 条件判断
            if left >= 0 and right >= 0:
                gap_remove(coords[right] - coords[left])
                gap_add(coords[index] - coords[left])
                gap_add(coords[right] - coords[index])
            # 条件判断
            elif left >= 0:
                gap_add(coords[index] - coords[left])
            # 条件判断
            elif right >= 0:
                gap_add(coords[right] - coords[index])
            distinct += 1

        count[index] += 1
        bit_add(index, 1)

    # 遍历 value
    for value in positions:
        index = rank[value]
        # 条件判断
        if count[index] == 0:
            distinct += 1
        count[index] += 1
        bit_add(index, 1)

    active = [index for index in range(size) if count[index] > 0]
    for left, right in zip(active, active[1:]):
        gap_add(coords[right] - coords[left])

    answers = []
    for item_index, new_value in queries:
        remove_at(rank[positions[item_index]])
        positions[item_index] = new_value
        insert_at(rank[new_value])
        answers.append(str(0 if distinct <= 1 else largest_gap() // 2))

    sys.stdout.write("\n".join(answers))


if __name__ == "__main__":
    solve()
