抽检子空间质心投票

遮住推导与代码，先自己想，再逐段揭示

来源：https://onefly.top/zero2Leetcode/04_real_interviews/oppo/algo-20260822/ · OPPO · 2026-08-22 · 算法岗 · ACM 模式（stdin/stdout）

题目描述

给定训练特征 X∈Rn×d 和非负整数标签 y，用 T 个基分类器对测试集分类。输入还给出每个分类器使用的特征数 m 和随机种子 seed 。只能使用 numpy 、 pandas 、 scikit-learn ，并且必须使用：

构造每个基分类器时，严格依次执行：

有放回抽袋 ：调用 rg.randint(0, n, size=n) 得到训练样本下标。 无放回抽特征 ：调用 rg.choice(d, size=m, replace=False) ，并将抽出的特征下标升序保存。 最近质心分类 ：在该袋样本和特征子集上，对每个类别 c 计算质心 μc。测试点 z 的预测为

距离相同时取类别编号较小者。

若某个类别在该袋中一次都没有抽到，不能删除该类别，而要使用完整训练集中该类别在相同特征子集上的全局质心。

全部基分类器各投一票，最终选择票数最多的类别；票数并列时同样取较小的类别编号。

rg = np.random.RandomState(seed)

输入描述

标准输入为一行 JSON，对象字段如下：

train 为二维列表，每行最后一列是标签，其余列是特征； test 只包含特征； n_estimators 是基分类器数 T； max_features 是每袋抽取的特征数 m； 标签为非负整数； 训练条数与测试条数均在 [2,19] 内； 1≤d≤9，1≤ m≤ d。

{
  "train": [[f11, f12, ..., y1], [f21, f22, ..., y2]],
  "test": [[g11, g12, ...], [g21, g22, ...]],
  "n_estimators": 5,
  "max_features": 1,
  "seed": 42
}

输出描述

只输出一个紧凑 JSON 对象：

features ：每个基分类器使用的升序特征下标； bootstraps ：每个基分类器的抽袋下标，保持随机抽取顺序； pred ：测试集的最终预测。

{"features":[[1],[0],[0]],"bootstraps":[[2,3,0,2],[3,0,0,2],[2,2,2,2]],"pred":[0,1,0]}

思路分析

全程只创建一个 RandomState ，每轮必须先抽样本、后抽特征，否则随机数流会变化。先将类别编号升序排列，并预计算各类别在完整特征空间中的全局质心。

每轮按袋内样本计算各类别在所选子空间中的均值；袋内缺失的类别则切出对应全局质心。对所有测试点向量化计算平方欧氏距离。由于类别编号有序， argmin 首值语义自然实现距离并列取小编号；同理，票箱上的 argmax 实现票数并列取小编号。

正确性说明

每轮抽袋和抽特征严格复现题面指定的随机调用顺序。对袋内存在的类别，代码使用袋内均值；对缺失类别，使用完整训练集的全局均值，故质心定义正确。平方欧氏距离与欧氏距离具有相同的大小关系， argmin 得到最近质心；升序类别数组保证距离并列取小编号。最终逐测试点统计全部票数并用相同规则取最大值，所以最终预测正确。

复杂度分析

设测试样本数为 q、类别数为 C。

时间复杂度：Obigl(T(Cn+nm+qCm)bigr)。

空间复杂度：O(nd+qCm+T(n+m))，其中最后一项用于保存并输出每个基分类器的抽袋下标和特征下标。

易错点

每轮必须先调用 randint 抽袋，再调用 choice 抽特征。 特征下标需要排序，抽袋下标不能排序。 袋内缺失的类别不能删除，必须改用该类别的全局质心。 距离并列和票数并列都取较小类别编号。 输出必须是紧凑 JSON，不能混入日志或解释文字。

Java 实现

import java.util.*;
public class Main {
    static class Json {
        private final String s; private int i;
        Json(String s) { this.s = s; }
        static Object parse(String s) { Json j = new Json(s); j.ws(); return j.value(); }
        private void ws() { while (i < s.length() && Character.isWhitespace(s.charAt(i))) i++; }
        private Object value() {
            ws(); char c = s.charAt(i);
            if (c == '{') return object();
            if (c == '[') return array();
            if (c == '"') return string();
            if (c == 't') { i += 4; return Boolean.TRUE; }
            if (c == 'f') { i += 5; return Boolean.FALSE; }
            if (c == 'n') { i += 4; return null; }
            return number();
        }
        private Map<String,Object> object() {
            Map<String,Object> m = new LinkedHashMap<>();
            i++; ws();
            if (s.charAt(i) == '}') { i++; return m; }
            while (true) {
                ws(); String k = string(); ws(); i++;
                Object v = value(); m.put(k, v); ws();
                char c = s.charAt(i++); if (c == '}') break;
            }
            return m;
        }
        private List<Object> array() {
            List<Object> a = new ArrayList<>();
            i++; ws();
            if (s.charAt(i) == ']') { i++; return a; }
            while (true) {
                a.add(value()); ws();
                char c = s.charAt(i++); if (c == ']') break;
            }
            return a;
        }
        private String string() {
            StringBuilder b = new StringBuilder(); i++;
            while (true) {
                char c = s.charAt(i++);
                if (c == '"') break;
                if (c == (char)92) {
                    char e = s.charAt(i++);
                    if (e == 'n') b.append((char)10);
                    else b.append(e);
                } else b.append(c);
            }
            return b.toString();
        }
        private Object number() {
            int start = i;
            while (i < s.length() && "+-0123456789.eE".indexOf(s.charAt(i)) >= 0) i++;
            return Double.parseDouble(s.substring(start, i));
        }
    }
    static class MT {
        int[] mt = new int[624]; int pos = 624;
        MT(long seed) {
            mt[0] = (int)(seed & 0xffffffffL);
            for (int i = 1; i < 624; i++) { long prev = mt[i-1] & 0xffffffffL; mt[i] = (int)((1812433253L * (prev ^ (prev >>> 30)) + i) & 0xffffffffL); }
            pos = 624;
        }
        void twist() {
            for (int i = 0; i < 624; i++) { long y = (mt[i] & 0x80000000L) | (mt[(i + 1) % 624] & 0x7fffffffL); long mag = (y & 1L) != 0 ? 0x9908b0dfL : 0L; mt[i] = mt[(i + 397) % 624] ^ (int)(y >>> 1) ^ (int)mag; }
            pos = 0;
        }
        long next32() { if (pos >= 624) twist(); long y = mt[pos++] & 0xffffffffL; y ^= (y >>> 11); y ^= (y << 7) & 0x9d2c5680L; y ^= (y << 15) & 0xefc60000L; y ^= (y >>> 18); return y & 0xffffffffL; }
        long interval(long max) { if (max == 0) return 0; long mask = max; mask |= mask >> 1; mask |= mask >> 2; mask |= mask >> 4; mask |= mask >> 8; mask |= mask >> 16; while (true) { long value = next32() & mask; if (value <= max) return value; } }
    }
    public static void main(String[] args) throws Exception {
        java.io.BufferedReader br = new java.io.BufferedReader(new java.io.InputStreamReader(System.in));
        String line = br.readLine();
        Map<String,Object> root = (Map<String,Object>) Json.parse(line);
        List<Object> trainRows = (List<Object>) root.get("train");
        int nSamples = trainRows.size();
        int dimsPlus = ((List<Object>) trainRows.get(0)).size();
        int nDims = dimsPlus - 1;
        double[][] xTrain = new double[nSamples][nDims];
        int[] labels = new int[nSamples];
        for (int i = 0; i < nSamples; i++) {
            List<Object> row = (List<Object>) trainRows.get(i);
            for (int j = 0; j < nDims; j++) xTrain[i][j] = ((Number) row.get(j)).doubleValue();
            labels[i] = (int) Math.round(((Number) row.get(nDims)).doubleValue());
        }
        List<Object> testRows = (List<Object>) root.get("test");
        int nTest = testRows.size();
        double[][] xTest = new double[nTest][nDims];
        for (int i = 0; i < nTest; i++) { List<Object> row = (List<Object>) testRows.get(i); for (int j = 0; j < nDims; j++) xTest[i][j] = ((Number) row.get(j)).doubleValue(); }
        int nEstimators = ((Number) root.get("n_estimators")).intValue();
        int maxFeatures = ((Number) root.get("max_features")).intValue();
        long seed = ((Number) root.get("seed")).longValue();
        int[] unique = Arrays.stream(labels).distinct().sorted().toArray();
        int nClasses = unique.length;
        double[][] globalCenters = new double[nClasses][nDims];
        for (int c = 0; c < nClasses; c++) {
            int cnt = 0; double[] sum = new double[nDims];
            for (int i = 0; i < nSamples; i++) if (labels[i] == unique[c]) { cnt++; for (int j = 0; j < nDims; j++) sum[j] += xTrain[i][j]; }
            for (int j = 0; j < nDims; j++) globalCenters[c][j] = cnt > 0 ? sum[j] / cnt : 0.0;
        }
        MT rg = new MT(seed);
        int[][] votes = new int[nTest][nClasses];
        List<int[]> allFeatures = new ArrayList<>();
        List<int[]> allBoot = new ArrayList<>();
        for (int est = 0; est < nEstimators; est++) {
            int[] bagRows = new int[nSamples];
            for (int i = 0; i < nSamples; i++) bagRows[i] = (int) rg.interval(nSamples - 1);
            int[] perm = new int[nDims];
            for (int i = 0; i < nDims; i++) perm[i] = i;
            for (int i = nDims - 1; i > 0; i--) { int j = (int) rg.interval(i); int tmp = perm[j]; perm[j] = perm[i]; perm[i] = tmp; }
            int[] featureIds = Arrays.copyOf(perm, maxFeatures);
            Arrays.sort(featureIds);
            double[][] centers = new double[nClasses][maxFeatures];
            for (int c = 0; c < nClasses; c++) {
                int cnt = 0; double[] sum = new double[maxFeatures];
                for (int bi = 0; bi < nSamples; bi++) {
                    int row = bagRows[bi];
                    if (labels[row] == unique[c]) { cnt++; for (int m = 0; m < maxFeatures; m++) sum[m] += xTrain[row][featureIds[m]]; }
                }
                for (int m = 0; m < maxFeatures; m++) centers[c][m] = cnt > 0 ? sum[m] / cnt : globalCenters[c][featureIds[m]];
            }
            for (int q = 0; q < nTest; q++) {
                int best = 0; double bestDist = Double.MAX_VALUE;
                for (int c = 0; c < nClasses; c++) {
                    double d = 0;
                    for (int m = 0; m < maxFeatures; m++) { double diff = xTest[q][featureIds[m]] - centers[c][m]; d += diff * diff; }
                    if (d < bestDist) { bestDist = d; best = c; }
                }
                votes[q][best]++;
            }
            allFeatures.add(featureIds.clone());
            allBoot.add(bagRows.clone());
        }
        int[] pred = new int[nTest];
        for (int q = 0; q < nTest; q++) {
            int best = 0;
            for (int c = 1; c < nClasses; c++) if (votes[q][c] > votes[q][best]) best = c;
            pred[q] = unique[best];
        }
        StringBuilder sb = new StringBuilder();
        sb.append('{').append((char)34).append("features").append((char)34).append(':').append('[');
        for (int e = 0; e < allFeatures.size(); e++) { if (e > 0) sb.append(','); sb.append('['); int[] f = allFeatures.get(e); for (int m = 0; m < f.length; m++) { if (m > 0) sb.append(','); sb.append(f[m]); } sb.append(']'); }
        sb.append(']').append(',').append((char)34).append("bootstraps").append((char)34).append(':').append('[');
        for (int e = 0; e < allBoot.size(); e++) { if (e > 0) sb.append(','); sb.append('['); int[] b = allBoot.get(e); for (int m = 0; m < b.length; m++) { if (m > 0) sb.append(','); sb.append(b[m]); } sb.append(']'); }
        sb.append(']').append(',').append((char)34).append("pred").append((char)34).append(':').append('[');
        for (int q = 0; q < nTest; q++) { if (q > 0) sb.append(','); sb.append(pred[q]); }
        sb.append(']').append('}');
        System.out.print(sb);
    }
}

Python 实现

import json
import sys

import numpy as np


def solve():
    case = json.loads(sys.stdin.buffer.readline())
    train = np.asarray(case["train"], dtype=float)
    x_train = train[:, :-1]
    labels = train[:, -1].astype(int)
    x_test = np.asarray(case["test"], dtype=float)

    n_estimators = case["n_estimators"]
    max_features = case["max_features"]
    n_samples, n_dims = x_train.shape

    classes = np.unique(labels)
    n_classes = len(classes)
    global_centers = np.stack([
        x_train[labels == class_id].mean(axis=0)
        for class_id in classes
    ])

    rg = np.random.RandomState(case["seed"])
    all_features = []
    all_bootstraps = []
    votes = np.zeros((len(x_test), n_classes), dtype=int)

    for _ in range(n_estimators):
        bag_rows = rg.randint(0, n_samples, size=n_samples)
        feature_ids = np.sort(
            rg.choice(n_dims, size=max_features, replace=False)
        )

        bag_x = x_train[bag_rows][:, feature_ids]
        bag_y = labels[bag_rows]
        centers = np.empty((n_classes, max_features), dtype=float)

        for slot, class_id in enumerate(classes):
            mask = bag_y == class_id
            if mask.any():
                centers[slot] = bag_x[mask].mean(axis=0)
            else:
                centers[slot] = global_centers[slot, feature_ids]

        gaps = x_test[:, feature_ids][:, None, :] - centers[None, :, :]
        squared_distances = np.einsum("qcm,qcm->qc", gaps, gaps)
        winners = squared_distances.argmin(axis=1)
        votes[np.arange(len(x_test)), winners] += 1

        all_features.append([int(value) for value in feature_ids])
        all_bootstraps.append([int(value) for value in bag_rows])

    prediction_slots = votes.argmax(axis=1)
    predictions = [int(classes[slot]) for slot in prediction_slots]
    answer = {
        "features": all_features,
        "bootstraps": all_bootstraps,
        "pred": predictions,
    }
    sys.stdout.write(json.dumps(answer, separators=(",", ":")))


if __name__ == "__main__":
    solve()
