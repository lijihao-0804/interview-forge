最长匀差脉冲

遮住推导与代码，先自己想，再逐段揭示

原题解析 · OPPO · 2026-08-22 · 算法岗 · ACM 模式（stdin/stdout）

题目描述

航标站记录了 p 个读数 x1,x2,…,xp，每个读数都是模 K 意义下的非负整数。相邻两次脉冲的前向变化量定义为

(xi+1-xi)modK.

若一段连续读数中每一对相邻读数的变化量都相同，就称其为一段匀差脉冲。求最长的匀差脉冲；若有多段长度相同，取起始下标最小的一段。只有一个读数时也视为一段，公共变化量记为 0。

输入描述

第一行输入两个整数 p,K，其中

1≤p≤200000,2≤K≤109.

第二行输入 p 个整数 x1,x2,…,xp。所有输入均为整数。

输出描述

输出三个整数：最长匀差脉冲的长度、左端点下标（从 1 开始）及公共变化量。

输出

5 10

思路分析

构造差分序列

di=(xi+1-xi)modK,1≤i<p.

读数中的匀差段恰好对应差分序列中的连续等值段。若差分等值段长度为 L，则对应读数段长度为 L+1。从左向右扫描，只有当前段严格更长时才更新答案，便能在等长时保留最早出现的区间。

当 p=1 时差分序列为空，直接按约定输出 1 1 0 。

正确性说明

差分定义逐项等价于题目规定的模 K 前向变化量，因此一段读数是匀差脉冲，当且仅当它对应的差分子段全部相等。扫描会枚举每个极大连续等值段并记录最长者；严格大于才更新又保证等长时保留最小起点。因此输出的长度、起点及公共变化量均正确。

复杂度分析

时间复杂度：O(p)。

空间复杂度：O(p)。

易错点

差值必须在模 m 意义下计算，直接相减会在读数回绕处断开等差段。 多个最长段并列时取起点更小者，扫描时只能在严格变长时更新答案。 单个读数也构成长度为 1 的合法区间，其公差按题意输出为 0。

Java 实现

// 题目：最长匀差脉冲
// 算法：按题意模拟
// 模式：ACM（stdin/stdout）
// 复杂度：时间 O(p)；空间 O(p)

import java.io.*;
import java.util.*;

public class Main {
    static BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
    static StringTokenizer st;
    static String next() throws IOException {
        while (st == null || !st.hasMoreTokens()) {
            String line = br.readLine();
            if (line == null) return null;
            st = new StringTokenizer(line);
        }
        return st.nextToken();
    }
    static int nextInt() throws IOException { return Integer.parseInt(next()); }
    static long nextLong() throws IOException { return Long.parseLong(next()); }

    // 主函数：读取输入并输出答案
    public static void main(String[] args) throws IOException {
        // 条件判断
        int p = (int) nextLong();
        long mod = nextLong();
        long[] values = new long[p];
        // 枚举位置 i
        for (int i = 0; i < p; i++) values[i] = nextLong();
        // 条件判断
        if (p == 1) { System.out.println("1 1 0"); return; }
        long[] diff = new long[p - 1];
        // 枚举位置 i
        for (int i = 0; i + 1 < p; i++) diff[i] = Math.floorMod(values[i + 1] - values[i], mod);
        int bestLen = 1, bestStart = 0, curStart = 0;
        // 枚举位置 i
        for (int i = 1; i < p - 1; i++) {
            // 条件判断
            if (diff[i] != diff[i - 1]) curStart = i;
            int curLen = i - curStart + 1;
            // 条件判断
            if (curLen > bestLen) { bestLen = curLen; bestStart = curStart; }
        }
        System.out.println((bestLen + 1) + " " + (bestStart + 1) + " " + diff[bestStart]);
    }
}

Python 实现

# 题目：最长匀差脉冲
# 算法：按题意模拟
# 模式：ACM（stdin/stdout）
# 复杂度：时间 O(p)；空间 O(p)

import sys


# 读取输入并输出答案
def solve():
    data = list(map(int, sys.stdin.buffer.read().split()))
    p, mod = data[0], data[1]
    values = data[2:2 + p]

    # 条件判断
    if p == 1:
        print(1, 1, 0)
        # 返回结果
        return

    diff = [(values[i + 1] - values[i]) % mod for i in range(p - 1)]
    best_len = 1
    best_start = 0
    current_start = 0

    # 枚举位置 i
    for i in range(1, p - 1):
        # 条件判断
        if diff[i] != diff[i - 1]:
            current_start = i
        current_len = i - current_start + 1
        # 条件判断
        if current_len > best_len:
            best_len = current_len
            best_start = current_start

    print(best_len + 1, best_start + 1, diff[best_start])


if __name__ == "__main__":
    solve()
