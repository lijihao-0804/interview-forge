最优分段常数量化

遮住推导与代码，先自己想，再逐段揭示

题目描述

给定已排序的 N 个整数序列，将其划分为至多 K 个连续区间。每个区间用其下中位数（长度为偶数时取第 ⌊(len+1)/2⌋ 个数）作为代表值，区间误差为所有数到代表值的绝对误差之和。求最小总误差。

思路分析

第一步：定义区间代价

数据已排序，区间 [l, r] 的下中位数位于下标 ⌊(l+r)/2⌋，用前缀和可以 O(1) 计算区间内所有数到中位数的绝对误差之和。

第二步：区间 DP 状态设计

设 f[k][i] 为把前 i 个数划分成 k 段的最小总代价：

朴素实现是 O(K · N2)，N 较大时会超时。

第三步：决策单调性优化

代价函数 cost(l,r) 满足四边形不等式，因此对固定的 k，最优切点随 i 单调不减。利用分治：先求中点的最优切点，再左右两半各在缩小后的候选区间内搜索，单层从 O(N2) 降到 O(N log N)。

第四步：多分段只减不增

多分一段不会增加总代价，最终取 f[K][N] 即可。

题解代码

复杂度分析

时间复杂度 ：O(K · N · log N)，每层分治 O(N log N)，共 K 层。 空间复杂度 ：O(N)，前缀和加滚动 DP 数组。

Java 实现

import java.util.*;
public class Main {
    static int N; static int K;
    static long[] a; static long[] pre; static long[] f; static long[] g;
    static long cost(int l, int r) {
        int mid = (l + r) / 2;
        long rep = a[mid - 1];
        return rep * (mid - l + 1) - (pre[mid] - pre[l - 1]) + (pre[r] - pre[mid]) - rep * (r - mid);
    }
    static void solve(int iL, int iR, int jL, int jR, int k) {
        if (iL > iR) return;
        int mid = (iL + iR) / 2;
        long best = Long.MAX_VALUE / 4;
        int bestj = Math.max(jL, k - 1);
        int lo = Math.max(jL, k - 1);
        int hi = Math.min(jR, mid - 1);
        for (int j = lo; j <= hi; j++) { long v = f[j] + cost(j + 1, mid); if (v < best) { best = v; bestj = j; } }
        g[mid] = best;
        solve(iL, mid - 1, jL, bestj, k);
        solve(mid + 1, iR, bestj, jR, k);
    }
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        N = sc.nextInt(); K = sc.nextInt();
        a = new long[N];
        for (int i = 0; i < N; i++) a[i] = sc.nextLong();
        pre = new long[N + 1];
        for (int i = 1; i <= N; i++) pre[i] = pre[i - 1] + a[i - 1];
        f = new long[N + 1];
        for (int i = 1; i <= N; i++) f[i] = cost(1, i);
        int kUse = Math.min(K, N);
        for (int k = 2; k <= kUse; k++) {
            g = new long[N + 1];
            Arrays.fill(g, Long.MAX_VALUE / 4);
            solve(k, N, k - 1, N - 1, k);
            f = g;
        }
        System.out.println(f[N]);
    }
}

Python 实现

import sys
sys.setrecursionlimit(1000000)

def main():
    N, K = map(int, input().split())
    a = list(map(int, input().split()))

    pre = [0] * (N + 1)
    for i in range(1, N + 1):
        pre[i] = pre[i - 1] + a[i - 1]

    def cost(l, r):
        mid = (l + r) // 2
        rep = a[mid - 1]
        return rep * (mid - l + 1) - (pre[mid] - pre[l - 1]) + (pre[r] - pre[mid]) - rep * (r - mid)

    K_use = min(K, N)
    INF = float("inf")

    f = [INF] * (N + 1)
    for i in range(1, N + 1):
        f[i] = cost(1, i)

    for k in range(2, K_use + 1):
        g = [INF] * (N + 1)

        def solve(iL, iR, jL, jR):
            if iL > iR:
                return
            mid = (iL + iR) // 2
            best, bestj = INF, max(jL, k - 1)
            lo = max(jL, k - 1)
            hi = min(jR, mid - 1)
            for j in range(lo, hi + 1):
                v = f[j] + cost(j + 1, mid)
                if v < best:
                    best, bestj = v, j
            g[mid] = best
            solve(iL, mid - 1, jL, bestj)
            solve(mid + 1, iR, bestj, jR)

        solve(k, N, k - 1, N - 1)
        f = g

    print(f[N])

main()
