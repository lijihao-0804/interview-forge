# 最优流水线并行切分

> <a href="https://onefly.top/zero2Leetcode/04_real_interviews/huawei/ai-20261028/" target="_blank" rel="noopener noreferrer">原题解析</a> · 华为 · 2026-10-28 · AI岗 · ACM 模式（stdin/stdout）

## 题目描述

把包含 N 层的深度神经网络部署到 K 个 GPU 上，采用顺序流水线并行。第 i 层计算耗时为 T[i]，输出张量对应的通信耗时为 S[i]。

相邻层在同一个 GPU 上，不产生层间通信耗时。 第 i 层和第 i + 1 层在不同 GPU 上，则产生 S[i] 的通信耗时，计入前一阶段，即以第 i 层结尾的 GPU。 将全部层按原顺序切分为 恰好 K 个非空连续子序列 ，每段分配给一个 GPU。 最后一个阶段后面没有下一层，不收取输出通信费用，即便输入提供了 S[N]。

每个 GPU 的总耗时为其层计算耗时之和，加上该阶段末尾需要支付的通信耗时。求所有合法切分中，“单个 GPU 最大总耗时”的最小值。

## 输入描述与约束

第一行：N 个空格分隔的整数，表示 T。 第二行：N 个空格分隔的整数，表示 S。 第三行：整数 K，表示 GPU 数量。

输入没有单独的 N，也没有方括号或逗号。已有材料未给出 N、K、T[i]、S[i] 的明确数值上限。按“耗时”语义使用非负值；合法切分要求 $1\le K\le N$。非法输入如何输出未披露，代码不自行约定返回 -1。由于上限未披露，下面给出与材料一致的 $O(KN^2)$ 解法，不宣称它能处理任意大规模数据。

## 输出描述

输出一个整数，表示最优切分的最大 GPU 总耗时。

## 思路分析

第一步：为什么普通分段贪心不适用？ 没有通信开销时，把非负序列多切一刀不会增大任一段的和。因此常见做法可以二分答案，再贪心检查能否用至多 K 段装下。

本题增加一个切口，会给左段新增一笔段尾通信。材料给出的反例是 T = [1, 1] 、 S = [100, 0] 、 K = 2 ：一段时耗时为 2，恰好两段时瓶颈却为 101。因此上限 2 对“至多两段”可行，对“恰好两段”不可行。失败的是这个贪心判定与段数替换，不是答案上限本身失去了可行性的单调性。

第二步：用前缀和表达一段的代价。 以下公式使用从 1 开始的层编号，令：

$$pre[0]=0,\qquad pre[i]=\sum_{t=1}^{i}T[t].$$

设上一段结束于 b，本段为第 b + 1 到 i 层，则：

$$cost(b,i)=pre[i]-pre[b]+comm(i), \qquad comm(i)=\begin{cases}S[i],&i<N,\\0,&i=N.\end{cases}$$

段内通信免费，只看末尾是否连接下一张 GPU。代码数组从零开始，因此公式中的 S[i] 对应 s[i - 1] 。

第三步：把段数写进状态。 令 $f[j][i]$ 表示前 i 层恰好组成 j 段时，这些阶段最大总耗时的最小值。特别注意：若 $i<N$，当前前缀的最后一段也需要支付向第 i + 1 层发送的费用；只有到达整网末尾 N 才免通信。

初始状态为 $f[0][0]=0$，其他状态为正无穷。枚举最后一个切口 b：

$$f[j][i]=\min_{j-1\le b<i} \max\bigl(f[j-1][b],\ pre[i]-pre[b]+comm(i)\bigr).$$

下界 $b\ge j-1$ 保证前 j - 1 段至少各有一层。 上界 $b<i$ 保证最后一段非空。 内层 max 计算某一种切法的瓶颈；外层 min 选择最优切法。 最终答案是 $f[K][N]$，而不是在所有不超过 K 的段数中取最小值。

第四步：滚动数组。 第 j 行只依赖第 j - 1 行，用 prev 保存上一行、cur 保存当前行。每完成一行就令 prev = cur 。不能直接原地覆盖同一行，否则可能误用本轮状态，破坏“恰好 j 段”的语义。

## 正确性证明

对阶段数 j 归纳。

初始情况 ：零层划为零段没有耗时，对应 $f[0][0]=0$；其余零段状态不可行，设为正无穷，正确。

归纳步骤 ：考虑前 i 层的任意合法 j 段切分，其最后一段必然是 b + 1 到 i，且 $j-1\le b<i$。前 b 层恰好分为 j - 1 段。由归纳假设，这部分的最小瓶颈是 $f[j-1][b]$；最后一段的成本只取决于 b、i，与前面具体如何切分无关。

对固定 b，将前缀替换为最优划分不会增大总瓶颈，故该切口下的最优值就是递推式中的 max。枚举范围覆盖所有合法最后切口，并且每个有限候选都能由一个合法前缀加上一个非空末段构成，因此取最小值既不会漏掉最优方案，也不会引入非法方案。

归纳得到所有状态正确，故 $f[K][N]$ 正是恰好 K 个阶段的最优瓶颈。滚动数组只删除后续不再使用的行，不改变递推结果。

### Python 实现

```python
# 题目：最优流水线并行切分
# 算法：动态规划（前缀和 + 滚动数组）
# 模式：ACM（stdin/stdout）
# 复杂度：时间 O(KN^2)；空间 O(N)

import sys


def min_max_cost(t, s, k):
    n = len(t)
    pre = [0] * (n + 1)
    for i, value in enumerate(t, 1):
        pre[i] = pre[i - 1] + value

    inf = float("inf")
    prev = [inf] * (n + 1)
    prev[0] = 0
    for j in range(1, k + 1):
        cur = [inf] * (n + 1)
        for i in range(j, n + 1):
            comm = s[i - 1] if i < n else 0
            best = inf
            for b in range(j - 1, i):
                if prev[b] == inf:
                    continue
                last = pre[i] - pre[b] + comm
                candidate = max(prev[b], last)
                if candidate < best:
                    best = candidate
            cur[i] = best
        prev = cur
    return prev[n]
```

## 复杂度分析

时间复杂度 ：$O(KN^2)$。有 $O(KN)$ 个状态，每个枚举至多 N 个切口；前缀和使每段代价在常数时间内求出。

空间复杂度 ：$O(N)$。存储输入数组、前缀和及两行 DP，不保留所有阶段数对应的状态。有效代价始终是整数，正无穷只作为不可达标记。

### Java 实现

```java
// 题目：最优流水线并行切分
// 算法：动态规划（前缀和 + 滚动数组）
// 模式：ACM（stdin/stdout）
// 复杂度：时间 O(KN^2)；空间 O(N)

import java.io.*;
import java.util.*;
public class Main {
    static long INF=Long.MAX_VALUE/4;
    static long minMax(int[] t,int[] s,int k) {
        int n=t.length;
        long[] pre=new long[n+1];
        for(int i=1;i<=n;i++)pre[i]=pre[i-1]+t[i-1];
        long[] prev=new long[n+1];
        Arrays.fill(prev,INF);
        prev[0]=0;
        for(int j=1;j<=k;j++) {
            long[] cur=new long[n+1];
            Arrays.fill(cur,INF);
            for(int i=j;i<=n;i++) {
                int comm=(i<n)?s[i-1]:0;
                long best=INF;
                for(int b=j-1;b<i;b++) {
                    if(prev[b]==INF)continue;
                    long last=pre[i]-pre[b]+comm;
                    long cand=Math.max(prev[b],last);
                    if(cand<best)best=cand;
                }
                cur[i]=best;
            }
            prev=cur;
        }
        return prev[n];
    }
    static int[] readLine(BufferedReader br)throws IOException {
        String l;
        while((l=br.readLine())!=null&&l.trim().isEmpty()) {
        }
        if(l==null)return new int[0];
        StringTokenizer st=new StringTokenizer(l);
        int[] a=new int[st.countTokens()];
        for(int i=0;i<a.length;i++)a[i]=Integer.parseInt(st.nextToken());
        return a;
    }
    // 主函数：读取输入并输出答案
    public static void main(String[] x)throws Exception {
        BufferedReader br=new BufferedReader(new InputStreamReader(System.in));
        int[] t=readLine(br);
        int[] s=readLine(br);
        String l;
        while((l=br.readLine())!=null&&l.trim().isEmpty()) {
        }
        int k=Integer.parseInt(l.trim());
        long ans=minMax(t,s,k);
        if(ans>=INF)System.out.println("inf");
        else System.out.println(ans);
    }
}
```
