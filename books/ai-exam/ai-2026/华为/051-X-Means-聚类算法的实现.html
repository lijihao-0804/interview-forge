题目描述

给定 N 个 d 维数据点及允许的簇数范围 [Kmin,Kmax]，对范围内每个簇数运行确定性 K-Means，合并重合中心，再用 BIC 选出最终聚类，输出中心和每个输入点的标签。 这里的“X-Means”按本题定义，是 枚举簇数并比较 BIC ，不是另行实现文献中基于局部二分裂的版本。 设点 xi 的标签为 c(i)，中心为 μc(i)，误差平方和为 若合并后的实际簇数为 k，使用参数数目 p=k(d+1)，评分为 BIC 越小越好 。前一项衡量拟合误差，后一项惩罚过多的簇。计算中用 (SSE+10-8)/N 保护对数输入。 按点的第一维坐标升序稳定排序；请求 K>1 个簇时，初始中心取排序后下标 i(N-1)//(K-1) 的点，其中 i=0,…,K-1。K=1 单独取排序后的第一个点。 按欧氏距离平方分配点；距离相等时取编号最小的簇。 非空簇更新为所属点的均值；空簇保留旧中心。 交替分配、更新；一轮分配后所有标签不变时收敛。 先令 Kmax=min(Kmax,N)；若此时 Kmin>Kmax，令 Kmin=Kmax。上下界相同时只运行一次。 收敛后，中心距离平方严格小于 10-4 的簇需要合并，标签同步映射；合并后的中心使用所属全部点的均值。 用合并后的实际簇数和 SSE 计算 BIC；BIC 并列时选择较小的枚举 K。实现使用 10-9 的比较容差。 输出前按中心第一维升序重新编号为 0,1,…,k-1；第一维相同保持原编号顺序，点标签仍按输入顺序输出。 实现口径 ：近邻关系不一定具有传递性，本文按材料题解的“归为同一组”实现：在合并前的中心之间连边，合并每个连通分量，然后重新求均值，不反复合并新均值。完全为空的分量保留代表中心。此细节不应被误认为所有 X-Means 实现通用的规则。

输入描述

第一行：两个整数 N,d。 接下来 N 行：每行 d 个浮点数，表示一个点。 最后一行：两个整数 Kmin,Kmax。

输出描述

第一行输出实际簇数 k；接下来 k 行输出中心，各坐标保留两位小数；最后一行输出 N 个标签。无法聚类时输出 0 。

数据范围与边界

1≤ N≤ 2000，1≤ d≤ 10。 每个坐标的绝对值不超过 104。 正常输入保证 1≤ Kmin≤ Kmax≤ N；材料同时给出越界截断规则，实现仍保留该保护。 材料未给出可保证收敛的固定迭代轮数；以下代码按标签不变停止，不把任意迭代上限说成题面保证。

思路分析

簇数增多通常能让点更接近某个中心。极端情况下，每个点单独成簇就能让 SSE 为零，但这样的模型未必有价值。题目给定的 BIC 把误差项与簇数惩罚放在一起比较，因此应完整枚举候选 K，不能看到 SSE 下降就立即接受，也不能假定 BIC 关于 K 单调。 各个 K 必须独立初始化、独立迭代，不能直接把上一轮的中心拿来续算，否则就不是题目指定的确定性结果。 分配时只比较距离平方，省去开根号。从小编号向大编号扫描，只有距离严格更小时才替换，这自然实现距离平局取小编号。 更新时累计每个簇的点数和各维坐标和，非空簇取均值，空簇跳过。上一轮已经更新过中心，如果新一轮标签完全相同，那么再更新得到的均值也相同，可以直接结束。 第一维的稳定排序只需预处理一次；初始化时按当前 K 取不同的等距下标。 把合并前的中心看成图的顶点，距离平方小于阈值时连边。使用并查集维护连通分量，并让较小编号作为代表，避免归组结果取决于边的处理顺序。 接着将每个点的旧标签映射到所在分量，重新统计点数和坐标和。合并中心必须是 所属点的加权均值 ，不能对原中心直接等权平均，因为不同簇的点数可能不同。最后用新中心和新标签重新计算 SSE。 此时请求簇数与实际簇数可能不同，甚至实际簇数小于 Kmin；BIC 中应使用实际簇数。 从小到大枚举 K，仅当新 BIC 小于当前最优值减去 10-9 时替换。这样将容差范围内的差异视为平局，保留先出现的小 K。这属于浮点比较约定，并不表示相差极小的两个真实数严格相等。 统一使用 SSE+10-8 与材料题解保持一致。这个平滑项在 SSE 极小时可能影响分数，不能断言它对所有正 SSE 都毫无影响；SSE 为零也不要求全部输入点相同，各簇内点分别重合时同样可能发生。 选定结果后再排序中心并重映射标签。仅在格式化后将字符串 -0.00 改成 0.00 ，不要提前修改坐标，否则会影响距离和 BIC。

正确性说明

  1. 每一轮执行了规定的 K-Means 操作。 固定中心时，每个点选距离平方最小的中心，逐点最小化当前分配的 SSE，并按扫描顺序解决距离平局。固定标签时，对某个非空簇及任意中心 a，有 其中 ¯x 为均值，故均值最小化该簇的 SSE；空簇对 SSE 无贡献，保留旧中心符合规则。因此交替操作不会增加 SSE。标签不变时，均值也不变，结果满足指定的停止条件。
  2. 合并符合分组口径。 并查集恰好连接所有满足阈值的中心对，其分量就是规定的合并组。重映射后每个点仍恰好属于一个组；按该组全部点求均值，得到一致的中心、标签和 SSE。
  3. 枚举保留最优候选。 每轮得到的 BIC 都使用合并后的实际簇数。按约定的浮点比较规则维护最优值，枚举结束后保留评分最优的候选，容差内并列保留较小的请求 K。最后的重编号只改变名称，不改变聚类。 这里证明的是 实现符合本题算法 ，不是证明 K-Means 求得全局最小 SSE，也不保证 BIC 选出的簇数一定等于数据的真实类别数。

题解代码

仅使用 Python 标准库，ACM 输入输出。为便于核对，代码将 K-Means、中心合并和模型选择分开实现。

Python 实现

import sys
import math

MERGE_EPS = 1e-4
BIC_EPS = 1e-9


def dist2(a, b):
    value = 0.0
    for x, y in zip(a, b):
        delta = x - y
        value += delta * delta
    return value


def kmeans(points, order, d, k):
    n = len(points)
    centers = []
    for i in range(k):
        pos = 0 if k == 1 else i * (n - 1) // (k - 1)
        centers.append(points[order[pos]][:])

    labels = [-1] * n
    while True:
        new_labels = []
        for point in points:
            best = 0
            best_dist = dist2(point, centers[0])
            for c in range(1, k):
                current = dist2(point, centers[c])
                if current < best_dist:
                    best, best_dist = c, current
            new_labels.append(best)

        if new_labels == labels:
            return centers, labels
        labels = new_labels

        counts = [0] * k
        totals = [[0.0] * d for _ in range(k)]
        for point, c in zip(points, labels):
            counts[c] += 1
            for j in range(d):
                totals[c][j] += point[j]
        for c in range(k):
            if counts[c]:
                centers[c] = [v / counts[c] for v in totals[c]]


def merge_centers(points, centers, labels, d):
    k = len(centers)
    parent = list(range(k))

    def find(x):
        while parent[x] != x:
            parent[x] = parent[parent[x]]
            x = parent[x]
        return x

    # 所有距离都使用合并前的中心，不在枚举中修改中心。
    for a in range(k):
        for b in range(a + 1, k):
            if dist2(centers[a], centers[b]) < MERGE_EPS:
                ra, rb = find(a), find(b)
                if ra != rb:
                    parent[max(ra, rb)] = min(ra, rb)

    roots = [find(c) for c in range(k)]
    representatives = sorted(set(roots))
    number = {root: i for i, root in enumerate(representatives)}
    new_labels = [number[roots[c]] for c in labels]
    size = len(representatives)
    counts = [0] * size
    totals = [[0.0] * d for _ in range(size)]
    for point, c in zip(points, new_labels):
        counts[c] += 1
        for j in range(d):
            totals[c][j] += point[j]

    merged = []
    for c, root in enumerate(representatives):
        if counts[c]:
            merged.append([v / counts[c] for v in totals[c]])
        else:
            merged.append(centers[root][:])
    return merged, new_labels


def main():
    stream = iter(sys.stdin.buffer.read().split())
    first = next(stream, None)
    if first is None:
        return
    n, d = int(first), int(next(stream))
    if n <= 0 or d <= 0:
        print(0)
        return
    points = [[float(next(stream)) for _ in range(d)] for _ in range(n)]
    kmin, kmax = int(next(stream)), int(next(stream))
    kmax = min(kmax, n)
    kmin = min(kmin, kmax)
    if kmin < 1:
        print(0)
        return

    order = sorted(range(n), key=lambda i: points[i][0])
    best_bic = math.inf
    best_centers = best_labels = None
    for k in range(kmin, kmax + 1):
        centers, labels = kmeans(points, order, d, k)
        centers, labels = merge_centers(points, centers, labels, d)
        sse = sum(dist2(point, centers[c])
                  for point, c in zip(points, labels))
        bic = (n * math.log((sse + 1e-8) / n)
               + len(centers) * (d + 1) * math.log(n))
        if bic < best_bic - BIC_EPS:
            best_bic = bic
            best_centers, best_labels = centers, labels

    order = sorted(range(len(best_centers)),
                   key=lambda c: (best_centers[c][0], c))
    remap = {old: new for new, old in enumerate(order)}
    print(len(order))
    for c in order:
        row = []
        for value in best_centers[c]:
            text = f"{value:.2f}"
            row.append("0.00" if text == "-0.00" else text)
        print(" ".join(row))
    print(" ".join(str(remap[c]) for c in best_labels))


if __name__ == "__main__":
    main()

复杂度分析

记候选簇数为 K，其 K-Means 分配轮数为 TK。 排序预处理：O(Nlog N)。 固定 K 的分配、更新：O(TKNKd)。 合并时检查中心对的距离：O(K2d)；并查集使用路径压缩、按较小编号连接，未使用按秩合并，保守另计 O(K2log(K+1)) 的摊还上界。 重算均值与 SSE：O(Nd+Kd)；最终排序和重编号不超过 O(Kmaxlog Kmax+N)。 时间复杂度 ：总时间可保守写为 空间复杂度 ：O(Nd+Kmaxd+N)=O(Nd)，因为截断后 Kmax≤ N。只保留当前候选和最佳候选，不存储全部枚举结果。 性能边界 ：若允许枚举从小簇数直到 N，该纯 Python 直接实现的最坏代价较高。材料未披露时间限制、总迭代预算或更小的枚举跨度，不能仅凭样例通过就声称覆盖最大规模的运行时间保证；也不能为了加速擅自提前停止枚举。
