Certainty Forcing 训练损失计算

遮住推导与代码，先自己想，再逐段揭示

原题解析 · 华为 · 2026-07-01 · AI岗 · ACM 模式（stdin/stdout）

题目描述

给定 N 个 token，词表大小 V，每个 token 有 logits 向量 z、正确标签 y、稳定性影响值 c。需要：

对每个 token 计算 softmax 概率，得到基础交叉熵 CEi=-logpi[yi] 和预测分布熵 Hi=-∑jpjlogpj 在总稳定性影响不超过上限 B 的约束下，选择一部分 token 使其交叉熵之和最大（0/1 背包） 最终总损失 = 基础损失之和 + λ× 被选 token 的熵之和

对数一律使用自然对数，结果保留两位小数。

思路分析

第一步：数值稳定的 softmax 与交叉熵

直接对 logits 取指数可能上溢，先减去每个 token 的最大 logit 值 m 再取指数。交叉熵可以化简为 CEi=-(zyi-m)+log(∑ezj-m)，避免先算概率再取对数的精度损失。

第二步：分布熵的计算

熵看的是整个词表的概率分布：Hi=-∑jpjlogpj。这里 pj=ezj-m/∑ezk-m。

第三步：0/1 背包建模

基础损失 ∑CEi 恒定不变，增强项只由被选集合决定。令价值 = 交叉熵、重量 = 影响值、容量 = B，”选出交叉熵之和最大的合法子集”就是标准 0/1 背包。关键是求出最优子集后，需要同步搬运该子集对应的熵之和——在 DP 更新价值时，同步更新一个附属数组 g 记录对应的熵之和。

第四步：最终答案

total=base+λ·g[B]，四舍五入保留两位小数。

题解代码

复杂度分析

时间复杂度 ：O(NV + NB)，softmax 与熵 O(NV)，背包 O(NB)。 空间复杂度 ：O(B + NV)。

Java 实现

// 题目：Certainty Forcing 训练损失计算
// 算法：按题意模拟
// 模式：ACM（stdin/stdout）
// 复杂度：时间 O(NV + NB)，softmax 与熵 O(NV)，背包 O(NB)；空间 O(B + NV)

import java.util.*;
public class Main {
    // 主函数：读取输入并输出答案
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int N = sc.nextInt(), V = sc.nextInt(), B = sc.nextInt();
        double lam = sc.nextDouble();
        double base = 0.0;
        double[] f = new double[B + 1];
        double[] g = new double[B + 1];
        // 循环处理
        for (int it = 0; it < N; it++) {
            double[] z = new double[V];
            // 枚举阶段 j
            for (int j = 0; j < V; j++) z[j] = sc.nextDouble();
            int y = sc.nextInt(); int c = sc.nextInt();
            double mx = Double.NEGATIVE_INFINITY;
            // 循环处理
            for (double v : z) if (v > mx) mx = v;
            double sum = 0;
            double[] exps = new double[V];
            // 枚举阶段 j
            for (int j = 0; j < V; j++) { exps[j] = Math.exp(z[j] - mx); sum += exps[j]; }
            double ce = -(z[y] - mx) + Math.log(sum);
            double H = 0;
            // 枚举阶段 j
            for (int j = 0; j < V; j++) { double p = exps[j] / sum; if (p > 0) H -= p * Math.log(p); }
            base += ce;
            // 循环处理
            for (int bb = B; bb >= c; bb--) { double cand = f[bb - c] + ce; if (cand > f[bb]) { f[bb] = cand; g[bb] = g[bb - c] + H; } }
        }
        double total = base + lam * g[B];
        System.out.println(String.format(Locale.US, "%.2f", total));
    }
}

Python 实现

# 题目：Certainty Forcing 训练损失计算
# 算法：按题意模拟
# 模式：ACM（stdin/stdout）
# 复杂度：时间 O(NV + NB)，softmax 与熵 O(NV)，背包 O(NB)；空间 O(B + NV)

import sys
import math
input = sys.stdin.readline

# 读取输入并输出答案
def solve():
    first = input().split()
    N = int(first[0]); V = int(first[1]); B = int(first[2]); lam = float(first[3])
    base = 0.0
    items = []
    # 遍历 _
    for _ in range(N):
        row = input().split()
        z = [float(row[j]) for j in range(V)]
        y = int(row[V]); c = int(row[V + 1])
        m = max(z)
        exps = [math.exp(v - m) for v in z]
        s = sum(exps)
        ce = -(z[y] - m) + math.log(s)
        H = 0.0
        # 遍历 e
        for e in exps:
            p = e / s
            # 条件判断
            if p > 0.0:
                H -= p * math.log(p)
        base += ce
        items.append((ce, c, H))
    # 0/1 背包：容量 B，重量 c，价值 ce，同步搬运熵
    f = [0.0] * (B + 1)
    g = [0.0] * (B + 1)
    for ce, c, H in items:
        # 枚举分割点 b
        for b in range(B, c - 1, -1):
            cand = f[b - c] + ce
            # 条件判断
            if cand > f[b]:
                f[b] = cand
                g[b] = g[b - c] + H
    total = base + lam * g[B]
    print(f"{total:.2f}")
