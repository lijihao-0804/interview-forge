# 流水线并行最优配置

> <a href="https://onefly.top/zero2Leetcode/04_real_interviews/huawei/ai-20260617/" target="_blank" rel="noopener noreferrer">原题解析</a> · 华为 · 2026-06-17 · AI岗 · ACM 模式（stdin/stdout）

## 题目描述

在大模型流水线并行训练中，需要把模型按层切分到多个加速卡上。给定模型总层数 $L$、单卡最大承载层数 $M$、micro batch 数目 $m$、硬件总卡数 $C$，求最优流水线 stage 数 $PP$ 和对应的气泡率。

$PP$ 需满足三条约束：$PP \leq C$；$L / PP$ 为整数；$L / PP \leq M$。

气泡率公式为 $(PP - 1) / (m + PP - 1)$。优先最小化气泡率，相同时取 $PP$ 更小的。

输出最优 $PP$ 和气泡率（四舍五入保留 4 位小数）。若无可行方案或输入不合法，输出 -1 -1 。

## 思路分析

第一步：输入校验

参数个数必须恰为 4 个，且每个都是正整数（纯数字串，无负号/小数点/字母），数值大于 0。任一条不满足直接输出 -1 -1 。

第二步：利用单调性

气泡率 $(PP-1)/(m+PP-1)$ 对 $PP$ 单调递增——$PP$ 越大气泡率越高。因此从小到大枚举 $PP$，第一个满足三条约束的值就同时实现了”气泡率最小”和”$PP$ 最小”两个目标。

第三步：定点输出避免浮点舍入陷阱

用整数算术计算：分子 $(PP-1) \times 10000$，整除分母 $(m+PP-1)$ 得商和余数，余数过半进位。这样完全避免浮点 printf 各语言半值舍入策略不同的问题。

## 题解代码

### Python 实现

```python
# 题目：流水线并行最优配置
# 算法：按题意模拟
# 模式：ACM（stdin/stdout）
# 复杂度：时间 O(C)，枚举一遍 PP 即可；空间 O(1)

import sys
import re

# 读取输入并输出答案
def solve(line):
    tokens = line.split()
    # 条件判断
    if len(tokens) != 4:
        # 返回结果
        return "-1 -1"
    # 遍历 t
    for t in tokens:
        # 条件判断
        if not re.fullmatch(r"[0-9]+", t):
            # 返回结果
            return "-1 -1"
    layers, max_load, m, cards = (int(t) for t in tokens)
    # 条件判断
    if min(layers, max_load, m, cards) < 1:
        # 返回结果
        return "-1 -1"

    best_pp = -1
    # 遍历 pp
    for pp in range(1, cards + 1):
        # 条件判断
        if layers % pp == 0 and layers // pp <= max_load:
            best_pp = pp
            break
    # 条件判断
    if best_pp == -1:
        # 返回结果
        return "-1 -1"

    # 整数算术四舍五入到4位小数
    num = (best_pp - 1) * 10000
    den = m + best_pp - 1
    q, r = divmod(num, den)
    # 条件判断
    if 2 * r >= den:
        q += 1
    # 返回结果
    return f"{best_pp} {q // 10000}.{q % 10000:04d}"

line = sys.stdin.readline()
print(solve(line))
```

## 复杂度分析

时间复杂度 ：$O(C)$，枚举一遍 $PP$ 即可。$C \leq 10000$。 空间复杂度 ：$O(1)$。

### Java 实现

```java
// 题目：流水线并行最优配置
// 算法：按题意模拟
// 模式：ACM（stdin/stdout）
// 复杂度：时间 O(C)，枚举一遍 PP 即可；空间 O(1)

import java.io.*;
import java.util.*;

public class Main {
    static BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
    static StringTokenizer st;
    static String next() throws IOException {
        while (st == null || !st.hasMoreTokens()) {
            String line = br.readLine();
            if (line == null) return null;
            st = new StringTokenizer(line);
        }
        return st.nextToken();
    }
    static int nextInt() throws IOException { return Integer.parseInt(next()); }
    static long nextLong() throws IOException { return Long.parseLong(next()); }
    static String nextLine() throws IOException { return br.readLine(); }

    // 主函数：读取输入并输出答案
    public static void main(String[] args) throws IOException {
        String line = nextLine();
        List<String> toks = new ArrayList<>();
        // 条件判断
        if (line != null) {
            int i = 0; int L = line.length();
            // 循环处理
            while (i < L) {
                // 循环处理
                while (i < L && Character.isWhitespace(line.charAt(i))) i++;
                int st = i;
                // 循环处理
                while (i < L && !Character.isWhitespace(line.charAt(i))) i++;
                // 条件判断
                if (i > st) toks.add(line.substring(st, i));
            }
        }
        // 条件判断
        if (toks.size() != 4) { System.out.println("-1 -1"); return; }
        // 循环处理
        for (String t : toks) {
            // 条件判断
            if (t.isEmpty()) { System.out.println("-1 -1"); return; }
            // 枚举位置 i
            for (int i = 0; i < t.length(); i++) { char c = t.charAt(i); if (c < '0' || c > '9') { System.out.println("-1 -1"); return; } }
        }
        long layers = Long.parseLong(toks.get(0)), maxLoad = Long.parseLong(toks.get(1)), m = Long.parseLong(toks.get(2)), cards = Long.parseLong(toks.get(3));
        // 条件判断
        if (Math.min(Math.min(layers, maxLoad), Math.min(m, cards)) < 1) { System.out.println("-1 -1"); return; }
        long bestPp = -1;
        // 循环处理
        for (long pp = 1; pp <= cards; pp++) { if (layers % pp == 0 && layers / pp <= maxLoad) { bestPp = pp; break; } }
        // 条件判断
        if (bestPp == -1) { System.out.println("-1 -1"); return; }
        long num = (bestPp - 1) * 10000; long den = m + bestPp - 1;
        long q = num / den; long r = num % den;
        // 条件判断
        if (2 * r >= den) q += 1;
        String out = bestPp + " " + (q / 10000) + "." + String.format(Locale.US, "%04d", q % 10000);
        System.out.println(out);
    }
}
```
