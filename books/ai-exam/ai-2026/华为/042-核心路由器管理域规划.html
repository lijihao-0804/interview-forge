核心路由器管理域规划

遮住推导与代码，先自己想，再逐段揭示

原题解析 · 华为 · 2026-09-16 · AI岗 · ACM 模式（stdin/stdout）

题目描述

给定 L 个二维点，使用 Bi-K-Means 把它们从一个初始簇逐步分裂为 N 个簇。簇的误差平方和为：

SSE(C)=∑p∈C‖p-μC‖2

每次分裂一个簇时执行 K=2 的 K-Means，并遵循以下规则：

两个初始质心分别取当前簇中 x 坐标最小和最大的点；所有点的 x 坐标互不相同。 每轮先分配点、再更新质心。材料未单列等距归组规则；为复现其参考实现，本文约定等距时归入第二个子簇。 所有点归属不再变化，或两个新质心的最大移动距离小于 10-6 时停止。 待分裂簇按 SSE 下降量从大到小选择；差值不超过 10-6 视为相同，再优先点数更多的簇，仍相同时选择更早生成的簇。 删除父簇后，两个子簇依次追加到簇列表末尾。

SSE 下降量为父簇 SSE 减去两个子簇 SSE 之和。

输入描述

第一行是目标簇数 N，1≤N≤20。

第二行是点数 L，1≤L≤100。

接下来 L 行每行两个整数 x,y，满足 0≤x,y≤1000，且不同点的 x 坐标互不相同。

输出描述

先输出初始簇的点数。每完成一次分裂，再输出当前所有簇的点数降序序列，共输出到簇数达到 N。

思路分析

第一步：实现一次确定性的二分。 初始质心由最小和最大 x 唯一决定。每轮按平方距离分组，再把质心更新为组内均值，直到满足任一停止条件。固定等距归组规则后，分裂结果可以复现。

第二步：评估全部候选簇。 单点簇不能分裂。对每个其他簇试做一次二分，计算 SSE 下降量。比较时依次使用下降量、簇大小和生成时间三个关键字。

第三步：维护生成顺序。 簇列表本身按生成时间排列。平局时只在候选严格更优或同下降量但点数更多时替换当前答案，就会自然保留更早生成的簇。父簇删除后把两个孩子追加到末尾，顺序继续成立。

正确性说明

split_two 严格执行题面的初始化、分配、更新和停止规则，因此返回指定 K-Means 过程的两个子簇。 choose_cluster 枚举全部可分裂簇，并按三层优先级保留唯一胜者，所以每轮选择正确。循环从一个簇开始，每轮删除一个父簇并加入两个子簇，簇数恰好增加一；因此输出覆盖从 1 个簇到 N 个簇的全部状态。

题解代码

复杂度分析

时间复杂度 ：O(NLI)，其中 I 是一次二分 K-Means 的迭代轮数。每一轮分裂评估的所有簇总点数为 L。

空间复杂度 ：O(L)，不计输入与输出之外，每个点只属于当前簇列表中的一个簇。

易错点

比较下降量时使用 10-6 容差，不能直接用浮点数相等。 点到两个质心等距时的归组会影响后续质心，必须固定规则。 子簇要追加到列表末尾，不能原地替换父簇后打乱生成时间。

Java 实现

// 题目：核心路由器管理域规划
// 算法：排序 + 扫描
// 模式：ACM（stdin/stdout）
// 复杂度：时间 O(NLI)，其中 I 是一次二分 K-Means 的迭代轮数；空间 O(L)，不计输入与输出之外，每个点只属于当前簇列表中的一个簇

import java.io.*;
import java.util.*;

public class Main {

    static final double EPS = 1e-6;
    // 核心方法：Choice
    static class Choice { int index; List<double[]> first, second; Choice(int i, List<double[]> a, List<double[]> b) { index=i; first=a; second=b; } }
    // 核心方法：sse
    static double sse(List<double[]> pts) {
        int n = pts.size();
        double mx = 0.0, my = 0.0;
        // 循环处理
        for (double[] p : pts) { mx += p[0]; my += p[1]; }
        mx /= n; my /= n;
        double s = 0.0;
        // 循环处理
        for (double[] p : pts) { double dx = p[0] - mx, dy = p[1] - my; s += dx*dx + dy*dy; }
        // 返回结果
        return s;
    }
    // 核心方法：splitTwo
    static List<List<double[]>> splitTwo(List<double[]> pts) {
        double[] left = pts.get(0);
        // 循环处理
        for (double[] p : pts) if (p[0] < left[0]) left = p;
        double[] right = pts.get(0);
        // 循环处理
        for (double[] p : pts) if (p[0] > right[0]) right = p;
        double[][] centers = {{left[0], left[1]}, {right[0], right[1]}};
        int[] labels = null;
        // 循环处理
        while (true) {
            int m = pts.size();
            int[] newLabels = new int[m];
            // 枚举位置 i
            for (int i = 0; i < m; i++) {
                double[] p = pts.get(i);
                double d0 = (p[0]-centers[0][0])*(p[0]-centers[0][0]) + (p[1]-centers[0][1])*(p[1]-centers[0][1]);
                double d1 = (p[0]-centers[1][0])*(p[0]-centers[1][0]) + (p[1]-centers[1][1])*(p[1]-centers[1][1]);
                newLabels[i] = d0 < d1 ? 0 : 1;
            }
            // 条件判断
            if (labels != null && Arrays.equals(newLabels, labels)) break;
            labels = newLabels;
            double[] sums0 = {0,0}; int c0 = 0;
            double[] sums1 = {0,0}; int c1 = 0;
            // 枚举位置 i
            for (int i = 0; i < m; i++) { double[] p = pts.get(i); if (labels[i] == 0) { sums0[0]+=p[0]; sums0[1]+=p[1]; c0++; } else { sums1[0]+=p[0]; sums1[1]+=p[1]; c1++; } }
            double cx0 = sums0[0]/c0, cy0 = sums0[1]/c0, cx1 = sums1[0]/c1, cy1 = sums1[1]/c1;
            double move = Math.max(Math.hypot(cx0-centers[0][0], cy0-centers[0][1]), Math.hypot(cx1-centers[1][0], cy1-centers[1][1]));
            centers = new double[][]{{cx0,cy0},{cx1,cy1}};
            // 条件判断
            if (move < EPS) break;
        }
        List<double[]> first = new ArrayList<>();
        List<double[]> second = new ArrayList<>();
        // 枚举位置 i
        for (int i = 0; i < pts.size(); i++) { if (labels[i] == 0) first.add(pts.get(i)); else second.add(pts.get(i)); }
        List<List<double[]>> res = new ArrayList<>(); res.add(first); res.add(second);
        // 返回结果
        return res;
    }
    // 核心方法：chooseCluster
    static Choice chooseCluster(List<List<double[]>> clusters) {
        int bestIndex = -1;
        double bestGradient = 0.0;
        List<double[]> bestFirst = null, bestSecond = null;
        // 循环处理
        for (int idx = 0; idx < clusters.size(); idx++) {
            List<double[]> cluster = clusters.get(idx);
            // 条件判断
            if (cluster.size() < 2) continue;
            List<List<double[]>> children = splitTwo(cluster);
            double gradient = sse(cluster) - sse(children.get(0)) - sse(children.get(1));
            boolean better = gradient > bestGradient + EPS;
            boolean tied = Math.abs(gradient - bestGradient) <= EPS;
            boolean larger = bestIndex == -1 || cluster.size() > clusters.get(bestIndex).size();
            // 条件判断
            if (bestIndex == -1 || better || (tied && larger)) { bestIndex = idx; bestGradient = gradient; bestFirst = children.get(0); bestSecond = children.get(1); }
        }
        // 返回结果
        return new Choice(bestIndex, bestFirst, bestSecond);
    }
    // 主函数：读取输入并输出答案
    public static void main(String[] args) throws IOException {
        Scanner sc = new Scanner(System.in);
        int target = sc.nextInt();
        int pointCount = sc.nextInt();
        List<double[]> points = new ArrayList<>();
        // 枚举位置 i
        for (int i = 0; i < pointCount; i++) { double x = (double) sc.nextInt(); double y = (double) sc.nextInt(); points.add(new double[]{x, y}); }
        List<List<double[]>> clusters = new ArrayList<>();
        clusters.add(points);
        StringBuilder out = new StringBuilder();
        out.append(pointCount).append((char)10);
        // 循环处理
        for (int step = 0; step < target - 1; step++) {
            Choice ch = chooseCluster(clusters);
            clusters.remove(ch.index);
            clusters.add(ch.first);
            clusters.add(ch.second);
            List<Integer> sizes = new ArrayList<>();
            // 循环处理
            for (List<double[]> c : clusters) sizes.add(c.size());
            sizes.sort(Collections.reverseOrder());
            StringBuilder line = new StringBuilder();
            // 枚举位置 i
            for (int i = 0; i < sizes.size(); i++) { if (i > 0) line.append(' '); line.append(sizes.get(i)); }
            out.append(line).append((char)10);
        }
        System.out.print(out.toString());
    }
}

Python 实现

# 题目：核心路由器管理域规划
# 算法：排序 + 扫描
# 模式：ACM（stdin/stdout）
# 复杂度：时间 O(NLI)，其中 I 是一次二分 K-Means 的迭代轮数；空间 O(L)，不计输入与输出之外，每个点只属于当前簇列表中的一个簇

import sys
from math import hypot


EPS = 1e-6


# 核心函数：sse
def sse(points):
    mean_x = sum(x for x, _ in points) / len(points)
    mean_y = sum(y for _, y in points) / len(points)
    # 返回结果
    return sum((x - mean_x) ** 2 + (y - mean_y) ** 2 for x, y in points)


# 核心函数：split_two
def split_two(points):
    left = min(points, key=lambda point: point[0])
    right = max(points, key=lambda point: point[0])
    centers = [[float(left[0]), float(left[1])],
               [float(right[0]), float(right[1])]]
    labels = None

    # 循环处理
    while True:
        new_labels = []
        for x, y in points:
            distance_0 = (x - centers[0][0]) ** 2 + (y - centers[0][1]) ** 2
            distance_1 = (x - centers[1][0]) ** 2 + (y - centers[1][1]) ** 2
            new_labels.append(0 if distance_0 < distance_1 else 1)

        # 条件判断
        if new_labels == labels:
            break
        labels = new_labels

        new_centers = []
        maximum_move = 0.0
        # 遍历 label
        for label in range(2):
            group = [points[i] for i in range(len(points)) if labels[i] == label]
            center_x = sum(x for x, _ in group) / len(group)
            center_y = sum(y for _, y in group) / len(group)
            maximum_move = max(
                maximum_move,
                hypot(center_x - centers[label][0], center_y - centers[label][1]),
            )
            new_centers.append([center_x, center_y])
        centers = new_centers

        # 条件判断
        if maximum_move < EPS:
            break

    first = [points[i] for i in range(len(points)) if labels[i] == 0]
    second = [points[i] for i in range(len(points)) if labels[i] == 1]
    # 返回结果
    return first, second


# 核心函数：choose_cluster
def choose_cluster(clusters):
    best_index = -1
    best_gradient = 0.0
    best_children = None

    for index, cluster in enumerate(clusters):
        # 条件判断
        if len(cluster) < 2:
            continue
        first, second = split_two(cluster)
        gradient = sse(cluster) - sse(first) - sse(second)
        better = gradient > best_gradient + EPS
        tied = abs(gradient - best_gradient) <= EPS
        larger = best_index == -1 or len(cluster) > len(clusters[best_index])
        # 条件判断
        if best_index == -1 or better or (tied and larger):
            best_index = index
            best_gradient = gradient
            best_children = (first, second)

    # 返回结果
    return best_index, best_children


# 读取输入并输出答案
def solve():
    data = list(map(int, sys.stdin.buffer.read().split()))
    target_count = data[0]
    point_count = data[1]
    points = [tuple(data[i:i + 2]) for i in range(2, 2 + 2 * point_count, 2)]

    clusters = [points]
    print(point_count)
    # 遍历 _
    for _ in range(target_count - 1):
        index, children = choose_cluster(clusters)
        clusters.pop(index)
        clusters.extend(children)
        print(" ".join(map(str, sorted((len(cluster) for cluster in clusters), reverse=True))))
