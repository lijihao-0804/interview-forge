# 训练成本优化

> <a href="https://onefly.top/zero2Leetcode/04_real_interviews/huawei/ai-20260923/" target="_blank" rel="noopener noreferrer">原题解析</a> · 华为 · 2026-09-23 · AI岗 · ACM 模式（stdin/stdout）

## 题目描述

将 $n$ 个梯度计算任务分配给 $k$ 张 NPU，每个任务恰好分配一次。先最小化所有卡的最大总耗时 $T$；若有多个方案达到同一个最优 $T$，再最小化总训练成本。

设第 $i$ 张卡的任务总耗时为 $s_i$，基础学习率为 $b$，衰减系数为 $r$，则

$$\mathrm{lr}_i=b\cdot r^{T-s_i},\qquad \mathrm{Cost}=\sum_{i=1}^{k}s_i\cdot b\cdot r^{T-s_i}.$$

输入格式 ：一行四段，以分号分隔： 任务耗时列表;NPU数量;基础学习率;衰减系数 。列表中的数以逗号分隔。约束为 $1\le n\le12$、$0\le t_i\le1000$、$1\le k\le n$、$0<b\le1$、$0<r<1$；两个小数均不超过四位小数。

输出格式 ： 最小最大总耗时;总训练成本 ，成本保留四位小数。

格式说明纠正 ：材料的格式说明另写了 6;1.6590 ，但它不是下面第一个输入的正确结果。该输入总耗时为 $20$，三张卡的最大负载至少为 $\lceil20/3\rceil=7$；应以正式样例的 7;1.9400 为准。

## 思路分析

第一步：分清两个目标的优先级。 不能把最大耗时和成本加权成一个数，也不能只在某一个最小最大耗时方案上计算成本。先求出全局最优阈值 $T$，再在这个阈值内重新优化成本。

第二步：用任务集合消除重复计算。 $n\le12$，只有 $2^n$ 个子集。以位掩码 $M$ 表示任务集合，预处理 $S[M]$ 为其耗时之和。直接给每个任务枚举卡号会产生 $k^n$ 种分配，子集 DP 则复用相同的剩余任务状态。

第三步：第一遍 DP 求负载。 $G_j[M]$ 表示把 $M$ 分成 $j$ 个非空任务组的最小最大负载。初值 $G_0[0]=0$，其余为无穷大。枚举本组 $U\subseteq M$：

$$G_j[M]=\min_U\max\bigl(G_{j-1}[M\setminus U],S[U]\bigr).$$

只枚举含 $M$ 最低位任务的 $U$，因为任一无标号划分恰有一组包含该任务；把这一组作为当前组不会漏解。组数不足、或剩余任务不够填满其余卡的状态直接跳过。

第四步：固定 $T=G_k[\mathrm{full}]$，重新优化成本。 令 $h(s)=s\cdot r^{T-s}$。第二遍使用同样的子集枚举，但只允许 $S[U]\le T$，并把取最大值换成求和：

$$F_j[M]=\min_{U\subseteq M,\ S[U]\le T}\bigl(F_{j-1}[M\setminus U]+h(S[U])\bigr).$$

最终成本为 $b\cdot F_k[\mathrm{full}]$。每一遍只保留上一层和当前层。任务耗时可以为零，非空任务组不等于正负载；所有任务都是零时输出 0;0.0000 。

## 正确性证明

两次转移都将一个划分唯一拆成“包含最低位任务的一组”和其余组，因此完整枚举全部集合划分。第一遍的组合运算是各组负载的最大值，故得到最优 $T$。第二遍只排除超过 $T$ 的组，保留所有一级目标最优方案；总成本可逐组相加，故再次取最小得到二级目标最优值。

即使允许某些卡空闲，也存在使用 $k$ 个非空任务组的最优方案：固定 $T$ 时，对 $a,b\ge0$，有 $h(a)+h(b)\le h(a+b)$，因为 $r^{T-a},r^{T-b}\le r^{T-a-b}$。拆组不增大最大负载，也不增加成本；又因 $k\le n$，可不断拆到 $k$ 组。

样例 1 的负载可为 $7,7,6$，成本为 $0.7+0.7+0.54=1.94$；样例 2 只有一组，成本为 $5\cdot0.1=0.5$。最后才格式化小数，不在转移中反复舍入。

```python
# 题目：训练成本优化
# 算法：动态规划（前缀和 + 滚动数组）

# 复杂度：时间 O(k3^n)，两遍子集 DP；所有掩码的子集数之和为 3^n；空间 O(2^n)，子集和、成本表和滚动 DP 数组

import sys
input = sys.stdin.readline


def optimize(times, k, base_lr, decay):
    n = len(times)
    size = 1 << n
    subset_sum = [0] * size
    count = [0] * size
    for mask in range(1, size):
        low = mask & -mask
        subset_sum[mask] = subset_sum[mask ^ low] + times[low.bit_length() - 1]
        count[mask] = count[mask ^ low] + 1

    inf = float('inf')
    previous = [inf] * size
    previous[0] = 0
    for groups in range(1, k + 1):
        current = [inf] * size
        for mask in range(1, size):
            if not groups <= count[mask] <= n - k + groups:
                continue
            low = mask & -mask
            rest = mask ^ low
            sub = rest
            while True:
                group = sub | low
                candidate = max(previous[mask ^ group], subset_sum[group])
                if candidate < current[mask]:
                    current[mask] = candidate
                if sub == 0:
                    break
                sub = (sub - 1) & rest
        previous = current
    best_time = previous[-1]

    cost = [inf] * size
    for mask, load in enumerate(subset_sum):
        if load <= best_time:
            cost[mask] = load * decay ** (best_time - load)
    previous = [inf] * size
    previous[0] = 0.0
    for groups in range(1, k + 1):
        current = [inf] * size
        for mask in range(1, size):
            if not groups <= count[mask] <= n - k + groups:
                continue
            low = mask & -mask
            rest = mask ^ low
            sub = rest
            while True:
                group = sub | low
                candidate = previous[mask ^ group] + cost[group]
                if candidate < current[mask]:
                    current[mask] = candidate
                if sub == 0:
                    break
                sub = (sub - 1) & rest
        previous = current
    return best_time, previous[-1] * base_lr
```

## 复杂度分析

时间复杂度 ：$O(k\cdot3^n)$，两遍子集 DP；所有掩码的子集数之和为 $3^n$。

空间复杂度 ：$O(2^n)$，子集和、成本表和滚动 DP 数组。

### Java 实现

```java
// 题目：训练成本优化
// 算法：动态规划（前缀和 + 滚动数组）
// 模式：ACM（stdin/stdout）
// 复杂度：时间 O(k3^n)，两遍子集 DP；所有掩码的子集数之和为 3^n；空间 O(2^n)，子集和、成本表和滚动 DP 数组

import java.io.*;
import java.util.*;
import java.util.Locale;

public class Main {
    // 主函数：读取输入并输出答案
    public static void main(String[] args) throws Exception {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        String line = br.readLine();
        if (line == null) { return; }
        String[] parts = line.trim().split(";");
        String[] timeStrs = parts[0].split(",");
        int n = timeStrs.length;
        long[] times = new long[n];
        for (int i = 0; i < n; i++) times[i] = Long.parseLong(timeStrs[i].trim());
        int k = Integer.parseInt(parts[1].trim());
        double baseLr = Double.parseDouble(parts[2].trim());
        double decay = Double.parseDouble(parts[3].trim());
        int size = 1 << n;
        long[] subsetSum = new long[size];
        int[] count = new int[size];
        for (int mask = 1; mask < size; mask++) {
            int low = mask & -mask;
            int bit = Integer.numberOfTrailingZeros(low);
            subsetSum[mask] = subsetSum[mask ^ low] + times[bit];
            count[mask] = count[mask ^ low] + 1;
        }
        final double INF = Double.POSITIVE_INFINITY;
        double[] previous = new double[size];
        Arrays.fill(previous, INF);
        previous[0] = 0;
        for (int groups = 1; groups <= k; groups++) {
            double[] current = new double[size];
            Arrays.fill(current, INF);
            for (int mask = 1; mask < size; mask++) {
                if (!(groups <= count[mask] && count[mask] <= n - k + groups)) continue;
                int low = mask & -mask;
                int rest = mask ^ low;
                int sub = rest;
                while (true) {
                    int group = sub | low;
                    double cand = Math.max(previous[mask ^ group], (double) subsetSum[group]);
                    if (cand < current[mask]) current[mask] = cand;
                    if (sub == 0) break;
                    sub = (sub - 1) & rest;
                }
            }
            previous = current;
        }
        double bestTime = previous[size - 1];
        double[] cost = new double[size];
        Arrays.fill(cost, INF);
        for (int mask = 0; mask < size; mask++) {
            long load = subsetSum[mask];
            if (load <= bestTime) cost[mask] = load * Math.pow(decay, bestTime - load);
        }
        previous = new double[size];
        Arrays.fill(previous, INF);
        previous[0] = 0.0;
        for (int groups = 1; groups <= k; groups++) {
            double[] current = new double[size];
            Arrays.fill(current, INF);
            for (int mask = 1; mask < size; mask++) {
                if (!(groups <= count[mask] && count[mask] <= n - k + groups)) continue;
                int low = mask & -mask;
                int rest = mask ^ low;
                int sub = rest;
                while (true) {
                    int group = sub | low;
                    double cand = previous[mask ^ group] + cost[group];
                    if (cand < current[mask]) current[mask] = cand;
                    if (sub == 0) break;
                    sub = (sub - 1) & rest;
                }
            }
            previous = current;
        }
        double answer = previous[size - 1] * baseLr;
        String bt;
        if (!Double.isInfinite(bestTime) && bestTime == Math.floor(bestTime)) bt = String.valueOf((long) bestTime) + ".0";
        else bt = String.valueOf(bestTime);
        System.out.println(bt + ";" + String.format(Locale.US, "%.4f", answer));
    }
}
```
