网游皮肤智能推荐系统

遮住推导与代码，先自己想，再逐段揭示

来源：https://onefly.top/zero2Leetcode/04_real_interviews/huawei/ai-20261021/ · 华为 · 2026-10-21 · AI岗 · ACM 模式（stdin/stdout）

题目描述

某款 5v5 竞技游戏希望根据玩家行为，为玩家推荐更可能购买的英雄皮肤。给定训练样本，按题目指定的信息增益规则构建二叉决策树，再预测每个推理样本是否购买。 每个样本包含三个布尔特征，输入用 0 表示 False、 1 表示 True： 编号 特征 说明 0 是否 VIP 会员 是否购买 VIP 会员或月卡 1 是否购买过该英雄皮肤 是否有该英雄的皮肤购买记录 2 是否熟练英雄 是否有该英雄达到最高段位王者的记录 类别 0 表示预测不购买、不推荐；类别 1 表示预测购买、推荐。 设当前节点的非空训练集为 S，两类占比分别为 p0,p1，信息熵为 约定 0log20=0，实现跳过计数为零的项。对特征 A，令 Sv 是特征值为 v 的样本子集，则 空子集的加权项记为零。 在当前路径未使用过的特征中，选择信息增益最大的特征。 多个特征并列最大时，选择编号最小者。 样本全属于同一类别时，生成该类别的叶子。 特征用尽，或剩余特征的信息增益均不大于零时，生成多数类别叶子；两类数量相同时取 0 。 特征值为 0 的样本进入左子树，为 1 的进入右子树。 对推理样本，从根按对应特征值走到叶子，输出叶子类别。 浮点实现采用 10-9 容差判断增益并列与非正增益。空子集额外以父节点的多数类别兜底；在严格正信息增益分裂下，两边本应均非空。

输入描述

第一行：训练样本数 N 和推理样本数 M。 接下来 N 行：每行四个 0/1 整数，依次为特征 0,1,2 和类别标签。 接下来 M 行：每行三个 0/1 整数，为待预测的三个特征。

输出描述

输出 M 行，每行一个 0 或 1 ，对应输入顺序下的预测结果。

数据范围与边界

特征数固定为三个，特征值和类别均为 0/1 。材料没有披露 N,M 的具体数值上限，因此不另造范围。相同特征组合可以对应不同标签，应保留样本频次参与熵和多数表决，不能去重。

思路分析

一个节点如果全是同一类，已经不需要再问玩家特征；两类混杂时，才需要找一个有区分能力的特征。熵刻画混杂程度，信息增益比较分裂前后的熵差。 条件熵必须按子集大小加权，不能把左右熵直接取平均，否则一个样本的分支会和大量样本的分支拥有相同权重。由于三个特征都为布尔值，每个特征只需统计左右分支中两类的数量，即可计算增益。 这里不是搜索所有可能的决策树来求全局最优，而是在每个节点执行题目规定的贪心特征选择。 从小编号开始检查特征，仅当增益超过当前最优值加上容差时替换，因此近似并列保留小编号。 以下情况直接生成叶子：样本全同类、可用特征为空、最大增益不为正。后两种情况下取多数类别，只有正例严格多于反例才输出 1 ，平票必须输出 0 。 零增益不等于以后永远无法分类。 某些组合关系可能让每个单独特征的信息增益都为零，但联合起来能区分标签。本题明确要求此时停止，因此不能为了拟合训练集而继续向下分裂。 选择特征后，从可用集合中删除它，再将剩余集合传给两个子树。使用不可变元组，可以避免全局 used 状态忘记回溯的问题。 某个特征在左分支用过，不代表右分支也不能使用；只有祖先节点已经使用的特征才应在两边共同排除。 叶子直接保存整数 0/1 ；内部节点保存 (特征编号, 左子树, 右子树) 。每次读取样本对应特征，为 0 进入左边，为 1 进入右边，直到叶子。

正确性证明

按当前路径剩余特征数归纳。 若样本全同类，代码输出该类别；若没有剩余特征或所有增益均不为正，代码按多数表决输出，平票为 0 。这些都是题目指定的终止规则。 否则，代码对每个可用特征计算两个子集的类别计数，得到规定的熵、条件熵和信息增益，并按容差与编号规则选出分裂特征。因此当前节点选择正确。 左右子树分别接收特征为 0/1 的全部样本，且剩余特征数减少。由归纳假设，两个子树均按题意构建，故当前子树也正确。 预测时，每一步恰好根据当前节点的特征选择规定分支，最终返回对应叶子的类别，因此预测结果符合所建决策树。 每条路径至多使用全部三个特征，递归必然终止。该证明不意味着贪心 ID3 得到最小决策树，或能保证未见样本的真实购买行为。

题解代码

复杂度分析

记一般情形的特征数为 F。每层节点的样本集合互不相交，总样本数至多为 N；每个节点需要扫描其剩余特征，因此建树时间可界为 O(NF2)。每个样本预测至多经过 F 次分支，总预测时间为 O(MF)。 本题 F=3 固定，因此： 时间复杂度 ：O(N+M)。 空间复杂度 ：O(N)。训练数据和递归子集占线性空间，树的深度有固定上界；推理数据逐行处理，不额外保存全部 M 个样本。

Python 实现

import sys
import math

EPS = 1e-9


def entropy(positive, total):
    if total == 0 or positive == 0 or positive == total:
        return 0.0
    p = positive / total
    q = (total - positive) / total
    return -p * math.log2(p) - q * math.log2(q)


def build(rows, features, fallback=0):
    if not rows:
        return fallback
    n = len(rows)
    positive = sum(row[3] for row in rows)
    label = int(positive > n - positive)
    if positive == 0 or positive == n or not features:
        return label

    base = entropy(positive, n)
    best_feature = -1
    best_gain = -math.inf
    for feature in features:
        count = [0, 0]
        pos = [0, 0]
        for row in rows:
            value = row[feature]
            count[value] += 1
            pos[value] += row[3]
        conditional = sum(count[v] / n * entropy(pos[v], count[v])
                          for v in (0, 1))
        gain = base - conditional
        if gain > best_gain + EPS:
            best_gain = gain
            best_feature = feature

    if best_gain <= EPS:
        return label
    remaining = tuple(f for f in features if f != best_feature)
    left_rows = [row for row in rows if row[best_feature] == 0]
    right_rows = [row for row in rows if row[best_feature] == 1]
    left = build(left_rows, remaining, label)
    right = build(right_rows, remaining, label)
    return best_feature, left, right


def predict(tree, sample):
    while isinstance(tree, tuple):
        feature, left, right = tree
        tree = right if sample[feature] == 1 else left
    return tree


def main():
    read = sys.stdin.buffer.readline
    first = read().split()
    if not first:
        return
    n, m = map(int, first)
    train = [tuple(map(int, read().split())) for _ in range(n)]
    tree = build(train, (0, 1, 2))
    for _ in range(m):
        sample = tuple(map(int, read().split()))
        print(predict(tree, sample))


if __name__ == "__main__":
    main()
