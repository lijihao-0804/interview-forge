# 激活重计算

> <a href="https://onefly.top/zero2Leetcode/04_real_interviews/huawei/ai-20260923/" target="_blank" rel="noopener noreferrer">原题解析</a> · 华为 · 2026-09-23 · AI岗 · ACM 模式（stdin/stdout）

## 题目描述

模型有 $N$ 层，编号为 $1$ 到 $N$。第 $i$ 层的前向耗时为 $f_i$，保存该层激活值需要 $m_i$ 显存；它们分别对应输入数组下标 $i-1$。

第 $0$ 层是免费且常驻的起始检查点，第 $N$ 层是免费的终点。只能在中间层 $1$ 到 $N-1$ 选择额外检查点，总显存不超过 $B$。若相邻检查点为 $c<d$，其中第 $k$ 层会重算 $d-k$ 次，区间代价为

$$C(c,d)=\sum_{k=c+1}^{d-1} f_k\cdot(d-k).$$

相邻层之间的空区间代价为 $0$。求所有相邻检查点区间代价之和的最小值。

输入格式 ：第一行 $N,B$；第二行 $N$ 个前向耗时；第三行 $N$ 个显存开销。约束为 $1\le N\le100$、$0\le B\le1000$、$1\le f_i\le1000$、$1\le m_i\le100$。

输出格式 ：一个整数，表示最小重计算代价。第 $N$ 层虽有输入数据，但不占检查点显存，其前向耗时也不计入重计算区间。

## 思路分析

第一步：区间代价不能按单个检查点独立计算。 一个检查点是否划算，取决于它前后两个检查点的位置。仅做普通物品背包会丢失相邻关系，因此状态还要记录最后一个检查点。

第二步：用两个前缀和消掉区间枚举。 令 $P_x=\sum_{i=1}^x f_i$、$Q_x=\sum_{i=1}^x i\cdot f_i$。把 $d$ 从求和中提出，得到

$$C(c,d)=d\cdot(P_{d-1}-P_c)-(Q_{d-1}-Q_c).$$

这样每对端点只需常数时间计算，不必重新遍历区间。

第三步：按位置和显存做 DP。 令 $D[c][b]$ 表示最后一个检查点为 $c$、恰好使用 $b$ 显存时，从 $0$ 到 $c$ 的最小代价。初始化 $D[0][0]=0$，其他状态不可达。枚举下一个中间检查点 $d$，执行

$$D[d][b+m_d]=\min\bigl(D[d][b+m_d],D[c][b]+C(c,d)\bigr),\quad c<d,\ b+m_d\le B.$$

终点 $N$ 不收费，答案是 $\min_{c,b}(D[c][b]+C(c,N))$。不选择任何中间检查点的路径始终存在，因此 $B=0$ 也能处理；$N=1$ 的答案为 $0$。

样例推演 ：样例 1 选第 $1,3$ 层，显存 $3+2=5$，只有区间 $(1,3)$ 重算第 $2$ 层，代价 $20$。样例 2 没有额外检查点，代价 $5\cdot2+5\cdot1=15$。

## 正确性证明

对检查点位置归纳。任意以 $d$ 结尾的方案都有唯一的前一检查点 $c$；删去末段后，它必对应某个 $D[c][b]$。该末段代价恰为 $C(c,d)$，新增显存恰为 $m_d$，所以转移覆盖所有合法方案。反之每个转移都连接递增端点且遵守预算，不会产生非法方案。最后连接免费的终点并对全部显存状态取最小，即得到全局最优值。

实现说明 ：使用标准库即可表达该规模的 DP；没有题目时限证据时，不能断言纯 Python 必然超时，也不能把 NumPy 当作提交环境的必备依赖。

## 题解代码

### Python 实现

```python
# 题目：激活重计算
# 算法：动态规划（前缀和 + 滚动数组）
# 模式：ACM（stdin/stdout）
# 复杂度：时间 O(N^2(B+1))，包括零预算情形；空间 O(N(B+1))，保存 DP 表与前缀和

import sys
input = sys.stdin.readline


# 核心函数：min_cost
def min_cost(n, budget, forward_time, memory):
    prefix = [0] * (n + 1)
    weighted = [0] * (n + 1)
    for i, value in enumerate(forward_time, 1):
        prefix[i] = prefix[i - 1] + value
        weighted[i] = weighted[i - 1] + i * value
    inf = float('inf')
    dp = [[inf] * (budget + 1) for _ in range(n)]
    dp[0][0] = 0
    answer = inf
    # 遍历 end
    for end in range(1, n + 1):
        need = memory[end - 1] if end < n else 0
        # 条件判断
        if need > budget:
            continue
        # 遍历 start
        for start in range(end):
            cost = end * (prefix[end - 1] - prefix[start])
            cost -= weighted[end - 1] - weighted[start]
            previous = dp[start]
            # 条件判断
            if end == n:
                answer = min(answer, min(previous) + cost)
            else:
                current = dp[end]
                # 遍历 used
                for used in range(budget - need + 1):
                    candidate = previous[used] + cost
                    # 条件判断
                    if candidate < current[used + need]:
                        current[used + need] = candidate
    # 返回结果
    return answer


# 读取输入并输出答案
def solve():
    n, budget = map(int, input().split())
    forward_time = list(map(int, input().split()))
    memory = list(map(int, input().split()))
    print(min_cost(n, budget, forward_time, memory))


solve()
```

## 复杂度分析

时间复杂度 ：$O(N^2(B+1))$，包括零预算情形。

空间复杂度 ：$O(N(B+1))$，保存 DP 表与前缀和。

### Java 实现

```java
// 题目：激活重计算
// 算法：动态规划（前缀和 + 滚动数组）
// 模式：ACM（stdin/stdout）
// 复杂度：时间 O(N^2(B+1))，包括零预算情形；空间 O(N(B+1))，保存 DP 表与前缀和

import java.io.*;
import java.util.*;

public class Main {
    static BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
    static StringTokenizer st;
    static String next() throws IOException {
        while (st == null || !st.hasMoreTokens()) {
            String line = br.readLine();
            if (line == null) return null;
            st = new StringTokenizer(line);
        }
        return st.nextToken();
    }
    static int nextInt() throws IOException { return Integer.parseInt(next()); }
    static long nextLong() throws IOException { return Long.parseLong(next()); }

    // 主函数：读取输入并输出答案
    public static void main(String[] args) throws IOException {
        int n = nextInt();
        int budget = nextInt();
        long[] forward = new long[n];
        // 枚举位置 i
        for (int i = 0; i < n; i++) forward[i] = nextLong();
        long[] memory = new long[n];
        // 枚举位置 i
        for (int i = 0; i < n; i++) memory[i] = nextLong();
        long[] prefix = new long[n + 1];
        long[] weighted = new long[n + 1];
        // 枚举位置 i
        for (int i = 1; i <= n; i++) { prefix[i] = prefix[i - 1] + forward[i - 1]; weighted[i] = weighted[i - 1] + (long) i * forward[i - 1]; }
        final long INF = Long.MAX_VALUE / 4;
        long[][] dp = new long[n][budget + 1];
        // 枚举位置 i
        for (int i = 0; i < n; i++) Arrays.fill(dp[i], INF);
        dp[0][0] = 0;
        long answer = INF;
        // 循环处理
        for (int end = 1; end <= n; end++) {
            long need = end < n ? memory[end - 1] : 0;
            // 条件判断
            if (need > budget) continue;
            // 循环处理
            for (int start = 0; start < end; start++) {
                long cost = (long) end * (prefix[end - 1] - prefix[start]) - (weighted[end - 1] - weighted[start]);
                long[] previous = dp[start];
                // 条件判断
                if (end == n) {
                    long minPrev = INF;
                    // 循环处理
                    for (int u = 0; u <= budget; u++) if (previous[u] < minPrev) minPrev = previous[u];
                    // 条件判断
                    if (minPrev < INF) { long cand = minPrev + cost; if (cand < answer) answer = cand; }
                } else {
                    long[] current = dp[end];
                    int lim = (int)(budget - need);
                    // 循环处理
                    for (int used = 0; used <= lim; used++) {
                        // 条件判断
                        if (previous[used] >= INF) continue;
                        long cand = previous[used] + cost;
                        int idx = used + (int) need;
                        // 条件判断
                        if (cand < current[idx]) current[idx] = cand;
                    }
                }
            }
        }
        System.out.println(answer);
    }
}
```
