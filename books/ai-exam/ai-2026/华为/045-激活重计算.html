题目描述

模型有 N 层，编号为 1 到 N。第 i 层的前向耗时为 fi，保存该层激活值需要 mi 显存；它们分别对应输入数组下标 i-1。 第 0 层是免费且常驻的起始检查点，第 N 层是免费的终点。只能在中间层 1 到 N-1 选择额外检查点，总显存不超过 B。若相邻检查点为 c<d，其中第 k 层会重算 d-k 次，区间代价为 相邻层之间的空区间代价为 0。求所有相邻检查点区间代价之和的最小值。 输入格式 ：第一行 N,B；第二行 N 个前向耗时；第三行 N 个显存开销。约束为 1≤N≤100、0≤B≤1000、1≤fi≤1000、1≤mi≤100。 输出格式 ：一个整数，表示最小重计算代价。第 N 层虽有输入数据，但不占检查点显存，其前向耗时也不计入重计算区间。

样例 1

输入 输出

4 5
10 20 30 40
3 4 2 6
20

样例 2

输入 输出

3 0
5 5 5
1 1 1
15

思路分析

第一步：区间代价不能按单个检查点独立计算。 一个检查点是否划算，取决于它前后两个检查点的位置。仅做普通物品背包会丢失相邻关系，因此状态还要记录最后一个检查点。 第二步：用两个前缀和消掉区间枚举。 令 Px=∑i=1xfi、Qx=∑i=1xi·fi。把 d 从求和中提出，得到 这样每对端点只需常数时间计算，不必重新遍历区间。 第三步：按位置和显存做 DP。 令 D[c][b] 表示最后一个检查点为 c、恰好使用 b 显存时，从 0 到 c 的最小代价。初始化 D[0][0]=0，其他状态不可达。枚举下一个中间检查点 d，执行 终点 N 不收费，答案是 minc,b(D[c][b]+C(c,N))。不选择任何中间检查点的路径始终存在，因此 B=0 也能处理；N=1 的答案为 0。 样例推演 ：样例 1 选第 1,3 层，显存 3+2=5，只有区间 (1,3) 重算第 2 层，代价 20。样例 2 没有额外检查点，代价 5·2+5·1=15。

正确性证明

对检查点位置归纳。任意以 d 结尾的方案都有唯一的前一检查点 c；删去末段后，它必对应某个 D[c][b]。该末段代价恰为 C(c,d)，新增显存恰为 md，所以转移覆盖所有合法方案。反之每个转移都连接递增端点且遵守预算，不会产生非法方案。最后连接免费的终点并对全部显存状态取最小，即得到全局最优值。 实现说明 ：使用标准库即可表达该规模的 DP；没有题目时限证据时，不能断言纯 Python 必然超时，也不能把 NumPy 当作提交环境的必备依赖。

复杂度分析

时间复杂度 ：O(N2(B+1))，包括零预算情形。 空间复杂度 ：O(N(B+1))，保存 DP 表与前缀和。

Java 实现

import java.io.*;
import java.util.*;

public class Main {
    static class In {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        StringTokenizer st = new StringTokenizer("");
        String next() { while (!st.hasMoreTokens()) { String l=null; try { l=br.readLine(); } catch (IOException e) { throw new RuntimeException(e); } if (l==null) return null; st=new StringTokenizer(l); } return st.nextToken(); }
        int ni() { return Integer.parseInt(next()); }
        long nl() { return Long.parseLong(next()); }
    }
    public static void main(String[] args) {
        In in = new In();
        int n = in.ni();
        int budget = in.ni();
        long[] forward = new long[n];
        for (int i = 0; i < n; i++) forward[i] = in.nl();
        long[] memory = new long[n];
        for (int i = 0; i < n; i++) memory[i] = in.nl();
        long[] prefix = new long[n + 1];
        long[] weighted = new long[n + 1];
        for (int i = 1; i <= n; i++) { prefix[i] = prefix[i - 1] + forward[i - 1]; weighted[i] = weighted[i - 1] + (long) i * forward[i - 1]; }
        final long INF = Long.MAX_VALUE / 4;
        long[][] dp = new long[n][budget + 1];
        for (int i = 0; i < n; i++) Arrays.fill(dp[i], INF);
        dp[0][0] = 0;
        long answer = INF;
        for (int end = 1; end <= n; end++) {
            long need = end < n ? memory[end - 1] : 0;
            if (need > budget) continue;
            for (int start = 0; start < end; start++) {
                long cost = (long) end * (prefix[end - 1] - prefix[start]) - (weighted[end - 1] - weighted[start]);
                long[] previous = dp[start];
                if (end == n) {
                    long minPrev = INF;
                    for (int u = 0; u <= budget; u++) if (previous[u] < minPrev) minPrev = previous[u];
                    if (minPrev < INF) { long cand = minPrev + cost; if (cand < answer) answer = cand; }
                } else {
                    long[] current = dp[end];
                    int lim = (int)(budget - need);
                    for (int used = 0; used <= lim; used++) {
                        if (previous[used] >= INF) continue;
                        long cand = previous[used] + cost;
                        int idx = used + (int) need;
                        if (cand < current[idx]) current[idx] = cand;
                    }
                }
            }
        }
        System.out.println(answer);
    }
}

Python 实现

import sys
input = sys.stdin.readline


def min_cost(n, budget, forward_time, memory):
    prefix = [0] * (n + 1)
    weighted = [0] * (n + 1)
    for i, value in enumerate(forward_time, 1):
        prefix[i] = prefix[i - 1] + value
        weighted[i] = weighted[i - 1] + i * value
    inf = float('inf')
    dp = [[inf] * (budget + 1) for _ in range(n)]
    dp[0][0] = 0
    answer = inf
    for end in range(1, n + 1):
        need = memory[end - 1] if end < n else 0
        if need > budget:
            continue
        for start in range(end):
            cost = end * (prefix[end - 1] - prefix[start])
            cost -= weighted[end - 1] - weighted[start]
            previous = dp[start]
            if end == n:
                answer = min(answer, min(previous) + cost)
            else:
                current = dp[end]
                for used in range(budget - need + 1):
                    candidate = previous[used] + cost
                    if candidate < current[used + need]:
                        current[used + need] = candidate
    return answer


def solve():
    n, budget = map(int, input().split())
    forward_time = list(map(int, input().split()))
    memory = list(map(int, input().split()))
    print(min_cost(n, budget, forward_time, memory))


solve()
