## 题目描述

在大型语言模型（LLM）的实时推理场景中（如长文档生成、无限对话系统），KV 缓存会随序列增长消耗大量显存。为解决显存瓶颈，需要对 KV 缓存进行稀疏化处理：在全局显存预算约束下，为每层每个注意力头选择重要性较高的 token 保留其 KV 缓存，且每层可保留不同数量的 token。

约束要求如下：

必须保留当前正在生成的 token（位置索引 ）的 KV 缓存。 其他剩余位置的 KV，按注意力分数从高到低全局排序，优先保留注意力分数高的 token。 当注意力分数相同时，按以下优先级选择：层索引 从低到高排序，头索引 从低到高排序，token 索引 从低到高排序。例如 与 ，则优先保留 内的 token。 总保留 token 数不超过显存预算 ，本题中显存预算保证每层每头至少保留 个 token。

核心解题步骤如下：

计算必须保留的 token 数 （即每层每头位置 各一个），从预算中减去必须保留的 token 数： 。 对除位置 之外的所有注意力分数进行全局从高到低排序，取注意力分数前 的数值，记录对应的层索引 、头索引 、token 索引 。 如遇到注意力分数相同且超出显存预算的情况，按照约束要求 的规则选择。 输出符合要求的每层每头最终保留的 token 索引 。

## 题解：排序贪心

## 思路分析

每层每个注意力头都有 个 token 的注意力分数，全局只允许保留 份 KV 缓存，其中每层每头当前生成位置 的那份必须保留。问每层每头最终留下哪些 token 索引。

这是一道规则已经写死、难点在读懂规则的排序贪心题：要看清剩余名额是跨层跨头统一竞争的，以及同分时那条三级优先级怎么落到比较器上。

剩下的名额给谁，约束二写的是”全局排序”。全局二字是关键：它不是给每层各切一份预算，而是把 个候选丢进同一个池子排队，所以每层保留的数量才会互不相同。

## 题解代码

### Python 实现

```python
# 题目：动态KV缓存稀疏优化
# 算法：排序 + 扫描
# 模式：ACM（stdin/stdout）

import sys
input = sys.stdin.readline

# 读取输入并输出答案
def solve(L, H, N, M, scores, C):
    """在显存预算 M 之内，算出每层每头最终保留的 token 索引。"""
    kept = [[[C] for _ in range(H)] for _ in range(L)]
    remaining = M - L * H

    cands = []
    # 遍历 l
    for l in range(L):
        # 遍历 h
        for h in range(H):
            row = scores[l][h]
            # 遍历 t
            for t in range(N):
                # 条件判断
                if t == C:
                    continue
                cands.append((-row[t], l, h, t))
    cands.sort()

    for _, l, h, t in cands[:max(remaining, 0)]:
        kept[l][h].append(t)

    # 遍历 l
    for l in range(L):
        # 遍历 h
        for h in range(H):
            kept[l][h].sort()
    # 返回结果
    return kept

L, H, N, M = map(int, input().split())

scores = []
# 遍历 _
for _ in range(L):
    row = list(map(float, input().split()))
    scores.append([row[h * N:(h + 1) * N] for h in range(H)])
C = int(input())

kept = solve(L, H, N, M, scores, C)
# 遍历 l
for l in range(L):
    print(' '.join(','.join(map(str, kept[l][h])) for h in range(H)))
```

## 正确性说明

先保留所有强制位置是可行解的必要条件。余下候选的比较键是题面规定的全序，取其前 remaining 个恰好执行规则；最终只对各头索引重排，不改变被选集合。

## 易错点与边界

全局预算不是每头均分；强制位置不能在候选池再次选中；分数相同时依次比较层、头、位置。

### Java 实现

```java
// 题目：动态KV缓存稀疏优化
// 算法：排序 + 扫描
// 模式：ACM（stdin/stdout）

import java.io.*;
import java.util.*;

public class Main {
    static BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
    static StringTokenizer st;
    static String next() throws IOException {
        while (st == null || !st.hasMoreTokens()) {
            String line = br.readLine();
            if (line == null) return null;
            st = new StringTokenizer(line);
        }
        return st.nextToken();
    }
    static int nextInt() throws IOException { return Integer.parseInt(next()); }
    static long nextLong() throws IOException { return Long.parseLong(next()); }
    static final char NL = (char) 10;

    static class Candidate {
        double negScore;
        int l;
        int h;
        int t;
        Candidate(double negScore, int l, int h, int t) {
            this.negScore = negScore;
            this.l = l;
            this.h = h;
            this.t = t;
        }
    }

    // 主函数：读取输入并输出答案
    public static void main(String[] args) throws IOException {
        String first = next();
        // 条件判断
        if (first == null) return;
        int L = Integer.parseInt(first);
        int H = nextInt();
        int N = nextInt();
        int M = nextInt();
        double[][][] scores = new double[L][H][N];
        // 循环处理
        for (int l = 0; l < L; l++) {
            // 循环处理
            for (int h = 0; h < H; h++) {
                // 循环处理
                for (int t = 0; t < N; t++) scores[l][h][t] = Double.parseDouble(next());
            }
        }
        int C = nextInt();
        ArrayList<Candidate> cands = new ArrayList<>();
        // 循环处理
        for (int l = 0; l < L; l++) {
            // 循环处理
            for (int h = 0; h < H; h++) {
                // 循环处理
                for (int t = 0; t < N; t++) {
                    // 条件判断
                    if (t == C) continue;
                    cands.add(new Candidate(-scores[l][h][t], l, h, t));
                }
            }
        }
        cands.sort(new Comparator<Candidate>() {
            public int compare(Candidate x, Candidate y) {
                int c = Double.compare(x.negScore, y.negScore);
                // 条件判断
                if (c != 0) return c;
                // 条件判断
                if (x.l != y.l) return Integer.compare(x.l, y.l);
                // 条件判断
                if (x.h != y.h) return Integer.compare(x.h, y.h);
                // 返回结果
                return Integer.compare(x.t, y.t);
            }
        });
        long remaining = (long) M - (long) L * H;
        int take = (int) Math.min(Math.max(remaining, 0L), (long) cands.size());
        List<List<Integer>> kept = new ArrayList<>();
        // 循环处理
        for (int l = 0; l < L; l++) {
            // 循环处理
            for (int h = 0; h < H; h++) {
                List<Integer> list = new ArrayList<>();
                list.add(C);
                kept.add(list);
            }
        }
        // 枚举位置 i
        for (int i = 0; i < take; i++) {
            Candidate cd = cands.get(i);
            kept.get(cd.l * H + cd.h).add(cd.t);
        }
        StringBuilder sb = new StringBuilder();
        // 循环处理
        for (int l = 0; l < L; l++) {
            // 条件判断
            if (l > 0) sb.append(NL);
            // 循环处理
            for (int h = 0; h < H; h++) {
                // 条件判断
                if (h > 0) sb.append(' ');
                List<Integer> list = kept.get(l * H + h);
                Collections.sort(list);
                // 循环处理
                for (int idx = 0; idx < list.size(); idx++) {
                    // 条件判断
                    if (idx > 0) sb.append(',');
                    sb.append(list.get(idx));
                }
            }
        }
        System.out.print(sb);
    }
}
```
