## 题解：k-medoids 迭代

## 思路分析

在 个城市里挑 个放 CDN，每个城市的用户都就近接入，按题面规定的迭代过程反复”分簇、挪址”直到 CDN 不再变化，输出最终各 CDN 的坐标与它覆盖的用户数。

这是一道流程照做题：算法骨架题面已经给全，难点不在想到什么，而在把五条规则一条不落地落进代码，尤其是两处同分怎么断。

## 算法实现

先看它与课本 kmeans 的差别。标准 kmeans 的簇心取簇内坐标均值，可以落在任意位置；本题第二条规则要求 CDN 必须建在城市里，所以挪址时只能从簇内已有的城市中挑一个，这就是 k-medoids。

挪址挑谁，由题面的 式决定。对簇 ，选城市 的代价为

取 最小的那个 。距离必须按用户数 加权，漏掉权重在样例二就会对不上。

算法实现上分三步：

第一步，取前 个城市作为初始 CDN，序号 的 CDN 记作 。

第二步，分簇。每个城市扫一遍 个 CDN，归给距离最小的那个。

第三步，挪址。每个簇内枚举候选城市 ，取 最小者作为新的 。新旧 完全一致就停止，否则回到第二步。

两处同分都按”序号靠前”断：分簇时等距取 CDN 序号小的，挪址时代价相等取城市序号小的。实现上只要坚持”严格更优才更新”，先遍历到的那个自然胜出。

数值计算用 1e-9 容差处理样例中的理论同代价；这一容差是工程约定，并未证明所有合法输入的非零代价间隙都大于它。

精确计算下目标值不增，但仅凭“有限状态 + 单调不增”不能排除同值循环。实现按确定性规则更新，检测重复中心配置；若未达到固定点而出现循环，则显式报错，不把旧分簇当成收敛答案。浮点容差不构成数学上的全局收敛证明。

## 复杂度分析

时间复杂度 ：O(Tp²+q log q)，T 为到固定点或重复配置前的轮数，不预设为常数。

空间复杂度 ：O(p+Tq)，包含城市、分簇及用于循环检测的中心历史。

```python
# 算法：排序 + 扫描
# 模式：ACM（stdin/stdout）
# 复杂度：时间 O(Tp²+q log q)，T 为到固定点或重复配置前的轮数，不预设为常数；空间 O(p+Tq)，包含城市、分簇及用于循环检测的中心历史

import sys
input = sys.stdin.readline

from math import sqrt

EPS = 1e-9

def dist(a, b):
    """两座城市之间的欧氏距离，城市用 (x, y, u) 三元组表示。"""
    return sqrt((a[0] - b[0]) ** 2 + (a[1] - b[1]) ** 2)

def assign(cs, centers):
    """分簇：每个城市归给距离最短的 CDN，同距时保留序号靠前的那个。"""
    cluster = [[] for _ in centers]
    for i in range(len(cs)):
        best_j = 0
        best_d = dist(cs[i], cs[centers[0]])
        for j in range(1, len(centers)):
            d = dist(cs[i], cs[centers[j]])
            if d < best_d - EPS:
                best_d = d
                best_j = j
        cluster[best_j].append(i)
    return cluster

def relocate(cs, centers, cluster):
    """挪址：簇内换一个城市当 CDN，使簇内加权距离和最小。"""
    nxt = list(centers)
    for j in range(len(centers)):
        mem = cluster[j]
        if not mem:
            continue
        best_c = -1
        best_cost = 0.0
        for c in mem:
            cost = 0.0
            for i in mem:
                cost += cs[i][2] * dist(cs[i], cs[c])
            if best_c < 0 or cost < best_cost - EPS:
                best_cost = cost
                best_c = c
        nxt[j] = best_c
    return nxt

# 读取输入并输出答案

    """迭代到 CDN 不再变化，返回最终选址与对应的分簇。"""
    centers = list(range(q))
    cluster = [[] for _ in range(q)]
    seen = set()
    while tuple(centers) not in seen:
        seen.add(tuple(centers))
        cluster = assign(cs, centers)
        nxt = relocate(cs, centers, cluster)
        if nxt == centers:
            return centers, cluster
        centers = nxt
```

## 正确性说明

分配步骤逐城市选择最近中心，固定中心时最小化加权距离；更新步骤枚举簇内所有城市，固定分簇时得到最小加权距离的候选。该流程是局部迭代，不保证全局最优。本文的同代价和空簇规则属于明确列出的实现约定。

## 易错点与边界

题面称 kmeans，但要求城市内选址且优化欧氏距离加权和，本文按样例解释采用 weighted k-medoids。题面仅明确等距分配选择较早 CDN，没有完整规定中心更新同代价、空簇与数值容差：本文约定更新同代价取输入序号较早城市、空簇保持原址、使用 1e-9 容差。这是与给定样例一致的参考实现，不宣称唯一标准答案或全局最优。坐标约束写为正数，但样例含 0.00，程序兼容零坐标。

### Java 实现

```java
// 题目：CDN分发服务器选址
// 算法：排序 + 扫描
// 模式：ACM（stdin/stdout）
// 复杂度：时间 O(Tp²+q log q)，T 为到固定点或重复配置前的轮数，不预设为常数；空间 O(p+Tq)，包含城市、分簇及用于循环检测的中心历史

import java.io.*;
import java.util.*;

public class Main {
    static final char NL = (char) 10;
    static final double EPS = 1e-9;

    static double dist(double[] a, double[] b) {
        return Math.sqrt((a[0] - b[0]) * (a[0] - b[0]) + (a[1] - b[1]) * (a[1] - b[1]));
    }

    static List<List<Integer>> assign(double[][] cs, int[] centers) {
        int m = centers.length;
        List<List<Integer>> cluster = new ArrayList<>();
        for (int j = 0; j < m; j++) cluster.add(new ArrayList<Integer>());
        for (int i = 0; i < cs.length; i++) {
            int bestJ = 0;
            double bestD = dist(cs[i], cs[centers[0]]);
            for (int j = 1; j < m; j++) {
                double d = dist(cs[i], cs[centers[j]]);
                if (d < bestD - EPS) {
                    bestD = d;
                    bestJ = j;
                }
            }
            cluster.get(bestJ).add(i);
        }
        return cluster;
    }

    static int[] relocate(double[][] cs, int[] centers, List<List<Integer>> cluster) {
        int m = centers.length;
        int[] nxt = centers.clone();
        for (int j = 0; j < m; j++) {
            List<Integer> mem = cluster.get(j);
            if (mem.isEmpty()) continue;
            int bestC = -1;
            double bestCost = 0.0;
            for (int ci = 0; ci < mem.size(); ci++) {
                int c = mem.get(ci);
                double cost = 0.0;
                for (int ii = 0; ii < mem.size(); ii++) {
                    int i = mem.get(ii);
                    cost += cs[i][2] * dist(cs[i], cs[c]);
                }
                if (bestC < 0 || cost < bestCost - EPS) {
                    bestCost = cost;
                    bestC = c;
                }
            }
            nxt[j] = bestC;
        }
        return nxt;
    }

    // 主函数：读取输入并输出答案
    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        String line = br.readLine();
        if (line == null) return;
        int p = Integer.parseInt(line.trim());
        double[][] cs = new double[p][3];
        for (int i = 0; i < p; i++) {
            String[] parts = br.readLine().trim().split(",");
            cs[i][0] = Double.parseDouble(parts[0]);
            cs[i][1] = Double.parseDouble(parts[1]);
            cs[i][2] = Double.parseDouble(parts[2]);
        }
        int q = Integer.parseInt(br.readLine().trim());
        int[] centers = new int[q];
        for (int i = 0; i < q; i++) centers[i] = i;
        List<List<Integer>> cluster = new ArrayList<>();
        Set<String> seen = new HashSet<>();
        while (true) {
            String key = Arrays.toString(centers);
            if (seen.contains(key)) throw new RuntimeException();
            seen.add(key);
            cluster = assign(cs, centers);
            int[] nxt = relocate(cs, centers, cluster);
            if (Arrays.equals(nxt, centers)) {
                centers = nxt;
                break;
            }
            centers = nxt;
        }
        double[][] rows = new double[q][3];
        for (int j = 0; j < q; j++) {
            double cov = 0.0;
            for (int i : cluster.get(j)) cov += cs[i][2];
            rows[j][0] = cs[centers[j]][0];
            rows[j][1] = cs[centers[j]][1];
            rows[j][2] = cov;
        }
        Arrays.sort(rows, new Comparator<double[]>() {
            public int compare(double[] a, double[] b) {
                int c = Double.compare(a[0], b[0]);
                if (c != 0) return c;
                return Double.compare(a[1], b[1]);
            }
        });
        StringBuilder sb = new StringBuilder();
        for (int i = 0; i < rows.length; i++) {
            if (i > 0) sb.append(NL);
            sb.append(String.format(Locale.US, "%.2f,%.2f,%.2f", rows[i][0], rows[i][1], rows[i][2]));
        }
        System.out.print(sb);
    }
}
```
