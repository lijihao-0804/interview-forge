题目描述

实现一个基于信息增益的离散特征决策树分类器。每条训练数据由 m 个整数特征和一个整数标签组成： 对样本集合 S，设其中第 c 类所占比例为 pc，信息熵定义为： 按特征 A 的不同取值分组，取值 v 对应的样本子集记作 Sv。信息增益为： 从根节点递归建树：在尚未使用的特征中选择信息增益最大的特征，按其取值建立分支，再对子集重复这一过程。 增益相同时选择特征索引较小者 。如果当前子集标签全部相同，或已经没有特征可用，就建立叶子，输出当前子集的多数类。 概念示意中，天气特征 Outlook 可作为根节点，Sunny 对应 No、Overcast 对应 Yes，Rain 再按风力分为 Weak → Yes、Strong → No。已有文字只保留了树形示意，未保留对应训练表，因此不补造这张表。实际输入全部使用整数，不需要转换天气字符串。

feature_1 feature_2 ... feature_m label

输入描述与约束

第一行整数 m：特征数，1<m≤50。 第二行整数 n：训练样本数，1<n≤2000。 接下来 n 行，每行 m + 1 个整数，前 m 个是特征，最后一个是标签。 接下来一行整数 k：测试样本数。 接下来 k 行，每行 m 个整数，表示待分类样本。 材料未给出 k、特征值和标签值的数值范围，不能自行假定为二分类或只包含 0、1。 规则边界 ：原题文字明确了特征增益平局规则，但未明确“多数类票数相同”与“测试特征出现未知取值”的处理。下方实现沿用配套题解的补充约定：多数类平票时取较小标签，未知取值时返回当前节点的多数类。这两条不是新增的原题披露条件。

输出描述

输出 k 行，每行一个整数标签，顺序与测试数据一致。

思路分析

第一步：把信息增益变成计数。 对当前 rows 统计标签频数 cnt，即可计算划分前熵 base。对一个候选特征 f，按 row[f] 分组，统计每组的标签频数，再加权求组内熵。用 base 减去加权熵，便得到该特征的信息增益。 第二步：只在当前路径未用过的特征中选择。 对同一个节点，base 不随候选特征改变，所以最大化信息增益等价于最小化条件熵。feats 按原始索引升序保存，选中 best_f 后，子树只接收去掉它的 rest。不是把该特征从整棵树中全局删除：不同分支仍可独立选择。 第三步：控制平局与停止条件。 浮点对数求和可能让数学上相同的增益出现微小差异。实现采用 EPS = 1e-9 ，只有 gain > best_gain + EPS 才替换，数值近似相等时保留较小索引。这是浮点比较约定，不是原题额外给出的阈值；极接近但不相等的真实增益也可能被视作平局。 不要因为最优增益为零就提前停止。某些标签依赖多个特征的组合，单独看任一特征都可能没有增益。题目只要求在标签纯净或特征耗尽时结束，所以即使零增益也继续消耗一个特征，递归仍会终止。 第四步：每个节点保存多数类。 节点表示为 (label, feature, children) ，叶子的 feature 为 -1。预测时沿取值对应的分支下行；取值没有对应子节点时，按补充约定直接返回当前 label，而不是根节点的多数类。

正确性证明

对剩余特征数作归纳，证明建树实现满足题目及明确标注的补充约定。 若样本标签唯一，返回该标签；若没有剩余特征，返回计数最多的标签，平票取较小者。因此终止节点正确。 否则，代码对每个候选特征逐样本计数，按定义计算各组条件熵和信息增益。按升序扫描并使用上述容差比较，选出浮点实现规则下的最佳特征。各分支恰好包含该特征对应取值的全部样本，彼此不重叠且覆盖当前子集。 每个子问题少一个可用特征，由归纳假设，其子树也正确实现相同规则。因此当前节点及整棵树满足递归构造定义，且路径长度不超过 m。 预测过程保持“当前节点对应已匹配的全部路径条件”这一不变量。存在分支时继续匹配，抵达叶子后输出叶子标签；不存在分支时按约定返回当前多数类。因此预测也符合规定。这里证明的是按 ID3 规则构造，不是证明这棵树在所有决策树中具有最少节点或最高泛化精度。

复杂度分析

时间复杂度 ：建树 O(nm2)，预测 O(km)。一个节点对每个候选特征扫描该节点的样本；同一深度的样本集合不重叠，总数不超过 n，深度不超过 m。标签计数及分组使用字典，按均摊常数操作分析。 空间复杂度 ：O(nm+m2)，含训练数据、树、递归保留的样本引用以及每层复制的候选特征列表；测试样本逐条读取。常见简写为 O(nm)，但当样本很少、很多特征为常量时，路径上的剩余特征列表仍可能累计占用 O(m2)，这里将其单独计入。

Python 实现

import sys
from collections import Counter
from math import log2

EPS = 1e-9


def entropy(counts, total):
    return -sum((c / total) * log2(c / total) for c in counts)


def info_gain(rows, feature, base):
    groups = {}
    for row in rows:
        value, label = row[feature], row[-1]
        if value not in groups:
            groups[value] = Counter()
        groups[value][label] += 1
    total = len(rows)
    conditional = 0.0
    for cnt in groups.values():
        size = sum(cnt.values())
        conditional += size / total * entropy(cnt.values(), size)
    return base - conditional


def build_tree(rows, feats):
    cnt = Counter(row[-1] for row in rows)
    label = min(cnt, key=lambda value: (-cnt[value], value))
    if len(cnt) == 1 or not feats:
        return (label, -1, None)

    base = entropy(cnt.values(), len(rows))
    best_f, best_gain = -1, float("-inf")
    for feature in feats:
        gain = info_gain(rows, feature, base)
        if gain > best_gain + EPS:
            best_f, best_gain = feature, gain

    parts = {}
    for row in rows:
        parts.setdefault(row[best_f], []).append(row)
    rest = [feature for feature in feats if feature != best_f]
    children = {}
    for value, subset in parts.items():
        children[value] = build_tree(subset, rest)
    return (label, best_f, children)


def predict(node, features):
    while node[1] != -1:
        child = node[2].get(features[node[1]])
        if child is None:
            return node[0]
        node = child
    return node[0]


def solve():
    input = sys.stdin.readline
    m = int(input())
    n = int(input())
    train = [list(map(int, input().split())) for _ in range(n)]
    root = build_tree(train, list(range(m)))
    k = int(input())
    for _ in range(k):
        features = list(map(int, input().split()))
        print(predict(root, features))


if __name__ == "__main__":
    solve()
