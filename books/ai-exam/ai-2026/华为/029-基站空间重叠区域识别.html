基站空间重叠区域识别

遮住推导与代码，先自己想，再逐段揭示

题目描述

无线网络运维需要根据基站的密集程度识别信号重叠区域。给定 N 个平面基站 Pi(xi,yi)、距离门限 ε 和邻域数量门限 MinPts，定义：

则 Pj 位于 Pi 的邻域内。邻域包含基站自身。

核心点（Core） ：邻域内基站总数不少于 MinPts。 边界点（Border） ：自身不是核心点，但邻域内至少存在一个核心点。 噪声点（Noise） ：既不是核心点，也不是边界点。

请按输入顺序输出每个基站的类别： 0 表示 Core， 1 表示 Border， 2 表示 Noise。

输入格式

第一行包含三个整数 N,ε,MinPts：

1≤N≤2000； 0≤ε≤10000； 1≤ MinPts≤ N。

接下来 N 行，每行包含两个整数 xi,yi，满足 -10000≤xi,yi≤10000。

输出格式

输出 N 行，第 i 行为第 i 个基站的类别编号。

思路分析

第一步：统计邻域规模

初始化 count[i] = 1 ，因为每个基站与自身的距离为 0。只枚举 i<j 的点对；若曼哈顿距离不超过 ε，同时增加两端的计数。

第二步：一次性确定所有核心点

边界点的定义依赖最终核心点集合，因此不能边统计边判断，否则结果可能受遍历顺序影响。

第三步：标记非核心点

核心点直接输出 0 。对每个非核心点扫描核心点集合，只要找到一个距离不超过 ε 的核心点，就标为 1 ；否则标为 2 。

复杂度分析

时间复杂度 ：O(N2)。邻域计数需要枚举点对；边界点判断最坏也为平方级。 空间复杂度 ：O(N)，用于保存坐标、邻域计数、核心点标记和答案。

易错点

漏算自身 ：邻域包含 d=0 的自身，计数初值应为 1 。 距离类型写错 ：题目使用曼哈顿距离，不是欧氏距离，无需开平方。 边统计边标边界点 ：应先确定全部核心点，再判断 Border。 重复坐标 ：即使两个基站坐标相同，它们仍是两个不同输入点，彼此都应计入邻域。 边界为闭区间 ：距离恰好等于 ε 时也属于邻域。

Java 实现

import java.io.*;
import java.util.*;

public class Main {
    static final char NL = (char) 10;
    static class FastScanner {
        BufferedReader br;
        StringTokenizer st;
        FastScanner() {
            br = new BufferedReader(new InputStreamReader(System.in));
        }
        String next() throws IOException {
            while (st == null || !st.hasMoreTokens()) {
                String line = br.readLine();
                if (line == null) return null;
                st = new StringTokenizer(line);
            }
            return st.nextToken();
        }
        int nextInt() throws IOException {
            return Integer.parseInt(next());
        }
        long nextLong() throws IOException {
            return Long.parseLong(next());
        }
    }

    public static void main(String[] args) throws IOException {
        FastScanner fs = new FastScanner();
        String t = fs.next();
        if (t == null) return;
        int n = Integer.parseInt(t);
        long eps = fs.nextLong();
        int minPts = fs.nextInt();
        long[] xs = new long[n];
        long[] ys = new long[n];
        for (int i = 0; i < n; i++) {
            xs[i] = fs.nextLong();
            ys[i] = fs.nextLong();
        }
        long[] count = new long[n];
        Arrays.fill(count, 1);
        for (int i = 0; i < n; i++) {
            for (int j = i + 1; j < n; j++) {
                if (Math.abs(xs[i] - xs[j]) + Math.abs(ys[i] - ys[j]) <= eps) {
                    count[i]++;
                    count[j]++;
                }
            }
        }
        boolean[] isCore = new boolean[n];
        List<Integer> coreIndices = new ArrayList<>();
        for (int i = 0; i < n; i++) {
            isCore[i] = count[i] >= minPts;
            if (isCore[i]) coreIndices.add(i);
        }
        int[] answer = new int[n];
        Arrays.fill(answer, 2);
        for (int i = 0; i < n; i++) {
            if (isCore[i]) {
                answer[i] = 0;
                continue;
            }
            for (int j : coreIndices) {
                if (Math.abs(xs[i] - xs[j]) + Math.abs(ys[i] - ys[j]) <= eps) {
                    answer[i] = 1;
                    break;
                }
            }
        }
        StringBuilder sb = new StringBuilder();
        for (int i = 0; i < n; i++) {
            if (i > 0) sb.append(NL);
            sb.append(answer[i]);
        }
        System.out.print(sb);
    }
}

Python 实现

import sys


def solve():
    input = sys.stdin.readline
    n, eps, min_pts = map(int, input().split())
    points = [tuple(map(int, input().split())) for _ in range(n)]

    # 邻域包含自身。
    count = [1] * n

    for i in range(n):
        xi, yi = points[i]
        for j in range(i + 1, n):
            xj, yj = points[j]
            if abs(xi - xj) + abs(yi - yj) <= eps:
                count[i] += 1
                count[j] += 1

    # 必须先完整确定核心点集合。
    is_core = [value >= min_pts for value in count]
    core_indices = [i for i in range(n) if is_core[i]]

    answer = [2] * n
    for i in range(n):
        if is_core[i]:
            answer[i] = 0
            continue

        xi, yi = points[i]
        for j in core_indices:
            xj, yj = points[j]
            if abs(xi - xj) + abs(yi - yj) <= eps:
                answer[i] = 1
                break

    sys.stdout.write("\n".join(map(str, answer)))


if __name__ == "__main__":
    solve()
