# 分组查询注意力

> 来源：https://onefly.top/zero2Leetcode/04_real_interviews/huawei/ai-20261010/ · 华为 · 2026-10-10 · AI岗 · ACM 模式（stdin/stdout）

## 题目描述

实现 GQA：给定序列长度 $n$、Query 头数 $h_q$、KV 头数 $h_{kv}$、单个 Q/K 头维度 $d_k$ 和单个 V 头维度 $d_v$。保证 $h_q$ 是 $h_{kv}$ 的整数倍，令 $g=h_q/h_{kv}$，Query 头 $h$ 共享 KV 头 $\lfloor h/g\rfloor$。

每个头取矩阵中的 连续列块 。对单头计算缩放分数 $S=QK^T/\sqrt{d_k}$，掩码为 1 的位置将分数覆盖为 $-10^{30}$，掩码为 0 的位置保留。逐行减去最大分数，再计算 softmax 权重，与对应的 V 头加权求和。最后按 Query 头编号拼接输出。

输入格式 ：第一行 $n,h_q,h_{kv},d_k,d_v$，满足 $1\le n\le100$、$1\le h_q\le16$、$1\le h_{kv}\le8$、$1\le d_k,d_v\le10$。然后依次输入：

$n$ 行 Q，每行 $h_qd_k$ 个浮点数。 $n$ 行 K，每行 $h_{kv}d_k$ 个浮点数。 $n$ 行 V，每行 $h_{kv}d_v$ 个浮点数。 $n$ 行掩码，每行 $n$ 个 0 或 1。

Q、K、V 的数值范围为 $[-10,10]$。

输出格式 ：输出 $n$ 行，每行 $h_qd_v$ 个数，保留两位小数。

掩码边界 ：这里采用题目允许的有限替代值 $-10^{30}$。若某行全部被屏蔽，所有替代分数相等，softmax 会得到均匀权重；这与使用真正的负无穷时可能出现未定义值不同，不应自行把全屏蔽行改为零向量。

## 思路分析

第一步：写清楚三套列偏移。 Query 头 $h$ 的起点是 $hd_k$，对应 KV 头编号为 $q=\lfloor h/g\rfloor$，K 和 V 的起点分别是 $qd_k$、$qd_v$。不能用取模代替整除，否则会把连续分组变成交错分组。

第二步：逐行计算稳定 softmax。 对 Query 行 $i$，与每个 Key 行 $j$ 做点积，再除以 $\sqrt{d_k}$。覆盖掩码位置后，取当前行最大值 $s_{max}$，计算 $w_j=\exp(S_{ij}-s_{max})$。减去同一个常数不改变归一化结果，同时避免指数上溢。

第三步：直接累加 V。 每个输出坐标等于 $\sum_j w_j V_{jt}/\sum_j w_j$。只需保留当前行分数和权重，不必存完整注意力矩阵；把结果写入当前 Query 头对应的输出列块。

样例二的第一行只能看到第一个 Key，因此两个 Query 头都输出 7.00 ；第二行可见两项，两个 Query 头因分数不同，分别得到 7.95 与 7.98 。

正确性说明 ：列偏移保证每个 Query 头读取指定共享组；点积、缩放、掩码、稳定归一化、V 加权和依次对应定义。按头编号写入连续列块，正好实现最终拼接。

## 题解代码

### Python 实现

```python
import sys
import math


def grouped_attention(query, key, value, mask, hq, hkv, dk, dv):
    n = len(query)
    group = hq // hkv
    output = [[0.0] * (hq * dv) for _ in range(n)]
    scale = math.sqrt(dk)
    for head in range(hq):
        shared = head // group
        q_start, k_start, v_start = head * dk, shared * dk, shared * dv
        for i in range(n):
            scores = []
            for j in range(n):
                score = sum(query[i][q_start + t] * key[j][k_start + t]
                            for t in range(dk)) / scale
                scores.append(-1e30 if mask[i][j] else score)
            maximum = max(scores)
            weights = [math.exp(score - maximum) for score in scores]
            total = sum(weights)
            for t in range(dv):
                output[i][head * dv + t] = sum(
                    weights[j] * value[j][v_start + t] for j in range(n)
                ) / total
    return output


def solve():
    input = sys.stdin.readline
    n, hq, hkv, dk, dv = map(int, input().split())
    query = [list(map(float, input().split())) for _ in range(n)]
    key = [list(map(float, input().split())) for _ in range(n)]
    value = [list(map(float, input().split())) for _ in range(n)]
    mask = [list(map(int, input().split())) for _ in range(n)]
    output = grouped_attention(query, key, value, mask, hq, hkv, dk, dv)
    for row in output:
        print(" ".join(f"{x:.2f}" for x in row))


if __name__ == "__main__":
    solve()
```

## 复杂度分析

时间复杂度 ：$O(h_qn^2(d_k+d_v))$，每个头计算所有 Query/Key 点积及 V 加权和。

空间复杂度 ：$O(n^2+nh_q(d_k+d_v)+nh_{kv}(d_k+d_v))$，包括掩码、输入及输出；单行临时缓冲仅为 $O(n)$。

### Java 实现

```java
import java.io.*;
import java.util.*;
import java.util.Locale;

public class Main {
    static class In {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        StringTokenizer st = new StringTokenizer("");
        String next() { while (!st.hasMoreTokens()) { String l=null; try { l=br.readLine(); } catch (IOException e) { throw new RuntimeException(e); } if (l==null) return null; st=new StringTokenizer(l); } return st.nextToken(); }
        int ni() { return Integer.parseInt(next()); }
        double nd() { return Double.parseDouble(next()); }
    }
    public static void main(String[] args) {
        In in = new In();
        int n = in.ni(), hq = in.ni(), hkv = in.ni(), dk = in.ni(), dv = in.ni();
        double[][] query = new double[n][hq * dk];
        double[][] key = new double[n][hkv * dk];
        double[][] value = new double[n][hkv * dv];
        int[][] mask = new int[n][n];
        for (int i = 0; i < n; i++) for (int j = 0; j < hq * dk; j++) query[i][j] = in.nd();
        for (int i = 0; i < n; i++) for (int j = 0; j < hkv * dk; j++) key[i][j] = in.nd();
        for (int i = 0; i < n; i++) for (int j = 0; j < hkv * dv; j++) value[i][j] = in.nd();
        for (int i = 0; i < n; i++) for (int j = 0; j < n; j++) mask[i][j] = in.ni();
        int group = hq / hkv;
        double[][] output = new double[n][hq * dv];
        double scale = Math.sqrt(dk);
        for (int head = 0; head < hq; head++) {
            int shared = head / group;
            int qStart = head * dk, kStart = shared * dk, vStart = shared * dv;
            for (int i = 0; i < n; i++) {
                double[] scores = new double[n];
                for (int j = 0; j < n; j++) {
                    double s = 0;
                    for (int t = 0; t < dk; t++) s += query[i][qStart + t] * key[j][kStart + t];
                    s /= scale;
                    scores[j] = mask[i][j] != 0 ? -1e30 : s;
                }
                double maximum = scores[0];
                for (int j = 1; j < n; j++) if (scores[j] > maximum) maximum = scores[j];
                double[] w = new double[n];
                double total = 0;
                for (int j = 0; j < n; j++) { w[j] = Math.exp(scores[j] - maximum); total += w[j]; }
                for (int t = 0; t < dv; t++) {
                    double sum = 0;
                    for (int j = 0; j < n; j++) sum += w[j] * value[j][vStart + t];
                    output[i][head * dv + t] = sum / total;
                }
            }
        }
        StringBuilder out = new StringBuilder();
        for (int i = 0; i < n; i++) {
            StringBuilder line = new StringBuilder();
            for (int j = 0; j < hq * dv; j++) { if (j > 0) line.append(' '); line.append(String.format(Locale.US, "%.2f", output[i][j])); }
            out.append(line).append((char)10);
        }
        System.out.print(out.toString());
    }
}
```
