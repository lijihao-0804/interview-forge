OCR 智能纠错系统迭代训练和推理

遮住推导与代码，先自己想，再逐段揭示

原题解析 · 华为 · 2026-10-23 · AI岗 · ACM 模式（stdin/stdout）

题目描述

某智能终端搭载字符级 OCR 纠错系统，把“识别字符到真实字符”的纠错建模为朴素贝叶斯过程。

字符集为小写英文字母 a,b,…,z，记 K=26。模型由两组统计量描述：

emit[c][o]：训练语料中，真实字符 c 被 OCR 识别为 o 的次数。 prior[c]：训练语料中，真实字符 c 出现的次数。

对发射概率和先验概率使用加 α 拉普拉斯平滑，α 是正整数：

P(o|c)=emit[c][o]+α∑o′emit[c][o′]+αK,P(c)=prior[c]+α∑c′prior[c′]+αK.

对于待纠错字符串中的每一个 OCR 字符 o，独立选择使 P(o|c)P(c) 最大的真实字符 c。如果多个候选取得相同最大值，选择字典序最小的字符。

除 N 条带标注训练对外，还有 M 条只有 OCR 输出、没有真实文本的未标注样本。初始模型仅由原始带标注样本统计得到，共进行 T 轮自训练。每轮执行：

使用当前模型对全部 M 条未标注样本解码，得到伪真实文本。 使用 N 条原始标注样本，加上本轮的 M 条“（OCR，伪真实）”训练对， 重新统计 模型。

每轮伪标注替换上一轮伪标注，不累积叠加；原始标注始终保留。完成 T 轮后，用最终模型纠正测试 OCR 字符串并输出。

数值稳定性要求 ：比较候选时必须用整数交叉相乘，避免浮点误差。令

Nc=(emit[c][o]+α)(prior[c]+α),Dc=∑o′emit[c][o′]+αK.

先验概率的分母对所有候选相同，可以省略。两个候选的比较为

N1D1>N2D2iffN1D2>N2D1.

输入描述与约束

第一行四个整数 N,M,T,α，依次表示带标注样本数、未标注样本数、迭代轮数和平滑系数。

接下来 N 行，每行两个等长字符串 ocri,truthi， 前者是 OCR 输出，后者是真实文本 。

接下来 M 行，每行一个未标注 OCR 字符串。最后一行是测试 OCR 字符串。

1≤ N≤ 100。 0≤ M≤ 100。 0≤ T≤ 20。 1≤α≤10。 所有字符串仅含小写英文字母，长度满足 1≤ L≤ 100。 每个标注对内的两个字符串长度相等，不要求不同样本之间等长。

输出描述

输出一行，表示测试 OCR 字符串经过最终模型纠正后的结果。

解题思路：朴素贝叶斯计数与同步迭代

对一对 (ocr, truth) ，逐位置取真实字符 c 和识别字符 o ，增加 emit[c][o] 与 prior[c] 。再用 total[c] 记录该真实字符的发射总数。

在本题每个真实字符恰好对应一个 OCR 字符，所以 total[c] == prior[c] 。代码保留两个数组，使发射分母和先验分子分别对应题面定义，便于核对。

删去所有候选共有的先验分母后，得分是

score(c,o)=(emit[c][o]+α)(prior[c]+α)total[c]+αK.

由于 α>0，分母始终为正。交叉相乘可以精确判断大于和相等，不需要对数、浮点数或误差阈值。

按 a 到 z 的顺序枚举候选，初始化最优候选为 a ，仅在新分数 严格更大 时替换。相等时保留先遇到的候选，正好实现字典序规则。Python 整数可自动扩展；其他语言实现应使用足够宽的整数，不能直接用 32 位乘积。

同一轮内，一个 OCR 字符的预测只由字符本身和当前模型决定，与其位置、所在字符串无关。因此可以先计算

table[o]=当前模型对字符 o 的最优预测.

枚举 K 个识别字符及 K 个真实字符，建表需要 O(K2) 时间。之后解码任何字符串只需逐字符查表。

先由原始标注建立初始统计量。每轮先固定当前映射表，用它解码全部未标注样本；全部解码完成后，将原始标注和本轮伪标注一起传入计数函数，从零建立新统计量。

不能解码一条就更新模型，让后续样本看到已经改变的统计量；也不能在上一轮统计量上直接累加，否则会重复计算旧伪标注。

完成循环后必须再用最终模型建表，不能直接拿最后一轮用于产生伪标注的旧表输出测试结果。T=0 时直接使用初始模型；M=0 时每轮仍只统计原始标注，模型不变。

正确性证明

引理一：计数函数正确。 每对训练字符串中的每个位置，恰好对题面定义的 emit[c][o]、prior[c] 及发射总数贡献一次。遍历所有位置后得到的统计量与定义相同。

引理二：映射表符合解码规则。 省略的先验分母对所有候选相同且为正，不改变得分顺序；交叉相乘保持大小关系。枚举覆盖所有真实字符，只在严格更优时替换，因此最终得到最大分数及其中字典序最小的候选。逐字符查表与逐字符独立解码完全等价。

归纳证明迭代正确。 初始计数由原始标注建立，由引理一正确。假设某轮开始时模型与规定一致，由引理二，本轮统一生成的所有伪标注正确；随后从原始标注和本轮伪标注重新统计，由引理一得到规定的新模型，且没有上一轮伪标注残留。归纳可得完成 T 轮后的模型正确，再由引理二可得测试输出正确。

复杂度分析

记 A 为原始标注中 OCR 字符串的总长度，U 为未标注字符串的总长度，Q 为测试串长度，字符集大小 K=26。

初始计数：O(A+K2)。 每轮：建表 O(K2)，生成伪标注 O(U)，重新计数 O(A+U+K2)。 最终建表与输出：O(K2+Q)。

总时间复杂度为

O(A+K2+T(A+U+K2)+Q).

以最大字符串长度 L 表示，上界也可写为

O(NL+(T+1)K2+T(N+M)L+L).

这包含 T=0 时仍需执行的初始计数和最终建表，不能把所有预处理都放进乘以 T 的项中。

空间复杂度为 O(A+U+Q+K2)，包括输入字符串、当前轮伪标注和计数表；每轮旧伪标注被替换，不随轮数线性增长。

本题小结

实现重点有四个： emit[真实][识别] 的方向、整数交叉相乘、相等时不替换、每轮重新计数。映射表把同字符的重复预测合并，既降低开销，也便于保证本轮所有伪标注使用同一个模型。

Java 实现

// 题目：OCR 智能纠错系统迭代训练和推理
// 算法：按题意模拟
// 模式：ACM（stdin/stdout）

import java.io.*;
import java.util.*;

public class Main {

    static final int K=26;
    static class Cnt {
        long[][] emit=new long[K][K];
        long[] total=new long[K];
        long[] prior=new long[K];
    }
    // 核心方法：buildCounts
    static Cnt buildCounts(List<String[]> pairs) {
        Cnt c=new Cnt();
        // 循环处理
        for(String[] p:pairs) {
            String o=p[0],t=p[1];
            // 循环处理
            for(int k=0;k<o.length();k++) {
                int oo=o.charAt(k)-'a',cc=t.charAt(k)-'a';
                c.emit[cc][oo]++;
                c.total[cc]++;
                c.prior[cc]++;
            }
        }
        // 返回结果
        return c;
    }
    // 核心方法：buildTable
    static int[] buildTable(Cnt c,int alpha) {
        int[] tab=new int[K];
        // 循环处理
        for(int o=0;o<K;o++) {
            int best=0;
            long bn=(c.emit[0][o]+alpha)*(c.prior[0]+alpha);
            long bd=c.total[0]+(long)alpha*K;
            // 循环处理
            for(int cc=1;cc<K;cc++) {
                long num=(c.emit[cc][o]+alpha)*(c.prior[cc]+alpha);
                long den=c.total[cc]+(long)alpha*K;
                // 条件判断
                if(num*bd>bn*den) {
                    best=cc;
                    bn=num;
                    bd=den;
                }
            }
            tab[o]=best;
        }
        // 返回结果
        return tab;
    }
    // 核心方法：decode
    static String decode(int[] tab,String text) {
        StringBuilder sb=new StringBuilder();
        // 枚举位置 i
        for(int i=0;i<text.length();i++)sb.append((char)('a'+tab[text.charAt(i)-'a']));
        // 返回结果
        return sb.toString();
    }
    // 核心方法：selfTrain
    static int[] selfTrain(List<String[]> labeled,List<String> unlabeled,int rounds,int alpha) {
        Cnt c=buildCounts(labeled);
        // 循环处理
        for(int r=0;r<rounds;r++) {
            int[] tab=buildTable(c,alpha);
            List<String[]> ps=new ArrayList<>();
            // 循环处理
            for(String ocr:unlabeled)ps.add(new String[] {
                ocr,decode(tab,ocr)
            }
            );
            List<String[]> all=new ArrayList<>(labeled);
            all.addAll(ps);
            c=buildCounts(all);
        }
        // 返回结果
        return buildTable(c,alpha);
    }
    // 主函数：读取输入并输出答案
    public static void main(String[] a) throws IOException {
        Scanner sc = new Scanner(System.in);
        // 条件判断
        int n=sc.nextInt();
        int m=sc.nextInt();
        int rounds=sc.nextInt();
        int alpha=sc.nextInt();
        List<String[]> lab=new ArrayList<>();
        // 枚举位置 i
        for(int i=0;i<n;i++) {
            String o=sc.next();
            String t=sc.next();
            lab.add(new String[] {
                o,t
            }
            );
        }
        List<String> unl=new ArrayList<>();
        // 枚举位置 i
        for(int i=0;i<m;i++)unl.add(sc.next());
        String test=sc.next();
        int[] tab=selfTrain(lab,unl,rounds,alpha);
        System.out.println(decode(tab,test));
    }
}

Python 实现

# 题目：OCR 智能纠错系统迭代训练和推理
# 算法：按题意模拟
# 模式：ACM（stdin/stdout）

import sys

K = 26


# 核心函数：build_counts
def build_counts(pairs):
    emit = [[0] * K for _ in range(K)]
    total = [0] * K
    prior = [0] * K
    for ocr, truth in pairs:
        for observed, actual in zip(ocr, truth):
            o = ord(observed) - ord('a')
            c = ord(actual) - ord('a')
            emit[c][o] += 1
            total[c] += 1
            prior[c] += 1
    # 返回结果
    return emit, total, prior


# 核心函数：build_table
def build_table(emit, total, prior, alpha):
    table = [0] * K
    # 遍历 o
    for o in range(K):
        best = 0
        best_num = (emit[0][o] + alpha) * (prior[0] + alpha)
        best_den = total[0] + alpha * K
        # 遍历 c
        for c in range(1, K):
            num = (emit[c][o] + alpha) * (prior[c] + alpha)
            den = total[c] + alpha * K
            # 条件判断
            if num * best_den > best_num * den:
                best = c
                best_num = num
                best_den = den
        table[o] = best
    # 返回结果
    return table


# 核心函数：decode
def decode(table, text):
    # 返回结果
    return ''.join(
        chr(ord('a') + table[ord(ch) - ord('a')])
        # 遍历 ch
        for ch in text
    )


# 核心函数：self_train
def self_train(labeled, unlabeled, rounds, alpha):
    emit, total, prior = build_counts(labeled)
    # 遍历 _
    for _ in range(rounds):
        table = build_table(emit, total, prior, alpha)
        pseudo = [(ocr, decode(table, ocr)) for ocr in unlabeled]
        # 从零统计：仅保留原始标注与本轮伪标注。
        emit, total, prior = build_counts(labeled + pseudo)
    # 返回结果
    return build_table(emit, total, prior, alpha)


# 核心函数：main
def main():
    tokens = iter(sys.stdin.read().split())
    first = next(tokens, None)
    # 条件判断
    if first is None:
        # 返回结果
        return
    n = int(first)
    m = int(next(tokens))
    rounds = int(next(tokens))
    alpha = int(next(tokens))
    labeled = [(next(tokens), next(tokens)) for _ in range(n)]
    unlabeled = [next(tokens) for _ in range(m)]
    test = next(tokens)
    table = self_train(labeled, unlabeled, rounds, alpha)
    print(decode(table, test))


if __name__ == "__main__":
    main()
