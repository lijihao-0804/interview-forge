题目描述

实现 GQA：给定序列长度 n、Query 头数 hq、KV 头数 hkv、单个 Q/K 头维度 dk 和单个 V 头维度 dv。保证 hq 是 hkv 的整数倍，令 g=hq/hkv，Query 头 h 共享 KV 头 ⌊h/g⌋。 每个头取矩阵中的 连续列块 。对单头计算缩放分数 S=QKT/dk，掩码为 1 的位置将分数覆盖为 -1030，掩码为 0 的位置保留。逐行减去最大分数，再计算 softmax 权重，与对应的 V 头加权求和。最后按 Query 头编号拼接输出。 输入格式 ：第一行 n,hq,hkv,dk,dv，满足 1≤n≤100、1≤hq≤16、1≤hkv≤8、1≤dk,dv≤10。然后依次输入： n 行 Q，每行 hqdk 个浮点数。 n 行 K，每行 hkvdk 个浮点数。 n 行 V，每行 hkvdv 个浮点数。 n 行掩码，每行 n 个 0 或 1。 Q、K、V 的数值范围为 [-10,10]。 输出格式 ：输出 n 行，每行 hqdv 个数，保留两位小数。 掩码边界 ：这里采用题目允许的有限替代值 -1030。若某行全部被屏蔽，所有替代分数相等，softmax 会得到均匀权重；这与使用真正的负无穷时可能出现未定义值不同，不应自行把全屏蔽行改为零向量。

思路分析

第一步：写清楚三套列偏移。 Query 头 h 的起点是 hdk，对应 KV 头编号为 q=⌊h/g⌋，K 和 V 的起点分别是 qdk、qdv。不能用取模代替整除，否则会把连续分组变成交错分组。 第二步：逐行计算稳定 softmax。 对 Query 行 i，与每个 Key 行 j 做点积，再除以 dk。覆盖掩码位置后，取当前行最大值 smax，计算 wj=exp(Sij-smax)。减去同一个常数不改变归一化结果，同时避免指数上溢。 第三步：直接累加 V。 每个输出坐标等于 ∑jwjVjt/∑jwj。只需保留当前行分数和权重，不必存完整注意力矩阵；把结果写入当前 Query 头对应的输出列块。 样例二的第一行只能看到第一个 Key，因此两个 Query 头都输出 7.00 ；第二行可见两项，两个 Query 头因分数不同，分别得到 7.95 与 7.98 。 正确性说明 ：列偏移保证每个 Query 头读取指定共享组；点积、缩放、掩码、稳定归一化、V 加权和依次对应定义。按头编号写入连续列块，正好实现最终拼接。

题解代码

Python 实现

import sys
import math


def grouped_attention(query, key, value, mask, hq, hkv, dk, dv):
    n = len(query)
    group = hq // hkv
    output = [[0.0] * (hq * dv) for _ in range(n)]
    scale = math.sqrt(dk)
    for head in range(hq):
        shared = head // group
        q_start, k_start, v_start = head * dk, shared * dk, shared * dv
        for i in range(n):
            scores = []
            for j in range(n):
                score = sum(query[i][q_start + t] * key[j][k_start + t]
                            for t in range(dk)) / scale
                scores.append(-1e30 if mask[i][j] else score)
            maximum = max(scores)
            weights = [math.exp(score - maximum) for score in scores]
            total = sum(weights)
            for t in range(dv):
                output[i][head * dv + t] = sum(
                    weights[j] * value[j][v_start + t] for j in range(n)
                ) / total
    return output


def solve():
    input = sys.stdin.readline
    n, hq, hkv, dk, dv = map(int, input().split())
    query = [list(map(float, input().split())) for _ in range(n)]
    key = [list(map(float, input().split())) for _ in range(n)]
    value = [list(map(float, input().split())) for _ in range(n)]
    mask = [list(map(int, input().split())) for _ in range(n)]
    output = grouped_attention(query, key, value, mask, hq, hkv, dk, dv)
    for row in output:
        print(" ".join(f"{x:.2f}" for x in row))


if __name__ == "__main__":
    solve()

复杂度分析

时间复杂度 ：O(hqn2(dk+dv))，每个头计算所有 Query/Key 点积及 V 加权和。 空间复杂度 ：O(n2+nhq(dk+dv)+nhkv(dk+dv))，包括掩码、输入及输出；单行临时缓冲仅为 O(n)。
