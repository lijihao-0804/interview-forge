# 时间序列数据清洗与特征评分

> <a href="https://onefly.top/zero2Leetcode/04_real_interviews/huawei/ai-20260904/" target="_blank" rel="noopener noreferrer">原题解析</a> · 华为 · 2026-09-04 · AI岗 · ACM 模式（stdin/stdout）

## 题目描述

给定 $n$ 条按时间戳严格递增的记录 $(t_i,v_i,q_i)$。质量标记中，0 表示有效、1 表示可疑、2 表示无效。依次执行：

插值 ：仅处理 $q_i=2$ 的记录，前继/后继锚点只认 $q=0$。两侧都有锚点 $(t_a,v_a),(t_b,v_b)$ 时令

\(v_i=v_a+(v_b-v_a)\frac{t_i-t_a}{t_b-t_a};\)

只有一侧时复制该侧值；两侧都没有则保留原值。 异常平滑 ：窗口大小 $w$ 为奇数。位置 $i$ 的窗口是序列范围与 $[i-(w-1)/2,i+(w-1)/2]$ 的交集。窗口均值、总体标准差都由步骤 1 的同一份快照计算；若 $\lvert v_i-\mu\rvert>k\sigma$，则把该点替换为 $\mu$。所有替换统一写入新序列。 标准化 ：对步骤 2 的序列计算总体均值 $\bar v$ 和总体标准差 $s$，令 $z_i=(v_i-\bar v)/s$；若 $s=0$，所有 $z_i=0$。 评分 ：质量权重 $p_i$ 在 $q_i=0,1,2$ 时分别为 $1,0.5,0.25$。令

\(w_i=\frac{p_i\lvert v_i\rvert}{\sum_jp_j\lvert v_j\rvert},\qquad S=\sum_iw_i\lvert z_i\rvert.\)

若分母为 0，则 $S=0$。输出 $S\times100$ 四舍五入后的整数，恰为 0.5 时向上取整。

## 输入描述

第一行输入 $n,w,k$，其中

接下来 $n$ 行输入 $t_i,v_i,q_i$，满足

且 $t_i$ 严格递增，至少有一条 $q_i=0$ 的记录。

## 输出描述

输出最终评分乘 100 后按题意取整的整数。

## 样例

输入

输出

```text
6 3 2
1 10 0
2 15 2
3 20 0
4 18 0
5 100 0
6 12 0
152
```

## 算法

插值用正反两次扫描得到最近有效锚点。异常检测若使用“平方和减均值平方”，当数据整体很大但波动很小时会发生灾难性消减。为兼顾 $n=10^4$ 与数值稳定性，使用两层分块：

每块维护值的总和、块均值与块内离差平方和 $M_2$； 查询窗口时，把完整块通过 Chan 合并公式加入统计量，窗口两端不足整块的元素逐个加入； 这样不再相减两个约 $10^{18}$ 的近似数，方差由中心化离差直接得到。

块长取约 $\sqrt n$，每个窗口访问 $O(\sqrt n)$ 个完整块与边缘元素，总复杂度 $O(n\sqrt n)$，在 $n=10^4$ 时可行。全局标准化同样用 Welford 在线算法计算稳定方差。

## 正确性证明

最近锚点扫描显然给出每个位置左右最近的 $q=0$ 记录，因此步骤 1 严格按题意插值。

对步骤 2，Welford 单点更新维护样本数、均值和离差平方和。Chan 公式精确描述两个不交集合统计量合并后的均值与离差平方和；每个窗口被拆成互不重叠的边缘单点和完整块，合并后覆盖且仅覆盖该窗口，因此得到窗口总体均值与方差。所有查询只读取插值后的 cleaned ，结果另存，满足快照要求。

步骤 3 的 Welford 统计覆盖平滑后全部元素，故得到题定总体均值和标准差。步骤 4 逐项代入权重公式并按 floor(x+0.5) 取整。四步均正确，最终输出正确。

## Python ACM 题解

```text
import math
import sys


def merge_stats(a, b):
    na, ma, m2a = a
    nb, mb, m2b = b
    if na == 0:
        return b
    if nb == 0:
        return a
    delta = mb - ma
    n = na + nb
    mean = ma + delta * nb / n
    m2 = m2a + m2b + delta * delta * na * nb / n
    return n, mean, m2


def add_value(stat, x):
    n, mean, m2 = stat
    n2 = n + 1
    delta = x - mean
    mean2 = mean + delta / n2
    return n2, mean2, m2 + delta * (x - mean2)


def clean_values(ts, raw, quality):
    n = len(raw)
    previous = [-1] * n
    following = [-1] * n
    last = -1
    for i in range(n):
        previous[i] = last
        if quality[i] == 0:
            last = i
    last = -1
    for i in range(n - 1, -1, -1):
        following[i] = last
        if quality[i] == 0:
            last = i

    values = [float(x) for x in raw]
    for i in range(n):
        if quality[i] != 2:
            continue
        left, right = previous[i], following[i]
        if left != -1 and right != -1:
            ratio = (ts[i] - ts[left]) / (ts[right] - ts[left])
            values[i] = raw[left] + (raw[right] - raw[left]) * ratio
        elif left != -1:
            values[i] = float(raw[left])
        elif right != -1:
            values[i] = float(raw[right])
    return values


def smooth_values(values, window, threshold):
    n = len(values)
    block_size = max(1, math.isqrt(n))
    block_stats = []
    for start in range(0, n, block_size):
        stat = (0, 0.0, 0.0)
        for x in values[start:start + block_size]:
            stat = add_value(stat, x)
        block_stats.append(stat)

    def range_stats(left, right):
        stat = (0, 0.0, 0.0)
        while left <= right and left % block_size:
            stat = add_value(stat, values[left])
            left += 1
        while left + block_size - 1 <= right:
            stat = merge_stats(stat, block_stats[left // block_size])
            left += block_size
        while left <= right:
            stat = add_value(stat, values[left])
            left += 1
        return stat

    half = (window - 1) // 2
    result = values.copy()
    for i, value in enumerate(values):
        left = max(0, i - half)
        right = min(n - 1, i + half)
        count, mean, m2 = range_stats(left, right)
        variance = max(0.0, m2 / count)
        if abs(value - mean) > threshold * math.sqrt(variance):
            result[i] = mean
    return result


def score(values, quality):
    stat = (0, 0.0, 0.0)
    for x in values:
        stat = add_value(stat, x)
    n, mean, m2 = stat
    standard_deviation = math.sqrt(max(0.0, m2 / n))

    quality_weight = (1.0, 0.5, 0.25)
    denominator = sum(quality_weight[q] * abs(x) for x, q in zip(values, quality))
    if denominator == 0.0 or standard_deviation == 0.0:
        return 0

    total = 0.0
    for x, q in zip(values, quality):
        weight = quality_weight[q] * abs(x) / denominator
        total += weight * abs((x - mean) / standard_deviation)
    return math.floor(total * 100 + 0.5)


def solve():
    data = list(map(int, sys.stdin.buffer.read().split()))
    n, window, threshold = data[:3]
    ts, raw, quality = [], [], []
    pointer = 3
    for _ in range(n):
        t, value, q = data[pointer:pointer + 3]
        pointer += 3
        ts.append(t)
        raw.append(value)
        quality.append(q)

    cleaned = clean_values(ts, raw, quality)
    smoothed = smooth_values(cleaned, window, threshold)
    print(score(smoothed, quality))


if __name__ == "__main__":
    solve()
```

## 复杂度分析

时间复杂度 ：$O(n\sqrt n)$；插值、建块、标准化和评分为 $O(n)$，$n$ 个窗口查询各为 $O(\sqrt n)$。

空间复杂度 ：$O(n)$。

## 易错点

无效点只能使用原始质量为 0 的点作为插值锚点。 窗口统计必须全部读取步骤 1 的同一快照，不能边算边改。 标准差采用总体口径，分母是窗口长度或 $n$，不是减 1。 sum(x*x)/n - mean*mean 对大基线、小波动数据会数值消减，简单截零不能修复误差。 Python round 使用银行家舍入；题目要求 0.5 向上，应使用 floor(x + 0.5) 。

### Java 实现

```java
// 题目：时间序列数据清洗与特征评分
// 算法：按题意模拟
// 模式：ACM（stdin/stdout）
// 复杂度：时间 O(n\sqrt n)；插值、建块、标准化和评分为 O(n)，n 个窗口查询各为 O(\sqrt n)；空间 O(n)

import java.io.*;
import java.util.*;

public class Main {
    static class FastScanner {
        BufferedReader br;
        StringTokenizer st;
        FastScanner() {
            br = new BufferedReader(new InputStreamReader(System.in));
        }
        String next() throws IOException {
            while (st == null || !st.hasMoreTokens()) {
                String line = br.readLine();
                if (line == null) return null;
                st = new StringTokenizer(line);
            }
            return st.nextToken();
        }
        int nextInt() throws IOException {
            return Integer.parseInt(next());
        }
    }

    static int isqrt(int n) {
        int r = (int) Math.sqrt((double) n);
        while ((long) (r + 1) * (r + 1) <= n) r++;
        while ((long) r * r > n) r--;
        return r;
    }

    static double[] mergeStats(double[] a, double[] b) {
        double na = a[0], ma = a[1], m2a = a[2];
        double nb = b[0], mb = b[1], m2b = b[2];
        if (na == 0) return b;
        if (nb == 0) return a;
        double delta = mb - ma;
        double n = na + nb;
        double mean = ma + delta * nb / n;
        double m2 = m2a + m2b + delta * delta * na * nb / n;
        return new double[]{n, mean, m2};
    }

    static double[] addValue(double[] stat, double x) {
        double n = stat[0];
        double mean = stat[1];
        double m2 = stat[2];
        double n2 = n + 1;
        double delta = x - mean;
        double mean2 = mean + delta / n2;
        return new double[]{n2, mean2, m2 + delta * (x - mean2)};
    }

    static double[] cleanValues(int[] ts, int[] raw, int[] quality) {
        int n = raw.length;
        int[] previous = new int[n];
        int[] following = new int[n];
        int last = -1;
        for (int i = 0; i < n; i++) {
            previous[i] = last;
            if (quality[i] == 0) last = i;
        }
        last = -1;
        for (int i = n - 1; i >= 0; i--) {
            following[i] = last;
            if (quality[i] == 0) last = i;
        }
        double[] values = new double[n];
        for (int i = 0; i < n; i++) values[i] = (double) raw[i];
        for (int i = 0; i < n; i++) {
            if (quality[i] != 2) continue;
            int left = previous[i];
            int right = following[i];
            if (left != -1 && right != -1) {
                double ratio = (double) (ts[i] - ts[left]) / (ts[right] - ts[left]);
                values[i] = raw[left] + (raw[right] - raw[left]) * ratio;
            } else if (left != -1) {
                values[i] = (double) raw[left];
            } else if (right != -1) {
                values[i] = (double) raw[right];
            }
        }
        return values;
    }

    static double[] rangeStats(double[] values, double[][] blockStats, int blockSize, int left, int right) {
        double[] stat = new double[]{0, 0.0, 0.0};
        while (left <= right && left % blockSize != 0) {
            stat = addValue(stat, values[left]);
            left++;
        }
        while (left + blockSize - 1 <= right) {
            stat = mergeStats(stat, blockStats[left / blockSize]);
            left += blockSize;
        }
        while (left <= right) {
            stat = addValue(stat, values[left]);
            left++;
        }
        return stat;
    }

    static double[] smoothValues(double[] values, int window, double threshold) {
        int n = values.length;
        int blockSize = Math.max(1, isqrt(n));
        int blockCount = (n + blockSize - 1) / blockSize;
        double[][] blockStats = new double[blockCount][];
        for (int s = 0; s < n; s += blockSize) {
            double[] stat = new double[]{0, 0.0, 0.0};
            for (int i = s; i < Math.min(n, s + blockSize); i++) stat = addValue(stat, values[i]);
            blockStats[s / blockSize] = stat;
        }
        int half = (window - 1) / 2;
        double[] result = values.clone();
        for (int i = 0; i < n; i++) {
            int left = Math.max(0, i - half);
            int right = Math.min(n - 1, i + half);
            double[] st = rangeStats(values, blockStats, blockSize, left, right);
            double count = st[0];
            double mean = st[1];
            double m2 = st[2];
            double variance = Math.max(0.0, m2 / count);
            if (Math.abs(values[i] - mean) > threshold * Math.sqrt(variance)) {
                result[i] = mean;
            }
        }
        return result;
    }

    static long score(double[] values, int[] quality) {
        double[] stat = new double[]{0, 0.0, 0.0};
        for (double x : values) stat = addValue(stat, x);
        double n = stat[0];
        double mean = stat[1];
        double m2 = stat[2];
        double sd = Math.sqrt(Math.max(0.0, m2 / n));
        double[] qw = new double[]{1.0, 0.5, 0.25};
        double denominator = 0.0;
        for (int i = 0; i < values.length; i++) denominator += qw[quality[i]] * Math.abs(values[i]);
        if (denominator == 0.0 || sd == 0.0) return 0;
        double total = 0.0;
        for (int i = 0; i < values.length; i++) {
            double weight = qw[quality[i]] * Math.abs(values[i]) / denominator;
            total += weight * Math.abs((values[i] - mean) / sd);
        }
        return (long) Math.floor(total * 100 + 0.5);
    }

    // 主函数：读取输入并输出答案
    public static void main(String[] args) throws IOException {
        FastScanner fs = new FastScanner();
        String t = fs.next();
        if (t == null) return;
        int n = Integer.parseInt(t);
        int window = fs.nextInt();
        int threshold = fs.nextInt();
        int[] ts = new int[n];
        int[] raw = new int[n];
        int[] quality = new int[n];
        for (int i = 0; i < n; i++) {
            ts[i] = fs.nextInt();
            raw[i] = fs.nextInt();
            quality[i] = fs.nextInt();
        }
        double[] cleaned = cleanValues(ts, raw, quality);
        double[] smoothed = smoothValues(cleaned, window, (double) threshold);
        System.out.println(score(smoothed, quality));
    }
}
```
