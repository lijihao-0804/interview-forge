题目描述

将 n 个梯度计算任务分配给 k 张 NPU，每个任务恰好分配一次。先最小化所有卡的最大总耗时 T；若有多个方案达到同一个最优 T，再最小化总训练成本。 设第 i 张卡的任务总耗时为 si，基础学习率为 b，衰减系数为 r，则 输入格式 ：一行四段，以分号分隔： 任务耗时列表;NPU数量;基础学习率;衰减系数 。列表中的数以逗号分隔。约束为 1≤n≤12、0≤ti≤1000、1≤ k≤ n、0<b≤1、0<r<1；两个小数均不超过四位小数。 输出格式 ： 最小最大总耗时;总训练成本 ，成本保留四位小数。 格式说明纠正 ：材料的格式说明另写了 6;1.6590 ，但它不是下面第一个输入的正确结果。该输入总耗时为 20，三张卡的最大负载至少为 ⌈20/3⌉=7；应以正式样例的 7;1.9400 为准。

样例 1

输入 输出

4,3,2,3,5,2,1;3;0.1;0.9
7;1.9400

样例 2

输入 输出

5;1;0.1;0.9
5;0.5000

思路分析

第一步：分清两个目标的优先级。 不能把最大耗时和成本加权成一个数，也不能只在某一个最小最大耗时方案上计算成本。先求出全局最优阈值 T，再在这个阈值内重新优化成本。 第二步：用任务集合消除重复计算。 n≤12，只有 2n 个子集。以位掩码 M 表示任务集合，预处理 S[M] 为其耗时之和。直接给每个任务枚举卡号会产生 kn 种分配，子集 DP 则复用相同的剩余任务状态。 第三步：第一遍 DP 求负载。 Gj[M] 表示把 M 分成 j 个非空任务组的最小最大负载。初值 G0[0]=0，其余为无穷大。枚举本组 U⊆M： 只枚举含 M 最低位任务的 U，因为任一无标号划分恰有一组包含该任务；把这一组作为当前组不会漏解。组数不足、或剩余任务不够填满其余卡的状态直接跳过。 第四步：固定 T=Gk[full]，重新优化成本。 令 h(s)=s· rT-s。第二遍使用同样的子集枚举，但只允许 S[U]≤ T，并把取最大值换成求和： 最终成本为 b·Fk[full]。每一遍只保留上一层和当前层。任务耗时可以为零，非空任务组不等于正负载；所有任务都是零时输出 0;0.0000 。

正确性证明

两次转移都将一个划分唯一拆成“包含最低位任务的一组”和其余组，因此完整枚举全部集合划分。第一遍的组合运算是各组负载的最大值，故得到最优 T。第二遍只排除超过 T 的组，保留所有一级目标最优方案；总成本可逐组相加，故再次取最小得到二级目标最优值。 即使允许某些卡空闲，也存在使用 k 个非空任务组的最优方案：固定 T 时，对 a,b≥0，有 h(a)+h(b)≤ h(a+b)，因为 rT-a,rT-b≤ rT-a-b。拆组不增大最大负载，也不增加成本；又因 k≤ n，可不断拆到 k 组。 样例 1 的负载可为 7,7,6，成本为 0.7+0.7+0.54=1.94；样例 2 只有一组，成本为 5·0.1=0.5。最后才格式化小数，不在转移中反复舍入。

题解代码

Python 实现

import sys
input = sys.stdin.readline


def optimize(times, k, base_lr, decay):
    n = len(times)
    size = 1 << n
    subset_sum = [0] * size
    count = [0] * size
    for mask in range(1, size):
        low = mask & -mask
        subset_sum[mask] = subset_sum[mask ^ low] + times[low.bit_length() - 1]
        count[mask] = count[mask ^ low] + 1

    inf = float('inf')
    previous = [inf] * size
    previous[0] = 0
    for groups in range(1, k + 1):
        current = [inf] * size
        for mask in range(1, size):
            if not groups <= count[mask] <= n - k + groups:
                continue
            low = mask & -mask
            rest = mask ^ low
            sub = rest
            while True:
                group = sub | low
                candidate = max(previous[mask ^ group], subset_sum[group])
                if candidate < current[mask]:
                    current[mask] = candidate
                if sub == 0:
                    break
                sub = (sub - 1) & rest
        previous = current
    best_time = previous[-1]

    cost = [inf] * size
    for mask, load in enumerate(subset_sum):
        if load <= best_time:
            cost[mask] = load * decay ** (best_time - load)
    previous = [inf] * size
    previous[0] = 0.0
    for groups in range(1, k + 1):
        current = [inf] * size
        for mask in range(1, size):
            if not groups <= count[mask] <= n - k + groups:
                continue
            low = mask & -mask
            rest = mask ^ low
            sub = rest
            while True:
                group = sub | low
                candidate = previous[mask ^ group] + cost[group]
                if candidate < current[mask]:
                    current[mask] = candidate
                if sub == 0:
                    break
                sub = (sub - 1) & rest
        previous = current
    return best_time, previous[-1] * base_lr


def solve():
    raw_times, raw_k, raw_lr, raw_decay = input().strip().split(';')
    times = list(map(int, raw_times.split(',')))
    best_time, cost = optimize(times, int(raw_k), float(raw_lr), float(raw_decay))
    print(f'{best_time};{cost:.4f}')


solve()

复杂度分析

时间复杂度 ：O(k·3n)，两遍子集 DP；所有掩码的子集数之和为 3n。 空间复杂度 ：O(2n)，子集和、成本表和滚动 DP 数组。
