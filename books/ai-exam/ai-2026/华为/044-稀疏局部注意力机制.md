# 稀疏局部注意力机制

> 来源：https://onefly.top/zero2Leetcode/04_real_interviews/huawei/ai-20260918/ · 华为 · 2026-09-18 · AI岗

## 题目描述

给定三个整数矩阵 $Q$、$K$、$V$，大小均为 $L\times D$，再给定 $G$ 个全局位置，组成集合 $P$。
对于位置 $i$，可参与注意力计算的位置集合 $C_{i}$ 定义为
集合中的同一位置只计算一次。
对 $j\in C_{i}$，注意力分数定义为
只保留分数严格大于 $0$ 的位置，并从中选出最多 $T$ 个分数最大的候选；分数相同时，下标 $j$ 较小的位置优先。设最终选中的位置集合为 $A_{i}$，若有效候选数量不超过 $T$ 则全部保留。
输出矩阵 $O$ 定义为
若 $A_{i}$ 为空，则 $O[i][x]=0$。请输出最终的 $L\times D$ 矩阵 $O$。

## 输入描述

第一行包含五个整数 $L,D,G,W,T$，含义为序列长度、特征维度、全局位置数量、局部窗口单侧大小和每个位置最多保留的候选数量，满足 $1\le L\le10000$、$1\le D\le64$、$0\le G\le\min(L,32)$、$0\le W\le128$、$1\le T\le\min(L,16)$。
若 $G>0$，下一行包含 $G$ 个互不相同的整数 $p_{1},p_{2},\dots,p_{G}$，满足 $0\le p_{i}<L$，表示全局位置；若 $G=0$ 则不输入这一行，直接输入矩阵 $Q$。
接下来 $L$ 行，每行 $D$ 个整数 $Q[i][j]$，表示矩阵 $Q$；随后同样格式的 $L$ 行表示矩阵 $K$，再 $L$ 行表示矩阵 $V$。三个矩阵的元素都在 $[-10,10]$ 内。
所有矩阵和序列下标均从 $0$ 开始，全局位置的输入顺序不影响计算结果。保证所有中间结果和最终结果均在 64 位有符号整数范围内。

## 输出描述

输出 $L$ 行，每行 $D$ 个整数，表示最终矩阵 $O$。同一行中的整数之间用一个空格分隔。

## 思路分析

第一步：圈出每个位置能看的地方。 全局位置看全部 $L$ 个下标；普通位置看窗口 $[\max(0,i-W),\min(L-1,i+W)]$，再补上落在窗口之外的全局位置。全局位置若本来就在窗口里，补的时候跳过，这就保证了「同一位置只计算一次」。
第二步：打分并筛出候选。 对每个候选 $j$ 用 $D$ 维点积算出 $\operatorname{score}(i,j)$，丢掉 $\operatorname{score}(i,j)\le0$ 的，剩下的按「分数降序、同分下标升序」排序后取前 $\min(T,\operatorname{cnt})$ 个，其中 $\operatorname{cnt}$ 是正分候选的个数。$\operatorname{cnt}=0$ 时这一行不累加任何东西，自然输出全 $0$。
第三步：加权求和。 把选中的项按 $O[i][x]=\sum_{j\in A_{i}}\operatorname{score}(i,j)\cdot V[j][x]$ 累加，得到第 $i$ 行的 $D$ 个输出值。
第四步：实现要点。 全量注意力的打分是 $O(L^{2}D)$，而候选集把每个普通位置的候选压到 $2W+1+G$ 个以内，全局位置才需要看整段序列。Python 的纯循环点积在最大数据上要跑上亿次乘法，因此每行只把点积交给 NumPy：取出候选的 $K$ 行与 $Q[i]$ 相乘，一次得到全部分数；排序用 np.lexsort ，以分数降序为主键、下标升序为次键。单个分数最大为 $64\times100$，再乘 $V$ 并按 $T$ 项累加，仍远小于 $2^{63}$，用 64 位整数不会溢出。

## 正确性说明

候选集的构造与题面定义逐条对应：全局位置取全部下标，普通位置取窗口内下标并补上窗口外的全局位置，且同一位置只出现一次；窗口两端按 $0$ 与 $L-1$ 截断。打分只保留严格正分的候选，再按「分数降序、同分下标升序」取不超过 $T$ 个，与题面的筛选规则一致；候选不足 $T$ 个时切片自动全部保留。最后按定义式把 $\operatorname{score}(i,j)$ 与 $V[j]$ 加权求和，空集时输出全 $0$。三处都与定义一致，因此输出矩阵与题面要求完全相同。

## 题解代码

### Python 实现

```python
import sys

import numpy as np


# 构造位置 i 的候选集：全局位置取全部下标，其余位置取窗口并补上窗口外的全局位置
def build_candidates(i, length, window, is_global, global_list):
    # 全局位置能看整个序列，候选就是 0..L-1
    if is_global[i]:
        return np.arange(length)
    # 窗口在两端被截断到 [0, L-1]
    lo = max(0, i - window)
    hi = min(length - 1, i + window)
    cand = list(range(lo, hi + 1))
    # 已在窗口里的全局位置跳过，保证同一位置只算一次
    for p in global_list:
        if p < lo or p > hi:
            cand.append(p)
    return np.array(cand)


# 对候选打分，取前 T 个正分位置，加权求和得到输出行
def attend_row(cand, query, keys, values, top_t, dim):
    # 一次矩阵乘法算出全部候选的点积：(m, D) @ (D,) -> (m,)
    scores = keys[cand] @ query
    # 只保留严格为正的分数
    keep = scores > 0
    cand = cand[keep]
    scores = scores[keep]
    # lexsort 以最后一个键为主键：先按分数降序，同分再按下标升序
    order = np.lexsort((cand, -scores))[:top_t]
    # 一个有效候选都没有时，这一行输出全 0
    if order.size == 0:
        return np.zeros(dim, dtype=np.int64)
    # 有效候选不足 T 个时，切片自动全部保留
    return scores[order] @ values[cand[order]]


def solve():
    data = sys.stdin.buffer.read().split()
    pos = 0
    length, dim, global_count, window, top_t = (int(v) for v in data[pos:pos + 5])
    pos += 5
    global_list = []
    # G = 0 时没有全局位置这一行，按 G 决定是否读取
    if global_count > 0:
        global_list = [int(v) for v in data[pos:pos + global_count]]
        pos += global_count
    is_global = [False] * length
    for p in global_list:
        is_global[p] = True
    size = length * dim
    # 依次读入 Q、K、V 三个 L x D 矩阵，用 int64 防止累加溢出
    flat = np.fromiter((int(v) for v in data[pos:pos + 3 * size]),
                       dtype=np.int64, count=3 * size)
    q_mat = flat[:size].reshape(length, dim)
    k_mat = flat[size:2 * size].reshape(length, dim)
    v_mat = flat[2 * size:].reshape(length, dim)

    # 每个位置独立计算：建候选、打分排序取前 T 个、加权求和，逐行输出
    lines = []
    for i in range(length):
        cand = build_candidates(i, length, window, is_global, global_list)
        row = attend_row(cand, q_mat[i], k_mat, v_mat, top_t, dim)
        lines.append(" ".join(str(int(x)) for x in row.tolist()))
    sys.stdout.write("\n".join(lines) + "\n")


solve()
```

## 复杂度分析

时间复杂度 ：$O((L\cdot(2W+1+G)+G\cdot L)\cdot D)$。瓶颈是打分：普通位置至多 $2W+1+G$ 个候选，全局位置有 $L$ 个候选，每个候选要做一次 $D$ 维点积；排序的元素个数比打分少一个因子 $D$。
空间复杂度 ：$O(L\cdot D)$，存下三个矩阵；每行的候选与分数另占 $O(L)$，可以随用随弃。

## 易错点

只保留 严格大于 $0$ 的分数，$0$ 分候选必须剔除；剔除后一个都不剩时输出全 $0$ 行。 候选集要去重：全局位置落在局部窗口内时不能重复计入，否则同一位置的分数会被算两次。 排序口径是「分数降序、同分下标升序」，两次比较不能写反。 $G=0$ 时输入里没有全局位置那一行，多读一行会把矩阵整体错位。 输出是每行 $D$ 个整数、行内空格分隔，不要输出成 Python 的列表格式。
