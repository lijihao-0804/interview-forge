# 动态旋转位置编码

> 来源：https://onefly.top/zero2Leetcode/04_real_interviews/huawei/ai-20260624/ · 华为 · 2026-06-24 · AI岗 · ACM 模式（stdin/stdout）

## 题目描述

实现 Dynamic NTK-aware Scaled RoPE：根据当前序列长度 $T$ 动态调整基频，对位置 $m$ 处的向量逐对施加二维旋转。

动态缩放因子：$s = \max(1, T/L)$，其中 $L$ 为原始预训练长度 基频变换：$\text{base}’ = b \cdot s^{D/(D-2)}$ 第 $i$ 对维度的旋转角：$\theta_i = m \cdot \text{base}’^{-2i/D}$ 旋转变换：$x’ {2i} = x {2i} \cos\theta_i - x_{2i+1} \sin\theta_i$，$x’ {2i+1} = x {2i} \sin\theta_i + x_{2i+1} \cos\theta_i$

输出保留 4 位小数。

## 思路分析

第一步：理解 NTK-aware RoPE

标准 RoPE 用固定基频 $b = 10000$ 对不同维度对赋予不同频率的旋转。当推理序列超过预训练长度时，需要动态内插：通过放大基频来拉伸低频分量的波长，使更长上下文中仍能区分相对位置。

第二步：三步公式直接模拟

计算缩放因子 $s$（仅当 $T > L$ 时放大） 计算新基频 $\text{base}’ = b \cdot s^{D/(D-2)}$ 对 $D/2$ 对维度依次计算旋转角 $\theta_i$ 并做二维旋转

第三步：精度注意

全程使用 float64，输出统一 4 位小数，注意 -0.0000 要输出为 0.0000 。

## 题解代码

### Python 实现

```python
# 题目：动态旋转位置编码
# 算法：按题意模拟
# 模式：ACM（stdin/stdout）
# 复杂度：时间 O(D)，遍历 D/2 对维度；空间 O(D)

import math

first = input().split()
T = int(first[0]); L = int(first[1]); D = int(first[2])
b = float(first[3]); m = int(first[4])
x = list(map(float, input().split()))

s = max(1.0, T / L)
base = b * s ** (D / (D - 2))

out = [0.0] * D
for i in range(D // 2):
    theta = m * base ** (-2.0 * i / D)
    c = math.cos(theta)
    sn = math.sin(theta)
    p = 2 * i
    out[p] = x[p] * c - x[p + 1] * sn
    out[p + 1] = x[p] * sn + x[p + 1] * c

def fmt(v):
    t = f"{v:.4f}"
    return "0.0000" if t == "-0.0000" else t

print(" ".join(fmt(v) for v in out))
```

## 复杂度分析

时间复杂度 ：$O(D)$，遍历 $D/2$ 对维度。 空间复杂度 ：$O(D)$。

### Java 实现

```java
// 题目：动态旋转位置编码
// 算法：按题意模拟
// 模式：ACM（stdin/stdout）
// 复杂度：时间 O(D)，遍历 D/2 对维度；空间 O(D)

import java.util.*;
public class Main {
    static String fmt(double v) { String t = String.format(Locale.US, "%.4f", v); return t.equals("-0.0000") ? "0.0000" : t; }
    // 主函数：读取输入并输出答案
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int T = sc.nextInt(), L = sc.nextInt(), D = sc.nextInt();
        double b = sc.nextDouble();
        int m = sc.nextInt();
        double[] x = new double[D];
        for (int i = 0; i < D; i++) x[i] = sc.nextDouble();
        double s = Math.max(1.0, (double) T / L);
        double base = b * Math.pow(s, (double) D / (D - 2));
        double[] out = new double[D];
        for (int i = 0; i < D / 2; i++) {
            double theta = m * Math.pow(base, -2.0 * i / D);
            double c = Math.cos(theta), sn = Math.sin(theta);
            int p = 2 * i;
            out[p] = x[p] * c - x[p + 1] * sn;
            out[p + 1] = x[p] * sn + x[p + 1] * c;
        }
        StringBuilder sb = new StringBuilder();
        for (int i = 0; i < D; i++) { if (i > 0) sb.append(' '); sb.append(fmt(out[i])); }
        System.out.println(sb);
    }
}
```
