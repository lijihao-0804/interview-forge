题目描述

在大模型流水线并行训练中，需要把模型按层切分到多个加速卡上。给定模型总层数 L、单卡最大承载层数 M、micro batch 数目 m、硬件总卡数 C，求最优流水线 stage 数 PP 和对应的气泡率。 PP 需满足三条约束：PP≤C；L / PP 为整数；L/PP≤M。 气泡率公式为 (PP - 1) / (m + PP - 1)。优先最小化气泡率，相同时取 PP 更小的。 输出最优 PP 和气泡率（四舍五入保留 4 位小数）。若无可行方案或输入不合法，输出 -1 -1 。

样例

输入 输出 输入 输出 输入 输出

9 2 3 4
-1 -1
10 5 2
-1 -1
8 4 3 4
2 0.2500

思路分析

第一步：输入校验 参数个数必须恰为 4 个，且每个都是正整数（纯数字串，无负号/小数点/字母），数值大于 0。任一条不满足直接输出 -1 -1 。 第二步：利用单调性 气泡率 (PP-1)/(m+PP-1) 对 PP 单调递增——PP 越大气泡率越高。因此从小到大枚举 PP，第一个满足三条约束的值就同时实现了”气泡率最小”和”PP 最小”两个目标。 第三步：定点输出避免浮点舍入陷阱 用整数算术计算：分子 (PP-1) × 10000，整除分母 (m+PP-1) 得商和余数，余数过半进位。这样完全避免浮点 printf 各语言半值舍入策略不同的问题。

复杂度分析

时间复杂度 ：O(C)，枚举一遍 PP 即可。C≤10000。 空间复杂度 ：O(1)。

Java 实现

import java.util.*;
public class Main {
    public static void main(String[] args) throws Exception {
        java.io.BufferedReader br = new java.io.BufferedReader(new java.io.InputStreamReader(System.in));
        String line = br.readLine();
        List<String> toks = new ArrayList<>();
        if (line != null) {
            int i = 0; int L = line.length();
            while (i < L) {
                while (i < L && Character.isWhitespace(line.charAt(i))) i++;
                int st = i;
                while (i < L && !Character.isWhitespace(line.charAt(i))) i++;
                if (i > st) toks.add(line.substring(st, i));
            }
        }
        if (toks.size() != 4) { System.out.println("-1 -1"); return; }
        for (String t : toks) {
            if (t.isEmpty()) { System.out.println("-1 -1"); return; }
            for (int i = 0; i < t.length(); i++) { char c = t.charAt(i); if (c < '0' || c > '9') { System.out.println("-1 -1"); return; } }
        }
        long layers = Long.parseLong(toks.get(0)), maxLoad = Long.parseLong(toks.get(1)), m = Long.parseLong(toks.get(2)), cards = Long.parseLong(toks.get(3));
        if (Math.min(Math.min(layers, maxLoad), Math.min(m, cards)) < 1) { System.out.println("-1 -1"); return; }
        long bestPp = -1;
        for (long pp = 1; pp <= cards; pp++) { if (layers % pp == 0 && layers / pp <= maxLoad) { bestPp = pp; break; } }
        if (bestPp == -1) { System.out.println("-1 -1"); return; }
        long num = (bestPp - 1) * 10000; long den = m + bestPp - 1;
        long q = num / den; long r = num % den;
        if (2 * r >= den) q += 1;
        String out = bestPp + " " + (q / 10000) + "." + String.format(Locale.US, "%04d", q % 10000);
        System.out.println(out);
    }
}

Python 实现

import sys
import re

def solve(line):
    tokens = line.split()
    if len(tokens) != 4:
        return "-1 -1"
    for t in tokens:
        if not re.fullmatch(r"[0-9]+", t):
            return "-1 -1"
    layers, max_load, m, cards = (int(t) for t in tokens)
    if min(layers, max_load, m, cards) < 1:
        return "-1 -1"

    best_pp = -1
    for pp in range(1, cards + 1):
        if layers % pp == 0 and layers // pp <= max_load:
            best_pp = pp
            break
    if best_pp == -1:
        return "-1 -1"

    # 整数算术四舍五入到4位小数
    num = (best_pp - 1) * 10000
    den = m + best_pp - 1
    q, r = divmod(num, den)
    if 2 * r >= den:
        q += 1
    return f"{best_pp} {q // 10000}.{q % 10000:04d}"

line = sys.stdin.readline()
print(solve(line))
