题目描述

给定长度为 n 的整数数组 a，需要依次执行 m 次操作。每次操作基于上一次操作后的数组： 1 i x ：把 ai 修改为 x； 2 ：查询当前所有无序下标对的绝对差之和

输入描述

第一行输入测试数据组数 T。 每组数据中，第一行输入 n,m；第二行输入 n 个整数 a1,a2,…,an；接下来 m 行每行输入一次操作。 数据范围： 所有测试数据中 n+m 的总和不超过 5×105。

输出描述

对每次类型 2 的查询输出一行，表示当前数组的两两绝对差之和。

思路分析

朴素查询要枚举全部数对，单次需要 O(n2)。但一次单点修改只会改变包含该下标的 n-1 个数对，其余数对的贡献完全不变。因此可以始终维护总答案，只在修改时删除旧值的贡献、加入新值的贡献。 设修改位置从 old 变为 new 。先把 old 从当前多重集合中删除，剩下的元素集合记为 R。答案更新为 其中 要快速求 f(v)，把元素按是否不超过 v 分成两部分。设 c≤、s≤ 分别是不超过 v 的元素个数与元素和，ctot、stot 是集合总个数与总和，则 这只需要“值域前缀个数”和“值域前缀和”。分别使用两棵树状数组维护即可，单点增删和前缀查询都是 O(log K)，其中 K 是离散值数量。 数组值可达 109，不能直接作为树状数组下标。每组数据先读完全部操作，把初始值和所有修改目标一起排序去重，再做离散化。 初始答案也不需要枚举数对。对排序后的数组从左向右扫描，当前第 k 个元素 value 与前面所有元素的绝对差之和为 k * value - prefix_sum ，累加即可。

正确性证明

引理 1 ：修改 ai 时，不包含下标 i 的数对贡献保持不变。 证明 ：这些数对的两个元素都没有被修改，其绝对差自然不变。 引理 2 ：从集合删除旧值后，f(v) 的计算公式等于 v 与剩余所有元素的绝对差之和。 证明 ：对 u≤ v，有 |v-u|=v-u，这部分总和为 v· c≤-s≤；对 u>v，有 |v-u|=u-v，这部分总和为 (stot-s≤)-v·(ctot-c≤)。两部分相加即为全部贡献。 定理 ：每次查询时，算法维护的 S 等于当前数组所有无序下标对的绝对差之和。 证明 ：初始 S 由排序扫描准确计算。每次修改时，由引理 1，只需调整包含被修改下标的数对；算法先减去旧值与其余元素的贡献，再加入新值与其余元素的贡献，两项均由引理 2 准确计算。因此修改后不变量仍成立，查询直接输出 S 即为正确答案。

复杂度分析

设一组数据中参与离散化的不同值数量为 K，其中 K≤ n+m。 时间复杂度：O((n+m)log(n+m))。其中初始排序、离散化和树状数组操作都在该上界内；每次查询为 O(1)。 空间复杂度：O(n+m)，用于保存操作、离散值和两棵树状数组。

易错点

求和对象是 i<j 的无序下标对，不能把每对计算两次。 修改时必须先删除旧值，再计算旧值和新值相对“其余元素”的贡献。 所有修改目标都要提前加入离散值集合。 相同值可能出现多次，所以既要维护元素个数，也要维护元素和。 答案可能超过 32 位整数范围；Python 可直接处理，其他语言应使用 64 位整数。

Java 实现

import java.io.*;
import java.util.*;

public class Main {
    static void bitAdd(long[] countBit, long[] sumBit, int index, long countDelta, long sumDelta) {
        int size = countBit.length - 1;
        while (index <= size) {
            countBit[index] += countDelta;
            sumBit[index] += sumDelta;
            index += index & -index;
        }
    }

    static long[] bitPrefix(long[] countBit, long[] sumBit, int index) {
        long count = 0, total = 0;
        while (index > 0) {
            count += countBit[index];
            total += sumBit[index];
            index -= index & -index;
        }
        return new long[]{count, total};
    }

    static long contribution(long[] countBit, long[] sumBit, int index, long value, long totalCount, long totalSum) {
        long[] lp = bitPrefix(countBit, sumBit, index);
        long leftCount = lp[0], leftSum = lp[1];
        long leftPart = value * leftCount - leftSum;
        long rightPart = (totalSum - leftSum) - value * (totalCount - leftCount);
        return leftPart + rightPart;
    }

    static long initialPairSum(long[] values) {
        long[] sorted = values.clone();
        Arrays.sort(sorted);
        long prefixSum = 0, answer = 0;
        for (int i = 0; i < sorted.length; i++) {
            answer += (long) i * sorted[i] - prefixSum;
            prefixSum += sorted[i];
        }
        return answer;
    }

    static int lowerBound(long[] arr, long key) {
        int lo = 0, hi = arr.length;
        while (lo < hi) {
            int mid = (lo + hi) >>> 1;
            if (arr[mid] < key) lo = mid + 1;
            else hi = mid;
        }
        return lo;
    }

    public static void main(String[] args) throws Exception {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        StringBuilder all = new StringBuilder();
        String l;
        while ((l = br.readLine()) != null) { all.append(l); all.append(' '); }
        StringTokenizer st = new StringTokenizer(all.toString());
        if (!st.hasMoreTokens()) return;
        int testCases = Integer.parseInt(st.nextToken());
        for (int tc = 0; tc < testCases; tc++) {
            int n = Integer.parseInt(st.nextToken());
            int operationCount = Integer.parseInt(st.nextToken());
            long[] values = new long[n];
            for (int i = 0; i < n; i++) values[i] = Long.parseLong(st.nextToken());
            int[] opType = new int[operationCount];
            long[] opIndex = new long[operationCount];
            long[] opNew = new long[operationCount];
            TreeSet<Long> allValues = new TreeSet<>();
            for (long v : values) allValues.add(v);
            for (int o = 0; o < operationCount; o++) {
                opType[o] = Integer.parseInt(st.nextToken());
                if (opType[o] == 1) {
                    opIndex[o] = Long.parseLong(st.nextToken());
                    opNew[o] = Long.parseLong(st.nextToken());
                    allValues.add(opNew[o]);
                }
            }
            long[] coordinates = new long[allValues.size()];
            int ci = 0;
            for (long v : allValues) coordinates[ci++] = v;
            int size = coordinates.length;
            long[] countBit = new long[size + 1];
            long[] sumBit = new long[size + 1];
            long answer = initialPairSum(values);
            long totalCount = n;
            long totalSum = 0;
            for (long v : values) totalSum += v;
            for (long v : values) {
                int position = lowerBound(coordinates, v) + 1;
                bitAdd(countBit, sumBit, position, 1, v);
            }
            for (int o = 0; o < operationCount; o++) {
                if (opType[o] != 1) { System.out.println(answer); continue; }
                int index = (int) opIndex[o];
                long newValue = opNew[o];
                long oldValue = values[index - 1];
                if (oldValue == newValue) continue;
                int oldPosition = lowerBound(coordinates, oldValue) + 1;
                int newPosition = lowerBound(coordinates, newValue) + 1;
                bitAdd(countBit, sumBit, oldPosition, -1, -oldValue);
                totalCount -= 1;
                totalSum -= oldValue;
                answer -= contribution(countBit, sumBit, oldPosition, oldValue, totalCount, totalSum);
                answer += contribution(countBit, sumBit, newPosition, newValue, totalCount, totalSum);
                bitAdd(countBit, sumBit, newPosition, 1, newValue);
                totalCount += 1;
                totalSum += newValue;
                values[index - 1] = newValue;
            }
        }
    }
}

Python 实现

import sys
from bisect import bisect_left


def bit_add(count_bit, sum_bit, index, count_delta, sum_delta):
    size = len(count_bit) - 1
    while index <= size:
        count_bit[index] += count_delta
        sum_bit[index] += sum_delta
        index += index & -index


def bit_prefix(count_bit, sum_bit, index):
    count = 0
    total = 0
    while index > 0:
        count += count_bit[index]
        total += sum_bit[index]
        index -= index & -index
    return count, total


def contribution(count_bit, sum_bit, index, value, total_count, total_sum):
    left_count, left_sum = bit_prefix(count_bit, sum_bit, index)
    left_part = value * left_count - left_sum
    right_part = (total_sum - left_sum) - value * (total_count - left_count)
    return left_part + right_part


def initial_pair_sum(values):
    prefix_sum = 0
    answer = 0
    for index, value in enumerate(sorted(values)):
        answer += index * value - prefix_sum
        prefix_sum += value
    return answer


def solve():
    data = sys.stdin.buffer.read().split()
    cursor = 0
    test_cases = int(data[cursor])
    cursor += 1
    output = []

    for _ in range(test_cases):
        n = int(data[cursor])
        operation_count = int(data[cursor + 1])
        cursor += 2
        values = list(map(int, data[cursor:cursor + n]))
        cursor += n

        operations = []
        all_values = set(values)
        for _ in range(operation_count):
            operation_type = int(data[cursor])
            cursor += 1
            if operation_type == 1:
                index = int(data[cursor])
                new_value = int(data[cursor + 1])
                cursor += 2
                operations.append((index, new_value))
                all_values.add(new_value)
            else:
                operations.append(None)

        coordinates = sorted(all_values)
        size = len(coordinates)
        count_bit = [0] * (size + 1)
        sum_bit = [0] * (size + 1)

        answer = initial_pair_sum(values)
        total_count = n
        total_sum = sum(values)
        for value in values:
            position = bisect_left(coordinates, value) + 1
            bit_add(count_bit, sum_bit, position, 1, value)

        for operation in operations:
            if operation is None:
                output.append(str(answer))
                continue

            index, new_value = operation
            old_value = values[index - 1]
            if old_value == new_value:
                continue

            old_position = bisect_left(coordinates, old_value) + 1
            new_position = bisect_left(coordinates, new_value) + 1

            bit_add(count_bit, sum_bit, old_position, -1, -old_value)
            total_count -= 1
            total_sum -= old_value

            answer -= contribution(
                count_bit, sum_bit, old_position, old_value,
                total_count, total_sum
            )
            answer += contribution(
                count_bit, sum_bit, new_position, new_value,
                total_count, total_sum
            )

            bit_add(count_bit, sum_bit, new_position, 1, new_value)
            total_count += 1
            total_sum += new_value
            values[index - 1] = new_value

    sys.stdout.write("\n".join(output))


if __name__ == "__main__":
    solve()
