礼品盒补足的最少弯腰次数

遮住推导与代码，先自己想，再逐段揭示

原题解析 · 科大讯飞 · 2026-10-11 · 算法岗 · ACM 模式（stdin/stdout）

题目描述

有 n 份礼品盒，第 i 份有 ai 个苹果和 bi 个糖果。一次弯腰可以给任意一个盒子加一个苹果、加一个糖果，或者同时加一个苹果和一个糖果；组合操作的两样物品必须放进同一盒子。只能添加，不能取走。

求使所有盒子的苹果数相等、糖果数也相等的最少弯腰次数。最终苹果数不必等于糖果数。

输入格式 ：首行 1≤T≤100；每组先读 1≤n≤1000，再读两行各 n 个正整数，分别为苹果数和糖果数，1≤ai,bi≤1000。

输出格式 ：每组一行最少弯腰次数。

样例

输入

输出

2
1
999
666
2
1 2
2 1
0
2

思路分析

第一步：确定最终目标。 因为不能取走物品，最终苹果数至少为 A=maxiai，糖果数至少为 B=maxibi。把目标继续抬高只会扩大每个盒子的缺口，不可能减少次数，所以直接取这两个下限。

第二步：求单盒最优费用。 某盒缺 u=A-ai 个苹果、v=B-bi 个糖果。一次最多补一种物品各一个，至少要 max(u,v) 次。先组合补 min(u,v) 次，再单独补 |u-v| 次，恰好达到该下界。

第三步：逐盒相加。 不同盒子不能共用一次操作，故

ans=∑i=1nmax(A-ai,B-bi).

样例第一组仅有一个盒子，无须添加；第二组两个盒子分别只缺一个苹果和一个糖果，必须各弯腰一次，不能把不同盒子的缺口合成一次。

复杂度分析

时间复杂度 ：每组 O(n)。

空间复杂度 ：O(n)，保存两种物品数量；若计入多组输出缓存，则额外为 O(T)。

Java 实现

// 题目：礼品盒补足的最少弯腰次数
// 算法：按题意模拟
// 模式：ACM（stdin/stdout）
// 复杂度：时间 每组 O(n)；空间 O(n)，保存两种物品数量；若计入多组输出缓存，则额外为 O(T)

import java.io.*;
import java.util.*;

public class Main {
    static BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
    static StringTokenizer st;
    static String next() throws IOException {
        while (st == null || !st.hasMoreTokens()) {
            String line = br.readLine();
            if (line == null) return null;
            st = new StringTokenizer(line);
        }
        return st.nextToken();
    }
    static int nextInt() throws IOException { return Integer.parseInt(next()); }
    static long nextLong() throws IOException { return Long.parseLong(next()); }

    // 主函数：读取输入并输出答案
    public static void main(String[] args) throws IOException {
        int tests = nextInt();
        // 循环处理
        for (int tc = 0; tc < tests; tc++) {
            int n = nextInt();
            long[] a = new long[n];
            long[] b = new long[n];
            long maxA = Long.MIN_VALUE, maxB = Long.MIN_VALUE;
            // 枚举位置 i
            for (int i = 0; i < n; i++) { a[i] = nextLong(); if (a[i] > maxA) maxA = a[i]; }
            // 枚举位置 i
            for (int i = 0; i < n; i++) { b[i] = nextLong(); if (b[i] > maxB) maxB = b[i]; }
            long sum = 0;
            // 枚举位置 i
            for (int i = 0; i < n; i++) sum += Math.max(maxA - a[i], maxB - b[i]);
            System.out.println(sum);
        }
    }
}

Python 实现

# 题目：礼品盒补足的最少弯腰次数
# 算法：按题意模拟
# 模式：ACM（stdin/stdout）
# 复杂度：时间 每组 O(n)；空间 O(n)，保存两种物品数量；若计入多组输出缓存，则额外为 O(T)

import sys
input = sys.stdin.readline


# 核心函数：min_bends
def min_bends(a, b):
    target_a, target_b = max(a), max(b)
    # 返回结果
    return sum(max(target_a - x, target_b - y) for x, y in zip(a, b))


# 读取输入并输出答案
def solve():
    tests = int(input())
    answers = []
    # 遍历 _
    for _ in range(tests):
        n = int(input())
        a = list(map(int, input().split()))
        b = list(map(int, input().split()))
        answers.append(str(min_bends(a, b)))
    print("\n".join(answers))
