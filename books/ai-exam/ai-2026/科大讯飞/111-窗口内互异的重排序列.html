题目描述

给定长度为 n 的整数序列 a 和正整数 k，将它重新排列为 b，使 b 中任意长度不超过 k 的连续非空子数组的元素互不相同。可以输出任意合法重排；不存在时输出 -1。子数组指连续的一段。 输入格式 ：仅一组数据。首行 n,k，1≤n≤2×105，1≤ k≤ n；第二行 n 个整数，1≤ai≤109。 输出格式 ：一行合法重排，或者一行 -1。本题答案不唯一，输出与正式样例不同并不代表错误，应检查元素多重集合与间距。

样例

输入 输出 输入 输出

5 2
1 1 2 3 4
1 2 1 3 4
5 4
1 1 2 2 4
-1

思路分析

第一步：换成相同元素的间隔。 长度不超过 k 的窗口内不出现重复，等价于任意相同值相邻两次出现的下标差至少为 k。差恰为 k 是合法的，因为同时包含它们需要长度 k+1。 第二步：找出放不下的情况。 设最高频次为 f，达到该频次的值有 c 个。每个这样的值最后一次出现的下标至少为 (f-1)k；这些末次出现又占据不同位置。因此必要条件为 下面的分行构造也证明它充分。建 f 行，先在每行依次放入 c 个最高频值。其余值按频次降序排列，把每个值的所有副本连续列出，再轮流放到前 f-1 行，最后一行不放这些值，按行拼接得到答案。 第三步：证明构造的间距。 设剩余元素数为 m=n-cf。前 f-1 行长度至少为 最后一个不等式正是判定条件的等价变形。最高频值在每行同一列出现，两次距离就是上一行长度，满足要求。 其余值频次至多 f-1。频次恰为 f-1 的值排在前面，每个恰占满前 f-1 行的一整列。更低频值若不跨轮回边界，也是在相邻行同列出现；若跨过最后一行回到第零行，因其频次至多 f-2，同值的两段在最终行序中至少隔着一整行。该完整行长度至少为 k，因此跨边界后的最近两次出现也安全。按频次降序填充用于保证只有更低频值可能跨列回绕。 f=1 时全部值互异，直接返回排序后的所有值，不执行对 f-1 取模。 第四步：样例和输出判定。 第一组按分行法得到 1 2 3 4 1 ，与正式样例 1 2 1 3 4 都合法。为了兼容逐字样例运行器，代码先尝试“剩余次数最多优先”的堆调度，同次数优先选数值小者。一个值在位置 i 使用后，若还有剩余，就进入冷却队列，直到位置 i+k 才允许再次选择；释放位置严格递增，因此每步至多释放一个值。这样输出完整时，多重集合与同值间距天然合法；若中途无可选值，则回退到上述有充分性保证的分行构造，不因试排失败误判无解。第一组依次生成 1 2 1 3 4 ；第二组 f=2,c=2,k=4，下界为 6，大于 5，无解。

题解代码

Python 实现

import sys
import heapq
from collections import Counter, deque
input = sys.stdin.readline


def rearrange(a, k):
    n = len(a)
    groups = sorted(Counter(a).items(), key=lambda item: (-item[1], item[0]))
    frequency = groups[0][1]
    tied = sum(count == frequency for _, count in groups)
    if (frequency - 1) * k + tied > n:
        return None
    if frequency == 1:
        return sorted(a)
    available = [(-count, value) for value, count in groups]
    heapq.heapify(available)
    cooling = deque()
    candidate = []
    for i in range(n):
        if cooling and cooling[0][0] <= i:
            _, count, value = cooling.popleft()
            heapq.heappush(available, (count, value))
        if not available:
            break
        count, value = heapq.heappop(available)
        candidate.append(value)
        if count + 1 < 0:
            cooling.append((i + k, count + 1, value))
    if len(candidate) == n:
        return candidate
    rows = [[] for _ in range(frequency)]
    for value, _ in groups[:tied]:
        for row in rows:
            row.append(value)
    row_index = 0
    for value, count in groups[tied:]:
        for _ in range(count):
            rows[row_index].append(value)
            row_index = (row_index + 1) % (frequency - 1)
    return [value for row in rows for value in row]


def solve():
    n, k = map(int, input().split())
    a = list(map(int, input().split()))
    result = rearrange(a, k)
    if result is None:
        print(-1)
    else:
        print(*result)


solve()

复杂度分析

时间复杂度 ：O(nlog n)，排序与堆调度均在此上界内，分行填充为线性。 空间复杂度 ：O(n)。
