# 区间内可表示整数的个数

> 来源：https://onefly.top/zero2Leetcode/04_real_interviews/iflytek/algo-20261011/ · 科大讯飞 · 2026-10-11 · 算法岗 · ACM 模式（stdin/stdout）

## 题目描述

给定整数 $x,y,l,r$。若存在任意整数 $a,b$，使 $n=a\cdot x+b\cdot y$，则称整数 $n$ 能用 $x,y$ 表示。系数可以是负数或零，$x,y$ 为正整数。求闭区间 $[l,r]$ 内可表示整数的个数。

输入格式 ：首行 $1\le T\le10^5$；每组一行 $x,y,l,r$，满足 $1\le x,y\le10^9$，$-10^{18}\le l\le r\le10^{18}$。

输出格式 ：每组一行一个可表示整数数量。

## 思路分析

第一步：刻画所有可表示的数。 记 $g=\gcd(x,y)$。任何 $a x+b y$ 都是 $g$ 的倍数，这是必要性。裴蜀定理保证存在整数系数表示 $g$，将这组系数同乘任意整数，就能表示 $g$ 的任何整数倍，这是充分性。允许负系数是结论成立的关键，不能按非负背包处理。

## 题解代码

### Python 实现

```python
import sys
from math import gcd
input = sys.stdin.readline


def count_representable(x, y, lo, hi):
    g = gcd(x, y)
    return hi // g - (lo - 1) // g


def solve():
    tests = int(input())
    answers = []
    for _ in range(tests):
        x, y, lo, hi = map(int, input().split())
        answers.append(str(count_representable(x, y, lo, hi)))
    print("\n".join(answers))


solve()
```

## 复杂度分析

时间复杂度 ：每组 $O(\log\min(x,y))$，由欧几里得算法决定。

空间复杂度 ：单组计算 $O(1)$，本实现输出缓存 $O(T)$。

### Java 实现

```java
import java.io.*;
import java.util.*;

public class Main {
    static long gcd(long a, long b) {
        while (b != 0) { long t = a % b; a = b; b = t; }
        return a;
    }

    public static void main(String[] args) throws Exception {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        String line = br.readLine();
        while (line != null && line.trim().isEmpty()) line = br.readLine();
        int tests = Integer.parseInt(line.trim());
        for (int i = 0; i < tests; i++) {
            String s = br.readLine();
            while (s != null && s.trim().isEmpty()) s = br.readLine();
            StringTokenizer st = new StringTokenizer(s);
            long x = Long.parseLong(st.nextToken());
            long y = Long.parseLong(st.nextToken());
            long lo = Long.parseLong(st.nextToken());
            long hi = Long.parseLong(st.nextToken());
            long g = gcd(x, y);
            System.out.println(hi / g - (lo - 1) / g);
        }
    }
}
```
