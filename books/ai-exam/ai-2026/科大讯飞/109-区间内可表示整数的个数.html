题目描述

给定整数 x,y,l,r。若存在任意整数 a,b，使 n=a· x+b· y，则称整数 n 能用 x,y 表示。系数可以是负数或零，x,y 为正整数。求闭区间 [l,r] 内可表示整数的个数。 输入格式 ：首行 1≤T≤105；每组一行 x,y,l,r，满足 1≤x,y≤109，-1018≤l≤r≤1018。 输出格式 ：每组一行一个可表示整数数量。

样例

输入 输出

3
2 3 1 10
4 6 1 15
2 4 -5 5
10
7
5

思路分析

第一步：刻画所有可表示的数。 记 g=gcd(x,y)。任何 a x+b y 都是 g 的倍数，这是必要性。裴蜀定理保证存在整数系数表示 g，将这组系数同乘任意整数，就能表示 g 的任何整数倍，这是充分性。允许负系数是结论成立的关键，不能按非负背包处理。 第二步：把倍数计数变为两次整除。 令 n=tg，则需要 整数数量为 该式对负端点也成立，理解为整数下标区间的长度即可，不应把负半轴上“不超过某数的倍数总数”当成有限计数。 第三步：注意负数整除。 Python 的 // 向下取整，正好适用。比如第三组 g=2，区间包含 -4,-2,0,2,4 共五个倍数，零也要计入。若 x=y=1 且区间覆盖全部边界，答案可达到 2×1018+1，Python 整数能正确保存。

题解代码

Python 实现

import sys
from math import gcd
input = sys.stdin.readline


def count_representable(x, y, lo, hi):
    g = gcd(x, y)
    return hi // g - (lo - 1) // g


def solve():
    tests = int(input())
    answers = []
    for _ in range(tests):
        x, y, lo, hi = map(int, input().split())
        answers.append(str(count_representable(x, y, lo, hi)))
    print("\n".join(answers))


solve()

复杂度分析

时间复杂度 ：每组 O(logmin(x,y))，由欧几里得算法决定。 空间复杂度 ：单组计算 O(1)，本实现输出缓存 O(T)。
