最小爆发值

遮住推导与代码，先自己想，再逐段揭示

原题解析 · 百度 · 2026-08-06 · 算法岗 · ACM 模式（stdin/stdout）

题目描述

给定正整数 n。选择整数 x，满足 0≤ x≤ n，并把 n 分成 x 与 n-x 两部分。

定义这次分割的爆发值为

V(x)=x⊕(n-x),

其中 ⊕ 表示按位异或。求最小可能的爆发值，即

min0≤x≤n(x⊕(n-x)).

输入描述

第一行输入整数 T，表示测试数据组数，满足 1≤ T≤ 105。

接下来 T 行，每行输入一个整数 n，满足 1≤ n≤ 1018。

输出描述

对每组测试数据输出一行一个整数，表示最小爆发值。

思路分析

记

y=n-x,s=x⊕y,c=x&y.

二进制加法恒等式给出

n=x+y=(x⊕y)+2(x&y)=s+2c,

并且 s&c=0：同一位不可能既表示 x,y 不同，又表示二者都为 1。

设 n 的二进制末尾恰有 t 个连续的 1。也就是说，n 的第 0 至第 t-1 位为 1，第 t 位为 0；当 n 为偶数时 t=0。

下面考察等式 n=s+2c 的低位：

第 0 位中，2c 恒为 0，所以当 t≥1 时，s 的第 0 位必须为 1；再由 s&c=0，c 的第 0 位必须为 0。 假设 s 的前 i 位都是 1、c 的前 i 位都是 0。这些低位相加不会产生进位；在第 i 位，2c 取的是 c 的第 i-1 位，仍为 0。由于 n 的第 i 位为 1，s 的第 i 位只能为 1，进而 c 的第 i 位只能为 0。

归纳可知，s 的低 t 位必须全为 1，因此

s≥2t-1.

这个下界可以达到。取

s=2t-1,c=n-s2.

由于 n 的二进制末尾恰为 t 个 1，n-s 是 2t+1 的倍数，所以 c 的低 t 位全为 0，从而 s&c=0。令 x=s+c,y=c，便有 x⊕y=s 且 x+y=n。

因此答案就是 n 二进制末尾连续 1 组成的数 2t-1。而 n+1 的末尾恰有 t 个 0，故

2t=lowbit(n+1)=(n+1)&(-(n+1)),

最终得到闭式

boxedlowbit(n+1)-1.

正确性证明

引理 1 ：任意合法分割的爆发值 s 的低 t 位均为 1，其中 t 是 n 末尾连续 1 的数量。

证明 ：由 n=s+2c 与 s&c=0，从最低位开始归纳。每一位上，之前没有产生进位，且 2c 的当前位由已证明为 0 的 c 的前一位提供；为得到 n 当前位的 1，s 当前位必须为 1，继而 c 当前位必须为 0。归纳覆盖低 t 位。引理得证。

引理 2 ：存在爆发值为 2t-1 的合法分割。

证明 ：令 s=2t-1,c=(n-s)/2。由尾随位结构可知 c 的低 t 位全为 0，所以 s&c=0。取 x=s+c,y=c，在二进制中 s 与 c 没有重叠的 1，故 x=s+c=s⊕c，于是 x⊕y=s，同时 x+y=s+2c=n。引理得证。

定理 ：算法输出最小爆发值。

证明 ：引理 1 给出任何答案都不小于 2t-1；引理 2 构造出恰好达到该下界的分割。算法用 lowbit(n + 1) - 1 计算该值，所以输出最优。定理得证。

复杂度分析

时间复杂度 ：每组 O(1)，全部测试为 O(T)。

空间复杂度 ：除输入输出缓冲外为 O(1)；代码中的答案缓冲为 O(T)。

易错点

x 可以取 0 或 n，不要错误地限制为两部分都为正数。 偶数 n 的答案是 0，对应 x=n/2；公式也会自然得到 0。 不要枚举 x，因为 n 可达 1018。 应对 n + 1 求 lowbit，而不是对 n 求 lowbit。

import java.io.*;
import java.util.*;
public class Main{
 static class FS{byte[] b=new byte[1<<16];int p=0,n=0;InputStream in=System.in;int r()throws IOException{if(p>=n){n=in.read(b);p=0;if(n<=0)return -1;}return b[p++];}long nl()throws IOException{int c;do{c=r();}while(c!=-1&&c<=' ');boolean g=false;if(c=='-'){g=true;c=r();}long v=0;while(c>' '){v=v*10+(c-'0');c=r();}return g?-v:v;}int ni()throws IOException{return (int)nl();}String ns()throws IOException{int c;do{c=r();}while(c!=-1&&c<=' ');StringBuilder s=new StringBuilder();while(c>' '){s.append((char)c);c=r();}return s.toString();}}
 static long minimumBurst(long n){long value=n+1;return (value&-value)-1;}
 // 主函数：读取输入并输出答案
    public static void main(String[] args)throws IOException{
  FS fs=new FS();
  int t=fs.ni();StringBuilder out=new StringBuilder();char NL=(char)10;
  for(int tc=0;tc<t;tc++){long n=fs.nl();out.append(minimumBurst(n));if(tc<t-1)out.append(NL);}
  System.out.print(out);
 }
}
