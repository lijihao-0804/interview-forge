区间异或和最小右端点

遮住推导与代码，先自己想，再逐段揭示

原题解析 · 百度 · 2026-09-17 · 算法岗 · ACM 模式（stdin/stdout）

题目描述

给定两个非负整数 x 与 z，求满足

x⊕(x+1)⊕(x+2)⊕⋯⊕y=z

且 y≥ x 的最小整数 y，其中 ⊕ 表示按位异或操作。若不存在这样的 y，输出 -1。

输入描述

输入两个整数 x,z，满足 0≤ x<220，0≤ z<220。

输出描述

如果不存在对应的 y，直接输出 -1；否则输出一个非负整数，表示最小的能使等式成立的 y。

思路分析

第一步：把区间异或拆成两个前缀异或。 记

F(n)=0⊕1⊕⋯⊕n,F(-1)=0

由 a⊕a=0，F(y)⊕F(x-1) 中下标小于 x 的那些数两两抵消，剩下的恰好是区间 [x,y] 的异或和。于是原等式等价于

F(y)=t,t=z⊕F(x-1)

而 x=0 时 F(-1) 取 0。

第二步：看懂前缀异或的周期。 连续四个数 4k,4k+1,4k+2,4k+3 的高位完全相同，低两位取遍 00,01,10,11，异或结果为 0，所以前缀每满 4 个数就清零一次，F(n) 只由 nmod4 决定：

F(n)=(n,nmod4=0,1,nmod4=1,n+1,nmod4=2,0,nmod4=3.)

第三步：把候选压到 6 个。 当 F(y) 取常数值 1 或 0 时，满足 F(y)=t 的 y 每 4 个数出现一次，而 x,x+1,x+2,x+3 恰好覆盖一个完整的模 4 周期，所以最小的那个若存在必定落在这四个数里。当 F(y) 取 y 或 y+1 时，方程只有一个解，y 只能是 t 或 t-1。

第四步：实现。 先按上面的式子算出 t，再逐个检查 x,x+1,x+2,x+3,t-1,t 这 6 个候选，保留同时满足 y≥ x 与 F(y)=t 的，取最小值；一个都不满足就说明无解。

正确性说明

前缀分解对任意 y≥ x 都成立，所以「F(y)=t」与原等式完全等价。又因为 F 按模 4 只取上述四种形态：当 F(y) 取常数 1 或 0 时，可行下标每 4 个出现一次，其中最小的一个必定落在 [x,x+3] 这段完整周期内；当 F(y) 取 y 或 y+1 时，方程的解只能是 y=t 或 y=t-1。因此 6 个候选覆盖了解的全部可能，代码筛掉不满足 y≥ x 与 F(y)=t 的候选取最小值，得到的就是最小的可行 y；候选全被筛掉时确实不存在可行解。

题解代码

复杂度分析

时间复杂度 ：O(1)。只检查 6 个候选，每个候选按 nmod4 用常数时间算出前缀异或；朴素的逐个异或是 O(y-x)，而且在无解时根本没有终止条件。

空间复杂度 ：O(1)。只用到几个整型变量，与输入规模无关。

易错点

x=0 时要用 F(-1)=0，不能把 F(x-1) 当成未定义。 候选必须先过滤 y≥ x，其中 t-1 还可能是负数。 无解的情形确实存在：tmod4=2 时四个分支都取不到 t；tmod4=1 且 t≠1 时同理；tmod4=0 但 t<x 时，唯一候选 t 会被 y≥ x 挡掉。 按位异或与十进制加法不同，不要写出越界的中间值去试算。

Java 实现

// 题目：区间异或和最小右端点
// 算法：按题意模拟
// 模式：ACM（stdin/stdout）
// 复杂度：时间 O(1)；空间 O(1)

import java.io.*;
import java.util.*;

public class Main {

    // 核心方法：prefixXor
    static long prefixXor(long n) {
        // 条件判断
        if (n < 0) return 0;
        long r = n % 4;
        // 条件判断
        if (r == 0) return n;
        // 条件判断
        if (r == 1) return 1;
        // 条件判断
        if (r == 2) return n + 1;
        // 返回结果
        return 0;
    }

    // 核心方法：minRight
    static long minRight(long x, long z) {
        long target = z ^ prefixXor(x - 1);
        long best = -1;
        long[] cand = {x, x + 1, x + 2, x + 3, target - 1, target};
        // 循环处理
        for (long y : cand) {
            // 条件判断
            if (y >= x && prefixXor(y) == target) {
                // 条件判断
                if (best == -1 || y < best) best = y;
            }
        }
        // 返回结果
        return best;
    }

    // 主函数：读取输入并输出答案
    public static void main(String[] args) throws IOException {
        Scanner sc = new Scanner(System.in);
        long x = sc.nextLong();
        long z = sc.nextLong();
        System.out.println(minRight(x, z));
    }
}

Python 实现

# 题目：区间异或和最小右端点
# 算法：按题意模拟
# 模式：ACM（stdin/stdout）
# 复杂度：时间 O(1)；空间 O(1)

import sys

input = sys.stdin.readline


# 前缀异或 F(n) = 0 ^ 1 ^ ... ^ n，按 n % 4 分成四种情况
# 核心函数：prefix_xor
def prefix_xor(n):
    # 条件判断
    if n < 0:
        # 空前缀的异或和为 0
        # 返回结果
        return 0
    r = n % 4
    # 条件判断
    if r == 0:
        # 返回结果
        return n
    # 条件判断
    if r == 1:
        # 返回结果
        return 1
    # 条件判断
    if r == 2:
        # 返回结果
        return n + 1
    # 返回结果
    return 0


# 返回最小的 y >= x 使 x ^ (x+1) ^ ... ^ y == z，不存在返回 -1
# 核心函数：min_right
def min_right(x, z):
    # 区间异或 = F(y) ^ F(x-1)，所以只要找 F(y) 等于 target 的下标
    target = z ^ prefix_xor(x - 1)
    # F(y) 取 1 或 0 时，y 每 4 个数出现一次，x..x+3 里必定有最小的那个；
    # F(y) 取 y 或 y+1 时，y 只能是 target 或 target-1
    best = -1
    # 遍历 y
    for y in (x, x + 1, x + 2, x + 3, target - 1, target):
        # 条件判断
        if y >= x and prefix_xor(y) == target:
            # 条件判断
            if best == -1 or y < best:
                best = y
    # 返回结果
    return best


# 核心函数：main
def main():
    x, z = map(int, input().split())
    print(min_right(x, z))
