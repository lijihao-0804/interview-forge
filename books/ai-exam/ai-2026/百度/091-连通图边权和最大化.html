连通图边权和最大化

遮住推导与代码，先自己想，再逐段揭示

原题解析 · 百度 · 2026-08-20 · 算法岗 · ACM 模式（stdin/stdout）

站内勘误：修正原参考实现把 min 边权按较大端累计的问题。保留排序与线性扫描框架，改为完整图总权值减去最小前缀层内部权值；正、零、负权均已用独立分层枚举核验。

题目描述

给定权值数组 a，构造整数数组 b。对任意两个不同节点 i,j：

若 bi≠bj，就在两点之间连一条边，边权为 min(ai,aj)； 若 bi=bj，两点之间不连边。

要求构造出的图连通，并最大化所有边权之和。

思路推导

先看一个不会算错的上限。假设权值是 [1, 2, 3, 4]，把四个点各放一层，所有点对都有边：

  • 权值 1 和后面三个点相连，贡献 1 + 1 + 1 = 3；
  • 权值 2 和后面两个点相连，贡献 2 + 2 = 4；
  • 权值 3 和最后一个点相连，贡献 3。

总和就是 3 + 4 + 3 = 10。这已经包含全部六条可能的边，结果不可能超过 10。原实现按降序累计时把较大端的权值算了进去，得到 20，方向反了。

但也不能直接说“全部连边就好”。如果允许负权，例如 [-3, -1, 2]，全连边会得到 -3 - 3 - 1 = -7；把前两个点放在同一层，删掉它们之间权值为 -3 的边，反而得到更大的 -4。

于是换个角度：先把所有点对连好，再减去同层内部的边。

将权值按升序排列。对于位置 i，它和后面每个点相连时都是较小端，完整图总权值为：

T=∑i=0n-1ai(n-1-i).

接下来要让“被删掉的同层内部权值”尽可能小。可以用交换说明：含负权的节点集中到一组，其它只含非负权的组拆开，不会使最优值变差；共同组需要带入非负节点时，优先选较小的值。因此只需考虑：把升序数组最前面的若干个点放在同一层，其余点各自一层。全为非正数时，最大节点单独一层、其它点共同一层同样属于这个结构。

至少留一个点在共同层外，这样不同层之间的边会让整个图连通；n=1 时单独返回 0。

用两个量就能一路扫描：prefix_sum 是当前共同层已有点的权值和，inside_sum 是它们的内部边权和。放入下一个更大的点时，它与之前每个点的边权都等于之前那个点的权值，所以：

  1. inside_sum += prefix_sum：把新出现的内部边全部记上；
  2. prefix_sum += value：新点也进入共同层；
  3. 记住至今最小的 inside_sum。

最小值初始为 0，表示不删除任何边。最后返回 T - best_inside：删掉负权内部边会提高答案；若权值都非负，最好的选择自然是不删边。

参考实现

复杂度

排序时间为 O(nlog n)，计算完整图权值与扫描前缀层均为 O(n)；输入存储和排序辅助空间为 O(n)，扫描仅需常数个累计变量。

Java 实现

// 题目：连通图边权和最大化
// 算法：排序 + 扫描
// 模式：ACM（stdin/stdout）

import java.io.*;
import java.util.*;

public class Main {
    static BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
    static StringTokenizer st;
    static String next() throws IOException {
        while (st == null || !st.hasMoreTokens()) {
            String line = br.readLine();
            if (line == null) return null;
            st = new StringTokenizer(line);
        }
        return st.nextToken();
    }
    static int nextInt() throws IOException { return Integer.parseInt(next()); }
    static long nextLong() throws IOException { return Long.parseLong(next()); }
 // 核心方法：bestSum
 static long bestSum(int[] a) {
        int n = a.length;
        if (n <= 1) return 0;
        Arrays.sort(a);
        long total = 0;
        for (int i = 0; i < n; i++) total += (long) a[i] * (n - 1 - i);
        long prefixSum = 0, insideSum = 0, bestInside = 0;
        // 至少留一个点在共同层外，保持图连通。
        for (int i = 0; i < n - 1; i++) {
            insideSum += prefixSum;
            prefixSum += a[i];
            bestInside = Math.min(bestInside, insideSum);
        }
        return total - bestInside;
    }
 // 主函数：读取输入并输出答案
    public static void main(String[] args) throws IOException {
  int t=nextInt();StringBuilder out=new StringBuilder();char NL=(char)10;
  // 循环处理
  for(int tc=0;tc<t;tc++){int n=nextInt();int[] a=new int[n];for(int i=0;i<n;i++)a[i]=nextInt();out.append(bestSum(a));if(tc<t-1)out.append(NL);}
  System.out.print(out);
 }
}

Python 实现

# 题目：连通图边权和最大化
# 算法：排序 + 扫描
# 模式：ACM（stdin/stdout）

import sys


# 核心函数：best_sum
def best_sum(a):
    n = len(a)
    if n <= 1:
        return 0

    a.sort()
    total = sum(value * (n - 1 - i) for i, value in enumerate(a))
    prefix_sum = 0
    inside_sum = 0
    best_inside = 0

    # 只把最小的一段放在同一层，至少留一个点在层外。
    for value in a[:-1]:
        inside_sum += prefix_sum
        prefix_sum += value
        best_inside = min(best_inside, inside_sum)

    return total - best_inside


# 读取输入并输出答案
def solve():
    data = list(map(int, sys.stdin.buffer.read().split()))
    it = iter(data)
    t = next(it)
    ans = []
    # 遍历 _
    for _ in range(t):
        n = next(it)
        a = [next(it) for _ in range(n)]
        ans.append(str(best_sum(a)))
    print("\n".join(ans))


if __name__ == "__main__":
    solve()
