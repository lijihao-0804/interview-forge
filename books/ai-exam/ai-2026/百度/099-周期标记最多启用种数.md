## 思路分析

给定 个周期，选一个 ，只能启用周期是 倍数的标记，且起点对 的余数互不相同，求最多启用几种。

改为从周期出发去数。 不是任何 的约数时 ，不影响答案；反过来从每个 出发，给它的每个约数各记一次，就恰好得到全部非零的 。总工作量是 ， 以内的数约数最多 个，最坏约 次加法。

算法实现上分三步：

第一步，用调和级数 筛预处理约数表：对每个 ，把它追加到 的约数表里。

第二步，每组先按值去重得到重数 ，对每个不同的值 ，给它约数表里的每个 执行 。C++、Java、Go 用数组计数，处理完一组只清零本组碰过的下标；若每组都清空整个数组， 时就是 次清零。

第三步，遍历本组出现过的 ，取 的最大值作为该组答案。

### Python 实现

```python
# 题目：周期标记最多启用种数
# 算法：按题意模拟
# 模式：ACM（stdin/stdout）
# 复杂度：时间 O(M log(M+1)+S+∑τ(v))，S 为全部周期输入数；求和按各组不同周期 v 计，τ 为约数个数；空间 O(M log(M+1)+S)，包含约数表及全部输入组

import sys
input = sys.stdin.readline

from collections import Counter
from itertools import chain

# 核心函数：build_divisors
def build_divisors(limit):
    divs = [[] for _ in range(limit + 1)]
    # 遍历 d
    for d in range(1, limit + 1):
        # 枚举阶段 j
        for j in range(d, limit + 1, d):
            divs[j].append(d)
    # 返回结果
    return divs

# 核心函数：max_enabled
def max_enabled(ps, divs):
    freq = Counter(ps)
    cnt = Counter(chain.from_iterable(map(divs.getitem, freq)))
    for v, f in freq.items():
        # 条件判断
        if f > 1:
            # 遍历 d
            for d in divs[v]:
                cnt[d] += f - 1
    # 返回结果
    return max(map(min, cnt.keys(), cnt.values()))

t = int(input())
groups = []
# 遍历 _
for _ in range(t):
    nums = list(map(int, input().split()))
    groups.append(nums[1:])

limit = max(max(g) for g in groups)
divs = build_divisors(limit)
print(' '.join(str(max_enabled(g, divs)) for g in groups))
```

## 正确性说明

固定 H 后只有整除 H 的周期可选，且最多使用 H 个不同余数。取互异起点余数可使各标记集合不相交，因此上界 min(H,cnt) 可以达到。枚举所有实际出现的周期约数覆盖一切可能有正贡献的 H，取最大值正确。

## 易错点与边界

H 可以大于标记种数，例如两个周期均为 5。复杂度需包含全部输入组占用，不能只写约数表的空间。
