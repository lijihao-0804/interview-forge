# 幂等工具执行器

> 来源：外部面经参考/02-AI与Agent手撕代码题.md · AI/Agent 手撕题

### Python 实现

```python
class IdempotentExecutor:
    def __init__(self):
        self.results = {}

    def execute(self, call_id, function, **kwargs):
        if call_id in self.results:
            return self.results[call_id]
        result = function(**kwargs)
        self.results[call_id] = result
        return result
```

**追问**：进程在外部操作成功后、写入 `results` 前崩溃怎么办？为什么真正系统需要业务端支持幂等？

### Java 实现

```java
import java.util.HashMap;
import java.util.LinkedHashMap;
import java.util.Map;

final class IdempotentExecutor {
    interface Function {
        Object apply(Map<String, Object> arguments) throws Exception;
    }

    private final Map<String, Object> results = new HashMap<>();

    Object execute(String callId, Function function, Map<String, Object> arguments) throws Exception {
        if (results.containsKey(callId)) {
            return results.get(callId);
        }
        Object result = function.apply(arguments);
        results.put(callId, result);
        return result;
    }

    Object execute(String callId, Function function) throws Exception {
        return execute(callId, function, new LinkedHashMap<>());
    }

    public static void main(String[] args) throws Exception {
        IdempotentExecutor executor = new IdempotentExecutor();
        Function function = arguments -> "result";
        System.out.println(executor.execute("call-1", function));
        System.out.println(executor.execute("call-1", function));
    }
}
```
