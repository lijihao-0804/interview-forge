# 第1题

> 来源：语雀「阿里真题题解」（已做 OCR 校对）

## 题目描述

给定一个正整数 x。请在所有严格小于 x 的非负整数中，找到数位之和最大的那个数，并将这个数输出。

直观解释：把一个数写成十进制后，把每一位相加得到数位之和。我们要在 [0, x−1] 里找到数位之和尽可能大的那个数。如果有多个数的数位之和同为最大值，输出其中任意一个即可。

## 输入描述

每个测试文件均包含多组测试数据。第一行输入一个整数 T（1 ≤ T ≤ 2×10^5）表示数据组数；之后共 T 行，每行输入一个正整数 x（十进制，无前导零），其长度不超过 2×10^5。

除此之外，保证单个测试文件内所有 x 的数位长度之和不超过 5×10^5。

## 输出描述

对于每一组测试数据，输出一行，一个整数，表示答案。

## 示例

输入：
```
3
10
1234
```

输出：
```
6
999
```

（原文示例存在缺失/错位：声明了 3 组数据但只列出 2 组，且输入 10 时按题意答案应为 9、OCR 显示为 6，疑为识别误差。）

## 解题思路

本题要在所有小于 x 的数中找数位和最大的数。关键观察：最优解一定形如「把 x 的某一位减 1、该位之前保持不变、该位之后全部置 9」。
枚举这个「被减 1 的位」i：若 s[i] > '0'，则前缀 s[0..i−1] 不变、第 i 位减 1、后面全为 9，数位和 = pre[i] + (s[i]−'0'−1) + 9·(n−1−i)；取数位和最大的方案。
用该方案还原出对应的数字，去掉前导零后输出；若无可行位（如 x 为一位数且为 0），输出 0。
前缀和 pre 用来 O(1) 求出不变前缀的数位和。

## 复杂度分析

- 时间复杂度：O(数字长度)，每组数据线性扫描；所有 x 的数位长度之和不超过 5×10^5。
- 空间复杂度：O(数字长度)，用于存前缀和与结果字符串。

## 解题代码

### Java 实现

```java
import java.io.*;
import java.util.*;

public class Main {
    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        int T = Integer.parseInt(br.readLine().trim());
        StringBuilder out = new StringBuilder();
        for (int tc = 0; tc < T; tc++) {
            String s = br.readLine().trim();
            int n = s.length();
            long[] pre = new long[n + 1];
            for (int i = 0; i < n; i++) pre[i + 1] = pre[i] + (s.charAt(i) - '0');
            long bestSum = -1; int bestI = -1;
            for (int i = 0; i < n; i++) {
                int dig = s.charAt(i) - '0';
                if (dig == 0) continue;
                long sum = pre[i] + (dig - 1) + 9L * (n - 1 - i);
                if (sum > bestSum) { bestSum = sum; bestI = i; }
            }
            StringBuilder r = new StringBuilder();
            if (bestI < 0) {
                r.append('0');
            } else {
                r.append(s, 0, bestI);
                r.append((char) ('0' + (s.charAt(bestI) - '0' - 1)));
                for (int k = 0; k < n - 1 - bestI; k++) r.append('9');
            }
            int p = 0;
            while (p < r.length() - 1 && r.charAt(p) == '0') p++;
            out.append(r.substring(p)).append('\n');
        }
        System.out.print(out);
    }
}
```


### Python 实现

```python
import sys

def main():
    data = sys.stdin.read().splitlines()
    if not data:
        return
    p = 0
    T = int(data[p].strip())
    p += 1
    out = []
    for _ in range(T):
        s = data[p].strip()
        p += 1
        n = len(s)
        pre = [0] * (n + 1)
        for i in range(n):
            pre[i + 1] = pre[i] + (ord(s[i]) - 48)
        best_sum = -1
        best_i = -1
        for i in range(n):
            dig = ord(s[i]) - 48
            if dig == 0:
                continue
            ssum = pre[i] + (dig - 1) + 9 * (n - 1 - i)
            if ssum > best_sum:
                best_sum = ssum
                best_i = i
        if best_i < 0:
            r = '0'
        else:
            r = s[:best_i] + str(ord(s[best_i]) - 48 - 1) + '9' * (n - 1 - best_i)
        q = 0
        while q < len(r) - 1 and r[q] == '0':
            q += 1
        out.append(r[q:])
    for v in out:
        print(v)

main()
```
