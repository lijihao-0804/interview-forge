题目描述

某电商平台希望分析用户的购买行为，找出经常一起购买的商品对（商品对指两个不同商品 ID 的商品在同一用户的购物记录中同时出现）。

给定多个用户的购物记录，请找出满足共现次数要求的商品对的数量。

注意： - 如果单次购物记录中存在重复的商品 ID，需要去重。 - 如果某个用户只购买了 1 个商品（K=1），则不会生成任何商品对。

输入描述

第一行：两个整数 N、Q。N 表示购物记录（用户）数量，Q 表示查询数量（1 ≤ Q ≤ 200）。

接下来 N 行，每行描述一个用户的购物记录：第一个整数 K 表示该用户购买的商品数量（1 ≤ K ≤ 100），接下来 K 个整数表示商品 ID（1 ≤ 商品ID ≤ 1000）。

接下来 Q 行，每行一个整数 T，询问共现次数 ≥ T 的商品对数量。

输出描述

共 Q 行，每行输出一个整数：满足条件的商品对数量。

示例 1

输入：

5 2
3 1 2 3
1 4
2 2 4
1 5
2 1 3
1
2

输出：

4
1

说明：商品对共现统计为 (1,2):1 次、(1,3):2 次（用户 1 和用户 5）、(2,3):1 次、(2,4):1 次。 - 查询 T=1：共现次数 ≥ 1 的有全部 4 对，共 4 个； - 查询 T=2：共现次数 ≥ 2 的只有 (1,3)，共 1 个。

其中用户 2、4 只购买了 1 个商品，不生成商品对。

示例 2

输入：

3 1
5 1 1 2 2 3
3 1 2 4
2 1 3
1

输出：

5

说明：购物记录 1 为 "5 1 1 2 2 3"，存在重复商品 ID，去重后的商品 ID 为 {1,2,3}。 商品对共现统计为 (1,2):2 次、(1,3):2 次、(2,3):1 次、(1,4):1 次、(2,4):1 次，共 5 对，均满足次数 ≥ 1。

解题思路

本题核心是「统计商品对的共现次数」并用二分回答阈值查询。 对每个用户：先用 HashSet 对该条记录去重，排序后枚举所有商品对，用「大 ID×基数 + 小 ID」编码成一个 long 作为 key，在哈希表中累加共现次数。 统计完成后把所有共现次数取出排序，对每个查询 T 用二分（lowerBound）找到第一个 ≥ T 的位置，用总对数减去该位置即为答案。 基数取 2001（大于商品 ID 上限 1000）保证不同商品对映射到不同 key，避免冲突。

复杂度分析

  • 时间复杂度：O(Σk² + P log P + Q log P)，k 为单条记录去重后的商品数，P 为不同商品对数量，Q 为查询数。
  • 空间复杂度：O(P)，哈希表存储所有商品对的共现次数。

解题代码

Java 实现

import java.io.*;
import java.util.*;

public class Solution {
    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        StringTokenizer first = new StringTokenizer(br.readLine());
        int N = Integer.parseInt(first.nextToken());
        int Q = Integer.parseInt(first.nextToken());
        HashMap<Long, Integer> pairCount = new HashMap<>();
        for (int u = 0; u < N; u++) {
            StringTokenizer st = new StringTokenizer(br.readLine());
            int k = Integer.parseInt(st.nextToken());
            HashSet<Integer> set = new HashSet<>();
            for (int i = 0; i < k; i++) set.add(Integer.parseInt(st.nextToken()));
            int[] ids = new int[set.size()];
            int idx = 0;
            for (int v : set) ids[idx++] = v;
            Arrays.sort(ids);
            for (int i = 0; i < ids.length; i++) {
                for (int j = i + 1; j < ids.length; j++) {
                    long key = (long) ids[i] * 2001L + ids[j];
                    pairCount.merge(key, 1, Integer::sum);
                }
            }
        }
        int[] counts = new int[pairCount.size()];
        int idx = 0;
        for (int v : pairCount.values()) counts[idx++] = v;
        Arrays.sort(counts);
        StringBuilder out = new StringBuilder();
        for (int q = 0; q < Q; q++) {
            int T = Integer.parseInt(br.readLine().trim());
            int pos = lowerBound(counts, T);
            out.append(counts.length - pos).append('\n');
        }
        System.out.print(out);
    }

    static int lowerBound(int[] arr, int target) {
        int lo = 0, hi = arr.length;
        while (lo < hi) {
            int mid = (lo + hi) >>> 1;
            if (arr[mid] < target) lo = mid + 1; else hi = mid;
        }
        return lo;
    }
}
