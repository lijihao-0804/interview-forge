# 尾巴大人

> 来源：语雀「携程真题题解」（已做 OCR 校对）

## 题目描述

众所周知，"!" 很像一个尾巴，它表示阶乘，即 N! = 1×2×…×N。给定一个整数 N，游游想知道 N! 的个位数是多少，请输出这个值。

## 输入描述

输入一行一个整数 N（1 ≤ N ≤ 10^9）。（原文范围表述模糊）

## 输出描述

输出一个整数，表示 N! 的个位数字。

## 示例 1

输入：
```
1
```

输出：
```
1
```

## 示例 2

输入：
```
3
```

输出：
```
6
```

说明：3! = 1×2×3 = 6，个位是 6。

## 解题思路

本题考「阶乘个位数」的规律。N! = 1×2×…×N。
当 N ≥ 5 时，因子中同时含有 2 和 5（如 2×5=10），乘积末尾必带 0，个位数恒为 0。
因此只需特判 N = 0..4：0!=1、1!=1、2!=2、3!=6、4!=24，个位分别为 1、1、2、6、4；N ≥ 5 一律输出 0。
用一个长度 5 的数组直接查表即可。

## 复杂度分析

- 时间复杂度：O(1)，常数次判断。
- 空间复杂度：O(1)，仅一个常量数组。

## 解题代码

### Java 实现

```java
// 题目：尾巴大人
// 算法：按题意模拟
// 模式：ACM（stdin/stdout）

import java.io.*;
import java.util.*;

public class Main {
    static BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
    static String nextLine() throws IOException { return br.readLine(); }

    public static void main(String[] args) throws IOException {
        String l = nextLine();
        if (l == null) return;
        long N = Long.parseLong(l.trim());
        int[] d = {1, 1, 2, 6, 4};
        if (N <= 4) System.out.println(d[(int) N]);
        else System.out.println(0);
    }
}
```


### Python 实现

```python
# 题目：尾巴大人
# 算法：按题意模拟
# 模式：ACM（stdin/stdout）

import sys

# 核心函数：main
def main():
    line = sys.stdin.readline()
    # 条件判断
    if not line:
        # 返回结果
        return
    N = int(line.strip())
    d = [1, 1, 2, 6, 4]
    # 条件判断
    if N <= 4:
        print(d[N])
    else:
        print(0)

main()
```
