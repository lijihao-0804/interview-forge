拆盲盒

遮住推导与代码，先自己想，再逐段揭示

来源：语雀「携程真题题解」（已做 OCR 校对，原文损坏严重，题意只能部分还原）

题目描述

给定一个正整数 N 与一个正整数 M。需要把 N 拆分为若干个素数之和（素数：大于 1 且只有 1 与其本身两个正因子的整数），并满足：所选素数中奇素数（除 2 以外的素数）的数量必须为 M。（原文约束表述模糊）

在满足约束的前提下，使所选素数的数量最大化，并输出这个最大的数量；若不存在任何满足要求的拆分方案，输出 -1。

输入描述

每个测试文件包含多组测试数据。第一行输入一个整数 T（1 ≤ T ≤ 10）表示测试数据组数；每组测试数据描述如下：在一行上输入两个整数 N, M。（原文取值范围识别严重缺失，无法还原具体上下界）

输出描述

对于每组测试数据，新起一行输出一个整数：满足要求的最大素数个数；若无解，则输出 -1。

示例

（原文示例数据严重损坏，无法完整还原，仅保留片段：对于第一组样例，6 可以拆分为 3+3。）

解题思路

要把 N 拆成若干素数之和，其中奇素数（除 2 外）恰好 M 个，并使素数个数最多。 要使个数最多，就应尽量用小素数：M 个奇素数每个最小取 3，其余全部用偶素数 2 填充。 M 个奇素数之和的奇偶性恒为 M（奇数个奇数相加为奇），故剩余部分与 N − M 同奇偶，必须为偶数才能全用 2 填满；同时 N 至少为 3M 才放得下这 M 个奇素数。 满足 N ≥ 3M 且 (N − M) 为偶数时，答案 = M + (N − 3M)/2 = (N − M)/2，否则输出 −1。 （题面数据严重缺失，此为实现所依据的推导。）

复杂度分析

  • 时间复杂度：O(1)，每组数据只做常数次判断。
  • 空间复杂度：O(1)。

解题代码

Java 实现

// 题目：拆盲盒
// 算法：按题意模拟
// 模式：ACM（stdin/stdout）

import java.io.*;
import java.util.*;

public class Main {
    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        int T = Integer.parseInt(br.readLine().trim());
        StringBuilder out = new StringBuilder();
        for (int tc = 0; tc < T; tc++) {
            StringTokenizer st = new StringTokenizer(br.readLine());
            long N = Long.parseLong(st.nextToken());
            long M = Long.parseLong(st.nextToken());
            long ans;
            if (N >= 3 * M && ((N - M) & 1L) == 0) ans = (N - M) / 2;
            else ans = -1;
            out.append(ans).append('\n');
        }
        System.out.print(out);
    }
}

Python 实现

# 题目：拆盲盒
# 算法：按题意模拟
# 模式：ACM（stdin/stdout）

import sys

# 核心函数：main
def main():
    data = sys.stdin.buffer.read().split()
    # 条件判断
    if not data:
        # 返回结果
        return
    it = iter(data)
    T = int(next(it))
    out = []
    # 遍历 _
    for _ in range(T):
        N = int(next(it))
        M = int(next(it))
        # 条件判断
        if N >= 3 * M and ((N - M) % 2 == 0):
            ans = (N - M) // 2
        else:
            ans = -1
        out.append(str(ans))
    # 遍历 v
    for v in out:
        print(v)
