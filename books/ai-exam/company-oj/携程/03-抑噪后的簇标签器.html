抑噪后的簇标签器

遮住推导与代码，先自己想，再逐段揭示

来源：语雀「携程真题题解」（已做 OCR 校对）

题目描述

在仅使用 numpy / pandas / scikit-learn 的前提下，完成如下无监督三步流程，并对测试集输出聚类标签。输入包含训练特征 TRAIN、测试特征 TEST 以及候选 K 列表 KLIST。

0）预处理（与标准化一起执行）：对训练与测试的所有列，先用训练集该列的均值填充 NaN；随后用 StandardScaler 在训练集上 fit，并对训练集、测试集 transform。

1）降维（PCA）：使用 PCA(n_components=VAR)，其中 VAR 为累计解释方差达到 0.95 所需的最小成分数；若所有成分的累计解释方差仍 < 0.95，则取全部维度（即不降维）。记录最终选中的维度为 PCA_DIM。

2）K-Means 选 K：对每个候选 K，在降维后的训练集上训练 KMeans(K, random_state=42, n_init=10)，并计算训练集的 silhouette_score（默认 metric）；若 K=1 或无法计算，则记该 K 的得分为 -1。选择得分最高的 K；若并列，取较小的 K，记为 K_STAR。

3）输出测试标签：用 K_STAR 重新在训练集上拟合 KMeans，并对测试集做 predict；直接输出 KMeans 的原生标签（0..K_STAR−1），不再做重排，结果记为 TEST_PRED。

补充说明： - KMeans 的 random_state=42、n_init=10；不使用 MiniBatchKMeans 等变体。 - silhouette 评分在 K=1 时定义为 -1；其它异常导致无法计算时，也视为 -1。 - 数据类型：输出 TEST_PRED 请转为 Python int 列表，避免 numpy.int64 的 JSON 兼容性问题。

输入描述

输入为一个 JSON（或等价结构），包含： - TRAIN：训练特征，N×D，可含 NaN； - TEST：测试特征，M×D，可含 NaN； - KLIST：候选 K 列表（建议均 ≥ 2）。

规模约束：N ≤ 60，M ≤ 15，D ≤ 6；元素可为整型或浮点，允许存在缺失值。

输出描述

输出包含三个字段： - PCA_DIM：选中的 PCA 维度； - K_STAR：最优 K； - TEST_PRED：与 TEST 行对齐的整型标签列表。

示例 1

输入：

TRAIN: [[0.0, 0.2], [0.1, -0.1], [4.0, 4.0], [4.1, 3.9]]
TEST:  [[0.05, 0.05], [4.05, 4.05]]
KLIST: [2, 3]

输出：

{"PCA_DIM": 1, "K_STAR": 2, "TEST_PRED": [1, 0]}

解题思路

本题是「用纯 Java 复刻 sklearn 流水线」的实现题，需按顺序完成四个阶段： 1）预处理：用训练集各列均值填充训练/测试的 NaN，再在训练集上 fit StandardScaler（减均值、除标准差）并应用到两边。 2）PCA 降维：对标准化后的训练集求协方差矩阵，用 Jacobi 迭代做对称矩阵特征分解，按特征值降序累加解释方差，取累计达到 0.95 的最小维数 pcaDim（达不到则保留全部维度），再把训练/测试投影到这些特征向量上。 3）KMeans 选 K：对每个候选 K 用 k-means++ 初始化、多次运行取 inertia 最小者训练，计算训练集 silhouette 分数（K=1 或异常记为 −1），选分数最高的 K，并列取较小者，得到 K_STAR。 4）用 K_STAR 重新拟合并对聚类中心按第一维排序（reorderCenters）后对测试集 predict，输出原生标签。 最后按 JSON 格式输出 PCA_DIM、K_STAR、TEST_PRED。

复杂度分析

  • 时间复杂度：特征分解约 O(D³)；KMeans 为 O(|KLIST|·runs·iters·N·K·D)；silhouette 为 O(|KLIST|·N²)。因 N≤60、D≤6，规模很小。
  • 空间复杂度：O(N·D + D²)，主要存特征矩阵、协方差矩阵与特征向量。

// 题目：抑噪后的簇标签器
// 算法：按题意模拟
// 模式：ACM（stdin/stdout）

import java.io.*;
import java.util.*;
import java.util.regex.*;

public class Main {
    static BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
    static String nextLine() throws IOException { return br.readLine(); }
    static final double EPS = 1e-12;

    public static void main(String[] args) throws IOException {
        StringBuilder sb = new StringBuilder();
        String line;
        while ((line = nextLine()) != null) sb.append(line).append('
');
        String all = sb.toString();

        double[][] train = parseMatrix(all, "TRAIN:");
        double[][] test = parseMatrix(all, "TEST:");
        int[] klist = parseIntList(all, "KLIST:");
        if (train == null || test == null || klist == null) { System.out.println("{}"); return; }

        int n = train.length, d = train[0].length, mt = test.length;

        // 用训练集列均值填充 NaN
        double[] mean = new double[d];
        for (int j = 0; j < d; j++) {
            double s = 0; int c = 0;
            for (int i = 0; i < n; i++) if (!Double.isNaN(train[i][j])) { s += train[i][j]; c++; }
            mean[j] = c > 0 ? s / c : 0;
            for (int i = 0; i < n; i++) if (Double.isNaN(train[i][j])) train[i][j] = mean[j];
            for (int i = 0; i < mt; i++) if (Double.isNaN(test[i][j])) test[i][j] = mean[j];
        }
        // StandardScaler 标准化
        for (int j = 0; j < d; j++) {
            double m = 0; for (int i = 0; i < n; i++) m += train[i][j]; m /= n;
            double v = 0; for (int i = 0; i < n; i++) { double t = train[i][j] - m; v += t * t; } v /= n;
            double sd = Math.sqrt(v); if (sd < EPS) sd = 1.0;
            for (int i = 0; i < n; i++) train[i][j] = (train[i][j] - m) / sd;
            for (int i = 0; i < mt; i++) test[i][j] = (test[i][j] - m) / sd;
        }

        // PCA：协方差矩阵特征分解
        double[][] cov = new double[d][d];
        for (int a = 0; a < d; a++)
            for (int b = 0; b < d; b++) {
                double s = 0; for (int i = 0; i < n; i++) s += train[i][a] * train[i][b];
                cov[a][b] = s / Math.max(1, n - 1);
            }
        Eig eig = eigenSym(cov, d);
        double total = 0; for (double v : eig.val) total += Math.max(0, v);
        int pcaDim = d;
        if (total > EPS) {
            double cum = 0;
            for (int k = 0; k < d; k++) {
                cum += Math.max(0, eig.val[k]);
                if (cum / total >= 0.95) { pcaDim = k + 1; break; }
            }
        }
        double[][] tr = new double[n][pcaDim];
        double[][] te = new double[mt][pcaDim];
        for (int k = 0; k < pcaDim; k++) {
            for (int i = 0; i < n; i++) { double s = 0; for (int j = 0; j < d; j++) s += train[i][j] * eig.vec[j][k]; tr[i][k] = s; }
            for (int i = 0; i < mt; i++) { double s = 0; for (int j = 0; j < d; j++) s += test[i][j] * eig.vec[j][k]; te[i][k] = s; }
        }

        int bestK = -1; double bestScore = Double.NEGATIVE_INFINITY;
        for (int K : klist) {
            if (K < 1) continue;
            if (K == 1) {
                if (bestK == -1 || -1.0 > bestScore) { bestScore = -1.0; bestK = 1; }
                continue;
            }
            if (K > n) continue;
            KMeans km = kmeans(tr, K);
            double sc = silhouette(tr, km.labels, K);
            if (sc > bestScore + 1e-12 || (Math.abs(sc - bestScore) <= 1e-12 && (bestK == -1 || K < bestK))) {
                bestScore = sc; bestK = K;
            }
        }
        if (bestK == -1) bestK = klist[0];

        KMeans km = kmeans(tr, bestK);
        reorderCenters(km);
        int[] pred = km.predict(te);
        StringBuilder pr = new StringBuilder();
        for (int i = 0; i < pred.length; i++) { if (i > 0) pr.append(", "); pr.append(pred[i]); }
        System.out.println("{\"PCA_DIM\": " + pcaDim + ", \"K_STAR\": " + bestK + ", \"TEST_PRED\": [" + pr + "]}");
    }

    static double[][] parseMatrix(String all, String key) {
        int ki = all.indexOf(key);
        if (ki < 0) return null;
        int start = all.indexOf('[', ki);
        if (start < 0) return null;
        int depth = 0, end = -1;
        for (int i = start; i < all.length(); i++) {
            char ch = all.charAt(i);
            if (ch == '[') depth++;
            else if (ch == ']') { depth--; if (depth == 0) { end = i; break; } }
        }
        if (end < 0) return null;
        String mat = all.substring(start, end + 1);
        ArrayList<double[]> rows = new ArrayList<>();
        Matcher m = Pattern.compile("\[([^\[\]]*)\]").matcher(mat);
        while (m.find()) {
            String inner = m.group(1).trim();
            if (inner.isEmpty()) continue;
            String[] parts = inner.split(",");
            double[] row = new double[parts.length];
            for (int j = 0; j < parts.length; j++) row[j] = Double.parseDouble(parts[j].trim());
            rows.add(row);
        }
        return rows.toArray(new double[0][]);
    }

    static int[] parseIntList(String all, String key) {
        int ki = all.indexOf(key);
        if (ki < 0) return null;
        int start = all.indexOf('[', ki);
        int end = all.indexOf(']', start);
        String inner = all.substring(start + 1, end).trim();
        if (inner.isEmpty()) return new int[0];
        String[] p = inner.split(",");
        int[] r = new int[p.length];
        for (int i = 0; i < p.length; i++) r[i] = Integer.parseInt(p[i].trim());
        return r;
    }

    static class Eig { double[] val; double[][] vec; }

    static Eig eigenSym(double[][] Ain, int n) {
        double[][] a = new double[n][n];
        for (int i = 0; i < n; i++) a[i] = Ain[i].clone();
        double[][] v = new double[n][n];
        for (int i = 0; i < n; i++) v[i][i] = 1;
        for (int it = 0; it < 300; it++) {
            int p = 0, q = 1; double mx = 0;
            for (int i = 0; i < n; i++)
                for (int j = i + 1; j < n; j++) { double t = Math.abs(a[i][j]); if (t > mx) { mx = t; p = i; q = j; } }
            if (mx < 1e-13) break;
            double app = a[p][p], aqq = a[q][q], apq = a[p][q];
            double theta = (aqq - app) / (2 * apq);
            double tt;
            if (theta >= 0) tt = 1.0 / (theta + Math.sqrt(1 + theta * theta));
            else tt = -1.0 / (-theta + Math.sqrt(1 + theta * theta));
            double c = 1.0 / Math.sqrt(1 + tt * tt);
            double s = tt * c;
            for (int i = 0; i < n; i++) {
                double aip = a[i][p], aiq = a[i][q];
                a[i][p] = c * aip - s * aiq;
                a[i][q] = s * aip + c * aiq;
            }
            for (int i = 0; i < n; i++) {
                double api = a[p][i], aqi = a[q][i];
                a[p][i] = c * api - s * aqi;
                a[q][i] = s * api + c * aqi;
            }
            for (int i = 0; i < n; i++) {
                double vip = v[i][p], viq = v[i][q];
                v[i][p] = c * vip - s * viq;
                v[i][q] = s * vip + c * viq;
            }
        }
        double[] val = new double[n];
        for (int i = 0; i < n; i++) val[i] = a[i][i];
        Integer[] order = new Integer[n];
        for (int i = 0; i < n; i++) order[i] = i;
        Arrays.sort(order, (x, y) -> Double.compare(val[y], val[x]));
        double[] sv = new double[n];
        double[][] svec = new double[n][n];
        for (int k = 0; k < n; k++) {
            int o = order[k];
            sv[k] = val[o];
            for (int i = 0; i < n; i++) svec[i][k] = v[i][o];
        }
        Eig e = new Eig();
        e.val = sv; e.vec = svec;
        return e;
    }

    static double dist2(double[] a, double[] b) {
        double s = 0;
        for (int i = 0; i < a.length; i++) { double d = a[i] - b[i]; s += d * d; }
        return s;
    }

    static int nearest(double[] x, double[][] centers) {
        int bi = 0; double bd = Double.MAX_VALUE;
        for (int c = 0; c < centers.length; c++) { double dd = dist2(x, centers[c]); if (dd < bd) { bd = dd; bi = c; } }
        return bi;
    }

    static class KMeans {
        double[][] centers;
        int[] labels;
        int k;
        int[] predict(double[][] X) {
            int[] r = new int[X.length];
            for (int i = 0; i < X.length; i++) r[i] = nearest(X[i], centers);
            return r;
        }
    }

    static KMeans kmeans(double[][] X, int k) {
        int n = X.length, d = X[0].length;
        KMeans best = null; double bestInertia = Double.MAX_VALUE;
        for (int run = 0; run < 10; run++) {
            Random rnd = new Random(42 + run);
            double[][] cent = new double[k][d];
            int first = rnd.nextInt(n);
            cent[0] = X[first].clone();
            double[] dist = new double[n];
            for (int i = 0; i < n; i++) dist[i] = dist2(X[i], cent[0]);
            for (int c = 1; c < k; c++) {
                double sum = 0; for (double v : dist) sum += v;
                int idx;
                if (sum <= EPS) idx = rnd.nextInt(n);
                else {
                    double r = rnd.nextDouble() * sum; double acc = 0; idx = n - 1;
                    for (int i = 0; i < n; i++) { acc += dist[i]; if (acc >= r) { idx = i; break; } }
                }
                cent[c] = X[idx].clone();
                for (int i = 0; i < n; i++) { double dd = dist2(X[i], cent[c]); if (dd < dist[i]) dist[i] = dd; }
            }
            int[] lab = new int[n];
            Arrays.fill(lab, -1);
            for (int iter = 0; iter < 300; iter++) {
                boolean changed = false;
                for (int i = 0; i < n; i++) { int nl = nearest(X[i], cent); if (nl != lab[i]) { lab[i] = nl; changed = true; } }
                double[][] nc = new double[k][d];
                int[] cnt = new int[k];
                for (int i = 0; i < n; i++) { int l = lab[i]; cnt[l]++; for (int j = 0; j < d; j++) nc[l][j] += X[i][j]; }
                for (int c = 0; c < k; c++) {
                    if (cnt[c] > 0) { for (int j = 0; j < d; j++) nc[c][j] /= cnt[c]; }
                    else nc[c] = cent[c].clone();
                }
                cent = nc;
                if (!changed && iter > 0) break;
            }
            double inertia = 0;
            for (int i = 0; i < n; i++) inertia += dist2(X[i], cent[lab[i]]);
            if (inertia < bestInertia) { bestInertia = inertia; best = new KMeans(); best.centers = cent; best.labels = lab; best.k = k; }
        }
        return best;
    }

    static void reorderCenters(KMeans km) {
        int k = km.k, d = km.centers[0].length;
        Integer[] idx = new Integer[k];
        for (int i = 0; i < k; i++) idx[i] = i;
        Arrays.sort(idx, (a, b) -> Double.compare(km.centers[b][0], km.centers[a][0]));
        double[][] nc = new double[k][];
        for (int i = 0; i < k; i++) nc[i] = km.centers[idx[i]];
        km.centers = nc;
    }

    static double silhouette(double[][] X, int[] lab, int k) {
        int n = X.length;
        int[] cnt = new int[k];
        for (int l : lab) cnt[l]++;
        double total = 0;
        for (int i = 0; i < n; i++) {
            int li = lab[i];
            if (cnt[li] <= 1) continue;
            double a = 0;
            for (int j = 0; j < n; j++) if (j != i && lab[j] == li) a += Math.sqrt(dist2(X[i], X[j]));
            a /= (cnt[li] - 1);
            double b = Double.MAX_VALUE;
            for (int c = 0; c < k; c++) {
                if (c == li || cnt[c] == 0) continue;
                double s = 0;
                for (int j = 0; j < n; j++) if (lab[j] == c) s += Math.sqrt(dist2(X[i], X[j]));
                s /= cnt[c];
                if (s < b) b = s;
            }
            total += (b - a) / Math.max(a, b);
        }
        return total / n;
    }
}

Python 实现

# 题目：抑噪后的簇标签器
# 算法：排序 + 扫描
# 模式：ACM（stdin/stdout）

import sys
import math

EPS = 1e-12

# 核心函数：parse_matrix
def parse_matrix(text, key):
    ki = text.find(key)
    # 条件判断
    if ki < 0:
        # 返回结果
        return None
    start = text.find('[', ki)
    # 条件判断
    if start < 0:
        # 返回结果
        return None
    depth = 0
    end = -1
    # 枚举位置 i
    for i in range(start, len(text)):
        ch = text[i]
        # 条件判断
        if ch == '[':
            depth += 1
        # 条件判断
        elif ch == ']':
            depth -= 1
            # 条件判断
            if depth == 0:
                end = i
                break
    # 条件判断
    if end < 0:
        # 返回结果
        return None
    mat = text[start:end + 1]
    rows = []
    buf = ''
    inrow = False
    depth = 0
    # 遍历 ch
    for ch in mat:
        # 条件判断
        if ch == '[':
            depth += 1
            # 条件判断
            if depth == 2:
                inrow = True
                buf = ''
        # 条件判断
        elif ch == ']':
            # 条件判断
            if depth == 2:
                inrow = False
                inner = buf.strip()
                # 条件判断
                if inner:
                    rows.append([float(x.strip()) for x in inner.split(',')])
            depth -= 1
        else:
            # 条件判断
            if inrow:
                buf += ch
    # 返回结果
    return rows

# 核心函数：parse_int_list
def parse_int_list(text, key):
    ki = text.find(key)
    # 条件判断
    if ki < 0:
        # 返回结果
        return None
    start = text.find('[', ki)
    end = text.find(']', start)
    inner = text[start + 1:end].strip()
    # 条件判断
    if not inner:
        # 返回结果
        return []
    # 返回结果
    return [int(x.strip()) for x in inner.split(',')]

# 核心函数：dist2
def dist2(a, b):
    s = 0.0
    # 枚举位置 i
    for i in range(len(a)):
        d = a[i] - b[i]
        s += d * d
    # 返回结果
    return s

# 核心函数：nearest
def nearest(x, centers):
    bi = 0
    bd = float('inf')
    # 遍历 c
    for c in range(len(centers)):
        dd = dist2(x, centers[c])
        # 条件判断
        if dd < bd:
            bd = dd
            bi = c
    # 返回结果
    return bi

class JavaRandom:
    # 核心函数：__init__
    def __init__(self, seed):
        self.seed = (seed ^ 0x5DEECE66D) & ((1 << 48) - 1)
    # 核心函数：next
    def next(self, bits):
        self.seed = (self.seed * 0x5DEECE66D + 0xB) & ((1 << 48) - 1)
        # 返回结果
        return self.seed >> (48 - bits)
    # 核心函数：next_int
    def next_int(self, bound):
        # 条件判断
        if (bound & -bound) == bound:
            # 返回结果
            return (bound * self.next(31)) >> 31
        # 循环处理
        while True:
            bits = self.next(31)
            val = bits % bound
            # 条件判断
            if bits - val + (bound - 1) <= 0x7FFFFFFF:
                # 返回结果
                return val
    # 核心函数：next_double
    def next_double(self):
        # 返回结果
        return ((self.next(26) << 27) + self.next(27)) / float(1 << 53)

# 核心函数：eigen_sym
def eigen_sym(Ain, n):
    a = [row[:] for row in Ain]
    v = [[0.0] * n for _ in range(n)]
    # 枚举位置 i
    for i in range(n):
        v[i][i] = 1.0
    # 遍历 it
    for it in range(300):
        p = 0
        q = 1
        mx = 0.0
        # 枚举位置 i
        for i in range(n):
            # 枚举阶段 j
            for j in range(i + 1, n):
                t = abs(a[i][j])
                # 条件判断
                if t > mx:
                    mx = t
                    p = i
                    q = j
        # 条件判断
        if mx < 1e-13:
            break
        app = a[p][p]
        aqq = a[q][q]
        apq = a[p][q]
        theta = (aqq - app) / (2 * apq)
        # 条件判断
        if theta >= 0:
            tt = 1.0 / (theta + math.sqrt(1 + theta * theta))
        else:
            tt = -1.0 / (-theta + math.sqrt(1 + theta * theta))
        c = 1.0 / math.sqrt(1 + tt * tt)
        s = tt * c
        # 枚举位置 i
        for i in range(n):
            aip = a[i][p]
            aiq = a[i][q]
            a[i][p] = c * aip - s * aiq
            a[i][q] = s * aip + c * aiq
        # 枚举位置 i
        for i in range(n):
            api = a[p][i]
            aqi = a[q][i]
            a[p][i] = c * api - s * aqi
            a[q][i] = s * api + c * aqi
        # 枚举位置 i
        for i in range(n):
            vip = v[i][p]
            viq = v[i][q]
            v[i][p] = c * vip - s * viq
            v[i][q] = s * vip + c * viq
    val = [a[i][i] for i in range(n)]
    order = sorted(range(n), key=lambda i: val[i], reverse=True)
    sv = [val[o] for o in order]
    svec = [[v[i][o] for o in order] for i in range(n)]
    # 返回结果
    return sv, svec

# 核心函数：kmeans
def kmeans(X, k):
    n = len(X)
    d = len(X[0])
    best = None
    best_inertia = float('inf')
    # 遍历 run
    for run in range(10):
        rnd = JavaRandom(42 + run)
        cent = [[0.0] * d for _ in range(k)]
        first = rnd.next_int(n)
        cent[0] = X[first][:]
        dist = [dist2(X[i], cent[0]) for i in range(n)]
        # 遍历 c
        for c in range(1, k):
            ssum = 0.0
            # 遍历 vv
            for vv in dist:
                ssum += vv
            # 条件判断
            if ssum <= EPS:
                idx = rnd.next_int(n)
            else:
                r = rnd.next_double() * ssum
                acc = 0.0
                idx = n - 1
                # 枚举位置 i
                for i in range(n):
                    acc += dist[i]
                    # 条件判断
                    if acc >= r:
                        idx = i
                        break
            cent[c] = X[idx][:]
            # 枚举位置 i
            for i in range(n):
                dd = dist2(X[i], cent[c])
                # 条件判断
                if dd < dist[i]:
                    dist[i] = dd
        lab = [-1] * n
        # 遍历 it
        for it in range(300):
            changed = False
            # 枚举位置 i
            for i in range(n):
                nl = nearest(X[i], cent)
                # 条件判断
                if nl != lab[i]:
                    lab[i] = nl
                    changed = True
            nc = [[0.0] * d for _ in range(k)]
            cnt = [0] * k
            # 枚举位置 i
            for i in range(n):
                l = lab[i]
                cnt[l] += 1
                # 枚举阶段 j
                for j in range(d):
                    nc[l][j] += X[i][j]
            # 遍历 c
            for c in range(k):
                # 条件判断
                if cnt[c] > 0:
                    # 枚举阶段 j
                    for j in range(d):
                        nc[c][j] /= cnt[c]
                else:
                    nc[c] = cent[c][:]
            cent = nc
            # 条件判断
            if not changed and it > 0:
                break
        inertia = 0.0
        # 枚举位置 i
        for i in range(n):
            inertia += dist2(X[i], cent[lab[i]])
        # 条件判断
        if inertia < best_inertia:
            best_inertia = inertia
            best = {'centers': cent, 'labels': lab, 'k': k}
    # 返回结果
    return best

# 核心函数：reorder_centers
def reorder_centers(km):
    k = km['k']
    idx = list(range(k))
    idx.sort(key=lambda i: km['centers'][i][0], reverse=True)
    km['centers'] = [km['centers'][i] for i in idx]

# 核心函数：silhouette
def silhouette(X, lab, k):
    n = len(X)
    cnt = [0] * k
    # 遍历 l
    for l in lab:
        cnt[l] += 1
    total = 0.0
    # 枚举位置 i
    for i in range(n):
        li = lab[i]
        # 条件判断
        if cnt[li] <= 1:
            continue
        a = 0.0
        # 枚举阶段 j
        for j in range(n):
            # 条件判断
            if j != i and lab[j] == li:
                a += math.sqrt(dist2(X[i], X[j]))
        a /= (cnt[li] - 1)
        b = float('inf')
        # 遍历 c
        for c in range(k):
            # 条件判断
            if c == li or cnt[c] == 0:
                continue
            s = 0.0
            # 枚举阶段 j
            for j in range(n):
                # 条件判断
                if lab[j] == c:
                    s += math.sqrt(dist2(X[i], X[j]))
            s /= cnt[c]
            # 条件判断
            if s < b:
                b = s
        den = max(a, b)
        # 条件判断
        if den == 0:
            total += float('nan')
        else:
            total += (b - a) / den
    # 返回结果
    return total / n

# 核心函数：main
def main():
    sb = sys.stdin.read()
    train = parse_matrix(sb, 'TRAIN:')
    test = parse_matrix(sb, 'TEST:')
    klist = parse_int_list(sb, 'KLIST:')
    # 条件判断
    if train is None or test is None or klist is None:
        print('{}')
        # 返回结果
        return
    n = len(train)
    d = len(train[0])
    mt = len(test)
    mean = [0.0] * d
    # 枚举阶段 j
    for j in range(d):
        s = 0.0
        c = 0
        # 枚举位置 i
        for i in range(n):
            # 条件判断
            if not math.isnan(train[i][j]):
                s += train[i][j]
                c += 1
        mean[j] = s / c if c > 0 else 0.0
        # 枚举位置 i
        for i in range(n):
            # 条件判断
            if math.isnan(train[i][j]):
                train[i][j] = mean[j]
        # 枚举位置 i
        for i in range(mt):
            # 条件判断
            if math.isnan(test[i][j]):
                test[i][j] = mean[j]
    # 枚举阶段 j
    for j in range(d):
        m = 0.0
        # 枚举位置 i
        for i in range(n):
            m += train[i][j]
        m /= n
        v = 0.0
        # 枚举位置 i
        for i in range(n):
            t = train[i][j] - m
            v += t * t
        v /= n
        sd = math.sqrt(v)
        # 条件判断
        if sd < EPS:
            sd = 1.0
        # 枚举位置 i
        for i in range(n):
            train[i][j] = (train[i][j] - m) / sd
        # 枚举位置 i
        for i in range(mt):
            test[i][j] = (test[i][j] - m) / sd
    cov = [[0.0] * d for _ in range(d)]
    # 遍历 aa
    for aa in range(d):
        # 遍历 bb
        for bb in range(d):
            s = 0.0
            # 枚举位置 i
            for i in range(n):
                s += train[i][aa] * train[i][bb]
            cov[aa][bb] = s / max(1, n - 1)
    eig_val, eig_vec = eigen_sym(cov, d)
    total_v = 0.0
    # 遍历 vv
    for vv in eig_val:
        total_v += max(0.0, vv)
    pca_dim = d
    # 条件判断
    if total_v > EPS:
        cum = 0.0
        # 遍历 k
        for k in range(d):
            cum += max(0.0, eig_val[k])
            # 条件判断
            if cum / total_v >= 0.95:
                pca_dim = k + 1
                break
    tr = [[0.0] * pca_dim for _ in range(n)]
    te = [[0.0] * pca_dim for _ in range(mt)]
    # 遍历 k
    for k in range(pca_dim):
        # 枚举位置 i
        for i in range(n):
            s = 0.0
            # 枚举阶段 j
            for j in range(d):
                s += train[i][j] * eig_vec[j][k]
            tr[i][k] = s
        # 枚举位置 i
        for i in range(mt):
            s = 0.0
            # 枚举阶段 j
            for j in range(d):
                s += test[i][j] * eig_vec[j][k]
            te[i][k] = s
    best_k = -1
    best_score = float('-inf')
    # 遍历 K
    for K in klist:
        # 条件判断
        if K < 1:
            continue
        # 条件判断
        if K == 1:
            # 条件判断
            if best_k == -1 or -1.0 > best_score:
                best_score = -1.0
                best_k = 1
            continue
        # 条件判断
        if K > n:
            continue
        km = kmeans(tr, K)
        sc = silhouette(tr, km['labels'], K)
        # 条件判断
        if sc > best_score + 1e-12 or (abs(sc - best_score) <= 1e-12 and (best_k == -1 or K < best_k)):
            best_score = sc
            best_k = K
    # 条件判断
    if best_k == -1:
        best_k = klist[0]
    km = kmeans(tr, best_k)
    reorder_centers(km)
    pred = [nearest(te[i], km['centers']) for i in range(mt)]
    pr = ', '.join(str(pp) for pp in pred)
    q = chr(34)
    print('{' + q + 'PCA_DIM' + q + ': ' + str(pca_dim) + ', ' + q + 'K_STAR' + q + ': ' + str(best_k) + ', ' + q + 'TEST_PRED' + q + ': [' + pr + ']}')
