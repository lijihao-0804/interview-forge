子集合

遮住推导与代码，先自己想，再逐段揭示

来源：语雀「携程真题题解」（已做 OCR 校对，原文损坏严重，题意据片段还原）

题目描述

给定一个长度为 n 的非负整数序列 A_1, A_2, …, A_n，以及若干次询问。每次询问给定一个整数 K，需要计算所有满足「下标 i 的二进制位集合是 K 的二进制位集合的子集」（即 i & K == i）的 A_i 之和。

符号 "&" 表示按位与运算（逐位与）：对应位均为 1 时结果位为 1，否则为 0。

输入描述

输入包含多组测试数据。第一行包含整数 T 表示测试组数。每组数据： - 包含 n 个整数 A_1, A_2, …, A_n（原文取值范围识别缺失）； - 接下来有 q 次询问，每次给定一个整数 K，需要按上述规则求和。

（原文下标与取值范围识别严重缺失）

输出描述

对于每组测试数据，按询问顺序输出，每行一个整数，表示对应查询的答案。

示例

（原文示例数据严重损坏，无法完整还原。据保留下来的片段，当查询 K 分别为 0、3、5、2、6、7、4 时，对应下标集合与和大致如下： - K=0：无合法下标，和为 0； - K=3：下标集合 {1,2,3}，和为 ?； - K=5：下标集合 {1,4,5}，和为 10； - K=2：仅下标 2，和为 5； - K=6：下标集合 {2,4,6}，和为 9； - K=7：下标集合 {1,2,3,4,5,6}，和为 15； - K=4：仅下标 4，和为 3。）

解题思路

本题要求对每个查询 K，求所有满足 i & K == i（即 i 的二进制位是 K 二进制位的子集）的 A_i 之和。 这是「子集和（SOS DP / 高维前缀和）」的经典模型：令 f[mask] 初始为 A_mask（下标即掩码），然后对每个二进制位 b，对所有含该位的 mask 做 f[mask] += f[mask ^ (1<<b)]。 经过若干轮后，f[mask] 即为所有 mask 子集位置上的 A 之和，查询直接输出 f[K]。 掩码空间取不小于 max(n, maxK) 的 2 的幂，保证下标与查询都能容纳。

复杂度分析

  • 时间复杂度：O(size·log size)，size 为掩码空间大小（2 的幂），即高维前缀和的经典复杂度。
  • 空间复杂度：O(size)，即 f 数组。

解题代码

Java 实现

import java.io.*;
import java.util.*;

public class Main {
    public static void main(String[] args) throws IOException {
        StreamTokenizer in = new StreamTokenizer(new BufferedReader(new InputStreamReader(System.in)));
        in.nextToken();
        int T = (int) in.nval;
        StringBuilder out = new StringBuilder();
        for (int tc = 0; tc < T; tc++) {
            in.nextToken(); int n = (int) in.nval;
            long[] a = new long[n + 1];
            for (int i = 1; i <= n; i++) { in.nextToken(); a[i] = (long) in.nval; }
            in.nextToken(); int q = (int) in.nval;
            int[] Ks = new int[q];
            int maxK = 0;
            for (int i = 0; i < q; i++) { in.nextToken(); Ks[i] = (int) in.nval; if (Ks[i] > maxK) maxK = Ks[i]; }
            int size = 1;
            int need = Math.max(n, maxK) + 1;
            while (size < need) size <<= 1;
            long[] f = new long[size];
            for (int i = 1; i <= n && i < size; i++) f[i] = a[i];
            for (int b = 0; (1 << b) < size; b++) {
                int bit = 1 << b;
                for (int mask = 0; mask < size; mask++) {
                    if ((mask & bit) != 0) f[mask] += f[mask ^ bit];
                }
            }
            for (int i = 0; i < q; i++) out.append(f[Ks[i]]).append('\n');
        }
        System.out.print(out);
    }
}

Python 实现

import sys

def main():
    data = sys.stdin.buffer.read().split()
    if not data:
        return
    it = iter(data)
    T = int(next(it))
    out = []
    for _ in range(T):
        n = int(next(it))
        a = [0] * (n + 1)
        for i in range(1, n + 1):
            a[i] = int(next(it))
        q = int(next(it))
        Ks = [0] * q
        maxK = 0
        for i in range(q):
            Ks[i] = int(next(it))
            if Ks[i] > maxK:
                maxK = Ks[i]
        size = 1
        need = max(n, maxK) + 1
        while size < need:
            size <<= 1
        f = [0] * size
        for i in range(1, n + 1):
            if i < size:
                f[i] = a[i]
        b = 0
        while (1 << b) < size:
            bit = 1 << b
            for mask in range(size):
                if mask & bit:
                    f[mask] += f[mask ^ bit]
            b += 1
        for i in range(q):
            out.append(str(f[Ks[i]]))
    for v in out:
        print(v)
