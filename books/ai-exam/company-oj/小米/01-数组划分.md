# 数组划分

> 来源：语雀「小米真题题解」（已做 OCR 校对）

## 题目描述

小明来玩数组了。他有一个长度为 n 的数组 a 以及一个给定的数字 k，需要把数组 a 划分成连续的 k 个子数组。定义 f[i] 表示第 i 个子数组中数字的最大值，小明的任务是最小化 f[] 中最大值与最小值之间的差，并输出划分方案。如果存在多种方案，则输出字典序最小的那一组。

## 输入描述

输入包括多组测试数据。

第一行有一个正整数 T（1 ≤ T ≤ 100），表示测试数据的组数。

每组测试数据的第一行有两个正整数 n（1 ≤ n ≤ 10^5）和 k（1 ≤ k ≤ n），表示数组的长度以及划分的子数组个数；

接下来一行有 n 个正整数 a_1, a_2, …, a_n（1 ≤ a_i ≤ 10^5），表示题目给定的数组。

保证每个测试点的所有测试数据的 n 之和不超过 10^5。

## 输出描述

对于每组测试数据，输出 k 行，其中第 i 行包含两个数字 l 和 r，表示第 i 个子数组的下标区间。合法的划分方案需要保证：
1. l_1 = 1，r_k = n；
2. r_i + 1 = l_{i+1}（1 ≤ i ≤ k−1）。

对于两个不同的方案，若下标 j 表示两个方案之间第一对不同的 l 和 r，则 l 更小的方案字典序更小；若 l 相同，则 r 更小的方案字典序更小。

## 示例

输入：
```
1
6 3
8 3 5 6 4 2
```

输出：
```
1 1
2 3
4 6
```

## 解题思路

本题要让 k 段各自最大值之间的极差最小，并输出字典序最小的划分方案。
关键结论：最优时 k 段的最大值恰好是数组中最大的 k 个元素。因此先排序取第 k 大的值 x = sorted[n−k] 作为阈值。
下标 i 满足 a[i] ≥ x 的位置恰好有 k 个（即那 k 个「大值」）。要让每段的最大值各对应一个大值，每段至少要包含一个这样的位置。
贪心取字典序最小：第 1 段在第 1 个大值处结束，第 2 段在第 2 个大值处结束……前 k−1 段分别以第 1..k−1 个大值位置为右端点，最后一段延伸到 n。
这样每段最大值正好是第 i 大的值，极差最小，且左端点尽可能靠前，满足字典序最小。

## 复杂度分析

- 时间复杂度：O(n log n)，瓶颈在排序（所有测试数据的 n 之和不超过 10^5）。
- 空间复杂度：O(n)，用于排序副本与记录大值位置。

## 解题代码

### Java 实现

```java
// 题目：数组划分
// 算法：按题意模拟
// 模式：ACM（stdin/stdout）

import java.io.*;
import java.util.*;

public class Main {
    static BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
    static StringTokenizer st;
    static String next() throws IOException {
        while (st == null || !st.hasMoreTokens()) {
            String line = br.readLine();
            if (line == null) return null;
            st = new StringTokenizer(line);
        }
        return st.nextToken();
    }
    static int nextInt() throws IOException { return Integer.parseInt(next()); }
    static long nextLong() throws IOException { return Long.parseLong(next()); }

    public static void main(String[] args) throws IOException {
        int T = nextInt();
        StringBuilder out = new StringBuilder();
        for (int tc = 0; tc < T; tc++) {
            int n = nextInt();
            int k = nextInt();
            int[] a = new int[n];
            for (int i = 0; i < n; i++) { a[i] = nextInt(); }
            int[] sorted = a.clone();
            Arrays.sort(sorted);
            int x = sorted[n - k]; // k-th largest
            ArrayList<Integer> big = new ArrayList<>();
            for (int i = 0; i < n; i++) if (a[i] >= x) big.add(i + 1);
            int prev = 0;
            for (int i = 0; i < k; i++) {
                int r = (i == k - 1) ? n : big.get(i);
                int l = prev + 1;
                out.append(l).append(' ').append(r).append('
');
                prev = r;
            }
        }
        System.out.print(out);
    }
}
```


### Python 实现

```python
# 题目：数组划分
# 算法：排序 + 扫描
# 模式：ACM（stdin/stdout）

import sys

# 核心函数：main
def main():
    data = sys.stdin.buffer.read().split()
    # 条件判断
    if not data:
        # 返回结果
        return
    it = iter(data)
    T = int(next(it))
    out = []
    # 遍历 _
    for _ in range(T):
        n = int(next(it))
        k = int(next(it))
        a = [int(next(it)) for _i in range(n)]
        s = sorted(a)
        x = s[n - k]
        big = [i + 1 for i in range(n) if a[i] >= x]
        prev = 0
        # 枚举位置 i
        for i in range(k):
            r = n if i == k - 1 else big[i]
            l = prev + 1
            out.append(str(l) + ' ' + str(r))
            prev = r
    # 遍历 v
    for v in out:
        print(v)

main()
```
