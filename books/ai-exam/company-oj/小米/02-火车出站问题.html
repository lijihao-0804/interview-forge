来源：语雀「小米真题题解」（已做 OCR 校对）

题目描述

有 n 辆火车准备按照编号 1, 2, …, n 的顺序进站，每辆火车有两种出站方式：第一种是从原进站口（出站口 1）出站，第二种是沿着直行的轨道（出站口 2）出站。需要注意的是，只有当该火车在沿着某个出站口轨道的方向上没有其他火车时，该火车才能够从该出站口出站。

现在有一个出站序列，表示火车的出站顺序。请问最多有多少辆火车是从原进站口（出站口 1）出站的？如果该出站序列不能表示某种合法的出站顺序，请输出 -1。

输入描述

第一行一个整数 n（1 ≤ n ≤ 10^6），表示火车的数量。

第二行 n 个整数，表示出站序列，保证该序列为一个 1 到 n 的排列，即 1 到 n 出现且仅出现一次。

输出描述

一行一个整数，表示答案。

示例 1

输入：

5
1 3 5 2 4

输出：

4

说明

第 1 辆火车进站后立即从原进站口（出站口 1）出站。 第 2 辆火车进站后没有立即出站。 第 3 辆火车进站后立即从原进站口（出站口 1）出站。 第 4 辆火车进站后没有立即出站。 第 5 辆火车进站后立即从原进站口（出站口 1）出站。 由于第 2 辆火车在沿着原进站口出站的方向上存在着第 4 辆火车，因此第 2 辆火车只能沿着直行的轨道（出站口 2）出站。最后第 4 辆火车从原进站口（出站口 1）出站。因此最多有 4 辆火车从原进站口出站。

示例 2

输入：

4
4 2 1 3

输出：

-1

说明

由于第 4 辆火车最先出站，因此当第 4 辆火车出站后，车站里还剩下第 1、2、3 辆火车。由于第 2 辆火车在沿着原进站口出站的方向以及沿着直行轨道的方向上分别存在着第 3 辆火车以及第 1 辆火车，所以此时第 2 辆火车不可能出站，该序列不能表示一种出站序列，输出 -1。

解题思路

把车站看作一个「双端结构」：火车按 1..n 进站，最深（编号最小）的车在直行轨道一端，最新（编号最大）的车在原进站口一端。 任一时刻仍在站内的火车编号构成一段连续区间 [lo, hi]，只有区间两端能出站：编号为 hi 的车只能从原进站口（出站口 1）出，编号为 lo 的车只能从直行轨道（出站口 2）出，中间编号被两侧挡住无法出站。 用布尔数组标记哪些编号仍在站内，并维护 lo、hi。遇到比已出现最大编号更大的车时，把中间所有新车标记进站。 若当前出站编号等于 hi，则从出站口 1 出站（计数 +1），hi 下移并跳过已出站者；若等于 lo，则从出站口 2 出站，lo 上移；否则该车被夹在中间，序列非法，输出 −1。 统计从出站口 1 出站的数量即为答案。

复杂度分析

  • 时间复杂度：O(n)，每个编号进站、出站各一次，lo/hi 指针只单调移动。
  • 空间复杂度：O(n)，布尔数组标记站内火车。

解题代码

Java 实现

import java.io.*;

public class Solution {
    static class FastScanner {
        InputStream in;
        byte[] buf = new byte[1 << 16];
        int len = 0, ptr = 0;
        FastScanner(InputStream i) { in = i; }
        int read() {
            if (ptr >= len) {
                try { len = in.read(buf); } catch (IOException e) { len = -1; }
                ptr = 0;
                if (len <= 0) return -1;
            }
            return buf[ptr++];
        }
        int nextInt() {
            int c = read();
            while (c <= 32) { if (c == -1) return -1; c = read(); }
            int sign = 1;
            if (c == '-') { sign = -1; c = read(); }
            int val = 0;
            while (c > 32) { val = val * 10 + (c - '0'); c = read(); }
            return val * sign;
        }
    }

    public static void main(String[] args) {
        FastScanner fs = new FastScanner(System.in);
        int n = fs.nextInt();
        boolean[] inDeck = new boolean[n + 2];
        int maxAdded = 0, lo = 1, hi = 0;
        boolean empty = true;
        long front = 0;
        boolean ok = true;
        for (int i = 0; i < n && ok; i++) {
            int p = fs.nextInt();
            if (p > maxAdded) {
                int old = maxAdded;
                for (int v = old + 1; v <= p; v++) inDeck[v] = true;
                maxAdded = p;
                if (empty) lo = old + 1;
                hi = p;
                empty = false;
            } else {
                if (empty) { ok = false; break; }
                if (!inDeck[p]) { ok = false; break; }
            }
            if (p == hi) {
                inDeck[p] = false;
                front++;
                hi--;
                while (hi >= lo && !inDeck[hi]) hi--;
                if (hi < lo) empty = true;
            } else if (p == lo) {
                inDeck[p] = false;
                lo++;
                while (lo <= hi && !inDeck[lo]) lo++;
                if (lo > hi) empty = true;
            } else {
                ok = false;
            }
        }
        System.out.println(ok ? front : -1);
    }
}
