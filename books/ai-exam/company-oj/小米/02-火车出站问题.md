# 火车出站问题

> 来源：语雀「小米真题题解」（已做 OCR 校对）

## 题目描述

有 n 辆火车准备按照编号 1, 2, …, n 的顺序进站，每辆火车有两种出站方式：第一种是从原进站口（出站口 1）出站，第二种是沿着直行的轨道（出站口 2）出站。需要注意的是，只有当该火车在沿着某个出站口轨道的方向上没有其他火车时，该火车才能够从该出站口出站。

现在有一个出站序列，表示火车的出站顺序。请问最多有多少辆火车是从原进站口（出站口 1）出站的？如果该出站序列不能表示某种合法的出站顺序，请输出 -1。

## 输入描述

第一行一个整数 n（1 ≤ n ≤ 10^6），表示火车的数量。

第二行 n 个整数，表示出站序列，保证该序列为一个 1 到 n 的排列，即 1 到 n 出现且仅出现一次。

## 输出描述

一行一个整数，表示答案。

## 示例 1

输入：
```
5
1 3 5 2 4
```

输出：
```
4
```

## 说明

第 1 辆火车进站后立即从原进站口（出站口 1）出站。
第 2 辆火车进站后没有立即出站。
第 3 辆火车进站后立即从原进站口（出站口 1）出站。
第 4 辆火车进站后没有立即出站。
第 5 辆火车进站后立即从原进站口（出站口 1）出站。
由于第 2 辆火车在沿着原进站口出站的方向上存在着第 4 辆火车，因此第 2 辆火车只能沿着直行的轨道（出站口 2）出站。最后第 4 辆火车从原进站口（出站口 1）出站。因此最多有 4 辆火车从原进站口出站。

## 示例 2

输入：
```
4
4 2 1 3
```

输出：
```
-1
```

## 说明

由于第 4 辆火车最先出站，因此当第 4 辆火车出站后，车站里还剩下第 1、2、3 辆火车。由于第 2 辆火车在沿着原进站口出站的方向以及沿着直行轨道的方向上分别存在着第 3 辆火车以及第 1 辆火车，所以此时第 2 辆火车不可能出站，该序列不能表示一种出站序列，输出 -1。

## 解题思路

把车站看作一个「双端结构」：火车按 1..n 进站，最深（编号最小）的车在直行轨道一端，最新（编号最大）的车在原进站口一端。
任一时刻仍在站内的火车编号构成一段连续区间 [lo, hi]，只有区间两端能出站：编号为 hi 的车只能从原进站口（出站口 1）出，编号为 lo 的车只能从直行轨道（出站口 2）出，中间编号被两侧挡住无法出站。
用布尔数组标记哪些编号仍在站内，并维护 lo、hi。遇到比已出现最大编号更大的车时，把中间所有新车标记进站。
若当前出站编号等于 hi，则从出站口 1 出站（计数 +1），hi 下移并跳过已出站者；若等于 lo，则从出站口 2 出站，lo 上移；否则该车被夹在中间，序列非法，输出 −1。
统计从出站口 1 出站的数量即为答案。

## 复杂度分析

- 时间复杂度：O(n)，每个编号进站、出站各一次，lo/hi 指针只单调移动。
- 空间复杂度：O(n)，布尔数组标记站内火车。

## 解题代码

### Java 实现

```java
// 题目：火车出站问题
// 算法：按题意模拟
// 模式：ACM（stdin/stdout）

import java.io.*;
import java.util.*;

public class Main {
    static BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
    static StringTokenizer st;
    static String next() throws IOException {
        while (st == null || !st.hasMoreTokens()) {
            String line = br.readLine();
            if (line == null) return null;
            st = new StringTokenizer(line);
        }
        return st.nextToken();
    }
    static int nextInt() throws IOException { return Integer.parseInt(next()); }
    static long nextLong() throws IOException { return Long.parseLong(next()); }

    public static void main(String[] args) throws IOException {
        int n = nextInt();
        boolean[] inDeck = new boolean[n + 2];
        int maxAdded = 0, lo = 1, hi = 0;
        boolean empty = true;
        long front = 0;
        boolean ok = true;
        for (int i = 0; i < n && ok; i++) {
            int p = nextInt();
            if (p > maxAdded) {
                int old = maxAdded;
                for (int v = old + 1; v <= p; v++) inDeck[v] = true;
                maxAdded = p;
                if (empty) lo = old + 1;
                hi = p;
                empty = false;
            } else {
                if (empty) { ok = false; break; }
                if (!inDeck[p]) { ok = false; break; }
            }
            if (p == hi) {
                inDeck[p] = false;
                front++;
                hi--;
                while (hi >= lo && !inDeck[hi]) hi--;
                if (hi < lo) empty = true;
            } else if (p == lo) {
                inDeck[p] = false;
                lo++;
                while (lo <= hi && !inDeck[lo]) lo++;
                if (lo > hi) empty = true;
            } else {
                ok = false;
            }
        }
        System.out.println(ok ? front : -1);
    }
}
```


### Python 实现

```python
# 题目：火车出站问题
# 算法：按题意模拟
# 模式：ACM（stdin/stdout）

import sys

# 核心函数：main
def main():
    data = sys.stdin.buffer.read().split()
    # 条件判断
    if not data:
        # 返回结果
        return
    it = iter(data)
    n = int(next(it))
    in_deck = [False] * (n + 2)
    max_added = 0
    lo = 1
    hi = 0
    empty = True
    front = 0
    ok = True
    # 遍历 _
    for _ in range(n):
        # 条件判断
        if not ok:
            break
        p = int(next(it))
        # 条件判断
        if p > max_added:
            old = max_added
            # 遍历 v
            for v in range(old + 1, p + 1):
                in_deck[v] = True
            max_added = p
            # 条件判断
            if empty:
                lo = old + 1
            hi = p
            empty = False
        else:
            # 条件判断
            if empty:
                ok = False
                break
            # 条件判断
            if not in_deck[p]:
                ok = False
                break
        # 条件判断
        if p == hi:
            in_deck[p] = False
            front += 1
            hi -= 1
            # 循环处理
            while hi >= lo and not in_deck[hi]:
                hi -= 1
            # 条件判断
            if hi < lo:
                empty = True
        # 条件判断
        elif p == lo:
            in_deck[p] = False
            lo += 1
            # 循环处理
            while lo <= hi and not in_deck[lo]:
                lo += 1
            # 条件判断
            if lo > hi:
                empty = True
        else:
            ok = False
    print(front if ok else -1)

main()
```
