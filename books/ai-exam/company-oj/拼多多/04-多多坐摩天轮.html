题目描述

摩天轮有 n 个吊舱，第 i 个吊舱的幸福指数为 h[i]。m 名玩家排队，每圈坐满 n 个吊舱后玩家回到队尾。问经过 L 圈后，哪个排队位置的总幸福值最大（并列时取靠前的位置）。

输入描述

  • 第一行三个整数 n, m, L。
  • 第二行 n 个整数表示吊舱幸福指数。

输出描述

输出幸福值最大的排队位置。

示例

（原文示例的具体输入数据缺失，仅保留以下说明） - 说明：每圈只能坐前 3 个吊舱，幸福值总是 1、2、3，第 3 位玩家总幸福值最大。 - 说明：第 2 位玩家两轮幸福值分别为 3 和 1，总幸福值 4，与第 5 位并列但位置更靠前。

解题思路

每圈能坐的人数 riders = min(n, m)；第 r 圈（从 0 起）队列的起始位置为 (r·n) mod m，玩家在圈内依次占据吊舱 p 获得 h[p]。 由于起始位置只依赖 r·n mod m，整个分配序列以 period = m / gcd(m, n) 圈为一个周期循环。 先算出一个周期内每位玩家的幸福值，乘以完整周期数 cycles = L / period；再单独累加剩余 rem = L mod period 圈。 最后遍历所有玩家取总幸福值最大者，并列时取编号最小（靠前）——用严格大于更新即可保证取靠前。 （题面示例数据缺失，此处依据代码逻辑还原。）

复杂度分析

  • 时间复杂度：O(period·riders + m)，period = m/gcd(m,n)，riders = min(n,m)。
  • 空间复杂度：O(m)，存储每位玩家的累计幸福值。

解题代码

Java 实现

import java.io.*;
import java.util.*;

public class Solution {
    static long gcd(long a, long b) { return b == 0 ? a : gcd(b, a % b); }

    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        StringTokenizer st = new StringTokenizer(br.readLine());
        long n = Long.parseLong(st.nextToken());
        long m = Long.parseLong(st.nextToken());
        long L = Long.parseLong(st.nextToken());
        int ni = (int) n, mi = (int) m;
        int riders = (int) Math.min(n, m);
        int[] h = new int[ni];
        st = new StringTokenizer(br.readLine());
        for (int i = 0; i < ni; i++) h[i] = Integer.parseInt(st.nextToken());

        long g = gcd(m, n);
        long period = m / g;
        long cycles = L / period;
        long rem = L % period;

        long[] total = new long[mi];
        for (long r = 0; r < period; r++) {
            long start = (r % m) * (n % m) % m;
            for (int p = 0; p < riders; p++) {
                int player = (int) ((start + p) % m);
                total[player] += h[p];
            }
        }
        for (int i = 0; i < mi; i++) total[i] *= cycles;
        for (long r = 0; r < rem; r++) {
            long start = (r % m) * (n % m) % m;
            for (int p = 0; p < riders; p++) {
                int player = (int) ((start + p) % m);
                total[player] += h[p];
            }
        }
        long best = Long.MIN_VALUE;
        int bi = 0;
        for (int i = 0; i < mi; i++) {
            if (total[i] > best) { best = total[i]; bi = i; }
        }
        System.out.println(bi + 1);
    }
}
