# 多多的消消乐

> 来源：语雀「拼多多真题题解」（已做 OCR 校对，原文示例数据缺失）

## 题目描述

给定二进制字符串 s，允许两种操作：
1. 删除任意字符（花费 1 硬币）。
2. 交换任意两个字符（免费）。

目标得到漂亮字符串：对于所有位置 i，字符串的第 i 个字符不能等于原字符串 s 的第 i 个字符。求最小花费硬币数。

## 输入描述

- 第一行整数 T 表示测试数据组数。
- 每组数据一个字符串 s。

## 输出描述

每组数据输出最小花费硬币数。

## 示例

（原文示例的具体输入数据缺失，仅保留以下说明）
- 第一组：删除唯一字符得到空串，花费 1 硬币。
- 第二组：删除最后一个字符后交换前两个字符，花费 1 硬币。
- 第三组：通过免费交换得到漂亮字符串，花费 0 硬币。
- 第四组：删除前 4 个字符，花费 4 硬币。

## 解题思路

删除代价 1、交换免费，因此可把问题理解为：保留若干字符（删除其余，花费 = 删除个数），再对保留字符任意重排。
设最终保留长度为 L，需让新串第 i 位不等于原串第 i 位（i < L）。若原串前 L 位中有 a 个 '0'、b 个 '1'（a+b=L），则这 a 个位置必须放 '1'、b 个位置必须放 '0'。
于是要求剩余字符里恰有 a 个 '1' 和 b 个 '0'，即全串 '1' 总数 tot1 ≥ a、'0' 总数 tot0 ≥ b（多余的可删掉）。满足时即可完成重排。
从 L=n 向下枚举，找到第一个满足条件的 L，答案即删除数 n−L（L 越大代价越小）。

## 复杂度分析

- 时间复杂度：O(n)，预处理前缀 '0' 个数后，枚举 L 从 n 到 0 最多 O(n)。
- 空间复杂度：O(n)，前缀计数数组。

## 解题代码

### Java 实现

```java
// 题目：多多的消消乐
// 算法：按题意模拟
// 模式：ACM（stdin/stdout）

import java.io.*;

public class Main {
    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        int T = Integer.parseInt(br.readLine().trim());
        StringBuilder out = new StringBuilder();
        for (int tc = 0; tc < T; tc++) {
            String s = br.readLine().trim();
            int n = s.length();
            int[] zeros = new int[n + 1];
            for (int i = 0; i < n; i++) zeros[i + 1] = zeros[i] + (s.charAt(i) == '0' ? 1 : 0);
            int tot0 = zeros[n];
            int tot1 = n - tot0;
            int ans = n;
            for (int L = n; L >= 0; L--) {
                int a = zeros[L];
                int b = L - a;
                if (tot1 >= a && tot0 >= b) { ans = n - L; break; }
            }
            out.append(ans).append('\n');
        }
        System.out.print(out);
    }
}
```


### Python 实现

```python
# 题目：多多的消消乐
# 算法：按题意模拟
# 模式：ACM（stdin/stdout）

import sys

# 核心函数：main
def main():
    data = sys.stdin.read().splitlines()
    # 条件判断
    if not data:
        # 返回结果
        return
    p = 0
    T = int(data[p].strip())
    p += 1
    out = []
    # 遍历 _
    for _ in range(T):
        s = data[p].strip()
        p += 1
        n = len(s)
        zeros = [0] * (n + 1)
        # 枚举位置 i
        for i in range(n):
            zeros[i + 1] = zeros[i] + (1 if s[i] == '0' else 0)
        tot0 = zeros[n]
        tot1 = n - tot0
        ans = n
        # 遍历 L
        for L in range(n, -1, -1):
            a = zeros[L]
            b = L - a
            # 条件判断
            if tot1 >= a and tot0 >= b:
                ans = n - L
                break
        out.append(str(ans))
    # 遍历 v
    for v in out:
        print(v)

main()
```
