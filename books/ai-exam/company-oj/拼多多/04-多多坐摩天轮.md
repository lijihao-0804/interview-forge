# 多多坐摩天轮

> 来源：语雀「拼多多真题题解」（已做 OCR 校对，原文示例数据缺失）

## 题目描述

摩天轮有 n 个吊舱，第 i 个吊舱的幸福指数为 h[i]。m 名玩家排队，每圈坐满 n 个吊舱后玩家回到队尾。问经过 L 圈后，哪个排队位置的总幸福值最大（并列时取靠前的位置）。

## 输入描述

- 第一行三个整数 n, m, L。
- 第二行 n 个整数表示吊舱幸福指数。

## 输出描述

输出幸福值最大的排队位置。

## 示例

（原文示例的具体输入数据缺失，仅保留以下说明）
- 说明：每圈只能坐前 3 个吊舱，幸福值总是 1、2、3，第 3 位玩家总幸福值最大。
- 说明：第 2 位玩家两轮幸福值分别为 3 和 1，总幸福值 4，与第 5 位并列但位置更靠前。

## 解题思路

每圈能坐的人数 riders = min(n, m)；第 r 圈（从 0 起）队列的起始位置为 (r·n) mod m，玩家在圈内依次占据吊舱 p 获得 h[p]。
由于起始位置只依赖 r·n mod m，整个分配序列以 period = m / gcd(m, n) 圈为一个周期循环。
先算出一个周期内每位玩家的幸福值，乘以完整周期数 cycles = L / period；再单独累加剩余 rem = L mod period 圈。
最后遍历所有玩家取总幸福值最大者，并列时取编号最小（靠前）——用严格大于更新即可保证取靠前。
（题面示例数据缺失，此处依据代码逻辑还原。）

## 复杂度分析

- 时间复杂度：O(period·riders + m)，period = m/gcd(m,n)，riders = min(n,m)。
- 空间复杂度：O(m)，存储每位玩家的累计幸福值。

### Java 实现

```java
// 题目：多多坐摩天轮
// 算法：按题意模拟
// 模式：ACM（stdin/stdout）

import java.io.*;
import java.util.*;

public class Main {

    static long gcd(long a, long b) { return b == 0 ? a : gcd(b, a % b); }

    public static void main(String[] args) throws IOException {
        Scanner sc = new Scanner(System.in);
        long n = sc.nextLong();
        long m = sc.nextLong();
        long L = sc.nextLong();
        int ni = (int) n, mi = (int) m;
        int riders = (int) Math.min(n, m);
        int[] h = new int[ni];
        for (int i = 0; i < ni; i++) h[i] = sc.nextInt();

        long g = gcd(m, n);
        long period = m / g;
        long cycles = L / period;
        long rem = L % period;

        long[] total = new long[mi];
        for (long r = 0; r < period; r++) {
            long start = (r % m) * (n % m) % m;
            for (int p = 0; p < riders; p++) {
                int player = (int) ((start + p) % m);
                total[player] += h[p];
            }
        }
        for (int i = 0; i < mi; i++) total[i] *= cycles;
        for (long r = 0; r < rem; r++) {
            long start = (r % m) * (n % m) % m;
            for (int p = 0; p < riders; p++) {
                int player = (int) ((start + p) % m);
                total[player] += h[p];
            }
        }
        long best = Long.MIN_VALUE;
        int bi = 0;
        for (int i = 0; i < mi; i++) {
            if (total[i] > best) { best = total[i]; bi = i; }
        }
        System.out.println(bi + 1);
    }
}
```


### Python 实现

```python
# 题目：多多坐摩天轮
# 算法：按题意模拟
# 模式：ACM（stdin/stdout）

import sys
import math

# 核心函数：main
def main():
    data = sys.stdin.buffer.read().split()
    # 条件判断
    if not data:
        # 返回结果
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))
    L = int(next(it))
    h = [int(next(it)) for _ in range(n)]
    riders = min(n, m)
    g = math.gcd(m, n)
    period = m // g
    cycles = L // period
    rem = L % period
    total = [0] * m
    # 遍历 r
    for r in range(period):
        start = ((r % m) * (n % m)) % m
        # 遍历 pp
        for pp in range(riders):
            player = (start + pp) % m
            total[player] += h[pp]
    # 枚举位置 i
    for i in range(m):
        total[i] *= cycles
    # 遍历 r
    for r in range(rem):
        start = ((r % m) * (n % m)) % m
        # 遍历 pp
        for pp in range(riders):
            player = (start + pp) % m
            total[player] += h[pp]
    best = None
    bi = 0
    # 枚举位置 i
    for i in range(m):
        # 条件判断
        if best is None or total[i] > best:
            best = total[i]
            bi = i
    print(bi + 1)

main()
```
