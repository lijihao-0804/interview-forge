# 多多的演唱会灯光方案

> 来源：语雀「拼多多真题题解」（已做 OCR 校对，原文示例数据缺失）

## 题目描述

舞台灯光有五种主色（D、M、T、A、O）和其他辅助色。要求所取子串中包含全部五种主色（各至少一次），且恰好有 R 个辅助色。求满足条件的子串数量。

## 输入描述

- 第一行整数 T 表示测试数据组数。
- 每组数据第一行整数 R 表示所需辅助色数量，第二行字符串 s 表示灯光序列。

## 输出描述

每组数据输出满足条件的子串数量。

## 示例

（原文示例的具体输入数据缺失，仅保留以下说明）
- 说明：唯一满足条件的子串是 "AVMTTBL"，其中包含 3 个辅助色（A、V、L），且主色齐全。
- 说明：子串 "DOAMT" 全是主色，辅助色为 0。
- 说明：两个子串 "OYOMA" 和 "YOMAOTD" 均满足条件。

## 解题思路

本题求「同时包含 5 种主色 D、M、T、A、O，且辅助色恰好 R 个」的子串数量。
先用前缀和 pref[i] 记录前 i 个字符中辅助色的个数，则子串 [l, r] 的辅助色数 = pref[r+1] − pref[l]。
用 last[5] 记录五种主色各自最后一次出现的位置；对每个右端点 r，只有当左端点 l ≤ good（good 为五种主色最后出现位置的最小值）时，[l, r] 才包含全部主色。
把满足 l ≤ good 的所有前缀下标 ptr 的 pref[ptr] 值放进哈希表计数，再查目标 pref[r+1] − R 的出现次数，累加即为以 r 结尾的合法子串数。
指针 ptr 随 r 单调递增，整体均摊线性。

## 复杂度分析

- 时间复杂度：O(n)，右端点扫描一次，ptr 指针单调前进、哈希查询 O(1) 均摊，每个 r 还需 O(5) 求 good。
- 空间复杂度：O(n)，哈希表最多存 n 个不同前缀和。

## 解题代码

### Java 实现

```java
import java.io.*;
import java.util.*;

public class Solution {
    static int idx(char c) {
        switch (c) {
            case 'D': return 0;
            case 'M': return 1;
            case 'T': return 2;
            case 'A': return 3;
            case 'O': return 4;
            default: return -1;
        }
    }

    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        int T = Integer.parseInt(br.readLine().trim());
        StringBuilder out = new StringBuilder();
        for (int tc = 0; tc < T; tc++) {
            int R = Integer.parseInt(br.readLine().trim());
            String s = br.readLine().trim();
            int n = s.length();
            int[] pref = new int[n + 1];
            for (int i = 0; i < n; i++) pref[i + 1] = pref[i] + (idx(s.charAt(i)) >= 0 ? 0 : 1);
            int[] last = new int[5];
            Arrays.fill(last, -1);
            HashMap<Integer, Long> freq = new HashMap<>();
            int ptr = 0;
            long ans = 0;
            for (int r = 0; r < n; r++) {
                int ci = idx(s.charAt(r));
                if (ci >= 0) last[ci] = r;
                int good = Integer.MAX_VALUE;
                for (int k = 0; k < 5; k++) {
                    if (last[k] < 0) { good = -1; break; }
                    if (last[k] < good) good = last[k];
                }
                if (good < 0) continue;
                while (ptr <= good) {
                    freq.merge(pref[ptr], 1L, Long::sum);
                    ptr++;
                }
                int target = pref[r + 1] - R;
                ans += freq.getOrDefault(target, 0L);
            }
            out.append(ans).append('\n');
        }
        System.out.print(out);
    }
}
```
