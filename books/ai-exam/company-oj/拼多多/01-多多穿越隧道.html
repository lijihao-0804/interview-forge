多多穿越隧道

遮住推导与代码，先自己想，再逐段揭示

来源：语雀「拼多多真题题解」（已做 OCR 校对）

题目描述

多多在一个长为 n 的横向隧道里，隧道每个位置用 1 到 n 的整数表示。隧道由 #（障碍物）和 .（空地）组成，其中 D 表示多多的初始位置。

移动规则： - 轻松移动：如果当前位置左边或右边是空地，则可以移动到相邻空地。 - 穿墙技能：至少进行一次轻松移动后，可以穿过一段连续障碍物，停留在障碍物另一侧的空地。

（原文题目描述较简，未明确“穿出隧道”的判定；据样例可理解为判断多多能否离开隧道的两端。）

输入描述

  • 第一行整数 T 表示测试数据组数。
  • 每组数据第一行整数 n 表示隧道长度，第二行长度为 n 的字符串描述隧道。

输出描述

每组数据输出 YES 或 NO，表示是否能穿出隧道。

示例

输入：

4
5
#D###
5
..D.#
7
#.#.D##
5
D####

输出：

NO
YES
YES
YES

说明

  • 第一组：D 所在段长度为 1，无法启动穿墙，输出 NO。
  • 第二组：D 所在段长度 ≥ 2，可向左直接走出或向右穿墙而出。
  • 第三组：先向左走一步，再从右边穿墙而出。
  • 第四组：只能从左边走出隧道。

解题思路

本题本质是判断多多能否走出隧道两端，关键在于「能否启动穿墙技能」。 若 D 已在字符串两端（下标 0 或 n−1），可直接走出，输出 YES。 否则找出 D 所在的、向左右扩展得到的连续非障碍段 [l, r]（遇到 '#' 停止）。 穿墙技能要求「至少先进行一次轻松移动」，而轻松移动需要相邻位置也是空地，因此只有当这段空地长度 ≥ 2（即 D 旁边还有空地可迈出一步）时，才能启动穿墙并最终穿出隧道；若 D 是一个长度 1 的孤立空地，则寸步难行，输出 NO。

复杂度分析

  • 时间复杂度：O(n)，每组数据只向左右各扫描一次。
  • 空间复杂度：O(1)，只用到若干下标变量。

解题代码

Java 实现

// 题目：多多穿越隧道
// 算法：按题意模拟
// 模式：ACM（stdin/stdout）

import java.io.*;
import java.util.*;

public class Main {
    static BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
    static String nextLine() throws IOException { return br.readLine(); }

    public static void main(String[] args) throws IOException {
        int T = Integer.parseInt(nextLine().trim());
        StringBuilder out = new StringBuilder();
        for (int tc = 0; tc < T; tc++) {
            int n = Integer.parseInt(nextLine().trim());
            String s = nextLine().trim();
            int d = s.indexOf('D');
            boolean yes = false;
            if (d != -1) {
                if (d == 0 || d == n - 1) {
                    yes = true;
                } else {
                    int l = d;
                    while (l - 1 >= 0 && s.charAt(l - 1) != '#') l--;
                    int r = d;
                    while (r + 1 < n && s.charAt(r + 1) != '#') r++;
                    yes = (r - l + 1) >= 2;
                }
            }
            out.append(yes ? "YES" : "NO").append('
');
        }
        System.out.print(out);
    }
}

Python 实现

# 题目：多多穿越隧道
# 算法：按题意模拟
# 模式：ACM（stdin/stdout）

import sys

# 核心函数：main
def main():
    data = sys.stdin.read().splitlines()
    # 条件判断
    if not data:
        # 返回结果
        return
    p = 0
    T = int(data[p].strip())
    p += 1
    out = []
    # 遍历 _
    for _ in range(T):
        n = int(data[p].strip())
        p += 1
        s = data[p].strip()
        p += 1
        d = s.find('D')
        yes = False
        # 条件判断
        if d != -1:
            # 条件判断
            if d == 0 or d == n - 1:
                yes = True
            else:
                l = d
                # 循环处理
                while l - 1 >= 0 and s[l - 1] != '#':
                    l -= 1
                r = d
                # 循环处理
                while r + 1 < n and s[r + 1] != '#':
                    r += 1
                yes = (r - l + 1) >= 2
        out.append('YES' if yes else 'NO')
    # 遍历 v
    for v in out:
        print(v)
