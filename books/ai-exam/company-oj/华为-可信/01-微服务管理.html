微服务管理

遮住推导与代码，先自己想，再逐段揭示

来源：语雀「华为-可信真题题解」（已做 OCR 校对）

题目描述

微服务的运行规则如下：

  • 部署：一个微服务在一台服务器上只能部署一个实例，但可部署在多台服务器上。
  • 运行状态：一个微服务可以不依赖其它微服务独立启动并运行。
  • 提供服务：一个微服务，当无依赖时，只要有一个实例运行即可提供服务；当有依赖时，仅当其自身在运行且其所依赖的所有微服务都可提供服务，该微服务才能提供服务。

例如：某时刻，微服务 A 依赖微服务 B、B 依赖 C、C 无依赖，则： - 若 C 至少有一个实例处于运行状态，则 C 可提供服务； - 同时，若 B 至少有一个实例处于运行状态，则 B 也可提供服务； - 再者，若 A 至少有一个实例处于运行状态，则 A 也可提供服务。

然后，若把 B 的所有实例停止，则 A、B 都不能提供服务；但 C 仍可提供服务。

请模拟微服务的运行、访问、服务器重启，实现如下功能（函数）：

  • ServiceWgSys()：系统初始化，假设机房内的所有服务器都已启动、可供运行微服务。（原文函数名此处模糊）
  • rebootServers(int[] serverIds)：将服务器 serverIds 批量重启，这些服务器上的微服务不会自动启动。
  • startService(int serverId, String serviceName)：在指定的服务器 serverId 上启动微服务 serviceName。如果此服务器上已运行该微服务，则直接返回 false；否则启动该微服务（可能是新的微服务实例，也可以是之前因服务器重启而停止运行的微服务），该微服务处于运行状态，返回 true。
  • addDependency(String fromServiceName, String toServiceName)：令微服务 fromServiceName 依赖微服务 toServiceName，输入保证无循环依赖。如果此依赖关系已经存在，则直接返回 false；否则新添加此依赖关系（无论两个微服务是否启动过），返回 true。
  • isServiceAvailable(String serviceName)：如果指定的微服务可提供服务，返回 true；否则返回 false。

输入描述

每行表示一个函数调用，初始化函数仅首行调用一次，累计函数调用不超过 1000 次。

  • 0 ≤ serverId ≤ 1000，且是存在的服务器。
  • 0 < serverIds.length ≤ 500；0 ≤ serverIds[i] ≤ 1000，各不相同且是存在的服务器。
  • serviceName、fromServiceName、toServiceName 由英文字母或数字组成，0 < 长度 < 15。

输出描述

答题时按照函数方法原型中的要求（含返回值）进行实现，输出由框架完成（其中首行固定输出 null）。

解题思路

本题是「模拟 + 依赖图可达性」题，需要用哈希表维护三类状态：每台服务器上运行了哪些微服务、每个微服务当前运行的实例数、以及微服务之间的依赖边。 startService：用「服务器 → 服务集合」判重，成功启动则把该服务的运行实例数 +1。 rebootServers：把被重启服务器上的服务实例逐个扣减，并清空该服务器的服务集合。 addDependency：用「服务 → 依赖集合」判重后添加有向边（题目保证无环）。 isServiceAvailable：一个服务可提供服务，当且仅当它自身至少有一个实例在运行，且其所有依赖也都可提供服务；用带访问标记的 DFS 递归判断，避免重复遍历与死循环。 按行解析函数调用，按返回值规则输出（初始化与 reboot 输出 null）。

复杂度分析

  • 时间复杂度：每次查询最坏 O(V+E)（依赖图的点数与边数），累计函数调用不超过 1000 次，整体可接受。
  • 空间复杂度：O(V+E)，用于存储服务器服务集合与依赖关系。

解题代码

Java 实现

// 题目：微服务管理
// 算法：按题意模拟
// 模式：ACM（stdin/stdout）

import java.io.*;
import java.util.*;

public class Main {
    static BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
    static String nextLine() throws IOException { return br.readLine(); }
    static Map<Integer, Set<String>> serverServices = new HashMap<>();
    static Map<String, Integer> runningCount = new HashMap<>();
    static Map<String, Set<String>> deps = new HashMap<>();

    static void init() { serverServices.clear(); runningCount.clear(); deps.clear(); }

    static boolean startService(int serverId, String name) {
        Set<String> set = serverServices.computeIfAbsent(serverId, k -> new HashSet<>());
        if (set.contains(name)) return false;
        set.add(name);
        runningCount.merge(name, 1, Integer::sum);
        return true;
    }

    static void rebootServers(int[] ids) {
        for (int sid : ids) {
            Set<String> set = serverServices.get(sid);
            if (set != null) {
                for (String name : set) runningCount.merge(name, -1, Integer::sum);
                set.clear();
            }
        }
    }

    static boolean addDependency(String from, String to) {
        Set<String> s = deps.computeIfAbsent(from, k -> new HashSet<>());
        if (s.contains(to)) return false;
        s.add(to);
        return true;
    }

    static boolean isServiceAvailable(String name) {
        return avail(name, new HashSet<>());
    }

    static boolean avail(String name, Set<String> visiting) {
        Integer c = runningCount.get(name);
        if (c == null || c <= 0) return false;
        if (!visiting.add(name)) return true;
        Set<String> ds = deps.get(name);
        if (ds != null) {
            for (String d : ds) if (!avail(d, visiting)) return false;
        }
        visiting.remove(name);
        return true;
    }

    public static void main(String[] args) throws IOException {
        StringBuilder out = new StringBuilder();
        String line;
        init();
        while ((line = nextLine()) != null) {
            line = line.trim();
            if (line.isEmpty()) continue;
            if (line.startsWith("ServiceWgSys")) {
                init();
                out.append("null\n");
            } else if (line.startsWith("rebootServers")) {
                int l = line.indexOf('['), r = line.indexOf(']');
                String inside = line.substring(l + 1, r).trim();
                int[] ids = new int[0];
                if (!inside.isEmpty()) {
                    String[] ps = inside.split(",");
                    ids = new int[ps.length];
                    for (int i = 0; i < ps.length; i++) ids[i] = Integer.parseInt(ps[i].trim());
                }
                rebootServers(ids);
                out.append("null\n");
            } else if (line.startsWith("startService")) {
                int l = line.indexOf('('), r = line.lastIndexOf(')');
                String inside = line.substring(l + 1, r);
                int comma = inside.indexOf(',');
                int sid = Integer.parseInt(inside.substring(0, comma).trim());
                String name = extractQuoted(inside.substring(comma + 1));
                out.append(startService(sid, name)).append('\n');
            } else if (line.startsWith("addDependency")) {
                int l = line.indexOf('('), r = line.lastIndexOf(')');
                List<String> q = extractQuotedList(line.substring(l + 1, r));
                out.append(addDependency(q.get(0), q.get(1))).append('\n');
            } else if (line.startsWith("isServiceAvailable")) {
                int l = line.indexOf('('), r = line.lastIndexOf(')');
                String name = extractQuoted(line.substring(l + 1, r));
                out.append(isServiceAvailable(name)).append('\n');
            }
        }
        System.out.print(out);
    }

    static String extractQuoted(String s) {
        int a = s.indexOf('"');
        int b = s.indexOf('"', a + 1);
        return s.substring(a + 1, b);
    }

    static List<String> extractQuotedList(String s) {
        List<String> res = new ArrayList<>();
        int i = 0;
        while (true) {
            int a = s.indexOf('"', i);
            if (a < 0) break;
            int b = s.indexOf('"', a + 1);
            if (b < 0) break;
            res.add(s.substring(a + 1, b));
            i = b + 1;
        }
        return res;
    }
}

Python 实现

# 题目：微服务管理
# 算法：按题意模拟
# 模式：ACM（stdin/stdout）

import sys

server_services = {}
running_count = {}
deps = {}

# 核心函数：init
def init():
    server_services.clear()
    running_count.clear()
    deps.clear()

# 核心函数：start_service
def start_service(server_id, name):
    s = server_services.setdefault(server_id, set())
    # 条件判断
    if name in s:
        # 返回结果
        return False
    s.add(name)
    running_count[name] = running_count.get(name, 0) + 1
    # 返回结果
    return True

# 核心函数：reboot_servers
def reboot_servers(ids):
    # 遍历 sid
    for sid in ids:
        s = server_services.get(sid)
        # 条件判断
        if s is not None:
            # 遍历 name
            for name in list(s):
                running_count[name] = running_count.get(name, 0) - 1
            s.clear()

# 核心函数：add_dependency
def add_dependency(fr, to):
    s = deps.setdefault(fr, set())
    # 条件判断
    if to in s:
        # 返回结果
        return False
    s.add(to)
    # 返回结果
    return True

# 核心函数：avail
def avail(name, visiting):
    c = running_count.get(name, 0)
    # 条件判断
    if c <= 0:
        # 返回结果
        return False
    # 条件判断
    if name in visiting:
        # 返回结果
        return True
    visiting.add(name)
    ds = deps.get(name)
    # 条件判断
    if ds is not None:
        # 遍历 d
        for d in ds:
            # 条件判断
            if not avail(d, visiting):
                # 返回结果
                return False
    visiting.discard(name)
    # 返回结果
    return True

# 核心函数：is_service_available
def is_service_available(name):
    # 返回结果
    return avail(name, set())

# 核心函数：extract_quoted
def extract_quoted(s):
    a = s.index(chr(34))
    b = s.index(chr(34), a + 1)
    # 返回结果
    return s[a + 1:b]

# 核心函数：extract_quoted_list
def extract_quoted_list(s):
    res = []
    i = 0
    # 循环处理
    while True:
        a = s.find(chr(34), i)
        # 条件判断
        if a < 0:
            break
        b = s.find(chr(34), a + 1)
        # 条件判断
        if b < 0:
            break
        res.append(s[a + 1:b])
        i = b + 1
    # 返回结果
    return res

# 核心函数：main
def main():
    out = []
    init()
    # 遍历 line
    for line in sys.stdin:
        line = line.strip()
        # 条件判断
        if not line:
            continue
        # 条件判断
        if line.startswith('ServiceWgSys'):
            init()
            out.append('null')
        # 条件判断
        elif line.startswith('rebootServers'):
            l = line.index('[')
            r = line.index(']')
            inside = line[l + 1:r].strip()
            ids = []
            # 条件判断
            if inside:
                ids = [int(x.strip()) for x in inside.split(',')]
            reboot_servers(ids)
            out.append('null')
        # 条件判断
        elif line.startswith('startService'):
            l = line.index('(')
            r = line.rindex(')')
            inside = line[l + 1:r]
            comma = inside.index(',')
            sid = int(inside[:comma].strip())
            name = extract_quoted(inside[comma + 1:])
            out.append('true' if start_service(sid, name) else 'false')
        # 条件判断
        elif line.startswith('addDependency'):
            l = line.index('(')
            r = line.rindex(')')
            q = extract_quoted_list(line[l + 1:r])
            out.append('true' if add_dependency(q[0], q[1]) else 'false')
        # 条件判断
        elif line.startswith('isServiceAvailable'):
            l = line.index('(')
            r = line.rindex(')')
            name = extract_quoted(line[l + 1:r])
            out.append('true' if is_service_available(name) else 'false')
    # 遍历 v
    for v in out:
        print(v)

main()
