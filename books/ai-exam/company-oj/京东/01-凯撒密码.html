题目描述

小 Q 在路上捡到了一张字条，上面写了一个数组 a。小 Q 猜测这些数字可能是某种凯撒密码，于是他找来了一堆字符串，请你判断他找来的字符串能否匹配字条上的数字模板。

当字符串 s 同时满足以下所有条件时，视为匹配模板：

  • 字符串 s 的长度等于数组 a 的元素数量。
  • 数组 a 中相同的数字对应字符串 s 中相同的字符。即，若 a_i = a_j，则 s_i = s_j（1 ≤ i, j ≤ n）。
  • 字符串 s 中相同的字符对应数组 a 中相同的数字。即，若 s_i = s_j，则 a_i = a_j（1 ≤ i, j ≤ n）。

换句话说，字符串的字符与数组元素之间必须存在一一对应关系。例如，若 a = [3, 5, 2, 1, 3]，则字符串 "abfda" 匹配模板，而 "afbfa" 不匹配，因为字符 "f" 对应数字 1 和 5。

输入描述

单个测试用例包含多组数据，第一行输入一个整数 t（1 ≤ t ≤ 10^5），表示数据的组数。

对于每组数据： - 第一行包含一个整数 n（1 ≤ n ≤ 2×10^5），表示数组 a 的元素数量； - 第二行包含恰好 n 个整数 a_i（-10^9 ≤ a_i ≤ 10^9），表示数组 a 的元素； - 第三行包含一个整数 m（1 ≤ m ≤ 2×10^5），表示需要检查的字符串数量； - 接下来 m 行，每行包含一个非空字符串 s_i（1 ≤ |s_i| ≤ 2×10^5），由小写字母组成。

保证所有测试用例的 n 之和不超过 2×10^5，所有字符串长度之和不超过 2×10^5。

输出描述

每个测试用例输出 m 行。如果第 i 个字符串匹配模板，第 i 行输出 YES，否则输出 NO（注意输出为大写）。

解题思路

本题考的是「双向唯一映射」的判定：要求数组中的值与字符串中的字符一一对应（既不能一个值对应多个字符，也不能一个字符对应多个值）。 核心做法是用两个哈希表分别维护「值 → 字符」和「字符 → 值」的映射。 逐位扫描：若某个值之前已映射到不同的字符，或某个字符之前已映射到不同的值，说明不满足一一对应，直接返回 false；否则建立映射。 先比较长度，长度不同直接返回 false。 每个测试串独立判断，答案按行输出 YES / NO。

复杂度分析

  • 时间复杂度：O(|s|)，每个字符串只需线性扫描一遍，所有字符串长度之和不超过 2×10^5。
  • 空间复杂度：O(n)，两个哈希表最多存储 n 个不同值/字符的映射。

解题代码

Java 实现

import java.io.*;
import java.util.*;

public class Main {
    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        int t = Integer.parseInt(br.readLine().trim());
        StringBuilder out = new StringBuilder();
        for (int tc = 0; tc < t; tc++) {
            int n = Integer.parseInt(br.readLine().trim());
            StringTokenizer st = new StringTokenizer(br.readLine());
            long[] a = new long[n];
            for (int i = 0; i < n; i++) a[i] = Long.parseLong(st.nextToken());
            int m = Integer.parseInt(br.readLine().trim());
            for (int q = 0; q < m; q++) {
                String s = br.readLine().trim();
                out.append(matches(a, s) ? "YES" : "NO").append('\n');
            }
        }
        System.out.print(out);
    }

    static boolean matches(long[] a, String s) {
        int n = a.length;
        if (s.length() != n) return false;
        HashMap<Long, Character> v2c = new HashMap<>();
        HashMap<Character, Long> c2v = new HashMap<>();
        for (int i = 0; i < n; i++) {
            long v = a[i];
            char c = s.charAt(i);
            Character pc = v2c.get(v);
            if (pc == null) v2c.put(v, c); else if (pc != c) return false;
            Long pv = c2v.get(c);
            if (pv == null) c2v.put(c, v); else if (pv != v) return false;
        }
        return true;
    }
}

Python 实现

import sys

def matches(a, s):
    n = len(a)
    if len(s) != n:
        return False
    v2c = {}
    c2v = {}
    for i in range(n):
        v = a[i]
        c = s[i]
        if v in v2c:
            if v2c[v] != c:
                return False
        else:
            v2c[v] = c
        if c in c2v:
            if c2v[c] != v:
                return False
        else:
            c2v[c] = v
    return True

def main():
    line = sys.stdin.readline()
    if not line:
        return
    t = int(line.strip())
    out = []
    for _ in range(t):
        n = int(sys.stdin.readline().strip())
        a = list(map(int, sys.stdin.readline().split()))
        m = int(sys.stdin.readline().strip())
        for _q in range(m):
            s = sys.stdin.readline().strip()
            out.append('YES' if matches(a, s) else 'NO')
    for v in out:
        print(v)
