# 划分促销区

> 来源：语雀「京东真题题解」（已做 OCR 校对）

## 题目描述

某超市有一排 n 个连续的货架，每个货架上摆放的商品有一个单价。超市计划将这排货架分成 m 个连续的促销区域。每个区域是连续的货架区间，例如可以是第 2-5 个货架，但不能是第 2-3 个和第 5 个货架这样不连续的组合。

每个促销区域的「价格波动值」定义为该区域内商品单价的最大值减去最小值。特别地，如果单独一个货架成为促销区域，那么它的价格波动值为 0。

超市希望所有促销区域的价格波动值之和最小，以此吸引更多顾客。请你帮助他们计算将 n 个货架分成 m 个连续区域后，价格波动值之和的最小值。

## 输入描述

第一行包含两个整数 n 和 m（1 ≤ m ≤ n ≤ 500），分别表示货架的总数和要分成的区域数量。

第二行包含 n 个整数 a_i（1 ≤ a_i ≤ 1,000,000,000），依次表示从左到右每个货架上商品的单价。

## 输出描述

一行，一个整数，表示所有区域的价格波动值之和的最小值。

## 示例

输入：
```
4 2
3 1 4 2
```

输出：
```
3
```

## 说明

一种可行的方法是：将第一个货架分为一个促销区域，将后三个货架分为一个促销区域。促销区 1 的价格波动值为 0，促销区 2 的价格波动值为 3，波动值总和为 3。可以证明没有其他方案可以使波动值总和更小。

## 解题思路

这是一道区间划分 + 动态规划的题。要把 n 个货架切成 m 段连续区间，使「每段最大值 − 最小值」之和最小。
定义 dp[j][i] 表示把前 i 个货架分成 j 段的最小代价，答案为 dp[m][n]。
转移时枚举最后一段的起点 p：该段代价为 a[p..i−1] 的极差（max − min）。
实现时从右向左扩展 p，边扩展边维护当前段的 max、min，即可 O(1) 得到该段极差，逐个枚举切分点。
单独一个货架极差为 0，天然包含在 max − min = 0 中。

## 复杂度分析

- 时间复杂度：O(m·n²)，状态数 O(m·n)，每个状态枚举 O(n) 个切分点。
- 空间复杂度：O(m·n)，即 dp 表的大小。

## 解题代码

### Java 实现

```java
import java.io.*;
import java.util.*;

public class Solution {
    public static void main(String[] args) throws IOException {
        StreamTokenizer in = new StreamTokenizer(new BufferedReader(new InputStreamReader(System.in)));
        in.nextToken(); int n = (int) in.nval;
        in.nextToken(); int m = (int) in.nval;
        long[] a = new long[n];
        for (int i = 0; i < n; i++) { in.nextToken(); a[i] = (long) in.nval; }

        final long INF = Long.MAX_VALUE / 4;
        long[][] dp = new long[m + 1][n + 1];
        for (long[] row : dp) Arrays.fill(row, INF);
        dp[0][0] = 0;
        for (int j = 1; j <= m; j++) {
            for (int i = j; i <= n; i++) {
                long mx = Long.MIN_VALUE, mn = Long.MAX_VALUE;
                long best = INF;
                for (int p = i - 1; p >= j - 1; p--) {
                    long v = a[p];
                    if (v > mx) mx = v;
                    if (v < mn) mn = v;
                    if (dp[j - 1][p] < INF) {
                        long cand = dp[j - 1][p] + (mx - mn);
                        if (cand < best) best = cand;
                    }
                }
                dp[j][i] = best;
            }
        }
        System.out.println(dp[m][n]);
    }
}
```
