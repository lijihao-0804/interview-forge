# 扩展题源说明

本目录保存后续新增题目的持久正文源，不直接作为学习页面发布。

文件名必须使用 `四位题号-题名.md`，正文从 `### 题目与约束` 开始。题号、专题、方法、复杂度和一句话不变量在 `tools/build_hot100.py` 的 `PROBLEM_TSV` 中登记。

## 建议流程

1. 先看 [新增题目正文模板](../04-模板/04-新增题目页面模板.md)，确认专题、前置知识和约束。
2. 在本目录只写 Markdown 正文，保留“信号 → 不变量 → 手算 → 实现 → 反例”的顺序。
3. 按根目录 [维护与扩展指南](../../../MAINTENANCE.md) 登记元数据并执行构建；构建产物不是本目录的正文源。
4. 构建前检查相对链接、代码块围栏、复杂度与实现是否对应；不在本目录存放图片二进制或个人绝对路径。

本目录是“待纳入体系的题源”，不会自动替代 [复习清单](../00-总览/03-复习清单.md)；题目真正进入学习顺序前，还要补专题归属和复习锚点。
