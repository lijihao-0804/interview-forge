哈希表

  • [ ] 1. 两数之和 — 一遍哈希；记忆锚点：先查 target - x，再记录 x，避免元素与自身匹配
  • [ ] 49. 字母异位词分组 — 排序签名 + 哈希分组；记忆锚点：异位词必须映射成同一个稳定签名
  • [ ] 128. 最长连续序列 — 哈希集合找序列起点；记忆锚点：只从不存在 x - 1 的数字开始向右扩展

双指针

  • [ ] 283. 移动零 — 快慢指针原地交换；记忆锚点：slow 始终指向下一个非零元素应放的位置
  • [ ] 11. 盛最多水的容器 — 相向双指针；记忆锚点：移动短板才可能抵消宽度缩小带来的损失
  • [ ] 15. 三数之和 — 排序 + 固定一点 + 双指针；记忆锚点：固定第一数后夹逼，并在三层位置正确去重
  • [ ] 42. 接雨水 — 左右最大值双指针；记忆锚点：较低一侧的蓄水量已由该侧最大边界确定

滑动窗口

  • [ ] 3. 无重复字符的最长子串 — 可变滑动窗口；记忆锚点：窗口内始终无重复，left 只能向右不能回退
  • [ ] 438. 找到字符串中所有字母异位词 — 定长窗口 + 频次表；记忆锚点：窗口长度固定，频次完全匹配时记录左端点

子串

  • [ ] 560. 和为 K 的子数组 — 前缀和 + 频次哈希；记忆锚点：当前前缀为 pre 时，需要此前出现过 pre - k
  • [ ] 239. 滑动窗口最大值 — 单调队列；记忆锚点：队列保存有效下标，且对应值从队首到队尾递减
  • [ ] 76. 最小覆盖子串 — 可变滑动窗口 + 计数；记忆锚点：右扩直到满足，左缩直到刚好不满足

普通数组

  • [ ] 53. 最大子数组和 — Kadane 动态规划；记忆锚点：前一段和为负时不值得被当前位置继承
  • [ ] 56. 合并区间 — 排序 + 线性合并；记忆锚点：每个新区间只需和结果中的最后一个区间比较
  • [ ] 189. 轮转数组 — 三次反转；记忆锚点：整体反转后再分别恢复前 k 段和后 n-k 段的顺序
  • [ ] 238. 除自身以外数组的乘积 — 前缀积 + 后缀积；记忆锚点：答案先保存左侧乘积，再乘滚动的右侧乘积
  • [ ] 41. 缺失的第一个正数 — 原地哈希 / 循环置换；记忆锚点：值 x 的理想位置是下标 x - 1

矩阵

  • [ ] 73. 矩阵置零 — 首行首列原地标记；记忆锚点：首行首列兼作标记，另存它们自身是否需要清零
  • [ ] 54. 螺旋矩阵 — 四边界模拟；记忆锚点：走完一条边立刻收缩对应边界，并防止重复访问
  • [ ] 48. 旋转图像 — 转置 + 每行反转；记忆锚点：转置完成行列交换，水平翻转完成顺时针旋转
  • [ ] 240. 搜索二维矩阵 II — 右上角阶梯搜索；记忆锚点：每次比较都能排除一整行或一整列

链表

  • [ ] 160. 相交链表 — 双指针换头；记忆锚点：两指针各走 A+B 后自然对齐，比较的是节点引用
  • [ ] 234. 回文链表 — 找中点 + 反转后半段；记忆锚点：只比较等长的两半，结束后恢复链表更稳妥
  • [ ] 206. 反转链表 — 迭代三指针；记忆锚点：修改 next 前必须先保存原来的后继
  • [ ] 141. 环形链表 — Floyd 快慢指针；记忆锚点：有环时快指针一定会在环内追上慢指针
  • [ ] 142. 环形链表 II — Floyd 相遇后重置；记忆锚点：相遇后一个回到头部，同速再走会在入口相遇
  • [ ] 21. 合并两个有序链表 — 虚拟头节点 + 尾插；记忆锚点：tail 始终指向已合并部分的最后一个节点
  • [ ] 2. 两数相加 — 逐位模拟 + 进位；记忆锚点：循环条件必须包含两个链表和最后的 carry
  • [ ] 19. 删除链表的倒数第 N 个结点 — 快慢指针 + 虚拟头；记忆锚点：fast 先走 n 步，随后保持固定间距
  • [ ] 24. 两两交换链表中的节点 — 虚拟头 + 局部重连；记忆锚点：每轮保存下一组入口，再按固定顺序改三条指针
  • [ ] 25. K 个一组翻转链表 — 分组检测 + 区间反转；记忆锚点：不足 k 个保持原样；先确定组尾再反转
  • [ ] 138. 随机链表的复制 — 节点穿插复制；记忆锚点：复制节点紧跟原节点，random 可由 original.random.next 得到
  • [ ] 148. 排序链表 — 归并排序；记忆锚点：链表适合通过断链、归并完成稳定排序
  • [ ] 23. 合并 K 个升序链表 — 最小堆多路归并；记忆锚点：堆中始终只放每条链表当前最小的头节点
  • [ ] 146. LRU 缓存 — 哈希表 + 双向链表；记忆锚点：哈希负责定位，双链表负责 O(1) 调整新旧顺序

二叉树

  • [ ] 94. 二叉树的中序遍历 — 递归 / 栈 / Morris；记忆锚点：中序顺序是左—根—右，BST 中对应升序
  • [ ] 104. 二叉树的最大深度 — 后序 DFS；记忆锚点：节点深度等于左右子树最大深度加一
  • [ ] 226. 翻转二叉树 — 递归交换左右子树；记忆锚点：每个节点只做一件事：交换左右孩子
  • [ ] 101. 对称二叉树 — 镜像递归 / 队列；记忆锚点：成对比较外侧与外侧、内侧与内侧
  • [ ] 543. 二叉树的直径 — 后序高度 + 全局答案；记忆锚点：经过当前节点的直径是左高加右高
  • [ ] 102. 二叉树的层序遍历 — BFS 分层；记忆锚点：每轮先固定队列长度，它就是当前层节点数
  • [ ] 108. 将有序数组转换为二叉搜索树 — 分治取中点；记忆锚点：中点作根可同时保证 BST 有序与高度平衡
  • [ ] 98. 验证二叉搜索树 — 上下界递归 / 中序；记忆锚点：约束作用于整棵子树，不只是父子节点
  • [ ] 230. 二叉搜索树中第 K 小的元素 — 中序遍历提前停止；记忆锚点：BST 中序序列严格递增
  • [ ] 199. 二叉树的右视图 — 分层 BFS / 右优先 DFS；记忆锚点：每一层只记录最后访问或最先访问的右侧节点
  • [ ] 114. 二叉树展开为链表 — 逆前序递归；记忆锚点：按右—左—根处理，prev 始终是当前节点应接的后继
  • [ ] 105. 从前序与中序遍历序列构造二叉树 — 前序指针 + 中序索引表；记忆锚点：前序决定根，中序决定左右子树边界
  • [ ] 437. 路径总和 III — 前缀和 DFS；记忆锚点：当前前缀为 sum 时，祖先前缀 sum-target 的次数就是新增路径数
  • [ ] 236. 二叉树的最近公共祖先 — 后序递归；记忆锚点：左右子树各找到一个目标时，当前节点就是最近公共祖先
  • [ ] 124. 二叉树中的最大路径和 — 后序最大贡献；记忆锚点：向上只能贡献一条支路，更新答案时可以同时取左右支路

图论

  • [ ] 200. 岛屿数量 — DFS / BFS 洪泛；记忆锚点：发现陆地就立刻标记并扩展整座岛
  • [ ] 994. 腐烂的橘子 — 多源 BFS；记忆锚点：所有初始腐烂橘子同时作为第 0 分钟入队
  • [ ] 207. 课程表 — Kahn 拓扑排序；记忆锚点：每学完一门课就减少后继入度，最终处理数应等于课程数
  • [ ] 208. 实现 Trie — 前缀树；记忆锚点：路径表示前缀，结束标记区分完整单词与前缀

回溯

  • [ ] 46. 全排列 — 路径 + used 数组；记忆锚点：同一条路径中每个元素只能使用一次
  • [ ] 78. 子集 — 起点索引回溯；记忆锚点：每个递归节点本身就是一个合法子集
  • [ ] 17. 电话号码的字母组合 — 按位选择字符；记忆锚点：递归层数对应电话号码下标
  • [ ] 39. 组合总和 — 排序 + 可重复选择；记忆锚点：允许复用当前数，因此下一层仍从 i 开始
  • [ ] 22. 括号生成 — 计数约束剪枝；记忆锚点：任意前缀中右括号数不能超过左括号数
  • [ ] 79. 单词搜索 — 网格 DFS + 原地标记；记忆锚点：一个格子在同一路径中只能使用一次，返回前恢复
  • [ ] 131. 分割回文串 — 切割回溯 + 回文判断；记忆锚点：只有当前切片是回文串时才进入下一层
  • [ ] 51. N 皇后 — 列与两条对角线约束；记忆锚点：row-col 与 row+col 分别唯一标识两类对角线

二分查找

  • [ ] 35. 搜索插入位置 — lower_bound；记忆锚点：寻找第一个大于等于 target 的下标
  • [ ] 74. 搜索二维矩阵 — 二维下标映射一维；记忆锚点：mid / n 得行，mid % n 得列
  • [ ] 33. 搜索旋转排序数组 — 识别有序半边；记忆锚点：每轮至少有一半有序，再判断 target 是否落在其中
  • [ ] 153. 寻找旋转排序数组中的最小值 — mid 与 right 比较；记忆锚点：nums[mid] > nums[right] 时最小值一定在右侧
  • [ ] 4. 寻找两个正序数组的中位数 — 短数组上二分分割线；记忆锚点：正确分割满足左半最大值不大于右半最小值

栈

  • [ ] 20. 有效的括号 — 栈保存期待的右括号；记忆锚点：遇到右括号时必须与栈顶期待值一致
  • [ ] 155. 最小栈 — 数据栈 + 最小值栈；记忆锚点：辅助栈顶始终是当前所有元素的最小值
  • [ ] 394. 字符串解码 — 保存外层次数与字符串；记忆锚点：遇到 [ 保存现场，遇到 ] 恢复上一层并展开当前层
  • [ ] 739. 每日温度 — 单调递减索引栈；记忆锚点：栈内下标对应温度递减，升温时批量结算
  • [ ] 84. 柱状图中最大的矩形 — 单调递增栈 + 哨兵；记忆锚点：出栈时当前柱子的左右第一个更矮边界已经确定
  • [ ] 232. 用栈实现队列 — 输入栈 + 输出栈；记忆锚点：输出栈为空时才把输入栈全部倒入

堆

  • [ ] 215. 数组中的第K个最大元素 — 大小为 k 的小顶堆 / 快选；记忆锚点：堆顶始终是当前前 k 大中的最小者
  • [ ] 347. 前 K 个高频元素 — 频次表 + 小顶堆；记忆锚点：堆按频次比较，只保留频次最高的 k 个键
  • [ ] 295. 数据流的中位数 — 大顶堆 + 小顶堆；记忆锚点：两堆元素数之差不超过一，且左堆所有值不大于右堆

贪心

  • [ ] 121. 买卖股票的最佳时机 — 维护历史最低价；记忆锚点：卖出当天只需要此前最低买入价
  • [ ] 55. 跳跃游戏 — 维护最远可达位置；记忆锚点：遍历位置必须不超过 farthest
  • [ ] 45. 跳跃游戏 II — 分层最远边界；记忆锚点：到达当前层边界时才增加一步并更新下一层边界
  • [ ] 763. 划分字母区间 — 最后出现位置；记忆锚点：当前片段结束位置是片段内所有字符最后位置的最大值

动态规划

  • [ ] 70. 爬楼梯 — 滚动 Fibonacci；记忆锚点：到第 i 阶只能来自 i-1 或 i-2
  • [ ] 118. 杨辉三角 — 逐行递推；记忆锚点：内部元素来自上一行左上与正上方
  • [ ] 198. 打家劫舍 — 选或不选滚动状态；记忆锚点：dp[i] 只比较跳过当前与偷当前两种选择
  • [ ] 279. 完全平方数 — 完全背包；记忆锚点：dp[i] 从所有不超过 i 的平方数转移
  • [ ] 322. 零钱兑换 — 完全背包最小值；记忆锚点：正序遍历容量允许同一枚硬币重复使用
  • [ ] 139. 单词拆分 — 前缀可达性；记忆锚点：dp[i] 表示前 i 个字符是否可由字典组成
  • [ ] 300. 最长递增子序列 — DP / 贪心二分；记忆锚点：tails[len] 保存该长度递增子序列最小可能结尾
  • [ ] 152. 乘积最大子数组 — 同时维护最大积与最小积；记忆锚点：负数会交换最大与最小角色
  • [ ] 416. 分割等和子集 — 0-1 背包；记忆锚点：容量倒序保证每个数字只使用一次
  • [ ] 32. 最长有效括号 — 以右括号结尾的 DP；记忆锚点：dp[i] 只表示必须以 i 结尾的最长有效长度

多维动态规划

  • [ ] 62. 不同路径 — 网格路径计数；记忆锚点：当前位置方案数来自上方与左方
  • [ ] 64. 最小路径和 — 网格最小代价；记忆锚点：当前位置最小代价来自上方和左方较小者
  • [ ] 5. 最长回文子串 — 区间 DP / 中心扩展；记忆锚点：两端字符相同且内部是回文，当前区间才是回文
  • [ ] 1143. 最长公共子序列 — 双序列 DP；记忆锚点：字符相同取左上加一，否则取上方与左方最大值
  • [ ] 72. 编辑距离 — 双序列 DP；记忆锚点：最后字符相同不付代价，否则从增删改三种操作取最小

技巧

  • [ ] 136. 只出现一次的数字 — 异或消去；记忆锚点：x xor x = 0，且 0 xor x = x
  • [ ] 169. 多数元素 — Boyer-Moore 投票；记忆锚点：不同元素两两抵消后，多数元素仍会剩下
  • [ ] 75. 颜色分类 — 荷兰国旗三指针；记忆锚点：[0,left) 是 0，[left,i) 是 1，(right,n) 是 2
  • [ ] 31. 下一个排列 — 找拐点、交换、反转后缀；记忆锚点：从右侧找到仍可增大的最靠右位置，并使用最小增量
  • [ ] 287. 寻找重复数 — Floyd 隐式链表；记忆锚点：把下标到数值看作 next 指针，重复值就是环入口
