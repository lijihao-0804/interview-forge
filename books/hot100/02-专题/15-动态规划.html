Java 模式：动态规划

识别信号

最优值、方案数、可达性，且子问题重复。

先写状态定义，再写转移；不要从代码循环反推 dp 含义。

Java 核心不变量

状态含义、转移来源、初始化、遍历顺序缺一不可。

下笔顺序

  1. 状态是什么
  2. 答案从哪些更小状态来
  3. 边界如何初始化
  4. 遍历顺序是否满足依赖
  5. 能否压缩空间

工具箱

线性 DP、完全背包、0-1 背包、序列 DP。完整模板见 Hot 100 算法模板。

Python 模式：动态规划

动态规划先写状态含义，再写转移、初始化与遍历方向；空间压缩必须保留转移真正需要的旧状态。

状态表里到底保存什么

416 题的目标是判断能否选出一些元素，使它们的和正好等于总和的一半。以 nums = [1,5,11,5] 为例，总和为 22，目标为 11。

先用“可达和集合”理解：初始只有 {0}；处理 1 后是 {0,1}；处理第一个 5 后是 {0,1,5,6}；处理 11 时新增 11,12,16,17，已经包含目标 11；最后一个 5 也保留这一可达性。

一维数组只是把这些集合铺成布尔表：reachable[s] 表示是否存在一组已处理元素，和恰好为 s。处理新元素 value 时，可以从旧的 s - value 来到 s。

Python 模板：一维 0-1 背包可达性

模板解决 416 题：每个元素最多使用一次，目标是恰好凑出数组总和的一半。完全背包、序列 DP 和区间 DP 的遍历方向不同，需要重新推导。 300 题逐题抓手采用以每个位置结尾的 O(n²) DP，tails + bisect_left 只作扩展。

参考来源：灵茶山艾府题解（MIT License）

def can_partition(nums: list[int]) -> bool:
    total = sum(nums)
    if total % 2:
        return False
    target = total // 2
    reachable = [False] * (target + 1)
    reachable[0] = True
    for value in nums:
        for capacity in range(target, value - 1, -1):
            reachable[capacity] = reachable[capacity] or reachable[capacity - value]
    return reachable[target]

为什么容量必须倒序

如果容量从小到大更新，reachable[s - value] 可能已经在本轮被当前元素修改，于是同一个数字被用了多次。倒序时，较小容量还没在本轮更新，读到的是上一轮状态，正好对应“每个元素最多一次”。

总和为奇数时无法拆成两个整数和，提前返回 False。总和为偶数时，初始化 reachable[0] = True 表示什么都不选可以凑出 0。

时间和目标容量与元素数有关，为 O(n·target)；一维表占 O(target)。

本专题逐题抓手

题目 Python 主方法 时间 空间 本题抓手
70. 爬楼梯 滚动 Fibonacci DP O(n) O(1) 滚动 Fibonacci DP。到达第 i 阶的方法数只依赖 i-1 与 i-2 两步。
118. 杨辉三角 逐行递推杨辉三角 O(n²) O(n²)（包含输出） 逐行递推杨辉三角。每行首尾为 1，内部第 c 项等于上一行 c-1 与 c 两项之和。
198. 打家劫舍 打家劫舍滚动 DP O(n) O(1) 打家劫舍滚动 DP。处理到第 i 家时，skip 是不偷当前家的最优值，take 是偷当前家的最优值。
279. 完全平方数 完全背包最少平方数 O(n√n) O(n) 完全背包最少平方数。dp[x] 表示和为 x 的最少完全平方数个数，x 可由 x - j² 再加一个平方数得到。
322. 零钱兑换 完全背包最少硬币 O(amount·coins) O(amount) 完全背包最少硬币。dp[x] 表示凑出金额 x 的最少硬币数；x - coin 的值加一可以得到 x。
139. 单词拆分 前缀可达性 DP + startswith 按位置匹配 O(D + n·W·Lmax) O(n + W) 前缀可达性 DP + startswith 按位置匹配。reachable[end] 为真，表示 s[0:end] 能由字典单词完整切分。
300. 最长递增子序列 以每个位置结尾的最长递增子序列 DP O(n²) O(n) dp[i] 表示以 nums[i] 结尾的最长递增子序列长度，向前查找比自己小的末尾值；主解 O(n²)。
152. 乘积最大子数组 同时维护最大与最小结尾乘积 O(n) O(1) 同时维护最大与最小乘积。以当前位置结尾的最大/最小乘积只由上一位置最大/最小乘积与当前值产生。
416. 分割等和子集 0-1 背包可行性 O(n·target) O(target) 0-1 背包可行性。dp[s] 表示从已处理元素中选出一部分能否正好得到和 s；每个元素只能使用一次。
32. 最长有效括号 未匹配下标与基准单调栈 O(n) O(n) 无效右括号基准栈。栈底保存最近一个无法匹配的右括号下标；当前下标与栈顶之差是一段合法候选长度。
