## Java 模式：多维动态规划

### 识别信号

两个序列、二维网格或区间状态。

二维表的每个坐标必须有一句完整定义，否则转移方向很容易写反。

### Java 核心不变量

> 每个维度必须对应一个明确前缀、位置或区间。

### 下笔顺序

1. 画出 3×3 小表
2. 填第一行和第一列
3. 标出当前格依赖的方向
4. 最后再考虑滚动数组

### 工具箱

网格 DP、区间 DP、双序列 DP。完整模板见 [Hot 100 算法模板](../04-模板/01-Hot100算法模板.md)。

## Python 模式：多维动态规划

二维 DP 的每个坐标都要有一句完整定义；先填边界，再确认当前格只依赖已经完成的相邻状态。

### 每个格子的答案只从前两个格子来

对 `[[1,3,1],[1,5,1],[4,2,1]]` 逐行填表：

1. 第一行只能向右：`[1, 4, 5]`。
2. 第二行第一列只能向下：`1 + 1 = 2`；中间格取上方 4、左方 2 的最小值 2，再加 5 得 7；右格为 `min(5,7)+1 = 6`。
3. 第三行第一列为 `4+2=6`；中间格为 `min(7,6)+2=8`；终点为 `min(6,8)+1=7`。

完整表为：

```text
1  4  5
2  7  6
6  8  7
```

最终答案是右下角 7。第一行与第一列必须单独初始化，因为它们只有一个前驱；若从 `(0,0)` 统一循环，就需要额外的越界分支。

### Python 模板：网格最小路径和

模板解决非空网格的 64 题，保留完整二维表以便逐步核对。它没有修改输入；若使用一维滚动，必须把“上方旧值”与“左方新值”分别保存。

> 参考来源：经典解法实现


```python
def min_path_sum(grid: list[list[int]]) -> int:
    rows = len(grid)
    cols = len(grid[0])
    dp = [[0] * cols for _ in range(rows)]
    dp[0][0] = grid[0][0]
    for col in range(1, cols):
        dp[0][col] = dp[0][col - 1] + grid[0][col]
    for row in range(1, rows):
        dp[row][0] = dp[row - 1][0] + grid[row][0]
    for row in range(1, rows):
        for col in range(1, cols):
            dp[row][col] = grid[row][col] + min(
                dp[row - 1][col], dp[row][col - 1]
            )
    return dp[rows - 1][cols - 1]
```


### 二维列表与转移方向

先用 `[[0] * cols for _ in range(rows)]` 创建独立行。`dp[row - 1][col]` 是上方，`dp[row][col - 1]` 是左方，两者都已在当前格之前算好。

64 题也可原地覆盖 `grid`，把额外空间降到 O(1)，代价是输入被修改。1143 和 72 题处理两个字符串前缀时，通常只需上一行与当前行，但必须保存左上角的旧值。

完整表有 O(rows × cols) 个状态，每个格子常数时间，因此时间与空间（未压缩时）都是 O(rows × cols)。

### 本专题逐题抓手

| 题目 | Python 主方法 | 时间 | 空间 | 本题抓手 |
|---|---|---|---|---|
| **[62. 不同路径](../03-题解/16-多维动态规划/0062-不同路径.md)** | 一维滚动路径 DP | O(m·n) | O(n) | 一维组合 DP。处理下一行前，dp[col] 表示到达上一行该格的路径数；更新后表示当前行。 |

| **[1143. 最长公共子序列](../03-题解/16-多维动态规划/1143-最长公共子序列.md)** | 双序列二维前缀 DP | O(m·n) | O(m·n) | 二维最长公共子序列 DP。`dp[i][j]` 表示两个字符串前 i、j 个字符的最长公共子序列；末尾相同走左上角加一，不同则取上方或左方。 |
| **[72. 编辑距离](../03-题解/16-多维动态规划/0072-编辑距离.md)** | 双序列二维编辑距离 DP | O(m·n) | O(m·n) | 二维编辑距离 DP。`dp[i][j]` 表示两个前缀间的最少编辑次数；删、插、换分别对应上方、左方与左上角来源，末尾相同直接继承。 |
