# 多维动态规划

[总目录](../../../README.md) · [算法模式地图](../00-总览/02-算法模式地图.md)

## 识别信号

两个序列、二维网格或区间状态。

二维表的每个坐标必须有一句完整定义，否则转移方向很容易写反。

## 核心不变量

> 每个维度必须对应一个明确前缀、位置或区间。

## 下笔顺序

1. 画出 3×3 小表
2. 填第一行和第一列
3. 标出当前格依赖的方向
4. 最后再考虑滚动数组

## 工具箱

网格 DP、区间 DP、双序列 DP。完整 Java 模板见 [Hot 100 算法模板](../04-模板/01-Hot100算法模板.md)。

## 复习标准

- 能在 30 秒内说出每题的核心不变量。
- 能不看答案写出主循环或递归函数签名。
- 能解释为什么移动指针、弹栈、剪枝或状态转移不会漏解。
- 能主动写出至少 3 个边界用例。
