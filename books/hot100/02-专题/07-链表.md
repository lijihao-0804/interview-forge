# 链表

[总目录](../../../README.md) · [算法模式地图](../00-总览/02-算法模式地图.md)

## 识别信号

节点交换、区间反转、环、相交、缓存结构。

链表算法的难点是引用变化；画出局部的前驱、当前、后继比背代码可靠。

## 核心不变量

> 改 next 前先保存后继；复杂操作优先使用虚拟头节点。

## 下笔顺序

1. 优先添加 dummy
2. 改 next 前保存断开后仍需要的节点
3. 返回头节点前检查头部是否发生变化

## 工具箱

虚拟头、快慢指针、局部反转、归并、哈希+双链表。完整 Java 模板见 [Hot 100 算法模板](../04-模板/01-Hot100算法模板.md)。
