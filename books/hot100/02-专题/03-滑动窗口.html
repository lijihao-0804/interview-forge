Java 模式：滑动窗口

识别信号

连续区间、最长/最短、窗口内满足某个条件。

窗口只适合连续区间；关键在于条件能否随着左右端移动被增量维护。

Java 核心不变量

右端负责纳入，左端只在不变量被破坏或答案可收缩时移动。

下笔顺序

  1. 右端加入元素并更新状态
  2. while 循环收缩左端
  3. 在正确时机更新最长或最短答案

工具箱

定长窗口、可变窗口、频次表。完整模板见 Hot 100 算法模板。

Python 模式：滑动窗口

滑动窗口维护一段连续区间；右端加入新元素，左端只在不变量被破坏或需要缩短时移动。

右端扩张，左端只向右

以 s = "abcabcbb" 为例，last[ch] 保存字符最近一次出现的下标：

  1. 依次读入 a, b, c，窗口扩成 abc，best = 3。
  2. 再读到下标 3 的 a。最近位置是 0，所以 left = max(0, 0 + 1) = 1，窗口变为 bca。
  3. 下标 4 的 b 让 left 跳到 2；下标 5 的 c 再让 left 跳到 3。
  4. 下标 6 的 b 使 left 跳到 5，窗口只剩 cb；下标 7 又读到 b，窗口只剩当前的 b。

对 abba，最后处理 a 时字典仍记着旧位置 0。直接写 left = last[ch] + 1 会把左边界从 2 退回 1；max(left, ...) 则保住 2，窗口仍是 ba。因此左边界只会向前。

Python 模板：最近位置窗口

模板解决“无重复字符的最长子串”。它适合用最近位置一次跳转左端；438 题是固定长度频次窗口，76 题是最小覆盖窗口，移除步骤和答案更新时机都不同。

参考来源：代码随想录（programmercarl.com）

def length_of_longest_substring(s: str) -> int:
    last = {}
    left = 0
    best = 0
    for right, ch in enumerate(s):
        if ch in last:
            left = max(left, last[ch] + 1)
        last[ch] = right
        best = max(best, right - left + 1)
    return best

为什么字典不必逐项删除

last 记录“最近位置”，不是当前窗口的完整频次表。旧位置若已经在 left 左侧，max 会忽略它，所以不需要在移动左端时逐字符改字典。

顺序固定为：遇到旧字符时调整 left，写入当前字符的新位置，再用 right - left + 1 更新答案。写入被放到边界更新之后，否则会读到当前位置而错误缩短窗口。

扫描一次且左右边界都只向右，时间为 O(n)；字典最多保存不同字符的最近位置，空间为 O(min(n, 字符集大小))。
