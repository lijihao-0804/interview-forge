总目录 · 算法模式地图

识别信号

位运算、投票、三路划分、排列、隐式链表。

这组题不依赖统一数据结构，重点是识别隐藏模型并记住证明。

核心不变量

先识别题目隐藏的数据结构或数学不变量。

下笔顺序

  1. 位运算先列恒等式
  2. 投票法先说抵消含义
  3. 三路划分画出四个区间
  4. 排列题从字典序定义推导

工具箱

异或、投票、三路划分、字典序、隐式链表。完整 Java 模板见 Hot 100 算法模板。

练习顺序

顺序 题目 难度 主方法 时间 / 空间
1 136. 只出现一次的数字 简单 异或消去 O(n) / O(1)
2 169. 多数元素 简单 Boyer-Moore 投票 O(n) / O(1)
3 75. 颜色分类 中等 荷兰国旗三指针 O(n) / O(1)
4 31. 下一个排列 中等 找拐点、交换、反转后缀 O(n) / O(1)
5 287. 寻找重复数 中等 Floyd 隐式链表 O(n) / O(1)

复习标准

  • 能在 30 秒内说出每题的核心不变量。
  • 能不看答案写出主循环或递归函数签名。
  • 能解释为什么移动指针、弹栈、剪枝或状态转移不会漏解。
  • 能主动写出至少 3 个边界用例。
