识别信号

出现“快速查找、计数、分组、去重”时先想哈希结构。

键必须代表可稳定复用的特征；值保存下标、频次、分组或状态。

核心不变量

把已经处理过的信息压成可 O(1) 查询的键。

下笔顺序

  1. 先决定查什么，再决定 key
  2. 若依赖此前信息，通常先查后存
  3. 对象作 key 时确保 equals/hashCode 稳定

工具箱

计数、补数查找、规范化签名、集合边界。完整 Java 模板见 Hot 100 算法模板。

练习顺序

顺序 题目 难度 主方法 时间 / 空间
1 1. 两数之和 简单 一遍哈希 O(n) / O(n)
2 49. 字母异位词分组 中等 排序签名 + 哈希分组 O(n·k log k) / O(n·k)
3 128. 最长连续序列 中等 哈希集合找序列起点 O(n) / O(n)

复习标准

  • 能在 30 秒内说出每题的核心不变量。
  • 能不看答案写出主循环或递归函数签名。
  • 能解释为什么移动指针、弹栈、剪枝或状态转移不会漏解。
  • 能主动写出至少 3 个边界用例。
