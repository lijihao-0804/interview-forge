Java 模式：回溯

识别信号

枚举所有组合、排列、切分或棋盘方案。

回溯 = 枚举决策树；剪枝来自题目约束，而不是凭感觉提前 return。

Java 核心不变量

路径是当前选择，选择列表是下一步范围，返回前必须恢复现场。

下笔顺序

  1. 明确 path、选择范围、终止条件
  2. 做选择
  3. 递归
  4. 撤销选择

工具箱

排列、子集、组合、切割、棋盘。完整模板见 Hot 100 算法模板。

复习标准

  • 能在 30 秒内说出每题的核心不变量。
  • 能不看答案写出主循环或递归函数签名。

  • 能主动写出至少 3 个边界用例。

Python 模式：回溯

回溯把题目写成一棵决策树：当前路径、下一层候选、终止条件与撤销动作共同决定搜索结果。

每个递归节点都是一个子集

对 nums = [1, 2]，从 start = 0 开始：

  1. 进入根节点，先把空路径 [] 复制进答案。
  2. 选择 1，路径变成 [1]，下一层从下标 1 开始；再次复制得到 [1]。
  3. 在 [1] 分支再选择 2，得到 [1,2]；返回后弹出 2，恢复 [1]。
  4. 根节点弹出 1，改为选择 2，得到 [2]；返回后路径恢复为空。

最终答案包含 []、[1]、[1,2]、[2]。start 只允许向后选，所以不会又生成 [2,1]。

“恢复现场”在恢复什么

路径列表是共享的工作区。每次递归返回时，必须把这一层刚追加的元素弹出；否则下一次循环会在别人的路径上继续添加。输入网格题常用临时标记代替 pop，但恢复动作仍不可少。

Python 模板：起点索引子集树

模板解决元素互不相同的 78 题子集。start 保证只向后选，避免同一种子集换顺序重复；全排列、可重复组合和棋盘回溯需要各自的选择与剪枝条件。

参考来源：代码随想录（programmercarl.com）

def subsets(nums: list[int]) -> list[list[int]]:
    answer = []
    path = []

    def backtrack(start: int) -> None:
        answer.append(path[:])
        for index in range(start, len(nums)):
            path.append(nums[index])
            backtrack(index + 1)
            path.pop()

    backtrack(0)
    return answer

Python 快照与递归边界

answer.append(path[:]) 复制当前路径；若直接追加 path，答案里的每一项最终都会指向同一个列表。

backtrack(start) 先记录当前节点，再枚举 start 之后的元素。区间 range(start, len(nums)) 为空时循环自然结束，不需要单独的“失败”分支。

本题共 2ⁿ 个答案；复制每个长度为 O(n) 的路径使总时间为 O(n·2ⁿ)。递归路径和调用栈占 O(n)，答案本身按题目输出另计。

本专题逐题抓手

题目 Python 主方法 时间 空间 本题抓手
46. 全排列 路径与 used 下标全排列 O(n·n!) O(n) 路径 + used 数组全排列。path 中每个输入下标至多出现一次；达到长度 n 时形成一个完整排列。
78. 子集 起点索引子集回溯 O(n·2ⁿ) O(n) 起点索引子集回溯。每个递归节点都是一个合法子集；start 之后的选择保证组合按输入顺序不重复。
17. 电话号码的字母组合 按电话号码逐位枚举字母 O(n·4ⁿ) O(n) 逐位枚举字符回溯。递归深度等于 digits 的下标；path 长度恰为已处理的位数。
39. 组合总和 排序后可重复起点回溯 O(n log n + V) O(n + target/min(candidates)) 排序 + 可重复起点回溯。余数 remaining 只由当前和决定；每层从 index 开始，允许重复当前数但禁止回到更小下标。
22. 括号生成 左右括号计数剪枝回溯 O(n·Cₙ) O(n) 左右括号计数回溯。任意前缀都有 left >= right，且 left、right 都不超过 n。
79. 单词搜索 网格 DFS 原位标记回溯 O(m·n·3ᴸ) O(L) 网格 DFS + 原位标记回溯。递归下标 i 之前，路径恰好匹配 word[0:i]，当前格子在本路径中只使用一次。
131. 分割回文串 回文切片回溯 O(n·2ⁿ) O(n) 回文切片回溯。path 保存的分片按原顺序无重叠地覆盖 s[0:start]，下一层从切片右端加一开始。
51. N 皇后 列与双对角线集合回溯 O(n·n! + n²·S) O(n) 列与双对角线集合回溯。逐行放皇后；columns、diag1、diag2 分别保证同列、左上右下、右上左下不冲突。
