总目录 · 算法模式地图

识别信号

枚举所有组合、排列、切分或棋盘方案。

回溯 = 枚举决策树；剪枝来自题目约束，而不是凭感觉提前 return。

核心不变量

路径是当前选择，选择列表是下一步范围，返回前必须恢复现场。

下笔顺序

  1. 明确 path、选择范围、终止条件
  2. 做选择
  3. 递归
  4. 撤销选择

工具箱

排列、子集、组合、切割、棋盘。完整 Java 模板见 Hot 100 算法模板。

练习顺序

顺序 题目 难度 主方法 时间 / 空间
1 46. 全排列 中等 路径 + used 数组 O(n·n!) / O(n)
2 78. 子集 中等 起点索引回溯 O(n·2ⁿ) / O(n)
3 17. 电话号码的字母组合 中等 按位选择字符 O(4ⁿ) / O(n)
4 39. 组合总和 中等 排序 + 可重复选择 指数级 / O(target)

8 51. N 皇后 困难 列与两条对角线约束 O(n!) / O(n)

复习标准

  • 能在 30 秒内说出每题的核心不变量。
  • 能不看答案写出主循环或递归函数签名。
  • 能解释为什么移动指针、弹栈、剪枝或状态转移不会漏解。
  • 能主动写出至少 3 个边界用例。
