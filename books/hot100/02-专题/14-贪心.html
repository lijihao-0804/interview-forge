Java 模式：贪心

识别信号

每一步能安全丢弃历史、维护最远边界或局部最优。

贪心解法必须有排除证明：被丢掉的选择以后不可能更优。

Java 核心不变量

必须说明局部选择为何不会损失全局最优。

下笔顺序

  1. 定义当前维护的最优边界
  2. 说明何时提交一次选择
  3. 用反证或交换论证局部选择安全

工具箱

历史最优、最远边界、分段边界。完整模板见 Hot 100 算法模板。

Python 模式：贪心

贪心每一步提交局部选择，并由交换或反证说明被放弃的选择不会让未来更优。

到当前为止，最低买点足够回答今天

对 prices = [7,1,5,3,6,4]：

今天价格 截至今天最低价 今天卖出的利润 历史最好利润
7 7 0 0
1 1 0 0
5 1 4 4
3 1 2 4
6 1 5 5
4 1 3 5

以今天卖出时，未来信息没有用途；所有合法买点中，最低价必然给出最大利润。维护最低价和当前最好利润就足够，不需要保存整张按天状态表。

最远边界也是同一种滚动状态

跳跃游戏题保存“已经扫描的位置能到达的最远下标”，只要当前位置没越过它就能继续扩展；如果最远下标停在终点之前，就不可达。这里的证明是：所有能到达的位置都已扫描，边界之外的下一格没有任何路径可进入。

Python 模板：历史最低价滚动

模板解决 121 题：只能先买后卖且交易一次。lowest 包含当天价格，但当天卖出利润为 0；跳跃游戏和字符分段使用不同的最远边界，不能直接套用。

参考来源：代码随想录（programmercarl.com）

def max_profit(prices: list[int]) -> int:
    lowest = float("inf")
    best = 0
    for price in prices:
        lowest = min(lowest, price)
        best = max(best, price - lowest)
    return best

顺序与边界

先更新 lowest，再用它计算当日利润，得到的总是“当天或之前买入、当天卖出”的最好结果；当天利润最小为 0，因此 best 不会为负。

只有一个价格时循环执行一次，利润为 0。缺少买入或卖出交易的题目答案通常规定为 0，模板与这一约定一致。

扫描一次、只保存两个标量，时间 O(n)，额外空间 O(1)。贪心的难点在正确性说明，不是代码长度。

121. 买卖股票的最佳时机 历史最低价一次扫描 O(n) O(1) 历史最低价贪心。扫描当天价格后，lowest 是截至当天的最低买入价；用当天价格卖出时，最低买价给出截至当天的最好收益。
