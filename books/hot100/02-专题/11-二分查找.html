Java 模式：二分查找

识别信号

有序、单调、答案可判定。

二分最怕区间语义混用；模板不重要，循环不变量最重要。

Java 核心不变量

先写清搜索区间语义，再让每个分支严格缩小区间。

下笔顺序

  1. 写出答案可能存在的区间
  2. 判断 mid 后排除不可能半边
  3. 保证区间严格缩小
  4. 退出后解释 left/right 指向什么

工具箱

精确查找、lower_bound、旋转数组、二分答案。完整模板见 Hot 100 算法模板。

Python 模式：二分查找

二分查找先固定区间的开闭语义，再用单调条件排除一半候选；每一轮都必须严格缩小。

用 [left, right) 锁定下界

在 nums = [1, 3, 5, 7] 中查找 target = 4：

left right middle 与值 新候选区间
0 4 2, 值 5 [0, 2)
0 2 1, 值 3 [2, 2)

循环结束时 left = 2，正是 4 应插入的位置。right 从一开始就是“不包含”的边界，因此初值是 len(nums)，不是最后一个下标。

重复值可直接看出左右边界：在 [1,2,2,2,3] 中，bisect_left(..., 2) 返回 1，bisect_right(..., 2) 返回 4，重复区间是 [1, 4)。

Python 模板：右开区间下界

模板返回排序数组 nums 中第一个大于等于 target 的下标；没有任何元素满足时返回 len(nums)。右开区间模板不能随意改成 left <= right。

参考来源：代码随想录（programmercarl.com）

def lower_bound(nums: list[int], target: int) -> int:
    left = 0
    right = len(nums)
    while left < right:
        middle = (left + right) // 2
        if nums[middle] < target:
            left = middle + 1
        else:
            right = middle
    return left

手写与库函数怎样对应

手写模板中，nums[middle] < target 时，middle 本身不可能成为下界，所以 left = middle + 1；否则 middle 仍可能是答案，保留为 right = middle。

bisect_left 直接返回下界，bisect_right 返回第一个严格大于目标的位置。若数组可能已经整体小于目标，返回长度是合法插入位置；若目标整体小于数组，返回 0。

每次候选长度至少减半，时间 O(log n)，只有两个整数下标，额外空间 O(1)。

本专题逐题抓手

题目 Python 主方法 时间 空间 本题抓手
35. 搜索插入位置 闭区间二分找插入下界 O(log n) O(1) 闭区间二分下界。循环维持 [0, left) 都小于 target，[left, right] 仍可能达到或超过 target；left > right 时 left 就是插入位置。
74. 搜索二维矩阵 二维坐标映射的一维二分 O(log(m·n)) O(1) 二维映射一维二分。若把矩阵按行拼接，下标 mid 唯一映射为 row=mid//cols、col=mid%cols。
34. 在排序数组中查找元素的第一个和最后一个位置 两次二分寻找左右边界 O(log n) O(1) 左右边界二分。lower_bound 找第一个 >= target，upper_bound 找第一个 > target。
33. 搜索旋转排序数组 识别旋转数组的有序半边 O(log n) O(1) 识别旋转数组的有序半边。每轮至少有一半在数值上连续有序，可以先判断 target 是否落在这半区间。
153. 寻找旋转排序数组中的最小值 与右端比较的二分逼近最小值 O(log n) O(1) 与右端比较的二分。nums[mid] > nums[right] 时最小值严格在 mid 右侧，否则在 [left, mid]。
4. 寻找两个正序数组的中位数 短数组上二分分割线 O(log min(m,n)) O(1) 短数组上二分分割线。分割线左侧共有 half 个元素，且 a_left <= b_right、b_left <= a_right。
