总目录 · 算法模式地图

识别信号

有序、单调、答案可判定。

二分最怕区间语义混用；模板不重要，循环不变量最重要。

核心不变量

先写清搜索区间语义，再让每个分支严格缩小区间。

下笔顺序

  1. 写出答案可能存在的区间
  2. 判断 mid 后排除不可能半边
  3. 保证区间严格缩小
  4. 退出后解释 left/right 指向什么

工具箱

精确查找、lower_bound、旋转数组、二分答案。完整 Java 模板见 Hot 100 算法模板。

练习顺序

顺序 题目 难度 主方法 时间 / 空间
1 35. 搜索插入位置 简单 lower_bound O(log n) / O(1)
2 74. 搜索二维矩阵 中等 二维下标映射一维 O(log(mn)) / O(1)
3 33. 搜索旋转排序数组 中等 识别有序半边 O(log n) / O(1)
4 153. 寻找旋转排序数组中的最小值 中等 mid 与 right 比较 O(log n) / O(1)
5 4. 寻找两个正序数组的中位数 困难 短数组上二分分割线 O(log min(m,n)) / O(1)

复习标准

  • 能在 30 秒内说出每题的核心不变量。
  • 能不看答案写出主循环或递归函数签名。
  • 能解释为什么移动指针、弹栈、剪枝或状态转移不会漏解。
  • 能主动写出至少 3 个边界用例。
