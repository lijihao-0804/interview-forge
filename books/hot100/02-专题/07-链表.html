Java 模式：链表

识别信号

节点交换、区间反转、环、相交、缓存结构。

链表算法的难点是引用变化；画出局部的前驱、当前、后继比背代码可靠。

Java 核心不变量

改 next 前先保存后继；复杂操作优先使用虚拟头节点。

下笔顺序

  1. 优先添加 dummy
  2. 改 next 前保存断开后仍需要的节点
  3. 返回头节点前检查头部是否发生变化

工具箱

虚拟头、快慢指针、局部反转、归并、哈希+双链表。完整模板见 Hot 100 算法模板。

Python 模式：链表

链表题先画前驱、当前与后继。修改 next 前保存后路，复杂重连优先用虚拟头节点固定入口。

改方向之前，先记住后路

以 1 -> 2 -> 3 -> None 为例，初始 previous = None、current = 1。每一轮严格做四步：

  1. following = current.next：第一轮先记住节点 2。
  2. current.next = previous：让节点 1 指向 None。
  3. previous = current：已反转前缀的新头移到节点 1。
  4. current = following：下一轮处理节点 2，后路仍然找得到。

处理后两轮时，已反转部分依次变为 2 -> 1 -> None 和 3 -> 2 -> 1 -> None。current 最终为 None，previous 停在节点 3，所以返回 previous。

虚拟头节点解决什么

当删除或交换可能改变真正的头节点时，先创建 dummy.next = head。这样每轮只重连 previous.next，返回 dummy.next 即可，不必为“是否在头部操作”写两套分支。

Python 模板：四步原地反转

模板解决 206 反转链表；ListNode 由力扣判题入口提供，本地运行时可传入任意具有 next 属性的节点对象。它原地改链，调用后原头会变成尾。

参考来源：代码随想录（programmercarl.com）

from typing import Optional


def reverse_list(head: Optional["ListNode"]) -> Optional["ListNode"]:
    previous = None
    current = head
    while current is not None:
        following = current.next
        current.next = previous
        previous = current
        current = following
    return previous

Python 引用与判题环境

following 保存的是节点引用，不是复制出来的节点。赋值 current.next = previous 会原地修改节点；已保存的 following 仍然能带我们走到原后继。

力扣链表题的代码块通常由平台提供 ListNode，提交时无需重新定义。本模板用字符串形式的前向类型名 "ListNode"，因此把函数拿到本地测试环境也能先定义并运行。

每轮只有常数次引用赋值，时间 O(n)；没有新建节点，除几个引用外空间 O(1)。

本专题逐题抓手

题目 Python 主方法 时间 空间 本题抓手
160. 相交链表 双指针换头对齐 O(m+n) O(1) 双指针换头对齐。两个指针走过的路径都由本链表与另一条链表的全部节点组成。
206. 反转链表 迭代三指针原地反转 O(n) O(1) 每轮显式做四步：保存 following、反转 current.next、推进 previous、推进 current；空链表直接返回 None。
234. 回文链表 快慢找中点 + 原地反转后半段 O(n) O(1) 找中点 + 原地反转后半段。反转后的后半段与从头部出发的前半段逐个节点比较，直到后半段耗尽。
141. 环形链表 Floyd 快慢指针判环 O(n) O(1) Floyd 快慢指针判环。无环时快指针先到空；有环时两指针都在环内，速度差一会使距离缩短到零。
142. 环形链表 II Floyd 相遇后同速找入口 O(n) O(1) Floyd 相遇后重置找入口。相遇后两个同速指针分别从头和相遇点出发，会在环入口第一次相遇。
21. 合并两个有序链表 虚拟头节点双路归并 O(m+n) O(1) 虚拟头节点双路归并。tail 始终指向已归并结果最后一个节点，两条源链表各自仍保持有序。
2. 两数相加 逐位相加 + 进位 O(max(m,n)) O(1)（不含输出链表） 逐位相加 + 进位。每轮当前位的和等于两个输入位上数字与上一轮进位的和。
19. 删除链表的倒数第 N 个结点 虚拟头 + 固定间距快慢指针 O(L) O(1) 虚拟头 + 固定间距快慢指针。fast 先走 n+1 步后，fast 与 slow 之间的距离始终让 slow 停在待删节点前驱。
24. 两两交换链表中的节点 虚拟头 + 固定顺序局部重连 O(n) O(1) 虚拟头 + 固定顺序局部重连。previous.next 始终指向当前待交换的一对节点；每轮按固定顺序重连后前进两步。
25. K 个一组翻转链表 分组探测 + 组内头插反转 O(n) O(1) 分组探测 + 组内头插反转。previous_group 指向上一组尾节点；只有从它向后能找到 k 个节点时才翻转当前组。
138. 随机链表的复制 原链表穿插复制 + 三趟拆分 O(n) O(1)（不计新建的输出节点） 原链表穿插复制。每个复制节点紧跟其原节点，因此原节点的 random 后一个节点就是复制节点对应的 random。
148. 排序链表 自顶向下归并排序 O(n log n) O(log n)（递归调用栈；不计输入输出） 自顶向下归并排序。快慢指针在 slow.next 处切成两段，递归排序后用 dummy 合并；递归栈深度为 O(log n)。
23. 合并 K 个升序链表 两两分治多路归并 O(N log k) O(k)（每轮合并后的链表数组） 两两分治多路归并。每轮把当前链表数组按相邻两项合并，落单链表直接进入下一轮；链表数每轮减半。
146. LRU 缓存 哈希定位 + 循环双向链表顺序 get 与 put 平均 O(1) O(capacity) 哈希定位 + 双向链表顺序。哈希表指向每个节点；双向链表中越靠近头部越新，虚拟哨兵连接首尾。
