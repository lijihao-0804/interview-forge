## Python 模式：栈

栈保存尚未闭合的结构，或保存仍在等待答案的元素；先说明栈中存值还是下标，再说明何时弹出。

### 把日期放进“等待室”

输入 `temperatures = [73, 74, 75, 71, 69, 72, 76, 73]`，栈中保存日期编号，而不是温度本身：

| 今天与温度 | 处理 | 栈底 → 栈顶 |
|---|---|---|
| 0, 73 | 没有可结算项，入栈 | `[0]` |
| 1, 74 | 结算日期 0，答案 1；日期 1 入栈 | `[1]` |
| 2, 75 | 结算日期 1，答案 1；日期 2 入栈 | `[2]` |
| 3, 71 | 不高于栈顶，等待 | `[2,3]` |
| 4, 69 | 不高于栈顶，等待 | `[2,3,4]` |
| 5, 72 | 先结算 4，再结算 3；遇到 75 停下 | `[2,5]` |
| 6, 76 | 依次结算 5、2 | `[6]` |
| 7, 73 | 不高于 76，入栈 | `[6,7]` |

最后两天没有等到更高温度，答案保持 0。结果为 `[1,1,4,2,1,1,0,0]`。

一次循环可能弹出多个日期，所以用 `while`。每天最多入栈一次、出栈一次，总时间是线性的。84 题同样用下标栈，但当前高度严格小于栈顶时才弹出；等高柱会一起保留。

### Python 模板：等待室单调下标栈

模板解决 739 题。栈保存还没有等到更高温度的日期下标；相同温度仍会留在栈中，所以栈内温度是非递增而不是严格递减。

> 参考来源：代码随想录（programmercarl.com）


```python
def daily_temperatures(temperatures: list[int]) -> list[int]:
    answer = [0] * len(temperatures)
    stack = []
    for today, temperature in enumerate(temperatures):
        while stack and temperature > temperatures[stack[-1]]:
            previous = stack.pop()
            answer[previous] = today - previous
        stack.append(today)
    return answer
```


### `and` 短路与严格比较

条件 `while stack and temperature > temperatures[stack[-1]]` 先检查栈是否为空。`and` 短路后，空栈不会执行右侧的 `stack[-1]`。

答案写入 `today - previous`，这是日期差而不是温差。相同温度不算升温，因此 `[70,70,71]` 中前两个 70 都保留到 71 到来，答案分别为 2 和 1。

每个下标入栈一次、最多出栈一次，时间 O(n)；所有日期都不升温时，栈占 O(n)。
