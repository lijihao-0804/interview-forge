## Java 模式：图论

### 识别信号

连通块、扩散、依赖关系、前缀匹配。

树是无环图的特例；图中必须显式处理 visited、入度或状态标记。

### Java 核心不变量

> 访问即标记；多源问题先统一入队；依赖关系看入度。

### 下笔顺序

1. 入队或进入递归时立刻标记
2. 多源扩散把所有源同时入队
3. 依赖可行性用拓扑排序

### 工具箱

洪泛搜索、多源 BFS、拓扑排序、Trie。完整模板见 [Hot 100 算法模板](../04-模板/01-Hot100算法模板.md)。

## Python 模式：图论

网格是隐式图，显式依赖先建邻接表。搜索状态必须在进入容器时标记，多源问题先把所有源同时入队。

### 一次洪泛吞掉一个连通块

看网格：

```text
1 1 0
0 1 0
1 0 1
```

从 `(0,0)` 发现第一块陆地，先把起点改成 `0` 并入队；展开后把 `(0,1)` 和 `(1,1)` 也标记。后续扫描相邻格都是 `0`，这一块不会重复计数。继续扫描时，`(2,0)` 与 `(2,2)` 各自开启一次洪泛，因此答案是 3。

“进入即标记”很关键。若等出队时才改，两个邻居可能在同一时间把同一格加入队列，队列会膨胀，还可能重复计数。

### 其它图模型

- 994 题把所有腐烂橘子同时入队，BFS 的每一层对应一分钟。
- 207 题从入度 0 的课程出发，只有处理完所有课程才无环。
- Trie 把路径上的字符映射到子节点字典，终点标记区分完整单词与普通前缀。

### Python 模板：入队即标记的岛屿洪泛

模板解决 200 题，并把访问过的陆地原地改成 `"0"`。若调用方之后还需要原网格，应先复制；多源最短路径和拓扑排序要另建状态，不能只换函数名。

> 参考来源：代码随想录（programmercarl.com）


```python
from collections import deque


def count_islands(grid: list[list[str]]) -> int:
    if not grid or not grid[0]:
        return 0
    rows = len(grid)
    cols = len(grid[0])
    islands = 0
    directions = ((1, 0), (-1, 0), (0, 1), (0, -1))
    for start_row in range(rows):
        for start_col in range(cols):
            if grid[start_row][start_col] != "1":
                continue
            islands += 1
            grid[start_row][start_col] = "0"
            queue = deque([(start_row, start_col)])
            while queue:
                row, col = queue.popleft()
                for dr, dc in directions:
                    next_row = row + dr
                    next_col = col + dc
                    if not (0 <= next_row < rows and 0 <= next_col < cols):
                        continue
                    if grid[next_row][next_col] != "1":
                        continue
                    grid[next_row][next_col] = "0"
                    queue.append((next_row, next_col))
    return islands
```


### Python 容器与访问标记

`deque` 从右端加入、左端弹出，BFS 顺序稳定且操作均摊 O(1)。四个方向写成元组，避免复制四份判断代码。

模板直接改 `grid`，所以除队列外不再创建同尺寸 visited 表；代价是输入被修改。网格有 `m × n` 个格子，每个至多入队一次，时间 O(mn)，队列最坏保存 O(mn) 个坐标。

Trie 查询要区分 `dict.get(key)` 与 `setdefault(key, Trie())`：前者只查询，后者会在未命中时创建节点，适合插入而不适合搜索。

### 本专题逐题抓手

| 题目 | Python 主方法 | 时间 | 空间 | 本题抓手 |
|---|---|---|---|---|
| **[200. 岛屿数量](../03-题解/09-图论/0200-岛屿数量.md)** | BFS 网格洪泛 | O(m·n) | O(m·n) | BFS 网格洪泛 + `visited`。每发现一个未访问陆地就计数一次，入队时立即标记 `visited`，再展开同一座岛的全部四连通陆地块。 |
| **[994. 腐烂的橘子](../03-题解/09-图论/0994-腐烂的橘子.md)** | 多源 BFS 分层扩散 | O(m·n) | O(m·n) | 多源 BFS 分层扩散。队列在每轮开始时包含同一分钟会扩散的腐烂橘子；fresh 是尚未腐烂数量。 |
| **[207. 课程表](../03-题解/09-图论/0207-课程表.md)** | Kahn 拓扑排序 | O(V+E) | O(V+E) | Kahn 拓扑排序。入度为 0 的课程是当前可修集合；每学完一门课就减少所有后继入度。 |
