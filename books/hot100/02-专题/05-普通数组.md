## Java 模式：普通数组

### 识别信号

区间合并、原地置换、前后缀信息、局部最优。

数组题最常见的突破口是改变遍历顺序或把值映射回下标。

### Java 核心不变量

> 先明确下标含义，再决定排序、原地标记或滚动状态。

### 下笔顺序

1. 区间先排序
2. 需要左右信息时分两趟
3. 值域落在 1..n 时考虑原地哈希

### 工具箱

Kadane、区间合并、反转、前后缀、循环置换。完整模板见 [Hot 100 算法模板](../04-模板/01-Hot100算法模板.md)。

## Python 模式：普通数组

数组题先明确下标含义，再决定原地扫描、排序、前后缀或值域映射；不是看到数组就先切片。

### 只保留“必须接上当前元素”的最优值

对 `[-2, 1, -3, 4, -1, 2, 1, -5, 4]`，令 `current` 表示以当前下标结尾的最大子数组和：

| 下标与值 | `current` | `best` | 选择 |
|---|---:|---:|---|
| 0, -2 | -2 | -2 | 从 -2 开始 |
| 1, 1 | 1 | 1 | 丢弃更差的 `-2 + 1` |
| 2, -3 | -2 | 1 | 接上当前值仍然更大 |
| 3, 4 | 4 | 4 | 再次从 4 重新开始 |
| 4, -1 | 3 | 4 | 保留 4 后接 -1 |
| 5, 2 | 5 | 5 | 形成 `4,-1,2` |
| 6, 1 | 6 | 6 | 形成 `4,-1,2,1` |
| 7, -5 | 1 | 6 | 继续保留已有最佳值 6 |
| 8, 4 | 5 | 6 | 答案仍为 6 |

`max(value, current + value)` 同时覆盖“从头开始”和“接上前一段”两种选择。全部为负数时，`best` 初值取第一个元素，因此不会错误返回 0。

### 其他数组模型

- 合并区间先按起点排序，排序后新区间只可能与结果末尾重叠。
- 轮转数组用三次原地反转，避免切片。
- 41 题把 `[1, n]` 内的值放回下标 `value - 1`，下标本身成为状态。

### Python 模板：Kadane 滚动状态

模板解决非空“最大子数组和”。`current` 必须定义为“以当前位置结尾”的最大值；区间合并、三次反转和值域置换是另外三类数组模型。

> 参考来源：代码随想录（programmercarl.com）


```python
def kadane(nums: list[int]) -> int:
    current = nums[0]
    best = nums[0]
    for index in range(1, len(nums)):
        value = nums[index]
        current = max(value, current + value)
        best = max(best, current)
    return best
```


### 空间要按真实操作声明

模板从 `range(1, len(nums))` 开始扫描，不创建 `nums[1:]`。状态只有 `current` 与 `best` 两个整数，额外空间 O(1)。

`list.sort` 会原地重排调用方列表，但“原地”不等于额外空间 O(1)。判题环境限定为 Python 3.12 / CPython 时，Timsort 在最坏情况下需要 O(n) 级别的临时缓冲；如果题目严格要求 O(1)，应使用手工交换、反转、三路划分或链表重连。

### 本专题逐题抓手

| 题目 | Python 主方法 | 时间 | 空间 | 本题抓手 |
|---|---|---|---|---|
