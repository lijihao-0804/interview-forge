总目录 · 算法模式地图

识别信号

区间合并、原地置换、前后缀信息、局部最优。

数组题最常见的突破口是改变遍历顺序或把值映射回下标。

核心不变量

先明确下标含义，再决定排序、原地标记或滚动状态。

下笔顺序

  1. 区间先排序
  2. 需要左右信息时分两趟
  3. 值域落在 1..n 时考虑原地哈希

工具箱

Kadane、区间合并、反转、前后缀、循环置换。完整 Java 模板见 Hot 100 算法模板。

练习顺序

顺序 题目 难度 主方法 时间 / 空间
1 53. 最大子数组和 中等 Kadane 动态规划 O(n) / O(1)
2 56. 合并区间 中等 排序 + 线性合并 O(n log n) / O(log n)
3 189. 轮转数组 中等 三次反转 O(n) / O(1)
4 238. 除自身以外数组的乘积 中等 前缀积 + 后缀积 O(n) / O(1) 除答案外
5 41. 缺失的第一个正数 困难 原地哈希 / 循环置换 O(n) / O(1)

复习标准

  • 能在 30 秒内说出每题的核心不变量。
  • 能不看答案写出主循环或递归函数签名。
  • 能解释为什么移动指针、弹栈、剪枝或状态转移不会漏解。
  • 能主动写出至少 3 个边界用例。
