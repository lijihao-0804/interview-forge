Java 模式：双指针

识别信号

数组有序、原地修改、两端关系或快慢节奏。

双指针不是‘放两个变量’，而是用两个位置维护一个可证明的不变量。

Java 核心不变量

每次移动都要能排除一批不可能的答案。

下笔顺序

  1. 先说明两指针各代表什么
  2. 证明移动哪一侧能排除答案
  3. 原地改写时区分已处理区与未知区

工具箱

快慢、相向、同向覆盖、链表节奏。完整模板见 Hot 100 算法模板。

复习标准

  • 能在 30 秒内说出每题的核心不变量。
  • 能不看答案写出主循环或递归函数签名。
  • 能解释为什么移动指针、弹栈、剪枝或状态转移不会漏解。
  • 能主动写出至少 3 个边界用例。

Python 模式：双指针

双指针用一个区间或两个速度表达可证明的排除关系；两侧指针各有明确任务，不能只凭写法套模板。

两端夹住一个候选区间

容器面积是“短板高度 × 两板距离”。从两端开始时宽度最大，但最终高度只可能由较矮的一边决定。以 [1,8,6,2,5,4,8,3,7] 为例：

当前区间 两板高度 面积 下一步
[0, 8] 1 和 7 8 左板更矮，左移
[1, 8] 8 和 7 49 右板更矮，右移
[1, 7] 8 和 3 18 继续右移

为什么能丢掉较矮的那一边？当前宽度下，它已经把“以这块矮板为一端”的最大可能高度定住了。继续保留它，宽度只会更小，面积不可能超过当前位置；只有换掉矮板，高度才有机会上升。

同向双指针不是同一套移动规则

移动零使用 write 记录下一个非零值应写入的位置，read 扫描原数组；两个指针都从头向右。删除节点、找环或维护窗口时，“快慢”指速度而非左右边界。先解释区间含义，再决定移动哪一端。

Python 模板：相向指针排除短板

模板解决“盛最多水的容器”。相向移动适用于能从两端单调性排除答案的题；移动零一类的同向覆盖要另定义 write 指针，不能照搬这里的移动条件。

参考来源：代码随想录（programmercarl.com）

def max_area(height: list[int]) -> int:
    left = 0
    right = len(height) - 1
    best = 0
    while left < right:
        width = right - left
        area = min(height[left], height[right]) * width
        best = max(best, area)
        if height[left] <= height[right]:
            left += 1
        else:
            right -= 1
    return best

Python 写法与空间边界

left, right = 0, len(height) - 1 保存的是两个下标；每轮只更新一端，区间长度严格减小，所以循环一定会结束。

需要交换列表元素时，nums[i], nums[j] = nums[j], nums[i] 可以少写临时变量：右侧的 nums[j]、nums[i] 先按旧值求值，再从左到右赋给左侧的两个目标。

切片 nums[:] 或 nums[::-1] 会产生新列表。题目要求原地修改或 O(1) 额外空间时，应直接移动下标并交换。

每轮只移动两端中的一端，候选区间宽度严格减小；两个指针合计最多前进 n 次，因此时间 O(n)，除输入外只保存常数量，额外空间 O(1)。
