总目录 · 算法模式地图

识别信号

数组有序、原地修改、两端关系或快慢节奏。

双指针不是‘放两个变量’，而是用两个位置维护一个可证明的不变量。

核心不变量

每次移动都要能排除一批不可能的答案。

下笔顺序

  1. 先说明两指针各代表什么
  2. 证明移动哪一侧能排除答案
  3. 原地改写时区分已处理区与未知区

工具箱

快慢、相向、同向覆盖、链表节奏。完整 Java 模板见 Hot 100 算法模板。

练习顺序

顺序 题目 难度 主方法 时间 / 空间
1 283. 移动零 简单 快慢指针原地交换 O(n) / O(1)
2 11. 盛最多水的容器 中等 相向双指针 O(n) / O(1)
3 15. 三数之和 中等 排序 + 固定一点 + 双指针 O(n²) / O(log n)
4 42. 接雨水 困难 左右最大值双指针 O(n) / O(1)

复习标准

  • 能在 30 秒内说出每题的核心不变量。
  • 能不看答案写出主循环或递归函数签名。
  • 能解释为什么移动指针、弹栈、剪枝或状态转移不会漏解。
  • 能主动写出至少 3 个边界用例。
