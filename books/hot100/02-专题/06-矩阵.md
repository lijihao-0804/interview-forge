## Java 模式：矩阵

### 识别信号

二维原地修改、按层遍历、从某个角落搜索。

写矩阵题先统一行列含义，所有边界都使用同一套闭区间或开区间语义。

### Java 核心不变量

> 方向变化必须与边界收缩同步，原地标记要预留标记位。

### 下笔顺序

1. 记录 rows 与 cols，避免方阵假设
2. 原地标记先保护首行首列
3. 模拟遍历每走一边就收边界

## Python 模式：矩阵

矩阵题先固定 `rows`、`cols` 与边界开闭语义，再决定螺旋模拟、首行首列标记、转置翻转或阶梯搜索。

### 四条边围住尚未访问的区域

对 `[[1,2,3],[4,5,6],[7,8,9]]`，初始边界是 `top=0, bottom=2, left=0, right=2`：

1. 向右读 `[1,2,3]`，随后 `top=1`。
2. 向下读 `[6,9]`，随后 `right=1`。
3. 向左读 `[8,7]`，随后 `bottom=1`。
4. 向上读 `[4]`，随后 `left=1`。
5. 剩余区域只有中间的 `[5]`，再向右读完；下一轮边界交错，循环结束。

最后两条边前必须检查 `top <= bottom` 与 `left <= right`。对只有一行的矩阵，向下读时区间已经为空；若不检查，向左那一步会把同一行反向再读一遍。

### Python 模板：四边界螺旋模拟

模板解决非空或空列表都可安全处理的螺旋遍历。每收缩一条边都要重新检查剩余区域；置零、旋转和二维搜索需要各自的状态，不能共用这一个模板。

> 参考来源：代码随想录（programmercarl.com）


```python
def spiral(matrix: list[list[int]]) -> list[int]:
    if not matrix or not matrix[0]:
        return []
    rows = len(matrix)
    cols = len(matrix[0])
    top = 0
    bottom = rows - 1
    left = 0
    right = cols - 1
    answer = []
    while top <= bottom and left <= right:
        for col in range(left, right + 1):
            answer.append(matrix[top][col])
        top += 1
        for row in range(top, bottom + 1):
            answer.append(matrix[row][right])
        right -= 1
        if top <= bottom:
            for col in range(right, left - 1, -1):
                answer.append(matrix[bottom][col])
            bottom -= 1
        if left <= right:
            for row in range(bottom, top - 1, -1):
                answer.append(matrix[row][left])
            left += 1
    return answer
```


### 行列与二维列表

`rows` 控制第 1 维，`cols` 控制第 2 维；写成 `matrix[row][col]`，不要依赖方阵。四个循环都包含当前边界，因此范围使用 `+1` 或 `-1`。

`[[0] * cols for _ in range(rows)]` 才会创建独立的内层列表。用乘法复制一整行时，多行共享同一个对象，改一格会同时改多行。

螺旋遍历访问每个元素一次，时间 O(rows × cols)；除返回列表外只保存四个边界，额外空间 O(1)。
