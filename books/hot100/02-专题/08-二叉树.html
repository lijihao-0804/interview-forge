Java 模式：二叉树

识别信号

子树信息、层级信息、搜索树有序性或路径关系。

看到树先问：信息是从父节点向下传，还是从子树向上汇总。

Java 核心不变量

先判断答案来自向下传参、向上汇总，还是中序有序。

下笔顺序

  1. 向下传参数：前序/DFS
  2. 向上返回信息：后序
  3. BST 排序性质：中序
  4. 按层处理：BFS

工具箱

前序传参、后序汇总、中序有序、层序遍历。完整模板见 Hot 100 算法模板。

Python 模式：二叉树

树题先确定信息流向：父节点向下传边界，子节点向上返回高度或贡献，BFS 按层处理，BST 利用中序。

子树先算完，父节点才能汇总

以根为 1、左孩子 2、右孩子 3、节点 2 还有左孩子 4 的树为例：节点 4 返回高度 1，节点 2 得到 1 + max(1, 0) = 2，根节点得到 1 + max(2, 1) = 3。

后序处理的顺序是“左子树、右子树、当前节点”。递归代码读起来短，但一条合法深链可能超过 Python 默认递归深度。因此模板把节点压栈两次：第一次标记还没处理，第二次表示左右孩子的高度都已经算好。

不同题目的返回语义

  • 104 的高度为“当前子树最长向下路径”。
  • 543 的返回值是给父节点的一条单边高度，而全局答案可以同时连接左右两边。
  • 98 向下传的是取值上下界，向上返回子树是否合法。

先写清函数返回什么，才能避免把全局答案误当成父节点的返回值。

Python 模板：后序返回树高

模板返回二叉树高度，空树返回 0。它用 (node, expanded) 显式表示后序的进入与返回，TreeNode 由力扣提供；本地测试时传入具有 left、right 属性的节点即可。

参考来源：代码随想录（programmercarl.com）；原始递归思路，本模板改为显式栈

from __future__ import annotations


def tree_height(root: TreeNode | None) -> int:
    if root is None:
        return 0
    heights = {}
    stack = [(root, False)]
    while stack:
        node, expanded = stack.pop()
        if expanded:
            left_height = 0 if node.left is None else heights[node.left]
            right_height = 0 if node.right is None else heights[node.right]
            heights[node] = 1 + max(left_height, right_height)
            continue
        stack.append((node, True))
        if node.right is not None:
            stack.append((node.right, False))
        if node.left is not None:
            stack.append((node.left, False))
    return heights[root]

显式后序帧

expanded=False 的帧负责展开左右孩子，并把 expanded=True 的当前节点后压入栈，使它在孩子之后弹出。孩子全部结算后，可以从 heights 取出左右高度；空孩子直接按 0 处理。

from __future__ import annotations 让 TreeNode | None 只作为注解保存，运行时不要求先定义 TreeNode。力扣提交时仍使用平台提供的节点类。

每个节点恰好进入和返回一次，时间 O(n)。heights 为每个节点保存高度，空间为 O(n)；显式栈在最深路径上占 O(h) 个帧，h 为树高，总空间仍为 O(n)。

本专题逐题抓手

题目 Python 主方法 时间 空间 本题抓手
94. 二叉树的中序遍历 显式栈中序遍历 O(n) O(h) 显式栈中序遍历。cur 指向尚未沿左链下潜的子树根；栈中依次保存等待访问的祖先。
104. 二叉树的最大深度 显式栈记录根到节点深度 O(n) O(h) 显式栈记录根到节点深度。栈项 (node, depth) 随孩子把深度加一，best 取所有访问节点中的最大深度。
226. 翻转二叉树 递归交换每个节点的左右子树 O(n) O(h) 递归交换左右子树。处理完某节点后，其左右子树都已翻转，并且该节点的左右孩子已经交换。
101. 对称二叉树 成对递归比较镜像位置 O(n) O(h) 镜像递归比较。左右子树成镜像，当且仅当根值相同，且左外侧对右外侧、左内侧对右内侧分别镜像。
543. 二叉树的直径 显式后序帧计算子树高度 O(n) O(h) 显式后序帧计算子树高度。返回给父节点的是最长单边高度，best 另外记录可同时连接左右两边的最大直径。
102. 二叉树的层序遍历 BFS 固定当前层长度 O(n) O(w) BFS 固定层长度。每轮处理开始时队列长度恰为当前层节点数，只有该批节点出队后才进入下一层。
108. 将有序数组转换为二叉搜索树 中位分治构造平衡 BST O(n) O(log n) 中位分治构造平衡 BST。递归区间 [left, right] 只由有序数组的一段组成；区间中点作为根，左右半段分别递归。
98. 验证二叉搜索树 显式栈中序严格递增校验 O(n) O(h) 显式栈中序严格递增校验。按中序依次弹出节点，只比较 previous 与当前值；发现 current.val <= previous 立即失败。
230. 二叉搜索树中第 K 小的元素 显式栈中序遍历提前停止 O(h+k) O(h) 中序遍历提前停止。BST 的中序访问序列严格递增；弹栈计数到第 k 次时，该节点就是答案。
199. 二叉树的右视图 BFS 收集每层最右节点 O(n) O(w) BFS 记录每层最后节点。队列长度固定为当前层节点数，该批最后一个出队节点是当前层的右侧可见节点。
114. 二叉树展开为链表 原地前驱重接先序链 O(n) O(1) 原地前驱重接先序链。处理到 current 时，其左侧子树的先序链接到 current.right，右子树接到左子树最右节点的 right。
105. 从前序与中序遍历序列构造二叉树 前序增量附着与中序游标 O(n) O(h) 前序增量附着 + 中序游标。新前序值默认接为栈顶左孩子；当栈顶与 inorder[inorder_index] 相等时连续弹栈，再把节点接到最后弹出的右孩子。
437. 路径总和 III 显式进入/退出栈维护路径前缀和 O(n) O(h) 显式进入/退出栈维护根到当前节点路径。current 是路径前缀和，historical[current-target] 统计以当前节点结尾的合法向下路径。
236. 二叉树的最近公共祖先 父节点映射与祖先集合 O(n) O(n) 父节点映射 + 祖先集合。显式遍历记录每个节点的 parent，从 p 向上标记祖先，再让 q 向上走到第一个集合内节点。
124. 二叉树中的最大路径和 显式后序帧最大单边贡献 O(n) O(h) 显式后序帧维护最大单边贡献。返回给父节点的是当前节点可向下延伸的最大非负贡献，完整路径可同时连接左右贡献。
