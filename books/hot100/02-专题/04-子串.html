总目录 · 算法模式地图

Java 模式：子串

识别信号

连续子数组/子串的计数、最值或固定和。

先区分题目要的是区间和、区间最值还是覆盖关系，再选前缀和、单调队列或窗口。

Java 核心不变量

前缀和解决区间和，单调队列解决区间最值，可变窗口解决覆盖关系。

下笔顺序

  1. 连续但允许负数求和：优先前缀和
  2. 固定窗口最值：单调队列
  3. 覆盖/频次条件：滑动窗口

工具箱

前缀和、单调队列、最小覆盖。完整模板见 Hot 100 算法模板。

Java 练习顺序

  • 能在 30 秒内说出每题的核心不变量。
  • 能不看答案写出主循环或递归函数签名。
  • 能解释为什么移动指针、弹栈、剪枝或状态转移不会漏解。
  • 能主动写出至少 3 个边界用例。

Python 模式：子串

连续区间的“和”“最值”“覆盖”需要不同工具：区间和查前缀，定长最值用单调队列，覆盖条件用可变窗口。

区间和可以变成两个前缀相减

令 prefix 表示从数组开头到当前位置的和。若此前某个前缀是 prefix - k，那么这两个前缀之间的连续区间和就是 k。

以 nums = [1, 1, 1]、k = 2 为例，初始 seen = {0: 1}：

元素 当前前缀 查询 prefix-k 累计答案 记录后的字典
1 1 查询 -1，得到 0 0 {0:1, 1:1}
1 2 查询 0，得到 1 1 {0:1, 1:1, 2:1}
1 3 查询 1，得到 1 2 {0:1, 1:1, 2:1, 3:1}

初始的 0 代表空前缀，它让第一个元素就能形成从下标 0 开始的合法区间。

另外两类连续区间

  • 239 题求固定长度窗口最大值：队列存下标，值递减；右端删除更小候选，左端删除已离开窗口的下标。
  • 76 题求最小覆盖窗口：先扩张到覆盖目标，再持续缩短左端，直到再删一个字符就不覆盖。

Python 模板：前缀和频次

模板解决元素可为负数的“和为 K 的子数组”。遇到固定长度窗口最值或覆盖窗口时，应改看 deque 或频次表模板；前缀和不能直接替换窗口最值。

参考来源：代码随想录（programmercarl.com）

def subarray_sum(nums: list[int], k: int) -> int:
    seen = {0: 1}
    prefix = 0
    answer = 0
    for value in nums:
        prefix += value
        answer += seen.get(prefix - k, 0)
        seen[prefix] = seen.get(prefix, 0) + 1
    return answer

Python 细节

seen.get(prefix - k, 0) 既完成查询又没有写入默认值；之后再把当前前缀加入字典。先查后存保证只统计此前的前缀。

同样的前缀值可能出现多次，所以字典的值必须是次数而不是单个下标。元素含负数时也不能用普通滑动窗口，因为窗口变长不再保证和单调增加。

前缀表最多保存 n+1 个不同前缀，额外空间 O(n)，扫描时间为 O(n)（dict 按平均 O(1) 查询计）。
