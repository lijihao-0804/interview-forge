难度中等核心模式哈希集合找序列起点时间复杂度O(n)空间复杂度O(n)

题目与约束

给定一个未排序的整数数组 nums ，找出数字连续的最长序列（不要求序列元素在原数组中连续）的长度。

请你设计并实现时间复杂度为 O(n)的算法解决此问题。

示例 1：

输入：nums = [100,4,200,1,3,2]
输出：4
解释：最长数字连续序列是 [1, 2, 3, 4]。它的长度为 4。

示例 2：

输入：nums = [0,3,7,2,5,8,4,6,0,1]
输出：9

示例 3：

输入：nums = [1,0,1,2]
输出：3

提示：

  • 0 <= nums.length <= 105
  • -109 <= nums[i] <= 109

核心不变量

只从不存在 x - 1 的数字开始向右扩展。

完整推导

思路推导

  1. 直觉与痛点（排序后扫描）：

    最简单的方法是先把数组排序，再找最长的连续段。排序需要 O(N log N)，而题目明确要求 O(N)，所以这条路直接不符合要求。

  2. 破局思路（哈希集合 + 只从序列起点扩展）：

    先把所有数字放进 HashSet。遍历每个数字 x，只有 x - 1 不存在时才从 x 开始向右扩展，统计连续长度。这样每个数字最多只会被扩展一次，整体是 O(N)。

    为什么只从起点扩展？因为如果 x - 1 已经存在，说明 x 所在的连续序列一定是从更小的数字开始的，从 x 开始统计会重复计算，而且无法保证线性时间。

  3. 逻辑推演（以 nums = [100,4,200,1,3,2] 为例）：

    • 数字 100 的前驱 99 不存在，从它开始只能扩展出 {100}，长度 1。
    • 数字 4 的前驱 3 存在，跳过，因为它的序列应该从 1 开始统计。
    • 数字 1 的前驱 0 不存在，从 1 开始：1 → 2 → 3 → 4，长度 4。
    • 数字 3、2 都因为前驱存在被跳过，不会重复统计。
    • 最大长度就是 4。

    Java 实现

    C++ 实现

    实现来源：灵茶山艾府题解（MIT License）

    class Solution {
public:
    int longestConsecutive(vector<int>& nums) {
        unordered_set<int> st(nums.begin(), nums.end()); // 把 nums 转成哈希集合
        int ans = 0;
        for (int x : st) { // 遍历哈希集合
            if (st.contains(x - 1)) { // 如果 x 不是序列的起点，直接跳过
                continue;
            }
            // x 是序列的起点
            int y = x + 1;
            while (st.contains(y)) { // 不断查找下一个数是否在哈希集合中
                y++;
            }
            // 循环结束后，y-1 是最后一个在哈希集合中的数
            ans = max(ans, y - x); // 从 x 到 y-1 一共 y-x 个数
        }
        return ans;
    }
};

    C 实现

    实现来源：灵茶山艾府题解（MIT License）

    #define MAX(a, b) ((b) > (a) ? (b) : (a))

typedef struct {
    int key; // 哈希集合保存的元素
    UT_hash_handle hh; // uthash 需要
} HashEntry;

int longestConsecutive(int* nums, int numsSize) {
    HashEntry* hashSet = NULL; // 创建一个空哈希集合
    HashEntry* e;
    // 构建哈希集合
    for (int i = 0; i < numsSize; i++) {
        HASH_FIND_INT(hashSet, &nums[i], e);
        if (e == NULL) { // 如果 nums[i] 不在集合中，则插入
            e = malloc(sizeof(HashEntry));
            e->key = nums[i];
            HASH_ADD_INT(hashSet, key, e);
        }
    }

    int ans = 0;
    HashEntry* tmp;
    HASH_ITER(hh, hashSet, e, tmp) { // 遍历哈希集合
        int x = e->key;
        int y = x - 1;
        HASH_FIND_INT(hashSet, &y, e);
        if (e) { // 如果 x 不是序列的起点，直接跳过
            continue;
        }
        // x 是序列的起点
        y = x;
        do {
            y++;
            HASH_FIND_INT(hashSet, &y, e);
        } while (e);
        // 循环结束后，y-1 是最后一个在哈希集合中的数
        ans = MAX(ans, y - x);
    }

    // 释放哈希表中所有节点，防止内存泄漏
    HASH_ITER(hh, hashSet, e, tmp) {
        HASH_DEL(hashSet, e);
        free(e);
    }

    return ans;
}

class Solution {
    public int longestConsecutive(int[] nums) {
        // 空数组没有连续序列，直接返回 0
        if (nums == null || nums.length == 0) return 0;

        // 去重并支持 O(1) 判断某个数字是否存在
        Set<Integer> set = new HashSet<>();
        for (int num : nums) {
            set.add(num);
        }

        int max = 0;
        for (int num : set) {
            // 只有不存在 num - 1 时，num 才是一个连续序列的起点，
            // 保证每个序列只被统计一次，整体仍是 O(N)
            if (!set.contains(num - 1)) {
                int count = 1;
                // 从起点向右扩展，统计连续数字的长度
                while (set.contains(num + 1)) {
                    count++;
                    num++;
                }
                max = Math.max(max, count);
            }
        }
        return max;
    }
}

复杂度

  • 时间复杂度：O(N)。每个数字最多只会作为起点扩展一次。

  • 空间复杂度：O(N)。哈希集合需要保存全部数字。

  • 💡 面试避坑与考点拓展：

  1. 重复数字：数组可能有重复，放进 HashSet 后自然去重，不会影响连续序列长度。
  2. 不要对每个数字都向内扩展：只有 x - 1 不存在时才扩展，这是线性时间的关键。
  3. 边界条件：空数组返回 0；只有一个数字返回 1。
