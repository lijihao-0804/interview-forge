51. N 皇后

难度困难核心模式列与两条对角线约束时间复杂度O(n!)空间复杂度O(n)

题目与约束

按照国际象棋的规则，皇后可以攻击与之处在同一行或同一列或同一斜线上的棋子。

n 皇后问题 研究的是如何将 n 个皇后放置在 n×n 的棋盘上，并且使皇后彼此之间不能相互攻击。

给你一个整数 n ，返回所有不同的 n皇后问题 的解决方案。

每一种解法包含一个不同的 n 皇后问题 的棋子放置方案，该方案中 'Q' 和 '.' 分别代表了皇后和空位。

示例 1：

输入：n = 4 输出：[[".Q..","...Q","Q...","..Q."],["..Q.","Q...","...Q",".Q.."]] 解释：如上图所示，4 皇后问题存在两个不同的解法。

示例 2：

输入：n = 1 输出：[["Q"]]

提示：

1 <= n <= 9

核心不变量

row-col 与 row+col 分别唯一标识两类对角线。

完整推导

思路推导

  1. 直觉与痛点（二维瞎撞的灾难）：

    如果在 N × N 的格子里随便挑 N 个格子放皇后，那组合数大得惊人，绝对会超时。

    优化思路第一步：既然同一行绝不能有两个皇后，那这就变成了一个“逐行分配”的问题。第一行放一个，第二行放一个... 我们只需要一个深度为 N 的 for 循环（代表行），在每一行里遍历 N 个列就行了！

  2. 破局思路（如何优雅地判断斜线冲突？）：

    当前行是 row，准备遍历列 col。

    • 同列冲突：查一下以前的行在 col 这列放过皇后没有。
    • 左上 -> 右下（主对角线 \）冲突：数学规律发现，同一条主对角线上的坐标，它们的 row - col 是一个固定常数！
    • 右上 -> 左下（副对角线 /）冲突：同理，同一条副对角线上的坐标，它们的 row + col 是一个固定常数！

  3. 核心微操（空间换时间的 O(1) 查杀）：

    我们完全不需要每次都用 for 循环去扫描斜线！

    准备三个布尔数组（或者 HashSet）：cols、diags1、diags2。

    只要在某放了一个皇后，就把对应的列和两条斜线设为 true。下一行的皇后如果算出来的常数在这三个数组里是 true，直接剪枝（跳过）！

    C++ 实现

    实现来源：代码随想录（programmercarl.com）

    void backtracking(参数) {
    if (终止条件) {
        存放结果;
        return;
    }
    for (选择：本层集合中元素（树中节点孩子的数量就是集合的大小）) {
        处理节点;
        backtracking(路径，选择列表); // 递归
        回溯，撤销处理结果
    }
}

    Python 实现

    实现来源：代码随想录（programmercarl.com）

    class Solution:
    def solveNQueens(self, n: int) -> List[List[str]]:
        result = []  # 存储最终结果的二维字符串数组

        chessboard = ['.' * n for _ in range(n)]  # 初始化棋盘
        self.backtracking(n, 0, chessboard, result)  # 回溯求解
        return [[''.join(row) for row in solution] for solution in result]  # 返回结果集

    def backtracking(self, n: int, row: int, chessboard: List[str], result: List[List[str]]) -> None:
        if row == n:
            result.append(chessboard[:])  # 棋盘填满，将当前解加入结果集
            return

        for col in range(n):
            if self.isValid(row, col, chessboard):
                chessboard[row] = chessboard[row][:col] + 'Q' + chessboard[row][col+1:]  # 放置皇后
                self.backtracking(n, row + 1, chessboard, result)  # 递归到下一行
                chessboard[row] = chessboard[row][:col] + '.' + chessboard[row][col+1:]  # 回溯，撤销当前位置的皇后

    def isValid(self, row: int, col: int, chessboard: List[str]) -> bool:
        # 检查列
        for i in range(row):
            if chessboard[i][col] == 'Q':
                return False  # 当前列已经存在皇后，不合法

        # 检查 45 度角是否有皇后
        i, j = row - 1, col - 1
        while i >= 0 and j >= 0:
            if chessboard[i][j] == 'Q':
                return False  # 左上方向已经存在皇后，不合法
            i -= 1
            j -= 1

        # 检查 135 度角是否有皇后
        i, j = row - 1, col + 1
        while i >= 0 and j < len(chessboard):
            if chessboard[i][j] == 'Q':
                return False  # 右上方向已经存在皇后，不合法
            i -= 1
            j += 1

        return True  # 当前位置合法

    Go 实现

    实现来源：代码随想录（programmercarl.com）

    func solveNQueens(n int) [][]string {
    var res [][]string
    chessboard := make([][]string, n)
    for i := 0; i < n; i++ {
        chessboard[i] = make([]string, n)
    }
    for i := 0; i < n; i++ {
        for j := 0; j < n; j++ {
            chessboard[i][j] = "."
        }
    }
    var backtrack func(int)
    backtrack = func(row int) {
        if row == n {
            temp := make([]string, n)
            for i, rowStr := range chessboard {
                temp[i] = strings.Join(rowStr, "")
            }
            res = append(res, temp)
            return
        }
        for i := 0; i < n; i++ {
            if isValid(n, row, i, chessboard) {
                chessboard[row][i] = "Q"
                backtrack(row + 1)
                chessboard[row][i] = "."
            }
        }
    }
    backtrack(0)
    return res
}

    C 实现

    实现来源：代码随想录（programmercarl.com）

    char ***ans;
char **path;
int ansTop, pathTop;
//将path中元素复制到ans中
void copyPath(int n) {
    char **tempPath = (char**)malloc(sizeof(char*) * pathTop);
    int i;
    for(i = 0; i < pathTop; ++i) {
        tempPath[i] = (char*)malloc(sizeof(char) * n + 1);
        int j;
        for(j = 0; j < n; ++j)
            tempPath[i][j] = path[i][j];
        tempPath[i][j] = '\0';

    }
    ans[ansTop++] = tempPath;
}

//判断当前位置是否有效（是否不被其它皇后影响）
int isValid(int x, int y, int n) {
    int i, j;
    //检查同一行以及同一列是否有效
    for(i = 0; i < n; ++i) {
        if(path[y][i] == 'Q' || path[i][x] == 'Q')
            return 0;
    }
    //下面两个for循环检查斜角45度是否有效
    i = y - 1;
    j = x - 1;
    while(i >= 0 && j >= 0) {
        if(path[i][j] == 'Q')
            return 0;
        --i, --j;
    }

    i = y + 1;
    j = x + 1;
    while(i < n && j < n) {
        if(path[i][j] == 'Q')
            return 0;
        ++i, ++j;
    }

    //下面两个for循环检查135度是否有效
    i = y - 1;
    j = x + 1;
    while(i >= 0 && j < n) {
        if(path[i][j] == 'Q')
            return 0;
        --i, ++j;
    }

    i = y + 1;
    j = x -1;
    while(j >= 0 && i < n) {
        if(path[i][j] == 'Q')
            return 0;
        ++i, --j;
    }
    return 1;
}

void backTracking(int n, int depth) {
    //若path中有四个元素，将其拷贝到ans中。从当前层返回
    if(pathTop == n) {
        copyPath(n);
        return;
    }

    //遍历横向棋盘
    int i;
    for(i = 0; i < n; ++i) {
        //若当前位置有效
        if(isValid(i, depth, n)) {
            //在当前位置放置皇后
            path[depth][i] = 'Q';
            //path中元素数量+1
            ++pathTop;

            backTracking(n, depth + 1);
            //进行回溯
            path[depth][i] = '.';
            //path中元素数量-1
            --pathTop;
        }
    }
}

//初始化存储char*数组path，将path中所有元素设为'.'
void initPath(int n) {
    int i, j;
    for(i = 0; i < n; i++) {
        //为path中每个char*开辟空间
        path[i] = (char*)malloc(sizeof(char) * n + 1);
        //将path中所有字符设为'.'
        for(j = 0; j < n; j++)
            path[i][j] = '.';
        //在每个字符串结尾加入'\0'
        path[i][j] = '\0';
    }
}

char *** solveNQueens(int n, int* returnSize, int** returnColumnSizes){
    //初始化辅助变量
    ans = (char***)malloc(sizeof(char**) * 400);
    path = (char**)malloc(sizeof(char*) * n);
    ansTop = pathTop = 0;

    //初始化path数组
    initPath(n);
    backTracking(n, 0);

    //设置返回数组大小
    *returnSize = ansTop;
    int i; 
    *returnColumnSizes = (int*)malloc(sizeof(int) * ansTop);
    for(i = 0; i < ansTop; ++i) {
        (*returnColumnSizes)[i] = n;
    }
    return ans;
}

import java.util.ArrayList;
import java.util.Arrays;
import java.util.List;

class Solution {
    List<List<String>> res = new ArrayList<>();

    public List<List<String>> solveNQueens(int n) {
        // 初始化空棋盘，全填上 '.'
        char[][] board = new char[n][n];
        for (char[] row : board) {
            Arrays.fill(row, '.');
        }

        // 🌟 致命武器：用三个布尔数组，实现 O(1) 的冲突查杀！
        boolean[] cols = new boolean[n]; // 记录哪一列已经被占了
        boolean[] diag1 = new boolean[2 * n - 1]; // 记录主对角线 (\) row - col 为常数
        boolean[] diag2 = new boolean[2 * n - 1]; // 记录副对角线 (/) row + col 为常数

        backtrack(board, 0, n, cols, diag1, diag2);
        return res;
    }

    // 参数：棋盘，当前处理到的行号(row)，N，三个冲突记录表
    private void backtrack(char[][] board, int row, int n, boolean[] cols, boolean[] diag1, boolean[] diag2) {
        // 1. 终止条件：如果成功走到了第 N 行（越界了），说明 0 到 N-1 行都成功放上了皇后！
        if (row == n) {
            res.add(arrayToList(board));
            return;
        }

        // 2. 站在当前行，面对 N 个列，开始做选择
        for (int col = 0; col < n; col++) {
            // 计算当前坐标所属的对角线编号
            // diag1: row - col 可能是负数，加上 n - 1 使其映射到 0 到 2n-2 的正数索引
            int d1 = row - col + n - 1;
            // diag2: row + col 必然是正数
            int d2 = row + col;

            // --- 查杀剪枝 ---
            // 如果列被占了，或者两条斜线被占了，死路一条，直接跳过
            if (cols[col] || diag1[d1] || diag2[d2]) {
                continue;
            }

            // --- 做选择（放皇后，并拉起警戒线） ---
            board[row][col] = 'Q';
            cols[col] = true;
            diag1[d1] = true;
            diag2[d2] = true;

            // --- 递归进入下一行 ---
            backtrack(board, row + 1, n, cols, diag1, diag2);

            // --- 撤销选择（回溯魔法，把皇后拿走，撤销警戒线） ---
            board[row][col] = '.';
            cols[col] = false;
            diag1[d1] = false;
            diag2[d2] = false;
        }
    }

    // 辅助函数：把 char[][] 棋盘转换成题目要求的 List<String>
    private List<String> arrayToList(char[][] board) {
        List<String> list = new ArrayList<>();
        for (char[] row : board) {
            list.add(new String(row));
        }
        return list;
    }
}

复杂度

  • 时间复杂度：O(N!)。在第一行放置皇后有 N 种选择，第二行最多有 N-1 种选择（实际受斜线影响更少），第三行最多 N-2 种... 整体复杂度是阶乘级别。但这已经是 N 皇后问题的理论最优解了。
  • 空间复杂度：O(N)。三个布尔数组的长度都在 2N 以内，递归调用栈的深度最大为 N。不算结果集的空间，这是完美的线性空间。
易错点与扩展（面试的高难追问）

  • 面试终极追问：“你能把空间复杂度进一步压缩吗？连那三个 boolean[] 数组都不要！”（对应力扣 52 题：N皇后 II）

  • 满分优化思路（位运算优化 / Bitmask）：

    面试面试中最爱问位运算！既然 N 一般都不超过 32，那我们可以直接用 3 个 int 变量来代替那 3 个布尔数组！

    我们用一个 32 位的整数，0 代表空，1 代表被占。

    • col：第 i 列被占，就把 col 的第 i 位置为 1（col |= (1 << i)）。

    • diag1：进入下一行时，左对角线的攻击范围会整体向左平移一位！所以只需要 (diag1 | (1 << i)) << 1。

    • diag2：进入下一行时，右对角线的攻击范围会整体向右平移一位！只需 (diag2 | (1 << i)) >> 1。

    这种利用 CPU 寄存器极速位运算解 N 皇后的算法，是传说中的 “N 皇后位运算进阶”，写出来能让面试官直接给你发 SSSP（特级 Offer）！
