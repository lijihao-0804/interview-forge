## 题目与约束

给你一个整数数组 `nums` ，数组中的元素 **互不相同** 。返回该数组所有可能的子集（幂集）。

  解集 **不能** 包含重复的子集。你可以按 **任意顺序** 返回解集。

  **示例 1：**

  **输入：**nums = [1,2,3]<br>**输出：**[[],[1],[2],[1,2],[3],[1,3],[2,3],[1,2,3]]

  **示例 2：**

  **输入：**nums = [0]<br>**输出：**[[],[0]]

  **提示：**

  - `1 <= nums.length <= 10`
  - `-10 <= nums[i] <= 10`
  - `nums` 中的所有元素 **互不相同**

## Java 完整推导



### Java 核心不变量



> 每个递归节点本身就是一个合法子集。

## 完整推导

### 思路推导
  1. **直觉与痛点（排列 vs 子集的本质区别）**：

     全排列找的是**叶子节点**（一定要等口袋装满了 3 个数字才算一个结果）。

     但子集找的是**树上的所有节点**！甚至连一开始什么都没装的空树根 `[]`，也是一个合法的子集。所以，我们走到任何一个节点，都要把它放进结果集里。

  2. **破局思路（不走回头路的 `startIndex`）**：

     怎么避免收集了 `[1, 2]` 之后，又跑去收集 `[2, 1]` 呢？

     答案是：**永远只向后看！**

     - 当你抓了 `1` 之后，你面前的选项只剩下它后面的 `[2, 3]`。

     - 当你抓了 `2` 之后，你面前的选项只剩下它后面的 `[3]`。（绝对不允许再回头去抓 `1`）

     - 当你抓了 `3` 之后，后面没数字了，这条路就结束了。

       为了实现这个“只向后看”的机制，我们在回溯函数里加一个参数 `startIndex`。每次向下一层递归时，告诉下一层：“你只能从 `startIndex + 1` 开始挑数字哦！”
### Java 实现（子集黄金模板）
```Java
import java.util.ArrayList;
import java.util.List;

class Solution {
    List<List<Integer>> res = new ArrayList<>();

    public List<List<Integer>> subsets(int[] nums) {
        List<Integer> currentPath = new ArrayList<>();
        // 从索引 0 开始挑选
        backtrack(nums, 0, currentPath);
        return res;
    }

    private void backtrack(int[] nums, int startIndex, List<Integer> currentPath) {
        // 🌟 核心差异 1：收集树上的【所有节点】
        // 不需要写终止条件才收集，来到一个新节点，二话不说先把它装进结果集！
        res.add(new ArrayList<>(currentPath));

        // 🌟 核心差异 2：用 startIndex 控制遍历的起点，不走回头路
        for (int i = startIndex; i < nums.length; i++) {
            // --- 做选择 ---
            currentPath.add(nums[i]);

            // --- 递归进入下一层 ---
            // 注意！这里传给下一层的是 i + 1，意思是：
            // 如果我这一层挑了索引为 i 的数字，下一层只能从 i 的后面开始挑！
            backtrack(nums, i + 1, currentPath);

            // --- 撤销选择（回溯） ---
            currentPath.remove(currentPath.size() - 1);
        }
    }
}
```
### 复杂度
  - **时间复杂度**：$O(N \times 2^N)$。一个包含 $N$ 个元素的集合，它的子集一共有 $2^N$ 个。每个子集加入结果集时都需要拷贝一次（拷贝时间与子集长度有关，平均为 $N/2$），所以总时间复杂度是 $O(N \times 2^N)$。
  - **空间复杂度**：$O(N)$。主要消耗在递归调用栈的深度和 `currentPath` 数组上，最大深度为 $N$。

### 易错点与扩展（面试高频连环问）

1. **踩坑警告：`used` 数组和 `startIndex` 到底怎么选？**

   - 记住这个口诀：**排列问题用 `used`，组合/子集问题用 `startIndex`。**
   - 全排列讲究顺序（[1,2] 和 [2,1] 不同），所以每次都要从头开始扫整个数组，靠 `used` 数组来跳过已经选过的数。
   - 子集/组合不讲究顺序，为了去重，必须强制规定选取的顺序（比如只能从前往后选），所以靠 `startIndex` 挡住后面的递归回头看。

2. **面试追问：“如果给你的 `nums` 数组里面有【重复数字】（例如 `[1, 2, 2]`），你该怎么修改代码，保证子集不重复？”（对应力扣 90 题：子集 II）**

   - **满分抢答**：依然是**排序 + 剪枝**！

   - 先对数组排序：`[1, 2, 2]`。

   - 在 `for` 循环里加入极其经典的树层剪枝代码：

     `if (i > startIndex && nums[i] == nums[i - 1]) continue;`

   - *解释*：注意这里是 `i > startIndex` 而不是全排列里的 `i > 0`。它的意思是：在**同一个树层（同一层 for 循环）**中，如果当前数字和前一个数字一样，说明前一个数字已经把包含该数字的所有子集都找过了，直接跳过。但如果是**树枝向下（递归到了下一层）**，是可以选重复数字的（比如允许出现 `[2, 2]`）。

## Python 完整推导

### 每个递归节点都是一个答案

全排列要等到 path 装够 n 个元素才收集，子集则不同：`[]`、`[1]`、`[1,2]` 都是合法结果。因此每次进入递归函数，先把当前 path 复制保存，再继续尝试添加后面的元素。

为避免把 `[1,2]` 和 `[2,1]` 当成两个集合，规定只能向后选。参数 `start` 表示本层允许的最小下标；选了 `nums[index]` 后，下一层从 `index + 1` 开始。

### 用 `[1,2,3]` 走一遍

1. 根节点 `path=[]`，先保存空集。
2. 尝试 1，进入 `[1]` 后保存；再选 2，保存 `[1,2]`；再选 3，保存 `[1,2,3]`。
3. 退回 `[1]`，3 仍未尝试，于是得到 `[1,3]`。退回根后，从 2 开始得到 `[2]`、`[2,3]`，最后得到 `[3]`。

顺序是 `[]、[1]、[1,2]、[1,2,3]、[1,3]、[2]、[2,3]、[3]`。每个子集对应一条从根到某个递归节点的选择路径。

子集数量固定为 2 的 n 次方，就算输入元素互不相同也不应再额外去重。结果里的空列表来自根节点，而不是某个循环分支结束后的补充；保存后继续向更深层扩展。每个元素在一条路径上只会被加入一次，不同路径则可以选择不同元素组合，最终恰好覆盖所有子集，输出展开后的排列顺序也固定。

### Python 实现

> 参考来源：代码随想录（programmercarl.com）
>
> 沿用项目旧 Python 的子集回溯代码与旧 Java 的“收集所有递归节点、只向后看”说明；仅整理导入、函数边界和注释。

```python
from typing import List


class Solution:
    def subsets(self, nums: List[int]) -> List[List[int]]:
        answer = []
        path = []

        def backtrack(start):
            answer.append(path[:])
            for index in range(start, len(nums)):
                path.append(nums[index])
                backtrack(index + 1)
                path.pop()

        backtrack(0)
        return answer
```

### 为什么用 start 而不是 used

组合不关心先后。start 规定了唯一的选择顺序：选了下标较大的元素后，不允许回头补一个更小下标。这样每个集合只会沿递增下标生成一次，额外只需 path，不需要 used 数组。

递归没有显式终止分支也有自然边界：`range(start, len(nums))` 为空时循环不执行，函数返回父层。刚进入时空集的保存已经发生，因此最终仍包含空输入的唯一结果 `[[]]`。

### 复杂度

- 时间复杂度：`O(n·2ⁿ)`。
- 空间复杂度：`O(n)`。

共有 2ⁿ 个递归节点，每个节点复制当前 path，最坏总复制量 O(n·2ⁿ)；递归与 path 深度 O(n)，答案空间另计。

## Go 实现

> 实现来源：代码随想录（programmercarl.com）



```go
var (
    path   []int
    res  [][]int
)
func subsets(nums []int) [][]int {
    res, path = make([][]int, 0), make([]int, 0, len(nums))
    dfs(nums, 0)
    return res
}
func dfs(nums []int, start int) {
    tmp := make([]int, len(path))
    copy(tmp, path)
    res = append(res, tmp)

    for i := start; i < len(nums); i++ {
        path = append(path, nums[i])
        dfs(nums, i+1)
        path = path[:len(path)-1]
    }
}
```

## C 实现

> 实现来源：代码随想录（programmercarl.com）



```c
int* path;
int pathTop;
int** ans;
int ansTop;
//记录二维数组中每个一维数组的长度
int* length;
//将当前path数组复制到ans中
void copy() {
    int* tempPath = (int*)malloc(sizeof(int) * pathTop);
    int i;
    for(i = 0; i < pathTop; i++) {
        tempPath[i] = path[i];
    }
    ans = (int**)realloc(ans, sizeof(int*) * (ansTop+1));
    length[ansTop] = pathTop;
    ans[ansTop++] = tempPath;
}

void backTracking(int* nums, int numsSize, int startIndex) {
    //收集子集，要放在终止添加的上面，否则会漏掉自己
    copy();
    //若startIndex大于数组大小，返回
    if(startIndex >= numsSize) {
        return;
    }
    int j;
    for(j = startIndex; j < numsSize; j++) {
        //将当前下标数字放入path中
        path[pathTop++] = nums[j];
        backTracking(nums, numsSize, j+1);
        //回溯
        pathTop--;
    }
}

int** subsets(int* nums, int numsSize, int* returnSize, int** returnColumnSizes){
    //初始化辅助变量
    path = (int*)malloc(sizeof(int) * numsSize);
    ans = (int**)malloc(0);
    length = (int*)malloc(sizeof(int) * 1500);
    ansTop = pathTop = 0;
    //进入回溯
    backTracking(nums, numsSize, 0);
    //设置二维数组中元素个数
    *returnSize = ansTop;
    //设置二维数组中每个一维数组的长度
    *returnColumnSizes = (int*)malloc(sizeof(int) * ansTop);
    int i;
    for(i = 0; i < ansTop; i++) {
        (*returnColumnSizes)[i] = length[i];
    }
    return ans;
}
```
