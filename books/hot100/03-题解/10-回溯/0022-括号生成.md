## 题目与约束

数字 `n` 代表生成括号的对数，请你设计一个函数，用于能够生成所有可能的并且 **有效的**括号组合。

  **示例 1：**

  **输入：**n = 3<br>**输出：**["((()))","(()())","(())()","()(())","()()()"]

  **示例 2：**

  **输入：**n = 1<br>**输出：**["()"]

  **提示：**

  - `1 <= n <= 8`

## 完整推导

### 思路推导
  1. **直觉与痛点（暴力的代价）**：

     最暴力的做法是：总共需要放 `2n` 个字符，每个位置要么放 `(` 要么放 `)`。我们不管三七二十一，用回溯法生成所有 $2^{2n}$ 种组合，最后写个函数挨个检查它们是不是合法的括号。

     **痛点**：极其浪费算力！当生成出 `)(` 作为开头时，其实就已经死局了，但暴力法还会傻乎乎地把它后面的所有组合生成完。

  2. **破局思路（边生成边校验的双指针）**：

     我们要把事后的“尸检”，变成事前的“体检”。

     我们在回溯的时候，手里拿着两个计数器：**`leftCount`（左括号用了几个）** 和 **`rightCount`（右括号用了几个）**。

     然后，死死盯住**两条黄金天规**：

     - **天规一（左括号的底线）**：只要左括号的数量还没达到 `n`（`leftCount < n`），你**随时随地**都可以放左括号。
     - **天规二（右括号的红线）**：右括号绝对不能比左括号多！所以，**只有当目前放的右括号比左括号少时（`rightCount < leftCount`）**，你才有资格放一个右括号。

  3. **逻辑推演**：

     拿着这两条天规去走迷宫，但凡违反任何一条，连路口都不让进（完美剪枝）。当 `leftCount == n` 且 `rightCount == n` 时，一条完美的合法括号链就诞生了。
### Java 实现（满分规则剪枝版）
```Java
import java.util.ArrayList;
import java.util.List;

class Solution {
    List<String> res = new ArrayList<>();

    public List<String> generateParenthesis(int n) {
        StringBuilder path = new StringBuilder();
        // 初始状态：左括号 0 个，右括号 0 个
        backtrack(n, 0, 0, path);
        return res;
    }

    private void backtrack(int n, int leftCount, int rightCount, StringBuilder path) {
        // 1. 终止条件：当左括号和右括号都用完了，说明找到了一组合法的括号
        if (leftCount == n && rightCount == n) {
            res.add(path.toString());
            return;
        }

        // 2. 尝试放置【左括号】
        // 天规一：只要左括号没用完，就可以一直放
        if (leftCount < n) {
            path.append("("); // 做选择
            backtrack(n, leftCount + 1, rightCount, path); // 进入下一层
            path.deleteCharAt(path.length() - 1); // 撤销选择（回溯）
        }

        // 3. 尝试放置【右括号】
        // 天规二：只有目前右括号比左括号少，才能放右括号，否则就会出现 ())( 的非法情况
        if (rightCount < leftCount) {
            path.append(")"); // 做选择
            backtrack(n, leftCount, rightCount + 1, path); // 进入下一层
            path.deleteCharAt(path.length() - 1); // 撤销选择（回溯）
        }
    }
}
```
### 复杂度
  - 这道题的时间复杂度和空间复杂度非常特殊，它涉及到一个极其著名的数学数列——**卡特兰数 (Catalan Number)**。
  - **时间复杂度**：$O\left(\frac{4^n}{\sqrt{n}}\right)$。第 `n` 个卡特兰数决定了合法括号的组合总数。因为我们使用了完美的剪枝，算法的时间复杂度严格等于解的数量，没有浪费一丝一毫的算力。
  - **空间复杂度**：$O(n)$。除了存储结果的列表外，递归调用栈的深度以及 `StringBuilder` 的长度最大均为 $2n$。

### 易错点与扩展（面试的终极拷问）

1. **面试追问：“如果我想偷懒，把传入参数直接写成 `String path`，不写撤销操作，可以吗？”**
   - **回答**：可以，因为 `String` 是不可变的。每次 `path + "("` 都会生成一个新的字符串传给下一层，当前层的 `path` 并没有被修改，所以自然就不需要撤销。
   - **灵魂暴击**：但是！在追求极致性能的工业界或面试面试中，每次拼接都会产生新的字符串对象，造成大量内存碎片。虽然这题的 $n$ 最大只有 8，用 `String` 不会超时，但使用 `StringBuilder` 并在最后 `deleteCharAt` 是**最高级的工程品味**，它体现了你对内存控制的严谨。
2. **面试追问：“你能用【动态规划】来解这道题吗？”**
   - 这是一道绝佳的思考题。如果有 `n` 对括号，其实可以分解为：**`(` + `a` 对括号的合法组合 + `)` + `b` 对括号的合法组合**。其中 $a + b = n - 1$。
   - 通过遍历 $a$ 从 $0$ 到 $n-1$，我们可以利用之前算好的子结果，拼凑出当前的答案。这证明了回溯题有时候可以用 DP 来降维！

## Python 完整推导

### 只走仍有机会合法的分支

生成 `2n` 个括号位置时，每个位置似乎都有两种选择，但许多前缀已经不可能合法：右括号多于左括号后的任何补法都无法修复。回溯时用 `left`、`right` 记录已放数量，从源头排除这些死路。

放左括号的条件是 `left < n`，因为总共只有 n 个；放右括号的条件是 `right < left`，因为上一步之前一定要有可匹配的左括号。

### 用 `n = 2` 走一遍

1. 从 `(0,0)` 出发，只能放左括号，path 变为 `(`，计数为 `(1,0)`。
2. 此时左括号还能放，也可以放右括号。若继续放左得到 `((`、计数 `(2,0)`；下一层左额度用完，只能连续补右，最终得到 `(())`。
3. 回到路径 `(` 后，改放右括号得到 `()`、计数 `(1,1)`；再到下一层放左得到 `()(`，最后补右得到 `()()`。
4. 其他两个位置组合，例如第一次就尝试右括号，会因 `right < left` 不成立而不进入，因此不会生成 `)(`。

最终答案是 `["(())", "()()"]`。每一步新增字符后都弹出恢复，分支之间只共享当前 path 状态。

如果已经放满 n 个左括号，仍可以先尝试右侧条件；只要 right 还小于 left，就还有可以与其配对的左括号，路径不会提前断掉。最终两个计数与长度判断同时收敛。

### Python 实现

> 参考来源：经典解法实现
>
> 沿用项目旧 Python 的左右计数回溯与旧 Java 的两条黄金规则；仅整理导入、变量和注释。

```python
from typing import List


class Solution:
    def generateParenthesis(self, n: int) -> List[str]:
        answer = []
        path = []

        def backtrack(left, right):
            if len(path) == 2 * n:
                answer.append("".join(path))
                return
            if left < n:
                path.append("(")
                backtrack(left + 1, right)
                path.pop()
            if right < left:
                path.append(")")
                backtrack(left, right + 1)
                path.pop()

        backtrack(0, 0)
        return answer
```

### 两个计数器怎样保持前缀合法

`left`、`right` 在本层递归中不变；选择括号时只在递归参数里加一。这样兄弟分支不会互相污染。

`right < left` 比“右括号还没到 n”更严格：即使右边额度还在，也不能在原路径没有多余左括号时放下。`len(path) == 2 * n` 使用字符总数判断叶节点，两个计数此时自然都为 n。

### 复杂度

- 时间复杂度：`O(n·Cₙ)`。
- 空间复杂度：`O(n)`。

搜索只保留能形成合法前缀的分支，叶节点数等于第 n 个卡特兰数 Cₙ；每个叶子用 join 复制长度 2n 的字符串，因此时间 O(n·Cₙ)。递归深度与 path 长度至多 2n，即 O(n)，答案空间另计。

## C++ 实现

> 实现来源：经典解法实现

<ol class="lang-steps"><li>回溯：每层选择放 '(' 或 ')'</li><li>约束：左括号剩余可用才可放 '('；已放右括号数 < 左括号数才可放 ')'</li><li>长度达到 2n 时收集方案</li></ol>

```cpp
class Solution {
    vector<string> out;
    void go(string& cur, int left, int right, int n) {
        if (cur.size() == 2 * n) { out.push_back(cur); return; }
        if (left < n)   { cur.push_back('('); go(cur, left + 1, right, n); cur.pop_back(); }
        if (right < left) { cur.push_back(')'); go(cur, left, right + 1, n); cur.pop_back(); }
    }
public:
    vector<string> generateParenthesis(int n) {
        string cur;
        go(cur, 0, 0, n);
        return out;
    }
};
```

## Go 实现

> 实现来源：经典解法实现

<ol class="lang-steps"><li>回溯：每层选择放 '(' 或 ')'</li><li>约束：左括号剩余可用才可放 '('；已放右括号数 < 左括号数才可放 ')'</li><li>长度达到 2n 时收集方案</li></ol>

```go
func generateParenthesis(n int) []string {
    var out []string
    var path []byte
    var go func(left, right int)
    go = func(left, right int) {
        if len(path) == 2*n { out = append(out, string(path)); return }
        if left < n { path = append(path, '('); go(left+1, right); path = path[:len(path)-1] }
        if right < left { path = append(path, ')'); go(left, right+1); path = path[:len(path)-1] }
    }
    go(0, 0)
    return out
}
```

## C 实现

> 实现来源：经典解法实现

<ol class="lang-steps"><li>回溯：每层选择放 '(' 或 ')'</li><li>约束：左括号剩余可用才可放 '('；已放右括号数 < 左括号数才可放 ')'</li><li>长度达到 2n 时收集方案</li></ol>

```c
char out[2048][64]; int outN = 0;
void go(char* cur, int pos, int left, int right, int n) {
    if (pos == 2 * n) { cur[pos] = 0; strcpy(out[outN++], cur); return; }
    if (left < n)   { cur[pos] = '('; go(cur, pos + 1, left + 1, right, n); }
    if (right < left) { cur[pos] = ')'; go(cur, pos + 1, left, right + 1, n); }
}
char** generateParenthesis(int n, int* returnSize) {
    char** result = malloc(sizeof(char*) * 2048);
    char cur[64];
    outN = 0;
    go(cur, 0, 0, 0, n);
    for (int i = 0; i < outN; i++) result[i] = strdup(out[i]);
    *returnSize = outN;
    return result;
}
```
