# 131. 分割回文串

|---|---|
| 难度 | 中等 |

## 题目与约束

给你一个字符串 `s`，请你将`s`分割成一些 子串，使每个子串都是 **回文串** 。返回 `s` 所有可能的分割方案。

  **示例 1：**

  **输入：**s = "aab"
  **输出：**[["a","a","b"],["aa","b"]]

  **示例 2：**

  **输入：**s = "a"
  **输出：**[["a"]]

  **提示：**

  - `1 <= s.length <= 16`
  - `s` 仅由小写英文字母组成

[🔗 前往力扣原题验证 →](https://leetcode.cn/problems/palindrome-partitioning/?envType=study-plan-v2&envId=top-100-liked)

## 核心不变量

> 只有当前切片是回文串时才进入下一层。

## 完整推导

### 思路推导
  1. **直觉与痛点（怎么用回溯模拟“切蛋糕”？）**：

     之前我们在数组里挑数字，`startIndex` 代表“我当前能从哪个数字开始挑”。

     在字符串里，**`startIndex` 就代表“我当前这把刀，起点在哪里”**。

     而 `for` 循环里的游标 **`i`，就代表“我当前这把刀，终点切在哪里”**。

     所以，被切下来的这块蛋糕，就是字符串 `s.substring(startIndex, i + 1)`！

  2. **破局思路（边切边检查，非回文直接扔）**：

     假设字符串是 `aab`，`startIndex` 在 0。

     - 我们先试着切第一刀，切下 `a`（`i = 0`）。它是回文吗？是！好，把 `a` 装进口袋，然后剩下的 `ab` 留给下一层去切（传给下一层的参数是 `i + 1`）。
     - 等下一层全切完了退回来，我们撤销选择，试着切第二刀，切下 `aa`（`i = 1`）。它是回文吗？是！装进口袋，把剩下的 `b` 交给下一层。
     - 再次退回，试着切第三刀，切下 `aab`（`i = 2`）。它是回文吗？不是！**直接跳过（剪枝）**，连下一层都不用去了，因为当前这块都不合法。

  3. **逻辑推演（终止条件）**：

     什么时候说明蛋糕被完美切完了？

     当我们的刀的起点 `startIndex` 已经**越过了整个字符串的末尾（等于 `s.length()`）**，说明连一点碎屑都没剩下，此时口袋里装的所有子串就是一种完美的合法分割方案！
### Java 实现（满分双指针回文校验版）
```java
import java.util.ArrayList;
import java.util.List;

class Solution {
    List<List<String>> res = new ArrayList<>();

    public List<List<String>> partition(String s) {
        List<String> currentPath = new ArrayList<>();
        // 从索引 0 开始准备下第一刀
        backtrack(s, 0, currentPath);
        return res;
    }

    private void backtrack(String s, int startIndex, List<String> currentPath) {
        // 1. 终止条件：切菜板上的起点已经超出了字符串末尾，说明整条字符串都被切干净了
        if (startIndex == s.length()) {
            res.add(new ArrayList<>(currentPath));
            return;
        }

        // 2. 尝试下刀：从 startIndex 开始，一寸一寸往后试探切口 i
        for (int i = startIndex; i < s.length(); i++) {
            // --- 核心剪枝 ---
            // 判断当前切下来的这一块 s[startIndex...i] 是不是回文串
            if (isPalindrome(s, startIndex, i)) {
                // 如果是，做选择：把它切下来，装进盘子里
                String subStr = s.substring(startIndex, i + 1);
                currentPath.add(subStr);
            } else {
                // 如果不是回文，直接放弃这种切法，连下一层都不用进去了，继续往后找新的切口 i
                continue;
            }

            // --- 递归进入下一层 ---
            // 剩下的字符串从 i + 1 开始，交给下一层继续切
            backtrack(s, i + 1, currentPath);

            // --- 撤销选择（回溯） ---
            // 退回来，把刚刚切下来的那一块拿掉，尝试在当前层换个地方下刀
            currentPath.remove(currentPath.size() - 1);
        }
    }

    // 辅助函数：双指针法判断字符串 s 的 [left, right] 区间是否是回文串
    private boolean isPalindrome(String s, int left, int right) {
        while (left < right) {
            if (s.charAt(left) != s.charAt(right)) {
                return false;
            }
            left++;
            right--;
        }
        return true;
    }
}
```
### 复杂度
  - **时间复杂度**：$O(N \cdot 2^N)$。最坏情况下（比如字符串全是同一个字符 `"aaaaa"`），每一个位置都可以切，一共有 $2^{N-1}$ 种分割方法。每次还要花 $O(N)$ 的时间生成子串和检查回文，所以总时间复杂度是极其暴力的指数级。
  - **空间复杂度**：$O(N)$。主要消耗在递归调用栈的深度上，最大深度就是字符串的长度 $N$（全切成单字符）。

### 易错点与扩展（面试的性能压榨）

- **面试终极追问：“如果在最坏情况下（如 `"aaaaaaaa"`），每次判断回文 `isPalindrome` 都有极大的冗余重复计算，你能优化吗？”**

  - **满分优化思路（动态规划预处理）**：

    面试官想听到的绝对是“动态规划（DP）”！

    如果在回溯之前，我们先开辟一个 $N \times N$ 的布尔型二维数组 `dp`。`dp[i][j]` 表示字符串从 $i$ 到 $j$ 是否是回文串。

    利用 DP 的状态转移方程：`dp[i][j] = (s[i] == s[j]) && dp[i+1][j-1]`，我们可以在 $O(N^2)$ 的时间里把所有可能的子串是不是回文全部提前算出来！

    这样，在回溯的 `for` 循环里，`isPalindrome` 函数就变成了一次 $O(1)$ 的查表操作：`if (dp[startIndex][i])`。这才是这道题最完美的工业级终极形态！
