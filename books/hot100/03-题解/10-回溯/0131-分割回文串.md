## 题目与约束

给你一个字符串 `s`，请你将`s`分割成一些 子串，使每个子串都是 **回文串** 。返回 `s` 所有可能的分割方案。

  **示例 1：**

  **输入：**s = "aab"<br>**输出：**[["a","a","b"],["aa","b"]]

  **示例 2：**

  **输入：**s = "a"<br>**输出：**[["a"]]

  **提示：**

  - `1 <= s.length <= 16`
  - `s` 仅由小写英文字母组成

## 完整推导

### 思路推导
  1. **直觉与痛点（怎么用回溯模拟“切蛋糕”？）**：

     之前我们在数组里挑数字，`startIndex` 代表“我当前能从哪个数字开始挑”。

     在字符串里，**`startIndex` 就代表“我当前这把刀，起点在哪里”**。

     而 `for` 循环里的游标 **`i`，就代表“我当前这把刀，终点切在哪里”**。

     所以，被切下来的这块蛋糕，就是字符串 `s.substring(startIndex, i + 1)`！

  2. **破局思路（边切边检查，非回文直接扔）**：

     假设字符串是 `aab`，`startIndex` 在 0。

     - 我们先试着切第一刀，切下 `a`（`i = 0`）。它是回文吗？是！好，把 `a` 装进口袋，然后剩下的 `ab` 留给下一层去切（传给下一层的参数是 `i + 1`）。
     - 等下一层全切完了退回来，我们撤销选择，试着切第二刀，切下 `aa`（`i = 1`）。它是回文吗？是！装进口袋，把剩下的 `b` 交给下一层。
     - 再次退回，试着切第三刀，切下 `aab`（`i = 2`）。它是回文吗？不是！**直接跳过（剪枝）**，连下一层都不用去了，因为当前这块都不合法。

  3. **逻辑推演（终止条件）**：

     什么时候说明蛋糕被完美切完了？

     当我们的刀的起点 `startIndex` 已经**越过了整个字符串的末尾（等于 `s.length()`）**，说明连一点碎屑都没剩下，此时口袋里装的所有子串就是一种完美的合法分割方案！
### Java 实现（满分双指针回文校验版）
```java
import java.util.ArrayList;
import java.util.List;

class Solution {
    List<List<String>> res = new ArrayList<>();

    public List<List<String>> partition(String s) {
        List<String> currentPath = new ArrayList<>();
        // 从索引 0 开始准备下第一刀
        backtrack(s, 0, currentPath);
        return res;
    }

    private void backtrack(String s, int startIndex, List<String> currentPath) {
        // 1. 终止条件：切菜板上的起点已经超出了字符串末尾，说明整条字符串都被切干净了
        if (startIndex == s.length()) {
            res.add(new ArrayList<>(currentPath));
            return;
        }

        // 2. 尝试下刀：从 startIndex 开始，一寸一寸往后试探切口 i
        for (int i = startIndex; i < s.length(); i++) {
            // --- 核心剪枝 ---
            // 判断当前切下来的这一块 s[startIndex...i] 是不是回文串
            if (isPalindrome(s, startIndex, i)) {
                // 如果是，做选择：把它切下来，装进盘子里
                String subStr = s.substring(startIndex, i + 1);
                currentPath.add(subStr);
            } else {
                // 如果不是回文，直接放弃这种切法，连下一层都不用进去了，继续往后找新的切口 i
                continue;
            }

            // --- 递归进入下一层 ---
            // 剩下的字符串从 i + 1 开始，交给下一层继续切
            backtrack(s, i + 1, currentPath);

            // --- 撤销选择（回溯） ---
            // 退回来，把刚刚切下来的那一块拿掉，尝试在当前层换个地方下刀
            currentPath.remove(currentPath.size() - 1);
        }
    }

    // 辅助函数：双指针法判断字符串 s 的 [left, right] 区间是否是回文串
    private boolean isPalindrome(String s, int left, int right) {
        while (left < right) {
            if (s.charAt(left) != s.charAt(right)) {
                return false;
            }
            left++;
            right--;
        }
        return true;
    }
}
```
### 复杂度
  - **时间复杂度**：$O(N \cdot 2^N)$。最坏情况下（比如字符串全是同一个字符 `"aaaaa"`），每一个位置都可以切，一共有 $2^{N-1}$ 种分割方法。每次还要花 $O(N)$ 的时间生成子串和检查回文，所以总时间复杂度是极其暴力的指数级。
  - **空间复杂度**：$O(N)$。主要消耗在递归调用栈的深度上，最大深度就是字符串的长度 $N$（全切成单字符）。

### 易错点与扩展（面试的性能压榨）

- **面试终极追问：“如果在最坏情况下（如 `"aaaaaaaa"`），每次判断回文 `isPalindrome` 都有极大的冗余重复计算，你能优化吗？”**

  - **满分优化思路（动态规划预处理）**：

    面试官想听到的绝对是“动态规划（DP）”！

    如果在回溯之前，我们先开辟一个 $N \times N$ 的布尔型二维数组 `dp`。`dp[i][j]` 表示字符串从 $i$ 到 $j$ 是否是回文串。

    利用 DP 的状态转移方程：`dp[i][j] = (s[i] == s[j]) && dp[i+1][j-1]`，我们可以在 $O(N^2)$ 的时间里把所有可能的子串是不是回文全部提前算出来！

    这样，在回溯的 `for` 循环里，`isPalindrome` 函数就变成了一次 $O(1)$ 的查表操作：`if (dp[startIndex][i])`。这才是这道题最完美的工业级终极形态！

## Python 完整推导

### 一刀一刀切出回文片段

用 `start` 表示下一刀从哪里切，`end` 表示当前这一片切到哪里。片段是 `s[start:end+1]`；只有它本身是回文，才能加入 path，并让下一层从 `end+1` 处理剩下的后缀。

回文检查用左右两个下标，从片段两端向中心走。只要有一对字符不同就失败；走到 `left >= right` 说明每一对都相等。

### 用 `"aab"` 走一遍

1. `start=0`，先试片段 `a`，它是回文，path 变为 `[a]`，下一层从 1 开始。
2. `start=1` 处片段 `a` 也是回文，path 变为 `[a,a]`；下一层从 2 开始，片段 `b` 是回文，完成 `[a,a,b]`。
3. 回到根，试 `start=0, end=1` 的片段 `aa`，它左右字符相等，path 变为 `[aa]`。
4. 下一层从 2 开始，只剩 `b`，完成 `[aa,b]`。
5. 最后的整段 `aab` 两端分别是 a、b，不是回文，不进入下一层。

最终结果是两种切法。`start == len(s)` 表示最后一刀恰好落在字符串末尾，path 中的片段无缝隙覆盖全部字符。
这里选择保留双指针检查，而不是先建整张回文表：本题长度最多 16，最长全相同字符串的分支数已经由结果规模主导，检查逻辑和切片动作直接对应，更便于核对每一步。

切割区间的边界始终满足 left <= right，因此不会对空片段检查回文；当 start 恰好到达末尾时，path 已经覆盖全部字符。

### Python 实现

> 参考来源：代码随想录（programmercarl.com）
>
> 沿用项目旧 Python 的回文切片回溯和双指针校验，以及旧 Java 的“切蛋糕”过程；仅整理导入、变量和注释。

```python
from typing import List


class Solution:
    def partition(self, s: str) -> List[List[str]]:
        answer = []
        path = []

        def is_palindrome(left, right):
            while left < right:
                if s[left] != s[right]:
                    return False
                left += 1
                right -= 1
            return True

        def backtrack(start):
            if start == len(s):
                answer.append(path[:])
                return
            for end in range(start, len(s)):
                if not is_palindrome(start, end):
                    continue
                path.append(s[start:end + 1])
                backtrack(end + 1)
                path.pop()

        backtrack(0)
        return answer
```

### API 与可选优化

`s[start:end + 1]` 复制当前片段并加入 path；右端点要加一，因为 Python 切片右端不包含。`continue` 会直接尝试下一种切口，不会把非回文片段留在 path 里。

如果字符串更长，可预先用二维表记录每个区间是否回文，使回溯时查询 O(1)。本题 n <= 16，主解保留旧代码的双指针检查，避免为了理论优化改变清晰的切割叙事；额外表是面试追问中的扩展。

### 复杂度

- 时间复杂度：`O(n·2ⁿ)`。
- 空间复杂度：`O(n)`。

最坏如全 a 字符串有约 2ⁿ 个分割叶节点；每个叶子复制最多 n 个片段，合计 O(n·2ⁿ)。双指针检查会在不同前缀下重复，但调用次数随剩余后缀长度呈倍增关系，所有候选区间的检查与成功切片总成本仍为 O(2ⁿ)，因此总时间 O(n·2ⁿ)；递归栈与 path 深度 O(n)，输出另计。

## C 实现

> 实现来源：代码随想录（programmercarl.com）



```c
char** path;
int pathTop;
char*** ans;
int ansTop = 0;
int* ansSize;

//将path中的字符串全部复制到ans中
void copy() {
    //创建一个临时tempPath保存path中的字符串
    char** tempPath = (char**)malloc(sizeof(char*) * pathTop);
    int i;
    for(i = 0; i < pathTop; i++) {
        tempPath[i] = path[i];
    }
    //保存tempPath
    ans[ansTop] = tempPath;
    //将当前path的长度（pathTop）保存在ansSize中
    ansSize[ansTop++] = pathTop;
}

//判断字符串是否为回文字符串
bool isPalindrome(char* str, int startIndex, int endIndex) {
    //双指针法：当endIndex（右指针）的值比startIndex（左指针）大时进行遍历
    while(endIndex >= startIndex) {
        //若左指针和右指针指向元素不一样，返回False
        if(str[endIndex--] != str[startIndex++])
            return 0;
    }
    return 1;
}

//切割从startIndex到endIndex子字符串
char* cutString(char* str, int startIndex, int endIndex) {
    //开辟字符串的空间
    char* tempString = (char*)malloc(sizeof(char) * (endIndex - startIndex + 2));
    int i;
    int index = 0;
    //复制子字符串
    for(i = startIndex; i <= endIndex; i++)
        tempString[index++] = str[i];
    //用'\0'作为字符串结尾
    tempString[index] = '\0';
    return tempString;
}

void backTracking(char* str, int strLen,  int startIndex) {
    if(startIndex >= strLen) {
        //将path拷贝到ans中
        copy();
        return ;
    }

    int i;
    for(i = startIndex; i < strLen; i++) {
        //若从subString到i的子串是回文字符串，将其放入path中
        if(isPalindrome(str, startIndex, i)) {
            path[pathTop++] = cutString(str, startIndex, i);
        }
        //若从startIndex到i的子串不为回文字符串，跳过这一层 
        else {
            continue;
        }
        //递归判断下一层
        backTracking(str, strLen, i + 1);
        //回溯，将path中最后一位元素弹出
        pathTop--;
    }
}

char*** partition(char* s, int* returnSize, int** returnColumnSizes){
    int strLen = strlen(s);
    //因为path中的字符串最多为strLen个（即单个字符的回文字符串），所以开辟strLen个char*空间
    path = (char**)malloc(sizeof(char*) * strLen);
    //存放path中的数组结果
    ans = (char***)malloc(sizeof(char**) * 40000);
    //存放ans数组中每一个char**数组的长度
    ansSize = (int*)malloc(sizeof(int) * 40000);
    ansTop = pathTop = 0;

    //回溯函数
    backTracking(s, strLen, 0);

    //将ansTop设置为ans数组的长度
    *returnSize = ansTop;
    //设置ans数组中每一个数组的长度
    *returnColumnSizes = (int*)malloc(sizeof(int) * ansTop);
    int i;
    for(i = 0; i < ansTop; ++i) {
        (*returnColumnSizes)[i] = ansSize[i];
    }
    return ans;
}
```
