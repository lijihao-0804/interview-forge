543. 二叉树的直径

难度中等核心模式后序高度 + 全局答案时间复杂度O(n)空间复杂度O(h)

题目与约束

给你一棵二叉树的根节点，返回该树的 直径 。

二叉树的 直径 是指树中任意两个节点之间最长路径的 长度 。这条路径可能经过也可能不经过根节点 root 。

两节点之间路径的 长度 由它们之间边数表示。

示例 1：

输入：root = [1,2,3,4,5]
输出：3
解释：3 ，取路径 [4,2,1,3] 或 [5,2,1,3] 的长度。

示例 2：

输入：root = [1,2]
输出：1

提示：

  • 树中节点数目在范围 [1, 104] 内
  • -100 <= Node.val <= 100

核心不变量

经过当前节点的直径是左高加右高。

完整推导

思路推导

  1. 直觉与痛点（根节点依赖症）：

    直觉公式：直径 = 左子树深度 + 右子树深度。

    痛点：如果你只算根节点的 左+右，你会漏掉那些藏在深山老林里、但内部非常宽广的子树。

  2. 破局思路（全员皆可为王）：

    既然任何一个节点都有可能成为那条最长路径的“最高顶点”（也就是连接左右两端的那个拐点），那我们就一视同仁！

    在求深度的过程中，我们让每一个节点都暗自算一下：“如果我是最高顶点，经过我的最长路径是多少？（也就是我自己的 左子树深度 + 右子树深度）”。

    我们需要在代码外面挂一个全局告示牌（全局变量 maxDiameter），每个节点算完自己的路径长度后，都去和告示牌比一下。如果比告示牌上的数字大，就擦掉旧的，写上自己的。

  3. 逻辑推演（后序遍历的妙用）：

    我们要算深度，必须要等左右小弟都汇报完工作才行，这就是天然的后序遍历（左右中）。

    • 【左】：问左小弟，左子树最大深度是多少？（L）
    • 【右】：问右小弟，右子树最大深度是多少？（R）
    • 【中 - 夹带私货】：算一下经过我这个节点的直径 L + R，如果比全局的 maxDiameter 大，就更新它！
    • 【向上汇报】：向上级（父节点）汇报我这棵树的深度 max(L, R) + 1。

    Java 实现（满分版）

    C++ 实现

    实现来源：经典解法实现

    1. 直径必经过某个节点，长度 = 其左子树深度 + 右子树深度
    2. 后序递归：自底向上返回子树深度（max(左,右)+1）
    3. 每层用 左+右 更新全局最大直径
    class Solution {
    int best = 0;
public:
    int go(TreeNode* node) {
        if (!node) return 0;
        int L = go(node->left), R = go(node->right);
        best = max(best, L + R);              // 经过该节点的路径长
        return max(L, R) + 1;
    }
    int diameterOfBinaryTree(TreeNode* root) {
        go(root);
        return best;
    }
};

    实现来源：经典解法实现

    1. 直径必经过某个节点，长度 = 其左子树深度 + 右子树深度
    2. 后序递归：自底向上返回子树深度（max(左,右)+1）

    class Solution:
    def diameterOfBinaryTree(self, root: TreeNode) -> int:
        self.best = 0
        def go(node):
            if not node:
                return 0
            L, R = go(node.left), go(node.right)
            self.best = max(self.best, L + R)   # 经过该节点的路径长
            return max(L, R) + 1
        go(root)
        return self.best

    Go 实现

    实现来源：经典解法实现

    1. 直径必经过某个节点，长度 = 其左子树深度 + 右子树深度
    2. 后序递归：自底向上返回子树深度（max(左,右)+1）
    3. 每层用 左+右 更新全局最大直径
    func diameterOfBinaryTree(root *TreeNode) int {
    best := 0
    var go func(node *TreeNode) int
    go = func(node *TreeNode) int {
        if node == nil { return 0 }
        L, R := go(node.Left), go(node.Right)
        if L+R > best { best = L + R }
        if L > R { return L + 1 }
        return R + 1
    }
    go(root)
    return best
}

    C 实现

    实现来源：经典解法实现

    1. 直径必经过某个节点，长度 = 其左子树深度 + 右子树深度
    2. 后序递归：自底向上返回子树深度（max(左,右)+1）
    3. 每层用 左+右 更新全局最大直径
    int best = 0;
int go(struct TreeNode* node) {
    if (!node) return 0;
    int L = go(node->left), R = go(node->right);
    if (L + R > best) best = L + R;
    return (L > R ? L : R) + 1;
}
int diameterOfBinaryTree(struct TreeNode* root) {
    best = 0;
    go(root);
    return best;
}

/**
 * Definition for a binary tree node.
 * public class TreeNode {
 *     int val;
 *     TreeNode left;
 *     TreeNode right;
 *     TreeNode() {}
 *     TreeNode(int val) { this.val = val; }
 *     TreeNode(int val, TreeNode left, TreeNode right) {
 *         this.val = val;
 *         this.left = left;
 *         this.right = right;
 *     }
 * }
 */
class Solution {
    // 全局告示牌：记录所有节点里，能拼凑出的最大直径
    int maxDiameter = 0;

    public int diameterOfBinaryTree(TreeNode root) {
        // 调用递归函数，但我们其实不在乎它的返回值（根节点的最大深度）
        // 我们真正在乎的是它在递归过程中，顺手更新的 maxDiameter
        depth(root);
        return maxDiameter;
    }

    // 辅助函数：求节点的最大深度，并在内部“夹带私货”更新最大直径
    private int depth(TreeNode node) {
        // 终止条件：空节点深度为 0
        if (node == null) {
            return 0;
        }

        // 向下派发任务，获取左右子树的深度
        int leftDepth = depth(node.left);
        int rightDepth = depth(node.right);

        // 🌟 核心私货：更新全局最大直径
        // 注意：这里的长度是指“边数”，刚好等于 左子树深度 + 右子树深度
        maxDiameter = Math.max(maxDiameter, leftDepth + rightDepth);

        // 向上级汇报工作：返回我自己这棵树的最大深度
        return Math.max(leftDepth, rightDepth) + 1;
    }
}

复杂度

  • 时间复杂度：O(N)。每个节点都被访问了一次，做了一次常数时间的运算。
  • 空间复杂度：O(H)。递归调用栈的最大深度即为树的高度 H。
易错点与扩展（进阶的细节）
  1. 节点数 vs 边数的陷阱： - 力扣上关于路径长度的定义经常变。这道题明确了“路径长度由边数表示”。 - 假设根节点的左孩子深度是 1，右孩子深度是 1。经过根节点的路径一共涉及 3 个节点，但只有 2 条边。刚好 leftDepth + rightDepth = 1 + 1 = 2。公式天生契合题目要求！如果题目要求按节点数算，你得在最后加上 1。
  2. 面试追问：“为什么非要用一个全局变量？我能不能不用全局变量写出来？” - 高情商回答：在 Java 中，由于基础类型是值传递的，我们没法直接通过函数参数传递一个 int 的引用。但如果实在不想把变量写在类层级（污染类的状态，并发时不安全），我们可以：
    • 方法一：传一个只有一个元素的数组 int[] res = new int[1] 进去当作引用传值。
    • 方法二：设计一个自定义的返回值对象（比如 class Result { int depth; int maxDiam; }），让递归函数同时返回两个值（当前深度，和当前子树内的最大直径）。这种写法更符合函数式编程的理念，但在算法题中显得稍微冗长。第一种 int[] 是最常见的优化手段。
