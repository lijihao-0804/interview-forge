236. 二叉树的最近公共祖先

难度中等核心模式后序递归时间复杂度O(n)空间复杂度O(h)

题目与约束

给定一个二叉树, 找到该树中两个指定节点 p 和 q 的最近公共祖先（LCA）。

最近公共祖先定义：“对于有根树 T 的两个节点 p、q，最近公共祖先表示为一个节点 x，满足 x 是 p、q 的祖先且 x 的深度尽可能大（一个节点也可以是它自己的祖先）。”

核心不变量

左右子树各找到一个目标时，当前节点就是最近公共祖先。

完整推导

思路推导

  1. 直觉与痛点（自顶向下的迷茫）：

如果你站在树根往下看，你根本不知道 p 和 q 藏在哪个角落，你很难判断当前节点是不是“最近”的。

  1. 破局思路（自底向上的情报网）：

我们要改变策略：先让小弟们去底下找，找到了再层层往上报！

要想“先看底下，再处理自己”，这完美契合了后序遍历（左 -> 右 -> 中）的逻辑。

  • 我们定义一个递归函数：如果我在我这棵子树里发现了 p 或者 q，我就把发现的节点当做“情报”往上汇报。如果啥也没发现，我就汇报 null。
  1. 逻辑推演（四种情报汇聚场景）：

假设你是一个父节点，你的左小弟和右小弟分别给你汇报了情报（left 和 right）：

Java 实现（极简后序遍历版）

/**
 * Definition for a binary tree node.
 * public class TreeNode {
 * int val;
 * TreeNode left;
 * TreeNode right;
 * TreeNode(int x) { val = x; }
 * }
 */
class Solution {
    public TreeNode lowestCommonAncestor(TreeNode root, TreeNode p, TreeNode q) {
        // 1. 递归终止条件与“撞见目标”
        // 如果越过了叶子节点，返回 null
        // 如果正好撞见 p 或 q，直接把这个节点当做情报返回给上级
        if (root == null || root == p || root == q) {
            return root;
        }

        // 2. 深入敌后：去左边和右边打探情报（后序遍历的体现）
        TreeNode left = lowestCommonAncestor(root.left, p, q);
        TreeNode right = lowestCommonAncestor(root.right, p, q);

        // 3. 汇总情报，向上汇报
        // 场景 A：左右两边都传来了好消息，说明 p 和 q 刚好在我两边，我就是 LCA！
        if (left != null && right != null) {
            return root;
        }

        // 场景 B & C：如果一边有消息，另一边没消息，就把有消息的那边传上去
        // 场景 D：如果两边都没消息，刚好 left 和 right 都是 null，随便返回一个 null 即可
        return left != null ? left : right;
    }
}

C++ 实现

实现来源：站内标准实现

class Solution {
public:
    TreeNode* lowestCommonAncestor(TreeNode* root, TreeNode* p, TreeNode* q) {
        if (root == nullptr || root == p || root == q) return root;
        TreeNode* left = lowestCommonAncestor(root->left, p, q);
        TreeNode* right = lowestCommonAncestor(root->right, p, q);
        if (left != nullptr && right != nullptr) return root; // p、q 分居两侧
        return left != nullptr ? left : right;
    }
};

Go 实现

实现来源：代码随想录（programmercarl.com）

func lowestCommonAncestor(root, p, q *TreeNode) *TreeNode {
    // check
    if root == nil {
        return root
    }
    // 相等 直接返回root节点即可
    if root == p || root == q {
        return root
    }
    // Divide
    left := lowestCommonAncestor(root.Left, p, q)
    right := lowestCommonAncestor(root.Right, p, q)

复杂度

  • 时间复杂度：O(N)。在最坏的情况下，我们需要遍历树的所有节点才能找到 p 和 q。
  • 空间复杂度：O(H)。其中 H 是二叉树的高度。空间消耗主要是递归调用的系统栈，最坏情况下（树退化成链表）为 O(N)，平均情况为 O(log N)。
易错点与扩展（面试连环追问）
  1. 面试追问 1：“如果这是一棵【二叉搜索树 (BST)】，你有更优的解法吗？”（对应力扣 235 题） - 满分抢答：有！因为 BST 左小右大，我们可以利用节点的值进行 O(1) 的方向判断。 - 从根节点往下：如果 p 和 q 的值都大于根节点，说明 LCA 一定在右子树；如果都小于，LCA 一定在左子树；如果一小一大，说明它们在根节点的两侧，当前根节点就是 LCA！ 这就变成了从上往下的迭代，时间复杂度降为 O(H)，空间复杂度降为 O(1)！
  2. 面试追问 2：“如果树里的每个节点都有一个指向父节点的 parent 指针呢？”（对应力扣 1650 题） - 满分抢答：那这就根本不是二叉树的题了，这就变成了“求两个单链表的相交节点”（力扣 160 题）！ - 我们分别从 p 和 q 顺着 parent 指针往上爬，这就相当于两条链表求交点，用双指针法跑两圈就能相遇，空间复杂度直接压缩到 O(1)！
