139. 单词拆分

难度中等
Java 主方法前缀可达性时间O(n²)空间O(n)
Python 主方法前缀可达性 DP + startswith 按位置匹配时间O(D + n·W·Lmax)空间O(n + W)

题目与约束

给你一个字符串 s 和一个字符串列表 wordDict 作为字典。如果可以利用字典中出现的一个或多个单词拼接出 s 则返回 true。

注意：不要求字典中出现的单词全部都使用，并且字典中的单词可以重复使用。

示例 1：

输入: s = "leetcode", wordDict = ["leet", "code"]
输出: true
解释: 返回 true 因为 "leetcode" 可以由 "leet" 和 "code" 拼接成。

示例 2：

输入: s = "applepenapple", wordDict = ["apple", "pen"]
输出: true
解释: 返回 true 因为 "applepenapple" 可以由 "apple" "pen" "apple" 拼接成。
注意，你可以重复使用字典中的单词。

示例 3：

输入: s = "catsandog", wordDict = ["cats", "dog", "sand", "and", "cat"]
输出: false

提示：

  • 1 <= s.length <= 300
  • 1 <= wordDict.length <= 1000
  • 1 <= wordDict[i].length <= 20
  • s 和 wordDict[i] 仅由小写英文字母组成
  • wordDict 中的所有字符串 互不相同

Java 完整推导

Java 核心不变量

dp[i] 表示前 i 个字符是否可由字典组成。

完整推导

思路推导

  1. 直觉与痛点（DFS 回溯的灾难）：

    很多人的直觉是写一个回溯算法：从头开始截取字符串，如果截取到的单词在字典里，就对剩下的字符串继续递归。

    痛点：假设 s = "aaaaab"，字典是 ["a", "aa", "aaa"]。你会产生无数种组合（比如先切 a 再切 aa，或者先切 aa 再切 a），然后走到最后发现都没有 b，全部失败回溯。这种做法会产生极度庞大的重叠子问题，时间复杂度呈指数级 O(2N)，必定超时。

  2. 破局思路（寻找“历史的锚点”）：

    我们换个思路：与其漫无目的地往后切，不如“向后看”。 假设字符串长度为 i。要想知道前 i 个字符能不能被成功拆分，我们只需要在 0 到 i 之间寻找一个切割点 j。 只要满足以下两个条件同时成立，前 i 个字符就一定能被完美拆分：

    • 条件 1：前 j 个字符构成的子串能够被成功拆分（这是历史记录，早就查好了！）。
    • 条件 2：从 j 到 i 剩下的这段子串，刚好在字典里！

  3. 核心微操（状态转移方程）：

    我们定义一个布尔数组 dp[i]：表示字符串 s 的前 i 个字符能否被拆分。

    状态转移方程：

    dp[i]=dp[j]&&wordDict.contains(s[j..i])

    只要在 0 到 i 之间找到任何一个满足条件的 j，dp[i] 就直接定为 true，并停止当前 i 的寻找（因为只要能切开就行，不需要穷举所有切法）。

    Java 实现（满分哈希表提速版）

import java.util.HashSet;
import java.util.List;
import java.util.Set;

class Solution {
    public boolean wordBreak(String s, List<String> wordDict) {
        // 1. 将字典转为 HashSet，把 O(N) 的查找时间降维到 O(1)
        Set<String> dict = new HashSet<>(wordDict);

        // dp[i] 表示：字符串 s 的前 i 个字符能否被成功拆分
        boolean[] dp = new boolean[s.length() + 1];

        // 🌟 边界初始化：空字符串被认为是“可以被拆分”的基石
        // 如果没有 dp[0] = true，后面的推导将无从借力
        dp[0] = true;

        // 外层循环：i 表示当前正在考察的字符串前缀长度
        for (int i = 1; i <= s.length(); i++) {
            // 内层循环：j 表示寻找的切割点
            // 从 0 遍历到 i-1，尝试把前 i 个字符切成 [0..j] 和 [j..i] 两半
            for (int j = 0; j < i; j++) {
                // 如果前半段是合法的，并且后半段在字典里
                if (dp[j] && dict.contains(s.substring(j, i))) {
                    dp[i] = true;
                    break; // 只要找到一种合法的切法，当前 i 就搞定了，直接 break
                }
            }
        }

        // 返回整个字符串能否被拆分
        return dp[s.length()];
    }
}

复杂度

  • 时间复杂度：O(N3)。外层循环 N 次，内层循环 N 次。在 Java 中，s.substring(j, i) 截取子串的操作底层需要复制字符，耗时 O(N)。所以整体是 N × N × N = O(N3)。
  • 空间复杂度：O(N + M)。dp 数组占用了 O(N) 的空间，HashSet 占用了 O(M) 的空间（M 为字典中所有字符的总长度）。
易错点与扩展（面试的性能压榨）
  1. 踩坑警告：s.substring(j, i) 的隐形性能杀手 - 很多同学以为时间复杂度是 O(N2)，因为看到了两层 for 循环。但在面试时，如果你不主动点出 substring 也有时间开销（O(N)），面试官会认为你对语言底层不够了解。
  2. 面试追问：“既然时间复杂度是 O(N3)，如果字典里的单词都很短，但被拆分的字符串极其长，这段代码有优化空间吗？” - 满分抢答（极速剪枝优化）：绝对有！我们可以提前找出字典里“最长单词的长度（maxLength）”。 - 在内层寻找切割点 j 时，根本不需要从 0 扫到 i-1！ - 我们只需要检查从 i - maxLength 到 i - 1 的区间即可。因为如果后半段的长度超过了字典里最长的单词，那它绝对不可能在字典里！ - 这个优化能把内层循环降维成一个常数（最大单词长度），从而将时间复杂度压榨到极尽完美的 O(N2)。

Python 完整推导

在每个可达前缀上接一个词典单词

reachable[end] 表示 s[:end] 能否被字典完整切分。只要一个位置可达，就可以尝试把字典中的单词接在它后面；如果 s.startswith(word, end) 成立，那么结束位置 end + len(word) 也可达。

这比逐个切割位置创建子串更直接：所有状态都由“当前已经拼好的前缀 + 一个单词”产生。reachable[0] = True 是空串能够被切分的起点。

用 s = "leetcode"、词典 ["leet", "code"]

  1. end = 0 可达。尝试 leet，它在下标 0 处匹配，于是 reachable[4] = True；尝试 code 没有匹配。
  2. 扫描到 end = 4，此前 reachable[4] 为真。从 4 开始尝试 code，正好匹配到下标 8。
  3. reachable[8] = True，而 8 就是字符串长度，最终返回 True。

如果 end 不可达，就不会从它向后接词。这个限制避免把字符从中间悬空截断。

容易误判的词典

"catsandog" 可以先切成 cat + sand，也可以切成 cats + and，但剩下的 og 无法继续。两种前缀会留下不同的可达结束位置，DP 会同时记录它们，不因一条切法失败就丢掉另一条。

Python 实现

参考来源：代码随想录（programmercarl.com）

旧项目该条目的 Python 片段只保留回溯入口，不构成完整实现；主解沿用同题旧 Java 的前缀 DP，并把 substring 判断整理为 str.startswith(word, end)，source 仍沿用旧项目标注。

from typing import List


class Solution:
    def wordBreak(self, s: str, wordDict: List[str]) -> bool:
        words = set(wordDict)
        reachable = [False] * (len(s) + 1)
        reachable[0] = True
        for end in range(len(s)):
            if not reachable[end]:
                continue
            for word in words:
                next_end = end + len(word)
                if s.startswith(word, end):
                    reachable[next_end] = True
        return reachable[len(s)]

set 与 str.startswith

words = set(wordDict) 去掉重复单词，后续遍历集合即可；本题只关心是否存在切法，单词尝试顺序不影响最终真假。s.startswith(word, end) 从原字符串的指定位置比较，不需要执行 s[end:next_end] 创建切片。

next_end = end + len(word) 是接上单词后的新前缀长度。即使 next_end 超过字符串长度，startswith 会返回 False，不会把状态写出范围。

时间复杂度

最坏有 n 个可达起点，每个起点尝试 W 个不同单词；一次 startswith 最坏比较 Lmax 个字符，所以建表后时间是 O(n·W·Lmax)。布尔数组表达所有前缀状态，空间 O(n) 外加词典。

复杂度

  • 时间复杂度：O(D + n·W·Lmax)。
  • 空间复杂度：O(n + W)。

设去重词典字符总量 D、单词数 W、最长单词 Lmax、字符串长度 n：建集合约 O(D)，至多 n 个可达位置各尝试 W 个词，每次比较至多 Lmax 个字符，时间 O(D+nWLmax)；状态与词典空间 O(n+W)。

C++ 实现

实现来源：代码随想录（programmercarl.com）

class Solution {
private:
    bool backtracking (const string& s, const unordered_set<string>& wordSet, int startIndex) {
        if (startIndex >= s.size()) {
            return true;
        }
        for (int i = startIndex; i < s.size(); i++) {
            string word = s.substr(startIndex, i - startIndex + 1);
            if (wordSet.find(word) != wordSet.end() && backtracking(s, wordSet, i + 1)) {
                return true;
            }
        }
        return false;
    }
public:
    bool wordBreak(string s, vector<string>& wordDict) {
        unordered_set<string> wordSet(wordDict.begin(), wordDict.end());
        return backtracking(s, wordSet, 0);
    }
};

Go 实现

实现来源：代码随想录（programmercarl.com）

func wordBreak(s string,wordDict []string) bool  {
    wordDictSet := make(map[string]bool)
    for _, w := range wordDict {
        wordDictSet[w] = true
    }
    dp := make([]bool, len(s)+1)
    dp[0] = true
    for i := 1; i <= len(s); i++ {
        for j := 0; j < i; j++ {
            if dp[j] && wordDictSet[s[j:i]] { 
                dp[i] = true
                break
            }
        }
    }
    return dp[len(s)]
}
// 转化为 求装满背包s的前几位字符的方式有几种
func wordBreak(s string, wordDict []string) bool {
    // 装满背包s的前几位字符的方式有几种
    dp := make([]int, len(s)+1)
    dp[0] = 1
    for i := 0; i <= len(s); i++ { // 背包
        for j := 0; j < len(wordDict); j++ { // 物品
            if i >= len(wordDict[j]) && wordDict[j] == s[i-len(wordDict[j]):i] {
                dp[i] += dp[i-len(wordDict[j])]
            }
        }
    }

    return dp[len(s)] > 0
}

C 实现

实现来源：代码随想录（programmercarl.com）

bool wordBreak(char* s, char** wordDict, int wordDictSize) {
    int len = strlen(s);
    // 初始化
    bool dp[len + 1];
    memset(dp, false, sizeof (dp));
    dp[0] = true;
    for (int i = 1; i < len + 1; ++i) {
        for(int j =  0; j < wordDictSize; j++){
            int wordLen = strlen(wordDict[j]);
            // 分割点是由i和字典单词长度决定
            int k = i - wordLen;
            if(k < 0){
                continue;
            }
            // 这里注意要限制长度，故用strncmp
            dp[i] = (dp[k] && !strncmp(s + k, wordDict[j], wordLen)) || dp[i];
        }
    }
    return dp[len];
}
