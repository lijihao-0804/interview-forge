## 题目与约束

假设你正在爬楼梯。需要 `n` 阶你才能到达楼顶。

  每次你可以爬 `1` 或 `2` 个台阶。你有多少种不同的方法可以爬到楼顶呢？

  **示例 1：**

  **输入：**n = 2<br>**输出：**2<br>**解释：**有两种方法可以爬到楼顶。<br>1. 1 阶 + 1 阶<br>2. 2 阶

  **示例 2：**

  **输入：**n = 3<br>**输出：**3<br>**解释：**有三种方法可以爬到楼顶。<br>1. 1 阶 + 1 阶 + 1 阶<br>2. 1 阶 + 2 阶<br>3. 2 阶 + 1 阶

  **提示：**

  - `1 <= n <= 45`

## 完整推导

### 思路推导
  1. **直觉与痛点（暴力的迷惘）**：

     很多人的第一反应是硬算组合数，或者用回溯去穷举所有可能（比如 `1,1,1`, `1,2`, `2,1`）。

     **痛点**：当 `n` 变大时（比如 `n = 45`），回溯树的规模会呈指数级爆炸，时间复杂度是 $O(2^n)$，你的程序会直接卡死。

  2. **降维破局（倒推法与重叠子问题）**：

     DP 的核心秘诀在于“向后看”**。 闭上眼睛想象一下：假如你现在已经神奇地站在了第 `n` 阶台阶上。请问，**你是从哪里走过来的？** 因为题目规定每次只能爬 1 阶或 2 阶，所以你**必定是从第 `n-1` 阶跨了 1 步上来，**或者**是从第 `n-2` 阶跨了 2 步上来！

     除了这两种可能，别无他法。

  3. **核心微操（状态转移方程的诞生）**：

     既然终局只有这两条路，那么：

     **爬到第 `n` 阶的方法总数 = 爬到第 `n-1` 阶的方法总数 + 爬到第 `n-2` 阶的方法总数！**

     这就是大名鼎鼎的状态转移方程：

     $dp[i] = dp[i-1] + dp[i-2]$

     这不就是斐波那契数列（Fibonacci sequence）吗？！我们只需要知道第 1 阶和第 2 阶的答案，就能像滚雪球一样，一路推导到第 `n` 阶！
### Java 实现（满分空间压缩版）
```Java
class Solution {
    public int climbStairs(int n) {
        // 边界防御：1 阶和 2 阶是基石，直接返回
        if (n <= 2) {
            return n;
        }

        // 传统 DP 需要开辟一个长度为 n+1 的数组，空间复杂度 O(n)
        // 但其实每次计算 dp[i]，我们只依赖它前面的【两个】状态！
        // 🌟 极致优化：我们只需要三个变量，交替滚动更新，将空间复杂度降维至 O(1)！

        int prev2 = 1; // 相当于 dp[1]：爬到第 1 阶有 1 种方法
        int prev1 = 2; // 相当于 dp[2]：爬到第 2 阶有 2 种方法 (1+1, 2)
        int current = 0; // 用来存当前阶数的方法总数

        // 从第 3 阶开始，一步步滚雪球到第 n 阶
        for (int i = 3; i <= n; i++) {
            current = prev1 + prev2; // 状态转移：当前 = 前一步 + 前两步

            // 准备进入下一轮循环，整体向前挪动一格
            prev2 = prev1; // 原来的 prev1 退位成 prev2
            prev1 = current; // 刚刚算出来的 current 成为新的 prev1
        }

        return current;
    }
}
```
### 复杂度
  - **时间复杂度**：$O(n)$。我们只需要一个简单的 `for` 循环，从 3 遍历到 `n`，极速出解。
  - **空间复杂度**：$O(1)$。这是这套代码最大的亮点。因为我们抛弃了 DP 数组，只用了 `prev1`, `prev2`, `current` 三个变量滚动，内存消耗恒定。

### 易错点与扩展（面试的数学暴击）

1. **面试追问 1：“如果我非要用递归写，怎么才能不超时？”**

   - **满分抢答（记忆化搜索）**：单纯的递归会产生海量的**重复计算**（比如算 `dp(5)` 时算了 `dp(3)`，算 `dp(4)` 时又算了一遍 `dp(3)`）。
   - 只要我们在递归外面挂一个**备忘录（数组或 HashMap）**。每次算出一个阶梯的答案，就记在备忘录里；下次再遇到，直接查表返回。这叫“带备忘录的自顶向下递归”，它的时间复杂度同样能优化到 $O(n)$。

2. **面试终极进阶：“你能把时间复杂度优化到 $O(\log n)$ 吗？”**

   - **满分优化思路（矩阵快速幂）**：如果你遇到字节跳动或者极致追求算法的面试官，抛出这个解法绝对加分。

   - 既然是斐波那契数列，我们可以将其转化为矩阵乘法的形式：

     $\begin{bmatrix} dp[n] \\ dp[n-1] \end{bmatrix} = \begin{bmatrix} 1 & 1 \\ 1 & 0 \end{bmatrix}^{n-2} \begin{bmatrix} dp[2] \\ dp[1] \end{bmatrix}$

   - 利用**快速幂算法**（类似二分法求 $x^n$），可以在 $O(\log n)$ 的时间内算出该矩阵的 `n-2` 次方！这在 $n$ 高达几百亿、要求取模的极速场景下，是优化思路。

## Python 完整推导

### 最后一步只能跨 1 阶或 2 阶

要到第 `i` 阶，倒数第二步只有两种来源：从 `i - 1` 跨 1 阶，或从 `i - 2` 跨 2 阶。因此到达第 `i` 阶的方法数是这两个历史状态之和。它和斐波那契递推相同。

状态只依赖前两项，不必保留整张 DP 表。`previous_two` 表示到达 `i-2` 阶的方法数，`previous_one` 表示到达 `i-1` 阶的方法数；算出 `current` 后，把这两个变量同时向前滚动。

### `n = 5` 的逐步状态

先有两个基态：到第 1 阶有 1 种方法，到第 2 阶有 2 种方法。

1. 第 3 阶：`1 + 2 = 3`。滚动后两个状态为 2、3。
2. 第 4 阶：`2 + 3 = 5`。滚动后两个状态为 3、5。
3. 第 5 阶：`3 + 5 = 8`。滚动后返回 8。

完整序列是 1、2、3、5、8。`n = 3` 时答案 3：路径分别是 1+1+1、1+2、2+1。题目规模很小，不需要递归，也不会出现重复计算。

### 为什么不是乘法

每一种从 `i-1` 来的走法和每一种从 `i-2` 来的走法表示不同的最后一步，因此两类方法相加。最后一步为 1 或 2 的选择之间没有先后顺序需要再相乘。

### Python 实现

> 参考来源：代码随想录（programmercarl.com）
>
> 旧项目该条目收录的 Python 代码是可走 1..m 阶的泛化版本，与力扣本题固定 1、2 阶签名不完全匹配；主解沿用同题旧 Java 的 Fibonacci 滚动代码，source 仍沿用旧项目标注。

```python
class Solution:
    def climbStairs(self, n: int) -> int:
        if n <= 2:
            return n
        previous_two, previous_one = 1, 2
        for _ in range(3, n + 1):
            current = previous_one + previous_two
            previous_two, previous_one = previous_one, current
        return previous_one
```

### 边界与同步滚动

`if n <= 2: return n` 使用了题目约束：1 阶只有 1 种方法，2 阶有 1+1 与 2 两种。这样循环可以从第 3 阶开始，不需要在循环中访问负数下标。

`previous_two, previous_one = previous_one, current` 是 Python 的元组打包赋值：右侧先同时求值，再写入左边，两个状态不会像连续两条赋值那样互相覆盖。

题目约束下结果落在 32 位有符号整数范围。若扩展到极大 n 并给取模条件，仍可沿用同一滚动递推；若没有取模，需要按 Python 任意精度整数处理。

### 复杂度

- 时间复杂度：`O(n)`。
- 空间复杂度：`O(1)`。

从第 3 阶到第 n 阶共做 O(n) 次加法，只保存两个历史状态与当前值，空间 O(1)。

## C++ 实现

> 实现来源：站内标准实现



```cpp
// 完全背包思路：dp[j] 表示爬到第 j 阶的方案数，
// 每次可以爬 1~m 个台阶，抽象为物品重量 1~m。
// 排列题，注意循环顺序：背包在外、物品在内。
int climbing_stairs(int n, int m) {
    vector<int> dp(n + 1, 0);   // 背包总容量
    dp[0] = 1;
    for (int j = 1; j <= n; j++) {          // 背包容量
        for (int i = 1; i <= m; i++) {      // 物品（每次爬的阶数）
            if (j >= i) dp[j] += dp[j - i]; // 这里 i 就是阶数而非下标
        }
    }
    return dp[n];
}
```
