152. 乘积最大子数组

难度中等核心模式同时维护最大积与最小积时间复杂度O(n)空间复杂度O(1)

题目与约束

给你一个整数数组 nums ，请你找出数组中乘积最大的非空连续 子数组（该子数组中至少包含一个数字），并返回该子数组所对应的乘积。

测试用例的答案是一个 32-位 整数。

请注意，一个只包含一个元素的数组的乘积是这个元素的值。

示例 1:

输入: nums = [2,3,-2,4]
输出: 6
解释: 子数组 [2,3] 有最大乘积 6。

示例 2:

输入: nums = [-2,0,-1]
输出: 0
解释: 结果不能为 2, 因为 [-2,-1] 不是子数组。

提示:

  • 1 <= nums.length <= 2 * 104
  • -10 <= nums[i] <= 10
  • nums 的任何子数组的乘积都 保证 是一个 32-位 整数

核心不变量

负数会交换最大与最小角色。

完整推导

思路推导

  1. 直觉与痛点（为什么直接套用 Kadane 算法会翻车？）：

    在求最大子数组和时，我们只要维护一个当前最大和 maxSum，遇到负数直接不要它就行了。

    痛点：在求乘积时，假设当前序列是 [2, 3, -2, 4, -1]。

    • 当走到 4 的时候，前面的连续乘积是 -48。如果按“及时止损”的逻辑，我们肯定丢弃 -48，从 4 重新开始。

    • 可是紧接着遇到了 -1！如果我们保留了刚才的深渊 -48，那么 -48 * -1 = 48，再乘以 4 就是 192！

    所以，当前的最小值（绝对值很大的负数），有在未来翻盘成为最大值的巨大潜力。

  2. 破局思路（同时记录“巅峰”与“深渊”）：

    既然最小值能逆袭，那我们在动态规划迭代时，就不能只贪心地记录最大值，必须同时把最小值也死死记下来！

    我们维护两个动态规划状态：

    • maxProd：以当前数字结尾的子数组的最大乘积。
    • minProd：以当前数字结尾的子数组的最小乘积（保存可能翻盘的负数火种）。

  3. 核心微操（绝妙的太极阴阳反转）：

    当新来的数字 nums[i] 是一个负数时：

    它乘以原来的最大值，会变成一个极小的负数（新深渊）；

    它乘以原来的最小值，会变成一个极大的正数（新巅峰）！

    致命技巧：只要发现 nums[i] < 0，我们直接把 maxProd 和 minProd 互换！然后顺理成章地用常规公式更新，代码逻辑直接干净一倍。

    Java 实现（空间压榨 O(1) 版）

    C++ 实现

    实现来源：经典解法实现

    1. 同时维护以 i 结尾的最大乘积与最小乘积（负数乘负数会翻正）
    2. 转移：max = max(x, 上max×x, 上min×x)，min 同理取最小
    3. 答案为全程 max 的最大值
    class Solution {
public:
    int maxProduct(vector<int>& nums) {
        int maxP = nums[0], minP = nums[0], ans = nums[0];
        for (int i = 1; i < nums.size(); i++) {
            int x = nums[i];
            int cand[] = {x, maxP * x, minP * x};
            maxP = *max_element(cand, cand + 3);
            minP = *min_element(cand, cand + 3);
            ans = max(ans, maxP);
        }
        return ans;
    }
};

    Python 实现

    实现来源：经典解法实现

    1. 同时维护以 i 结尾的最大乘积与最小乘积（负数乘负数会翻正）
    2. 转移：max = max(x, 上max×x, 上min×x)，min 同理取最小
    3. 答案为全程 max 的最大值
    class Solution:
    def maxProduct(self, nums: List[int]) -> int:
        maxP = minP = ans = nums[0]
        for x in nums[1:]:
            cands = (x, maxP * x, minP * x)
            maxP, minP = max(cands), min(cands)
            ans = max(ans, maxP)
        return ans

    Go 实现

    实现来源：经典解法实现

    1. 同时维护以 i 结尾的最大乘积与最小乘积（负数乘负数会翻正）
    2. 转移：max = max(x, 上max×x, 上min×x)，min 同理取最小
    3. 答案为全程 max 的最大值
    func maxProduct(nums []int) int {
    maxP, minP, ans := nums[0], nums[0], nums[0]
    for _, x := range nums[1:] {
        c1, c2, c3 := x, maxP*x, minP*x
        maxP = max(c1, max(c2, c3))
        minP = min(c1, min(c2, c3))
        if maxP > ans { ans = maxP }
    }
    return ans
}

    C 实现

    实现来源：经典解法实现

    1. 同时维护以 i 结尾的最大乘积与最小乘积（负数乘负数会翻正）
    2. 转移：max = max(x, 上max×x, 上min×x)，min 同理取最小
    3. 答案为全程 max 的最大值
    int maxProduct(int* nums, int numsSize) {
    int maxP = nums[0], minP = nums[0], ans = nums[0];
    for (int i = 1; i < numsSize; i++) {
        int x = nums[i];
        int c1 = x, c2 = maxP * x, c3 = minP * x;
        maxP = c1 > c2 ? (c1 > c3 ? c1 : c3) : (c2 > c3 ? c2 : c3);
        minP = c1 < c2 ? (c1 < c3 ? c1 : c3) : (c2 < c3 ? c2 : c3);
        if (maxP > ans) ans = maxP;
    }
    return ans;
}

class Solution {
    public int maxProduct(int[] nums) {
        if (nums == null || nums.length == 0) return 0;

        // 初始化：由于必须包含至少一个数字，第一天的巅峰和深渊都是 nums[0]
        int maxProd = nums[0];
        int minProd = nums[0];
        // 记录全局出现过的最高巅峰
        int globalMax = nums[0];

        // 从第二个数字开始看滚动过山车
        for (int i = 1; i < nums.length; i++) {
            int num = nums[i];

            // 🌟 核心高光细节：如果当前数字是负数，最大和最小瞬间颠倒
            if (num < 0) {
                int temp = maxProd;
                maxProd = minProd;
                minProd = temp;
            }

            // 状态转移方程：
            // 到底是【自立门户（从 num 开始）】，还是【继承家业（跟前面的乘起来）】
            maxProd = Math.max(num, maxProd * num);
            minProd = Math.min(num, minProd * num);

            // 每一轮都把当前产生的最大值拿去挑战历史纪录
            globalMax = Math.max(globalMax, maxProd);
        }

        return globalMax;
    }
}

复杂度

  • 时间复杂度：O(N)。只需对数组进行一次单向线性扫描，没有任何嵌套循环，效率极高。
  • 空间复杂度：O(1)。我们极其敏锐地发现当前状态只和前一个状态有关，因此直接用 maxProd 和 minProd 滚动变量代替了 DP 数组，将空间压榨到了常数级别。
易错点与扩展（面试的隐藏考点）
  1. 极度高频坑点：数字 0 的拆台效应 - 数组里如果出现 0（比如 [2, 3, 0, 4]），由于任何数乘以 0 都是 0，它会让 maxProd 和 minProd 瞬间归零。 - 无需特殊处理：我们的代码里有 Math.max(num, ...) 和 Math.min(num, ...)。当走到 0 之后的 4 时，Math.max(4, 0 * 4) 会让代码果断选择 4，相当于自动完成了“原地复活，重新建队”的逻辑。这就是动态规划自适应的优美之处。
  2. 面试追问：“这道题除了双极值 DP，还有什么脑筋急转弯的双向解法吗？” - 满分抢答（前后缀乘积双向奔赴法）：这是一个非常惊艳的视角。 - 如果一个子数组乘积最大，它要么从左边开始延伸，要么从右边开始延伸。除非中间被 0 截断。 - 我们可以算一遍前缀乘积，再算一遍后缀乘积（遇到 0 就把乘积重置为 1 重新算）。这两波数据的全局最大值，必然就是最大乘积子数组！ - 这种解法代码行数极少，而且完全不需要考虑繁琐的负负得正调换，是极具极简美学的面试加分答卷。
