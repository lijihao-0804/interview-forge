279. 完全平方数

Python 主方法完全背包最少平方数时间O(n√n)空间O(n)

题目与约束

给你一个整数 n ，返回 和为 n 的完全平方数的最少数量 。

完全平方数 是一个整数，其值等于另一个整数的平方；换句话说，其值等于一个整数自乘的积。例如，1、4、9 和 16 都是完全平方数，而 3 和 11 不是。

示例 1：

输入：n = 12
输出：3
解释：12 = 4 + 4 + 4

示例 2：

输入：n = 13
输出：2
解释：13 = 4 + 9

提示：

  • 1 <= n <= 104

Java 完整推导

Java 核心不变量

dp[i] 从所有不超过 i 的平方数转移。

完整推导

思路推导

  1. 直觉与痛点（贪心算法的滑铁卢）：

    很多人的第一反应是贪心法：既然要数量最少，那我就每次挑尽可能大的完全平方数去减！

    比如 n = 12，比 12 小的最大平方数是 9。

    12 - 9 = 3。剩下的 3 只能用三个 1 来凑（1+1+1）。

    所以贪心法得出结论：需要 4 个数（9 + 1 + 1 + 1）。

    痛点：真的是 4 个吗？其实 12 = 4 + 4 + 4，只需要 3 个数！贪心法因为过于短视（只顾着眼前的最大数字 9），完美错过了全局最优解。

  2. 降维破局（动态规划的上帝视角）：

    既然贪心会翻车，我们就必须老老实实地试探所有的可能性。

    这其实就是一个“换硬币”游戏（完全背包）：你手头有面值为 1, 4, 9, 16... 的无限量硬币，怎么凑出金额 n 使用的硬币最少？

    我们定义一个数组 dp[i]：凑出数字 i 所需要的最少完全平方数。

  3. 核心微操（状态转移方程）：

    要算出 dp[i]，我们可以尝试从 i 中减去一个完全平方数 j2（其中 j2 ≤ i）。

    减去之后，剩下的数字就是 i - j2。而凑出 i - j2 的最少数量，我们早就存在 dp[i - j*j] 里了！

    所以，我们只需遍历所有可能的 j，找出最小的那一个：

    dp[i]=min(dp[i],dp[i-j×j]+1)

    Java 实现（满分完全背包版）

import java.util.Arrays;

class Solution {
    public int numSquares(int n) {
        // dp[i] 表示：和为 i 的完全平方数的最少数量
        int[] dp = new int[n + 1];

        // 🌟 初始化：因为要求最小值，所以先把所有位置填满“无穷大”
        // 只有 dp[0] = 0，因为凑出数字 0 不需要任何完全平方数
        Arrays.fill(dp, Integer.MAX_VALUE);
        dp[0] = 0;

        // 外层循环：遍历背包容量（我们要凑的数字 i，从 1 到 n）
        for (int i = 1; i <= n; i++) {
            // 内层循环：遍历物品（完全平方数 j*j，只要它不超过当前的背包容量 i）
            for (int j = 1; j * j <= i; j++) {
                // 🌟 核心状态转移方程：
                // 方案 A：保持原样 dp[i]
                // 方案 B：拿一个当前的平方数 j*j，剩下的数字交由历史结果 dp[i - j*j] 解决
                dp[i] = Math.min(dp[i], dp[i - j * j] + 1);
            }
        }

        return dp[n];
    }
}

复杂度

  • 时间复杂度：O(nn)。外层循环执行 n 次，内层循环对于每个 i，最多执行 i 次。总体时间复杂度极低，能够轻松应对百万级别的数据。
  • 空间复杂度：O(n)。需要一个长度为 n+1 的 dp 数组来记录历史状态。
易错点与扩展（面试的数学暴击）
  1. 面试追问 1：“除了 DP，这道题能用图论解决吗？” - 满分抢答（BFS 最短路径法）：绝对可以！这其实是一个求最短路径的问题。 - 我们把数字 n 当作起点，0 当作终点。每次可以走出的“步长”必须是完全平方数（1, 4, 9...）。 - 用广度优先搜索（BFS），像水波纹一样一层层向外扩散。因为 BFS 天然具备“先找到的必定是最短层数”的特性，所以只要 BFS 到达了 0，当前的层数（步数）就是最少数量！
  2. 面试终极进阶：“你能把时间复杂度降到 O(n) 甚至 O(1) 吗？” - 满分优化思路（四平方和定理）：如果你遇到的是极其硬核的算法官，抛出这个定理绝对能直接结束面试。 - 数学界有一个著名的拉格朗日四平方和定理：任何一个正整数都可以表示为至多四个正整数的平方和。 - 也就是说，这道题的答案只可能是 1, 2, 3, 4 中的一个！
    • 答案是 1：如果 n 本身就是完全平方数。
    • 答案是 4：当且仅当 n 满足勒让德三平方和定理的特殊形式 n = 4a(8b+7) 时。
    • 答案是 2：枚举所有的 j2，看看 n - j2 是不是完全平方数。
    • 排除以上所有情况，答案就是 3。
    • 用纯数学定理去秒杀，时间复杂度直接降维到 O(n)！

Python 完整推导

把问题看成完全背包

完全平方数可以重复使用：和为 12 可以由 9+1+1+1 组成，也可以由 4+4+4 组成。若 dp[x] 表示凑出 x 的最少平方数个数，那么枚举一个平方数 j*j <= x，可以先解决 x - j*j，再加当前这一个。

贪心每次取最大平方数会失败。对 12，先取 9 后会得到 4 个数；但三个 4 只需 3 个数。DP 会同时比较所有最后一步。

用 12 看关键转移

先有 dp[0] = 0。计算到 12 时，可能的最后平方数是 1、4、9：

  1. 若最后取 1，前面 11 的最优值 dp[11] = 3，候选为 4。
  2. 若最后取 4，前面 8 的最优值 dp[8] = 2，候选为 3。
  3. 若最后取 9，前面 3 的最优值 dp[3] = 3，候选为 4。

取最小得到 dp[12] = 3。对应路径可以是 dp[8] 的 4+4，再补一个 4。

小规模状态可以验证为：dp[1]=1、dp[2]=2、dp[3]=3、dp[4]=1、dp[8]=2、dp[9]=1。计算每个值时只依赖更小的和，所以从左到右递推不会读到未完成状态。

Python 实现

参考来源：代码随想录（programmercarl.com）

沿用旧项目收录的《代码随想录》完全背包 Python 代码；用 math.isqrt 替代浮点平方根，变量与注释按本页整理。

from math import isqrt


class Solution:
    def numSquares(self, n: int) -> int:
        infinity = n + 1
        dp = [infinity] * (n + 1)
        dp[0] = 0
        for value in range(1, n + 1):
            for root in range(1, isqrt(value) + 1):
                dp[value] = min(dp[value], dp[value - root * root] + 1)
        return dp[n]

整数平方根与完全背包方向

isqrt(value) 返回不超过真实平方根的最大整数，避免浮点误差。range(1, isqrt(value) + 1) 枚举所有平方数根，右端加一才能包含恰好等于 value 的情况。

infinity = n + 1 是安全无效值：任意正整数 n 都可以用 n 个 1 组成，所以合法答案不会超过 n。这样既不用浮点无穷，也不会在加一时溢出。

为什么不需要预先构造硬币列表

每个和 value 都重新枚举 1..isqrt(value)，平方数表达式简单，不需要额外列表。总状态转移数是 sum(sqrt(x))，即 O(n√n)。

复杂度

  • 时间复杂度：O(n√n)。
  • 空间复杂度：O(n)。

外层 n 个和，计算 x 时枚举 sqrt(x) 个平方数，总额 O(n√n)；一维 dp 有 n+1 个状态，空间 O(n)。

C++ 实现

实现来源：代码随想录（programmercarl.com）

// 版本一
class Solution {
public:
    int numSquares(int n) {
        vector<int> dp(n + 1, INT_MAX);
        dp[0] = 0;
        for (int i = 0; i <= n; i++) { // 遍历背包
            for (int j = 1; j * j <= i; j++) { // 遍历物品
                dp[i] = min(dp[i - j * j] + 1, dp[i]);
            }
        }
        return dp[n];
    }
};

Go 实现

实现来源：代码随想录（programmercarl.com）

// 版本一,先遍历物品, 再遍历背包
func numSquares1(n int) int {
    //定义
    dp := make([]int, n+1)
    // 初始化
    dp[0] = 0
    for i := 1; i <= n; i++ {
        dp[i] = math.MaxInt32
    }
    // 遍历物品
    for i := 1; i <= n; i++ {
        // 遍历背包
        for j := i*i; j <= n; j++ {
            dp[j] = min(dp[j], dp[j-i*i]+1)
        }
    }

    return dp[n]
}

// 版本二,先遍历背包, 再遍历物品
func numSquares2(n int) int {
    //定义
    dp := make([]int, n+1)
    // 初始化
    dp[0] = 0
    // 遍历背包
    for j := 1; j <= n; j++ {
        //初始化
        dp[j] = math.MaxInt32
        // 遍历物品
        for i := 1; i <= n; i++ {
            if j >= i*i {
                dp[j] = min(dp[j], dp[j-i*i]+1)
            }
        }
    }

    return dp[n]
}

func min(a, b int) int {
    if a < b {
        return a
    }
    return b
}

C 实现

实现来源：站内标准实现

int numSquares(int n) {
    int* dp = malloc(sizeof(int) * (n + 1));
    dp[0] = 0;
    for (int i = 1; i <= n; ++i) {
        dp[i] = INT_MAX;
        for (int j = 1; j * j <= i; ++j)
            if (dp[i - j * j] + 1 < dp[i]) dp[i] = dp[i - j * j] + 1;
    }
    return dp[n];
}
