题目与约束

给你一个只包含 '(' 和 ')' 的字符串，找出最长有效（格式正确且连续）括号 子串 的长度。

左右括号匹配，即每个左括号都有对应的右括号将其闭合的字符串是格式正确的，比如 "(()())"。

示例 1：

输入：s = "(()" 输出：2 解释：最长有效括号子串是 "()"

示例 2：

输入：s = ")()())" 输出：4 解释：最长有效括号子串是 "()()"

示例 3：

输入：s = "" 输出：0

提示：

0 <= s.length <= 3 * 104 s[i] 为 '(' 或 ')'

Java 完整推导

Java 核心不变量

dp[i] 只表示必须以 i 结尾的最长有效长度。

完整推导

思路推导

  1. 直觉与痛点（断裂的连续性）：

    如果单纯用消消乐，遇到 ( 入栈，遇到 ) 出栈，当栈空了或者不匹配时，我们知道括号断了。

    痛点：断了之后怎么计算长度？比如 ()())()，前面一段 () 长度是 4，后面一段 () 长度是 2。我们必须精准地知道每一次完美的消除是从哪个索引开始，到哪个索引结束的，并且还要把连续消除的长度累加起来。

  2. 破局思路（不存字符，存“索引”；引入“虚拟锚点”）：

    为了计算长度，栈里绝对不能存字符 (，必须存它们的【数组索引】！

    更绝的是，为了处理边界情况（比如一上来就是个完美的 ()），我们需要在栈底死死压入一个“虚拟地基”——索引 -1！ 这个 -1 的含义是：“当前这波连续消除的合法边界，是从 -1 之后开始的”。

  3. 核心微操（锚点的自我迭代）：

    我们从左到右遍历字符串：

    • 遇到 (：说明新一波的闭合期待开始了，直接把它的索引 i 压入栈中。
    • 遇到 )：说明我们要尝试消除。不管三七二十一，先把栈顶弹出来（Pop）。
    • 弹完之后，看一眼栈：
    • 如果栈不为空：说明刚刚触发了一次完美的消除！这时候，当前合法的连续括号长度就是：当前索引 i - 此时最新的栈顶索引。我们拿这个长度去挑战历史最大值。
    • 如果栈变空了：高能预警！这意味着当前这个 ) 是一个多余的、把前面连续性彻底砸碎的破坏者（比如 ()()) 最后一个右括号）。前面的连续性当场暴毙。但我们不能气馁，我们要把当前这个 ) 的索引 i 强行压入栈底，作为下一波新连续区间的“全新虚拟地基（新锚点）”！

    Java 实现（满分栈指针极速版）

import java.util.ArrayDeque;
import java.util.Deque;

class Solution {
    public int longestValidParentheses(String s) {
        if (s == null || s.length() < 2) {
            return 0;
        }

        int maxLen = 0;
        // 栈里不存字符，只存索引
        Deque<Integer> stack = new ArrayDeque<>();

        // 🌟 灵魂一步：先注入一个虚拟地基 -1
        // 这样如果第 0 和第 1 个字符是 "()"，弹出后栈底剩下 -1，1 - (-1) = 2，完美契合
        stack.push(-1);

        for (int i = 0; i < s.length(); i++) {
            char c = s.charAt(i);

            if (c == '(') {
                // 遇到左括号，无脑压入当前索引
                stack.push(i);
            } else {
                // 遇到右括号，先弹栈，表示尝试匹配
                stack.pop();

                if (stack.isEmpty()) {
                    // 如果弹完之后栈空了，说明这个右括号无家可归（多余了）
                    // 它成了新的“断裂点”，我们把它压入栈中，作为下一轮计算长度的全新底座（地基）
                    stack.push(i);
                } else {
                    // 如果栈不空，说明匹配成功！
                    // 当前有效括号的长度 = 当前索引 i - 弹栈后新的栈顶索引
                    maxLen = Math.max(maxLen, i - stack.peek());
                }
            }
        }

        return maxLen;
    }
}

复杂度

  • 时间复杂度：O(N)。只需要对字符串进行一次单向的线性扫描，每个索引最多入栈一次出栈一次。
  • 空间复杂度：O(N)。在最坏的情况下（比如全是左括号 "(((((("），栈的深度会达到 N+1。
易错点与扩展（面试的终极审判）
  1. 面试追问 1：“我看你用栈实现了 O(N) 空间。如果面试官要求【空间复杂度必须是 O(1)】，不准用任何栈和额外数组，你能破局吗？” - 满分抢答（正反双向贪心扫描法）：绝对可以！这是一个极其巧妙的脑筋急转弯。 - 我们只需要准备两个变量 left 和 right 记录左右括号的数量。 - 从左向右扫一遍：遇到 ( 则 left++，遇到 ) 则 right++。只要 left == right，说明完美闭合，更新 maxLen = 2 * right；如果 right > left，说明右边多出来了，连续性断裂，直接把 left 和 right 全部清零重来。 - 致命细节：光这么扫会漏掉一种情况，比如 "(()"（左边多余），扫完 left=2, right=1，永远不会触发 left==right。 - 破局补刀：我们只需要从右向左再反向扫一遍！逻辑完全对称：遇到 ( 且 left > right 时清零。两次扫描双向奔赴，用 O(1) 的神级空间即可完美通关！
  2. 面试追问 2：“这道题如果用动态规划（DP）该怎么定义状态？” - DP 状态思维：定义 dp[i] 表示以当前字符 s[i] 结尾的最长有效括号长度。 - 只有当 s[i] == ')' 时才有可能有值。如果 s[i-1] == '('，那很简单，dp[i] = dp[i-2] + 2。 - 如果 s[i-1] == ')'（比如 ((...))），我们需要跨过 dp[i-1] 算出来的这一整段有效安全区，去窥探它前方的那个字符 s[i - dp[i-1] - 1] 是不是 (。如果是，说明这一大段被完美闭合了，状态转移方程就会变成：dp[i] = dp[i-1] + 2 + dp[i - dp[i-1] - 2]。 - 面试点评：DP 解法的边界条件极度容易写错（一不小心就数组越界），在面试有限的时间内，上面的“栈锚点法”是容错率最高、最不容易写挂的教科书级代码。

Python 完整推导

栈里既有左括号，也有一个基准

遇到 ( 时，它的下标还没有匹配，压入栈。遇到 ) 时，先弹出一个栈顶：如果弹后栈空，说明这个右括号没有匹配，它自己成为新的基准；如果栈仍非空，就用当前下标减去新栈顶，得到刚闭合的这一段连续有效长度。

弹后的新栈顶不一定是“断裂点”。例如输入 (()：

  1. 初始 stack = [-1]。
  2. 下标 0 和下标的 1 都是左括号，压栈后为 [-1, 0, 1]。
  3. 下标 2 是右括号，弹出 1 后栈为 [-1, 0]。新栈顶 0 是一个还未匹配的左括号，不是断裂基准。当前有效长度是 2 - 0 = 2，对应子串 ()。

所以栈的基准只有两类：开头的 -1，以及之后遇到的无匹配右括号下标；其余项都是等待匹配的左括号。

用 ")()())" 走一遍

初始 stack = [-1]、best = 0。

  1. 下标 0 是 )：弹出基准 -1，栈空，说明 0 号右括号无效；压入 0，基准变为 0。
  2. 下标 1 是 (：压入 1，栈为 [0, 1]。
  3. 下标 2 是 )：弹出 1，新栈顶为 0，有效长度 2 - 0 = 2，best = 2。
  4. 下标 3 是 (：栈变 [0, 3]。
  5. 下标 4 是 )：弹出 3，长度 4 - 0 = 4，best = 4。
  6. 下标 5 是 )：先弹出 0，弹后为空，说明这个右括号多余，压入 5 作为新基准。最终答案仍为 4。

Python 实现

参考来源：经典解法实现

沿用旧项目“经典解法实现”的 -1 基准下标栈代码；变量、注释和公式说明按本页整理。

class Solution:
    def longestValidParentheses(self, s: str) -> int:
        stack = [-1]
        best = 0
        for index, ch in enumerate(s):
            if ch == "(":
                stack.append(index)
            else:
                stack.pop()
                if not stack:
                    stack.append(index)
                else:
                    best = max(best, index - stack[-1])
        return best

为什么右括号先 pop 再判断

遇到左括号只压入下标，不计算长度。遇到右括号时，stack.pop() 移除当前最内层的待匹配位置。弹后若仍有元素，新栈顶可能是外层左括号，也可能是 -1 或某个无匹配右括号基准；长度公式不要求继续区分这两类，因为新栈顶之后到当前的内容都已被该次匹配闭合为连续有效段。

如果弹出后栈空，当前右括号之前已经没有可提供边界的元素，因此当前下标必须成为新基准。此时不能直接用 index - (-1) 更新答案，因为这一段包含无效右括号。

(() 的边界

处理下标 2 的右括号时，弹出的是下标 1，栈顶保留下标 0 的未匹配左括号。2 - 0 = 2 计的是从下标 0 之后到下标 2 的有效串 ()；如果把栈顶 0 误称为断裂基准，就会错误丢弃一个有效字符。

空间

最坏情况下，很多左括号都没有闭合，栈会保存 O(n) 个下标。不需要额外的有效长度数组。

复杂度

  • 时间复杂度：O(n)。
  • 空间复杂度：O(n)。

每个下标最多入栈一次、出栈一次，时间 O(n)；最坏全为左括号时栈保存 n 个下标，空间 O(n)。

C++ 实现

实现来源：经典解法实现

  1. 栈存「上一个未匹配位置」下标，初始 -1
  2. 遇 '(' 压下标；遇 ')' 弹栈：栈空 → 当前位置成为新基准；非空 → 有效长度 = i − 栈顶
  3. 全程取最大值
class Solution {
public:
    int longestValidParentheses(string s) {
        vector<int> stack = {-1};
        int best = 0;
        for (int i = 0; i < s.size(); i++) {
            if (s[i] == '(') stack.push_back(i);
            else {
                stack.pop_back();
                if (stack.empty()) stack.push_back(i);   // 新基准
                else best = max(best, i - stack.back());
            }
        }
        return best;
    }
};

Go 实现

实现来源：经典解法实现

  1. 栈存「上一个未匹配位置」下标，初始 -1
  2. 遇 '(' 压下标；遇 ')' 弹栈：栈空 → 当前位置成为新基准；非空 → 有效长度 = i − 栈顶
  3. 全程取最大值
func longestValidParentheses(s string) int {
    stack := []int{-1}
    best := 0
    for i, ch := range s {
        if ch == '(' { stack = append(stack, i) } else {
            stack = stack[:len(stack)-1]
            if len(stack) == 0 { stack = append(stack, i) } else if i-stack[len(stack)-1] > best { best = i - stack[len(stack)-1] }
        }
    }
    return best
}

C 实现

实现来源：经典解法实现

  1. 栈存「上一个未匹配位置」下标，初始 -1
  2. 遇 '(' 压下标；遇 ')' 弹栈：栈空 → 当前位置成为新基准；非空 → 有效长度 = i − 栈顶
  3. 全程取最大值
int longestValidParentheses(char* s) {
    int stack[100001], top = 0, best = 0;
    stack[top++] = -1;
    for (int i = 0; s[i]; i++) {
        if (s[i] == '(') stack[top++] = i;
        else {
            top--;
            if (top == 0) { stack[top++] = i; }
            else if (i - stack[top-1] > best) best = i - stack[top-1];
        }
    }
    return best;
}
