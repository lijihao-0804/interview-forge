难度中等
Java 主方法选或不选滚动状态时间O(n)空间O(1)
Python 主方法打家劫舍滚动 DP时间O(n)空间O(1)

题目与约束

你是一个专业的小偷，计划偷窃沿街的房屋。每间房内都藏有一定的现金，影响你偷窃的唯一制约因素就是相邻的房屋装有相互连通的防盗系统，如果两间相邻的房屋在同一晚上被小偷闯入，系统会自动报警。

给定一个代表每个房屋存放金额的非负整数数组，计算你不触动警报装置的情况下，一夜之内能够偷窃到的最高金额。

示例 1：

输入：[1,2,3,1]
输出：4
解释：偷窃 1 号房屋 (金额 = 1) ，然后偷窃 3 号房屋 (金额 = 3)。
偷窃到的最高金额 = 1 + 3 = 4 。

示例 2：

输入：[2,7,9,3,1]
输出：12
解释：偷窃 1 号房屋 (金额 = 2), 偷窃 3 号房屋 (金额 = 9)，接着偷窃 5 号房屋 (金额 = 1)。
偷窃到的最高金额 = 2 + 9 + 1 = 12 。

提示：

  • 1 <= nums.length <= 100
  • 0 <= nums[i] <= 400

Java 完整推导

Java 核心不变量

dp[i] 只比较跳过当前与偷当前两种选择。

完整推导

思路推导

  1. 直觉与痛点（贪心的滑铁卢）：

    很多同学的第一反应是贪心法：我把奇数下标的房子全偷了，或者把偶数下标的房子全偷了，哪个大取哪个。

    痛点：这种“隔一个偷一个”的固定步长贪心是错误的！比如 [2, 1, 1, 2]，如果你按奇偶偷，最多只能拿到 2+1=3。但如果你偷第 0 个和第 3 个（不按固定步长），你能拿到 2+2=4。

  2. 降维破局（一切取决于今晚偷不偷）：

    假设我们走到了第 i 间房子，面对这笔钱，小偷的脑海里会有两个小人打架：

    • 方案 A（今晚干一票）：既然决定偷第 i 间房，那第 i-1 间房绝对不能碰。所以我能拿到的总金额是：第 i 间房的钱 + 走到第 i-2 间房时的最高收益。
    • 方案 B（今晚忍一手）：我觉得第 i-1 间房太香了，我已经偷了。为了不报警，今天这间房我绝对不能偷。所以我能拿到的总金额是：走到第 i-1 间房时的最高收益（维持原样）。

  3. 核心微操（状态转移方程）：

    究竟偷还是不偷？当然是看哪个收益大！

    这就得出了极度优美的状态转移方程：

    dp[i]=max(dp[i-1],dp[i-2]+nums[i])

    Java 实现（满分滚动变量空间压缩版）

class Solution {
    public int rob(int[] nums) {
        // 边界防御：如果没有房子，一分钱也偷不到；只有一间房子，只能偷这一间
        if (nums == null || nums.length == 0) return 0;
        if (nums.length == 1) return nums[0];

        // 🌟 空间压缩技巧（同爬楼梯）：
        // 我们计算当前房子的最高收益时，只依赖于“前一间”和“前两间”的最高收益
        // 所以我们不需要开辟 O(N) 的 dp 数组，用两个变量滚动即可！

        int prev2 = nums[0]; // 相当于 dp[0]：只有第 0 间房时的最高收益
        int prev1 = Math.max(nums[0], nums[1]); // 相当于 dp[1]：有第 0 和 1 间房时的最高收益

        // 当前走到第 i 间房的最高收益
        int current = prev1;

        // 从第 2 间房开始，一路扫荡过去
        for (int i = 2; i < nums.length; i++) {
            // 核心状态转移：不偷这家(prev1) vs 偷这家(prev2 + 这家的钱)
            current = Math.max(prev1, prev2 + nums[i]);

            // 算完当前房子后，准备往前走一步，变量全体滚动
            prev2 = prev1;
            prev1 = current;
        }

        return current;
    }
}

复杂度

  • 时间复杂度：O(N)。只需一次极其轻量的 for 循环遍历整条街。
  • 空间复杂度：O(1)。没有使用 dp 数组，仅仅用了三个整型变量来保存历史状态。
易错点与扩展（面试的连环计）
  1. 面试追问 1：“如果这些房子不是排成一条直线，而是围成了一个【首尾相连的环】呢？”（对应力扣 213 题：打家劫舍 II） - 满分优化思路（破环成链）：这绝对是面试里最喜欢连带考的一道题。 - 既然首尾相连，说明第一间房和最后一间房，你绝对不可能同时偷。 - 破局方法：把问题拆分成两个普通的直线打家劫舍！
    • 方案一：我硬着头皮把第一间房纳入考虑范围，那最后一间房就当它不存在（算区间 [0, n-2] 的最高收益）。
    • 方案二：我硬着头皮把最后一间房纳入考虑范围，那第一间房就当它不存在（算区间 [1, n-1] 的最高收益）。
    • 最后，比较这两个方案，谁大就选谁！只需要复用我们上面的代码逻辑跑两遍即可。
  2. 面试追问 2：“如果房子不是一条街，而是排成了一棵【二叉树】，并且相连的父子节点不能同时偷，怎么办？”（对应力扣 337 题：打家劫舍 III - 中等偏难） - 满分抢答（树形 DP）：这时候一维 DP 就不管用了。我们需要对二叉树进行后序遍历。 - 每个节点返回一个长度为 2 的数组 res：
    • res[0] 表示不偷当前节点时，子树的最大收益（等于左孩子各种情况的最大值 + 右孩子各种情况的最大值）。
    • res[1] 表示偷当前节点时，子树的最大收益（等于当前节点的钱 + 不偷左孩子的收益 + 不偷右孩子的收益）。
    • 把“偷与不偷”的状态直接挂载在递归树的节点上，这是面试极度偏爱的树形 DP 终极模板。

Python 完整推导

每间房只问“偷还是不偷”

走到第 i 间房时，有两种合法选择：不偷这一家，最优值保持为前 i-1 家的答案；偷这一家，就不能偷第 i-1 家，只能加上前 i-2 家的答案。比较两者即可。

这不等于固定隔一家。[2, 1, 1, 2] 中，最优是偷第 0 家和第 3 家，间隔并不固定。DP 会在每一步保留所有合法前缀内的最佳方案。

用 [2, 7, 9, 3, 1] 逐步计算

开始 previous_two = 0、previous_one = 0。

  1. 金额 2：max(0, 0 + 2) = 2。两个状态滚动为 0、2。
  2. 金额 7：max(2, 0 + 7) = 7。状态滚动为 2、7。
  3. 金额 9：max(7, 2 + 9) = 11。状态滚动为 7、11。
  4. 金额 3：max(11, 7 + 3) = max(11, 10) = 11，仍取 11。状态滚动为 11、11。
  5. 金额 1：max(11, 11 + 1) = 12。最终答案 12。

最后的 12 来自偷 2、9、1 三间房；每两间被偷房屋之间都至少隔了一间，符合警报条件。

Python 实现

参考来源：代码随想录（programmercarl.com）

旧项目该条目的 Python 片段只保留了空数组和单房屋边界；主解沿用同题旧 Java 的滚动 DP，source 继续使用旧项目标注，未把当前代码称作上游原稿。

from typing import List


class Solution:
    def rob(self, nums: List[int]) -> int:
        previous_two = 0
        previous_one = 0
        for money in nums:
            current = max(previous_one, previous_two + money)
            previous_two, previous_one = previous_one, current
        return previous_one

两个滚动状态的含义

处理当前房屋前，previous_one 是前一家为止的最优答案，previous_two 是前两家为止的最优答案。current = max(previous_one, previous_two + money) 对应“跳过当前家”和“偷当前家”两种来源。

算完后整体向前平移：旧的 previous_one 变成下一轮的 previous_two，current 变成下一轮的 previous_one。元组赋值确保两个变量同步更新。

边界

两个状态初始都为 0，使第一间房可以通过 0 + money 被选中。空数组也会自然返回 0；即使题目通常保证非空，这个初值不需要额外特判。如果房屋金额可能为负，初始化为 0 会相当于允许一间都不偷，但本题金额非负。

复杂度

  • 时间复杂度：O(n)。
  • 空间复杂度：O(1)。

每家房屋只做一次加法、一次比较和一次同步滚动，时间 O(n)；只保存两个前缀状态和当前值，空间 O(1)。

C++ 实现

实现来源：代码随想录（programmercarl.com）

class Solution {
public:
    int rob(vector<int>& nums) {
        if (nums.size() == 0) return 0;
        if (nums.size() == 1) return nums[0];
        vector<int> dp(nums.size());
        dp[0] = nums[0];
        dp[1] = max(nums[0], nums[1]);
        for (int i = 2; i < nums.size(); i++) {
            dp[i] = max(dp[i - 2] + nums[i], dp[i - 1]);
        }
        return dp[nums.size() - 1];
    }
};

Go 实现

实现来源：代码随想录（programmercarl.com）

func rob(nums []int) int {
    n := len(nums)
    dp := make([]int, n+1) // dp[i]表示偷到第i家能够偷得的最大金额
    dp[1] = nums[0]
    for i := 2; i <= n; i++ {
        dp[i] = max(dp[i-1], dp[i-2] + nums[i-1])
    }
    return dp[n]
}

C 实现

实现来源：站内标准实现

int rob(int* nums, int numsSize) {
    int prev = 0, cur = 0;   // prev = dp[i-2], cur = dp[i-1]
    for (int i = 0; i < numsSize; ++i) {
        int t = (prev + nums[i] > cur) ? prev + nums[i] : cur;
        prev = cur;
        cur = t;
    }
    return cur;
}
