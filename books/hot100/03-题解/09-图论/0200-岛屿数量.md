## 题目与约束

给你一个由 `'1'`（陆地）和 `'0'`（水）组成的的二维网格，请你计算网格中岛屿的数量。

  岛屿总是被水包围，并且每座岛屿只能由水平方向和/或竖直方向上相邻的陆地连接形成。

  此外，你可以假设该网格的四条边均被水包围。

  **示例 1：**

  **输入：**grid = [<br>  ['1','1','1','1','0'],<br>  ['1','1','0','1','0'],<br>  ['1','1','0','0','0'],<br>  ['0','0','0','0','0']<br>]<br>**输出：**1

  **示例 2：**

  **输入：**grid = [<br>  ['1','1','0','0','0'],<br>  ['1','1','0','0','0'],<br>  ['0','0','1','0','0'],<br>  ['0','0','0','1','1']<br>]<br>**输出：**3

  **提示：**

  - `m == grid.length`
  - `n == grid[i].length`
  - `1 <= m, n <= 300`
  - `grid[i][j]` 的值为 `'0'` 或 `'1'`

## 完整推导

### 思路推导
  1. **直觉与痛点（怎么防止重复计数？）**：

     直觉告诉我们，需要用两层 `for` 循环去遍历这个二维网格。遇到 `'1'`，说明发现了陆地，岛屿数量就 `+1`。

     **痛点**：一个岛屿通常由好几个 `'1'` 连在一起组成。当你遍历到其中一个 `'1'` 时计数了，等你遍历到它旁边的 `'1'` 时，你怎么知道它们其实是同一座岛？如果不加处理，一座大岛会被你数成好几座小岛！

  2. **破局思路（沉岛战术 / 病毒感染）**：

     我们不能只当个观察者，我们得当个“破坏者”。

     当我们通过 `for` 循环扫描到一个 `'1'` 时，立刻宣布：“发现一座新岛屿！数量加 1！”

     紧接着，我们**立刻触发一次深度优先搜索（DFS）**，就像空投了一枚炸弹，把这块陆地，以及所有和它相连的陆地，全部**炸平变成 `'0'`（沉岛）**。

     这样，当我们主循环的雷达继续往后扫描时，刚才那座岛已经沉入海底（变成 `'0'`）了，绝对不可能被重复计数！

  3. **逻辑推演（网格上的 DFS 怎么写？）**：

     在二叉树里，一个节点只有左右两个孩子（`left`, `right`）。

     在二维网格里，一个格子有上下左右**四个邻居**（`r-1`, `r+1`, `c-1`, `c+1`）。

     所以网格的 DFS 就是：先把自己变成 `'0'`，然后对上下左右四个邻居分别调用 DFS。当然，**必须加上边界判断**，不能让雷达扫到地图外面去报错。
### Java 实现（DFS 沉岛满分版）
```Java
class Solution {
    public int numIslands(char[][] grid) {
        // 边界防御
        if (grid == null || grid.length == 0) {
            return 0;
        }

        int rows = grid.length;
        int cols = grid[0].length;
        int islandCount = 0;

        // 两层 for 循环，扮演“雷达”，一格一格扫描整个地图
        for (int r = 0; r < rows; r++) {
            for (int c = 0; c < cols; c++) {
                // 如果雷达扫到了陆地 '1'
                if (grid[r][c] == '1') {
                    islandCount++; // 发现新岛屿，计数器 +1
                    dfs(grid, r, c); // 派出空军，把这座岛以及和它相连的陆地全部炸平！
                }
            }
        }

        return islandCount;
    }

    // 辅助函数：深度优先搜索（沉岛行动）
    private void dfs(char[][] grid, int r, int c) {
        int rows = grid.length;
        int cols = grid[0].length;

        // 1. 递归终止条件（越界，或者是水）
        // 如果超出了地图边界，或者当前格子已经是水（'0'）了，立刻返回
        if (r < 0 || c < 0 || r >= rows || c >= cols || grid[r][c] == '0') {
            return;
        }

        // 2. 核心操作：把当前陆地“击沉”，变成水 '0'，防止后续重复访问！
        grid[r][c] = '0';

        // 3. 蔓延扩散：向四周（上下左右）继续发起沉岛行动
        dfs(grid, r - 1, c); // 上
        dfs(grid, r + 1, c); // 下
        dfs(grid, r, c - 1); // 左
        dfs(grid, r, c + 1); // 右
    }
}
```
### 复杂度
  - **时间复杂度**：$O(M \times N)$。其中 $M$ 和 $N$ 分别为行数和列数。整个网格中的每个格子最多只会被主循环雷达扫描一次，被 DFS 访问一次，是极其高效的线性时间。
  - **空间复杂度**：$O(M \times N)$。在最坏情况下（整个网格全都是连成一片的陆地 `'1'`），DFS 的递归调用栈会深入到 $M \times N$ 层。

### 易错点与扩展（面试细节大考问）

1. **面试追问 1：“如果面试官要求【绝不能修改原数组】（不可变约束），你该怎么办？”**
   - **满分抢答**：在真实的工程中，直接修改传入的参数确实是不好的习惯（可能有其他线程正在读这幅地图）。如果不允许原地修改 `grid` 变 `'0'`，我们可以开辟一个同等大小的布尔矩阵 `boolean[][] visited`。
   - 每次遇到陆地时，先检查 `visited[r][c]` 是不是 `true`。如果在 DFS 遍历时，把经过的格子标记为 `visited[r][c] = true`，一样能起到防止重复计算的作用。这叫“状态备忘录”。
2. **面试追问 2：“如果地图极其巨大，DFS 导致系统栈溢出了，你能用【广度优先搜索 (BFS)】来实现吗？”**
   - **满分抢答**：可以！思路一模一样，只是把“递归的 DFS”换成“基于队列的 BFS”。
   - 遇到 `'1'` 时计数加 1，并把坐标存入 `Queue`。然后只要队列不为空，就弹出一个坐标，把它变成 `'0'`，并把周围合法的 `'1'` 的坐标塞进队列。这就像往水面上扔一块石头，波纹一圈圈荡开去吞噬陆地。
3. **高级装杯词汇：“并查集 (Union-Find)”**
   - 这道题也是并查集的绝佳练手题。一开始把所有的 `'1'` 都看作独立的集合（各自为王），然后遍历网格，如果两个 `'1'` 相邻，就把它们“合并（Union）”成一个集合。最后统计一共有多少个独立的“大头目”即可。你能提一嘴并查集，面试官会觉得你基础非常扎实。

## Python 完整推导

### 一块岛只数一次

外层两层循环像雷达一样扫描网格。遇到 `1` 时会发现一块可能的陆地，但如果它是已经走过的大岛的一部分，就不能再次增加答案，所以需要 `visited`。每次发现一个从未访问的 `1`，就确定出现了一座新岛，再从这个起点把整座岛找完。

所谓“整座岛找完”，就是不断从队列取出陆地格，查看上下左右。界内、未访问、值为 `1` 的邻居属于同一座岛；标记它们后加入队列。整座岛的全部分量处理完，队列才会空，外层扫描才继续。

### 走一遍 `[["1","1","0"],["1","0","1"]]`

1. 扫描到左上角 `(0,0)` 为 `1` 且未访问，岛屿数变为 1。标记它，队列为 `[(0,0)]`。
2. 弹出 `(0,0)`，右邻居 `(0,1)` 和下邻居 `(1,0)` 都被标记并入队。队列变为 `[(0,1),(1,0)]`。
3. 弹出 `(0,1)`，它的陆地邻居都已经访问；再弹出 `(1,0)`，左上方也处理过。队列为空，第一座岛完成。
4. 外层继续扫描到 `(1,2)`，它未被访问且为 `1`，岛屿数变为 2。它周围没有其他陆地，扩展结束。

最终返回 2。标记发生在入队时，所以同一格不会因两个邻居同时发现而重复入队。

全水网格不会启动任何 BFS，答案保持 0；每一个新岛只会由外层扫描中第一个未访问的陆地开启，后续同岛格子都被 visited 挡住。

### Python 实现

> 参考来源：代码随想录（programmercarl.com）
>
> 沿用项目旧 Python 的 BFS 与 visited 方案，并结合旧 Java 的“发现陆地后扩展整座岛”叙事；变量、方向和注释按本站整理。

```python
from collections import deque
from typing import List


class Solution:
    def numIslands(self, grid: List[List[str]]) -> int:
        rows, cols = len(grid), len(grid[0])
        visited = [[False] * cols for _ in range(rows)]
        islands = 0

        for row in range(rows):
            for col in range(cols):
                if grid[row][col] == "0" or visited[row][col]:
                    continue

                islands += 1
                visited[row][col] = True
                queue = deque([(row, col)])
                while queue:
                    current_row, current_col = queue.popleft()
                    for next_row, next_col in (
                        (current_row + 1, current_col),
                        (current_row - 1, current_col),
                        (current_row, current_col + 1),
                        (current_row, current_col - 1),
                    ):
                        if (
                            0 <= next_row < rows
                            and 0 <= next_col < cols
                            and not visited[next_row][next_col]
                            and grid[next_row][next_col] == "1"
                        ):
                            visited[next_row][next_col] = True
                            queue.append((next_row, next_col))
        return islands
```

### 队列和访问标记

`deque.popleft()` 遵循先进先出，当前层的格子扩展完后再处理刚发现的邻居；DFS 或 BFS 都能划出同一分量，这里选队列是为了避免深连通区域占用 Python 递归栈。

`visited` 有 `rows` 行，每一行都用独立的 `[False] * cols` 创建。若写 `[[False] * cols] * rows`，所有行会共享同一列表。向量判断中的 `and` 会先检查边界，再访问形状中的格子。

### 复杂度

- 时间复杂度：`O(m·n)`。
- 空间复杂度：`O(m·n)`。

每个格子最多扫描一次、入队一次、出队一次，时间 O(m·n)；visited 与最坏队列大小均为 O(m·n)。

```cpp
int dir[4][2] = {0, 1, 1, 0, -1, 0, 0, -1}; // 四个方向
void bfs(vector<vector<char>>& grid, vector<vector<bool>>& visited, int x, int y) {
    queue<pair<int, int>> que;
    que.push({x, y});
    while(!que.empty()) {
        pair<int ,int> cur = que.front(); que.pop();
        int curx = cur.first;
        int cury = cur.second;
        visited[curx][cury] = true; // 从队列中取出在标记走过
        for (int i = 0; i < 4; i++) {
            int nextx = curx + dir[i][0];
            int nexty = cury + dir[i][1];
            if (nextx < 0 || nextx >= grid.size() || nexty < 0 || nexty >= grid[0].size()) continue;  // 越界了，直接跳过
            if (!visited[nextx][nexty] && grid[nextx][nexty] == '1') {
                que.push({nextx, nexty});
            }
        }
    }

}
```

## Go 实现

> 实现来源：站内标准实现



```go
func numIslands(grid [][]byte) int {
	ans := 0
	m, n := len(grid), len(grid[0])
	var dfs func(i, j int)
	dfs = func(i, j int) {
		if i < 0 || i >= m || j < 0 || j >= n || grid[i][j] != '1' {
			return
		}
		grid[i][j] = '0' // 沉岛：访问过即置 0，避免重复计数
		dfs(i+1, j)
		dfs(i-1, j)
		dfs(i, j+1)
		dfs(i, j-1)
	}
	for i := 0; i < m; i++ {
		for j := 0; j < n; j++ {
			if grid[i][j] == '1' {
				ans++
				dfs(i, j)
			}
		}
	}
	return ans
}
```
