207. 课程表

← 图论专题 · 总目录 · 复习清单

难度中等核心模式Kahn 拓扑排序时间复杂度O(V+E)空间复杂度O(V+E)

题目与约束

你这个学期必须选修 numCourses 门课程，记为 0 到 numCourses - 1 。

在选修某些课程之前需要一些先修课程。 先修课程按数组 prerequisites 给出，其中 prerequisites[i] = [ai, bi] ，表示如果要学习课程 ai 则 必须 先学习课程 bi~ ~。

  • 例如，先修课程对 [0, 1] 表示：想要学习课程 0 ，你需要先完成课程 1 。

请你判断是否可能完成所有课程的学习？如果可以，返回 true ；否则，返回 false 。

示例 1：

输入：numCourses = 2, prerequisites = [[1,0]]
输出：true
解释：总共有 2 门课程。学习课程 1 之前，你需要完成课程 0 。这是可能的。

示例 2：

输入：numCourses = 2, prerequisites = [[1,0],[0,1]]
输出：false
解释：总共有 2 门课程。学习课程 1 之前，你需要先完成课程 0 ；并且学习课程 0 之前，你还应先完成课程 1 。这是不可能的。

提示：

  • 1 <= numCourses <= 2000
  • 0 <= prerequisites.length <= 5000
  • prerequisites[i].length == 2
  • 0 <= ai, bi < numCourses
  • prerequisites[i] 中的所有课程对 互不相同

核心不变量

每学完一门课就减少后继入度，最终处理数应等于课程数。

完整推导

思路推导

  1. 直觉与痛点（循环死锁）：

    如果想学 A 必须先学 B，想学 B 必须先学 C，而想学 C 又必须先学 A。这三个课程就形成了一个死循环（环）。只要图里有环，你就一门课也学不了。所以，这道题的本质就是：在一个有向图中，判断是否存在环。

  2. 破局思路（Kahn 算法 / BFS 入度表法）：

    想象一下，全学校的学生都在挑课。哪些课是大家可以直接报名的？显然是那些“不需要任何先修课”的清流课程。

    在图论中，一个节点被指向的边数叫做入度（In-degree）。不需要先修课，就意味着它的入度为 0。

    • 第一步（建账本）：我们统计出所有课程的入度，并把所有入度为 0 的课程推进一个队列（Queue）里。
    • 第二步（毕业一门，解锁一批）：从队列里弹出一门入度为 0 的课（代表你修完了这门课）。既然你修完了它，那么所有以它为先修课的后续课程，压力都减轻了！我们将这些后续课程的入度全部减 1。
    • 第三步（接力跑）：在减 1 的过程中，如果发现某门后续课程的入度也变成了 0（代表它的所有先修课你都修完了），那就立刻把它也推进队列。
    • 结算：当队列空了，数一数你一共修完了多少门课。如果等于总课程数，皆大欢喜（返回 true）；如果小于总课程数，说明剩下的课掉进了循环依赖的死锁里，谁也无法变成 0（返回 false）。

    Java 实现（邻接表 + 入度表 BFS 满分版）

    C++ 实现

    实现来源：经典解法实现

    1. 建邻接表与入度表：修完一门课后继课程入度 -1
    2. 入度为 0 的课程入队（没有先修依赖，立刻可修）
    3. BFS 消费队列；最终修完的课程数 == 总数则无环 → true
    class Solution {
public:
    bool canFinish(int numCourses, vector<vector<int>>& prerequisites) {
        vector<vector<int>> adj(numCourses);
        vector<int> indeg(numCourses, 0);
        for (auto& p : prerequisites) { adj[p[1]].push_back(p[0]); indeg[p[0]]++; }
        queue<int> q;
        for (int i = 0; i < numCourses; i++) if (indeg[i] == 0) q.push(i);
        int taken = 0;
        while (!q.empty()) {
            int cur = q.front(); q.pop();
            taken++;
            for (int next : adj[cur])
                if (--indeg[next] == 0) q.push(next);
        }
        return taken == numCourses;
    }
};

    Python 实现

    实现来源：经典解法实现

    1. 建邻接表与入度表：修完一门课后继课程入度 -1
    2. 入度为 0 的课程入队（没有先修依赖，立刻可修）
    3. BFS 消费队列；最终修完的课程数 == 总数则无环 → true
    from collections import deque
class Solution:
    def canFinish(self, numCourses: int, prerequisites: List[List[int]]) -> bool:
        adj = [[] for _ in range(numCourses)]
        indeg = [0] * numCourses
        for a, b in prerequisites:
            adj[b].append(a)
            indeg[a] += 1
        q = deque(i for i in range(numCourses) if indeg[i] == 0)
        taken = 0
        while q:
            cur = q.popleft()
            taken += 1
            for nxt in adj[cur]:
                indeg[nxt] -= 1
                if indeg[nxt] == 0:
                    q.append(nxt)
        return taken == numCourses

    Go 实现

    实现来源：经典解法实现

    1. 建邻接表与入度表：修完一门课后继课程入度 -1
    2. 入度为 0 的课程入队（没有先修依赖，立刻可修）
    3. BFS 消费队列；最终修完的课程数 == 总数则无环 → true
    func canFinish(numCourses int, prerequisites [][]int) bool {
    adj := make([][]int, numCourses)
    indeg := make([]int, numCourses)
    for _, p := range prerequisites {
        adj[p[1]] = append(adj[p[1]], p[0])
        indeg[p[0]]++
    }
    queue := []int{}
    for i := 0; i < numCourses; i++ {
        if indeg[i] == 0 { queue = append(queue, i) }
    }
    taken := 0
    for len(queue) > 0 {
        cur := queue[0]
        queue = queue[1:]
        taken++
        for _, nxt := range adj[cur] {
            indeg[nxt]--
            if indeg[nxt] == 0 { queue = append(queue, nxt) }
        }
    }
    return taken == numCourses
}

    C 实现

    实现来源：经典解法实现

    1. 建邻接表与入度表：修完一门课后继课程入度 -1
    2. 入度为 0 的课程入队（没有先修依赖，立刻可修）
    3. BFS 消费队列；最终修完的课程数 == 总数则无环 → true
    bool canFinish(int numCourses, int** prerequisites, int prerequisitesSize, int* prerequisitesColSize) {
    int indeg[numCourses]; memset(indeg, 0, sizeof(indeg));
    /* 邻接表用扁平数组：edge[k] = {from, to} */
    int total = prerequisitesSize;
    int* to = malloc(sizeof(int) * (total + 1));
    int* head = malloc(sizeof(int) * (numCourses + 1));
    int* nxt = malloc(sizeof(int) * (total + 1));
    for (int i = 0; i < numCourses; i++) head[i] = -1;
    for (int i = 0; i < total; i++) {
        to[i] = prerequisites[i][0];
        nxt[i] = head[prerequisites[i][1]];
        head[prerequisites[i][1]] = i;
        indeg[prerequisites[i][0]]++;
    }
    int queue[numCourses], headq = 0, tailq = 0;
    for (int i = 0; i < numCourses; i++) if (indeg[i] == 0) queue[tailq++] = i;
    int taken = 0;
    while (headq < tailq) {
        int cur = queue[headq++];
        taken++;
        for (int e = head[cur]; e != -1; e = nxt[e])
            if (--indeg[to[e]] == 0) queue[tailq++] = to[e];
    }
    return taken == numCourses;
}

import java.util.ArrayList;
import java.util.LinkedList;
import java.util.List;
import java.util.Queue;

class Solution {
    public boolean canFinish(int numCourses, int[][] prerequisites) {
        // 1. 准备数据结构
        // inDegree 数组：记录每门课的入度（需要多少门先修课）
        int[] inDegree = new int[numCourses];
        // adj 邻接表：记录每门课是哪些课的先修课（主修课 -> 后续课列表）
        List<List<Integer>> adj = new ArrayList<>();
        for (int i = 0; i < numCourses; i++) {
            adj.add(new ArrayList<>());
        }

        // 2. 灌入数据，初始化邻接表和入度表
        for (int[] req : prerequisites) {
            int course = req[0];
            int pre = req[1];
            adj.get(pre).add(course); // pre -> course
            inDegree[course]++;       // 想要学 course，入度加 1
        }

        // 3. 将所有入度为 0（无须先修课）的课程放进队列
        Queue<Integer> queue = new LinkedList<>();
        for (int i = 0; i < numCourses; i++) {
            if (inDegree[i] == 0) {
                queue.offer(i);
            }
        }

        // 记录成功修完的课程数量
        int count = 0;

        // 4. 开始 BFS 拓扑排序
        while (!queue.isEmpty()) {
            int curr = queue.poll();
            count++; // 修完一门，计数加 1

            // 拿到当前课程的所有后续课程
            for (int nextCourse : adj.get(curr)) {
                inDegree[nextCourse]--; // 后续课程的先修条件达成一个，入度减 1

                // 如果入度被减到了 0，说明所有先修课都修完了，可以入队
                if (inDegree[nextCourse] == 0) {
                    queue.offer(nextCourse);
                }
            }
        }

        // 5. 如果修完的课程数等于总课程数，说明图里无环，可以全部修完
        return count == numCourses;
    }
}

复杂度

  • 时间复杂度：O(V + E)。其中 V 是课程数（顶点），E 是先修关系数（边）。建图需要遍历一遍所有边，BFS 过程中每个顶点进出队一次，每条边被剥离一次，是标准且极其高效的图遍历时间。
  • 空间复杂度：O(V + E)。邻接表占用 O(V + E) 的空间，入度数组占用 O(V)，队列最多占用 O(V)。
易错点与扩展（面试变体局）
  1. 面试追问 1：“如果我不单单想知道能不能修完，我还想让你【返回一种合理的修课顺序】，该怎么改？”（对应力扣 210 题：课程表 II） - 满分抢答：极其简单！上面的代码框架一个字都不用改。我们只需要把那个 int count 计数器，改成一个长为 numCourses 的一维数组 int[] order。每次从队列里 poll() 出一个节点时，顺手按顺序填进 order 数组里。最后判断如果填进去的课数等于 numCourses，返回 order，否则返回空数组。这就是拓扑排序的完全体！
  2. 面试追问 2：“这道题除了 BFS，能用 DFS（深度优先搜索）做吗？” - 满分抢答：完全可以。DFS 做这道题的本质是染色标记法（三色标记法）。 - 我们对每个节点定义三种状态：0（未访问）、1（正在访问中）、2（已经安全访问完毕）。 - 顺着某条路径一条道走到黑。如果 DFS 过程中撞见了一个状态为 1 的节点，说明它在当前这条递归路径里自己碰到了自己，当场捕获一个环，直接终止并返回 false。如果一条路顺利走到头，就把沿途节点染成 2（安全）。
