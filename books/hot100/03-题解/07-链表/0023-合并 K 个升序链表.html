难度困难
Java 主方法最小堆多路归并时间O(N log k)空间O(k)
Python 主方法两两分治多路归并时间O(N log k)空间O(k)（每轮合并后的链表数组）

题目与约束

给你一个链表数组，每个链表都已经按升序排列。

请你将所有链表合并到一个升序链表中，返回合并后的链表。

示例 1：

输入：lists = [[1,4,5],[1,3,4],[2,6]]
输出：[1,1,2,3,4,4,5,6]
解释：链表数组如下：
[
1->4->5,
1->3->4,
2->6
]
将它们合并到一个有序链表中得到。
1->1->2->3->4->4->5->6

示例 2：

输入：lists = []
输出：[]

示例 3：

输入：lists = [[]]
输出：[]

提示：

  • k == lists.length
  • 0 <= k <= 10^4
  • 0 <= lists[i].length <= 500
  • -10^4 <= lists[i][j] <= 10^4
  • lists[i] 按 升序 排列
  • lists[i].length 的总和不超过 10^4

Java 完整推导

Java 核心不变量

堆中始终只放每条链表当前最小的头节点。

完整推导

思路推导

  1. 直觉与痛点（顺序合并的惨剧）：

    既然我会“合并两个链表”，那我能不能先合并 1 和 2，把结果再去跟 3 合并，结果再去跟 4 合并……？

    痛点：极其低效！假设每个链表长度都是 n。第一次合并长度变成 2n，第二次变成 3n…… 第一个链表的节点会被反复遍历 k-1 次。时间复杂度飙升到 O(k2 · n)，面对庞大的数据绝对会超时。

  2. 破局思路 A（利用数据结构：最小堆 / 优先队列）：

    想象我们在举办一场多兵团比武。有 k 个排好序的队伍。

    • 擂台（最小堆）：我们只需要把这 k 个队伍的当前队长（头节点）叫到擂台上。
    • 打擂：裁判（优先队列）瞬间挑出这 k 个人里最弱（值最小）的一个，把他提出来，编入最终的结果链表。
    • 替补：这个最弱的人被调走后，他所在队伍的下一个人顶上来，站到擂台上继续比较。
    • 如此循环，直到所有队伍的人都被抽空！

  3. 破局思路 B（算法降维：分治法 Divide & Conquer）：

    参考体育比赛的淘汰赛赛程表。

    不需要一个个轮流上。让这 k 个链表两两配对，进行“合并两个链表”的比赛。

    第一轮过后，k 个链表变成了 k/2 个；第二轮变成 k/4 个…… 直到最后合并成 1 个总冠军！

    Java 实现（分治法 / 两两归并版，推荐）

    分治法的核心是复用“合并两个有序链表”：每轮把链表数组两两合并，规模减半， 共合并 log k 轮。这个版本不需要优先队列，面试中更适合作为主解法。

/**
 * Definition for singly-linked list.
 * public class ListNode {
 *     int val;
 *     ListNode next;
 *     ListNode() {}
 *     ListNode(int val) { this.val = val; }
 *     ListNode(int val, ListNode next) { this.val = val; this.next = next; }
 * }
 */
class Solution {
    private ListNode mergeTwo(ListNode a, ListNode b) {
        ListNode dummy = new ListNode(0);
        ListNode tail = dummy;
        while (a != null && b != null) {
            if (a.val <= b.val) {
                tail.next = a;
                a = a.next;
            } else {
                tail.next = b;
                b = b.next;
            }
            tail = tail.next;
        }
        tail.next = a != null ? a : b;
        return dummy.next;
    }

    public ListNode mergeKLists(ListNode[] lists) {
        if (lists == null || lists.length == 0) return null;

        ListNode[] current = lists;
        while (current.length > 1) {
            ListNode[] next = new ListNode[(current.length + 1) / 2];
            for (int i = 0; i < current.length; i += 2) {
                ListNode b = i + 1 < current.length ? current[i + 1] : null;
                next[i / 2] = mergeTwo(current[i], b);
            }
            current = next;
        }
        return current[0];
    }
}

复杂度

  • 时间复杂度：O(N log k)。每轮把所有链表两两合并，处理节点总数为 N；链表数量每轮减半，共进行 log k 轮。
  • 空间复杂度：O(k)。每轮保存合并后的链表数组；如果使用递归版分治，递归栈为 O(log k)。
易错点与扩展（进阶的细节）
  1. 踩坑警告：空链表的背刺 - 题目给的 lists 数组里，可能存在 null （比如 [[], [1], []]）。如果你在初始化堆的时候不加 if (head != null) 的判断，直接把 null 塞进 PriorityQueue，运行时会直接抛出 NullPointerException。
  2. 面试追问：“如果让你用【分治法】写，时间复杂度是多少？空间复杂度呢？” - 秒答：分治法的时间复杂度同样是 O(N log k)。因为每次合并两个链表是 O(N)，总共要合并 log k 轮（树的高度）。 - 进阶对比：分治法的空间复杂度更优！如果是迭代版的分治法，不需要优先队列的 O(k) 空间，空间复杂度可以压缩到极致的 O(1)。但最小堆解法在工程扩展性上更好（比如处理无限数据流（Data Stream）的合并，你无法一开始拿到所有链表进行分治，只能用堆实时处理）。

📝 备选思路：PriorityQueue（最小堆）

思路推导

  • 普通队列 (Queue)：就像在超市排队结账，讲究“先来后到”（FIFO：先进先出）。
  • 优先队列 (Priority Queue)：就像医院的急诊室，不看你什么时候来的，而是看“谁的病情最重”。优先级最高的人永远第一个被叫号！
  • 在 Java 中的默认设定：Java 的 PriorityQueue 默认是一个“最小堆（Min-Heap）”。也就是说，无论你怎么乱序把数字扔进去，只要你往外拿（出队），永远是最小的那个数第一个出来！

思路推导

先来看看我们在上一题中写的那句稍微有点复杂的代码：

PriorityQueue<ListNode> pq = new PriorityQueue<>(
    lists.length,
    (a, b) -> Integer.compare(a.val, b.val)
);

如果你只写 PriorityQueue<Integer> pq = new PriorityQueue<>();，Java 知道怎么比较整数大小，一切正常。

但是，在这个算法里，我们要往里面扔的是 ListNode（链表节点）！

Java 会懵逼：“你扔给我一堆节点，我怎么知道哪个节点更大、哪个节点更小？” 如果你不告诉它规则，程序运行时直接抛出报错（ClassCastException）。

思路推导

  1. lists.length：这是初始容量。告诉漏斗大概要装多少个元素（这里最多装 k 个队长），避免底层数组频繁扩容，提升性能。
  2. (a, b) -> Integer.compare(a.val, b.val)：这就是大名鼎鼎的比较器（Comparator）的 Lambda 简写。
    • 这句话是在教 Java 做人：“当你拿节点 a 和节点 b 比较时，不要管别的，请直接取出它们的里面的数字 a.val 和 b.val 进行比较！谁的 val 小，谁的优先级就高！”

补充：掌握它，只需要记住 3 个核心方法（API）

把 PriorityQueue 想象成一个带有自动排序魔法的盲盒。你只需要记住以下三个动作：

  1. 扔进去：pq.offer(node) - 把一个节点扔进堆里。不管你扔进去的是什么，它会在底层自动调整位置。 - 时间复杂度：O(log k)（底层是在一棵二叉树上顺着找位置，非常快）。
  2. 拿出来：pq.poll() - 这是最爽的一步。直接调用 poll()，它会把当前堆里最小的那个节点拿出来，并且从堆里删掉。 - 时间复杂度：O(log k)（拿走最顶上的元素后，它底层会自动把第二小的元素顶上来）。
  3. 看看不拿：pq.peek() - 仅仅是偷看一下目前最小的元素是谁，但不把它从堆里删掉。 - 时间复杂度：O(1)（瞬间瞄一眼最顶上的元素）。
  4. 是否为空：pq.isEmpty() - 判断堆里还有没有人。

👨‍🏫 老师的总结：

为什么在“合并 K 个链表”中，PriorityQueue 被称为神兵利器？

假设你有 10000 个链表（k = 10000）。

如果你每次都用一个 for 循环去这 10000 个节点里找最小值，找一次就要看 10000 眼，时间复杂度是 O(k)。

但如果你用 PriorityQueue，你把 10000 个节点扔进去，由于它是树形结构，每次找最小值并重排，只需要走 log2(10000) 步，也就是大约 14 步！

从 10000 步优化思路到 14 步，这就是数据结构的魅力，也是这道题被称为 Hard 的原因！掌握了它，以后所有的“前 K 个最大/最小元素（Top K）”问题，对你来说都是小菜一碟！

Python 完整推导

每轮把链表两两配对

把合并两条有序链表作为一个固定操作。第一轮让 k 条链表两两合并，得到约 k/2 条；下一轮继续减半，直到只剩一个头。

用三条链表走一遍

  • L1=1→4→5
  • L2=1→3→4
  • L3=2→6

第一轮合并 L1、L2，得到 1→1→3→4→4→5；L3 落单，原样进入下一轮。

第二轮合并这两段，得到 1→1→2→3→4→4→5→6。

Python 实现

参考来源：经典解法实现

保留旧 Python 的两两分治归并实现，整理变量并省略判题环境提供的节点类；算法未改变。

from typing import List, Optional


# ListNode 由力扣提供。
class Solution:
    def mergeKLists(
        self, lists: List[Optional[ListNode]]
    ) -> Optional[ListNode]:
        def merge_two(left, right):
            dummy = ListNode()
            tail = dummy
            while left and right:
                if left.val <= right.val:
                    tail.next = left
                    left = left.next
                else:
                    tail.next = right
                    right = right.next
                tail = tail.next
            tail.next = left if left else right
            return dummy.next

        if not lists:
            return None
        current = lists
        while len(current) > 1:
            next_round = []
            for i in range(0, len(current), 2):
                left = current[i]
                right = current[i + 1] if i + 1 < len(current) else None
                next_round.append(merge_two(left, right))
            current = next_round
        return current[0]

merge_two 的动作

只比较两条链当前头，接走较小节点并推进对应链表。其中一条耗尽后，另一条的剩余整段直接接到 tail.next。

null 输入

lists 为空时直接返回 None。lists 中有 None 时，merge_two(None, node) 会返回 node；一条落单链表也可原样进入下一轮。

为什么能如实得到 O(N log k)

每轮合并访问的节点总数至多 N；链表数量每轮减半，共 log k 轮。当前轮和下一轮保存的链表头合计 O(k)，算法的 Node 连接全部复用输入节点。

复杂度

  • 时间复杂度：O(N log k)。
  • 空间复杂度：O(k)（每轮合并后的链表数组）。

每轮合并总节点数至多 N，k 条链减半需要 log k 轮，故 O(N log k)；当前轮和下一轮数组总规模 O(k)。

C++ 实现

实现来源：经典解法实现

  1. 分治：两两合并链表数组，规模每轮减半
  2. 合并两个有序链表用哑头 + tail 逐个摘取（同 21 题）
  3. 共 log(k) 轮，每轮总工作量 O(n)
class Solution {
public:
    ListNode* mergeTwo(ListNode* a, ListNode* b) {
        ListNode dummy(0), *tail = &dummy;
        while (a && b) {
            if (a->val <= b->val) { tail->next = a; a = a->next; }
            else                  { tail->next = b; b = b->next; }
            tail = tail->next;
        }
        tail->next = a ? a : b;
        return dummy.next;
    }
    ListNode* mergeKLists(vector<ListNode*>& lists) {
        if (lists.empty()) return nullptr;
        while (lists.size() > 1) {
            vector<ListNode*> next;
            for (int i = 0; i < lists.size(); i += 2) {
                ListNode* a = lists[i];
                ListNode* b = i + 1 < lists.size() ? lists[i + 1] : nullptr;
                next.push_back(mergeTwo(a, b));
            }
            lists = next;
        }
        return lists[0];
    }
};

Go 实现

实现来源：经典解法实现

  1. 分治：两两合并链表数组，规模每轮减半
  2. 合并两个有序链表用哑头 + tail 逐个摘取（同 21 题）
  3. 共 log(k) 轮，每轮总工作量 O(n)
func mergeKLists(lists []*ListNode) *ListNode {
    var mergeTwo = func(a, b *ListNode) *ListNode {
        dummy := &ListNode{}
        tail := dummy
        for a != nil && b != nil {
            if a.Val <= b.Val { tail.Next = a; a = a.Next } else { tail.Next = b; b = b.Next }
            tail = tail.Next
        }
        if a != nil { tail.Next = a } else { tail.Next = b }
        return dummy.Next
    }
    if len(lists) == 0 { return nil }
    for len(lists) > 1 {
        var nxt []*ListNode
        for i := 0; i < len(lists); i += 2 {
            a := lists[i]
            var b *ListNode
            if i+1 < len(lists) { b = lists[i+1] }
            nxt = append(nxt, mergeTwo(a, b))
        }
        lists = nxt
    }
    return lists[0]
}

C 实现

实现来源：经典解法实现

  1. 分治：两两合并链表数组，规模每轮减半
  2. 合并两个有序链表用哑头 + tail 逐个摘取（同 21 题）
  3. 共 log(k) 轮，每轮总工作量 O(n)
struct ListNode* mergeTwo(struct ListNode* a, struct ListNode* b) {
    struct ListNode dummy; dummy.next = NULL;
    struct ListNode* tail = &dummy;
    while (a && b) {
        if (a->val <= b->val) { tail->next = a; a = a->next; }
        else                  { tail->next = b; b = b->next; }
        tail = tail->next;
    }
    tail->next = a ? a : b;
    return dummy.next;
}
struct ListNode* mergeKLists(struct ListNode** lists, int listsSize) {
    if (listsSize == 0) return NULL;
    while (listsSize > 1) {
        int out = 0;
        for (int i = 0; i < listsSize; i += 2) {
            struct ListNode* b = i + 1 < listsSize ? lists[i + 1] : NULL;
            lists[out++] = mergeTwo(lists[i], b);
        }
        listsSize = out;
    }
    return lists[0];
}
