## 题目与约束

请你设计并实现一个满足  [LRU (最近最少使用) 缓存](https://baike.baidu.com/item/LRU) 约束的数据结构。

  实现 `LRUCache` 类：

  `LRUCache(int capacity)` 以 **正整数** 作为容量 `capacity` 初始化 LRU 缓存
  `int get(int key)` 如果关键字 `key` 存在于缓存中，则返回关键字的值，否则返回 `-1` 。
  `void put(int key, int value)` 如果关键字 `key` 已经存在，则变更其数据值 `value` ；如果不存在，则向缓存中插入该组 `key-value` 。如果插入操作导致关键字数量超过 `capacity` ，则应该 **逐出** 最久未使用的关键字。

  函数 `get` 和 `put` 必须以 `O(1)` 的平均时间复杂度运行。

  **示例：**

  **输入**<br>["LRUCache", "put", "put", "get", "put", "get", "put", "get", "get", "get"]<br>[[2], [1, 1], [2, 2], [1], [3, 3], [2], [4, 4], [1], [3], [4]]<br>**输出**<br>[null, null, null, 1, null, -1, null, -1, 3, 4]<br><br>**解释**<br>LRUCache lRUCache = new LRUCache(2);<br>lRUCache.put(1, 1); // 缓存是 {1=1}<br>lRUCache.put(2, 2); // 缓存是 {1=1, 2=2}<br>lRUCache.get(1);    // 返回 1<br>lRUCache.put(3, 3); // 该操作会使得关键字 2 作废，缓存是 {1=1, 3=3}<br>lRUCache.get(2);    // 返回 -1 (未找到)<br>lRUCache.put(4, 4); // 该操作会使得关键字 1 作废，缓存是 {4=4, 3=3}<br>lRUCache.get(1);    // 返回 -1 (未找到)<br>lRUCache.get(3);    // 返回 3<br>lRUCache.get(4);    // 返回 4

  **提示：**

  - `1 <= capacity <= 3000`
  - `0 <= key <= 10000`
  - `0 <= value <= 105`
  - 最多调用 `2 * 105` 次 `get` 和 `put`

## 完整推导

### 思路推导
  1. **直觉与痛点分析**：
     - 要想 $O(1)$ 查找（`get`），必须得用**哈希表（HashMap）**。
     - 要想有“最近最少使用”的淘汰机制，必须有**顺序**，并且能频繁地在两头进行移动和删除（新来的放一头，旧的从另一头踢掉）。数组挪动元素是 $O(N)$，不行；普通的单链表删除节点需要找前驱节点，也是 $O(N)$，不行。
  2. **破局思路（哈希表 + 双向链表）**：
     - 既然单一结构搞不定，我们就把它们拼起来！
     - 我们构建一个**双向链表**：规定**靠近头部的节点是“最近使用的”**，**靠近尾部的节点是“最久未使用的”**。
     - 同时用一个 **HashMap**：Key 就是缓存的 Key，Value 直接指向双向链表中的节点（Node）内存地址。
  3. **微操推演（四套标准动作）**：
     - **遇到 `get` 且存在**：通过 HashMap 瞬间 $O(1)$ 找到那个节点。不仅返回值，还要**把这个节点从链表当前位置剪下来，重新插到链表头部**（因为它刚被用过，变成“最近使用”了）。
     - **遇到 `put` 且已存在**：和 `get` 类似，先通过 HashMap 找到节点，更新它的值，然后**把它挪到头部**。
     - **遇到 `put` 且不存在（缓存未满）**：新建一个节点，把它插入到链表头部，并在 HashMap 中记录。
     - **遇到 `put` 且不存在（缓存已满）**：残酷的淘汰来了。直接把**链表尾部**的那个节点咔嚓掉（它就是最久没用的），同时**务必记得从 HashMap 中也删掉对应的 Key**！然后再把新节点插到头部并放入 HashMap。
### Java 实现（手撕底层实现）
```java
import java.util.HashMap;
import java.util.Map;

class LRUCache {

    // 1. 定义双向链表的节点类
    class DLinkedNode {
        int key;
        int value;
        DLinkedNode prev;
        DLinkedNode next;
        public DLinkedNode() {}
        public DLinkedNode(int _key, int _value) {key = _key; value = _value;}
    }

    private Map<Integer, DLinkedNode> cache = new HashMap<>();
    private int size;
    private int capacity;
    // 使用虚拟头节点和虚拟尾节点，拯救无数繁琐的判空逻辑！
    private DLinkedNode head, tail;

    public LRUCache(int capacity) {
        this.size = 0;
        this.capacity = capacity;
        // 初始化双向链表：head <-> tail
        head = new DLinkedNode();
        tail = new DLinkedNode();
        head.next = tail;
        tail.prev = head;
    }

    public int get(int key) {
        DLinkedNode node = cache.get(key);
        if (node == null) {
            return -1; // 没找到
        }
        // 如果找到了，说明该被访问了，把它挪到头部（VIP座）
        moveToHead(node);
        return node.value;
    }

    public void put(int key, int value) {
        DLinkedNode node = cache.get(key);
        if (node == null) {
            // 如果不存在，是个新数据
            DLinkedNode newNode = new DLinkedNode(key, value);
            cache.put(key, newNode); // 放进 HashMap
            addToHead(newNode);      // 放进链表头部
            size++;

            // 如果超标了，执行淘汰机制
            if (size > capacity) {
                // 揪出尾巴前面的那个真实的最后一名
                DLinkedNode tail = removeTail();
                // 极其容易忘的一步：把 HashMap 里的 Key 也删掉！
                cache.remove(tail.key);
                size--;
            }
        } else {
            // 如果存在，只是更新值
            node.value = value;
            // 刚被操作过，挪到头部
            moveToHead(node);
        }
    }

    // ================= 以下是极其优雅的链表微操（黑盒化） =================

    // 动作A：把新节点加到头部（head 和第一个真实节点之间）
    private void addToHead(DLinkedNode node) {
        node.prev = head;
        node.next = head.next;
        head.next.prev = node;
        head.next = node;
    }

    // 动作B：把一个节点从链表中硬生生挖出来（前后相连）
    private void removeNode(DLinkedNode node) {
        node.prev.next = node.next;
        node.next.prev = node.prev;
    }

    // 动作C：把节点挪到头部（= 挖出来 + 加到头部）
    private void moveToHead(DLinkedNode node) {
        removeNode(node);
        addToHead(node);
    }

    // 动作D：淘汰真实的尾部节点，并返回它（为了让上层去 HashMap 里删对应的 Key）
    private DLinkedNode removeTail() {
        DLinkedNode res = tail.prev;
        removeNode(res);
        return res;
    }
}
```
### 复杂度
  - **时间复杂度**：对于 `put` 和 `get` 都是绝对的 $O(1)$。
  - **空间复杂度**：$O(capacity)$。HashMap 和双向链表最多存储 `capacity` 个元素。

### 易错点与扩展（面试灵魂追问）

1. **送命题：“为什么一定要用【双向】链表？单链表不行吗？”**
   - **满分抢答**：单链表**绝对不行**。因为当我们用 HashMap 以 $O(1)$ 的时间定位到某个节点准备把它移动到头部时（或者准备删除它时），我们必须修改它**前驱节点**的 `next` 指针！如果是单链表，我们找不到前驱节点，只能从头遍历去找，那时间复杂度就退化成 $O(N)$ 了。双向链表的 `prev` 指针完美解决了这个问题！
2. **踩坑警告：为什么 Node 里面除了存 Value，还要存 Key？**
   - 仔细看代码里的淘汰逻辑：当缓存满了，我们要删掉链表尾部的节点。**删完尾部节点后，我们还必须去 HashMap 里把对应的键值对也删掉！** 如果节点里不存 Key，我们只知道被删的节点长啥样，却不知道拿什么 Key 去 HashMap 里调用 `cache.remove(key)`。
3. **进阶的后路：“其实 Java 原生支持 LRU...”**
   - 在完成手写后，你可以云淡风轻地向面试官提一嘴：“在工程实践中，Java 的 `LinkedHashMap` 只要重写 `removeEldestEntry` 方法，5 行代码就能实现一个工业级的 LRU 缓存。” 这能展现出你不仅仅是个做题家，还是个懂 JDK 底层的实战派。

## Python 完整推导

### 字典定位节点，双向链表维护顺序

字典回答 key 对应的节点在哪里；双向链表把节点从新到旧排列。dummy 自成一个环，dummy.next 是最新节点，dummy.previous 是最旧节点。

get 命中时把节点先摘下再插回头部。put 命中时更新值并移到头部；未命中时创建节点，插入后若超过容量，就从 dummy.previous 淘汰最旧节点，并同步删除字典项。

### 用容量 2 追踪 LeetCode 操作序列

1. put(1,1)：新到旧为 [1]。
2. put(2,2)：新到旧为 [2,1]。
3. get(1)：返回 1，并把 1 移到头部；新到旧才变成 [1,2]。
4. put(3,3)：3 放到头部，超容量淘汰尾部 2；顺序变成 [3,1]。
5. get(2)：返回 -1。
6. put(4,4)：淘汰尾部 1，顺序变成 [4,3]。
7. get(3) 返回 3 并把顺序变成 [3,4]；get(4) 返回 4。

注意第 2 步只是 put(2,2)，还没有 get(1)，所以不能提前把顺序写成 [1,2]。

### Python 实现

> 参考来源：灵茶山艾府题解（MIT License）
>
> 保留旧 Python 的单个自环虚拟节点加字典实现，整理辅助方法名和非必要注解；算法未改变。

```python
class _Node:
    __slots__ = ("key", "value", "previous", "next")

    def __init__(self, key=0, value=0):
        self.key = key
        self.value = value
        self.previous = None
        self.next = None


class LRUCache:
    def __init__(self, capacity: int):
        self.capacity = capacity
        self.nodes = {}
        self.dummy = _Node()
        self.dummy.previous = self.dummy.next = self.dummy

    def _remove(self, node):
        node.previous.next = node.next
        node.next.previous = node.previous

    def _push_front(self, node):
        node.previous = self.dummy
        node.next = self.dummy.next
        node.previous.next = node
        node.next.previous = node

    def _get_node(self, key):
        node = self.nodes.get(key)
        if node is None:
            return None
        self._remove(node)
        self._push_front(node)
        return node

    def get(self, key: int) -> int:
        node = self._get_node(key)
        if node is None:
            return -1
        return node.value

    def put(self, key: int, value: int) -> None:
        node = self._get_node(key)
        if node is not None:
            node.value = value
            return
        node = _Node(key, value)
        self.nodes[key] = node
        self._push_front(node)
        if len(self.nodes) > self.capacity:
            oldest = self.dummy.previous
            del self.nodes[oldest.key]
            self._remove(oldest)
```

### get_node 同时完成移动

_get_node 先查字典，未命中返回 None；命中后先摘除再插到 dummy 后。get 与 put 的已有键分支都复用这一动作。

### 循环链表的摘除与插入

- _remove 让节点前后邻居直接相连。
- _push_front 让 node.previous=dummy、node.next=原第一节点，再把邻居指向它。
- 空缓存时 dummy.previous 和 dummy.next 都指向 dummy 自己，插入和淘汰不需要额外判空。

### 淘汰顺序

新节点先进入字典与链表，再用 len(self.nodes) > capacity 判断超限。oldest=dummy.previous 后，先从字典删除 oldest.key，再摘链，链表和字典才保持一致。

### 成本口径

字典查询、插入和删除按平均 O(1) 计；双向链表的摘除和头插也是 O(1)，节点数不超过 capacity。

### 复杂度

- 时间复杂度：`get 与 put 平均 O(1)`。
- 空间复杂度：`O(capacity)`。

字典定位平均 O(1)，双向链表摘除和头部插入 O(1)，节点数不超过 capacity。

## C++ 实现

> 实现来源：灵茶山艾府题解（MIT License）



```cpp
struct Node {
    int key;
    int value;
    Node* prev;
    Node* next;

    Node(int k = 0, int v = 0) : key(k), value(v) {}
};

class LRUCache {
private:
    int capacity;
    Node* dummy; // 哨兵节点
    unordered_map<int, Node*> key_to_node;

    // 删除一个节点（抽出一本书）
    void remove(Node* x) {
        x->prev->next = x->next;
        x->next->prev = x->prev;
    }

    // 在链表头添加一个节点（把一本书放到最上面）
    void push_front(Node* x) {
        x->prev = dummy;
        x->next = dummy->next;
        x->prev->next = x;
        x->next->prev = x;
    }

    // 获取 key 对应的节点，同时把该节点移到链表头部
    Node* get_node(int key) {
        auto it = key_to_node.find(key);
        if (it == key_to_node.end()) { // 没有这本书
            return nullptr;
        }
        Node* node = it->second; // 有这本书
        remove(node); // 把这本书抽出来
        push_front(node); // 放到最上面
        return node;
    }

public:
    LRUCache(int capacity) : capacity(capacity), dummy(new Node()) {
        dummy->prev = dummy;
        dummy->next = dummy;
    }

    int get(int key) {
        Node* node = get_node(key); // get_node 会把对应节点移到链表头部
        return node ? node->value : -1;
    }

    void put(int key, int value) {
        Node* node = get_node(key); // get_node 会把对应节点移到链表头部
        if (node) { // 有这本书
            node->value = value; // 更新 value
            return;
        }
        key_to_node[key] = node = new Node(key, value); // 新书
        push_front(node); // 放到最上面
        if (key_to_node.size() > capacity) { // 书太多了
            Node* back_node = dummy->prev;
            key_to_node.erase(back_node->key);
            remove(back_node); // 去掉最后一本书
            delete back_node; // 释放内存
        }
    }
};
```

## Go 实现

> 实现来源：灵茶山艾府题解（MIT License）



```go
type Node struct {
    key, value int
    prev, next *Node
}

type LRUCache struct {
    capacity  int
    dummy     *Node // 哨兵节点
    keyToNode map[int]*Node
}

func Constructor(capacity int) LRUCache {
    dummy := &Node{}
    dummy.prev = dummy
    dummy.next = dummy
    return LRUCache{
        capacity:  capacity,
        dummy:     dummy,
        keyToNode: map[int]*Node{},
    }
}

// 删除一个节点（抽出一本书）
func (c *LRUCache) remove(x *Node) {
    x.prev.next = x.next
    x.next.prev = x.prev
}

// 在链表头添加一个节点（把一本书放到最上面）
func (c *LRUCache) pushFront(x *Node) {
    x.prev = c.dummy
    x.next = c.dummy.next
    x.prev.next = x
    x.next.prev = x
}

// 获取 key 对应的节点，同时把该节点移到链表头部
func (c *LRUCache) getNode(key int) *Node {
    node := c.keyToNode[key]
    if node == nil { // 没有这本书
        return nil
    }
    c.remove(node)    // 把这本书抽出来
    c.pushFront(node) // 放到最上面
    return node
}

func (c *LRUCache) Get(key int) int {
    node := c.getNode(key) // getNode 会把对应节点移到链表头部
    if node == nil {
        return -1
    }
    return node.value
}

func (c *LRUCache) Put(key, value int) {
    node := c.getNode(key) // getNode 会把对应节点移到链表头部
    if node != nil {       // 有这本书
        node.value = value // 更新 value
        return
    }
    node = &Node{key: key, value: value} // 新书
    c.keyToNode[key] = node
    c.pushFront(node) // 放到最上面
    if len(c.keyToNode) > c.capacity { // 书太多了
        backNode := c.dummy.prev
        delete(c.keyToNode, backNode.key)
        c.remove(backNode) // 去掉最后一本书
    }
}
```
