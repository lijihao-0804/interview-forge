31. 下一个排列

难度中等
Java 主方法找拐点、交换、反转后缀时间O(n)空间O(1)
Python 主方法右端拐点 + 最小增量交换 + 后缀反转时间O(n)空间O(1)

题目与约束

整数数组的一个 排列 就是将其所有成员以序列或线性顺序排列。

  • 例如，arr = [1,2,3] ，以下这些都可以视作 arr 的排列：[1,2,3]、[1,3,2]、[3,1,2]、[2,3,1] 。

整数数组的 下一个排列 是指其整数的下一个字典序更大的排列。更正式地，如果数组的所有排列根据其字典顺序从小到大排列在一个容器中，那么数组的 下一个排列 就是在这个有序容器中排在它后面的那个排列。如果不存在下一个更大的排列，那么这个数组必须重排为字典序最小的排列（即，其元素按升序排列）。

  • 例如，arr = [1,2,3] 的下一个排列是 [1,3,2] 。
  • 类似地，arr = [2,3,1] 的下一个排列是 [3,1,2] 。
  • 而 arr = [3,2,1] 的下一个排列是 [1,2,3] ，因为 [3,2,1] 不存在一个字典序更大的排列。

给你一个整数数组 nums ，找出 nums 的下一个排列。

必须原地修改，只允许使用额外常数空间。

示例 1：

输入：nums = [1,2,3]
输出：[1,3,2]

示例 2：

输入：nums = [3,2,1]
输出：[1,2,3]

示例 3：

输入：nums = [1,1,5]
输出：[1,5,1]

提示：

  • 1 <= nums.length <= 100
  • 0 <= nums[i] <= 100

Java 完整推导

Java 核心不变量

从右侧找到仍可增大的最靠右位置，并使用最小增量。

完整推导

思路推导

  1. 直觉与痛点（全排列的噩梦）：

    最暴力的想法是：把所有排列都生成出来，排个序，找当前排列的下一个。

    痛点：全排列的时间复杂度是 O(N!)（阶乘级），如果数组长度是 20，这辈子也算不完。

  2. 降维破局（尽可能小的变大）：

    我们要寻找“下一个”排列，这就意味着我们需要把数组变得比现在大一点点，但又不能太大。

    怎么才能让它只大一点点呢？

    • 原则 1：我们应该尽量修改靠右边（低位）的数字，保留靠左边（高位）的数字不动。
    • 原则 2：我们需要把右边的一个小数字和它后面的一个大数字交换。

  3. 核心微操（悬崖寻宝四步曲）：

    假设数组是 [1, 3, 5, 4, 2]。我们把数字想象成一座座山峰。

    • 第一步（找悬崖底）：从右往左扫描，找到第一个不再递增的数字。

    2 -> 4 -> 5 都是一路走高的。走到 3 的时候，突然跌落了（3 < 5）。这个 3（索引为 i）就是我们要替换的“小数”！

    • 第二步（找接班人）：既然要把 3 换掉，换成谁呢？要找一个比 3 大，但又是尽可能小的数。

    因为 i 右边的数字 [5, 4, 2] 绝对是降序的，所以我们再次从右往左扫，找到第一个比 3 大的数字，发现是 4（索引为 j）。

    • 第三步（完成交接）：把 3 和 4 交换。数组变成了 [1, 4, 5, 3, 2]。

    现在数字变大了吗？确实变大了（前缀从 13 变成了 14）。

    • 第四步（完美掉头）：现在是最小的变大吗？不是！因为交换后的后缀 [5, 3, 2] 仍然是降序（极大值）。为了让整个数字尽可能小，我们需要把这个后缀变成升序（极小值）。怎么把降序变成升序？直接反转（Reverse）即可！

    后缀反转后变成 [2, 3, 5]，最终结果 [1, 4, 2, 3, 5]，完美破局！

    Java 实现（满分四步法）

class Solution {
    public void nextPermutation(int[] nums) {
        if (nums == null || nums.length <= 1) return;

        // 1. 从右向左找第一个下降的数字（悬崖底）
        int i = nums.length - 2;
        while (i >= 0 && nums[i] >= nums[i + 1]) {
            i--;
        }

        // 如果 i >= 0，说明找到了这个悬崖底；
        // 如果 i < 0，说明整个数组完全是降序的（比如 [3, 2, 1]），它是最大的排列。
        // 对于完全降序，我们跳过第 2 和 3 步，直接进入第 4 步将其全部反转即可。
        if (i >= 0) {
            // 2. 再次从右向左，在 i 的右侧寻找第一个比 nums[i] 大的数字（接班人）
            int j = nums.length - 1;
            while (j >= 0 && nums[j] <= nums[i]) {
                j--;
            }

            // 3. 交换这两个数字
            swap(nums, i, j);
        }

        // 4. 将 i 之后的全部元素反转（从降序变成升序，达到局部极小值）
        reverse(nums, i + 1, nums.length - 1);
    }

    // 辅助函数：交换数组元素
    private void swap(int[] nums, int a, int b) {
        int temp = nums[a];
        nums[a] = nums[b];
        nums[b] = temp;
    }

    // 辅助函数：双指针反转指定区间的数组
    private void reverse(int[] nums, int start, int end) {
        while (start < end) {
            swap(nums, start, end);
            start++;
            end--;
        }
    }
}

复杂度

  • 时间复杂度：O(N)。在最坏情况下，我们只需要对数组进行至多两次单向扫描，外加一次局部反转，这都是极其迅速的线性操作。
  • 空间复杂度：O(1)。我们仅仅用了 i 和 j 两个整型指针，所有的交换和反转都在原数组上就地（In-place）完成，满足了最苛刻的内存要求。
易错点与扩展（面试的关键细节）
  1. 极度高频坑点：“如果有重复元素怎么办？比如 [1, 1, 5]，你的代码会死循环或者找错吗？” - 满分保命细节：绝对不会！请死死盯住第一步的 nums[i] >= nums[i + 1] 和第二步的 nums[j] <= nums[i]，这里的等号 = 是这道题的定海神针！ - 因为有等号的存在，我们在遇到重复元素时会毫不犹豫地继续往左滑。这保证了我们找到的 i 一定是严格小于后面的某个数，找到的 j 一定是严格大于 nums[i] 的数，完美规避了重复元素互相交换导致的无效操作。
  2. 面试追问：“为什么要用 Reverse（反转）而不是 Sort（排序）？” - 架构师级抢答：这是这道题最闪光的灵魂！因为我们在第一步找 i 时，i 右边的数字序列一定是一个严格单调递减（或包含相等）的序列！即使在第三步交换了 i 和 j 之后，由于 j 是刚好大于 i 的数，换上去之后，整个右侧依然保持着递减的特性。 - 既然一个序列已经是降序的，把它变成升序还需要调用 O(K log K) 的 Sort 吗？完全不需要！只需要双指针从两头向中间靠拢，做一次 O(K) 的 Reverse 即可！用 Reverse 代替 Sort，是把时间复杂度降维到 O(N) 的核心之钥。

Python 完整推导

让排列只增大“一点点”

从右向左看，如果一串数字一直递减，例如 5,4,2，它已经无法靠调换这一串内部顺序变得更大；真正需要改变的是它左边第一个停止递减的位置。把那个较小数字换成一个更大的，同时让变化尽量发生在右侧，才能得到字典序的下一个排列。

用 [1, 3, 5, 4, 2] 走四步

  1. 从右向左比较：4 >= 2，继续；5 >= 4，继续；到 3 < 5 时停止，pivot 指向下标 1 的数字 3。它右侧 [5,4,2] 是递减的。
  2. 在右侧从右向左找第一个大于 3 的数。最右的 2 不大于 3，继续到 4，得到 successor 下标 3。4 是右侧比 3 大的数中最小者。
  3. 交换 3 和 4，数组变为 [1,4,5,3,2]。前两位从 13 变成 14，整体确实增大，而且增大幅度尽量小。
  4. 交换后后缀仍递减。为了得到同一前缀下的最小排列，把后缀反转成 [2,3,5]，最终得到 [1,4,2,3,5]。

如果数组已经完全递减，例如 [3,2,1]，不存在 pivot。它已经是最大排列，下一个应回到最小排列，因此直接反转整个数组为 [1,2,3]。

找 successor 时必须使用严格 >，找到递减拐点时使用 >=。重复元素相等时继续向左，不会让排列停留在原值。

Python 实现

参考来源：代码随想录（programmercarl.com）

沿用旧项目收录的《代码随想录》下一排列 Python 代码；调整辅助函数为显式双指针后缀反转，变量、注释和类型签名按本页整理。

from typing import List


class Solution:
    def nextPermutation(self, nums: List[int]) -> None:
        pivot = len(nums) - 2
        while pivot >= 0 and nums[pivot] >= nums[pivot + 1]:
            pivot -= 1

        if pivot >= 0:
            successor = len(nums) - 1
            while nums[successor] <= nums[pivot]:
                successor -= 1
            nums[pivot], nums[successor] = nums[successor], nums[pivot]

        left = pivot + 1
        right = len(nums) - 1
        while left < right:
            nums[left], nums[right] = nums[right], nums[left]
            left += 1
            right -= 1

原地反转而非切片

while pivot >= 0 and nums[pivot] >= nums[pivot + 1] 找到最靠右的严格上升断点。若 pivot 不存在，它保持 -1，下一段 pivot + 1 正好从 0 开始，反转全数组。

找 successor 的循环从末尾开始，因为递减后缀从右往左看是从小到大，第一个严格大于 pivot 的值就是可用的最小增量。

left, right 双指针交换只移动两个下标，不创建后缀切片；所以空间为 O(1)。切片 nums[i+1:][::-1] 会新建列表，而且若写 nums = ... 还只会重新绑定局部名字，不能完成题目要求的原地修改。

边界

题目数组可能包含重复元素，也至少有一个。长度为 1 时 pivot 为 -1，反转区间只有一个元素，结果不变。

复杂度

  • 时间复杂度：O(n)。
  • 空间复杂度：O(1)。

寻找拐点、寻找 successor 和反转后缀各最多扫描一次，总时间 O(n)；除下标外没有额外容器，空间 O(1)。

C++ 实现

实现来源：站内标准实现

class Solution {
public:
    void nextPermutation(vector<int>& nums) {
        int n = nums.size(), i = n - 2;
        // 1) 从右往左找第一个升序对 (i, i+1)
        while (i >= 0 && nums[i] >= nums[i + 1]) --i;
        // 2) 在后缀中找最后一个大于 nums[i] 的数与之交换
        if (i >= 0) {
            int j = n - 1;
            while (nums[j] <= nums[i]) --j;
            swap(nums[i], nums[j]);
        }
        // 3) 反转后缀使其升序（变最小排列）
        reverse(nums.begin() + i + 1, nums.end());
    }
};

//卡尔的解法
func nextPermutation(nums []int)  {
    for i:=len(nums)-1;i>=0;i--{
        for j:=len(nums)-1;j>i;j--{
            if nums[j]>nums[i]{
                //交换
                nums[j],nums[i]=nums[i],nums[j]
                reverse(nums,0+i+1,len(nums)-1)
                return 
            }
        }
    }
    reverse(nums,0,len(nums)-1)
}
//对目标切片指定区间的反转方法
func reverse(a []int,begin,end int){
    for i,j:=begin,end;i<j;i,j=i+1,j-1{
        a[i],a[j]=a[j],a[i]
    }
}
