## 题目与约束

给定一个包含红色、白色和蓝色、共 `n`个元素的数组 `nums` ，**[原地](https://baike.baidu.com/item/%E5%8E%9F%E5%9C%B0%E7%AE%97%E6%B3%95)**对它们进行排序，使得相同颜色的元素相邻，并按照红色、白色、蓝色顺序排列。

  我们使用整数 0、 1 和 2 分别表示红色、白色和蓝色。

  必须在不使用库内置的 sort 函数的情况下解决这个问题。

  **示例 1：**

  **输入：**nums = [2,0,2,1,1,0]
  **输出：**[0,0,1,1,2,2]
  **解释：**
  该数组包含两个 0、两个 1 和两个 2。将它们原地排序后，所有 0 排在最前面，接着是所有 1，最后是所有 2。

  **示例 2：**

  **输入：**nums = [2,0,1]
  **输出：**[0,1,2]
  **解释：**
  数组中有且仅有一个 0、一个 1 和一个 2，按 0、1、2 的顺序原地排列。

  **提示：**

  - `n == nums.length`
  - `1 <= n <= 300`
  - `nums[i]` 为 0、1 或 2

  **进阶：**

  - 你能想出一个仅使用常数空间的一趟扫描算法吗？

## 完整推导

### 思路推导
  1. **直觉与痛点（两趟扫描的平庸）**：

     最简单的做法是计数排序：第一遍数出有多少个 0、1、2；第二遍直接把对应数量的 0、1、2 填进数组。

     **痛点**：这需要遍历数组**两次**。如果这个数组特别大，或者数组里的元素其实是带着巨大属性的复杂对象（不仅仅是数字），重写两次的代价会非常高昂。

  2. **降维破局（三路划分的艺术）**：

     我们要在一趟遍历中完成排序，就必须在数组中动态划定三个“势力范围”。

     我们引入三个指针：

     - **`p0`（0 的边界）**：它指向的位置，是**下一个 `0` 应该待的地方**。
     - **`p2`（2 的边界）**：它指向的位置，是**下一个 `2` 应该待的地方**。
     - **`i`（探索者/游标）**：负责从左到右去前线探路。

  3. **核心微操（遇到不同的敌人，怎么甩？）**：

     当探索者 `i` 遇到不同的数字时，执行不同的策略：

     - **遇到 `1`（白色）**：最省心。`1` 本来就该待在中间，所以 `i` 直接跳过，继续往前走（`i++`）。
     - **遇到 `0`（红色）**：红色的归宿在最左边！我们把 `nums[i]` 和 `nums[p0]` 互换。换完之后，左边的 0 阵营多了一名大将（`p0++`），并且游标也可以安心向前走（`i++`）。
     - **遇到 `2`（蓝色）**：蓝色的归宿在最右边！我们把 `nums[i]` 和 `nums[p2]` 互换。右边的 2 阵营多了一名大将（`p2--`）。
     - **💥 致命陷阱预警**：遇到 2 交换完之后，游标 `i` **绝对不能前进（绝不能 `i++`）**！为什么？因为你从右边 `p2` 换过来的那个数字，`i` 还没看过它呢！它可能是一个刺客（比如换过来一个 `0` 或者另一个 `2`），你必须停在原地，下一轮继续审视它！
### Java 实现（满分一次遍历版）
```java
class Solution {
    public void sortColors(int[] nums) {
        // p0 指向下一个 0 应该存放的位置
        int p0 = 0;
        // p2 指向下一个 2 应该存放的位置
        int p2 = nums.length - 1;
        // i 是正在遍历的游标
        int i = 0;

        // 🌟 致命细节：循环条件必须是 i <= p2
        // 因为 p2 指向的位置及其右边，已经被确认为全是 2 了
        // 当 i 越过 p2 时，说明所有的未知区域都已探索完毕，战斗结束！
        while (i <= p2) {
            if (nums[i] == 0) {
                // 遇到 0：扔给左边 p0。换过来的肯定是处理过的 1 或者自己，所以 i 可以放心前进
                swap(nums, i, p0);
                p0++;
                i++;
            } else if (nums[i] == 2) {
                // 遇到 2：扔给右边 p2。换过来的数字是未知的！所以 i 必须留在原地继续考察！
                swap(nums, i, p2);
                p2--;
                // 注意这里没有 i++ ！！！
            } else {
                // 遇到 1：完美，直接跳过
                i++;
            }
        }
    }

    // 辅助函数：交换数组元素
    private void swap(int[] nums, int a, int b) {
        int temp = nums[a];
        nums[a] = nums[b];
        nums[b] = temp;
    }
}
```
### 复杂度
  - **时间复杂度**：$O(N)$。游标 `i` 从左向右走，`p2` 从右向左走，每次循环至少有一个指针在收缩。当 `i > p2` 时立即停止，所有的元素严格只会被看一次。
  - **空间复杂度**：$O(1)$。全程只用了 `p0`、`p2`、`i` 三个指针，没有任何额外的数据结构。

### 易错点与扩展（面试的关键细节）

1. **最强高频翻车点：“为什么遇到 `0` 交换后可以 `i++`，遇到 `2` 交换后却不能 `i++`？”**

   - **满分保命大白话**：

     “因为游标 `i` 是从左往右走的！当我们执行 `swap(i, p0)` 时，`p0` 指向的那个元素，**肯定是被游标 `i` 提前扫过并验证过的**。在正确的运行逻辑下，`p0` 那个位置要么是 `0`（它俩重合），要么是已经被跳过的 `1`。把一个无害的 `1` 换到 `i` 的位置上，`i` 当然可以放心前进！”

     “但是！当我们执行 `swap(i, p2)` 时，`p2` 是从右边未知的黑暗区域拉过来的元素。这个新换过来的元素到底是 0、1 还是 2？游标 `i` 根本不知道。如果不留在原地查验它就直接 `i++`，就会把一个可能需要分类的错误元素遗漏在数组中间！”

     （只要你能在面试中极其流利地把这段话说出来，面试官的眼神绝对会充满赞赏。）

2. **面试进阶追踪：“这个『三路划分』的思想，在著名的排序算法里也用到过，你知道是哪个吗？”**

   - **满分架构级抢答**：这是快速排序（Quick Sort）的极致优化版——三路快排（3-Way Quicksort）的核心思想！
   - 当数组里有大量重复元素时，普通的快排每次只能把一个基准元素（Pivot）放到正确位置，递归效率会退化到 $O(N^2)$。
   - 而引入了 Dijkstra 的三路划分思想后，我们以 Pivot 为准，一次性把数组切分成“小于 Pivot”、“等于 Pivot”、“大于 Pivot”三段。所有等于 Pivot 的元素直接一次性就位，大大减少了递归深度，在处理大量重复数据时，可以说是优化思路级的提速！

## Python 完整推导

### 三个区域与一个未检查区间

三路划分在一次扫描中维护三个范围：`[0, left)` 已经全是 0；`[left, index)` 已经全是 1；`(right, n)` 已经全是 2。中间 `[index, right]` 是尚未检查的部分。

遇到 0 时，它与 left 处交换，左侧 0 区扩大；遇到 2 时，它与 right 处交换，右侧 2 区扩大；遇到 1 时它已在正确中间区，index 直接前进。

### 用 `[2, 0, 2, 1, 1, 0]` 走一遍

初始 `left = index = 0`、`right = 5`。

1. index 0 是 2，与 right 5 交换：数组变为 `[0,0,2,1,1,2]`，right 变为 4。index 不前进，因为换来的 0 还没检查。
2. index 0 是 0，与 left 0 交换（位置不变），left 和 index 都变为 1。
3. index 1 是 0，再与 left 1 交换，left 和 index 都变为 2。
4. index 2 是 2，与 right 4 交换：数组变为 `[0,0,1,1,2,2]`，right 变为 3；index 仍停在 2。
5. index 2 现在是 1，直接前进到 3；index 3 也是 1，再前进到 4。此时 `index > right`，未知区为空，排序完成。

最终 `[0,0,1,1,2,2]`。遇到 2 后不能无条件 `index += 1`，因为从右端换来的值可能是 0，必须留在当前位置重新分类。

### Python 实现

> 参考来源：经典解法实现
>
> 沿用旧项目“经典解法实现”的三指针原地划分代码；变量、注释和同步交换写法按本页整理。

```python
from typing import List


class Solution:
    def sortColors(self, nums: List[int]) -> None:
        left = 0
        index = 0
        right = len(nums) - 1
        while index <= right:
            if nums[index] == 0:
                nums[left], nums[index] = nums[index], nums[left]
                left += 1
                index += 1
            elif nums[index] == 2:
                nums[index], nums[right] = nums[right], nums[index]
                right -= 1
            else:
                index += 1
```

### 交换与边界更新

`left` 是已经确认的 0 区 `[0, left)` 外第一个位置。处理当前 0 时，把它与 `left` 交换：若 `left == index`，交换的是同一个位置；若 `left < index`，下标 `left` 处必然已属于确认的 1 区，换到 `index` 的这个 1 也正是已知值。因此交换后可以让 `index` 前进。

处理 2 时，`right` 原来的值进入未知区，新换到 `index` 的值尚未检查，所以只缩小 `right`，下一次继续处理当前位置。循环条件 `index <= right` 包含单个剩余元素。

### 为什么不排序两次

本题只有三个离散值，单次三路划分即可完成分区。时间 O(n)，只存三个下标；没有使用额外计数数组或排序库。

### 复杂度

- 时间复杂度：`O(n)`。
- 空间复杂度：`O(1)`。

index 只向右移动，right 只向左移动，每个位置最多被检查常数次，时间 O(n)；只维护三个边界下标，空间 O(1)。

## C++ 实现

> 实现来源：经典解法实现

<ol class="lang-steps"><li>三指针：low 管 0 的右边界，mid 扫描，high 管 2 的左边界</li><li>mid=0 → 与 low 交换，双指针各进一格</li><li>mid=2 → 与 high 交换，仅 high--（换来的数未看）；mid=1 → mid++</li></ol>

```cpp
class Solution {
public:
    void sortColors(vector<int>& nums) {
        int low = 0, mid = 0, high = nums.size() - 1;
        while (mid <= high) {
            if (nums[mid] == 0) swap(nums[low++], nums[mid++]);
            else if (nums[mid] == 2) swap(nums[mid], nums[high--]);
            else mid++;
        }
    }
};
```

## C 实现

> 实现来源：经典解法实现

<ol class="lang-steps"><li>三指针：low 管 0 的右边界，mid 扫描，high 管 2 的左边界</li><li>mid=0 → 与 low 交换，双指针各进一格</li><li>mid=2 → 与 high 交换，仅 high--（换来的数未看）；mid=1 → mid++</li></ol>

```c
void sortColors(int* nums, int numsSize) {
    int low = 0, mid = 0, high = numsSize - 1;
    while (mid <= high) {
        if (nums[mid] == 0) { int t = nums[low]; nums[low] = nums[mid]; nums[mid] = t; low++; mid++; }
        else if (nums[mid] == 2) { int t = nums[mid]; nums[mid] = nums[high]; nums[high] = t; high--; }
        else mid++;
    }
}
```
