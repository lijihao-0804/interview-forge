## 题目与约束

给定两个字符串 `s` 和 `p`，找到 `s`中所有 `p`的 **异位词**的子串，返回这些子串的起始索引。不考虑答案输出的顺序。

  **示例 1:**

  **输入:**s = "cbaebabacd", p = "abc"<br>**输出:**[0,6]<br>**解释:**<br>起始索引等于 0 的子串是 "cba", 它是 "abc" 的异位词。<br>起始索引等于 6 的子串是 "bac", 它是 "abc" 的异位词。

  **示例 2:**

  **输入:**s = "abab", p = "ab"<br>**输出:**[0,1,2]<br>**解释:**<br>起始索引等于 0 的子串是 "ab", 它是 "ab" 的异位词。<br>起始索引等于 1 的子串是 "ba", 它是 "ab" 的异位词。<br>起始索引等于 2 的子串是 "ab", 它是 "ab" 的异位词。

  **提示:**

  - `1 <= s.length, p.length <= 3 * 104`
  - `s` 和 `p` 仅包含小写字母

## 完整推导

### 思路推导
  1. **直觉与痛点**：

     如果对 `s` 的每个子串都进行排序再和排序后的 `p` 比较，复杂度会爆炸。

  2. **破局思路（固定窗口 + 频次数组）**：

     - **频次数组**：由于题目说明仅包含小写字母，我们可以用长度为 26 的 `int[]` 数组来代替 HashMap，统计每个字母出现的次数。
     - **固定窗口**：窗口的宽度永远等于 `p.length()`。
     - **滑动逻辑**：窗口每向右移动一位，就“吃进”一个新字符，“吐出”一个旧字符。我们只需要实时维护窗口内的频次数组，并与 `p` 的频次数组进行比对。

  3. **逻辑推演（以 `s = "cbaebabacd", p = "abc"` 为例）**：

     - `p` 的频次数组：`{a:1, b:1, c:1}`。
     - 初始化窗口：前 3 个字符 `cba`。窗口数组：`{a:1, b:1, c:1}`。比对成功，记录索引 `0`。
     - 移动窗口：
       - 吃进 `e`，吐出 `c`。窗口变为 `bae`。比对失败。
       - 吃进 `b`，吐出 `b`。窗口变为 `aeb`（注意吐出的是最左边的字符）。比对失败。
       - ……以此类推。
### Java 实现
```java
import java.util.*;

class Solution {
    public List<Integer> findAnagrams(String s, String p) {
        List<Integer> result = new ArrayList<>();
        int sLen = s.length();
        int pLen = p.length();

        // 如果 s 比 p 还短，绝对不可能存在异位词
        if (sLen < pLen) return result;

        // 1. 定义两个频次数组：一个存标准答案 p，一个存滑动窗口内容
        int[] pCount = new int[26];
        int[] windowCount = new int[26];

        // 2. 初始化：统计 p 的频次，以及 s 中第一个窗口的频次
        for (int i = 0; i < pLen; i++) {
            pCount[p.charAt(i) - 'a']++;
            windowCount[s.charAt(i) - 'a']++;
        }

        // 3. 检查第一个窗口是否匹配
        if (Arrays.equals(pCount, windowCount)) {
            result.add(0);
        }

        // 4. 开始滑动窗口：从索引 pLen 开始遍历 s
        for (int i = pLen; i < sLen; i++) {
            // “吃进”右边的一个字符
            windowCount[s.charAt(i) - 'a']++;
            // “吐出”左边的一个字符（索引为 i - pLen）
            windowCount[s.charAt(i - pLen) - 'a']--;

            // 5. 比对两个数组：Arrays.equals 是 O(26)，即 O(1)
            if (Arrays.equals(pCount, windowCount)) {
                // 异位词的起始索引是吐出位置的下一个，即 i - pLen + 1
                result.add(i - pLen + 1);
            }
        }

        return result;
    }
}
```
### 复杂度
  - **时间复杂度**：$O(N)$。其中 $N$ 是 `s` 的长度。我们只遍历了一遍 `s`。虽然中间有 `Arrays.equals`，但数组长度固定为 26，比较时间是常数级的。
  - **空间复杂度**：$O(1)$。我们使用了两个长度为 26 的整数数组，空间开销不随输入规模增长。

### 易错点与扩展

- **避坑：千万别忘了处理 `sLen < pLen` 的情况**。如果 `s` 比 `p` 短，直接返回空列表。如果不处理，初始化窗口的循环可能会报越界错误（IndexOutOfBounds）。
- **优化追问：“如果字符集很大（比如 Unicode），不能开数组怎么办？”**
  - **回答**：那就必须用 `HashMap<Character, Integer>` 了。在滑动窗口时，如果某个字符的频率减为 0，记得手动从 Map 中 `remove` 掉那个 Key，否则两个 Map 永远不会相等（因为一个有 `count=0` 的 Key，另一个没有）。

## Python 完整推导

### 固定长度的窗口只改两个频次

p 的异位词必须与 p 等长。用 need 保存 p 的 26 格频次，用 window 保存当前连续子串的频次。

窗口右端每次加入新字符；长度超过 m 后，再删除 right - m 位置的旧字符。窗口完整时比较两个数组，相等就记录左端 right - m + 1。

### 用 s=cbaebabacd、p=abc 走一遍

- right=0..2 依次加入 c、b、a，窗口为 cba，频次与 abc 相同，记录起点 0。
- right=3 加入 e、删除位置 0 的 c，窗口为 bae，不匹配。
- 继续滑动，字符本身顺序可以不同，频次数组决定是否匹配。
- right=8 加入 c、删除位置 5 的 a，窗口为 bac，再次匹配，记录起点 6。

所以答案是 [0, 6]。

### Python 实现

> 参考来源：代码随想录（programmercarl.com）
>
> 保留旧 Python 的固定窗口 26 格频次实现，整理变量与签名；算法未改变。

```python
from typing import List


class Solution:
    def findAnagrams(self, s: str, p: str) -> List[int]:
        n, m = len(s), len(p)
        if m > n:
            return []
        need = [0] * 26
        window = [0] * 26
        for ch in p:
            need[ord(ch) - ord("a")] += 1
        answer = []
        for right in range(n):
            window[ord(s[right]) - ord("a")] += 1
            if right >= m:
                window[ord(s[right - m]) - ord("a")] -= 1
            if right >= m - 1 and window == need:
                answer.append(right - m + 1)
        return answer
```

### 三个下标不要混用

- 新字符写入位置是 right。
- 超长后删除位置是 right - m。
- 当前窗口左端和答案下标是 right - m + 1。

### 长度边界

m > n 不可能出现等长异位词，直接返回空列表。right >= m - 1 才表示已经形成完整窗口；在此之前频次数组尚未包含 m 个字符。

### 固定字母表

ord("a") 对应下标 0，ord("z") 对应 25。题目限定小写字母，所以两个数组长度固定为 26。

### 复杂度

- 时间复杂度：`O(n + m)`。
- 空间复杂度：`O(1)（固定 26 格频次数组）`。

统计 p 与扫描 s 共 O(m+n)；每次数组比较固定 26 格，可视为常数，空间固定 O(1)。

## C++ 实现

> 实现来源：代码随想录（programmercarl.com）



```cpp
class Solution {
public:
    vector<int> findAnagrams(string s, string p) {
        int n = s.size();
        int m = p.size();
        vector<int> result;

        if (m > n) return result;

        vector<int> need(26, 0);
        vector<int> window(26, 0);
        for (char c : p) need[c - 'a']++;

        for (int right = 0; right < n; right++) {
            window[s[right] - 'a']++;

            // 窗口超过p的长度时，移出最左侧字符
            if (right >= m) {
                window[s[right - m] - 'a']--;
            }

            // 只有窗口长度达到m时，才有可能成为字母异位词
            if (right >= m - 1 && window == need) {
                result.push_back(right - m + 1);
            }
        }

        return result;
    }
};
```

## Go 实现

> 实现来源：代码随想录（programmercarl.com）



```go
func findAnagrams(s string, p string) []int {
    n, m := len(s), len(p)
    result := make([]int, 0)

    if m > n {
        return result
    }

    var need [26]int
    var window [26]int
    for i := 0; i < m; i++ {
        need[p[i]-'a']++
    }

    for right := 0; right < n; right++ {
        window[s[right]-'a']++

        if right >= m {
            window[s[right-m]-'a']--
        }

        // Go中的定长数组可以直接比较
        if right >= m-1 && window == need {
            result = append(result, right-m+1)
        }
    }

    return result
}
```
