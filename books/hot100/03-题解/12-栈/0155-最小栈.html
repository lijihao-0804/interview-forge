题目信息 内容
难度 中等
核心模式 数据栈 + 最小值栈
时间复杂度 O(1)
空间复杂度 O(n)

题目与约束

设计一个支持 push ，pop ，top 操作，并能在常数时间内检索到最小元素的栈。

  • MinStack() 初始化 MinStack 对象。
  • void push(int val) 将元素 val 推入堆栈。
  • void pop() 删除堆栈顶部的元素。
  • int top() 获取堆栈顶部的元素。
  • int getMin() 获取堆栈中的最小元素。

🔗 前往力扣原题验证 →

核心不变量

辅助栈顶始终是当前所有元素的最小值。

完整推导

思路推导

  1. 直觉与痛点（为什么一个变量不行？）：

    很多同学第一反应是：这简单啊，我在类里挂一个 int minValue 变量。每次 push 进来新数字，如果它比 minValue 小，我就更新 minValue。

    痛点：如果这个当前最小的数字被 pop 弹出了呢？比如栈里现在是 [3, 5, 1]，最小是 1。现在把 1 弹出了，请问剩下的数字里谁最小？变量已经失忆了，它不记得在 1 进来之前，历史最小是 3。

  2. 破局思路（留住历史的罪证：辅助栈）：

    既然一个变量记不住历史，那我们就用另一个栈来记录历史的每一次“最小状态”。

    • 数据栈（Data Stack）：老老实实装用户传进来的所有数字。
    • 最小栈（Min Stack）：装对应这一刻，全栈的最小数字是谁。

  3. 核心微操（双栈同步战术）：

    为了让逻辑最严谨、最不容易出错，我们采用“双栈完全同步”的标配打法：

    • push(val)：数据栈直接入栈 val。最小栈要看一眼：如果当前准备入栈的 val 比我自己的栈顶还要小，那没的说，val 入最小栈；如果 val 比我的栈顶还大，说明它动摇不了当前最小值的地位，那我就把我自己现有的栈顶复制一份，再次压入栈！
    • pop()：两个栈同时弹出栈顶。因为它们是绝对同步的，所以数据栈弹出的同时，最小栈也弹出了那一刻的历史最小值，两边的状态永远对称。
    • getMin()：直接看一眼最小栈的栈顶，那必然是当前的天下第一小。

    Java 实现（双栈同步满分版）

import java.util.ArrayDeque;
import java.util.Deque;

class MinStack {
    // 数据栈：存放实际数据
    private Deque<Integer> dataStack;
    // 辅助栈：存放每次入栈时，栈内的最小值状态
    private Deque<Integer> minStack;

    public MinStack() {
        dataStack = new ArrayDeque<>();
        minStack = new ArrayDeque<>();
    }

    public void push(int val) {
        dataStack.push(val);

        // 如果辅助栈为空，说明是第一个元素，直接作为最小值入栈
        // 否则，拿当前值 val 和辅助栈栈顶（当前最小值）比较，谁小就压入谁
        if (minStack.isEmpty()) {
            minStack.push(val);
        } else {
            int currentMin = minStack.peek();
            if (val < currentMin) {
                minStack.push(val);
            } else {
                // 🌟 核心工程细节：把老栈顶复制一份压进去，保持两个栈高度绝对一致
                minStack.push(currentMin);
            }
        }
    }

    public void pop() {
        // 两个栈必须同生共死，同时弹出
        if (!dataStack.isEmpty()) {
            dataStack.pop();
            minStack.pop();
        }
    }

    public int top() {
        // 获取数据栈的栈顶
        return dataStack.peek();
    }

    public int getMin() {
        // 🌟 O(1) 极速获取：直接看辅助栈的栈顶即可！
        return minStack.peek();
    }
}

/**
 * Your MinStack object will be instantiated and called as such:
 * MinStack obj = new MinStack();
 * obj.push(val);
 * obj.pop();
 * int param_3 = obj.top();
 * int param_4 = obj.getMin();
 */

复杂度

  • 时间复杂度：push、pop、top、getMin 全部为 O(1)。没有任何循环，纯粹是指针和栈顶的常规操作。
  • 空间复杂度：O(N)。因为引入了一个和数据栈一样高、同步增长的辅助栈。

易错点与扩展（面试高频加分项）

  1. 面试追问 1：“我看你的最小栈在 val > currentMin 时，复制了老栈顶压进去。如果我不想浪费空间复制老栈顶，代码怎么改？” - 满分抢答（异步不复制流派）：可以改用“异步模式”。 - push 时：只有当 val <= minStack.peek() 时，才把 val 压入最小栈。（注意一定要是 <=, 不能是 <，因为可能有相同的最小值）。 - pop 时：只有当 dataStack.peek() == minStack.peek() 时，最小栈才跟着弹出。 - 面试点评：这种写法节省了一部分空间。但在面试时，需要非常小心空指针判断以及 Integer 对象的 == 比较坑点（Java 缓存机制中，超出 -128 到 127 必须用 .equals()）。所以同步双栈依然是最推荐的、抗压稳健的写法。
  2. 终极装杯追问：“如果面试官要求【空间复杂度必须是 O(1)】（不允许开辟任何辅助栈或额外数组），你还能玩得转吗？” - 神仙写法（差值存储法）：这是一个极其炫酷的 trick！ - 我们的纯数据栈里，不存原始数据，改存“差值（CurrentValue - CurrentMin）”。 - 同时在外部只用一个 long minValue 变量。 - 当入栈一个更小的数时，栈里存入一个负数，并更新 minValue。通过这个负数和当前的 minValue，在 pop 的时候我们可以通过逆向数学公式，反推出前一个历史最小值是多少！ - 这种解法不需要任何额外空间，如果你能在面试中把差值推导公式手写出来，面试官会直接起立为你鼓掌。
