## 题目与约束

给定一个只包括 `'('`，`')'`，`'{'`，`'}'`，`'['`，`']'` 的字符串 `s` ，判断字符串是否有效。

  有效字符串需满足：

  1. 左括号必须用相同类型的右括号闭合。
  2. 左括号必须以正确的顺序闭合。
  3. 每个右括号都有一个对应的相同类型的左括号。

  **示例 1：**

  **输入：**s = "()"
  **输出：**true

  **示例 2：**

  **输入：**s = "()[]{}"
  **输出：**true

  **示例 3：**

  **输入：**s = "(]"
  **输出：**false

  **示例 4：**

  **输入：**s = "([])"
  **输出：**true

  **示例 5：**

  **输入：**s = "([)]"
  **输出：**false

  **提示：**

  - `1 <= s.length <= 104`
  - `s` 仅由括号 `'()[]{}'` 组成

## 完整推导

### 思路推导
  1. **直觉与痛点（为什么不能用计数器？）**：

     有的同学第一反应是：我数一下左括号和右括号的数量不就行了？保证数量相等。

     **痛点**：数量相等不代表顺序对！比如 `([)]`，数量完全相等，但它是错的，因为最内层的 `[` 还没闭合，就被外层的 `)` 给强行截胡了。

     所以，这个问题的核心在于**顺序和最近匹配原则**：**“最后出现的左括号，必须最先闭合”**。

  2. **破局思路（引入“栈”结构）**：

     “最后出现的必须最先处理”——这简直就是把身份证拍在桌子上，大喊一声：“我是**后进先出（LIFO - Last In First Out）**，我需要一个**栈（Stack）**！”

     我们可以把左括号看作是“未满足的期待”，把右括号看作是“回应期待”。

     - 我们从左到右扫描字符串。
     - 遇到任何**左括号**，说明来了一个新的期待，不管三七二十一，直接**压入栈底（Push）**。
     - 遇到任何**右括号**，说明要回应期待了。此时我们看向**栈顶（Top）**，也就是我们刚刚接到的“最近的一个期待”。如果这个右括号刚好能和栈顶的左括号配对，太棒了，把栈顶元素**弹出（Pop）**（这就是消消乐）。
     - 如果不配对，或者栈已经空了（说明右括号多出来了），直接判死刑，返回 `false`。

  3. **核心微操（绝妙的入栈反转法）**：

     常规写法是：遇到 `(` 入栈 `(`，遇到 `)` 则检查栈顶是不是 `(`。

     **进阶的极简写法**：遇到 `(`，我们直接在栈里压入它**对应的右括号 `)`**！

     这样一来，当我们遇到右括号时，只需要极其简单的一步：`if (当前字符 != 栈顶弹出的字符) return false;`。这简直是极简美学的巅峰。
### Java 实现（极简反转消消乐版）
```Java
import java.util.ArrayDeque;
import java.util.Deque;

class Solution {
    public boolean isValid(String s) {
        // 奇数长度的字符串，绝对不可能完美闭合，直接提前剪枝
        if (s.length() % 2 != 0) {
            return false;
        }

        // 🌟 致命细节：在 Java 中，推荐使用 Deque (ArrayDeque) 来代替过时的 Stack 类
        Deque<Character> stack = new ArrayDeque<>();

        for (int i = 0; i < s.length(); i++) {
            char c = s.charAt(i);

            // 遇到左括号，把它的“另一半”压入栈中，等待未来的重逢
            if (c == '(') {
                stack.push(')');
            } else if (c == '[') {
                stack.push(']');
            } else if (c == '{') {
                stack.push('}');
            }
            // 遇到右括号了！
            else {
                // 如果栈已经空了（说明右括号多了，没人等它）
                // 或者栈顶弹出的字符和当前的右括号不相等（类型不匹配）
                if (stack.isEmpty() || stack.pop() != c) {
                    return false;
                }
            }
        }

        // 字符串全扫完了，如果栈也刚好空了，说明所有的括号都完美消除了！
        // 如果栈没空（说明左括号多了），返回 false
        return stack.isEmpty();
    }
}
```
### 复杂度
  - **时间复杂度**：$O(N)$。只需从头到尾遍历一次字符串，每一次的入栈（`push`）和出栈（`pop`）操作时间都是常数级的 $O(1)$。
  - **空间复杂度**：$O(N)$。在最坏的情况下（比如字符串全是左括号 `"((((((("`），所有的字符都会被压入栈中，栈的深度等于字符串的长度。

### 易错点与扩展（面试的底层拷问）

1. **面试追问 1：“我看你代码里用了 `Deque<Character> stack = new ArrayDeque<>();`，为什么不用 `Stack<Character> stack = new Stack<>();` 呢？”**

   - **满分抢答（直击 Java 源码）**：在 Java 早期的设计中，`Stack` 是继承自 `Vector` 的。`Vector` 里的每一个方法（包括 `push` 和 `pop`）都加了 `synchronized` 同步锁！这使得 `Stack` 在单线程环境下性能极其拉垮（因为要频繁获取和释放没用的锁）。
   - 后来 Java 官方都看不下去了，在官方文档里强烈建议使用 `Deque` 接口（通常实例化为 `ArrayDeque`）来代替 `Stack`。`ArrayDeque` 基于循环数组实现，没有线程同步的额外开销，速度飞快，是现代 Java 工程师的标配。

2. **面试追问 2：“这道题你能总结出一共有哪几种失败的情况吗？”**

   - **满分总结（三种死法）**：

     1. **左边多余**：遍历完了，栈里面还有剩余的括号没被消除掉。例如 `({}`。

     2. **右边多余**：遍历到右括号时，栈竟然已经空了。例如 `([{}])))`。

     3. **中途不匹配**：遍历到右括号时，栈顶拿出来的右括号跟当前的手里的右括号长得不一样。例如 `([)]`。

        只要你能清晰地把这三种情况说出来，面试官就知道你对栈的生命周期了如指掌。

## Python 完整推导

### 为什么只数左右括号还不够

数量相等只说明括号总数对得上，却不能保证闭合顺序正确。`([)]` 里左右括号各有两个，但最里面的 `[` 还没等到 `]`，就先遇到了 `)`，所以字符串无效。真正有效的匹配必须服从“最后打开的左括号先闭合”，这正好对应栈的后进先出。

这里换一个角度保存状态：读到左括号时，不保存左括号本身，而是保存它正在等待的右括号。之后每遇到一个右括号，只检查它是否等于当前最上层的期待值。

### 用 `s = "{[]}"` 走一遍

最初 `stack = []`。

1. 下标 0 是 `{`。查表可知它等待 `}`，于是压入 `}`，`stack = ["}"]`。
2. 下标 1 是 `[`。新的期待是 `]`，压到栈顶，`stack = ["}", "]"]`。
3. 下标 2 是 `]`。栈顶正是 `]`，这个期待得到满足，弹栈后变为 `["}"]`。
4. 下标 3 是 `}`。栈顶仍是 `}`，再次匹配并弹栈，最后 `stack = []`。

整个字符串读完且栈为空，说明每个左括号都等到了正确的右括号，返回 `True`。如果输入是 `"([)]"`，读到中间的 `)` 时栈顶仍是 `]`，两者不等，程序立即返回 `False`，后面的字符没有必要再看。

### 三种失败分别在哪里被发现

- 右括号多出来：例如先读 `"]"`，栈为空，说明没有左括号在等它。
- 左右类型错位：例如 `"([)]"` 在栈顶比较时失败。
- 左括号多余：例如 `"("` 虽然过程中没有报错，但扫描结束栈里还留着 `[")"]`，最终要返回 `False`。

### Python 实现

> 参考来源：代码随想录（programmercarl.com）
>
> 沿用旧项目收录的《代码随想录》Python“期待右括号”思路；变量名、字典查表与空栈判断按本页整理，算法未更换。

```python
class Solution:
    def isValid(self, s: str) -> bool:
        pairs = {"(": ")", "[": "]", "{": "}"}
        stack = []
        for ch in s:
            expected = pairs.get(ch)
            if expected is not None:
                stack.append(expected)
            elif not stack or stack.pop() != ch:
                return False
        return not stack
```

### 这段 Python 代码的对应动作

- `pairs.get(ch)` 在遇到左括号时返回对应的右括号；遇到右括号时返回 `None`。题目只包含六种括号字符，因此用 `is not None` 判断“当前是左括号”足够直接。
- `stack.append(expected)` 把尚未满足的期待压到列表尾部；`stack[-1]` 是最新期待。
- `stack.pop() != ch` 会先取出栈顶再比较。这里能安全调用，是因为前面的 `not stack` 已经由 `or` 短路处理了空栈。

### 容易漏掉的边界

比较必须发生在弹栈动作中，不能只比较 `stack[-1]` 后忘记删除；否则一个左括号会被重复匹配。扫描结束也不能只返回循环里的结果，还必须检查 `not stack`，因为可能仍有左括号没有闭合。

### 复杂度

- 时间复杂度：`O(n)`。
- 空间复杂度：`O(n)`。

每个字符只处理一次；每个左括号最多入栈一次，每个右括号最多弹栈一次，因此时间 O(n)，最坏栈深 O(n)。

## C++ 实现

> 实现来源：代码随想录（programmercarl.com）



```cpp
class Solution {
public:
    bool isValid(string s) {
        if (s.size() % 2 != 0) return false; // 如果s的长度为奇数，一定不符合要求
        stack<char> st;
        for (int i = 0; i < s.size(); i++) {
            if (s[i] == '(') st.push(')');
            else if (s[i] == '{') st.push('}');
            else if (s[i] == '[') st.push(']');
            // 第三种情况：遍历字符串匹配的过程中，栈已经为空了，没有匹配的字符了，说明右括号没有找到对应的左括号 return false
            // 第二种情况：遍历字符串匹配的过程中，发现栈里没有我们要匹配的字符。所以return false
            else if (st.empty() || st.top() != s[i]) return false;
            else st.pop(); // st.top() 与 s[i]相等，栈弹出元素
        }
        // 第一种情况：此时我们已经遍历完了字符串，但是栈不为空，说明有相应的左括号没有右括号来匹配，所以return false，否则就return true
        return st.empty();
    }
};
```

## Go 实现

> 实现来源：代码随想录（programmercarl.com）



```go
// 思路： 使用栈来进行括号的匹配
// 时间复杂度 O(n)
// 空间复杂度 O(n)
func isValid(s string) bool {
	// 使用切片模拟栈的行为
	stack := make([]rune, 0)

	// m 用于记录某个右括号对应的左括号
	m := make(map[rune]rune)
	m[')'] = '('
	m[']'] = '['
	m['}'] = '{'

	// 遍历字符串中的 rune
	for _, c := range s {
		// 左括号直接入栈
		if c == '(' || c == '[' || c == '{' {
			stack = append(stack, c)
		} else {
			// 如果是右括号，先判断栈内是否还有元素
			if len(stack) == 0 {
				return false
			}
			// 再判断栈顶元素是否能够匹配
			peek := stack[len(stack)-1]
			if peek != m[c] {
				return false
			}
			// 模拟栈顶弹出
			stack = stack[:len(stack)-1]
		}
	}

	// 若栈中不再包含元素，则能完全匹配
	return len(stack) == 0
}
```

```c
//辅助函数：判断栈顶元素与输入的括号是否为一对。若不是，则返回False
int notMatch(char par, char* stack, int stackTop) {
    switch(par) {
        case ']':
            return stack[stackTop - 1] != '[';
        case ')':
            return stack[stackTop - 1] != '(';
        case '}':
            return stack[stackTop - 1] != '{';
    }
    return 0;
}
```
