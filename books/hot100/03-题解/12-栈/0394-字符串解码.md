## 题目与约束

给定一个经过编码的字符串，返回它解码后的字符串。

  编码规则为: `k[encoded_string]`，表示其中方括号内部的 `encoded_string` 正好重复 `k` 次。注意 `k` 保证为正整数。

  你可以认为输入字符串总是有效的；输入字符串中没有额外的空格，且输入的方括号总是符合格式要求的。

  此外，你可以认为原始数据不包含数字，所有的数字只表示重复的次数 `k` ，例如不会出现像 `3a` 或 `2[4]` 的输入。

  测试用例保证输出的长度不会超过 `105`。

  **示例 1：**

  **输入：**s = "3[a]2[bc]"<br>**输出：**"aaabcbc"

  **示例 2：**

  **输入：**s = "3[a2[c]]"<br>**输出：**"accaccacc"

  **示例 3：**

  **输入：**s = "2[abc]3[cd]ef"<br>**输出：**"abcabccdcdcdef"

  **示例 4：**

  **输入：**s = "abc3[cd]xyz"<br>**输出：**"abccdcdcdxyz"

  **提示：**

  - `1 <= s.length <= 30`
  - `s` 由小写英文字母、数字和方括号 `'[]'` 组成
  - `s` 保证是一个 **有效** 的输入。
  - `s` 中所有整数的取值范围为 `[1, 300]`

## 完整推导

### 思路推导
  1. **直觉与痛点（为什么必须用栈？）**：

     字符串里有嵌套，比如 `3[a2[c]]`，我们必须先解码最内层的 `2[c]` 变成 `cc`，然后再和外面的 `a` 拼起来变成 `acc`，最后再把整个 `acc` 翻 3 倍。

     **痛点**：当我们读到 `3` 和 `a` 时，我们还不能处理它们，必须把它们“挂起（记住）”**，去处理内层。等内层处理完了，再把它们**“唤醒”**。这种“挂起当前状态，去处理子任务，然后再恢复状态”的机制，完美契合**栈（Stack）。

  2. **破局思路（双栈战术：数字栈 + 字符串栈）**：

     我们需要准备两个栈，以及两个全局变量：

     - `countStack`：专门存倍数（我要重复几次）。
     - `stringStack`：专门存**遇到 `[` 之前的那个半成品字符串**（我要把重复后的结果拼在谁的后面）。
     - `k`：记录当前正在计算的倍数。
     - `currStr`：记录当前括号里正在拼装的字符串。

  3. **核心微操（四个分支的精准打击）**：

     遍历字符串，遇到四种不同的字符，执行不同的战术：

     - **遇到数字**：因为数字可能是多位数（比如 `12[a]`），所以要用 `k = k * 10 + (c - '0')` 把数字完整拼出来。
     - **遇到 `[`（时空冻结）**：要把当前的倍数 `k` 压入 `countStack`，把当前的 `currStr` 压入 `stringStack`。然后**清空 `k` 和 `currStr`**，准备进入全新的内层世界。
     - **遇到字母**：直接追加到当前世界的 `currStr` 后面。
     - **遇到 `]`（时空缝合）**：当前内层世界拼装完毕了！从 `countStack` 弹出一个倍数，把 `currStr` 翻那么多倍。然后从 `stringStack` 弹出一个“前世”的字符串，把翻倍后的结果拼在它后面，重新赋给 `currStr`。
### Java 实现（满分双栈 StringBuilder 版）
```Java
import java.util.ArrayDeque;
import java.util.Deque;

class Solution {
    public String decodeString(String s) {
        // 存储倍数的栈
        Deque<Integer> countStack = new ArrayDeque<>();
        // 存储之前已经拼好的字符串前缀的栈
        Deque<StringBuilder> stringStack = new ArrayDeque<>();

        // 记录当前正在构建的字符串
        StringBuilder currStr = new StringBuilder();
        // 记录当前正在计算的倍数
        int k = 0;

        for (char c : s.toCharArray()) {
            if (Character.isDigit(c)) {
                // 🌟 致命细节：处理多位数字，比如 "100[a]"
                k = k * 10 + (c - '0');
            } else if (c == '[') {
                // 遇到左括号，立刻把当前的状态（k 和 currStr）存档（入栈）
                countStack.push(k);
                stringStack.push(currStr);

                // 存档完毕后，重置状态，准备迎接新括号里的内容
                k = 0;
                currStr = new StringBuilder();
            } else if (c == ']') {
                // 遇到右括号，说明当前层的 currStr 已经收集完毕，开始解码！
                // 1. 取出这一层需要翻倍的次数
                int repeatTimes = countStack.pop();

                // 2. 取出遇到 '[' 之前，上一个维度的老字符串
                StringBuilder prevStr = stringStack.pop();

                // 3. 把当前层的字符串翻倍，拼在老字符串的后面
                for (int i = 0; i < repeatTimes; i++) {
                    prevStr.append(currStr);
                }

                // 4. 更新 currStr，时空缝合完毕！
                currStr = prevStr;
            } else {
                // 普通字母，直接收集到当前层的字符串容器里
                currStr.append(c);
            }
        }

        return currStr.toString();
    }
}
```
### 复杂度
  - **时间复杂度**：$O(N)$。这里 $N$ 指的是**解码后结果字符串的长度**。虽然看起来只有一个 `for` 循环，但遇到 `]` 时的翻倍拼接操作会消耗时间，整体时间严格与最终输出的字符数量成正比。
  - **空间复杂度**：$O(S)$。$S$ 是字符串中左括号 `[` 的嵌套层数。栈的深度等于括号的最大嵌套深度。

### 易错点与扩展（面试的底层拷问）

1. **踩坑警告：多位数字的陷阱**
   - 很多同学在写提取数字的代码时，习惯性地写成 `k = c - '0'`。
   - 如果测试用例是 `12[a]`，你的代码走到 `2` 的时候，就会把 `k` 覆盖成 2，丢掉了前面的 10！
   - **必记范式**：在任何需要连续读取数字字符的题里，提取完整数字的黄金公式永远是 `k = k * 10 + (c - '0')`。
2. **面试追问：“除了用栈，这题能用【递归】写吗？哪种更好？”**
   - **满分抢答**：绝对能用递归！因为括号的嵌套本质就是一棵树的深度优先遍历（DFS）。我们可以写一个递归函数，只要遇到 `[` 就向下递归，遇到 `]` 就 `return` 当前层拼接好的字符串。
   - **两种对比**：
     - **栈写法（迭代）**：工程上更稳健，不会因为嵌套过深导致 `StackOverflowError`（系统栈溢出），所有的栈操作都在堆内存的 `Deque` 中完成，空间上限更大。
     - **递归写法**：代码更短、更符合人类数学直觉，但在工业界处理超长恶意嵌套字符串时存在爆栈风险。面试时能把栈的代码用 `StringBuilder` 写得滴水不漏，是最优选择。

## Python 完整推导

### 嵌套编码要保存的是“现场”

`3[a2[c]]` 不能一看到 `3` 就把后面的字符整体乘三，因为后面还包着另一层 `2[c]`。读到一个 `[` 时，当前倍数和已经拼好的父层前缀都必须暂时挂起，等对应的 `]` 才能恢复。两个栈分别保存这两类现场信息。

### 让 `3[a2[c]]` 一层层展开

读到 `3` 时，`repeat = 3`。读到第一个 `[`，把倍数 `3` 放进 `repeat_counts`，把此前空前缀 `""` 放进 `parents`；随后 `current` 清空，准备读取括号内部。

接着读到 `a`，`current = "a"`。读到 `2` 后，第二个 `[` 把倍数 `2` 和父层前缀 `"a"` 分别入栈；新的 `current` 又从空串开始。

读到 `c` 后，`current = "c"`。遇到第一个 `]`，取出 `count = 2` 和 `parent = "a"`，执行 `"a" + "c" * 2`，当前层变成 `"acc"`。遇到最后一个 `]`，取出 `count = 3` 和更外层的空父串，得到 `"" + "acc" * 3`。扫描结束时，`current` 就是 `"accaccacc"`。

### 多位数字为什么不能丢掉前面几位

对 `12[a]`，读到 `1` 时 `repeat = 1`；再读到 `2`，要计算 `1 * 10 + 2 = 12`。如果每个数字都直接赋值，第二个字符就会覆盖前面的 `1`。

这份双栈实现按层立即生成字符串：写起来直接，也没有递归深度问题；代价是某些深嵌套或外层大量重复会产生重复复制，因此复杂度需要按各层实际生成长度分析。

### Python 实现

> 参考来源：经典解法实现
>
> 主算法沿用 packet 中“经典解法实现”的旧 Python 双栈现场保存代码；变量命名和排版按教学稿整理，仍按闭合层即时生成字符串，未将整理稿表述为未经整理的上游原稿。

```python
class Solution:
    def decodeString(self, s: str) -> str:
        repeat_counts = []
        parents = []
        current = ""
        repeat = 0

        for ch in s:
            if ch.isdigit():
                repeat = repeat * 10 + int(ch)
            elif ch == "[":
                repeat_counts.append(repeat)
                parents.append(current)
                current = ""
                repeat = 0
            elif ch == "]":
                count = repeat_counts.pop()
                parent = parents.pop()
                current = parent + current * count
            else:
                current += ch

        return current
```

### 两个栈与两个滚动变量

`ch.isdigit()` 识别十进制数字；`repeat = repeat * 10 + int(ch)` 累积多位倍数。遇到 `[` 时，`repeat_counts.append(repeat)` 保存这一层要重复多少次，`parents.append(current)` 保存进入该层之前的父层前缀。随后把 `current` 和 `repeat` 清零，表示开始一个新的括号层。

遇到普通字符时，只把它追加到 `current`。遇到 `]` 时，`count = repeat_counts.pop()` 和 `parent = parents.pop()` 同时恢复一层的两个现场值；`current = parent + current * count` 先复制当前层内容，再与父层前缀连接。

### 边界与成本

题目保证括号配对且重复次数为正，所以每个 `]` 都有对应的栈项。扫描字符串本身是 O(n)，但每次闭合可能复制一段长度不小的中间结果。设最终输出长度为 L，最多 O(n) 个括号层，把所有复制与拼接加总可保守估为 O(nL)；双栈中保留的父层前缀合计也按 O(nL) 作为上界。深嵌套只说明不会触发递归上限，并不自动意味着线性时间。

### 复杂度

- 时间复杂度：`保守 O(n·L) 上界`。
- 空间复杂度：`保守 O(n·L) 上界`。

扫描输入需要 O(n)。完成一次括号层时有重复复制和拼接，结果长度不超过最终解码长度 L；最多有 O(n) 次这样的合成，因此保守上界为 O(nL)。各层保存的父层前缀合计也为 O(nL)；实际成本取决于各层中间串长度。

## C++ 实现

> 实现来源：经典解法实现

<ol class="lang-steps"><li>双栈：数字栈存重复次数，字符串栈存上一层已完成的结果</li><li>遇数字入数字栈、当前串压字符串栈清空（进入新一层）</li><li>遇 ']' 弹出重复次数与上一层串，当前串重复后拼接回去</li></ol>

```cpp
class Solution {
public:
    string decodeString(string s) {
        vector<int> numStack;
        vector<string> strStack;
        string cur;
        int num = 0;
        for (char ch : s) {
            if (isdigit(ch)) num = num * 10 + (ch - '0');
            else if (ch == '[') { numStack.push_back(num); strStack.push_back(cur); cur.clear(); num = 0; }
            else if (ch == ']') {
                int times = numStack.back(); numStack.pop_back();
                string prev = strStack.back(); strStack.pop_back();
                while (times--) cur = prev + cur;
                num = 0;
            } else cur += ch;
        }
        return cur;
    }
};
```

## Go 实现

> 实现来源：经典解法实现

<ol class="lang-steps"><li>双栈：数字栈存重复次数，字符串栈存上一层已完成的结果</li><li>遇数字入数字栈、当前串压字符串栈清空（进入新一层）</li><li>遇 ']' 弹出重复次数与上一层串，当前串重复后拼接回去</li></ol>

```go
func decodeString(s string) string {
    var numStack []int
    var strStack []string
    cur := ""
    num := 0
    for _, ch := range s {
        if ch >= '0' && ch <= '9' { num = num*10 + int(ch-'0') } else if ch == '[' {
            numStack = append(numStack, num)
            strStack = append(strStack, cur)
            cur, num = "", 0
        } else if ch == ']' {
            times := numStack[len(numStack)-1]; numStack = numStack[:len(numStack)-1]
            prev := strStack[len(strStack)-1]; strStack = strStack[:len(strStack)-1]
            for i := 0; i < times; i++ { prev += cur }
            cur = prev
        } else { cur += string(ch) }
    }
    return cur
}
```

## C 实现

> 实现来源：经典解法实现

<ol class="lang-steps"><li>双栈：数字栈存重复次数，字符串栈存上一层已完成的结果</li><li>遇数字入数字栈、当前串压字符串栈清空（进入新一层）</li><li>遇 ']' 弹出重复次数与上一层串，当前串重复后拼接回去</li></ol>

```c
char* decodeString(char* s) {
    int numStack[64], numTop = 0, num = 0;
    char* strStack[64]; int strTop = 0;
    char cur[32768] = ""; int len = 0;
    for (int i = 0; s[i]; i++) {
        if (s[i] >= '0' && s[i] <= '9') num = num * 10 + (s[i] - '0');
        else if (s[i] == '[') {
            numStack[numTop++] = num;
            strStack[strTop] = strdup(cur); strTop++;
            cur[0] = 0; len = 0; num = 0;
        } else if (s[i] == ']') {
            int times = numStack[--numTop];
            char* prev = strStack[--strTop];
            int plen = strlen(prev);
            for (int t = 0; t < times; t++) memcpy(cur + len + t * len, cur, len);
            len *= times;
            memmove(cur + plen * times, cur, len);
            memcpy(cur, prev, plen * times);
            len += plen * times;
            cur[len] = 0;
        } else cur[len++] = s[i], cur[len] = 0;
    }
    return strdup(cur);
}
```
