## 题目与约束

设计一个支持 `push` ，`pop` ，`top` 操作，并能在常数时间内检索到最小元素的栈。

  实现 `MinStack` 类:

  - `MinStack()` 初始化堆栈对象。
  - `void push(int value)` 将元素 `value` 推入堆栈。
  - `void pop()` 删除堆栈顶部的元素。
  - `int top()` 获取堆栈顶部的元素。
  - `int getMin()` 获取堆栈中的最小元素。

  **示例 1:**

  **输入：**<br>["MinStack","push","push","push","getMin","pop","top","getMin"]<br>[[],[-2],[0],[-3],[],[],[],[]]<br><br>**输出：**<br>[null,null,null,null,-3,null,0,-2]<br><br>**解释：**<br>MinStack minStack = new MinStack();<br>minStack.push(-2);<br>minStack.push(0);<br>minStack.push(-3);<br>minStack.getMin();   --> 返回 -3.<br>minStack.pop();<br>minStack.top();      --> 返回 0.<br>minStack.getMin();   --> 返回 -2.

  **提示：**

  - `-231 <= val <= 231 - 1`
  - `pop`、`top` 和 `getMin` 操作总是在 **非空栈** 上调用
  - `push`, `pop`, `top`, and `getMin`最多被调用 `3 * 104` 次

## 完整推导

### 思路推导
  1. **直觉与痛点（为什么一个变量不行？）**：

     很多同学第一反应是：这简单啊，我在类里挂一个 `int minValue` 变量。每次 `push` 进来新数字，如果它比 `minValue` 小，我就更新 `minValue`。

     **痛点**：如果这个当前最小的数字被 `pop` 弹出了呢？比如栈里现在是 `[3, 5, 1]`，最小是 `1`。现在把 `1` 弹出了，请问剩下的数字里谁最小？变量已经失忆了，它不记得在 `1` 进来之前，历史最小是 `3`。

  2. **破局思路（留住历史的罪证：辅助栈）**：

     既然一个变量记不住历史，那我们就**用另一个栈来记录历史的每一次“最小状态”**。

     - **数据栈（Data Stack）**：老老实实装用户传进来的所有数字。
     - **最小栈（Min Stack）**：装**对应这一刻**，全栈的最小数字是谁。

  3. **核心微操（双栈同步战术）**：

     为了让逻辑最严谨、最不容易出错，我们采用“双栈完全同步”的标配打法：

     - **`push(val)`**：数据栈直接入栈 `val`。最小栈要看一眼：如果当前准备入栈的 `val` 比我自己的栈顶还要小，那没的说，`val` 入最小栈；如果 `val` 比我的栈顶还大，说明它动摇不了当前最小值的地位，那我就**把我自己现有的栈顶复制一份，再次压入栈**！
     - **`pop()`**：两个栈同时弹出栈顶。因为它们是绝对同步的，所以数据栈弹出的同时，最小栈也弹出了那一刻的历史最小值，两边的状态永远对称。
     - **`getMin()`**：直接看一眼最小栈的栈顶，那必然是当前的天下第一小。
### Java 实现（双栈同步满分版）
```Java
import java.util.ArrayDeque;
import java.util.Deque;

class MinStack {
    // 数据栈：存放实际数据
    private Deque<Integer> dataStack;
    // 辅助栈：存放每次入栈时，栈内的最小值状态
    private Deque<Integer> minStack;

    public MinStack() {
        dataStack = new ArrayDeque<>();
        minStack = new ArrayDeque<>();
    }

    public void push(int val) {
        dataStack.push(val);

        // 如果辅助栈为空，说明是第一个元素，直接作为最小值入栈
        // 否则，拿当前值 val 和辅助栈栈顶（当前最小值）比较，谁小就压入谁
        if (minStack.isEmpty()) {
            minStack.push(val);
        } else {
            int currentMin = minStack.peek();
            if (val < currentMin) {
                minStack.push(val);
            } else {
                // 🌟 核心工程细节：把老栈顶复制一份压进去，保持两个栈高度绝对一致
                minStack.push(currentMin);
            }
        }
    }

    public void pop() {
        // 两个栈必须同生共死，同时弹出
        if (!dataStack.isEmpty()) {
            dataStack.pop();
            minStack.pop();
        }
    }

    public int top() {
        // 获取数据栈的栈顶
        return dataStack.peek();
    }

    public int getMin() {
        // 🌟 O(1) 极速获取：直接看辅助栈的栈顶即可！
        return minStack.peek();
    }
}

/**
 * Your MinStack object will be instantiated and called as such:
 * MinStack obj = new MinStack();
 * obj.push(val);
 * obj.pop();
 * int param_3 = obj.top();
 * int param_4 = obj.getMin();
 */
```
### 复杂度
  - **时间复杂度**：`push`、`pop`、`top`、`getMin` **全部为 $O(1)$**。没有任何循环，纯粹是指针和栈顶的常规操作。
  - **空间复杂度**：$O(N)$。因为引入了一个和数据栈一样高、同步增长的辅助栈。

### 易错点与扩展（面试高频加分项）

1. **面试追问 1：“我看你的最小栈在 `val > currentMin` 时，复制了老栈顶压进去。如果我不想浪费空间复制老栈顶，代码怎么改？”**
   - **满分抢答（异步不复制流派）**：可以改用“异步模式”。
   - `push` 时：只有当 `val <= minStack.peek()` 时，才把 `val` 压入最小栈。（注意一定要是 `<=`, 不能是 `<`，因为可能有相同的最小值）。
   - `pop` 时：只有当 `dataStack.peek() == minStack.peek()` 时，最小栈才跟着弹出。
   - *面试点评*：这种写法节省了一部分空间。但在面试时，**需要非常小心空指针判断以及 `Integer` 对象的 `==` 比较坑点（Java 缓存机制中，超出 -128 到 127 必须用 `.equals()`）**。所以同步双栈依然是最推荐的、抗压稳健的写法。
2. **终极装杯追问：“如果面试官要求【空间复杂度必须是 $O(1)$】（不允许开辟任何辅助栈或额外数组），你还能玩得转吗？”**
   - **神仙写法（差值存储法）**：这是一个极其炫酷的 trick！
   - 我们的纯数据栈里，**不存原始数据，改存“差值（CurrentValue - CurrentMin）”**。
   - 同时在外部只用一个 `long minValue` 变量。
   - 当入栈一个更小的数时，栈里存入一个负数，并更新 `minValue`。通过这个负数和当前的 `minValue`，在 `pop` 的时候我们可以通过逆向数学公式，反推出**前一个历史最小值**是多少！
   - 这种解法不需要任何额外空间，如果你能在面试中把差值推导公式手写出来，面试官会直接起立为你鼓掌。

## Python 完整推导

### 一个最小值变量为什么会失忆

最小栈不仅要返回当前最小值，还要在 `pop` 之后恢复更早的最小值。只保存一个 `current_min` 时，栈从 `[-2, 0, -3]` 弹出 `-3` 后，变量无法知道剩下的元素里最小值是 `-2`。

解决办法是让数据栈和最小值栈完全同步。数据栈第 `i` 层存当时的元素，最小值栈第 `i` 层存“从栈底到这一层为止的最小值”。它不是只保存某个全局数字，而是在每一层留下当时的历史快照。

### 连续执行 `push(-2)`、`push(0)`、`push(-3)`

1. 压入 `-2`：数据栈为 `[-2]`；最小值栈为空，所以这里的历史最小值就是 `-2`，最小值栈变为 `[-2]`。
2. 压入 `0`：数据栈为 `[-2, 0]`；`min(0, -2) = -2`，最小值栈追加 `-2`，变为 `[-2, -2]`。
3. 压入 `-3`：数据栈为 `[-2, 0, -3]`；`min(-3, -2) = -3`，最小值栈变为 `[-2, -2, -3]`。此时 `getMin()` 读最后一个值，得到 `-3`。
4. 执行 `pop()`：两个列表同时删掉最后一项，数据栈恢复为 `[-2, 0]`，最小值栈恢复为 `[-2, -2]`。再调用 `getMin()`，自然回到 `-2`。
5. 执行 `top()`：它只读取数据栈末尾，此时返回 `0`。

两个栈的高度始终一致，是因为每次 `push` 都在两边各追加一项，每次 `pop` 也都在两边各删除一项。即使出现两个相同的最小值，也会分别占两格，不会发生“弹掉一个，另一个也被误删”的问题。

### Python 实现

> 参考来源：经典解法实现
>
> 沿用旧项目“经典解法实现”中的同步双栈 Python 代码；补全变量命名、方法空行和注释，算法仍为每层保存最小快照。

```python
class MinStack:
    def __init__(self):
        self.stack = []
        self.minimums = []

    def push(self, val: int) -> None:
        self.stack.append(val)
        current_min = val if not self.minimums else min(val, self.minimums[-1])
        self.minimums.append(current_min)

    def pop(self) -> None:
        self.stack.pop()
        self.minimums.pop()

    def top(self) -> int:
        return self.stack[-1]

    def getMin(self) -> int:
        return self.minimums[-1]
```

### Python 列表怎样承担栈操作

`self.stack.append(val)` 和 `self.minimums.append(current_min)` 都从列表尾部加入，复杂度按均摊 O(1) 处理。`pop()` 删除末尾，`top()` 读取 `self.stack[-1]`，`getMin()` 读取 `self.minimums[-1]`。

`current_min = val if not self.minimums else min(val, self.minimums[-1])` 把第一个元素单独处理：最小值栈为空时不能读取 `[-1]`。之后每次只需把新值和此前的最小快照比较。

### 为什么两边必须一起弹出

两个列表靠相同下标表示同一个历史层级。若只弹出数据栈，`minimums` 的末尾就会描述一个已经不存在的数据状态。题目保证 `pop`、`top`、`getMin` 只在非空栈上调用，因此实现不需要额外写异常分支。

### 复杂度

- 时间复杂度：`每次操作 O(1)`。
- 空间复杂度：`O(n)`。

四个公开操作都只做常数次列表尾部操作，时间 O(1)；最小值栈与数据栈等长，空间 O(n)。

## C++ 实现

> 实现来源：经典解法实现

<ol class="lang-steps"><li>双栈：主栈存值，辅助栈顶永远存「到该层为止的最小值」</li><li>push 时辅助栈压 min(x, 辅助栈顶)</li><li>pop 两栈同弹；getMin O(1) 读辅助栈顶</li></ol>

```cpp
class MinStack {
    vector<long> stack, mins;
public:
    void push(int val) {
        stack.push_back(val);
        mins.push_back(min(val, mins.empty() ? (long)val : mins.back()));
    }
    void pop() { stack.pop_back(); mins.pop_back(); }
    int top() { return stack.back(); }
    int getMin() { return mins.back(); }
};
```

## Go 实现

> 实现来源：经典解法实现

<ol class="lang-steps"><li>双栈：主栈存值，辅助栈顶永远存「到该层为止的最小值」</li><li>push 时辅助栈压 min(x, 辅助栈顶)</li><li>pop 两栈同弹；getMin O(1) 读辅助栈顶</li></ol>

```go
type MinStack struct {
    stack []int
    mins  []int
}
func Constructor() MinStack { return MinStack{} }
func (s *MinStack) Push(val int) {
    m := val
    if len(s.mins) > 0 && s.mins[len(s.mins)-1] < val { m = s.mins[len(s.mins)-1] }
    s.stack = append(s.stack, val)
    s.mins = append(s.mins, m)
}
func (s *MinStack) Pop() { s.stack = s.stack[:len(s.stack)-1]; s.mins = s.mins[:len(s.mins)-1] }
func (s *MinStack) Top() int { return s.stack[len(s.stack)-1] }
func (s *MinStack) GetMin() int { return s.mins[len(s.mins)-1] }
```

## C 实现

> 实现来源：经典解法实现

<ol class="lang-steps"><li>双栈：主栈存值，辅助栈顶永远存「到该层为止的最小值」</li><li>push 时辅助栈压 min(x, 辅助栈顶)</li><li>pop 两栈同弹；getMin O(1) 读辅助栈顶</li></ol>

```c
typedef struct { int val, min; } Node;
typedef struct { Node* data; int top, cap; } MinStack;
MinStack* minStackCreate() {
    MinStack* s = malloc(sizeof(MinStack));
    s->cap = 64; s->top = 0;
    s->data = malloc(sizeof(Node) * s->cap);
    return s;
}
void minStackPush(MinStack* obj, int val) {
    if (obj->top == obj->cap) { obj->cap *= 2; obj->data = realloc(obj->data, sizeof(Node) * obj->cap); }
    int m = obj->top ? (obj->data[obj->top-1].min < val ? obj->data[obj->top-1].min : val) : val;
    obj->data[obj->top].val = val; obj->data[obj->top].min = m; obj->top++;
}
void minStackPop(MinStack* obj) { obj->top--; }
int minStackTop(MinStack* obj) { return obj->data[obj->top-1].val; }
int minStackGetMin(MinStack* obj) { return obj->data[obj->top-1].min; }
void minStackFree(MinStack* obj) { free(obj->data); free(obj); }
```
