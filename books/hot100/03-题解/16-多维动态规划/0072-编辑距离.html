时间复杂度 O(mn)

题目与约束

给你两个单词 word1 和 word2， 请返回将 word1 转换成 word2 所使用的最少操作数。

你可以对一个单词进行如下三种操作：

  1. 插入一个字符 (Insert)
  2. 删除一个字符 (Delete)
  3. 替换一个字符 (Replace)

🔗 前往力扣原题验证 →

核心不变量

最后字符相同不付代价，否则从增删改三种操作取最小。

完整推导

思路推导

  1. 直觉与痛点（无从下手的多重宇宙）：

    当我们看到 word1 = "horse"，word2 = "ros"。你是该先把 h 替换成 r？还是先把 h 删掉？每一次操作都会引发蝴蝶效应，改变后续字符的位置。用 DFS 穷举会产生极其恐怖的指数级时间复杂度。

  2. 降维破局（二维矩阵与“最后一步”的哲学）：

    像 LCS 一样，我们引入二维矩阵。定义 dp[i][j]：将 word1 的前 i 个字符转换成 word2 的前 j 个字符，所需的最少操作数。

    我们只看双方的最后一个字符（假设是 c1 和 c2），思考这“最后一步”该怎么走。

  3. 核心微操（状态转移方程的四大宿命）：

    • 宿命 A（心有灵犀：c1 == c2）：

    太好了，最后这两个字符完全一样，不需要任何操作！

    那当前的成本，就完全等于它们俩还没相遇时的成本。

    dp[i][j]=dp[i-1][j-1]

    • 宿命 B（痛下杀手：c1 != c2）：

    字符不一样，我们必须花 1 块钱动手术。有三种方案，我们挑最便宜的：

    1. 删除：把 word1 的 c1 删掉。成本等于 word1 前 i-1 个字符变成 word2 前 j 个字符的成本 + 1。也就是看上方：dp[i-1][j]+1
    2. 插入：在 word1 末尾插一个 c2。这意味着 word1 前 i 个字符已经搞定了 word2 的前 j-1 个字符。也就是看左方：dp[i][j-1]+1
    3. 替换：把 c1 替换成 c2。说明双方的前面都已经匹配好了。也就是看左上方：dp[i-1][j-1]+1

    最终决策：dp[i][j]=min(dp[i-1][j],dp[i][j-1],dp[i-1][j-1])+1

    Java 实现（满分标准矩阵版）

class Solution {
    public int minDistance(String word1, String word2) {
        int m = word1.length();
        int n = word2.length();

        // dp[i][j] 代表 word1 的前 i 个字符转换成 word2 的前 j 个字符需要的最少步数
        int[][] dp = new int[m + 1][n + 1];

        // 🌟 边界基石初始化 (极其重要！)
        // 1. 如果 word2 是空串，那 word1 变成 word2 只能不断【删除】
        for (int i = 0; i <= m; i++) {
            dp[i][0] = i;
        }
        // 2. 如果 word1 是空串，那 word1 变成 word2 只能不断【插入】
        for (int j = 0; j <= n; j++) {
            dp[0][j] = j;
        }

        // 开始在二维矩阵中填表
        for (int i = 1; i <= m; i++) {
            for (int j = 1; j <= n; j++) {
                // 注意索引偏移，第 i 个字符的索引是 i-1
                if (word1.charAt(i - 1) == word2.charAt(j - 1)) {
                    // 字符相等：什么都不用做，直接继承左上角的历史最低成本
                    dp[i][j] = dp[i - 1][j - 1];
                } else {
                    // 字符不等：在【删除(上)】、【插入(左)】、【替换(左上)】中选最小的，然后 + 1
                    int deleteCost = dp[i - 1][j];
                    int insertCost = dp[i][j - 1];
                    int replaceCost = dp[i - 1][j - 1];

                    dp[i][j] = Math.min(Math.min(deleteCost, insertCost), replaceCost) + 1;
                }
            }
        }

        // 右下角就是将整个 word1 变成 word2 的最终答案
        return dp[m][n];
    }
}

复杂度

  • 时间复杂度：O(M×N)。M 和 N 为两字符串长度，双重循环填满矩阵。
  • 空间复杂度：O(M×N)。

易错点与扩展（面试的终极拷问）

  1. 面试追问 1：“代码里的 insertCost 是看左边，deleteCost 是看上边。为什么？能直观解释一下吗？”

  • 满分大白话解释：

    • 看上边 dp[i-1][j]：意思是 word1 舍弃了自己最新的字符（删除了它），所以行数退了一步（i-1），而 word2 的目标没变（j）。这叫删除。

    • 看左边 dp[i][j-1]：意思是 word1 凭空生出了一个字符来迎合 word2 最新字符，既然迎合成功了，word2 的目标就完成了一个（列数退一步 j-1），而 word1 自己的主体还没变（i）。这叫插入。

    把抽象的网格方向翻译成物理意义，面试官会觉得你的基本功无比扎实。

  1. 面试追问 2：“这题的空间复杂度还能优化吗？”
  • 优化思路（滚动数组）：绝对可以！和 LCS 一模一样，计算第 i 行时，我们只依赖第 i-1 行（正上方和左上方）和当前行（左方）。
  • 我们可以把二维数组压缩成一个长度为 N+1 的一维数组。在遍历时，用一个临时变量 prev 存下马上要被覆盖的左上角的值（dp[i-1][j-1]），这样就能在 O(N) 的极限空间内完成手术！
