题目与约束

给你两个单词 word1 和 word2， 请返回将 word1 转换成 word2 所使用的最少操作数 。

你可以对一个单词进行如下三种操作：

  • 插入一个字符
  • 删除一个字符
  • 替换一个字符

示例 1：

输入：word1 = "horse", word2 = "ros"
输出：3
解释：
horse -> rorse (将 'h' 替换为 'r')
rorse -> rose (删除 'r')
rose -> ros (删除 'e')

示例 2：

输入：word1 = "intention", word2 = "execution"
输出：5
解释：
intention -> inention (删除 't')
inention -> enention (将 'i' 替换为 'e')
enention -> exention (将 'n' 替换为 'x')
exention -> exection (将 'n' 替换为 'c')
exection -> execution (插入 'u')

提示：

  • 0 <= word1.length, word2.length <= 500
  • word1 和 word2 由小写英文字母组成

Java 完整推导

Java 核心不变量

最后字符相同不付代价，否则从增删改三种操作取最小。

完整推导

思路推导

  1. 直觉与痛点（无从下手的多重宇宙）：

    当我们看到 word1 = "horse"，word2 = "ros"。你是该先把 h 替换成 r？还是先把 h 删掉？每一次操作都会引发蝴蝶效应，改变后续字符的位置。用 DFS 穷举会产生极其恐怖的指数级时间复杂度。

  2. 降维破局（二维矩阵与“最后一步”的哲学）：

    像 LCS 一样，我们引入二维矩阵。定义 dp[i][j]：将 word1 的前 i 个字符转换成 word2 的前 j 个字符，所需的最少操作数。

    我们只看双方的最后一个字符（假设是 c1 和 c2），思考这“最后一步”该怎么走。

  3. 核心微操（状态转移方程的四大宿命）：

    • 宿命 A（心有灵犀：c1 == c2）：

    太好了，最后这两个字符完全一样，不需要任何操作！

    那当前的成本，就完全等于它们俩还没相遇时的成本。

    dp[i][j] = dp[i-1][j-1]

    • 宿命 B（痛下杀手：c1 != c2）：

    字符不一样，我们必须花 1 块钱动手术。有三种方案，我们挑最便宜的：

    1. 删除：把 word1 的 c1 删掉。成本等于 word1 前 i-1 个字符变成 word2 前 j 个字符的成本 + 1。也就是看上方：dp[i-1][j] + 1
    2. 插入：在 word1 末尾插一个 c2。这意味着 word1 前 i 个字符已经搞定了 word2 的前 j-1 个字符。也就是看左方：dp[i][j-1] + 1
    3. 替换：把 c1 替换成 c2。说明双方的前面都已经匹配好了。也就是看左上方：dp[i-1][j-1] + 1

    最终决策：dp[i][j]=min(dp[i-1][j],dp[i][j-1],dp[i-1][j-1])+1

    Java 实现（满分标准矩阵版）

class Solution {
    public int minDistance(String word1, String word2) {
        int m = word1.length();
        int n = word2.length();

        // dp[i][j] 代表 word1 的前 i 个字符转换成 word2 的前 j 个字符需要的最少步数
        int[][] dp = new int[m + 1][n + 1];

        // 🌟 边界基石初始化 (极其重要！)
        // 1. 如果 word2 是空串，那 word1 变成 word2 只能不断【删除】
        for (int i = 0; i <= m; i++) {
            dp[i][0] = i;
        }
        // 2. 如果 word1 是空串，那 word1 变成 word2 只能不断【插入】
        for (int j = 0; j <= n; j++) {
            dp[0][j] = j;
        }

        // 开始在二维矩阵中填表
        for (int i = 1; i <= m; i++) {
            for (int j = 1; j <= n; j++) {
                // 注意索引偏移，第 i 个字符的索引是 i-1
                if (word1.charAt(i - 1) == word2.charAt(j - 1)) {
                    // 字符相等：什么都不用做，直接继承左上角的历史最低成本
                    dp[i][j] = dp[i - 1][j - 1];
                } else {
                    // 字符不等：在【删除(上)】、【插入(左)】、【替换(左上)】中选最小的，然后 + 1
                    int deleteCost = dp[i - 1][j];
                    int insertCost = dp[i][j - 1];
                    int replaceCost = dp[i - 1][j - 1];

                    dp[i][j] = Math.min(Math.min(deleteCost, insertCost), replaceCost) + 1;
                }
            }
        }

        // 右下角就是将整个 word1 变成 word2 的最终答案
        return dp[m][n];
    }
}

复杂度

  • 时间复杂度：O(M × N)。M 和 N 为两字符串长度，双重循环填满矩阵。
  • 空间复杂度：O(M × N)。
易错点与扩展（面试的终极拷问）
  1. 面试追问 1：“代码里的 insertCost 是看左边，deleteCost 是看上边。为什么？能直观解释一下吗？”

  • 满分大白话解释：

    • 看上边 dp[i-1][j]：意思是 word1 舍弃了自己最新的字符（删除了它），所以行数退了一步（i-1），而 word2 的目标没变（j）。这叫删除。

    • 看左边 dp[i][j-1]：意思是 word1 凭空生出了一个字符来迎合 word2 最新字符，既然迎合成功了，word2 的目标就完成了一个（列数退一步 j-1），而 word1 自己的主体还没变（i）。这叫插入。

    把抽象的网格方向翻译成物理意义，面试官会觉得你的基本功无比扎实。

  1. 面试追问 2：“这题的空间复杂度还能优化吗？”
  • 优化思路（滚动数组）：绝对可以！和 LCS 一模一样，计算第 i 行时，我们只依赖第 i-1 行（正上方和左上方）和当前行（左方）。
  • 我们可以把二维数组压缩成一个长度为 N+1 的一维数组。在遍历时，用一个临时变量 prev 存下马上要被覆盖的左上角的值（dp[i-1][j-1]），这样就能在 O(N) 的极限空间内完成手术！

Python 完整推导

编辑距离也只看两个前缀的最后一个字符

dp[i][j] 表示把 word1[:i] 变成 word2[:j] 的最少操作数。若两个末尾字符相同，无需再付操作成本，直接继承左上角 dp[i-1][j-1]。

若末尾不同，就有三种最后操作：删除 word1 末尾后看上方；在 word1 末尾插入目标字符后看左方；替换末尾后看左上角。三种操作都付 1 次成本，取较小值再加一。

用 "horse" 变成 "ros" 填完整张表

列下标 0 到 3 分别对应 ""、"r"、"ro"、"ros"：

i word1[:i] j=0 j=1 j=2 j=3
0 "" 0 1 2 3
1 "h" 1 1 2 3
2 "ho" 2 2 1 2
3 "hor" 3 2 2 2
4 "hors" 4 3 3 2
5 "horse" 5 4 4 3

dp[1][1] 中 h 与 r 不同，可以选择替换，成本为 dp[0][0] + 1 = 1。到 dp[2][2]，ho 与 ro 的末尾 o 相同，因此继承左上角 dp[1][1] = 1。最后 dp[5][3] 的 e 与 s 不同，三个候选是上方 dp[4][3] = 2、左方 dp[5][2] = 4、左上 dp[4][2] = 3，取最小值再加一得到 3。

一条具体操作序列是：horse -> rorse 把 h 替换成 r，rorse -> rose 删除第二个 r，rose -> ros 再删除末尾 e，总共三步。表中每个前缀对的价值都可按同一规则逐格复核。

Python 实现

参考来源：代码随想录（programmercarl.com）

沿用旧项目收录的《代码随想录》二维编辑距离 Python 代码；变量、边界循环和注释按本页整理，修正插入/删除方向表述。

class Solution:
    def minDistance(self, word1: str, word2: str) -> int:
        rows = len(word1)
        cols = len(word2)
        dp = [[0] * (cols + 1) for _ in range(rows + 1)]

        for i in range(rows + 1):
            dp[i][0] = i
        for j in range(cols + 1):
            dp[0][j] = j

        for i in range(1, rows + 1):
            for j in range(1, cols + 1):
                if word1[i - 1] == word2[j - 1]:
                    dp[i][j] = dp[i - 1][j - 1]
                else:
                    dp[i][j] = min(
                        dp[i - 1][j],
                        dp[i][j - 1],
                        dp[i - 1][j - 1],
                    ) + 1
        return dp[rows][cols]

插入和删除方向不要写反

dp[i-1][j] 表示已经处理 word1 的前 i-1 个字符，相当于删掉 word1 当前末尾，所以是删除来源。dp[i][j-1] 表示目标少看一个字符，相当于在 word1 中插入它，所以是插入来源。dp[i-1][j-1] 同时少看双方末尾，若字符不同就是替换来源。

字符相同时不能无条件取三种操作最小值：已经匹配的末尾不该再删、插或改，直接继承对角线才是零额外成本。

边界与空间

首行 dp[0][j]=j 是插入 j 个字符，首列 dp[i][0]=i 是删除 i 个字符。二维表占 O(mn)；两行滚动可以压缩到 O(min(m,n))，但仍必须保存左上角在覆盖前的旧值。

复杂度

  • 时间复杂度：O(m·n)。
  • 空间复杂度：O(m·n)。

二维表有 (m+1)(n+1) 个前缀对，每格做常数次比较，时间 O(mn)；完整保存所有状态占 O(mn) 空间。

C++ 实现

实现来源：站内标准实现

class Solution {
public:
    int minDistance(string word1, string word2) {
        int m = word1.size(), n = word2.size();
        vector<vector<int>> dp(m + 1, vector<int>(n + 1));
        for (int i = 0; i <= m; ++i) dp[i][0] = i;
        for (int j = 0; j <= n; ++j) dp[0][j] = j;
        for (int i = 1; i <= m; ++i)
            for (int j = 1; j <= n; ++j)
                dp[i][j] = word1[i - 1] == word2[j - 1]
                    ? dp[i - 1][j - 1]
                    : min({dp[i - 1][j], dp[i][j - 1], dp[i - 1][j - 1]}) + 1;
        return dp[m][n];
    }
};

Go 实现

实现来源：代码随想录（programmercarl.com）

func minDistance(word1 string, word2 string) int {
    m, n := len(word1), len(word2)
    dp := make([][]int, m+1)
    for i := range dp {
        dp[i] = make([]int, n+1)
    }
    for i := 0; i < m+1; i++ {
        dp[i][0] = i // word1[i] 变成 word2[0], 删掉 word1[i], 需要 i 部操作
    }
    for j := 0; j < n+1; j++ {
        dp[0][j] = j // word1[0] 变成 word2[j], 插入 word1[j]，需要 j 部操作
    }
    for i := 1; i < m+1; i++ {
        for j := 1; j < n+1; j++ {
            if word1[i-1] == word2[j-1] {
                dp[i][j] = dp[i-1][j-1]
            } else { // Min(插入，删除，替换)
                dp[i][j] = Min(dp[i][j-1], dp[i-1][j], dp[i-1][j-1]) + 1
            }
        }
    }
    return dp[m][n]
}
func Min(args ...int) int {
    min := args[0]
    for _, item := range args {
        if item < min {
            min = item
        }
    }
    return min
}

C 实现

实现来源：代码随想录（programmercarl.com）

int min(int num1, int num2, int num3) {
    return num1 > num2 ? (num2 > num3 ? num3 : num2) : (num1 > num3 ? num3 : num1); 
}
