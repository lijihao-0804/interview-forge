1143. 最长公共子序列

难度中等
Java 主方法双序列 DP时间O(mn)空间O(mn)
Python 主方法双序列二维前缀 DP时间O(m·n)空间O(m·n)

题目与约束

给定两个字符串 text1 和 text2，返回这两个字符串的最长 公共子序列 的长度。如果不存在 公共子序列 ，返回 0 。

一个字符串的 子序列是指这样一个新的字符串：它是由原字符串在不改变字符的相对顺序的情况下删除某些字符（也可以不删除任何字符）后组成的新字符串。

  • 例如，"ace" 是 "abcde" 的子序列，但 "aec" 不是 "abcde" 的子序列。

两个字符串的 公共子序列 是这两个字符串所共同拥有的子序列。

示例 1：

输入：text1 = "abcde", text2 = "ace"
输出：3
解释：最长公共子序列是 "ace" ，它的长度为 3 。

示例 2：

输入：text1 = "abc", text2 = "abc"
输出：3
解释：最长公共子序列是 "abc" ，它的长度为 3 。

示例 3：

输入：text1 = "abc", text2 = "def"
输出：0
解释：两个字符串没有公共子序列，返回 0 。

提示：

  • 1 <= text1.length, text2.length <= 1000
  • text1 和 text2 仅由小写英文字符组成。

Java 完整推导

Java 核心不变量

字符相同取左上加一，否则取上方与左方最大值。

完整推导

思路推导

  1. 直觉与痛点（双指针的迷茫）：

    很多人的第一直觉是搞两个指针 i 和 j 分别扫两个字符串，遇到一样的就同时后移。

    痛点：假设 text1 = "abcde"，text2 = "ace"。你遇到 'a' 匹配了，那如果遇到 text1 = "bsbininm", text2 = "jmjkbkjkv" 呢？面对错综复杂的交替字符，贪心双指针极容易在错误的字符上“过早绑定”，导致丢掉后面更长的匹配机会。

  2. 降维破局（二维矩阵的上帝视角）：

    既然是两个字符串的纠葛，我们需要一个二维的 DP 数组来记录所有的历史状态。

    定义 dp[i][j]：表示 text1 的前 i 个字符和 text2 的前 j 个字符，它们的最长公共子序列的长度。

  3. 核心微操（状态转移的两种宿命）：

    当我们看 text1 的第 i 个字符（记为 c1）和 text2 的第 j 个字符（记为 c2）时，只会有两种情况：

    • 宿命 A（一拍即合：c1 == c2）：

    太完美了！这两个字符可以手牵手加入 LCS 俱乐部。

    那么当前的 LCS 长度，就是它们俩都没加入时的长度（也就是左上角的格子），再加上这新的一对。

    dp[i][j] = dp[i-1][j-1] + 1

    • 宿命 B（擦肩而过：c1 != c2）：

    它们俩不相等，无法配对。那我们就得做出取舍：

    要么让 c1 委屈一下，去看看 text2 前面的字符能不能配上（对应上方的格子 dp[i-1][j]）；

    要么让 c2 委屈一下，去看看 text1 前面的字符能不能配上（对应左方的格子 dp[i][j-1]）。

    我们是一个贪心且理智的算法，谁留下来的匹配长度更长，我们就继承谁的遗产！

    dp[i][j]=max(dp[i-1][j],dp[i][j-1])

    Java 实现（满分标准二维版）

class Solution {
    public int longestCommonSubsequence(String text1, String text2) {
        int m = text1.length();
        int n = text2.length();

        // 🌟 致命细节：数组长度为什么要 +1？
        // 因为我们需要一排“空字符串”作为基石（Base Case）。
        // dp[0][j] 表示 text1 是空字符串时，无论 text2 是什么，LCS 都是 0。
        // 这极大地简化了边界处理，避免了各种 i-1, j-1 导致的数组越界报错！
        int[][] dp = new int[m + 1][n + 1];

        // i 和 j 从 1 开始遍历，对应字符串的第 1 个字符（索引为 0）
        for (int i = 1; i <= m; i++) {
            for (int j = 1; j <= n; j++) {
                // 拿出现实的字符进行比对（注意索引偏移，字符索引是 i-1 和 j-1）
                char c1 = text1.charAt(i - 1);
                char c2 = text2.charAt(j - 1);

                if (c1 == c2) {
                    // 字符相等：继承左上角历史记录，并且 + 1
                    dp[i][j] = dp[i - 1][j - 1] + 1;
                } else {
                    // 字符不等：继承上方或左方中较大的那一个
                    dp[i][j] = Math.max(dp[i - 1][j], dp[i][j - 1]);
                }
            }
        }

        // 矩阵的最右下角，就是两军交战完毕后的最终结果
        return dp[m][n];
    }
}

复杂度

  • 时间复杂度：O(M × N)。M 和 N 是两个字符串的长度，我们需要极其均匀地填满整个二维矩阵。
  • 空间复杂度：O(M × N)。开辟了一个同等大小的二维 dp 数组。
易错点与扩展（面试的终极审判）
  1. 面试追问 1：“我看你用了二维矩阵，空间复杂度是 O(M × N)。你能把它优化到一维吗？” - 满分抢答（滚动数组的极致压榨）：绝对可以！ - 我们观察转移方程，计算第 i 行的 dp 值时，仅仅依赖于“当前行（左边）”和“上一行（正上方和左上方）”的数据。 - 所以我们完全可以只开辟一个长度为 N+1 的一维数组。在遍历时，用一个临时变量 prev 记住左上角的值（因为会被覆盖），然后不断原地更新这个一维数组。 - 空间复杂度瞬间从 O(M × N) 降维到了 O(min(M,N))（把较短的字符串放在内层循环）。
  2. 面试追问 2：“如果我不仅要长度，我还要你把那个具体的【最长公共子序列打印出来】，你怎么做？” - 架构师级回答（DP 逆向回溯法）： - 这也是极其高频的拔高题。我们只需要站在矩阵的右下角 dp[m][n]，开始倒推寻找来时的路： - 如果 text1[i-1] == text2[j-1]，说明这个字符绝对在 LCS 里！把它记录下来，然后往左上角走（i--, j--）。 - 如果不相等，说明它不在 LCS 里，那是谁把能量传递给它的？我们比较上方 dp[i-1][j] 和左方 dp[i][j-1]，谁大就往谁的方向退一步。 - 一路退回原点，收集到的字符倒序打印，就是完美的字符串！

Python 完整推导

两个前缀共享一个二维状态表

dp[i][j] 表示 text1[:i] 与 text2[:j] 的最长公共子序列长度。多出的一行一列代表空前缀，值为 0，这样处理第一个字符时不需要额外判断下标是否小于 0。

看两个前缀的末尾字符：如果它们相等，就可以把这一对接到更短前缀的左上角 dp[i-1][j-1] 后，长度加一；如果不同，最后一个字符不可能同时进入公共子序列，只能分别舍弃其中一个再去比较，于是取上方和左方的较大者。

用 text1 = "abcde"、text2 = "ace" 填完整张表

列下标 0 到 3 分别对应 ""、"a"、"ac"、"ace"：

i text1[:i] j=0 j=1 j=2 j=3
0 "" 0 0 0 0
1 "a" 0 1 1 1
2 "ab" 0 1 1 1
3 "abc" 0 1 2 2
4 "abcd" 0 1 2 2
5 "abcde" 0 1 2 3

例如 dp[3][2] 对应 "abc" 与 "ac"：末尾都是 c，所以从左上角 dp[2][1] = 1 得到 2。最后 dp[5][3] 对应末尾 e = e，继承 dp[4][2] = 2 再加一，得到 3。

“子序列”允许跳过字符。若末尾不同，例如 dp[2][3] 的 b 与 e，就只能继承 dp[1][3] = 1 或 dp[2][2] = 1，不能在当前格凭空增加长度。

Python 实现

参考来源：代码随想录（programmercarl.com）

沿用旧项目收录的《代码随想录》二维 LCS Python 代码；变量、状态表边界和注释按本页整理。

class Solution:
    def longestCommonSubsequence(self, text1: str, text2: str) -> int:
        rows = len(text1)
        cols = len(text2)
        dp = [[0] * (cols + 1) for _ in range(rows + 1)]
        for i in range(1, rows + 1):
            for j in range(1, cols + 1):
                if text1[i - 1] == text2[j - 1]:
                    dp[i][j] = dp[i - 1][j - 1] + 1
                else:
                    dp[i][j] = max(dp[i - 1][j], dp[i][j - 1])
        return dp[rows][cols]

下标偏移与两个转移分支

外层用 i 表示 text1 的前 i 个字符，内层用 j 表示 text2 的前 j 个字符。真实字符分别是 text1[i-1] 和 text2[j-1]，这也是数组要多一行一列的原因。

dp[i][j] = dp[i-1][j-1] + 1 只在末尾字符相等时使用；max(dp[i-1][j], dp[i][j-1]) 表示跳过 text1 当前末尾或跳过 text2 当前末尾。

空间与返回值

本题只返回长度，二维表大小 O(mn)。若需要降低空间，两行滚动可以做到 O(min(m,n))，但必须额外保存左上角旧状态；这里保留完整表，便于逐步观察每个前缀对。

复杂度

  • 时间复杂度：O(m·n)。
  • 空间复杂度：O(m·n)。

状态表有 (m+1)(n+1) 项，每项常数次比较和加法，时间 O(mn)；表中每个整数都保存，空间 O(mn)。

C++ 实现

实现来源：代码随想录（programmercarl.com）

class Solution {
public:
    int longestCommonSubsequence(string text1, string text2) {
        vector<vector<int>> dp(text1.size() + 1, vector<int>(text2.size() + 1, 0));
        for (int i = 1; i <= text1.size(); i++) {
            for (int j = 1; j <= text2.size(); j++) {
                if (text1[i - 1] == text2[j - 1]) {
                    dp[i][j] = dp[i - 1][j - 1] + 1;
                } else {
                    dp[i][j] = max(dp[i - 1][j], dp[i][j - 1]);
                }
            }
        }
        return dp[text1.size()][text2.size()];
    }
};

Go 实现

实现来源：代码随想录（programmercarl.com）

func longestCommonSubsequence(text1 string, text2 string) int {
    t1 := len(text1)
    t2 := len(text2)
    dp:=make([][]int,t1+1)
    for i:=range dp{
        dp[i]=make([]int,t2+1)
    }

    for i := 1; i <= t1; i++ {
        for j := 1; j <=t2; j++ {
            if text1[i-1]==text2[j-1]{
                dp[i][j]=dp[i-1][j-1]+1
            }else{
                dp[i][j]=max(dp[i-1][j],dp[i][j-1])
            }
        }
    }
    return dp[t1][t2]
}

func max(a,b int)int  {
    if a>b{
        return a
    }
    return b
}

C 实现

实现来源：站内标准实现

int longestCommonSubsequence(char* text1, char* text2) {
    int m = strlen(text1), n = strlen(text2);
    int** dp = malloc(sizeof(int*) * (m + 1));
    for (int i = 0; i <= m; ++i) dp[i] = calloc(n + 1, sizeof(int));
    for (int i = 1; i <= m; ++i)
        for (int j = 1; j <= n; ++j)
            dp[i][j] = text1[i - 1] == text2[j - 1]
                ? dp[i - 1][j - 1] + 1
                : (dp[i - 1][j] > dp[i][j - 1] ? dp[i - 1][j] : dp[i][j - 1]);
    return dp[m][n];
}
