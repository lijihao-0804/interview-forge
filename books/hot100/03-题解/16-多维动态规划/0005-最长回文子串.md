## 题目与约束

给你一个字符串 `s`，找到 `s` 中最长的 回文 子串。

  **示例 1：**

  **输入：**s = "babad"<br>**输出：**"bab"<br>**解释：**"aba" 同样是符合题意的答案。

  **示例 2：**

  **输入：**s = "cbbd"<br>**输出：**"bb"

  **提示：**

  - `1 <= s.length <= 1000`
  - `s` 仅由数字和英文字母组成

## 完整推导

### 思路推导
  1. **直觉与痛点（暴力的代价与 DP 的浪费）**：

     - **暴力法**：找出所有的子串（$O(N^2)$ 个），再挨个判断是不是回文（$O(N)$），总时间 $O(N^3)$，直接超时。
     - **动态规划**：开一个二维数组 `dp[i][j]` 记录子串是否为回文。时间 $O(N^2)$，空间也是 $O(N^2)$。如果字符串长度达到 1000，需要极其庞大的内存开销。

  2. **破局思路（回文的天然对称性）**：

     回文串有一个极其美妙的物理特性：**它必定是绕着某个“中心”绝对对称的！**

     既然如此，我们为什么要从两头往中间检查呢？完全可以“站在中心，向两边同时扩散”！

     只要两边的字符相等，我们的回文雷达就可以继续向外扩张；一旦不相等，扩张立刻停止，当前的回文长度也就确定了。

  3. **核心微操（奇偶双中心的幽灵陷阱）**：

     这里的致命难点在于，回文串有两种形态：

     - **奇数长度（如 `"aba"`）**：它的中心是一个**实实在在的字符**（`'b'`）。

     - **偶数长度（如 `"abba"`）**：它的中心是**两个字符中间的虚空缝隙**（`'b'` 和 `'b'` 之间）。

       为了做到滴水不漏，我们遍历字符串的每一个索引 `i` 时，都要以它为中心做**两次扩散**：

       一次把 `i` 当作唯一的中心（奇数扩散）；

       另一次把 `i` 和 `i+1` 当作共同的中心（偶数扩散）。
### Java 实现（满分中心扩展法）
```Java
class Solution {
    public String longestPalindrome(String s) {
        // 边界防御
        if (s == null || s.length() < 1) {
            return "";
        }

        // 记录最长回文子串的起始位置和结束位置
        int start = 0;
        int end = 0;

        // 游标 i 依次遍历字符串的每一个字符
        for (int i = 0; i < s.length(); i++) {
            // 方案 A：以当前字符 i 为唯一中心，向两边扩散（处理奇数长度回文）
            int len1 = expandAroundCenter(s, i, i);
            // 方案 B：以 i 和 i+1 之间的缝隙为中心，向两边扩散（处理偶数长度回文）
            int len2 = expandAroundCenter(s, i, i + 1);

            // 挑出这两种方案里，扩散出来的最大长度
            int len = Math.max(len1, len2);

            // 如果新长度打破了历史记录，更新 start 和 end
            if (len > end - start) {
                // 🌟 致命数学推导：已知中心位置 i 和回文总长度 len，求起点和终点
                // 无论奇偶，起始坐标推导公式都是自洽的：
                start = i - (len - 1) / 2;
                end = i + len / 2;
            }
        }

        // 截取并返回最长回文子串（注意 substring 的右边界是开区间，所以要 end + 1）
        return s.substring(start, end + 1);
    }

    // 辅助函数：雷达中心扩散，返回扩散能达到的最大长度
    private int expandAroundCenter(String s, int left, int right) {
        // 只要没有越界，且左右指针指向的字符相等，就继续疯狂向外扩张
        while (left >= 0 && right < s.length() && s.charAt(left) == s.charAt(right)) {
            left--;
            right++;
        }
        // 循环被打破时，left 和 right 已经指向了不满足条件的字符
        // 此时真实的回文串长度应该是 (right - 1) - (left + 1) + 1 = right - left - 1
        return right - left - 1;
    }
}
```
### 复杂度
  - **时间复杂度**：$O(N^2)$。共有 $2N-1$ 个中心点（$N$ 个单字符中心，加上 $N-1$ 个双字符间隙中心）。围绕每个中心向外扩展，最坏情况下可能要扩散 $N/2$ 步。所以总时间依然是优秀的平方级别。
  - **空间复杂度**：$O(1)$。只用了 `start`、`end` 和几个整型变量，相比动态规划省下了极大的二维数组内存，这是纯正的工业级代码。

### 易错点与扩展（面试的数学迷阵与终极进阶）

1. **极度高频坑点：计算 `start` 时的偏移量公式是怎么来的？**

   - 很多同学在面试白板写代码时，公式 `start = i - (len - 1) / 2` 总是写错。

   - **满分记忆法**：假设扩散中心是 `i`，总长度是 `len`。

     如果 `len` 是 3（奇数），`len - 1` 就是 2，除以 2 得到 1。`i` 往前走 1 步就是起点。

     如果 `len` 是 4（偶数），中心其实是在 `i` 和 `i+1` 之间。`len - 1` 就是 3，在 Java 整数除法里 `3 / 2 = 1`。所以 `i` 往前走 1 步依然是正确的起点！

     利用 `(len - 1) / 2`，完美抹平了奇偶带来的数学差异，这是这套代码最极客的细节。

2. **面试终极追踪：“你能把这道题的时间复杂度降到严格的 $O(N)$ 吗？”**

   - **满分优化思路（马拉车算法 Manacher's Algorithm）**：
   - 回答套路：“面试官您好，这道题存在时间复杂度为 $O(N)$ 的 Manacher 算法。它的核心思想是通过向字符串中插入特殊字符（如 `#`），将所有偶数回文转化为奇数回文，并且利用已经计算过的右边界和对称中心，使得后面的扩散过程能够直接借用前面的结果，从而避免重复探测，把时间压榨到了线性级别。”
   - *工程风控提示*：“不过在实际工程中，Manacher 算法代码极其晦涩难懂，维护成本极高。除非明确遇到超大规模字符串的性能瓶颈，否则中心扩展法的 $O(N^2)$ 配合 $O(1)$ 空间，才是性价比最高、最易读的选择。”（这番话说出来，架构师思维直接拉满）。

## Python 完整推导

### 回文中心只有两种

奇数长度回文以某一个字符为中心，例如 `aba` 的中心是 `b`；偶数长度回文以两个字符之间的缝隙为中心，例如 `abba` 的中心是两个 `b` 之间。全部回文中心一共有 `2n - 1` 个。

固定中心后，只要左右字符相等就继续向外扩张；第一次遇到越界或字符不等时，前一个区间就是该中心能给出的最长回文。逐个中心比较，保留最长的一段。

### 用 `"babad"` 走奇数中心

1. 以 0 号字符 `b` 为中心：左指针越界、右指针停在 1，得到的长度是 `1 - (-1) - 1 = 1`，当前答案 `b`。
2. 以 1 号字符 `a` 为中心：左右字符 `b` 和 `b` 相等，继续向两侧走；再到边界，得到 `bab` 长度 3，刷新答案。
3. 以 2 号字符 `b` 为中心：左右是 `a` 和 `a`，先得到 `aba`，但随后字符不再相等，长度仍是 3。
4. 以 3、4 号位置为中心得不到更长回文。最终保留最早达到长度 3 的 `bab`。

### 偶数中心不能漏掉

对 `"cbbd"`，若只看单个字符，最长长度只会是 1。以 1 号和 2 号字符之间的缝隙为中心，左右都是 `b`，扩张得到 `bb`；再向外是 `c` 和 `d`，不相等，因此答案为 2。

每个中心都要分别尝试 `(center, center)` 和 `(center, center+1)`。两套长度比较后再更新起点和最大长度，返回时切片正好复制出答案串。

### Python 实现

> 参考来源：代码随想录（programmercarl.com）
>
> 旧项目收录的 Python 为二维回文 DP；主解采用同题旧 Java 的主推中心扩展，source 沿用旧项目标注，代码按本页重写并明确并非上游原稿。

```python
class Solution:
    def longestPalindrome(self, s: str) -> str:
        if not s:
            return ""

        best_start = 0
        best_length = 0

        def expand(left, right):
            nonlocal best_start, best_length
            while left >= 0 and right < len(s) and s[left] == s[right]:
                left -= 1
                right += 1
            length = right - left - 1
            if length > best_length:
                best_start = left + 1
                best_length = length

        for center in range(len(s)):
            expand(center, center)
            expand(center, center + 1)
        return s[best_start:best_start + best_length]
```

### 扩张结束后的指针关系

内层 `while` 只在左右下标都合法且字符相等时继续。循环停止时，`left` 已经向左多走一格，`right` 已经向右多走一格，所以当前回文长度是 `right - left - 1`，起点是 `left + 1`。

辅助函数用 `nonlocal` 修改外层的 `best_start` 和 `best_length`，不需要把每个中心的答案都存进列表。主循环每个下标调用两次，分别覆盖奇数和偶数中心。

### 时间与返回空间

共有 O(n) 个中心，最坏每个中心向两侧扩张 O(n)，时间 O(n²)。扩张过程只保存指针和两个最佳值；最终 `s[best_start:best_start + best_length]` 会复制返回串，所以空间记为 O(n)，额外工作状态是 O(1)。若明确要求 O(n) 时间，应讨论 Manacher 算法，不能把中心扩展写成线性。

### 复杂度

- 时间复杂度：`O(n²)`。
- 空间复杂度：`O(n)（返回切片；额外工作状态 O(1)）`。

共有 2n-1 个中心，最坏情况下每个中心扩张 O(n)，总时间 O(n²)；扩张只使用索引，但最终返回的子串切片占 O(n)。

## C++ 实现

> 实现来源：代码随想录（programmercarl.com）



```cpp
class Solution {
public:
    string longestPalindrome(string s) {
        vector<vector<int>> dp(s.size(), vector<int>(s.size(), 0));
        int maxlenth = 0;
        int left = 0;
        int right = 0;
        for (int i = s.size() - 1; i >= 0; i--) {
            for (int j = i; j < s.size(); j++) {
                if (s[i] == s[j]) {
                    if (j - i <= 1) { // 情况一 和 情况二
                        dp[i][j] = true;
                    } else if (dp[i + 1][j - 1]) { // 情况三
                        dp[i][j] = true;
                    }
                }
                if (dp[i][j] && j - i + 1 > maxlenth) {
                    maxlenth = j - i + 1;
                    left = i;
                    right = j;
                }
            }

        }
        return s.substr(left, right - left + 1);
    }
};
```

```go
func longestPalindrome(s string) string {
    maxLen := 0
    left := 0
    length := 0
    dp := make([][]bool, len(s))
    for i := 0; i < len(s); i++ {
        dp[i] = make([]bool,len(s))
    }
    for i := len(s)-1; i >= 0; i-- {
        for j := i; j < len(s); j++ {
            if s[i] == s[j]{
                if j-i <= 1{ // 情况一和情况二
                    length = j-i
                    dp[i][j]=true
                }else if dp[i+1][j-1]{ // 情况三
                    length = j-i
                    dp[i][j] = true
                }
            }
        }
        if length > maxLen {
            maxLen = length
            left = i
        }
    }
    return s[left: left+maxLen+1]
}
```

//初始化dp数组，全部初始为false
bool **initDP(int strLen) {
    bool **dp = (bool **)malloc(sizeof(bool *) * strLen);
    int i, j;
    for(i = 0; i < strLen; ++i) {
        dp[i] = (bool *)malloc(sizeof(bool) * strLen);
        for(j = 0; j < strLen; ++j)
            dp[i][j] = false;
    }
    return dp;
}
