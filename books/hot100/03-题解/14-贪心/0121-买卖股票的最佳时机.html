121. 买卖股票的最佳时机

难度简单
Java 主方法维护历史最低价时间O(n)空间O(1)
Python 主方法历史最低价一次扫描时间O(n)空间O(1)

题目与约束

给定一个数组 prices ，它的第 i 个元素 prices[i] 表示一支给定股票第 i 天的价格。

你只能选择 某一天 买入这只股票，并选择在 未来的某一个不同的日子 卖出该股票。设计一个算法来计算你所能获取的最大利润。

返回你可以从这笔交易中获取的最大利润。如果你不能获取任何利润，返回 0 。

示例 1：

输入：[7,1,5,3,6,4]
输出：5
解释：在第 2 天（股票价格 = 1）的时候买入，在第 5 天（股票价格 = 6）的时候卖出，最大利润 = 6-1 = 5 。
注意利润不能是 7-1 = 6, 因为卖出价格需要大于买入价格；同时，你不能在买入前卖出股票。

示例 2：

输入：prices = [7,6,4,3,1]
输出：0
解释：在这种情况下, 没有交易完成, 所以最大利润为 0。

提示：

  • 1 <= prices.length <= 105
  • 0 <= prices[i] <= 104

Java 完整推导

Java 核心不变量

卖出当天只需要此前最低买入价。

完整推导

思路推导

  1. 直觉与痛点（先知模式的失败）：

    最暴力的做法是用两层 for 循环：第一层遍历买入的时间，第二层遍历卖出的时间，找出差值最大的。时间复杂度 O(N2)，在庞大的股市数据前必定超时。

    还有同学试图找“全局最低点”和“全局最高点”，但如果全局最高点出现在全局最低点之前呢？（比如 [7, 1]，你不能在第 2 天花 1 块钱买，然后穿越回第 1 天按 7 块钱卖）。

  2. 破局思路（底线思维 / 贪心策略）：

    我们换一种思维：假设我必须在今天卖出，那我能赚多少钱？

    显然，只要我在今天之前出现过的最低价格买入，我今天卖出的利润就是最大的！

    所以，随着时间（游标）一天天往后走，我们根本不需要两层循环，只需要在遍历的过程中，死死记住两件事：

    • minPrice（历史最低价）：如果今天跌破了历史最低价，我就更新它（作为未来可能的买入点）。
    • maxProfit（历史最高利润）：如果今天没跌破历史最低价，我就算一下：如果今天卖，利润是多少（今天价格 - 历史最低价）？如果这个利润比我之前算出来的利润还要高，我就更新 maxProfit。

    Java 实现（满分一次遍历版）

class Solution {
    public int maxProfit(int[] prices) {
        // 边界防御：如果只有不到 2 天，根本没法买卖
        if (prices == null || prices.length < 2) {
            return 0;
        }

        // 记录历史最低价格，初始值设为第一天的价格（或者 Integer.MAX_VALUE）
        int minPrice = prices[0];
        // 记录历史最大利润，初始值为 0（即便亏本大不了我不操作，利润就是 0）
        int maxProfit = 0;

        // 时光游标，从第二天开始一天天往后走
        for (int i = 1; i < prices.length; i++) {
            // 如果今天的价格比历史最低价还要低，说明今天绝不是卖出的好时机，而是未来可能买入的好时机
            if (prices[i] < minPrice) {
                minPrice = prices[i];
            }
            // 如果今天的价格没跌破底线，那我就试试今天卖出会怎样
            else {
                int currentProfit = prices[i] - minPrice;
                // 如果今天卖出的利润，比我之前记录的最大利润还要高，那就更新最高纪录！
                if (currentProfit > maxProfit) {
                    maxProfit = currentProfit;
                }
            }
        }

        return maxProfit;
    }
}

复杂度

  • 时间复杂度：O(N)。我们只需要让时间游标顺着数组走一遍，每一步只做极简单的比较和减法运算，性能拉满。
  • 空间复杂度：O(1)。仅仅用了 minPrice 和 maxProfit 两个整型变量，完全是常数级别的空间开销。
易错点与扩展（面试的连环计）
  1. 面试追问 1：“如果我允许你买卖【无数次】，也就是买完可以卖，卖完立刻又能买，只要能赚差价就行，代码怎么改？”（对应力扣 122 题：买卖股票的最佳时机 II） - 满分抢答（贪心极致）：如果是买卖无数次，那就极其简单了！我们只需要关注相邻两天的价格差。只要明天的价格比今天高，我们就在今天买、明天卖，把所有微小的上涨波段全部吃掉（即使是 A -> B -> C 的连续上涨，B-A + C-B 也完美等于 C-A）。 - 代码只需一行核心逻辑：if (prices[i] > prices[i-1]) profit += prices[i] - prices[i-1];。
  2. 面试追问 2：“这道题除了贪心，还有没有更系统的解法？” - 架构师级回答：这道题最正统的底层思想其实是状态机 DP（动态规划）。 - 我们可以定义一个二维数组 dp[i][0] 表示第 i 天手里【没有】股票时的最大现金，dp[i][1] 表示第 i 天手里【持有】股票时的最大现金。 - 虽然在这道题里用 DP 显得有些杀鸡用牛刀（因为它可以被压缩成上面那种贪心写法），但只要掌握了这种 DP 状态机的写法，后面那些什么“最多买卖 K 次”、“带手续费”、“带冷冻期”的股票 Hard 题，全都可以用同一个模板闭眼秒杀！

Python 完整推导

必须在卖出日之前先买入

暴力枚举买卖两天需要平方时间。换一个视角：假设今天一定卖出，最优买入日就是此前所有日期里价格最低的一天。于是扫描时只要记住“已经见过的最低价”，就能立刻算出今天卖出能获得的最佳利润。

这个变量不能换成“全数组最低价”，因为买入日必须早于卖出日。当前价格更新历史低价后，只能用于之后的日期；先计算今天的利润，再更新最低价，顺序与时间方向一致。

用 [7, 1, 5, 3, 6, 4] 走一遍

代码先设下标 0 的 7 为 lowest，再把 best 设为 0；下标 0 不进入循环。

  1. 下标 1 的价格是 1：今天卖出的收益为 1 - 7 = -6，不能改善空交易的 0；随后 lowest 更新为 1。
  2. 下标 2 的价格是 5：在最低价 1 买入、今天卖出，收益 4，刷新 best = 4。
  3. 下标 3 的价格是 3：收益为 2，不刷新。
  4. 下标 4 的价格是 6：收益为 5，best 更新为 5。
  5. 下标 5 的价格是 4：收益为 3，最终仍返回 5。

若价格持续下降，例如 [7, 6, 4, 3, 1]，每次候选收益都小于 0，始终保留 0，表示可以选择不交易。

Python 实现

参考来源：代码随想录（programmercarl.com）

沿用旧项目收录的《代码随想录》历史最低价贪心代码；初始化改为第一天价格，并整理循环变量与注释。

from typing import List


class Solution:
    def maxProfit(self, prices: List[int]) -> int:
        lowest = prices[0]
        best = 0
        for index in range(1, len(prices)):
            price = prices[index]
            best = max(best, price - lowest)
            lowest = min(lowest, price)
        return best

min 与 max 分别守什么

best = max(best, price - lowest) 表示比较“此前已有最佳收益”和“今天卖出”的收益。lowest = min(lowest, price) 随后把今天纳入未来可能的买入日。

本题保证至少一天价格。用第一天的价格初始化 lowest，比为 inf 更直观；循环从第二天开始，避免同一天买卖这种无意义的候选。

边界

只有一天时循环不执行，返回 0。收益变量初始为 0，因为允许不交易；即使出现更低价，也不会返回负数。

复杂度

  • 时间复杂度：O(n)。
  • 空间复杂度：O(1)。

只从第二个价格扫描一次，每天做一次减法和两次比较；除几个标量外不创建额外数据结构。

C++ 实现

实现来源：代码随想录（programmercarl.com）

class Solution {
public:
    int maxProfit(vector<int>& prices) {
        int result = 0;
        for (int i = 0; i < prices.size(); i++) {
            for (int j = i + 1; j < prices.size(); j++){
                result = max(result, prices[j] - prices[i]);
            }
        }
        return result;
    }
};

Go 实现

实现来源：代码随想录（programmercarl.com）

func maxProfit(prices []int) int {
    min := prices[0]
    res := 0
    for i := 1; i < len(prices); i++ {
        if prices[i] - min > res {
            res = prices[i]-min
        }
        if min > prices[i] {
            min = prices[i]
        }
    }
    return res
}

C 实现

实现来源：站内标准实现

int maxProfit(int* prices, int pricesSize) {
    int minPrice = prices[0], ans = 0;
    for (int i = 1; i < pricesSize; ++i) {
        if (prices[i] < minPrice) minPrice = prices[i];
        else if (prices[i] - minPrice > ans) ans = prices[i] - minPrice;
    }
    return ans;
}
