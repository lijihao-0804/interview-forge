763. 划分字母区间

← 贪心专题 · 总目录 · 复习清单

难度中等
Java 主方法最后出现位置时间O(n)空间O(字符集)
Python 主方法最后出现位置 + 片段最远边界时间O(n)空间O(字符集)

题目与约束

给你一个字符串 s 。我们要把这个字符串划分为尽可能多的片段，同一字母最多出现在一个片段中。例如，字符串 "ababcc" 能够被分为 ["abab", "cc"]，但类似 ["aba", "bcc"] 或 ["ab", "ab", "cc"] 的划分是非法的。

注意，划分结果需要满足：将所有划分结果按顺序连接，得到的字符串仍然是 s 。

返回一个表示每个字符串片段的长度的列表。

示例 1：

输入：s = "ababcbacadefegdehijhklij"
输出：[9,7,8]
解释：
划分结果为 "ababcbaca"、"defegde"、"hijhklij" 。
每个字母最多出现在一个片段中。
像 "ababcbacadefegde", "hijhklij" 这样的划分是错误的，因为划分的片段数较少。

示例 2：

输入：s = "eccbbbbdec"
输出：[10]

提示：

  • 1 <= s.length <= 500
  • s 仅由小写英文字母组成

Java 完整推导

Java 核心不变量

当前片段结束位置是片段内所有字符最后位置的最大值。

完整推导

思路推导

  1. 直觉与痛点（不可分割的羁绊）：

    题目要求“同一个字母最多只能出现在一个片段中”。这意味着，如果你在片段里包容了字符 'a'，那么这个字符串里所有的 'a' 都必须被强行拉进这个片段里，一个都不能少！

    痛点：如果你边看边切，走到 'a' 刚想切一刀，结果发现后面很远的地方还有一个 'a'，你之前的切割就全部作废了。

  2. 破局思路（先做背调，再划结界）：

    既然我们要保证包含所有的同类字符，我们为什么不先对所有字符做一次“背景调查”？

    • 第一遍扫描：记录下每个字符在字符串中最后一次出现的索引（Deadline）。
    • 第二遍扫描：我们开始从头划定“结界”（用 start 和 end 两个指针）。

    当我们遍历到字符 c 时，查一下它的 Deadline 在哪。为了包容它，我们的当前片段结界 end 必须至少扩展到它的 Deadline。

    如果在扩展的途中，又遇到了其他字符（比如 'b'），且 'b' 的 Deadline 比当前结界还要远，那对不起，结界 end 只能被迫继续向后扩张！

  3. 核心微操（贪心结算的瞬间）：

    什么时候这个结界算彻底稳固了？

    当你遍历的当前索引 i，恰好等于当前结界的极限边界 end 时！

    这说明什么？说明在这个结界里，所有的字符都已经齐聚一堂，没有任何一个字符的“分身”流落在结界之外了！此时果断手起刀落，切出一段，然后开启下一个新结界。

    Java 实现（满分两次遍历版）

import java.util.ArrayList;
import java.util.List;

class Solution {
    public List<Integer> partitionLabels(String s) {
        // 1. 战前背调：记录每个字符最后一次出现的位置（Deadline）
        // 因为全是小写字母，用长度为 26 的数组完美替代 HashMap，极致提速
        int[] last = new int[26];
        for (int i = 0; i < s.length(); i++) {
            last[s.charAt(i) - 'a'] = i;
        }

        List<Integer> partitions = new ArrayList<>();
        int start = 0; // 当前片段的起始位置
        int end = 0;   // 当前片段的最远边界（结界）

        // 2. 遍历字符串，动态扩张结界
        for (int i = 0; i < s.length(); i++) {
            // 当前字符的 Deadline 可能会迫使我们的结界向后扩张
            end = Math.max(end, last[s.charAt(i) - 'a']);

            // 🌟 贪心高光时刻：游标 i 终于追赶上了结界的极限！
            // 说明 [start, end] 区间内的所有字符，都没有出现在这个区间之外
            if (i == end) {
                // 结算当前片段的长度
                partitions.add(end - start + 1);
                // 为下一个片段初始化起点
                start = i + 1;
            }
        }

        return partitions;
    }
}

复杂度

  • 时间复杂度：O(N)。我们仅仅对字符串进行了两次完整的遍历。第一次找最后出现位置，第二次计算区间，非常完美的线性时间。
  • 空间复杂度：O(1)。或者说是 O(Σ)，其中 Σ=26 是字符集的大小。数组 last 永远只占 26 个整型空间，与字符串长度无关。
易错点与扩展（面试的底层逻辑）
  • 面试追问：“这道题其实是另一道极其经典的 Hard / Medium 题的特殊降维版，你能看出来是哪道题吗？”（对应力扣 56 题：合并区间）
  • 满分架构师级回答：这道题本质上就是“合并区间”！
  • 我们记录每个字符的第一次出现位置 first 和最后出现位置 last，那么每个字符就变成了一个区间 [first, last]。
  • 字符串里有 26 个字符，就等于有 26 个区间。题目要求“同一字母最多出现在一个片段中”，翻译过来就是：把所有有交集的区间全部合并起来！合并后剩下了几个互不相交的大区间，就是我们切出的片段。
  • 只不过因为字符串遍历的天然有序性，我们省略了显式构建区间并对区间排序的过程，直接在第二遍遍历中用 end = Math.max 隐式地完成了区间合并！点破这层本质，面试官会直接对你刮目相看。

Python 完整推导

每个字符都有自己的“最后期限”

如果当前片段包含字符 a，字符串后面出现的每个 a 都必须被拉进同一个片段，否则同一个字母就跨越了两个片段。先记录每个字符最后一次出现的位置，第二遍扫描时就能知道当前片段最少要延伸到哪里。

维护 start 表示当前片段起点，end 表示为了容纳已经遇到的字符必须延伸到的右端。遇到字符 ch 时，用它的最后位置扩大 end；当扫描下标 index 追上了 end，说明片段内所有字符的最后一次出现都已经包进来，可以切分。

用 "ababcbacadefegdehijhklij" 看前两段

先记录 a:8, b:5, c:7。从下标 0 开始：

  1. 下标 0 是 a，end 扩到 8。
  2. 下标 1 是 b，最后位置 5 没有超过 8；随后遇到的 c 最后位置 7 也没超过 8。
  3. 在这段中间再次遇到 a、b、c，它们的最后期限都已经包含在 8 以内。
  4. 扫描到下标 8 时 index == end，切出长度 8 - 0 + 1 = 9，当前片段为 ababcbaca。
  5. 新片段从下标 9 开始。d、e 会把 end 推到最后下标 15，扫描到 15 时切出第二段长度 7。
  6. 剩下的 hijhklij 共同延伸到下标 23，最后切出长度 8。

结果为 [9, 7, 8]。end 取的是片段内所有字符最后位置的最大值，而不是当前字符自己的最后位置；这是扫描能继续扩张边界的核心。

Python 实现

参考来源：代码随想录（programmercarl.com）

沿用旧项目收录的《代码随想录》Python 两遍扫描实现；字典建立方式、变量和注释按本页整理。

from typing import List


class Solution:
    def partitionLabels(self, s: str) -> List[int]:
        last = {}
        for index, ch in enumerate(s):
            last[ch] = index

        answer = []
        start = 0
        end = 0
        for index, ch in enumerate(s):
            end = max(end, last[ch])
            if index == end:
                answer.append(end - start + 1)
                start = index + 1
        return answer

两遍扫描分别在做什么

第一遍用 enumerate(s) 建立字符到最后下标的字典。后出现的同字符会覆盖旧下标，覆盖后的值正好是最终需要记录的最后位置。

第二遍又在原字符串上扫描。end = max(end, last[ch]) 把当前字符的最后位置与片段已有右端合并。只有 index == end 才结算，因为如果 index < end，区间内仍可能有字符没被检查。

切分后的状态

记录长度后把 start = index + 1，而不是 start += 1。当前片段可能有很多字符，新片段必须从刚切掉区间之后开始。字典大小为字符集大小；若字符集固定，可视为 O(1) 额外空间。

复杂度

  • 时间复杂度：O(n)。
  • 空间复杂度：O(字符集)。

两遍都只扫描字符串一次，字典操作按平均 O(1) 计；字典最多保存字符集大小的键，输出不计入。

C++ 实现

实现来源：代码随想录（programmercarl.com）

class Solution {
public:
    vector<int> partitionLabels(string S) {
        int hash[27] = {0}; // i为字符，hash[i]为字符出现的最后位置
        for (int i = 0; i < S.size(); i++) { // 统计每一个字符最后出现的位置
            hash[S[i] - 'a'] = i;
        }
        vector<int> result;
        int left = 0;
        int right = 0;
        for (int i = 0; i < S.size(); i++) {
            right = max(right, hash[S[i] - 'a']); // 找到字符出现的最远边界
            if (i == right) {
                result.push_back(right - left + 1);
                left = i + 1;
            }
        }
        return result;
    }
};

Go 实现

实现来源：代码随想录（programmercarl.com）

func partitionLabels(s string) []int {
    var res []int;
    var marks [26]int;
    size, left, right := len(s), 0, 0;
    for i := 0; i < size; i++ {
        marks[s[i] - 'a'] = i;
    }
    for i := 0; i < size; i++ {
        right = max(right, marks[s[i] - 'a']);
        if i == right {
            res = append(res, right - left + 1);
            left = i + 1;
        }
    }
    return res;
}

C 实现

实现来源：站内标准实现

int* partitionLabels(char* s, int* returnSize) {
    int len = strlen(s);
    int last[26] = {0};
    for (int i = 0; i < len; ++i) last[s[i] - 'a'] = i; // 每字符最后出现位置
    int* ans = malloc(sizeof(int) * len);
    *returnSize = 0;
    int start = 0, end = 0;
    for (int i = 0; i < len; ++i) {
        if (last[s[i] - 'a'] > end) end = last[s[i] - 'a'];
        if (i == end) { // 当前片段已涵盖所有成员的最远位置
            ans[(*returnSize)++] = end - start + 1;
            start = i + 1;
        }
    }
    return ans;
}
