## 题目与约束

给你一个按照非递减顺序排列的整数数组 `nums` 和一个目标值 `target`，请找出 `target` 在数组中的起始位置和结束位置。如果数组中不存在 `target`，返回 `[-1, -1]`。

请设计并实现时间复杂度为 `O(log n)` 的算法。

**示例 1：**

**输入：**nums = [5,7,7,8,8,10], target = 8<br>**输出：**[3,4]

**示例 2：**

**输入：**nums = [5,7,7,8,8,10], target = 6<br>**输出：**[-1,-1]

**示例 3：**

**输入：**nums = [], target = 0<br>**输出：**[-1,-1]

**提示：**

- `0 <= nums.length <= 10^5`
- `-10^9 <= nums[i] <= 10^9`
- `nums` 按非递减顺序排列。
- `-10^9 <= target <= 10^9`

## 完整推导

### 思路推导

找到一个 `target` 后向两侧线性扫描，重复值很多时会退化为 `O(n)`。更直接的做法是执行两次二分查找，每次都在命中后记录答案，并继续把搜索区间推向一侧：

1. 找左边界：首次命中 `target` 后记录下标，并令 `right = mid - 1`，继续在左半区查找更靠左的命中位置。
2. 找右边界：首次命中 `target` 后记录下标，并令 `left = mid + 1`，继续在右半区查找更靠右的命中位置。
3. 任一方向都没有命中时，答案保持为 `-1`；两个结果组成 `[first, last]`。

每轮仍按普通闭区间二分更新 `[left, right]`。关键差异只在命中时不立即返回：先保存 `mid`，再按本轮目标方向排除已经检查过的位置。这样既不会漏掉边界，也不需要额外扫描。

### Java 实现

```java
class Solution {
    public int[] searchRange(int[] nums, int target) {
        int first = findBound(nums, target, true);
        int last = findBound(nums, target, false);
        return new int[]{first, last};
    }

    private int findBound(int[] nums, int target, boolean isFirst) {
        int left = 0;
        int right = nums.length - 1;
        int ans = -1;

        while (left <= right) {
            int mid = left + (right - left) / 2;

            if (nums[mid] == target) {
                ans = mid;
                if (isFirst) {
                    right = mid - 1;
                } else {
                    left = mid + 1;
                }
            } else if (nums[mid] > target) {
                right = mid - 1;
            } else {
                left = mid + 1;
            }
        }

        return ans;
    }
}
```

### 复杂度

左右边界各进行一次二分查找，时间复杂度为 `O(log n)`；只使用几个变量记录区间和答案，额外空间复杂度为 `O(1)`。

### 易错点与扩展

- 命中后要先保存 `mid`，再继续搜索；如果立即返回，只能得到任意一次命中，不能保证是边界。
- 找左边界时收缩右端（`right = mid - 1`）；找右边界时收缩左端（`left = mid + 1`）。方向写反会得到错误边界。
- 空数组时 `right` 初始为 `-1`，循环不会执行，`ans` 保持 `-1`，因此无需额外特判。

## Python 完整推导

### 命中一次还不够

普通二分命中 target 就返回，但重复值可能占一段连续区间。这段区间的左右端点都要找：左边界要继续在命中位置的左边看，右边界要继续在命中位置的右边看。

`find_bound` 复用同一个闭区间模板。区别只在 `nums[middle] == target` 时：`find_first=True` 执行 `right = middle-1`，把搜索推向更左；否则执行 `left = middle+1`，把搜索推向更右。之前命中的位置先存入 `bound`。

### 在 `[5,7,7,8,8,10]` 中找 8

找左边界时，即使中点命中 8，也把右边界移到中点左边，继续寻找更早的 8，最终 bound 停在 3。

找右边界时，同样命中也不停止，而是把左边界移到中点右边，最终 bound 停在 4。两个结果组成 `[3,4]`。

若目标不存在，左边界搜索结束后 bound 仍为 -1。此时已经能确定没有区间，直接返回 `[-1,-1]`，无需再做第二次二分。

在 `[2,2]` 查 2 时，左边界二分会把右侧 2 排除到只剩下标 0，右边界二分则把左侧 2 排除到只剩下标 1，最终得到 `[0,1]`。这段重复值正好验证两次二分的收缩方向，也说明不能命中后立即返回。若数组只有目标的一个值，两次 search 都会停在同一位置，结果仍是单点区间。

### Python 实现

> 参考来源：原收录经典实现（站内整理）
>
> 本题没有旧 Python 代码；依据项目原 Java 的两次边界二分整理为可执行 Python。source 表示原收录经典二分实现，source_note 明确说明为站内整理，未声称来自外部上游。

```python
from typing import List


class Solution:
    def searchRange(self, nums: List[int], target: int) -> List[int]:
        def find_bound(value, find_first):
            left = 0
            right = len(nums) - 1
            bound = -1

            while left <= right:
                middle = (left + right) // 2
                if nums[middle] < value:
                    left = middle + 1
                elif nums[middle] > value:
                    right = middle - 1
                else:
                    bound = middle
                    if find_first:
                        right = middle - 1
                    else:
                        left = middle + 1
            return bound

        first = find_bound(target, True)
        if first == -1:
            return [-1, -1]
        last = find_bound(target, False)
        return [first, last]
```

### 布尔模式让两个边界共用模板

`find_first` 只改变命中后的收缩方向，不改变比较 nums[middle] 与 value 的规则。左边界和右边界各扫描一次，不会共享循环中的下标。

闭区间模板保证空数组自然结束。`bound` 使用 -1 作为未命中标记；题目下标从 0 开始，因此不会与合法位置冲突。

### 复杂度

- 时间复杂度：`O(log n)`。
- 空间复杂度：`O(1)`。

每次 find_bound 都是标准二分，O(log n)；调用两次仍是 O(log n)。只保存左右下标与 bound，空间 O(1)。
