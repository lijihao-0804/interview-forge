4. 寻找两个正序数组的中位数

难度困难
Java 主方法短数组上二分分割线时间O(log min(m,n))空间O(1)
Python 主方法短数组上二分分割线时间O(log min(m,n))空间O(1)

题目与约束

给定两个大小分别为 m 和 n 的正序（从小到大）数组 nums1 和 nums2。请你找出并返回这两个正序数组的 中位数 。

算法的时间复杂度应该为 O(log (m+n)) 。

示例 1：

输入：nums1 = [1,3], nums2 = [2]
输出：2.00000
解释：合并数组 = [1,2,3] ，中位数 2

示例 2：

输入：nums1 = [1,2], nums2 = [3,4]
输出：2.50000
解释：合并数组 = [1,2,3,4] ，中位数 (2 + 3) / 2 = 2.5

提示：

  • nums1.length == m
  • nums2.length == n
  • 0 <= m <= 1000
  • 0 <= n <= 1000
  • 1 <= m + n <= 2000
  • -106 <= nums1[i], nums2[i] <= 106

Java 完整推导

Java 核心不变量

正确分割满足左半最大值不大于右半最小值。

完整推导

思路推导

  1. 直觉与痛点（二分到底在分什么？）：

    O(log(m+n)) 强制我们必须用二分。但是，两个数组错综复杂，我们该对谁做二分？二分的目标又是什么？

    痛点：如果你试图在两个数组里直接去“找”那个中位数的具体数值，你会陷入极其痛苦的边界比较中，因为你不知道这个数字到底在 nums1 还是 nums2 里。

  2. 降维破局（寻找那条“完美的割线”）：

    中位数的本质是什么？它是将一个集合划分为长度相等的上下两部分，并且上半部分的最大值 ≤ 下半部分的最小值。

    既然有两个数组，那我们就分别在 nums1 和 nums2 中各切一刀（划一条割线）。

    • 我们要求：左半边的元素总个数，恰好等于右半边的元素总个数（如果是奇数，让左边多一个）。
    • 这意味着，只要我们在 nums1 中切了一刀，由于总人数固定，nums2 中的那一刀也就自动确定了！

  3. 核心微操（交叉验证法）：

    假设 nums1 切在位置 i，nums2 切在位置 j。

    割线左边的两个元素我们叫 A_left 和 B_left，右边的叫 A_right 和 B_right。

    为了保证左半边全体 ≤ 右半边全体，由于数组本身是有序的，我们只需要交叉验证：

    • A_left <= B_right （A 的左边必须小于 B 的右边）

    • B_left <= A_right （B 的左边必须小于 A 的右边）

    二分逻辑：

    • 如果 B_left > A_right：说明 B 左边的数字太大了！这意味着我们在 B 里划的数字太多，而在 A 里划的数字太少。所以，A 的割线必须向右移（增大 i）。

    • 反之，向左移。当交叉验证通过时，我们就找到了那条完美的割线！

    Java 实现（满分虚拟极值版）

class Solution {
    public double findMedianSortedArrays(int[] nums1, int[] nums2) {
        // 🌟 核心技巧 1：保证 nums1 永远是那个比较短的数组！
        // 因为我们在较短的数组上做二分，不仅速度更快，而且可以防止 nums2 越界
        if (nums1.length > nums2.length) {
            return findMedianSortedArrays(nums2, nums1);
        }

        int m = nums1.length;
        int n = nums2.length;

        // 分割线左边需要的总元素个数（向上取整，奇数时左边多一个）
        int totalLeft = (m + n + 1) / 2;

        // 在短数组 nums1 的区间 [0, m] 里寻找最完美的割线 i
        int left = 0;
        int right = m;

        while (left <= right) {
            // i 是 nums1 的割线位置（表示 nums1 左半边有 i 个元素）
            int i = left + (right - left) / 2;
            // j 是 nums2 的割线位置（剩下的元素全归 nums2 凑齐 totalLeft）
            int j = totalLeft - i;

            // 🌟 核心技巧 2：处理边界问题（利用无穷大/无穷小虚拟补位）
            // 如果切在最左边，左边没元素了，用 MIN_VALUE 代替；切在最右边，用 MAX_VALUE 代替
            int A_left  = (i == 0) ? Integer.MIN_VALUE : nums1[i - 1];
            int A_right = (i == m) ? Integer.MAX_VALUE : nums1[i];
            int B_left  = (j == 0) ? Integer.MIN_VALUE : nums2[j - 1];
            int B_right = (j == n) ? Integer.MAX_VALUE : nums2[j];

            // 交叉验证
            if (A_left <= B_right && B_left <= A_right) {
                // 完美割线找到了！
                // 如果总长度是奇数，中位数就是左半边的最大值
                if ((m + n) % 2 != 0) {
                    return Math.max(A_left, B_left);
                }
                // 如果总长度是偶数，中位数是 (左半边最大值 + 右半边最小值) / 2.0
                else {
                    return (Math.max(A_left, B_left) + Math.min(A_right, B_right)) / 2.0;
                }
            } else if (B_left > A_right) {
                // B 的左边太大了，A 的割线必须往右走，多吃一点元素进来
                left = i + 1;
            } else {
                // A 的左边太大了，A 的割线必须往左走
                right = i - 1;
            }
        }

        return 0.0; // 正常情况下代码不会走到这里
    }
}

复杂度

  • 时间复杂度：O(log(min(m,n)))。由于我们强制对较短的数组进行二分查找，查找空间就是 min(m,n)，完全符合题目的极致性能要求。
  • 空间复杂度：O(1)。我们仅仅用了几个游标变量来记录割线和边缘的数值。
易错点与扩展（面试生死狙击）
  1. 踩坑警告：为什么要写 totalLeft = (m + n + 1) / 2？ - 这个 +1 是个极其精妙的数学统筹。 - 假设总长度是偶数（例如 4），(4 + 1) / 2 = 2，左半边分到 2 个。 - 假设总长度是奇数（例如 5），(5 + 1) / 2 = 3，左半边分到 3 个。 - 它完美地统一了奇偶数情况，并且保证了当长度为奇数时，中位数永远只会出现在左半边的最大值里（即 Math.max(A_left, B_left)），省去了极多冗余的条件判断。
  2. 面试追问：“遇到数组极度倾斜（比如 A 为空，或者 A 完全大于 B），这个算法会越界报错吗？” - 满分抢答（优雅的哨兵模式）：绝不会报错！因为我们采用了 Integer.MIN_VALUE 和 Integer.MAX_VALUE 作为“哨兵（Sentinel）”。 - 比如 A 如果一刀切在最左侧（i = 0），意味着 A 没有任何元素分给左半边。程序直接给 A_left 赋值为负无穷，负无穷去比较任何真实的数字，都会顺利通过 <= B_right 的交叉验证。这正是工业级代码对于“边界消解”的最高级手法！

Python 完整推导

不去合并，只寻找一条正确的分割线

合并两个数组当然能得到中位数，但会额外使用 O(m+n) 空间，也浪费两个数组已经有序的条件。换一种看法：把合并后的序列从中间切开，左边元素数固定，并且左边最大值不大于右边最小值。

设总长是 m+n，左半需要 half=(m+n+1)//2 个元素。若短数组 nums1 的左半取前 i 个，长数组 nums2 就必须取前 j=half-i 个。我们只二分 i；j 随它确定。

用 [1,3] 与 [2,4] 走一遍

总长 4，half=2，nums1 的 i 在 0 到 2 之间尝试。

  1. i=1、j=1。两侧分割值分别是 left1=1、right1=3、left2=2、right2=4。左侧目前是 [1,2]，右侧是 [3,4]。
  2. 检查交叉边界：1 <= 4 成立，2 <= 3 也成立，所以分割有效。
  3. 总长为偶数，中位数是左最大 2 与右最小 3 的平均值，即 2.5。

如果左侧最大来自 nums1 且大于 nums2 的右侧最小，说明 nums1 左边取得太多，i 要左移；相反情况则 i 要右移。

若一个数组为空，交换后短数组长度仍为 0，i 只能在 0 处；另一个数组的 left 与 right 由 half 和奇偶直接给出，哨兵分支会正确返回其中位数。

Python 实现

参考来源：经典解法实现

沿用项目旧 Python 的短数组分割线代码与旧 Java 的交叉边界推导；仅整理变量、导入与注释，移除未命中异常框架。

from typing import List


class Solution:
    def findMedianSortedArrays(self, nums1: List[int], nums2: List[int]) -> float:
        if len(nums1) > len(nums2):
            nums1, nums2 = nums2, nums1

        m, n = len(nums1), len(nums2)
        half = (m + n + 1) // 2
        left = 0
        right = m

        while left <= right:
            i = (left + right) // 2
            j = half - i
            left1 = nums1[i - 1] if i > 0 else float("-inf")
            right1 = nums1[i] if i < m else float("inf")
            left2 = nums2[j - 1] if j > 0 else float("-inf")
            right2 = nums2[j] if j < n else float("inf")

            if left1 <= right2 and left2 <= right1:
                if (m + n) % 2 == 1:
                    return float(max(left1, left2))
                return (max(left1, left2) + min(right1, right2)) / 2.0
            if left1 > right2:
                right = i - 1
            else:
                left = i + 1
        return 0.0

哨兵与 half 的奇偶统一

当 i=0 时，nums1 没有元素分在左半，left1=-inf 会自然输掉左最大比较；当 i=m 时，右半不存在 nums1 元素，right1=inf 会自然输掉右最小比较。空数组也可走同一逻辑。

half=(m+n+1)//2 在偶数时正好为一半，在奇数时让左半多一个；因此奇数总长直接返回 max(left1,left2)。两个正序数组的题目保证存在中位数，循环必然在某个合法分割处返回。

复杂度

  • 时间复杂度：O(log min(m,n))。
  • 空间复杂度：O(1)。

短数组长度为 m，分割位置在 [0,m] 上二分，时间 O(log m)=O(log min(m,n))；只保存分割下标与四个边界值，空间 O(1)。

C++ 实现

实现来源：经典解法实现

  1. 对两个数组二分找第 k 小：每次比较两数组各自第 k/2 个元素
  2. 较小的一方前 k/2 个不可能是第 k 小 → 整段排除，k 减半
  3. 最终在两数组总长一半处分割：中位数 = max(左半)/2 与 min(右半) 组合
class Solution {
public:
    double findMedianSortedArrays(vector<int>& a, vector<int>& b) {
        if (a.size() > b.size()) return findMedianSortedArrays(b, a);  // 保证 a 短
        int m = a.size(), n = b.size();
        int half = (m + n + 1) / 2;
        int lo = 0, hi = m;
        while (lo <= hi) {
            int i = (lo + hi) / 2, j = half - i;       // a 取前 i 个，b 取前 j 个
            int aL = i ? a[i-1] : INT_MIN, aR = i < m ? a[i] : INT_MAX;
            int bL = j ? b[j-1] : INT_MIN, bR = j < n ? b[j] : INT_MAX;
            if (aL <= bR && bL <= aR) {
                if ((m + n) % 2) return max(aL, bL);
                return (max(aL, bL) + min(aR, bR)) / 2.0;
            }
            aL > bR ? hi = i - 1 : lo = i + 1;
        }
        return 0;
    }
};

  2. 较小的一方前 k/2 个不可能是第 k 小 → 整段排除，k 减半

func findMedianSortedArrays(a []int, b []int) float64 {
    if len(a) > len(b) { a, b = b, a }
    m, n := len(a), len(b)
    half := (m + n + 1) / 2
    lo, hi := 0, m
    for lo <= hi {
        i := (lo + hi) / 2
        j := half - i
        aL, aR, bL, bR := math.MinInt, math.MaxInt, math.MinInt, math.MaxInt
        if i > 0 { aL = a[i-1] }
        if i < m { aR = a[i] }
        if j > 0 { bL = b[j-1] }
        if j < n { bR = b[j] }
        if aL <= bR && bL <= aR {
            if (m+n)%2 == 1 { return float64(max(aL, bL)) }
            return float64(max(aL, bL)+min(aR, bR)) / 2
        }
        if aL > bR { hi = i - 1 } else { lo = i + 1 }
    }
    return 0
}

C 实现

实现来源：经典解法实现

  1. 对两个数组二分找第 k 小：每次比较两数组各自第 k/2 个元素
  2. 较小的一方前 k/2 个不可能是第 k 小 → 整段排除，k 减半

double findMedianSortedArrays(int* a, int m, int* b, int n) {
    if (m > n) { int* t = a; a = b; b = t; int s = m; m = n; n = s; }
    int half = (m + n + 1) / 2, lo = 0, hi = m;
    while (lo <= hi) {
        int i = (lo + hi) / 2, j = half - i;
        int aL = i ? a[i-1] : INT_MIN, aR = i < m ? a[i] : INT_MAX;
        int bL = j ? b[j-1] : INT_MIN, bR = j < n ? b[j] : INT_MAX;
        if (aL <= bR && bL <= aR) {
            if ((m + n) % 2) return (double)fmax(aL, bL);
            return (fmax(aL, bL) + fmin(aR, bR)) / 2.0;
        }
        if (aL > bR) hi = i - 1; else lo = i + 1;
    }
    return 0;
}
