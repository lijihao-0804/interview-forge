35. 搜索插入位置

题目与约束

给定一个排序数组和一个目标值，在数组中找到目标值，并返回其索引。如果目标值不存在于数组中，返回它将会被按顺序插入的位置。

请必须使用时间复杂度为 O(log n) 的算法。

示例 1:

输入: nums = [1,3,5,6], target = 5
输出: 2

示例 2:

输入: nums = [1,3,5,6], target = 2
输出: 1

示例 3:

输入: nums = [1,3,5,6], target = 7
输出: 4

提示:

  • 1 <= nums.length <= 104
  • -104 <= nums[i] <= 104
  • nums 为 无重复元素的 升序排列数组
  • -104 <= target <= 104

Java 完整推导

Java 核心不变量

寻找第一个大于等于 target 的下标。

完整推导

思路推导

  1. 直觉与痛点（为什么不用 for 循环？）：

    一个 for 循环从头扫到尾，遇到第一个大于等于目标值的数字就返回它的索引。这叫线性查找，时间复杂度是 O(N)。在几千万的数据量下，会被面试立刻判为不合格。

    只要看到“有序数组”和“O(log n)”这两个关键词，你的大脑必须条件反射般地弹出四个大字：二分查找！

  2. 破局思路（逼近与夹击）：

    设两个指针，left 指向数组开头，right 指向数组末尾。

    每次算出中间位置 mid，拿 nums[mid] 和目标值 target 比大小：

    • 如果 nums[mid] == target，皆大欢喜，直接返回 mid。
    • 如果 nums[mid] < target，说明目标值在右半边，立刻让 left = mid + 1。
    • 如果 nums[mid] > target，说明目标值在左半边，立刻让 right = mid - 1。

  3. 核心微操（致命的边界与返回值）：

    最让人头疼的是：如果目标值不在数组里，循环结束时我该返回什么？

    黄金定律：当 while(left <= right) 循环打破时，left 和 right 必然错位（即 left = right + 1）。此时，right 指向的是最后一个小于 target 的元素，而 left 指向的是第一个大于 target 的元素！

    既然是要插入目标值，当然应该插在“第一个大于它的元素”的位置上。所以，永远返回 left！

    Java 实现（二分查找无死角模板）

class Solution {
    public int searchInsert(int[] nums, int target) {
        int left = 0;
        int right = nums.length - 1;

        // 🌟 核心细节 1：必须是 <=。因为当 left == right 时，那个唯一的元素还没被检查！
        while (left <= right) {
            // 🌟 核心细节 2：防溢出的 mid 写法
            // 不要写 (left + right) / 2，如果左右指针特别大，相加会超出 int 的最大范围
            int mid = left + (right - left) / 2;

            if (nums[mid] == target) {
                // 找到了，直接返回索引
                return mid;
            } else if (nums[mid] < target) {
                // 目标值在右边，把左边界拉过来
                left = mid + 1;
            } else {
                // 目标值在左边，把右边界拉过来
                right = mid - 1;
            }
        }

        // 🌟 核心细节 3：如果没找到，循环结束时 left 必然大于 right
        // 此时 left 指向的就是目标值理应插入的正确位置！
        return left;
    }
}

复杂度

  • 时间复杂度：O(log N)。每次循环都会砍掉一半的搜索空间。如果数组有 40 亿个数字，最多只需要找 32 次就能出结果！这就是二分查找的恐怖威力。
  • 空间复杂度：O(1)。我们仅仅用了 left、right 和 mid 三个整型变量，完全是原地操作。
易错点与扩展（进阶的底层细节）
  1. 踩坑警告：防溢出的 mid 写法 - 很多新手习惯写 int mid = (left + right) / 2;。在 LeetCode 早期，这个写法坑死了无数人。因为当 left 和 right 都是接近 2147483647 的大数字时，两者相加会直接变成负数，导致数组越界报错。 - 满分习惯：永远写成 int mid = left + (right - left) / 2;。或者在追求极致性能的面试（比如 C++ 岗），可以直接写位运算：int mid = left + ((right - left) >> 1);，面试官看了绝对会给你竖大拇指。
  2. 关键追问：“为什么插入位置一定是 left，不是 right？” - 闭上眼睛想象一下最后一步：此时 left == right，假设它们都指向数字 5，而你要找的 target 是 6。 - nums[mid] 是 5，比 6 小。程序会执行 left = mid + 1。 - 此时循环结束（left > right）。你看，left 已经往前走了一步，恰好指向了 5 的后面！这就完美地留出了插入 6 的空位。所以返回 left 绝对精准。

Python 完整推导

二分找“第一个不小于目标”的位置

题目要的不是单纯判断 target 在不在，而是找到它应该插入的下标。对有序数组来说，这个位置是第一个大于等于 target 的元素；若 target 比所有数都大，位置就是数组末尾 n。

用闭区间 [left,right]。若中点值小于 target，中点以及它左边都不可能是答案，left 移到中点右边；若中点值大于 target，中点本身可能是插入位置，但它的右侧都更大，因此只把 right 移到中点左边；相等时中点就是要找的位置。

用 [1,3,5,6] 搜 5 和 7

搜 5 时，初始 [0,3]，中点 1 的值是 3，小于 5，于是 left = 2。新区间 [2,3]，中点 2 的值正好是 5，直接返回 2。

搜 7 时，中点 1 的值 3 过小，left = 2；中点 2 的值 5 仍过小，left = 3；区间 [3,3] 中值为 6，仍过小，left = 4。此时 left > right，left 等于数组长度 4，表示把 7 放在末尾。

关键在最后的 left：它左边都已确认更小，而它当前位置及其右边都不小于 target，所以正好是插入缺口。

本题保证数组元素互不相同，所以命中 target 时直接返回它的位置即可。若推广到带重复值的输入，并要求插入下界，命中后还应继续压缩左边界，不能直接返回任意一个相等下标。

Python 实现

参考来源：代码随想录（programmercarl.com）

沿用项目旧 Python 的左闭右闭二分法和旧 Java 的插入下界推导；保留手写二分，没有换成 bisect 简写，变量与注释由本站整理。

from typing import List


class Solution:
    def searchInsert(self, nums: List[int], target: int) -> int:
        left = 0
        right = len(nums) - 1

        while left <= right:
            middle = (left + right) // 2
            if nums[middle] < target:
                left = middle + 1
            elif nums[middle] > target:
                right = middle - 1
            else:
                return middle
        return left

闭区间模板的配套动作

while left <= right 保证单元素区间仍会被检查。中点已经确认过大小时，可以安全地把它排除：小则 left = middle + 1，大则 right = middle - 1。

Python 整数没有固定位宽溢出问题，所以中点直接写 (left + right) // 2 即可。循环结束后 left 的取值可能为 0 到 n，涵盖插在最前和最后的情况。

复杂度

  • 时间复杂度：O(log n)。
  • 空间复杂度：O(1)。

每轮搜索区间长度至少减半，最坏 O(log n) 轮；只保存 left、right、middle，空间 O(1)。

C++ 实现

实现来源：代码随想录（programmercarl.com）

class Solution {
public:
    int searchInsert(vector<int>& nums, int target) {
        for (int i = 0; i < nums.size(); i++) {
        // 分别处理如下三种情况
        // 目标值在数组所有元素之前
        // 目标值等于数组中某一个元素
        // 目标值插入数组中的位置
            if (nums[i] >= target) { // 一旦发现大于或者等于target的num[i]，那么i就是我们要的结果
                return i;
            }
        }
        // 目标值在数组所有元素之后的情况
        return nums.size(); // 如果target是最大的，或者 nums为空，则返回nums的长度
    }
};

Go 实现

实现来源：代码随想录（programmercarl.com）

// 第一种二分法
func searchInsert(nums []int, target int) int {
    left, right := 0, len(nums)-1
    for left <= right {
        mid := left + (right-left)/2
        if nums[mid] == target {
            return mid
        } else if nums[mid] > target {
            right = mid - 1
        } else {
            left = mid + 1
        }
    }
    return right+1
}

C 实现

实现来源：代码随想录（programmercarl.com）

//版本一 [left, right]左闭右闭区间
int searchInsert(int* nums, int numsSize, int target){
    //左闭右开区间 [0 , numsSize-1]
        int left =0;
        int mid =0;
        int right = numsSize - 1;
        while(left <= right){//左闭右闭区间 所以可以 left == right
            mid = left + (right - left) / 2;
            if(target < nums[mid]){
        //target 在左区间 [left, mid - 1]中，原区间包含mid，右区间边界可以向左内缩
                right = mid -1;
            }else if( target > nums[mid]){
        //target 在右区间 [mid + 1, right]中,原区间包含mid，左区间边界可以向右内缩
                left = mid + 1;
            }else {
        // nums[mid] == target ，顺利找到target，直接返回mid
                return mid;
            }
        }
        //数组中未找到target元素
        //target在数组所有元素之后，[left, right]是右闭区间，需要返回 right +1
        return right + 1;
}
