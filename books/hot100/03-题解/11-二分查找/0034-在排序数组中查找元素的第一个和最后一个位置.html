34. 在排序数组中查找元素的第一个和最后一个位置

← 二分查找专题 · 总目录 · 复习清单

难度中等核心模式左右边界二分时间复杂度O(log n)空间复杂度O(1)

题目与约束

给你一个按照非递减顺序排列的整数数组 nums 和一个目标值 target，请找出 target 在数组中的起始位置和结束位置。如果数组中不存在 target，返回 [-1, -1]。

要求算法的时间复杂度为 O(log n)。

🔗 前往力扣原题验证 →

核心不变量

分别寻找第一个大于等于 target 和第一个大于 target 的位置。

完整推导

思路推导

这道题不应在找到一个 target 后向两侧线性扫描，因为重复值很多时会退化为 O(n)。可以把问题拆成两个相互独立的边界查询：

  1. 用一次二分查找找第一个大于等于 target 的位置，它就是左边界候选。
  2. 用一次二分查找找第一个大于 target 的位置，再向左退一格，就得到右边界。
  3. 如果左边界越界，或 nums[left] 不是 target，说明目标不存在。

二分过程中保持不变量：答案边界始终位于尚未排除的闭区间内。向左找边界时，命中目标仍继续收缩右端；向右找边界时，命中目标仍继续收缩左端。

Java 实现

class Solution {
    public int[] searchRange(int[] nums, int target) {
        int left = lowerBound(nums, target);
        if (left == nums.length || nums[left] != target) {
            return new int[]{-1, -1};
        }
        int right = upperBound(nums, target) - 1;
        return new int[]{left, right};
    }

    private int lowerBound(int[] nums, int target) {
        int lo = 0, hi = nums.length;
        while (lo < hi) {
            int mid = lo + (hi - lo) / 2;
            if (nums[mid] < target) {
                lo = mid + 1;
            } else {
                hi = mid;
            }
        }
        return lo;
    }

    private int upperBound(int[] nums, int target) {
        int lo = 0, hi = nums.length;
        while (lo < hi) {
            int mid = lo + (hi - lo) / 2;
            if (nums[mid] <= target) {
                lo = mid + 1;
            } else {
                hi = mid;
            }
        }
        return lo;
    }
}

复杂度

两次二分查找各访问 O(log n) 个位置，总时间复杂度为 O(log n)，只使用常数个变量，空间复杂度为 O(1)。

易错点与扩展
  • lowerBound 找的是第一个 >= target 的位置，不是任意一个命中位置。
  • upperBound 找的是第一个 > target 的位置，所以右边界必须减一。
  • 使用半开区间 [lo, hi) 可以自然处理空数组，并避免访问 nums[nums.length]。
