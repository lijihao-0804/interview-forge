难度中等核心模式左右边界二分时间复杂度O(log n)空间复杂度O(1)

题目与约束

给你一个按照非递减顺序排列的整数数组 nums 和一个目标值 target，请找出 target 在数组中的起始位置和结束位置。如果数组中不存在 target，返回 [-1, -1]。

请设计并实现时间复杂度为 O(log n) 的算法。

示例 1：

输入：nums = [5,7,7,8,8,10], target = 8
输出：[3,4]

示例 2：

输入：nums = [5,7,7,8,8,10], target = 6
输出：[-1,-1]

示例 3：

输入：nums = [], target = 0
输出：[-1,-1]

提示：

  • 0 <= nums.length <= 10^5
  • -10^9 <= nums[i] <= 10^9
  • nums 按非递减顺序排列。
  • -10^9 <= target <= 10^9

核心不变量

分别寻找第一个大于等于 target 和第一个大于 target 的位置。

完整推导

思路推导

找到一个 target 后向两侧线性扫描，重复值很多时会退化为 O(n)。更直接的做法是执行两次二分查找，每次都在命中后记录答案，并继续把搜索区间推向一侧：

  1. 找左边界：首次命中 target 后记录下标，并令 right = mid - 1，继续在左半区查找更靠左的命中位置。
  2. 找右边界：首次命中 target 后记录下标，并令 left = mid + 1，继续在右半区查找更靠右的命中位置。
  3. 任一方向都没有命中时，答案保持为 -1；两个结果组成 [first, last]。

每轮仍按普通闭区间二分更新 [left, right]。关键差异只在命中时不立即返回：先保存 mid，再按本轮目标方向排除已经检查过的位置。这样既不会漏掉边界，也不需要额外扫描。

Java 实现

class Solution {
    public int[] searchRange(int[] nums, int target) {
        int first = findBound(nums, target, true);
        int last = findBound(nums, target, false);
        return new int[]{first, last};
    }

    private int findBound(int[] nums, int target, boolean isFirst) {
        int left = 0;
        int right = nums.length - 1;
        int ans = -1;

        while (left <= right) {
            int mid = left + (right - left) / 2;

            if (nums[mid] == target) {
                ans = mid;
                if (isFirst) {
                    right = mid - 1;
                } else {
                    left = mid + 1;
                }
            } else if (nums[mid] > target) {
                right = mid - 1;
            } else {
                left = mid + 1;
            }
        }

        return ans;
    }
}

复杂度

左右边界各进行一次二分查找，时间复杂度为 O(log n)；只使用几个变量记录区间和答案，额外空间复杂度为 O(1)。

易错点与扩展
  • 命中后要先保存 mid，再继续搜索；如果立即返回，只能得到任意一次命中，不能保证是边界。
  • 找左边界时收缩右端（right = mid - 1）；找右边界时收缩左端（left = mid + 1）。方向写反会得到错误边界。
  • 空数组时 right 初始为 -1，循环不会执行，ans 保持 -1，因此无需额外特判。
