## 题目与约束

给定一个数组 `nums`，编写一个函数将所有 `0` 移动到数组的末尾，同时保持非零元素的相对顺序。

  **请注意** ，必须在不复制数组的情况下原地对数组进行操作。

  **示例 1:**

  **输入:** nums = `[0,1,0,3,12]`<br>**输出:** `[1,3,12,0,0]`

  **示例 2:**

  **输入:** nums = `[0]`<br>**输出:** `[0]`

  **提示**:

  - `1 <= nums.length <= 104`
  - `-231 <= nums[i] <= 231 - 1`

  **进阶：**你能尽量减少完成的操作次数吗？

## 完整推导

### 思路推导
  1. **直觉与痛点（开辟新数组）**：

     最简单的想法是新建一个同样大小的数组，遇到非零的数字就按顺序塞进去，剩下的空位自然全是 0。

     **痛点**：空间复杂度是 $O(N)$，违反了题目“原地修改”的硬性要求（空间复杂度必须为 $O(1)$）。

  2. **破局思路（快慢双指针）**：

     既然不能用新数组，我们就用**两个指针（游标）**在原数组上打配合：

     - **快指针 `fast`**：像前线侦察兵，负责遍历整个数组，寻找**非零元素**。

     - **慢指针 `slow`**：像后方收容所，它永远指向**下一个非零元素应该存放的位置**。

       一旦快指针找到一个非零元素，就把它和慢指针指向的值**交换**，然后慢指针前进一步。

  3. **逻辑推演（以 `nums = [0, 1, 0, 3, 12]` 为例）**：

     初始状态：`fast = 0`, `slow = 0`

     - `fast=0`，指向 `0`。是零，侦察兵跳过。

     - `fast=1`，指向 `1`。是非零！把它和 `slow` (索引0) 交换。数组变成 `[1, 0, 0, 3, 12]`。此时 `slow` 前进到 1。

     - `fast=2`，指向 `0`。跳过。

     - `fast=3`，指向 `3`。是非零！把它和 `slow` (索引1) 交换。数组变成 `[1, 3, 0, 0, 12]`。`slow` 前进到 2。

     - `fast=4`，指向 `12`。是非零！把它和 `slow` (索引2) 交换。数组变成 `[1, 3, 12, 0, 0]`。`slow` 前进到 3。

       遍历结束，所有的 0 自然被“挤”到了最后面。
### Java 实现
```java
class Solution {
    public void moveZeroes(int[] nums) {
        // 定义慢指针，记录下一个非零元素应该放置的位置
        int slow = 0;

        // fast 作为快指针，遍历整个数组
        for (int fast = 0; fast < nums.length; fast++) {
            // 当快指针发现非零元素时，执行交换操作
            if (nums[fast] != 0) {
                // 优化点：只有在 fast 和 slow 不相等时才交换，避免自己和自己交换的无用功
                // 只有当slow停在0之后两者才会不相等
                if (fast != slow) {
                    int temp = nums[fast];
                    nums[fast] = nums[slow];
                    nums[slow] = temp;
                }
                // 非零元素安顿好后，慢指针向后移动一位，准备接收下一个非零元素
                slow++;
            }
        }
    }
}
```
### 复杂度
  - **时间复杂度**：$O(N)$。快指针 `fast` 只需要把数组从头到尾遍历一次，每次交换操作都是 $O(1)$ 的时间。
  - **空间复杂度**：$O(1)$。只使用了两个额外的整型变量 `fast` 和 `slow`，完全是在原数组上进行操作。

### 易错点与扩展

1. **思路变体：覆写与补零法（另一种常见解法）**
   - **逻辑**：也是双指针，遇到非零元素不交换，而是直接**覆盖**到 `slow` 的位置。等 `fast` 遍历完，非零元素都排在前面了，最后再把 `slow` 之后的所有位置统一赋值为 `0`。
   - **优缺点对比**：覆写法的代码稍微简单一点点，但在**数组全是 0 的极端情况下**（例如 `[0,0,0,0,0]`），覆写法最后还要跑一个循环把所有位置赋值为 0，而我们目前写的**“交换法”**遇到全 0 数组时，`fast!=0` 的条件进不去，根本不会发生任何内存写操作，性能更优。
2. **高频追问：为什么这段代码不仅移动了 0，还能保证非零元素的“相对顺序”不乱？**
   - **回答**：因为我们的快指针是从左到右顺序扫描的。先遇到的非零元素，一定会先被塞到慢指针靠前的位置。这就好像在队列里把 0 剔除，剩下的元素自然会按原来的先后顺序往前补位。

这道题是双指针（对撞指针）的经典例题，也是面试中极大概率遇到的超级高频题。它完美展现了如何通过简单的数学逻辑，将 $O(N^2)$ 的暴力解法优化到 $O(N)$。

这道题的核心难点不在于写代码，而在于“证明为什么这么移动指针是正确的”。

## Python 完整推导

### 用一个慢位置保存下一个非零值

slow 指向下一个非零值应写入的位置。按原顺序读取数组，遇到非零值就写到 nums[slow]，然后让 slow 前进一步。

这一遍结束后，前缀 nums[:slow] 已按原顺序保存了全部非零值。再从 slow 到末尾逐项写 0，就得到目标数组。

### 用 [0, 1, 0, 3, 12] 走一遍

初始 slow = 0。

1. 读到 0，跳过。
2. 读到 1，写入 nums[0]，数组暂为 [1, 1, 0, 3, 12]，slow = 1。
3. 读到 0，跳过。
4. 读到 3，写入 nums[1]，数组暂为 [1, 3, 0, 3, 12]，slow = 2。
5. 读到 12，写入 nums[2]，数组暂为 [1, 3, 12, 3, 12]，slow = 3。

最后把下标 3、4 写成 0，得到 [1, 3, 12, 0, 0]。

### Python 实现

> 参考来源：灵茶山艾府题解（MIT License）
>
> 保留旧 Python 的非零覆盖与尾段清零实现，变量和注释有整理；算法未改变。

```python
from typing import List


class Solution:
    def moveZeroes(self, nums: List[int]) -> None:
        slow = 0
        for value in nums:
            if value != 0:
                nums[slow] = value
                slow += 1
        for index in range(slow, len(nums)):
            nums[index] = 0
```

### 为什么不会读到被覆盖的未来元素

slow 永远不大于当前读取位置。写回只会覆盖已经读过的位置，不会改动尚未读取的尾部。

- 全零时第一遍不写，slow 仍为 0，第二遍把整个数组写成 0。
- 全非零时第二遍从 len(nums) 开始，没有清零操作。
- 先覆盖、后补零，比切片赋值少一份长度为 n 的临时列表。

### 复杂度

- 时间复杂度：`O(n)`。
- 空间复杂度：`O(1)`。

第一遍读 n 个元素，第二遍最多清 n 个尾项，时间 O(n)；只使用 slow 与 index 等常数变量。

```cpp
class Solution {
public:
    void moveZeroes(vector<int>& nums) {
        int stack_size = 0;
        for (int x : nums) {
            if (x) {
                nums[stack_size++] = x; // 把 x 入栈
            }
        }
        fill(nums.begin() + stack_size, nums.end(), 0);
    }
};
```

func moveZeroes(nums []int) {
    stackSize := 0 // 另一种写法见【Go 写法二】
    for _, x := range nums {
        if x != 0 {
            nums[stackSize] = x // 把 x 入栈
            stackSize++
        }
    }
    clear(nums[stackSize:]) // nums[stackSize:] 所有元素置为 0
}

## C 实现

> 实现来源：灵茶山艾府题解（MIT License）



```c
void moveZeroes(int* nums, int numsSize) {
    int stackSize = 0;
    for (int i = 0; i < numsSize; i++) {
        if (nums[i]) {
            nums[stackSize++] = nums[i]; // 把 nums[i] 入栈
        }
    }
    // 其余位置填充 0
    memset(nums + stackSize, 0, (numsSize - stackSize) * sizeof(int));
}
```
