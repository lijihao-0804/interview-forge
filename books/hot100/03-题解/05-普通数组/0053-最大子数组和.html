题目与约束

给你一个整数数组 nums ，请你找出一个具有最大和的连续子数组（子数组最少包含一个元素），返回其最大和。

子数组是数组中的一个连续部分。

示例 1：

输入：nums = [-2,1,-3,4,-1,2,1,-5,4]
输出：6
解释：连续子数组 [4,-1,2,1] 的和最大，为 6 。

示例 2：

输入：nums = [1]
输出：1

示例 3：

输入：nums = [5,4,-1,7,8]
输出：23

提示：

  • 1 <= nums.length <= 105
  • -104 <= nums[i] <= 104

进阶：如果你已经实现复杂度为 O(n) 的解法，尝试使用更为精妙的 分治法 求解。

Java 完整推导

Java 核心不变量

前一段和为负时不值得被当前位置继承。

完整推导

思路推导

  1. 直觉与痛点（暴力枚举）：

    两层 for 循环，枚举所有的起点和终点，计算区间和。时间复杂度 O(N2)，在面对巨大数组时必然超时。

  2. 破局思路（“资产”与“负债”的贪心抉择）：

    假设我们正从左到右遍历数组，手里攒着一个“当前累加和 (currentSum)”。

    每走到一个新的数字面前，我们都面临一个关键追问：是要把它加入之前的队伍，还是让它自立门户？

    • 评判标准：看看我们手里的 currentSum 是正数还是负数。
    • 如果 currentSum > 0：它是资产。带着它，总和会变得更大。所以果断让新数字加入队伍。
    • 如果 currentSum <= 0：它是负债。带上它只会拖累新数字（哪怕新数字也是负数，加个负债只会更加负）。所以果断抛弃历史包袱，让新数字从自己开始“自立门户”。

  3. 逻辑推演（以 [-2, 1, -3, 4, -1, 2, 1, -5, 4] 为例）：

    • num = -2：起步，currentSum = -2，maxSum = -2。
    • num = 1：之前的 currentSum 是 -2（负债），果断抛弃！自立门户，currentSum 重新变成 1。maxSum 更新为 1。
    • num = -3：之前的 currentSum 是 1（资产），带着！currentSum = 1 + (-3) = -2。maxSum 还是 1。
    • num = 4：之前的 currentSum 是 -2（负债），抛弃！自立门户，currentSum 变成 4。maxSum 更新为 4。
    • num = -1：带着（因为 4 是资产）。currentSum = 3。
    • num = 2：带着。currentSum = 5。maxSum 更新为 5。
    • num = 1：带着。currentSum = 6。maxSum 更新为 6。
    • ……以此类推，最终找到最大和 6（对应子数组 [4, -1, 2, 1]）。

    Java 实现

class Solution {
    public int maxSubArray(int[] nums) {
        // 如果数组为空，理论上应该抛出异常，但力扣题目保证至少有 1 个元素

        // 记录当前的连续子数组和
        int currentSum = 0;
        // 记录全局见过的最大和，初始化为极小值（或直接用 nums[0]）
        int maxSum = Integer.MIN_VALUE;

        for (int num : nums) {
            // 核心抉择逻辑：
            // 如果历史累加和 <= 0，说明是“负债”，对后续的求和毫无帮助，直接丢弃，从当前数字重新开始。
            if (currentSum <= 0) {
                currentSum = num;
            } else {
                // 如果历史累加和 > 0，说明是“资产”，加上当前数字继续走。
                currentSum += num;
            }

            // 每次抉择完，都尝试去打破历史最高记录
            maxSum = Math.max(maxSum, currentSum);
        }

        return maxSum;
    }
}

复杂度

  • 时间复杂度：O(N)。我们只需要把数组从头到尾遍历一次即可，时间复杂度达到理论最优。
  • 空间复杂度：O(1)。全程只使用了两个变量 currentSum 和 maxSum，不需要额外开辟数组。
易错点与扩展
  1. 代码的极致精简版（动态规划视角）：
  • 上面的 if-else 是贪心思想的体现，如果在动态规划视角下，代码可以精简得连 if 都不需要：
int currentSum = 0, maxSum = nums[0];
for (int x : nums) {
    // 状态转移方程：要么自立门户 (x)，要么加入前驱 (currentSum + x)，取较大者
    currentSum = Math.max(currentSum + x, x);
    maxSum = Math.max(maxSum, currentSum);
}

 *这两种写法本质完全一样，但 `if-else` 的“资产/负债”说辞在面试时讲出来更容易让面试官眼前一亮。*
  1. 高频追问：“如果我还想知道这个最大子数组的具体起始和结束位置呢？”
  • 回答思路：只需要额外维护两个指针 start 和 end。当 currentSum <= 0 决定“自立门户”时，把临时起点 tempStart 更新为当前下标 i；当 currentSum > maxSum 破纪录时，把真正的 start 更新为 tempStart，把 end 更新为当前的下标 i。

Python 完整推导

以当前元素结尾，决定接续还是重开

current 表示必须以刚处理的元素结尾的最大子数组和。下一个 value 到来时只有两种选择：

  • 接在旧段后：current + value。
  • 从当前元素重新开始：value。

较大的那个就是新的 current。best 另外保存历史最大值。

用题目标例核对每一步

初始 current = best = -2。

当前值 新的 current 新的 best
1 max(1, -1) = 1 1
-3 max(-3, -2) = -2 1
4 max(4, 2) = 4 4
-1 max(-1, 3) = 3 4
2 max(2, 5) = 5 5
1 max(1, 6) = 6 6
-5 max(-5, 1) = 1 6
4 max(4, 5) = 5 6

最终 best=6，对应子数组 [4, -1, 2, 1]。

Python 实现

参考来源：代码随想录（programmercarl.com）

沿用旧 Python 的滚动子数组和思路，把转移写成等价的 max 形式并整理变量；算法未改变。

from typing import List


class Solution:
    def maxSubArray(self, nums: List[int]) -> int:
        current = best = nums[0]
        for index in range(1, len(nums)):
            value = nums[index]
            current = max(value, current + value)
            best = max(best, current)
        return best

首元素作为初始状态

题目保证数组非空，所以 current 和 best 都从 nums[0] 开始。若从 0 开始，全负数数组会错误地返回 0。

两个状态的职责

current 只回答“以当前下标结尾时，能取得的局部最大值”。best 负责全局最大值，所以 current 重新开始时，best 不跟着清零。

从第二个元素开始

循环从下标 1 开始，第一个元素已经进入初值。使用 range 遍历下标，也避免 nums[1:] 复制一份列表。

复杂度

  • 时间复杂度：O(n)。
  • 空间复杂度：O(1)。

从第二个下标扫描到末尾一次，每个位置常数次比较；只保留 current 与 best。

C++ 实现

实现来源：代码随想录（programmercarl.com）

class Solution {
public:
    int maxSubArray(vector<int>& nums) {
        int result = INT32_MIN;
        int count = 0;
        for (int i = 0; i < nums.size(); i++) { // 设置起始位置
            count = 0;
            for (int j = i; j < nums.size(); j++) { // 从起始位置i开始遍历寻找最大值
                count += nums[j];
                result = count > result ? count : result;
            }
        }
        return result;
    }
};

Go 实现

func maxSubArray(nums []int) int {
    max := nums[0]
    count := 0
    for i := 0; i < len(nums); i++ {
        count += nums[i]
        if count > max {
            max = count
        }
        if count < 0 {
            count = 0
        }
    }
    return max
}

C 实现

实现来源：代码随想录（programmercarl.com）

int maxSubArray(int* nums, int numsSize) {
    int result = nums[0];
    int dp = nums[0];
    for (int i = 1; i < numsSize; i++) {
        dp = (dp + nums[i]) > nums[i] ? (dp + nums[i]) : nums[i];
        result = result > dp ? result : dp;
    }
    return result;
}
