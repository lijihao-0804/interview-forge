56. 合并区间

← 普通数组专题 · 总目录 · 复习清单

难度中等核心模式排序 + 线性合并时间复杂度O(n log n)空间复杂度O(log n)

题目与约束

以数组 intervals 表示若干个区间的集合，其中单个区间为 intervals[i] = [starti, endi] 。请你合并所有重叠的区间，并返回 一个不重叠的区间数组，该数组需恰好覆盖输入中的所有区间 。

示例 1：

输入：intervals = [[1,3],[2,6],[8,10],[15,18]]
输出：[[1,6],[8,10],[15,18]]
解释：区间 [1,3] 和 [2,6] 重叠, 将它们合并为 [1,6].

示例 2：

输入：intervals = [[1,4],[4,5]]
输出：[[1,5]]
解释：区间 [1,4] 和 [4,5] 可被视为重叠区间。

示例 3：

输入：intervals = [[4,7],[1,4]]
输出：[[1,7]]
解释：区间 [1,4] 和 [4,7] 可被视为重叠区间。

提示：

  • 1 <= intervals.length <= 104
  • intervals[i].length == 2
  • 0 <= starti <= endi <= 104

核心不变量

每个新区间只需和结果中的最后一个区间比较。

完整推导

思路推导

  1. 直觉与痛点（无序的混乱）：

    如果区间是乱序的（比如先给你 [15,18]，再给你 [1,3]，最后给 [2,6]），你很难判断当前区间到底要和谁合并，因为能和它合并的区间可能在很后面。每次都要回头找，逻辑极其混乱。

  2. 破局思路（先排序，后贪心）：

    • 第一步（排序）：既然乱，我们就给它定个规矩。将所有区间按照“起点”从小到大排序。
    • 第二步（贪心合并）：排序后，所有能合并的区间一定都是连续挨在一起的！我们只需要拿一个“当前正在合并的区间（current）”，去和下一个区间比对。

  3. 逻辑推演（以 [[1,3], [2,6], [8,10], [15,18]] 为例，已排序）：

    • 准备：拿第一个区间 [1, 3] 作为 current，放入结果集。
    • 下一个是 [2, 6]：
    • 判断：它的起点 2 ≤ current 的终点 3，说明有重叠！
    • 合并：起点不用变，终点变成两者终点的最大值 max(3, 6) = 6。于是结果集里的 current 更新为 [1, 6]。
    • 下一个是 [8, 10]：
    • 判断：它的起点 8 > current 的终点 6，说明断开了，不可能再重叠了（因为后面的区间起点只会越来越大）。
    • 操作：把 [8, 10] 作为新的 current 放入结果集。
    • 下一个是 [15, 18]：同理，断开，作为新区间放入。

    C++ 实现

    实现来源：站内标准实现

    class Solution {
public:
    vector<vector<int>> merge(vector<vector<int>>& intervals) {
        sort(intervals.begin(), intervals.end());
        vector<vector<int>> ans;
        for (auto& p : intervals) {
            if (!ans.empty() && ans.back()[1] >= p[0])
                ans.back()[1] = max(ans.back()[1], p[1]);
            else
                ans.push_back(p);
        }
        return ans;
    }
};

    Python 实现

    实现来源：代码随想录（programmercarl.com）

    class Solution:
    def merge(self, intervals):
        result = []
        if len(intervals) == 0:
            return result
        # 按照区间的左边界进行排序
        intervals.sort(key=lambda x: x[0])
        # 第一个区间可以直接放入结果集中
        result.append(intervals[0])
        for i in range(1, len(intervals)):
            if result[-1][1] >= intervals[i][0]:  # 发现重叠区间
                # 合并区间，只需要更新右边界
                result[-1][1] = max(result[-1][1], intervals[i][1])
            else:
                result.append(intervals[i])  # 区间不重叠
        return result

    Go 实现

    实现来源：代码随想录（programmercarl.com）

    func merge(intervals [][]int) [][]int {
    sort.Slice(intervals, func(i, j int) bool {
        return intervals[i][0] < intervals[j][0]
    })
    res := make([][]int, 0, len(intervals))
    left, right := intervals[0][0], intervals[0][1]
    for i := 1; i < len(intervals); i++ {
        if right < intervals[i][0] {
            res = append(res, []int{left, right})
            left, right = intervals[i][0], intervals[i][1]
        } else {
            right = max(right, intervals[i][1])
        }
    }
    res = append(res, []int{left, right})
    return res
}
func max(a, b int) int {
    if a > b {
        return a
    }
    return b
}

    C 实现

    实现来源：站内标准实现

    int cmp(const void* a, const void* b) {
    return (*(int**)a)[0] - (*(int**)b)[0];
}

int** merge(int** intervals, int intervalsSize, int* intervalsColSize,
            int* returnSize, int** returnColumnSizes) {
    qsort(intervals, intervalsSize, sizeof(int*), cmp);
    int** ans = malloc(sizeof(int*) * intervalsSize);
    *returnColumnSizes = malloc(sizeof(int) * intervalsSize);
    *returnSize = 0;
    for (int i = 0; i < intervalsSize; ++i) {
        int l = intervals[i][0], r = intervals[i][1];
        if (*returnSize > 0 && ans[*returnSize - 1][1] >= l) {
            if (r > ans[*returnSize - 1][1]) ans[*returnSize - 1][1] = r;
        } else {
            ans[*returnSize] = malloc(sizeof(int) * 2);
            ans[*returnSize][0] = l;
            ans[*returnSize][1] = r;
            (*returnColumnSizes)[*returnSize] = 2;
            ++*returnSize;
        }
    }
    return ans;
}

import java.util.ArrayList;
import java.util.Arrays;
import java.util.List;

class Solution {
    public int[][] merge(int[][] intervals) {
        // 边界条件：如果没有区间，直接返回空
        if (intervals == null || intervals.length == 0) {
            return new int[0][0];
        }

        // 1. 灵魂操作：按区间的起点（start）从小到大进行排序
        // 注意：使用 Integer.compare 可以有效防止 a[0] - b[0] 导致的整型溢出风险
        Arrays.sort(intervals, (a, b) -> Integer.compare(a[0], b[0]));

        List<int[]> merged = new ArrayList<>();

        // 先把排序后的第一个区间放入结果集中，作为“当前合并区间”的初始基准
        merged.add(intervals[0]);

        // 2. 从第二个区间开始遍历
        for (int i = 1; i < intervals.length; i++) {
            // 获取当前正在试图扩充的区间（即结果集中的最后一个区间）
            int[] current = merged.get(merged.size() - 1);
            int[] next = intervals[i];

            // 3. 核心判断逻辑
            if (next[0] <= current[1]) {
                // 有重叠！更新当前区间的终点为两者的最大值
                // 为什么不更新起点？因为我们已经按起点排过序了，current 的起点一定是最小的
                current[1] = Math.max(current[1], next[1]);
            } else {
                // 没有重叠！说明 current 已经扩充到极限了，将 next 作为新的独立区间加入结果集
                merged.add(next);
            }
        }

        // 4. 将 List 转换为二维数组返回
        return merged.toArray(new int[merged.size()][]);
    }
}

复杂度

  • 时间复杂度：O(N log N)。遍历区间只需要 O(N) 的时间，但之前的排序步骤需要 O(N log N)。在算法中，取最高阶，因此总时间复杂度为 O(N log N)。
  • 空间复杂度：O(log N) 或 O(N)。取决于底层排序算法的空间开销（Java 中对象排序通常是 TimSort，基本类型是 Dual-Pivot Quicksort，有递归栈空间）。如果算上用来装结果的 merged 列表，最坏情况下不重叠的空间为 O(N)。
易错点与扩展（可能会被追问）
  1. 踩坑点：a[0] - b[0] 的溢出陷阱 - 很多人在写自定义比较器时喜欢偷懒写 (a, b) -> a[0] - b[0]。 - 面试官必问：如果 a[0] 是 -2147483648，b[0] 是 2147483647 呢？相减会产生整数溢出，导致排序完全错乱！ - 满分解法：老老实实写 Integer.compare(a[0], b[0])，这是极其专业且严谨的工程体现。
  2. 细微逻辑：为什么是取 max 而不是直接等于 next[1]？ - 假设有区间 [1, 5] 和 [2, 3]。排序后顺序是对的。 - 当合并时，2 <= 5 重叠了。此时终点应该是 max(5, 3) 也就是 5。[1, 5] 完全“吞噬”了 [2, 3]。如果直接等于 next[1]，终点反而会缩水变成 3。
