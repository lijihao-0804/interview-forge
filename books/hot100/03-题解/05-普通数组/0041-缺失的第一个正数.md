## 题目与约束

给你一个未排序的整数数组 `nums` ，请你找出其中没有出现的最小的正整数。

  `O(n)`

  **示例 1：**

  **输入：**nums = [1,2,0]<br>**输出：**3<br>**解释：**范围 [1,2] 中的数字都在数组中。

  **示例 2：**

  **输入：**nums = [3,4,-1,1]<br>**输出：**2<br>**解释：**1 在数组中，但 2 没有。

  **示例 3：**

  **输入：**nums = [7,8,9,11,12]<br>**输出：**1<br>**解释：**最小的正数 1 没有出现。

  **提示：**

  - `1 <= nums.length <= 105`
  - `-231 <= nums[i] <= 231 - 1`

## 完整推导

### 思路推导
  1. **直觉与痛点**：

     想找缺失的数字，直觉上放进 HashSet 里，然后从 1 开始往上数，谁不在 HashSet 里就是谁。但这样空间复杂度是 $O(N)$，不符合要求。

  2. **破局思路（鸽巢原理/萝卜一个坑）**：

     - 假设数组长度为 $N$。那么缺失的第一个正数**绝对不可能大于 $N+1$**。
       - *为什么？* 因为就算数组里塞满了最紧凑的正整数 `[1, 2, 3, ..., N]`，缺失的也就是 $N+1$。如果数组里有乱七八糟的负数或大数，缺失的数字只会更小。
     - 既然答案一定在 $[1, N]$ 这个范围内，我们手里刚好有一个长度为 $N$ 的数组！
     - **灵魂操作**：我们把数组本身当成一个哈希表！**让数字 `x` 回到它该去的索引位置 `x - 1` 上。**（即数字 1 放在索引 0，数字 2 放在索引 1... 数字 $N$ 放在索引 $N-1$）。

  3. **逻辑推演（以 `[3, 4, -1, 1]` 为例，N = 4）**：

     - 遍历数组：
     - 遇到 `3`：它应该待在索引 `2` 的位置。把它和索引 `2` 的数字（`-1`）交换。数组变成 `[-1, 4, 3, 1]`。
     - 遇到 `-1`：它是负数，直接无视（不属于 $[1, N]$ 的范围）。
     - 遇到 `4`：应该待在索引 `3`。把它和索引 `3` 的数字（`1`）交换。数组变成 `[-1, 1, 3, 4]`。
     - 新换过来的 `1`：应该待在索引 `0`。把它和索引 `0` 的数字（`-1`）交换。数组变成 `[1, -1, 3, 4]`。
     - 最后，遍历整理好的数组：
       - 索引 0 是 1（正确）
       - 索引 1 是 -1（**错误！这里本该是 2**）
       - 所以，缺失的最小正整数就是 `2`！
### Java 实现
```java
class Solution {
    public int firstMissingPositive(int[] nums) {
        int n = nums.length;

        // 第一步：原地哈希（把数字放到对应的索引坑位上）
        for (int i = 0; i < n; i++) {
            // 核心判断：
            // 1. nums[i] > 0 且 nums[i] <= n：只处理范围在 [1, n] 内的有效数字
            // 2. nums[nums[i] - 1] != nums[i]：目标位置上的数字如果和当前数字不一样，才需要交换
            // （注意这里必须用 while，因为换过来的新数字可能还需要继续被交换走）
            while (nums[i] > 0 && nums[i] <= n && nums[nums[i] - 1] != nums[i]) {
                // 将 nums[i] 交换到它该去的位置：下标为 nums[i] - 1 的地方
                int temp = nums[nums[i] - 1];
                nums[nums[i] - 1] = nums[i];
                nums[i] = temp;
            }
        }

        // 第二步：遍历寻找第一个“没坑里萝卜”的位置
        for (int i = 0; i < n; i++) {
            // 如果索引 i 的位置没有放数字 i+1，说明 i+1 就是缺失的最小正数
            if (nums[i] != i + 1) {
                return i + 1;
            }
        }

        // 极端情况：如果数组是完美的 [1, 2, 3, ..., n]，那缺失的就是 n + 1
        return n + 1;
    }
}
```
### 复杂度
  - **时间复杂度**：$O(N)$。虽然代码里有 `for` 嵌套 `while`，但每次进入 `while` 都会把一个正确的数字放到正确的坑位上，这个过程对每个坑位最多发生一次。所以总的交换次数最多是 $N$ 次。摊销下来时间复杂度就是 $O(N)$。
  - **空间复杂度**：$O(1)$。全程只用了一个额外的 `temp` 变量，完全在原数组上折腾。

### 易错点与扩展（极易写错的陷阱）

1. **致命陷阱：为什么要用 `while` 而不是 `if`？**
   - 当我们把当前位置 `i` 的数字交换出去后，换回来的**新数字**可能依然属于 $[1, N]$ 的范围，并且没有待在正确的位置上！如果用 `if`，我们就错过了一次让新数字“回老家”的机会。用 `while` 才能保证当前坑位拿到完美的萝卜（或者换来废弃的负数/超大数）才会停下。
2. **死循环防范：`nums[nums[i] - 1] != nums[i]` 极其重要！**
   - 如果数组是 `[1, 1]`。当前索引 0 的数字是 1，待在正确位置。索引 1 的数字是 1，它该去索引 0。
   - 如果你不加这行判断，代码会不断地把索引 1 的 `1` 和索引 0 的 `1` 互相交换，产生**死循环**！这行代码既是交换条件，也是对重复数字的去重过滤。

## Python 完整推导

### 把值 v 放回下标 v-1

长度为 n 时，真正需要整理的候选是 1 到 n。值 1 的目标位置是 0，值 v 的目标位置是 v-1。

遍历数组，当前值落在 1 到 n 且目标位置还没有相同值时，就与目标位置交换。换到当前下标的新值可能仍需归位，所以用 while 继续处理。

整理完毕后从左扫描，第一个不满足 nums[i] == i+1 的位置，其应有值就是答案；全部满足时返回 n+1。

### 用 [3, 4, -1, 1] 走一遍

- i=0，3 去下标 2，数组变成 [-1,4,3,1]。
- 下标 0 的 -1 不在范围内，停止。
- i=1，4 去下标 3，得到 [-1,1,3,4]；换来的 1 再去下标 0，得到 [1,-1,3,4]。
- 第二趟发现 nums[1] 是 -1，而不是应有的 2，返回 2。

### Python 实现

> 参考来源：经典解法实现
>
> 保留旧 Python 的值域原地交换实现，拆分落点变量并整理签名；算法未改变。

```python
from typing import List


class Solution:
    def firstMissingPositive(self, nums: List[int]) -> int:
        n = len(nums)
        for i in range(n):
            while 1 <= nums[i] <= n:
                value = nums[i]
                target = value - 1
                if nums[target] == value:
                    break
                nums[i], nums[target] = nums[target], nums[i]
        for i, value in enumerate(nums):
            if value != i + 1:
                return i + 1
        return n + 1
```

### 重复值必须停止

[1,1] 中下标 1 的 1 想去下标 0，但那里已经是同一个值。目标位置相同值时 break，否则两个 1 会无限交换。

### 非法值如何处理

0、负数和大于 n 的数没有可用目标下标，直接跳过。它们最终占据的错位位置会在第二趟暴露缺口。

### 候选范围与答案范围

需要归位的值只可能是 1 到 n；最终答案则可能为 n+1。若 1 到 n 都已出现，就没有更小的正数可作为答案。

### 交换次数

每次成功交换至少把一个合法值送到它的最终位置。虽然外层有 for、内层有 while，总成功交换次数仍与 n 同阶。

### 复杂度

- 时间复杂度：`O(n)`。
- 空间复杂度：`O(1)`。

每次成功交换至少让一个元素到达最终位置，总交换 O(n)；两趟扫描 O(n)，只用常数下标变量。

## C++ 实现

> 实现来源：经典解法实现

<ol class="lang-steps"><li>原地哈希：把值 v（1≤v≤n）交换到下标 v-1 上</li><li>交换后再扫一遍，第一个 nums[i] != i+1 的位置，答案就是 i+1</li><li>若全部归位，答案是 n+1</li></ol>

```cpp
class Solution {
public:
    int firstMissingPositive(vector<int>& nums) {
        int n = nums.size();
        for (int i = 0; i < n; i++) {
            while (nums[i] >= 1 && nums[i] <= n && nums[nums[i] - 1] != nums[i]) {
                swap(nums[i], nums[nums[i] - 1]);   // 值 v 归位到下标 v-1
            }
        }
        for (int i = 0; i < n; i++) {
            if (nums[i] != i + 1) return i + 1;
        }
        return n + 1;
    }
};
```

## C 实现

> 实现来源：经典解法实现

<ol class="lang-steps"><li>原地哈希：把值 v（1≤v≤n）交换到下标 v-1 上</li><li>交换后再扫一遍，第一个 nums[i] != i+1 的位置，答案就是 i+1</li><li>若全部归位，答案是 n+1</li></ol>

```c
int firstMissingPositive(int* nums, int numsSize) {
    for (int i = 0; i < numsSize; i++) {
        while (nums[i] >= 1 && nums[i] <= numsSize && nums[nums[i] - 1] != nums[i]) {
            int tmp = nums[nums[i] - 1];
            nums[nums[i] - 1] = nums[i];
            nums[i] = tmp;                              /* 值 v 归位到下标 v-1 */
        }
    }
    for (int i = 0; i < numsSize; i++) {
        if (nums[i] != i + 1) return i + 1;
    }
    return numsSize + 1;
}
```
