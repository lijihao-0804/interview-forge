## 题目与约束

给你一个整数数组 `nums`，返回 数组 `answer` ，其中 `answer[i]` 等于 `nums` 中除了 `nums[i]` 之外其余各元素的乘积 。

  题目数据 **保证** 数组 `nums`之中任意元素的全部前缀元素和后缀的乘积都在  **32 位** 整数范围内。

  请 **不要使用除法，**且在 `O(n)` 时间复杂度内完成此题。

  **示例 1:**

  **输入:** nums = `[1,2,3,4]`<br>**输出:** `[24,12,8,6]`

  **示例 2:**

  **输入:** nums = [-1,1,0,-3,3]<br>**输出:** [0,0,9,0,0]

  **提示：**

  - `2 <= nums.length <= 105`
  - `-30 <= nums[i] <= 30`
  - 输入 **保证** 数组 `answer[i]` 在  **32 位** 整数范围内

  **进阶：**你可以在 `O(1)` 的额外空间复杂度内完成这个题目吗？（ 出于对空间复杂度分析的目的，输出数组 **不被视为**额外空间。）

## 完整推导

### 思路推导
  1. **直觉与痛点（除法与零的陷阱）**：

     原本最简单的想法是求出所有数字的总乘积，然后遍历数组，对于位置 `i`，答案就是 `总乘积 / nums[i]`。

     **痛点**：首先，题目严禁使用除法；其次，如果数组里包含 `0`，除以 `0` 就会直接报错；如果不止一个 `0`，逻辑会变得极其繁琐。

  2. **破局思路（左右乘积分解法）**：

     既然不能除，那就只能乘。除 `nums[i]` 以外的乘积，其实可以完美地拆分成两部分：

     **`answer[i] = (i 左边所有数字的乘积) × (i 右边所有数字的乘积)`**

     因此，我们只需要计算出每个位置的“左前缀乘积”和“右后缀乘积”，然后两两相乘即可。

  3. **逻辑推演（空间压缩的艺术）**：

     - *常规做法（$O(N)$ 空间）*：开辟两个新数组 `L` 和 `R`。`L[i]` 存 `i` 左边的乘积，`R[i]` 存 `i` 右边的乘积。最后 `answer[i] = L[i] * R[i]`。
     - *终极优化（$O(1)$ 空间）*：题目说明输出数组不计入空间复杂度。我们可以直接把 `answer` 数组当成 `L` 数组来用！
       - **第一遍扫描（从左到右）**：计算左侧乘积，存入 `answer` 中。
       - **第二遍扫描（从右到左）**：用一个动态变化的单个变量 `R` 来维护右侧乘积。一边维护 `R`，一边把它乘到 `answer[i]` 里。
### Java 实现
```java
class Solution {
    public int[] productExceptSelf(int[] nums) {
        int n = nums.length;
        int[] answer = new int[n];

        // 1. 第一遍扫描：计算每个位置【左边】所有数字的乘积
        // 对于下标 0，它的左边没有数字，所以左乘积的初始基准值为 1
        answer[0] = 1;
        for (int i = 1; i < n; i++) {
            // 当前位置的左乘积 = 前一个位置的左乘积 * 前一个位置的数字
            answer[i] = answer[i - 1] * nums[i - 1];
        }

        // 2. 第二遍扫描：计算每个位置【右边】所有数字的乘积，并直接与 answer 相乘
        // R 用于实时记录当前位置右边所有数字的乘积，最右边元素的右侧没有数字，基准值为 1
        int R = 1;
        // 从右往左遍历
        for (int i = n - 1; i >= 0; i--) {
            // 此时 answer[i] 里存的是左乘积，R 里存的是右乘积
            // 两者相乘，就是最终答案
            answer[i] = answer[i] * R;

            // 更新 R：将当前数字乘入 R，供前一个元素（左边的元素）使用
            R = R * nums[i];
        }

        return answer;
    }
}
```
### 复杂度
  - **时间复杂度**：$O(N)$。我们仅仅对数组进行了两次遍历（一次从左到右，一次从右到左），总操作次数约为 $2N$，属于线性时间复杂度。
  - **空间复杂度**：$O(1)$。我们除了作为返回结果的 `answer` 数组之外，只使用了一个常数级别的整型变量 `R` 来实时更新后缀乘积。（*注：力扣官方规定，作为返回结果的数组不计入空间复杂度分析*）。

### 易错点与扩展

1. **面试官追问：为什么题目要刻意限制你不让你用除法？仅仅是为了增加难度吗？**
   - **满分回答**：不完全是。在真实的底层开发和数值计算中，**除法运算的 CPU 周期消耗远大于乘法**。更重要的是，除法天然存在除数为 0（Division by zero）的致命异常风险，需要写大量的 `if-else` 分支去处理数组中存在 1 个 0 还是 2 个 0 的情况。而这种“前缀乘后缀”的思想，无论是正数、负数还是 0，逻辑统一，天然免疫 0 的干扰，代码更加健壮。
2. **动态规划视角的降维**：
   - 你可以把这种做法看作是动态规划中“状态压缩”的一种体现。原本我们需要两个状态表 `L[]` 和 `R[]`。但因为我们在计算 `R` 的时候，只需依赖上一步的 `R`，所以把一维的 `R[]` 压缩成了一个单变量 `R`，极大地节约了内存。

## Python 完整推导

### 每个答案由左侧乘积和右侧乘积组成

answer[i] 先保存下标 i 左侧所有数的乘积。第一趟从左到右只需用前一位结果乘上前一位数字。

第二趟从右到左维护 right_product。对每个 i，先把当前右侧乘积乘入 answer[i]，再把 nums[i] 加入 right_product，供左侧位置使用。

### 用 [1, 2, 3, 4] 走一遍

第一趟后 answer = [1, 1, 2, 6]。

第二趟：

- i=3：6 × 1 = 6，right_product 变成 4。
- i=2：2 × 4 = 8，right_product 变成 12。
- i=1：1 × 12 = 12，right_product 变成 24。
- i=0：1 × 24 = 24。

最终得到 [24, 12, 8, 6]。

### Python 实现

> 参考来源：经典解法实现
>
> 保留旧 Python 的前缀积与滚动后缀积实现，只整理变量、注释与签名；算法未改变。

```python
from typing import List


class Solution:
    def productExceptSelf(self, nums: List[int]) -> List[int]:
        n = len(nums)
        answer = [1] * n
        for i in range(1, n):
            answer[i] = answer[i - 1] * nums[i - 1]
        right_product = 1
        for i in range(n - 1, -1, -1):
            answer[i] *= right_product
            right_product *= nums[i]
        return answer
```

### 两行顺序决定是否包含自身

每轮必须先执行 answer[i] *= right_product，再执行 right_product *= nums[i]。如果顺序反过来，右侧乘积会提前包含当前位置。

### 含零输入

只有一个零时，除零所在位置外，其余答案都包含这个零，结果为 0；零所在位置得到其余非零数之积。若有两个或更多零，任何一个答案排除自身后仍会包含至少一个零，因此全部答案都是 0。

### 空间口径

answer 是题目要求的返回数组，不计入额外工作空间；除此之外只保存 right_product 和循环下标。

### 复杂度

- 时间复杂度：`O(n)`。
- 空间复杂度：`O(1)（不含答案数组）`。

两趟各扫描 n 个元素；answer 是题目要求的输出，额外只使用 right_product。

## C++ 实现

> 实现来源：经典解法实现

<ol class="lang-steps"><li>answer[i] = 左边所有数的乘积 × 右边所有数的乘积</li><li>第一遍从左到右算前缀乘积存入 answer</li><li>第二遍从右到左用一个变量累积后缀乘积，原地乘进 answer</li></ol>

```cpp
class Solution {
public:
    vector<int> productExceptSelf(vector<int>& nums) {
        int n = nums.size();
        vector<int> answer(n);
        answer[0] = 1;
        for (int i = 1; i < n; i++) answer[i] = answer[i - 1] * nums[i - 1];  // 左积
        int right = 1;
        for (int i = n - 1; i >= 0; i--) {
            answer[i] *= right;      // 乘上右积
            right *= nums[i];
        }
        return answer;
    }
};
```
