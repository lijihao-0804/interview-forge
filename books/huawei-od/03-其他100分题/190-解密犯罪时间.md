# 190 解密犯罪时间

## 题目描述

警察在侦破一个案件时，得到了线人给出的可能犯罪时间，形如`HH:MM`表示的时刻。根据警察和线人的约定，为了隐蔽，该时间是修改过的。

解密规则为：利用当前出现过的数字，构造下一个距离当前时间最近的时刻，则该时间为可能的犯罪时间。每个出现数字都可以被无限次使用。

## 输入描述

形如`HH:SS`字符串，表示原始输入。

## 输出描述

形如`HH:SS`字符串，表示推理处理的犯罪时间。

## 示例描述

### 示例一

**输入：**

```text
20:12
```

**输出：**

```text
20:20
```

### 示例二

**输入：**

```text
23:59
```

**输出：**

```text
22:22
```

## 解题思路

1. 得到时间中出现过的数字，存入列表`nums`中。
2. 得到当前时间的小时`h`和分钟`m`。
3. 得到由这些数字组成的时间，存入列表`lst`中。
4. 如果分钟数不大，可得到当前小时的时刻的最近分钟，返回结果。
5. 如果当前时间的分钟数很大，则得到后面小时的时刻，返回结果。
6. 上述两个条件都不满足，则得到第二天的最近时刻的最小分钟数，返回结果。

## 复杂度分析

- 时间复杂度：O(1)，仅对至多 4 个数字组成的常数规模候选（≤ 16 个分钟值）进行枚举。
- 空间复杂度：O(1)，常数规模集合。

## 解题代码

```python
def solve_method(time):
    # 得到时间中出现过的数字
    nums = [int(c) for c in time if c != ":"]
    # 得到小时和分钟
    h, m = map(int, time.split(":"))
    lst = set()
    # 得到由这些数字组成的时间
    for i in nums:
        for j in nums:
            if i <= 5:
                lst.add(i * 10 + j)
    lst = list(sorted(lst))

    # 当前小时的时刻的最近分钟
    for i in lst:
        if i <= m:
            continue
        return format_time(h, i)

    # 当前时间的分钟数很大，则是后面小时的时刻
    if h != 23:
        for i in lst:
            if i <= h:
                continue
            if i <= 23:
                # 得到最近小时的时刻最小分钟数
                return format_time(i, lst[0])

    # 第二天的最近时刻的最小分钟数
    return format_time(lst[0], lst[0])


def format_time(h, m):
    return f"{h:02d}:{m:02d}"


if __name__ == "__main__":
    assert solve_method("20:12") == "20:20"
    assert solve_method("23:59") == "22:22"
    assert solve_method("20:59") == "22:00"
    assert solve_method("23:09") == "23:20"
```

```java
import java.util.*;

public class Solution {
    static String formatTime(int h, int m) {
        return String.format("%02d:%02d", h, m);
    }

    static String solve(String time) {
        List<Integer> nums = new ArrayList<>();
        for (char c : time.toCharArray()) if (c != ':') nums.add(c - '0');
        String[] parts = time.split(":");
        int h = Integer.parseInt(parts[0]);
        int m = Integer.parseInt(parts[1]);
        TreeSet<Integer> set = new TreeSet<>();
        for (int i : nums) for (int j : nums) if (i <= 5) set.add(i * 10 + j);
        List<Integer> lst = new ArrayList<>(set);
        for (int i : lst) {
            if (i <= m) continue;
            return formatTime(h, i);
        }
        if (h != 23) {
            for (int i : lst) {
                if (i <= h) continue;
                if (i <= 23) return formatTime(i, lst.get(0));
            }
        }
        return formatTime(lst.get(0), lst.get(0));
    }

    public static void main(String[] args) {
        if (!solve("20:12").equals("20:20")) throw new RuntimeException("c1");
        if (!solve("23:59").equals("22:22")) throw new RuntimeException("c2");
        if (!solve("20:59").equals("22:00")) throw new RuntimeException("c3");
        if (!solve("23:09").equals("23:20")) throw new RuntimeException("c4");
        System.out.println("OK 190");
    }
}
```
