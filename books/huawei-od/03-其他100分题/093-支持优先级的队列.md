# 093 支持优先级的队列

## 题目描述

实现一个支持优先级的队列，高优先级先出队列；同优先级时先进先出。如果两个输入数据和优先级都相同，则后一个数据不入队列被丢弃。队列存储的数据内容是一个整数。

## 输入描述

一组待存入队列的数据（包含内容和优先级）。

## 输出描述

队列的数据内容（优先级信息，输出时不再体现）。

## 示例描述

### 示例一

**输入：**
```text
(10,1),(20,1),(30,2),(40,3)
```

**输出：**
```text
40,30,10,20
```

**说明：**  

输入样例中，向队列写入了4个数据，每个数据由数据内容和优先级组成。输入和输出内容都不含空格。10和20优先级相同，所以按输入顺序输出。

### 示例二

**输入：**
```text
(10,1),(10,1),(30,2),(40,3)
```

**输出：**
```text
40,30,10
```

**说明：**

输入样例中，向队列写入了4个数据，每个数据由数据内容和优先级组成。输入和输出内容都不含空格。

数据40的优先级最高，所以最先输出，其次是30，两个10和10构成重复数据，被丢弃一个。

## 解题思路

1. 使用`set`方法进行列表去重。
2. 对列表进行排序，先按照优先级从大到小，再按照数据从小到大。
3. 返回结果，取出列表中的数据。

## 复杂度分析

- 时间复杂度：O(n log n)，其中 n 为元素个数。去重为 O(n)，排序为 O(n log n)。
- 空间复杂度：O(n)，需要用集合和列表保存去重后的元素。

## 解题代码

```python
def solve_method(arr):
    arr = list(set(arr))
    arr.sort(key=lambda x: (-x[1], x[0]))
    return [x[0] for x in arr]


if __name__ == '__main__':
    assert solve_method([(10, 1), (20, 1), (30, 2), (40, 3)]) == [40, 30, 10, 20]
    assert solve_method([(10, 1), (10, 1), (30, 2), (40, 3)]) == [40, 30, 10]
```

```java
import java.util.*;

public class Solution {
    static List<Integer> solveMethod(int[][] arr) {
        Set<String> seen = new LinkedHashSet<>();
        List<int[]> items = new ArrayList<>();
        for (int[] p : arr) {
            String key = p[0] + "," + p[1];
            if (!seen.contains(key)) {
                seen.add(key);
                items.add(new int[]{p[0], p[1]});
            }
        }
        items.sort((x, y) -> {
            if (x[1] != y[1]) return Integer.compare(y[1], x[1]);
            return Integer.compare(x[0], y[0]);
        });
        List<Integer> result = new ArrayList<>();
        for (int[] it : items) result.add(it[0]);
        return result;
    }

    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        if (!sc.hasNextLine()) return;
        String line = sc.nextLine().trim();
        List<int[]> arr = new ArrayList<>();
        java.util.regex.Matcher m = java.util.regex.Pattern.compile("\\((\\d+),(\\d+)\\)").matcher(line);
        while (m.find()) arr.add(new int[]{Integer.parseInt(m.group(1)), Integer.parseInt(m.group(2))});
        int[][] a = arr.toArray(new int[0][]);
        List<Integer> res = solveMethod(a);
        StringBuilder sb = new StringBuilder();
        for (int i = 0; i < res.size(); i++) {
            if (i > 0) sb.append(',');
            sb.append(res.get(i));
        }
        System.out.println(sb.toString());
    }
}
```
