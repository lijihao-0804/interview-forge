题目描述

已知连续正整数数列{K}=K1,K2,K3,...,Ki的各个数相加之和为S，其中i＝N (0 < S,N < 100000)，求此数列K。

输入描述

输入包含两个参数： 1. 连续正整数数列之和S。 2. 数列里数的个数N。

输出描述

如果有解，则输出数列K，以空格分隔，如果无解，则输出-1。

示例描述

示例一

输入：

525 6

输出：

85 86 87 88 89 90

说明：

求平均值525/6=87.5，根据此值找到87和88，然后依次往两边找数，找到85和90时，验证(85+90)*6/2=525，成功找到该数列。

或者更简单地，使用等差数列公式计算最小的那一项：a1=[Sum-(n^2-n)/2]/n=[525-(36-6)/2]/6=[525-15]/6=85

然后得到[85, 86, 87, 88, 89, 90]。

解题思路

基本思路： 通过等差数列求和公式来计算出长度为N、和为S的连续整数序列。

等差数列的性质： Sum=(a1+an)×n2\an=a1+(n-1)×d

在本题中，公差d=1，所以有： Sum=(2a1+n-1)×n2=na1+n2-n2\a1=[Sum-n2-n2]n

  1. 用公式求解最小项a1。
  2. 如果有整数解，则返回从该数开始的N个正整数列表。
  3. 如果没有整数解，则返回-1。

解题代码

def solve_method(S: int, N: int):
    # 用公式求解最小项
    a1 = (S - (N ** 2 - N) / 2) / N

    if abs(a1 - int(a1)) < 1e-6:
        a1 = int(a1)
        result = [num for num in range(a1, a1 + N)]
    else:
        return -1

    return result


if __name__ == '__main__':
    assert solve_method(525, 6) == [85, 86, 87, 88, 89, 90]
    assert solve_method(7, 3) == -1
