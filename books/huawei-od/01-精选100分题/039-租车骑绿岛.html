题目描述

部门组织绿岛骑行团建活动。租用公共双人自行车骑行，每辆自行车最多坐两人、最大载重M。给出部门每个人的体重，请问最多需要租用多少双人自行车。

输入描述

第一行两个数字m、n，m表示自行车限重，n表示部门总人数。

第二行，n个数字，代表每个人的体重。体重都小于等于自行车限重m。

取值范围为： - 0 < m <= 200 - 0 < n <= 1000000

输出描述

最小需要的双人自行车数量。

示例描述

示例一

输入：

3 4
3 2 2 1

输出：

3

解题思路

基本思路： 使用双指针解题。 1. 将所有人体重从小到大排序。 2. 左指针设置为0，右指针设置为列表末尾位置。 3. 使用while循环，从右到左遍历： - 如果两个人的体重小于等于上限，已经找到了可以共享骑车的人，左指针向右移动。 - 如果两个人的体重大于上限，独占一车，右指针向左移动。 - 统计结果加1。 4. 返回统计结果。

解题代码

def solve_method(m, arr):
    arr.sort()
    count = 0

    i = 0
    j = len(arr) - 1

    while i < j:
        if arr[i] + arr[j] <= m:
            i += 1
        j -= 1
        count += 1

    if i == j:
        count += 1

    return count


if __name__ == '__main__':
    assert solve_method(3, [3, 2, 2, 1]) == 3
