# 734. 句子相似性

### 题意

逐词比较两句话，同一词或被明确列为相似的一对词可以匹配。相似关系对称。

### 示例

仅有词对 red–scarlet、scarlet–ruby。red 与 ruby 没被直接列为一对，两句各只有这一个词时结果为假。

### 思路

先比较词数，再查看每个位置。词对可按两种方向检索，完全相同的两个词无需出现在词表里。

### 边界检查

相似关系是双向的，完全相同的词始终匹配。词对 `red–scarlet` 可以反向使用，但这道题不通过第三个词建立关系。

### Java

```java
import java.util.*;

class Solution {
    public boolean areSentencesSimilar(
            String[] sentence1, String[] sentence2, List<List<String>> similarPairs) {
        if (sentence1.length != sentence2.length) return false;

        Map<String, Set<String>> map = new HashMap<>();

        // 关系是对称的，必须同时记录两个方向。
        for (List<String> pair : similarPairs) {
            map.putIfAbsent(pair.get(0), new HashSet<>());
            map.putIfAbsent(pair.get(1), new HashSet<>());
            map.get(pair.get(1)).add(pair.get(0));
            map.get(pair.get(0)).add(pair.get(1));
        }

        for (int i = 0; i < sentence1.length; ++i) {
            if (sentence1[i].equals(sentence2[i])) continue;
            if (!map.containsKey(sentence1[i])) return false;
            if (!map.get(sentence1[i]).contains(sentence2[i])) return false;
        }

        return true;
    }
}
```

### Python

```python
from __future__ import annotations
import collections


class Solution:
    def areSentencesSimilar(
        self,
        sentence1: list[str],
        sentence2: list[str],
        similarPairs: list[list[str]],
    ) -> bool:
        if len(sentence1) != len(sentence2):
            return False

        map = collections.defaultdict(set)

        # 关系是对称的，必须同时记录两个方向。
        for a, b in similarPairs:
            map[a].add(b)
            map[b].add(a)

        for word1, word2 in zip(sentence1, sentence2):
            if word1 == word2:
                continue
            if word1 not in map:
                return False
            if word2 not in map[word1]:
                return False

        return True
```

### 复杂度

p 个词对、n 个词，按词操作计；平均时间 O(p+n)，空间 O(p)。
