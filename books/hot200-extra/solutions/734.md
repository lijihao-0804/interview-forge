# 734. 句子相似性

### 题意

逐词比较两句话，同一词或被明确列为相似的一对词可以匹配。相似关系对称。

### 输入与约束

输入两个词序列与无向相似词对，同一词天然相似，相似关系不传递。需对应位置逐词匹配且两句长度相同。

### 示例

仅有词对 red–scarlet、scarlet–ruby。red 与 ruby 没被直接列为一对，两句各只有这一个词时结果为假。

### 核心不变量

邻接集合仅含显式词对；检查完某个位置后，两个前缀在每一位上都已直接匹配。

### 思路

先比较词数，再查看每个位置。词对可按两种方向检索，完全相同的两个词无需出现在词表里。

比较的单位是同一位置上的一对词，词数不等时位置都无法对齐。对于异词只需查一次直接关系；把已知词对同时记入双方邻接集合，查询时不用猜录入方向。集合去重不会改变结论。

### 边界检查

相似关系是双向的，完全相同的词始终匹配。词对 `red–scarlet` 可以反向使用，但这道题不通过第三个词建立关系。

### Java

Java 的 `Map<String,Set<String>>` 保存每个词的一跳邻居。逐位先用 equals 判断内容相同，再查 containsKey 和邻居集合；这也保证从未被登记的相同单词可以直接通过。

#### 直接检查 red 的邻居

| 步骤 | 当前状态 | 判断依据 |
| --- | --- | --- |
| 加入第一对 | red 的邻居为 {scarlet} | 也同时把 red 加入 scarlet 的集合。 |
| 加入第二对 | ruby 的邻居为 {scarlet} | 现有两条直接关系，red 的集合未改变。 |
| 比较 red 和 ruby | ruby 不在 red 的邻居中，返回 false | 经过第三个词无法满足直接匹配。 |

```java
import java.util.*;

class Solution {
    public boolean areSentencesSimilar(
            String[] sentence1, String[] sentence2, List<List<String>> similarPairs) {
        if (sentence1.length != sentence2.length) return false;

        Map<String, Set<String>> map = new HashMap<>();

        // 关系是对称的，必须同时记录两个方向。
        for (List<String> pair : similarPairs) {
            map.putIfAbsent(pair.get(0), new HashSet<>());
            map.putIfAbsent(pair.get(1), new HashSet<>());
            map.get(pair.get(1)).add(pair.get(0));
            map.get(pair.get(0)).add(pair.get(1));
        }

        for (int i = 0; i < sentence1.length; ++i) {
            if (sentence1[i].equals(sentence2[i])) continue;
            if (!map.containsKey(sentence1[i])) return false;
            if (!map.get(sentence1[i]).contains(sentence2[i])) return false;
        }

        return true;
    }
}
```

### Python

Python 用 defaultdict(set) 添加双向边。zip 只遍历两句的公共长度，因此必须在 zip 前检查长度。每个位置通过时，已检查的两个句子前缀都满足对应关系。

#### 直接检查 red 的邻居

| 步骤 | 当前状态 | 判断依据 |
| --- | --- | --- |
| 加入第一对 | red 的邻居为 {scarlet} | 也同时把 red 加入 scarlet 的集合。 |
| 加入第二对 | ruby 的邻居为 {scarlet} | 现有两条直接关系，red 的集合未改变。 |
| 比较 red 和 ruby | ruby 不在 red 的邻居中，返回 false | 经过第三个词无法满足直接匹配。 |

```python
from __future__ import annotations
import collections


class Solution:
    def areSentencesSimilar(
        self,
        sentence1: list[str],
        sentence2: list[str],
        similarPairs: list[list[str]],
    ) -> bool:
        if len(sentence1) != len(sentence2):
            return False

        map = collections.defaultdict(set)

        # 关系是对称的，必须同时记录两个方向。
        for a, b in similarPairs:
            map[a].add(b)
            map[b].add(a)

        for word1, word2 in zip(sentence1, sentence2):
            if word1 == word2:
                continue
            if word1 not in map:
                return False
            if word2 not in map[word1]:
                return False

        return True
```

### 面试追问

**换成“相似可以传递”会怎样？** 此时应判断两词在同一连通分量，可用并查集维护。直接查邻居会漏掉中间经过 scarlet 的路径。

### 复杂度

p 个词对、n 个词，按词操作计；平均时间 O(p+n)，空间 O(p)。

每对关系插入两个哈希集合，每对句中词只做常数次集合查询。若计入单词字符的散列与比较，应再乘相应字符处理成本。
