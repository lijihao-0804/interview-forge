# 361. 轰炸敌人


### 题意

在一个空格放一枚炸弹，可沿同行同列消灭直到遇墙前的敌人。求最大消灭数。

### 输入与约束

非空矩形网格使用 E、W、0 表示敌人、墙、空地。炸弹只能放在空地，可沿四个方向击中至第一堵墙前的敌人。

### 示例

一行 E0EWE，在唯一空位可击中左右两个 E，墙后的敌人不受影响，答案 2。

### 核心不变量

沿一个方向扫描时，enemyCount 恰是当前位置之前、最近一堵墙之后的敌人数。

### 思路

沿行和列分别从两端扫描，遇墙清空累计数，遇敌递增，遇空格就把当前方向的计数加到它的答案。四方向的敌人互不重复。

逐空格往四面找敌人会反复扫描同一条无墙走廊。换成沿整行扫一遍，每到一个空位，左方能击中的敌人就是自最近墙以来的累计数。再反向及沿列扫，便得到另外三份互不重叠的贡献。

#### 一堵墙切断右侧敌人

| 步骤 | 当前状态 | 为什么这样走 |
| --- | --- | --- |
| 从左看空位 | E0EWE，左扫到列 1 时 enemyCount=1，dp[0][1]=1 | 列 0 的 E 在同一无墙段。 |
| 从右看空位 | 右扫经墙清零，再经列 2 的 E，dp[0][1]=2 | 最右侧 E 被列 3 的墙隔断。 |
| 加入竖直贡献 | 上、下方向各为 0，最大值 2 | 单行棋盘没有其他行的敌人。 |

### 边界检查

墙会同时截断行方向和列方向的视线。只有空格能放炸弹，统计到的敌人数可以沿同一段无墙区域复用。

### 反例推演

一行 `0 E W E` 中从左端放炸弹只能击中一个敌人。扫到墙后必须清空当前方向的计数，墙后的敌人不能进入左端得分。

### Java

#### 四次扫描如何给同一空格加分

`enemyCount` 在每条新扫描线和每次遇墙时清零。update 只给空格的 dp 加分，遇敌只增加计数，所以最后在整张 dp 上取最大值也是安全的。

```java
import java.util.*;

class Solution {
    public int maxKilledEnemies(char[][] grid) {
        if (grid.length == 0 || grid[0].length == 0) return 0;

        final int m = grid.length;
        final int n = grid[0].length;

        int[][] dp = new int[m][n];

        // 每条扫描线独立累计敌人数，墙会截断此前的贡献。
        for (int i = 0; i < m; ++i) {
            enemyCount = 0;
            for (int j = 0; j < n; ++j) update(grid, i, j, dp);
            enemyCount = 0;
            for (int j = n - 1; j >= 0; --j) update(grid, i, j, dp);
        }

        for (int j = 0; j < n; ++j) {
            enemyCount = 0;
            for (int i = 0; i < m; ++i) update(grid, i, j, dp);
            enemyCount = 0;
            for (int i = m - 1; i >= 0; --i) update(grid, i, j, dp);
        }

        return Arrays.stream(dp).flatMapToInt(Arrays::stream).max().getAsInt();
    }

    private int enemyCount = 0;

    private void update(char[][] grid, int i, int j, int[][] dp) {
        if (grid[i][j] == '0') dp[i][j] += enemyCount;
        else if (grid[i][j] == 'E') ++enemyCount;
        else enemyCount = 0;
    }
}
```

### Python

#### 用闭包共享一条扫描线的计数

辅助函数使用 nonlocal 修改当前方向的累计数。reversed(range(...)) 反向走同一条扫描线，再看一次空位时只补上另一侧的敌人。

```python
from __future__ import annotations


class Solution:
    def maxKilledEnemies(self, grid: list[list[str]]) -> int:
        m = len(grid)
        n = len(grid[0])
        enemyCount = 0

        dp = [[0] * n for _ in range(m)]

        def update(i: int, j: int) -> None:
            nonlocal enemyCount
            if grid[i][j] == "0":
                dp[i][j] += enemyCount
            elif grid[i][j] == "E":
                enemyCount += 1
            else:
                enemyCount = 0

        # 每条扫描线独立累计敌人数，墙会截断此前的贡献。
        for i in range(m):
            enemyCount = 0
            for j in range(n):
                update(i, j)
            enemyCount = 0
            for j in reversed(range(n)):
                update(i, j)

        for j in range(n):
            enemyCount = 0
            for i in range(m):
                update(i, j)
            enemyCount = 0
            for i in reversed(range(m)):
                update(i, j)

        return max(map(max, dp))
```

### 复杂度

四次扫描共 O(mn)，分数矩阵占 O(mn)。

四次遍历各访问 mn 个格子；每次更新只做常数工作。dp 为每格留一个累计分数。

### 面试追问

**能减少整张 dp 的内存吗？** 可按行维护当前无墙行段敌人数，再给每列维护无墙列段计数。每遇一段起点才重算该段，于空格处直接比较两项之和。
