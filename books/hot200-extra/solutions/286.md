# 286. 墙与门


### 题意

矩阵的门为 0，墙为 -1，空房为最大 32 位整数。把每间可达空房改成到最近门的步数。

### 输入与约束

rooms 是非空矩形网格，门、墙、未填空房分别为 0、−1、2³¹−1。只可四邻行走，直接在原矩阵写距离。

### 示例

一行 [0,∞,∞,-1,∞] 从左门扩展为 [0,1,2,-1,∞]，最右房间被墙隔开。

### 核心不变量

队列中的已发现房间距离按非递减顺序排列，未发现的房间仍为输入哨兵。

### 思路

所有门同时入队，先进先出队列逐层扩展。只给尚为无穷大的格子赋值，因此第一次到达的距离就是所有门中的最短距离。

若每间房各自去找门，很多过道会被反复走过。反过来让所有门同时出发，第 d 层队列代表恰好距某扇门 d 步的房间。任何更短路径都应在更早的层发现该房间，故初次写下的距离即可定案。

#### 隔墙的一行房间

| 步骤 | 当前状态 | 为什么这样走 |
| --- | --- | --- |
| 门进入队列 | 房号 0 入队，距离为 0 | 所有扩展从已知的零距离开始。 |
| 发现第一间房 | 房号 1 写为 1，房号 0 出队 | 向右迈一步即可到达。 |
| 扩展到墙前 | 房号 2 写为 2，房号 3 为墙 | 墙不能入队，房号 4 保持 ∞。 |

### 边界检查

所有门都是距离为零的起点，应在扩展前一起入队。每个空房间第一次被访问时取得的是距最近一扇门的距离。

### 反例推演

一行房间 `[0,INF,INF,0]` 中，两间空房距离都为 1。如果只从左门扩展并锁定已访问格，会把右侧空房写成 2；所有门应从第零层同时入队。

### Java

#### 用整数哨兵作发现标记

队列只含已知距离的坐标，`Integer.MAX_VALUE` 同时标识未访问空房。入队前写 `rooms[x][y]`，即使两扇门都通向该格，也只有先到者能将它加入队列。

```java
import java.util.*;

class Solution {
    public void wallsAndGates(int[][] rooms) {
        final int[][] DIRS = {{0, 1}, {1, 0}, {0, -1}, {-1, 0}};
        final int m = rooms.length;
        final int n = rooms[0].length;
        Queue<Map.Entry<Integer, Integer>> q = new ArrayDeque<>();

        for (int i = 0; i < m; ++i)
            for (int j = 0; j < n; ++j) if (rooms[i][j] == 0) q.offer(Map.entry(i, j));

        // 所有门同时出发，首次抵达空房的那一层就是最近距离。
        while (!q.isEmpty()) {
            final int i = q.peek().getKey();
            final int j = q.poll().getValue();
            for (int[] dir : DIRS) {
                final int x = i + dir[0];
                final int y = j + dir[1];
                if (x < 0 || x == m || y < 0 || y == n) continue;
                if (rooms[x][y] != Integer.MAX_VALUE) continue;
                rooms[x][y] = rooms[i][j] + 1;
                q.offer(Map.entry(x, y));
            }
        }
    }
}
```

### Python

#### deque 中的房号与距离

`deque.popleft()` 维持距离从小到大的顺序。初始生成式一次搜齐所有零，之后只用父格已确定的距离加一；负一墙和有限距离的格子都会被跳过。

```python
from __future__ import annotations
import collections


class Solution:
    def wallsAndGates(self, rooms: list[list[int]]) -> None:
        DIRS = ((0, 1), (1, 0), (0, -1), (-1, 0))
        INF = 2**31 - 1
        m = len(rooms)
        n = len(rooms[0])
        q = collections.deque((i, j) for i in range(m) for j in range(n) if rooms[i][j] == 0)

        # 所有门同时出发，首次抵达空房的那一层就是最近距离。
        while q:
            i, j = q.popleft()
            for dx, dy in DIRS:
                x = i + dx
                y = j + dy
                if x < 0 or x == m or y < 0 or y == n:
                    continue
                if rooms[x][y] != INF:
                    continue
                rooms[x][y] = rooms[i][j] + 1
                q.append((x, y))
```

### 复杂度

时间 O(mn)，队列最多 O(mn)。

初始化扫描全部格子，每个可达空房只入队一次，出队查看四个方向。队列可能同时含大量门。

### 面试追问

**若走廊通行时间各不相同呢？** 按步数分层不再保证最短时间。非负边权时可从全部门以初始代价零做多源 Dijkstra。
