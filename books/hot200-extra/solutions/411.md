# 411. 最短独占单词缩写


### 题意

为目标词找最短的规范缩写，使词典中的任何词都不能解释成同一缩写。每个字母或一段省略计数各算一个单位。

### 输入与约束

词典不包含目标词本身。省略数字一整段算一个长度单位，每个保留字母也算一个单位；允许返回任一最短唯一缩写。

### 示例

目标 car、词典 [bar,cat]。首字母 c 排除 bar，末字母 r 排除 cat；c1r 是合法最短答案之一。

### 核心不变量

有效保留掩码必须与每个等长竞争词的差异位集合相交，最佳候选始终是迄今合法候选中单位数最少者。

### 思路

只有等长词可能冲突。对每个等长词生成差异位掩码；目标保留的位置必须与每个差异掩码至少相交一位。枚举保留掩码并将连续省略位合成一段，取长度最小者。

若目标和词典词在所有保留位置都相同，缩写的数字只说明长度，无法区分二者。因此每个等长词都提供一组“至少保留其中一个”的差异位置。找合法候选变成逐个掩码测试是否击中所有这些集合。

#### car 与两个竞争词的差异掩码

| 步骤 | 当前状态 | 为什么这样走 |
| --- | --- | --- |
| 记录两个差异 | car 对 bar 得 001，对 cat 得 100 | 位 0 是首字符，位 2 是末字符。 |
| 测试单字母 | keep=001 排除 bar，但与 100 位与为 0 | 只留 c 仍与 cat 冲突，单留 r 同理。 |
| 同时保留首尾 | keep=101 形成 c1r，大小 3；初值 car 也是 3 | 没有更短合格解，当前实现保留 car。 |

### 边界检查

只需处理与目标等长的词。对每个这样的词，至少保留一个与它不同的位置；同一个保留位置有时能同时排除好几个词典项。

### Java

#### 位与筛选和单位计数

`1 << i` 表示保留第 i 个字母，keep 与 diff 位与为零便可立刻放弃。生成候选时 size 每遇一段省略只加一，多位数的位数不影响题目规定长度。

```java
import java.util.*;

class Solution {
    public String minAbbreviation(String target, String[] dictionary) {
        int length = target.length();
        List<Integer> differences = new ArrayList<>();
        for (String word : dictionary) {
            if (word.length() != length) continue;
            int mask = 0;
            for (int i = 0; i < length; i++) if (target.charAt(i) != word.charAt(i)) mask |= 1 << i;
            differences.add(mask);
        }
        if (differences.isEmpty()) return Integer.toString(length);
        String best = target;
        int bestSize = length;
        // 保留掩码必须击中每个等长词的一处差异，才能排除所有冲突。
        for (int keep = 0; keep < (1 << length); keep++) {
            boolean unique = true;
            for (int diff : differences)
                if ((keep & diff) == 0) {
                    unique = false;
                    break;
                }
            if (!unique) continue;
            StringBuilder candidate = new StringBuilder();
            int size = 0, skipped = 0;
            for (int i = 0; i < length; i++) {
                if ((keep & (1 << i)) == 0) {
                    skipped++;
                    continue;
                }
                if (skipped > 0) {
                    candidate.append(skipped);
                    size++;
                    skipped = 0;
                }
                candidate.append(target.charAt(i));
                size++;
            }
            if (skipped > 0) {
                candidate.append(skipped);
                size++;
            }
            if (size < bestSize) {
                bestSize = size;
                best = candidate.toString();
            }
        }
        return best;
    }
}
```

### Python

#### 以 pieces 的项数度量缩写

differences 里的每个整数表示一个竞争词。通过 all 检查后才构造 pieces，每个数字段与每个字母各占列表一项。只在严格更短时替换，因此同长的原词也可保留。

```python
from __future__ import annotations


class Solution:
    def minAbbreviation(self, target: str, dictionary: list[str]) -> str:
        length = len(target)
        differences = []
        for word in dictionary:
            if len(word) == length:
                differences.append(sum(1 << i for i in range(length) if word[i] != target[i]))
        if not differences:
            return str(length)
        best = target
        best_size = length
        # 保留掩码必须击中每个等长词的一处差异，才能排除所有冲突。
        for keep in range(1 << length):
            if not all(keep & diff for diff in differences):
                continue
            pieces = []
            skipped = 0
            for i, char in enumerate(target):
                if keep & (1 << i):
                    if skipped:
                        pieces.append(str(skipped))
                        skipped = 0
                    pieces.append(char)
                else:
                    skipped += 1
            if skipped:
                pieces.append(str(skipped))
            if len(pieces) < best_size:
                best, best_size = "".join(pieces), len(pieces)
        return best
```

### 复杂度

m 为词长、d 为等长词数。构建差异 O(dm)，枚举与生成 O(2ᵐ(d+m))，每次只保留当前候选和最佳答案，额外空间 O(d+m)。

每个等长词逐位比对一次。2ᵐ 个保留掩码分别查看至多 d 个差异掩码，合格者另扫 m 位拼串；遍历词典还需读取每个词的长度。

### 面试追问

**示例为什么代码可能直接返回 car？** c 和 r 必须保留，中间 a 写成 1 仍占一个单位。car 与 c1r 都长三单位，代码用严格小于更新，所以返回初始候选 car 也是最优。
