# 246. 中心对称数

### 题意

给一个十进制数字串，判断它转过 180° 后是否仍是原数字。

### 输入与约束

输入一个十进制数字串，按字符串的原有位数检查整体旋转 180° 后是否相同；不可旋转成数字的字符会使匹配失败。

### 示例

旋转 `619` 后从右到左读为 `619`，答案为真；`169` 旋转后不相同。

### 核心不变量

进入每轮时，l 左侧与 r 右侧的成对数字都已通过旋转映射校验。

### 思路

数位旋转时两端互换，用对应表检查成对数字。6 与 9 互换，奇数长度的中间位只能取 0、1、8。

旋转整个数会同时颠倒位置并改变字符。最左字符应等于最右字符旋转后的形状，向中心反复检查即可。能自己旋转成原样的是 0、1、8；6 与 9 必须成对出现，其他数字无法参与。

### 边界检查

一对位置要同时检查能否旋转以及旋转后是否对应。奇数长度的中点也需要检查，只有 0、1、8 旋转后仍等于自己。

### 反例推演

数字 `69` 旋转后仍是 69，`66` 却变成 99。只检查每个字符能否旋转，无法判断旋转后两端是否相互对应。

### Java

Java 的 rotated 数组由数字字符减 '0' 访问，非法旋转用无法与数字相等的占位字符表示。循环用 l<=r，奇数长度时中间那一位也需通过自映射检查。

#### 核对旋转后的镜像数字

| 步骤 | 当前状态 | 判断依据 |
| --- | --- | --- |
| 对照 619 的两端 | 左 6，右 9；旋转 9 得 6 | 外层一对匹配，可以进入中心。 |
| 检验中心 | 中央 1 旋转仍为 1；619 通过 | 奇数长度必须检验这一格。 |
| 再查 169 | 左 1，右 9；旋转 9 得 6≠1 | 首对就不匹配，立即返回假。 |

```java
import java.util.*;

class Solution {
    public boolean isStrobogrammatic(String num) {
        final char[] rotated = {'0', '1', 'x', 'x', 'x', 'x', '9', 'x', '8', '6'};
        int l = 0;
        int r = num.length() - 1;

        // 两端交换后必须互为旋转对应数字；中间位也应检验。
        while (l <= r) if (num.charAt(l++) != rotated[num.charAt(r--) - '0']) return false;

        return true;
    }
}
```

### Python

Python 的 rotated 字典只收录五种可旋转的数字。访问前判断键存在，避免非法数字产生 KeyError。每次成功后左右指针同时向内移动，外侧已验证的数字无需再读。

#### 核对旋转后的镜像数字

| 步骤 | 当前状态 | 判断依据 |
| --- | --- | --- |
| 对照 619 的两端 | 左 6，右 9；旋转 9 得 6 | 外层一对匹配，可以进入中心。 |
| 检验中心 | 中央 1 旋转仍为 1；619 通过 | 奇数长度必须检验这一格。 |
| 再查 169 | 左 1，右 9；旋转 9 得 6≠1 | 首对就不匹配，立即返回假。 |

```python
from __future__ import annotations


class Solution:
    def isStrobogrammatic(self, num: str) -> bool:
        rotated = {"0": "0", "1": "1", "6": "9", "8": "8", "9": "6"}
        l = 0
        r = len(num) - 1

        # 两端交换后必须互为旋转对应数字；中间位也应检验。
        while l <= r:
            if num[r] not in rotated:
                return False
            if num[l] != rotated[num[r]]:
                return False
            l += 1
            r -= 1

        return True
```

### 面试追问

**能把它当普通回文来查吗？** 69 旋转后仍是 69，但是两个字符并不相同。反过来 66 虽然是普通回文，旋转得到 99。

### 复杂度

n 位；时间 O(n)，辅助空间 O(1)。

两个游标每次各移动一格，最多检查一半位置对，旋转表大小固定为常数。
