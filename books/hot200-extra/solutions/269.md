# 269. 火星词典

### 题意

已知若干外星词按其字母表排序，恢复任意满足该顺序的字母排列；若矛盾则返回空串。

### 输入与约束

输入按未知字母表排列的非空小写单词。输出所有出现过的字符各一次，满足词典先后约束；矛盾则返回空串。

### 示例

词序 [za,zb,ca,cb] 给出 a 在 b 前、z 在 c 前。`zabc` 是一种可行回答。

### 核心不变量

拓扑阶段的入度仅计尚未输出的前驱，入度为零的字母可接到当前合法前缀之后。

### 思路

相邻词只有第一个不同字母决定先后，因此只建这一条边。长词排在自身前缀之前立即矛盾；拓扑排序若不能输出全部字母，存在环。

字典序只由最早不同的字母决定。例如 za 与 zb 约束 a<b，后缀再长也不会产生第二条必然关系。把每个字母当作顶点，已知先后当作有向边；不断取没有前置要求的字母，就可拼出一种满足全部比较的次序。

### 边界检查

相邻两个单词只在第一个不同字符处提供字母顺序。若短词是前一个长词的前缀却排在它后面，如 `abc, ab`，这组输入直接无解。

### 反例推演

词表 `[abc,ab]` 不含字符间的首个分歧，却违反短前缀必须在前的规则。仅做拓扑排序，即使没有环也会错误接受。

### Java

Java 用 `Map<Character,Set<Character>>` 建邻接表，int[] 记录入度。相同边第二次出现时不能再次增加入度，否则拓扑遍历只减一次，会让一个本来可输出的字母永远无法入队。

#### 从四个单词取得两条独立顺序

| 步骤 | 当前状态 | 判断依据 |
| --- | --- | --- |
| 比较 za 与 zb | 首个差异 a、b，建立 a→b | 共同前缀 z 不提供两个字母的先后。 |
| 比较 zb 与 ca，再比较 ca 与 cb | 建立 z→c；已有 a→b 不再计入度 | 得到两个互相独立的约束。 |
| 拓扑取字母 | 可先取 z、a，再取 b、c，得到 zabc | 每次取出的字母都已满足全部前置关系。 |

```java
import java.util.*;
import java.util.stream.Collectors;

class Solution {
    public String alienOrder(String[] words) {
        Map<Character, Set<Character>> graph = new HashMap<>();
        int[] inDegrees = new int[26];
        buildGraph(graph, words, inDegrees);
        return topology(graph, inDegrees);
    }

    private void buildGraph(Map<Character, Set<Character>> graph, String[] words, int[] inDegrees) {

        // 先登记全部字符，即使没有前后约束的字母也必须出现在答案里。
        for (final String word : words)
            for (final char c : word.toCharArray()) graph.putIfAbsent(c, new HashSet<>());

        for (int i = 1; i < words.length; ++i) {
            final String first = words[i - 1];
            final String second = words[i];
            final int length = Math.min(first.length(), second.length());
            for (int j = 0; j < length; ++j) {
                final char u = first.charAt(j);
                final char v = second.charAt(j);
                if (u != v) {
                    if (!graph.get(u).contains(v)) {
                        graph.get(u).add(v);
                        ++inDegrees[v - 'a'];
                    }
                    break;
                }

                if (j == length - 1 && first.length() > second.length()) {
                    graph.clear();
                    return;
                }
            }
        }
    }

    private String topology(Map<Character, Set<Character>> graph, int[] inDegrees) {
        StringBuilder sb = new StringBuilder();
        Queue<Character> q =
                graph.keySet().stream()
                        .filter(c -> inDegrees[c - 'a'] == 0)
                        .collect(Collectors.toCollection(ArrayDeque::new));

        while (!q.isEmpty()) {
            final char u = q.poll();
            sb.append(u);
            for (final char v : graph.get(u)) if (--inDegrees[v - 'a'] == 0) q.offer(v);
        }

        return sb.length() == graph.size() ? sb.toString() : "";
    }
}
```

### Python

Python 先登记每个单词出现的所有字母，连只有孤立顶点的词也能输出。deque 中保存当前入度为零的顶点，使用哪一端弹出只影响合法解的选择次序；输出不全说明存在环。

#### 从四个单词取得两条独立顺序

| 步骤 | 当前状态 | 判断依据 |
| --- | --- | --- |
| 比较 za 与 zb | 首个差异 a、b，建立 a→b | 共同前缀 z 不提供两个字母的先后。 |
| 比较 zb 与 ca，再比较 ca 与 cb | 建立 z→c；已有 a→b 不再计入度 | 得到两个互相独立的约束。 |
| 拓扑取字母 | 可先取 z、a，再取 b、c，得到 zabc | 每次取出的字母都已满足全部前置关系。 |

```python
from __future__ import annotations
import collections


class Solution:
    def alienOrder(self, words: list[str]) -> str:
        graph = {}
        inDegrees = [0] * 26

        self._buildGraph(graph, words, inDegrees)
        return self._topology(graph, inDegrees)

    def _buildGraph(
        self,
        graph: dict[str, set[str]],
        words: list[str],
        inDegrees: list[int],
    ) -> None:

        # 先登记全部字符，即使没有前后约束的字母也必须出现在答案里。
        for word in words:
            for c in word:
                if c not in graph:
                    graph[c] = set()

        for i in range(1, len(words)):
            first, second = words[i - 1], words[i]
            length = min(len(first), len(second))
            for j in range(length):
                u = first[j]
                v = second[j]
                if u != v:
                    if v not in graph[u]:
                        graph[u].add(v)
                        inDegrees[ord(v) - ord("a")] += 1
                    break

                if j == length - 1 and len(first) > len(second):
                    graph.clear()
                    return

    def _topology(self, graph: dict[str, set[str]], inDegrees: list[int]) -> str:
        s = ""
        q = collections.deque()

        for c in graph:
            if inDegrees[ord(c) - ord("a")] == 0:
                q.append(c)

        while q:
            u = q.pop()
            s += u
            for v in graph[u]:
                inDegrees[ord(v) - ord("a")] -= 1
                if inDegrees[ord(v) - ord("a")] == 0:
                    q.append(v)

        return s if len(s) == len(graph) else ""
```

### 面试追问

**如何判断字母表是否唯一？** 拓扑遍历的每一步若恰有一个零入度候选且最后输出全部字母，则次序被完全确定。一旦可以从两个候选任选一个，就至少存在两种合法次序。

### 复杂度

输入字符数 S、约束边数 E、字母数 V；时间 O(S+V+E)，空间 O(V+E)。

相邻单词比较的总字符读取受输入字符总量约束，每条不重复的约束边只增加及减少一次入度。邻接表与队列合计 O(V+E)。
