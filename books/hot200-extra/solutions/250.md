# 250. 统计同值子树

### 题意

统计二叉树中，整棵子树所有节点值都相同的子树数，叶节点也算一棵。

### 示例

根 3 的两个孩子分别是叶 3 和叶 4。两个叶各贡献 1，根的子树不满足，共 2。

### 思路

用显式栈做后序遍历。第一次遇到节点时把它连同“返回”标记入栈，再安排左右孩子；第二次遇到它时，孩子的结果已经可用。两个实际存在的孩子必须既是同值子树，又与父节点同值。统计完父节点可释放孩子的结果。

### 边界检查

一个节点值与两个孩子相同，仍不能单凭这点计入答案：更深处可能有异值。先拿到左右子树各自是否同值，再判断当前根。

### Java

```java
import java.util.*;

class Solution {
    private record Visit(TreeNode node, boolean returning) {}

    public int countUnivalSubtrees(TreeNode root) {
        if (root == null) return 0;
        int count = 0;
        Deque<Visit> stack = new ArrayDeque<>();
        Map<TreeNode, Boolean> uniform = new IdentityHashMap<>();
        stack.push(new Visit(root, false));
        while (!stack.isEmpty()) {
            Visit visit = stack.pop();
            TreeNode node = visit.node();
            if (!visit.returning()) {
                stack.push(new Visit(node, true));
                if (node.right != null) stack.push(new Visit(node.right, false));
                if (node.left != null) stack.push(new Visit(node.left, false));
                continue;
            }
            // 两个孩子的结果都要消费，随后只保留父节点的结果。
            boolean left =
                    node.left == null || (uniform.remove(node.left) && node.left.val == node.val);
            boolean right =
                    node.right == null
                            || (uniform.remove(node.right) && node.right.val == node.val);
            uniform.put(node, left && right);
            if (left && right) count++;
        }
        return count;
    }
}
```

### Python

```python
class Solution:
    def countUnivalSubtrees(self, root) -> int:
        if root is None:
            return 0
        count = 0
        uniform = {}
        stack = [(root, False)]
        while stack:
            node, returning = stack.pop()
            if not returning:
                # 父节点压在孩子下方，等左右子树都处理完再汇总。
                stack.append((node, True))
                if node.right is not None:
                    stack.append((node.right, False))
                if node.left is not None:
                    stack.append((node.left, False))
                continue
            left, right = node.left, node.right
            left_ok = left is None or (uniform.pop(left) and left.val == node.val)
            right_ok = right is None or (uniform.pop(right) and right.val == node.val)
            uniform[node] = left_ok and right_ok
            count += int(uniform[node])
        return count
```

### 复杂度

n 个节点、树高 h；时间 O(n)，辅助空间 O(h)。每层至多保留一个尚未合并的兄弟结果。
