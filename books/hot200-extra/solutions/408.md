# 408. 有效单词缩写


### 题意

判断给定缩写能否完整表示一个单词，字母必须逐个匹配，正整数表示跳过的字符个数且不允许前导零。

### 输入与约束

word 由小写英文字母组成，abbr 由字母和十进制数字组成。数字表示正的跳过长度，禁止前导零，须完整解释原词。

### 示例

keyboard 可以写成 k6d，保留首尾并跳过中间六个字符；k06d 中数字有前导零，返回 false。

### 核心不变量

每轮开始，word[:i] 已被 abbr[:j] 精确解释，游标都指向下一份尚未匹配的内容。

### 思路

双指针分别指向词和缩写。字母直接比较，数字一次解析完整并推进词指针。结束时两侧必须同时耗尽，防止跳过过多或遗漏尾部。

匹配没有分支：遇到字母就必须匹配当前字符，遇到数字就必须把整个连续数字段解释为十进制长度。故只要维护“下一个未匹配词字符”和“下一个未解析缩写字符”两个位置，走完后核对是否同时耗尽。

#### keyboard 与 k6d 的两根游标

| 步骤 | 当前状态 | 为什么这样走 |
| --- | --- | --- |
| 匹配首字母 | keyboard / k6d，读 k 后 i=1、j=1 | 两个游标都越过刚匹配的 k。 |
| 处理数字段 | 读 6，j=2，i 从 1 跳到 7 | 原词下标 1～6 全部省略。 |
| 匹配并核对 | word[7]=d，结束时 i=8、j=3，返回 true | 原词与缩写恰好同时耗尽。 |

### 边界检查

数字段表示应跳过多少个原词字符，不能有前导零。缩写读完后，原词也必须恰好用完，跳过头和只匹配前缀都应失败。

### 反例推演

用 `a01` 缩写 `ab` 不合法，尽管把 01 当成十进制 1 看起来长度合适。每段数字的首位必须非零。

### Java

#### 在读数字段前排除零开头

`i` 指 word，j 指 abbr。数字段首个字符必须在 1～9，后续才能含 0；num=num*10+digit 表示扩展同一个数。最后用等号检验 i，越过词尾也不能通过。

```java
class Solution {
    public boolean validWordAbbreviation(String word, String abbr) {
        int i = 0;
        int j = 0;

        while (i < word.length() && j < abbr.length()) {
            if (word.charAt(i) == abbr.charAt(j)) {
                ++i;
                ++j;
                continue;
            }
            if (abbr.charAt(j) <= '0' || abbr.charAt(j) > '9') return false;
            int num = 0;
            // 连续数字表示一个完整的跳过长度，不能逐位跳过。
            while (j < abbr.length() && Character.isDigit(abbr.charAt(j))) {
                num = num * 10 + abbr.charAt(j) - '0';
                ++j;
            }
            i += num;
        }

        return i == word.length() && j == abbr.length();
    }
}
```

### Python

#### 一次解析完整的跳过长度

先比较两个字母能否直接匹配，否则检查是否能开启数字段。数字循环只推动 j，段结束后一次性让 i 前进 num；输入是小写英文字母和数字，二者不会混淆。

```python
from __future__ import annotations


class Solution:
    def validWordAbbreviation(self, word: str, abbr: str) -> bool:
        i = 0
        j = 0

        while i < len(word) and j < len(abbr):
            if word[i] == abbr[j]:
                i += 1
                j += 1
                continue
            if not abbr[j].isdigit() or abbr[j] == "0":
                return False
            num = 0
            # 连续数字表示一个完整的跳过长度，不能逐位跳过。
            while j < len(abbr) and abbr[j].isdigit():
                num = num * 10 + int(abbr[j])
                j += 1
            i += num

        return i == len(word) and j == len(abbr)
```

### 复杂度

时间 O(n+m)，辅助空间 O(1)。

两个游标均单向移动。每个缩写字符最多解析一次，词内的跳过不需要逐个读取字符；题设数值范围内只使用常数个标量。

### 面试追问

**为什么 k06d 不能与 k6d 等价？** 缩写语法要求数字段为无前导零的正整数，必须在解析整个数字之前拒绝首位 0，不能先转换成整数再检查。
