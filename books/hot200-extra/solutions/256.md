# 256. 粉刷房子

### 题意

一排房子各有三种刷色成本，相邻房子颜色必须不同，求总花费最小值。

### 输入与约束

输入非空成本矩阵，每间房有三种涂色报价，相邻两房不可同色。返回总价最小值，此实现会修改成本矩阵。

### 示例

两行成本 [4,1,7]、[3,2,5]。先选第二色花 1，再选第一色花 3，总计 4。

### 核心不变量

第 i 行更新后，costs[i][c] 是涂完前 i+1 间且第 i 间为颜色 c 的最低总价。

### 思路

当前颜色只能接在另两色后面，所以把两种前缀最优成本中的较小者加到当前成本。首行即初始状态，最后取末行最小值。

前面房子如何涂色，只通过最后一间房的颜色影响下一间。因此将每行三项改写成“截至此房、末色固定”的最小总价。转移只取上一行另外两色的最小值，三种末色全算完再进入下一行。

### 边界检查

给本行某颜色算成本时，要读上一行另外两种颜色的最小值。若原地更新，要避免把刚更新的本行数据混入上一行状态。

### Java

Java 在 costs 原数组上累加。更新第 i 行三种末色时，读取的只会是 i−1 行的完成态，行内先后无关。最后必须在末行取最小，而非固定返回某一种末色。

#### 按三种末色填写第二行

| 步骤 | 当前状态 | 判断依据 |
| --- | --- | --- |
| 初始化第一房 | 三种末色的成本 [4,1,7] | 第一行没有前一房限制。 |
| 计算第二房第一色 | 3+min(1,7)=4 | 上一房必须是第二或第三色。 |
| 补齐末行 | 第二色 2+min(4,7)=6；第三色 5+min(4,1)=6 | 末行 [4,6,6] 的最小值为 4。 |

```java
import java.util.*;

class Solution {
    public int minCost(int[][] costs) {
        final int n = costs.length;

        // 本行某色只能接在上一行另外两色之后。
        for (int i = 1; i < n; ++i) {
            costs[i][0] += Math.min(costs[i - 1][1], costs[i - 1][2]);
            costs[i][1] += Math.min(costs[i - 1][0], costs[i - 1][2]);
            costs[i][2] += Math.min(costs[i - 1][0], costs[i - 1][1]);
        }

        return Math.min(costs[n - 1][0], Math.min(costs[n - 1][1], costs[n - 1][2]));
    }
}
```

### Python

Python 对每个 costs[i][c] 原地加上不同末色的最优代价，min(costs[-1]) 即全局最优。调用后输入矩阵已变成 DP 表；若要求保留原始收费，可用三个滚动变量替代。

#### 按三种末色填写第二行

| 步骤 | 当前状态 | 判断依据 |
| --- | --- | --- |
| 初始化第一房 | 三种末色的成本 [4,1,7] | 第一行没有前一房限制。 |
| 计算第二房第一色 | 3+min(1,7)=4 | 上一房必须是第二或第三色。 |
| 补齐末行 | 第二色 2+min(4,7)=6；第三色 5+min(4,1)=6 | 末行 [4,6,6] 的最小值为 4。 |

```python
from __future__ import annotations


class Solution:
    def minCost(self, costs: list[list[int]]) -> int:
        # 本行某色只能接在上一行另外两色之后。
        for i in range(1, len(costs)):
            costs[i][0] += min(costs[i - 1][1], costs[i - 1][2])
            costs[i][1] += min(costs[i - 1][0], costs[i - 1][2])
            costs[i][2] += min(costs[i - 1][0], costs[i - 1][1])

        return min(costs[-1])
```

### 面试追问

**可否每次只选本行最便宜且不冲突的颜色？** 若首行成本 [1,2,9]、次行 [1,100,100]，贪心先选第一色只能得到 101；保留第二色的前缀方案，总价却只有 3。

### 复杂度

n 间房；时间 O(n)，原地更新成本表，辅助空间 O(1)。

每间房的三个状态各比较两个前驱，颜色数固定，故总时间随房数增长。直接复用输入成本表使额外空间为常数。
