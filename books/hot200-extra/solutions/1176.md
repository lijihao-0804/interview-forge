# 1176. 健身计划评估

### 题意

逐个检查长度为 k 的连续饮食记录，热量和低于下界扣一分，高于上界加一分，求总分。

### 输入与约束

输入每日热量列表、合法窗口长度 k 和下上界 lower、upper。每个连续 k 天的总和低于下界扣一分，高于上界加一分。

### 示例

热量 [2,1,4,5]，k=2，下上界分别为 4、8。三个窗口的和为 3、5、9，得分 −1、0、1，合计 0。

### 核心不变量

评分时 sum 恰是以当前天结尾的 k 天热量和，ans 是所有已经完整经过的窗口得分之和。

### 思路

相邻窗口复用 k−1 项，加入当前值并移除离开的值。必须等窗口满 k 项再计分，等于上下界均不计。

每个连续 k 天都要评分，相邻两段重叠 k−1 天。保存上一个窗口总热量，加入今天、扣除刚离开的那天，就能避免重复求和。前 k−1 天先积累而不打分，之后每个右端点对应唯一一个应评分窗口。

### 边界检查

窗口和刚好等于下界或上界都记零分。第一段长度达到 k 后才开始评分，后面每移一格只替换一个入窗和一个出窗值。

### 反例推演

窗口和恰好等于下界或上界时，本窗口得 0 分。严格小于才减分、严格大于才加分；两个阈值不能用非严格比较。

### Java

Java 用 sum 维护当前热量。当 i>=k 时扣除 calories[i-k]，这时 sum 恰好覆盖最近 k 天。只有窗口完整后才拿它与 lower、upper 比较，阈值相等不改分。

#### 滚动比较三组两天热量

| 步骤 | 当前状态 | 判断依据 |
| --- | --- | --- |
| 第一段 | [2,1] 的和为 3<4，累计 −1 | 窗口首次达到两天。 |
| 右移一天 | 3−2+4=5，落在 [4,8]，累计仍为 −1 | 复用上一窗口的一天。 |
| 再右移一天 | 5−1+5=9>8，累计变为 0 | 最后一个窗口贡献 +1。 |

```java
import java.util.*;

class Solution {
    public int dietPlanPerformance(int[] calories, int k, int lower, int upper) {
        int ans = 0;
        int sum = 0;

        for (int i = 0; i < calories.length; ++i) {
            sum += calories[i];
            // 未满一个窗口前不计分，之后移出离开窗口的热量。
            if (i < k - 1) continue;
            if (i >= k) sum -= calories[i - k];
            if (sum < lower) --ans;
            else if (sum > upper) ++ans;
        }

        return ans;
    }
}
```

### Python

Python 的 enumerate 提供离窗索引所需的 i，summ 做滚动累加，ans 只记录扣分与加分后的净值。固定窗口长度让每项最多被加一次、减一次。

#### 滚动比较三组两天热量

| 步骤 | 当前状态 | 判断依据 |
| --- | --- | --- |
| 第一段 | [2,1] 的和为 3<4，累计 −1 | 窗口首次达到两天。 |
| 右移一天 | 3−2+4=5，落在 [4,8]，累计仍为 −1 | 复用上一窗口的一天。 |
| 再右移一天 | 5−1+5=9>8，累计变为 0 | 最后一个窗口贡献 +1。 |

```python
from __future__ import annotations


class Solution:
    def dietPlanPerformance(
        self,
        calories: list[int],
        k: int,
        lower: int,
        upper: int,
    ) -> int:
        ans = 0
        summ = 0

        for i, calorie in enumerate(calories):
            summ += calorie
            # 未满一个窗口前不计分，之后移出离开窗口的热量。
            if i < k - 1:
                continue
            if i >= k:
                summ -= calories[i - k]
            if summ < lower:
                ans -= 1
            elif summ > upper:
                ans += 1

        return ans
```

### 面试追问

**如果今天正好等于上界要得分吗？** 比较对象是整个 k 天窗口的和，只有严格高于上界才加一；等于任一阈值均保持原分。

### 复杂度

n 天；时间 O(n)，辅助空间 O(1)。

每项热量被加入窗口一次、移出最多一次，评分只做常数个比较；只维护窗口和与累计分数。
