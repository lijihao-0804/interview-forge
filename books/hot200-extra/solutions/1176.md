# 1176. 健身计划评估

### 题意

逐个检查长度为 k 的连续饮食记录，热量和低于下界扣一分，高于上界加一分，求总分。

### 示例

热量 [2,1,4,5]，k=2，下上界分别为 4、8。三个窗口的和为 3、5、9，得分 −1、0、1，合计 0。

### 思路

相邻窗口复用 k−1 项，加入当前值并移除离开的值。必须等窗口满 k 项再计分，等于上下界均不计。

### 边界检查

窗口和刚好等于下界或上界都记零分。第一段长度达到 k 后才开始评分，后面每移一格只替换一个入窗和一个出窗值。

### Java

```java
import java.util.*;

class Solution {
    public int dietPlanPerformance(int[] calories, int k, int lower, int upper) {
        int ans = 0;
        int sum = 0;

        for (int i = 0; i < calories.length; ++i) {
            sum += calories[i];
            // 未满一个窗口前不计分，之后移出离开窗口的热量。
            if (i < k - 1) continue;
            if (i >= k) sum -= calories[i - k];
            if (sum < lower) --ans;
            else if (sum > upper) ++ans;
        }

        return ans;
    }
}
```

### Python

```python
from __future__ import annotations


class Solution:
    def dietPlanPerformance(
        self,
        calories: list[int],
        k: int,
        lower: int,
        upper: int,
    ) -> int:
        ans = 0
        summ = 0

        for i, calorie in enumerate(calories):
            summ += calorie
            # 未满一个窗口前不计分，之后移出离开窗口的热量。
            if i < k - 1:
                continue
            if i >= k:
                summ -= calories[i - k]
            if summ < lower:
                ans -= 1
            elif summ > upper:
                ans += 1

        return ans
```

n 天；时间 O(n)，辅助空间 O(1)。
