# 444. 序列重建


### 题意

给定一个目标排列及若干子序列约束，判断是否只能重建出这一种排列。

### 输入与约束

目标 org 是 1…n 的一个排列，seqs 给出必须按序出现的子序列。只有覆盖所有目标元素且唯一重建成 org 才返回真。

### 示例

目标 [1,2,3]、约束 [[1,2],[1,3]]。取出 1 后 2 与 3 都可选，答案为 false；再加入 [2,3] 就唯一。

### 核心不变量

已输出的拓扑前缀与目标一致，队列包含且仅包含剩余图中入度为零的所有点。

### 思路

把每对相邻约束元素变为有向边。拓扑排序每一步必须恰有一个零入度点，并与目标的下一项一致；最后还要检查所有节点均被覆盖。

给出子序列就是给出若干必须先后的关系，将相邻两项连成边，传递关系自然通过路径体现。一个目标要成为唯一合法顺序，除了自身满足所有边，在每个位置也必须没有第二个可选点。去掉唯一点后，对剩余图重复这个判断。

#### 从两个可选点到唯一后继

| 步骤 | 当前状态 | 为什么这样走 |
| --- | --- | --- |
| 建立两个约束 | 1→2、1→3，入度 [0,1,1]，候选 [1] | 第一位暂时唯一且吻合目标。 |
| 移除顶点 1 | 2、3 的入度都降到 0，候选 [2,3] | 第二位出现分歧，原约束返回 false。 |
| 补入 2→3 | 移除 1 后仅 2 可选，再移除 2 才轮到 3 | 顺序被强制为 [1,2,3]，返回 true。 |

### 边界检查

每步拓扑排序若同时有两个可选节点，就已经存在不同的重建顺序。即使最后得到的一种排序碰巧等于目标，也不能称为唯一。

### Java

#### 入度、目标下标与重复边

`inDegrees` 表示尚未移除的先决边数。输入编号 1…n 转为数组下标 0…n−1，与 org 比较时同样减一。重复边会分别计入和扣除，保持入度平衡。

```java
import java.util.*;
import java.util.stream.*;

class Solution {
    public boolean sequenceReconstruction(int[] org, List<List<Integer>> seqs) {
        if (seqs.isEmpty()) return false;

        final int n = org.length;
        List<Integer>[] graph = new List[n];
        int[] inDegrees = new int[n];
        Arrays.setAll(graph, i -> new ArrayList<>());

        Set<Integer> present = new HashSet<>();

        for (List<Integer> seq : seqs) {
            present.addAll(seq);
            if (!seq.isEmpty() && (seq.get(0) < 1 || seq.get(0) > n)) return false;
            for (int i = 0; i + 1 < seq.size(); ++i) {
                final int u = seq.get(i);
                final int v = seq.get(i + 1);
                if (u < 1 || u > n || v < 1 || v > n) return false;
                graph[u - 1].add(v - 1);
                ++inDegrees[v - 1];
            }
        }

        if (present.size() != n) return false;

        Queue<Integer> q =
                IntStream.range(0, n)
                        .filter(i -> inDegrees[i] == 0)
                        .boxed()
                        .collect(Collectors.toCollection(ArrayDeque::new));

        int i = 0;

        while (!q.isEmpty()) {
            // 同时有两个可选的零入度点，就存在不同的重建顺序。
            if (q.size() > 1) return false;
            final int u = q.poll();
            if (u != org[i] - 1) return false;
            ++i;
            for (final int v : graph[u]) if (--inDegrees[v] == 0) q.offer(v);
        }

        return i == n;
    }
}
```

### Python

#### 检查覆盖后要求队列仅一项

集合先核对序列是否覆盖全部元素，再用 deque 存当前全部零入度点。即使每轮都只取了一个点，若最后 i<n，表示仍有环，不能形成完整排列。

```python
from __future__ import annotations
import collections


class Solution:
    def sequenceReconstruction(
        self,
        org: list[int],
        seqs: list[list[int]],
    ) -> bool:
        if not seqs:
            return False

        n = len(org)
        if len({v for seq in seqs for v in seq}) != n:
            return False
        graph = [[] for _ in range(n)]
        inDegrees = [0] * n

        for seq in seqs:
            if seq and not 1 <= seq[0] <= n:
                return False
            for u, v in zip(seq, seq[1:]):
                if u < 1 or u > n or v < 1 or v > n:
                    return False
                graph[u - 1].append(v - 1)
                inDegrees[v - 1] += 1

        q = collections.deque([i for i, d in enumerate(inDegrees) if d == 0])
        i = 0

        while q:
            # 同时有两个可选的零入度点，就存在不同的重建顺序。
            if len(q) > 1:
                return False
            u = q.popleft()
            if u != org[i] - 1:
                return False
            i += 1
            for v in graph[u]:
                inDegrees[v] -= 1
                if inDegrees[v] == 0:
                    q.append(v)

        return i == n
```

### 复杂度

总输入长度 S，时间 O(n+S)，邻接表和入度计数占 O(n+S)。

建图按输入中的相邻项加边，遍历时每条边只扣一次入度；队列与入度数组各至多 n 个位置。

### 面试追问

**给出一种拓扑排序恰好等于目标就足够了吗？** 不足。若某步能选 2 也能选 3，在无环图中两者都能首先加入剩余的合法排序，目标就不是唯一解。
