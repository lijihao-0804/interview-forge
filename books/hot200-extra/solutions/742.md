# 742. 二叉树最近的叶节点

### 题意

给出值唯一的二叉树和目标节点的值，返回离目标边数最少的一个叶节点的值。

### 输入与约束

给定非空二叉树及其中唯一值为 k 的节点。距离按无向边数计算，叶节点按原树孩子定义；并列最近时可返回任一叶值。

### 示例

根 8 有左右子 4、9，4 向下还有一条三条边的单支。目标为 4，向上到 8 再到叶 9 只需两步，返回 9。

### 核心不变量

队列出队距离从小到大，seen 保证每个节点首次到达时已走最少边。

### 思路

把二叉树当作无向图搜索。先用显式栈记下每个节点的父节点，并找到目标节点；再从目标开始按层走向左子、右子或父节点，遇到的第一个叶子距离最短。叶子只按原树有没有孩子判断。

树的给定指针只能向下走，而到叶节点的最短路可以先向父节点走。先用一次遍历补出父指针，再把每条边当成无权双向边做 BFS。出队距离非递减，遇到的第一个原树叶节点即可返回。

### 边界检查

离目标最近的叶子可能在父节点的另一棵子树里。把父子边当作可双向走的边后，用原树的左右孩子判断叶子，根只有一个孩子时也不会被误认成叶子。

### 反例推演

目标节点的后代叶子距它 3 条边，而其父节点的另一侧只有一个叶子，距它 2 条边。只在目标子树内搜索会遗漏向上走的最短路径。

### Java

Java 用 IdentityHashMap 记录节点对象到父对象的对应，再用基于 identity 的集合记已入队节点。反向边会让同一路径来回走，因此邻居只有首次见到才入队。

#### 由目标 4 展开两层 BFS

| 步骤 | 当前状态 | 判断依据 |
| --- | --- | --- |
| 建立反向边 | parent[4]=8，parent[9]=8；起点为 4 | 从目标可以选择向父节点或孩子移动。 |
| 第一层扩展 | 距 4 一步的是它的单支孩子与 8 | 两者都不是叶子，继续扩展。 |
| 到达第二层 | 经 8 到叶 9，距离为 2 | 向下单支的末端距离为 3，返回 9。 |

```java
import java.util.*;

class Solution {
    public int findClosestLeaf(TreeNode root, int k) {
        Map<TreeNode, TreeNode> parent = new IdentityHashMap<>();
        Deque<TreeNode> stack = new ArrayDeque<>();
        stack.push(root);
        TreeNode start = null;
        while (!stack.isEmpty()) {
            TreeNode node = stack.pop();
            if (node.val == k) start = node;
            for (TreeNode child : new TreeNode[] {node.left, node.right}) {
                if (child != null) {
                    parent.put(child, node);
                    stack.push(child);
                }
            }
        }

        Deque<TreeNode> queue = new ArrayDeque<>();
        Set<TreeNode> seen = Collections.newSetFromMap(new IdentityHashMap<>());
        queue.add(start);
        seen.add(start);
        while (!queue.isEmpty()) {
            TreeNode node = queue.remove();
            // 回到父节点的路径也可能比向下走更短。
            if (node.left == null && node.right == null) return node.val;
            for (TreeNode next : new TreeNode[] {node.left, node.right, parent.get(node)}) {
                if (next != null && seen.add(next)) queue.add(next);
            }
        }
        throw new IllegalStateException();
    }
}
```

### Python

Python 先用 stack 扫整棵树并定位 start，再用 deque.popleft 由近到远扩展。叶子的判定依旧是左右孩子都为 None；根在无向图中的度数为一，也可能并非原树叶子。

#### 由目标 4 展开两层 BFS

| 步骤 | 当前状态 | 判断依据 |
| --- | --- | --- |
| 建立反向边 | parent[4]=8，parent[9]=8；起点为 4 | 从目标可以选择向父节点或孩子移动。 |
| 第一层扩展 | 距 4 一步的是它的单支孩子与 8 | 两者都不是叶子，继续扩展。 |
| 到达第二层 | 经 8 到叶 9，距离为 2 | 向下单支的末端距离为 3，返回 9。 |

```python
from collections import deque


class Solution:
    def findClosestLeaf(self, root, k: int) -> int:
        parent = {root: None}
        stack = [root]
        while stack:
            node = stack.pop()
            if node.val == k:
                start = node
            for child in (node.left, node.right):
                if child is not None:
                    parent[child] = node
                    stack.append(child)
        queue = deque([start])
        seen = {start}
        # 按距离逐层扩展，首次遇到的叶节点距离最短。
        while queue:
            node = queue.popleft()
            if node.left is None and node.right is None:
                return node.val
            for neighbor in (node.left, node.right, parent[node]):
                if neighbor is not None and neighbor not in seen:
                    seen.add(neighbor)
                    queue.append(neighbor)
```

### 面试追问

**为什么不能直接找目标子树的最浅叶子？** 示例中向下必须走三步。绕父节点到兄弟子树只走两步，限定在目标子树会排除最优解。

### 复杂度

n 个节点；时间 O(n)，父节点映射、访问集合和队列共 O(n) 空间。

建父映射访问全树一次，BFS 中每个节点最多入队一次，并只检查三个邻居，故总工作量线性。
