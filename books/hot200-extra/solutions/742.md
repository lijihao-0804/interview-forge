# 742. 二叉树最近的叶节点

### 题意

给出值唯一的二叉树和目标节点的值，返回离目标边数最少的一个叶节点的值。

### 示例

根 8 有左右子 4、9，4 向下还有一条三条边的单支。目标为 4，向上到 8 再到叶 9 只需两步，返回 9。

### 思路

把二叉树当作无向图搜索。先用显式栈记下每个节点的父节点，并找到目标节点；再从目标开始按层走向左子、右子或父节点，遇到的第一个叶子距离最短。叶子只按原树有没有孩子判断。

### 边界检查

离目标最近的叶子可能在父节点的另一棵子树里。把父子边当作可双向走的边后，用原树的左右孩子判断叶子，根只有一个孩子时也不会被误认成叶子。

### Java

```java
import java.util.*;

class Solution {
    public int findClosestLeaf(TreeNode root, int k) {
        Map<TreeNode, TreeNode> parent = new IdentityHashMap<>();
        Deque<TreeNode> stack = new ArrayDeque<>();
        stack.push(root);
        TreeNode start = null;
        while (!stack.isEmpty()) {
            TreeNode node = stack.pop();
            if (node.val == k) start = node;
            for (TreeNode child : new TreeNode[] {node.left, node.right}) {
                if (child != null) {
                    parent.put(child, node);
                    stack.push(child);
                }
            }
        }

        Deque<TreeNode> queue = new ArrayDeque<>();
        Set<TreeNode> seen = Collections.newSetFromMap(new IdentityHashMap<>());
        queue.add(start);
        seen.add(start);
        while (!queue.isEmpty()) {
            TreeNode node = queue.remove();
            // 回到父节点的路径也可能比向下走更短。
            if (node.left == null && node.right == null) return node.val;
            for (TreeNode next : new TreeNode[] {node.left, node.right, parent.get(node)}) {
                if (next != null && seen.add(next)) queue.add(next);
            }
        }
        throw new IllegalStateException();
    }
}
```

### Python

```python
from collections import deque


class Solution:
    def findClosestLeaf(self, root, k: int) -> int:
        parent = {root: None}
        stack = [root]
        while stack:
            node = stack.pop()
            if node.val == k:
                start = node
            for child in (node.left, node.right):
                if child is not None:
                    parent[child] = node
                    stack.append(child)
        queue = deque([start])
        seen = {start}
        # 按距离逐层扩展，首次遇到的叶节点距离最短。
        while queue:
            node = queue.popleft()
            if node.left is None and node.right is None:
                return node.val
            for neighbor in (node.left, node.right, parent[node]):
                if neighbor is not None and neighbor not in seen:
                    seen.add(neighbor)
                    queue.append(neighbor)
```

### 复杂度

n 个节点；时间 O(n)，父节点映射、访问集合和队列共 O(n) 空间。
