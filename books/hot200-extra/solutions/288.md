# 288. 单词的唯一缩写


### 题意

词典中的单词用首字母、省略的字符数、末字母缩写；长度不超过二的词保持原样。判断查询词是否与另一个不同的词共用缩写。

### 输入与约束

构造器接收可能含重复词的词典；查询可在词典内或外。只要没有另一个不同的词共用其缩写，即应返回真。

### 示例

词典 ["stone","stare","at","at"] 中，stone 与 stare 都是 s3e，所以查询 stone 得 false；at 重复但属于同一个词，查询 at 得 true。

### 核心不变量

处理完的每个缩写键对应唯一性标志，只有恰好一种不同原词占用该键时才为真。

### 思路

先按完整单词去重，再按缩写记录它是否只对应一个词。查询时若缩写不存在，或它唯一且查询词就在词典中，便可通过。

查询针对的是“另一个词”。一个缩写桶有三种情况：空桶一定通过；多词桶一定失败；单词桶只有查询词恰为那个原词才通过。这个分类解释了为什么要同时保存原词集合和桶的唯一性。

#### stone 与 stare 争用一个桶

| 步骤 | 当前状态 | 为什么这样走 |
| --- | --- | --- |
| 提取不同词 | 词典去重后为 {stone,stare,at} | 两个 at 只拥有一个词的身份。 |
| 构造缩写桶 | s3e 对应两词，at 对应一词 | 统计冲突时只算不同身份。 |
| 查询原词 | stone → false，at → true | stone 与 stare 冲突，at 没有别的竞争词。 |

### 边界检查

词典里重复的同一个词只占一个身份。只有不同的单词共享缩写时才发生冲突，原词碰到自己不算冲突。

### 反例推演

字典只有两个重复的 `deer` 时，查询 deer 仍然唯一；若再加入 door 才不唯一。缩写冲突按不同原词计数，不按词条出现次数计数。

### Java

#### 用 Boolean 区分三种缩写桶

`HashSet` 先消掉重复词，`Map<String,Boolean>` 的 null、true、false 分别代表三类桶。第一次见缩写写 true，以后每次见它都写 false，第三个不同词也不会把标记翻回去。

```java
import java.util.*;

class ValidWordAbbr {
    public ValidWordAbbr(String[] dictionary) {
        dict = new HashSet<>(Arrays.asList(dictionary));

        // 同一原词要先去重，只有不同原词共用缩写才算冲突。
        for (final String word : dict) {
            final String abbr = getAbbr(word);
            abbrUnique.put(abbr, !abbrUnique.containsKey(abbr));
        }
    }

    public boolean isUnique(String word) {
        final String abbr = getAbbr(word);
        final Boolean hasAbbr = abbrUnique.get(abbr);
        return hasAbbr == null || hasAbbr && dict.contains(word);
    }

    private Set<String> dict;
    private Map<String, Boolean> abbrUnique = new HashMap<>();

    private String getAbbr(final String s) {
        final int n = s.length();
        if (n <= 2) return s;
        return s.charAt(0) + Integer.toString(n - 2) + s.charAt(n - 1);
    }
}
```

### Python

#### 先去重再记录缩写身份

`abbr not in self.abbrUnique` 在写入新标记前求值。查询单词即便产生一个已有的唯一缩写，也要用 `word in self.dict` 确认身份。长度 2 的 at 直接作为自己的键。

```python
from __future__ import annotations


class ValidWordAbbr:
    def __init__(self, dictionary: list[str]):
        self.dict = set(dictionary)

        self.abbrUnique = {}

        # 同一原词要先去重，只有不同原词共用缩写才算冲突。
        for word in self.dict:
            abbr = self._getAbbr(word)
            self.abbrUnique[abbr] = abbr not in self.abbrUnique

    def isUnique(self, word: str) -> bool:
        abbr = self._getAbbr(word)
        return abbr not in self.abbrUnique or self.abbrUnique[abbr] and word in self.dict

    def _getAbbr(self, s: str) -> str:
        n = len(s)
        if n <= 2:
            return s
        return s[0] + str(n - 2) + s[-1]
```

### 复杂度

建表时间 O(S)，S 是输入总字符数；存储 O(S)。单次查询含字符串哈希为 O(L)，L 为词长。

去重和字符串哈希的费用随输入字符总数增长。查询不扫描词典，只计算缩写并最多检查一次完整原词。

### 面试追问

**若还要支持删除词，布尔标记够吗？** 删除一个冲突者后要知道还剩几种词。可给每个桶维护原词集合；若按出现次数删除，还需原词的频数。
