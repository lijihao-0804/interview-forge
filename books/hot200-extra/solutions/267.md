# 267. 回文排列 II

### 题意

列出给定字符串能组成的所有不同回文排列，不能组成时返回空集合。

### 输入与约束

输入字符串，返回使用全部字符的所有不同回文排列；若不存在则返回空列表，结果顺序不限。

### 示例

串 `aabb` 的左半可为 ab 或 ba，镜像后分别是 abba、baab，没有别的结果。

### 核心不变量

路径表示回文的左半前缀，used 与该路径中的候选副本完全对应，同值副本按固定顺序占用。

### 思路

先确定唯一可能的奇数中心，再从每种字符拿一半组成左半。只枚举不同的半串排列，镜像即可得到完整回文，避免在全排列上筛选。

任一回文只要确定了左半及中心，右半就被唯一确定。按频数先摘出奇数中心，再把每种字符放入候选池 floor(count/2) 次。回溯只排列这些候选，省去对完整字符串全排列后再判回文的工作。

### 边界检查

先生成一半，再在中间放上唯一的奇数字符并镜像。若直接给整个字符串生成排列，重复字母会带来大量相同分支。

### Java

Java 按字符分桶生成 candidates，因此同字符的副本相邻；used 记录具体副本是否在当前路径。前一个相同副本未使用时跳过后一个，确保同层相同字母只开一次分支。

#### 枚举两个不同的左半再镜像

| 步骤 | 当前状态 | 判断依据 |
| --- | --- | --- |
| 拆成半串 | aabb 的频数 a:2、b:2，左半候选 [a,b]，中心为空 | 每个左右配对只在左侧选一次。 |
| 先选 a | 左半 ab，镜像 ba，得到 abba | 剩余位置只能使用 b。 |
| 先选 b | 左半 ba，镜像 ab，得到 baab | 两个左半互异，完整回文也互异。 |

```java
import java.util.*;

class Solution {
    public List<String> generatePalindromes(String s) {
        int odd = 0;
        Map<Character, Integer> count = new HashMap<>();

        for (final char c : s.toCharArray()) count.merge(c, 1, Integer::sum);

        for (Map.Entry<Character, Integer> entry : count.entrySet())
            if (entry.getValue() % 2 == 1) ++odd;

        // 超过一个奇数频次无法组成回文；其余字符按半数参与排列。
        if (odd > 1) return new ArrayList<>();

        List<String> ans = new ArrayList<>();
        List<Character> candidates = new ArrayList<>();
        StringBuilder mid = new StringBuilder();

        for (Map.Entry<Character, Integer> entry : count.entrySet()) {
            final char key = entry.getKey();
            final int value = entry.getValue();
            if (value % 2 == 1) mid.append(key);
            for (int i = 0; i < value / 2; ++i) candidates.add(key);
        }

        dfs(candidates, mid, new boolean[candidates.size()], new StringBuilder(), ans);
        return ans;
    }

    private void dfs(
            List<Character> candidates,
            StringBuilder mid,
            boolean[] used,
            StringBuilder sb,
            List<String> ans) {
        if (sb.length() == candidates.size()) {
            ans.add(sb.toString() + mid + sb.reverse().toString());
            sb.reverse();
            return;
        }

        for (int i = 0; i < candidates.size(); ++i) {
            if (used[i]) continue;
            if (i > 0 && candidates.get(i).equals(candidates.get(i - 1)) && !used[i - 1]) continue;
            used[i] = true;
            sb.append(candidates.get(i));
            dfs(candidates, mid, used, sb, ans);
            sb.deleteCharAt(sb.length() - 1);
            used[i] = false;
        }
    }
}
```

### Python

Python 用 Counter 统计频数，candidates 按各个键成组加入，path 仅保存左半。到达完整长度时 join(path)、mid、反转的 path 一次拼成结果；回溯使用 pop 和恢复 used 撤销选择。

#### 枚举两个不同的左半再镜像

| 步骤 | 当前状态 | 判断依据 |
| --- | --- | --- |
| 拆成半串 | aabb 的频数 a:2、b:2，左半候选 [a,b]，中心为空 | 每个左右配对只在左侧选一次。 |
| 先选 a | 左半 ab，镜像 ba，得到 abba | 剩余位置只能使用 b。 |
| 先选 b | 左半 ba，镜像 ab，得到 baab | 两个左半互异，完整回文也互异。 |

```python
from __future__ import annotations
import collections


class Solution:
    def generatePalindromes(self, s: str) -> list[str]:
        count = collections.Counter(s)

        odd = sum(value & 1 for value in count.values())

        # 超过一个奇数频次无法组成回文；其余字符按半数参与排列。
        if odd > 1:
            return []

        ans = []
        candidates = []
        mid = ""

        for key, value in count.items():
            if value % 2 == 1:
                mid += key
            for _ in range(value // 2):
                candidates.append(key)

        def dfs(used: list[bool], path: list[str]) -> None:

            if len(path) == len(candidates):
                ans.append("".join(path) + mid + "".join(reversed(path)))
                return

            for i, candidate in enumerate(candidates):
                if used[i]:
                    continue
                if i > 0 and candidate == candidates[i - 1] and not used[i - 1]:
                    continue
                used[i] = True
                path.append(candidate)
                dfs(used, path)
                path.pop()
                used[i] = False

        dfs([False] * len(candidates), [])
        return ans
```

### 面试追问

**如何知道不会漏掉重复字符组成的回文？** 对每个字符约定多个副本必须按出现顺序占用。每种值序列都有这种规范占用方式，删掉的只是交换等值副本产生的重复路径。

### 复杂度

n 个字符，m=⌊n/2⌋；时间上界 O(n²·m!)，除结果外空间 O(n)。

当前实现每层枚举 m 个候选下标，最多 m 层且最坏有 m! 个叶子，因此采用 O(n²·m!) 的保守上界；每个输出另需 O(n) 字符。
