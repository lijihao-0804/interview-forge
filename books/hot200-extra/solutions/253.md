# 253. 会议室 II

### 题意

给定所有会议的时间段，计算同时承办它们所需的最少会议室数。

### 输入与约束

输入一组开始时刻早于结束时刻的会议区间，结束时刻等于另一场开始时刻时可复用房间。求同时容纳全部会议的最少房数。

### 示例

[1,5]、[2,3]、[3,4] 可以用两间房。第三场复用第二场的房间，峰值仍为 2。

### 核心不变量

堆中每个条目对应一间已开房的最近结束时刻，堆顶是最早可复用的房间。

### 思路

按开始时间处理；已经结束的会议室可复用。峰值就是重叠会议数，某场结束与另一场开始同刻时，先释放房间。

按开始时刻依次分房。当最早空出的房间都还在使用，当前会议便与所有已开房间冲突，增开一间是必要的；若最早的房间已空，直接复用即可。堆里为每间开过的房保留一个最新结束时间，因此堆大小表示迄今配置的房数。

### 边界检查

同一分钟有人离场、另一人入场，可以复用同一间房。结合 `[2,3]` 与 `[3,4]` 检查事件比较或堆顶弹出的条件。

### Java

Java 的 `PriorityQueue<Integer>` 自动把最小结束时刻放在堆顶。每安排一场最多 poll 一个可复用房间，再 offer 当前结束时间。其余已空房可以保留，等待未来的会议使用。

#### 观察房间结束时间的堆顶

| 步骤 | 当前状态 | 判断依据 |
| --- | --- | --- |
| 安排第一场 | [1,5] 占第一间，堆中结束时间 {5} | 没有旧房可以复用。 |
| 安排第二场 | 开始 2<5，新开一间；结束时间 {3,5} | 两场实际重叠，至少两间。 |
| 安排第三场 | 开始 3=最早结束 3，复用后为 {4,5} | 总房间数保持 2。 |

```java
import java.util.Arrays;
import java.util.PriorityQueue;

class Solution {
    public int minMeetingRooms(int[][] intervals) {
        if (intervals.length == 0) {
            return 0;
        }

        // 1. 按会议开始时间升序排序
        Arrays.sort(intervals, (a, b) -> Integer.compare(a[0], b[0]));

        // 2. 小根堆：存放每间已开房间的最近结束时间，堆顶是最早可复用的
        PriorityQueue<Integer> heap = new PriorityQueue<>();

        // 优先复用最早结束的房间，堆顶结束时间大于起点才需新房间。
        for (int[] it : intervals) {
            // 3. 若最早结束的会议已经结束，可复用这间会议室
            if (!heap.isEmpty() && it[0] >= heap.peek()) {
                heap.poll();
            }
            // 占用（或新开）一间会议室
            heap.offer(it[1]);
        }

        // 4. 堆的大小即为所需的最少会议室数
        return heap.size();
    }
}
```

### Python

Python 读 heap[0] 判断是否可复用。复用时一弹一压，房间数不变；只有最早结束时间仍大于 start 时才只压不弹。正因保留已开房间，最后的 len(heap) 就是峰值容量。

#### 观察房间结束时间的堆顶

| 步骤 | 当前状态 | 判断依据 |
| --- | --- | --- |
| 安排第一场 | [1,5] 占第一间，堆中结束时间 {5} | 没有旧房可以复用。 |
| 安排第二场 | 开始 2<5，新开一间；结束时间 {3,5} | 两场实际重叠，至少两间。 |
| 安排第三场 | 开始 3=最早结束 3，复用后为 {4,5} | 总房间数保持 2。 |

```python
import heapq
from typing import List


class Solution:
    def minMeetingRooms(self, intervals: List[List[int]]) -> int:
        if not intervals:
            return 0

        # 按开始时间升序排序
        intervals.sort(key=lambda x: x[0])

        heap = []  # 小根堆，保存每间已开房间的最近结束时间
        # 优先复用最早结束的房间，堆顶结束时间大于起点才需新房间。
        for start, end in intervals:
            # 最早结束的会议已结束，可复用这间会议室
            if heap and start >= heap[0]:
                heapq.heappop(heap)
            heapq.heappush(heap, end)

        # 堆的大小即为最少会议室数量
        return len(heap)
```

### 面试追问

**为什么这里不循环弹出所有过期会议？** 本实现跟踪已配置的房间数。若全部弹出，堆表示当前仍开会的数量，应另存最大堆大小才得到峰值。

### 复杂度

n 场会议；时间 O(n log n)，空间 O(n)。

每场会议进行至多一次堆弹出与一次压入，单次为 O(log n)，加上排序仍为 O(n log n)。最坏所有会议重叠，堆长 n。
