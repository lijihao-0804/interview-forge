# 272. 最接近的二叉搜索树值 II

### 题意

从二叉搜索树里找出距离目标实数最近的 k 个值，返回顺序不限。

### 输入与约束

输入 BST、实数 target 及不超过节点数的 k。返回 k 个最接近的值，题设保证答案集合唯一，返回顺序不限。

### 示例

树中有 1、3、6、8，目标 4.1，k=2；首选 3，再选 6，答案为 {3,6}。

### 核心不变量

lower 栈顶是尚未取出的最大前驱，higher 栈顶是最小后继，下一近邻必在两者中。

### 思路

沿搜索路径把不大于目标的节点放进前驱栈，大于目标的放进后继栈。栈顶分别是两侧最近候选。每次取距离较小者：若取前驱，进入其左子树并沿右边界入栈；若取后继，进入其右子树并沿左边界入栈。只需推进 k 次。

把 BST 的有序序列沿目标分开：左边从大到小扫描，右边从小到大扫描，两边各自离目标越来越远。因此每轮只比较两条序列的头部，选走全局最近的候选。双栈充当两个惰性迭代器，可以省去整树中序数组。

### 边界检查

返回的是 k 个最近的值，题目接受不同的排列顺序。验证时先比较成员，再看是否有更靠近目标却被落掉的候选。

### 反例推演

目标恰等于节点值 4，且 k=2。把等于目标的节点同时压入前驱和后继两边会返回两个 4，尽管树中只有一个该节点。

### Java

Java 的两个 Deque 分存前驱与后继。取前驱后，要从其左孩子沿右链找到下一前驱；取后继则从右孩子沿左链。压入的路径留待后续轮次消费，无需每次回到根重新搜索。

#### 比较前驱和后继的两端距离

| 步骤 | 当前状态 | 判断依据 |
| --- | --- | --- |
| 定位两侧候选 | 目标 4.1；左侧从近到远 3、1，右侧 6、8 | 两侧各自有序。 |
| 第一次比较 | 3 距 1.1，6 距 1.9；先取 3 | 左侧下一候选变成 1。 |
| 第二次比较 | 1 距 3.1，6 距 1.9；取 6 | 已有 k=2 个数，结果为 {3,6}。 |

```java
import java.util.*;

class Solution {
    public List<Integer> closestKValues(TreeNode root, double target, int k) {
        Deque<TreeNode> lower = new ArrayDeque<>(), higher = new ArrayDeque<>();
        for (TreeNode node = root; node != null; ) {
            if (node.val <= target) {
                lower.push(node);
                node = node.right;
            } else {
                higher.push(node);
                node = node.left;
            }
        }
        List<Integer> answer = new ArrayList<>();
        while (answer.size() < k) {
            boolean takeLower =
                    higher.isEmpty()
                            || (!lower.isEmpty()
                                    && target - lower.peek().val <= higher.peek().val - target);
            Deque<TreeNode> stack = takeLower ? lower : higher;
            TreeNode closest = stack.pop();
            answer.add(closest.val);
            // 前驱转向左子树找最大值，后继转向右子树找最小值。
            TreeNode node = takeLower ? closest.left : closest.right;
            while (node != null) {
                stack.push(node);
                node = takeLower ? node.right : node.left;
            }
        }
        return answer;
    }
}
```

### Python

Python 的 lower[-1] 与 higher[-1] 分别是两侧当前最近候选。一侧为空时直接选另一侧，防止读取空栈。answer 长度达到 k 即停止，未被要求的远端节点不用访问。

#### 比较前驱和后继的两端距离

| 步骤 | 当前状态 | 判断依据 |
| --- | --- | --- |
| 定位两侧候选 | 目标 4.1；左侧从近到远 3、1，右侧 6、8 | 两侧各自有序。 |
| 第一次比较 | 3 距 1.1，6 距 1.9；先取 3 | 左侧下一候选变成 1。 |
| 第二次比较 | 1 距 3.1，6 距 1.9；取 6 | 已有 k=2 个数，结果为 {3,6}。 |

```python
from __future__ import annotations


class Solution:
    def closestKValues(self, root: TreeNode, target: float, k: int) -> list[int]:
        lower, higher = [], []
        node = root
        while node:
            if node.val <= target:
                lower.append(node)
                node = node.right
            else:
                higher.append(node)
                node = node.left
        answer = []
        while len(answer) < k:
            take_lower = not higher or (
                lower and target - lower[-1].val <= higher[-1].val - target
            )
            stack = lower if take_lower else higher
            closest = stack.pop()
            answer.append(closest.val)
            # 沿相邻子树的一侧下降，准备下一位候选。
            node = closest.left if take_lower else closest.right
            while node:
                stack.append(node)
                node = node.right if take_lower else node.left
        return answer
```

### 面试追问

**为何连续 k 次推进不是 O(kh)？** 搜索路径上的节点只会进入其所属的一个栈，弹出后不会再进入。除了已经取走的 k 个节点，两个栈的残余路径长度至多与树高同阶。

### 复杂度

树高 h。双栈初始化 O(h)，之后每个节点最多入栈出栈各一次，总时间 O(h+k)，辅助空间 O(h)，返回列表另占 O(k)。

每个经过的节点至多压栈弹栈一次，除取出的 k 个值外只保留高度量级的两条搜索路径，累计为 O(h+k)。
