# 360. 有序转化数组


### 题意

对升序数组各元素施加 ax²+bx+c，返回变换后的升序序列。

### 示例

[-3,-1,2] 经 x² 变成 [9,1,4]。从两端取较大值填入末尾，依次放入 9、4、1，得到 [1,4,9]。

### 思路

开口向上的抛物线在当前闭区间的最大值位于一个端点，故从大到小填；开口向下时改取端点最小值由小到大填。线性函数也满足端点性质。

### 边界检查

抛物线开口向上时，两端较大的函数值应放到结果尾部；开口向下时反过来填。即使原 x 已有序，也不能假设变换后的值仍按原顺序。

### Java

```java
class Solution {
    public int[] sortTransformedArray(int[] nums, int a, int b, int c) {
        final int n = nums.length;
        final boolean upward = a > 0;
        int[] ans = new int[n];
        int[] quad = new int[n];

        for (int i = 0; i < nums.length; ++i) quad[i] = f(nums[i], a, b, c);

        int i = upward ? n - 1 : 0;
        // 开口朝上时端点提供最大值，朝下时端点提供最小值。
        for (int l = 0, r = n - 1; l <= r; )
            if (upward) ans[i--] = quad[l] > quad[r] ? quad[l++] : quad[r--];
            else ans[i++] = quad[l] < quad[r] ? quad[l++] : quad[r--];

        return ans;
    }

    private int f(int x, int a, int b, int c) {
        return (a * x + b) * x + c;
    }
}
```

### Python

```python
from __future__ import annotations


class Solution:
    def sortTransformedArray(
        self,
        nums: list[int],
        a: int,
        b: int,
        c: int,
    ) -> list[int]:
        n = len(nums)
        upward = a > 0
        ans = [0] * n

        def f(x: int, a: int, b: int, c: int) -> int:
            return (a * x + b) * x + c

        quad = [f(num, a, b, c) for num in nums]

        i = n - 1 if upward else 0
        l = 0
        r = n - 1
        # 开口朝上时端点提供最大值，朝下时端点提供最小值。
        while l <= r:
            if upward:
                if quad[l] > quad[r]:
                    ans[i] = quad[l]
                    l += 1
                else:
                    ans[i] = quad[r]
                    r -= 1
                i -= 1
            else:
                if quad[l] < quad[r]:
                    ans[i] = quad[l]
                    l += 1
                else:
                    ans[i] = quad[r]
                    r -= 1
                i += 1

        return ans
```

### 复杂度

时间 O(n)，输出占 O(n)，预先计算变换值的实现另用 O(n)。
