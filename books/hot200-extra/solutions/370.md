# 370. 区间加法


### 题意

长度固定的全零数组，依次在一系列闭区间上增加给定数值，输出最终数组。

### 输入与约束

数组初始全零，每个更新为有效闭区间 [start,end] 与整数增量，可重叠且增量可为负。只需在全部更新后返回最终数组。

### 示例

长度 4，对 [1,3] 加 2，再对 [2,2] 减 1。差分变化为 [0,2,-1,1]，前缀和得到 [0,2,1,2]。

### 核心不变量

登记完成后，差分下标 i 的前缀和等于所有覆盖 i 的区间增量总和。

### 思路

每次只在左端加上增量，并在右端下一位减去同量（若仍在数组内）。最后一次前缀扫描把区间的影响还原为逐点的值。

所有修改先给出，最后只读取一次完整数组，没必要在每次更新时真的走遍区间。对相邻数值的差看影响：整段一起加 inc，内部相邻差都不变，只有进入和离开区间的两条边改变。

#### 单点减量的进入和撤销

| 步骤 | 当前状态 | 为什么这样走 |
| --- | --- | --- |
| 登记第一个区间 | [1,3] 加 2，line=[0,2,0,0] | 右端在数组末尾，省去退出标记。 |
| 登记单点减量 | [2,2] 减 1，line=[0,2,−1,1] | 下标 2 进入 −1，下标 3 撤销它。 |
| 还原实际数组 | 累计和依次 0、2、1、2 | 各位置自动叠加全部覆盖它的区间。 |

### 边界检查

闭区间更新在左端加值，在右端的下一格撤销。如果右端已经是最后一个元素，这次撤销可用哨兵格接住，也可直接略过。

### 反例推演

长度 4，给闭区间 [1,2] 加 5，答案是 [0,5,5,0]。抵消项在下标 3，写在 2 就少覆盖最后一个元素。

### Java

#### 用差分数组接住闭区间的退出事件

`line` 存每个下标相对前一位置的变化。endIndex+1 出界时无需登记撤销，因为返回数组里不会再读到这个界外位置。prefix 在下标 i 正好等于覆盖 i 的所有增量总和。

```java
class Solution {
    public int[] getModifiedArray(int length, int[][] updates) {
        int[] ans = new int[length];
        int[] line = new int[length];
        int prefix = 0;

        // 闭区间在左端开始生效，在右端之后撤销增量。
        for (int[] update : updates) {
            final int startIndex = update[0];
            final int endIndex = update[1];
            final int inc = update[2];
            line[startIndex] += inc;
            if (endIndex + 1 < length) line[endIndex + 1] -= inc;
        }

        for (int i = 0; i < length; ++i) {
            prefix += line[i];
            ans[i] = prefix;
        }

        return ans;
    }
}
```

### Python

#### 用 accumulate 展开所有更新

`line[end+1] -= inc` 对负增量同样成立，表示离开区间时取消此前影响。itertools.accumulate 产生逐项前缀和，最后转 list 交付数组。

```python
from __future__ import annotations
import itertools


class Solution:
    def getModifiedArray(
        self,
        length: int,
        updates: list[list[int]],
    ) -> list[int]:
        line = [0] * length

        # 闭区间在左端开始生效，在右端之后撤销增量。
        for start, end, inc in updates:
            line[start] += inc
            if end + 1 < length:
                line[end + 1] -= inc

        return list(itertools.accumulate(line))
```

### 复杂度

k 次操作与展开共 O(k+n)，返回数组及差分需要 O(n) 空间。

每个区间只做一到两次加减，共 k 次常数更新；最后一次 n 项扫描恢复数组。当前实现另保留差分表。

### 面试追问

**若每次更新后马上查询某个位置呢？** 静态差分需要重新做前缀扫描。可以用树状数组存两处边界变化，查询位置的值等于其差分前缀和。
