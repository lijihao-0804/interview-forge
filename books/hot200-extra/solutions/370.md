# 370. 区间加法


### 题意

长度固定的全零数组，依次在一系列闭区间上增加给定数值，输出最终数组。

### 示例

长度 4，对 [1,3] 加 2，再对 [2,2] 减 1。差分变化为 [0,2,-1,1]，前缀和得到 [0,2,1,2]。

### 思路

每次只在左端加上增量，并在右端下一位减去同量（若仍在数组内）。最后一次前缀扫描把区间的影响还原为逐点的值。

### 边界检查

闭区间更新在左端加值，在右端的下一格撤销。如果右端已经是最后一个元素，这次撤销可用哨兵格接住，也可直接略过。

### Java

```java
class Solution {
    public int[] getModifiedArray(int length, int[][] updates) {
        int[] ans = new int[length];
        int[] line = new int[length];
        int prefix = 0;

        // 闭区间在左端开始生效，在右端之后撤销增量。
        for (int[] update : updates) {
            final int startIndex = update[0];
            final int endIndex = update[1];
            final int inc = update[2];
            line[startIndex] += inc;
            if (endIndex + 1 < length) line[endIndex + 1] -= inc;
        }

        for (int i = 0; i < length; ++i) {
            prefix += line[i];
            ans[i] = prefix;
        }

        return ans;
    }
}
```

### Python

```python
from __future__ import annotations
import itertools


class Solution:
    def getModifiedArray(
        self,
        length: int,
        updates: list[list[int]],
    ) -> list[int]:
        line = [0] * length

        # 闭区间在左端开始生效，在右端之后撤销增量。
        for start, end, inc in updates:
            line[start] += inc
            if end + 1 < length:
                line[end + 1] -= inc

        return list(itertools.accumulate(line))
```

### 复杂度

k 次操作与展开共 O(k+n)，返回数组及差分需要 O(n) 空间。
