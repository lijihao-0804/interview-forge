# 302. 包含全部黑色像素的最小矩形


### 题意

已知某个黑像素及全部黑像素四连通，求覆盖它们的最小轴对齐矩形面积。

### 示例

图像 010 / 011 的黑像素行跨 0–1，列跨 1–2，因此最小矩形面积 2×2=4。

### 思路

四连通保证黑像素在行、列两个方向的投影各自连续。已知黑点把行区间分为两边，在上侧找首个含黑行、下侧找首个全白行；列区间同理。右边界与下边界都按开区间计算。

### 边界检查

已知黑点相当于给两段二分各提供了一个肯定含黑的端点。返回面积时注意右、下边界若取“第一个空列或空行”，宽高直接用差即可。

### Java

```java
class Solution {
    public int minArea(char[][] image, int x, int y) {
        int top = boundary(image, 0, x, true, true);
        int bottom = boundary(image, x + 1, image.length, true, false);
        int left = boundary(image, 0, y, false, true);
        int right = boundary(image, y + 1, image[0].length, false, false);
        return (bottom - top) * (right - left);
    }

    private int boundary(char[][] image, int lo, int hi, boolean rows, boolean target) {
        // 给定黑点使本侧投影单调，每轮排除一半不可能的边界。
        while (lo < hi) {
            int mid = lo + (hi - lo) / 2;
            boolean found = false;
            int span = rows ? image[0].length : image.length;
            for (int i = 0; i < span && !found; i++)
                found = (rows ? image[mid][i] : image[i][mid]) == '1';
            if (found == target) hi = mid;
            else lo = mid + 1;
        }
        return lo;
    }
}
```

### Python

```python
from __future__ import annotations


class Solution:
    def minArea(self, image: list[list[str]], x: int, y: int) -> int:
        def boundary(lo, hi, contains, target):
            # 给定黑点使本侧投影单调，每轮排除一半不可能的边界。
            while lo < hi:
                mid = (lo + hi) // 2
                if contains(mid) == target:
                    hi = mid
                else:
                    lo = mid + 1
            return lo

        def black_row(row):
            return "1" in image[row]

        def black_col(col):
            return any(row[col] == "1" for row in image)

        top = boundary(0, x, black_row, True)
        bottom = boundary(x + 1, len(image), black_row, False)
        left = boundary(0, y, black_col, True)
        right = boundary(y + 1, len(image[0]), black_col, False)
        return (bottom - top) * (right - left)
```

### 复杂度

每次检查一行花 O(n)，检查一列花 O(m)，故时间 O(n log(m+1)+m log(n+1))，额外空间 O(1)。
