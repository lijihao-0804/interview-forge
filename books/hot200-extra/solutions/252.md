# 252. 会议室

### 题意

给出一人的会议起止时间，判断能否参加全部会议，允许上一场结束时马上开始下一场。

### 示例

[1,3]、[3,5]、[4,6] 中前两场首尾相接，但 4 早于 5，故不能全部参加。

### 思路

按起点排序，检查后一个起点是否严格小于前一个终点。一旦相邻区间重叠即可返回；相等时没有时间冲突。

### 边界检查

会议按半开区间理解。如果上一场结束时间正好等于下一场开始时间，同一人可以参加两场；判定冲突时应使用严格小于。

### Java

```java
import java.util.Arrays;

class Solution {
    public boolean canAttendMeetings(int[][] intervals) {
        // 按会议开始时间升序排序
        Arrays.sort(intervals, (a, b) -> Integer.compare(a[0], b[0]));

        // 开始时间已排序，只比较相邻两场，首尾相接允许复用时间。
        for (int i = 1; i < intervals.length; i++) {
            // 当前会议的开始时间早于上一场会议的结束时间 => 时间重叠
            if (intervals[i][0] < intervals[i - 1][1]) {
                return false;
            }
        }
        return true;
    }
}
```

### Python

```python
from typing import List


class Solution:
    def canAttendMeetings(self, intervals: List[List[int]]) -> bool:
        # 按开始时间升序排序
        intervals.sort(key=lambda x: x[0])

        # 开始时间已排序，只比较相邻两场，首尾相接允许复用时间。
        for i in range(1, len(intervals)):
            # 当前会议开始时间早于上一场结束时间 => 重叠
            if intervals[i][0] < intervals[i - 1][1]:
                return False
        return True
```

### 复杂度

n 场会议；时间 O(n log n)，排序额外空间最坏 O(n)。
