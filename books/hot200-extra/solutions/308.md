# 308. 二维区域和检索 - 矩阵可修改


### 题意

实现可修改的整数矩阵，支持把一个位置改成给定值以及查询闭矩形内的总和。

### 输入与约束

构造时给出非空整数矩阵。update 设置单格新值，sumRegion 的两个角坐标均含在查询范围内，使用零基输入坐标。

### 示例

矩阵 [[1,2],[3,4]] 的右列和为 6，把右上角从 2 改为 7 后，右列和变成 11。

### 核心不变量

树状数组每个一基块始终等于其覆盖矩形内原值之和；原矩阵同时保存各格最近一次赋值。

### 思路

二维树状数组存若干矩形块的和。赋值操作先换成新旧值之差；矩形查询用四个左上前缀的容斥消掉多余部分。

普通二维前缀和查得快，但改一个格会影响其右下所有前缀。树状数组让一个格只影响对数个行块与列块的组合。内部格 (i,j) 管辖以它结尾、边长分别是 lowbit(i)、lowbit(j) 的矩形，前缀能拆成互不重叠的这些块。

#### 右上角覆盖赋值与右列查询

| 步骤 | 当前状态 | 为什么这样走 |
| --- | --- | --- |
| 初始查右列 | P(2,2)=10，P(2,1)=4，右列和 6 | 右列等于整矩形去掉左列。 |
| 把 2 改成 7 | delta=5，更新点的一基坐标为 (1,2) | 包含该点的块都加 5。 |
| 重新查右列 | P(2,2)=15，P(2,1)=4，右列和 11 | 左列没有覆盖更新点，因此保持原和。 |

### 边界检查

更新把格子设为新值，不是再把新值加一次。先求新旧差，再维护区间和结构；把同一格连续更新成同一数值应当没有影响。

### Java

#### 用 lowbit 维护二维块和

`add` 用一基坐标沿 i、j 加 lowbit 走到包含更新点的更大块。`get` 反向减 lowbit，把左上前缀恰好拆完。原矩阵保留旧值，update 因此可算 delta。

```java
class FenwickTree {
    public FenwickTree(int m, int n) {
        sums = new int[m + 1][n + 1];
    }

    public void add(int row, int col, int delta) {
        for (int i = row; i < sums.length; i += lowbit(i))
            for (int j = col; j < sums[0].length; j += lowbit(j)) sums[i][j] += delta;
    }

    public int get(int row, int col) {
        int sum = 0;
        for (int i = row; i > 0; i -= lowbit(i))
            for (int j = col; j > 0; j -= lowbit(j)) sum += sums[i][j];
        return sum;
    }

    private int[][] sums;

    private static int lowbit(int i) {
        return i & -i;
    }
}

class NumMatrix {
    public NumMatrix(int[][] matrix) {
        this.matrix = matrix;
        tree = new FenwickTree(matrix.length, matrix[0].length);
        for (int i = 0; i < matrix.length; ++i)
            for (int j = 0; j < matrix[0].length; ++j) tree.add(i + 1, j + 1, matrix[i][j]);
    }

    // 树状数组累加的是新旧值之差，重复赋同一值不会改变总和。
    public void update(int row, int col, int val) {
        tree.add(row + 1, col + 1, val - matrix[row][col]);
        matrix[row][col] = val;
    }

    public int sumRegion(int row1, int col1, int row2, int col2) {
        return tree.get(row2 + 1, col2 + 1)
                - tree.get(row1, col2 + 1)
                - tree.get(row2 + 1, col1)
                + tree.get(row1, col1);
    }

    private int[][] matrix;
    private FenwickTree tree;
}
```

### Python

#### 每轮行跳转后重启列循环

内层 while 每换一个行块都从原来的 col 重新开始，否则会漏掉后续行块里的列块。get(r,c) 表示前 r 行、前 c 列之和，查询时补回被两次扣掉的左上重叠区。

```python
from __future__ import annotations


class FenwickTree:
    def __init__(self, m: int, n: int):
        self.sums = [[0] * (n + 1) for _ in range(m + 1)]

    def add(self, row: int, col: int, delta: int) -> None:
        i = row
        while i < len(self.sums):
            j = col
            while j < len(self.sums[0]):
                self.sums[i][j] += delta
                j += FenwickTree.lowbit(j)
            i += FenwickTree.lowbit(i)

    def get(self, row: int, col: int) -> int:
        summ = 0
        i = row
        while i > 0:
            j = col
            while j > 0:
                summ += self.sums[i][j]
                j -= FenwickTree.lowbit(j)
            i -= FenwickTree.lowbit(i)
        return summ

    @staticmethod
    def lowbit(i: int) -> int:
        return i & -i


class NumMatrix:
    def __init__(self, matrix: list[list[int]]):
        self.matrix = matrix
        self.tree = FenwickTree(len(matrix), len(matrix[0]))

        for i in range(len(matrix)):
            for j, val in enumerate(matrix[i]):
                self.tree.add(i + 1, j + 1, val)

    def update(self, row: int, col: int, val: int) -> None:
        # 树状数组累加的是新旧值之差，重复赋同一值不会改变总和。
        self.tree.add(row + 1, col + 1, val - self.matrix[row][col])
        self.matrix[row][col] = val

    def sumRegion(self, row1: int, col1: int, row2: int, col2: int) -> int:
        return (
            self.tree.get(row2 + 1, col2 + 1)
            - self.tree.get(row1, col2 + 1)
            - self.tree.get(row2 + 1, col1)
            + self.tree.get(row1, col1)
        )
```

### 复杂度

逐个插入建树 O(mn log(m+1) log(n+1))；更新和查询 O(log(m+1) log(n+1))，空间 O(mn)。

每个方向沿 lowbit 走至多对数步，行列嵌套故相乘。初始化按每个原格调用一次 add，内部矩阵槽数与原矩阵同阶。
