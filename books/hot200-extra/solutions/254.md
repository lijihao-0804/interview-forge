# 254. 因子的组合

### 题意

把 n 写成至少两个大于 1 的整数之积，列出忽略因子次序后的所有拆分。

### 输入与约束

输入正整数 n，输出至少两个大于 1 且小于 n 的因子组成的乘积分解。同一组因子只记一次，顺序不影响答案。

### 示例

n=16 有 [2,8]、[2,2,4]、[2,2,2,2] 和 [4,4]；[8,2] 与 [2,8] 相同。

### 核心不变量

已选路径单调不减，路径乘积乘当前余数恒等于原始 n。

### 思路

设剩余乘积为 r。每一组尚可继续拆分的因子，较小项 d 一定不超过 √r；故只枚举从前一个因子到 √r 的整除数。找到 d 后，先输出当前路径加 [d,r/d]，然后把 r/d 当作新的余数继续拆分。

每个非递减分解的首项唯一，递归深度决定在第几个因子停止，故不会重复。对 16，d=2 给出 [2,8]，拆 8 又得到 [2,2,4] 和 [2,2,2,2]；d=4 给出 [4,4]。

### 边界检查

分解 16 时，一旦选了 4，后面的因子就从 4 起步。这样保留 `[4,4]`，也避免把 `[2,8]` 倒过来再输出一遍。

### 反例推演

对 16，`[2,2,4]` 与 `[4,2,2]` 是同一分解。递归下传上一个因子作为下界，同时保留 `[4,4]`，说明去重不能用严格递增。

### Java

#### 枚举小因子并配对输出

用 d ≤ remaining/d 判断平方根上界，避免 d*d 的整数溢出。

| 步骤 | 当前状态 | 判断依据 |
| --- | --- | --- |
| 试 d=2 | 16=2×8 | 输出 [2,8]；余数 8 可继续拆 |
| 递归拆 8 | 8=2×4 | 输出 [2,2,4]；再拆 4 有 [2,2,2,2] |
| 退回根层 | 16=4×4 | 保留 [4,4]；d 再增大就越过平方根 |

```java
import java.util.*;
class Solution {
    public List<List<Integer>> getFactors(int n) {
        List<List<Integer>> results = new ArrayList<>();
        search(n, 2, new ArrayList<>(), results);
        return results;
    }

    private void search(int remaining, int start, List<Integer> path, List<List<Integer>> results) {
        for (int d = start; d <= remaining / d; d++) {
            if (remaining % d != 0) continue;
            path.add(d);
            List<Integer> factors = new ArrayList<>(path);
            factors.add(remaining / d);
            results.add(factors);
            search(remaining / d, d, path, results);
            path.remove(path.size() - 1);
        }
    }
}
```

### Python

#### 枚举小因子并配对输出

isqrt 给出精确整数边界；新建返回列表后再回溯，避免共享随后会缩短的 path。

| 步骤 | 当前状态 | 判断依据 |
| --- | --- | --- |
| 试 d=2 | 16=2×8 | 输出 [2,8]；余数 8 可继续拆 |
| 递归拆 8 | 8=2×4 | 输出 [2,2,4]；再拆 4 有 [2,2,2,2] |
| 退回根层 | 16=4×4 | 保留 [4,4]；d 再增大就越过平方根 |

```python
from math import isqrt

class Solution:
    def getFactors(self, n: int) -> list[list[int]]:
        result = []
        path = []
        def search(remaining, start):
            for d in range(start, isqrt(remaining) + 1):
                if remaining % d:
                    continue
                path.append(d)
                result.append([*path, remaining // d])
                search(remaining // d, d)
                path.pop()
        search(n, 2)
        return result
```

### 面试追问

**为什么不试大于平方根的首因子？** 若 d>√r，则与之配对的 r/d 比 d 更小，与非递减路径冲突。质数状态因此只需要试到平方根。

### 复杂度

以 T 表示递归访问的余数状态数，S 表示所有结果的因子总数。时间上界 O(T√n+S)，辅助栈和路径 O(log n)，输出占 O(S)。
