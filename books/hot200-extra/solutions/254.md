# 254. 因子的组合

### 题意

把 n 写成至少两个大于 1 的整数之积，列出忽略因子次序后的所有拆分。

### 输入与约束

输入正整数 n，输出至少两个大于 1 且小于 n 的因子组成的乘积分解。同一组因子只记一次，顺序不影响答案。

### 示例

n=16 有 [2,8]、[2,2,4]、[2,2,2,2] 和 [4,4]；[8,2] 与 [2,8] 相同。

### 核心不变量

已选路径单调不减，路径乘积乘当前余数恒等于原始 n。

### 思路

递归选择能整除当前余数的因子，下一层只从上次选的因子开始，保持非递减。不能把单独的 n 当作有效分解。

同一组因子的任意排列都表示同一种分解，先约定路径中的因子非递减。每次从前一个因子开始试，只在能整除当前余数时递归。余数等于一时，路径乘积已经回到原数，保留至少含两个因子的路径即可。

### 边界检查

分解 16 时，一旦选了 4，后面的因子就从 4 起步。这样保留 `[4,4]`，也避免把 `[2,8]` 倒过来再输出一遍。

### Java

Java 的 s 表示这一层可试因子的最小值。path.add 后以 n/i 和 i 进入下一层，返回后删除末元素。加入结果时复制 path，否则继续回溯会把已收集的组合一起改掉。

#### 沿非递减路径拆解 16

| 步骤 | 当前状态 | 判断依据 |
| --- | --- | --- |
| 选首因子 2 | 16÷2=8，路径 [2]，后续因子至少为 2 | 可用剩余因子 8 收尾，得到 [2,8]。 |
| 继续拆 8 | 8=2×4，4=2×2 | 分别得到 [2,2,4] 和 [2,2,2,2]。 |
| 改选首因子 4 | 16÷4=4，输出 [4,4] | 首因子选 8 时余数 2 小于下限，无法输出倒序副本。 |

```java
import java.util.*;

class Solution {
    public List<List<Integer>> getFactors(int n) {
        List<List<Integer>> ans = new ArrayList<>();
        dfs(n, 2, new ArrayList<>(), ans);
        return ans;
    }

    private void dfs(int n, int s, List<Integer> path, List<List<Integer>> ans) {
        if (n == 1) {
            if (path.size() > 1) ans.add(new ArrayList<>(path));
            return;
        }

        // 因子只按非递减顺序加入路径，避免重复计入不同排列。
        for (int i = s; i <= n; ++i)
            if (n % i == 0) {
                path.add(i);
                dfs(n / i, i, path, ans);
                path.remove(path.size() - 1);
            }
    }
}
```

### Python

Python 的 path 由所有递归层共享。append/pop 是一对，path.copy() 只在成功叶子执行。候选可以等于上一因子，因此会生成多个 2；从 s 开始也排除了先选 8 再选 2。

#### 沿非递减路径拆解 16

| 步骤 | 当前状态 | 判断依据 |
| --- | --- | --- |
| 选首因子 2 | 16÷2=8，路径 [2]，后续因子至少为 2 | 可用剩余因子 8 收尾，得到 [2,8]。 |
| 继续拆 8 | 8=2×4，4=2×2 | 分别得到 [2,2,4] 和 [2,2,2,2]。 |
| 改选首因子 4 | 16÷4=4，输出 [4,4] | 首因子选 8 时余数 2 小于下限，无法输出倒序副本。 |

```python
from __future__ import annotations


class Solution:
    def getFactors(self, n: int) -> list[list[int]]:
        ans = []

        def dfs(n: int, s: int, path: list[int]) -> None:
            if n <= 1:
                if len(path) > 1:
                    ans.append(path.copy())
                return

            # 因子只按非递减顺序加入路径，避免重复计入不同排列。
            for i in range(s, n + 1):
                if n % i == 0:
                    path.append(i)
                    dfs(n // i, i, path)
                    path.pop()

        dfs(n, 2, [])
        return ans
```

### 面试追问

**如何减少尝试不能整除的数？** 可只尝试不超过余数平方根的较小因子 i，找到时直接输出配对 i 与 n/i，再继续拆 n/i。这样仍能覆盖所有非递减分解。

### 复杂度

设搜索树有 T 个节点；时间上界 O(nT+输出元素数)，递归深度 O(log n)，结果另计。

本实现每个搜索节点扫描从 s 到当前余数的全部候选，不能把它标成只与答案数相等的时间。路径每加入至少为 2 的因子就将余数至少减半。
