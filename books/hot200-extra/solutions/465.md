# 465. 最优账单平衡


### 题意

给出多笔转账，可重新安排结算双方。求消除所有净欠款所需的最少转账次数。

### 示例

0 向 1 转 4、1 向 2 转 4。1 的净额为零，剩下 0 和 2 各有符号相反的 4，仅需一次结算。

### 思路

先按参与者合并净额，移除零余额。回溯选第一个未清债务，让它与一个反号余额结算，递归处理后续人员，再撤销尝试。每条分支都让当前人退出未清集合。

### 边界检查

先把每人的转入、转出折算成一个净额。余额为零的人无需继续参与，搜索时只尝试符号相反的两笔净额，避免把问题越拆越大。

### Java

```java
import java.util.*;

class Solution {
    public int minTransfers(int[][] transactions) {
        int[] balance = new int[21];
        List<Integer> debts = new ArrayList<>();

        for (int[] t : transactions) {
            final int from = t[0];
            final int to = t[1];
            final int amount = t[2];
            balance[from] -= amount;
            balance[to] += amount;
        }

        for (final int b : balance) if (b != 0) debts.add(b);

        return dfs(debts, 0);
    }

    private int dfs(List<Integer> debts, int s) {
        // 跳过已经清账的人，使当前步骤至少结清一个新的余额。
        while (s < debts.size() && debts.get(s) == 0) ++s;
        if (s == debts.size()) return 0;

        int ans = Integer.MAX_VALUE;

        for (int i = s + 1; i < debts.size(); ++i)
            if ((long) debts.get(i) * debts.get(s) < 0) {
                debts.set(i, debts.get(i) + debts.get(s));
                ans = Math.min(ans, 1 + dfs(debts, s + 1));
                debts.set(i, debts.get(i) - debts.get(s));
            }

        return ans;
    }
}
```

### Python

```python
from __future__ import annotations
import math


class Solution:
    def minTransfers(self, transactions: list[list[int]]) -> int:
        balance = [0] * 21

        for u, v, amount in transactions:
            balance[u] -= amount
            balance[v] += amount

        debts = [b for b in balance if b]

        def dfs(s: int) -> int:
            # 跳过已经清账的人，使当前步骤至少结清一个新的余额。
            while s < len(debts) and not debts[s]:
                s += 1
            if s == len(debts):
                return 0

            ans = math.inf

            for i in range(s + 1, len(debts)):
                if debts[i] * debts[s] < 0:
                    debts[i] += debts[s]
                    ans = min(ans, 1 + dfs(s + 1))
                    debts[i] -= debts[s]

            return ans

        return dfs(0)
```

### 复杂度

若有 k 个非零余额，时间最坏 O(k!+t)，t 为交易数；净额与递归空间 O(k+p)，p 为参与者数。
