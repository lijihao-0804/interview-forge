# 759. 员工空闲时间

### 题意

给出多位员工各自的工作区间，返回时间轴内所有人同时空闲的有限正长度区间。

### 输入与约束

各员工的工作表按时间排列，每段具有正长度。返回所有员工共同空闲的有限正长度区间，输入含有工作时段。

### 示例

甲工作 [1,3]、[7,8]，乙工作 [2,4]。工作并集为 [1,4] 和 [7,8]，共同空闲段为 [4,7]。

### 核心不变量

prevEnd 是已处理工作区间的最大结束时刻；下一段若从它之后开始，两者之间就是完整空档。

### 思路

合并全员工作区间。下一段起点大于当前最远终点时，两者之间就是共同空档；忽略首段前、末段后的无界时间。

所有员工都空闲，等价于没有任何人在工作。先合并各人的工作区间，再只取并集内部相邻工作段之间的缺口。按起点排序后，维护的最大结束时间可以处理完全包含和部分重叠，不会因遇到短区间而倒退。

### 边界检查

共同空闲时间只输出两个合并后的工作区间之间、长度大于零的缝隙。第一场工作之前和最后一场之后的无限区间都无需返回。

### Java

Java 汇集 Interval 对象并按 start 排序。遇到下一个 start 严格大于 prevEnd 才创建新的空闲 Interval；每轮取 Math.max 更新 prevEnd，可跳过被当前工作段完全覆盖的区间。

#### 求工作并集内部的空档

| 步骤 | 当前状态 | 判断依据 |
| --- | --- | --- |
| 按起点合并输入 | 工作段依次是 [1,3]、[2,4]、[7,8] | 员工身份在求工作并集时无需保留。 |
| 延长工作段 | 2≤3，将已占用末端从 3 延长到 4 | [1,4] 期间至少一人工作。 |
| 发现缺口 | 下一场从 7 开始，4<7，记录 [4,7] | 随后末端改为 8，唯一有限共同空档已找到。 |

```java
import java.util.*;

class Solution {
    public List<Interval> employeeFreeTime(List<List<Interval>> schedule) {
        List<Interval> ans = new ArrayList<>();
        List<Interval> intervals = new ArrayList<>();

        schedule.forEach(s -> intervals.addAll(s));
        Collections.sort(intervals, Comparator.comparingInt(interval -> interval.start));

        int prevEnd = intervals.get(0).end;

        // 仅当下一段的起点超过当前最远终点时，才产生共同空闲段。
        for (Interval interval : intervals) {
            if (interval.start > prevEnd) ans.add(new Interval(prevEnd, interval.start));
            prevEnd = Math.max(prevEnd, interval.end);
        }

        return ans;
    }
}
```

### Python

Python 的 intervals 列表保存各工作段引用，sort 后按时间扫描。答案只包含有正长度的内部缺口；首个开始时间之前和最后结束时间之后都没有有限的另一端。

#### 求工作并集内部的空档

| 步骤 | 当前状态 | 判断依据 |
| --- | --- | --- |
| 按起点合并输入 | 工作段依次是 [1,3]、[2,4]、[7,8] | 员工身份在求工作并集时无需保留。 |
| 延长工作段 | 2≤3，将已占用末端从 3 延长到 4 | [1,4] 期间至少一人工作。 |
| 发现缺口 | 下一场从 7 开始，4<7，记录 [4,7] | 随后末端改为 8，唯一有限共同空档已找到。 |

```python
from __future__ import annotations


class Solution:
    def employeeFreeTime(self, schedule: "[[Interval]]") -> "[Interval]":
        ans = []
        intervals = []

        for s in schedule:
            intervals.extend(s)

        intervals.sort(key=lambda x: x.start)

        prevEnd = intervals[0].end

        # 仅当下一段的起点超过当前最远终点时，才产生共同空闲段。
        for interval in intervals:
            if interval.start > prevEnd:
                ans.append(Interval(prevEnd, interval.start))
            prevEnd = max(prevEnd, interval.end)

        return ans
```

### 面试追问

**如果两人的工作在时刻 4 首尾相接，是否得到 [4,4]？** 不会。两个工作区间之间没有正长度空闲，严格大于才产生返回区间。

### 复杂度

共有 n 段工作；时间 O(n log n)，空间 O(n)。

设共有 M 个工作段，收集与扫描都为 O(M)，排序为 O(M log M)。排序用的列表与至多线性数量的空闲段决定空间。
