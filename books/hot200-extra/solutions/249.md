# 249. 移位字符串分组

### 题意

小写字母循环后移时 z 的后继是 a；把能够通过整体平移得到彼此的字符串分组。

### 输入与约束

输入由小写英文字母组成的非空字符串列表，每次将整个串所有字符在 26 个字母上循环平移相同距离。组及组内顺序不限。

### 示例

az 和 ba 的相邻差都等于 25（模 26），在同一组；ab 的差为 1，另成一组。

### 核心不变量

同键字符串的相邻模 26 差逐项相等，首字符对齐后整串也会逐位对齐。

### 思路

整体平移保留每对相邻字符的模 26 差值。以整个差值序列为键；给数字之间加分隔，防止不同差值序列编码成同一串。

若整串每个字母都加同一个偏移量，相邻差会把这个共同偏移抵消。反过来，若所有相邻差相等，选一个偏移把首字母对齐后，后面的每个字母也由差值唯一确定。这说明差值序列既不会拆散一组，也不会混合不同组。

### 边界检查

碰到从 z 回到 a 的一步，差值要按 26 取模。所有单字符词都没有相邻差，因此自然属于同一组。

### Java

Java 用 StringBuilder 以逗号隔开每个数值，避免 [1,12] 和 [11,2] 被拼成同一个键。先加 26 再取余保证 z 到 a 的负差也按循环字母表计算。

#### 把跨过字母边界的差归一化

| 步骤 | 当前状态 | 判断依据 |
| --- | --- | --- |
| 计算 az 的键 | z−a=25，键为 [25] | 首词进入差值为 25 的桶。 |
| 处理 ba | a−b=−1，模 26 为 25 | 与 az 进入同一个桶。 |
| 处理 ab | b−a=1，键为 [1] | 分组为 {az,ba} 和 {ab}。 |

```java
import java.util.*;

class Solution {
    public List<List<String>> groupStrings(String[] strings) {
        Map<String, List<String>> keyToStrings = new HashMap<>();

        for (final String s : strings)
            keyToStrings.computeIfAbsent(getKey(s), k -> new ArrayList<>()).add(s);

        return new ArrayList<>(keyToStrings.values());
    }

    private String getKey(final String s) {
        StringBuilder sb = new StringBuilder();

        for (int i = 1; i < s.length(); ++i) {
            // 相邻差取模 26，跨越 z 到 a 的移位也能归入同一组。
            final int diff = (s.charAt(i) - s.charAt(i - 1) + 26) % 26;
            sb.append(diff).append(",");
        }

        return sb.toString();
    }
}
```

### Python

Python 用 ord 取字符编码，逐对计算差值并拼成键；defaultdict(list) 保存同键单词。单字符的差序列为空，因此所有单字符都进同一组。

#### 把跨过字母边界的差归一化

| 步骤 | 当前状态 | 判断依据 |
| --- | --- | --- |
| 计算 az 的键 | z−a=25，键为 [25] | 首词进入差值为 25 的桶。 |
| 处理 ba | a−b=−1，模 26 为 25 | 与 az 进入同一个桶。 |
| 处理 ab | b−a=1，键为 [1] | 分组为 {az,ba} 和 {ab}。 |

```python
from __future__ import annotations
import collections


class Solution:
    def groupStrings(self, strings: list[str]) -> list[list[str]]:
        keyToStrings = collections.defaultdict(list)

        def getKey(s: str) -> str:

            diffs = []

            for i in range(1, len(s)):
                # 相邻差取模 26，跨越 z 到 a 的移位也能归入同一组。
                diff = (ord(s[i]) - ord(s[i - 1]) + 26) % 26
                diffs.append(str(diff))

            return ",".join(diffs)

        for s in strings:
            keyToStrings[getKey(s)].append(s)

        return keyToStrings.values()
```

### 面试追问

**为什么不能对字符排序作为键？** 移位保持原位置之间的相对差，排序会抹去顺序。ab 和 ba 使用相同的字母，但两者的模 26 差分别是 1 与 25。

### 复杂度

字符总数 S；平均时间 O(S)，空间 O(S)。

每个字符串只计算一遍相邻差，哈希键总长度随原始字符总数 S 增长，各输入字符串仅加入一个桶。
