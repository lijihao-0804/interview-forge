# 249. 移位字符串分组

### 题意

小写字母循环后移时 z 的后继是 a；把能够通过整体平移得到彼此的字符串分组。

### 示例

az 和 ba 的相邻差都等于 25（模 26），在同一组；ab 的差为 1，另成一组。

### 思路

整体平移保留每对相邻字符的模 26 差值。以整个差值序列为键；给数字之间加分隔，防止不同差值序列编码成同一串。

### 边界检查

碰到从 z 回到 a 的一步，差值要按 26 取模。所有单字符词都没有相邻差，因此自然属于同一组。

### Java

```java
import java.util.*;

class Solution {
    public List<List<String>> groupStrings(String[] strings) {
        Map<String, List<String>> keyToStrings = new HashMap<>();

        for (final String s : strings)
            keyToStrings.computeIfAbsent(getKey(s), k -> new ArrayList<>()).add(s);

        return new ArrayList<>(keyToStrings.values());
    }

    private String getKey(final String s) {
        StringBuilder sb = new StringBuilder();

        for (int i = 1; i < s.length(); ++i) {
            // 相邻差取模 26，跨越 z 到 a 的移位也能归入同一组。
            final int diff = (s.charAt(i) - s.charAt(i - 1) + 26) % 26;
            sb.append(diff).append(",");
        }

        return sb.toString();
    }
}
```

### Python

```python
from __future__ import annotations
import collections


class Solution:
    def groupStrings(self, strings: list[str]) -> list[list[str]]:
        keyToStrings = collections.defaultdict(list)

        def getKey(s: str) -> str:

            diffs = []

            for i in range(1, len(s)):
                # 相邻差取模 26，跨越 z 到 a 的移位也能归入同一组。
                diff = (ord(s[i]) - ord(s[i - 1]) + 26) % 26
                diffs.append(str(diff))

            return ",".join(diffs)

        for s in strings:
            keyToStrings[getKey(s)].append(s)

        return keyToStrings.values()
```

### 复杂度

字符总数 S；平均时间 O(S)，空间 O(S)。
