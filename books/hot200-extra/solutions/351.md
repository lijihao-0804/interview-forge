# 351. 安卓系统手势解锁


### 题意

统计九宫格中长度介于 m 和 n 的解锁手势。点不可重复，跨过一个正中点时，该中点必须已经访问。

### 示例

当 m=n=1 时共有 9 种。从 1 直接去 3 会跨过 2；若 2 尚未出现，这一步不合法。

### 思路

预存哪些点对之间有必经中点。DFS 每次只加入未用且满足跨越条件的点；四角对称、四边中点对称，各算一次后乘四。

### 边界检查

从 1 跨到 3 时必须检查中点 2；从 1 到 6 则没有九宫格点落在线段中间。判断能否连线取决于具体点对，不能仅按距离限制。

### Java

```java
class Solution {
    public int numberOfPatterns(int m, int n) {
        int ans = 0;
        int[][] across = new int[10][10];
        boolean[] seen = new boolean[10];

        across[1][3] = across[3][1] = 2;
        across[1][7] = across[7][1] = 4;
        across[3][9] = across[9][3] = 6;
        across[7][9] = across[9][7] = 8;
        across[1][9] =
                across[9][1] =
                        across[2][8] =
                                across[8][2] =
                                        across[3][7] =
                                                across[7][3] = across[4][6] = across[6][4] = 5;

        ans += dfs(m, n, 1, 1, seen, across) * 4;
        ans += dfs(m, n, 2, 1, seen, across) * 4;
        ans += dfs(m, n, 5, 1, seen, across);
        return ans;
    }

    private int dfs(int m, int n, int u, int level, boolean[] seen, int[][] across) {
        if (level > n) return 0;

        seen[u] = true;
        int ans = level >= m ? 1 : 0;

        for (int v = 1; v <= 9; ++v) {
            if (v == u || seen[v]) continue;
            final int acrossed = across[u][v];
            // 跨过某个中点时，那个点必须已经出现在手势中。
            if (acrossed == 0 || seen[acrossed]) ans += dfs(m, n, v, level + 1, seen, across);
        }

        seen[u] = false;
        return ans;
    }
}
```

### Python

```python
from __future__ import annotations


class Solution:
    def numberOfPatterns(self, m: int, n: int) -> int:
        seen = set()
        accross = [[0] * 10 for _ in range(10)]

        accross[1][3] = accross[3][1] = 2
        accross[1][7] = accross[7][1] = 4
        accross[3][9] = accross[9][3] = 6
        accross[7][9] = accross[9][7] = 8
        accross[1][9] = accross[9][1] = accross[2][8] = accross[8][2] = accross[3][7] = accross[
            7
        ][3] = accross[4][6] = accross[6][4] = 5

        def dfs(u: int, depth: int) -> int:
            if depth > n:
                return 0

            seen.add(u)
            ans = 1 if depth >= m else 0

            for v in range(1, 10):
                if v == u or v in seen:
                    continue
                accrossed = accross[u][v]
                # 跨过某个中点时，那个点必须已经出现在手势中。
                if not accrossed or accrossed in seen:
                    ans += dfs(v, depth + 1)

            seen.remove(u)
            return ans

        return dfs(1, 1) * 4 + dfs(2, 1) * 4 + dfs(5, 1)
```

### 复杂度

九点固定。按最多 n 层计，时间上界 O(9·Σ P(9,d))（d 从 1 到 n），递归深度 O(n)，中点表固定大小。
