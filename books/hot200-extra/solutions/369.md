# 369. 给单链表加一


### 题意

正整数按高位在前的顺序存于单链表，返回给原数加一后的链表。

### 示例

9→9→8 加一是 9→9→9；再次加一时进位穿过三位，得到 1→0→0→0。

### 思路

走到最低位再回溯，把进位与当前数字相加并拆成个位和下一次进位。最高位仍有进位时需要创建新头。

### 边界检查

全是 9 时会产生一个新头节点，例如 99 变成 100。还要保住另一端的情况：尾部数字小于 9 时，前面的 9 根本无需参与进位。

### Java

```java
class Solution {
    public ListNode plusOne(ListNode head) {
        if (head == null) return new ListNode(1);
        if (addOne(head) == 1) return new ListNode(1, head);
        return head;
    }

    private int addOne(ListNode node) {
        // 先处理低位返回的进位，再决定当前节点的新值。
        final int carry = node.next == null ? 1 : addOne(node.next);
        final int sum = node.val + carry;
        node.val = sum % 10;
        return sum / 10;
    }
}
```

### Python

```python
from __future__ import annotations


class Solution:
    def plusOne(self, head: ListNode) -> ListNode:
        if not head:
            return ListNode(1)
        if self._addOne(head) == 1:
            return ListNode(1, head)
        return head

    def _addOne(self, node: ListNode) -> int:
        # 先处理低位返回的进位，再决定当前节点的新值。
        carry = self._addOne(node.next) if node.next else 1
        summ = node.val + carry
        node.val = summ % 10
        return summ // 10
```

### 复杂度

时间 O(n)，递归栈 O(n)。
