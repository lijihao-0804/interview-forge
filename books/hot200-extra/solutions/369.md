# 369. 给单链表加一


### 题意

正整数按高位在前的顺序存于单链表，返回给原数加一后的链表。

### 输入与约束

给定十进制单链表，每个节点存 0…9 的一位，高位在前。返回加一后的头节点，可能新增最高位。

### 示例

9→9→8 加一是 9→9→9；再次加一时进位穿过三位，得到 1→0→0→0。

### 核心不变量

子调用返回时，低位后缀已写成正确结果，返回的 0 或 1 是该后缀唯一需要传给当前位的进位。

### 思路

走到最低位再回溯，把进位与当前数字相加并拆成个位和下一次进位。最高位仍有进位时需要创建新头。

个位先决定进位，但链表只允许从高位往低位前进。递归调用沿 next 走到尾，返回方向便恰好从个位回到最高位；每层只需要向父层报告一位进位。处理完头后仍有进位才多建一格。

#### 从 998 加到 1000

| 步骤 | 当前状态 | 为什么这样走 |
| --- | --- | --- |
| 第一次加一 | 998 的尾 8+1=9，向左进位 0，得到 999 | 两位更高的 9 都不需要增加。 |
| 第二次从尾开始 | 999 的个位 9+1=10，写 0，进位 1 | 尾端变成 0，进位传给十位。 |
| 穿过最高位 | 后两次 9+1 都写 0，头返回 1，新链 1→0→0→0 | 最高位外仍有进位，必须补新头。 |

### 边界检查

全是 9 时会产生一个新头节点，例如 99 变成 100。还要保住另一端的情况：尾部数字小于 9 时，前面的 9 根本无需参与进位。

### Java

#### 用递归返回值传一位进位

`addOne` 在尾节点把 carry 设为 1，其他节点的 carry 来自右边。sum%10 写当前数字，sum/10 用整数除法回传进位。只有原头进位时才换头指针。

```java
class Solution {
    public ListNode plusOne(ListNode head) {
        if (head == null) return new ListNode(1);
        if (addOne(head) == 1) return new ListNode(1, head);
        return head;
    }

    private int addOne(ListNode node) {
        // 先处理低位返回的进位，再决定当前节点的新值。
        final int carry = node.next == null ? 1 : addOne(node.next);
        final int sum = node.val + carry;
        node.val = sum % 10;
        return sum / 10;
    }
}
```

### Python

#### 用整除与取模拆分新数字

`_addOne` 的返回值为 0 或 1。更新节点用 summ%10，回传用 // 而不是浮点除法；进位归零以后外层仍会返回，但更高位的值都保持原数。

```python
from __future__ import annotations


class Solution:
    def plusOne(self, head: ListNode) -> ListNode:
        if not head:
            return ListNode(1)
        if self._addOne(head) == 1:
            return ListNode(1, head)
        return head

    def _addOne(self, node: ListNode) -> int:
        # 先处理低位返回的进位，再决定当前节点的新值。
        carry = self._addOne(node.next) if node.next else 1
        summ = node.val + carry
        node.val = summ % 10
        return summ // 10
```

### 复杂度

时间 O(n)，递归栈 O(n)。

递归下降和返回各走一遍整链，栈中最深时同时保留 n 个节点的调用帧。

### 面试追问

**能不使用递归栈吗？** 从头记录最后一个不等于 9 的节点，给它加一，再把它后面全是 9 的后缀置零。头前设零哨兵即可统一处理全 9 情况。
