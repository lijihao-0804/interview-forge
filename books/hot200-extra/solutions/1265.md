# 1265. 逆序打印不可变链表


### 题意

给定只允许 getNext 和 printValue 的不可变单链表，从尾到头打印所有节点的值。

### 输入与约束

节点只提供 getNext 与 printValue，不能读取私有字段或修改指针。按从尾到头的顺序调用各节点的打印方法。

### 示例

链表 A→B→C，先沿 getNext 保存三个节点，再依次弹出 C、B、A 调用 printValue。链表指针无需改动。

### 核心不变量

正向扫描后栈按链表次序保存全部节点，弹栈阶段每次取到尚未打印部分中最靠后的节点。

### 思路

单向链只能从头向尾访问，用栈保存节点引用。栈的后进先出次序恰好是要打印的次序；整个算法只调用题目公开的两个操作。

走到 B 时无法从 B 的接口取回 A，输出值也只能通过节点自己的方法完成。顺向访问时保存每个节点引用，直到确认尾部，再按后进先出顺序调用打印方法，就能把遍历与输出拆成两个方向。

#### A、B、C 的保存与打印顺序

| 步骤 | 当前状态 | 为什么这样走 |
| --- | --- | --- |
| 沿链收集 | 先压入 A，再压入 B，栈底到顶 [A,B] | 不能提前打印，因为尾部还有 C。 |
| 抵达链尾 | 压入 C，下一节点为空，栈 [A,B,C] | 栈顶恰是第一个要打印的节点。 |
| 逆向打印 | 依次弹 C、B、A，栈归空 | 每次只调用弹出节点的 printValue。 |

### 边界检查

节点不可修改，所以不能靠原地翻转链表完成逆序输出。保存节点引用后，逆序调用的是每个节点自己的 `printValue()` 方法。

### 反例推演

链表 A→B→C 只有向前接口，不能把 C 的 next 改到 B。若采用显式栈，第一次扫描只暂存节点，第二阶段再依次调用 C、B、A 的打印接口。

### Java

#### 栈保存 ImmutableListNode 引用

`Deque<ImmutableListNode>` 只保存引用。push 和 pop 都操作栈顶，弹出后调用 printValue；整个过程既不需要读取私有值，也不修改 next。

```java
import java.util.*;

class Solution {
    public void printLinkedListInReverse(ImmutableListNode head) {
        Deque<ImmutableListNode> nodes = new ArrayDeque<>();
        // 栈中只保存节点引用，因此无需改动不可变链表。
        while (head != null) {
            nodes.push(head);
            head = head.getNext();
        }
        while (!nodes.isEmpty()) nodes.pop().printValue();
    }
}
```

### Python

#### list 末端弹出对应链表逆序

list 的 append 按访问顺序积累节点，pop 默认从末尾取，恰好逆序。head 在第一段循环中向前移动只会重绑定局部变量，不影响调用者的链表。

```python
from __future__ import annotations


class Solution:
    def printLinkedListInReverse(self, head: ImmutableListNode) -> None:
        stack = []
        # 栈中只保存节点引用，因此无需改动不可变链表。
        while head is not None:
            stack.append(head)
            head = head.getNext()
        while stack:
            stack.pop().printValue()
```

### 复杂度

时间 O(n)，辅助栈 O(n)。

两种实现均按不可变链表的公开接口编写。

每个节点前进一次、打印一次。尾节点被发现前，所有 n 个节点的引用都可能同时保存在栈里。

### 面试追问

**若栈空间只够约 √n 个节点引用呢？** 可先计数，把链分成约 √n 个等长块，记住各块的起点。从最后一块往前，每次只用一个块大小的栈逆序打印块内节点，仍然只需线性访问。
