# 1265. 逆序打印不可变链表


### 题意

给定只允许 getNext 和 printValue 的不可变单链表，从尾到头打印所有节点的值。

### 示例

链表 A→B→C，先沿 getNext 保存三个节点，再依次弹出 C、B、A 调用 printValue。链表指针无需改动。

### 思路

单向链只能从头向尾访问，用栈保存节点引用。栈的后进先出次序恰好是要打印的次序；整个算法只调用题目公开的两个操作。

### 边界检查

节点不可修改，所以不能靠原地翻转链表完成逆序输出。保存节点引用后，逆序调用的是每个节点自己的 `printValue()` 方法。

### Java

```java
import java.util.*;

class Solution {
    public void printLinkedListInReverse(ImmutableListNode head) {
        Deque<ImmutableListNode> nodes = new ArrayDeque<>();
        // 栈中只保存节点引用，因此无需改动不可变链表。
        while (head != null) {
            nodes.push(head);
            head = head.getNext();
        }
        while (!nodes.isEmpty()) nodes.pop().printValue();
    }
}
```

### Python

```python
from __future__ import annotations


class Solution:
    def printLinkedListInReverse(self, head: ImmutableListNode) -> None:
        stack = []
        # 栈中只保存节点引用，因此无需改动不可变链表。
        while head is not None:
            stack.append(head)
            head = head.getNext()
        while stack:
            stack.pop().printValue()
```

### 复杂度

时间 O(n)，辅助栈 O(n)。

两种实现均按不可变链表的公开接口编写。
