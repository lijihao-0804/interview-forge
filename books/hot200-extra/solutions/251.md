# 251. 展开二维向量

### 题意

为二维整数向量实现按行迭代的 next 和 hasNext，允许出现空行。

### 输入与约束

构造参数是允许空行的二维整数序列。按行返回元素，只有在存在下一项时才调用 next；hasNext 可以重复调用。

### 示例

输入 [[],[3],[],[4,5]]，连续读取为 3、4、5；读取前多次询问 hasNext 不会跳过 3。

### 核心不变量

游标 (row,col) 之前的元素都已消费。跳过空行或已经耗尽的行只改变位置表示；一旦停在有效元素上，反复调用 hasNext 会保持这个位置。

### 思路

构造时仅保存二维序列的引用。从当前行内的 col 开始，若它等于行长就转到下一行的第 0 列。第一次遇到非空的剩余部分即可停止。next 先定位到有效元素，返回后仅增加列号。

输入 [[],[3],[],[4,5]] 时，第一次探测从第 0 行跳到 (1,0)，再探测仍停在那里。取 3 后才跨过空行到 (3,0)，最终取完 5 后行号升到 4。

### 边界检查

把 `[[], [3], []]` 当作试纸。连续问两次 `hasNext()` 都应返回真，随后一次 `next()` 才取出 3，尾部空行也应安全跳过。

### 反例推演

向量 `[[],[4],[]]` 只产出 4。消费这一项后，即使末尾还有一行，下一次 hasNext 也必须返回 false；重复询问 hasNext 不应跳过 4。

### Java

#### 行列游标的惰性迭代

二维数组保存在实例字段中；hasNext 仅越过行界，next 才移动有效元素的列下标。

| 步骤 | 当前状态 | 判断依据 |
| --- | --- | --- |
| 跳空行 | [[],[3],[],[4,5]] | 首次探测到 (1,0)，值为 3 |
| 观察同一项 | 连续调用两次 hasNext | 仍停在 (1,0) |
| 消费后推进 | 取 3 后探测 | 越过空行，定位 (3,0)，值为 4 |

```java
class Vector2D {
    private final int[][] rows;
    private int row, col;

    public Vector2D(int[][] vec) { rows = vec; }

    public boolean hasNext() {
        while (row < rows.length && col == rows[row].length) {
            ++row;
            col = 0;
        }
        return row < rows.length;
    }

    public int next() {
        if (!hasNext()) throw new java.util.NoSuchElementException();
        return rows[row][col++];
    }
}
```

### Python

#### 行列游标的惰性迭代

实例持有列表引用。next 返回当前数值，再移动列游标；走过的空行不会在下次调用时重复扫描。

| 步骤 | 当前状态 | 判断依据 |
| --- | --- | --- |
| 跳空行 | [[],[3],[],[4,5]] | 首次探测到 (1,0)，值为 3 |
| 观察同一项 | 连续调用两次 hasNext | 仍停在 (1,0) |
| 消费后推进 | 取 3 后探测 | 越过空行，定位 (3,0)，值为 4 |

```python
class Vector2D:
    def __init__(self, vec: list[list[int]]):
        self.rows = vec
        self.row = self.col = 0

    def hasNext(self) -> bool:
        while self.row < len(self.rows) and self.col == len(self.rows[self.row]):
            self.row += 1
            self.col = 0
        return self.row < len(self.rows)

    def next(self) -> int:
        if not self.hasNext():
            raise StopIteration
        value = self.rows[self.row][self.col]
        self.col += 1
        return value
```

### 面试追问

**为什么不在构造时拍平列表？** 如果调用者只取第一个元素，预先复制仍需遍历全部内容。按需推进仅检查它实际经过的行，并保留原始输入；若允许外部修改输入，还需另行约定迭代器的可见性。

### 复杂度

构造 O(1)，额外空间 O(1)。若有 R 行、N 个元素，完整遍历 O(R+N)；单次遇到连续空行可能耗时 O(R)，额外的重复探测每次仅增加 O(1)。
