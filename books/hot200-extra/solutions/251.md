# 251. 展开二维向量

### 题意

为二维整数向量实现按行迭代的 next 和 hasNext，允许出现空行。

### 输入与约束

构造参数是允许空行的二维整数序列。按行返回元素，只有在存在下一项时才调用 next；hasNext 可以重复调用。

### 示例

输入 [[],[3],[],[4,5]]，连续读取为 3、4、5；读取前多次询问 hasNext 不会跳过 3。

### 核心不变量

i 前面恰是已经返回的元素，i 对应下一个尚未消费的元素，hasNext 不改 i。

### 思路

构造时按行展开，记录下一个待返回位置。空行不产生元素；hasNext 只检查边界，只有 next 推进游标。

设计迭代器时先分清两种操作：hasNext 只观察，next 才消费。这里在构造阶段按行复制元素，二维坐标随后被一个游标替代。空行贡献零个元素，迭代阶段从数据表示上消除了跨空行的问题。

### 边界检查

把 `[[], [3], []]` 当作试纸。连续问两次 `hasNext()` 都应返回真，随后一次 `next()` 才取出 3，尾部空行也应安全跳过。

### Java

Java 用 `ArrayList<Integer>` 接收原二维数组的元素，i 指向下一个未返回的值。get(i++) 使用旧下标读取，再将游标推进一位。只要 i<vec.size()，当前位置就有效。

#### 观察与消费同一个游标

| 步骤 | 当前状态 | 判断依据 |
| --- | --- | --- |
| 按行展开 | [[],[3],[],[4,5]] → [3,4,5]，i=0 | 两条空行都不生成占位值。 |
| 连续探测 | 两次 hasNext 均为真，i 始终为 0 | 观察不会消费首元素 3。 |
| 依次取值 | next 返回 3、4、5，i 变为 3 | 此时 i 等于总元素数，hasNext 为假。 |

```java
import java.util.*;

class Vector2D {
    public Vector2D(int[][] vec) {
        // 按行展开，空行不生成元素；迭代时只推进一个游标。
        for (int[] arr : vec) for (final int a : arr) this.vec.add(a);
    }

    public int next() {
        return vec.get(i++);
    }

    public boolean hasNext() {
        return i < vec.size();
    }

    private List<Integer> vec = new ArrayList<>();
    private int i = 0;
}
```

### Python

Python 的 self.vec += arr 按顺序扩展同一列表；hasNext 仅读长度和 self.i。next 先保存当前位置的值再加一，这样反复查看剩余状态不会跳过任何元素。

#### 观察与消费同一个游标

| 步骤 | 当前状态 | 判断依据 |
| --- | --- | --- |
| 按行展开 | [[],[3],[],[4,5]] → [3,4,5]，i=0 | 两条空行都不生成占位值。 |
| 连续探测 | 两次 hasNext 均为真，i 始终为 0 | 观察不会消费首元素 3。 |
| 依次取值 | next 返回 3、4、5，i 变为 3 | 此时 i 等于总元素数，hasNext 为假。 |

```python
from __future__ import annotations


class Vector2D:
    def __init__(self, vec: list[list[int]]):
        self.vec = []
        self.i = 0

        # 按行展开，空行不生成元素；迭代时只推进一个游标。
        for arr in vec:
            self.vec += arr

    def next(self) -> int:
        ans = self.vec[self.i]
        self.i += 1
        return ans

    def hasNext(self) -> bool:
        return self.i < len(self.vec)
```

### 面试追问

**如果输入很大，能否不复制整份数据？** 可以只保存行列游标，并在访问前跳过空行。构造和额外空间可降为常数，但一次寻找下一项可能跨过多个空行。

### 复杂度

R 行、N 个元素；构造 O(R+N)，每次迭代操作 O(1)，空间 O(N)。

构造时检查每行并复制每个整数，分别贡献 R、N 的工作。迭代时只做数组访问、游标加一与长度比较。
