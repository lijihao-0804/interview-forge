# 776. 拆分二叉搜索树

### 题意

按阈值将一棵 BST 拆成两棵，分别保存小于等于阈值和大于阈值的节点，尽量保留原父子边。

### 输入与约束

输入可为空的 BST 与阈值 target。返回两个根，小树包含所有不大于阈值的节点，大树包含其他节点；保留可保留的原父子边。

### 示例

根 5，左右子为 3、8，3 的右子为 4。阈值 4 时小树为 3→右4，大树为 5→右8。

### 核心不变量

a 的右边与 b 的左边是两侧待续接的位置，其余已归类子树完整保留，root 指向唯一尚待拆分的分支。

### 思路

沿原树向下只查看一条搜索路径。节点值不超过阈值时，它和整棵左子树属于较小结果，将它接到较小树尾节点的右侧，再去拆原右子树。大于阈值时对称地接到较大树尾的左侧。接好后先断开待拆的旧边，保留另一侧完整子树。

BST 的有序性意味着根的一侧总能整体保留。若根不大于阈值，它和左子树都属于小树，只剩右子树需继续拆；根大于阈值时则整棵右子树归大树。沿这一条分界路径，将小树沿右侧续接、大树沿左侧续接即可。

### 边界检查

遇到值不大于阈值的节点时，它的整棵左子树都属于较小的一侧。只继续拆右边，再把拆下来的小树接回去，就能保留其余父子关系。

### Java

Java 用 small、large 两个哑节点分别提供结果入口，a 和 b 指向两棵树等待续接的边界节点。先保存 root 的下一搜索方向再断旧边，避免结果仍引用另一棵树的节点。

#### 把 5 的左侧按阈值 4 拆开

| 步骤 | 当前状态 | 判断依据 |
| --- | --- | --- |
| 访问根 5 | 5>4，归大树；保留右子 8，待拆原左子 3 | 断开 5.left 后，大树不会再指向小树。 |
| 访问 3 | 3≤4，归小树；继续处理原右子 4 | 小树边界指针来到 3。 |
| 访问 4 | 4=阈值，接成 3.right=4；路径结束 | 两棵树分别以 3 和 5 为根，5.right=8 保留。 |

```java
class Solution {
    public TreeNode[] splitBST(TreeNode root, int target) {
        TreeNode small = new TreeNode(0), large = new TreeNode(0);
        TreeNode a = small, b = large;
        while (root != null) {
            if (root.val <= target) {
                a.right = root;
                a = root;
                // 左子树整体归小树，只有旧右边仍可能跨越阈值。
                root = root.right;
                a.right = null;
            } else {
                b.left = root;
                b = root;
                root = root.left;
                b.left = null;
            }
        }
        return new TreeNode[] {small.right, large.left};
    }
}
```

### Python

Python 改写原有节点的 left 或 right，不复制子树。遇到等于 target 的节点走小树分支，最后返回 small.right 和 large.left；若一侧无节点，其哑入口仍为 None。

#### 把 5 的左侧按阈值 4 拆开

| 步骤 | 当前状态 | 判断依据 |
| --- | --- | --- |
| 访问根 5 | 5>4，归大树；保留右子 8，待拆原左子 3 | 断开 5.left 后，大树不会再指向小树。 |
| 访问 3 | 3≤4，归小树；继续处理原右子 4 | 小树边界指针来到 3。 |
| 访问 4 | 4=阈值，接成 3.right=4；路径结束 | 两棵树分别以 3 和 5 为根，5.right=8 保留。 |

```python
class Solution:
    def splitBST(self, root, target: int):
        small, large = TreeNode(0), TreeNode(0)
        a, b = small, large
        while root is not None:
            if root.val <= target:
                a.right = root
                a = root
                root = root.right
                a.right = None
            else:
                b.left = root
                b = root
                # 保留整棵右子树，旧左子树继续参与拆分。
                root = root.left
                b.left = None
        return [small.right, large.left]
```

### 面试追问

**为什么不能提前把正在拆的孩子指针清空？** 尚待分类的节点只通过这条边可达。如果先断再取，剩余子树会从工作指针里丢失，必须先记住下一节点。

### 复杂度

树高 h；时间 O(h)，辅助空间 O(1)。

每个循环只沿原树的一条搜索路径走一步，未触及的整棵子树直接保留。仅创建两个哑节点并保存常数个指针。
