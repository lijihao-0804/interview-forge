# 346. 数据流中的移动平均值


### 题意

实现固定容量的滑动平均值。每收到一个数，返回最近至多 size 个数的均值。

### 输入与约束

构造时给定正窗口容量，每次 next 接收一个整数，并返回最近至多 size 个数的浮点平均值。

### 示例

容量 2，输入 4、8、10，依次返回 4、6、9；第三步淘汰 4，保留 8 和 10。

### 核心不变量

方法返回前，队列按到达顺序保存当前窗口且 sum 等于队列全部元素之和。

### 思路

队列记录窗口中的实际元素，另存窗口总和。满窗时先减掉队头，再把新值加入总和，最后除以当前队列长度。

每来一个值重新遍历窗口会反复求同一个和。新总和等于旧总和减去退出的一项再加新项；唯一还需记下的信息是下一次应退出谁，因此用先进先出队列保存窗口。

#### 容量 2 的三个读数

| 步骤 | 当前状态 | 为什么这样走 |
| --- | --- | --- |
| 收到 4 | 队列 [4]，sum=4，平均 4 | 窗口未满，分母取 1。 |
| 收到 8 | 队列 [4,8]，sum=12，平均 6 | 第一次填满容量 2。 |
| 收到 10 | 移走 4，队列 [8,10]，sum=18，平均 9 | 旧和 12−4+10 正好等于新窗口总和。 |

### 边界检查

窗口尚未填满时，分母要用实际已收到的元素数。容量为 2 时第一次收到 4，平均值仍是 4，而不是 2。

### Java

#### 用 double 除以实际队长

`q.poll()` 取出最早样本并从 sum 扣掉。sum 使用 double，所以除以队列长度时不会截断小数。执行返回语句前，sum 与队列中的值始终相等于同一份总和。

```java
import java.util.*;

class MovingAverage {
    public MovingAverage(int size) {
        this.size = size;
    }

    public double next(int val) {
        // 加入新值之前，从总和里扣除被淘汰的队头。
        if (q.size() == size) sum -= q.poll();
        sum += val;
        q.offer(val);
        return sum / q.size();
    }

    private int size = 0;
    private double sum = 0;
    private Queue<Integer> q = new ArrayDeque<>();
}
```

### Python

#### 先减队头再算平均数

`deque.popleft()` 避免从列表头部删除的搬移成本。self.sum 用整数精确累计，到 return 的除法才转为浮点；分母是更新后的 len(self.q)。

```python
from __future__ import annotations
import collections


class MovingAverage:
    def __init__(self, size: int):
        self.size = size
        self.sum = 0
        self.q = collections.deque()

    def next(self, val: int) -> float:
        # 加入新值之前，从总和里扣除被淘汰的队头。
        if len(self.q) == self.size:
            self.sum -= self.q.popleft()
        self.sum += val
        self.q.append(val)
        return self.sum / len(self.q)
```

### 复杂度

每次更新 O(1)，空间 O(size)。

每个 next 至多执行一次出队、一次入队和常数次算术操作。队列只保留最近 size 项。

### 面试追问

**为什么不能只保存上一次的平均数和个数？** 窗口满后需要扣除最旧值。两组具有同一平均数和个数的窗口可以拥有不同的首项，下一次的平均数便不同。
