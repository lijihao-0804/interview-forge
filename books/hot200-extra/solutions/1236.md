# 1236. 网络爬虫

### 题意

给出起始 URL 以及题目提供的 HtmlParser 邻接表接口，找出能沿链接到达且主机名与起点相同的 URL。

### 输入与约束

输入 startUrl 和题目给定的 HtmlParser，链接遵循题设的 HTTP URL 格式。仅返回能从起点沿同主机页面到达的不同完整 URL，顺序不限。

### 示例

起点 http://a.test/1 指向同主机的 /2 与 http://b.test/1；/2 又指回起点。答案只含 a.test 的这两个页面。

### 核心不变量

队列中的 URL 都已登记且主机匹配；每个已发现页面最多解析一次。

### 思路

把接口返回的链接看成有向图邻居，逐页扩展，并在首次发现时登记。比较完整主机名；用字符串前缀会把相似域名也纳入。

把完整 URL 看成顶点、页面中的链接看成有向边。待访问集合需要同时满足“从起点可达”和“主机与起点相同”。把主机判断放在入队之前，便不会请求外站页面；把去重也放在此处，同一页面有多个入口时只会解析一次。

### 边界检查

以 `http://a.test` 为起点，`a.test.cn` 有相同的字符串前缀，却属于另一个主机。比较完整主机名，同时在页面入队时记录已访问，回链就不会反复入队。

### Java

Java 的 Queue 暂存已发现但未解析的 URL，Set 则包含已发现的所有 URL。按题中固定的 HTTP URL 格式取第三个斜杠分段作主机名，用 equals 比较，路径不同的同主机页面保留为不同顶点。

#### 按域名筛选起点的出链

| 步骤 | 当前状态 | 判断依据 |
| --- | --- | --- |
| 初始化 | 队列 [a.test/1]，seen={a.test/1} | 起点无需由别的页面链接才能计入。 |
| 解析起点 | a.test/2 入队；忽略 b.test/1 | 两条出边中只有一条主机匹配。 |
| 解析第二页 | a.test/2 指回 a.test/1，队列清空 | 起点已登记，返回两个 a.test 页面。 |

```java
import java.util.*;

class Solution {
    public List<String> crawl(String startUrl, HtmlParser htmlParser) {
        Queue<String> q = new ArrayDeque<>(List.of(startUrl));
        Set<String> seen = new HashSet<>(Arrays.asList(startUrl));
        final String hostname = startUrl.split("/")[2];

        // 只扩展主机名完全相同、尚未入队的页面。
        while (!q.isEmpty()) {
            final String currUrl = q.poll();
            for (final String url : htmlParser.getUrls(currUrl)) {
                if (seen.contains(url)) continue;
                if (url.split("/")[2].equals(hostname)) {
                    q.offer(url);
                    seen.add(url);
                }
            }
        }

        return new ArrayList<>(seen);
    }
}
```

### Python

Python 的 deque 与 seen 分工相同，seen 一开始就有 startUrl。如果等第一次解析之后才登记，回到起点的链接会将它再排一次。题目不要求顺序，直接把集合转成列表即可。

#### 按域名筛选起点的出链

| 步骤 | 当前状态 | 判断依据 |
| --- | --- | --- |
| 初始化 | 队列 [a.test/1]，seen={a.test/1} | 起点无需由别的页面链接才能计入。 |
| 解析起点 | a.test/2 入队；忽略 b.test/1 | 两条出边中只有一条主机匹配。 |
| 解析第二页 | a.test/2 指回 a.test/1，队列清空 | 起点已登记，返回两个 a.test 页面。 |

```python
from __future__ import annotations
import collections


class Solution:
    def crawl(self, startUrl: str, htmlParser: "HtmlParser") -> list[str]:
        q = collections.deque([startUrl])
        seen = {startUrl}
        hostname = startUrl.split("/")[2]

        # 只扩展主机名完全相同、尚未入队的页面。
        while q:
            currUrl = q.popleft()
            for url in htmlParser.getUrls(currUrl):
                if url in seen:
                    continue
                if url.split("/")[2] == hostname:
                    q.append(url)
                    seen.add(url)

        return list(seen)
```

### 面试追问

**能用 startswith 判断同主机吗？** http://a.test.evil.example/ 也以 http://a.test 开头。应完整比较主机字段；处理更一般的真实 URL 时可使用标准 URL 解析器。

### 复杂度

访问 V 个同主机页面、检查 E 条链接；按 URL 为单位，平均时间 O(V+E)，空间 O(V)。

每个同主机页面只解析一次，每条取回的链接只做去重与主机判断；队列和集合最多存 V 个页面。复杂度按接口调用及 URL 处理为单位。
