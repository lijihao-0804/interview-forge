# 723. 粉碎糖果

### 题意

反复同时消去棋盘上横向或纵向连续至少三个的同色糖果，剩余糖果按列下落，返回稳定棋盘。

### 输入与约束

输入非空矩形棋盘，正整数表示颜色，零表示空格。每轮同时消除所有横竖连续至少三颗的同色糖，再施加向下重力。

### 示例

三行从上到下是 [1,2,1]、[4,4,4]、[2,3,2]。中行消失，上行下落，最终为 [0,0,0]、[1,2,1]、[2,3,2]。

### 核心不变量

标记阶段每格的绝对值仍表示本轮开始时的颜色；压缩阶段每列底部已经写入的糖果保持原有顺序。

### 思路

一轮先标记所有应消除格，再按列从底向上压实。检查颜色用绝对值，使交叉处已标记的糖仍可参加本轮的另一组三连。

一次消除由下落前的棋盘决定。对每个非零格检查向右、向下的三元组，长度四或五的连续段会被重叠的三元组完整覆盖。把待删糖果改成负数，同时保留颜色绝对值，扫描后再做一次稳定的列压缩。

### 边界检查

一颗糖可能同时位于横排和竖排的交叉点。先从整张旧棋盘找出本轮要消除的所有位置，再统一下落；边找边下落会改变另一方向的匹配。

### Java

Java 用 Math.abs 恢复原色，零不参与匹配。压缩时从下往上拷贝正数，写入位置在当前读取位置或其下方，所以不会覆盖上方尚未检查的糖果。

#### 标记中行，再按列下落

| 步骤 | 当前状态 | 判断依据 |
| --- | --- | --- |
| 发现中行 | 三行中第二行为 [4,4,4]，标记为 [-4,-4,-4] | 先保留格子位置，以便继续判竖向三连。 |
| 逐列压实 | 第一列 [1,-4,2] → [0,1,2] | 底部 2 保留，顶部 1 下移一格。 |
| 复查新棋盘 | [0,0,0] / [1,2,1] / [2,3,2] | 零不是糖果，剩余各行各列均无三连。 |

```java
import java.util.*;

class Solution {
    public int[][] candyCrush(int[][] board) {
        final int m = board.length;
        final int n = board[0].length;
        boolean haveCrushes = true;

        // 本轮先标记全部三连，之后再统一下落，保留交叉消除。
        while (haveCrushes) {
            haveCrushes = false;

            for (int i = 0; i < m; ++i)
                for (int j = 0; j < n; ++j) {
                    final int val = Math.abs(board[i][j]);
                    if (val == 0) continue;

                    if (j + 2 < n
                            && Math.abs(board[i][j + 1]) == val
                            && Math.abs(board[i][j + 2]) == val) {
                        haveCrushes = true;
                        for (int k = j; k < j + 3; ++k) board[i][k] = -val;
                    }

                    if (i + 2 < m
                            && Math.abs(board[i + 1][j]) == val
                            && Math.abs(board[i + 2][j]) == val) {
                        haveCrushes = true;
                        for (int k = i; k < i + 3; ++k) board[k][j] = -val;
                    }
                }

            if (haveCrushes) {

                for (int j = 0; j < n; ++j) {
                    int nextIndex = m - 1;
                    for (int i = m - 1; i >= 0; --i)
                        if (board[i][j] > 0) board[nextIndex--][j] = board[i][j];

                    for (int i = nextIndex; i >= 0; --i) board[i][j] = 0;
                }
            }
        }

        return board;
    }
}
```

### Python

Python 的 write 是当前列最靠下的空位；写入一颗幸存糖后向上移动一格。扫描结束后只把顶部剩余区域清零。changed 为假表示整轮检查没有找到三连，此时可以返回原列表。

#### 标记中行，再按列下落

| 步骤 | 当前状态 | 判断依据 |
| --- | --- | --- |
| 发现中行 | 三行中第二行为 [4,4,4]，标记为 [-4,-4,-4] | 先保留格子位置，以便继续判竖向三连。 |
| 逐列压实 | 第一列 [1,-4,2] → [0,1,2] | 底部 2 保留，顶部 1 下移一格。 |
| 复查新棋盘 | [0,0,0] / [1,2,1] / [2,3,2] | 零不是糖果，剩余各行各列均无三连。 |

```python
class Solution:
    def candyCrush(self, board: list[list[int]]) -> list[list[int]]:
        rows, cols = len(board), len(board[0])
        # 本轮先标记全部三连，之后再统一下落，保留交叉消除。
        while True:
            changed = False
            for r in range(rows):
                for c in range(cols):
                    value = abs(board[r][c])
                    if not value:
                        continue
                    if c + 2 < cols and abs(board[r][c + 1]) == abs(board[r][c + 2]) == value:
                        for col in range(c, c + 3):
                            board[r][col] = -value
                        changed = True
                    if r + 2 < rows and abs(board[r + 1][c]) == abs(board[r + 2][c]) == value:
                        for row in range(r, r + 3):
                            board[row][c] = -value
                        changed = True
            if not changed:
                return board
            for c in range(cols):
                write = rows - 1
                for r in range(rows - 1, -1, -1):
                    if board[r][c] > 0:
                        board[write][c] = board[r][c]
                        write -= 1
                for r in range(write + 1):
                    board[r][c] = 0
```

### 面试追问

**为什么消完还要再扫一轮？** 下落可以把原本隔开的同色糖果连起来。只有一次完整扫描没有标出任何格子，才能确认当前棋盘稳定。

### 复杂度

R 行 C 列、t 轮消除，时间 O((t+1)RC)，辅助空间 O(1)。

每轮完整检查一次棋盘并压实所有列，两次都是 RC 量级。稳定后仍需最后一轮检查，因此复杂度包含 t+1。
