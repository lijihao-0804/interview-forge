# 244. 最短单词距离 II

### 题意

给固定词序列建索引，随后多次回答两个不同词之间的最短下标距离。

### 输入与约束

构造 WordDistance 时传入固定词典；之后每次查询两个不同且已出现的词，返回任意一对出现位置间的最短距离。

### 示例

序列 [a,b,x,x,a] 中 a 的下标为 [0,4]，x 为 [2,3]，最短距离来自 4 和 3，答案 1。

### 核心不变量

比较两游标后，较小位置与对方余下所有位置的距离都不会更优，可以永久移走。

### 思路

每个词的下标天然有序。双指针对比两个下标，把较小者前移：若保留较小者并推进较大者，距离只会增加。

词典固定而查询会反复到来，预先存储每个词按扫描顺序出现的位置。查询时两条列表都已升序。较小位置若不移动，它与对方后续更大位置的距离只会增长，因此比较后可以安全跳过它。

### 边界检查

两个位置表都已从小到大排列。当前下标较小的一侧应先向前走，因为让较大的一侧再往右移，本轮差距只会变大。

### 反例推演

两词下标分别为 `[0,3]` 与 `[2,7]`。首对差 2；推进较小的 0 后，3 和 2 的差为 1。如果反而推进较大的 2，会错过唯一相差 1 的位置对。

### Java

Java 构造函数写入 wordToIndices，查询只读取两个 `List<Integer>`。下标 i、j 各自只向右走，任一列表耗尽就已考察所有可能改善答案的配对。

#### 合并扫描 a 和 x 的下标表

| 步骤 | 当前状态 | 判断依据 |
| --- | --- | --- |
| 建立索引 | a→[0,4]，x→[2,3] | 构造一次后可供所有查询重复使用。 |
| 比较 0 与 2 | 差为 2；0<2，推进 a 到 4 | 未来的 x 只会离 0 更远。 |
| 比较 4 与 2、3 | 先得 2，推进 x 后得到 1 | x 列表耗尽，返回最小距离 1。 |

```java
import java.util.*;

class WordDistance {
    public WordDistance(String[] words) {
        for (int i = 0; i < words.length; ++i) {
            wordToIndices.putIfAbsent(words[i], new ArrayList<>());
            wordToIndices.get(words[i]).add(i);
        }
    }

    public int shortest(String word1, String word2) {
        List<Integer> indices1 = wordToIndices.get(word1);
        List<Integer> indices2 = wordToIndices.get(word2);
        int ans = Integer.MAX_VALUE;

        // 两表都有序，推进较小的位置才可能缩短距离。
        for (int i = 0, j = 0; i < indices1.size() && j < indices2.size(); ) {
            ans = Math.min(ans, Math.abs(indices1.get(i) - indices2.get(j)));
            if (indices1.get(i) < indices2.get(j)) ++i;
            else ++j;
        }

        return ans;
    }

    private Map<String, List<Integer>> wordToIndices = new HashMap<>();
}
```

### Python

Python 的 defaultdict(list) 让首次出现的词有独立列表。ans 从无穷大开始，先用当前两个下标的绝对差更新，再推进值较小一侧；不能按列表游标 i、j 自身的大小决定移动。

#### 合并扫描 a 和 x 的下标表

| 步骤 | 当前状态 | 判断依据 |
| --- | --- | --- |
| 建立索引 | a→[0,4]，x→[2,3] | 构造一次后可供所有查询重复使用。 |
| 比较 0 与 2 | 差为 2；0<2，推进 a 到 4 | 未来的 x 只会离 0 更远。 |
| 比较 4 与 2、3 | 先得 2，推进 x 后得到 1 | x 列表耗尽，返回最小距离 1。 |

```python
from __future__ import annotations
import collections
import math


class WordDistance:
    def __init__(self, wordsDict: list[str]):
        self.wordToIndices = collections.defaultdict(list)
        for i, word in enumerate(wordsDict):
            self.wordToIndices[word].append(i)

    def shortest(self, word1: str, word2: str) -> int:
        indices1 = self.wordToIndices[word1]
        indices2 = self.wordToIndices[word2]
        ans = math.inf

        i = 0
        j = 0
        # 两表都有序，推进较小的位置才可能缩短距离。
        while i < len(indices1) and j < len(indices2):
            ans = min(ans, abs(indices1[i] - indices2[j]))
            if indices1[i] < indices2[j]:
                i += 1
            else:
                j += 1

        return ans
```

### 面试追问

**为什么不直接把两份列表做笛卡尔积？** 各有 p、q 个位置时，逐对比较要 pq 次。已排序的结构允许每次永久淘汰一个位置，最多考察 p+q−1 对。

### 复杂度

建表 O(n) 时间与空间；两词出现 a、b 次，单次查询 O(a+b) 时间、O(1) 辅助空间。

预处理将 N 个下标各保存一次。一次查询的双指针最多合计推进 p+q 次，其中 p、q 是两个词各自的出现次数。
