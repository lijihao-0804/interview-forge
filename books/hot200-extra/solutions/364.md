# 364. 嵌套列表加权和 II


### 题意

深层整数权重较小：若整数最大深度为 D，深度 d 的整数乘 D−d+1，求加权和。

### 输入与约束

输入为 NestedInteger 的嵌套列表，顶层深度为 1。D 按整数所在最深层计算，深度 d 的整数权重为 D−d+1。

### 示例

[2,[3,[4]]] 的权重依次是 3、2、1，所以结果为 6+6+4=16。

### 核心不变量

走到层 t 时，prevSum 是前 t 层整数和，weightedSum 对深度 d 的已见整数累计 t−d+1 次。

### 思路

按层遍历并累计截至当前层出现过的整数之和；每多一层，浅层整数又加一次。答案取最后一个含整数的层，避免末尾空列表造成多算。

如果先找最大深度再逐项乘权，会遍历两遍。也可以反向看权重：深度 d 的整数，恰好应在 d,d+1,…,D 这几层各贡献一次。每层把“到目前为止见过的整数总和”整体累加，就实现了这个重复次数。

#### 三个整数的重复贡献

| 步骤 | 当前状态 | 为什么这样走 |
| --- | --- | --- |
| 第 1 层 | 读 2，prevSum=2，weightedSum=2 | 2 第一次贡献。 |
| 第 2 层 | 读 3，prevSum=5，weightedSum=7 | 2 再贡献一次，3 开始贡献。 |
| 第 3 层 | 读 4，prevSum=9，weightedSum=16 | 总计 2×3+3×2+4×1=16。 |

### 边界检查

只有整数决定最深有效层。若更深处只是空列表，不应让上层整数的反向权重凭空增加。

### 反例推演

输入 `[1,[2,[[]]]]`，最深整数是 2。空列表的嵌套不能提高 1 和 2 的反向权重，正确和为 1×2+2×1=4。

### Java

#### 三个累计值与最后一个整数层

`prevSum` 跨层保留整数和，weightedSum 逐层加 prevSum。hasInteger 指示当前层是否可能成为最深有效层，只有此时才把累计值交给 ans。

```java
import java.util.*;

class Solution {
    public int depthSumInverse(List<NestedInteger> nestedList) {
        int ans = 0;
        int prevSum = 0;
        int weightedSum = 0;
        Queue<NestedInteger> q = new ArrayDeque<>(nestedList);

        while (!q.isEmpty()) {
            boolean hasInteger = false;
            for (int sz = q.size(); sz > 0; --sz) {
                final NestedInteger ni = q.poll();
                if (ni.isInteger()) {
                    hasInteger = true;
                    prevSum += ni.getInteger();
                } else q.addAll(ni.getList());
            }
            // 每加深一层，先前发现的整数就再贡献一次。
            weightedSum += prevSum;
            if (hasInteger) ans = weightedSum;
        }

        return ans;
    }
}
```

### Python

#### 将层和带入更深的队列批次

`range(len(q))` 固定当前层，遇到列表则把直接孩子留给下一层。has_integer 依据对象类型设置，即便这一层整数和为零，也要保存该层结果。

```python
from __future__ import annotations
import collections


class Solution:
    def depthSumInverse(self, nestedList: list[NestedInteger]) -> int:
        ans = 0
        prevSum = 0
        weightedSum = 0
        q = collections.deque(nestedList)

        while q:
            has_integer = False
            for _ in range(len(q)):
                ni = q.popleft()
                if ni.isInteger():
                    has_integer = True
                    prevSum += ni.getInteger()
                else:
                    for nextNi in ni.getList():
                        q.append(nextNi)
            # 每加深一层，先前发现的整数就再贡献一次。
            weightedSum += prevSum
            if has_integer:
                ans = weightedSum

        return ans
```

### 复杂度

时间 O(N)，队列空间 O(W)，N 为总节点数，W 为最大层宽。

每个对象仅出入队一次。队列同时容纳当前层末尾和下一层开头，规模受最大层宽约束。

### 面试追问

**中间一层没有整数是否跳过累加？** 不能。它可能连接一个更深整数，浅层整数仍该多贡献一次。每层都加 prevSum，只让最终答案停在最后一个真正含整数的层。
