# 248. 中心对称数 III

### 题意

给定两个用字符串表示的整数界限，统计闭区间内旋转 180° 后保持不变的整数。

### 输入与约束

输入无多余前导零的非负十进制字符串 low、high，且 low≤high；计算两端都包含在内的中心对称数个数。

### 示例

从 68 到 89 含 69、88，共 2 个；端点若恰好对称也要计入。

### 核心不变量

每进入下一层就固定一对合法镜像数字，完成的候选才参与同长度端点比较。

### 思路

逐个长度从两端向中间填旋转对。长度等于边界时再按字典序筛选；不同长度的十进制数字不能直接按字典序比较。

两端都是数字串，直接遍历其间整数会把绝大多数计算花在旋转不合法的数上。按位数枚举，只填合法首尾对；填满后，只需与同长度的边界比较，因为无前导零的等长数字串，字典序就是数值序。

### 边界检查

同长度数字可以直接按字符串顺序和端点比较。长度介于上下界之间的候选无需逐个和两个端点比，但仍须排除多位数的前导零。

### Java

Java 在每个长度上复用一个 char[]，l、r 以外的数字已经确定。到叶子时创建 String 进行 compareTo，严格小于下界或严格大于上界才排除；进入新一轮调用先重置计数。

#### 筛选 68 到 89 的候选

| 步骤 | 当前状态 | 判断依据 |
| --- | --- | --- |
| 确定枚举长度 | 68 与 89 都有两位，只构造长度 2 | 不检查一位或三位候选。 |
| 筛下界 | 两位首位不可为零；11<68，69 在区间内 | 计数从 0 变为 1。 |
| 筛上界 | 88≤89，计数到 2；96>89 被排除 | 最后留下 69、88。 |

```java
import java.util.*;

class Solution {
    public int strobogrammaticInRange(String low, String high) {
        ans = 0;
        for (int n = low.length(); n <= high.length(); ++n) {
            char[] c = new char[n];
            dfs(low, high, c, 0, n - 1);
        }

        return ans;
    }

    private int ans = 0;

    private static final char[][] pairs = {
        {'0', '0'}, {'1', '1'}, {'6', '9'}, {'8', '8'}, {'9', '6'}
    };

    private void dfs(final String low, final String high, char[] c, int l, int r) {
        // 只有全部数字填好后才与同长度界限比较。
        if (l > r) {
            final String s = new String(c);
            if (s.length() == low.length() && s.compareTo(low) < 0) return;
            if (s.length() == high.length() && s.compareTo(high) > 0) return;
            ++ans;
            return;
        }

        for (char[] pair : pairs) {
            if (l == r && pair[0] != pair[1]) continue;
            c[l] = pair[0];
            c[r] = pair[1];
            if (c.length > 1 && c[0] == '0') continue;
            dfs(low, high, c, l + 1, r - 1);
        }
    }
}
```

### Python

Python 在列表 s 上覆盖左右位置，递归回到同一层后会重写，因而无需复制整个数组。中心只有一格时先过滤 leftDigit!=rightDigit，避免放入旋转后会改变的 6 或 9。

#### 筛选 68 到 89 的候选

| 步骤 | 当前状态 | 判断依据 |
| --- | --- | --- |
| 确定枚举长度 | 68 与 89 都有两位，只构造长度 2 | 不检查一位或三位候选。 |
| 筛下界 | 两位首位不可为零；11<68，69 在区间内 | 计数从 0 变为 1。 |
| 筛上界 | 88≤89，计数到 2；96>89 被排除 | 最后留下 69、88。 |

```python
from __future__ import annotations


class Solution:
    def strobogrammaticInRange(self, low: str, high: str) -> int:
        pairs = [["0", "0"], ["1", "1"], ["6", "9"], ["8", "8"], ["9", "6"]]
        ans = 0

        def dfs(s: list[str], l: int, r: int) -> None:
            nonlocal ans
            # 只有全部数字填好后才与同长度界限比较。
            if l > r:
                if len(s) == len(low) and "".join(s) < low:
                    return
                if len(s) == len(high) and "".join(s) > high:
                    return
                ans += 1
                return

            for leftDigit, rightDigit in pairs:
                if l == r and leftDigit != rightDigit:
                    continue
                s[l] = leftDigit
                s[r] = rightDigit
                if len(s) > 1 and s[0] == "0":
                    continue
                dfs(s, l + 1, r - 1)

        for n in range(len(low), len(high) + 1):
            dfs([" "] * n, 0, n - 1)

        return ans
```

### 面试追问

**位数很大时，如何避免生成每个完整候选？** 可以按前半段逐位计数。一旦前缀已严格落在界内，余下每层按允许的数对数相乘即可；贴着边界的分支才继续比较。

### 复杂度

最大位数 L；时间 O(L·5^⌈L/2⌉)，递归及缓冲区 O(L)。

每对位置至多五个候选，故叶子数量上界为 5 的半位数次方；每个完整候选作 O(L) 拼接及比较，路径与填数缓冲长 O(L)。
