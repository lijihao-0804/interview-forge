# 248. 中心对称数 III

### 题意

给定两个用字符串表示的整数界限，统计闭区间内旋转 180° 后保持不变的整数。

### 示例

从 68 到 89 含 69、88，共 2 个；端点若恰好对称也要计入。

### 思路

逐个长度从两端向中间填旋转对。长度等于边界时再按字典序筛选；不同长度的十进制数字不能直接按字典序比较。

### 边界检查

同长度数字可以直接按字符串顺序和端点比较。长度介于上下界之间的候选无需逐个和两个端点比，但仍须排除多位数的前导零。

### Java

```java
import java.util.*;

class Solution {
    public int strobogrammaticInRange(String low, String high) {
        ans = 0;
        for (int n = low.length(); n <= high.length(); ++n) {
            char[] c = new char[n];
            dfs(low, high, c, 0, n - 1);
        }

        return ans;
    }

    private int ans = 0;

    private static final char[][] pairs = {
        {'0', '0'}, {'1', '1'}, {'6', '9'}, {'8', '8'}, {'9', '6'}
    };

    private void dfs(final String low, final String high, char[] c, int l, int r) {
        // 只有全部数字填好后才与同长度界限比较。
        if (l > r) {
            final String s = new String(c);
            if (s.length() == low.length() && s.compareTo(low) < 0) return;
            if (s.length() == high.length() && s.compareTo(high) > 0) return;
            ++ans;
            return;
        }

        for (char[] pair : pairs) {
            if (l == r && pair[0] != pair[1]) continue;
            c[l] = pair[0];
            c[r] = pair[1];
            if (c.length > 1 && c[0] == '0') continue;
            dfs(low, high, c, l + 1, r - 1);
        }
    }
}
```

### Python

```python
from __future__ import annotations


class Solution:
    def strobogrammaticInRange(self, low: str, high: str) -> int:
        pairs = [["0", "0"], ["1", "1"], ["6", "9"], ["8", "8"], ["9", "6"]]
        ans = 0

        def dfs(s: list[str], l: int, r: int) -> None:
            nonlocal ans
            # 只有全部数字填好后才与同长度界限比较。
            if l > r:
                if len(s) == len(low) and "".join(s) < low:
                    return
                if len(s) == len(high) and "".join(s) > high:
                    return
                ans += 1
                return

            for leftDigit, rightDigit in pairs:
                if l == r and leftDigit != rightDigit:
                    continue
                s[l] = leftDigit
                s[r] = rightDigit
                if len(s) > 1 and s[0] == "0":
                    continue
                dfs(s, l + 1, r - 1)

        for n in range(len(low), len(high) + 1):
            dfs([" "] * n, 0, n - 1)

        return ans
```

### 复杂度

最大位数 L；时间 O(L·5^⌈L/2⌉)，递归及缓冲区 O(L)。
