# 439. 三元表达式解析器


### 题意

解析右结合的三元表达式，每个条件是 T 或 F，每个叶子是一个字符。返回最终选择的字符。

### 输入与约束

输入是语法正确的右结合三元表达式，条件为 T 或 F，叶子为单个数字或布尔字符。返回最终单字符值。

### 示例

F?3:T?4:5 的外层取右分支，内层 T 再选择 4，所以结果为字符 4。

### 核心不变量

扫描到某条件时，其右侧已完整处理的嵌套表达式均化为单值，栈顶问号下方的真假分支可以直接取用。

### 思路

从右到左扫描，让内层选择先完成。遇到条件字符且栈顶是问号时，栈顶以下已就绪的两个分支分别给出真假值；取出问号、两个分支和冒号，把选中的值压回栈。

从左到右遇到问号时两个分支都还没有值，需要额外处理右结合的嵌套关系。逆向读则恰好相反：遇到一个条件前，右侧的真分支与假分支已经分别化成单字符，弹出它们即可就地归约。

#### 先算 T 再算外层 F

| 步骤 | 当前状态 | 为什么这样走 |
| --- | --- | --- |
| 准备内层分支 | 从右向左读 5、:、4、?，栈顶为 ? | 真分支为 4，假分支为 5。 |
| 归约 T 条件 | T?4:5 → 4，栈只剩 4 | 已选真分支可当作外层假分支。 |
| 归约 F 条件 | F?3:4 → 4，返回字符 4 | 外层 F 取右分支。 |

### 边界检查

三元表达式按右结合解释，例如 `F?3:T?4:5`。从右向左先化简内层后，外层面对的左右分支都已经是单个值。

### 反例推演

表达式 `F?1:T?4:5` 的结果为 4。先从最左端随意取一对问号/冒号会破坏右结合关系，须先将右侧子表达式归约为单值。

### Java

#### 按问号识别一次完整归约

`Deque<Character>` 的栈顶若为问号，此时正在读的 token 才是条件。依次弹问号、真值、冒号、假值，根据 T 或 F 压回其中一个。

```java
import java.util.*;

class Solution {
    public String parseTernary(String expression) {
        Deque<Character> stack = new ArrayDeque<>();
        for (int i = expression.length() - 1; i >= 0; i--) {
            char token = expression.charAt(i);
            // 逆序读取到条件时，内层两个分支都已收缩成单个值。
            if (!stack.isEmpty() && stack.peek() == '?') {
                stack.pop();
                char first = stack.pop();
                stack.pop();
                char second = stack.pop();
                stack.push(token == 'T' ? first : second);
            } else {
                stack.push(token);
            }
        }
        return String.valueOf(stack.pop());
    }
}
```

### Python

#### 从列表尾部弹出真假分支

`reversed(expression)` 从右端开始扫描，每次归约的结果仍是可当作外层分支使用的字符。仅凭 token 是 T/F 不能决定归约，因为它们也可能出现在叶子位置。

```python
from __future__ import annotations


class Solution:
    def parseTernary(self, expression: str) -> str:
        stack = []
        for token in reversed(expression):
            # 逆序读取到条件时，内层两个分支都已收缩成单个值。
            if stack and stack[-1] == "?":
                stack.pop()
                first = stack.pop()
                stack.pop()
                second = stack.pop()
                stack.append(first if token == "T" else second)
            else:
                stack.append(token)
        return stack.pop()
```

### 复杂度

每个字符进出栈至多一次，时间 O(n)，栈空间 O(n)。

单个输入 token 最多压栈一次，每次条件归约只弹常数项。未完成的右侧表达式最多占 n 个栈位。

### 面试追问

**叶子改成多位整数怎么办？** 先将表达式拆成条件、问号、冒号及完整数值的 token，再按 token 的逆序运行同样的归约；不能继续逐字符压栈。
