# 737. 句子相似性 II

### 题意

逐词判定两句话是否相似，这次允许沿若干已知相似词对传递。

### 输入与约束

输入两个句子及无向相似词对，允许沿任意条已给关系传递；词数和对应位置均须匹配。

### 示例

词对 red–scarlet、scarlet–ruby 把三个词连成一组，因此 `ruby car` 与 `red car` 相似。

### 核心不变量

处理过的边把词划成若干分量，两个已登记的词同根，当且仅当它们能沿这些边相连。

### 思路

每个词起初是自己的集合。读入相似词对时合并两端的集合，把较小树的根接到较大树上；查询代表时用循环压缩路径。逐位比较两句，词相同直接通过，不同词只有同属一个集合才能匹配。词数不等立即失败。

允许传递后，需要判断的是“能不能沿边走到”，而不是必须找出具体路径。每条新边把两个已有连通分量合为一个。并查集只保留谁是代表，句中不同词逐位查代表即可；合并与压缩都不改变分量成员。

### 边界检查

两句话中相同位置的词若拼写一致，即使没出现在任何词对里也应通过。只有拼写不同的一对才需要检查能否沿着相似关系相连。

### Java

Java 用两个 Map 分别保存父代表和分量大小。字符串比较应按内容使用 equals；只在根的 size 上合并重量，把较小分量接入较大分量后，其他结点暂时仍可沿旧父指针找到新根。

#### 追踪同义词分量的合并

| 步骤 | 当前状态 | 判断依据 |
| --- | --- | --- |
| 合并第一对 | {red,scarlet} 成为一个分量 | 直接相似提供第一条连接。 |
| 合并第二对 | scarlet 与 ruby 相连，分量变成 {red,scarlet,ruby} | 二者通过已有代表合并。 |
| 逐词对照 | ruby 和 red 同根；car 和 car 相同，返回 true | 第二个位置无需在词表中查找。 |

```java
import java.util.*;

class Solution {
    private String find(Map<String, String> parent, String word) {
        while (!word.equals(parent.get(word))) {
            // 把当前节点直接接到祖父，逐步压短以后的查找路径。
            parent.put(word, parent.get(parent.get(word)));
            word = parent.get(word);
        }
        return word;
    }

    public boolean areSentencesSimilarTwo(String[] a, String[] b, List<List<String>> pairs) {
        if (a.length != b.length) return false;
        Map<String, String> parent = new HashMap<>();
        Map<String, Integer> size = new HashMap<>();
        for (List<String> pair : pairs) {
            for (String word : pair) {
                parent.putIfAbsent(word, word);
                size.putIfAbsent(word, 1);
            }
            String x = find(parent, pair.get(0)), y = find(parent, pair.get(1));
            if (x.equals(y)) continue;
            if (size.get(x) < size.get(y)) {
                String tmp = x;
                x = y;
                y = tmp;
            }
            parent.put(y, x);
            size.put(x, size.get(x) + size.get(y));
        }
        for (int i = 0; i < a.length; i++) {
            if (a[i].equals(b[i])) continue;
            if (!parent.containsKey(a[i]) || !parent.containsKey(b[i])) return false;
            if (!find(parent, a[i]).equals(find(parent, b[i]))) return false;
        }
        return true;
    }
}
```

### Python

Python 以 setdefault 初始化单词，find 中让当前节点指向祖父，缩短以后查询的路径。句中完全相同的词可以跳过，若不同且任一未登记，则不可能由词对推出相似。

#### 追踪同义词分量的合并

| 步骤 | 当前状态 | 判断依据 |
| --- | --- | --- |
| 合并第一对 | {red,scarlet} 成为一个分量 | 直接相似提供第一条连接。 |
| 合并第二对 | scarlet 与 ruby 相连，分量变成 {red,scarlet,ruby} | 二者通过已有代表合并。 |
| 逐词对照 | ruby 和 red 同根；car 和 car 相同，返回 true | 第二个位置无需在词表中查找。 |

```python
class Solution:
    def areSentencesSimilarTwo(self, sentence1, sentence2, similarPairs) -> bool:
        if len(sentence1) != len(sentence2):
            return False
        parent, size = {}, {}

        def find(word):
            while word != parent[word]:
                parent[word] = parent[parent[word]]
                word = parent[word]
            return word

        for a, b in similarPairs:
            for word in (a, b):
                parent.setdefault(word, word)
                size.setdefault(word, 1)
            x, y = find(a), find(b)
            if x == y:
                continue
            # 小树接到大树，避免长同义词链产生很深的搜索路径。
            if size[x] < size[y]:
                x, y = y, x
            parent[y] = x
            size[x] += size[y]

        for a, b in zip(sentence1, sentence2):
            if a != b and (a not in parent or b not in parent or find(a) != find(b)):
                return False
        return True
```

### 面试追问

**为什么不对句中的每对词分别做 DFS？** 每次都可能重新遍历同一个大分量。预处理时合并一次之后，每次查根就能复用先前得到的连通信息。

### 复杂度

p 个词对、n 对待比较词、V 个不同词；平均哈希访问下，时间 O((p+n)α(V+1))，空间 O(V)。

按大小合并与路径压缩使每次查根的摊还成本为反阿克曼函数；parent 和 size 各保存一次已出现的词。
