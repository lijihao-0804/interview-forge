# 314. 二叉树的垂直遍历


### 题意

按列从左到右输出二叉树。同列按深度排序，同层同列按在树中的左右次序排列。

### 输入与约束

输入是可能为空的二叉树。输出按列由左及右，同列先按深度、再按同层左右先后，节点值不参与排序。

### 示例

根 7 有左右子 2、9，2 的右子是 4，9 的左子是 5。列结果为 [[2],[7,4,5],[9]]，同层同列的 4 排在 5 前。

### 核心不变量

每次从队首取出的节点按层和同层左右顺序排列，追加到所属列后该桶内顺序已确定。

### 思路

根的列为 0，向左列减一，向右列加一。先求列范围，再按层遍历并先入左子，列桶中的追加次序就是题目要求的次序。

列号决定归属，却不能决定同一列里谁先出现。沿广度优先队列先处理浅层，在同层按父节点先后及左孩子优先入队，碰到同层同列的两个节点时已经排好了顺序。预先知道列范围即可直接追加到数组桶。

#### 同层的 4、5 落在同一列

| 步骤 | 当前状态 | 为什么这样走 |
| --- | --- | --- |
| 编号并放入根 | 实际列范围 −1…1，根 7 写中间桶 | 左、根、右三个桶下标依次为 0、1、2。 |
| 处理第一层 | 2 入左桶，9 入右桶；下一层依次排 4、5 | 先处理左父 2，它的右子先进入队列。 |
| 处理同列冲突 | 中间桶由 [7] 变成 [7,4,5] | 同层保留队列先后，结果 [[2],[7,4,5],[9]]。 |

### 边界检查

同一行、同一列的两个节点要按从左到右的顺序输出。逐层访问时让左孩子先入队，此时保留入队顺序就足够了。

### Java

#### 先求列跨度再分桶

`getRange` 用 int[2] 在递归中更新最左和最右列。根在结果中的下标是 −range[0]。范围偏移只改变桶号，不改变每走左边减一、走右边加一的规律。

```java
import java.util.*;

class Solution {
    public List<List<Integer>> verticalOrder(TreeNode root) {
        if (root == null) return new ArrayList<>();

        List<List<Integer>> ans = new ArrayList<>();
        Queue<Map.Entry<TreeNode, Integer>> q = new ArrayDeque<>();
        int[] range = new int[2];
        getRange(root, range, 0);

        for (int i = range[0]; i <= range[1]; ++i) ans.add(new ArrayList<>());

        q.offer(Map.entry(root, -range[0]));

        // 队列按层访问，先左后右使同列同层的值保持读图顺序。
        while (!q.isEmpty()) {
            final TreeNode node = q.peek().getKey();
            final int x = q.poll().getValue();
            ans.get(x).add(node.val);
            if (node.left != null) q.offer(Map.entry(node.left, x - 1));
            if (node.right != null) q.offer(Map.entry(node.right, x + 1));
        }

        return ans;
    }

    private void getRange(TreeNode root, int[] range, int x) {
        if (root == null) return;

        range[0] = Math.min(range[0], x);
        range[1] = Math.max(range[1], x);

        getRange(root.left, range, x - 1);
        getRange(root.right, range, x + 1);
    }
}
```

### Python

#### 为每个列号建独立列表

`ans` 的列表推导为每列创建独立桶。队列项携带节点和偏移后的列，popleft 后把节点值追加到对应桶，然后依次放入两名孩子。

```python
from __future__ import annotations
import collections


class Solution:
    def verticalOrder(self, root: TreeNode | None) -> list[list[int]]:
        if not root:
            return []

        range_ = [0] * 2

        def getRange(root: TreeNode | None, x: int) -> None:
            if not root:
                return

            range_[0] = min(range_[0], x)
            range_[1] = max(range_[1], x)

            getRange(root.left, x - 1)
            getRange(root.right, x + 1)

        getRange(root, 0)

        ans = [[] for _ in range(range_[1] - range_[0] + 1)]
        q = collections.deque([(root, -range_[0])])

        # 队列按层访问，先左后右使同列同层的值保持读图顺序。
        while q:
            node, x = q.popleft()
            ans[x].append(node.val)
            if node.left:
                q.append((node.left, x - 1))
            if node.right:
                q.append((node.right, x + 1))

        return ans
```

### 复杂度

时间 O(n)，队列、递归栈与结果合计 O(n)。

一次深搜确定范围，一次层序遍历分桶，各节点每遍访问一次。栈最多树高、队列最多层宽，结果保存全部节点。

### 面试追问

**可否让同层同列按值排序？** 本题要保持树中的左右次序。若把 4 和 5 的值对调，先到的仍应先输出；按值排序会改变这种次序。
