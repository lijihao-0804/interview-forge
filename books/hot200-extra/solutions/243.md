# 243. 最短单词距离

### 题意

在一个词序列里求两个不同指定词的最小下标距离。

### 输入与约束

输入词序列与两个不同的查询词，二者均在序列中出现。位置从零计，距离为两个位置之差的绝对值。

### 示例

序列 [a,x,b,a] 中 a、b 的最近位置是 3 和 2，差为 1。

### 核心不变量

index1、index2 各自保存最新出现的位置；ans 是已经看过的所有有效位置对的最短距离。

### 思路

顺序扫描只保存两词最近的下标；碰到其中一词时，另一词在它左侧的最近位置支配更早的出现位置。第二种词还没出现前不能更新距离。

最短距离的一对出现位置必有一个较晚者。扫描到较晚者时，只需与另一词最近一次出现的位置相减；比它更早的位置距离只会更大。这把所有成对比较压缩成两个下标和一个历史最小值。

### 边界检查

对当前遇到的词，只用比较另一个词最近一次出现的位置。更早出现的同一个词离当前位置只会更远，可以直接用新下标替换。

### Java

Java 的 index1 与 index2 初始为 −1。读到某个目标时先更新它自己的下标，另一侧已出现才计算差；当前位置一定更靠右，所以这一分支无需取绝对值。

#### 跟随最新一次 a 与 b

| 步骤 | 当前状态 | 判断依据 |
| --- | --- | --- |
| 读 a 与 x | 下标 0 记为最新 a；下标 1 的 x 跳过 | 另一词尚未出现，无法计算距离。 |
| 遇到 b | b 在 2；与 a 的下标 0 相差 2，ans=2 | 这是首个有效词对。 |
| 遇到新的 a | a 在 3，最近 b 在 2；ans=min(2,1)=1 | 未来只需保留更新的 a 下标。 |

```java
import java.util.*;

class Solution {
    public int shortestDistance(String[] wordsDict, String word1, String word2) {
        int ans = wordsDict.length;
        int index1 = -1;
        int index2 = -1;

        // 遇到一个目标词，只需和另一个词最近出现的位置比较。
        for (int i = 0; i < wordsDict.length; ++i) {
            if (wordsDict[i].equals(word1)) {
                index1 = i;
                if (index2 != -1) ans = Math.min(ans, index1 - index2);
            }
            if (wordsDict[i].equals(word2)) {
                index2 = i;
                if (index1 != -1) ans = Math.min(ans, index2 - index1);
            }
        }

        return ans;
    }
}
```

### Python

Python 的 enumerate 同时交付下标和词。非目标词不改动任何记录，ans 始终代表此前已完整遇到的词对的最小距离，列表无需切片或复制。

#### 跟随最新一次 a 与 b

| 步骤 | 当前状态 | 判断依据 |
| --- | --- | --- |
| 读 a 与 x | 下标 0 记为最新 a；下标 1 的 x 跳过 | 另一词尚未出现，无法计算距离。 |
| 遇到 b | b 在 2；与 a 的下标 0 相差 2，ans=2 | 这是首个有效词对。 |
| 遇到新的 a | a 在 3，最近 b 在 2；ans=min(2,1)=1 | 未来只需保留更新的 a 下标。 |

```python
from __future__ import annotations


class Solution:
    def shortestDistance(
        self,
        wordsDict: list[str],
        word1: str,
        word2: str,
    ) -> int:
        ans = len(wordsDict)
        index1 = -1
        index2 = -1

        # 遇到一个目标词，只需和另一个词最近出现的位置比较。
        for i, word in enumerate(wordsDict):
            if word == word1:
                index1 = i
                if index2 != -1:
                    ans = min(ans, index1 - index2)
            if word == word2:
                index2 = i
                if index1 != -1:
                    ans = min(ans, index2 - index1)

        return ans
```

### 面试追问

**若相同词典要回答大量查询，仍每次扫描吗？** 可预先为各词收集有序位置列表。一次指定词对查询只需在这两条列表上做双指针，跳过所有不相关词。

### 复杂度

n 个词；时间 O(n)，辅助空间 O(1)。

每个词仅检查一次，历史仅用两个最近下标和当前最短距离概括，不额外保存出现列表。
