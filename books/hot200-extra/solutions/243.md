# 243. 最短单词距离

### 题意

在一个词序列里求两个不同指定词的最小下标距离。

### 示例

序列 [a,x,b,a] 中 a、b 的最近位置是 3 和 2，差为 1。

### 思路

顺序扫描只保存两词最近的下标；碰到其中一词时，另一词在它左侧的最近位置支配更早的出现位置。第二种词还没出现前不能更新距离。

### 边界检查

对当前遇到的词，只用比较另一个词最近一次出现的位置。更早出现的同一个词离当前位置只会更远，可以直接用新下标替换。

### Java

```java
import java.util.*;

class Solution {
    public int shortestDistance(String[] wordsDict, String word1, String word2) {
        int ans = wordsDict.length;
        int index1 = -1;
        int index2 = -1;

        // 遇到一个目标词，只需和另一个词最近出现的位置比较。
        for (int i = 0; i < wordsDict.length; ++i) {
            if (wordsDict[i].equals(word1)) {
                index1 = i;
                if (index2 != -1) ans = Math.min(ans, index1 - index2);
            }
            if (wordsDict[i].equals(word2)) {
                index2 = i;
                if (index1 != -1) ans = Math.min(ans, index2 - index1);
            }
        }

        return ans;
    }
}
```

### Python

```python
from __future__ import annotations


class Solution:
    def shortestDistance(
        self,
        wordsDict: list[str],
        word1: str,
        word2: str,
    ) -> int:
        ans = len(wordsDict)
        index1 = -1
        index2 = -1

        # 遇到一个目标词，只需和另一个词最近出现的位置比较。
        for i, word in enumerate(wordsDict):
            if word == word1:
                index1 = i
                if index2 != -1:
                    ans = min(ans, index1 - index2)
            if word == word2:
                index2 = i
                if index1 != -1:
                    ans = min(ans, index2 - index1)

        return ans
```

### 复杂度

n 个词；时间 O(n)，辅助空间 O(1)。
