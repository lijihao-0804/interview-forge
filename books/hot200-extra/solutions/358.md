# 358. K 距离间隔重排字符串


### 题意

重新排列小写字母，使相同字符的下标之差至少 k，无法实现时返回空串。

### 示例

aabbc、k=3 可排成 abcab，两对重复字母的下标差都是 3。aaab、k=3 则无法安放第三个 a。

### 思路

对每种字符记录剩余次数和下一次允许使用的位置。在当前已冷却的字符中优先选剩余最多者，尽早消化最难安排的重复字母。

### 边界检查

每次取出一个字符后，它必须跨过 k 个下标间距才能再次使用。若还有未放字符但此刻没有任何字符可选，说明当前输入无法满足间距。

### Java

```java
class Solution {
    public String rearrangeString(String s, int k) {
        final int n = s.length();
        StringBuilder sb = new StringBuilder();
        int[] count = new int[26];

        int[] valid = new int[26];

        for (final char c : s.toCharArray()) ++count[c - 'a'];

        // 在冷却已结束的字符中优先选剩余数量最多的一个。
        for (int i = 0; i < n; ++i) {
            final char c = getBestLetter(count, valid, i);
            if (c == '*') return "";
            sb.append(c);
            --count[c - 'a'];
            valid[c - 'a'] = i + k;
        }

        return sb.toString();
    }

    private char getBestLetter(int[] count, int[] valid, int index) {
        int maxCount = -1;
        char bestLetter = '*';

        for (char c = 'a'; c <= 'z'; ++c)
            if (count[c - 'a'] > 0 && count[c - 'a'] > maxCount && index >= valid[c - 'a']) {
                bestLetter = c;
                maxCount = count[c - 'a'];
            }

        return bestLetter;
    }
}
```

### Python

```python
from __future__ import annotations
import collections
import string


class Solution:
    def rearrangeString(self, s: str, k: int) -> str:
        n = len(s)
        ans = []
        count = collections.Counter(s)

        valid = collections.Counter()

        def getBestLetter(index: int) -> str:
            maxCount = -1
            bestLetter = "*"

            for c in string.ascii_lowercase:
                if count[c] > 0 and count[c] > maxCount and index >= valid[c]:
                    bestLetter = c
                    maxCount = count[c]

            return bestLetter

        # 在冷却已结束的字符中优先选剩余数量最多的一个。
        for i in range(n):
            c = getBestLetter(i)
            if c == "*":
                return ""
            ans.append(c)
            count[c] -= 1
            valid[c] = i + k

        return "".join(ans)
```

### 复杂度

小写字母表大小为 26，时间 O(26n)，除返回字符串外状态空间 O(26)。
