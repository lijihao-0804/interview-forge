# 758. 字符串中的加粗单词

### 题意

在字符串中用最少的粗体标签包住所有匹配词覆盖的字符，重叠或相邻的覆盖必须合并。

### 输入与约束

输入原串及非空词组成的词表。命中区域全部加粗，重叠或紧邻的区域必须合并，未命中字符原样输出。

### 示例

原串 cabde，词表 [ab,bd]。ab 和 bd 共享 b，结果为 `c<b>abd</b>e`。

### 核心不变量

扫描到 i 时，boldEnd 是截至该处开始的所有匹配区间的最远右开端点，i<boldEnd 即被覆盖。

### 思路

对每个起点找匹配，维护已覆盖的最右边界，再将连续覆盖段统一加标签。相邻匹配间没有未覆盖字符，不应拆标签。

字符串中一个位置可能被多个匹配覆盖，但只需判定“至少一个匹配覆盖它”。从左到右处理起点，记录迄今匹配的最远右开端点。当前位置只要小于这个端点就要加粗。第二遍把连续的已覆盖位置合成一个标签，重叠与相邻两种情况便统一了。

### 边界检查

相邻或重叠的命中范围都应该连成一个加粗片段。例如 ab 与 bd 覆盖同一个 b，最终只写一对起止标签。

### Java

Java 用 startsWith(word,i) 直接比对当前位置，并以 Math.max 更新 boldEnd。boolean[] bold 把找词与输出分离，StringBuilder 可一次追加连续区间，索引 j 指向该粗体段后的首字符。

#### 从相交的两个词拼出一个粗体段

| 步骤 | 当前状态 | 判断依据 |
| --- | --- | --- |
| 在下标 1 命中 ab | cabde 中 ab 覆盖 [1,3)，boldEnd=3 | 字符 a、b 将被标记。 |
| 在下标 2 命中 bd | bd 覆盖 [2,4)，boldEnd 从 3 延至 4 | 共享的 b 只需要一份粗体标签。 |
| 输出连续段 | 标记为 [假,真,真,真,假]，粗体段是 abd | 生成 c<b>abd</b>e。 |

```java
import java.util.*;

class Solution {
    public String boldWords(String[] words, String s) {
        final int n = s.length();
        StringBuilder sb = new StringBuilder();

        boolean[] bold = new boolean[n];

        int boldEnd = -1;
        // 更新覆盖的最右端，重叠和相邻的匹配最后一次性加标签。
        for (int i = 0; i < n; ++i) {
            for (final String word : words)
                if (s.startsWith(word, i)) boldEnd = Math.max(boldEnd, i + word.length());
            bold[i] = boldEnd > i;
        }

        int i = 0;
        while (i < n)
            if (bold[i]) {
                int j = i;
                while (j < n && bold[j]) ++j;

                sb.append("<b>").append(s.substring(i, j)).append("</b>");
                i = j;
            } else {
                sb.append(s.charAt(i++));
            }

        return sb.toString();
    }
}
```

### Python

Python 的 s.startswith(word,i) 省去手动切片比较；boldEnd 是排他的右端。输出只在连续真值段两侧放标签，ans 保存片段最终 join，一段中出现几个词都不会多加嵌套标签。

#### 从相交的两个词拼出一个粗体段

| 步骤 | 当前状态 | 判断依据 |
| --- | --- | --- |
| 在下标 1 命中 ab | cabde 中 ab 覆盖 [1,3)，boldEnd=3 | 字符 a、b 将被标记。 |
| 在下标 2 命中 bd | bd 覆盖 [2,4)，boldEnd 从 3 延至 4 | 共享的 b 只需要一份粗体标签。 |
| 输出连续段 | 标记为 [假,真,真,真,假]，粗体段是 abd | 生成 c<b>abd</b>e。 |

```python
from __future__ import annotations


class Solution:
    def boldWords(self, words: list[str], s: str) -> str:
        n = len(s)
        ans = []

        bold = [0] * n

        boldEnd = -1
        # 更新覆盖的最右端，重叠和相邻的匹配最后一次性加标签。
        for i in range(n):
            for word in words:
                if s.startswith(word, i):
                    boldEnd = max(boldEnd, i + len(word))
            bold[i] = boldEnd > i

        i = 0
        while i < n:
            if bold[i]:
                j = i
                while j < n and bold[j]:
                    j += 1

                ans.append("<b>" + s[i:j] + "</b>")
                i = j
            else:
                ans.append(s[i])
                i += 1

        return "".join(ans)
```

### 面试追问

**词表特别大时，瓶颈在哪里？** 当前每个起点都会尝试所有词。可用多模式匹配一次扫描收集出现区间，再沿用同一套区间合并和输出规则。

### 复杂度

字符串长 n、所有词总长 W；时间 O(nW)，空间 O(n)。

每个起点逐一尝试词表匹配，设词表总字符数为 S、原串长 n，匹配最坏 O(nS)，标记和输出扫描 O(n)；覆盖标记与返回内容都随 n 增长。
