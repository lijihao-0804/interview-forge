# 751. IP 到 CIDR

### 题意

把从某个 IPv4 地址起的 n 个连续地址恰好覆盖成最少的 CIDR 地址块。

### 示例

从 10.0.0.2 起取 4 个地址，分成 10.0.0.2/31 和 10.0.0.4/31，覆盖 .2 到 .5。

### 思路

每块大小必须是二的幂，且起始地址需按该大小对齐。选择既对齐又不超过剩余数量的最大块。全零地址可按任意大小对齐，要单独处理。

### 边界检查

起始地址决定当前块的最大对齐尺寸，剩余地址数又给出长度上限，两者都要满足。特别留意全零地址：它可以从任意合法块尺寸开始对齐。

### Java

```java
import java.util.*;

class Solution {
    public List<String> ipToCIDR(String ip, int n) {
        List<String> ans = new ArrayList<>();
        long num = getNum(ip.split("\\."));

        // 取当前地址允许的最大对齐块，同时不能超过剩余地址数。
        while (n > 0) {
            final long lowbit = num & -num;
            final long count = lowbit == 0 ? maxLow(n) : firstFit(lowbit, n);
            ans.add(getCIDR(num, getPrefix(count)));
            n -= (int) count;
            num += count;
        }

        return ans;
    }

    private long getNum(String[] x) {
        long num = 0;
        for (int i = 0; i < 4; ++i) num = num * 256 + Long.parseLong(x[i]);
        return num;
    }

    private int maxLow(int n) {
        for (int i = 0; i < 32; ++i) if (1 << i + 1 > n) return 1 << i;
        throw new IllegalArgumentException();
    }

    private long firstFit(long lowbit, long n) {
        while (lowbit > n) lowbit >>= 1;
        return lowbit;
    }

    private String getCIDR(long num, long prefix) {
        final long d = num & 255;
        num >>= 8;
        final long c = num & 255;
        num >>= 8;
        final long b = num & 255;
        num >>= 8;
        final long a = num & 255;
        return new StringBuilder()
                .append(a)
                .append(".")
                .append(b)
                .append(".")
                .append(c)
                .append(".")
                .append(d)
                .append("/")
                .append(prefix)
                .toString();
    }

    private int getPrefix(long count) {
        for (int i = 0; i < 32; ++i) if (count == 1 << i) return 32 - i;
        throw new IllegalArgumentException();
    }
}
```

### Python

```python
from __future__ import annotations


class Solution:
    def ipToCIDR(self, ip: str, n: int) -> list[str]:
        ans = []
        num = self._getNum(ip.split("."))

        # 取当前地址允许的最大对齐块，同时不能超过剩余地址数。
        while n > 0:
            lowbit = num & -num
            count = self._maxLow(n) if lowbit == 0 else self._firstFit(lowbit, n)
            ans.append(self._getCIDR(num, self._getPrefix(count)))
            n -= count
            num += count

        return ans

    def _getNum(self, x: list[str]) -> int:
        num = 0
        for i in range(4):
            num = num * 256 + int(x[i])
        return num

    def _maxLow(self, n: int) -> int | None:

        for i in range(32):
            if 1 << i + 1 > n:
                return 1 << i

    def _firstFit(self, lowbit: int, n: int) -> int:
        while lowbit > n:
            lowbit >>= 1
        return lowbit

    def _getCIDR(self, num: int, prefix: int) -> str:
        d = num & 255
        num >>= 8
        c = num & 255
        num >>= 8
        b = num & 255
        num >>= 8
        a = num & 255
        return ".".join([str(s) for s in [a, b, c, d]]) + "/" + str(prefix)

    def _getPrefix(self, count: int) -> int | None:

        for i in range(32):
            if count == 1 << i:
                return 32 - i
```

### 复杂度

输出 b 个地址块，IPv4 固定 32 位；时间 O(32b)，除输出外空间 O(1)。
