# 379. 电话目录管理系统


### 题意

管理有限数量的电话号码，支持分配任意空闲号、查询是否空闲、释放已分配的号码。

### 输入与约束

正整数 maxNumbers 定义有效号码 0…maxNumbers−1。get 分配任意空号或返回 −1，check 和 release 使用有效号码。

### 示例

号码池只有 0、1。连续分配两次后再次申请返回 −1，释放 0 后可以再次取得 0。

### 核心不变量

next[x] 为 −1 当且仅当号码 x 已分配；池内仍有空闲号时表头指向可立即取出的号码。

### 思路

用数组维护空闲链表的后继和表头，已用槽标记为 −1。分配弹出表头，释放将节点压回表头，重复释放不会制造重复条目。

分配操作需要立刻找到一个可用号，检查操作又需立刻判断某个指定号。把每个号码当作数组下标，空闲时槽值指向下一个候选，已分配时槽值设为 −1，于是一个数组同时承担链表和状态标记的作用。

#### 两个号码的发放与归还

| 步骤 | 当前状态 | 为什么这样走 |
| --- | --- | --- |
| 分配第一个号 | 初始 next=[1,0]，取 0 后 next=[−1,0]，头 1 | 槽 −1 表明号码 0 已在用。 |
| 号码耗尽 | 取出 1 后 next=[−1,−1]，头 0；再取返回 −1 | 候选头本身已占用，所有号均已分配。 |
| 归还并再取 | 释放 0 后 next=[0,−1]，下一次得到 0 | 释放使该槽重回可分配状态。 |

### 边界检查

重复释放同一个号码，不应把它放入可用池两次。先判断它当前是否已被分配，后续两个申请才不会拿到同一个号码。

### 反例推演

号码 0 已经在空闲池里时重复 release(0)，不能把它插入两次。否则随后两次 get 可能将同一个号码分配给两个调用者。

### Java

#### 用槽值编码已占用状态

`number` 是候选表头。get 先保存其后继再把当前槽置为 −1；若候选槽已经为 −1，池为空。release 只处理已占用槽，重新指向旧头，再把该号设为新头。

```java
class PhoneDirectory {
    public PhoneDirectory(int maxNumbers) {
        next = new int[maxNumbers];
        for (int i = 0; i < maxNumbers - 1; ++i) next[i] = i + 1;
        next[maxNumbers - 1] = 0;
    }

    public int get() {
        // 已占用节点标为 −1；空闲链表头也被占用时没有号码可取。
        if (next[number] == -1) return -1;
        final int availableNum = number;
        number = next[number];
        next[availableNum] = -1;
        return availableNum;
    }

    public boolean check(int number) {
        return next[number] != -1;
    }

    public void release(int number) {
        if (next[number] != -1) return;

        next[number] = this.number;
        this.number = number;
    }

    private int number;
    private int[] next;
}
```

### Python

#### 复用候选头和后继数组

`self.next` 初始令末号指回 0。成功分配后该号的槽立即变成 −1，这个标记可阻止空池继续循环。check 直接查槽值，不会消费号码。

```python
from __future__ import annotations


class PhoneDirectory:
    def __init__(self, maxNumbers: int):

        self.next = [i + 1 for i in range(maxNumbers - 1)] + [0]

        self.number = 0

    def get(self) -> int:
        # 已占用节点标为 −1；空闲链表头也被占用时没有号码可取。
        if self.next[self.number] == -1:
            return -1
        ans = self.number
        self.number = self.next[self.number]
        self.next[ans] = -1
        return ans

    def check(self, number: int) -> bool:
        return self.next[number] != -1

    def release(self, number: int) -> None:
        if self.next[number] != -1:
            return
        self.next[number] = self.number
        self.number = number
```

### 复杂度

初始化时间和空间 O(n)，每种操作 O(1)。

初始化串起 n 个槽。之后的 get、check 和 release 都只读写表头及指定数组项，无需遍历。

### 面试追问

**释放同一个号两次后能否连续取到两份？** 第二次释放时槽已经不是 −1，代码直接返回；只有第一次释放会修改头和后继。
