# 276. 栅栏涂色

### 题意

给 n 根连续栅栏使用 k 种颜色，禁止连续三根颜色相同，求涂法数。

### 输入与约束

给定栅栏数 n 和可用颜色数 k，允许相邻同色但不允许连续三根同色，返回合法涂法总数。

### 示例

n=3、k=2 时共有 8 种无约束排列，删去两种全同色，答案为 6。

### 核心不变量

计算第 i 项之前，older、previous 分别等于完整计数 f(i−2)、f(i−1)。计算新项后仅向前滚动一次。

### 思路

末尾若与前一根不同，有 k−1 种新色；若同色，倒数第三根必须与末尾不同。由此 f(n)=(k−1)(f(n−1)+f(n−2))。两根时所有 k² 种都合法。

把最后一段同色连续长度分成一根或两根。若最后一根单独成段，可在任意合法的前 i−1 根后选不同色，有 (k−1)f(i−1) 种；若最后两根同色，则在任意合法前 i−2 根后选另一色并连续涂两次，有 (k−1)f(i−2) 种。两种情况互斥且穷尽。

### 边界检查

末两根是否同色决定下一步能做什么。若它们已同色，下一根只有 k−1 种选择；若不同色，下一根既可延续也可换色。

### 反例推演

只给一种颜色时，两根栅栏有 1 种合法涂法，三根为 0。初始两根允许同色，第三根开始才禁止三连，同一递推不可从第一根生搬。

### Java

#### 滚动保存末两项

计算 current 时同时使用旧的两个状态，用 long 做中间运算后再按题目的返回类型输出。

| 步骤 | 当前状态 | 判断依据 |
| --- | --- | --- |
| 一根 | k=2 | f(1)=2 |
| 两根 | 任意二色对都合法 | f(2)=4 |
| 三根 | (k−1)×(4+2) | f(3)=6；滚动状态更新为 (4,6) |

```java
class Solution {
    public int numWays(int n, int k) {
        if (n <= 1) return n * k;
        long older = k, previous = (long) k * k;
        for (int i = 3; i <= n; i++) {
            long current = (older + previous) * (k - 1);
            older = previous;
            previous = current;
        }
        return (int) previous;
    }
}
```

### Python

#### 滚动保存末两项

元组赋值的右侧先统一求值，因此上一轮的两个计数都能参与新一轮运算。

| 步骤 | 当前状态 | 判断依据 |
| --- | --- | --- |
| 一根 | k=2 | f(1)=2 |
| 两根 | 任意二色对都合法 | f(2)=4 |
| 三根 | (k−1)×(4+2) | f(3)=6；滚动状态更新为 (4,6) |

```python
class Solution:
    def numWays(self, n: int, k: int) -> int:
        if n <= 1:
            return n * k
        older, previous = k, k * k
        for _ in range(3, n + 1):
            older, previous = previous, (older + previous) * (k - 1)
        return previous
```

### 面试追问

**如何区分不能三连与不能相邻同色？** 当 n=2 时，相同颜色仍合法，所以应为 k² 种；只有延伸长度至少为 3 的序列时才需要二阶递推。

### 复杂度

n 根栅栏；时间 O(n)，辅助空间 O(1)。每一项只依赖前两项，保存长度为 n 的整表没有后续用途。
