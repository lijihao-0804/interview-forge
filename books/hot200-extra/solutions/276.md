# 276. 栅栏涂色

### 题意

给 n 根连续栅栏使用 k 种颜色，禁止连续三根颜色相同，求涂法数。

### 输入与约束

给定栅栏数 n 和可用颜色数 k，允许相邻同色但不允许连续三根同色，返回合法涂法总数。

### 示例

n=3、k=2 时共有 8 种无约束排列，删去两种全同色，答案为 6。

### 核心不变量

dp[i] 恰计合法长度 i 的全部涂法，最后一段的长度只可能为一或二。

### 思路

末尾若与前一根不同，有 k−1 种新色；若同色，倒数第三根必须与末尾不同。由此 f(n)=(k−1)(f(n−1)+f(n−2))。两根时所有 k² 种都合法。

把最后一段同色连续长度分成一根或两根。若最后一根单独成段，可在任意合法的前 i−1 根后选不同色，有 (k−1)f(i−1) 种；若最后两根同色，则在任意合法前 i−2 根后选另一色并连续涂两次，有 (k−1)f(i−2) 种。两种情况互斥且穷尽。

### 边界检查

末两根是否同色决定下一步能做什么。若它们已同色，下一根只有 k−1 种选择；若不同色，下一根既可延续也可换色。

### Java

Java 用 int[] dp 存每个长度的合法涂法总数。前两根还不会触发三连，分别初始化为 k 和 k²，递推从第三根开始，不会误对最初两根施加异色限制。

#### 把三根栅栏按末尾同色长度拆开

| 步骤 | 当前状态 | 判断依据 |
| --- | --- | --- |
| 准备短栅栏 | k=2；f(1)=2，f(2)=4 | 1、2 根时所有涂法均合法。 |
| 计算末段长度一 | 两根的 4 种前缀各有一种换色选择，贡献 4 | 末根不同于前一根，不可能形成三连。 |
| 计算末段长度二 | 一根的 2 种前缀各接另一色两次，贡献 2 | 两类相加 f(3)=4+2=6。 |

```java
import java.util.*;

class Solution {
    public int numWays(int n, int k) {
        if (n == 0) return 0;
        if (n == 1) return k;
        if (n == 2) return k * k;

        int[] dp = new int[n + 1];
        dp[0] = 0;
        dp[1] = k;
        dp[2] = k * k;

        // 按末两根是否同色分类；当它们同色时，前一根必须换色。
        for (int i = 3; i <= n; ++i) dp[i] = (dp[i - 1] + dp[i - 2]) * (k - 1);

        return dp[n];
    }
}
```

### Python

Python 先处理短长度，再分配 n+1 个列表元素。每次只读最近两项，因此若无需展示所有中间答案，用两个变量交替存储也能得到同一个结果。

#### 把三根栅栏按末尾同色长度拆开

| 步骤 | 当前状态 | 判断依据 |
| --- | --- | --- |
| 准备短栅栏 | k=2；f(1)=2，f(2)=4 | 1、2 根时所有涂法均合法。 |
| 计算末段长度一 | 两根的 4 种前缀各有一种换色选择，贡献 4 | 末根不同于前一根，不可能形成三连。 |
| 计算末段长度二 | 一根的 2 种前缀各接另一色两次，贡献 2 | 两类相加 f(3)=4+2=6。 |

```python
from __future__ import annotations


class Solution:
    def numWays(self, n: int, k: int) -> int:
        if n == 0:
            return 0
        if n == 1:
            return k
        if n == 2:
            return k * k

        dp = [0] * (n + 1)
        dp[0] = 0
        dp[1] = k
        dp[2] = k * k

        # 按末两根是否同色分类；当它们同色时，前一根必须换色。
        for i in range(3, n + 1):
            dp[i] = (dp[i - 1] + dp[i - 2]) * (k - 1)

        return dp[n]
```

### 面试追问

**若只有一种颜色，会得到什么结果？** 长度一和二都只有一种涂法。长度从三开始，k−1 为零，恰好对应任何涂法都会出现连续三根同色。

### 复杂度

n 根栅栏；时间 O(n)，空间 O(n)。

从第三根到第 n 根逐项填表，每项只读取两个前驱并做常数次运算；当前保留整个长度 n+1 的表。
