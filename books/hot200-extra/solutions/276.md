# 276. 栅栏涂色

### 题意

给 n 根连续栅栏使用 k 种颜色，禁止连续三根颜色相同，求涂法数。

### 示例

n=3、k=2 时共有 8 种无约束排列，删去两种全同色，答案为 6。

### 思路

末尾若与前一根不同，有 k−1 种新色；若同色，倒数第三根必须与末尾不同。由此 f(n)=(k−1)(f(n−1)+f(n−2))。两根时所有 k² 种都合法。

### 边界检查

末两根是否同色决定下一步能做什么。若它们已同色，下一根只有 k−1 种选择；若不同色，下一根既可延续也可换色。

### Java

```java
import java.util.*;

class Solution {
    public int numWays(int n, int k) {
        if (n == 0) return 0;
        if (n == 1) return k;
        if (n == 2) return k * k;

        int[] dp = new int[n + 1];
        dp[0] = 0;
        dp[1] = k;
        dp[2] = k * k;

        // 按末两根是否同色分类；当它们同色时，前一根必须换色。
        for (int i = 3; i <= n; ++i) dp[i] = (dp[i - 1] + dp[i - 2]) * (k - 1);

        return dp[n];
    }
}
```

### Python

```python
from __future__ import annotations


class Solution:
    def numWays(self, n: int, k: int) -> int:
        if n == 0:
            return 0
        if n == 1:
            return k
        if n == 2:
            return k * k

        dp = [0] * (n + 1)
        dp[0] = 0
        dp[1] = k
        dp[2] = k * k

        # 按末两根是否同色分类；当它们同色时，前一根必须换色。
        for i in range(3, n + 1):
            dp[i] = (dp[i - 1] + dp[i - 2]) * (k - 1)

        return dp[n]
```

### 复杂度

n 根栅栏；时间 O(n)，空间 O(n)。
