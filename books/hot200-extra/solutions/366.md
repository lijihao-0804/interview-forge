# 366. 寻找二叉树的叶子节点


### 题意

每一轮同时摘掉当前所有叶子，按轮返回它们的值。

### 示例

根 6 的左子为 2，右子 8 的左子为 7。先摘 [2,7]，再摘 [8]，最后摘 [6]。

### 思路

用后序遍历求自底向上的高度。空树高度定为 −1，叶子高度 0；节点必须等两个子树都摘完才会成为叶子，因此高度就是它所在的轮次。

### 边界检查

按从叶子往上的高度分组，叶子的高度取同一个起点。多个叶子会同时出现在第一轮，不能在遍历过程中提前删除它们而影响其他分支。

### Java

```java
import java.util.*;

class Solution {
    public List<List<Integer>> findLeaves(TreeNode root) {
        List<List<Integer>> ans = new ArrayList<>();
        depth(root, ans);
        return ans;
    }

    private int depth(TreeNode root, List<List<Integer>> ans) {
        if (root == null) return -1;

        final int l = depth(root.left, ans);
        final int r = depth(root.right, ans);
        // 两个子树都被摘完后，父节点才进入下一轮。
        final int h = 1 + Math.max(l, r);
        if (ans.size() == h) ans.add(new ArrayList<>());

        ans.get(h).add(root.val);
        return h;
    }
}
```

### Python

```python
from __future__ import annotations


class Solution:
    def findLeaves(self, root: TreeNode | None) -> list[list[int]]:
        ans = []

        def depth(root: TreeNode | None) -> int:
            if not root:
                return -1

            l = depth(root.left)
            r = depth(root.right)
            # 两个子树都被摘完后，父节点才进入下一轮。
            h = 1 + max(l, r)

            if len(ans) == h:
                ans.append([])

            ans[h].append(root.val)
            return h

        depth(root)
        return ans
```

### 复杂度

时间 O(n)，栈 O(h)，输出 O(n)。
