# 366. 寻找二叉树的叶子节点


### 题意

每一轮同时摘掉当前所有叶子，按轮返回它们的值。

### 输入与约束

输入为可能为空的二叉树。按每轮同时移除所有叶子的规则分组返回节点值，同一轮内无需特定顺序。

### 示例

根 6 的左子为 2，右子 8 的左子为 7。先摘 [2,7]，再摘 [8]，最后摘 [6]。

### 核心不变量

depth 返回节点从零开始的摘除轮号，调用返回前整棵子树的每个值均已加入对应轮次桶。

### 思路

用后序遍历求自底向上的高度。空树高度定为 −1，叶子高度 0；节点必须等两个子树都摘完才会成为叶子，因此高度就是它所在的轮次。

直接一轮轮找叶子，会在每一轮重新访问那些还不能摘的祖先。设节点进入的轮编号从 0 开始，叶子在第 0 轮；一个父节点必须等最后一个孩子被摘后再等一轮。于是轮号就是从它到最远叶子的边数。

#### 叶 2、7 到根 6 的三轮摘取

| 步骤 | 当前状态 | 为什么这样走 |
| --- | --- | --- |
| 叶子先进桶 | 节点 2、7 的子树均空，h=0，第 0 桶 [2,7] | 它们在第一次同时移除。 |
| 处理节点 8 | 左孩子 7 高度 0，右空 −1，h=1 | 8 被分配到第二轮。 |
| 处理根 6 | 孩子高度分别 0、1，所以 h=2 | 完整结果为 [[2,7],[8],[6]]。 |

### 边界检查

按从叶子往上的高度分组，叶子的高度取同一个起点。多个叶子会同时出现在第一轮，不能在遍历过程中提前删除它们而影响其他分支。

### 反例推演

一条三节点链从根到叶是 a、b、c，摘除顺序是 c、b、a。按离根深度分桶再反转，换成非等高的左右子树就会把不同摘除轮次混在一起。

### Java

#### 递归高度直接定位轮次桶

`depth(null)=-1` 让叶子自动计算为 0。递归返回孩子各自的轮号后取最大值加一，第一次出现某个高度时新建桶，然后把当前值追加进去。

```java
import java.util.*;

class Solution {
    public List<List<Integer>> findLeaves(TreeNode root) {
        List<List<Integer>> ans = new ArrayList<>();
        depth(root, ans);
        return ans;
    }

    private int depth(TreeNode root, List<List<Integer>> ans) {
        if (root == null) return -1;

        final int l = depth(root.left, ans);
        final int r = depth(root.right, ans);
        // 两个子树都被摘完后，父节点才进入下一轮。
        final int h = 1 + Math.max(l, r);
        if (ans.size() == h) ans.add(new ArrayList<>());

        ans.get(h).add(root.val);
        return h;
    }
}
```

### Python

#### 先创建孩子轮次再加入父节点

闭包 depth 共享 ans，只回传一个整数高度。如果 len(ans)==h，说明此前还没有这一轮；较低高度的桶已在后序处理孩子时创建完成。

```python
from __future__ import annotations


class Solution:
    def findLeaves(self, root: TreeNode | None) -> list[list[int]]:
        ans = []

        def depth(root: TreeNode | None) -> int:
            if not root:
                return -1

            l = depth(root.left)
            r = depth(root.right)
            # 两个子树都被摘完后，父节点才进入下一轮。
            h = 1 + max(l, r)

            if len(ans) == h:
                ans.append([])

            ans[h].append(root.val)
            return h

        depth(root)
        return ans
```

### 复杂度

时间 O(n)，栈 O(h)，输出 O(n)。

后序遍历每个节点只计算一次高度，递归深度随树高增长。保存全部轮次必然需要容纳 n 个输出值。

### 面试追问

**求的是离最近叶子的距离吗？** 若一个孩子是叶子而另一个孩子还有多层，父节点要等较深分支摘光，故取最大高度而非最小高度。
