# 270. 最接近的二叉搜索树值

### 题意

求二叉搜索树里离目标实数最近的节点值，若距离相等取较小值。

### 示例

树根 4，右子 6；目标 5 距两者都为 1，返回 4。

### 思路

维护路径上最接近目标的节点，距离相等时保留较小值。若目标小于当前值，整棵右子树都不会更接近，反之亦然。每步只沿一个孩子继续，直到空指针。

### 边界检查

目标落在两个候选的正中间时返回较小值。例如目标 5 与 4、6 距离相同，判断更新条件时要把这个并列规则写进去。

### Java

```java
class Solution {
    public int closestValue(TreeNode root, double target) {
        int best = root.val;
        while (root != null) {
            double gap = Math.abs(root.val - target);
            double previousGap = Math.abs(best - target);
            // 同距时选较小节点，不能只按先访问的节点决定。
            if (gap < previousGap || (gap == previousGap && root.val < best)) best = root.val;
            root = target < root.val ? root.left : root.right;
        }
        return best;
    }
}
```

### Python

```python
class Solution:
    def closestValue(self, root, target: float) -> int:
        best = root.val
        while root is not None:
            if (abs(root.val - target), root.val) < (abs(best - target), best):
                best = root.val
            # 由二叉搜索树的顺序，每次可以排除整棵子树。
            root = root.left if target < root.val else root.right
        return best
```

### 复杂度

树高 h；时间 O(h)，辅助空间 O(1)。
