# 270. 最接近的二叉搜索树值

### 题意

求二叉搜索树里离目标实数最近的节点值，若距离相等取较小值。

### 输入与约束

传入非空二叉搜索树以及实数 target。返回整树所有整数节点中距离最近的值，若并列则选较小的值。

### 示例

树根 4，右子 6；目标 5 距两者都为 1，返回 4。

### 核心不变量

best 是已访问路径上按“距离、节点值”排序最优的节点，剪掉的一侧不会改善 best。

### 思路

维护路径上最接近目标的节点，距离相等时保留较小值。若目标小于当前值，整棵右子树都不会更接近，反之亦然。每步只沿一个孩子继续，直到空指针。

当前值若小于目标，当前节点已经比整个左子树更接近目标或同样接近，只需继续向右寻找更近候选。当前值大于目标时对称地向左查找。一路经过的节点包含最终答案，维护一个当前最佳值即可。

### 边界检查

目标落在两个候选的正中间时返回较小值。例如目标 5 与 4、6 距离相同，判断更新条件时要把这个并列规则写进去。

### Java

Java 对每个经过的节点计算 double 距离，与 best 的距离比较。相等时显式检查节点整数值更小才改写，避免结果随着树形或访问顺序改变。

#### 平局时比较 4 与 6

| 步骤 | 当前状态 | 判断依据 |
| --- | --- | --- |
| 访问根 4 | 目标 5，当前差为 1，best=4 | 5>4，可以排除整个左子树。 |
| 访问右子 6 | 6 距目标也为 1；6>4，保留 best=4 | 按并列规则取较小值。 |
| 转向 6 的左侧 | 左孩子为空，搜索结束，返回 4 | 沿途两个候选均已比较。 |

```java
class Solution {
    public int closestValue(TreeNode root, double target) {
        int best = root.val;
        while (root != null) {
            double gap = Math.abs(root.val - target);
            double previousGap = Math.abs(best - target);
            // 同距时选较小节点，不能只按先访问的节点决定。
            if (gap < previousGap || (gap == previousGap && root.val < best)) best = root.val;
            root = target < root.val ? root.left : root.right;
        }
        return best;
    }
}
```

### Python

Python 按 (绝对差,节点值) 的元组顺序比较，前者相同再比后者。root 逐次移动到一个孩子，只保存 best 和当前指针；树若退化成链，访问量也会随高度增加。

#### 平局时比较 4 与 6

| 步骤 | 当前状态 | 判断依据 |
| --- | --- | --- |
| 访问根 4 | 目标 5，当前差为 1，best=4 | 5>4，可以排除整个左子树。 |
| 访问右子 6 | 6 距目标也为 1；6>4，保留 best=4 | 按并列规则取较小值。 |
| 转向 6 的左侧 | 左孩子为空，搜索结束，返回 4 | 沿途两个候选均已比较。 |

```python
class Solution:
    def closestValue(self, root, target: float) -> int:
        best = root.val
        while root is not None:
            if (abs(root.val - target), root.val) < (abs(best - target), best):
                best = root.val
            # 由二叉搜索树的顺序，每次可以排除整棵子树。
            root = root.left if target < root.val else root.right
        return best
```

### 面试追问

**为什么丢弃一侧子树仍能正确处理距离相等？** 当前节点小于目标时，所有更小值的距离只会更大；当前节点大于目标时，所有更大值同理。可能与当前值并列的较小值仍位于保留的搜索方向。

### 复杂度

树高 h；时间 O(h)，辅助空间 O(1)。

每轮沿一个孩子下降，访问次数至多为 h，始终只保留当前节点和最佳值。非平衡树的 h 可达到节点数。
