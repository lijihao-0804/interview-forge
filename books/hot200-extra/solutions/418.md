# 418. 屏幕可显示句子的数量


### 题意

每行各有固定列数，重复排入给定句子的单词，单词不能跨行。求指定行数内能放下几遍完整句子。

### 输入与约束

句子由非空单词组成，屏幕给定正行数与列数。词之间一格空格，单词不能拆行，句子按原次序循环。

### 示例

句子 [ab,c]、每行 4 列、共 2 行。每行正好能排 ab c，所以放下 2 遍。

### 核心不变量

每行开始的绝对游标 i 指向一个完整单词的首字母，已经跨过的周期都是完整放入的句子。

### 思路

把句子连成末尾带空格的周期字符串。每行先尝试前进 cols 个字符；若落在词内就退到上个词边界，若落在分隔处则跳过分隔符。最终游标整除周期长度就是完成遍数。

将句子尾部补一个分隔空格后，无限重复的排版内容就成了周期字符串。用 i 表示下一行待放的首字符的绝对下标，先按列数试跳，再对齐到合法词首，便能跨过许多完整的句子而不逐字排版。

#### ab c 恰好填满四列

| 步骤 | 当前状态 | 为什么这样走 |
| --- | --- | --- |
| 建立周期 | ab c 加尾空格，周期长 5，i=0 | 下一行从完整的 ab 开始。 |
| 排第一行 | 4 列后 i=4 遇空格，再到 i=5 | 本行容纳 ab c，跨过一次完整周期。 |
| 排第二行 | i=9 再遇空格，i=10，10÷5=2 | 两行各放下一遍句子。 |

### 边界检查

若一行的末尾正好落在单词内部，这个词要整体移到下一行。句子末尾也需要与下一遍句首留一个分隔位置，避免把两个词粘在一起。

### Java

#### 游标取模只用于访问字符

`combined.charAt(i%n)` 只在定位字符时取模，i 本身保留跨过的周期总数。若 i 正落空格，刚好已有完整词可结束本行，额外跳过空格。

```java
class Solution {
    public int wordsTyping(String[] sentence, int rows, int cols) {
        final String combined = String.join(" ", sentence) + " ";
        final int n = combined.length();
        int i = 0;

        // 每行先试填到最右端，落在词内时再回到词边界。
        while (rows-- > 0) {
            i += cols;
            if (combined.charAt(i % n) == ' ') {
                ++i;
            } else {
                while (i > 0 && combined.charAt((i - 1) % n) != ' ') --i;
            }
        }

        return i / n;
    }
}
```

### Python

#### 退到前一字符为空格的位置

若试跳后是字母，则检查前一字符：前一字符是空格说明已到词首，否则逐步后退到本词开头。此时下一行从完整单词开始；最终 i//n 给出完整周期数。

```python
from __future__ import annotations


class Solution:
    def wordsTyping(self, sentence: list[str], rows: int, cols: int) -> int:
        combined = " ".join(sentence) + " "
        n = len(combined)
        i = 0

        # 每行先试填到最右端，落在词内时再回到词边界。
        for _ in range(rows):
            i += cols
            if combined[i % n] == " ":
                i += 1
            else:
                while i > 0 and combined[(i - 1) % n] != " ":
                    i -= 1

        return i // n
```

### 复杂度

句子总字符数 L、最长词长 w。时间 O(L+rows·(w+1))，空间 O(L)。

构造周期串需要 L 个字符，每行最多回退最长词长 w 步。保留周期串即可，不保存屏幕上每一个单元格。

### 面试追问

**有一个词比整行还长会死循环吗？** 单行回退只会退到该词起点，外层仍然按固定行数结束。该词一直放不下，后续周期无法完成。
