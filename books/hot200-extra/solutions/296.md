# 296. 最佳的碰头地点


### 题意

从网格中选一个集合点，使所有住户走到它的曼哈顿距离之和最小。

### 输入与约束

输入为以 1 表示住户的二值矩形网格。可选任意格子，每走一行或一列代价为 1，返回全体住户的最小路程和。

### 示例

住户在 (0,0)、(2,1)、(2,3)。行中位数 2，列中位数 1，距离和为 3+0+2=5。

### 核心不变量

两端剥去一对坐标后，已结算的差值是这一对同时可达到的下界，剩余坐标的中位区间仍在配对区间内。

### 思路

行、列的费用可以独立最小化。在排好序的一维坐标上，把两端配对，每对在二者之间的任一点产生相同费用；中位数同时落在所有这些区间内。

沿同一维，把最左、最右两个住户记为 a、b。选点 x 落在 [a,b] 中时，两人的路程相加总是 b−a，超出区间只会增加。剥掉两端继续配对，所有配对区间套在一起，中位数落在每一对的最优区间内。

#### 三个住户分摊行列路程

| 步骤 | 当前状态 | 为什么这样走 |
| --- | --- | --- |
| 分离坐标 | 行 [0,2,2]，列 [0,1,3] | 按行和按列各收集一次得到有序值。 |
| 结算行距离 | 首尾 2−0=2，行中位数为 2 | 剩余的中间住户在该行上的距离为零。 |
| 结算列距离 | 首尾 3−0=3，中位列 1，总费用 5 | 会合于 (2,1)，两维费用相加。 |

### 边界检查

曼哈顿距离可以分别按行和列求最小值。最佳行、最佳列即使来自不同住户，组合成的格子也仍是合法会合点。

### 反例推演

住户横坐标为 0、0、9，选平均值 3 的距离和为 12，选中位数 0 仅为 9。曼哈顿距离的目标是绝对值和，均值针对的是平方差和。

### Java

#### 有序行列坐标的双指针

`I` 按行收集，`J` 按列收集，因此传给重载方法的两张表天然有序。两指针每轮结算一个首尾对，奇数个住户剩下的中位点本身贡献零。

```java
import java.util.*;

class Solution {
    public int minTotalDistance(int[][] grid) {
        final int m = grid.length;
        final int n = grid[0].length;
        List<Integer> I = new ArrayList<>();
        List<Integer> J = new ArrayList<>();

        for (int i = 0; i < m; ++i) for (int j = 0; j < n; ++j) if (grid[i][j] == 1) I.add(i);

        for (int j = 0; j < n; ++j) for (int i = 0; i < m; ++i) if (grid[i][j] == 1) J.add(j);

        return minTotalDistance(I) + minTotalDistance(J);
    }

    private int minTotalDistance(List<Integer> grid) {
        int sum = 0;
        int i = 0;
        int j = grid.size() - 1;
        // 配对最小值与最大值，两端距离和等于坐标差。
        while (i < j) sum += grid.get(j--) - grid.get(i++);
        return sum;
    }
}
```

### Python

#### 改变推导式的外层维度

两条列表推导的外层循环顺序不同，这一步省掉了排序。辅助函数的 summ 累计已经剥离的坐标对差值，最后把行与列两项相加。

```python
from __future__ import annotations


class Solution:
    def minTotalDistance(self, grid: list[list[int]]) -> int:
        m = len(grid)
        n = len(grid[0])

        I = [i for i in range(m) for j in range(n) if grid[i][j]]

        J = [j for j in range(n) for i in range(m) if grid[i][j]]

        def minTotalDistance(grid: list[int]) -> int:
            summ = 0
            i = 0
            j = len(grid) - 1
            # 配对最小值与最大值，两端距离和等于坐标差。
            while i < j:
                summ += grid[j] - grid[i]
                i += 1
                j -= 1
            return summ

        return minTotalDistance(I) + minTotalDistance(J)
```

### 复杂度

时间 O(mn)，两条坐标表占 O(k)，k 为住户数。

网格按两种方向各扫描一遍，共 2mn 次格子检查。两列表各保存 k 个坐标，随后配对只走半张表。

### 面试追问

**偶数个住户时应该选哪个中位数？** 两个中间坐标之间的任意整数都在所有配对区间内；行和列可分别选，最优点可能有多个。
