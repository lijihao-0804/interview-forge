# 296. 最佳的碰头地点


### 题意

从网格中选一个集合点，使所有住户走到它的曼哈顿距离之和最小。

### 示例

住户在 (0,0)、(2,1)、(2,3)。行中位数 2，列中位数 1，距离和为 3+0+2=5。

### 思路

行、列的费用可以独立最小化。在排好序的一维坐标上，把两端配对，每对在二者之间的任一点产生相同费用；中位数同时落在所有这些区间内。

### 边界检查

曼哈顿距离可以分别按行和列求最小值。最佳行、最佳列即使来自不同住户，组合成的格子也仍是合法会合点。

### Java

```java
import java.util.*;

class Solution {
    public int minTotalDistance(int[][] grid) {
        final int m = grid.length;
        final int n = grid[0].length;
        List<Integer> I = new ArrayList<>();
        List<Integer> J = new ArrayList<>();

        for (int i = 0; i < m; ++i) for (int j = 0; j < n; ++j) if (grid[i][j] == 1) I.add(i);

        for (int j = 0; j < n; ++j) for (int i = 0; i < m; ++i) if (grid[i][j] == 1) J.add(j);

        return minTotalDistance(I) + minTotalDistance(J);
    }

    private int minTotalDistance(List<Integer> grid) {
        int sum = 0;
        int i = 0;
        int j = grid.size() - 1;
        // 配对最小值与最大值，两端距离和等于坐标差。
        while (i < j) sum += grid.get(j--) - grid.get(i++);
        return sum;
    }
}
```

### Python

```python
from __future__ import annotations


class Solution:
    def minTotalDistance(self, grid: list[list[int]]) -> int:
        m = len(grid)
        n = len(grid[0])

        I = [i for i in range(m) for j in range(n) if grid[i][j]]

        J = [j for j in range(n) for i in range(m) if grid[i][j]]

        def minTotalDistance(grid: list[int]) -> int:
            summ = 0
            i = 0
            j = len(grid) - 1
            # 配对最小值与最大值，两端距离和等于坐标差。
            while i < j:
                summ += grid[j] - grid[i]
                i += 1
                j -= 1
            return summ

        return minTotalDistance(I) + minTotalDistance(J)
```

### 复杂度

时间 O(mn)，两条坐标表占 O(k)，k 为住户数。
