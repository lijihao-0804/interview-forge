# 247. 中心对称数 II

### 题意

列出所有恰有 n 位且旋转 180° 后不变的数字串，多位数禁止前导零。

### 输入与约束

输入正整数位数 n，输出所有恰有 n 位的中心对称数字串，顺序不限。多位数不能有前导零，单个 0 可以输出。

### 示例

n=2 时合法结果是 11、69、88、96；00 只有外观对称，不是两位数。

### 核心不变量

helper 返回的每个候选都满足旋转对称；仅最终外层禁止前导零。

### 思路

从空中心或单位中心开始，两端加上相应的旋转数字对。内部允许 00，最外层禁止 00；奇数中心有三种选择。

如果先枚举所有 n 位数再检查旋转，多数候选一开始就注定失败。反过来，去掉合格数字的首尾，内部仍具中心对称性；确定内部后只需为最外两格选择允许的数字对。奇数长度从一个自对称数字开始，偶数长度从空串开始。

### 边界检查

将 0 和 0 放在中间是合法的，例如 1001。只在最外层排除前导零，才不会漏掉这种结果。

### 反例推演

构造三位数时，中心只能是 0、1 或 8。例如 `609` 有效，`669` 无效；把左右镜像对中的 6 直接当作中心会产生伪解。

### Java

Java 中 helper(n,k) 的 n 是当前层长度、k 是最终长度。List.of("") 中那一个空串代表一种偶数中心；若返回空列表，外层循环一次都不会执行。

#### 从空中心包出两位数

| 步骤 | 当前状态 | 判断依据 |
| --- | --- | --- |
| 选择两位数中心 | n=2，内部长度为 0，唯一内部串为空串 | 为添加一对数字留出两个位置。 |
| 尝试外层 00 | 拼出 00，因首位为 0 排除 | 外层要求真正的两位数。 |
| 填入合法外层 | 11、69、88、96，共四个 | 每个结果对应唯一的一对首尾数字。 |

```java
import java.util.*;

class Solution {
    public List<String> findStrobogrammatic(int n) {
        return helper(n, n);
    }

    private List<String> helper(int n, int k) {
        // 空中心用于构造偶数位结果，单字符中心用于奇数位结果。
        if (n == 0) return List.of("");
        if (n == 1) return List.of("0", "1", "8");

        List<String> ans = new ArrayList<>();

        for (final String inner : helper(n - 2, k)) {
            if (n < k) ans.add("0" + inner + "0");
            ans.add("1" + inner + "1");
            ans.add("6" + inner + "9");
            ans.add("8" + inner + "8");
            ans.add("9" + inner + "6");
        }

        return ans;
    }
}
```

### Python

Python 每个 inner 都来自 helper(n-2,k)，两端拼接时 6 与 9 的两个方向分别生成。只有 n<k 的内层允许 0 包围，因为这些零以后还会被外层的非零数字包住。

#### 从空中心包出两位数

| 步骤 | 当前状态 | 判断依据 |
| --- | --- | --- |
| 选择两位数中心 | n=2，内部长度为 0，唯一内部串为空串 | 为添加一对数字留出两个位置。 |
| 尝试外层 00 | 拼出 00，因首位为 0 排除 | 外层要求真正的两位数。 |
| 填入合法外层 | 11、69、88、96，共四个 | 每个结果对应唯一的一对首尾数字。 |

```python
from __future__ import annotations


class Solution:
    def findStrobogrammatic(self, n: int) -> list[str]:
        def helper(n: int, k: int) -> list[str]:
            # 空中心用于构造偶数位结果，单字符中心用于奇数位结果。
            if n == 0:
                return [""]
            if n == 1:
                return ["0", "1", "8"]

            ans = []

            for inner in helper(n - 2, k):
                if n < k:
                    ans.append("0" + inner + "0")
                ans.append("1" + inner + "1")
                ans.append("6" + inner + "9")
                ans.append("8" + inner + "8")
                ans.append("9" + inner + "6")

            return ans

        return helper(n, n)
```

### 面试追问

**能不能所有层都禁用 00？** 四位数 1001 需要内部先生成 00，再在外围添 11。限制只应落在最终输出的最高位上。

### 复杂度

设输出 K 个 n 位数；时间 O(nK)，包含结果和中间字符串的空间 O(nK)。

每个输出串含 n 个字符，光写出全部结果就需 nK 工作量。递归过程中较短层的候选总规模受最终结果规模支配。
