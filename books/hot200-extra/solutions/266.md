# 266. 回文排列

### 题意

判断能否通过重排一个字符串的字符形成回文。

### 输入与约束

输入一个字符串，可任意重排字符，需返回能否构成一个回文。每个字符及其全部出现次数都要保留。

### 示例

串 `aabbc` 中只有 c 出现奇数次，可排成 `abcba`；`aabc` 有两个奇数频数，不能。

### 核心不变量

读完任意前缀后，集合中的字符恰是当前出现奇数次的字符。

### 思路

镜像位置上的字符必须成对，只有中心允许单个字符。扫描时让同一字符在集合内交替加入和删除，最终集合大小至多为 1 即可。

回文中每个非中心位置都与另一位置配对，因此全串至多允许一个字符出现奇数次。这个条件也充分：从每个字符中拿出一半放左侧，剩余成对部分镜像放右侧，多出的唯一字符放在中间。只判存在性时无需构造字符串。

### 边界检查

回文的两端总是成对消耗同一个字符。长度为奇数时留给中心的字符只有一个，第二种奇数频次一出现，就无法全部配完。

### Java

Java 的 `Set<Character>` 保存当前前缀里频次为奇数的字符。同一字符再次到达时移除，下次再加入；最终检查集合大小，不能在前缀出现两个奇数时过早退出。

#### 跟随出现奇数次的字符集合

| 步骤 | 当前状态 | 判断依据 |
| --- | --- | --- |
| 消去两对 | aabb 依次使集合变为 {a}、空、{b}、空 | 每两次相同字符抵消。 |
| 给中心留 c | aabbc 的最终集合为 {c} | 仅一项，能排成 abcba。 |
| 对照 aabc | 读完 aa 后为空，再读 b、c 得 {b,c} | 两个字符都想占中心，因此无解。 |

```java
import java.util.*;

class Solution {
    public boolean canPermutePalindrome(String s) {
        Set<Character> seen = new HashSet<>();

        // 用集合保存频数为奇数的字符，最多允许一个作为回文中心。
        for (final char c : s.toCharArray()) if (!seen.add(c)) seen.remove(c);

        return seen.size() <= 1;
    }
}
```

### Python

Python 的 set 用成员测试切换奇偶状态。集合持续保存的是奇数字符的身份，既不存已配成多少对，也无需排序；所有字符读完才得到最终奇数数目。

#### 跟随出现奇数次的字符集合

| 步骤 | 当前状态 | 判断依据 |
| --- | --- | --- |
| 消去两对 | aabb 依次使集合变为 {a}、空、{b}、空 | 每两次相同字符抵消。 |
| 给中心留 c | aabbc 的最终集合为 {c} | 仅一项，能排成 abcba。 |
| 对照 aabc | 读完 aa 后为空，再读 b、c 得 {b,c} | 两个字符都想占中心，因此无解。 |

```python
from __future__ import annotations


class Solution:
    def canPermutePalindrome(self, s: str) -> bool:
        seen = set()

        # 用集合保存频数为奇数的字符，最多允许一个作为回文中心。
        for c in s:
            if c in seen:
                seen.remove(c)
            else:
                seen.add(c)

        return len(seen) <= 1
```

### 面试追问

**如果前缀中已有两种奇数字符，可以马上返回假吗？** 不可以。前缀 ab 有两个奇数，加上 ab 变成 abab 后两者都配成对，仍能组成回文。

### 复杂度

n 个字符、字母集合大小 σ；时间 O(n)，空间 O(σ)。

每字符执行常数次集合操作，集合最多保存字母集合里的全部字符。空间更精确地为 O(min(n,σ))。
