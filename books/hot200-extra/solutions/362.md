# 362. 敲击计数器


### 题意

记录按时间到达的敲击，查询最近 300 秒内的总次数。同一秒可以发生多次。

### 示例

在 1 秒记录两次、300 秒记录一次。300 秒查询为 3，301 秒查询为 1，恰好相差 300 秒的敲击已经过期。

### 思路

用时间戳模 300 定位槽位。时间戳相同则累加，不同则覆盖旧计数；查询时以完整时间戳区分仍在窗口内的槽。

### 边界检查

在第 301 秒查询时，第 1 秒的敲击已在窗口外，第 2 秒的仍在窗口内。窗口左端是否取等号就用这两个时间点来检查。

### Java

```java
class HitCounter {
    public void hit(int timestamp) {
        final int i = timestamp % 300;
        // 模 300 的槽会复用，先比较完整时间戳才能累加。
        if (timestamps[i] == timestamp) {
            ++hits[i];
        } else {
            timestamps[i] = timestamp;
            hits[i] = 1;
        }
    }

    public int getHits(int timestamp) {
        int countHits = 0;
        for (int i = 0; i < 300; ++i) if (timestamp - timestamps[i] < 300) countHits += hits[i];
        return countHits;
    }

    private int[] timestamps = new int[300];
    private int[] hits = new int[300];
}
```

### Python

```python
from __future__ import annotations


class HitCounter:
    def __init__(self):
        self.timestamps = [0] * 300
        self.hits = [0] * 300

    def hit(self, timestamp: int) -> None:
        i = timestamp % 300
        # 模 300 的槽会复用，先比较完整时间戳才能累加。
        if self.timestamps[i] == timestamp:
            self.hits[i] += 1
        else:
            self.timestamps[i] = timestamp
            self.hits[i] = 1

    def getHits(self, timestamp: int) -> int:
        return sum(h for t, h in zip(self.timestamps, self.hits) if timestamp - t < 300)
```

### 复杂度

记录 O(1)，查询 O(300)，固定存储 O(300)。
