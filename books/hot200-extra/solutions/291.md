# 291. 单词规律 II


### 题意

判断能否把模式中每个字符固定映射到非空子串，不同字符映射不同，串联后恰好得到目标串。

### 示例

模式 `aba` 配 `redxred` 可取 a = red、b = x。配 `redxblue` 时，尝试不同切分也无法让前后两段相同。

### 思路

递归状态给出模式位置和文本位置。已有映射必须匹配当前前缀；遇到新字符就试每个可用的非空前缀，同时登记正向与反向映射，回溯时撤销。

### 边界检查

映射需要双向唯一。例如模式 `ab` 和字符串 `xx` 不能让 a、b 同时表示 x；回溯时要同时恢复映射表和已占用的单词片段。

### Java

```java
import java.util.*;

class Solution {
    public boolean wordPatternMatch(String pattern, String s) {
        return isMatch(pattern, 0, s, 0, new HashMap<>(), new HashSet<>());
    }

    private boolean isMatch(
            final String pattern,
            int i,
            final String s,
            int j,
            Map<Character, String> charToString,
            Set<String> seen) {
        if (i == pattern.length() && j == s.length()) return true;
        if (i == pattern.length() || j == s.length()) return false;

        final char c = pattern.charAt(i);

        // 已有映射必须从当前文本位置开始完整匹配。
        if (charToString.containsKey(c)) {
            final String t = charToString.get(c);

            if (!s.startsWith(t, j)) return false;

            return isMatch(pattern, i + 1, s, j + t.length(), charToString, seen);
        }

        for (int k = j; k < s.length(); ++k) {
            final String t = s.substring(j, k + 1);

            if (seen.contains(t)) continue;

            charToString.put(c, t);
            seen.add(t);

            if (isMatch(pattern, i + 1, s, k + 1, charToString, seen)) return true;

            charToString.remove(c);
            seen.remove(t);
        }

        return false;
    }
}
```

### Python

```python
from __future__ import annotations


class Solution:
    def wordPatternMatch(self, pattern: str, s: str) -> bool:
        def isMatch(i: int, j: int, charToString: dict[str, str], seen: set[str]) -> bool:
            if i == len(pattern) and j == len(s):
                return True
            if i == len(pattern) or j == len(s):
                return False

            c = pattern[i]

            # 已有映射必须从当前文本位置开始完整匹配。
            if c in charToString:
                t = charToString[c]

                if not s.startswith(t, j):
                    return False

                return isMatch(i + 1, j + len(t), charToString, seen)

            for k in range(j, len(s)):
                t = s[j : k + 1]

                if t in seen:
                    continue

                charToString[c] = t
                seen.add(t)

                if isMatch(i + 1, k + 1, charToString, seen):
                    return True

                del charToString[c]
                seen.remove(t)

            return False

        return isMatch(0, 0, {}, set())
```

### 复杂度

长度为 n 的文本有至多 2ⁿ 种切分；含切片比较的保守时间上界 O(mn²·2ⁿ)，m 为模式长。沿一条路径的映射与递归栈 O(n+m)，临时切片另计。
