# 716. 最大栈

### 题意

设计栈，除压入、弹出和读栈顶，还能查询最大值、删除离栈顶最近的一个最大值。

### 示例

依次压入 6、2、6，调用 popMax 返回 6，此时栈顶为 2，peekMax 仍为 6。

### 思路

栈序和数值顺序是两个不同的访问方向。给相同数值保留插入顺序，删除最大值时只移去它最近的那次插入。 Java 用按值排序的映射和双向链表，Python 用可按下标删除的最大堆和双向链表。堆用递增序号解决最大值并列。

### 边界检查

把 `[6, 2, 6]` 画成三个节点。两个 6 的值相同，`popMax` 删除的是右边那个节点；删除后，按值查询与按入栈顺序查询都必须跳过它。

### Java

```java
import java.util.ArrayDeque;
import java.util.Deque;
import java.util.TreeMap;

class MaxStack {
    private static class Entry {
        int value;
        Entry prev, next;

        Entry(int value) {
            this.value = value;
        }
    }

    private final TreeMap<Integer, Deque<Entry>> byValue = new TreeMap<>();
    private final Entry head = new Entry(0);
    private Entry tail = head;

    public void push(int x) {
        Entry node = new Entry(x);
        tail.next = node;
        node.prev = tail;
        tail = node;
        byValue.computeIfAbsent(x, ignored -> new ArrayDeque<>()).push(node);
    }

    private int remove(int value) {
        Deque<Entry> entries = byValue.get(value);
        // 先在栈顺序中摘下目标节点，再维护最大值索引。
        Entry node = entries.pop();
        if (entries.isEmpty()) byValue.remove(value);
        node.prev.next = node.next;
        if (node.next == null) tail = node.prev;
        else node.next.prev = node.prev;
        return value;
    }

    public int pop() {
        return remove(tail.value);
    }

    public int top() {
        return tail.value;
    }

    public int peekMax() {
        return byValue.lastKey();
    }

    public int popMax() {
        return remove(peekMax());
    }
}
```

### Python

```python
class MaxStack:
    def __init__(self):
        self.heap = []
        self.indices = {}
        self.links = {}
        self.tail = None
        self.serial = 0

    def _swap(self, a, b):
        self.heap[a], self.heap[b] = self.heap[b], self.heap[a]
        self.indices[self.heap[a][1]] = a
        self.indices[self.heap[b][1]] = b

    def _rise(self, i):
        while i:
            parent = (i - 1) // 2
            if self.heap[parent] >= self.heap[i]:
                break
            self._swap(parent, i)
            i = parent

    def push(self, x: int) -> None:
        key = self.serial
        self.serial += 1
        self.links[key] = [self.tail, None]
        if self.tail is not None:
            self.links[self.tail][1] = key
        self.tail = key
        self.indices[key] = len(self.heap)
        self.heap.append((x, key))
        self._rise(len(self.heap) - 1)

    def _remove(self, key):
        # 先在栈顺序中摘下目标节点，再维护最大值索引。
        prev, nxt = self.links.pop(key)
        if prev is not None:
            self.links[prev][1] = nxt
        if nxt is None:
            self.tail = prev
        else:
            self.links[nxt][0] = prev
        i = self.indices.pop(key)
        value = self.heap[i][0]
        last = self.heap.pop()
        if i < len(self.heap):
            self.heap[i] = last
            self.indices[last[1]] = i
            if i and self.heap[i] > self.heap[(i - 1) // 2]:
                self._rise(i)
            else:
                while 2 * i + 1 < len(self.heap):
                    child = 2 * i + 1
                    if child + 1 < len(self.heap) and self.heap[child] < self.heap[child + 1]:
                        child += 1
                    if self.heap[i] >= self.heap[child]:
                        break
                    self._swap(i, child)
                    i = child
        return value

    def top(self) -> int:
        return self.heap[self.indices[self.tail]][0]

    def peekMax(self) -> int:
        return self.heap[0][0]

    def pop(self) -> int:
        return self._remove(self.tail)

    def popMax(self) -> int:
        return self._remove(self.heap[0][1])
```

### 复杂度

n 个现存元素；top 为 O(1)，其余操作均在 O(log(n+1)) 以内，空间 O(n)。
