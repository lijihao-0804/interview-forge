# 708. 循环有序列表的插入


### 题意

向非递减排序的循环单链表插入一个值。入口可以是环中任意节点。

### 输入与约束

输入为循环非递减单链表的任意入口或空引用，允许重复值。插入一个值，非空时仍可返回原入口。

### 示例

环从 4 开始是 4→1→3→4，插入 5 时把它放在 4 与 1 的下降边上，得到 4→5→1→3→4。

### 核心不变量

游标始终夹住一条真实环边；此前检查过的边均不能按普通有序或极值跨界规则放入新值。

### 思路

普通边允许把介于两端之间的值插入。唯一从最大值回到最小值的下降边还接受新的极值；前面的边都未命中时，在最后一条边插入；全相等的环也能由这一规则处理。

环的入口未必是最小点，因此不能只沿着“小于插入值”的方向走。除最大回到最小的一条边外，其余边都非递减。按边类型测试，或走到最后一条未试的边，最多一圈即可完成插入。

#### 在 4 到 1 的下降边插入 5

| 步骤 | 当前状态 | 为什么这样走 |
| --- | --- | --- |
| 读入口的出边 | left=4，right=1，插入值 5 | 4>1，正在从全局最大回到最小。 |
| 判定新极值 | 5≥4，下降边接受 5 | 把新最大放在旧最大之后、最小之前。 |
| 接回原环 | 4→5→1→3→4，返回原入口 4 | 仍只有一条下降边 5→1。 |

### 边界检查

当环内所有节点都相等，或者原本只有一个节点，可能整圈都找不到通常的插入位置。走完一圈后仍应插入，并保持链表首尾相连。

### Java

#### 最后一条未检查的环边

`prev,curr` 指向一条相邻边。循环检查直到 curr 再次是 head；若前面未返回，最后一条边直接接入。它可能是唯一合适的普通边、下降边，或属于全相等的环。

```java
class Solution {
    public Node insert(Node head, int insertVal) {
        if (head == null) {
            Node newNode = new Node(insertVal);
            newNode.next = newNode;
            return newNode;
        }

        Node prev = head;
        Node curr = head.next;

        // 普通边容纳区间内的值，环的下降边可以接纳新的极值。
        while (curr != head) {

            if ((prev.val <= insertVal && insertVal <= curr.val)
                    || (prev.val > curr.val && (insertVal >= prev.val || insertVal <= curr.val))) {

                prev.next = new Node(insertVal, curr);
                return head;
            }
            prev = prev.next;
            curr = curr.next;
        }

        prev.next = new Node(insertVal, curr);
        return head;
    }
}
```

### Python

#### 以节点身份检测绕回入口

`right is head` 按对象身份表示最后一条边，相同数值不表示绕完一圈。连接时先保存 right，再把现有边改成 left→node→right；非空输入返回原入口。

```python
from __future__ import annotations


class Solution:
    def insert(self, head: Node | None, insertVal: int) -> Node:
        node = Node(insertVal)
        if head is None:
            node.next = node
            return node
        left = head
        # 普通边容纳区间内的值，环的下降边可以接纳新的极值。
        while True:
            right = left.next
            fits = left.val <= insertVal <= right.val
            wraps = left.val > right.val and (insertVal >= left.val or insertVal <= right.val)
            if fits or wraps or right is head:
                left.next = node
                node.next = right
                return head
            left = right
```

### 复杂度

时间 O(n)，额外空间 O(1)。

每走一步检查一条边，至多 n 条。除返回的新节点外，仅用两个邻接指针。

### 面试追问

**为什么最后一条边可以直接插？** 非全等的有序环中，区间内的新值总有一条普通边容纳，区间外的新值由下降边容纳。此前全部不合格，合适位置便只剩最后一条；全等环则任意处都行。
