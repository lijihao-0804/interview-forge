# 431. 将 N 叉树编码为二叉树

### 题意

在二叉树与有序 N 叉树之间做可逆转换，保持每个节点的孩子顺序。

### 输入与约束

输入有序 N 叉树，可为空。编码为二叉树，使用同一约定解码后必须还原节点值、孩子归属及顺序。

### 示例

根 1 有孩子 2、3、4，节点 3 又有孩子 5。编码后 1.left=2，2.right=3，3.right=4，3.left=5。

### 核心不变量

每个已编码的父节点，其 left 通向第一个孩子，此后沿 right 恰好枚举原有的其余兄弟。

### 思路

让二叉节点的左指针表示第一个孩子，右指针表示下一个兄弟。解码从左孩子开始沿右链收集该层，再分别还原这些孩子的子树。

二叉节点的两条边要能表示任意多个有序孩子。给 left 固定含义“第一个孩子”，给 right 固定含义“下一个兄弟”。这样无论孩子有多少，都只从父节点分出一条 left 边；后续孩子沿 right 链排队，解码按这两种角色反向读取即可。

### 边界检查

编码里，同一父节点的第二个孩子接在第一个孩子的右侧。解码时沿右链找兄弟，向左进入孩子，才能还原每层原有的顺序。

### Java

Java 的队列元素配对保存原节点与对应的新节点。处理一组孩子时 headTreeNode 记第一个，prevTreeNode 记前一个；依次链接兄弟，再把头挂到 parentTreeNode.left。

#### 沿左孩子与右兄弟重建两层树

| 步骤 | 当前状态 | 判断依据 |
| --- | --- | --- |
| 编码根的首个孩子 | 1.left=2 | 从根进入孩子链只有一个入口。 |
| 串起同层兄弟 | 2.right=3，3.right=4 | 按原来的孩子顺序组成链 2→3→4。 |
| 编码下一层 | 3.left=5；解码得 1 的孩子 [2,3,4]，3 的孩子 [5] | 兄弟链与孩子入口分别用不同方向。 |

```java
import java.util.*;

class Codec {

    public TreeNode encode(Node root) {
        if (root == null) return null;

        TreeNode rootTreeNode = new TreeNode(root.val);
        Queue<Pair<Node, TreeNode>> q = new ArrayDeque<>(List.of(new Pair<>(root, rootTreeNode)));

        // 二叉树左边连第一个孩子，其余孩子依次用右边相连。
        while (!q.isEmpty()) {
            Node parentNode = q.peek().getKey();
            TreeNode parentTreeNode = q.poll().getValue();
            TreeNode prevTreeNode = null;
            TreeNode headTreeNode = null;
            if (parentNode.children == null) continue;
            for (Node child : parentNode.children) {
                TreeNode currTreeNode = new TreeNode(child.val);
                if (prevTreeNode == null) headTreeNode = currTreeNode;
                else prevTreeNode.right = currTreeNode;
                prevTreeNode = currTreeNode;
                q.offer(new Pair<>(child, currTreeNode));
            }
            parentTreeNode.left = headTreeNode;
        }

        return rootTreeNode;
    }

    public Node decode(TreeNode root) {
        if (root == null) return null;

        Node rootNode = new Node(root.val, new ArrayList<>());
        Queue<Pair<Node, TreeNode>> q = new ArrayDeque<>(List.of(new Pair<>(rootNode, root)));

        while (!q.isEmpty()) {
            Node parentNode = q.peek().getKey();
            TreeNode parentTreeNode = q.poll().getValue();
            TreeNode sibling = parentTreeNode.left;
            while (sibling != null) {
                Node currNode = new Node(sibling.val, new ArrayList<>());
                parentNode.children.add(currNode);
                q.offer(new Pair<>(currNode, sibling));
                sibling = sibling.right;
            }
        }

        return rootNode;
    }
}

record Pair<K, V>(K getKey, V getValue) {}
```

### Python

Python 用 deque 保存 (原节点,新节点)，处理每个父节点时重新清空上一个兄弟指针。解码先取该节点的 left，然后连续读 right，每次遇到的节点都成为同一 N 叉父节点的直接孩子。

#### 沿左孩子与右兄弟重建两层树

| 步骤 | 当前状态 | 判断依据 |
| --- | --- | --- |
| 编码根的首个孩子 | 1.left=2 | 从根进入孩子链只有一个入口。 |
| 串起同层兄弟 | 2.right=3，3.right=4 | 按原来的孩子顺序组成链 2→3→4。 |
| 编码下一层 | 3.left=5；解码得 1 的孩子 [2,3,4]，3 的孩子 [5] | 兄弟链与孩子入口分别用不同方向。 |

```python
from __future__ import annotations
import collections


class Codec:
    def encode(self, root: "Node") -> TreeNode | None:
        if not root:
            return None

        rootTreeNode = TreeNode(root.val)
        q = collections.deque([(root, rootTreeNode)])

        # 二叉树左边连第一个孩子，其余孩子依次用右边相连。
        while q:
            parentNode, parentTreeNode = q.popleft()
            prevTreeNode = None
            headTreeNode = None
            for child in parentNode.children or []:
                currTreeNode = TreeNode(child.val)
                if prevTreeNode:
                    prevTreeNode.right = currTreeNode
                else:
                    headTreeNode = currTreeNode
                prevTreeNode = currTreeNode
                q.append((child, currTreeNode))
            parentTreeNode.left = headTreeNode

        return rootTreeNode

    def decode(self, root: TreeNode | None) -> "Node":
        if not root:
            return None

        rootNode = Node(root.val, [])
        q = collections.deque([(rootNode, root)])

        while q:
            parentNode, parentTreeNode = q.popleft()
            sibling = parentTreeNode.left
            while sibling:
                currNode = Node(sibling.val, [])
                parentNode.children.append(currNode)
                q.append((currNode, sibling))
                sibling = sibling.right

        return rootNode
```

### 面试追问

**二叉树里 3.right 指向 4，是否表示 4 是 3 的孩子？** 在该编码中 right 始终连接兄弟。3 的第一个孩子由 3.left 找到，即示例的 5。

### 复杂度

n 个节点；时间 O(n)，含输出与遍历空间 O(n)。

每个 N 叉节点创建一次对应节点，每条孩子边只处理一次，编码和解码均 O(n)。队列最坏随宽度增长，输出本身需要 O(n) 节点。
