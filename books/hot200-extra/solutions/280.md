# 280. 摆动排序


### 题意

原地重排数组，使偶数下标为谷、奇数下标为峰。相邻值可以相等。

### 输入与约束

输入是可修改的整数数组，允许重复值。直接修改原数组，任意满足峰谷次序的结果都可接受。

### 示例

输入 [4,1,3,2]。先交换 4 与 1，再保留 4 与 3，最后交换 3 与 2，得到 [1,4,2,3]。

### 核心不变量

处理完下标 i 时，相邻对 (0,1) 到 (i−1,i) 已全部按奇峰偶谷排列。

### 思路

从第二项起检查新边的方向，方向相反就交换两端。把较大的数放到峰顶或把较小的数放进谷底，都会加强前一条边原有的不等式，已处理前缀始终合法。

若先排序再交错摆放，会为任意两个数确定先后，题目却只约束相邻元素。设刚刚修好前 i 个数，若当前位置应为峰却小于左邻，交换会让左邻这个谷变得更小。它与再左边峰之间的关系自然保持。当前位置应为谷的证明完全对称。

#### 四个数的三条相邻边

| 步骤 | 当前状态 | 为什么这样走 |
| --- | --- | --- |
| 修第一个峰 | i=1，4>1，交换为 [1,4,3,2] | 第 1 格应至少等于左边。 |
| 检查第一个谷 | i=2，4≥3，保留 [1,4,3,2] | 第 2 格已是合格的右端谷。 |
| 修第二个峰 | i=3，3>2，交换为 [1,4,2,3] | 原谷从 3 降到 2，与左峰 4 的关系仍成立。 |

### 边界检查

只需相邻位置满足大小交替。原数组中若有相等的数，也允许相邻相等，因此局部顺序已经合格时就无需交换。

### Java

#### 用下标奇偶决定是否交换

`i % 2` 决定右端角色。两个分支都只在严格违反关系时调用 `swap`，临时变量保住被覆盖的元素。处理完 i 后，从 0 到 i 的每条边都已合法。

```java
class Solution {
    public void wiggleSort(int[] nums) {

        // 新边方向错误时交换两端，前一条边仍满足峰谷顺序。
        for (int i = 1; i < nums.length; ++i)
            if (i % 2 == 0 && nums[i] > nums[i - 1] || i % 2 == 1 && nums[i] < nums[i - 1])
                swap(nums, i, i - 1);
    }

    private void swap(int[] nums, int i, int j) {
        final int temp = nums[i];
        nums[i] = nums[j];
        nums[j] = temp;
    }
}
```

### Python

#### 用列表交换修最后一条边

`range(1, len(nums))` 让左邻始终存在。元组赋值先读取两个旧值，再写回列表。奇数位置交换后新峰取两者较大者，偶数位置交换后新谷取较小者。

```python
from __future__ import annotations


class Solution:
    def wiggleSort(self, nums: list[int]) -> None:

        # 新边方向错误时交换两端，前一条边仍满足峰谷顺序。
        for i in range(1, len(nums)):
            if i % 2 == 0 and nums[i] > nums[i - 1] or i % 2 == 1 and nums[i] < nums[i - 1]:
                nums[i], nums[i - 1] = nums[i - 1], nums[i]
```

### 复杂度

时间 O(n)，额外空间 O(1)。

共检查 n−1 条边，每次只读写常数个位置，不需要将数组复制出来。

### 面试追问

**改成严格峰谷还能用同一判断吗？** 相等的一对交换后仍相等，例如 [1,1] 无法满足严格不等式。即使存在严格解，也需要考虑重复值如何分散到不同位置。
