# 280. 摆动排序


### 题意

原地重排数组，使偶数下标为谷、奇数下标为峰。相邻值可以相等。

### 示例

输入 [4,1,3,2]。先交换 4 与 1，再保留 4 与 3，最后交换 3 与 2，得到 [1,4,2,3]。

### 思路

从第二项起检查新边的方向，方向相反就交换两端。把较大的数放到峰顶或把较小的数放进谷底，都会加强前一条边原有的不等式，已处理前缀始终合法。

### 边界检查

只需相邻位置满足大小交替。原数组中若有相等的数，也允许相邻相等，因此局部顺序已经合格时就无需交换。

### Java

```java
class Solution {
    public void wiggleSort(int[] nums) {

        // 新边方向错误时交换两端，前一条边仍满足峰谷顺序。
        for (int i = 1; i < nums.length; ++i)
            if (i % 2 == 0 && nums[i] > nums[i - 1] || i % 2 == 1 && nums[i] < nums[i - 1])
                swap(nums, i, i - 1);
    }

    private void swap(int[] nums, int i, int j) {
        final int temp = nums[i];
        nums[i] = nums[j];
        nums[j] = temp;
    }
}
```

### Python

```python
from __future__ import annotations


class Solution:
    def wiggleSort(self, nums: list[int]) -> None:

        # 新边方向错误时交换两端，前一条边仍满足峰谷顺序。
        for i in range(1, len(nums)):
            if i % 2 == 0 and nums[i] > nums[i - 1] or i % 2 == 1 and nums[i] < nums[i - 1]:
                nums[i], nums[i - 1] = nums[i - 1], nums[i]
```

### 复杂度

时间 O(n)，额外空间 O(1)。
