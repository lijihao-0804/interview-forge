# 359. 日志速率限制器


### 题意

同一条日志在成功输出后的 10 秒内不能再次输出，时间戳按顺序到达。

### 示例

消息 A 在秒数 2、11、12 到达，依次返回 true、false、true。第 11 秒被挡住的请求不会刷新时钟。

### 思路

队列按成功输出时间排列，用集合保存当前窗口已输出的内容。先移走所有满足当前时间≥旧时间+10 的记录，再测试新消息。

### 边界检查

只有真正打印的消息才更新它的时间。若把被拒绝的请求也写进记录，一条频繁到达的消息可能永远等不到再次打印。

### Java

```java
import java.util.*;

class Logger {
    public boolean shouldPrintMessage(int timestamp, String message) {

        // 先淘汰满十秒的成功记录，被拒绝的请求不会延长等待时间。
        while (!messageQueue.isEmpty()) {
            Map.Entry<Integer, String> head = messageQueue.peekFirst();
            if (timestamp - head.getKey() < 10) break;
            messageQueue.pollFirst();
            messageSet.remove(head.getValue());
        }

        if (messageSet.contains(message)) return false;

        messageQueue.offerLast(Map.entry(timestamp, message));
        messageSet.add(message);
        return true;
    }

    private Deque<Map.Entry<Integer, String>> messageQueue = new ArrayDeque<>();
    private Set<String> messageSet = new HashSet<>();
}
```

### Python

```python
from __future__ import annotations
import collections


class Logger:
    def __init__(self):

        self.messageQueue = collections.deque()
        self.messageSet = set()

    def shouldPrintMessage(self, timestamp: int, message: str) -> bool:

        # 先淘汰满十秒的成功记录，被拒绝的请求不会延长等待时间。
        while self.messageQueue:
            headTimestamp, headMessage = self.messageQueue[0]
            if timestamp < headTimestamp + 10:
                break
            self.messageQueue.popleft()
            self.messageSet.remove(headMessage)

        if message in self.messageSet:
            return False

        self.messageQueue.append((timestamp, message))
        self.messageSet.add(message)
        return True
```

### 复杂度

每条记录只入队出队一次，平均摊销 O(1)，状态空间与十秒内不同的成功消息数成正比。
