# 340. 至多包含 K 个不同字符的最长子串


### 题意

求最多含 k 种不同字符的最长连续子串长度。

### 输入与约束

输入为字符串和非负整数 k。要找连续子串，长度按字符计；Java 数组实现使用 ASCII 字符下标。

### 示例

abaccc，k=2。读到首个 c 时向右移掉含 b 的前缀，后缀 accc 长为 4，是答案。

### 核心不变量

收缩结束后窗口最多有 k 种字符，且对于当前右端，l 是能够保持合法的最左起点。

### 思路

右端每加入一个字符就更新计数。若种类超限则移动左端，直到计数归零的字符退出窗口。对每个右端点，这留下最长合法后缀。

种类数随右端扩张只增不减，随左端收缩只减不增。因此一旦窗口超额便从左端删到刚好合法；此前更早的起点对当前右端都不可能合法。每个右端只需考察这个最长合法后缀。

#### 从 aba 收缩到 accc

| 步骤 | 当前状态 | 为什么这样走 |
| --- | --- | --- |
| 窗口达到两类 | aba，l=0，r=2，计数 a:2、b:1，best=3 | 重复的 a 不增加种类。 |
| 首个 c 触发收缩 | abac → bac → ac，l=2，r=3 | 先移一个 a 仍有三类，再移 b 才合法。 |
| 继续接纳 c | 窗口 accc，l=2，r=5，best=4 | 后两个 c 都属于已有种类。 |

### 边界检查

窗口内某字符的频次减到零时，及时删除这项，种类数才会同步减少。若 k 为 0，返回 0 就符合“至多零种字符”的约束。

### 反例推演

字符串 `eceba`，k=2。读取 b 后只移走第一个 e，窗口中仍有 e、c、b 三种；必须继续收缩直到某种字符的最后一份离开。

### Java

#### 128 个频数槽如何增减种类

`count` 用字符码下标定位频数，适用于这里的 ASCII 输入。只有频数从零变一或一变零才改变 distinct，重复字符本身不会再占一个种类。

```java
class Solution {
    public int lengthOfLongestSubstringKDistinct(String s, int k) {
        int ans = 0;
        int distinct = 0;
        int[] count = new int[128];

        for (int l = 0, r = 0; r < s.length(); ++r) {
            if (++count[s.charAt(r)] == 1) ++distinct;
            // 字符种类超出限制时移动左端，直到窗口重新合法。
            while (distinct == k + 1) if (--count[s.charAt(l++)] == 0) --distinct;
            ans = Math.max(ans, r - l + 1);
        }

        return ans;
    }
}
```

### Python

#### Counter 归零与 distinct 的区别

Counter 的计数变成零时键仍可能存在，因此代码用 distinct 单独跟踪正频数的键数；每移出一个字符都前移 l，直到恢复合法后再比较长度。

```python
from __future__ import annotations
import collections


class Solution:
    def lengthOfLongestSubstringKDistinct(self, s: str, k: int) -> int:
        ans = 0
        distinct = 0
        count = collections.Counter()

        l = 0
        for r, c in enumerate(s):
            count[c] += 1
            if count[c] == 1:
                distinct += 1
            # 字符种类超出限制时移动左端，直到窗口重新合法。
            while distinct == k + 1:
                count[s[l]] -= 1
                if count[s[l]] == 0:
                    distinct -= 1
                l += 1
            ans = max(ans, r - l + 1)

        return ans
```

### 复杂度

时间 O(n)，计数表占 O(Σ)，Σ 为输入字符种类数。

每个字符最多加入和移出各一次。Java 使用 128 个固定槽，Python Counter 保留曾遇见字符的键，空间取决于整串字符集大小。

### 面试追问

**k=0 时如何避免 off-by-one？** 新字符一加入便超额，收缩会使 l=r+1，窗口长度 r−l+1 正好为零。
