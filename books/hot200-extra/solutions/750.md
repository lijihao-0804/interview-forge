# 750. 角矩形的数量

### 题意

统计 0/1 网格中四个顶点都是 1 的轴对齐矩形数量。

### 输入与约束

输入仅含 0、1 的矩形网格。选两条不同的行、两条不同的列，四个角都为 1 即可，中间的格子不限。

### 示例

两行都是 [1,0,1,1]，共同为 1 的列有三列，任取两列作左右边，共 3 个矩形。

### 核心不变量

对固定行对，count 等于已扫列中上下两个角都为 1 的列数。

### 思路

固定上下两行，数共同为 1 的列 c。这两行之间形成 c(c−1)/2 个矩形，每个矩形只归属于一对行。

矩形由上下两行、左右两列唯一确定。固定一对行后，把两行同时为 1 的列筛出来，任意两列都能补全四个角。如果有 c 列，按顺序选择两列有 c(c−1) 种，每个无序选择计了两次，应除以二。

### 边界检查

固定上下两行后，若三列在两行中都为 1，可选的是三对左右边。算一对列时让左列排在右列之前，同一个矩形就只会贡献一次。

### 反例推演

两行在三个列位置上都为 1，共有 3×2/2=3 个矩形。用相邻匹配列配对只得到两个，遗漏由最左、最右两列构成的那个。

### Java

Java 让 row2 从 row1+1 开始，排除颠倒上下边的重复。count 只在这对行的同一列都为 1 时加一，一对行扫完才把组合数计入 ans。

#### 从三条共同列选择一对

| 步骤 | 当前状态 | 判断依据 |
| --- | --- | --- |
| 固定上下两行 | [1,0,1,1] 与 [1,0,1,1] | 只有一对上下边需要考虑。 |
| 统计共同的列 | 0、2、3 三列上下均为 1；c=3 | 列 1 任一端都无法作为角。 |
| 选择两列 | 列对 (0,2)、(0,3)、(2,3)，贡献 3×2÷2=3 | 每对确定一个矩形，计数完毕。 |

```java
import java.util.*;

class Solution {
    public int countCornerRectangles(int[][] grid) {
        int ans = 0;

        for (int row1 = 0; row1 < grid.length - 1; ++row1)
            for (int row2 = row1 + 1; row2 < grid.length; ++row2) {
                // 固定两行，在共同为 1 的列中任选两列即得到一个矩形。
                int count = 0;
                for (int j = 0; j < grid[0].length; ++j)
                    if (grid[row1][j] == 1 && grid[row2][j] == 1) ++count;
                ans += count * (count - 1) / 2;
            }

        return ans;
    }
}
```

### Python

Python 用 zip 将上下两行按列配对。比较结果可当作 0 或 1 求和，columns 仅表示这一对行的可用列，随后用整数除法算得组合数。

#### 从三条共同列选择一对

| 步骤 | 当前状态 | 判断依据 |
| --- | --- | --- |
| 固定上下两行 | [1,0,1,1] 与 [1,0,1,1] | 只有一对上下边需要考虑。 |
| 统计共同的列 | 0、2、3 三列上下均为 1；c=3 | 列 1 任一端都无法作为角。 |
| 选择两列 | 列对 (0,2)、(0,3)、(2,3)，贡献 3×2÷2=3 | 每对确定一个矩形，计数完毕。 |

```python
class Solution:
    def countCornerRectangles(self, grid: list[list[int]]) -> int:
        rectangles = 0
        for top in range(len(grid)):
            for bottom in range(top + 1, len(grid)):
                # 固定两行，在共同为 1 的列中任选两列即得到一个矩形。
                columns = sum(a == b == 1 for a, b in zip(grid[top], grid[bottom]))
                rectangles += columns * (columns - 1) // 2
        return rectangles
```

### 面试追问

**如果行很多、列很少，能从列入手吗？** 可以固定列对再数共同行，矩形的唯一性不变。令较短的维度负责两层枚举可减少行列高度不均时的开销。

### 复杂度

R 行、C 列；时间 O(R²C)，辅助空间 O(1)。

共有 R(R−1)/2 对上下行，每对扫 C 列，故时间为 O(R²C)；计数过程只保留两个行号和一个列计数。
