# 750. 角矩形的数量

### 题意

统计 0/1 网格中四个顶点都是 1 的轴对齐矩形数量。

### 示例

两行都是 [1,0,1,1]，共同为 1 的列有三列，任取两列作左右边，共 3 个矩形。

### 思路

固定上下两行，数共同为 1 的列 c。这两行之间形成 c(c−1)/2 个矩形，每个矩形只归属于一对行。

### 边界检查

固定上下两行后，若三列在两行中都为 1，可选的是三对左右边。算一对列时让左列排在右列之前，同一个矩形就只会贡献一次。

### Java

```java
import java.util.*;

class Solution {
    public int countCornerRectangles(int[][] grid) {
        int ans = 0;

        for (int row1 = 0; row1 < grid.length - 1; ++row1)
            for (int row2 = row1 + 1; row2 < grid.length; ++row2) {
                // 固定两行，在共同为 1 的列中任选两列即得到一个矩形。
                int count = 0;
                for (int j = 0; j < grid[0].length; ++j)
                    if (grid[row1][j] == 1 && grid[row2][j] == 1) ++count;
                ans += count * (count - 1) / 2;
            }

        return ans;
    }
}
```

### Python

```python
class Solution:
    def countCornerRectangles(self, grid: list[list[int]]) -> int:
        rectangles = 0
        for top in range(len(grid)):
            for bottom in range(top + 1, len(grid)):
                # 固定两行，在共同为 1 的列中任选两列即得到一个矩形。
                columns = sum(a == b == 1 for a, b in zip(grid[top], grid[bottom]))
                rectangles += columns * (columns - 1) // 2
        return rectangles
```

### 复杂度

R 行、C 列；时间 O(R²C)，辅助空间 O(1)。
