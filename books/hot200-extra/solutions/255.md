# 255. 验证二叉搜索树的前序遍历序列

### 题意

给出互异的整数序列，判断它是否可能是某棵二叉搜索树的前序遍历。

### 输入与约束

输入互不相同的整数，判断能否依次作为某棵 BST 的前序遍历；左子树值小于根，右子树值大于根。

### 示例

[5,2,6,1] 中看到 6 表示已经进入根 5 的右子树，后续 1 小于 5，所以无效。

### 核心不变量

low 是已经跨入其右子树的祖先下界；栈保留尚可能成为以后节点右转起点的祖先。

### 思路

祖先栈表示尚未进入右子树的路径，读到较大值时连续弹栈。最后弹出的祖先给后续节点设下界，不能再落回它的左侧。

BST 前序按根、左、右访问。读到更大值时，会结束一段向左下降的路径，转入某个祖先的右子树。最后一个弹出的祖先确定新的严格下界，后续遍历不可能再回到它左边。整条路径只需一个栈，无需真正造树。

### 边界检查

一旦前序遍历进入某棵右子树，它的根值就给后续节点设了下界。这个下界即使对应节点已从栈中弹出也要保留。

### 反例推演

序列 `[5,2,6,1]` 在读取 6 时已转入 5 的右子树，随后出现的 1 非法。局部相邻大小都可能正常，关键是祖先 5 给出的永久下界。

### Java

Java 用 `Deque<Integer>` 存尚未越过的祖先值。每次先测 low，再连续弹出比当前值小的栈顶，最后压入当前值；每个数只进出栈各一次，连续弹栈不使总时间变成平方级。

#### 寻找不能再越过的祖先 5

| 步骤 | 当前状态 | 判断依据 |
| --- | --- | --- |
| 读 5、2 | 栈底→栈顶 [5,2]，尚未进入根的右子树 | 递减前缀可作为连续左孩子。 |
| 读 6 | 依次弹 2、5，low=5，栈为 [6] | 6 已位于根 5 的右子树。 |
| 读 1 | `1 < low = 5`，立即失败 | 无法在前序顺序中重新走回根的左子树。 |

```java
import java.util.ArrayDeque;
import java.util.Deque;

class Solution {
    public boolean verifyPreorder(int[] preorder) {
        Deque<Integer> stack = new ArrayDeque<>();
        int low = Integer.MIN_VALUE; // 当前允许的最小值（下界）

        // 弹出祖先表示进入其右子树，后续节点必须高于新的下界。
        for (int x : preorder) {
            // 落入已完成祖先的右子树，却比下界还小 -> 非法
            if (x < low) {
                return false;
            }
            // 回退到右子树：压平所有小于 x 的祖先，并抬高下界
            while (!stack.isEmpty() && stack.peek() < x) {
                low = stack.pop();
            }
            stack.push(x);
        }
        return true;
    }
}
```

### Python

Python 用 float("-inf") 初始化 low，避免最小整数哨兵与实际值冲突。stack[-1] 是最近祖先，弹出最后一个较小祖先后将它作为下界。题目保证值互异，因此不需要约定重复值应放哪一边。

#### 寻找不能再越过的祖先 5

| 步骤 | 当前状态 | 判断依据 |
| --- | --- | --- |
| 读 5、2 | 栈底→栈顶 [5,2]，尚未进入根的右子树 | 递减前缀可作为连续左孩子。 |
| 读 6 | 依次弹 2、5，low=5，栈为 [6] | 6 已位于根 5 的右子树。 |
| 读 1 | `1 < low = 5`，立即失败 | 无法在前序顺序中重新走回根的左子树。 |

```python
from typing import List


class Solution:
    def verifyPreorder(self, preorder: List[int]) -> bool:
        stack = []
        low = float("-inf")  # 下界
        # 弹出祖先表示进入其右子树，后续节点必须高于新的下界。
        for x in preorder:
            if x < low:
                return False
            while stack and stack[-1] < x:
                low = stack.pop()  # 抬高下界
            stack.append(x)
        return True
```

### 面试追问

**只核对相邻两数的大小行吗？** 6 后面接 1 看似可以向左，但先前跨过的祖先 5 已要求后续节点大于 5。必须记住由整个访问历史给出的下界。

### 复杂度

n 个节点；时间 O(n)，空间 O(n)。

尽管有嵌套 while，每个值只被压入和弹出各一次，累计栈操作为 O(n)。严格递减输入会让栈保存全部 n 个值。
