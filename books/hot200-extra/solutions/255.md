# 255. 验证二叉搜索树的前序遍历序列

### 题意

给出互异的整数序列，判断它是否可能是某棵二叉搜索树的前序遍历。

### 示例

[5,2,6,1] 中看到 6 表示已经进入根 5 的右子树，后续 1 小于 5，所以无效。

### 思路

祖先栈表示尚未进入右子树的路径，读到较大值时连续弹栈。最后弹出的祖先给后续节点设下界，不能再落回它的左侧。

### 边界检查

一旦前序遍历进入某棵右子树，它的根值就给后续节点设了下界。这个下界即使对应节点已从栈中弹出也要保留。

### Java

```java
import java.util.ArrayDeque;
import java.util.Deque;

class Solution {
    public boolean verifyPreorder(int[] preorder) {
        Deque<Integer> stack = new ArrayDeque<>();
        int low = Integer.MIN_VALUE; // 当前允许的最小值（下界）

        // 弹出祖先表示进入其右子树，后续节点必须高于新的下界。
        for (int x : preorder) {
            // 落入已完成祖先的右子树，却比下界还小 -> 非法
            if (x < low) {
                return false;
            }
            // 回退到右子树：压平所有小于 x 的祖先，并抬高下界
            while (!stack.isEmpty() && stack.peek() < x) {
                low = stack.pop();
            }
            stack.push(x);
        }
        return true;
    }
}
```

### Python

```python
from typing import List


class Solution:
    def verifyPreorder(self, preorder: List[int]) -> bool:
        stack = []
        low = float("-inf")  # 下界
        # 弹出祖先表示进入其右子树，后续节点必须高于新的下界。
        for x in preorder:
            if x < low:
                return False
            while stack and stack[-1] < x:
                low = stack.pop()  # 抬高下界
            stack.append(x)
        return True
```

### 复杂度

n 个节点；时间 O(n)，空间 O(n)。
