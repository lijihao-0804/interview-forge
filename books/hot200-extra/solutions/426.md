# 426. 将二叉搜索树转化为排序的双向链表

### 题意

将二叉搜索树的节点原地串成有序的循环双向链表，原来的 left、right 分别表示前驱和后继。

### 输入与约束

输入二叉搜索树根节点，可为空。要求复用原节点，left 表示前驱、right 表示后继，返回环中值最小的节点。

### 示例

根 4 的左右子分别为 2 和 7。返回节点 2；沿 right 访问 2、4、7、2，沿 left 从 2 回到 7。

### 核心不变量

中序已经交付的节点组成从 head 到 previous 的双向有序前缀，未访问的原右子树仍可由 current 或栈到达。

### 思路

BST 的中序遍历按值从小到大输出节点。用显式栈沿左链入栈，每次弹出一个节点，就把它与上一个输出节点双向相连。保留待访问的右子树，最后将最小值和最大值首尾相接；空树直接返回。

BST 中序遍历会按从小到大的次序交付节点，因此只需在连续交付的两个节点之间建立双向边。第一次交付时记住头节点，最后交付的是尾节点。封环要等遍历结束，否则后续仍沿树指针搜索时可能进入环。

### 边界检查

先区分两种连接：遍历中只连接相邻的中序节点，遍历结束才闭合首尾。只有一个节点时，它的左右指针最终都应指回自己。

### Java

Java 用 `Deque<Node>` 模拟左根右遍历。弹栈后把 node.right 存进 current，再连接 previous.right 和 node.left。previous 为 null 的那次将 node 记为 head，只在尾声连接两端。

#### 中序访问后封环

| 步骤 | 当前状态 | 判断依据 |
| --- | --- | --- |
| 沿左边界入栈 | 栈底→栈顶为 4、2；第一次交付 2，head=2 | 最左节点是有序链起点。 |
| 依次交付 4 和 7 | 连接 2.right=4、4.left=2，再连接 4↔7 | previous 每步正好指向当前节点的前驱。 |
| 首尾相接 | 7.right=2，2.left=7 | 正向访问 2、4、7 后回到 2。 |

```java
import java.util.*;

class Solution {
    public Node treeToDoublyList(Node root) {
        if (root == null) return null;
        Deque<Node> stack = new ArrayDeque<>();
        Node current = root, head = null, previous = null;
        while (current != null || !stack.isEmpty()) {
            while (current != null) {
                stack.push(current);
                current = current.left;
            }
            Node node = stack.pop();
            current = node.right;
            if (previous == null) head = node;
            else {
                previous.right = node;
                node.left = previous;
            }
            previous = node;
        }
        // 所有节点接入后才闭环，遍历期间不会沿已改写指针绕圈。
        head.left = previous;
        previous.right = head;
        return head;
    }
}
```

### Python

Python 的 stack 保存尚未交付的祖先。已处理前缀始终是一条以 head 开始、以 previous 结束的有序链；两个方向同时改写才能支持倒着走。空树在建栈前直接返回 None。

#### 中序访问后封环

| 步骤 | 当前状态 | 判断依据 |
| --- | --- | --- |
| 沿左边界入栈 | 栈底→栈顶为 4、2；第一次交付 2，head=2 | 最左节点是有序链起点。 |
| 依次交付 4 和 7 | 连接 2.right=4、4.left=2，再连接 4↔7 | previous 每步正好指向当前节点的前驱。 |
| 首尾相接 | 7.right=2，2.left=7 | 正向访问 2、4、7 后回到 2。 |

```python
class Solution:
    def treeToDoublyList(self, root):
        if root is None:
            return None
        stack = []
        current, head, previous = root, None, None
        while current is not None or stack:
            while current is not None:
                stack.append(current)
                current = current.left
            node = stack.pop()
            # 先保留右子树入口，再把当前节点与前驱相连。
            current = node.right
            if previous is None:
                head = node
            else:
                previous.right = node
                node.left = previous
            previous = node
        head.left, previous.right = previous, head
        return head
```

### 面试追问

**若只有一个节点，首尾怎么接？** head 与 previous 指向同一个对象，最后两次赋值让它的 left 与 right 都指向自己，单节点也能循环遍历。

### 复杂度

n 个节点、树高 h；时间 O(n)，辅助栈空间 O(h)。

每个树节点入栈和出栈各一次，建链常数次改边；中序栈最多保存一条根到叶路径。
