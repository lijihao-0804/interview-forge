# 1259. 不相交的握手

### 题意

偶数个人围坐一圈，每人和一人握手。计算连线互不相交的配对数，结果对 10⁹+7 取余。

### 输入与约束

numPeople 为偶数，圆周上的人各有固定位置，每人恰配一次。返回合法配对数对 1,000,000,007 的余数。

### 示例

六个人围成一圈。固定第一人的伙伴，左右两边分别剩 0 与 4、2 与 2、4 与 0 人，计数为 2+1+2=5。

### 核心不变量

计算 dp[i] 时，所有少于 i 对人的结果已经完成，内层累计项仅按 1 号伙伴划分。

### 思路

把固定弦两侧视作独立子问题，以配对数为下标。每种划分的方案数相乘，不同划分的结果相加。空区间只有一种配法。

给人编号 1 到 2i。若 1 牵住第 2j+2 人，弦内有 2j 人，外侧有 2(i−1−j) 人。跨越这条弦会相交，因此每个内侧方案都可以且只能和一个所选外侧方案组成一组搭配。按固定伙伴拆解也保证不会重复计数。

### 边界检查

固定一个人的握手对象后，弦的两边都要留下偶数个人。空的一侧恰好有一种配法，所以递推的起点是 `dp[0] = 1`。

### 反例推演

六人围桌，固定 1 号的握手对象；若与 3 号相连，中间只剩一人，无法独立配完。只枚举能把两侧都分成偶数人数的伙伴，合计 5 种。

### Java

Java 的 long[] dp 用配对数作下标。两项均已取模，但其乘积仍可能超过 int；用 long 相乘，每轮累加后立即取模，再把最终余数转回 int。

#### 固定 1 号的三个伙伴

| 步骤 | 当前状态 | 判断依据 |
| --- | --- | --- |
| 建立小规模状态 | dp[0]=1，dp[1]=1，dp[2]=2 | 空区域的一种完成方式是不用再配对。 |
| 让 1 握 2 | 左右配对数为 0、2；累计 1×2=2 | 另外四人可按两种方式完成。 |
| 让 1 握 4 | 左右配对数为 1、1；累计 2+1×1=3 | 两侧各剩一对，选择唯一。 |
| 让 1 握 6 | 左右配对数为 2、0；累计 3+2×1=5 | 六人的三个合法伙伴均已覆盖。 |

```java
import java.util.*;

class Solution {
    public int numberOfWays(int numPeople) {
        final long MOD = 1_000_000_007;

        long[] dp = new long[numPeople / 2 + 1];
        dp[0] = 1;

        // 固定一个人的伙伴；这条弦两侧的合法配对数相乘。
        for (int i = 1; i <= numPeople / 2; ++i)
            for (int j = 0; j < i; ++j) {
                dp[i] += dp[j] * dp[i - 1 - j];
                dp[i] %= MOD;
            }

        return (int) dp[numPeople / 2];
    }
}
```

### Python

Python 的 dp[j] 和 dp[i-1-j] 都在当前 i 之前算好。内层走完 j=0 到 i−1 后，dp[i] 刚好囊括固定点的所有伙伴。逐项取模还能控制整数长度。

#### 固定 1 号的三个伙伴

| 步骤 | 当前状态 | 判断依据 |
| --- | --- | --- |
| 建立小规模状态 | dp[0]=1，dp[1]=1，dp[2]=2 | 空区域的一种完成方式是不用再配对。 |
| 让 1 握 2 | 左右配对数为 0、2；累计 1×2=2 | 另外四人可按两种方式完成。 |
| 让 1 握 4 | 左右配对数为 1、1；累计 2+1×1=3 | 两侧各剩一对，选择唯一。 |
| 让 1 握 6 | 左右配对数为 2、0；累计 3+2×1=5 | 六人的三个合法伙伴均已覆盖。 |

```python
from __future__ import annotations


class Solution:
    def numberOfWays(self, numPeople: int) -> int:
        MOD = 1_000_000_007

        dp = [1] + [0] * (numPeople // 2)

        # 固定一个人的伙伴；这条弦两侧的合法配对数相乘。
        for i in range(1, numPeople // 2 + 1):
            for j in range(i):
                dp[i] += dp[j] * dp[i - 1 - j]
                dp[i] %= MOD

        return dp[numPeople // 2]
```

### 面试追问

**为什么不再乘 2i 表示固定点的选择？** 所有人都带编号，每个方案里 1 号都有唯一伙伴。改选固定点重新计算会把同一组握手重复计入。

### 复杂度

n 人；时间 O(n²)，空间 O(n)。

外层为 n/2 个状态，内层依次枚举 1 到 n/2 个伙伴划分，总项数为等差和，表长与人数成正比。
