# 293. 翻转游戏


### 题意

列举把字符串中一对相邻加号翻成两个减号后，一步能够抵达的全部局面。

### 输入与约束

输入串只含加号和减号，每次只允许改一对相邻加号。返回所有一步状态，若没有合法动作则返回空列表。

### 示例

输入 ++-+++。可选起点 0、3、4，对应 ---+++、++---+、++-+--。

### 核心不变量

扫描到 i 前，结果恰好包含所有起点小于 i 的合法一步后继。

### 思路

扫描每条相邻边；两端都是加号时，复制这一处改变后的字符串。每个合法动作有唯一的起始位置。

问题只要求翻一次。把字符串看成一条路径，每条边对应一对相邻格。输出不同的合法边即可，因为两个不同的起点改变的位置集合也不同，无需用集合去重。

#### 连续三个加号的重叠起点

| 步骤 | 当前状态 | 为什么这样走 |
| --- | --- | --- |
| 翻前两格 | 起点 0，输出 ---+++ | 原局面 ++-+++ 的第 0、1 格都是加号。 |
| 越过减号 | 起点 1、2 都跳过，起点 3 输出 ++---+ | 跨过减号的两条边不合法。 |
| 保留重叠动作 | 起点 4，输出 ++-+-- | 在原串上检查，上一条答案不影响第 4、5 格。 |

### 边界检查

连续三个加号中有两个合法起点，它们共享中间字符。生成一个结果后，用原字符串继续尝试下一个起点，避免漏掉重叠位置。

### 反例推演

状态 `++++` 有 3 个后继：分别翻下标 0、1、2 开头的相邻对。找到一对后若把扫描游标多跳一格，会漏掉中间的翻法。

### Java

#### 命中起点才创建副本

在只读的 currentState 上检查相邻字符，命中才复制成 `StringBuilder`。修改副本的 i、i+1 后保存快照，循环仍按步长 1 遍历原串。

```java
import java.util.*;

class Solution {
    public List<String> generatePossibleNextMoves(String currentState) {
        List<String> ans = new ArrayList<>();

        // 每个合法起点对应一条不同的后继局面。
        for (int i = 0; i + 1 < currentState.length(); ++i)
            if (currentState.charAt(i) == '+' && currentState.charAt(i + 1) == '+') {
                StringBuilder sb = new StringBuilder(currentState);
                sb.setCharAt(i, '-');
                sb.setCharAt(i + 1, '-');
                ans.add(sb.toString());
            }

        return ans;
    }
}
```

### Python

#### 把原串与错开一位的串配对

`zip(currentState, currentState[1:])` 让每一对依次对应起点 i。切片在 i 和 i+2 两侧保留原字符，中间换为两个减号，保证结果长度不变。

```python
from __future__ import annotations


class Solution:
    def generatePossibleNextMoves(self, currentState: str) -> list[str]:
        # 每个合法起点对应一条不同的后继局面。
        return [
            currentState[:i] + "--" + currentState[i + 2 :]
            for i, (a, b) in enumerate(zip(currentState, currentState[1:]))
            if a == "+" and b == "+"
        ]
```

### 复杂度

有 t 个合法动作时耗时 O(n+tn)，返回值占 O(tn)。

扫描需 n−1 次相邻检查，每个命中都生成一条长度 n 的新串。Python 形成右移一位的切片还需 O(n) 临时空间。

### 面试追问

**能在“++”命中后跳过两个字符吗？** 不能。末尾的 +++ 有两条合法边，跨两步会漏掉后一条；每个答案都从相同原局面开始。
