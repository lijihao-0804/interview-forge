# 469. 凸多边形


### 题意

顶点沿边界按顺序给出，判断简单多边形是否为凸多边形，连续三点共线可以接受。

### 输入与约束

输入为简单多边形按边界顺序排列的顶点。可接受连续三点共线，任务只判定凸性。

### 示例

依次连接 (0,0)、(3,0)、(1,1)、(0,3)。在 (3,0) 和 (1,1) 处转向符号不同，因此为凹多边形。

### 核心不变量

已检查的所有非零叉积均与 sign 同号，零叉积不会改变已确定的转向。

### 思路

计算每三连顶点的边向量叉积，跳过零值。一旦有两个非零叉积异号，就出现向内的转角；若全程同号，边界转向一致。注意检查首尾相接的三元组。

沿简单多边形边界行走，凸形的所有拐弯方向一致；凹入的顶点必有一次反向拐弯。三点叉积正负给出转向，零只表示沿直线继续。检查是环形的，最后一边到第一边的转向也必须纳入。

#### 示例中的两个相反叉积

| 步骤 | 当前状态 | 为什么这样走 |
| --- | --- | --- |
| 取三连点 | A=(0,0)，B=(3,0)，C=(1,1)，D=(0,3) | 沿边界考察连续的三点。 |
| 检查 B 的转向 | AB=(3,0)，AC=(1,1)，叉积 3 | 在 B 处向左转。 |
| 检查 C 的转向 | BC=(−2,1)，BD=(−3,3)，叉积 −3 | 符号相反，边界凹入，返回 false。 |

### 边界检查

连续三个点共线时，叉积为零，不能据此设置转向。记录第一个非零符号，后续若见到相反符号，才确定拐进了多边形内部。

### 反例推演

连续三个边界点共线时叉积为 0。把零当作反向转弯会拒绝带共线边界点的凸多边形；只有出现相反的非零符号才能认定凹陷。

### Java

#### 环形下标覆盖最后两个转角

用 `(i+1)%n` 与 `(i+2)%n` 对末尾三元组回绕。叉积用 long 做乘法，比较符号时直接比较两个布尔条件，无需把两个大叉积再次相乘。

```java
import java.util.*;

class Solution {
    public boolean isConvex(List<List<Integer>> points) {
        final int n = points.size();
        long sign = 0;

        for (int i = 0; i < n; ++i) {
            final long cross =
                    getCross(points.get(i), points.get((i + 1) % n), points.get((i + 2) % n));
            // 连续三点共线不决定转向，比较其余叉积的符号。
            if (cross == 0) continue;
            if (sign == 0) sign = cross;
            else if ((cross < 0) != (sign < 0)) return false;
        }

        return true;
    }

    private long getCross(List<Integer> p, List<Integer> q, List<Integer> r) {
        return (long) (q.get(0) - p.get(0)) * (r.get(1) - p.get(1))
                - (long) (q.get(1) - p.get(1)) * (r.get(0) - p.get(0));
    }
}
```

### Python

#### 负下标连接首尾三个点

`points[i-2]`、`points[i-1]` 在 i=0、1 时利用负下标从末端取点，故无需复制首点。sign 只在首次非零叉积时设定，cross*sign<0 表示真正反向。

```python
from __future__ import annotations


class Solution:
    def isConvex(self, points: list[list[int]]) -> bool:
        def getCross(p: list[int], q: list[int], r: list[int]):
            return (q[0] - p[0]) * (r[1] - p[1]) - (q[1] - p[1]) * (r[0] - p[0])

        sign = 0
        for i in range(len(points)):
            cross = getCross(points[i - 2], points[i - 1], points[i])
            # 连续三点共线不决定转向，比较其余叉积的符号。
            if cross == 0:
                continue
            if sign == 0:
                sign = cross
            elif cross * sign < 0:
                return False

        return True
```

### 复杂度

时间 O(n)，辅助空间 O(1)。

每个顶点作一次定长向量运算即可。只保存一个参考叉积和当前值，没有额外点集。

### 面试追问

**打乱顶点次序还能直接检查吗？** 不能。边界次序决定了哪两条边相邻；对无序点集需要先明确是求凸包，还是验证某个给定多边形。
