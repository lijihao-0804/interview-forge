# 489. 扫地机器人


### 题意

机器人只提供前进、左右转与清扫操作，无法读取地图。清扫起点可抵达的全部格子。

### 输入与约束

机器人处于固定有墙网格，能使用 move、turnLeft、turnRight、clean，无法读取绝对坐标。目标是清扫初始位置可达的区域。

### 示例

一个只有两格相通的房间，机器人清扫起点后进入邻格清扫，再转身原路返回；外围四壁都不能前进。

### 核心不变量

每次试探前机器人真实位置为栈顶格，其朝向与入格方向加已试次数一致，seen 中各格均已清扫。

### 思路

以起点为相对坐标原点，深搜时记录当前坐标和朝向。显式栈记下每格已尝试的方向数。四个方向都试完后，原地转两次、前进一步、再转两次，恢复父格的位置和原朝向，再右转一次尝试下一方向。

无法读地图，但可以把第一次面向的方向定义为相对北。物理动作使 DFS 的回溯多了一个条件：上一层恢复执行时，机器人必须真的站回父格，朝向也要与父层下一次试探相符，否则虚拟坐标和真实位置会分离。

#### 两格房间的进入与原路返回

| 步骤 | 当前状态 | 为什么这样走 |
| --- | --- | --- |
| 清扫起点 | 把唯一邻格设在初始前方，原点 (0,0) 已清扫 | 两个相通格可用相对方向描述，无需绝对地图。 |
| 进入邻格 | move 成功到 (−1,0)，清扫，已访共 2 格 | 其余方向不是墙就是已访问的父格。 |
| 复原并结束 | 掉头返回 (0,0)，恢复朝向后右转 | 父格试完剩余三面，两格均只清扫一次。 |

### 边界检查

搜索返回父格时，要同时复原机器人的朝向。如果只走回父格却留下相反朝向，后续“右转尝试下一邻格”的方向将整体错位。

### Java

#### Frame 记住物理方向与试探次数

`Frame` 保存格子、进入时方向及已试方向数。只有 move 成功才将邻格写进 visited；四面试完时用两次右转、前进、两次右转完成返回，额外一次右转对准父格下一方向。

```java
import java.util.*;

class Solution {
    private record Cell(int row, int col) {}

    private static class Frame {
        final Cell cell;
        final int heading;
        int turns;

        Frame(Cell cell, int heading) {
            this.cell = cell;
            this.heading = heading;
        }
    }

    public void cleanRoom(Robot robot) {
        int[][] directions = {{-1, 0}, {0, 1}, {1, 0}, {0, -1}};
        Cell origin = new Cell(0, 0);
        Set<Cell> visited = new HashSet<>();
        Deque<Frame> stack = new ArrayDeque<>();
        visited.add(origin);
        stack.push(new Frame(origin, 0));
        robot.clean();
        while (!stack.isEmpty()) {
            Frame current = stack.peek();
            // 四面都试过后退回父格，恢复原朝向并右转尝试下一面。
            if (current.turns == 4) {
                stack.pop();
                if (!stack.isEmpty()) {
                    robot.turnRight();
                    robot.turnRight();
                    robot.move();
                    robot.turnRight();
                    robot.turnRight();
                    robot.turnRight();
                }
                continue;
            }
            int direction = (current.heading + current.turns++) % 4;
            int[] step = directions[direction];
            Cell next = new Cell(current.cell.row() + step[0], current.cell.col() + step[1]);
            if (!visited.contains(next) && robot.move()) {
                visited.add(next);
                robot.clean();
                stack.push(new Frame(next, direction));
            } else {
                robot.turnRight();
            }
        }
    }
}
```

### Python

#### 更新栈顶列表并复原机器人

栈顶列表的第 4 项记录已试方向数。在移动前先增加它，便能在子帧返回后接续。seen 仅存已清扫的相对坐标，遇到已访问邻居可以直接转向。

```python
from __future__ import annotations


class Solution:
    def cleanRoom(self, robot: Robot) -> None:
        directions = ((-1, 0), (0, 1), (1, 0), (0, -1))
        seen = {(0, 0)}
        stack = [[0, 0, 0, 0]]
        robot.clean()
        while stack:
            row, col, heading, turns = stack[-1]
            # 四面都试过后退回父格，恢复原朝向并右转尝试下一面。
            if turns == 4:
                stack.pop()
                if stack:
                    robot.turnRight()
                    robot.turnRight()
                    robot.move()
                    robot.turnRight()
                    robot.turnRight()
                    robot.turnRight()
                continue
            direction = (heading + turns) % 4
            dr, dc = directions[direction]
            neighbor = (row + dr, col + dc)
            stack[-1][3] += 1
            if neighbor not in seen and robot.move():
                seen.add(neighbor)
                robot.clean()
                stack.append([*neighbor, direction, 0])
            else:
                robot.turnRight()
```

### 复杂度

可达格子为 V 个时，动作与时间均 O(V)，访问集合和显式栈 O(V)。

每个可达格清扫一次且最多试四个方向。每条深搜树边另做一趟常数动作的返回；访问集合与深搜栈都至多记录 V 个格子。

### 面试追问

**为什么原路返回时可以直接 move？** 那条边刚才已成功经过，房间布局固定。完成子格的四面试探后朝向恢复为进入方向，掉头便正对原来的父格。
