# 489. 扫地机器人


### 题意

机器人只提供前进、左右转与清扫操作，无法读取地图。清扫起点可抵达的全部格子。

### 示例

一个只有两格相通的房间，机器人清扫起点后进入邻格清扫，再转身原路返回；外围四壁都不能前进。

### 思路

以起点为相对坐标原点，深搜时记录当前坐标和朝向。显式栈记下每格已尝试的方向数。四个方向都试完后，原地转两次、前进一步、再转两次，恢复父格的位置和原朝向，再右转一次尝试下一方向。

### 边界检查

搜索返回父格时，要同时复原机器人的朝向。如果只走回父格却留下相反朝向，后续“右转尝试下一邻格”的方向将整体错位。

### Java

```java
import java.util.*;

class Solution {
    private record Cell(int row, int col) {}

    private static class Frame {
        final Cell cell;
        final int heading;
        int turns;

        Frame(Cell cell, int heading) {
            this.cell = cell;
            this.heading = heading;
        }
    }

    public void cleanRoom(Robot robot) {
        int[][] directions = {{-1, 0}, {0, 1}, {1, 0}, {0, -1}};
        Cell origin = new Cell(0, 0);
        Set<Cell> visited = new HashSet<>();
        Deque<Frame> stack = new ArrayDeque<>();
        visited.add(origin);
        stack.push(new Frame(origin, 0));
        robot.clean();
        while (!stack.isEmpty()) {
            Frame current = stack.peek();
            // 四面都试过后退回父格，恢复原朝向并右转尝试下一面。
            if (current.turns == 4) {
                stack.pop();
                if (!stack.isEmpty()) {
                    robot.turnRight();
                    robot.turnRight();
                    robot.move();
                    robot.turnRight();
                    robot.turnRight();
                    robot.turnRight();
                }
                continue;
            }
            int direction = (current.heading + current.turns++) % 4;
            int[] step = directions[direction];
            Cell next = new Cell(current.cell.row() + step[0], current.cell.col() + step[1]);
            if (!visited.contains(next) && robot.move()) {
                visited.add(next);
                robot.clean();
                stack.push(new Frame(next, direction));
            } else {
                robot.turnRight();
            }
        }
    }
}
```

### Python

```python
from __future__ import annotations


class Solution:
    def cleanRoom(self, robot: Robot) -> None:
        directions = ((-1, 0), (0, 1), (1, 0), (0, -1))
        seen = {(0, 0)}
        stack = [[0, 0, 0, 0]]
        robot.clean()
        while stack:
            row, col, heading, turns = stack[-1]
            # 四面都试过后退回父格，恢复原朝向并右转尝试下一面。
            if turns == 4:
                stack.pop()
                if stack:
                    robot.turnRight()
                    robot.turnRight()
                    robot.move()
                    robot.turnRight()
                    robot.turnRight()
                    robot.turnRight()
                continue
            direction = (heading + turns) % 4
            dr, dc = directions[direction]
            neighbor = (row + dr, col + dc)
            stack[-1][3] += 1
            if neighbor not in seen and robot.move():
                seen.add(neighbor)
                robot.clean()
                stack.append([*neighbor, direction, 0])
            else:
                robot.turnRight()
```

### 复杂度

可达格子为 V 个时，动作与时间均 O(V)，访问集合和显式栈 O(V)。
