# 760. 找出变位映射

### 题意

两个数组包含相同的多重集合。给第一个数组的每个位置分配第二个数组中相同值的下标。

### 输入与约束

nums1 与 nums2 含相同元素及其重数。返回一组从 nums1 各位置到 nums2 相同值位置的映射，允许多种合法输出。

### 示例

A=[5,2,5]，B=[2,5,5]；映射 [2,0,1] 成立，因为 B 在三个对应下标上的值依次为 5、2、5。

### 核心不变量

每次赋值只取走对应值的一个未分配位置，桶内余量等于尚需匹配该值的次数。

### 思路

对 B 按值收集下标，扫 A 时每次取走一个。相同数可以有多个合法映射，用完的下标应从候选中删去。

两个数组的多重集合相同，意味着每个值的“需求次数”等于在 B 中的候选位置数。先将这些候选按值分桶，处理 A 的一个位置只消费桶里一个下标。处理完任一前缀后，余下的候选数仍足以应对剩余需求。

### 边界检查

遇到重复值时，题解可能给出不同的合法映射。检验输出要核对每个位置的值和题目对下标的约定，不能要求输出与示例逐位相同。

### 反例推演

数组 A、B 都是 [7,7]，若要产出两个数组之间逐个元素的一一对应，本实现会分配两个不同下标。只保存一个下标也能反复查到数值 7，却无法还原这两个副本各自的去向。

### Java

Java 用 `Map<Integer,Deque<Integer>>` 储存下标。push 和 pop 使用同一端，因此对重复值先分配较晚出现的位置。ans[i] 写的是 B 的下标，在最后检查时应读 B[ans[i]]。

#### 消耗两个 5 的下标

| 步骤 | 当前状态 | 判断依据 |
| --- | --- | --- |
| 建立候选桶 | B=[2,5,5]；2→[0]，5→[1,2] | 记录下标而非值本身。 |
| 处理 5 和 2 | 从 5 桶取 2，再从 2 桶取 0；答案前缀 [2,0] | 弹出后只剩下标 1 可供 5 使用。 |
| 分配最后的 5 | 映射 [2,0,1]；B[2],B[0],B[1] 是 5,2,5 | 每个目标下标都恰好使用一次。 |

```java
import java.util.*;

class Solution {
    public int[] anagramMappings(int[] nums1, int[] nums2) {
        int[] ans = new int[nums1.length];
        Map<Integer, Deque<Integer>> numToIndices = new HashMap<>();

        // 每个值保留全部可用位置，取走一个位置后不再复用。
        for (int i = 0; i < nums2.length; ++i) {
            numToIndices.putIfAbsent(nums2[i], new ArrayDeque<>());
            numToIndices.get(nums2[i]).push(i);
        }

        for (int i = 0; i < nums1.length; ++i) ans[i] = numToIndices.get(nums1[i]).pop();

        return ans;
    }
}
```

### Python

Python 用 defaultdict(list) 逐项 append，因此下标在桶中从小到大；列表推导按 nums1 的顺序执行 pop，每次 O(1) 摊还。相同数总从同一列表取值，自然不会重复消费。

#### 消耗两个 5 的下标

| 步骤 | 当前状态 | 判断依据 |
| --- | --- | --- |
| 建立候选桶 | B=[2,5,5]；2→[0]，5→[1,2] | 记录下标而非值本身。 |
| 处理 5 和 2 | 从 5 桶取 2，再从 2 桶取 0；答案前缀 [2,0] | 弹出后只剩下标 1 可供 5 使用。 |
| 分配最后的 5 | 映射 [2,0,1]；B[2],B[0],B[1] 是 5,2,5 | 每个目标下标都恰好使用一次。 |

```python
from __future__ import annotations
import collections


class Solution:
    def anagramMappings(self, nums1: list[int], nums2: list[int]) -> list[int]:
        numToIndices = collections.defaultdict(list)

        # 每个值保留全部可用位置，取走一个位置后不再复用。
        for i, num in enumerate(nums2):
            numToIndices[num].append(i)

        return [numToIndices[num].pop() for num in nums1]
```

### 面试追问

**换成队列会得到不同答案吗？** 对示例按早到先取会得到 [1,0,2]。两个结果都逐位置匹配 A，且使用了 B 中三个不同位置。

### 复杂度

n 个元素；平均时间 O(n)，空间 O(n)。

每个 B 下标入桶一次，匹配 A 时出桶一次，桶中的所有下标总数为 n，返回数组也有 n 项。
