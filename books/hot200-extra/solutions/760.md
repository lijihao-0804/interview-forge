# 760. 找出变位映射

### 题意

两个数组包含相同的多重集合。给第一个数组的每个位置分配第二个数组中相同值的下标。

### 示例

A=[5,2,5]，B=[2,5,5]；映射 [2,0,1] 成立，因为 B 在三个对应下标上的值依次为 5、2、5。

### 思路

对 B 按值收集下标，扫 A 时每次取走一个。相同数可以有多个合法映射，用完的下标应从候选中删去。

### 边界检查

遇到重复值时，题解可能给出不同的合法映射。检验输出要核对每个位置的值和题目对下标的约定，不能要求输出与示例逐位相同。

### Java

```java
import java.util.*;

class Solution {
    public int[] anagramMappings(int[] nums1, int[] nums2) {
        int[] ans = new int[nums1.length];
        Map<Integer, Deque<Integer>> numToIndices = new HashMap<>();

        // 每个值保留全部可用位置，取走一个位置后不再复用。
        for (int i = 0; i < nums2.length; ++i) {
            numToIndices.putIfAbsent(nums2[i], new ArrayDeque<>());
            numToIndices.get(nums2[i]).push(i);
        }

        for (int i = 0; i < nums1.length; ++i) ans[i] = numToIndices.get(nums1[i]).pop();

        return ans;
    }
}
```

### Python

```python
from __future__ import annotations
import collections


class Solution:
    def anagramMappings(self, nums1: list[int], nums2: list[int]) -> list[int]:
        numToIndices = collections.defaultdict(list)

        # 每个值保留全部可用位置，取走一个位置后不再复用。
        for i, num in enumerate(nums2):
            numToIndices[num].append(i)

        return [numToIndices[num].pop() for num in nums1]
```

### 复杂度

n 个元素；平均时间 O(n)，空间 O(n)。
