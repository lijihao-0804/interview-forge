# 325. 和等于 k 的最长子数组长度


### 题意

在可含负数的数组中，找元素和恰为 k 的最长连续子数组长度。

### 输入与约束

给定允许正数、零与负数的整数数组和目标 k，求和为 k 的连续区间最大长度，没有时返回 0。

### 示例

[2,-2,3,1,-1] 的总和是 3。当 k=3，最后一个前缀减 3 得 0，最早前缀位置为 -1，得到长度 5。

### 核心不变量

处理第 i 项前，哈希表为每个旧前缀和保存最早下标，因而当前前缀匹配到的一定是最长可行起点。

### 思路

当前位置的前缀和为 P，只要更早出现过 P−k，两处之间的和就是 k。每个前缀和仅记录第一次出现的位置，才会得到最长区间。

数组含负数时，右移端点可能让区间和变小，不能靠和的大小决定滑窗该往哪里移。把连续段写成两个前缀之差：区间 (j,i] 合格恰好要求 P[j]=P[i]−k。右端固定后，选最早的 j 才能最大化 i−j。

#### 追踪两次出现的目标前缀差

| 步骤 | 当前状态 | 为什么这样走 |
| --- | --- | --- |
| 保住空前缀 | 读 2、−2 后 prefix 回到 0，表中 0 仍映射 −1 | 最早出现位置不能被下标 1 覆盖。 |
| 找到前三项 | i=2，prefix=3，target=0，长度 2−(−1)=3 | 区间从数组开头开始。 |
| 扩到全数组 | i=3 时和为 4；i=4 时和回到 3，长度 5 | 再次匹配最早的零前缀，刷新最大长度。 |

### 边界检查

相同前缀和若多次出现，要留下最早的位置才能把区间拉长。把和为 0 的空前缀放在下标 −1，答案就可以从数组首项开始。

### Java

#### long 前缀与 putIfAbsent

`long prefix` 避免多个 int 相加溢出，哈希键也用 Long。先查 target 再用 putIfAbsent 写当前位置，表里一直保留每种和第一次出现的下标。

```java
import java.util.*;

class Solution {
    public int maxSubArrayLen(int[] nums, int k) {
        int ans = 0;
        long prefix = 0;
        Map<Long, Integer> prefixToIndex = new HashMap<>();
        prefixToIndex.put(0L, -1);

        for (int i = 0; i < nums.length; ++i) {
            prefix += nums[i];
            final long target = prefix - k;
            // 查找前缀和减 k 的最早位置，才能让区间长度最大。
            if (prefixToIndex.containsKey(target))
                ans = Math.max(ans, i - prefixToIndex.get(target));
            prefixToIndex.putIfAbsent(prefix, i);
        }

        return ans;
    }
}
```

### Python

#### 保留最早出现的零前缀

`prefixToIndex={0:-1}` 把数组头之前也当作前缀。对每个 num 累加后只需一次目标查询；条件写入避免重复前缀替换掉更优的早期起点。

```python
from __future__ import annotations


class Solution:
    def maxSubArrayLen(self, nums: list[int], k: int) -> int:
        ans = 0
        prefix = 0
        prefixToIndex = {0: -1}

        for i, num in enumerate(nums):
            prefix += num
            target = prefix - k
            # 查找前缀和减 k 的最早位置，才能让区间长度最大。
            if target in prefixToIndex:
                ans = max(ans, i - prefixToIndex[target])
            if prefix not in prefixToIndex:
                prefixToIndex[prefix] = i

        return ans
```

### 复杂度

哈希表平均时间 O(n)，空间 O(n)。

每项求和、查表和按需插入均为平均常数时间，不同前缀最多 n+1 个。

### 面试追问

**若改求满足条件的子数组个数呢？** 相同前缀的每次出现都能配成一个区间，此时应记录出现次数，每到右端把目标前缀的次数加进答案。
