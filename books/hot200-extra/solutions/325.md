# 325. 和等于 k 的最长子数组长度


### 题意

在可含负数的数组中，找元素和恰为 k 的最长连续子数组长度。

### 示例

[2,-2,3,1,-1] 的总和是 3。当 k=3，最后一个前缀减 3 得 0，最早前缀位置为 -1，得到长度 5。

### 思路

当前位置的前缀和为 P，只要更早出现过 P−k，两处之间的和就是 k。每个前缀和仅记录第一次出现的位置，才会得到最长区间。

### 边界检查

相同前缀和若多次出现，要留下最早的位置才能把区间拉长。把和为 0 的空前缀放在下标 −1，答案就可以从数组首项开始。

### Java

```java
import java.util.*;

class Solution {
    public int maxSubArrayLen(int[] nums, int k) {
        int ans = 0;
        long prefix = 0;
        Map<Long, Integer> prefixToIndex = new HashMap<>();
        prefixToIndex.put(0L, -1);

        for (int i = 0; i < nums.length; ++i) {
            prefix += nums[i];
            final long target = prefix - k;
            // 查找前缀和减 k 的最早位置，才能让区间长度最大。
            if (prefixToIndex.containsKey(target))
                ans = Math.max(ans, i - prefixToIndex.get(target));
            prefixToIndex.putIfAbsent(prefix, i);
        }

        return ans;
    }
}
```

### Python

```python
from __future__ import annotations


class Solution:
    def maxSubArrayLen(self, nums: list[int], k: int) -> int:
        ans = 0
        prefix = 0
        prefixToIndex = {0: -1}

        for i, num in enumerate(nums):
            prefix += num
            target = prefix - k
            # 查找前缀和减 k 的最早位置，才能让区间长度最大。
            if target in prefixToIndex:
                ans = max(ans, i - prefixToIndex[target])
            if prefix not in prefixToIndex:
                prefixToIndex[prefix] = i

        return ans
```

### 复杂度

哈希表平均时间 O(n)，空间 O(n)。
