# 245. 最短单词距离 III

### 题意

求两个指定词的最短下标距离；当查询词相同时，必须使用不同位置。

### 输入与约束

两个查询词都在给定序列里，允许二者相同，同词时至少有两个可选位置。组成答案的两个下标必须不同。

### 示例

序列 [k,a,k,b,k]，查 k、k；相邻两次出现相隔 2，答案为 2，而非 0。

### 核心不变量

同词时 index1 指向最近一次、index2 指向前一次出现，真正的两端不会指向同一下标。

### 思路

词不同时比较双方最近位置；两词相同时只比较当前与上一次出现。更新位置前要先使用旧位置，否则会把自己当作配对。

当查询的两个词不同时，保存各自最近一次出现即可。相同时，两侧必须来自不同下标：读到新一次匹配，先把上一次保存到另一槽，再记录当前下标。相邻两次匹配已经是所有可能配对里最值得比较的。

### 边界检查

查询词相同时，可以用下一次出现的位置减去上一次的位置。更新答案后再覆盖旧下标，顺序颠倒会把同一个位置用两次。

### Java

Java 用 equals 检测同词查询；index1、index2 在初始时取词典长度及其相反数，让未形成完整匹配时的距离不会小于真实最优值。更新次序决定是否会错误地产生零距离。

#### 追踪 k 的三次不同出现

| 步骤 | 当前状态 | 判断依据 |
| --- | --- | --- |
| 首遇 k | 下标 0，尚无第二次真实出现 | 一个下标不能同时充当两端。 |
| 再遇 k | 下标从 0 到 2；候选差 2 | 先保留旧 0，再写入新 2。 |
| 第三次 k | 上一位置 2，当前位置 4，差仍为 2 | 最小值维持 2，跨过中间位置的差 4 不会更优。 |

```java
import java.util.*;

class Solution {
    public int shortestWordDistance(String[] words, String word1, String word2) {
        final boolean isSame = word1.equals(word2);
        int ans = Integer.MAX_VALUE;
        int index1 = words.length;
        int index2 = -words.length;

        for (int i = 0; i < words.length; ++i) {
            if (words[i].equals(word1)) {
                // 同词查询用上一次出现作配对，避免把当前位置与自身比较。
                if (isSame) index2 = index1;
                index1 = i;
            } else if (words[i].equals(word2)) {
                index2 = i;
            }
            ans = Math.min(ans, Math.abs(index1 - index2));
        }

        return ans;
    }
}
```

### Python

Python 的 if/elif 保证同一个词只走一个分支。isSame 为真时先做 index2=index1，再将 i 写入 index1；若先覆盖 index1 就丢失了上次出现的位置。

#### 追踪 k 的三次不同出现

| 步骤 | 当前状态 | 判断依据 |
| --- | --- | --- |
| 首遇 k | 下标 0，尚无第二次真实出现 | 一个下标不能同时充当两端。 |
| 再遇 k | 下标从 0 到 2；候选差 2 | 先保留旧 0，再写入新 2。 |
| 第三次 k | 上一位置 2，当前位置 4，差仍为 2 | 最小值维持 2，跨过中间位置的差 4 不会更优。 |

```python
from __future__ import annotations
import math


class Solution:
    def shortestWordDistance(
        self,
        wordsDict: list[str],
        word1: str,
        word2: str,
    ) -> int:
        isSame = word1 == word2
        ans = math.inf

        index1 = len(wordsDict)

        index2 = -len(wordsDict)

        for i, word in enumerate(wordsDict):
            if word == word1:
                # 同词查询用上一次出现作配对，避免把当前位置与自身比较。
                if isSame:
                    index2 = index1
                index1 = i
            elif word == word2:
                index2 = i
            ans = min(ans, abs(index1 - index2))

        return ans
```

### 面试追问

**同词查询只看相邻两次会漏吗？** 任意不相邻的两次之间至少还有一个相同词，用这个中间位置替换一个端点，距离必然缩小。因此最小值总来自相邻出现。

### 复杂度

n 个词；时间 O(n)，辅助空间 O(1)。

单次线性扫描同时处理同词与异词情况，每项最多更新两个下标，额外存储不随词典长度增长。
