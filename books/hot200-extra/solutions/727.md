# 727. 最小窗口子序列

### 题意

在字符串中找最短连续片段，使目标串按原顺序作为子序列出现。同样短时选起点最靠左的片段。

### 输入与约束

输入源串 s 与非空目标串 t，返回 s 的连续片段；片段中可跳过字符来匹配 t。不存在时返回空串，同长取最靠左者。

### 示例

源串 `axbxcab`，目标 `ab`。开头的 `axb` 可行，但末尾的 `ab` 更短，返回 `ab`。

### 核心不变量

读完 s[i] 后，cur[j] 是以 i 结尾且含有 t 的前 j+1 个字符作为子序列的最短后缀长度，不可达记为无穷。

### 思路

窗口必须保留目标字符的先后，统计字符频数不足以验证。记录完整匹配的起止，再比较长度；相同长度保留更早的窗口。 扫描源串，状态 j 保存截至当前位置覆盖目标前 j+1 个字符的最短后缀长度。当前字符匹配就接在上一行较短前缀后，否则延长上一行同一前缀。

固定源串的右端点后，最短窗口等价于取最靠右的可行起点。若当前字符匹配目标前缀的末字，直接让它担当末字即可，因为原来已经匹配的前缀去掉末字仍然可行；若不匹配，只能将上一轮同一目标前缀的窗口延长一格。不存在的前缀记成无穷。

### 边界检查

最短窗口如果有多个，要留最左边的那一个。例如 `axbxcab` 从开头也能凑齐目标，但只要末尾两个字符就已经完整匹配。

### 反例推演

源串 `abcdebdde`、目标 `bde` 的最短窗口有 `bcde` 和 `bdde`，等长时选更靠左的 `bcde`。只比较字符频次还会忽略子序列顺序。

### Java

Java 的 prev 与 cur 分属相邻两行，INF 表示尚不可达，bestEnd 只在长度严格缩小时改写。最终 substring 的右端不包含，故传 bestEnd+1 才能保留末字符。

#### 看目标 ab 的最短后缀怎样变短

| 步骤 | 当前状态 | 判断依据 |
| --- | --- | --- |
| 扫到下标 0 的 a | 匹配 a 的后缀长 1；ab 不可达 | 从当前位置重新开始比沿用更早窗口短。 |
| 扫到下标 2 的 b | 此前 ax 长 2，接 b 得 axb；best=3 | 第一次完成目标的两个字符。 |
| 扫到下标 5 的 a | 匹配 a 的最短后缀重置为 1 | 保留最新起点，为后续 b 作准备。 |
| 扫到下标 6 的 b | 接在下标 5 后得 ab；best=2 | 更短的窗口替代 axb。 |

```java
import java.util.Arrays;

class Solution {
    public String minWindow(String s, String t) {
        int n = s.length(), m = t.length();
        final long INF = Long.MAX_VALUE / 2;
        long[] prev = new long[m]; // 上一行 dp
        Arrays.fill(prev, INF);
        long best = INF;
        int bestEnd = -1; // 最优窗口的右端点

        // 只从上一行转移，防止同一源字符匹配目标中的两个位置。
        for (int i = 0; i < n; i++) {
            long[] cur = new long[m];
            Arrays.fill(cur, INF);
            for (int j = 0; j < m; j++) {
                if (s.charAt(i) == t.charAt(j)) {
                    if (j == 0) {
                        cur[j] = 1; // 从当前字符全新开始
                    } else if (prev[j - 1] < INF) {
                        cur[j] = prev[j - 1] + 1; // 用当前字符接上 t[j]
                    }
                } else {
                    if (prev[j] < INF) {
                        cur[j] = prev[j] + 1; // 窗口必须延伸到 i
                    }
                }
            }
            if (cur[m - 1] < best) {
                best = cur[m - 1];
                bestEnd = i;
            }
            prev = cur;
        }

        if (bestEnd == -1) return "";
        int start = bestEnd - (int) best + 1;
        return s.substring(start, bestEnd + 1);
    }
}
```

### Python

Python 先为每个源字符创建新的 cur。命中目标首字符时 cur[0]=1，旧的较长后缀可以丢弃。最后从 best_end 反推起点，只做一次切片，避免内层循环反复复制字符串。

#### 看目标 ab 的最短后缀怎样变短

| 步骤 | 当前状态 | 判断依据 |
| --- | --- | --- |
| 扫到下标 0 的 a | 匹配 a 的后缀长 1；ab 不可达 | 从当前位置重新开始比沿用更早窗口短。 |
| 扫到下标 2 的 b | 此前 ax 长 2，接 b 得 axb；best=3 | 第一次完成目标的两个字符。 |
| 扫到下标 5 的 a | 匹配 a 的最短后缀重置为 1 | 保留最新起点，为后续 b 作准备。 |
| 扫到下标 6 的 b | 接在下标 5 后得 ab；best=2 | 更短的窗口替代 axb。 |

```python
class Solution:
    def minWindow(self, s: str, t: str) -> str:
        n, m = len(s), len(t)
        INF = float("inf")
        prev = [INF] * m
        best = INF
        best_end = -1

        # 只从上一行转移，防止同一源字符匹配目标中的两个位置。
        for i in range(n):
            cur = [INF] * m
            for j in range(m):
                if s[i] == t[j]:
                    if j == 0:
                        cur[j] = 1
                    elif prev[j - 1] < INF:
                        cur[j] = prev[j - 1] + 1
                else:
                    if prev[j] < INF:
                        cur[j] = prev[j] + 1
            if cur[m - 1] < best:
                best = cur[m - 1]
                best_end = i
            prev = cur

        if best_end == -1:
            return ""
        start = best_end - best + 1
        return s[start : best_end + 1]
```

### 面试追问

**能像最小覆盖子串一样只维护频数吗？** 目标为 ab 时，ba 的频数已经满足，但它无法按序选出 ab。状态需要区分“已经完成 a”和“已经完成 ab”。

### 复杂度

源串长 n、目标串长 m；时间 O(nm)，辅助空间 O(m)。

源串每个位置计算 m 个目标前缀状态，只保存当前行和上一行；最后结果切片的复制量不超过 n。
