# 727. 最小窗口子序列

### 题意

在字符串中找最短连续片段，使目标串按原顺序作为子序列出现。同样短时选起点最靠左的片段。

### 示例

源串 `axbxcab`，目标 `ab`。开头的 `axb` 可行，但末尾的 `ab` 更短，返回 `ab`。

### 思路

窗口必须保留目标字符的先后，统计字符频数不足以验证。记录完整匹配的起止，再比较长度；相同长度保留更早的窗口。 扫描源串，状态 j 保存截至当前位置覆盖目标前 j+1 个字符的最短后缀长度。当前字符匹配就接在上一行较短前缀后，否则延长上一行同一前缀。

### 边界检查

最短窗口如果有多个，要留最左边的那一个。例如 `axbxcab` 从开头也能凑齐目标，但只要末尾两个字符就已经完整匹配。

### Java

```java
import java.util.Arrays;

class Solution {
    public String minWindow(String s, String t) {
        int n = s.length(), m = t.length();
        final long INF = Long.MAX_VALUE / 2;
        long[] prev = new long[m]; // 上一行 dp
        Arrays.fill(prev, INF);
        long best = INF;
        int bestEnd = -1; // 最优窗口的右端点

        // 只从上一行转移，防止同一源字符匹配目标中的两个位置。
        for (int i = 0; i < n; i++) {
            long[] cur = new long[m];
            Arrays.fill(cur, INF);
            for (int j = 0; j < m; j++) {
                if (s.charAt(i) == t.charAt(j)) {
                    if (j == 0) {
                        cur[j] = 1; // 从当前字符全新开始
                    } else if (prev[j - 1] < INF) {
                        cur[j] = prev[j - 1] + 1; // 用当前字符接上 t[j]
                    }
                } else {
                    if (prev[j] < INF) {
                        cur[j] = prev[j] + 1; // 窗口必须延伸到 i
                    }
                }
            }
            if (cur[m - 1] < best) {
                best = cur[m - 1];
                bestEnd = i;
            }
            prev = cur;
        }

        if (bestEnd == -1) return "";
        int start = bestEnd - (int) best + 1;
        return s.substring(start, bestEnd + 1);
    }
}
```

### Python

```python
class Solution:
    def minWindow(self, s: str, t: str) -> str:
        n, m = len(s), len(t)
        INF = float("inf")
        prev = [INF] * m
        best = INF
        best_end = -1

        # 只从上一行转移，防止同一源字符匹配目标中的两个位置。
        for i in range(n):
            cur = [INF] * m
            for j in range(m):
                if s[i] == t[j]:
                    if j == 0:
                        cur[j] = 1
                    elif prev[j - 1] < INF:
                        cur[j] = prev[j - 1] + 1
                else:
                    if prev[j] < INF:
                        cur[j] = prev[j] + 1
            if cur[m - 1] < best:
                best = cur[m - 1]
                best_end = i
            prev = cur

        if best_end == -1:
            return ""
        start = best_end - best + 1
        return s[start : best_end + 1]
```

### 复杂度

源串长 n、目标串长 m；时间 O(nm)，辅助空间 O(m)。
