# 259. 较小的三数之和

### 题意

统计数组中下标互异且三数之和严格小于 target 的三元组个数，每组三个下标只计一次。

### 输入与约束

传入整数数组与整数 target，统计三个互不相同且顺序递增的下标，使对应三数和严格小于 target。

### 示例

数组 [-2,0,1,4]，target=3。有 (-2,0,1)、(-2,0,4) 两组；(-2,1,4) 恰等于 3，不能计。

### 核心不变量

固定 i 时，[l,r] 之外的右侧下标选择已计入或已排除，后续不会重复计入同一三元组。

### 思路

排序并固定第一项。若当前左右端之和足够小，右端往左缩产生的所有组合都合格，直接累加间距；否则减小右端。

三个下标都枚举需要立方级时间。排序后固定第一个数，余下两个数在有序区间里选择。若由当前最右数构成的和已经足够小，换成它左边任何仍大于左指针的下标也合格，可以一口气数完整批；否则继续保留该右端只会让和更大，应缩右侧。

### 边界检查

排好序后，若最右端也满足严格小于目标，那么该端点左边的候选同样满足。让右指针从大到小逐个试会浪费这次比较得到的信息。

### 反例推演

排序后 `[-2,0,1,3]`，目标 2。固定 −2 和 0 时，搭配 1 或 3 都严格小于 2，一次可以计两项；不要只给当前右端计一次。

### Java

Java 先 Arrays.sort，再维护 l、r。count 加的是可用右端点数 r−l，计数用 long 累加，按题目接口返回 int。推广到不限制结果范围的数据时，返回类型也要足以表达组合数。

#### 一次统计固定左端的两个合法右端

| 步骤 | 当前状态 | 判断依据 |
| --- | --- | --- |
| 固定 −2 和 0 | 右端取 4，总和 2<3；一次加入 2 个 | 右端选 1 或 4 都满足。 |
| 左端改为 1 | −2+1+4=3，等于目标，缩小右端 | 这一组不应计入。 |
| 改固定数为 0 | 0+1+4=5，仍不合格 | 所有固定点处理完毕，答案 2。 |

```java
import java.util.Arrays;

class Solution {
    public int threeSumSmaller(int[] nums, int target) {
        Arrays.sort(nums);
        int n = nums.length;
        long count = 0; // 用 long 累计，返回值按题目要求的范围转换

        // 固定第一个下标 i，在右侧用双指针统计合法的 (j, k)
        for (int i = 0; i < n - 2; i++) {
            int l = i + 1, r = n - 1;
            // 若当前三数之和已经足够小，则中间所有右端点也都合格。
            while (l < r) {
                int sum = nums[i] + nums[l] + nums[r];
                if (sum < target) {
                    // 固定 i、l 后，r 取 l+1..当前 r 全部合法
                    count += r - l;
                    l++;
                } else {
                    r--; // 和太大，缩小右指针
                }
            }
        }
        return (int) count;
    }
}
```

### Python

Python 原地排序后用整数 count 累计。检查必须是严格小于 target；越界时只减 r，成功时只增 l，使已批量加入的同一批下标三元组不会再出现。

#### 一次统计固定左端的两个合法右端

| 步骤 | 当前状态 | 判断依据 |
| --- | --- | --- |
| 固定 −2 和 0 | 右端取 4，总和 2<3；一次加入 2 个 | 右端选 1 或 4 都满足。 |
| 左端改为 1 | −2+1+4=3，等于目标，缩小右端 | 这一组不应计入。 |
| 改固定数为 0 | 0+1+4=5，仍不合格 | 所有固定点处理完毕，答案 2。 |

```python
from typing import List


class Solution:
    def threeSumSmaller(self, nums: List[int], target: int) -> int:
        nums.sort()
        n = len(nums)
        count = 0
        for i in range(n - 2):
            l, r = i + 1, n - 1
            # 若当前三数之和已经足够小，则中间所有右端点也都合格。
            while l < r:
                if nums[i] + nums[l] + nums[r] < target:
                    count += r - l  # r 取 l+1..当前 r 全部合法
                    l += 1
                else:
                    r -= 1
        return count
```

### 面试追问

**要跳过相同数值吗？** 这题按不同下标计数，相同的值若位于不同下标，仍然对应不同选择。跳过重复值会少算。

### 复杂度

n 个数；时间 O(n²)，排序工作空间最坏 O(n)。

固定 i 后双指针最多走 O(n) 步，总计 O(n²)，高于排序的 O(n log n)。额外空间取决于语言的排序实现，指针扫描仅用常量空间。
