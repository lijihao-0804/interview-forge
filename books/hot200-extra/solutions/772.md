# 772. 基本计算器 III

### 题意

计算含非负整数字面量、四则运算和括号的表达式，整数除法向零截断。

### 输入与约束

输入合法整数算术表达式，支持加、减、乘、除与括号。除数非零，整数除法向零截断，值按题设范围处理。

### 示例

表达式 `18/(2+4)+3*2` 先得 6，再算 18/6 和 3*2，结果 9。

### 核心不变量

左括号隔开内外两层算符；每次归约用栈顶两个值按照右、左顺序弹出，再按原顺序运算。

### 思路

给数和运算符各用一个栈。遇到新算符时先执行栈顶优先级不低于它的运算；遇到右括号持续计算到对应左括号。二元运算先弹出的是右操作数。

从左往右扫描时，读到一个操作数并不能马上算，因为右侧也许有更高优先级的运算。用值栈保留操作数，用算符栈保留等待右端的操作。新算符会迫使栈里优先级更高或同级的运算先完成，左括号则隔断这种归约。

### 边界检查

除法需要向零截断。用 `(1-8)/3` 检查会得到 −2；Python 的 // 对负数向下取整；代码以 int(a / b) 在题设整数范围内实现向零截断。

### Java

Java 的 ArrayDeque 分别装整数和算符。多位整数连续读完再入栈，calc 先弹右操作数 b、再弹左操作数 a。尤其减法和除法不可交换顺序，Java 整数除法会向零截断。

#### 跟踪括号内外的归约顺序

| 步骤 | 当前状态 | 判断依据 |
| --- | --- | --- |
| 完成括号 | 18/(2+4) 中遇到右括号，值栈成为 [18,6] | 先归约加法，括号外的除号保留。 |
| 读到外层加号 | 先完成 18/6=3，值栈为 [3] | 除号比当前加号优先。 |
| 处理尾部乘法 | 先算 3×2=6，再算 3+6=9 | 乘号在加号之前归约，返回 9。 |

```java
import java.util.*;

class Solution {
    public int calculate(String s) {
        Deque<Integer> nums = new ArrayDeque<>();
        Deque<Character> ops = new ArrayDeque<>();
        boolean hasPrevNum = false;

        // 数字入值栈，算符按优先级归约；括号把内外计算分开。
        for (int i = 0; i < s.length(); ++i) {
            final char c = s.charAt(i);
            if (Character.isDigit(c)) {
                int num = c - '0';
                while (i + 1 < s.length() && Character.isDigit(s.charAt(i + 1)))
                    num = num * 10 + (s.charAt(i++ + 1) - '0');
                nums.push(num);
                hasPrevNum = true;
            } else if (c == '(') {
                ops.push('(');
                hasPrevNum = false;
            } else if (c == ')') {
                while (ops.peek() != '(') calc(nums, ops);
                ops.pop();
            } else if (c == '+' || c == '-' || c == '*' || c == '/') {
                if (!hasPrevNum) nums.push(0);
                while (!ops.isEmpty() && precedes(ops.peek(), c)) calc(nums, ops);
                ops.push(c);
            }
        }

        while (!ops.isEmpty()) calc(nums, ops);

        return nums.peek();
    }

    private void calc(Deque<Integer> nums, Deque<Character> ops) {
        final int b = nums.pop();
        final int a = nums.pop();
        final char op = ops.pop();
        if (op == '+') nums.push(a + b);
        else if (op == '-') nums.push(a - b);
        else if (op == '*') nums.push(a * b);
        else nums.push(a / b);
    }

    private boolean precedes(char prev, char curr) {
        if (prev == '(') return false;
        return prev == '*' || prev == '/' || curr == '+' || curr == '-';
    }
}
```

### Python

Python 两个 list 的尾部作为栈顶，遇到右括号时重复 calc，直到移除配对的左括号。除法要保留向零截断语义，不能直接把负数的 // 结果当答案。

#### 跟踪括号内外的归约顺序

| 步骤 | 当前状态 | 判断依据 |
| --- | --- | --- |
| 完成括号 | 18/(2+4) 中遇到右括号，值栈成为 [18,6] | 先归约加法，括号外的除号保留。 |
| 读到外层加号 | 先完成 18/6=3，值栈为 [3] | 除号比当前加号优先。 |
| 处理尾部乘法 | 先算 3×2=6，再算 3+6=9 | 乘号在加号之前归约，返回 9。 |

```python
from __future__ import annotations


class Solution:
    def calculate(self, s: str) -> int:
        nums = []
        ops = []

        def calc():
            b = nums.pop()
            a = nums.pop()
            op = ops.pop()
            if op == "+":
                nums.append(a + b)
            elif op == "-":
                nums.append(a - b)
            elif op == "*":
                nums.append(a * b)
            else:
                nums.append(int(a / b))

        def precedes(prev: str, curr: str) -> bool:

            if prev == "(":
                return False
            return prev in "*/" or curr in "+-"

        i = 0
        hasPrevNum = False

        # 数字入值栈，算符按优先级归约；括号把内外计算分开。
        while i < len(s):
            c = s[i]
            if c.isdigit():
                num = int(c)
                while i + 1 < len(s) and s[i + 1].isdigit():
                    num = num * 10 + int(s[i + 1])
                    i += 1
                nums.append(num)
                hasPrevNum = True
            elif c == "(":
                ops.append("(")
                hasPrevNum = False
            elif c == ")":
                while ops[-1] != "(":
                    calc()
                ops.pop()
            elif c in "+-*/":
                if not hasPrevNum:
                    nums.append(0)
                while ops and precedes(ops[-1], c):
                    calc()
                ops.append(c)
            i += 1

        while ops:
            calc()

        return nums.pop()
```

### 面试追问

**同优先级为什么也要先计算？** 例如 18/3/2 按左结合应先算 18/3 再除 2，结果为 3。若把两个除号都拖到末尾从右向左计算，分组就变了。

### 复杂度

长度 n；时间 O(n)，空间 O(n)。

每个字符只扫描一次，每个算符只入栈出栈一次，因此连续归约的总次数仍为 O(n)。深层括号或长表达式可使栈长线性增长。
