# 317. 离建筑物最近的距离


### 题意

在含建筑、空地和障碍的网格上选择一处空地，使步行到所有建筑的距离和最小；不能穿过其他建筑。

### 输入与约束

网格中 0 为空地、1 为建筑、2 为障碍。只可四邻行走，不能穿楼或障碍。候选必须是空地且通往每栋楼。

### 示例

网格 [1,0,0,1] 的两个空地到两楼距离和都为 3，返回 3；若中间隔着障碍且无共同可达空地，返回 -1。

### 核心不变量

完成若干栋楼的 BFS 后，dist 是这些楼贡献的距离和，reachCount 是其中确实到过该空地的楼数。

### 思路

从每栋楼分别做 BFS，累加每块空地的最短距离并记录到达次数。最终只比较到达次数等于建筑数的空地。

多源 BFS 只会保留“离最近楼的距离”，但本题要把所有楼的距离相加。每栋楼单独按层扩展，对每一块能抵达的空地贡献一次距离、一次访问次数。若某楼连另一楼的邻接处都无法抵达，两楼就不可能拥有共同空地。

#### 两栋楼分别向中间空地计费

| 步骤 | 当前状态 | 为什么这样走 |
| --- | --- | --- |
| 从左楼出发 | 两块空地的 dist=[1,2]，reach=[1,1] | 同一行向右逐层抵达。 |
| 从右楼出发 | 本轮贡献 [2,1]，累计 dist=[3,3] | 按与右楼的距离再加一轮。 |
| 筛选共同空地 | reach=[2,2]，最小累计距离为 3 | 两处都能到达两栋楼，任选其一。 |

### 边界检查

答案必须选在每栋楼都能到达的空地。只累加距离会把某些只靠近一栋楼的格子错选为答案，还要核对到达楼数。

### Java

#### 分开维护单次访问与跨楼累计

`dist` 与 `reachCount` 跨楼共享，`seen` 每次 BFS 重新创建。取出 sz 个旧队列元素后才增加步数。碰到楼只增加 seenBuildings，不把它当成通道。

```java
import java.util.*;

class Solution {
    public int shortestDistance(int[][] grid) {
        final int m = grid.length;
        final int n = grid[0].length;
        final int nBuildings = getBuildingsCount(grid);
        int ans = Integer.MAX_VALUE;

        int[][] dist = new int[m][n];

        int[][] reachCount = new int[m][n];

        for (int i = 0; i < m; ++i)
            for (int j = 0; j < n; ++j)
                if (grid[i][j] == 1) if (!bfs(grid, i, j, dist, reachCount, nBuildings)) return -1;

        for (int i = 0; i < m; ++i)
            for (int j = 0; j < n; ++j)
                if (reachCount[i][j] == nBuildings) ans = Math.min(ans, dist[i][j]);

        return ans == Integer.MAX_VALUE ? -1 : ans;
    }

    private static final int[][] DIRS = {{0, 1}, {1, 0}, {0, -1}, {-1, 0}};

    private boolean bfs(
            int[][] grid, int row, int col, int[][] dist, int[][] reachCount, int nBuildings) {
        final int m = grid.length;
        final int n = grid[0].length;
        Queue<Map.Entry<Integer, Integer>> q = new ArrayDeque<>(List.of(Map.entry(row, col)));
        boolean[][] seen = new boolean[m][n];
        seen[row][col] = true;
        int seenBuildings = 1;

        for (int step = 1; !q.isEmpty(); ++step)
            // 每一批队列节点距本轮出发的建筑相同。
            for (int sz = q.size(); sz > 0; --sz) {
                final int i = q.peek().getKey();
                final int j = q.poll().getValue();
                for (int[] dir : DIRS) {
                    final int x = i + dir[0];
                    final int y = j + dir[1];
                    if (x < 0 || x == m || y < 0 || y == n) continue;
                    if (seen[x][y]) continue;
                    seen[x][y] = true;
                    if (grid[x][y] == 0) {
                        dist[x][y] += step;
                        ++reachCount[x][y];
                        q.offer(Map.entry(x, y));
                    } else if (grid[x][y] == 1) {
                        ++seenBuildings;
                    }
                }
            }

        return seenBuildings == nBuildings;
    }

    private int getBuildingsCount(int[][] grid) {
        int buildingCount = 0;
        for (int[] row : grid) for (final int cell : row) if (cell == 1) ++buildingCount;
        return buildingCount;
    }
}
```

### Python

#### 固定队列一层的大小

`for _ in range(len(q))` 在该层开始时固定本批长度。集合记录本栋楼访问过的坐标，遇到同一空地的多条路径只累计最短的那次距离。

```python
from __future__ import annotations
import collections
import math


class Solution:
    def shortestDistance(self, grid: list[list[int]]) -> int:
        DIRS = ((0, 1), (1, 0), (0, -1), (-1, 0))
        m = len(grid)
        n = len(grid[0])
        nBuildings = sum(a == 1 for row in grid for a in row)
        ans = math.inf

        dist = [[0] * n for _ in range(m)]

        reachCount = [[0] * n for _ in range(m)]

        def bfs(row: int, col: int) -> bool:
            q = collections.deque([(row, col)])
            seen = {(row, col)}
            seenBuildings = 1

            step = 1
            while q:
                # 每一批队列节点距本轮出发的建筑相同。
                for _ in range(len(q)):
                    i, j = q.popleft()
                    for dx, dy in DIRS:
                        x = i + dx
                        y = j + dy
                        if x < 0 or x == m or y < 0 or y == n:
                            continue
                        if (x, y) in seen:
                            continue
                        seen.add((x, y))
                        if not grid[x][y]:
                            dist[x][y] += step
                            reachCount[x][y] += 1
                            q.append((x, y))
                        elif grid[x][y] == 1:
                            seenBuildings += 1
                step += 1

            return seenBuildings == nBuildings

        for i in range(m):
            for j in range(n):
                if grid[i][j] == 1:
                    if not bfs(i, j):
                        return -1

        for i in range(m):
            for j in range(n):
                if reachCount[i][j] == nBuildings:
                    ans = min(ans, dist[i][j])

        return -1 if ans == math.inf else ans
```

### 复杂度

B 栋建筑，时间 O(Bmn)，辅助空间 O(mn)。

每次搜索至多看完整网格，共 B 次。距离表、计数表及单轮队列和访问标记均与网格等大。

### 面试追问

**分别到过每栋楼是否就一定有共同空地？** 提前发现找不到某栋楼可以判失败，反过来仍需对每块候选核对 reachCount；不同两楼之间可能使用不同的空地区域。
