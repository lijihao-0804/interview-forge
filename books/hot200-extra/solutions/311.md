# 311. 稀疏矩阵的乘法


### 题意

给定维数兼容的两个稀疏矩阵，求普通矩阵乘积。

### 示例

[[0,2],[-1,0]] 乘 [[3,0],[4,5]] 得 [[8,10],[-3,0]]。第一行仅第二个系数贡献结果。

### 思路

固定左矩阵一行，在每个非零系数处扫描右矩阵对应的一行，把乘积累加进结果。跳过零系数可省去整行乘法。

### 边界检查

固定第一个矩阵的某一行和其中一个非零系数后，只需要把第二个矩阵对应行乘上该系数累加。先过滤零系数能省去整行无效乘法。

### Java

```java
class Solution {
    public int[][] multiply(int[][] mat1, int[][] mat2) {
        int cols = mat2[0].length;
        int[][] product = new int[mat1.length][cols];
        for (int row = 0; row < mat1.length; row++) {
            for (int k = 0; k < mat2.length; k++) {
                int value = mat1[row][k];
                // 左边系数为零时，它对整行结果的贡献都是零。
                if (value == 0) continue;
                for (int col = 0; col < cols; col++) product[row][col] += value * mat2[k][col];
            }
        }
        return product;
    }
}
```

### Python

```python
from __future__ import annotations


class Solution:
    def multiply(self, mat1: list[list[int]], mat2: list[list[int]]) -> list[list[int]]:
        columns = len(mat2[0])
        product = [[0] * columns for _ in mat1]
        for row, values in enumerate(mat1):
            for k, value in enumerate(values):
                # 左边系数为零时，它对整行结果的贡献都是零。
                if value:
                    for col, factor in enumerate(mat2[k]):
                        product[row][col] += value * factor
        return product
```

### 复杂度

左矩阵为 m×k、右矩阵 k×n，左矩阵有 z 个非零值。时间 O(mk+mn+zn)，结果占 O(mn)，额外空间 O(1)。
