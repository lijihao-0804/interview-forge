# 311. 稀疏矩阵的乘法


### 题意

给定维数兼容的两个稀疏矩阵，求普通矩阵乘积。

### 输入与约束

左矩阵为 m×k、右矩阵为 k×n，整数值可能为负或零。返回普通矩阵乘积的 m×n 稠密表示。

### 示例

[[0,2],[-1,0]] 乘 [[3,0],[4,5]] 得 [[8,10],[-3,0]]。第一行仅第二个系数贡献结果。

### 核心不变量

处理完左行的第 k 个系数，输出行每格等于此前所有已处理内维乘积的和。

### 思路

固定左矩阵一行，在每个非零系数处扫描右矩阵对应的一行，把乘积累加进结果。跳过零系数可省去整行乘法。

按输出格逐个做点积时，同一个左侧零系数会在所有输出列中反复出现。交换内两层循环，把结果行视为若干右矩阵行的线性组合；一个零系数直接取消整行贡献。

#### 乘出两行不同符号的结果

| 步骤 | 当前状态 | 为什么这样走 |
| --- | --- | --- |
| 跳过零系数 | 结果第 0 行 [0,0]，左系数 mat1[0][0]=0 | 右矩阵第 0 行不产生贡献。 |
| 展开系数 2 | 第 0 行加上 2×[4,5]，得到 [8,10] | 左侧第 1 列对应右侧第 1 行。 |
| 处理第二行 | −1×[3,0]=[−3,0]，另一个系数为 0 | 两行组合成 [[8,10],[−3,0]]。 |

### 边界检查

固定第一个矩阵的某一行和其中一个非零系数后，只需要把第二个矩阵对应行乘上该系数累加。先过滤零系数能省去整行无效乘法。

### Java

#### 一项系数更新整行结果

`product[row]` 初始全零。处理到 k 之后，它已包含来自左行前 k+1 个系数的全部贡献。非零项的正负都保留，判断只跳过 value==0。

```java
class Solution {
    public int[][] multiply(int[][] mat1, int[][] mat2) {
        int cols = mat2[0].length;
        int[][] product = new int[mat1.length][cols];
        for (int row = 0; row < mat1.length; row++) {
            for (int k = 0; k < mat2.length; k++) {
                int value = mat1[row][k];
                // 左边系数为零时，它对整行结果的贡献都是零。
                if (value == 0) continue;
                for (int col = 0; col < cols; col++) product[row][col] += value * mat2[k][col];
            }
        }
        return product;
    }
}
```

### Python

#### 用 enumerate 展开非零系数

列表推导为每个输出行创建独立列表。对 mat2[k] 用 enumerate 可同时拿列号及乘数；product[row][col] 用 +=，让不同 k 在同一结果格相加。

```python
from __future__ import annotations


class Solution:
    def multiply(self, mat1: list[list[int]], mat2: list[list[int]]) -> list[list[int]]:
        columns = len(mat2[0])
        product = [[0] * columns for _ in mat1]
        for row, values in enumerate(mat1):
            for k, value in enumerate(values):
                # 左边系数为零时，它对整行结果的贡献都是零。
                if value:
                    for col, factor in enumerate(mat2[k]):
                        product[row][col] += value * factor
        return product
```

### 复杂度

左矩阵为 m×k、右矩阵 k×n，左矩阵有 z 个非零值。时间 O(mk+mn+zn)，结果占 O(mn)，额外空间 O(1)。

先看完 mk 个左格并初始化 mn 个输出格。每个非零左系数再处理 n 个右列，故出现 zn 项。

### 面试追问

**右矩阵本身也几乎全是零呢？** 可事先把它的每一行压成 (列号,非零值) 对。命中左系数后只访问该行的非零项，代价是预处理和额外索引。
