# 311. 稀疏矩阵的乘法


### 题意

给定维数兼容的两个稀疏矩阵，求普通矩阵乘积。

### 输入与约束

左矩阵为 m×k、右矩阵为 k×n，整数值可能为负或零。返回普通矩阵乘积的 m×n 稠密表示。

### 示例

[[0,2],[-1,0]] 乘 [[3,0],[4,5]] 得 [[8,10],[-3,0]]。第一行仅第二个系数贡献结果。

### 核心不变量

处理完一行的前 k 个系数，输出对应行等于这些系数与右矩阵对应行的线性组合。右矩阵行没有登记的列贡献恒为 0。

### 思路

先为右矩阵每行列出非零的 (列号,值)。再扫左矩阵；发现非零 a[i][k] 时，仅访问右矩阵第 k 行登记的非零项 b[k][j]，把乘积加到结果 [i][j]。

例如 [0,2] 乘 [[9,8],[0,3]]，左侧只激活第 1 行，右侧该行只登记 (1,3)，于是只做一次乘加，得到 [0,6]。

### 边界检查

固定第一个矩阵的某一行和其中一个非零系数后，只需要把第二个矩阵对应行乘上该系数累加。先过滤零系数能省去整行无效乘法。

### 反例推演

计算 `[[0,2]] × [[9,8],[0,3]]`，结果是 `[[0,6]]`。左系数为零时可跳过对应整行；左系数非零时不能把它加到右行的零列。

### Java

#### 按右矩阵的行建立稀疏索引

每个二元数组记录原列号和系数。输出仍是二维数组，可直接按原坐标累加。

| 步骤 | 当前状态 | 判断依据 |
| --- | --- | --- |
| 建右行索引 | B=[[9,8],[0,3]] | 第 1 行非零项只有 (1,3) |
| 读左行 | A[0]=[0,2] | 系数 0 跳过；2 激活 B 的第 1 行 |
| 累加配对 | out[0][1]+=2×3 | 该行结果为 [0,6] |

```java
import java.util.*;
class Solution {
    public int[][] multiply(int[][] a, int[][] b) {
        List<List<int[]>> right = new ArrayList<>();
        for (int[] row : b) {
            List<int[]> entries = new ArrayList<>();
            for (int j = 0; j < row.length; j++)
                if (row[j] != 0) entries.add(new int[]{j, row[j]});
            right.add(entries);
        }
        int[][] out = new int[a.length][b[0].length];
        for (int i = 0; i < a.length; i++)
            for (int k = 0; k < a[i].length; k++)
                if (a[i][k] != 0)
                    for (int[] entry : right.get(k))
                        out[i][entry[0]] += a[i][k] * entry[1];
        return out;
    }
}
```

### Python

#### 按右矩阵的行建立稀疏索引

右行的非零项写成 (列号,值) 列表；左行某个系数为零时，连这个列表也不用访问。

| 步骤 | 当前状态 | 判断依据 |
| --- | --- | --- |
| 建右行索引 | B=[[9,8],[0,3]] | 第 1 行非零项只有 (1,3) |
| 读左行 | A[0]=[0,2] | 系数 0 跳过；2 激活 B 的第 1 行 |
| 累加配对 | out[0][1]+=2×3 | 该行结果为 [0,6] |

```python
class Solution:
    def multiply(self, mat1: list[list[int]], mat2: list[list[int]]) -> list[list[int]]:
        right = [[(j, x) for j, x in enumerate(row) if x] for row in mat2]
        out = [[0] * len(mat2[0]) for _ in mat1]
        for i, row in enumerate(mat1):
            for k, a in enumerate(row):
                if a:
                    for j, b in right[k]:
                        out[i][j] += a * b
        return out
```

### 复杂度

左矩阵 m×k、右矩阵 k×n，右矩阵有 z 个非零，实际相乘的非零项配对数为 P。时间 O(mk+kn+mn+P)，索引空间 O(k+z)，返回的稠密结果占 O(mn)。

### 面试追问

**什么时候只跳过左侧零值就够了？** 如果右矩阵几乎全非零，建立索引无法显著减少乘法，直接扫描右行可省索引空间。两边都稀疏时，预处理可让乘加次数恰等于非零项的配对数。
