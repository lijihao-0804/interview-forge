# 428. 序列化和反序列化 N 叉树

### 题意

为有序 N 叉树设计序列化与反序列化，使任意树往返后恢复原结构及孩子顺序。

### 输入与约束

输入为有序的 N 叉树，可为空。serialize 生成可供同一 Codec 的 deserialize 使用的字符串；往返后每个孩子列表顺序不变。

### 示例

根 7 的孩子依次为 2、9，9 又有孩子 4。解码时必须区分 4 是 9 的孩子，而不是根的第三个孩子。

### 核心不变量

解码栈顶是先序中最近一个尚有孩子待接的祖先，remaining 记录其未填的直接孩子数。

### 思路

前序依次记录节点值和孩子数。编码时把孩子倒序压栈，出栈顺序就和原顺序相同。解码时，栈顶为还缺孩子的最近祖先：读出一对值与数量，把新节点追加为其孩子；当父节点的孩子补齐便弹出，若新节点也有孩子则继续压栈。空串表示空树。

先序节点值本身不能区分兄弟与孩子。给每个值紧跟其直接孩子数，解码器便知道每个节点还有几个孩子待接。最近一个仍有空位的祖先就是下一个节点的父亲，这使得单向读取就能恢复结构与兄弟顺序。

### 边界检查

两个树可以有相同的前序节点值序列，却有不同的父子关系。序列化格式必须能恢复孩子的边界，叶子也不能省掉必要的结构标记。

### Java

Java 用 `Deque<Node>` 做先序，按逆序压孩子让第一个孩子先出栈。解码栈中的 Parent 同时保存节点与 remaining；接上孩子后减一，父帧满了就退出，再为有孩子的新节点建立自己的帧。

#### 按节点剩余名额还原父子关系

| 步骤 | 当前状态 | 判断依据 |
| --- | --- | --- |
| 先序写出记录 | 节点与孩子数依次为 (7,2)、(2,0)、(9,1)、(4,0) | 倒序压栈确保孩子 2 先于 9 编码。 |
| 给根分配孩子 | 7 接 2 后余 1 位，接 9 后余 0 位 | 根 7 现在已经配满。 |
| 把 4 接给 9 | 9 的待接数从 1 变成 0 | 根的名额已经耗尽，所以 4 不会成为根的第三个孩子。 |

```java
import java.util.*;

class Codec {
    private static class Parent {
        final Node node;
        int remaining;

        Parent(Node node, int remaining) {
            this.node = node;
            this.remaining = remaining;
        }
    }

    public String serialize(Node root) {
        if (root == null) return "";
        StringBuilder text = new StringBuilder();
        Deque<Node> stack = new ArrayDeque<>();
        stack.push(root);
        while (!stack.isEmpty()) {
            Node node = stack.pop();
            int count = node.children == null ? 0 : node.children.size();
            if (text.length() > 0) text.append(',');
            text.append(node.val).append(',').append(count);
            // 倒序入栈，确保第一个孩子先编码。
            if (count > 0) {
                ListIterator<Node> children = node.children.listIterator(count);
                while (children.hasPrevious()) stack.push(children.previous());
            }
        }
        return text.toString();
    }

    public Node deserialize(String data) {
        if (data.isEmpty()) return null;
        String[] tokens = data.split(",");
        Node root = null;
        Deque<Parent> parents = new ArrayDeque<>();
        for (int i = 0; i < tokens.length; i += 2) {
            Node node = new Node(Integer.parseInt(tokens[i]), new ArrayList<>());
            int count = Integer.parseInt(tokens[i + 1]);
            if (parents.isEmpty()) {
                root = node;
            } else {
                Parent parent = parents.peek();
                parent.node.children.add(node);
                if (--parent.remaining == 0) parents.pop();
            }
            if (count > 0) parents.push(new Parent(node, count));
        }
        return root;
    }
}
```

### Python

Python 用迭代器每次消费 value、count 两个字段。parents 的栈顶记录当前要填的位置，弹出后若还有余位就放回，再决定是否为新节点入栈。空串是空树编码，与值为零的单节点可清楚区分。

#### 按节点剩余名额还原父子关系

| 步骤 | 当前状态 | 判断依据 |
| --- | --- | --- |
| 先序写出记录 | 节点与孩子数依次为 (7,2)、(2,0)、(9,1)、(4,0) | 倒序压栈确保孩子 2 先于 9 编码。 |
| 给根分配孩子 | 7 接 2 后余 1 位，接 9 后余 0 位 | 根 7 现在已经配满。 |
| 把 4 接给 9 | 9 的待接数从 1 变成 0 | 根的名额已经耗尽，所以 4 不会成为根的第三个孩子。 |

```python
class Codec:
    def serialize(self, root: "Node") -> str:
        if root is None:
            return ""
        tokens, stack = [], [root]
        while stack:
            node = stack.pop()
            children = node.children or []
            tokens.extend((str(node.val), str(len(children))))
            stack.extend(reversed(children))
        return ",".join(tokens)

    def deserialize(self, data: str) -> "Node":
        if not data:
            return None
        tokens = iter(data.split(","))
        root, parents = None, []
        for value in tokens:
            count = int(next(tokens))
            node = Node(int(value), [])
            if parents:
                parent, remaining = parents.pop()
                parent.children.append(node)
                # 尚有孩子时保留父节点，下一层处理完还会回到这里。
                if remaining > 1:
                    parents.append((parent, remaining - 1))
            else:
                root = node
            if count:
                parents.append((node, count))
        return root
```

### 面试追问

**同值节点是否会混淆？** 父子关系由先序位置及孩子数确定，节点值无需唯一。两个相同值会分别构造两个节点对象。

### 复杂度

n 个节点、串长 L。时间 O(L)，编码缓冲及分词占 O(L)。编码时待访问节点最多 O(n)，解码时祖先栈最多 O(h)，h 为树高。

每个节点只编码解码一次，数字文本的读取和写入总量为 L。宽树可让编码工作栈存很多兄弟，解码栈则只沿尚未配满的祖先延伸。
