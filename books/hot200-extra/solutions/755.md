# 755. 倒水

### 题意

每滴水从下标 k 落下，优先流向左侧可达的更低处，其次向右，否则留在原位，求最终高度。

### 输入与约束

输入一维高度数组、非负水量和合法投放下标 k，按一滴一滴的顺序更新高度。可沿平台前进寻找低处，优先向左。

### 示例

高度 [2,1,2]，从最左边倒两滴。第一滴填平中间，第二滴停在起点，结果 [3,2,2]。

### 核心不变量

每次增高前，i 已在当前地形上完成可达性及等高回退检查；已落下的每滴水只使一个位置增高一单位。

### 思路

在不越过高坡的条件下寻找落点。可以横穿平台找更低处；若所有可达位置等高，水仍落在距起点应选的最近位置。

把一滴水的可达范围画成不升高的路径。左侧先遇到的低谷优先；若谷底是平台，应该回到平台上靠近投放点的一端。代码先向左探，再向右，最后把越过 k 的等高偏移收回来。加一改变了地形，下一滴必须依据新高度继续定位。

### 边界检查

一滴水的移动取决于本滴落下前的高度。遇到平台，要沿着平台继续找更低的位置；如果整侧都没有更低处，就不能把水留在远处的等高格。

### 反例推演

地形 [2,1,1,2]，从下标 3 倒一滴，落到下标 2。两个低点等高时应选离落水点较近者；扫到同高度就更新候选会误选下标 1。

### Java

Java 用 i 记录上一滴的落点。三段 while 处理向左探底、向右找到可停位置和消除右侧平台的多走步数；只有这一整套移动完成，才修改 heights[i]。

#### 两滴水怎样选择不同落点

| 步骤 | 当前状态 | 判断依据 |
| --- | --- | --- |
| 探测第一滴 | [2,1,2]，k=0；从 0 到 1，高度 2→1 | 可下坡，继续到 2 则会爬坡。 |
| 填平低谷 | i=1，高度变为 [2,2,2] | 第一滴只抬高实际落点。 |
| 放第二滴 | 等高平台回到 k=0，结果 [3,2,2] | 左右都无更低处，留在起点。 |

```java
import java.util.*;

class Solution {
    public int[] pourWater(int[] heights, int volume, int k) {
        int i = k;

        // 每滴水先尝试向左寻找低处，再向右，等高处不应无故远移。
        while (volume-- > 0) {
            while (i > 0 && heights[i] >= heights[i - 1]) --i;
            while (i + 1 < heights.length && heights[i] >= heights[i + 1]) ++i;
            while (i > k && heights[i] == heights[i - 1]) --i;
            ++heights[i];
        }

        return heights;
    }
}
```

### Python

Python 的比较使用 >=，因此允许经过等高格。最后向左退只在 i>k 且相邻两格等高时发生；如果已经在 k 的左侧低谷，程序不会为了回到投放点而爬坡。

#### 两滴水怎样选择不同落点

| 步骤 | 当前状态 | 判断依据 |
| --- | --- | --- |
| 探测第一滴 | [2,1,2]，k=0；从 0 到 1，高度 2→1 | 可下坡，继续到 2 则会爬坡。 |
| 填平低谷 | i=1，高度变为 [2,2,2] | 第一滴只抬高实际落点。 |
| 放第二滴 | 等高平台回到 k=0，结果 [3,2,2] | 左右都无更低处，留在起点。 |

```python
from __future__ import annotations


class Solution:
    def pourWater(self, heights: list[int], volume: int, k: int) -> list[int]:
        i = k

        # 每滴水先尝试向左寻找低处，再向右，等高处不应无故远移。
        while volume > 0:
            volume -= 1
            while i > 0 and heights[i] >= heights[i - 1]:
                i -= 1
            while i + 1 < len(heights) and heights[i] >= heights[i + 1]:
                i += 1
            while i > k and heights[i] == heights[i - 1]:
                i -= 1
            heights[i] += 1

        return heights
```

### 面试追问

**为什么不能把所有水一次加在初始最低处？** 每滴水都会改变可达的坡面。示例第一滴填平中间后，第二滴已经找不到更低处，落点随之改变。

### 复杂度

n 个位置、v 滴水；时间 O(nv)，辅助空间 O(1)。

一滴水至多做常数趟长度 n 的左右扫描，共 v 滴；高度直接写回输入，额外只有几个下标。
