# 320. 列举单词的全部缩写


### 题意

返回把任意若干段连续字母替换为其长度后得到的全部规范缩写。

### 输入与约束

输入为仅含字母的单词，每个字母可保留或省略，连续省略合并为十进制长度。返回全部缩写，次序不限。

### 示例

ab 有四种选择：两个都保留得到 ab，只留 a 得 a1，只留 b 得 1b，全部省略得 2。

### 核心不变量

进入第 i 个字符前，已确定的片段与末尾未输出的 count 合起来恰好编码了前 i 个字符的决策。

### 思路

回溯在每个字母处分支。省略时只增加未写出的计数，保留时才将计数和字母写出；到终点写出剩余计数，避免把同一段拆成相邻数字。

每个位置只有保留或省略两种选择，困难在于把连续的省略写成同一个数。令 count 表示“路径末端还没写出来的连续省略数”，这样省略只累加，遇到字母才结清，不会让同一段出现多个表示。

#### 两个字母的四种叶子

| 步骤 | 当前状态 | 为什么这样走 |
| --- | --- | --- |
| 两字都省略 | ab → i=2，count=2，写出 2 | 连续省略只结算一次。 |
| 省略后保留 | 先省 a，再保留 b，写出 1b | 保留字母前先写未结算的 1。 |
| 保留首字母 | 先写 a，次字母可省可留，得到 a1、ab | 四个叶子覆盖全部二元选择。 |

### 边界检查

连续省略的字母共用一个数字。例如两个字符都省略应写成 2。只有遇到保留字母或到达词尾时，才输出累计的省略数。

### Java

#### 复用 StringBuilder 并恢复长度

`StringBuilder` 由整棵搜索树共用，保留分支和叶子处都先记录长度，写完后 setLength 恢复。已有字符及 count 完整描述了前 i 个位置的选择。

```java
import java.util.*;

class Solution {
    public List<String> generateAbbreviations(String word) {
        List<String> ans = new ArrayList<>();
        dfs(word, 0, 0, new StringBuilder(), ans);
        return ans;
    }

    private void dfs(final String word, int i, int count, StringBuilder sb, List<String> ans) {
        // 到达末尾要写出尚未结算的省略长度。
        if (i == word.length()) {
            final int length = sb.length();
            ans.add(sb.append(getCountString(count)).toString());
            sb.setLength(length);
            return;
        }

        dfs(word, i + 1, count + 1, sb, ans);

        final int length = sb.length();

        dfs(word, i + 1, 0, sb.append(getCountString(count)).append(word.charAt(i)), ans);
        sb.setLength(length);
    }

    private String getCountString(int count) {
        return count > 0 ? String.valueOf(count) : "";
    }
}
```

### Python

#### 列表路径何时写入与弹出

`path` 存已确定的文字片段。省略分支无需改 path，保留分支把待写计数与字母打包成一项，递归返回只 pop 一次，叶子才 join 成最终答案。

```python
from __future__ import annotations


class Solution:
    def generateAbbreviations(self, word: str) -> list[str]:
        ans = []

        def getCountString(count: int) -> str:
            return str(count) if count > 0 else ""

        def dfs(i: int, count: int, path: list[str]) -> None:
            # 到达末尾要写出尚未结算的省略长度。
            if i == len(word):
                ans.append("".join(path) + getCountString(count))
                return

            dfs(i + 1, count + 1, path)

            path.append(getCountString(count) + word[i])

            dfs(i + 1, 0, path)
            path.pop()

        dfs(0, 0, [])
        return ans
```

### 复杂度

时间与输出总量上界 O(n·2ⁿ)，递归与路径额外空间 O(n)。

二叉搜索树有 2ⁿ 个叶子，复制一个答案最多需要 n 个字符。共享路径和递归层数最多 n。

### 面试追问

**为什么正好有 2ⁿ 个结果？** 每个位置都可独立选保留或省略，结果里的字母及每段跳过长度又能反推出这些选择，故不同选择不会形成同一结果。
