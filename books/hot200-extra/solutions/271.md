# 271. 字符串的编码与解码

### 题意

把字符串列表编码成单个字符串，随后无损解码，列表元素可以为空或含分隔符。

### 输入与约束

输入为字符串列表，元素可以为空或含分隔符。编码结果需在同一约定下无损恢复各项内容、个数与顺序。

### 示例

列表 `["a/b", ""]` 编为 `3/a/b0/`。第一个斜杠结束长度字段，随后固定读取三个字符，内部斜杠会被完整保留。

### 核心不变量

每次读长度字段时，游标恰指向下一项的首个长度数字，此前的项均已完整消费。

### 思路

每段先写十进制长度及分隔符，再写原串。解码只在读长度时找分隔符，正文按指定长度切取，因此空字符串和内部符号互不歧义。

编码要解决的是如何找出每一项的终点。只用分隔符会和正文里的相同字符冲突；先写长度后，解码器知道从下一个位置精确读取多少字符。长度字段和正文采用不同的读法，整个串可以从头到尾无歧义地切开。

### 边界检查

空列表和只含一个空串的列表是两个不同的输入。长度前缀可以把 `[]` 与 `[""]` 区分开，也允许原字符串本身含分隔符。

### 反例推演

列表 `["","a/b"]` 同时含空串和分隔符。解码先读长度，再原样消费指定个数的字符；按 / 全局切分无法区分正文与头部。

### Java

Java 将 String.length() 的长度和字符内容写入 StringBuilder，解码也用相同的 UTF-16 下标单位。indexOf('/',i) 只找长度后的分隔符；substring 取指定长度，游标直接移到下一项的长度字段。

#### 用长度字段越过正文内的斜杠

| 步骤 | 当前状态 | 判断依据 |
| --- | --- | --- |
| 编码两项 | a/b 的长度为 3，空串长 0；合并成 3/a/b0/ | 正文中的斜杠无需转义。 |
| 读第一项 | 第一个斜杠在下标 1，读取 [2,5) 的 a/b | 下标 3 的斜杠是正文，直接越过。 |
| 读第二项 | 从下标 5 读到长度 0，取得空串 | 游标到达末端，恢复两项列表。 |

```java
import java.util.*;

public class Codec {

    public String encode(List<String> strs) {
        StringBuilder encoded = new StringBuilder();

        // 每段先写长度，内容本身出现分隔符也不会影响解码。
        for (final String s : strs) encoded.append(s.length()).append('/').append(s);

        return encoded.toString();
    }

    public List<String> decode(String s) {
        List<String> decoded = new ArrayList<>();

        for (int i = 0; i < s.length(); ) {
            final int slash = s.indexOf('/', i);
            final int length = Integer.parseInt(s.substring(i, slash));
            i = slash + length + 1;
            decoded.add(s.substring(slash + 1, i));
        }

        return decoded;
    }
}
```

### Python

Python 用 len 和切片按 Python 字符串下标计数。s.find('/',i) 从项首找分隔符，空字符串的长度为零，切片为空但游标仍越过长度与斜杠，因此循环会前进。

#### 用长度字段越过正文内的斜杠

| 步骤 | 当前状态 | 判断依据 |
| --- | --- | --- |
| 编码两项 | a/b 的长度为 3，空串长 0；合并成 3/a/b0/ | 正文中的斜杠无需转义。 |
| 读第一项 | 第一个斜杠在下标 1，读取 [2,5) 的 a/b | 下标 3 的斜杠是正文，直接越过。 |
| 读第二项 | 从下标 5 读到长度 0，取得空串 | 游标到达末端，恢复两项列表。 |

```python
from __future__ import annotations


class Codec:
    def encode(self, strs: list[str]) -> str:

        # 每段先写长度，内容本身出现分隔符也不会影响解码。
        return "".join(str(len(s)) + "/" + s for s in strs)

    def decode(self, s: str) -> list[str]:

        decoded = []

        i = 0
        while i < len(s):
            slash = s.find("/", i)
            length = int(s[i:slash])
            i = slash + length + 1
            decoded.append(s[slash + 1 : i])

        return decoded
```

### 面试追问

**若由 Java 编码、Python 解码，长度天然一致吗？** 对基本多文种平面以外的字符，Java 的 UTF-16 单元数和 Python 的码点数可能不同。跨语言协议可统一到 UTF-8 字节数，再按字节读取正文。

### 复杂度

编码串长 L；编解码均 O(L) 时间，含结果空间 O(L)。

所有长度字段和正文按顺序读写，输出与解析总量均受编码长度 L 控制；正文切片复制计入返回结果空间。
