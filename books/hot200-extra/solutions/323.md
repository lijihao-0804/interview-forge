# 323. 无向图中连通分量的数目


### 题意

节点编号 0 到 n−1，按给出的无向边统计连通分量数，孤立点也算一个。

### 输入与约束

给出 n 个编号 0…n−1 的顶点与无向边列表。没有边的顶点也计为独立分量。

### 示例

n=5，边为 (0,2)、(2,4)、(1,3)，第一组搜索访问 0、2、4，第二组访问 1、3，共 2 个分量。

### 核心不变量

一次完整搜索结束时，其起点所在分量已全部标记，之后没有未访问顶点能再连到这整个分量。

### 思路

先构造双向邻接表。扫描顶点，每遇到一个未访问点就做一次 BFS，把整个分量都标记，这次搜索贡献一个分量。

连通性是等价关系。若从未访问顶点 u 出发搜尽所有可到顶点，这些顶点便属于一个完整分量，后续遇到其中任意一点都不能重新计数。无向边必须双向登记，否则可达性会受起点方向影响。

#### 两次搜索覆盖五个顶点

| 步骤 | 当前状态 | 为什么这样走 |
| --- | --- | --- |
| 从顶点 0 启动 | 沿 0—2—4 标记 {0,2,4}，ans=1 | 它们能互相走到，整组只计一次。 |
| 从顶点 1 启动 | 沿 1—3 标记 {1,3}，ans=2 | 1 尚未访问，属于另一个分量。 |
| 结束扫描 | 编号 2、3、4 均已访问，返回 2 | 外层后续检查不重复启动。 |

### 边界检查

没有任何边的顶点也各自构成一个连通分量。按全部 n 个顶点启动检查，而非只遍历邻接表中曾作为边端点的键。

### Java

#### 按编号建邻接表并逐点启动

邻接表数组为所有编号建空列表，孤立点也能启动一次 BFS。入队便放进 seen，所以多条边通向同一顶点时该顶点只会排队一次。

```java
import java.util.*;

class Solution {
    public int countComponents(int n, int[][] edges) {
        int ans = 0;
        List<Integer>[] graph = new List[n];
        Set<Integer> seen = new HashSet<>();
        Arrays.setAll(graph, i -> new ArrayList<>());

        for (int[] edge : edges) {
            final int u = edge[0];
            final int v = edge[1];
            graph[u].add(v);
            graph[v].add(u);
        }

        // 从一个未访问点出发即可标记整个连通分量。
        for (int i = 0; i < n; ++i)
            if (!seen.contains(i)) {
                bfs(graph, i, seen);
                ++ans;
            }

        return ans;
    }

    private void bfs(List<Integer>[] graph, int node, Set<Integer> seen) {
        Queue<Integer> q = new ArrayDeque<>(List.of(node));
        seen.add(node);

        while (!q.isEmpty()) {
            final int u = q.poll();
            for (final int v : graph[u])
                if (!seen.contains(v)) {
                    q.offer(v);
                    seen.add(v);
                }
        }
    }
}
```

### Python

#### 从 deque 右侧取点也能遍历分量

虽然辅助函数叫 bfs，实际使用 deque.pop 从同一端取出，是深度优先搜索。计分量只关心能否遍历到，无需最短距离，因此这里的栈式遍历同样正确。

```python
from __future__ import annotations
import collections


class Solution:
    def countComponents(self, n: int, edges: list[list[int]]) -> int:
        ans = 0
        graph = [[] for _ in range(n)]
        seen = set()

        for u, v in edges:
            graph[u].append(v)
            graph[v].append(u)

        def bfs(node: int, seen: set[int]) -> None:
            q = collections.deque([node])
            seen.add(node)

            while q:
                u = q.pop()
                for v in graph[u]:
                    if v not in seen:
                        q.append(v)
                        seen.add(v)

        # 从一个未访问点出发即可标记整个连通分量。
        for i in range(n):
            if i not in seen:
                bfs(i, seen)
                ans += 1

        return ans
```

### 复杂度

时间和含邻接表的额外空间均 O(n+e)，e 为边数。

每个顶点标记一次，每条无向边在邻接表中出现两次。存储包括邻接表、seen 和待访问容器。

### 面试追问

**边一条条到达，每次都要返回新分量数呢？** 可从 n 个分量开始，用并查集合并新边两端；仅当两端原先属于不同根时把计数减一。
