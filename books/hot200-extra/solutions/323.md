# 323. 无向图中连通分量的数目


### 题意

节点编号 0 到 n−1，按给出的无向边统计连通分量数，孤立点也算一个。

### 示例

n=5，边为 (0,2)、(2,4)、(1,3)，第一组搜索访问 0、2、4，第二组访问 1、3，共 2 个分量。

### 思路

先构造双向邻接表。扫描顶点，每遇到一个未访问点就做一次 BFS，把整个分量都标记，这次搜索贡献一个分量。

### 边界检查

没有任何边的顶点也各自构成一个连通分量。按全部 n 个顶点启动检查，而非只遍历邻接表中曾作为边端点的键。

### Java

```java
import java.util.*;

class Solution {
    public int countComponents(int n, int[][] edges) {
        int ans = 0;
        List<Integer>[] graph = new List[n];
        Set<Integer> seen = new HashSet<>();
        Arrays.setAll(graph, i -> new ArrayList<>());

        for (int[] edge : edges) {
            final int u = edge[0];
            final int v = edge[1];
            graph[u].add(v);
            graph[v].add(u);
        }

        // 从一个未访问点出发即可标记整个连通分量。
        for (int i = 0; i < n; ++i)
            if (!seen.contains(i)) {
                bfs(graph, i, seen);
                ++ans;
            }

        return ans;
    }

    private void bfs(List<Integer>[] graph, int node, Set<Integer> seen) {
        Queue<Integer> q = new ArrayDeque<>(List.of(node));
        seen.add(node);

        while (!q.isEmpty()) {
            final int u = q.poll();
            for (final int v : graph[u])
                if (!seen.contains(v)) {
                    q.offer(v);
                    seen.add(v);
                }
        }
    }
}
```

### Python

```python
from __future__ import annotations
import collections


class Solution:
    def countComponents(self, n: int, edges: list[list[int]]) -> int:
        ans = 0
        graph = [[] for _ in range(n)]
        seen = set()

        for u, v in edges:
            graph[u].append(v)
            graph[v].append(u)

        def bfs(node: int, seen: set[int]) -> None:
            q = collections.deque([node])
            seen.add(node)

            while q:
                u = q.pop()
                for v in graph[u]:
                    if v not in seen:
                        q.append(v)
                        seen.add(v)

        # 从一个未访问点出发即可标记整个连通分量。
        for i in range(n):
            if i not in seen:
                bfs(i, seen)
                ans += 1

        return ans
```

### 复杂度

时间和含邻接表的额外空间均 O(n+e)，e 为边数。
