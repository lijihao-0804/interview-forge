# 356. 直线镜像


### 题意

判断平面点集是否关于某条竖直线镜像对称；相同坐标代表同一个点。

### 示例

[(1,0),(5,0),(3,2)] 的左右极值和为 6，各点关于 x=3 都有对应点。删去 (5,0) 后剩下两点的纵坐标不同，无法互为镜像。

### 思路

若对称轴存在，它必经过最左与最右横坐标的中点。无需浮点数，对每个 (x,y) 在集合中查找 (minX+maxX−x,y) 即可。

### 边界检查

纵坐标保持不变，横坐标 x 的镜像是 `minX + maxX − x`。用这一表达式可以直接查整点，避免镜像轴是半整数时引入浮点误差。

### Java

```java
import java.util.*;

class Solution {
    public boolean isReflected(int[][] points) {
        int minX = Integer.MAX_VALUE;
        int maxX = Integer.MIN_VALUE;
        Set<String> seen = new HashSet<>();

        for (int[] p : points) {
            final int x = p[0];
            final int y = p[1];
            minX = Math.min(minX, x);
            maxX = Math.max(maxX, x);
            seen.add(x + "," + y);
        }

        // 最左与最右横坐标之和等于对称轴横坐标的两倍。
        final int sum = minX + maxX;

        for (int[] p : points) if (!seen.contains(sum - p[0] + "," + p[1])) return false;

        return true;
    }
}
```

### Python

```python
from __future__ import annotations
import math


class Solution:
    def isReflected(self, points: list[list[int]]) -> bool:
        minX = math.inf
        maxX = -math.inf
        seen = set()

        # 最左与最右横坐标之和等于对称轴横坐标的两倍。
        for x, y in points:
            minX = min(minX, x)
            maxX = max(maxX, x)
            seen.add((x, y))

        summ = minX + maxX

        return all((summ - x, y) in seen for x, y in points)
```

### 复杂度

哈希查询平均时间 O(n)，空间 O(n)。
