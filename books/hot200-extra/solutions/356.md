# 356. 直线镜像


### 题意

判断平面点集是否关于某条竖直线镜像对称；相同坐标代表同一个点。

### 输入与约束

输入为平面整数点坐标，判定是否存在一条竖直对称轴。相同坐标按同一个点处理。

### 示例

[(1,0),(5,0),(3,2)] 的左右极值和为 6，各点关于 x=3 都有对应点。删去 (5,0) 后剩下两点的纵坐标不同，无法互为镜像。

### 核心不变量

固定横坐标极值和后，通过检查的每个点，其唯一可能镜像 (minX+maxX−x,y) 都在集合里。

### 思路

若对称轴存在，它必经过最左与最右横坐标的中点。无需浮点数，对每个 (x,y) 在集合中查找 (minX+maxX−x,y) 即可。

若存在竖直镜像，最左横坐标必被映到最右横坐标，否则更靠右的点就没有对应原像。因此只可能有一条候选轴。把横坐标极值之和当作两倍轴位置，便能在整数坐标内逐点验证。

#### 用两倍轴值 6 查三个点

| 步骤 | 当前状态 | 为什么这样走 |
| --- | --- | --- |
| 由极值定轴 | minX=1，maxX=5，两倍轴值为 6 | 左端与右端必须互为镜像。 |
| 配对轴外两点 | (1,0) 寻找 (5,0)，反向也存在 | 两点纵坐标相同，横坐标和为 6。 |
| 检查轴上点 | (3,2) 寻找 (3,2)，返回 true | 轴上点是自身的镜像。 |

### 边界检查

纵坐标保持不变，横坐标 x 的镜像是 `minX + maxX − x`。用这一表达式可以直接查整点，避免镜像轴是半整数时引入浮点误差。

### Java

#### 把横纵坐标一起存入集合

`HashSet<String>` 用带逗号的键保存整对坐标；只记录 x 会把在不同行的点错误配对。先完成极值扫描，再用同一个 sum 对所有点检查。

```java
import java.util.*;

class Solution {
    public boolean isReflected(int[][] points) {
        int minX = Integer.MAX_VALUE;
        int maxX = Integer.MIN_VALUE;
        Set<String> seen = new HashSet<>();

        for (int[] p : points) {
            final int x = p[0];
            final int y = p[1];
            minX = Math.min(minX, x);
            maxX = Math.max(maxX, x);
            seen.add(x + "," + y);
        }

        // 最左与最右横坐标之和等于对称轴横坐标的两倍。
        final int sum = minX + maxX;

        for (int[] p : points) if (!seen.contains(sum - p[0] + "," + p[1])) return false;

        return true;
    }
}
```

### Python

#### 用元组测试镜像对应关系

set 保存 `(x,y)` 元组，`all` 在第一个找不到镜像点时停止。轴上的点映回自己，只要原集合里有它就通过。

```python
from __future__ import annotations
import math


class Solution:
    def isReflected(self, points: list[list[int]]) -> bool:
        minX = math.inf
        maxX = -math.inf
        seen = set()

        # 最左与最右横坐标之和等于对称轴横坐标的两倍。
        for x, y in points:
            minX = min(minX, x)
            maxX = max(maxX, x)
            seen.add((x, y))

        summ = minX + maxX

        return all((summ - x, y) in seen for x, y in points)
```

### 复杂度

哈希查询平均时间 O(n)，空间 O(n)。

两遍线性扫描分别建集合和查镜像。集合查询平均为常数时间，每个不同坐标只需一个键。

### 面试追问

**相同点出现两次，另一侧只出现一次怎么办？** 本题按点集判定，重复坐标没有新身份。若要求多重集对称，则需用频数表比较每对镜像坐标的出现次数。
