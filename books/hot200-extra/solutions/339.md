# 339. 嵌套列表加权和


### 题意

给定由整数和子列表组成的嵌套列表，计算每个整数乘所在深度后的总和，最外层深度为 1。

### 示例

[2,[3,[4]]] 的贡献依次为 2×1、3×2、4×3，总和 20。

### 思路

队列的每一批正好是一层。整数直接乘当前层数，子列表的元素入队留给下一层；使用题目提供的 NestedInteger 类型访问元素。

### 边界检查

顶层整数的深度是 1。进入下一层嵌套才增加深度，列表本身不产生加权项，空列表也不应增加总和。

### Java

```java
import java.util.*;

class Solution {
    public int depthSum(List<NestedInteger> nestedList) {
        int ans = 0;
        int depth = 0;
        Queue<NestedInteger> q = new ArrayDeque<>();

        addIntegers(q, nestedList);

        // 每批恰是一层，当前深度就是这一批整数的权重。
        while (!q.isEmpty()) {
            ++depth;
            for (int sz = q.size(); sz > 0; --sz) {
                final NestedInteger ni = q.poll();
                if (ni.isInteger()) ans += ni.getInteger() * depth;
                else addIntegers(q, ni.getList());
            }
        }

        return ans;
    }

    private void addIntegers(Queue<NestedInteger> q, List<NestedInteger> nestedList) {
        for (final NestedInteger ni : nestedList) q.offer(ni);
    }
}
```

### Python

```python
from __future__ import annotations
import collections


class Solution:
    def depthSum(self, nestedList: list[NestedInteger]) -> int:
        ans = 0
        depth = 0
        q = collections.deque()

        def addIntegers(nestedList: list[NestedInteger]) -> None:
            for ni in nestedList:
                q.append(ni)

        addIntegers(nestedList)

        # 每批恰是一层，当前深度就是这一批整数的权重。
        while q:
            depth += 1
            for _ in range(len(q)):
                ni = q.popleft()
                if ni.isInteger():
                    ans += ni.getInteger() * depth
                else:
                    addIntegers(ni.getList())

        return ans
```

### 复杂度

时间 O(N)，队列空间 O(W)，N 为整数和列表节点总数，W 为最宽层级的规模。
