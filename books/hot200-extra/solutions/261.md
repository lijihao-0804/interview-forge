# 261. 以图判树

### 题意

判断 n 个顶点和给定无向边是否恰好组成一棵树。

### 输入与约束

顶点编号 0 到 n−1，边为无向边，按题设无自环与重复边。判断全部顶点和全部边能否组成一棵树。

### 示例

四个顶点的边为 (0,1)、(1,2)、(2,0)，边数虽然为 3，顶点 3 没连入，所以不是树。

### 核心不变量

边数等于 n−1 后，只要从 0 出发的搜索能覆盖 n 个顶点，原图就已经是一棵树。

### 思路

树有 n−1 条边且连通。先检查边数，再从一个点遍历；若不是所有点可达，说明图分裂成多个分量。

无向树要同时满足连通、无环。n 个顶点的连通图至少需要 n−1 条边；若恰好 n−1 条且已连通，就不可能再有形成环的多余边。因此先查边数，再做一次从任一顶点出发的可达性检查即可。

### 边界检查

`n−1` 条边是必要条件，还应检查连通性。例如三个顶点成环、另一个孤立，边数正确但走不到第四个顶点。

### Java

Java 初始化每个顶点的邻接表，再把每条无向边分别登记到两个端点。以 0 入队，用 Set 记录发现的节点；最后比 seen.size() 与 n，孤立点即使没出现在边里也会被检测。

#### 区分边数满足与全图连通

| 步骤 | 当前状态 | 判断依据 |
| --- | --- | --- |
| 检查数量 | n=4，3 条边，满足 n−1=3 | 边数判定通过，还需验证连通。 |
| 从 0 搜索 | 0 连到 1、2，seen={0,1,2} | 1、2 的其余邻居都已访问。 |
| 核对顶点数 | 队列为空，已访问 3<4；顶点 3 缺失 | 图不连通，返回 false。 |

```java
import java.util.*;

class Solution {
    public boolean validTree(int n, int[][] edges) {
        // 先验证边数，再验证连通性；仅检查其中一项不能判树。
        if (n == 0 || edges.length != n - 1) return false;

        List<Integer>[] graph = new List[n];
        Queue<Integer> q = new ArrayDeque<>(List.of(0));
        Set<Integer> seen = new HashSet<>(Arrays.asList(0));
        Arrays.setAll(graph, i -> new ArrayList<>());

        for (int[] edge : edges) {
            final int u = edge[0];
            final int v = edge[1];
            graph[u].add(v);
            graph[v].add(u);
        }

        while (!q.isEmpty()) {
            final int u = q.poll();
            for (final int v : graph[u])
                if (!seen.contains(v)) {
                    q.offer(v);
                    seen.add(v);
                }
        }

        return seen.size() == n;
    }
}
```

### Python

Python 以 deque 对 graph 做广度遍历，通过 seen 防止重复入队；边数测试在构图之前完成。n=1 且无边时，唯一顶点自身已经构成一棵树。

#### 区分边数满足与全图连通

| 步骤 | 当前状态 | 判断依据 |
| --- | --- | --- |
| 检查数量 | n=4，3 条边，满足 n−1=3 | 边数判定通过，还需验证连通。 |
| 从 0 搜索 | 0 连到 1、2，seen={0,1,2} | 1、2 的其余邻居都已访问。 |
| 核对顶点数 | 队列为空，已访问 3<4；顶点 3 缺失 | 图不连通，返回 false。 |

```python
from __future__ import annotations
import collections


class Solution:
    def validTree(self, n: int, edges: list[list[int]]) -> bool:
        # 先验证边数，再验证连通性；仅检查其中一项不能判树。
        if n == 0 or len(edges) != n - 1:
            return False

        graph = [[] for _ in range(n)]
        q = collections.deque([0])
        seen = {0}

        for u, v in edges:
            graph[u].append(v)
            graph[v].append(u)

        while q:
            u = q.popleft()
            for v in graph[u]:
                if v not in seen:
                    q.append(v)
                    seen.add(v)

        return len(seen) == n
```

### 面试追问

**只检查边数会接受什么错误输入？** 示例的三个点组成环，另一点孤立。环多出的一条边刚好抵消了连接孤立点所缺的一条，边数却仍等于 n−1。

### 复杂度

V 个顶点、E 条边；时间 O(V+E)，空间 O(V+E)。

边数不等立即结束；通过后边数就是 n−1。邻接表每条边放两次，遍历每点每边常数次，时间空间均为 O(n)。
