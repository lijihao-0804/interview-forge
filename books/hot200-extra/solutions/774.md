# 774. 最小化去加油站的最大距离

### 题意

在已排序的加油站间再安置 k 个站，最小化相邻站之间的最大距离，允许实数位置。

### 示例

两站位于 0 和 9，新增两站可放在 3、6，最大间隔 3；想小于 3 就必须增加第三个站。

### 思路

尝试距离上限 d。长度 g 的间隔需增加 ceil(g/d)−1 个站。所需总数随 d 增大而不增，二分找到可行与不可行的交界；整除时无需多放一个站。

### 边界检查

在长度恰为 9 的间隔中把上限设为 3，需要新增两站，不能按 9÷3 算成三站。这个整除边界决定二分可行性谓词的方向。

### Java

```java
import java.util.*;

class Solution {
    public double minmaxGasDist(int[] stations, int k) {
        final double ERR = 1e-6;
        double l = 0;
        double r = stations[stations.length - 1] - stations[0];

        // 上界保持可行，间隔越小需要补的站越多。
        while (r - l > ERR) {
            final double m = (l + r) / 2;
            if (check(stations, k, m)) r = m;
            else l = m;
        }

        return r;
    }

    private boolean check(int[] stations, int k, double m) {
        for (int i = 1; i < stations.length; ++i) {
            final int diff = stations[i] - stations[i - 1];
            if (diff > m) {
                k -= Math.ceil(diff / m) - 1;
                if (k < 0) return false;
            }
        }
        return true;
    }
    ;
}
```

### Python

```python
from __future__ import annotations
import math


class Solution:
    def minmaxGasDist(self, stations: list[int], k: int) -> float:
        ERR = 1e-6
        l = 0
        r = stations[-1] - stations[0]

        def possible(k: int, m: float) -> bool:

            for a, b in zip(stations, stations[1:]):
                diff = b - a
                if diff > m:
                    k -= math.ceil(diff / m) - 1
                    if k < 0:
                        return False
            return True

        # 上界保持可行，间隔越小需要补的站越多。
        while r - l > ERR:
            m = (l + r) / 2
            if possible(k, m):
                r = m
            else:
                l = m

        return r
```

### 复杂度

n 个站、初始跨度 D、精度 ε；时间 O(n log(D/ε))，辅助空间 O(1)。
