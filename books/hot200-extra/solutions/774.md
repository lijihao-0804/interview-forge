# 774. 最小化去加油站的最大距离

### 题意

在已排序的加油站间再安置 k 个站，最小化相邻站之间的最大距离，允许实数位置。

### 输入与约束

站点坐标已按严格递增顺序给出，允许在相邻位置之间加入 k 个站，可取实数位置，返回最小可能的最大相邻距离。

### 示例

两站位于 0 和 9，新增两站可放在 3、6，最大间隔 3；想小于 3 就必须增加第三个站。

### 核心不变量

r 始终可行，l 为不可行侧的下界；距离限制增大时，各段所需新增站数均不会增加。

### 思路

尝试距离上限 d。长度 g 的间隔需增加 ceil(g/d)−1 个站。所需总数随 d 增大而不增，二分找到可行与不可行的交界；整除时无需多放一个站。

直接枚举新站坐标是连续优化，改问一个可判定的问题：最长段若限为 d，现有每段需要几个新站？长 g 的区间至少要被切成 ceil(g/d) 段，均分就能达到，所以所需站数精确为该段数减一。各段独立求和得到单调可行性谓词。

### 边界检查

在长度恰为 9 的间隔中把上限设为 3，需要新增两站，不能按 9÷3 算成三站。这个整除边界决定二分可行性谓词的方向。

### Java

Java 以 double 保存 l、r、m，check 逐段扣除所需站数，一旦预算不足立即结束。每轮把可行中点记入 r，最后返回 r，保证输出边界始终来自可实现的距离上限。

#### 检查距离 4.5、2.25 与 3 的站数预算

| 步骤 | 当前状态 | 判断依据 |
| --- | --- | --- |
| 首次测试中点 | 区间 [0,9]，d=4.5；需 1 站，预算 2，令 r=4.5 | 可行上界向下移动。 |
| 继续测试 | d=2.25；需 3 站，超过预算，令 l=2.25 | 不可能再考虑更小距离。 |
| 确定分界 | d=3 时需 2 站；任何 d<3 都至少需 3 站 | 在 3、6 放站使三段长度均为 3，二分收敛到该值。 |

```java
import java.util.*;

class Solution {
    public double minmaxGasDist(int[] stations, int k) {
        final double ERR = 1e-6;
        double l = 0;
        double r = stations[stations.length - 1] - stations[0];

        // 上界保持可行，间隔越小需要补的站越多。
        while (r - l > ERR) {
            final double m = (l + r) / 2;
            if (check(stations, k, m)) r = m;
            else l = m;
        }

        return r;
    }

    private boolean check(int[] stations, int k, double m) {
        for (int i = 1; i < stations.length; ++i) {
            final int diff = stations[i] - stations[i - 1];
            if (diff > m) {
                k -= Math.ceil(diff / m) - 1;
                if (k < 0) return false;
            }
        }
        return true;
    }
    ;
}
```

### Python

Python 的 math.ceil(diff/m)-1 负责整除边界。l 从零开始但不会拿零作除数，循环只测试正中点；当 r−l 不超过精度要求便停止，不比较浮点数是否恰好相等。

#### 检查距离 4.5、2.25 与 3 的站数预算

| 步骤 | 当前状态 | 判断依据 |
| --- | --- | --- |
| 首次测试中点 | 区间 [0,9]，d=4.5；需 1 站，预算 2，令 r=4.5 | 可行上界向下移动。 |
| 继续测试 | d=2.25；需 3 站，超过预算，令 l=2.25 | 不可能再考虑更小距离。 |
| 确定分界 | d=3 时需 2 站；任何 d<3 都至少需 3 站 | 在 3、6 放站使三段长度均为 3，二分收敛到该值。 |

```python
from __future__ import annotations
import math


class Solution:
    def minmaxGasDist(self, stations: list[int], k: int) -> float:
        ERR = 1e-6
        l = 0
        r = stations[-1] - stations[0]

        def possible(k: int, m: float) -> bool:

            for a, b in zip(stations, stations[1:]):
                diff = b - a
                if diff > m:
                    k -= math.ceil(diff / m) - 1
                    if k < 0:
                        return False
            return True

        # 上界保持可行，间隔越小需要补的站越多。
        while r - l > ERR:
            m = (l + r) / 2
            if possible(k, m):
                r = m
            else:
                l = m

        return r
```

### 面试追问

**如果只用 floor(g/d)，哪里会出错？** 当 g/d 为整数时，g/d 表示所需的小段数；中间插入的站比小段少一个。示例 g=9、d=3 只需要两站。

### 复杂度

n 个站、初始跨度 D、精度 ε；时间 O(n log(D/ε))，辅助空间 O(1)。

每次可行性检查扫 n−1 个间隔，二分将长度 D 缩到 ε 需要 O(log(D/ε)) 轮；预算与区间端点只占固定存储。
