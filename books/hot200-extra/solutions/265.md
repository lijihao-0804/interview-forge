# 265. 粉刷房子 II

### 题意

一排房子有 k 种颜色及各自成本，相邻房子不能同色，求最小总成本。

### 输入与约束

输入每间房对每种颜色的成本，选择可行着色使相邻颜色不同，返回总价最小值。颜色由列下标区分，即使成本相同也属于不同选择。

### 示例

两行成本 [2,2,9,8] 与 [1,6,5,2]。可先选第二色 2，再选第一色 1，答案 3。

### 核心不变量

处理新房前，prevMin1 与 prevMin2 是上行两个不同颜色下标的最低成本，prevIndex 指明第一项归属。

### 思路

上一行只保留最小和次小成本以及最小值所在颜色。当前颜色撞上最小值的颜色时用次小值；不同颜色成本相同仍可分别参与。

固定当前颜色 c 时，需要上一房所有异色成本的最小值。把每种颜色都与其余颜色比较需 O(k²)，但只排除一个颜色时，上一行最小值若不可用，唯一需要的替补就是另一颜色上的次小值。允许两值相等，关键是它们来自不同下标。

### 边界检查

若上一行最小成本出现两次，即使本次禁止其中一种颜色，另一种仍能提供同样的最小成本。要按颜色下标排除，不能只按数值排除。

### Java

Java 的 prevIndex 与 prevMin1、prevMin2 描述已经结束的上一行，index、min1、min2 单独构建本行。遇到新的最小值先将旧 min1 放到 min2，以免丢失备选；全行结束后才替换上一行状态。

#### 在最小值并列时替换末色

| 步骤 | 当前状态 | 判断依据 |
| --- | --- | --- |
| 记录首行 | [2,2,9,8]：最小值 2 在色 0，另一颜色的次小也为 2 | 保存两个不同颜色提供的成本。 |
| 试第二房色 0 | 当前收费 1，必须改用上行色 1 的 2，总计 3 | 恰好用到并列次小。 |
| 算齐第二行 | 四种末色为 [3,8,7,4]，最小为 3 | 其余三色均可接上行色 0 的 2。 |

```java
import java.util.*;

class Solution {
    public int minCostII(int[][] costs) {
        int prevIndex = -1;
        int prevMin1 = 0;
        int prevMin2 = 0;

        // 延续上一行的最小成本；若颜色相撞则改用次小成本。
        for (int[] cost : costs) {

            int index = -1;

            int min1 = Integer.MAX_VALUE;

            int min2 = Integer.MAX_VALUE;
            for (int i = 0; i < cost.length; ++i) {
                final int theCost = cost[i] + (i == prevIndex ? prevMin2 : prevMin1);
                if (theCost < min1) {
                    index = i;
                    min2 = min1;
                    min1 = theCost;
                } else if (theCost < min2) {
                    min2 = theCost;
                }
            }
            prevIndex = index;
            prevMin1 = min1;
            prevMin2 = min2;
        }

        return prevMin1;
    }
}
```

### Python

Python 选取 prevMin2 的条件是颜色下标与 prevIndex 相等。若两个不同颜色总价相同，第二个仍会通过 elif 更新 min2；这样禁止最优颜色时也可能保留相同最优代价。

#### 在最小值并列时替换末色

| 步骤 | 当前状态 | 判断依据 |
| --- | --- | --- |
| 记录首行 | [2,2,9,8]：最小值 2 在色 0，另一颜色的次小也为 2 | 保存两个不同颜色提供的成本。 |
| 试第二房色 0 | 当前收费 1，必须改用上行色 1 的 2，总计 3 | 恰好用到并列次小。 |
| 算齐第二行 | 四种末色为 [3,8,7,4]，最小为 3 | 其余三色均可接上行色 0 的 2。 |

```python
from __future__ import annotations
import math


class Solution:
    def minCostII(self, costs: list[list[int]]) -> int:
        prevIndex = -1
        prevMin1 = 0
        prevMin2 = 0

        # 延续上一行的最小成本；若颜色相撞则改用次小成本。
        for cost in costs:
            index = -1

            min1 = math.inf

            min2 = math.inf
            for i, cst in enumerate(cost):
                theCost = cst + (prevMin2 if i == prevIndex else prevMin1)
                if theCost < min1:
                    index = i
                    min2 = min1
                    min1 = theCost
                elif theCost < min2:
                    min2 = theCost

            prevIndex = index
            prevMin1 = min1
            prevMin2 = min2

        return prevMin1
```

### 面试追问

**为什么不能要求次小值严格大于最小值？** 示例上一行前两色成本都是 2。下一行选第一色时，换到第二色仍只需 2；跳过并列会误取 8。

### 复杂度

n 间房、k 种颜色；时间 O(nk)，辅助空间 O(1)。

每间房扫描 k 种末色并维护两个极值，故为 O(nk)。上一行仅保留两个值及一个下标，本行状态也是固定数量。
