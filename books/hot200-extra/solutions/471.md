# 471. 编码最短长度的字符串


### 题意

允许将重复子串写成次数加方括号的形式，括号内也可编码。求一个长度最短的等价表达式。

### 输入与约束

输入是非空小写字母串。重复编码为次数[子编码]，可嵌套，评价最终字符串字符数，返回任意最短等价结果。

### 示例

abababab 可写为 4[ab]，长度 5，比原串的 8 个字符短。若某段替换后没有缩短，保留原文即可。

### 核心不变量

区间结果在枚举中始终展开为原子串，候选只由已求最优的更短区间组合，最终覆盖全部外层结构。

### 思路

区间 DP 保存每段最短编码。一个最优解要么原样保留，要么从中间拼接两个最优编码，要么把某个周期的最优编码重复若干次；枚举切分与周期并取最短。

只压缩最长重复段是局部选择，可能错过两段拼接或重复单元内部的更短表示。看最外层结构：若有多个连续片段，就存在切分点；若是单个重复表达式，去掉外壳后是某个前缀的重复。把这两类都与原文比较，就是完整的区间递推。

#### 八字符周期串的三种表示

| 步骤 | 当前状态 | 为什么这样走 |
| --- | --- | --- |
| 先算重复单元 | dp(ab)=ab，dp(abab)=abab | 2[ab] 长 5，长度 4 的原文更短。 |
| 考察整段候选 | abababab 长 8，前缀 ab 重复 4 次完全覆盖 | 周期长 2 且 8 能整除 2。 |
| 比较编码长度 | 4[ab] 长 5，2[abab] 长 7，最短为 4[ab] | 对切分与其他周期一并比较后保存最短。 |

### 边界检查

最短编码可能有多个。例如十个 a 可写为 `10[a]` 或 `a9[a]`，两者都是五个字符。验算时既要检查长度，也要确认展开结果等于原串。

### Java

#### 缓存闭区间的编码字符串

`mem[i][j]` 保存闭区间最短编码。先试所有 k 的左右拼接，再试长度能整除整段、且确实覆盖全段的重复前缀。只在更短时写回，保留任一同长最优答案即可。

```java
class Solution {
    public String encode(String s) {
        final int n = s.length();
        String[][] mem = new String[n][n];
        return encode(s, 0, n - 1, mem);
    }

    private String encode(final String s, int i, int j, String[][] mem) {
        if (mem[i][j] != null) return mem[i][j];

        final String curr = s.substring(i, j + 1);
        mem[i][j] = curr;

        if (mem[i][j].length() < 5) return mem[i][j];

        // 先尝试按切分点拼接两段最优编码，再检查整段能否由周期重复构成。
        for (int k = i; k < j; ++k) {
            final String l = encode(s, i, k, mem);
            final String r = encode(s, k + 1, j, mem);
            if (l.length() + r.length() < mem[i][j].length()) mem[i][j] = l + r;
        }

        for (int k = i; k < j; ++k) {
            final String pattern = s.substring(i, k + 1);
            if (curr.length() % pattern.length() == 0 && curr.replaceAll(pattern, "").isEmpty()) {
                final String candidate =
                        String.valueOf(curr.length() / pattern.length())
                                + "["
                                + encode(s, i, k, mem)
                                + "]";
                if (candidate.length() < mem[i][j].length()) mem[i][j] = candidate;
            }
        }

        return mem[i][j];
    }
}
```

### Python

#### 用缓存函数压缩周期本身

`lru_cache` 按两端下标复用结果；比较 pattern * repeats == curr 核实每个重复位置。候选里嵌入 dp(i,k)，因此重复单元本身也能被递归压缩。

```python
from __future__ import annotations
import functools


class Solution:
    def encode(self, s: str) -> str:
        n = len(s)

        @functools.lru_cache(None)
        def dp(i: int, j: int) -> str:
            curr = s[i : j + 1]
            res = curr

            if len(res) < 5:
                return res

            # 先尝试按切分点拼接两段最优编码，再检查整段能否由周期重复构成。
            for k in range(i, j):
                l = dp(i, k)
                r = dp(k + 1, j)
                if len(l) + len(r) < len(res):
                    res = l + r

            for k in range(i, j):
                pattern = s[i : k + 1]
                if (
                    len(curr) % len(pattern) == 0
                    and pattern * (len(curr) // len(pattern)) == curr
                ):
                    candidate = f"{len(curr) // len(pattern)}[{dp(i, k)}]"
                    if len(candidate) < len(res):
                        res = candidate

            return res

        return dp(0, n - 1)
```

### 复杂度

由 n² 个区间枚举 O(n) 个切分或周期，每次字符串构造比较最多 O(n)，保守时间 O(n⁴)。缓存的编码总字符数上界 O(n³)。

二次方数量的区间各尝试线性数量的切分或周期，字符串构造与匹配还随区间长度增长。缓存中既有条目索引也有编码文本，后一项最坏可达三次方总字符。

### 面试追问

**长度不到 5 的子串为什么可以直接返回？** 最短重复形式如 2[a] 已占四个字符。对长度小于等于 4 的原文，即使可表示成重复，也不可能严格缩短。
