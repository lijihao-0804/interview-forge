# 第2题

> 来源：语雀「阿里真题题解」（已做 OCR 校对）

## 题目描述

在一条数轴上有 N 个机器人与 M 个充电桩，机器人与充电桩的位置均为整数。第 j 个充电桩可同时为至多 C_j 个机器人提供充电（容量可被多个机器人占用，彼此独立）。若某机器人与某充电桩的距离（两者位置差的绝对值）不超过某个整数阈值 E，则视为该机器人可以到达该充电桩充电。

请你最小化阈值 E，使得所有 N 个机器人都能被分配到某一充电桩，且不超过对应充电桩的容量限制。若无论如何分配都无法覆盖全部机器人，则输出 -1。

## 输入描述

每个测试文件包含多组测试数据。第一行输入整数 T（1 ≤ T ≤ 10）表示测试组数。每组数据格式如下：
- 第一行输入两个整数 N, M；（原文取值范围识别模糊）
- 第二行输入 N 个整数，表示 N 个机器人（扫地机器人）的位置；
- 第三行输入 M 个整数，表示 M 个充电桩的位置；
- 第四行输入 M 个整数 C_1, …, C_M，表示各充电桩的容量。

（原文取值范围识别严重缺失，仅大意为各位置与容量为非负整数。）

## 输出描述

对于每一组测试数据，新起一行。若无法覆盖全部机器人则输出 -1，否则输出一个整数，表示最小的阈值 E。

## 示例 1

输入：
```
2
2 2
1 5
2 6
1 1
3 2
0 10 20
5 15
1 1
```

输出：
```
1
-1
```

## 说明

第一组：取 E=1，可分配机器人 1→桩 2、机器人 5→桩 6，可行；无法取更小，故答案为 1。

第二组：所有充电桩总容量为 2 < 3（机器人数），无论 E 取何值都无法覆盖全部机器人，输出 -1。

（原文第二组数据首行 N、M 的数值缺失，此处“3 2”系据上下文推断；其余位置与容量数值为原文保留。）

```java
import java.io.*;
import java.util.*;

public class Solution {
    static int nR, mS;
    static long[] rpos, spos;
    static int[] scap;
    static List<Edge>[] g;
    static int[] level, iter;

    static class Edge {
        int to, rev, cap;
        Edge(int to, int rev, int cap) { this.to = to; this.rev = rev; this.cap = cap; }
    }

    static void addEdge(int f, int t, int c) {
        g[f].add(new Edge(t, g[t].size(), c));
        g[t].add(new Edge(f, g[f].size() - 1, 0));
    }

    static boolean bfs(int s, int t) {
        Arrays.fill(level, -1);
        ArrayDeque<Integer> q = new ArrayDeque<>();
        level[s] = 0; q.add(s);
        while (!q.isEmpty()) {
            int v = q.poll();
            for (Edge e : g[v]) {
                if (e.cap > 0 && level[e.to] < 0) {
                    level[e.to] = level[v] + 1;
                    q.add(e.to);
                }
            }
        }
        return level[t] >= 0;
    }

    static int dfs(int v, int t, int f) {
        if (v == t) return f;
        for (; iter[v] < g[v].size(); iter[v]++) {
            Edge e = g[v].get(iter[v]);
            if (e.cap > 0 && level[v] + 1 == level[e.to]) {
                int d = dfs(e.to, t, Math.min(f, e.cap));
                if (d > 0) { e.cap -= d; g[e.to].get(e.rev).cap += d; return d; }
            }
        }
        return 0;
    }

    static boolean feasible(long E) {
        int nodes = 1 + nR + mS + 1;
        int S = 0, T = nodes - 1;
        g = new List[nodes];
        for (int i = 0; i < nodes; i++) g[i] = new ArrayList<>();
        for (int i = 0; i < nR; i++) addEdge(S, 1 + i, 1);
        for (int j = 0; j < mS; j++) addEdge(1 + nR + j, T, scap[j]);
        for (int i = 0; i < nR; i++)
            for (int j = 0; j < mS; j++)
                if (Math.abs(rpos[i] - spos[j]) <= E) addEdge(1 + i, 1 + nR + j, 1);
        level = new int[nodes]; iter = new int[nodes];
        int flow = 0;
        while (bfs(S, T)) {
            Arrays.fill(iter, 0);
            int f;
            while ((f = dfs(S, T, Integer.MAX_VALUE)) > 0) {
                flow += f;
                if (flow >= nR) return true;
            }
        }
        return flow == nR;
    }

    public static void main(String[] args) throws IOException {
        StreamTokenizer in = new StreamTokenizer(new BufferedReader(new InputStreamReader(System.in)));
        in.nextToken(); int T = (int) in.nval;
        StringBuilder out = new StringBuilder();
        for (int tc = 0; tc < T; tc++) {
            in.nextToken(); nR = (int) in.nval;
            in.nextToken(); mS = (int) in.nval;
            rpos = new long[nR]; spos = new long[mS]; scap = new int[mS];
            for (int i = 0; i < nR; i++) { in.nextToken(); rpos[i] = (long) in.nval; }
            for (int j = 0; j < mS; j++) { in.nextToken(); spos[j] = (long) in.nval; }
            for (int j = 0; j < mS; j++) { in.nextToken(); scap[j] = (int) in.nval; }
            long totalCap = 0;
            for (int c : scap) totalCap += c;
            if (totalCap < nR) { out.append(-1).append('\n'); continue; }
            TreeSet<Long> set = new TreeSet<>();
            set.add(0L);
            for (int i = 0; i < nR; i++)
                for (int j = 0; j < mS; j++) set.add(Math.abs(rpos[i] - spos[j]));
            ArrayList<Long> list = new ArrayList<>(set);
            int lo = 0, hi = list.size() - 1, ansIdx = -1;
            while (lo <= hi) {
                int mid = (lo + hi) >>> 1;
                if (feasible(list.get(mid))) { ansIdx = mid; hi = mid - 1; }
                else lo = mid + 1;
            }
            out.append(ansIdx < 0 ? -1 : list.get(ansIdx)).append('\n');
        }
        System.out.print(out);
    }
}
```
