# 第1题

> 来源：语雀「阿里真题题解」（OCR 原文，可能存在识别误差）

给定一个正整数之.请在所有严格小于2的非负整数中,找到数位之和最大的那个数,并将这个数输出.
直观解释:把一个数写成十进制后,把每一位相办得到数位之村.我们要任(.:-1里找到数位之和尽可能大的那个数.如果有多个数位
之和同为最大值,输出其中任意一个即可.
输入描述
每个测试文件均包含多组测试数据.第一行输入一个整数工(1<2X10)表示数据组数;之后共工行:
每行输入一个正整数.(十进制,无前导零),其长度不超过2X10%;
.除此之外,保证单个测试文件内,所有2的数位长度之和不超过5X10%.
输出描述
对于每一组测试数据,输出一行,一个整数,表示答案.
输入
TEXT
3
10
1234
输出:
TEXT
6
999


思路与代码

遍历字符串x，对每个非零位，计算“该位减1、后续全9”的数位和，记录最大值位置。最后按位置构造答案并去除前导零，空结果补0。

import sys


dt = sys.stdin.read().split()
t = int(dt[0])
res = []


for k in range(1, t + 1):
    s = dt[k]
    n = len(s)
    mx_s = -1
    idx = -1
    p_sum = 0
    
    for i in range(n):
        if s[i] > '0':
            cur = p_sum + int(s[i]) - 1 + 9 * (n - 1 - i)
            if cur >= mx_s:
                mx_s = cur
                idx = i
        p_sum += int(s[i])
        
    ans = s[:idx] + str(int(s[idx]) - 1) + '9' * (n - 1 - idx)
    ans = ans.lstrip('0')
    res.append(ans if ans else '0')


sys.stdout.write('\n'.join(res) + '\n')
