# 第3题

> 来源：语雀「阿里真题题解」（OCR 原文，可能存在识别误差）

笨蛋同学来到了天才之国.她有N个想去的城市,编号为1,2,...N.
你知道两类距离信息:
从出发点到每个城市的距离
.从城市到城市的距离(不保证对称,也就是说和可能不同).
如果某个距离为-1,表示没有直接的路可以走.
笨蛋同学会从[出发点]出发,依次游历所有N个城市,并且满足:
离开出发点后,不会再回到出发点;
不会回到曾经去过的城市
市(每个城市最多去一次).
请你计算:游历完所有城市所需要走的最小总距离.如果无论怎么走都无法游历完全部城市,输出一1.


输入描述
第一行输入一个整数(16),表示城市数量.
第二行纷入.个整数山,山,4-134.6.<10%,
为正整数,表示距离.
此后:行,第行输入"个整数AU.93..40L-130L-13).表示认城市到城市到城市到城市到城市到城市到城市到城市到城市到城市到城市到城市到城市到城市到城市到城市到城市到城市到城市到城市到城市到城市
从城市值接到达城市J;否则为正整数,表示距离.
输出描述
输出一行一个整数,表示最小总距离;如果无法游历完全部城市,输出-1.
示例


输入

3

2 5 -1

0 2 4

-1 0 1

3 -1 0

输出

5

说明:
在这组数据中,笨蛋同学不能先去城市3(因为D3-1).
一种可行的游历方式是:出发点-1-2-3,对应的距离为山+A.2+2+2+2+1-5.


示例二

输入

2

-1 3

0 -1

-1 0

输出

-1

思路与代码

这是典型的状态压缩DP（旅行商问题）。用 f[mask][i] 表示已访问 mask 中节点、当前在 i 的最小代价，枚举状态转移，最终取所有节点都访问完的最小代价。
