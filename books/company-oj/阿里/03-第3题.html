题目描述

笨蛋同学来到了天才之国。她有 N 个想去的城市，编号为 1, 2, …, N。

已知两类距离信息： - 从出发点到每个城市的距离； - 从城市到城市的距离（不保证对称，也就是说 i→j 与 j→i 可能不同）。如果某个距离为 -1，表示没有直接的路可以走。

笨蛋同学会从出发点出发，依次游历所有 N 个城市，并且满足： - 离开出发点后，不会再回到出发点； - 不会回到曾经去过的城市（每个城市最多去一次）。

请你计算：游历完所有城市所需要走的最小总距离。如果无论怎么走都无法游历完全部城市，输出 -1。

输入描述

第一行输入一个整数 N（1 ≤ N ≤ 16），表示城市数量。

第二行输入 N 个整数，表示从出发点到各城市的距离；若为 -1 表示无直接道路，否则为正整数。

此后 N 行，第 i 行输入 N 个整数，表示从城市 i 直接到达城市 j 的距离；若为 -1 表示无直接道路，否则为正整数。（原文此处描述与部分数值有识别误差）

输出描述

输出一行一个整数，表示最小总距离；如果无法游历完全部城市，输出 -1。

示例 1

输入：

3
2 5 -1
0 2 4
-1 0 1
3 -1 0

输出：

5

说明

在这组数据中，笨蛋同学不能先去城市 3（因为从出发点到城市 3 的距离为 -1）。一种可行的游历方式是：出发点 → 1 → 2 → 3，对应距离为 2 + 2 + 1 = 5。

示例 2

输入：

2
-1 3
0 -1
-1 0

输出：

-1

解题思路

本题是带固定起点的旅行商问题（TSP）：从出发点依次游历全部城市、每城只去一次，求最短总距离。 由于 N ≤ 16，可用状态压缩 DP：dp[mask][last] 表示已访问城市集合为 mask、当前停留在城市 last 时的最小总距离。 初始化：dp[1<<i][i] = 出发点到城市 i 的距离（若为 −1 表示不可直达，则不初始化）。 转移：枚举未访问且从 last 有直接道路的城市 nxt，用 dp[mask][last] + d[last][nxt] 更新 dp[mask | 1<<nxt][nxt]。 最终答案为对所有 last 取 dp[(1<<N)−1][last] 的最小值；若仍为无穷大则输出 −1。

复杂度分析

  • 时间复杂度：O(2^N · N²)，状态 O(2^N·N)，每个状态枚举 O(N) 个后继。
  • 空间复杂度：O(2^N · N)，DP 表大小。

解题代码

import java.io.*;
import java.util.*;

public class Solution {
    public static void main(String[] args) throws IOException {
        StreamTokenizer in = new StreamTokenizer(new BufferedReader(new InputStreamReader(System.in)));
        in.nextToken(); int N = (int) in.nval;
        int[] start = new int[N];
        for (int i = 0; i < N; i++) { in.nextToken(); start[i] = (int) in.nval; }
        int[][] d = new int[N][N];
        for (int i = 0; i < N; i++)
            for (int j = 0; j < N; j++) { in.nextToken(); d[i][j] = (int) in.nval; }
        int full = 1 << N;
        long INF = Long.MAX_VALUE / 4;
        long[][] dp = new long[full][N];
        for (long[] row : dp) Arrays.fill(row, INF);
        for (int i = 0; i < N; i++) if (start[i] != -1) dp[1 << i][i] = start[i];
        for (int mask = 1; mask < full; mask++) {
            for (int last = 0; last < N; last++) {
                if (dp[mask][last] >= INF) continue;
                for (int nxt = 0; nxt < N; nxt++) {
                    if ((mask & (1 << nxt)) != 0) continue;
                    if (d[last][nxt] == -1) continue;
                    int nm = mask | (1 << nxt);
                    long cand = dp[mask][last] + d[last][nxt];
                    if (cand < dp[nm][nxt]) dp[nm][nxt] = cand;
                }
            }
        }
        long ans = INF;
        for (int last = 0; last < N; last++) ans = Math.min(ans, dp[full - 1][last]);
        System.out.println(ans >= INF ? -1 : ans);
    }
}
