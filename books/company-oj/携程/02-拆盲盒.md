# 拆盲盒

> 来源：语雀「携程真题题解」（已做 OCR 校对，原文损坏严重，题意只能部分还原）

## 题目描述

给定一个正整数 N 与一个正整数 M。需要把 N 拆分为若干个素数之和（素数：大于 1 且只有 1 与其本身两个正因子的整数），并满足：所选素数中奇素数（除 2 以外的素数）的数量必须为 M。（原文约束表述模糊）

在满足约束的前提下，使所选素数的数量最大化，并输出这个最大的数量；若不存在任何满足要求的拆分方案，输出 -1。

## 输入描述

每个测试文件包含多组测试数据。第一行输入一个整数 T（1 ≤ T ≤ 10）表示测试数据组数；每组测试数据描述如下：在一行上输入两个整数 N, M。（原文取值范围识别严重缺失，无法还原具体上下界）

## 输出描述

对于每组测试数据，新起一行输出一个整数：满足要求的最大素数个数；若无解，则输出 -1。

```java
import java.io.*;
import java.util.*;

public class Solution {
    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        int T = Integer.parseInt(br.readLine().trim());
        StringBuilder out = new StringBuilder();
        for (int tc = 0; tc < T; tc++) {
            StringTokenizer st = new StringTokenizer(br.readLine());
            long N = Long.parseLong(st.nextToken());
            long M = Long.parseLong(st.nextToken());
            long ans;
            if (N >= 3 * M && ((N - M) & 1L) == 0) ans = (N - M) / 2;
            else ans = -1;
            out.append(ans).append('\n');
        }
        System.out.print(out);
    }
}
```
