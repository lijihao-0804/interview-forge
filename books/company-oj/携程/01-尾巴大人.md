# 尾巴大人

> 来源：语雀「携程真题题解」（已做 OCR 校对）

## 题目描述

众所周知，"!" 很像一个尾巴，它表示阶乘，即 N! = 1×2×…×N。给定一个整数 N，游游想知道 N! 的个位数是多少，请输出这个值。

## 输入描述

输入一行一个整数 N（1 ≤ N ≤ 10^9）。（原文范围表述模糊）

## 输出描述

输出一个整数，表示 N! 的个位数字。

## 示例 1

输入：
```
1
```

输出：
```
1
```

## 示例 2

输入：
```
3
```

输出：
```
6
```

说明：3! = 1×2×3 = 6，个位是 6。

```java
import java.io.*;

public class Solution {
    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        String l = br.readLine();
        if (l == null) return;
        long N = Long.parseLong(l.trim());
        int[] d = {1, 1, 2, 6, 4};
        if (N <= 4) System.out.println(d[(int) N]);
        else System.out.println(0);
    }
}
```
