# 文件目录的分层压缩

> 来源：语雀「华为-软开岗真题题解」（已做 OCR 校对，原文损坏严重，部分内容为推测还原）

## 题目描述

有一个 N 层的文件系统，每个目录下可以有多个子目录（至多两个子目录，构成一棵二叉树）。每个目录自身占有一定的大小，要求自底向上统计每个目录（含所有子目录）的总大小。

目录大小统计规则：给定一个目录的自身大小为 10，该目录还有两个子目录，大小分别为 4 和 4，则统计的该目录大小为 18（10 + 4 + 4）。（原文此处数值模糊）

## 输入描述

输入包含两行：
- 第一行为目录的层数 N，取值范围 1 < N < 10；
- 第二行为按完全二叉树层序给出的目录树序列，节点之间以 `-` 分隔，空节点用 `-1` 表示。（原文遍历方式描述模糊）

输入示例（原文如此，分隔与数值可能有识别误差）：
```
3
12-153
```

## 输出描述

按与输入相同的层序、以 `-` 分隔，输出统计后的每个目录总大小；空节点仍输出 `-1`，输出末尾不带多余空格。（原文输出格式描述模糊）

输出示例（原文如此）：
```
1110-153
```

## 示例

样例 1（原文如此）：
```
输入：
3
1-12-13

输出：
6-15-1-13
```

样例 2（原文如此）：
```
输入：
3
12-153

输出：
1110-153
```

## 说明

计算逻辑（原文残缺，据片段推测）：自底向上，对每个非空节点，将其自身大小与左右合法子节点的总大小相加得到该目录总大小；空节点保持 `-1`。原文示例中的具体数值与分隔符存在较严重识别误差，无法完全还原。

## 解题思路

本题把文件目录看成按完全二叉树层序存储的二叉堆结构：下标 i 的左右子节点为 2i+1、2i+2。
要求自底向上统计每个目录（含所有子目录）的总大小：非空节点的总大小 = 自身大小 + 左右合法子节点（非 −1）的总大小，空节点保持 −1。
实现时先把整行按 '-' 拆分成数组，再从后往前（逆层序）计算，保证处理某节点时其子节点的 total 已经算好。
最后按原层序用 '-' 拼接输出。

## 复杂度分析

- 时间复杂度：O(n)，n 为节点总数，每个节点只计算一次。
- 空间复杂度：O(n)，需要存储自身大小和总大小两个数组。

## 解题代码
```java
import java.io.*;
import java.util.*;

public class Solution {
    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        String nl = br.readLine();
        if (nl == null) return;
        int N = Integer.parseInt(nl.trim());
        StringBuilder sb = new StringBuilder();
        String s;
        while ((s = br.readLine()) != null) sb.append(s.trim());
        String[] parts = sb.toString().split("-");
        List<Long> vals = new ArrayList<>();
        for (String p : parts) {
            p = p.trim();
            if (p.isEmpty()) continue;
            vals.add(Long.parseLong(p));
        }
        int cnt = vals.size();
        long[] self = new long[cnt];
        for (int i = 0; i < cnt; i++) self[i] = vals.get(i);
        long[] total = new long[cnt];
        for (int i = cnt - 1; i >= 0; i--) {
            if (self[i] == -1) { total[i] = -1; continue; }
            long t = self[i];
            int l = 2 * i + 1, r = 2 * i + 2;
            if (l < cnt && self[l] != -1) t += total[l];
            if (r < cnt && self[r] != -1) t += total[r];
            total[i] = t;
        }
        StringBuilder out = new StringBuilder();
        for (int i = 0; i < cnt; i++) {
            if (i > 0) out.append('-');
            out.append(total[i]);
        }
        System.out.println(out);
    }
}
```
