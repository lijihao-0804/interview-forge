多多穿越隧道

来源：语雀「拼多多真题题解」（已做 OCR 校对）

题目描述

多多在一个长为 n 的横向隧道里，隧道每个位置用 1 到 n 的整数表示。隧道由 #（障碍物）和 .（空地）组成，其中 D 表示多多的初始位置。

移动规则： - 轻松移动：如果当前位置左边或右边是空地，则可以移动到相邻空地。 - 穿墙技能：至少进行一次轻松移动后，可以穿过一段连续障碍物，停留在障碍物另一侧的空地。

（原文题目描述较简，未明确“穿出隧道”的判定；据样例可理解为判断多多能否离开隧道的两端。）

输入描述

  • 第一行整数 T 表示测试数据组数。
  • 每组数据第一行整数 n 表示隧道长度，第二行长度为 n 的字符串描述隧道。

输出描述

每组数据输出 YES 或 NO，表示是否能穿出隧道。

示例

输入：

4
5
#D###
5
..D.#
7
#.#.D##
5
D####

输出：

NO
YES
YES
YES

说明

  • 第一组：D 所在段长度为 1，无法启动穿墙，输出 NO。
  • 第二组：D 所在段长度 ≥ 2，可向左直接走出或向右穿墙而出。
  • 第三组：先向左走一步，再从右边穿墙而出。
  • 第四组：只能从左边走出隧道。
import java.io.*;

public class Solution {
    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        int T = Integer.parseInt(br.readLine().trim());
        StringBuilder out = new StringBuilder();
        for (int tc = 0; tc < T; tc++) {
            int n = Integer.parseInt(br.readLine().trim());
            String s = br.readLine().trim();
            int d = s.indexOf('D');
            boolean yes = false;
            if (d != -1) {
                if (d == 0 || d == n - 1) {
                    yes = true;
                } else {
                    int l = d;
                    while (l - 1 >= 0 && s.charAt(l - 1) != '#') l--;
                    int r = d;
                    while (r + 1 < n && s.charAt(r + 1) != '#') r++;
                    yes = (r - l + 1) >= 2;
                }
            }
            out.append(yes ? "YES" : "NO").append('\n');
        }
        System.out.print(out);
    }
}
