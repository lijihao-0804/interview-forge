# 多多的消消乐

> 来源：语雀「拼多多真题题解」（已做 OCR 校对，原文示例数据缺失）

## 题目描述

给定二进制字符串 s，允许两种操作：
1. 删除任意字符（花费 1 硬币）。
2. 交换任意两个字符（免费）。

目标得到漂亮字符串：对于所有位置 i，字符串的第 i 个字符不能等于原字符串 s 的第 i 个字符。求最小花费硬币数。

## 输入描述

- 第一行整数 T 表示测试数据组数。
- 每组数据一个字符串 s。

## 输出描述

每组数据输出最小花费硬币数。

## 示例

（原文示例的具体输入数据缺失，仅保留以下说明）
- 第一组：删除唯一字符得到空串，花费 1 硬币。
- 第二组：删除最后一个字符后交换前两个字符，花费 1 硬币。
- 第三组：通过免费交换得到漂亮字符串，花费 0 硬币。
- 第四组：删除前 4 个字符，花费 4 硬币。

```java
import java.io.*;

public class Solution {
    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        int T = Integer.parseInt(br.readLine().trim());
        StringBuilder out = new StringBuilder();
        for (int tc = 0; tc < T; tc++) {
            String s = br.readLine().trim();
            int n = s.length();
            int[] zeros = new int[n + 1];
            for (int i = 0; i < n; i++) zeros[i + 1] = zeros[i] + (s.charAt(i) == '0' ? 1 : 0);
            int tot0 = zeros[n];
            int tot1 = n - tot0;
            int ans = n;
            for (int L = n; L >= 0; L--) {
                int a = zeros[L];
                int b = L - a;
                if (tot1 >= a && tot0 >= b) { ans = n - L; break; }
            }
            out.append(ans).append('\n');
        }
        System.out.print(out);
    }
}
```
