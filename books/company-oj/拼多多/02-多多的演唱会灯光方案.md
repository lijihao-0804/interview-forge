# 多多的演唱会灯光方案

> 来源：语雀「拼多多真题题解」（已做 OCR 校对，原文示例数据缺失）

## 题目描述

舞台灯光有五种主色（D、M、T、A、O）和其他辅助色。要求所取子串中包含全部五种主色（各至少一次），且恰好有 R 个辅助色。求满足条件的子串数量。

## 输入描述

- 第一行整数 T 表示测试数据组数。
- 每组数据第一行整数 R 表示所需辅助色数量，第二行字符串 s 表示灯光序列。

## 输出描述

每组数据输出满足条件的子串数量。

## 示例

（原文示例的具体输入数据缺失，仅保留以下说明）
- 说明：唯一满足条件的子串是 "AVMTTBL"，其中包含 3 个辅助色（A、V、L），且主色齐全。
- 说明：子串 "DOAMT" 全是主色，辅助色为 0。
- 说明：两个子串 "OYOMA" 和 "YOMAOTD" 均满足条件。

<!-- 注意：本题原题面存在缺失，以下为按现有信息的推断实现，请核对 -->
```java
import java.io.*;
import java.util.*;

public class Solution {
    static int idx(char c) {
        switch (c) {
            case 'D': return 0;
            case 'M': return 1;
            case 'T': return 2;
            case 'A': return 3;
            case 'O': return 4;
            default: return -1;
        }
    }

    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        int T = Integer.parseInt(br.readLine().trim());
        StringBuilder out = new StringBuilder();
        for (int tc = 0; tc < T; tc++) {
            int R = Integer.parseInt(br.readLine().trim());
            String s = br.readLine().trim();
            int n = s.length();
            int[] pref = new int[n + 1];
            for (int i = 0; i < n; i++) pref[i + 1] = pref[i] + (idx(s.charAt(i)) >= 0 ? 0 : 1);
            int[] last = new int[5];
            Arrays.fill(last, -1);
            HashMap<Integer, Long> freq = new HashMap<>();
            int ptr = 0;
            long ans = 0;
            for (int r = 0; r < n; r++) {
                int ci = idx(s.charAt(r));
                if (ci >= 0) last[ci] = r;
                int good = Integer.MAX_VALUE;
                for (int k = 0; k < 5; k++) {
                    if (last[k] < 0) { good = -1; break; }
                    if (last[k] < good) good = last[k];
                }
                if (good < 0) continue;
                while (ptr <= good) {
                    freq.merge(pref[ptr], 1L, Long::sum);
                    ptr++;
                }
                int target = pref[r + 1] - R;
                ans += freq.getOrDefault(target, 0L);
            }
            out.append(ans).append('\n');
        }
        System.out.print(out);
    }
}
```
