来源：语雀「网易雷火真题题解」（已做 OCR 校对）

题目描述

在《蛋仔派对》世界里，X 个蛋仔误入 N×M 的迷宫，迷宫有 Y 个出口。

每个蛋仔初始携带 K_i 能量，每次可向上下左右移动一格，每移动一格消耗 1 单位能量，能量用尽无法移动。

每个蛋仔有特定能量需求 E_i，到达迷宫出口时，迷宫能量值达到或超过 E_i 才能逃脱，否则需等待。迷宫初始能量为 E，蛋仔逃脱后剩余能量会在下一时刻补充到迷宫能量值中。

蛋仔移动一格花费 1 单位时间，同一时间只能一个蛋仔移动，蛋仔间不相互阻挡。需计算所有蛋仔逃出迷宫所花费的最短时间，若无法全部逃脱则输出 -1。

输入描述

输入第一行为整数 P，表示有 P 组独立测试数据，每组数据格式如下： - 第一行包含五个整数 N, M, X, Y, E，分别表示迷宫的行数、列数、蛋仔数量、出口数量和迷宫的初始能量值。其中 1 ≤ N, M ≤ 800，1 ≤ X, Y ≤ 800，0 ≤ E ≤ 100000。 - 接下来 X 行，每行包含四个整数 x_i, y_i, E_i, K_i，表示第 i 个蛋仔的初始位置位于第 x_i 列第 y_i 行、逃脱所需的能量值 E_i 和蛋仔初始携带的能量值 K_i。其中 1 ≤ x_i ≤ M，1 ≤ y_i ≤ N，0 ≤ E_i, K_i ≤ 100000。 - 接下来 Y 行，每行包含两个整数 p_j, q_j，表示第 j 个出口的位置位于第 p_j 列第 q_j 行。其中 1 ≤ p_j ≤ M，1 ≤ q_j ≤ N。 - 接下来 N 行，每行包含 M 个字符，表示迷宫的布局。字符 '.' 表示空地，字符 '#' 表示障碍。

保证所有蛋仔初始位置和迷宫出口位置均为空地，且蛋仔初始位置不在迷宫出口上。

输出描述

输出一个整数，表示所有蛋仔逃出迷宫所花费的最短时间；若无法全部逃脱则输出 -1。

（题目中所有坐标 (x, y) 均为先列后行的形式，即 x 为水平方向，y 为竖直方向，迷宫图的左上角为起点，行列均从 1 开始计数。）

示例

输入：

1
5 5 2 2 10
1 1 5 7
3 3 8 2
2 4
4 2
.....
.#...
.....
...#.
.....

输出：

6

说明

第一个蛋仔从 (1,1) 移动到 (2,4) 需要 4 步，在 t=4 时刻逃生，逃生时蛋仔剩余能量 3，迷宫能量值在 t=5 时刻增加到 13。第二个蛋仔从 (3,3) 移动到 (4,2) 需要 2 步，在 t=6 时刻逃生，逃生时蛋仔剩余能量 0，迷宫能量值在 t=7 时刻无额外增加，仍然是 13。所有蛋仔都逃出迷宫的总时间为 6。

解题思路

本题先求每个格子到最近出口的最短距离，再按能量约束贪心安排蛋仔出逃顺序。 第一步：从所有出口同时出发做多源 BFS，得到每个格子的最近出口距离 dist。 第二步：对每个蛋仔，若其位置不可达或最近距离 d > 初始能量 K_i，则该蛋仔永远走不出去，整组输出 −1。 第三步：把蛋仔按「逃脱所需能量 E_i」升序排序后依次放行：每放一个耗时 += d；若当前迷宫能量 < E_i 则失败；否则该蛋仔到达结束，剩余 K_i − d 会补充进迷宫能量池。累计的总时间即为答案。

复杂度分析

  • 时间复杂度：O(N·M + X log X)，多源 BFS 为 O(N·M)，排序为 O(X log X)。
  • 空间复杂度：O(N·M)，距离矩阵与 BFS 队列。

解题代码

import java.io.*;
import java.util.*;

public class Solution {
    static class FastScanner {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        StringTokenizer st;
        String next() {
            while (st == null || !st.hasMoreTokens()) {
                try {
                    String l = br.readLine();
                    if (l == null) return null;
                    st = new StringTokenizer(l);
                } catch (IOException e) { return null; }
            }
            return st.nextToken();
        }
        int nextInt() { return Integer.parseInt(next()); }
    }

    public static void main(String[] args) {
        FastScanner fs = new FastScanner();
        int P = fs.nextInt();
        StringBuilder out = new StringBuilder();
        int[] dx = {1, -1, 0, 0};
        int[] dy = {0, 0, 1, -1};
        for (int tc = 0; tc < P; tc++) {
            int N = fs.nextInt(), M = fs.nextInt(), X = fs.nextInt(), Y = fs.nextInt(), E = fs.nextInt();
            int[] ex = new int[X], ey = new int[X], eE = new int[X], eK = new int[X];
            for (int i = 0; i < X; i++) { ex[i] = fs.nextInt(); ey[i] = fs.nextInt(); eE[i] = fs.nextInt(); eK[i] = fs.nextInt(); }
            int[] px = new int[Y], py = new int[Y];
            for (int j = 0; j < Y; j++) { px[j] = fs.nextInt(); py[j] = fs.nextInt(); }
            char[][] grid = new char[N][];
            for (int r = 0; r < N; r++) grid[r] = fs.next().toCharArray();

            int INF = Integer.MAX_VALUE / 2;
            int[][] dist = new int[N][M];
            for (int[] row : dist) Arrays.fill(row, INF);
            int[] qx = new int[N * M + 5], qy = new int[N * M + 5];
            int head = 0, tail = 0;
            for (int j = 0; j < Y; j++) {
                int r = py[j] - 1, c = px[j] - 1;
                if (r >= 0 && r < N && c >= 0 && c < M && grid[r][c] != '#' && dist[r][c] == INF) {
                    dist[r][c] = 0;
                    qx[tail] = r; qy[tail] = c; tail++;
                }
            }
            while (head < tail) {
                int r = qx[head], c = qy[head]; head++;
                for (int k = 0; k < 4; k++) {
                    int nr = r + dy[k], nc = c + dx[k];
                    if (nr >= 0 && nr < N && nc >= 0 && nc < M && grid[nr][nc] != '#' && dist[nr][nc] == INF) {
                        dist[nr][nc] = dist[r][c] + 1;
                        qx[tail] = nr; qy[tail] = nc; tail++;
                    }
                }
            }

            long[][] eggs = new long[X][2];
            boolean ok = true;
            for (int i = 0; i < X; i++) {
                int r = ey[i] - 1, c = ex[i] - 1;
                int d = dist[r][c];
                if (d >= INF || d > eK[i]) { ok = false; break; }
                eggs[i][0] = eE[i];
                eggs[i][1] = d;
            }
            if (!ok) { out.append(-1).append('\n'); continue; }
            Integer[] order = new Integer[X];
            for (int i = 0; i < X; i++) order[i] = i;
            final long[][] eggRef = eggs;
            Arrays.sort(order, (a, b) -> Long.compare(eggRef[a][0], eggRef[b][0]));
            long energy = E, time = 0;
            for (int oi = 0; oi < X; oi++) {
                int i = order[oi];
                long d = eggs[i][1];
                time += d;
                if (energy < eggs[i][0]) { ok = false; break; }
                energy += eK[i] - d;
            }
            out.append(ok ? time : -1).append('\n');
        }
        System.out.print(out);
    }
}
