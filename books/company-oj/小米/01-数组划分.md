# 数组划分

> 来源：语雀「小米真题题解」（已做 OCR 校对）

## 题目描述

小明来玩数组了。他有一个长度为 n 的数组 a 以及一个给定的数字 k，需要把数组 a 划分成连续的 k 个子数组。定义 f[i] 表示第 i 个子数组中数字的最大值，小明的任务是最小化 f[] 中最大值与最小值之间的差，并输出划分方案。如果存在多种方案，则输出字典序最小的那一组。

## 输入描述

输入包括多组测试数据。

第一行有一个正整数 T（1 ≤ T ≤ 100），表示测试数据的组数。

每组测试数据的第一行有两个正整数 n（1 ≤ n ≤ 10^5）和 k（1 ≤ k ≤ n），表示数组的长度以及划分的子数组个数；

接下来一行有 n 个正整数 a_1, a_2, …, a_n（1 ≤ a_i ≤ 10^5），表示题目给定的数组。

保证每个测试点的所有测试数据的 n 之和不超过 10^5。

## 输出描述

对于每组测试数据，输出 k 行，其中第 i 行包含两个数字 l 和 r，表示第 i 个子数组的下标区间。合法的划分方案需要保证：
1. l_1 = 1，r_k = n；
2. r_i + 1 = l_{i+1}（1 ≤ i ≤ k−1）。

对于两个不同的方案，若下标 j 表示两个方案之间第一对不同的 l 和 r，则 l 更小的方案字典序更小；若 l 相同，则 r 更小的方案字典序更小。

## 示例

输入：
```
1
6 3
8 3 5 6 4 2
```

输出：
```
1 1
2 3
4 6
```

```java
import java.io.*;
import java.util.*;

public class Solution {
    public static void main(String[] args) throws IOException {
        StreamTokenizer in = new StreamTokenizer(new BufferedReader(new InputStreamReader(System.in)));
        in.nextToken();
        int T = (int) in.nval;
        StringBuilder out = new StringBuilder();
        for (int tc = 0; tc < T; tc++) {
            in.nextToken(); int n = (int) in.nval;
            in.nextToken(); int k = (int) in.nval;
            int[] a = new int[n];
            for (int i = 0; i < n; i++) { in.nextToken(); a[i] = (int) in.nval; }
            int[] sorted = a.clone();
            Arrays.sort(sorted);
            int x = sorted[n - k]; // k-th largest
            ArrayList<Integer> big = new ArrayList<>();
            for (int i = 0; i < n; i++) if (a[i] >= x) big.add(i + 1);
            int prev = 0;
            for (int i = 0; i < k; i++) {
                int r = (i == k - 1) ? n : big.get(i);
                int l = prev + 1;
                out.append(l).append(' ').append(r).append('\n');
                prev = r;
            }
        }
        System.out.print(out);
    }
}
```
