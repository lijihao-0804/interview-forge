# 编程机试/ACM 测试系统调研

> 调研时间：2026-11-09。范围：华为 OD/校招机考相关平台、可直接登录使用的商业笔试平台、可自建部署的开源 OJ/ACM 评测系统。
>
> 先说结论：
> - **华为没有面向社会公开、可自行注册登录的“华为机试系统”**。华为校招/OD 的机考链接通常由 HR 或招聘流程发出，候选人只能在指定时间进入；公开面经显示 OD 常见平台是 **牛客网 / 赛码网**。
> - 想快速模拟“华为 OD/ACM 机试”，最省事的是 **牛客网企业版或赛码网**（SaaS，企业账号发起考试、考生收链接）。
> - 想自己部署、长期做内部练习/模拟赛，首选 **HydroOJ**（中文、现代、Docker 部署）；想严格复刻 ICPC 现场赛，选 **DOMjudge**；想简单快速搭一个 OJ，选 **HUSTOJ** 或 **QingdaoU OnlineJudge**。

## 一、华为机试到底是什么

### 1. 官方入口

华为招聘官网：[career.huawei.com](https://career.huawei.com/)

华为校招/OD 的机考不是公开练习网站，而是招聘流程中的一环：

- 投递简历并通过筛选后，HR/系统发出考试链接；
- 候选人在指定时间登录考试系统作答；
- 常见题型是 3 道编程题，按测试用例通过比例计分（公开面经中常见 100/100/200 分配）；
- 考试平台可能因招聘批次/部门不同而变化，公开面经里最常见的是 **牛客网** 和 **赛码网**。

### 2. 华为 OD 常见平台

- 牛客网：公开题库、ACM 模式练习、企业在线笔试
- 赛码网：在线考试/在线编程，支持多语言自动判题
- 相关公开面经：[华为 OD 面试机试注意点](https://www.nowcoder.com/discuss/359013089126162432)、[华为 OD 面试全流程拆解](https://www.nowcoder.com/feed/main/detail/a9dccde17f1f47258c8972f0134156e6)

> 注意：以上是公开面经/招聘流程信息，不代表华为官方固定使用某一家；正式考试以收到的邮件/链接为准。

## 二、可直接登录使用的商业平台（SaaS）

| 平台 | 是否能直接用 | ACM/编程题 | 适合场景 | 链接 |
|---|---|---|---|---|
| **牛客网企业版** | 企业注册/试用后发起考试，考生收链接 | 支持 ACM 模式、在线编程、AI 监考 | 最接近国内大厂/华为 OD 笔试体验 | [牛客企业版在线笔试](https://hr-dev.nowcoder.com/product/test) |
| **赛码网** | 企业注册/试用，考生通过考试链接进入 | 支持在线编程、自动判题，多语言 | 华为 OD 公开面经中常见；企业校招/社招笔试 | [赛码网](https://acmcoder.cn/) · [考试平台](https://kao.acmcoder.com) |
| **HackerRank for Work** | 企业账号/免费试用；候选人收邀请 | 编程题、代码运行、AI 面试 | 外企/海外团队，英文环境 | [HackerRank for Work](https://www.hackerrank.com/work) |
| **Codility** | 企业账号/试用；候选人收测试链接 | 编程测评、自动评分、防作弊 | 外企技术招聘 | [Codility](https://www.codility.com/) |
| **HackerEarth Assessments** | 企业账号 | 编程测评/竞赛 | 海外招聘、编程挑战 | [HackerEarth](https://www.hackerearth.com/) |

### 这些平台的特点

- **优点**：不用运维，注册/试用后就能组卷、发链接、自动判题；通常带监考、随机抽题、成绩报告。
- **限制**：不是给个人随便“登录就考”的公共系统；企业版一般要企业资质/试用申请，个人只能参加被邀请的考试。
- **如果只是自己练**：直接用牛客网公开题库 + ACM 模式练习即可，不需要企业版。

## 三、可自建部署的开源系统

| 系统 | 技术栈/部署 | ACM 支持 | 适合 | 维护成本 | 链接 |
|---|---|---|---|---|---|
| **HydroOJ** | Node/TypeScript、MongoDB，支持 Docker | 支持 ACM/OI/IOI 赛制、题目导入、比赛/榜单 | **最推荐的自建选择**：中文、界面现代、功能够用 | 中 | [GitHub](https://github.com/hydro-dev/Hydro) · [文档](https://hydro.js.org/) |
| **HUSTOJ** | PHP/C++/MySQL/Linux，Docker 镜像多 | ACM/ICPC、NOIP 训练 | 老牌、资料多、部署简单；界面偏传统 | 低 | [GitHub](https://github.com/zhblue/hustoj) · [官网](http://www.hustoj.com) |
| **QingdaoU OnlineJudge** | Vue + Django + Docker | ACM/OI，比赛、题目、榜单 | 界面好、Docker Compose 部署；更新节奏较慢 | 中 | [GitHub](https://github.com/QingdaoU/OnlineJudge) |
| **DOMjudge** | PHP/MySQL + Linux judgehost | **ICPC 官方使用**，标准 ACM 赛制 | 想严格模拟 ACM/ICPC 现场赛、多队伍榜单 | 高（需 judgehost、Linux/cgroup） | [GitHub](https://github.com/DOMjudge/domjudge) · [文档](https://www.domjudge.org/docs/manual/8.2/overview.html) |
| **Judge0** | Docker，代码执行 API | 不是完整竞赛系统 | 想自己做产品/嵌入代码运行能力 | 中 | [GitHub](https://github.com/judge0/judge0) · [官网](https://judge0.com/) |

### 自建建议

1. **只想搭一个能刷题、能办小型模拟赛的 OJ**：选 **HydroOJ**。
2. **想要最简单的传统 OJ、教程多**：选 **HUSTOJ**。
3. **想要好看的界面 + Docker 快速起**：选 **QingdaoU OnlineJudge**。
4. **要办正式 ACM/ICPC 5 小时现场赛、需要队伍账号和榜单**：选 **DOMjudge**。
5. **只要代码运行能力，不要完整 OJ**：选 **Judge0**，自己写前端/评测流程。

> 自建系统通常只解决“判题 + 比赛”，不天然带人脸识别、锁屏、屏幕监控等防作弊能力；正式招聘考试建议用商业 SaaS，或者把 OJ 部署在受控网络/机房环境。

## 四、按使用目的选型

### 1. 模拟华为 OD/大厂机试

- 最像真实体验：**牛客网企业版 / 赛码网**
- 个人练习：牛客网公开题库，重点练 **ACM 模式输入输出**
- 不建议：直接找“华为机试原系统”，因为官方不公开开放

### 2. 自建内部练习/培训平台

- 首选：**HydroOJ**
- 备选：HUSTOJ、QingdaoU
- 需要正式 ACM 现场赛：DOMjudge

### 3. 企业招聘/校招笔试

- 国内：**牛客企业版 / 赛码网**
- 海外：HackerRank for Work / Codility / HackerEarth
- 自建只适合有运维团队、且对防作弊要求不高的场景

### 4. 只做代码运行/自定义产品

- **Judge0**：提供代码执行 API，前端和考试流程要自己做
