38.1 力扣的代码形态与本地调试

力扣给的是函数签名，参数由平台传入，不需要写 input()。本地调试时，直接调用函数、打印返回值即可：

def two_sum(nums: list[int], target: int) -> list[int]:
    seen = {}
    for i, num in enumerate(nums):
        if target - num in seen:
            return [seen[target - num], i]
        seen[num] = i  # 记录“值 -> 下标”
    return []

print(two_sum([2, 7, 11, 15], 9))  # [0, 1]
print(two_sum([3, 3], 6))          # [0, 1]

本地排错时，优先打印类型、长度和关键变量：

nums = [3, 1, 2]

print(type(nums))    # <class 'list'>
print(len(nums))     # 3
print(max(nums))     # 3
print(sorted(nums))  # [1, 2, 3]
print(nums)          # [3, 1, 2]，sorted 不修改原列表

如果题目是 ACM 模式（华为 OD、牛客等），才需要自己读输入。力扣核心代码模式不要写 input()。

38.2 list：数组题的绝对主力

读取、切片和长度：

nums = [3, 1, 4, 1, 5]

print(nums[0])     # 3

print(nums[1:3])   # [1, 4]

增删改：

nums = [1, 2, 3]

nums.append(4)     # nums 变为 [1, 2, 3, 4]

nums.pop(0)        # 返回 1，nums 变为 [2, 3]

排序是数组题的第一高频操作。sort() 原地修改，sorted() 返回新列表：

nums = [3, 1, 2]

print(sorted(nums))             # [1, 2, 3]
print(nums)                     # [3, 1, 2]，原列表不变

nums.sort()                     # nums 变为 [1, 2, 3]
nums.sort(reverse=True)         # nums 变为 [3, 2, 1]
print(nums)                     # [3, 2, 1]

按规则排序用 key。key 是“把每个元素映射成比较依据的函数”：

words = ["bb", "a", "ccc"]

print(sorted(words, key=len))                # ['a', 'bb', 'ccc']
print(sorted(words, key=len, reverse=True))  # ['ccc', 'bb', 'a']

users = [
    {"name": "Ada", "score": 91},
    {"name": "Bob", "score": 85},
]
print(sorted(users, key=lambda u: u["score"]))  # [{'name': 'Bob', 'score': 85}, {'name': 'Ada', 'score': 91}]

二维列表必须按行创建，避免所有行共享同一个内层列表：

grid = [[0] * 3 for _ in range(2)]  # 两行三列，行之间互相独立
grid[0][0] = 1                      # grid 变为 [[1, 0, 0], [0, 0, 0]]

bad = [[0] * 3] * 2                 # 错误：两行引用同一个内层列表
bad[0][0] = 1                       # bad 变为 [[1, 0, 0], [1, 0, 0]]
print(bad)                          # [[1, 0, 0], [1, 0, 0]]

矩阵转置是一个很实用的小技巧：

    [1, 2, 3],

聚合函数：

38.4 dict 与 set：计数、分组、去重和索引

字典的 get() 和 setdefault() 是刷题最常用的两个方法：

counts = {}

counts["a"] = counts.get("a", 0) + 1  # counts 变为 {'a': 1}
counts["a"] = counts.get("a", 0) + 1  # counts 变为 {'a': 2}
counts.setdefault("b", []).append(1)  # counts 变为 {'a': 2, 'b': [1]}
print(counts)                         # {'a': 2, 'b': [1]}
print(counts.get("c", 0))             # 0

Counter 负责计数，defaultdict(list) 负责分组：

from collections import Counter, defaultdict

nums = [1, 1, 2, 3, 3, 3]
freq = Counter(nums)        # Counter({3: 3, 1: 2, 2: 1})
print(freq[3])              # 3
print(freq.most_common(2))  # [(3, 3), (1, 2)]

groups = defaultdict(list)
for word in ["eat", "tea", "tan"]:
    groups["".join(sorted(word))].append(word)  # 按排序后的字符串分组
print(dict(groups))  # {'aet': ['eat', 'tea'], 'ant': ['tan']}

字典的遍历、合并和推导式：

d = {"a": 1, "b": 2}

print(list(d.keys()))    # ['a', 'b']
print(list(d.values()))  # [1, 2]
print(list(d.items()))   # [('a', 1), ('b', 2)]

for k, v in d.items():
    print(k, v)  # a 1 / b 2

print({v: k for k, v in d.items()})  # {1: 'a', 2: 'b'}
print({"a": 1} | {"b": 2})           # {'a': 1, 'b': 2}

集合用于去重、成员判断和集合运算：

s = {1, 2, 3}

s.add(4)           # s 变为 {1, 2, 3, 4}
s.discard(2)       # s 变为 {1, 3, 4}
print(3 in s)      # True
print(s | {4, 5})  # {1, 3, 4, 5}，并集
print(s & {3, 4})  # {3, 4}，交集
print(s - {4})     # {1, 3}，差集
print(s ^ {4, 5})  # {1, 3, 5}，对称差

去重同时保留原顺序，用 dict.fromkeys()：

nums = [1, 2, 1, 3, 2]

visited = set()

38.5 栈与队列：LIFO 和 FIFO

栈直接用 list：append() 入栈、pop() 出栈。括号匹配是最典型的例子：

def is_valid(s: str) -> bool:
    pairs = {")": "(", "]": "[", "}": "{"}
    stack = []
    for ch in s:
        if ch in "([{":
            stack.append(ch)  # 左括号入栈
        else:
            if not stack or stack.pop() != pairs[ch]:  # 弹出栈顶并检查是否匹配
                return False
    return not stack

print(is_valid("()[]{}"))  # True
print(is_valid("(]"))      # False

队列用 collections.deque，popleft() 是 O(1)：

from collections import deque

queue = deque([1, 2])

queue.append(3)         # queue 变为 deque([1, 2, 3])
print(queue.popleft())  # 1
queue.appendleft(0)     # queue 变为 deque([0, 2, 3])
print(queue)            # deque([0, 2, 3])

deque 也是滑动窗口最大值的标准工具：单调队列保存下标，队头始终是当前窗口最大值：

from collections import deque

def max_sliding_window(nums: list[int], k: int) -> list[int]:
    q = deque()  # 存下标，对应值从队头到队尾递减
    result = []
    for i, num in enumerate(nums):
        while q and nums[q[-1]] <= num:
            q.pop()  # 比当前值小的都不可能成为最大值
        q.append(i)  # 当前下标入队
        if q[0] <= i - k:
            q.popleft()  # 移出窗口
        if i >= k - 1:
            result.append(nums[q[0]])  # 队头就是当前窗口最大值
    return result

print(max_sliding_window([1, 3, -1, -3, 5, 3, 6, 7], 3))  # [3, 3, 5, 5, 6, 7]

对应力扣：20. 有效的括号、155. 最小栈、232. 用栈实现队列、239. 滑动窗口最大值。

38.6 heapq：力扣最常用的最小堆

heapq 是最小堆。它只保证 heap[0] 最小，不保证整个列表有序。最常用的操作：

操作 写法 说明
建堆 heapq.heapify(nums) 原地 O(n) 建堆
入堆 heapq.heappush(heap, x) O(log n)
出堆 heapq.heappop(heap) 弹出最小值
入后出 heapq.heappushpop(heap, x) 比先 push 再 pop 更快
出后入 heapq.heapreplace(heap, x) 弹出最小值再压入 x
Top K heapq.nlargest(k, nums) / nsmallest 返回列表，不修改原数据 
import heapq

heap = []
heapq.heappush(heap, 3)  # heap 变为 [3]
heapq.heappush(heap, 1)  # heap 变为 [1, 3]
heapq.heappush(heap, 2)  # heap 变为 [1, 3, 2]
print(heapq.heappop(heap))  # 1
print(heap)                 # [2, 3]

nums = [5, 1, 4, 2]
heapq.heapify(nums)              # nums 变为 [1, 2, 4, 5]
print(nums)                      # [1, 2, 4, 5]
print(heapq.nlargest(2, nums))   # [5, 4]
print(heapq.nsmallest(2, nums))  # [1, 2]

Python 没有大根堆，存负数即可。以「最后一块石头的重量」为例：

import heapq

stones = [2, 7, 4, 1, 8, 1]
heap = [-x for x in stones]  # 存负数模拟大根堆
heapq.heapify(heap)          # heap 变为 [-8, -7, -4, -1, -2, -1]

while len(heap) > 1:
    a = -heapq.heappop(heap)  # 当前最重的石头
    b = -heapq.heappop(heap)  # 第二重的石头
    if a != b:
        heapq.heappush(heap, -(a - b))  # 差值放回堆

print(-heap[0] if heap else 0)  # 1

38.6.1 用最小堆求第 K 大

维护一个大小为 k 的最小堆：堆里始终保存当前最大的 k 个元素，堆顶就是第 k 大。

import heapq

def find_kth_largest(nums: list[int], k: int) -> int:
    heap = []
    for num in nums:
        heapq.heappush(heap, num)  # 入最小堆
        if len(heap) > k:
            heapq.heappop(heap)  # 丢掉当前最小的，只保留最大的 k 个
    return heap[0]

print(find_kth_largest([3, 2, 1, 5, 6, 4], 2))  # 5
print(find_kth_largest([3, 2, 3, 1, 2, 4, 5, 5, 6], 4))  # 4

这是力扣 215. 数组中的第 K 个最大元素的标准解法之一，时间复杂度 O(n log k)。

38.6.2 堆里放元组：优先级 + 数据

当堆元素是元组时，Python 按元组顺序比较。常见写法是 (优先级, 数据)：

import heapq

tasks = [(2, "homework"), (1, "eat"), (1, "brush")]
heapq.heapify(tasks)  # 按第一个元素排序，第一个相同再比第二个

print(heapq.heappop(tasks))  # (1, 'brush')
print(heapq.heappop(tasks))  # (1, 'eat')
print(heapq.heappop(tasks))  # (2, 'homework')

如果数据本身不可比较（例如自定义对象），加一个自增下标做“稳定排序”：

import heapq
import itertools

counter = itertools.count()  # 生成 0, 1, 2...
heap = []
heapq.heappush(heap, (5, next(counter), {"name": "任务A"}))  # 5 是优先级
heapq.heappush(heap, (3, next(counter), {"name": "任务B"}))  # 第二个任务入堆
print(heapq.heappop(heap)[2])  # {'name': '任务B'}

如果希望堆元素就是自定义对象，也可以实现 __lt__，让 heapq 知道谁更小：

import heapq

class Task:
    def __init__(self, priority: int, name: str):
        self.priority = priority
        self.name = name

    def __lt__(self, other: "Task") -> bool:
        return self.priority < other.priority  # 优先级小的算“更小”

heap = []
heapq.heappush(heap, Task(3, "低优先级"))  # 第 1 个任务入堆
heapq.heappush(heap, Task(1, "高优先级"))  # 第 2 个任务入堆
heapq.heappush(heap, Task(2, "中优先级"))  # 第 3 个任务入堆
print(heapq.heappop(heap).name)  # 高优先级

heapq 只依赖 < 比较，所以实现 __lt__ 就够了；元组方案更简单，自定义类更适合字段多、逻辑复杂的场景。

38.6.3 前 K 个高频元素：Counter + heap

import heapq
from collections import Counter

def top_k_frequent(nums: list[int], k: int) -> list[int]:
    freq = Counter(nums)  # Counter({1: 3, 2: 2, 3: 1})
    return heapq.nlargest(k, freq.keys(), key=freq.get)

print(top_k_frequent([1, 1, 1, 2, 2, 3], 2))  # [1, 2]

38.6.4 合并 K 个有序链表：堆的经典用法

import heapq

class ListNode:
    def __init__(self, val: int = 0, next=None):
        self.val = val
        self.next = next

def merge_k_lists(lists: list[ListNode | None]) -> ListNode | None:
    heap = []
    for i, node in enumerate(lists):
        if node:
            heapq.heappush(heap, (node.val, i, node))  # 值、链表编号、节点

    dummy = ListNode(0)
    tail = dummy
    while heap:
        val, i, node = heapq.heappop(heap)  # 取出当前最小节点
        tail.next = node
        tail = tail.next
        if node.next:
            heapq.heappush(heap, (node.next.val, i, node.next))  # 该链表的下一个节点入堆
    return dummy.next

对应力扣：23. 合并 K 个升序链表。

38.6.5 Dijkstra：堆优化最短路

import heapq

def network_delay_time(times: list[list[int]], n: int, k: int) -> int:
    graph = [[] for _ in range(n + 1)]
    for u, v, w in times:
        graph[u].append((v, w))  # 有向边 u -> v，权重 w

    dist = [float("inf")] * (n + 1)  # 到每个点的最短距离
    dist[k] = 0  # 起点距离为 0
    heap = [(0, k)]  # (当前距离, 节点)

    while heap:
        d, node = heapq.heappop(heap)  # 取出当前距离最小的节点
        if d > dist[node]:
            continue  # 过期状态，跳过
        for nxt, weight in graph[node]:
            nd = d + weight
            if nd < dist[nxt]:
                dist[nxt] = nd  # 更新最短距离
                heapq.heappush(heap, (nd, nxt))  # 更短距离入堆

    answer = max(dist[1:])
    return answer if answer < float("inf") else -1

print(network_delay_time([[2, 1, 1], [2, 3, 1], [3, 4, 1]], 4, 2))  # 2

对应力扣：743. 网络延迟时间。

38.7 排序与自定义比较器：能用 key 就别写 cmp

key 是最常用的排序方式。它把每个元素映射成一个“可比较的值”：

words = ["bb", "a", "ccc"]

print(sorted(words, key=len))                # ['a', 'bb', 'ccc']
print(sorted(words, key=lambda s: (len(s), s)))  # ['a', 'bb', 'ccc']

多字段排序时，key 返回元组，元组从左到右比较：

users = [
    {"name": "Ada", "dept": "A", "score": 91},
    {"name": "Bob", "dept": "A", "score": 85},
    {"name": "Cindy", "dept": "B", "score": 95},

38.7.1 什么时候用 cmp_to_key

Python 3 的 sort 没有 cmp 参数。如果两个元素的先后关系不能用简单的 key 表达，就要用 functools.cmp_to_key 把比较函数包装成 key。

比较函数规则：

  • 返回负数：a 排在 b 前面；
  • 返回 0：两者相等；
  • 返回正数：a 排在 b 后面。

先看最简单的降序：

from functools import cmp_to_key

def compare(a: int, b: int) -> int:
    return b - a  # b 比 a 大时返回正数，所以 a 往后排

nums = [3, 1, 2]
print(sorted(nums, key=cmp_to_key(compare)))  # [3, 2, 1]

38.7.2 经典比较器：把数字拼成最大数

力扣 179. 最大数要求把数字拼成最大的字符串。比较规则不是“谁大谁在前”，而是 a + b 与 b + a 哪个更大：

from functools import cmp_to_key

def largest_number(nums: list[int]) -> str:
    def compare(a: str, b: str) -> int:
        if a + b > b + a:
            return -1  # a 应排在 b 前面
        if a + b < b + a:
            return 1   # a 应排在 b 后面
        return 0

    strs = [str(x) for x in nums]
    strs.sort(key=cmp_to_key(compare))  # 按拼接后的结果排序
    result = "".join(strs)
    return "0" if result[0] == "0" else result

print(largest_number([10, 2]))    # 210
print(largest_number([3, 30, 34, 5, 9]))  # 9534330

这类题如果只按 key=int 排序，会得到 [10, 2] -> 102，是错的。必须比较拼接后的结果。

38.7.3 区间题：按起点或终点排序

合并区间按起点排序：

def merge_intervals(intervals: list[list[int]]) -> list[list[int]]:
    intervals.sort(key=lambda x: x[0])  # 按起点升序
    merged = []
    for start, end in intervals:
        if not merged or start > merged[-1][1]:
            merged.append([start, end])  # 新区间不重叠，直接加入
        else:
            merged[-1][1] = max(merged[-1][1], end)  # 合并重叠区间
    return merged

print(merge_intervals([[1, 3], [2, 6], [8, 10], [15, 18]]))  # [[1, 6], [8, 10], [15, 18]]

用最少数量箭引爆气球、无重叠区间这类题，通常按右端点排序：

def erase_overlap_intervals(intervals: list[list[int]]) -> int:
    if not intervals:
        return 0
    intervals.sort(key=lambda x: x[1])  # 按右端点升序
    count = 0
    end = intervals[0][1]
    for start, stop in intervals[1:]:
        if start < end:
            count += 1  # 与上一个区间重叠，需要移除
        else:
            end = stop
    return count

print(erase_overlap_intervals([[1, 2], [2, 3], [3, 4], [1, 3]]))  # 1

手写 lower_bound()，便于改成各种“二分答案”：

def lower_bound(nums: list[int], target: int) -> int:
    left, right = 0, len(nums)  # 搜索区间 [left, right)
    while left < right:
        mid = (left + right) // 2
        if nums[mid] < target:
            left = mid + 1      # 答案在 mid 右边
        else:
            right = mid         # 答案可能就是 mid
    return left                 # 第一个 >= target 的下标

print(lower_bound([1, 2, 2, 4], 2))  # 1
print(lower_bound([1, 2, 2, 4], 3))  # 3

标准二分查找：

def binary_search(nums: list[int], target: int) -> int:
    left, right = 0, len(nums) - 1
    while left <= right:
        mid = (left + right) // 2
        if nums[mid] == target:
            return mid
        if nums[mid] < target:
            left = mid + 1
        else:
            right = mid - 1
    return -1

print(binary_search([-1, 0, 3, 5, 9, 12], 9))  # 4
print(binary_search([-1, 0, 3, 5, 9, 12], 2))  # -1

38.11.1 双指针（对撞）

def two_sum_sorted(nums: list[int], target: int) -> list[int]:
    left, right = 0, len(nums) - 1
    while left < right:
        total = nums[left] + nums[right]
        if total == target:
            return [left, right]
        if total < target:
            left += 1   # 和太小，左指针右移
        else:
            right -= 1  # 和太大，右指针左移
    return []

print(two_sum_sorted([1, 2, 4, 7], 9))  # [1, 3]

38.11.2 滑动窗口

def longest_unique_substring(s: str) -> int:
    left = 0
    window = set()
    best = 0

    for right, ch in enumerate(s):
        while ch in window:
            window.remove(s[left])  # 左边界右移，缩小窗口
            left += 1               # 左指针右移
        window.add(ch)              # 当前字符加入窗口
        best = max(best, right - left + 1)

    return best

print(longest_unique_substring("abcabcbb"))  # 3

38.11.4 单调栈

def next_greater(nums: list[int]) -> list[int]:
    result = [-1] * len(nums)
    stack = []  # 存下标，栈内对应值单调递减

    for i, num in enumerate(nums):
        while stack and nums[stack[-1]] < num:
            index = stack.pop()   # 弹出下标
            result[index] = num   # 找到右侧第一个更大值
        stack.append(i)           # 当前下标入栈

    return result

print(next_greater([2, 1, 2, 4, 3]))  # [4, 2, 4, -1, -1]

38.11.5 动态规划

def coin_change(coins: list[int], amount: int) -> int:
    dp = [amount + 1] * (amount + 1)  # dp[i]：凑出金额 i 的最少硬币数
    dp[0] = 0  # 金额 0 需要 0 枚硬币

    for i in range(1, amount + 1):
        for coin in coins:
            if coin <= i:
                dp[i] = min(dp[i], dp[i - coin] + 1)  # 更新最少硬币数

    return dp[amount] if dp[amount] != amount + 1 else -1

print(coin_change([1, 2, 5], 11))  # 3
print(coin_change([2], 3))         # -1

38.12.1 BFS 网格最短路

from collections import deque

def shortest_path(grid: list[list[int]], start: tuple[int, int], end: tuple[int, int]) -> int:
    rows, cols = len(grid), len(grid[0])
    queue = deque([(start[0], start[1], 0)])  # (row, col, distance)
    visited = {start}

    while queue:
        r, c, dist = queue.popleft()  # 出队当前格子
        if (r, c) == end:
            return dist
        for dr, dc in ((1, 0), (-1, 0), (0, 1), (0, -1)):
            nr, nc = r + dr, c + dc
            if 0 <= nr < rows and 0 <= nc < cols and grid[nr][nc] == 0 and (nr, nc) not in visited:
                visited.add((nr, nc))             # 标记已访问
                queue.append((nr, nc, dist + 1))  # 入队，距离加一

    return -1

grid = [
    [0, 0, 0],
    [1, 1, 0],
    [0, 0, 0],
]
print(shortest_path(grid, (0, 0), (2, 2)))  # 4

38.12.2 DFS 与回溯

def subsets(nums: list[int]) -> list[list[int]]:
    result = []
    path = []

    def backtrack(start: int) -> None:
        result.append(path.copy())  # 复制当前路径，避免后续修改影响结果
        for i in range(start, len(nums)):
            path.append(nums[i])  # 选择当前元素
            backtrack(i + 1)
            path.pop()            # 回溯，撤销选择

    backtrack(0)
    return result

print(subsets([1, 2, 3]))  # [[], [1], [1, 2], [1, 2, 3], [1, 3], [2], [2, 3], [3]]

38.12.3 二叉树遍历

class TreeNode:
    def __init__(self, val: int = 0, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right

def inorder(root: TreeNode | None) -> list[int]:
    result = []

    def dfs(node: TreeNode | None) -> None:
        if node is None:
            return
        dfs(node.left)
        result.append(node.val)  # 访问当前节点
        dfs(node.right)

    dfs(root)
    return result

38.12.4 反转链表

class ListNode:
    def __init__(self, val: int = 0, next: "ListNode | None" = None):
        self.val = val
        self.next = next

def reverse_list(head: ListNode | None) -> ListNode | None:
    prev = None
    while head:
        nxt = head.next   # 先记住下一个节点
        head.next = prev  # 反转当前节点的指针
        prev = head       # prev 前移
        head = nxt        # head 前移
    return prev

38.12.5 并查集

class UnionFind:
    def __init__(self, n: int):
        self.parent = list(range(n))  # 每个元素自成一个集合
        self.rank = [0] * n

    def find(self, x: int) -> int:
        if self.parent[x] != x:
            self.parent[x] = self.find(self.parent[x])  # 路径压缩
        return self.parent[x]

    def union(self, a: int, b: int) -> bool:
        root_a, root_b = self.find(a), self.find(b)
        if root_a == root_b:
            return False  # 已经在同一集合
        if self.rank[root_a] < self.rank[root_b]:
            root_a, root_b = root_b, root_a
        self.parent[root_b] = root_a  # 合并到 root_a
        if self.rank[root_a] == self.rank[root_b]:
            self.rank[root_a] += 1  # 合并后秩加一
        return True

uf = UnionFind(5)
print(uf.union(0, 1))  # True
print(uf.union(1, 2))  # True
print(uf.union(0, 2))  # False，已经在同一集合

38.13.3 re：字符串题的正则工具

re 是标准库，处理复杂分隔、提取数字、替换空白时非常省事。先记住几个函数：

  • re.findall(pattern, text)：找出所有匹配；
  • re.search(pattern, text)：找第一个匹配；
  • re.match(pattern, text)：从开头匹配；
  • re.fullmatch(pattern, text)：整个字符串完全匹配；
  • re.sub(pattern, repl, text)：替换；
  • re.split(pattern, text)：按正则拆分。
import re

print(bool(re.fullmatch(r"[A-Za-z]+", "abc")))  # True
print(re.sub(r"\s+", " ", "a   b\tc"))  # a b c
print(re.split(r"[,;]\s*", "a, b;c"))  # ['a', 'b', 'c']

print(d)                    # {'a': 3}
print(dict.fromkeys(["x", "y"], 0))  # {'x': 0, 'y': 0}

集合的子集、超集和不相交判断：

a = {1, 2, 3}
b = {1, 2}

print(b.issubset(a))        # True
print(a.issuperset(b))      # True
print(a.isdisjoint({4, 5})) # True

38.14 高频坑与刷题流程

除法、取模和取整：

print(5 / 2)       # 2.5，真除法返回 float
print(5 // 2)      # 2，向下取整
print(-5 // 2)     # -3，朝负无穷取整
print(-5 % 2)      # 1，Python 取模结果与除数同号
print(int(-2.9))   # -2，向零截断
print(round(2.5))  # 2，银行家舍入

sort() 原地修改并返回 None，sorted() 返回新列表：

nums = [3, 1, 2]

result = nums.sort()  # result 为 None，nums 变为 [1, 2, 3]
print(result)         # None
print(sorted(nums))   # [1, 2, 3]

不要用可变对象作为默认参数：

def bad(path, result=[]):  # 默认列表只创建一次，会被多次调用共享
    result.append(path)  # 把当前路径加入结果
    return result

print(bad("a"))  # ['a']
print(bad("b"))  # ['a', 'b']

字符串不可原地修改：

s = "abc"
# s[0] = "x"  # TypeError: 'str' object does not support item assignment
s = "x" + s[1:]  # s 变为 'xbc'
print(s)         # xbc

不要边遍历边删除列表元素，遍历副本或用推导式：

nums = [1, 2, 3, 4]

for num in nums.copy():  # 遍历副本
    if num % 2 == 0:
        nums.remove(num)  # nums 变为 [1, 3]

print(nums)  # [1, 3]

heapq 的常见坑：

  • 默认是最小堆，大根堆要存负数；
  • 元组堆如果第一个元素相同，会继续比较后面的元素；后面的对象不可比较时要加自增下标；
  • heapify() 原地修改列表，不会返回新列表；
  • 空堆调用 heappop() 会抛 IndexError。

最后是一张“看到需求 → 想到工具”的速查表：

需求 优先使用的 Python 工具
计数 collections.Counter
分组 collections.defaultdict(list)
先进先出 collections.deque
后进先出 list 的 append() / pop()
Top K / 第 K 大 heapq（最小堆，维护大小为 k）
最值流 heapq
有序数组查找 bisect_left / bisect_right
去重且保序 dict.fromkeys()
记忆化 functools.lru_cache
简单排序 sorted(key=...)
多字段排序 key=lambda x: (x.a, -x.b)
复杂比较器 functools.cmp_to_key
前缀和 itertools.accumulate 或手写
枚举组合 itertools.combinations / permutations
图/网格遍历 deque + visited 集合
最短路 heapq + dist 数组
并查集 手写 parent + rank

刷题时按这个顺序推进：

  1. 先用最直白的暴力写法把题意跑通；
  2. 再判断瓶颈是查找、计数、排序、枚举还是重复子问题；
  3. 从上面的表里选数据结构和模板替换暴力部分；
  4. 用空输入、单元素、重复值、极值四类用例自测；
  5. 最后写清时间复杂度和空间复杂度。
