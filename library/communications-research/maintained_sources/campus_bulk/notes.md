# 通信工程校招批量补充：campus_bulk

采集窗口：2026-11-18（Asia/Shanghai）。本目录仅补充中国联通公开校招数据，以及已完成详情采集的烽火通信 38 条和中兴通讯 1 条；不修改专题目录中的其他成果。

## 交付文件

- `records.jsonl`：去重后保留的完整 JD；每条均为 `row_kind=full_jd`，专业筛选结果单独写入 `major_screen_class`。
- `screening_results.jsonl`：所有来源的逐行筛选审计，含排除行、重复行、岗位详情、学历/经验/学生资格、来源、专业证据和去重状态。
- `union_screening_results.jsonl`、`sd_screening_results.jsonl`、`fiberhome_screening_results.jsonl`、`zte_screening_results.jsonl`：来源分项审计。
- `union_records.jsonl`、`sd_records.jsonl`、`fiberhome_records.jsonl`、`zte_records.jsonl`：来源分项的合格完整 JD。
- `dedup_log.json`：按来源岗位 ID 去重的完整分组日志。
- `collection_summary.json`：来源行数、筛选结果和完整详情分母。
- `source_manifest.json`：来源入口、采集方式、原始归档路径及 SHA-256、官方依据链接和派生文件哈希。
- `source_archive/`：抓取的 HTML、JSON、JS 及正常匿名浏览器 UI 看到的完整详情文本/JSON。
- `finalize_campus.py`：可复跑的字段提取、筛选、去重及清单生成脚本。

山东数据有 324 条原始行含智联 `jobNumber`，对应 323 个不同号码；另有 7 条没有 `jobNumber`、没有 `iguopinId`，也没有详情正文。它们使用标明来源和定位字段的合成定位 ID，保留在全量审计中并记为 `listing_only` / excluded；没有因职位名称中的“通信”字样纳入。山东数据与联通 API 的 `jobNumber` 交集为 0。去重和 ID 来源细节见 `dedup_log.json` 及每行的 `source_job_id_note`。

## 专业筛选规则

- 仅使用岗位 `needMajor`/Major 字段，或单条 JD 的“任职要求/专业要求/相关专业”资格行。职责、公司介绍、岗位标题中的通信字样不作为专业证据。
- `direct`：岗位专业资格明确列出通信工程、通信类或通信相关专业。
- `adjacent`：专业资格明确列出电子信息/电子相关学科，但没有直接列出通信类；是否接受通信工程需以招聘单位审核为准。
- `major_catalog_match=true` 只表示原文出现广义“电子信息类”。教育部 2026 本科目录将通信工程（080703）列在电子信息类（0807）下；这只是专业目录对应关系，仍需核对岗位学历、单位代码及招聘单位的报名审核。单列“电子信息工程”是具体专业，未因此标成大类匹配。
- 没有完整详情或没有职位级专业条件的记录保留在审计，但不进入 `records.jsonl`。

## 学生资格、日期与限制

- 最终 1,109 条记录中，599 条在岗位正文明确写有“2027届、2026届未就业可投”（联通 API 319 条，山东批次 280 条）。其余按原文保留“2027届”、一般应届生或未注明年份等状态，没有推断个人资格。
- 山东就业平台公告发布日期为 2026-09-15，过期时间为 **2026-11-15**；截至本次采集日已过期。职位本身没有可信的发布日期字段，因此山东 `posted_date=null`，公告发布日期未被误作岗位发布日期。山东岗位 `application_deadline` 保留公告截止日。
- 联通智联 API 的 `modifiedTime` 语义不明确，`posted_date` 和岗位截止日均留空。烽火与中兴只在招聘职位卡明确显示“发布于”日期时使用该日期。
- 中兴详情展示应届生招聘投递窗口为 2026-06-01 至 2027-08-31；结构化保留截止日和原文。中兴集团归属未在本批次核实，因此 `parent_group=null`。
- 本数据是公开招聘 JD 样本，不能据此推算全国 HC 或实际录用人数。

## 归属依据与采集边界

- 中国联通集团归属以国务院国资委央企名录和天津大学官方招聘公告为依据；山东雇主招聘入口由山东高校就业平台公告链接验证。
- 烽火详情页明确显示“烽火通信科技股份有限公司是中国信科集团旗下上市企业”；中国信科官网组织架构页列出烽火通信，中国信科集团介绍页说明其为国务院国资委直属中央企业。对应官方链接见 `source_manifest.json`。
- 2026 教育部本科目录原始 HTML 已归档。国资委和中国信科页面链接保留在清单中；本机对这两站的原始下载遇到 TLS 证书/连接错误，相关页面内容通过公开官方页面检索核对，未伪称已保存原始 HTML。
- 中兴只纳入一条可稳定复核的完整详情；列表中还有其他岗位，但批量详情 API 返回加密字段。本次未解密、构造签名或绕过保护。南开就业公告原始请求返回 403，失败状态及响应已归档。
- 设备商范围按父任务指定，只完成现有烽火 38 条和中兴 1 条，不据此推断其他设备商岗位覆盖情况。

所有原始归档文件的字节数和 SHA-256 列在 `source_manifest.json`；全量 API 页响应和筛选脚本均在本目录内，可复核 1,619 条联通职位的专业筛选与排除计数。
