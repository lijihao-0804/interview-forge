2025 年 5 月 21 日答辩，有老师问到两位同学都用了 LoRA，各自训练的模型从哪里来。VoltEdu 的回答可以沿一条具体样本展开。开关接线是输入，电容如何放电是参考答案。监督微调决定模型要预测哪些词，LoRA 决定预测错了以后，哪些权重可以改。

面试时可以这样讲

我用大模型按电路知识点出题，再用整理后的文字问答训练公开的 DeepSeek-R1 蒸馏模型。训练时让模型根据题干、接线条件和参考解里已有的步骤，预测答案的下一个 token。基座权重冻结，误差沿计算图传到插入线性层的两个小矩阵。我的工作是做课程数据、训练和比较两套适配方案，最后把 7B 接进 VoltEdu 的文本问答。

出题脚本调用 deepseek-r1-250120，保存的是回答文本。论文把生成方记为 671B 的 DeepSeek-R1。用于课程训练的是已发布的 DeepSeek-R1-Distill-Qwen-1.5B 和 DeepSeek-R1-Distill-Qwen-7B，其上游分别是 Qwen2.5-Math-1.5B、Qwen2.5-Math-7B。蒸馏权重由 DeepSeek 发布，VoltEdu 用参考答案做监督微调（SFT）。DeepSeek 官方模型卡的基座对照表

一道题怎样变成损失

以原题库的 RC 放电题为例。归档 LLaMA-Factory 的 Alpaca 转换器把 instruction 和非空 input 用换行拼为用户消息，把 output 放入助手消息。模型因此同时看到开关的连接关系和题干。默认 train_on_prompt=False 时，框架把提示正文的标签置为 −100，让交叉熵跳过这些位置。提示仍参与注意力计算。特殊结束标记的监督由对话模板决定。

训练时，每个回答位置看到的是参考答案给出的上文，推理时则接着自己已生成的词往下写。若 T 是本条样本参加监督的位置，平均损失可写为 L = −Σ[t∈T] ln pθ(y_t | 提示, y_<t) / |T|。白板举例，目标 token 的预测概率从 0.10 升到 0.50，该位置的损失就从 −ln(0.10) ≈ 2.303 降至 −ln(0.50) ≈ 0.693。

梯度也从这里来。设 z_j 是词 j 在 softmax 前的分数，p_j 是其预测概率。单位置交叉熵对它的导数为 p_j − 1[j 为目标词]。目标词概率为 0.10 时，导数就是 −0.90，沿负梯度更新会推高该词的分数。若样本把电流单位误标成 V，这一步也会推高错标的单位。损失追随参考解，电路量纲还需另外验算。

第一次反向传播为什么先更新 B

标准 LoRA 的一层可写成 h = W₀x + sB(Ax)，其中 s = α/r。用列向量，原权重 W₀ 为 m × n，A 为 r × n，B 为 m × r。先算 Ax 得到 r 个分量，再由 B 把这些分量组合成 m 维增量，故 rank(BA) ≤ r。原论文将 A 随机初始化、B 置零，初始增量恰为零，模型从基座原有的输出起步。LoRA 原论文第 4.1 节

设上游传来的梯度为 g = ∂L/∂h。忽略 dropout，对一个样本、一层求导，得到 ∂L/∂B = s·g(Ax)ᵀ，∂L/∂A = s·(Bᵀg)xᵀ。第一步 B 为零，A 的任务梯度为零。只要 g 和 Ax 都非零，B 就能更新。传向前一层的梯度仍有 W₀ᵀg + sAᵀBᵀg，冻结权重也能让误差通过该层。

教学例。 用平方误差和普通梯度下降，手算两次反向传播。取 W₀ = I₂、r = 1、s = 1、A = (1, 0)、B = (0, 0)ᵀ，输入 x = (2, 1)ᵀ，目标 h* = (2, 3)ᵀ，损失为 L = ½‖h − h*‖²。

时刻 前向怎么走 反向或更新得到什么
初次前向 Ax = 2，旁路输出为零，h = (2, 1)ᵀ L = 2，g = (0, −2)ᵀ
第一步反传并更新 ∂L/∂B = (0, −4)ᵀ，∂L/∂A = (0, 0) 学习率取 1/8，更新后 B = (0, 0.5)ᵀ，A 保持初值
再过同一个输入 旁路输出 (0, 1)ᵀ，新输出 h = (2, 2)ᵀ，L = 0.5 g = (0, −1)ᵀ，此时 ∂L/∂A = (−1, −0.5)，A 也收到了学习信号

rank、alpha 和目标层分别改变什么

教学例中若把一个线性层设成 4,096 × 4,096，原矩阵有 16,777,216 个参数。取 r = 8，A 和 B 合计 r(m+n) = 65,536 个参数，是该矩阵的 0.39%。取 r = 16，可训练参数翻倍为 131,072。若两次都用 α = 16，缩放 α/r 同时由 2 降到 1。想单独考察容量，可以把第二组改成 r = 16, α = 32，保持缩放为 2，再固定层、数据和更新预算。实际增量大小还取决于训练得到的 A、B。

目标层决定更新落在哪里。给注意力的 Q、V 投影加旁路，可以改变查询和传递的信息。若再覆盖前馈层，就多出一批形状可能不同的矩阵。全模型可训练量要对实际选中的各层累加 r(m+n)。归档框架 0.9.3.dev0 的默认配置是 r = 8、dropout = 0、target = all（由框架查找适用的线性层），未填 alpha 时取 2r。毕设最终参数表记录了学习率、批量等七项，当次的秩、alpha 和插入层没有记下来。

显存省在哪里，部署时能合并什么

白板估算按名义 70 亿参数、每个权重 2 字节计，单放基座约 14 GB。若全量更新，并假设梯度也用 2 字节、Adam 两组矩用 FP32，梯度约另占 14 GB，两组矩合计约 56 GB。LoRA 冻结基座后，这部分基座梯度和优化器状态可以省下，适配器自身仍要存权重、梯度和优化器状态。训练峰值还包括激活、临时张量等，随批量和序列长度变化。这些是逐项估算，项目记录的硬件是双 RTX 4090、每卡 24 GB。

两组毕设训练记录的是 LoRA 和 bf16 计算。若改做 QLoRA，典型变化是以 4 位保存冻结基座，计算时将所需权重反量化，把梯度传给适配器。改量化方式会改变基座的存储和数值误差，需要单独评测。QLoRA 原论文

推理时，标准线性 LoRA 在关闭 dropout 后可把 W₀ + sBA 合成一份权重，从而省去额外的两次小矩阵乘法。保留独立适配器则便于给同一基座换课程。VoltEdu 的 load_lora.py 实际从一个本地模型目录加载分词器和因果语言模型，GPU 路径用 FP16。代码从这个目录直接读模型，线上一次请求只需用已经装好的权重做推理。

面试追问与参考答案

问一　若同时把 A、B 都初始化为零，下一步会发生什么？

参考答案　从两条梯度式可见，Ax = 0 且 Bᵀg = 0，两个矩阵的任务梯度都会为零，普通梯度更新会停在原点。反过来若只把 A 置零、B 随机初始化，初始输出仍等于基座，通常先收到梯度的是 A。

问二　学习率和 alpha 都能让变化变大，白板上如何区分？

参考答案　固定 A、B 和 x，把 alpha 加倍，这次前向的旁路输出就加倍。固定参数把学习率加倍，这次前向的数值相同，变化出现在优化器的下一次更新。做秩对照时，我会同时写出 r、alpha 和缩放系数，再说明插入了哪些层。

问三　把 rank 减半，显存会减半吗？

参考答案　同一组线性层下，适配器参数量随 r 成正比。冻结基座的存储仍约占上面的 14 GB，大批量长序列还会占用激活显存。要解释一次真实的显存不足，我会先固定序列长度测每设备批量的峰值，再固定批量比较 rank，记录每次实际峰值。

问四　把同一个课程提示词发给基座，和训练一个适配器有什么区别？

参考答案　写提示词是给这次回答补充上下文，比如请模型先标端口、再求开路电压。做 SFT 时，许多参考答案的预测误差共同更新 A、B，此后加载适配器就会改变下一词的条件概率。毕设表 3-4 比较了同组题上的 7B 基座与课程微调模型。若想知道一条精心设计的提示能追回多少分，我会再加一组固定强提示的基座，保持题目和解码设置相同。
