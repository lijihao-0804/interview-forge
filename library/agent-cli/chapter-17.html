17.2 为什么 Git 很适合 Agent

  • diff 提供明确变更集；
  • commit 是可回退检查点；
  • branch/worktree 隔离任务；
  • blame/history 提供设计背景；
  • PR 提供人类审查界面。

17.3 回滚不是万能撤销

文件检查点只能回滚受跟踪文件变化，无法自动撤销：

  • 已发送邮件；
  • 已执行支付；
  • 远程数据库更新；
  • 外部 API 副作用；
  • 已泄露的秘密。

因此副作用审批必须发生在执行之前。
