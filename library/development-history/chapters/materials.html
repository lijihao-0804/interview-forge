沿 Git 回看变化

本报告的主线取自当前分支截至 90b41de9 的历史。先用 git log --first-parent --oneline 看主线的合并顺序。读到某个短提交号时，用 git show --stat 提交号 看涉及哪些文件，再用 git show 提交号 -- 路径 看具体改动。每次只追一个行为，直到能说清用户看见的变化。

上传与续写

网站从学习书架的超级管理员入口打开这份报告。报告直接放在项目的 library/development-history 目录，点击篇名才加载那篇正文。本地副本保留 assets 和 chapters 的相对位置，双击 index.html 即可阅读。

更新已有章节时，只改对应 HTML。新增一篇时，沿用相邻章节的页头、正文和资料栏，在首页栏目中补一条链接，并更新相邻页的翻篇导航。

回到项目

开发历程选取实际提交串起阶段与合并。参考项目 AgentHub 的教学章给出了“同一个案例、沿途找实现、末尾做自测”的阅读方式，本报告中的案例、实现与测试记录均取自 InterviewForge。
