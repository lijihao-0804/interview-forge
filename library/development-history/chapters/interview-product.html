用《每日温度》讲清项目和取舍

设想一位准备 Python 面试的同学。去年他用 Java 通过了《每日温度》，现在认得解法，合上代码却写不出循环条件。他想再练一次，也想知道明天回来该先做什么。

给你一分钟，怎么向这位同学介绍 InterviewForge？

InterviewForge 是个面试备考站。我会请他从中控台搜“每日温度”，进 Hot 100 题页，换成 Python，试着讲清楚哪一天该出栈。公开题解和教材可以直接读。登录后，他可以记录这次练习的熟练程度，回到题库看下次复习日期，也可以在限时模拟里专挑自己还没用 Python 做过的题。

我把题解在构建时生成，把提交、评分和到期日留在账号里。同一份题面能给所有人看，个人复习队列会随每次练习改变。下次打开网站，他既能接着补今天卡住的地方，也能找到一道真正适合自己练 Python 的题。

切换到 Python 后，题页上什么内容真正帮到了他？

我会打开这道题的逐日推导。例子里第 5 天升到 72℃，栈顶两天的温度依次是 69℃、71℃。把这两个日期取出来，等待时间分别是一天、两天。再往前是 75℃，这个日期还得留下。读者可以对着表把这几个动作和 Python 的 stack[-1]、pop() 一一对上。

接着我给他三个温度 [70, 70, 71]。如果他写成大于等于，第二天就会提前结算第一天。题目要求等到更暖的一天，正确结果是 [2, 1, 0]。共用的题面给出判定标准，按语言写的讲解让他找得到自己该改的那一行。

他用 Java 通过了，为什么 Python 的“从未做过”还会抽出这道题？

这个筛选回答的是“我用选中的语言做过哪几题”。程序查有有效日期的通过记录，把 Python3 和 python 归成同一种语言。只有 Java 通过记录、Python 提交未通过、单纯浏览过题页，都会把这题留给他练。早期记录如果缺少语言，也保留在候选里，等拿到带语言的提交再更新。

我在开始之前反复预览，可抽题数会被我自己改掉吗？

预览和正式组卷共用同一套候选过滤。八道题的测试集里，只有第 1、3 题有有效的 Python 通过记录，预览报六题，正式抽取也只从这六题里选。预览不会写考试记录或近期抽题历史，所以多看几次候选数也不会改变后续抽题。

如果他同一天用两种语言都练了一遍，到期时复习几次？

这道题共用一张复习卡。语言进度保留他练过 Java 和 Python 的事实，题目总轮数按北京时间的不同练习日统计。测试把时间固定在 9 月 8 日，先记 Java 通过，再用 Python 手动评分，最后换回 Java 又点了一次评分。两个手动请求拿到相同的下次复习日，总轮数仍是一轮。所以我可以在 Python 题单里接着练这道题，到期提醒仍然只有一份。
