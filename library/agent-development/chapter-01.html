目标：从“会调用大模型”进阶到“能开发可靠、可评测、可维护的 Agent 系统”。
适用读者：已掌握 Python 基础和模型 API 调用（前置参考《Python 实用入门与 AI 开发：语法、API、并发及工程实践》）。
最后核对：2026-08-14（本次为审阅润色复核）。框架与模型变化很快，具体 API 以官方文档为准。
