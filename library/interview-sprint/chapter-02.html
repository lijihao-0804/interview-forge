全科八股自测总表

正在读取本章记录下次复习：—
请通过“启动学习站.cmd”进入，才能写入数据库。

全科 40 题，覆盖全部 15 门课的核心考点。盖住“一句话要点”自答，答不上就回对应课程对应章节，标记为薄弱点。

科目 问题 一句话要点
Java 核心 String 为什么不可变 不可变是前提：常量池复用、安全、hash 缓存稳定是收益
Java 核心 HashMap 底层 数组 + 链表 + 红黑树
Java 核心 为什么负载因子 0.75 空间与冲突次数的折中
Java 核心 ArrayList vs LinkedList 随机访问 vs 插入删除
Java 核心 泛型怎么实现的 编译期类型检查，运行期擦除
Java 核心 反射能干什么 运行时获取类信息并调用
并发 volatile 的作用 可见性与有序性，不保证原子
并发 synchronized 原理 监视器锁，锁升级：无锁→偏向→轻量→重量（偏向锁 JDK 15 起默认禁用，JEP 374）
并发 CAS 的问题 ABA、自旋 CPU 开销、只能单变量
并发 线程池七参数 核心/最大/队列/存活时间/时间单位/线程工厂/拒绝策略
并发 ThreadLocal 泄漏 key 弱引用，value 强引用，需 remove
JVM 运行时数据区 堆/栈/方法区/PC/本地方法栈
JVM GC 基础算法 标记清除/复制/标记整理/分代
JVM 双亲委派 父加载器先加载，防重复防篡改
OS 进程 vs 线程 资源分配单位 vs 调度单位
OS 死锁四条件 互斥/持有等待/不可剥夺/循环等待
OS epoll 优势 事件驱动，只返回就绪事件，免全量扫描（select/poll 为 O(n)）
网络 三次握手目的 同步双方序列号 + 协商窗口/MSS
网络 四次挥手 TIME_WAIT 等 2MSL 保证报文消失
网络 HTTP/1.1 vs 2.0 连接复用 vs 多路复用
网络 HTTPS 流程 证书验身份 + 非对称换对称密钥
MySQL 索引数据结构 B+ 树，矮、有序、范围友好
MySQL 默认隔离级别 REPEATABLE READ
MySQL MVCC 原理 版本链 + ReadView 快照读
MySQL 三大日志 redo 崩溃恢复、undo 回滚、binlog 复制
Redis 五种数据结构 String/Hash/List/Set/ZSet
Redis 缓存三兄弟 穿透/击穿/雪崩与对应解法
Redis 持久化 RDB 快照 + AOF 命令追加
Redis 分布式锁 SET NX EX（value 唯一 ID）+ Lua 校验释放 + 续期
Web Servlet 生命周期 init 一次、service 每次、destroy 收尾（单实例多线程，非线程安全）
Spring IoC 是什么 容器管理对象创建与依赖
Spring AOP 原理 JDK/CGLIB 动态代理
Spring Boot 自动装配 读 SPI 候选 + @Conditional 筛选
MQ 消息不丢失 生产 confirm + 多副本 + 手动 ACK
MQ 重复消费解决 唯一业务键 + 幂等
分布式 CAP 结论 P 必选（分区不可避免，故分区时在 C/A 间取舍），二选一
分布式 分布式事务 2PC 阻塞、TCC 补偿、Seata AT
分布式 一致性哈希 哈希环 + 虚拟节点
运维 Docker 镜像容器 只读模板 vs 运行实例
运维 K8s 核心对象 Pod/Deployment/Service 各司其职

1.1 自测方法

  • 第一轮：按科目刷，答不上的标红，回原课程精读对应章节；
  • 第二轮：随机抽 20 题限时作答，每题口头 60 秒内讲完；
  • 每轮结束把仍然卡壳的题抄进“薄弱清单”，第 5 章冲刺计划优先覆盖。
