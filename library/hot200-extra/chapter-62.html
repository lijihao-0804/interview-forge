题目与约束

从全是水的网格开始逐个加入陆地，每次返回四连通岛屿数；重复添加不产生新岛。

输入是 m 行 n 列网格及有效加地坐标序列。初始全水，只认上下左右相邻，每次添加后都要输出计数，包括重复坐标。

示例

在 1×3 网格依次加入最左、最右、中间、中间，岛数是 [1,2,1,1]。第三次加入把两个原岛接成一个。

Java 完整推导

核心不变量

每步完成后，每一座已激活的岛恰有一个并查集根，count 与这些不同根的个数相等。

思路推导

新格先作为独立分量使计数加一，随后与每个已经存在且根不同的邻居合并，每次真正合并才减一。

重新数连通块会反复走遍旧陆地。加一块地只能创建一个分量，或把原来的若干分量接起来；设接到 d 个不同旧岛，净变化就是 1−d。并查集根恰好代表“不同旧岛”的身份。

一格连接两个原岛

步骤 当前状态 为什么这样走
加入左端 陆地 {0}，count=1 没有已经激活的邻居。
加入右端 陆地 {0,2}，count=2 两端被中间水格隔开。
填中间 先加到 3，再并入两侧异根，count=1 新格连接两个原岛，发生两次有效合并。
重复填中间 输出 [1,2,1,1] 该格已经出现，不能再创建分量。

按秩合并不同岛根

坐标通过 i*n+j 映射到一维编号，id 为 −1 表示水。find 压缩路径，unionByRank 尽量让矮树接到高树。每看一个邻居都重新求当前根，避免同一岛被减两次。

Java 实现

import java.util.*;

class UnionFind {
    public int[] id;

    public UnionFind(int n) {
        id = new int[n];
        rank = new int[n];
        Arrays.fill(id, -1);
    }

    public void unionByRank(int u, int v) {
        final int i = find(u);
        final int j = find(v);
        if (i == j) return;
        if (rank[i] < rank[j]) {
            id[i] = j;
        } else if (rank[i] > rank[j]) {
            id[j] = i;
        } else {
            id[i] = j;
            ++rank[j];
        }
    }

    public int find(int u) {
        return id[u] == u ? u : (id[u] = find(id[u]));
    }

    private int[] rank;
}

class Solution {
    public List<Integer> numIslands2(int m, int n, int[][] positions) {
        final int[][] DIRS = {{0, 1}, {1, 0}, {0, -1}, {-1, 0}};
        List<Integer> ans = new ArrayList<>();
        boolean[][] seen = new boolean[m][n];
        UnionFind uf = new UnionFind(m * n);
        int count = 0;

        for (int[] p : positions) {
            final int i = p[0];
            final int j = p[1];
            // 重复添加陆地不会改变岛屿数量。
            if (seen[i][j]) {
                ans.add(count);
                continue;
            }
            seen[i][j] = true;
            final int id = getId(i, j, n);
            uf.id[id] = id;
            ++count;
            for (int[] dir : DIRS) {
                final int x = i + dir[0];
                final int y = j + dir[1];
                if (x < 0 || x == m || y < 0 || y == n) continue;
                final int neighborId = getId(x, y, n);
                if (uf.id[neighborId] == -1) continue;
                final int currentParent = uf.find(id);
                final int neighborParent = uf.find(neighborId);
                if (currentParent != neighborParent) {
                    uf.unionByRank(currentParent, neighborParent);
                    --count;
                }
            }
            ans.add(count);
        }

        return ans;
    }

    private int getId(int i, int j, int n) {
        return i * n + j;
    }
}

复杂度

初始化 O(mn)，k 次加入总计 O(kα(mn))；存储 O(mn)，结果另占 O(k)。

建好父指针、秩和访问表需要遍历 mn 个槽。每次加地最多查看四个邻居，按秩合并配合路径压缩得到所述摊销界。

易错点

重复添加已经是陆地的坐标应原样返回当前岛数。新地块同时接触同一座岛的两条边时，也只能因合并而减一次。

反例推演

在 1×2 网格依次加入 (0,0)、(0,0)、(0,1)，答案为 1、1、1。重复加入同一格不会制造新岛，更不能再次与邻居扣减计数。

面试追问

如果网格特别大却只添加几十块呢？ 可用坐标到父指针的字典只存已激活土地，四邻通过字典存在性判断，把初始化与存储从网格面积降到添加数量。

用坐标编号识别重复陆地

seen[i][j] 区分重复操作，uf.id 记录各陆地的父指针。每次处理完四邻，count 就是当前根的个数，此时才向 ans 追加一项。

Python 实现

from __future__ import annotations


class UnionFind:
    def __init__(self, n: int):
        self.id = [-1] * n
        self.rank = [0] * n

    def unionByRank(self, u: int, v: int) -> None:
        i = self.find(u)
        j = self.find(v)
        if i == j:
            return
        if self.rank[i] < self.rank[j]:
            self.id[i] = j
        elif self.rank[i] > self.rank[j]:
            self.id[j] = i
        else:
            self.id[i] = j
            self.rank[j] += 1

    def find(self, u: int) -> int:
        if self.id[u] != u:
            self.id[u] = self.find(self.id[u])
        return self.id[u]


class Solution:
    def numIslands2(
        self,
        m: int,
        n: int,
        positions: list[list[int]],
    ) -> list[int]:
        DIRS = ((0, 1), (1, 0), (0, -1), (-1, 0))
        ans = []
        seen = [[False] * n for _ in range(m)]
        uf = UnionFind(m * n)
        count = 0

        def getId(i: int, j: int, n: int) -> int:
            return i * n + j

        for i, j in positions:
            # 重复添加陆地不会改变岛屿数量。
            if seen[i][j]:
                ans.append(count)
                continue
            seen[i][j] = True
            id = getId(i, j, n)
            uf.id[id] = id
            count += 1
            for dx, dy in DIRS:
                x = i + dx
                y = j + dy
                if x < 0 or x == m or y < 0 or y == n:
                    continue
                neighborId = getId(x, y, n)
                if uf.id[neighborId] == -1:
                    continue
                currentParent = uf.find(id)
                neighborParent = uf.find(neighborId)
                if currentParent != neighborParent:
                    uf.unionByRank(currentParent, neighborParent)
                    count -= 1
            ans.append(count)

        return ans
