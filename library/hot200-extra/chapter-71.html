333. 最大二叉搜索子树

Python 主方法弹出子树摘要后再合并复杂度n 个节点各入栈、出栈常数次，期望时间 O(n)。父节点合并时移除孩子的摘要，同时保留的摘要与显式栈规模均为 O(h)，h 为树高。

题目与约束

在普通二叉树内，求整棵子树满足严格二叉搜索树次序时的最大节点数。

输入为普通二叉树，要求选一个节点连同它的全部后代作为严格二叉搜索子树。空树返回 0。

示例

根 5、左子 2、右子 7，且 7 的左子是 4。子树 7→4 合法，整树因右子树含 4 而失败，答案 2。

Java 完整推导

核心不变量

父节点复访时，两侧摘要已就绪；合法摘要的范围是真实极值，非法摘要只能传递内部最大规模。

思路推导

显式栈用“第一次访问”和“子树已处理”两个状态完成后序遍历。对子树汇总最小值、最大值及最大合法大小。左右均合法且左最大值 < 根值 < 右最小值时可以合并，否则保留两侧的最佳大小，并用相反的无穷边界阻止祖先把它当成合法子树。父节点用完后立即移除孩子的摘要。

若在每个候选根重新验证整棵子树，同一批孙节点会被检查很多次。父节点只需要孩子给出边界和规模。合法子树向上报告真实边界；不合法子树仍须传回内部最佳大小，但让边界必然无法参与下一层合并。

根 5 为何不能加入合法子树

步骤 当前状态 为什么这样走
计算叶子 2 的摘要 (2,2,1)，4 的摘要 (4,4,1) 单个节点都是大小为 1 的搜索树。
合并节点 7 4<7，子树 7 的摘要 (4,7,2) 根 7 加上左孩子 4，整棵合法。
检查根 5 右侧最小值 4<5，选 max(1,2)=2 局部关系 5<7 无法保证全树合法。

带就绪标志的后序栈

Visit.ready 区分初访与子树返回。IdentityHashMap 以节点身份存 Summary，即使两个节点同值也不会共用摘要。空孩子的 long 极值让任意 int 叶子的严格比较都能通过。

Java 实现

import java.util.ArrayDeque;
import java.util.Deque;
import java.util.IdentityHashMap;
import java.util.Map;

class Solution {
    private record Visit(TreeNode node, boolean ready) {}

    private record Summary(long low, long high, int best) {}

    public int largestBSTSubtree(TreeNode root) {
        if (root == null) return 0;
        Summary empty = new Summary(Long.MAX_VALUE, Long.MIN_VALUE, 0);
        Map<TreeNode, Summary> results = new IdentityHashMap<>();
        Deque<Visit> stack = new ArrayDeque<>();
        stack.push(new Visit(root, false));
        while (!stack.isEmpty()) {
            Visit visit = stack.pop();
            TreeNode node = visit.node();
            if (!visit.ready()) {
                // 父节点排在两个孩子之后计算。
                stack.push(new Visit(node, true));
                if (node.right != null) stack.push(new Visit(node.right, false));
                if (node.left != null) stack.push(new Visit(node.left, false));
                continue;
            }
            Summary left = node.left == null ? empty : results.remove(node.left);
            Summary right = node.right == null ? empty : results.remove(node.right);
            if (left.high() < node.val && node.val < right.low()) {
                results.put(
                        node,
                        new Summary(
                                Math.min(left.low(), node.val),
                                Math.max(right.high(), node.val),
                                left.best() + right.best() + 1));
            } else {
                results.put(
                        node,
                        new Summary(
                                Long.MIN_VALUE,
                                Long.MAX_VALUE,
                                Math.max(left.best(), right.best())));
            }
        }
        return results.get(root).best();
    }
}

复杂度

n 个节点各入栈、出栈常数次，期望时间 O(n)。父节点合并时移除孩子的摘要，同时保留的摘要与显式栈规模均为 O(h)，h 为树高。

每个节点初访、复访各一次。孩子摘要被父亲消费后删除，深搜每层只需保留待合并分支的信息，额外存储为 O(h)。

易错点

判断整棵子树是否合法要比较左子树最大值、根和右子树最小值。只把根与两个直接孩子比较，会漏过例子里藏在右子树中的 4。

面试追问

若允许删掉几个后代再组成搜索树呢？ 本算法要求选中根后包含它的全部后代。允许删点就不能用一次越界永久否决这棵子树，状态必须描述可舍弃的节点。

弹出子树摘要后再合并

results.pop(child,empty) 同时取出和释放孩子摘要。空树用 (∞,−∞,0)，非法子树恰好颠倒这对极值；left_max < node.val < right_min 足以完成合法性检查。

Python 实现

from __future__ import annotations
from math import inf


class Solution:
    def largestBSTSubtree(self, root: TreeNode | None) -> int:
        if root is None:
            return 0
        empty = (inf, -inf, 0)
        results = {}
        stack = [(root, False)]
        while stack:
            node, ready = stack.pop()
            if not ready:
                stack.append((node, True))
                if node.right is not None:
                    stack.append((node.right, False))
                if node.left is not None:
                    stack.append((node.left, False))
                continue
            # 后序遍历保证非空孩子的摘要已经算好。
            left_min, left_max, left_size = results.pop(node.left, empty)
            right_min, right_max, right_size = results.pop(node.right, empty)
            if left_max < node.val < right_min:
                results[node] = (
                    min(left_min, node.val),
                    max(right_max, node.val),
                    left_size + right_size + 1,
                )
            else:
                results[node] = (-inf, inf, max(left_size, right_size))
        return results[root][2]
