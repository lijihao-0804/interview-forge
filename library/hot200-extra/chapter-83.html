360. 有序转化数组

难度中等专题数组题单位置第 183 位
Java 主方法两个端点与输出写入方向复杂度时间 O(n)，输出占 O(n)，预先计算变换值的实现另用 O(n)。
Python 主方法对预先求出的函数值做端点合并复杂度时间 O(n)，输出占 O(n)，预先计算变换值的实现另用 O(n)。

题目与约束

对升序数组各元素施加 ax²+bx+c，返回变换后的升序序列。

输入整数数组已按非递减顺序排列，给定整数 a、b、c，返回每项经 ax²+bx+c 变换后的升序结果。

示例

[-3,-1,2] 经 x² 变成 [9,1,4]。从两端取较大值填入末尾，依次放入 9、4、1，得到 [1,4,9]。

Java 完整推导

核心不变量

未选的原下标始终构成连续区间，开口向上时结果后缀已放最大值，其他情形结果前缀已放最小值。

思路推导

开口向上的抛物线在当前闭区间的最大值位于一个端点，故从大到小填；开口向下时改取端点最小值由小到大填。线性函数也满足端点性质。

二次函数的顶点可能在数组中间，原顺序会先降后升或先升后降。开口向上时，对任意当前区间，函数的最大值都在两端之一；取走较大的端点便得到一个新的较短区间。开口向下则对最小值使用同一论证。

平方后如何归位 9、4、1

步骤 当前状态 为什么这样走
挑最大端 端点 f(−3)=9，f(2)=4，ans[2]=9 开口向上，当前最大在两端。
比较剩余端 f(−1)=1，f(2)=4，ans[1]=4 消去右端 2。
填最后一格 剩 −1，ans[0]=1，结果 [1,4,9] 三次选出的值由大到小写入后缀。

两个端点与输出写入方向

quad 预先保存各函数值。upward 决定 i 从末端向前还是从头向后，l、r 每轮仅推进被选中的一端。函数写成 (ax+b)x+c 与二次式相等。

Java 实现

class Solution {
    public int[] sortTransformedArray(int[] nums, int a, int b, int c) {
        final int n = nums.length;
        final boolean upward = a > 0;
        int[] ans = new int[n];
        int[] quad = new int[n];

        for (int i = 0; i < nums.length; ++i) quad[i] = f(nums[i], a, b, c);

        int i = upward ? n - 1 : 0;
        // 开口朝上时端点提供最大值，朝下时端点提供最小值。
        for (int l = 0, r = n - 1; l <= r; )
            if (upward) ans[i--] = quad[l] > quad[r] ? quad[l++] : quad[r--];
            else ans[i++] = quad[l] < quad[r] ? quad[l++] : quad[r--];

        return ans;
    }

    private int f(int x, int a, int b, int c) {
        return (a * x + b) * x + c;
    }
}

复杂度

时间 O(n)，输出占 O(n)，预先计算变换值的实现另用 O(n)。

先线性计算 n 个函数值，再进行 n 次端点比较。除结果外，当前代码的 quad 也占 n 个槽；按需算端点可以省去它。

易错点

抛物线开口向上时，两端较大的函数值应放到结果尾部；开口向下时反过来填。即使原 x 已有序，也不能假设变换后的值仍按原顺序。

反例推演

对有序输入 [-2,0,2] 使用 f(x)=-x²，端点值为 −4，中央为 0。开口向下时应从结果前端填最小值，不能沿用向上开口的填法。

面试追问

a=0 为什么能走“取小端”分支？ 线性函数在整个区间单调或恒定，最小值也位于某个端点，无论斜率正负都可以从小到大填。

Python 完整推导

核心不变量

未选的原下标始终构成连续区间，开口向上时结果后缀已放最大值，其他情形结果前缀已放最小值。

挑最大端 端点 f(−3)=9，f(2)=4，ans[2]=9 开口向上，当前最大在两端。
比较剩余端 f(−1)=1，f(2)=4，ans[1]=4 消去右端 2。
填最后一格 剩 −1，ans[0]=1，结果 [1,4,9] 三次选出的值由大到小写入后缀。

对预先求出的函数值做端点合并

在 while 的每轮开头，quad[l:r+1] 是剩余候选，而已经写进 ans 的部分已归位。相等时取右端不会改变排序，也仍然只消费一个元素。

Python 实现

from __future__ import annotations


class Solution:
    def sortTransformedArray(
        self,
        nums: list[int],
        a: int,
        b: int,
        c: int,
    ) -> list[int]:
        n = len(nums)
        upward = a > 0
        ans = [0] * n

        def f(x: int, a: int, b: int, c: int) -> int:
            return (a * x + b) * x + c

        quad = [f(num, a, b, c) for num in nums]

        i = n - 1 if upward else 0
        l = 0
        r = n - 1
        # 开口朝上时端点提供最大值，朝下时端点提供最小值。
        while l <= r:
            if upward:
                if quad[l] > quad[r]:
                    ans[i] = quad[l]
                    l += 1
                else:
                    ans[i] = quad[r]
                    r -= 1
                i -= 1
            else:
                if quad[l] < quad[r]:
                    ans[i] = quad[l]
                    l += 1
                else:
                    ans[i] = quad[r]
                    r -= 1
                i += 1

        return ans
