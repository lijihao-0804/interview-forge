281. 锯齿迭代器

本题学习状态正在读取学习记录…下次复习：—
本次复习：

遮住推导与代码，先自己想，再逐段揭示
难度中等专题设计题单位置第 152 位
Java 主方法迭代器出队后何时再入队复杂度遍历总时间 O(n+m)，状态空间 O(1)，输入序列由调用方持有。
Python 主方法生成器暂停在哪里复杂度遍历总时间 O(n+m)，状态空间 O(1)，输入序列由调用方持有。

题目与约束

设计迭代器，轮流取两个序列的下一项。一个序列耗尽后读完另一个。

构造器接收两份已给定顺序的整数列表，可有空列表。hasNext 不消费元素，next 在仍有元素时调用。

示例

两个输入 [4,9,8]、[2] 依次产生 4、2、9、8。读完第四项后 hasNext 返回 false。

🔗 前往力扣原题验证 →

Java 完整推导

核心不变量

已输出各序列的前缀保持原序；每一轮为每个尚未耗尽的序列贡献至多一项。

思路推导

按同一位置先读第一组再读第二组，跳过越过末尾的索引；也可轮转尚有剩余元素的迭代器。每个元素恰好被访问一次。

提前交织出一个新列表也能回答 next，却会复制尚未请求的全部元素。观察下一项只取决于轮到谁和各自消费到哪里，这两部分状态足以按需产出。

长列表与单元素列表轮转

步骤 当前状态 为什么这样走
第一组先出 A=[4,9,8]，B=[2]，先输出 4 A 还有 9、8，轮次交给 B。
第二组耗尽 已输出 [4,2]，B 没有下一项 下一轮只有 A 能提供元素。
读完余项 再输出 9、8，剩余数 0 此时 hasNext 为 false。

迭代器出队后何时再入队

ArrayDeque 里的每个 Iterator<Integer> 都已确认还有下一项。队首取值后才判断是否需要回到队尾，因此 hasNext 只查队列是否为空，不会提前消费。

Java 实现

import java.util.*;

public class ZigzagIterator {
    public ZigzagIterator(List<Integer> v1, List<Integer> v2) {
        // 只轮转尚有剩余元素的序列，较短的序列可以先耗尽。
        if (!v1.isEmpty()) q.offer(v1.iterator());
        if (!v2.isEmpty()) q.offer(v2.iterator());
    }

    public int next() {
        final Iterator<Integer> it = q.poll();
        final int next = it.next();
        if (it.hasNext()) q.offer(it);
        return next;
    }

    public boolean hasNext() {
        return !q.isEmpty();
    }

    private Queue<Iterator<Integer>> q = new ArrayDeque<>();
}

复杂度

遍历总时间 O(n+m)，状态空间 O(1)，输入序列由调用方持有。

两个序列时每一列最多检查两项，遍历与输出总数成正比。队列最多两项，生成器只保存当前循环位置。

易错点

从一个序列取出一个元素后，只有该序列还有下一项才把它排到队尾。一方先耗尽时，另一方可以连续输出剩余项。

面试追问

若有 k 个长度悬殊的序列呢？ Java 的活跃迭代器队列可直接扩到 k，空序列只在初始化检查一次，每次取一项仍为常数工作。逐列扫描全部 k 组会反复检查已经读完的组。

生成器暂停在哪里

生成器 vals 按下标 i 扫过 v1、v2，在 yield 处暂停，下一次从原位置恢复。无限的 count 自己不会报告耗尽，所以用 self.n 记录合法调用次数，调用者先检查 hasNext。

Python 实现

from __future__ import annotations
import itertools


class ZigzagIterator:
    def __init__(self, v1: list[int], v2: list[int]):
        def vals():
            # 只轮转尚有剩余元素的序列，较短的序列可以先耗尽。
            for i in itertools.count():
                for v in v1, v2:
                    if i < len(v):
                        yield v[i]

        self.vals = vals()
        self.n = len(v1) + len(v2)

    def next(self):
        self.n -= 1
        return next(self.vals)

    def hasNext(self):
        return self.n > 0

遍历总时间 O(n+m)，状态空间 O(1)，输入序列由调用方持有。
