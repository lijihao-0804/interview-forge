711. 不同岛屿的数量 II

Python 主方法把两座三格岛摆到同一方向复杂度N 个格子；遍历 O(N)，所有岛屿坐标的排序合计至多 O(N log N)，空间 O(N)。

题目与约束

按上下左右连通找出岛屿。允许平移、旋转或翻转后可以重合的岛屿只算一种。

输入非空二进制矩形网格，只认上下左右邻接。可以平移、旋转 90° 的整数倍或作镜像，返回岛形等价类数。

示例

一座岛占格 (0,0)、(1,0)、(1,1)，另一座占 (3,3)、(3,4)、(4,3)。两座都是三格拐角，答案为 1。

Java 完整推导

核心不变量

每个陆地格只入栈一次；等价岛的八种规范化坐标表示组成同一集合。

思路推导

先用显式栈收集每座四连通岛的格子，发现邻格时立即标记，防止重复入栈。将坐标交换两轴并分别变号，得到八个可能方向。每组排序后把首点移到原点，再挑一种固定的最小表示；形状等价的两座岛必然得到相同的键。

一次 DFS 解决的是哪些格子属于同一座岛；第二个问题是怎样比较两组点。旋转和镜像只会交换两轴或改变坐标的符号。对八种结果分别排序并减去首点，平移便不再影响表示。等价的岛得到相同的一组候选键，反过来，只要某个候选完全相同，就有一种变换使两岛重合。

Java 用 boolean[][] 按位置标记访问，用 Deque 弹出待扩展的格子。原始 int[] 的集合比较会按对象身份判断，因此把排序、归一后的坐标编码成带边界的字符串，再放进 shapes。

把两座三格岛摆到同一方向

步骤 当前状态 判断依据
收集第一座岛 A={(0,0),(1,0),(1,1)} 相邻格按四个方向连通。
统一第二座的位置 B 减去 (3,3) 得 平移后两组点仍有不同朝向。
把 A 上下镜像再平移 A 变为 已经找到能重合的方向，八方向规范键也相同，种数为 1。

Java 实现

import java.util.*;

class Solution {
    private static final int[][] DIRS = {{-1, 0}, {1, 0}, {0, -1}, {0, 1}};

    public int numDistinctIslands2(int[][] grid) {
        int rows = grid.length, cols = grid[0].length;
        boolean[][] seen = new boolean[rows][cols];
        Set<String> shapes = new HashSet<>();
        for (int r = 0; r < rows; r++) {
            for (int c = 0; c < cols; c++) {
                if (grid[r][c] == 0 || seen[r][c]) continue;
                List<int[]> island = new ArrayList<>();
                Deque<int[]> stack = new ArrayDeque<>();
                stack.push(new int[] {r, c});
                seen[r][c] = true;
                while (!stack.isEmpty()) {
                    int[] cell = stack.pop();
                    island.add(cell);
                    for (int[] dir : DIRS) {
                        int x = cell[0] + dir[0], y = cell[1] + dir[1];
                        if (x < 0 || x >= rows || y < 0 || y >= cols) continue;
                        if (grid[x][y] == 1 && !seen[x][y]) {
                            seen[x][y] = true;
                            stack.push(new int[] {x, y});
                        }
                    }
                }
                shapes.add(canonical(island));
            }
        }
        return shapes.size();
    }

    private String canonical(List<int[]> island) {
        String best = null;
        for (int mode = 0; mode < 8; mode++) {
            List<int[]> points = new ArrayList<>();
            for (int[] cell : island) {
                int x = cell[(mode & 1)], y = cell[1 - (mode & 1)];
                points.add(new int[] {(mode & 2) == 0 ? x : -x, (mode & 4) == 0 ? y : -y});
            }
            points.sort(Comparator.comparingInt((int[] p) -> p[0]).thenComparingInt(p -> p[1]));
            // 去掉平移，只比较各点相对于这个方向首点的坐标。
            int[] origin = points.get(0);
            StringBuilder key = new StringBuilder();
            for (int[] p : points) {
                key.append(p[0] - origin[0]).append(',').append(p[1] - origin[1]).append(';');
            }
            String candidate = key.toString();
            if (best == null || candidate.compareTo(best) < 0) best = candidate;
        }
        return best;
    }
}

复杂度

N 个格子；遍历 O(N)，所有岛屿坐标的排序合计至多 O(N log N)，空间 O(N)。

DFS 对每格只做常数个邻居检查。每座含 k 格的岛需要常数八次 O(k log k) 排序，各岛 k 的和至多 N；访问标记与坐标存储合计线性。

易错点

两座岛可以出现在相隔很远的位置。每次旋转或镜像后都要重新统一平移原点，再比较整组坐标；只比较宽、高和面积会把不同的形状合并。

反例推演

三个格子组成的 L 形绕原点旋转后会平移到不同的绝对坐标。每一种旋转或镜像都须单独平移归一并排序，才能稳定比较两个岛。

面试追问

只记每步 DFS 的方向够吗？ 起点、邻居访问次序和岛的朝向都会影响遍历记录。要用它比较旋转等价，还需对所有朝向统一起点和遍历规则。坐标集合直接保留了全部几何信息。

Python 的 seen 保存 (行,列) 元组。每个方向先得到排序列表，再减去该方向自己的首点；把所得坐标转成 tuple 才能作为 shapes 的集合元素。min(forms) 给八个方向一致的选择规则。

把两座三格岛摆到同一方向

步骤 当前状态 判断依据
收集第一座岛 A={(0,0),(1,0),(1,1)} 相邻格按四个方向连通。
统一第二座的位置 B 减去 (3,3) 得 平移后两组点仍有不同朝向。

Python 实现

class Solution:
    def numDistinctIslands2(self, grid: list[list[int]]) -> int:
        rows, cols = len(grid), len(grid[0])
        seen, shapes = set(), set()

        def canonical(island):
            forms = []
            for swap in (False, True):
                for sx, sy in ((1, 1), (1, -1), (-1, 1), (-1, -1)):
                    points = sorted(
                        (sx * y, sy * x) if swap else (sx * x, sy * y) for x, y in island
                    )
                    x0, y0 = points[0]
                    forms.append(tuple((x - x0, y - y0) for x, y in points))
            return min(forms)

        for r in range(rows):
            for c in range(cols):
                if not grid[r][c] or (r, c) in seen:
                    continue
                island, stack = [], [(r, c)]
                seen.add((r, c))
                while stack:
                    x, y = stack.pop()
                    island.append((x, y))
                    for nx, ny in ((x - 1, y), (x + 1, y), (x, y - 1), (x, y + 1)):
                        if (
                            0 <= nx < rows
                            and 0 <= ny < cols
                            and grid[nx][ny]
                            and (nx, ny) not in seen
                        ):
                            # 入栈就标记，同一个格子只会被处理一次。
                            seen.add((nx, ny))
                            stack.append((nx, ny))
                shapes.add(canonical(island))
        return len(shapes)
