362. 敲击计数器

本题学习状态正在读取学习记录…下次复习：—
本次复习：
按 M 快速切换薄弱标记
遮住推导与代码，先自己想，再逐段揭示
难度中等专题设计题单位置第 185 位
Java 主方法两个数组区分时间与敲击数复杂度记录 O(1)，查询 O(300)，固定存储 O(300)。
Python 主方法按实际年龄汇总有效槽复杂度记录 O(1)，查询 O(300)，固定存储 O(300)。

题目与约束

记录按时间到达的敲击，查询最近 300 秒内的总次数。同一秒可以发生多次。

hit 和 getHits 使用非递减的秒时间戳，同秒可有多次 hit。窗口包含当前秒及之前 299 秒。

示例

在 1 秒记录两次、300 秒记录一次。300 秒查询为 3，301 秒查询为 1，恰好相差 300 秒的敲击已经过期。

Java 完整推导

核心不变量

每个槽保存该余数最近记录的完整秒及其次数，任意有效 300 秒窗口中同一槽至多代表一秒。

思路推导

用时间戳模 300 定位槽位。时间戳相同则累加，不同则覆盖旧计数；查询时以完整时间戳区分仍在窗口内的槽。

查询只需要最近 300 个不同的秒值，无论每秒有多少敲击。同余模 300 的两秒至少相隔 300，不能同时留在一个有效窗口里，所以可以共享槽位。完整时间戳用来分清这个槽当前代表哪一秒。

第 1 秒如何在第 301 秒过期

步骤 当前状态 为什么这样走
同秒合并 t=1 敲两次，槽 1 记录 (1,2) 第二次命中完整时间戳，只增加次数。
第 300 秒 槽 0 记录 (300,1)，查询结果 2+1=3 300−1=299，小于 300。
第 301 秒 槽 1 年龄 300 被排除，结果 1 第 300 秒的那次敲击仍有效。

两个数组区分时间与敲击数

timestamps[i] 存实际秒，hits[i] 存该秒累积次数。新秒占用旧槽时将次数直接设为 1；查询即使遇到未初始化的零槽，也只会加零次。

Java 实现

class HitCounter {
    public void hit(int timestamp) {
        final int i = timestamp % 300;
        // 模 300 的槽会复用，先比较完整时间戳才能累加。
        if (timestamps[i] == timestamp) {
            ++hits[i];
        } else {
            timestamps[i] = timestamp;
            hits[i] = 1;
        }
    }

    public int getHits(int timestamp) {
        int countHits = 0;
        for (int i = 0; i < 300; ++i) if (timestamp - timestamps[i] < 300) countHits += hits[i];
        return countHits;
    }

    private int[] timestamps = new int[300];
    private int[] hits = new int[300];
}

复杂度

记录 O(1)，查询 O(300)，固定存储 O(300)。

hit 用一次取模和一次访问。getHits 逐槽加总，若窗口大小泛化为 W，则查询 O(W)、空间 O(W)，与敲击总数无关。

易错点

在第 301 秒查询时，第 1 秒的敲击已在窗口外，第 2 秒的仍在窗口内。窗口左端是否取等号就用这两个时间点来检查。

反例推演

在第 1 秒命中，查询 300 秒仍计入，查询 301 秒则应淘汰。刚好相差 300 秒的记录已经落在有效区间之外。

面试追问

为什么不能让每个槽只存计数？ 某秒过后长时间没有敲击，其计数可能一直停留在槽里。没有完整时间戳就无法在查询时区分它是否仍在窗口。

Python 完整推导

核心不变量

按实际年龄汇总有效槽

zip(self.timestamps,self.hits) 一一配对查询。输入时间非递减，因此只需检查 timestamp−t<300；不能只依槽号判断，因为过期槽未必已被覆盖。

Python 实现

from __future__ import annotations


class HitCounter:
    def __init__(self):
        self.timestamps = [0] * 300
        self.hits = [0] * 300

    def hit(self, timestamp: int) -> None:
        i = timestamp % 300
        # 模 300 的槽会复用，先比较完整时间戳才能累加。
        if self.timestamps[i] == timestamp:
            self.hits[i] += 1
        else:
            self.timestamps[i] = timestamp
            self.hits[i] = 1

    def getHits(self, timestamp: int) -> int:
        return sum(h for t, h in zip(self.timestamps, self.hits) if timestamp - t < 300)

复杂度

记录 O(1)，查询 O(300)，固定存储 O(300)。
