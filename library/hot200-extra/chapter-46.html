702. 搜索长度未知的有序数组

难度中等专题数组题单位置第 146 位
Java 主方法追踪下标 1、2、4 的指数上界复杂度若目标的插入位置为 p，调用数与时间 O(log(p+2))，辅助空间 O(1)。
Python 主方法追踪下标 1、2、4 的指数上界复杂度若目标的插入位置为 p，调用数与时间 O(log(p+2))，辅助空间 O(1)。

题目与约束

只能通过 reader.get(i) 读取严格递增数组，越界时得到特定大哨兵。返回目标下标，找不到返回 −1。

不提供数组长度，通过 reader.get(i) 读取严格递增数组，越界得到大于合法目标的哨兵。找到目标返回下标，否则返回 −1。

示例

隐藏数组为 [1,4,9,12,17]，查 12。从下标 1 再扩大到 2、4，确定上界 4，二分返回 3。

🔗 前往力扣原题验证 →

Java 完整推导

核心不变量

所有小于 low 的位置都已证实过小，扩张停止后 high 的读数一定大于等于目标。

思路推导

从小上界开始不断翻倍，直到读到不小于目标的值，越界哨兵同样能结束扩张。区间中二分，再确认终点的值确实等于目标。

没有数组长度就不能直接给二分提供右端，但 reader 的越界值比任何合法目标都大，因此“读数是否至少为 target”仍是单调谓词。先让右端成倍增加，直到越过谓词分界，再在封闭区间内寻找第一个满足条件的位置。

Java 把 low 推到旧 high+1，已经读过且过小的整个前缀随即淘汰。mid 用 low+(high-low)/2 计算；命中大于等于目标的值时保留 mid，直到 low 与 high 重合。

追踪下标 1、2、4 的指数上界

步骤 当前状态 判断依据
指数扩张 查 12；get(1)=4，get(2)=9，均过小 已排除下标 0 到 2。
锁定上界 读 get(4)=17，候选区间缩为 [3,4] 17≥12，首次形成包围区间。
执行二分 get(3)=12，high=3；最后确认 12，返回 3 相等时保留中点而非继续向右。

Java 实现

class Solution {
    public int search(ArrayReader reader, int target) {
        int low = 0, high = 1;
        // 上界逐次翻倍，第一次遇到目标、更大值或哨兵后转入二分。
        while (reader.get(high) < target) {
            low = high + 1;
            high *= 2;
        }
        while (low < high) {
            int mid = low + (high - low) / 2;
            if (reader.get(mid) < target) low = mid + 1;
            else high = mid;
        }
        return reader.get(low) == target ? low : -1;
    }
}

复杂度

若目标的插入位置为 p，调用数与时间 O(log(p+2))，辅助空间 O(1)。

上界每次翻倍，以对数次调用覆盖插入位置；随后二分每次折半，再用对数次调用缩到单点，游标存储为常数。

易错点

读到数组外的哨兵值说明上界已足够大。此时把有效答案限制在剩余区间内二分，不需要先把实际数组长度找出来。

面试追问

为什么无需寻找最后一个有效下标？ 任务只要求定位目标。越界下标与普通的大数都能安全作为二分上界，探出完整数组长度会给小位置查询增加无用访问。

Python 完整推导

核心不变量

从小上界开始不断翻倍，直到读到不小于目标的值，越界哨兵同样能结束扩张。区间中二分，再确认终点的值确实等于目标。

Python 用同时赋值推进两端。二分找到的是插入位置，可能存放大于目标的真实值，也可能是越界哨兵，所以必须最后再 reader.get(low) 检查相等。

追踪下标 1、2、4 的指数上界

步骤 当前状态 判断依据
指数扩张 查 12；get(1)=4，get(2)=9，均过小 已排除下标 0 到 2。
锁定上界 读 get(4)=17，候选区间缩为 [3,4] 17≥12，首次形成包围区间。
执行二分 get(3)=12，high=3；最后确认 12，返回 3 相等时保留中点而非继续向右。

Python 实现

class Solution:
    def search(self, reader, target: int) -> int:
        low, high = 0, 1
        # 上界逐次翻倍，第一次遇到目标、更大值或哨兵后转入二分。
        while reader.get(high) < target:
            low, high = high + 1, high * 2
        while low < high:
            mid = (low + high) // 2
            if reader.get(mid) < target:
                low = mid + 1
            else:
                high = mid
        return low if reader.get(low) == target else -1

上界每次翻倍，以对数次调用覆盖插入位置；随后二分每次折半，再用对数次调用缩到单点，游标存储为常数。

易错点

读到数组外的哨兵值说明上界已足够大。此时把有效答案限制在剩余区间内二分，不需要先把实际数组长度找出来。
