339. 嵌套列表加权和

Java 主方法把子列表送到下一批队列复杂度时间 O(N)，队列空间 O(W)，N 为整数和列表节点总数，W 为最宽层级的规模。

题目与约束

给定由整数和子列表组成的嵌套列表，计算每个整数乘所在深度后的总和，最外层深度为 1。

输入使用 NestedInteger 接口表示整数或子列表。最外层整数深度为 1，整数可为零或负数。

示例

[2,[3,[4]]] 的贡献依次为 2×1、3×2、4×3，总和 20。

Java 完整推导

核心不变量

每层开始时队列正好装着该深度的全部项，ans 已结算所有更浅层整数的贡献。

思路推导

队列的每一批正好是一层。整数直接乘当前层数，子列表的元素入队留给下一层；使用题目提供的 NestedInteger 类型访问元素。

整层元素的权重相同，因此无需给每个元素单独保存深度。先进先出队列先装最外层，本层整数立即计分，遇到列表只把直接孩子排到队尾，等深度加一后再处理。

三层嵌套各自乘上深度

步骤 当前状态 为什么这样走
第一层 2×1=2，ans=2，下一层含 3 和 [4] 外层列表中的整数权重为 1。
第二层 3×2=6，ans=8，4 加入下一层 当前批次固定，不提前取新入队的 4。
第三层 4×3=12，ans=20 队列清空，全部整数贡献已相加。

把子列表送到下一批队列

sz=q.size() 在本轮开始时取快照。addIntegers 只展开一层，后入队的项目不消耗本轮的 sz，否则深层整数会误按浅层权重计入。

Java 实现

import java.util.*;

class Solution {
    public int depthSum(List<NestedInteger> nestedList) {
        int ans = 0;
        int depth = 0;
        Queue<NestedInteger> q = new ArrayDeque<>();

        addIntegers(q, nestedList);

        // 每批恰是一层，当前深度就是这一批整数的权重。
        while (!q.isEmpty()) {
            ++depth;
            for (int sz = q.size(); sz > 0; --sz) {
                final NestedInteger ni = q.poll();
                if (ni.isInteger()) ans += ni.getInteger() * depth;
                else addIntegers(q, ni.getList());
            }
        }

        return ans;
    }

    private void addIntegers(Queue<NestedInteger> q, List<NestedInteger> nestedList) {
        for (final NestedInteger ni : nestedList) q.offer(ni);
    }
}

复杂度

时间 O(N)，队列空间 O(W)，N 为整数和列表节点总数，W 为最宽层级的规模。

每个整数或子列表各出队一次。队列最多同时保存相邻两层的部分元素，空间随最大层宽增长。

易错点

顶层整数的深度是 1。进入下一层嵌套才增加深度，列表本身不产生加权项，空列表也不应增加总和。

反例推演

输入 [1,[2]] 的结果是 1×1+2×2=5。列表本身不贡献数值，只有进入它的孩子才增加深度。

面试追问

能否先完全展平，再统一乘层数？ 展平时会丢掉每个整数自己的深度。若用深搜，可以在栈条目里携带深度再累加，BFS 则靠层边界隐式提供同样的信息。

按本轮长度处理 deque

range(len(q)) 固定这一层的个数。通过 isInteger 区分整数与列表，用 getInteger 取有符号数值；整数为零也按整数处理，不靠真值判断类型。

Python 实现

from __future__ import annotations
import collections


class Solution:
    def depthSum(self, nestedList: list[NestedInteger]) -> int:
        ans = 0
        depth = 0
        q = collections.deque()

        def addIntegers(nestedList: list[NestedInteger]) -> None:
            for ni in nestedList:
                q.append(ni)

        addIntegers(nestedList)

        # 每批恰是一层，当前深度就是这一批整数的权重。
        while q:
            depth += 1
            for _ in range(len(q)):
                ni = q.popleft()
                if ni.isInteger():
                    ans += ni.getInteger() * depth
                else:
                    addIntegers(ni.getList())

        return ans
