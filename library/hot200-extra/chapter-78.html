353. 贪吃蛇

题目与约束

实现带食物序列的贪吃蛇。移动后返回吃掉的食物数，越界或撞到身体返回 -1。

给定宽、高和按顺序出现的食物坐标；蛇起于 (0,0)，收到 U、D、L、R 单步指令，食物出现时不占蛇身。

示例

3×1 棋盘，蛇头起于最左，唯一食物在中间。依次右、右、左，得到 1、1、1。最后一步可踏入正在腾出的旧尾格。

Java 完整推导

核心不变量

每次成功移动后，双端队列按头到尾记录蛇身，集合恰好包含同一批格子，长度等于得分加一。

思路推导

双端队列存身体顺序，集合做占用检查。吃食物时保留尾部；普通移动要允许旧尾腾出，再登记新头。食物按给定次序出现。

每一手既要知道最旧的身体格，也要快速判断目标是否被身体占据。单用集合丢了次序，单用队列查碰撞需遍历蛇身。两者同步维护，先区分吃食与普通移动，才能知道旧尾这回合是否仍占格。

三格棋盘的一次折返

步骤 当前状态 为什么这样走
首步向右进食 格子按 0、1、2 编号，身体 [1,0]，得分 1 食物在 1，本轮尾 0 保留。
再向右 尾 0 移走，身体 [2,1]，得分仍为 1 没有食物，长度不变。
折返向左 目标 1 是旧尾，移尾后身体 [1,2] 头进入正在腾出的格子，合法，得分仍为 1。

一个格号同时服务队列和集合

body.peekFirst() 取头，lookup 查占用，坐标用 row*width+col 编码。边界检查先于编码。普通移动时允许 newHead 等于旧尾，然后先从集合移除旧尾再加入新头。

Java 实现

import java.util.*;

class SnakeGame {
    public SnakeGame(int width, int height, int[][] food) {
        this.width = width;
        this.height = height;
        this.food = food;
        lookup.add(getId(0, 0));
        body.offerLast(getId(0, 0));
    }

    public int move(String direction) {

        int i = body.peekFirst() / width;
        int j = body.peekFirst() % width;

        if (direction.equals("U") && --i < 0) return -1;
        if (direction.equals("L") && --j < 0) return -1;
        if (direction.equals("R") && ++j == width) return -1;
        if (direction.equals("D") && ++i == height) return -1;

        final int newHead = getId(i, j);

        // 吃到食物保留旧尾；普通移动允许新头进入即将腾空的尾格。
        if (k < food.length && i == food[k][0] && j == food[k][1]) {
            lookup.add(newHead);
            body.offerFirst(newHead);
            ++k;
            return ++score;
        }

        if (newHead != body.peekLast() && lookup.contains(newHead)) return -1;

        lookup.remove(body.peekLast());
        lookup.add(newHead);
        body.pollLast();
        body.offerFirst(newHead);
        return score;
    }

    private int width;
    private int height;
    private int score = 0;
    private int k = 0;
    private int[][] food;
    private Set<Integer> lookup = new HashSet<>();
    private Deque<Integer> body = new ArrayDeque<>();

    private int getId(int i, int j) {
        return i * width + j;
    }
}

复杂度

每一步平均 O(1)，蛇身与占用表占 O(L)，L 为当前长度。

每步只操作双端队列两端并做常数次平均 O(1) 的哈希查找。除已有的食物序列外，存储与蛇身长度成正比。

易错点

吃到食物这一回合尾巴不动。普通移动时尾巴会腾出格子，因此蛇头走进原尾格是否合法，要在区分这两种回合后判断。

面试追问

先把新头加入集合再删除旧尾会怎样？ 当新头就是旧尾时，删除会把新头的占用记录也抹掉，之后再撞这一格可能漏报。

旧尾格何时允许新头进入

self.body 的左端始终是头，右端是尾。self.k 只指向当前有效食物；增长时 appendleft 而不 pop，普通移动才同时操作两端。

Python 实现

from __future__ import annotations
import collections


class SnakeGame:
    def __init__(self, width: int, height: int, food: list[list[int]]):
        self.width = width
        self.height = height
        self.food = food
        self.score = 0
        self.k = 0
        self.lookup = set([self.getId(0, 0)])
        self.body = collections.deque([self.getId(0, 0)])

    def move(self, direction: str) -> int:

        i = self.body[0] // self.width
        j = self.body[0] % self.width

        if direction == "U":
            i -= 1
            if i < 0:
                return -1
        if direction == "L":
            j -= 1
            if j < 0:
                return -1
        if direction == "R":
            j += 1
            if j == self.width:
                return -1
        if direction == "D":
            i += 1
            if i == self.height:
                return -1

        newHead = self.getId(i, j)

        # 吃到食物保留旧尾；普通移动允许新头进入即将腾空的尾格。
        if self.k < len(self.food) and i == self.food[self.k][0] and j == self.food[self.k][1]:
            self.lookup.add(newHead)
            self.body.appendleft(newHead)
            self.k += 1
            self.score += 1
            return self.score

        if newHead != self.body[-1] and newHead in self.lookup:
            return -1

        self.lookup.remove(self.body[-1])
        self.lookup.add(newHead)
        self.body.pop()
        self.body.appendleft(newHead)

        return self.score

    def getId(self, i: int, j: int) -> int:
        return i * self.width + j
