358. K 距离间隔重排字符串

题目与约束

重新排列小写字母，使相同字符的下标之差至少 k，无法实现时返回空串。

输入只含小写英文字母，k 为非负间隔。输出须使用原来全部字符且不插空位，相同字母的下标之差至少为 k。

示例

aabbc、k=3 可排成 abcab，两对重复字母的下标差都是 3。aaab、k=3 则无法安放第三个 a。

Java 完整推导

核心不变量

放完前 i 个字符后，count 为各字符余量，valid 记录其下次可用下标，已放前缀的间距全部合法。

思路推导

对每种字符记录剩余次数和下一次允许使用的位置。在当前已冷却的字符中优先选剩余最多者，尽早消化最难安排的重复字母。

高频字符需要在剩余后缀里找到更多相隔 k 的位置，越晚开始排它，留下的可用位置越少。每个下标先排除仍在冷却的字符，再从合格者中优先消化最多的剩余次数。平局可以任取，代码按字母序决定。

把两组重复字母错开三个下标

步骤 当前状态 为什么这样走
选首字母 aabbc，i=0，放 a，剩余 a:1、b:2、c:1，a 最早 3 a、b 同为最高频，代码先挑 a。
填冷却间隔 i=1 放 b，i=2 放 c，前缀 abc a 和 b 冷却至下标 3、4。
排完余项 i=3 放 a，i=4 放 b，结果 abcab 两次 a、两次 b 的下标差都恰为 3。

在两个长度 26 的数组中选字母

count 保存剩余频次，valid 保存下一次可用下标。若在 i 放入 a，下次只能在 i+k 或之后再放；getBestLetter 返回星号表示当前下标没有合法填法。

Java 实现

class Solution {
    public String rearrangeString(String s, int k) {
        final int n = s.length();
        StringBuilder sb = new StringBuilder();
        int[] count = new int[26];

        int[] valid = new int[26];

        for (final char c : s.toCharArray()) ++count[c - 'a'];

        // 在冷却已结束的字符中优先选剩余数量最多的一个。
        for (int i = 0; i < n; ++i) {
            final char c = getBestLetter(count, valid, i);
            if (c == '*') return "";
            sb.append(c);
            --count[c - 'a'];
            valid[c - 'a'] = i + k;
        }

        return sb.toString();
    }

    private char getBestLetter(int[] count, int[] valid, int index) {
        int maxCount = -1;
        char bestLetter = '*';

        for (char c = 'a'; c <= 'z'; ++c)
            if (count[c - 'a'] > 0 && count[c - 'a'] > maxCount && index >= valid[c - 'a']) {
                bestLetter = c;
                maxCount = count[c - 'a'];
            }

        return bestLetter;
    }
}

复杂度

小写字母表大小为 26，时间 O(26n)，计数与冷却状态 O(26)。当前两种实现的答案缓冲占 O(n)，Java 还创建 O(n) 的输入字符副本。

每个下标遍历一次固定的 26 字母表。计数和冷却数组大小固定，Java 的 toCharArray 另产生 O(n) 临时字符数组，答案缓冲也需要 O(n)。

易错点

每次取出一个字符后，它必须跨过 k 个下标间距才能再次使用。若还有未放字符但此刻没有任何字符可选，说明当前输入无法满足间距。

面试追问

为什么不能像任务调度那样等待一个空闲时间片？ 要返回的是原串字符的一个排列，不能插入空位。剩余字符全部处于冷却时，即告失败。

用 Counter 表示余量与冷却结束位置

Counter 对未出现键返回零，因此每个字母初始可用下标都是零。ans 只放已确定前缀，选中字符后同步扣频并设置 valid，下一轮再按新的条件扫描字母。

Python 实现

from __future__ import annotations
import collections
import string


class Solution:
    def rearrangeString(self, s: str, k: int) -> str:
        n = len(s)
        ans = []
        count = collections.Counter(s)

        valid = collections.Counter()

        def getBestLetter(index: int) -> str:
            maxCount = -1
            bestLetter = "*"

            for c in string.ascii_lowercase:
                if count[c] > 0 and count[c] > maxCount and index >= valid[c]:
                    bestLetter = c
                    maxCount = count[c]

            return bestLetter

        # 在冷却已结束的字符中优先选剩余数量最多的一个。
        for i in range(n):
            c = getBestLetter(i)
            if c == "*":
                return ""
            ans.append(c)
            count[c] -= 1
            valid[c] = i + k

        return "".join(ans)
