186. 反转字符串中的单词 II

Java 主方法沿空格修复三个单词复杂度长度 n；时间 O(n)，辅助空间 O(1)。
Python 主方法沿空格修复三个单词复杂度长度 n；时间 O(n)，辅助空间 O(1)。

题目与约束

在字符数组内原地调换单词次序，各单词内的字母保持原顺序。输入词间以一个空格分隔。

传入可修改的字符数组。单词间恰有一个空格，无首尾空格；接口要求在原数组中完成操作。

示例

字符序列 we go now 先整段翻为 won og ew，再逐词翻转，得到 now go we。

Java 完整推导

核心不变量

第二次扫描时，i 左侧已处理的词已处于最终位置和方向，[i,j) 是本次要恢复的整词。

思路推导

整段反转同时颠倒词序与字母顺序，第二次只反转各词即可抵消后一种变化。最后一个词后面没有空格，也要处理。

把一个词看成一块，整串镜像已经把每块搬到了最终的位置，只差方向。第二遍的每次交换都限制在一块内，所以前面已经修好的词不会再移动。两个指针单向扫过数组，交换次数至多与字符数成正比。

Java 的 char[] 允许直接覆盖。reverse 的左右端点都包含在内，而找词用的是半开区间 [i,j)，交给 reverse 时右端必须减一。完成一个词后 i 追上 j，再跳过空格。

沿空格修复三个单词

步骤 当前状态 判断依据
整段镜像 we go now → won og ew 每个词已经占据正确的区间。
修复首词 [0,3) 的 won → now，得到 now og ew 交换首尾后，第一个词可以永久跳过。
修复后两词 [4,6) 的 og → go；[7,9) 的 ew → we 指针抵达末尾，最终为 now go we。

Java 实现

import java.util.*;

class Solution {
    public void reverseWords(char[] s) {
        // 先反转整个数组，再逐词反转以恢复单词内部顺序。
        reverse(s, 0, s.length - 1);
        reverseWords(s, s.length);
    }

    private void reverse(char[] s, int l, int r) {
        while (l < r) {
            final char c = s[l];
            s[l++] = s[r];
            s[r--] = c;
        }
    }

    private void reverseWords(char[] s, int n) {
        int i = 0;
        int j = 0;

        while (i < n) {
            while (i < j || i < n && s[i] == ' ') ++i;
            while (j < i || j < n && s[j] != ' ') ++j;
            reverse(s, i, j - 1);
        }
    }
}

复杂度

长度 n；时间 O(n)，辅助空间 O(1)。

整段与逐词交换各只触及每个字符常数次，游标和交换临时量的个数不随 n 增长。

易错点

整串翻转后，每个单词内部也变成了逆序。扫描到最后一个字符时要把最后一段一并翻转，可以把数组末尾当作一个虚拟空格。

反例推演

输入 a bc，只翻转全数组会得到 cb a。第二遍必须把最后一个词也当作完整区间处理；用数组长度作右开端点，便无需给原数组追加空格。

面试追问

能不能直接 split 后倒序拼起来？ 这样可以得到同样的字符序列，但会创建词列表和新的结果串。题目要求修改原数组，两次翻转只需一个交换位置的临时量。

Python 完整推导

核心不变量

第二次扫描时，i 左侧已处理的词已处于最终位置和方向，[i,j) 是本次要恢复的整词。

思路推导

整段反转同时颠倒词序与字母顺序，第二次只反转各词即可抵消后一种变化。最后一个词后面没有空格，也要处理。

把一个词看成一块，整串镜像已经把每块搬到了最终的位置，只差方向。第二遍的每次交换都限制在一块内，所以前面已经修好的词不会再移动。两个指针单向扫过数组，交换次数至多与字符数成正比。

Python 用列表元素的同时赋值交换两端，闭包直接操作调用者的 s。j 指向分隔符或数组末端；即使最后一个词没有空格，j 也会到达 len(s)，最后一次翻转仍然有效。

沿空格修复三个单词

步骤 当前状态 判断依据
整段镜像 we go now → won og ew 每个词已经占据正确的区间。
修复首词 [0,3) 的 won → now，得到 now og ew 交换首尾后，第一个词可以永久跳过。

Python 实现

from __future__ import annotations


class Solution:
    def reverseWords(self, s: list[str]) -> None:
        def reverse(l: int, r: int) -> None:
            while l < r:
                s[l], s[r] = s[r], s[l]
                l += 1
                r -= 1

        def reverseWords(n: int) -> None:
            i = 0
            j = 0

            while i < n:
                while i < j or (i < n and s[i] == " "):
                    i += 1
                while j < i or (j < n and s[j] != " "):
                    j += 1
                reverse(i, j - 1)

        # 先反转整个数组，再逐词反转以恢复单词内部顺序。
        reverse(0, len(s) - 1)
        reverseWords(len(s))

复杂度

长度 n；时间 O(n)，辅助空间 O(1)。

整段与逐词交换各只触及每个字符常数次，游标和交换临时量的个数不随 n 增长。
