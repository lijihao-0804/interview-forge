298. 二叉树最长连续序列

题目与约束

在二叉树中寻找最长的向下路径，要求下一节点恰好比前一节点大一。

给定一棵可能为空的二叉树。路径必须从祖先向后代逐边前进，长度按节点数计算。

示例

一条从根到叶的路径是 5→6→2→3→4。在 2 处断开重记，后半段提供最长长度 3。

Java 完整推导

核心不变量

栈中每项的长度是以该项节点结尾的最长向下连续后缀，best 保存所有已处理节点的最大后缀长度。

思路推导

栈中每一项保存节点和以它结尾的连续长度。弹出节点时更新答案，再分别检查左右子节点：子值恰好比父值大一就延长，否则从子节点重新计为 1。每条路径都有自己的长度，单侧深树也无需递归。

路径只沿父子方向，可以在每个节点问一个局部问题：以这个节点结尾的最长合法后缀有多长？只有父值比它恰小一时才能接上父亲的后缀。保存全局最大值后，祖先路径早先的数字就不必再带在栈里。

在节点 2 处重新起跑

步骤 当前状态 为什么这样走
延长根部路径 5 的长度 1，6 的长度 2，best=2 6 恰为 5+1。
从断点重开 到 2 时 length=1，best=2 2 不等于 6+1，之前的两项不能保留。
形成新纪录 2→3→4 的长度依次 1、2、3，best=3 新后缀连续两次延长，超过原纪录。

给每个节点配一份 Path

Path(node,length) 把节点与它自己那条连续后缀绑定。右孩子先压栈，左孩子先弹出。比较前把父值提升到 long，避免在整型最大值处加一回绕。

Java 实现

import java.util.ArrayDeque;
import java.util.Deque;

class Solution {
    private record Path(TreeNode node, int length) {}

    public int longestConsecutive(TreeNode root) {
        if (root == null) return 0;
        Deque<Path> stack = new ArrayDeque<>();
        stack.push(new Path(root, 1));
        int best = 0;
        while (!stack.isEmpty()) {
            Path path = stack.pop();
            TreeNode node = path.node();
            best = Math.max(best, path.length());
            for (TreeNode child : new TreeNode[] {node.right, node.left}) {
                if (child == null) continue;
                // 当前节点的左右分支各自继承或重置连续长度。
                int length = child.val == (long) node.val + 1 ? path.length() + 1 : 1;
                stack.push(new Path(child, length));
            }
        }
        return best;
    }
}

复杂度

n 个节点各处理一次，时间 O(n)。显式深搜栈最多保留每层一个待访问分支，辅助空间 O(h)，h 为树高。

每个节点进出栈一次。深搜沿一侧深入时，每层最多留下一个尚待访问的旁支，所以栈容量由树高控制。

易错点

路径方向固定从父到子，而且子值必须恰好等于父值加一。当前连续段断掉时，孩子仍可作为下一段的起点，长度重置为 1。

反例推演

路径 1→3→4 的最长连续段有 2 个节点。1→3 断开时，应把 3 当作新段的起点，不能清零后跳过当前节点。

面试追问

能把左孩子到父亲再到右孩子拼成更长的路径吗？ 本题限定向下走。左右分支没有祖先继承关系，各自更新最大值即可。

让左右分支独立继承长度

栈条目 (node, length) 自带该分支的长度，每个孩子独立计算 next_length。不能在一个共享的 length 上为左、右孩子先后加一，否则第二条分支将继承第一条的长度。

Python 实现

from __future__ import annotations


class Solution:
    def longestConsecutive(self, root: TreeNode | None) -> int:
        if root is None:
            return 0
        stack = [(root, 1)]
        best = 0
        while stack:
            node, length = stack.pop()
            best = max(best, length)
            for child in (node.right, node.left):
                if child is not None:
                    # 遇到断点，从这个子节点重新开始。
                    next_length = length + 1 if child.val == node.val + 1 else 1
                    stack.append((child, next_length))
        return best
