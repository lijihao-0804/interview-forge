277. 搜寻名人

本题学习状态正在读取学习记录…下次复习：—

Java 主方法先淘汰候选再核对双向关系复杂度n 人；时间及查询次数 O(n)，辅助空间 O(1)。
Python 主方法先淘汰候选再核对双向关系复杂度n 人；时间及查询次数 O(n)，辅助空间 O(1)。

题目与约束

n 人中，名人必须被其他所有人认识，同时不认识其他任何人。只能调用 knows(a,b)，返回名人编号或 −1。

人员编号 0 到 n−1，只能调用 knows(a,b) 查询有向认识关系。排除本人，返回被所有人认识且不认识任何其他人的编号，不存在则返回 −1。

示例

0、1 都认识 2，2 既不认识 0 也不认识 1。无需限制 0 与 1 的关系，名人是 2。

Java 完整推导

核心不变量

每次挑战后，已检查前缀中除 candidate 外的所有人都已被一条具体认识关系排除。

思路推导

逐人比较，若候选认识新人，旧候选出局，否则新人出局。最后仅余一个可能候选，还须逐一验证认识与被认识两个方向。

每次询问 knows(a,b) 都可让两人中的一个失去名人资格。若为真，a 认识他人而出局；若为假，b 没被所有人认识而出局。逐步淘汰只需保留一个候选，但没有任何事实保证名人存在，因此最后要验证候选的全部条件。

Java 的 candidate 代表当前前缀中唯一尚有可能成为名人的人。第一遍从 1 开始逐个挑战，第二遍跳过 candidate 自己，分别查它是否对外认识人、是否有别人不认识它。

先淘汰候选再核对双向关系

步骤 当前状态 判断依据
比较 0 与 1 若 0 认识 1 则保留 1，否则保留 0 两种可能都只剩一个候选。
与 2 比较 不论候选是 0 或 1，都认识 2；candidate=2 原候选出局。
验证候选 0→2、1→2 为真，2→0、2→1 为假 两个方向均满足，返回 2。

Java 实现

public class Solution extends Relation {
    public int findCelebrity(int n) {
        // 第一步：淘汰法找出唯一候选人
        int candidate = 0;
        // 每次询问淘汰一个人，留下的唯一候选仍需要完整验证。
        for (int i = 1; i < n; i++) {
            if (knows(candidate, i)) {
                // candidate 认识 i，说明 candidate 不可能是名人
                candidate = i;
            }
        }

        // 第二步：验证候选人是否真的是名人
        for (int i = 0; i < n; i++) {
            if (i == candidate) {
                continue;
            }
            // 候选人不能认识别人；且别人必须认识候选人
            if (knows(candidate, i) || !knows(i, candidate)) {
                return -1;
            }
        }
        return candidate;
    }
}

复杂度

n 人；时间及查询次数 O(n)，辅助空间 O(1)。

候选筛选 n−1 次查询，验证最多 2(n−1) 次查询，总数线性，只保存候选编号。

易错点

第一轮每次询问都能排除一个人，却只能留下候选人。最后要分别验证候选人不认识别人，以及所有其他人都认识候选人。

反例推演

候选人不认识任何人仍可能不是名人。例如 0、1 互不认识：仅凭淘汰阶段最后留下一个人不能证明所有人都认识他。

面试追问

如果所有人都不认识别人，第一轮会得到正确答案吗？ n>1 时它仍会留下某个候选，但此人也没有被其他人认识，第二轮才能识别全体均非名人。

步骤 当前状态 判断依据

Python 实现

class Solution:
    def findCelebrity(self, n: int) -> int:
        # 淘汰法找唯一候选人
        candidate = 0
        # 每次询问淘汰一个人，留下的唯一候选仍需要完整验证。
        for i in range(1, n):
            if knows(candidate, i):
                candidate = i  # candidate 认识 i，淘汰 candidate
        # 验证候选人
        for i in range(n):
            if i == candidate:
                continue
            if knows(candidate, i) or not knows(i, candidate):
                return -1
        return candidate

n 人；时间及查询次数 O(n)，辅助空间 O(1)。

候选筛选 n−1 次查询，验证最多 2(n−1) 次查询，总数线性，只保存候选编号。

易错点

第一轮每次询问都能排除一个人，却只能留下候选人。最后要分别验证候选人不认识别人，以及所有其他人都认识候选人。

反例推演
