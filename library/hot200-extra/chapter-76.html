348. 设计井字棋

难度中等专题设计题单位置第 176 位
Java 主方法用有符号目标值判断胜者复杂度初始化时间和空间 O(n)，每步判断 O(1)。
Python 主方法独立检查两条对角线复杂度初始化时间和空间 O(n)，每步判断 O(1)。

题目与约束

实现 n×n 井字棋。在每次合法落子后返回赢家编号，尚无人连成整行、整列或对角线时返回 0。

棋盘为 n×n，两玩家在空格上合法落子，决出胜者后对局结束。每次返回 0 或获胜者编号。

示例

2×2 上依次由玩家 1 下 (0,0)，玩家 2 下 (0,1)，玩家 1 下 (1,1)。最后一步使主对角线上都是玩家 1，返回 1。

Java 完整推导

核心不变量

在尚未结束的对局中，每条线的计数等于玩家 1 的子数减玩家 2 的子数；绝对值达到 n 就能判胜。

思路推导

把两名玩家记为 +1 与 −1，单次落子只影响一行、一列以及可能经过的对角线。某条线累计值达到 ±n 才能是同一方占满。

每步扫描整盘会检查许多与新落子无关的位置。把每条获胜线看成 n 个取值在 −1、0、1 的格子，和若为 n，则每项只能为 1；和为 −n 的情形对称。维护受影响线的和就能直接判胜。

二阶棋盘主对角线决胜

步骤 当前状态 为什么这样走
玩家 1 开局 (0,0) 加 1，diag=1，尚未达到 2 单个棋子不能占满二格线。
玩家 2 落子 (0,1) 加 −1，antiDiag=−1，第 0 行净和 0 这一手不在主对角线。
玩家 1 获胜 (1,1) 加 1，diag=2，返回玩家 1 主对角线的两格都属于玩家 1。

用有符号目标值判断胜者

target 取当前玩家的有符号胜线值，行列用两个 int 数组。对角线命中时可立即返回，因为合法对局在第一次出现胜者时结束。

Java 实现

class TicTacToe {
    public TicTacToe(int n) {
        this.n = n;
        rows = new int[n];
        cols = new int[n];
    }

    public int move(int row, int col, int player) {
        final int toAdd = player == 1 ? 1 : -1;
        final int target = player == 1 ? n : -n;

        // 一次落子只影响所在行列与经过该格的对角线。
        if (row == col) {
            diag += toAdd;
            if (diag == target) return player;
        }

        if (row + col == n - 1) {
            antiDiag += toAdd;
            if (antiDiag == target) return player;
        }

        rows[row] += toAdd;
        if (rows[row] == target) return player;

        cols[col] += toAdd;
        if (cols[col] == target) return player;

        return 0;
    }

    private final int n;

    private int[] rows;
    private int[] cols;
    private int diag = 0;
    private int antiDiag = 0;
}

复杂度

初始化时间和空间 O(n)，每步判断 O(1)。

只保存 n 个行和、n 个列和及两条对角线和。每一手最多修改四个计数，与棋盘边长无关。

易错点

一手落子至多影响一行、一列和两条对角线。奇数棋盘的中心同时位于主副对角线，两项都要更新。

反例推演

在 3×3 棋盘，(0,0)、(1,1)、(2,2) 同属主对角线；中心 (1,1) 也属于副对角线。使用互斥的判断更新两条对角线会漏掉一条。

面试追问

如果还要拒绝重复落子呢？ 行列计数无法指出具体哪个格已占用，需增加已落子坐标集合或棋盘。原接口假定每一手合法。

Python 实现

from __future__ import annotations


class TicTacToe:
    def __init__(self, n: int):
        self.n = n

        self.rows = [0] * n
        self.cols = [0] * n
        self.diag = 0
        self.antiDiag = 0

    def move(self, row: int, col: int, player: int) -> int:
        toAdd = 1 if player == 1 else -1
        target = self.n if player == 1 else -self.n

        # 一次落子只影响所在行列与经过该格的对角线。
        if row == col:
            self.diag += toAdd
            if self.diag == target:
                return player

        if row + col == self.n - 1:
            self.antiDiag += toAdd
            if self.antiDiag == target:
                return player

        self.rows[row] += toAdd
        if self.rows[row] == target:
            return player

        self.cols[col] += toAdd
        if self.cols[col] == target:
            return player

        return 0
