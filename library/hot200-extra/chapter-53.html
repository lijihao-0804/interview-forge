285. 二叉搜索树中的中序后继

题目与约束

给出严格二叉搜索树和树中的节点 p，找中序遍历中紧跟 p 的节点；没有后继时返回空。

给定严格二叉搜索树及树中的节点 p。返回节点引用，p 为最大值时返回空。

示例

根 8 的左子为 3，3 的右子为 6。查询 6，路径从 8 左转，经过 3、6 后走到空，最小的大于 6 的候选是 8。

Java 完整推导

核心不变量

successor 是迄今经过的节点中严格大于 p 且值最小者，潜在更优候选只在当前子树内。

思路推导

把后继看作严格大于 p.val 的最小值。从根向下，遇到更大的值就先保存为候选，再去左侧寻找更小者；否则去右侧。走到空指针后返回最后保存的候选。

完整中序遍历能把所有值排好序，但查询只需要比 p 大的第一个值。当根大于 p 时，它的右子树比该根还大，无法改善当前候选；根不大于 p 时，整个左子树都可排除。每次判断都排除一棵子树。

追踪值 6 的后继

步骤 当前状态 为什么这样走
在根留下候选 p=6，root=8，successor=8 8 大于 6，去左边寻找更小候选。
排除左侧 root=3，successor=8，转向右子 6 3 和它的左子树都过小。
越过目标 root=6，右侧为空，返回节点 8 相等不满足严格后继条件。

用节点引用保留祖先候选

用 TreeNode successor 保存节点对象，以便直接返回。向左走前更新候选，向右走时保留之前的候选；即便 root 最终指向 null，祖先节点仍由 successor 持有。

Java 实现

class Solution {
    public TreeNode inorderSuccessor(TreeNode root, TreeNode p) {
        TreeNode successor = null;
        while (root != null) {
            if (root.val > p.val) {
                successor = root;
                root = root.left;
            } else {
                // 当前节点和它的左子树都不大于目标。
                root = root.right;
            }
        }
        return successor;
    }
}

复杂度

时间 O(h)，h 为树高。只维护当前节点和候选指针，额外空间 O(1)。

每轮指针下降一层，平衡树约 log n 层，单链形树可达 n 层。迭代不占递归栈。

易错点

查询目标本身不能充当它的中序后继。沿搜索路径保留大于目标的最小候选，若目标已经是树中的最大值，结果就是空。

反例推演

若树中目标是最大值 7，沿查找路径从未遇到严格更大的祖先，则后继为空。返回最近访问节点会把 7 本身误作后继。

面试追问

p 有右子树时后继是谁？ 是右子树沿左指针走到底的节点。如果 p 没有右子树，答案才来自祖先中最近一次向左转的位置。

搜索路径与空候选

循环中 root 是尚未排除的子树入口，successor 是已离开路径中最小的合格值对应的节点。遇到目标本身仍去右侧寻找严格更大的节点。

Python 实现

from __future__ import annotations


class Solution:
    def inorderSuccessor(self, root: TreeNode, p: TreeNode) -> TreeNode | None:
        successor = None
        while root:
            if root.val > p.val:
                successor = root
                root = root.left
            else:
                # 后继只能位于右侧。
                root = root.right
        return successor

时间 O(h)，h 为树高。只维护当前节点和候选指针，额外空间 O(1)。

每轮指针下降一层，平衡树约 log n 层，单链形树可达 n 层。迭代不占递归栈。
