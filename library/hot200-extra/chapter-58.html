题目与约束

双方轮流把相邻两个加号改成减号，无合法动作的一方输，判断先手能否保证获胜。

给定由加减号组成的局面，双方轮流翻一对相邻加号，被迫无棋可走者输。返回最优对弈时先手是否可赢。

示例

++++ 的先手翻中间两格得到 +--+，对手没有相邻加号，因此先手必胜。

Java 完整推导

核心不变量

计算长度 l 前，所有更短连续段的 Grundy 数已知，一次落子只会产生两个这样的短段。

思路推导

把减号分隔的每段连续加号看作一个独立子游戏。长度 L 的一段翻掉两格后分成左右两段，可达状态的值是左右 Grundy 数的异或；取这些值中没有出现的最小非负整数，得到该长度的 Grundy 数。整局所有段的异或为零是败态，非零是胜态。

若直接递归枚举整串，每次翻转都会重新处理与该处无关的段。任意一手只在一个连续段中操作，所以把每种段长换成一个可异或组合的 Grundy 数。其值是所有一步可达值中缺少的最小非负整数（mex），确保非零组合存在一步可走到零，零组合则只能走到非零。

四个连续加号的胜负值

步骤 当前状态 为什么这样走
建立小段值 G(0)=G(1)=0，G(2)=mex{0}=1 两格一起消去，后继只剩空段。
计算三格 G(3)=mex{0}=1 无论翻左边还是右边，余下单格均无合法动作。
计算四格 后继异或值依次 1、0、1，G(4)=2 中间一对翻掉成为 +--+，给对手零值，先手赢。

逐长度计算 mex

grundy[0] 和 grundy[1] 默认零，两者均无棋可走。按 length 递增填表时，两侧长度都小于当前长度，reachable 中的每一个值都来自已算好的两个表项。

Java 实现

import java.util.*;

class Solution {
    public boolean canWin(String currentState) {
        String[] runs = currentState.split("-");
        int longest = 0;
        for (String run : runs) longest = Math.max(longest, run.length());
        int[] grundy = new int[longest + 1];
        for (int length = 2; length <= longest; length++) {
            // 翻掉两个相邻加号后，左右两段独立，后继局面的值取异或。
            Set<Integer> reachable = new HashSet<>();
            for (int left = 0; left < length - 1; left++)
                reachable.add(grundy[left] ^ grundy[length - left - 2]);
            while (reachable.contains(grundy[length])) grundy[length]++;
        }
        int value = 0;
        for (String run : runs) value ^= grundy[run.length()];
        return value != 0;
    }
}

复杂度

长度 n，最长连续段 g，时间 O(n+g²)。拆分字符串与表合计占 O(n+g) 空间。

每种长度 l 有 l−1 个起点，最长段以内的枚举次数为等差数列之和。每轮的后继集合只为当前长度保留。

易错点

一对加号翻掉后，相邻的减号把剩下的连续加号分成独立段。判断胜负时要组合所有段的状态，不能只看最长一段。

面试追问

可以把各段的胜负直接做“或”吗？ 例如 ++-++ 的两段单独都能先手赢，但先手消去一段，后手消去另一段，先手反而输。两段值为 1，异或结果为零。

用可达异或值集合填表

集合推导枚举被翻转的一对左边有几个加号，右长为 length-left-2。while 从零逐一检查求 mex，最后对各段长度的表值异或，同长度的两个段可以相互抵消。

Python 实现

from __future__ import annotations


class Solution:
    def canWin(self, currentState: str) -> bool:
        runs = [len(run) for run in currentState.split("-") if run]
        grundy = [0] * (max(runs, default=0) + 1)
        for length in range(2, len(grundy)):
            # 翻掉两个相邻加号后，左右两段独立，后继局面的值取异或。
            reachable = {grundy[left] ^ grundy[length - left - 2] for left in range(length - 1)}
            while grundy[length] in reachable:
                grundy[length] += 1
        value = 0
        for length in runs:
            value ^= grundy[length]
        return value != 0
