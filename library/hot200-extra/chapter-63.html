800. 相似 RGB 颜色

题目与约束

为六位十六进制 RGB 颜色找一个最接近的可简写颜色；可简写要求每个通道的两个数字相同。

输入以 # 开头，后接六个十六进制数字。输出仍是六位 RGB 格式，每通道两位相同，目标为最小化三个通道的总平方误差。

示例

1020fe 的通道值为 16、32、254，最近的 17 的倍数是 17、34、255，因此输出 #1122ff。

Java 完整推导

核心不变量

完成前 t 个通道后，已选通道的误差和最小，后续选择不可能改变这部分费用。

思路推导

平方误差是三个独立通道误差之和。每个通道在 00、11、…、ff 的 16 个候选里选最近者，三个局部最优拼接成全局最优。

六位颜色看似有 16³ 种可简写候选，但目标是三项差值平方的和，固定红色的选择不会影响绿或蓝的费用。两位相同的十六进制数 dd 的数值为 16d+d=17d，所以每个通道只须在一条等距刻度上选点。

分别量化 10、20、fe

步骤 当前状态 为什么这样走
量化红色 10₁₆=16，最近 17，写 11 到 17 的差为 1，比到 0 或 34 更近。
量化绿色 20₁₆=32，最近 34，写 22 到 34 的差仅为 2。
量化蓝色 fe₁₆=254，最近 255，拼出 #1122ff 三个通道各自取最近值，平方误差总和最小。

按十六进制字符串保留位宽

parseInt(...,16) 将两个字符转为 0～255 的整数。内层扫描始终令 closest 对应迄今最小的平方差；直接追加候选字符串自然保留 00 的前导零。

Java 实现

class Solution {
    public String similarRGB(String color) {
        String[] SHORTHANDS = {
            "00", "11", "22", "33", "44", "55", "66", "77",
            "88", "99", "aa", "bb", "cc", "dd", "ee", "ff"
        };
        StringBuilder ans = new StringBuilder("#");

        // 三个通道独立，各自选择误差最小的重复十六进制数字。
        for (int i = 1; i < color.length(); i += 2) {
            final int currValue = Integer.parseInt(color.substring(i, i + 2), 16);
            String closestShorthand = findClosestShorthand(currValue, SHORTHANDS);
            ans.append(closestShorthand);
        }

        return ans.toString();
    }

    private static final int maxSimilarity = 255 * 255;

    private String findClosestShorthand(int targetValue, String[] shorthands) {
        String closest = shorthands[0];
        int minSimilarity = Integer.MAX_VALUE;

        for (final String shorthand : shorthands) {
            final int shorthandValue = Integer.parseInt(shorthand, 16);
            final int similarity = (targetValue - shorthandValue) * (targetValue - shorthandValue);
            if (similarity < minSimilarity) {
                closest = shorthand;
                minSimilarity = similarity;
            }
        }

        return closest;
    }
}

复杂度

通道数和候选数均为常量，时间与额外空间均 O(1)。

三个通道各比较固定 16 次，每个候选只有两个字符；这些数量都不会随输入变化。

易错点

每个简写颜色通道都只能取 00、11、…、ff。三个通道可以独立挑最近值，输出时要保留两位十六进制，包括前导零。

面试追问

能不用遍历 16 项吗？ 对通道整数 x 计算 (x+8) 整除 17，得到最近刻度编号。相邻刻度相距 17，整数输入不会落在正中间。

min(SHORTHANDS,key=...) 返回候选字符串本身，key 只参与排序。外层从下标 1 每次走两格，ans 中始终保存 # 和已经量化好的各通道。

Python 实现

from __future__ import annotations


class Solution:
    def similarRGB(self, color: str) -> str:
        SHORTHANDS = [
            "00",
            "11",
            "22",
            "33",
            "44",
            "55",
            "66",
            "77",
            "88",
            "99",
            "aa",
            "bb",
            "cc",
            "dd",
            "ee",
            "ff",
        ]
        ans = ["#"]

        # 三个通道独立，各自选择误差最小的重复十六进制数字。
        for i in range(1, len(color), 2):
            currValue = int(color[i : i + 2], 16)
            closestShorthand = min(SHORTHANDS, key=lambda x: (currValue - int(x, 16)) ** 2)
            ans.append(closestShorthand)

        return "".join(ans)
