369. 给单链表加一

题目与约束

正整数按高位在前的顺序存于单链表，返回给原数加一后的链表。

给定十进制单链表，每个节点存 0…9 的一位，高位在前。返回加一后的头节点，可能新增最高位。

示例

9→9→8 加一是 9→9→9；再次加一时进位穿过三位，得到 1→0→0→0。

Java 完整推导

核心不变量

扫描时 pivot 始终是已看到的最右非 9 节点，且从它之后至扫描位置的数字全为 9。到达末尾后，进位就会停在 pivot。

思路推导

在头部先放一个值为 0 的哨兵。正向扫描记下最右一个非 9 节点，把它加一，并将其后的全 9 后缀清零。若原链全是 9，最右非 9 就是哨兵，新最高位自然变成 1。

对 1→9→9，扫描停在数字 1，加一并清后缀得到 2→0→0。对 9→9→8，停在尾节点 8，加一后没有后缀需要改变。

定位最后一个非 9 节点

即使链表全是 9，pivot 也指向合法的哨兵；原链其他节点保持原有连接。

步骤 当前状态 判断依据
从哨兵开始 0→1→9→9 pivot 初始为哨兵
定位进位停止处 扫描到 1，之后两位均为 9 pivot 指向首位 1
完成加一 1 变 2、后两位清零 返回原链头，得到 2→0→0

Java 实现

class Solution {
    public ListNode plusOne(ListNode head) {
        ListNode sentinel = new ListNode(0, head);
        ListNode pivot = sentinel;
        for (ListNode node = head; node != null; node = node.next)
            if (node.val != 9) pivot = node;
        pivot.val++;
        for (ListNode node = pivot.next; node != null; node = node.next)
            node.val = 0;
        return sentinel.val == 1 ? sentinel : head;
    }
}

复杂度

时间 O(n)，辅助空间 O(1)。第一次沿链表寻找进位停止处，第二次仅遍历尾部连续 9 的后缀。

易错点

全是 9 时会产生一个新头节点，例如 99 变成 100。还要保住另一端的情况：尾部数字小于 9 时，前面的 9 根本无需参与进位。

反例推演

链表 1→9→9 加一得到 2→0→0。进位需要跨过整个连续 9 后缀；只修改最后两个节点会留下错误的百位。

面试追问

怎样避免长链导致递归栈溢出？ 加一只可能改变最右非 9 节点和其后缀。保存这个节点引用即可，无须反转链表或用栈从低位回溯。

Python 完整推导

定位最后一个非 9 节点

第二次遍历从 pivot.next 开始，只将尾部变成 0，跳过未受进位影响的高位。

步骤 当前状态 判断依据

定位进位停止处 扫描到 1，之后两位均为 9 pivot 指向首位 1
完成加一 1 变 2、后两位清零 返回原链头，得到 2→0→0

Python 实现

from __future__ import annotations

class Solution:
    def plusOne(self, head: ListNode) -> ListNode:
        sentinel = ListNode(0, head)
        pivot = sentinel
        node = head
        while node:
            if node.val != 9:
                pivot = node
            node = node.next
        pivot.val += 1
        node = pivot.next
        while node:
            node.val = 0
            node = node.next
        return sentinel if sentinel.val else head

复杂度

时间 O(n)，辅助空间 O(1)。第一次沿链表寻找进位停止处，第二次仅遍历尾部连续 9 的后缀。
