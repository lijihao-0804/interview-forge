MCP 的两层协议结构

正在读取本章记录下次复习：—
请通过“启动学习站.cmd”进入，才能写入数据库。

MCP 可以分为数据层与传输层：

8.1 数据层

数据层定义“消息是什么意思”：

  • 请求、响应和通知结构；
  • 方法名称与参数；
  • 初始化和能力协商；
  • Tools、Resources、Prompts 等协议原语；
  • 进度、取消、日志等通用能力。

8.2 传输层

传输层定义“消息如何到达对端”：

  • 如何建立连接；
  • 如何分帧；
  • 如何管理 HTTP 会话；
  • 如何承载服务器推送；
  • 远程场景如何授权。

MCP 在不同传输之上保持同一套 JSON-RPC 语义，这使 SDK 可以把业务功能与通信细节分离。
