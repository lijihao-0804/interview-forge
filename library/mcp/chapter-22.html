最终心智模型

Function Calling：
模型说“我想调用 get_weather(city=广州)”

MCP：
Host 知道去哪个 Server 找 get_weather，
如何发现它、调用它、接收结果、处理通知与协商能力。

业务系统：
真正查询天气、数据库、文件或 SaaS，并承担权限与一致性。

MCP 最重要的意义不是“让模型会调用工具”，而是让不同 AI 应用与不同上下文服务之间形成可发现、可协商、可复用的开放连接层。
