怎样读这些数字

一条记录是什么？
公司名与原职位 ID 的组合。多地点不拆条；招聘池另有标记。广告数量不等于有效 HC、预算或新增人数。
技能提及率的分母
当前集合中可可靠拆分、内容足够的独立任职要求。职责词不混入资格统计，通用政策尾文在分析时排除，原始全文仍保留。
分类有多少确定性？
主分类依据标题、原职类及少量正文复核，不是全量人工真值。宽泛算法标题可能包含后训练职责，普通后端也可能承担 Agent 工作。
学历与经验如何解释？
本科、硕士、博士是词提及，允许重叠，不是最低学历分布。独立年限字段缺失不等于经验不限。
需求清晰度衡量什么？
职责、条件、场景与交付是否写清楚，不衡量公司名气、薪酬、岗位价值或个人录用概率。规则候选和逐条审读单独标记。

覆盖限制

  • 字节采研发、产品、运营及研发大模型补集，取完显示页码仍存在跨页重复；不能当全站零遗漏。
  • 拼多多校招正文已取，16条社招卡片只保留元数据；Apple另有60条详情未取得。
  • 网易总数在采集期间变化，部分网站只有列表入口加岗位 ID 定位。中国搜索也可能返回海外地点。
  • 社区帖子是自选经验，不能计算全国转岗成功率。平台报告的统计期和定义不同，不能直接合并。
  • 数据为2026年11月17日截面。薪资缺少统一结构化口径，本页不推算跨厂均薪。
