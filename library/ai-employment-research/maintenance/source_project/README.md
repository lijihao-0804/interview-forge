# 采集代码参考快照

本目录保留2026-11-17研究使用的采集器、公共解析助手与本地导入依赖。没有复制凭据、浏览器个人资料或会话cookie。这里只冻结源代码，不执行联网采集。

在每期独立工作目录复制本目录后使用；不要在已注册历史快照中运行采集器。脚本大多按其上一级目录写入 evidence/、archives/、analysis/，请先阅读入口 main 与参数，确认输出路径。部分历史补抓/归并脚本依赖前一阶段文件，并非独立一键采集命令。每站先做小范围公开页面/接口验证，再按指南运行；遇到验证或访问限制停止并记录缺口。

可选采集依赖列在 requirements-optional.txt；应在目标项目的隔离环境安装，不修改全局Python。Playwright相关脚本需要可用浏览器，网站结构与公开接口可能变化。

完整操作口径、每期范围清单、原文留档与跨期对比步骤见交接包根目录 MAINTENANCE.md。分析/注册工具只需Python标准库，见 tools/。源文件SHA256在 source-manifest.json；更新采集器应另存版本并保留旧版。
