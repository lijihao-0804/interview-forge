# 就业数据台 · 前端与数据交接包 v4

本文件夹可整体交给网站项目执行者。它是独立静态应用，无构建步骤、无 CDN、无登录依赖，也不依赖原笔记项目或 `E:\interview-forge` 的本机路径。视觉参考后者的紫色主色、冷灰蓝背景、细边框面板、紧凑导航与明暗主题，功能独立实现。

数据截面：2026年11月17日。28,344条记录、20家有数据的雇主；28,268条有正文，28,144条独立要求可统计；15,988条规则候选，37条审读精选。76条仅有元数据，已明确标记。数字是公开渠道广告记录，不是全国HC。

## 本地查看

Windows可运行 `启动预览.cmd`。或在任意平台执行：

```sh
python tools/serve.py --port 8765
```

然后打开 `http://127.0.0.1:8765/`。本地服务只绑定回环地址。直接双击HTML会受到浏览器对Worker/fetch的文件协议限制，页面会给出启动说明。

## 已有功能

- 市场总览：技能×四方向矩阵、职位加权/公司均权切换、雇主正文覆盖、职能、城市覆盖、技能组合支持度与Lift、数据缺口。
- 岗位探索：多公司/职能/方向/城市、技能AND/OR、学历词、经验字段披露、地域、正文与资格状态、清晰度、审读、日期、关键词与排除词；条件可复制为URL。
- 可导出全部匹配CSV；收藏与最多4个岗位的全文对照只保存在当前浏览器。
- 路线对比：当前集合的技能、学历词和公司集中度，个人技能清单与未覆盖的常见提及项；不输出录用概率或简历匹配分。
- 研究结论：证据数字、解释、准备建议和适用边界；结论固定于研究截面，和实时筛选结果分开。
- 完整JD按分片读取，可下载单岗JSON；所有已采正文均保留，不将简介或缺失字段补写成全文。

## 文件结构

```text
index.html                 应用入口
assets/app.css             样式与明暗主题
assets/app.mjs             界面和交互
assets/engine.mjs          纯筛选/统计函数，便于复用
assets/worker.mjs          目录加载与后台统计
data/catalog.json         前端元数据目录
data/catalog.json.gz      预压缩目录，约3.37MB（原JSON约44MB）
data/details/*.json       按需读取的全文分片
data/corpus.ndjson.gz      后续数据分析用完整标准化语料
data/analysis.json         高级统计结果
data/editorial.json        可读研究结论与证据
data/sources.json          市场、公司业务、社区来源
data/manifest.json         数据文件清单、大小、SHA-256
reports/                   高级分析、市场/讨论/前景报告、验收与预览
tools/                     本地预览与分析/索引示例
DATA_SCHEMA.md             字段与统计口径
INTEGRATION.md             挂站和二次开发契约
package-manifest.json      整个交接包的文件清单与哈希
```

推荐先看 `INTEGRATION.md`；需要重新计算或接后端时读 `DATA_SCHEMA.md` 和 `tools/`。原始招聘API响应完整档案仍在上游调研项目中，本交接包提供独立可用的JD字段快照、来源与正文哈希，不要求部署上游原始响应或日志。

现代浏览器优先读取预压缩目录并在Worker中原生解压，不依赖服务器开启压缩；不支持该能力时回退普通JSON。全文仍按分片加载，不在首屏拉取完整语料。

## v4：技术全表与分期维护

本版冻结词典970项、26类，资格段实际检出676项。逐岗索引覆盖28,344条记录；205,056条证据偏移已和保存的原文逐条核对。全文、职责、资格分开计数，2,000个未审核长尾候选单独留档。

研究结论加入随当前筛选重算的四方向对照、城市和技术图表。固定的已审读研究判断仍明确保留截面和原分母。技术清单支持搜索、分类、资格/职责/全文分段观察与完整导出；旧合并标签继续保留，新增原子技术索引用独立版本标识，LangChain和LangGraph等分别统计。

- `data/technology-index.json`：全部已登记技术词项、分类、别名、逐岗分段命中。
- `data/technology/`：冻结词典、可追溯证据和未收录技术候选。候选需要复核，不直接算正式需求。
- `data/snapshot-registry.json` 与 `data/snapshots/`：真实期次登记、不可覆盖的原文语料与哈希；当前只有2026-11-17一个真实观测期。
- `MAINTENANCE.md`：数据抓取、范围审计、断点和每期归档、词典更新、时间对比指南。
- `maintenance/source_project/`：采集源代码和解析依赖的冻结参考快照；不含会话凭据，不是承诺所有站点持续可一键采集。
- `reports/技术需求基线与维护.html`、完整CSV：原子技术的统计表和解释。

重新处理数据不会生成新市场观测。必须新增真实采集期、保持相同词典与可比范围后，才能计算需求变化；完整性不足时只能报告本次样本变化，不能把未重现广告说成已下架。自然语言存在长尾词项，有限词典与候选队列不能保证零遗漏。

## 必须保留的解释

公司渠道范围不同，不能用记录量给公司招聘实力排名。技能提及包含必备和优先；学历词不是最低门槛。多城市可重复计入城市覆盖。规则清晰度不是岗位价值。公司均权默认仅纳入该方向可用要求≥5条的公司。去重敏感性保留公司内相同正文的确定性代表ID；不证明实际名额重复。详见页面“数据口径”。
