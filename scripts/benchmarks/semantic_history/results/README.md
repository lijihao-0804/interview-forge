## 读数边界

这里的召回表示成功工具调用的证据中包含全部目标编号。旧版未持久化结果正文，采用相同参数、消息上界和同一份不可变原文重跑同一处理器，核对线上审计记录的结果长度。新版逐字引用、正确编号和可打开的原文另行判定。完整案例记录保留模型原回答、每次调用参数、真实轮次用量、候选原文位置以及逐次检索耗时。

三词全量翻页使用的调用数可能超过产品给 Agent 的单轮和总工具预算。重复样本、顺序部署、网络负载、人工选取的题目及模型单次采样均限制外推。公网时长按发出请求至 SSE 结束计时，工具时长对每题调用求和，遇并行时不能视为公网延迟分解。工具结果 token 由本地估算。聊天供应商记录真实输入和输出 token，未提供该账户的价格或缓存命中价分项，因此未推算实际账单。CPU 本地向量检索没有外部嵌入请求。
