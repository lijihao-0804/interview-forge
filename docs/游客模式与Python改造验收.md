## 阶段一：公开阅读与邮箱注册

- 游客可直接访问首页、Hot 100、专题、学习书架及搜索，刷新和异步请求均不得自动跳转登录。
- 登录后才允许代码运行或提交、力扣连接与同步、学习进度写入、收藏、聊天、反馈提交、AI 和个人数据读取；认证必须由后端执行。匿名写接口仅限登录、注册、获取注册验证码，以及找回密码的发送验证码/重置两步；公开操作清单统一维护在 `interview_forge/core/public_api.py`。
- 登录接受用户名或注册邮箱，密码正确即可；`/api/me` 返回绑定邮箱。已绑定邮箱的账号可用邮箱验证码找回密码（重置后会话全部失效），登录后可在账号设置页更换绑定邮箱。
- 管理后台及工具箱保持管理员限制，包括路径编码、路径规范化和 Windows 大小写场景。
- 公开接口只能返回题目与目录元数据，不得包含用户进度、邮件、凭证或私人内容。
- 注册使用邮箱验证码，复用现有内部 SMTP 配置。旧邀请码不得成为公开注册绕过途径。
- 验证码需有过期时间、失败次数限制、一次性兑换、哈希存储和邮箱唯一性约束。
- 发送及注册尝试具备原子、跨工作进程的限流；涵盖邮箱冷却、IP、邮箱与全局额度，超限返回 429 与 Retry-After。
- SMTP 未配置或发送失败必须清晰反馈，不返回验证码、不暴露 SMTP 凭证。

## 阶段二：游客交互与提示

- 显示游客身份与登录、注册入口，并保留返回当前页面的地址。
- 首屏不显示虚假的个人统计；受限操作明确提示登录后使用。
- 邮件发送倒计时、网络失败、验证码失效和超限反馈可恢复。
- 用户仍可阅读题解代码；代码运行、提交及同步需要登录。
- 书架自动完成、题解进度与其他延时写入不会为游客触发私人写入。

## 阶段三：Python 完整教学模式

- 覆盖全部 100 道题，Python 模式包含对应不变量、推导、API 提示、实现、复杂度和易错点。
- 算法选择与推导一致，注明适用约束和必要的实现权衡。
- Python 可见内容不混入 Java 实现或 API；保留公共题面、导航和可视化。
- 17 个专题以及基础、算法模板支持 Python 对应内容。
- 全量代码通过语法及执行验证；链表、树、状态类和边界输入需有代表性执行用例。
- 从维护源重新构建后仍保留修改，不能只修改生成页面。
