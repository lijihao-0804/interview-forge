## 直觉：先给同一类单词贴上同一张标签

字母异位词就像同一副扑克牌洗成了不同顺序。单词表面的排列不重要，字母的种类和数量才重要。排序正好抹掉排列：`eat`、`tea`、`ate` 排完都会变成 `aet`。

把排序后的字符串当作特征码，也就是字典的键；把原单词列表当作对应的抽屉。每遇到一个单词，先做特征码，再看对应的抽屉是否已经打开：没有抽屉就建一个空列表，有抽屉就把原单词塞进去。

## 用题目样例逐个开抽屉

输入为 `["eat", "tea", "tan", "ate", "nat", "bat"]`，初始 `groups = {}`。下面每一步列出的都是 `groups` 的**完整状态**，不只显示当前抽屉；已有列表只在末尾追加新词，不会被后续的键覆盖。

1. `eat` 排序得到 `aet`。还没有这个抽屉，先创建列表并放入 `eat`。完整字典为 `{"aet": ["eat"]}`。
2. `tea` 也得到 `aet`。找到已有抽屉，直接追加。完整字典为 `{"aet": ["eat", "tea"]}`。
3. `tan` 得到 `ant`。这个键第一次出现，于是开新抽屉。完整字典为 `{"aet": ["eat", "tea"], "ant": ["tan"]}`。
4. `ate` 得到 `aet`。向原来的 `aet` 列表追加，前面的 `eat`、`tea` 仍然保留。完整字典为 `{"aet": ["eat", "tea", "ate"], "ant": ["tan"]}`。
5. `nat` 得到 `ant`。再向已有的 `ant` 列表追加。完整字典为 `{"aet": ["eat", "tea", "ate"], "ant": ["tan", "nat"]}`。
6. `bat` 得到 `abt`。此时才第一次出现这个键，于是打开第三个抽屉。最终完整字典为 `{"aet": ["eat", "tea", "ate"], "ant": ["tan", "nat"], "abt": ["bat"]}`。

最后把三个抽屉依次取出来，就是分组结果。题目允许组内和组间的返回顺序不同，因此不需要额外排序答案。

## Python 实现

```python
from typing import List


class Solution:
    def groupAnagrams(self, strs: List[str]) -> List[List[str]]:
        groups = {}
        for word in strs:
            key = "".join(sorted(word))
            if key not in groups:
                groups[key] = []  # 第一次见到这种签名才开抽屉
            groups[key].append(word)
        return list(groups.values())
```

## 这段 Python 代码要留意的细节

- `sorted(word)` 返回字符列表；`"".join(...)` 再把字符拼回字符串。排序后的字符串不可变且可哈希，适合直接作为 `dict` 的键。
- `if key not in groups` 不能省成 `groups.get(key, []).append(word)`。当键不存在时，`get` 返回的是一个临时空列表；即使往里 `append`，这个列表也没有存回字典，单词会直接从结果中丢失。
- `groups[key].append(word)` 修改的是字典中已经保存的那个列表，所以不需要再执行一次 `groups[key] = ...`。后续同键单词会连续追加到同一个抽屉。
- `list(groups.values())` 把字典的值视图转换成函数签名要求的 `List[List[str]]`。空字符串也能正常工作，因为它的排序签名就是空字符串。

## 复杂度

设单词数为 `n`，最长单词长度为 `k`。

- 时间：每个单词主要花在排序上，常用上界写作 `O(nk log k)`；空串和单字符也各需常数时间处理，不能因为没有排序工作就跳过这 `n` 次遍历。
- 空间：需要保存各组的排序签名和 `n` 个原单词引用，合计 `O(nk + n)`；处理一个单词时另需 `O(k)` 的排序临时空间。抽屉里保存的是原字符串的引用，没有重新复制每个单词。

## 补充追问：为什么计数法可以更快

如果面试官追问超长单词的优化，可以利用题目只含 26 个小写字母的条件，统计每个单词的字符频次，再把长度 26 的频次元组作为键。这样不必逐词排序：扫描所有字符需要 `O(Σ L_i)`，每个单词另用固定 26 次操作构造元组；在字母表固定时，时间复杂度为线性。代价是每个不同分组要保存一个 26 项键，额外键空间为 `O(26g)`，`g` 是分组数。

本题的普通测试规模下，排序签名已经足够直观，主解无需为了纸面上的更优复杂度换掉原有的开抽屉过程；计数法更适合作为对长字符串和复杂度追问的补充。
