## 本轮重点回归

- 历史完成轮次能幂等迁移到当前 AC/submission 读模型；
- 同一接口成功响应与数据库提交保持一致，不再出现已写入却返回 500；
- dashboard、weekly、summary 与 AC 统计统一按 Asia/Shanghai 自然日；
- 非法 Content-Length、Transfer-Encoding、非对象 JSON、敏感路径编码与代理 IP 均有防护；
- 章节页、错题本、历史页、书架、中控台和力扣页的网络请求有超时与用户可见错误恢复；
- Service Worker 只对导航请求做页面回退，不把 HTML 首页误返回给脚本、样式或接口；
- 生成器会清理已知旧产物，并在 Windows 进程池受限时安全回退串行构建；
- README、维护手册和页面提示以线上 VPS 服务为当前语境，旧 Tunnel/阶段计划标记为历史存档。

## 人工验收边界

自动检查不能替代生产验收。部署后还需确认：

- systemd 服务为 `active`，本机与公网 `/api/health` 返回 200；
- 未登录访问受保护页面会跳转登录，未登录 API 返回 401；
- 登录后完成一轮、章节完成和薄弱标记可正常写入当前账号；
- nginx 传递的真实 IP 能进入限流逻辑；
- 部署前数据备份可恢复，运行时 `data/` 未被 Git 更新覆盖。
