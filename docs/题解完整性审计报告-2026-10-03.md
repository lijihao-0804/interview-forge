## 四、根因链（每一环都有证据）

1. **原始笔记（99-原稿归档）只有 Java**：0003 归档全文仅 2 个 ```java 围栏，无 cpp/python/go——非 Java 代码不是提取丢失，是原始笔记本来就没有。
2. **多语言代码由一次性补入管线生成**：`scripts/data/extract_lang_solutions.py`（来源 A：EndlessCheng 围栏笔记；来源 B：代码随想录网页格式，4 空格缩进块 + "### 语言：" 小节）→ 产物 `tools/lang_solutions.json`。
3. **污染点 = `tools/lang_solutions.json`**：`3.cpp` 末 3 行与用户报告截断逐字一致（`// 滑动窗口：[l, r]` / `int l = 0;` / `int result = 0; // 记录最大长度`）；全库截断签名 go 26 / python 26 / cpp 18 / c 10，与 md 层发现（61 处）吻合。
4. **截断机制（来源 B 解析器）**：`extract_carl()` 以"连续 4 空格缩进行"收集代码——**遇到第一个非缩进行即停止收集**；代码随想录网页稿若存在缩进丢失/装饰行，代码即被拦腰截断，且截断块只要"看起来像代码"就会入库（`looks_like_code` 不校验完整性）。
5. **构建无条件信任 JSON**：`build_hot100` 将 JSON 的 code 原文并入 md → `build_html_site` 渲染进 HTML → 部署上线。全链无完整性校验，因此坏数据畅通无阻地到达生产。
6. **来源相关性 100%**：38 题全部标注"实现来源：代码随想录（programmercarl.com）"；标注"实现来源：经典解法实现"的小节零受损——进一步佐证截断只发生在网页抓取补入路径。

## 五、影响评估

- **学习体验**：非 Java 学习者（C++/Python/Go）在 38 题上看到的是截断代码——不可运行、逻辑断裂（如 0003 连算法主体都没出现），且代码块"看起来正常闭合"，误导性强。用户报告的 `// 记录最大长度z` 中的杂散字符即截断边界的可视化痕迹。
- **波及面**：C++ 19 / Python 21 / Go 21；按题分布集中在滑动窗口、双指针、矩阵、栈等专题（代码随想录多语言覆盖到的题）。
- **生产已受影响**：md 是构建产物源头，HTML 同步截断，线上即坏。
- **叠加效应**：与此前发现的 DNS 污染（可用性）无关但叠加放大——能打开页面的非 Java 用户看到的是断码。
- **数据资产层面**：`lang_solutions.json` 作为"提交入库供构建期使用"的数据被污染，且无校验门禁，同类问题未来仍可能发生。

## 六、修复路径建议（按依赖顺序，本轮未动手）

1. **修 `extract_carl` 的缩进收集器**：代码块收集不应以"非缩进行"为终点（改为显式小节边界 + 括号/缩进状态机），或在 flush 时校验完整性（括号平衡 + return），不完整即拒绝入库并报告——把静默截断变成显式失败。
2. **重新生成 `tools/lang_solutions.json`**：用修复后的解析器重跑（源稿路径 `E:\JAVA\AI+agent\笔记\代码随想录-Hot100` 在本机存在）；若源稿本身缺行（需抽 2-3 题对照原网页确认），则从代码随想录官网/力扣重新抓取或人工补写对应语言的完整实现。
3. **重建与部署**：`build_hot100` → `build_html_site` → `check_hot100` → 部署，覆盖 38 题的 md/HTML。
4. **加防回归门禁**：把本轮扫描器的强规则（括号平衡 + 主块 return 存在 + void 豁免）固化为 `check_hot100` 断言或独立 check 脚本——本次事故的本质是"无校验的数据管线"。
5. **复核建议**：修复后用同一扫描器复扫，目标 0 高严重度发现。

## 七、审计局限

1. 散文（推导文字）只做了"小节末行断句"检查，段落中段的截断无法由此规则发现；但损坏样本全部来自代码补入路径，散文来自原始笔记（归档完整），风险低。
2. `c` 语言块（JSON 中 10 处签名）在 md/HTML 中的呈现位置未逐一核验（部分并入 C++ 小节渲染）。
3. 括号平衡规则对"字符串内含未配对括号"的极端代码可能误报——已通过字符串剥离降低，且所有入选样本经人工抽查为真截断。
4. 未审计 02-专题聚合页与 05-可视化（它们引用/内嵌题解，修复 md 后随构建自动恢复）。
