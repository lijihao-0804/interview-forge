# 内容来源与版权边界（本地内部记录）

本项目的书架由 `scripts/build/library_catalog.py` 人工登记，构建器只处理登记项；这不是自动抓取或目录扫描流程。后续不得把权利状态不明的第三方书籍、整站抓取、图片包或视频继续纳入发布构建。

新增内容只有在确认属于项目自有创作、取得明确授权/许可证，或符合可再分发的公有领域条件后才能登记，并应记录来源、权利依据及必要署名。仅“网上可下载”或“用于学习”不构成再分发许可。

2026-09-19 的本地审查报告曾记录仓库含约 1.7GB 第三方抓取内容，并特别指出《小林面试笔记》《agent 面经》等来源的分发风险。本轮不删除既有文件、不重写 Git 历史，也不扩充相关来源；现存材料仍需单独决定是否下架或从公开历史中移除。当前登记继续构建不应被解释为版权审核通过。

本文件仅作为本地开发复盘和操作边界，不作为公开仓库的版权声明或许可证文本；如需对外声明，应另行核验来源、授权和署名要求后，经明确同意再发布。
